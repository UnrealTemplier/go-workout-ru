## 2. Находки скаута

### G-01 — VERIFIED
- **Где / цитата:** `S2/018`, «Код решения»: `fmt.Printf("fn:  значение = %v, тип = %T\n", fn, fn)`.
- **Вердикт:** `go vet` ругается, как заявил скаут. Код компилируется и работает, но не проходит vet-проверку в CI. Адрес `0x48a240` в «Терминале» недетерминирован: у меня указатели выглядели как `0x20cb…`, а `fn` получает адрес, зависящий от сборки.
- **Доказательство:** `go vet` (go1.27.1): `main.go:18:38: fmt.Printf format %v arg fn is a func value, not called`.
- **Предлагаемая правка:** в код заменить вывод `fn` на `fmt.Printf("fn:  тип = %T, nil = %v\n", fn, fn == nil)` (проверено: `go vet` чисто, вывод детерминирован: `fn:  тип = func(int) bool, nil = false`). Если нужен адрес, использовать `%p`: `fmt.Printf("fn:  адрес = %p, тип = %T\n", fn, fn)`. Строку `fn:` в блоке «Терминал» обновить. Отметить в «Подводных камнях», что адреса указателей в выводе произвольные.

### G-02 — VERIFIED
- **Где / цитата:** `S2/025`: `fmt.Println("--- Вывод через %s (интерпретированный): ---")` и такая же строка с `%q`.
- **Вердикт:** подтверждено, vet жалуется на оба вызова.
- **Доказательство:** `main.go:8:2: fmt.Println call has possible Printf formatting directive %s`; `main.go:11:2: ... directive %q`.
- **Предлагаемая правка:** заменить на `fmt.Printf("--- Вывод через %%s (интерпретированный): ---\n")` и `fmt.Printf("--- Вывод через %%q (безопасный экранированный): ---\n")`. Вывод в «Терминале» не меняется.

### G-04 — VERIFIED
- **Где / цитата:** `S4/048` («Подводные камни»): «`fmt.Sprintf` рассчитывает ширину `%-12s` по байтам, а не по рунам…»; `S5/059`: «В пакете `fmt` ширина `%16s` считает байты».
- **Вердикт:** утверждение ложное, ширина считается в рунах. Таблицы из «Терминала» выровнены именно по рунам. Скаут прав по существу, но его цитата из `doc.go` («…or in bytes for %x…») в go1.27.1 отсутствует. Метод называется `padString`, а не `fmt_s`.
- **Доказательство:** `go1.27.1 src/fmt/doc.go`: «Width and precision are measured in units of Unicode code points, that is, runes.»; `src/fmt/format.go`, `padString`: `width := f.wid - utf8.RuneCountInString(s)`. Запуск: `"Москва"` (12 байт, 6 рун): `[%10s]` → `[    Москва]`, `[%-10s]` → `[Москва    ]`, `[%.3s]` → `[Мос]`, `[%6s]` → `[Москва]`. Для `"日本"` с `%4s` выдано два пробела: ширина считается в рунах, а не в ячейках терминала.
- **Предлагаемая правка:**
  - `S4/048`: заменить пункт на «`%-12s` считает ширину в **рунах** (`utf8.RuneCountInString`), поэтому кириллица выравнивается корректно. Визуально сдвиг возможен только для символов не в одну ячейку терминала: CJK, многие эмодзи, комбинируемые диакритики (`e` + U+0301): `fmt` считает их по рунам, а не по ячейкам.»
  - `S5/059`: «Длина кириллической строки в байтах вдвое больше, но `fmt` считает ширину в рунах, поэтому колонки выровнены. Для CJK, эмодзи и комбинируемых символов ширина в ячейках терминала расходится с числом рун — тогда используют `olekukonko/tablewriter` или `github.com/mattn/go-runewidth`.»

### G-05 — VERIFIED

### G-06 — VERIFIED

### G-07 — VERIFIED
- **Где / цитата:** `S5/058`: `bufio.NewReader(os.Stdin).ReadString('\n')` в теле цикла после ошибки `Scanln`.
- **Вердикт:** подтверждено, данные теряются. Но есть и более серьёзный дефект, который скаут не заметил: при EOF программа не завершается, а крутится бесконечно (см. F-01). Утверждение скаута, что программа «вылетает по `EOF`», неверно.
- **Доказательство:** `printf 'abc\n1\n3\n' | ./058` печатает меню, `❌ Ошибка ввода…`, затем «1» и «3» потеряны. Программа не выходит и за 2 с печатает 610 984 строки ошибки. Если вводить по строкам с паузой, всё работает: сначала `abc`, потом `1`, потом `3`. Поэтому в интерактивном режиме ошибка проявляется только при вставке нескольких строк сразу. `go1.27.1 src/bufio/bufio.go`: `NewReader` создаёт буфер 4096 байт, `ReadString` вычитывает из fd сразу всё доступное.
- **Предлагаемая правка** (проверено, `go vet` чисто; `abc,1,9,3` → ошибка, приветствие, «опция 9 не найдена», выход; на EOF выходит):
  ```go
  reader := bufio.NewReader(os.Stdin)
  for {
      // … вывод меню …
      var choice int
      _, err := fmt.Fscanln(reader, &choice)
      if err != nil {
          if errors.Is(err, io.EOF) {
              fmt.Println("\nВвод закончился.")
              return
          }
          fmt.Println("❌ Ошибка ввода: введите число 1, 2 или 3.")
          if _, err := reader.ReadString('\n'); err != nil {
              return
          }
          continue
      }
      // switch choice …
  }
  ```
  Добавить импорты `errors` и `io`. В «Под капотом» заменить фразу на: «Один `bufio.Reader` создаётся один раз перед циклом; `Fscanln(reader, …)` читает из него же, поэтому ничего не теряется».
