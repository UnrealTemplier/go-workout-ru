## 2. Находки брифа

### High

#### J-01. Тестовая зависимость якобы попадает в `go.mod` с `// indirect`
- **Где:** `001. Пакеты и модули/04. CLI на Cobra, Структурированные Логи, Дженерики/060. Тестовые зависимости github.com_stretchr_testify.md`, «## Условие».
- **Цитата:** «Убедись, что она попадает в `go.mod` с директивой `// indirect`.»
- **Утверждение:** пакет, который импортирует `_test.go` главного модуля, — прямая зависимость. `go mod tidy` пишет `require github.com/stretchr/testify vX` без `// indirect`. Комментарий `// indirect` получают только транзитивные `go-spew`, `go-difflib`, `yaml.v3`. **[судья: проверено]** на testify v1.9.0: ровно так.
- **Почему проверить:** условие требует невозможного результата. Решение и вывод про `// indirect` молчат, так что связь «условие → решение» разорвана.
- **Условие → решение → объяснение → вывод:** условие ложно; решение (тест + `go test`) верно и запускается; объяснение не касается `go.mod`; вывод `go test -v` правдоподобен.
- **Что проверить и где:** `go mod init example.com/tf`, `calc.go` + `calc_test.go` из задачи, `go get github.com/stretchr/testify@latest`, `go mod tidy`, `cat go.mod`. Источник: Go Modules Reference, раздел «go.mod files → require directive», абзац про `// indirect`.
- **Тип:** факт / условие↔результат. **Приоритет:** High.
- **Источники:** G-2.1, A-77.

#### J-02. Разворот по `[]rune` объявлен безопасным для «любых эмодзи»; в выводе опечатка
- **Где:** `001. Пакеты и модули/01. Введение, Окружение, Компиляция и Базовые Пакеты/009. Вложенные подпакеты (utils_strings).md`: H1 («безопасный разворот UTF-8»), «## Теория», «## Под капотом» (строка 84), «## Код решения» → «Терминал».
- **Цитата:** «Это гарантирует корректную работу с любыми Unicode-символами и эмодзи»; вывод `# Развернутая: !кичтобазрар-oG ,тевирП`.
- **Утверждение:** (а) руна — одна кодовая точка, а не графема. Разворот по рунам ломает комбинирующие знаки, флаги, модификаторы тона и ZWJ-последовательности. **[судья: проверено]** `"éa"` → `"áe"`, `"🇷🇺"` → `"🇺🇷"`, `"👍🏽"` → `"🏽👍"`. (б) Программа печатает `!кичтобарзар-oG ,тевирП`; в тексте переставлены буквы («…база**з**рар»). **[судья: проверено]**
- **Почему проверить:** у задачи неверная базовая модель строк Go, а это частый вопрос на собеседованиях. Вывод не совпадает с запуском.
- **Условие → решение → объяснение → вывод:** решение для кириллицы верно; объяснение переобобщает («любые эмодзи»); вывод не совпадает с кодом.
- **Что проверить и где:** запустить `Reverse` из задачи на строках выше. Источники: Unicode UAX #29 (Text Segmentation); блог Go «Strings, bytes, runes and characters in Go» (раздел про нормализацию и символы из нескольких кодовых точек).
- **Тип:** факт / педагогика + код (вывод). **Приоритет:** High.
- **Источники:** G-3.1, A-14, A-13.

#### J-03. «Ровно 5 директив» в «полном справочнике» `go.mod`; ошибки в разборе `exclude`
- **Где:** `001. Пакеты и модули/05. Анатомия go.mod, Безопасность govulncheck/062. Полный справочник директив go.mod.md`: «## Теория», «## Решение по шагам», «## Под капотом», «## На собеседовании».

Для (б): в модуле с `require github.com/google/uuid v1.5.0` и `exclude … v1.5.0` выполнить `go mod tidy` (нужна сеть или кэш с v1.6.0) и посмотреть, на какую версию поднимется `require`.

- **Где:** `001. Пакеты и модули/04. CLI на Cobra, Структурированные Логи, Дженерики/049. Автоматическая нормализация зависимостей через go.md`: «## Условие», «## Теория», пункт 2.
- **Цитата:** «Удалите из кода `main.go` использование библиотеки `uuid`, но оставьте её в импортах. Выполните команду `go mod tidy`. - **Условие → решение → объяснение → вывод:** «Решение по шагам» корректно (сначала увидеть ошибку сборки, потом удалить строку, потом `tidy`). Условие и теория ему противоречат. Код решения: строка импорта удалена, хотя условие требовало её оставить.
- **Что проверить и где:** повторить эксперимент; `go help mod tidy`.
- **Тип:** условие↔решение / факт (теория). **Приоритет:** Medium.
- **Источники:** G-2.2, A-70.

#### J-07. Горутина из `init()` якобы не исполняется до конца инициализации
