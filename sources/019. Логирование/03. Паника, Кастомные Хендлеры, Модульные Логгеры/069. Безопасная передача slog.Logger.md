# Безопасная передача *slog.Logger и fallback на slog.Default()

## Условие

Напишите функцию, которая принимает `*slog.Logger` в качестве аргумента. Это позволит вам легко передавать `nil` (что вызовет панику, проверьте `slog.Default()`) или мок-логгер при юнит-тестировании.

## Теория

Паттерн Fallback Logger защищает методы от паники при передаче `nil`: если переданный логгер равен `nil`, используется `slog.Default()`.

## Решение по шагам

1. Напишем функцию `ProcessOrder(logger *slog.Logger, orderID int)`.
2. Добавим защиту: `if logger == nil { logger = slog.Default() }`.
3. Протестируем вызов с реальным логгером и с `nil`.
4. В `main` убедимся в стабильной работе.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log/slog"
	"os"
)

func ProcessOrder(logger *slog.Logger, orderID int) {
	// Fallback на глобальный дефолтный логгер при передаче nil
	if logger == nil {
		logger = slog.Default()
	}

	logger.Info("Обработка заказа в транзакционном сервисе", "order_id", orderID)
}

func main() {
	customLogger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

	fmt.Println("=== 1. Вызов с кастомным JSON-логгером ===")
	ProcessOrder(customLogger, 1001)

	fmt.Println("\n=== 2. Вызов с nil (безопасный fallback на slog.Default) ===")
	ProcessOrder(nil, 1002)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# === 1. Вызов с кастомным JSON-логгером ===
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Обработка заказа в транзакционном сервисе","order_id":1001}
# 
# === 2. Вызов с nil (безопасный fallback на slog.Default) ===
# 2026/09/02 18:40:00 INFO Обработка заказа в транзакционном сервисе order_id=1002
```

## Под капотом

`slog.Default()` потокобезопасно возвращает атомарный указатель на текущий глобальный логгер.

## Подводные камни

Вызов методов на `nil` логгере без проверки (`logger.Info`) приведет к панике `runtime error: invalid memory address or nil pointer dereference`.

## На собеседовании

**Вопрос с собеседования:** «Как сделать логгер опциональным в структуре конфигурации (Options Pattern)?»
**Ответ:** В конструкторе `NewService(opts Options)` выполнить проверку: `if opts.Logger == nil { opts.Logger = slog.Default() }`, гарантируя непустой логгер во всех методах.
