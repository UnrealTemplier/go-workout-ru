# Установка глобального JSON логгера через slog.SetDefault

## Условие

**JSON Логирование**: Настройте `slog` так, чтобы он выводил логи исключительно в формате JSON. Для этого создайте новый логгер: `logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))` и установите его как глобальный логгер по умолчанию с помощью `slog.SetDefault(logger)`. Выведите лог и посмотрите на структуру JSON.

## Теория

`slog.SetDefault(logger)` переключает весь глобальный механизм логирования Go (включая `slog.Info`, `slog.Warn` и пакет `log`) на новый JSON-обработчик.

## Решение по шагам

1. Создадим `handler := slog.NewJSONHandler(os.Stdout, nil)`.
2. Создадим `logger := slog.New(handler)`.
3. Вызовем `slog.SetDefault(logger)`.
4. Вызовем глобальный `slog.Info` и стандартный `log.Println`.

## Код решения

**`main.go`**

```go
package main

import (
	"log"
	"log/slog"
	"os"
)

func main() {
	// 1. Создаем JSON-логгер
	jsonHandler := slog.NewJSONHandler(os.Stdout, nil)
	logger := slog.New(jsonHandler)

	// 2. Устанавливаем как дефолтный для всего приложения
	slog.SetDefault(logger)

	// 3. Вызовы глобального slog пишут в JSON:
	slog.Info("Глобальный JSON-логгер успешно инициализирован", "env", "production")

	// 4. Даже старый пакет log теперь пишет через slog:
	log.Println("Сообщение из старого пакета log")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Глобальный JSON-логгер успешно инициализирован","env":"production"}
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Сообщение из старого пакета log"}
```

## Под капотом

`slog.SetDefault` адаптирует старый стандартный пакет `log.Default()` к новому `slog.Handler`.

## Подводные камни

Вызывайте `slog.SetDefault` в самом начале `func main()` до запуска горутин и модулей.

## На собеседовании

**Вопрос с собеседования:** «Что происходит со старым пакетом log после вызова slog.SetDefault(jsonLogger)?»
**Ответ:** Старый пакет `log` автоматически перенаправляет все вызовы `log.Println` в новый `slog.Handler`, форматируя их как JSON с уровнем `INFO`.
