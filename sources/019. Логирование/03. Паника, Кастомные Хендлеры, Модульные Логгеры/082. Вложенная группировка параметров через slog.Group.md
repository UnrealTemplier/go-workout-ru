# Вложенная группировка параметров через slog.Group в вызове Info

## Условие

**slog Группы**: Используй `slog.Group("db", slog.String("host", "localhost"), slog.Int("port", 5432))` внутри вызова `slog.Info`, чтобы сгруппировать поля в JSON-логе под одним ключом `"db": {...}`.

## Теория

`slog.Group(key, attrs...)` внутри вызова логирования структурирует связанные параметры в единый JSON-объект, предотвращая захламление корневого пространства ключей.

## Решение по шагам

1. Создадим JSON логгер.
2. Вызовем `logger.Info` с группой `"db"` и группой `"pool"`.
3. В `main` убедимся в правильности JSON дерева.

## Код решения

**`main.go`**

```go
package main

import (
	"log/slog"
	"os"
)

func main() {
	logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

	logger.Info("Инициализация подключения к кластеру баз данных",
		slog.Group("db",
			slog.String("host", "localhost"),
			slog.Int("port", 5432),
			slog.String("database", "production_db"),
		),
		slog.Group("pool",
			slog.Int("max_open", 50),
			slog.Int("max_idle", 10),
		),
	)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Инициализация подключения к кластеру баз данных","db":{"host":"localhost","port":5432,"database":"production_db"},"pool":{"max_open":50,"max_idle":10}}
```

## Под капотом

`slog.Group` конструирует `slog.Attr` со значением `KindGroup`.

## Подводные камни

Вложенные группы можно создавать рекурсивно: `slog.Group("cluster", slog.Group("node1", ...))`.

## На собеседовании

**Вопрос с собеседования:** «Как обращаться к полям групп в запросах Elasticsearch?»
**Ответ:** По точечной нотации (Dot Notation): `db.host: "localhost" AND pool.max_open: 50`.
