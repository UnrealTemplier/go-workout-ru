# Обертка логгера с динамической фильтрацией уровней в Production

## Условие

Напиши обёртку вокруг `log.Logger` или `slog.Logger` с методами `Debug`, `Info`, `Warn`, `Error`. Добавь уровень логирования и фильтрацию (не выводить Debug в production).

## Теория

Обертка логгера инкапсулирует логику фильтрации по уровням, защищая production-окружение от спама отладочных логов.

## Решение по шагам

1. Объявим структуру `AppLogger struct { minLevel slog.Level; logger *slog.Logger }`.
2. Реализуем методы `Debug`, `Info`, `Warn`, `Error`.
3. В методе `Debug` проверим `if l.minLevel <= slog.LevelDebug`.
4. В `main` продемонстрируем работу в PROD режиме.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log/slog"
	"os"
)

type AppLogger struct {
	minLevel slog.Level
	handler  slog.Handler
}

func NewAppLogger(minLevel slog.Level) *AppLogger {
	return &AppLogger{
		minLevel: minLevel,
		handler:  slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{Level: minLevel}),
	}
}

func (l *AppLogger) Debug(msg string, args ...any) {
	slog.New(l.handler).Debug(msg, args...)
}

func (l *AppLogger) Info(msg string, args ...any) {
	slog.New(l.handler).Info(msg, args...)
}

func (l *AppLogger) Warn(msg string, args ...any) {
	slog.New(l.handler).Warn(msg, args...)
}

func (l *AppLogger) Error(msg string, args ...any) {
	slog.New(l.handler).Error(msg, args...)
}

func main() {
	// В проде устанавливаем уровень LevelInfo
	prodLog := NewAppLogger(slog.LevelInfo)

	fmt.Println("=== Режим Production (LevelInfo) ===")
	prodLog.Debug("Скрытый Debug-лог", "details", "verbose cache dump")
	prodLog.Info("Сервис запущен", "version", "1.0.0")
	prodLog.Error("Критический сбой диска", "path", "/dev/sda1")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# === Режим Production (LevelInfo) ===
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Сервис запущен","version":"1.0.0"}
# {"time":"2026-09-02T18:40:00Z","level":"ERROR","msg":"Критический сбой диска","path":"/dev/sda1"}
```

## Под капотом

`slog.Handler.Enabled` проверяет уровень до начала форматирования строк.

## Подводные камни

Не создавайте новый `slog.New` внутри каждого метода — сохраните `*slog.Logger` в структуре `AppLogger`.

## На собеседовании

**Вопрос с собеседования:** «Зачем скрывать Debug логи в production?»
**Ответ:** 1) Экономия дискового пространства и сети (Debug может составлять до 95% объема). 2) Предотвращение случайной утечки чувствительных внутренних данных. 3) Снижение нагрузки на CPU.
