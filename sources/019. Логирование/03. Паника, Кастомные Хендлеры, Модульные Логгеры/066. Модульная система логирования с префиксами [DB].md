# Модульная система логирования с префиксами [DB] и [API]

## Условие

Создайте кастомный логгер для каждого модуля приложения с префиксами `[DB]`, `[API]`.

## Теория

Модульные логгеры с текстовыми префиксами помогают быстро фильтровать логи в терминале при отладке без необходимости подключения тяжелых UI-систем.

## Решение по шагам

1. Создадим `dbLog := log.New(os.Stdout, "[DB] ", log.Ldate|log.Ltime)`.
2. Создадим `apiLog := log.New(os.Stdout, "[API] ", log.Ldate|log.Ltime)`.
3. Запишем сообщения из соответствующих слоев приложения.

## Код решения

**`main.go`**

```go
package main

import (
	"log"
	"os"
)

func main() {
	flags := log.Ldate | log.Ltime

	dbLogger := log.New(os.Stdout, "[DB]  ", flags)
	apiLogger := log.New(os.Stdout, "[API] ", flags)

	dbLogger.Println("Пул соединений PostgreSQL инициализирован (max_conns=50)")
	apiLogger.Println("Маршрут POST /auth/login зарегистрирован")
	dbLogger.Println("Миграция 002_add_indexes применена успешно")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [DB]  2026/09/02 18:40:00 Пул соединений PostgreSQL инициализирован (max_conns=50)
# [API] 2026/09/02 18:40:00 Маршрут POST /auth/login зарегистрирован
# [DB]  2026/09/02 18:40:00 Миграция 002_add_indexes применена успешно
```

## Под капотом

Выравнивание префиксов пробелами `[DB]  ` и `[API] ` сохраняет вертикальную колонку таймстемпов ровной.

## Подводные камни

В больших распределенных системах префиксы заменяют на структурированные JSON поля `module`.

## На собеседовании

**Вопрос с собеседования:** «Как легко парсить префиксы модулей в логах?»
**Ответ:** Использовать структурированный логгер `slog.With("module", "DB")`, который записывает модуль в отдельное JSON-поле, доступное для быстрой фильтрации.
