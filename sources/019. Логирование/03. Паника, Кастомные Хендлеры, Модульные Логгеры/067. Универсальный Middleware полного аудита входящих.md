# Универсальный Middleware полного аудита входящих HTTP-запросов

## Условие

Напиши middleware для HTTP-обработчика (или просто функцию-обёртку), которая логирует: время начала, метод, путь, время выполнения, статус ответа, ошибку (если есть).

## Теория

Аудит HTTP-запросов объединяет метаданные маршрутизации, длительность обработки и возможные ошибки выполнения в единую структурированную запись.

## Решение по шагам

1. Создадим структуру `loggingRW` для перехвата статуса.
2. В middleware зафиксируем `start := time.Now()`.
3. В `defer` вызовем `logger.Info` или `logger.Error` в зависимости от статус-кода.
4. В `main` протестируем выполнение запроса.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log/slog"
	"net/http"
	"net/http/httptest"
	"os"
	"time"
)

type loggingRW struct {
	http.ResponseWriter
	statusCode int
}

func (lrw *loggingRW) WriteHeader(code int) {
	lrw.statusCode = code
	lrw.ResponseWriter.WriteHeader(code)
}

func FullAuditMiddleware(logger *slog.Logger) func(http.Handler) http.Handler {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			start := time.Now()
			lrw := &loggingRW{ResponseWriter: w, statusCode: http.StatusOK}

			defer func() {
				latency := time.Since(start)
				lvl := slog.LevelInfo
				if lrw.statusCode >= 500 {
					lvl = slog.LevelError
				} else if lrw.statusCode >= 400 {
					lvl = slog.LevelWarn
				}

				logger.Log(r.Context(), lvl, "HTTP Request Completed",
					slog.String("method", r.Method),
					slog.String("path", r.URL.Path),
					slog.Int("status", lrw.statusCode),
					slog.Duration("latency", latency),
					slog.Time("started_at", start),
				)
			}()

			next.ServeHTTP(lrw, r)
		})
	}
}

func main() {
	logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
	mw := FullAuditMiddleware(logger)

	handler := mw(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte("OK"))
	}))

	req := httptest.NewRequest(http.MethodGet, "/api/v1/health", nil)
	rec := httptest.NewRecorder()

	fmt.Println("--- Выполнение HTTP-запроса через FullAuditMiddleware ---")
	handler.ServeHTTP(rec, req)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- Выполнение HTTP-запроса через FullAuditMiddleware ---
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"HTTP Request Completed","method":"GET","path":"/api/v1/health","status":200,"latency":12000,"started_at":"2026-09-02T18:40:00Z"}
```

## Под капотом

`logger.Log(ctx, level, msg, attrs...)` позволяет динамически выбирать уровень записи (INFO для 200, WARN для 404, ERROR для 500).

## Подводные камни

Если заголовок ответа пишется через `w.WriteHeader`, повторный вызов `w.WriteHeader` вызовет предупреждение в консоли `http: superfluous response.WriteHeader call`.

## На собеседовании

**Вопрос с собеседования:** «Как предотвратить дублирование вызовов WriteHeader в кастомном ResponseWriter?»
**Ответ:** Добавить булев флаг `wroteHeader bool` в структуру обертки. В методе `WriteHeader` проверять `if r.wroteHeader { return } r.wroteHeader = true; r.ResponseWriter.WriteHeader(code)`.
