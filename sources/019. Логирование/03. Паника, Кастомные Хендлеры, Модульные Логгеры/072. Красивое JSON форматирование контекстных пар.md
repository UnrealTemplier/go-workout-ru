# Красивое JSON форматирование контекстных пар в slog.Info

## Условие

**Атрибуты в `slog`**: Добавь в лог контекст (key-value пары). `slog.Info("юзер вошел", "user_id", 42, "ip", "127.0.0.1")`. Посмотри, как красиво это форматируется в JSON.

## Теория

При передаче пар "ключ-значение" в JSON-логгер `slog` автоматически трансформирует типы Go в соответствующие нативные JSON типы (`number`, `string`, `boolean`).

## Решение по шагам

1. Создадим JSON логгер.
2. Вызовем `slog.Info("юзер вошел", "user_id", 42, "ip", "127.0.0.1", "active", true)`.
3. В `main` убедимся в чистоте формата JSON.

## Код решения

**`main.go`**

```go
package main

import (
	"log/slog"
	"os"
)

func main() {
	handler := slog.NewJSONHandler(os.Stdout, nil)
	slog.SetDefault(slog.New(handler))

	slog.Info("юзер вошел",
		"user_id", 42,
		"ip", "127.0.0.1",
		"active", true,
		"role", "developer",
	)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"юзер вошел","user_id":42,"ip":"127.0.0.1","active":true,"role":"developer"}
```

## Под капотом

Сериализатор `slog` форматирует JSON-числа без кавычек (`42`), строки в кавычках (`"127.0.0.1"`), а булевы флаги как `true`/`false`.

## Подводные камни

Не передавайте сложные структуры без `LogValuer`, иначе они будут сериализованы через рефлексию.

## На собеседовании

**Вопрос с собеседования:** «Как в JSON выводе slog настроить форматирование времени в RFC3339Nano?»
**Ответ:** Настроить `ReplaceAttr`: `if a.Key == slog.TimeKey { return slog.String(a.Key, a.Value.Time().Format(time.RFC3339Nano)) }`.
