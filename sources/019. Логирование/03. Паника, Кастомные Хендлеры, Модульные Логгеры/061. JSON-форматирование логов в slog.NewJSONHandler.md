# JSON-форматирование логов в slog.NewJSONHandler для ELK

## Условие

Используй `slog.NewJSONHandler(os.Stdout, nil)`. Выведи логи в JSON-формате. Покажи, как это упрощает парсинг логов системами сбора.

## Теория

JSON-логирование исключает необходимость написания сложных регулярных выражений (Grok Patterns) в Logstash/Fluentbit. Каждое поле доступно сразу в структурированном виде.

## Решение по шагам

1. Создадим `logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))`.
2. Запишем событие создания заказа с вложенными атрибутами.
3. В `main` проверим валидный JSON.

## Код решения

**`main.go`**

```go
package main

import (
	"log/slog"
	"os"
)

func main() {
	logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

	logger.Info("Заказ успешно оформлен",
		slog.Int64("order_id", 849201),
		slog.String("customer_email", "buyer@corp.ru"),
		slog.Float64("total_amount", 12490.50),
		slog.String("payment_gateway", "SberPay"),
	)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Заказ успешно оформлен","order_id":849201,"customer_email":"buyer@corp.ru","total_amount":12490.5,"payment_gateway":"SberPay"}
```

## Под капотом

JSON-хендлер автоматически кодирует спецсимволы и кавычки внутри строк.

## Подводные камни

Не передавайте циклические структуры данных — сериализатор `slog` может вызвать ошибку переполнения стека.

## На собеседовании

**Вопрос с собеседования:** «Как в ELK настроить автоматический парсинг JSON-логов из stdout контейнеров?»
**Ответ:** Включить фильтр `json { source => "message" }` в Logstash или использовать процессор `json` в Fluent Bit / Vector.
