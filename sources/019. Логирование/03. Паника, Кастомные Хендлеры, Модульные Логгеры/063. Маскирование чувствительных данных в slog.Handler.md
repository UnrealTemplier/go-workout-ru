# Маскирование чувствительных данных в slog.Handler

## Условие

Реализуйте кастомный `slog.Handler`, который скрывает (маскирует) чувствительные данные (например, слово "password") перед записью лога.

## Теория

Фильтрация чувствительных ключей через `ReplaceAttr` в `slog.HandlerOptions` выполняется на этапе форматирования записи.

## Решение по шагам

1. Создадим функцию маскирования.
2. Проверим `a.Key == "password"`.
3. Заменим значение на `slog.StringValue("******")`.
4. В `main` вызовем логгер.

## Код решения

**`main.go`**

```go
package main

import (
	"log/slog"
	"os"
	"strings"
)

func maskSensitive(groups []string, a slog.Attr) slog.Attr {
	if strings.EqualFold(a.Key, "password") || strings.EqualFold(a.Key, "secret") {
		return slog.String(a.Key, "******")
	}
	return a
}

func main() {
	opts := &slog.HandlerOptions{
		ReplaceAttr: maskSensitive,
	}
	logger := slog.New(slog.NewJSONHandler(os.Stdout, opts))

	logger.Info("Попытка аутентификации пользователя",
		slog.String("username", "admin"),
		slog.String("password", "SuperSecretPass123"),
		slog.String("secret", "api-key-99182"),
	)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Попытка аутентификации пользователя","username":"admin","password":"******","secret":"******"}
```

## Под капотом

`strings.EqualFold` выполняет сравнение строк без учета регистра символов ASCII.

## Подводные камни

Учитывайте русскоязычные ключи (`"пароль"`, `"секрет"`), если они могут появиться в коде.

## На собеседовании

**Вопрос с собеседования:** «Как маскировать чувствительные данные в неструктурированном тексте msg?»
**Ответ:** Скомпилировать регулярное выражение `regexp.MustCompile(`(?i)(password|token)=([^\s&]+)`)` и заменять совпадения в функции `ReplaceAttr` для ключа `slog.MessageKey`.
