# Хелпер LogError с автоматическим захватом места вызова через runtime.Caller

## Условие

Напиши функцию `LogError(err error, attrs ...slog.Attr)`, которая форматирует ошибку с контекстом в JSON через `slog.Error`. Добавь атрибуты: функция, файл, строка (через `runtime.Caller`).

## Теория

Функция `runtime.Caller(1)` определяет файл, номер строки и имя вызывающей функции, автоматически добавляя координаты места сбоя в JSON-атрибуты лога.

## Решение по шагам

1. Напишем функцию `LogError(logger *slog.Logger, err error, attrs ...slog.Attr)`.
2. Вызовем `pc, file, line, ok := runtime.Caller(1)`.
3. Извлечем имя функции через `runtime.FuncForPC(pc).Name()`.
4. Сформируем и запишем `logger.LogAttrs(...)` с уровнем `LevelError`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"errors"
	"log/slog"
	"os"
	"path/filepath"
	"runtime"
)

func LogError(logger *slog.Logger, err error, extraAttrs ...slog.Attr) {
	if err == nil {
		return
	}

	// 1. Определение места вызова ошибки
	pc, file, line, ok := runtime.Caller(1)
	fnName := "unknown"
	if ok {
		fnName = runtime.FuncForPC(pc).Name()
	}

	// 2. Сбор атрибутов
	callerGroup := slog.Group("caller",
		slog.String("function", fnName),
		slog.String("file", filepath.Base(file)),
		slog.Int("line", line),
	)

	allAttrs := []slog.Attr{
		slog.String("error", err.Error()),
		callerGroup,
	}
	allAttrs = append(allAttrs, extraAttrs...)

	// 3. Запись ошибки
	logger.LogAttrs(context.Background(), slog.LevelError, "Произошла ошибка выполнения", allAttrs...)
}

func processInvoice() error {
	return errors.New("недостаточно средств на расчетном счете")
}

func main() {
	logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

	err := processInvoice()
	if err != nil {
		LogError(logger, err, slog.Int("invoice_id", 99482), slog.String("currency", "RUB"))
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"ERROR","msg":"Произошла ошибка выполнения","error":"недостаточно средств на расчетном счете","caller":{"function":"main.main","file":"main.go","line":48},"invoice_id":99482,"currency":"RUB"}
```

## Под капотом

Параметр `skip = 1` в `runtime.Caller(1)` пропускает сам хелпер `LogError` и захватывает точку вызова в функции `main`.

## Подводные камни

Используйте `filepath.Base(file)`, чтобы не раздувать логи длинными абсолютными путями файловой системы.

## На собеседовании

**Вопрос с собеседования:** «Почему важно оборачивать caller метаданные в slog.Group("caller")?»
**Ответ:** Чтобы изолировать технические поля источника (`caller.file`, `caller.line`) от бизнес-полей лога, сохраняя чистоту корневой схемы JSON-документа.
