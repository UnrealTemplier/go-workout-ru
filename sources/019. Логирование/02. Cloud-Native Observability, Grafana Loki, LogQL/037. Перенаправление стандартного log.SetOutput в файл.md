# Перенаправление стандартного log.SetOutput в файл

## Условие

Перенаправьте вывод стандартного `log` в файл вместо консоли с помощью `os.OpenFile` и `log.SetOutput`.

## Теория

Функция `log.SetOutput(w io.Writer)` перенаправляет поток вывода глобального стандартного логгера Go в любой объект, реализующий интерфейс `io.Writer` (например, файловый дескриптор `*os.File`).

## Решение по шагам

1. Откроем файл `service.log` в режиме `os.O_CREATE|os.O_WRONLY|os.O_APPEND`.
2. Вызовем `log.SetOutput(file)`.
3. Запишем несколько логов через `log.Println`.
4. Прочитаем и проверим содержимое файла.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	logPath := "service.log"

	file, err := os.OpenFile(logPath, os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0644)
	if err != nil {
		log.Fatalf("Ошибка открытия файла: %v", err)
	}
	defer func() {
		file.Close()
		_ = os.Remove(logPath)
	}()

	// Перенаправление стандартного логгера в файл
	log.SetOutput(file)

	log.Println("Инициализация сервиса авторизации")
	log.Printf("Подключение к БД PostgreSQL: порт %d", 5432)

	// Проверяем данные на диске
	data, _ := os.ReadFile(logPath)
	fmt.Println("--- Данные успешно записаны в файл service.log ---")
	fmt.Print(string(data))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- Данные успешно записаны в файл service.log ---
# 2026/09/02 18:40:00 Инициализация сервиса авторизации
# 2026/09/02 18:40:00 Подключение к БД PostgreSQL: порт 5432
```

## Под капотом

`log.SetOutput` защищен внутренним `sync.Mutex` стандартного пакета `log`, что делает смену вывода потокобезопасной.

## Подводные камни

Не закрывайте `file` до тех пор, пока работают горутины, пишущие в стандартный логгер, иначе возникнет паника `write on closed file`.

## На собеседовании

**Вопрос с собеседования:** «Потокобезопасен ли стандартный пакет log при вызове log.Println из 1000 горутин?»
**Ответ:** Да. Внутри стандартной структуры `log.Logger` каждая операция записи защищена мьютексом `l.mu.Lock()`, гарантируя целостность строк без перемешивания байтов.
