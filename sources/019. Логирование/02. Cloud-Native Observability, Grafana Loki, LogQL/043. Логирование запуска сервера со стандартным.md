# Логирование запуска сервера со стандартным таймстемпом

## Условие

Используй `log.Println("Server started")`. Покажи, что по умолчанию выводится с timestamp.

## Теория

По умолчанию флаги стандартного логгера установлены в `log.LstdFlags` (комбинация `log.Ldate | log.Ltime`). Это гарантирует наличие временной метки `2026/09/02 18:40:00`.

## Решение по шагам

1. Вызовем `log.Println("Server started on port :8080")`.
2. Зафиксируем структуру формата даты и времени.
3. В `main` убедимся в наличии таймстемпа.

## Код решения

**`main.go`**

```go
package main

import (
	"log"
)

func main() {
	// Дефолтный вызов standard library logger
	log.Println("Server started")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# 2026/09/02 18:40:00 Server started
```

## Под капотом

Таймстемп вычисляется через `time.Now()` в момент вызова метода `Output`.

## Подводные камни

Таймстемп стандартного логгера использует локальный часовой пояс сервера, что может вызвать путаницу при синхронизации логов из разных дата-центров. Для UTC используйте `log.LUTC`.

## На собеседовании

**Вопрос с собеседования:** «Как включить вывод таймстемпов в UTC в стандартном пакете log?»
**Ответ:** Установить флаг `log.LUTC`: `log.SetFlags(log.LstdFlags | log.LUTC)`.
