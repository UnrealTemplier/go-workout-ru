# Архитектура Log Shipping: Fluent Bit, Vector и централизованный сбор логов

## Условие

Настрой **log shipping**: Fluent Bit / Fluentd / Vector читает stdout (JSON), отправляет в Elasticsearch/Loki/CloudWatch. Покажи centralized logging architecture.

## Теория

Современные Go-приложения в контейнерах Kubernetes не знают об Elasticsearch или Loki. Они пишут чистый JSON в `os.Stdout`. Инфраструктурный DaemonSet-агент (Fluent Bit / Vector) вычитывает stdout контейнеров, парсит JSON, обогащает метаданными пода (`k8s.pod_name`, `k8s.namespace`) и асинхронно отправляет в хранилище.

## Решение по шагам

1. Сформируем идеальный Cloud-Native JSON логгер в Go.
2. Продемонстрируем формат вывода для парсера Fluent Bit.
3. Опишем архитектурную схему Log Shipping конвейера.
4. В `main` выведем запись.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log/slog"
	"os"
)

func main() {
	// Стандарт Cloud-Native 12-Factor App: вывод строго в os.Stdout
	handler := slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{
		Level: slog.LevelInfo,
	})
	logger := slog.New(handler)

	logger.Info("Order placed successfully",
		slog.String("service", "checkout-service"),
		slog.String("version", "v2.14.0"),
		slog.Int64("order_id", 998811),
		slog.String("currency", "RUB"),
		slog.Float64("total", 4590.00),
	)

	fmt.Println("\n=== Архитектура Log Shipping Конвейера ===")
	fmt.Println("1. Go App -> stdout (JSON Stream)")
	fmt.Println("2. Kubernetes Node -> /var/log/pods/*.log")
	fmt.Println("3. Fluent Bit / Vector DaemonSet -> вычитка, фильтрация, обогащение K8s тегами")
	fmt.Println("4. Ingestion Pipeline -> Kafka / Vector Aggregator")
	fmt.Println("5. Storage & Visualizer -> Grafana Loki / Elasticsearch + Kibana")
}
```

**`Терминал`**

```bash

```

## Под капотом

Vector и Fluent Bit написаны на Rust/C и потребляют всего 15–30 МБ RAM на ноду Kubernetes, обрабатывая сотни тысяч логов в секунду.

## Подводные камни

Не пишите ANSI-цвета терминала в stdout в production-режиме, так как ESC-последовательности ломают JSON-парсер Fluent Bit.

## На собеседовании

**Вопрос с собеседования:** «Почему запись логов напрямую по HTTP/TCP в Elasticsearch из Go сервиса считается антипаттерном?»
**Ответ:** При сбое сети или перегрузке Elasticsearch сервис либо заблокируется, либо начнет терять логи. Схема через `stdout -> Fluent Bit` полностью изолирует приложение от отказов хранилища логов.
