# Создание изолированного логгера log.New с префиксом и записью в файл

## Условие

Создай логгер, пишущий в файл: `f, _ := os.Create("app.log"); logger := log.New(f, "APP: ", log.LstdFlags)`. Пиши через `logger.Println`. Проверь файл.

## Теория

Функция `log.New(out, prefix, flag)` создает изолированный экземпляр `*log.Logger`. Это предотвращает конфликт префиксов и потоков вывода между независимыми модулями приложения.

## Решение по шагам

1. Создадим файл `app_custom.log`.
2. Инициализируем `appLogger := log.New(f, "APP: ", log.LstdFlags)`.
3. Запишем строки через `appLogger.Println`.
4. В `main` проверим содержимое файла.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	path := "app_custom.log"
	f, err := os.Create(path)
	if err != nil {
		log.Fatal(err)
	}
	defer func() {
		f.Close()
		_ = os.Remove(path)
	}()

	// Создаем выделенный экземпляр логгера для модуля APP
	appLogger := log.New(f, "APP: ", log.LstdFlags)

	appLogger.Println("Старт процесса обработки фоновых задач")
	appLogger.Println("Обработано 150 элементов очереди")

	data, _ := os.ReadFile(path)
	fmt.Println("--- Содержимое файла app_custom.log ---")
	fmt.Print(string(data))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- Содержимое файла app_custom.log ---
# APP: 2026/09/02 18:40:00 Старт процесса обработки фоновых задач
# APP: 2026/09/02 18:40:00 Обработано 150 элементов очереди
```

## Под капотом

Префикс `"APP: "` конкатенируется перед датой и временем в буфере строки лога.

## Подводные камни

Если не закрыть файл `f.Close()` перед выходом, буфер ОС может не успеть записать последние байты на диск.

## На собеседовании

**Вопрос с собеседования:** «Почему создание собственных инстансов *log.Logger лучше использования глобального пакета log?»
**Ответ:** Глобальное состояние (Package-level state) затрудняет тестирование, не позволяет настроить разные префиксы для модулей и создает неявные зависимости между пакетами.
