# Перенаправление логов в файл app.log в режиме дозаписи

## Условие

**Логирование в файл**: Напишите код, который открывает файл `app.log` на дозапись. Перенаправьте вывод стандартного логгера в этот файл с помощью `log.SetOutput(file)`. Сделайте тестовую запись и убедитесь, что логи пишутся на диск, а не в консоль.

## Теория

Режим `os.O_APPEND` гарантирует, что каждая новая запись добавляется в конец файла без затирания истории работы сервиса.

## Решение по шагам

1. Откроем `app.log` с флагами `os.O_CREATE|os.O_WRONLY|os.O_APPEND`.
2. Применим `log.SetOutput(file)`.
3. Запишем 2 строки.
4. Проверим чтением с диска.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	path := "app_append.log"

	// Открытие на дозапись
	file, err := os.OpenFile(path, os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0644)
	if err != nil {
		log.Fatalf("Ошибка открытия файла: %v", err)
	}
	defer func() {
		file.Close()
		_ = os.Remove(path)
	}()

	log.SetOutput(file)

	log.Println("[INFO] Сессия пользователя 101 открыта")
	log.Println("[INFO] Сессия пользователя 101 закрыта")

	data, _ := os.ReadFile(path)
	fmt.Println("--- Данные успешно сохранены в app_append.log ---")
	fmt.Print(string(data))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- Данные успешно сохранены в app_append.log ---
# 2026/09/02 18:40:00 [INFO] Сессия пользователя 101 открыта
# 2026/09/02 18:40:00 [INFO] Сессия пользователя 101 закрыта
```

## Под капотом

Системный вызов Linux `open(path, O_CREAT|O_WRONLY|O_APPEND, 0644)` гарантирует атомарную дозапись на уровне файловой системы.

## Подводные камни

В Windows при открытии файла другими процессами без флага общего доступа (Share Mode) может возникнуть ошибка доступа.

## На собеседовании

**Вопрос с собеседования:** «Могут ли два независимых процесса одновременно безопасно писать в один лог-файл с флагом O_APPEND в Linux?»
**Ответ:** Да. В POSIX-совместимых ОС запись с флагом `O_APPEND` размером меньше `PIPE_BUF` (обычно 4096 байт) является атомарной на уровне ядра.
