# Информационные сообщения стандартного пакета log с автоматическим таймстемпом

## Условие

Используйте стандартный пакет `log` для вывода информационного сообщения с автоматическим добавлением даты и времени.

## Теория

Стандартный пакет `log` по умолчанию добавляет локальную дату и время в формате `YYYY/MM/DD HH:MM:SS` к началу каждой строки сообщения и выводит результат в поток `os.Stderr`.

## Решение по шагам

1. Импортируем стандартный пакет `log`.
2. Вызовем `log.Println("Сервис мониторинга успешно запущен")`.
3. Вызовем `log.Printf("Слушатель открыт на порту :%d", 8080)`.
4. В `main` убедимся в автоматическом добавлении даты и времени.

## Код решения

**`main.go`**

```go
package main

import (
	"log"
)

func main() {
	// Базовый вывод со стандартным префиксом даты и времени
	log.Println("Сервис мониторинга успешно запущен")
	log.Printf("Слушатель открыт на порту :%d", 8080)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод (в поток Stderr):
# 2026/09/02 18:40:00 Сервис мониторинга успешно запущен
# 2026/09/02 18:40:00 Слушатель открыт на порту :8080
```

## Под капотом

Стандартный логгер использует неявный глобальный инстанс `std = New(os.Stderr, "", LstdFlags)`.

## Подводные камни

Вывод `log.Println` по умолчанию идет в `os.Stderr`, а не в `os.Stdout`! При фильтрации в bash `cmd > out.txt` логи останутся в терминале.

## На собеседовании

**Вопрос с собеседования:** «Почему стандартный пакет log в Go пишет в os.Stderr, а не в os.Stdout?»
**Ответ:** Чтобы не смешивать системные логи сервиса с полезным потоком данных (Payload / CLI Output) программы, который передается по Unix-пайпу `stdout | next_cmd`.
