# Фабрика логгеров с ежедневной сменой имени файла CreateDailyLogger

## Условие

Напиши функцию `CreateDailyLogger() *log.Logger`, создающую лог-файл с датой в имени (`app_2026-07-03.log`). Используй `log.New`.

## Теория

Ежедневное разделение лог-файлов (Daily Rolling Logger) группирует логи по датам, упрощая поиск инцидентов и настройку политик архивации.

## Решение по шагам

1. Получим текущую дату `time.Now().Format("2006-01-02")`.
2. Сформируем имя файла `fmt.Sprintf("app_%s.log", dateStr)`.
3. Откроем файл на дозапись.
4. Создадим и вернем `log.New(f, "[DAILY] ", log.LstdFlags)`.
5. В `main` протестируем запись.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
	"time"
)

func CreateDailyLogger() (*log.Logger, *os.File, error) {
	currentDate := time.Now().Format("2006-01-02")
	fileName := fmt.Sprintf("app_%s.log", currentDate)

	file, err := os.OpenFile(fileName, os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0644)
	if err != nil {
		return nil, nil, err
	}

	logger := log.New(file, "[DAILY] ", log.LstdFlags|log.Lshortfile)
	return logger, file, nil
}

func main() {
	dailyLogger, file, err := CreateDailyLogger()
	if err != nil {
		log.Fatal(err)
	}
	defer func() {
		fileName := file.Name()
		file.Close()
		_ = os.Remove(fileName)
	}()

	dailyLogger.Println("Старт обработки ежедневной финансовой сверки")
	dailyLogger.Println("Сверка завершена: 0 расхождений")

	data, _ := os.ReadFile(file.Name())
	fmt.Printf("--- Содержимое файла %s ---\n", file.Name())
	fmt.Print(string(data))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- Содержимое файла app_2026-09-02.log ---
# [DAILY] 2026/09/02 18:40:00 main.go:30: Старт обработки ежедневной финансовой сверки
# [DAILY] 2026/09/02 18:40:00 main.go:31: Сверка завершена: 0 расхождений
```

## Под капотом

Шаблон даты в Go `2006-01-02` (Mon Jan 2 15:04:05 MST 2006) — стандарт форматирования времени.

## Подводные камни

В долгоживущем процессе при наступлении полуночи необходимо переоткрывать файл на новую дату.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать ротацию Daily Logger ровно в 00:00:00 без перезапуска сервиса?»
**Ответ:** Запустить фоновую горутину, которая рассчитывает задержку до следующей полуночи: `time.Until(tomorrowMidnight)`, засыпает на этот интервал через `time.Sleep` и атомарно подменяет дескриптор файла под мьютексом.
