# Хелпер WithContext для обогащения логгера метаданными запроса

## Условие

Напиши функцию `WithContext(ctx context.Context, logger *slog.Logger) *slog.Logger`, добавляющую в логгер поля из контекста (`request_id`, `user_id`). Используй `slog.With`.

## Теория

Функция-хелпер `WithContext` проверяет набор стандартных ключей в `context.Context` и возвращает дочерний `*slog.Logger`, уже содержащий эти атрибуты.

## Решение по шагам

1. Определим типы ключей контекста.
2. Реализуем функцию `WithContext(ctx, logger)`.
3. Извлечем `request_id` и `user_id` и добавим в логгер через `logger.With(...)`.
4. В `main` вызовем хелпер и запишем лог.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log/slog"
	"os"
)

type contextKey string

const (
	RequestIDKey contextKey = "request_id"
	UserIDKey    contextKey = "user_id"
)

func WithContext(ctx context.Context, logger *slog.Logger) *slog.Logger {
	var attrs []any

	if reqID, ok := ctx.Value(RequestIDKey).(string); ok && reqID != "" {
		attrs = append(attrs, "request_id", reqID)
	}
	if userID, ok := ctx.Value(UserIDKey).(int); ok && userID != 0 {
		attrs = append(attrs, "user_id", userID)
	}

	if len(attrs) == 0 {
		return logger
	}
	return logger.With(attrs...)
}

func main() {
	baseLogger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

	ctx := context.Background()
	ctx = context.WithValue(ctx, RequestIDKey, "trace-abc-123")
	ctx = context.WithValue(ctx, UserIDKey, 881)

	enrichedLogger := WithContext(ctx, baseLogger)

	fmt.Println("--- Логирование через обогащенный логгер ---")
	enrichedLogger.Info("Загрузка профиля покупателя", "status", "active")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- Логирование через обогащенный логгер ---
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Загрузка профиля покупателя","request_id":"trace-abc-123","user_id":881,"status":"active"}
```

## Под капотом

`logger.With(attrs...)` создает легковесный `*slog.Logger`, разделяющий базовый обработчик со скопированным срезом атрибутов.

## Подводные камни

Если в контексте нет ни одного искомого поля, функция возвращает исходный указатель `logger` без лишних аллокаций.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие WithContext от Handler.Handle(ctx, record)?»
**Ответ:** `WithContext` возвращает новый инстанс `*slog.Logger`, который можно передать в другие методы. `Handler.Handle` прозрачно перехватывает контекст в точке вызова без создания промежуточных логгеров.
