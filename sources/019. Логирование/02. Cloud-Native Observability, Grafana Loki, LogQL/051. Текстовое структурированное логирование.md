# Текстовое структурированное логирование slog.NewTextHandler

## Условие

Перейди на `log/slog` (Go 1.21+). Создай `slog.Logger` с `slog.NewTextHandler(os.Stdout, nil)`. Выведи структурированный лог: `slog.Info("user login", slog.String("user_id", "123"), slog.String("ip", "10.0.0.1"))`.

## Теория

`slog.NewTextHandler` форматирует записи в human-readable формате `key=value` (формат logfmt). Он удобен для локальной разработки и отладки в терминале.

## Решение по шагам

1. Создадим `textHandler := slog.NewTextHandler(os.Stdout, nil)`.
2. Обернем в `slog.New(textHandler)`.
3. Запишем лог с типизированными атрибутами `slog.String`.
4. В `main` убедимся в формате `time=... level=INFO msg=... key=val`.

## Код решения

**`main.go`**

```go
package main

import (
	"log/slog"
	"os"
)

func main() {
	// Текстовый обработчик logfmt для локальной разработки
	handler := slog.NewTextHandler(os.Stdout, nil)
	logger := slog.New(handler)
	slog.SetDefault(logger)

	slog.Info("user login",
		slog.String("user_id", "123"),
		slog.String("ip", "10.0.0.1"),
	)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# time=2026-09-02T18:40:00.000Z level=INFO msg="user login" user_id=123 ip=10.0.0.1
```

## Под капотом

`slog.TextHandler` оборачивает значения в кавычки `""`, только если они содержат пробелы или спецсимволы.

## Подводные камни

В проде используйте `NewJSONHandler`, а не `NewTextHandler`, так как парсинг logfmt в Kibana медленнее JSON.

## На собеседовании

**Вопрос с собеседования:** «Как настроить автоматическое переключение TextHandler в DEV и JSONHandler в PROD?»
**Ответ:** Проверять переменную окружения `ENV == "production"` при инициализации и выбирать `slog.NewJSONHandler` для продакшена и `slog.NewTextHandler` для локальной разработки.
