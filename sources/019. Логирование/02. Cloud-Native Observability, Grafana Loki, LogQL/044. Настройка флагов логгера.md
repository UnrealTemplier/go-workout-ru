# Настройка флагов логгера: микросекунды и имя файла через log.SetFlags

## Условие

**Настройка флагов логгера**: Используя функцию `log.SetFlags`, настройте стандартный логгер так, чтобы он выводил микросекунды, а также имя файла и номер строки, где был вызван лог (флаги `log.Lmicroseconds`, `log.Lshortfile`).

## Теория

Битовая маска флагов `log.SetFlags` позволяет кастомизировать префикс логов: `log.Ldate` (дата), `log.Ltime` (время), `log.Lmicroseconds` (микросекунды) и `log.Lshortfile` (`main.go:24`).

## Решение по шагам

1. Скомбинируем флаги: `log.Ldate | log.Ltime | log.Lmicroseconds | log.Lshortfile`.
2. Применим через `log.SetFlags(...)`.
3. Запишем тестовый лог.
4. В `main` убедимся в отображении микросекунд и номера строки.

## Код решения

**`main.go`**

```go
package main

import (
	"log"
)

func main() {
	// Настройка флагов: дата + время с микросекундами + короткое имя файла и строка
	log.SetFlags(log.Ldate | log.Ltime | log.Lmicroseconds | log.Lshortfile)

	log.Println("Инициализация высокоточного таймера")
	log.Println("Соединение с брокером сообщений установлено")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# 2026/09/02 18:40:00.194821 main.go:11: Инициализация высокоточного таймера
# 2026/09/02 18:40:00.194899 main.go:12: Соединение с брокером сообщений установлено
```

## Под капотом

`log.Lshortfile` вызывает `runtime.Caller(calldepth)` и отсекает родительские директории пути через `strings.LastIndex`.

## Подводные камни

Флаг `log.Llongfile` выводит полный абсолютный путь к файлу `/home/ut/work/go-workout/main.go:11`, что сильно удлиняет строки.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие log.Lshortfile от log.Llongfile?»
**Ответ:** `log.Lshortfile` выводит только имя файла и строку (`server.go:42`), а `log.Llongfile` — полный абсолютный путь в файловой системе (`/app/pkg/api/server.go:42`).
