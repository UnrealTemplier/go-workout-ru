# Добавление информации об исходном коде через AddSource в slog

## Условие

Настрой **structured logging** с `log/slog`: `logger := slog.New(slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{Level: slog.LevelInfo, AddSource: true}))`. `logger.Info("request processed", slog.String("method", "GET"), slog.String("path", "/users"), slog.Int("status", 200), slog.Duration("latency", 15*time.Millisecond))`. Покажи JSON output.

## Теория

Опция `AddSource: true` указывает `slog` автоматически определять и добавлять файл, номер строки и имя функции, в которой был вызван лог, во вложенный объект `"source": {"function": "...", "file": "...", "line": 42}`.

## Решение по шагам

1. Создадим `slog.HandlerOptions{Level: slog.LevelInfo, AddSource: true}`.
2. Инициализируем `slog.NewJSONHandler(os.Stdout, opts)`.
3. Запишем структурированный лог с атрибутами `method`, `path`, `status`, `latency`.
4. В `main` убедимся в наличии блока `source`.

## Код решения

**`main.go`**

```go
package main

import (
	"log/slog"
	"os"
	"time"
)

func main() {
	opts := &slog.HandlerOptions{
		Level:     slog.LevelInfo,
		AddSource: true, // Включает автоопределение файла и строки вызова
	}

	logger := slog.New(slog.NewJSONHandler(os.Stdout, opts))

	logger.Info("request processed",
		slog.String("method", "GET"),
		slog.String("path", "/users"),
		slog.Int("status", 200),
		slog.Duration("latency", 15*time.Millisecond),
	)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","source":{"function":"main.main","file":"/home/ut/work/go-workout/main.go","line":15},"msg":"request processed","method":"GET","path":"/users","status":200,"latency":15000000}
```

## Под капотом

`slog` запрашивает программный счетчик `runtime.Caller(skip)` только тогда, когда `AddSource == true`.

## Подводные камни

Включение `AddSource: true` создает накладные расходы CPU (~1-2 мкс на вызов). В сверхвысоконагруженных сервисах (HighLoad) `AddSource` включают только для `LevelError` через кастомный `ReplaceAttr`.

## На собеседовании

**Вопрос с собеседования:** «Как сократить абсолютный путь файла в поле source.file до относительного?»
**Ответ:** Использовать функцию `ReplaceAttr`: проверить `if a.Key == slog.SourceKey { src := a.Value.Any().(*slog.Source); src.File = filepath.Base(src.File); return slog.Any(a.Key, src) }`.
