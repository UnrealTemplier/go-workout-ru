# Сравнение различных комбинаций флагов стандартного пакета log

## Условие

Настрой флаги логгера: `log.SetFlags(log.LstdFlags | log.Lshortfile | log.Lmicroseconds)`. Покажи разницу в выводе (файл, строка, микросекунды).

## Теория

Комбинирование битовых флагов через побитовое ИЛИ (`|`) формирует требуемый набор метаданных лога.

## Решение по шагам

1. Выведем лог с `log.LstdFlags`.
2. Установим `log.LstdFlags | log.Lshortfile | log.Lmicroseconds`.
3. Выведем лог и сравним форматы.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
)

func main() {
	// 1. Стандартные флаги (Дата + Время)
	log.SetFlags(log.LstdFlags)
	fmt.Println("=== 1. Стандартный вывод ===")
	log.Println("Лог со стандартными флагами")

	// 2. Расширенные флаги (+ микросекунды + файл и строка)
	log.SetFlags(log.LstdFlags | log.Lshortfile | log.Lmicroseconds)
	fmt.Println("\n=== 2. Расширенный вывод (Микросекунды + Файл:Строка) ===")
	log.Println("Лог с расширенными флагами")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# === 1. Стандартный вывод ===
# 2026/09/02 18:40:00 Лог со стандартными флагами
# 
# === 2. Расширенный вывод (Микросекунды + Файл:Строка) ===
# 2026/09/02 18:40:00.849201 main.go:17: Лог с расширенными флагами
```

## Под капотом

`log.LstdFlags` эквивалентен константе `log.Ldate | log.Ltime` (значение `3`).

## Подводные камни

Если передать флаг `0` (`log.SetFlags(0)`), логгер не будет выводить дату, время и имя файла, печатая только чистый текст.

## На собеседовании

**Вопрос с собеседования:** «Как полностью убрать префикс даты и времени в log?»
**Ответ:** Вызвать `log.SetFlags(0)`. Логгер будет выводить только переданный текст без префиксов времени.
