# Настройка JSON-формата slog для облачных сред ELK и Grafana Loki

## Условие

Настройте `slog` для вывода в формате JSON (через `slog.NewJSONHandler`), что является стандартом для облачных приложений и сбора логов (ELK, Loki).

## Теория

Вывод в JSON — фундаментальное требование для сбора логов в облачных средах (Kubernetes, AWS EKS, Yandex Cloud). JSON позволяет индексировать поля в Elasticsearch, OpenSearch и Grafana Loki.

## Решение по шагам

1. Создадим `slog.NewJSONHandler(os.Stdout, nil)`.
2. Обернем в `slog.New(handler)`.
3. Установим дефолтным через `slog.SetDefault(logger)`.
4. Запишем событие с контекстом окружения `env`, `service`, `version`.

## Код решения

**`main.go`**

```go
package main

import (
	"log/slog"
	"os"
)

func main() {
	// Инициализация стандартного JSON-хендлера для Cloud-Native
	jsonHandler := slog.NewJSONHandler(os.Stdout, nil)
	logger := slog.New(jsonHandler)
	slog.SetDefault(logger)

	slog.Info("Микросервис успешно развернут в кластере",
		slog.String("service.name", "billing-gateway"),
		slog.String("service.version", "v1.8.4"),
		slog.String("environment", "production"),
		slog.String("k8s.pod_name", "billing-gateway-7d89f4b-2kz8w"),
	)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Микросервис успешно развернут в кластере","service.name":"billing-gateway","service.version":"v1.8.4","environment":"production","k8s.pod_name":"billing-gateway-7d89f4b-2kz8w"}
```

## Под капотом

`slog.NewJSONHandler` использует буферизованный кодировщик с экранированием спецсимволов UTF-8 по стандарту RFC 8259.

## Подводные камни

Не перегружайте каждую запись статическими полями `service.name` вручную — добавьте их один раз при старте через `logger.With(...)`.

## На собеседовании

**Вопрос с собеседования:** «Как в slog один раз добавить глобальные поля окружения (service, env, version) ко всем логам приложения?»
**Ответ:** Создать логгер через `logger := slog.New(handler).With("service", "auth", "env", "prod")` и установить его через `slog.SetDefault(logger)`.
