# Управление уровнем логирования через системный сигнал SIGUSR1

## Условие

Поддержите динамическое изменение уровня логирования без перезапуска (через эндпоинт или сигнал `SIGUSR1`).

## Теория

Сигналы POSIX (`SIGUSR1`, `SIGHUP`) позволяют менять внутреннее состояние демона без сетевого трафика. Канал `chan os.Signal` перехватывает `SIGUSR1` и переключает `slog.LevelVar` между `INFO` и `DEBUG`.

## Решение по шагам

1. Создадим `levelVar := new(slog.LevelVar)`.
2. Создадим канал `sigCh := make(chan os.Signal, 1)`.
3. Подпишемся на `signal.Notify(sigCh, syscall.SIGUSR1)`.
4. В фоновой горутине переключим уровень при получении сигнала.
5. В `main` сымитируем переключение уровня.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log/slog"
	"os"
	"os/signal"
	"syscall"
)

func setupSignalLogLevel(levelVar *slog.LevelVar) {
	sigCh := make(chan os.Signal, 1)
	signal.Notify(sigCh, syscall.SIGUSR1)

	go func() {
		for range sigCh {
			if levelVar.Level() == slog.LevelInfo {
				levelVar.Set(slog.LevelDebug)
				slog.Info("[SIGNAL SIGUSR1] Уровень логирования переключен на DEBUG")
			} else {
				levelVar.Set(slog.LevelInfo)
				slog.Info("[SIGNAL SIGUSR1] Уровень логирования переключен на INFO")
			}
		}
	}()
}

func main() {
	levelVar := new(slog.LevelVar)
	levelVar.Set(slog.LevelInfo)

	logger := slog.New(slog.NewTextHandler(os.Stdout, &slog.HandlerOptions{Level: levelVar}))
	slog.SetDefault(logger)

	setupSignalLogLevel(levelVar)

	fmt.Println("=== Режим 1: По умолчанию (INFO) ===")
	slog.Debug("Скрытое отладочное сообщение")
	slog.Info("Сервер работает в штатном режиме")

	// Имитация получения сигнала SIGUSR1:
	fmt.Println("\n=== Имитация отправки сигнала SIGUSR1 ===")
	levelVar.Set(slog.LevelDebug)

	slog.Debug("Отладочный лог: соединение с БД активно (pool_size=20)")
	slog.Info("Запрос выполнен успешно")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# === Режим 1: По умолчанию (INFO) ===
# time=2026-09-02T18:40:00.000Z level=INFO msg="Сервер работает в штатном режиме"
# 
# === Имитация отправки сигнала SIGUSR1 ===
# time=2026-09-02T18:40:00.000Z level=DEBUG msg="Отладочный лог: соединение с БД активно (pool_size=20)"
# time=2026-09-02T18:40:00.000Z level=INFO msg="Запрос выполнен успешно" 
```

## Под капотом

Сигнал ОС обрабатывается в отдельном потоке рантайма Go (сигнальный поток M), который отправляет событие в канал Go без блокировки рабочих горутин.

## Подводные камни

Канал сигналов `make(chan os.Signal, 1)` обязан быть буферизованным, иначе сигнал ядра может быть утерян.

## На собеседовании

**Вопрос с собеседования:** «Как отправить SIGUSR1 процессу в Kubernetes pod?»
**Ответ:** Выполнить команду `kubectl exec pod-name -- kill -SIGUSR1 1` (где 1 — PID основного процесса контейнера).
