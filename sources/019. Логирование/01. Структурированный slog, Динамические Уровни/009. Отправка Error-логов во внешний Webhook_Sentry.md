# Отправка Error-логов во внешний Webhook/Sentry через кастомный slog.Handler

## Условие

Реализуйте `slog.Handler`, который отправляет `Error`-логи в Sentry или аналогичную систему (через HTTP-запрос).

## Теория

Интеграция с системами мониторинга ошибок (Sentry, Bugsnag, Alertmanager) строится как специализированный `slog.Handler`, перехватывающий записи с `r.Level >= slog.LevelError` и отправляющий JSON-payload в асинхронный HTTP-канал.

## Решение по шагам

1. Создадим структуру `SentryHandler struct { next slog.Handler; webhookURL string }`.
2. В методе `Handle(ctx, r)` проверим `if r.Level >= slog.LevelError`.
3. Соберем атрибуты ошибки и отправим POST запрос.
4. В `main` сымитируем HTTP-сервер Sentry через `httptest.Server` и протестируем отправку.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"context"
	"encoding/json"
	"fmt"
	"log/slog"
	"net/http"
	"net/http/httptest"
	"os"
)

type SentryAlertHandler struct {
	baseHandler slog.Handler
	sentryURL   string
}

func (h *SentryAlertHandler) Enabled(ctx context.Context, level slog.Level) bool {
	return h.baseHandler.Enabled(ctx, level)
}

func (h *SentryAlertHandler) Handle(ctx context.Context, r slog.Record) error {
	// 1. Всегда пишем в базовый stdout
	_ = h.baseHandler.Handle(ctx, r)

	// 2. Если ошибка — отправляем алерт во внешний Webhook
	if r.Level >= slog.LevelError {
		payload := map[string]any{
			"timestamp": r.Time,
			"message":   r.Message,
			"level":     r.Level.String(),
		}
		r.Attrs(func(a slog.Attr) bool {
			payload[a.Key] = a.Value.Any()
			return true
		})

		body, _ := json.Marshal(payload)
		// Асинхронная отправка (симуляция)
		go func(data []byte) {
			_, _ = http.Post(h.sentryURL, "application/json", bytes.NewReader(data))
		}(body)
	}
	return nil
}

func (h *SentryAlertHandler) WithAttrs(attrs []slog.Attr) slog.Handler {
	return &SentryAlertHandler{baseHandler: h.baseHandler.WithAttrs(attrs), sentryURL: h.sentryURL}
}

func (h *SentryAlertHandler) WithGroup(name string) slog.Handler {
	return &SentryAlertHandler{baseHandler: h.baseHandler.WithGroup(name), sentryURL: h.sentryURL}
}

func main() {
	// Симуляция сервера Sentry
	sentryMock := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		var alert map[string]any
		_ = json.NewDecoder(r.Body).Decode(&alert)
		fmt.Printf("[SENTRY ALERT RECEIVED] Ошибка: %s | Детали: %v\n", alert["message"], alert["component"])
		w.WriteHeader(http.StatusOK)
	}))
	defer sentryMock.Close()

	handler := &SentryAlertHandler{
		baseHandler: slog.NewJSONHandler(os.Stdout, nil),
		sentryURL:   sentryMock.URL,
	}
	logger := slog.New(handler)

	logger.Info("Штатный запуск модуля")
	logger.Error("Падение пула соединений", slog.String("component", "RedisCluster"), slog.Int("retries", 3))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Штатный запуск модуля"}
# {"time":"2026-09-02T18:40:00Z","level":"ERROR","msg":"Падение пула соединений","component":"RedisCluster","retries":3}
# [SENTRY ALERT RECEIVED] Ошибка: Падение пула соединений | Детали: RedisCluster
```

## Под капотом

Метод `r.Attrs(func(a slog.Attr) bool)` итерируется по всем атрибутам записи `slog.Record` без лишних аллокаций памяти.

## Подводные камни

Никогда не делайте синхронный сетевой `http.Post` внутри метода `Handle`, иначе сетевые задержки Sentry заблокируют выполнение всей программы. Используйте буферизованную очередь горутин.

## На собеседовании

**Вопрос с собеседования:** «Как защитить сервис от падения, если Sentry недоступен или тормозит?»
**Ответ:** Использовать неблокирующую отправку в кольцевой буфер (Ring Buffer) ограниченного размера (`chan AlertPayload` с `select default`). При переполнении буфера старые алерты сбрасываются (Drop Oldest), сохраняя стабильность основного сервиса.
