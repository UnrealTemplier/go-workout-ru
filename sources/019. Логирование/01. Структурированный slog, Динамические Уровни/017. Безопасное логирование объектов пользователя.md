# Безопасное логирование объектов пользователя без утечки паролей

## Условие

**[Каверзный кейс]**: Логирование секретов. Напиши структуру `User` с методом `LogValue() slog.Value`, который возвращает только `id` и `name`, скрывая поле `password`. Передай структуру в `slog.Info`.

## Теория

Реализация метода `LogValue()` с белым списком разрешенных полей гарантирует, что даже при добавлении новых секретных полей в структуру `User` они никогда случайно не попадут в логи.

## Решение по шагам

1. Объявим структуру `User struct { ID int; Name string; PasswordHash string; SecretSalt string }`.
2. Реализуем `(u User) LogValue() slog.Value`.
3. Внутри метода вернем только безопасные поля `ID` и `Name`.
4. В `main` вызовем `logger.Info`.

## Код решения

**`main.go`**

```go
package main

import (
	"log/slog"
	"os"
)

type UserAccount struct {
	ID           int
	Name         string
	PasswordHash string
	SecretSalt   string
}

// LogValue гарантирует белый список логируемых полей
func (u UserAccount) LogValue() slog.Value {
	return slog.GroupValue(
		slog.Int("id", u.ID),
		slog.String("name", u.Name),
	)
}

func main() {
	logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

	account := UserAccount{
		ID:           501,
		Name:         "Dmitry",
		PasswordHash: "$2a$12$e8Y9X7U8J8K9...",
		SecretSalt:   "0xDEADBEEF99",
	}

	logger.Info("Сессия пользователя создана", "account", account)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Сессия пользователя создана","account":{"id":501,"name":"Dmitry"}}
```

## Под капотом

`slog.GroupValue` создает объект `slog.Value` с типом `KindGroup`.

## Подводные камни

Если забыть объявить `LogValue`, `slog` через рефлексию выведет все экспортируемые поля структуры вместе с хэшами паролей!

## На собеседовании

**Вопрос с собеседования:** «Почему маскирование через LogValue надежнее ручного удаления полей перед каждым вызовом лога?»
**Ответ:** Ручное маскирование подвержено человеческому фактору: разработчик может забыть замаскировать поле в одном из 50 мест кодовой базы. `LogValue` централизованно защищает структуру во всех вызовах логирования.
