# Иерархическая группировка атрибутов через slog.Group и slog.Attr

## Условие

Используйте `slog.Attr` и `slog.Group` для создания вложенных структур в логах (например, `"request": {"method": "GET", "path": "/api"}`).

## Теория

`slog.Group(key, attrs...)` объединяет группу атрибутов во вложенный JSON-объект. Это структурирует логи сложных подсистем (HTTP-запрос, метаданные клиента, параметры БД).

## Решение по шагам

1. Создадим JSON-логгер.
2. Сформируем группу `"http_request"` с полями `method`, `path`, `status`.
3. Сформируем группу `"client"` с полями `ip`, `geo`.
4. Выведем лог через `logger.Info`.

## Код решения

**`main.go`**

```go
package main

import (
	"log/slog"
	"os"
)

func main() {
	logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

	// Логирование с вложенными группами
	logger.Info("Обработан входящий платеж",
		slog.Int("order_id", 99482),
		slog.Group("http",
			slog.String("method", "POST"),
			slog.String("path", "/api/v2/checkout"),
			slog.Int("status_code", 200),
		),
		slog.Group("geo_client",
			slog.String("ip", "195.201.45.12"),
			slog.String("country", "RU"),
			slog.String("city", "Moscow"),
		),
	)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Обработан входящий платеж","order_id":99482,"http":{"method":"POST","path":"/api/v2/checkout","status_code":200},"geo_client":{"ip":"195.201.45.12","country":"RU","city":"Moscow"}}
```

## Под капотом

`slog.Group` открывает новый фигурный блок `{` в JSON-буфере и рекурсивно сериализует дочерние атрибуты с префиксом группы.

## Подводные камни

Пустая группа `slog.Group("empty")` без дочерних атрибутов будет полностью опущена в выводе.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие slog.Group("req", ...) от logger.WithGroup("req")?»
**Ответ:** `slog.Group` оборачивает во вложенный объект только конкретные атрибуты одного вызова лога. `logger.WithGroup` возвращает новый дочерний логгер, у которого **все последующие** логи и добавленные атрибуты навсегда будут помещены внутрь указанной группы.
