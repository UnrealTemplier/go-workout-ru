# Интерфейс slog.LogValuer для кастомного маскирования структур

## Условие

**Маскирование чувствительных данных**: Логировать пароли или номера карт — преступление. Создай структуру `User{Email, Password}`. Реализуй для неё интерфейс `slog.LogValuer` (метод `LogValue() slog.Value`), в котором поле `Password` заменяется на `"***"`. Передай структуру в `slog.Info` и проверь вывод.

## Теория

Интерфейс `slog.LogValuer` с методом `LogValue() slog.Value` позволяет типам самостоятельно контролировать, как именно они сериализуются в логи. Это обеспечивает 100% гарантию защиты от утечек секретов при передаче объекта в любой логгер.

## Решение по шагам

1. Объявим `type User struct { Email string; Password string; CardNumber string }`.
2. Реализуем метод `(u User) LogValue() slog.Value`.
3. Внутри метода вернем `slog.GroupValue(...)` с замаскированными полями.
4. В `main` передадим структуру `User` в `slog.Info("создан пользователь", "user", u)`.

## Код решения

**`main.go`**

```go
package main

import (
	"log/slog"
	"os"
)

type User struct {
	Email      string
	Password   string
	CardNumber string
}

// LogValue реализует интерфейс slog.LogValuer
func (u User) LogValue() slog.Value {
	return slog.GroupValue(
		slog.String("email", u.Email),
		slog.String("password", "********"),
		slog.String("card_number", "****-****-****-"+u.CardNumber[len(u.CardNumber)-4:]),
	)
}

func main() {
	logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

	user := User{
		Email:      "cto@fintech.io",
		Password:   "VerySecretPassword99!",
		CardNumber: "4276123456789876",
	}

	// Передаем весь объект напрямую в лог
	logger.Info("Профиль пользователя обновлен", "user", user)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Профиль пользователя обновлен","user":{"email":"cto@fintech.io","password":"********","card_number":"****-****-****-9876"}}
```

## Под капотом

`slog` проверяет наличие метода `LogValue()` у переданного значения через утверждение типа интерфейса `slog.LogValuer` до начала сериализации в JSON.

## Подводные камни

Если объявить метод на указателе `(u *User) LogValue()`, а в лог передать структуру по значению `user` (не `&user`), интерфейс не сработает и секреты утекут! Реализуйте метод на значении `(u User)` или всегда передавайте указатель.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие slog.LogValuer от интерфейса fmt.Stringer?»
**Ответ:** `fmt.Stringer` превращает весь объект в единую плоскую строку `string`. `slog.LogValuer` возвращает структурированный `slog.Value` (включая группы, списки и типизированные атрибуты), сохраняя JSON-схему лога.
