# Zero-Allocation логирование в горячих путях через slog.LogAttrs

## Условие

Используйте `slog.LogAttrs` для zero-allocation логирования в горячих путях (high-performance logging без аллокаций).

## Теория

Обычный вызов `logger.Info(msg, "key", val)` упаковывает аргументы в срез `...any`, что создает аллокацию памяти в куче для каждого аргумента (boxing interface{}). Метод `logger.LogAttrs(ctx, level, msg, attrs...)` принимает строго типизированные `slog.Attr`, обеспечивая **0 аллокаций памяти**.

## Решение по шагам

1. Создадим JSON-логгер.
2. Подготовим типизированные атрибуты `slog.Int64`, `slog.String`, `slog.Float64`.
3. Вызовем `logger.LogAttrs(ctx, slog.LevelInfo, "HotPath Event", ...)`.
4. В `main` убедимся в корректном выводе.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"log/slog"
	"os"
)

func main() {
	logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
	ctx := context.Background()

	// HighLoad Zero-Allocation вызов без упаковки в ...any:
	logger.LogAttrs(ctx, slog.LevelInfo, "Order Processed Fast",
		slog.Int64("order_id", 88910293),
		slog.String("currency", "RUB"),
		slog.Float64("price", 1990.50),
		slog.Bool("is_vip", true),
	)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Order Processed Fast","order_id":88910293,"currency":"RUB","price":1990.5,"is_vip":true}
```

## Под капотом

`slog.Attr` — это структура из двух полей (`string` и `slog.Value`), где базовые числа хранятся в 64-битном поле без выделения памяти в куче.

## Подводные камни

Вызов `slog.Any("key", val)` для кастомных структур все равно аллоцирует память. Для структур реализуйте `slog.LogValuer`.

## На собеседовании

**Вопрос с собеседования:** «Почему logger.Info("msg", "key", 10) аллоцирует память, а logger.LogAttrs(ctx, LevelInfo, "msg", slog.Int("key", 10)) — нет?»
**Ответ:** Нетипизированный `logger.Info` принимает `...any`. Приведение числа `10` к `any` (interface{}) заставляет рантайм Go выделить память в куче (Escape to heap / boxing). `slog.Int` возвращает структуру `slog.Attr` со значением на стеке без упаковки в интерфейс.
