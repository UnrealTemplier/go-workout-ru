# Интеграция slog с OpenTelemetry: Trace ID и Span ID корреляция

## Условие

Напишите интеграцию `slog` с OpenTelemetry: каждый лог автоматически содержит `trace_id` и `span_id` текущего span'а для корреляции логов с трейсами.

## Теория

Log-to-Trace Correlation (корреляция логов и распределенных трейсов) связывает каждую строчку лога с графиком трассировки запроса в Jaeger/Grafana Tempo через поля `trace_id` и `span_id`.

## Решение по шагам

1. Создадим структуру контекста с идентификаторами `trace_id` (128-бит hex) и `span_id` (64-бит hex).
2. Напишем `OtelTracingHandler`, извлекающий `TraceID` из `ctx` и добавляющий их в запись лога.
3. В `main` вызовем `logger.InfoContext(ctx, "обработка запроса")`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log/slog"
	"os"
)

type traceContextKey struct{}

type TraceSpanInfo struct {
	TraceID string
	SpanID  string
}

type OtelTracingHandler struct {
	slog.Handler
}

func (h *OtelTracingHandler) Handle(ctx context.Context, r slog.Record) error {
	if span, ok := ctx.Value(traceContextKey{}).(TraceSpanInfo); ok {
		r.AddAttrs(
			slog.String("trace_id", span.TraceID),
			slog.String("span_id", span.SpanID),
		)
	}
	return h.Handler.Handle(ctx, r)
}

func main() {
	baseJSON := slog.NewJSONHandler(os.Stdout, nil)
	otelHandler := &OtelTracingHandler{Handler: baseJSON}
	logger := slog.New(otelHandler)

	// Имитация контекста со спаном OpenTelemetry
	ctx := context.WithValue(context.Background(), traceContextKey{}, TraceSpanInfo{
		TraceID: "4bf92f3577b34da6a3ce929d0e0e4736",
		SpanID:  "00f067aa0ba902b7",
	})

	fmt.Println("--- Логирование с Trace Correlation ---")
	logger.InfoContext(ctx, "gRPC вызов к сервису авторизации",
		slog.String("peer.service", "auth-v2"),
		slog.Int("rpc.status_code", 0),
	)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- Логирование с Trace Correlation ---
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"gRPC вызов к сервису авторизации","peer.service":"auth-v2","rpc.status_code":0,"trace_id":"4bf92f3577b34da6a3ce929d0e0e4736","span_id":"00f067aa0ba902b7"}
```

## Под капотом

В реальном OpenTelemetry Go SDK вызов `trace.SpanFromContext(ctx).SpanContext()` возвращает `trace.TraceID` и `trace.SpanID`.

## Подводные камни

Форматируйте `TraceID` строго как 32-символьную hex-строку, а `SpanID` как 16-символьную hex-строку в нижнем регистре по спецификации W3C Trace Context.

## На собеседовании

**Вопрос с собеседования:** «Как инженер по щелчку мыши в Grafana Loki переходит в трейс Jaeger?»
**Ответ:** Grafana парсит поле `trace_id` из JSON-лога и формирует прямую ссылку (Derived Field) на дэшборд Tempo/Jaeger `https://tempo/trace/${__value.raw}`, мгновенно открывая таймлайн всех спанов запроса.
