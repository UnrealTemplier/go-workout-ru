# Маскирование персональных данных (PII) через ReplaceAttr в slog

## Условие

Настройте глобальный `slog.Logger` с `JSONHandler` и `ReplaceAttr` для маскировки PII-данных (email, телефон, password → `***`).

## Теория

Функция `ReplaceAttr` в `slog.HandlerOptions` перехватывает каждый атрибут перед записью. Это позволяет централизованно маскировать персональные данные (Personally Identifiable Information — PII) в соответствии с законами о защите персональных данных (152-ФЗ, GDPR, PCI-DSS).

## Решение по шагам

1. Объявим функцию `sanitizeAttrs(groups []string, a slog.Attr) slog.Attr`.
2. Проверим ключ `a.Key`: для `password`, `email`, `phone`, `card_number` заменим значение на `"***"`.
3. Инициализируем `slog.NewJSONHandler` с этой опцией.
4. В `main` вызовем логирование и убедимся, что секреты скрыты.

## Код решения

**`main.go`**

```go
package main

import (
	"log/slog"
	"os"
	"strings"
)

func sanitizePII(groups []string, a slog.Attr) slog.Attr {
	// Список конфиденциальных ключей для маскирования
	switch strings.ToLower(a.Key) {
	case "password", "token", "secret", "cvv":
		return slog.String(a.Key, "[REDACTED]")
	case "email":
		// Частичное маскирование email: a***@corp.ru
		emailStr := a.Value.String()
		if parts := strings.Split(emailStr, "@"); len(parts) == 2 && len(parts[0]) > 0 {
			masked := string(parts[0][0]) + "***@" + parts[1]
			return slog.String(a.Key, masked)
		}
		return slog.String(a.Key, "***@***")
	case "phone":
		return slog.String(a.Key, "+7-***-***-**-99")
	}
	return a
}

func main() {
	opts := &slog.HandlerOptions{
		ReplaceAttr: sanitizePII,
	}
	handler := slog.NewJSONHandler(os.Stdout, opts)
	logger := slog.New(handler)
	slog.SetDefault(logger)

	slog.Info("Регистрация нового пользователя",
		slog.String("username", "alex_dev"),
		slog.String("email", "alexander.ivanov@company.ru"),
		slog.String("phone", "+79991234599"),
		slog.String("password", "SuperSecretP@ss123"),
	)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Регистрация нового пользователя","username":"alex_dev","email":"a***@company.ru","phone":"+7-***-***-**-99","password":"[REDACTED]"}
```

## Под капотом

`ReplaceAttr` вызывается на этапе обхода дерева атрибутов. Если вернуть пустой атрибут `slog.Attr{}`, поле будет полностью удалено из итогового JSON.

## Подводные камни

`ReplaceAttr` проверяет только имена ключей первого уровня, если не учитывать срез `groups` для вложенных структур.

## На собеседовании

**Вопрос с собеседования:** «Как удалить ключ time или level из вывода slog через ReplaceAttr?»
**Ответ:** Проверить `if a.Key == slog.TimeKey { return slog.Attr{} }`. Возврат нулевой структуры `slog.Attr{}` полностью удаляет встроенное поле из JSON.
