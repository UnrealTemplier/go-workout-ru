# Кастомный LogValuer для вывода time.Duration в миллисекундах

## Условие

Создай кастомный `LogValuer` для `time.Duration`, чтобы в логах длительность выводилась в миллисекундах, а не в наносекундах.

## Теория

По умолчанию `slog.JSONHandler` сериализует `time.Duration` в наносекундах (целое число), что затрудняет чтение человеком. Обертка `type Millis time.Duration` с методом `LogValue()` форматирует время в виде дробных миллисекунд `15.42ms` или числа `15.42`.

## Решение по шагам

1. Объявим тип `type LatencyMs time.Duration`.
2. Реализуем метод `(l LatencyMs) LogValue() slog.Value`.
3. Внутри метода вернем `slog.Float64Value(float64(time.Duration(l).Microseconds()) / 1000.0)`.
4. В `main` проверим красивый вывод задержки в миллисекундах.

## Код решения

**`main.go`**

```go
package main

import (
	"log/slog"
	"os"
	"time"
)

type Millis time.Duration

func (m Millis) LogValue() slog.Value {
	ms := float64(time.Duration(m).Microseconds()) / 1000.0
	return slog.Float64Value(ms)
}

func main() {
	logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

	duration := 15420 * time.Microsecond // 15.42 мс

	logger.Info("Вызов внешнего API завершен",
		slog.String("endpoint", "https://api.payment.corp/charge"),
		slog.Any("latency_ms", Millis(duration)),
	)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"time":"2026-09-02T18:40:00Z","level":"INFO","msg":"Вызов внешнего API завершен","endpoint":"https://api.payment.corp/charge","latency_ms":15.42}
```

## Под капотом

`slog.Float64Value` создает структуру значения с типом `KindFloat64` без упаковки в `interface{}`.

## Подводные камни

Использование `time.Duration.Milliseconds()` отбрасывает дробную часть (15 вместо 15.42). Для точности делите микросекунды на 1000.0.

## На собеседовании

**Вопрос с собеседования:** «Почему Prometheus и OpenTelemetry рекомендуют хранить задержки в секундах или миллисекундах float64?»
**Ответ:** Чтобы использовать стандартные единицы измерения СИ для агрегации перцентилей (p50, p95, p99) и вычисления средних значений без путаницы с множителями \(10^9\).
