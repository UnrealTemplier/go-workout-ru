# Стриминг биржевых котировок с дельта-кодированием (Delta-Only Updates)

## Условие

51. **Stock ticker streaming**: Real-time обновление цен акций через SSE с delta-only updates (отправляйте только изменения).

### Исходная формулировка

**Stock ticker streaming**: Real-time обновление цен акций через SSE с delta-only updates (отправляйте только изменения).

## Теория

При трансляции сотен биржевых котировок (Order Book, Tickers) отправка полного слепка каждого инструмента при малейшем изменении генерирует огромный сетевой трафик.

Паттерн Delta-Only Updates (Разностное кодирование):
1. **Первичный снимок (Snapshot):** При коннекте клиент получает полную таблицу цен: `{ "AAPL": 185.2, "GOOG": 175.4, "MSFT": 420.1 }`.
2. **Дельта (Diff):** Сервер отслеживает предыдущее состояние инструмента. Если изменилась только цена акции `AAPL`, сервер шлет миниатюрное событие:
   ```http
   event: delta
   data: {"s":"AAPL","p":185.5,"d":0.3}
   
   ```
3. Клиент применяет дельту к своей локальной таблице в оперативной памяти.
4. Трафик сокращается на 85-95%.

## Решение по шагам

1. Создайте структуру биржевого тикера `TickerState`.
2. Реализуйте кэш последних состояний на стороне сервера.
3. Перед отправкой проверяйте, изменилась ли цена по сравнению с предыдущим тиком.
4. Отправляйте только поля `Symbol`, `Price` и `Diff`.

## Код решения

**`ticker_stream.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"math"
	"math/rand"
	"net/http"
	"time"
)

type StockDelta struct {
	Symbol string  `json:"s"`
	Price  float64 `json:"p"`
	Delta  float64 `json:"d"`
}

func stockStreamHandler(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "text/event-stream")
	w.Header().Set("Cache-Control", "no-cache")
	w.Header().Set("Connection", "keep-alive")

	rc := http.NewResponseController(w)

	// Локальный кэш текущих цен
	prices := map[string]float64{
		"YNDX": 4120.0,
		"OZON": 3210.5,
		"SBER": 285.0,
	}

	// 1. Отправляем начальное состояние всех котировок
	initBytes, _ := json.Marshal(prices)
	fmt.Fprintf(w, "event: snapshot\ndata: %s\n\n", initBytes)
	_ = rc.Flush()

	ticker := time.NewTicker(500 * time.Millisecond)
	defer ticker.Stop()

	symbols := []string{"YNDX", "OZON", "SBER"}

	for {
		select {
		case <-r.Context().Done():
			return
		case <-ticker.C:
			// Выбираем случайную акцию для изменения цены
			sym := symbols[rand.Intn(len(symbols))]
			change := (rand.Float64() - 0.48) * 5.0 // Небольшое колебание
			newPrice := math.Round((prices[sym]+change)*100) / 100

			// Если цена фактически изменилась — шлем дельту
			if newPrice != prices[sym] {
				delta := math.Round((newPrice-prices[sym])*100) / 100
				prices[sym] = newPrice

				update := StockDelta{
					Symbol: sym,
					Price:  newPrice,
					Delta:  delta,
				}
				data, _ := json.Marshal(update)
				if _, err := fmt.Fprintf(w, "event: delta\ndata: %s\n\n", data); err != nil {
					return
				}
				if err := rc.Flush(); err != nil {
					return
				}
			}
		}
	}
}

func main() {
	http.HandleFunc("/stocks/stream", stockStreamHandler)
	fmt.Println("Stock ticker delta stream running on :8080/stocks/stream")
	_ = http.ListenAndServe(":8080", nil)
}
```

ℹ️ Дельта-кодирование котировок с отправкой только изменившихся позиций цен

## Под капотом

Дельта-кодирование минимизирует как сериализацию в Go (короткий JSON из 3 полей вместо объекта из сотен позиций), так и парсинг в браузере. В браузерном JavaScript обновление поля в хэш-таблице `cache[delta.s] = delta.p` занимает константное время \(O(1)\) без аллокаций памяти.

## Подводные камни

Рассинхронизация состояния при потере пакетов или реконнекте. Если клиент пропустил дельту, его локальное состояние станет неконсистентным. Для решения этой проблемы сервер должен периодически (например, раз в минуту) отправлять полный контрольный `snapshot`, либо клиент должен валидировать сквозной счетчик `version`.

## На собеседовании

В Московской Бирже (MOEX) и Tinkoff часто спрашивают: 'Как передавать котировки со скоростью 50 000 обновлений в секунду в браузер?' Ответ: объединять Conflation (сжатие нескольких изменений одной акции в единый срез за интервал 100 мс) и Delta-кодирование. Браузер физически не способен отрисовать 50k обновлений в секунду, поэтому отправляется только последняя цена каждого инструмента на конец интервала.
