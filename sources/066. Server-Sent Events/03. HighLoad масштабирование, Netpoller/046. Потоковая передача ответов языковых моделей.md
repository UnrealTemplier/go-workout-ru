# Потоковая передача ответов языковых моделей (ChatGPT-style Streaming)

## Условие

46. **ChatGPT-style streaming**: Реализуйте streaming LLM responses через SSE: каждый токен — отдельное событие `data: {"token": "Hello"}\n\n`, финальное `data: [DONE]\n\n`.

### Исходная формулировка

**ChatGPT-style streaming**: Реализуйте streaming LLM responses через SSE: каждый токен — отдельное событие `data: {"token": "Hello"}\n\n`, финальное `data: [DONE]\n\n`.

## Теория

Протокол потоковой генерации ответов больших языковых моделей (OpenAI Chat Completions Streaming API) стал де-факто стандартом индустрии GenAI:
1. По мере генерации моделью каждого следующего токена сервер отправляет компактный JSON-объект в формате SSE.
2. Фронтенд моментально отображает токен в интерфейсе, создавая эффект 'печатающегося текста' (Typewriter effect) и минимизируя воспринимаемую пользователем задержку (TTFT — Time to First Token).
3. По завершении генерации сервер отправляет специальный терминальный маркер:
   `data: [DONE]\n\n`
4. Клиент, встретив строку `[DONE]`, завершает стрим, отключает `EventSource` и переводит интерфейс в состояние ожидания следующего запроса.

## Решение по шагам

1. Создайте HTTP-хэндлер `/v1/chat/completions`.
2. Установите заголовки SSE и вызовите `Flush()`.
3. В цикле эмулируйте или проксируйте генерацию токенов нейросетью.
4. Отправляйте каждый токен в формате `data: {"token": "..."}\n\n`.
5. По завершении генерации отправьте маркер завершения `data: [DONE]\n\n`.

## Код решения

**`llm_stream.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"time"
)

type TokenChunk struct {
	Token string `json:"token"`
	Index int    `json:"index"`
}

func chatStreamHandler(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "text/event-stream")
	w.Header().Set("Cache-Control", "no-cache")
	w.Header().Set("Connection", "keep-alive")
	w.Header().Set("X-Accel-Buffering", "no")

	rc := http.NewResponseController(w)

	// Имитация ответа языковой модели
	responseTokens := []string{
		"Golang", " —", " это", " компилируемый,", " многопоточный",
		" язык", " программирования,", " разработанный", " Google.",
	}

	for i, token := range responseTokens {
		select {
		case <-r.Context().Done():
			// Пользователь отменил генерацию
			fmt.Println("Generation aborted by user.")
			return
		default:
		}

		payload, _ := json.Marshal(TokenChunk{
			Token: token,
			Index: i,
		})

		// Отправляем токен
		if _, err := fmt.Fprintf(w, "data: %s\n\n", payload); err != nil {
			return
		}
		if err := rc.Flush(); err != nil {
			return
		}

		// Имитация скорости генерации LLM (50 мс на токен)
		time.Sleep(50 * time.Millisecond)
	}

	// Финальный маркер завершения по стандарту OpenAI
	_, _ = fmt.Fprintf(w, "data: [DONE]\n\n")
	_ = rc.Flush()
}

func main() {
	http.HandleFunc("/v1/chat/completions", chatStreamHandler)
	fmt.Println("LLM Streaming API server running on :8080/v1/chat/completions")
	_ = http.ListenAndServe(":8080", nil)
}
```

**`client.js`**

```javascript
// JavaScript клиент на базе fetch и ReadableStream (для поддержки POST с телом)
async function streamChat(prompt) {
    const response = await fetch('/v1/chat/completions', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ prompt: prompt })
    });

    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let accumulatedText = "";

    while (true) {
        const { value, done } = await reader.read();
        if (done) break;

        const chunk = decoder.decode(value);
        const lines = chunk.split('\n');

        for (const line of lines) {
            if (line.startsWith('data: ')) {
                const data = line.slice(6).trim();
                if (data === '[DONE]') {
                    console.log("Generation complete!");
                    return;
                }
                const parsed = JSON.parse(data);
                accumulatedText += parsed.token;
                document.getElementById('output').innerText = accumulatedText;
            }
        }
    }
}
```

## Под капотом

Для передачи промпта в LLM требуется отправка объемного тела запроса (`POST` с историей сообщений). Поскольку браузерный `EventSource` поддерживает только метод `GET`, все современные клиенты для ChatGPT-подобного стриминга используют `fetch()` с `response.body.getReader()`, реализуя легкий парсер формата `data:` вручную.

## Подводные камни

Потеря части байтов мультибайтового символа UTF-8 на границе TCP-пакета при некорректном декодировании. В Go при отправке токенов убедитесь, что токены не разрывают руны UTF-8, либо на клиенте используйте `TextDecoder({ stream: true })`.

## На собеседовании

В Яндекс (YandexGPT) и Сбер (GigaChat) на собеседовании спрашивают: 'Что делать, если пользователь нажал кнопку Стоп генерация?' Ответ: клиент вызывает `abortController.abort()`, соединение разрывается, на сервере срабатывает `<-r.Context().Done()`, и горутина должна немедленно прервать вызов инференса модели, экономя дорогостоящие мощности GPU.
