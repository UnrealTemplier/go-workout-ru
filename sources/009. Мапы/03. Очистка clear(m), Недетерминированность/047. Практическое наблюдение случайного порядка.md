# Практическое наблюдение случайного порядка for range по мапе

## Условие

Используй `for range` для итерации по мапе. Запусти несколько раз и убедись, что порядок случайный.

## Теория

Финальное закрепление механики рандомизации обхода.

## Решение по шагам

1. Создаем мапу дней недели.
2. Выводим 3 раза.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	days := map[int]string{
		1: "Пн", 2: "Вт", 3: "Ср", 4: "Чт", 5: "Пт", 6: "Сб", 7: "Вс",
	}

	for i := 1; i <= 3; i++ {
		fmt.Printf("Проход #%d: ", i)
		for k := range days {
			fmt.Printf("%d:%s ", k, days[k])
		}
		fmt.Println()
	}
}
```

ℹ️ Случайный порядок range

**`Терминал`**

```bash
go run main.go
# Проход #1: 1:Пн 2:Вт 3:Ср 4:Чт 5:Пт 6:Сб 7:Вс 
# Проход #2: 4:Чт 5:Пт 6:Сб 7:Вс 1:Пн 2:Вт 3:Ср 
# Проход #3: 7:Вс 1:Пн 2:Вт 3:Ср 4:Чт 5:Пт 6:Сб
```

ℹ️ Разный порядок

## Под капотом

Рантайм исключает скрытые баги порядка.

## Подводные камни

- Попытка сохранять индекс в мапе в надежде на упорядоченность.

## На собеседовании
