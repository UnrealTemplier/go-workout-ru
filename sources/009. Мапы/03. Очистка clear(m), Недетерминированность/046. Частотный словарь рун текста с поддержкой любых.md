# Частотный словарь рун текста с поддержкой любых Unicode символов

## Условие

Напишите функцию, которая принимает строку и возвращает мапу с частотой встречаемости каждого символа (rune) в ней.

## Теория

Универсальный частотный анализатор символов.

## Решение по шагам

1. Пишем `CountRunes(s string) map[rune]int`.
2. Тестируем на смешанном тексте.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func CountRunes(s string) map[rune]int {
	counts := make(map[rune]int)
	for _, r := range s {
		counts[r]++
	}
	return counts
}

func main() {
	text := "abracadabra 🌟"
	res := CountRunes(text)

	fmt.Println("Частота символов:")
	for r, count := range res {
		fmt.Printf("  • %c -> %d\n", r, count)
	}
}
```

ℹ️ Частота рун

**`Терминал`**

```bash
go run main.go
# Частота символов:
#   • a -> 5
#   • b -> 2
#   • r -> 2
#   • c -> 1
#   • d -> 1
#   •   -> 1
#   • 🌟 -> 1
```

ℹ️ Вывод

## Под капотом

`utf8.DecodeRuneInString` в цикле `for range`.

## Подводные камни

- Использование `map[byte]int` для не-ASCII строк.

## На собеседовании

**Вопрос с собеседования:** «Как проверить, являются ли две строки анаграммами?»
**Ответ:** Посчитать `CountRunes` для обеих строк и сравнить через `maps.Equal(m1, m2)`.
