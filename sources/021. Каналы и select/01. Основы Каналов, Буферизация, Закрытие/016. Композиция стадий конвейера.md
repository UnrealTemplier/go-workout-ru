# Композиция стадий конвейера: Generate -> Square -> Consumer

## Условие

Соедини генератор и `Square` в pipeline: `for v := range Square(Generate(2, 3, 4, 5)) { fmt.Println(v) }`. Покажи композицию стадий.

## Теория

Композиция стадий конвейера позволяет выстраивать сложные потоки обработки данных в виде элегантной цепочки функций: `Stage3(Stage2(Stage1(Source)))`.

## Решение по шагам

1. Реализуем функцию-генератор `Generate(nums ...int) <-chan int`.
2. Реализуем стадию `Square(in <-chan int) <-chan int`.
3. Соединим их в единую цепочку `Square(Generate(2, 3, 4, 5))`.
4. Выведем результат в цикле `for range`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func Generate(nums ...int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out)
		for _, n := range nums {
			out <- n
		}
	}()
	return out
}

func Square(in <-chan int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out)
		for n := range in {
			out <- n * n
		}
	}()
	return out
}

func main() {
	fmt.Println("Запуск композиционного пайплайна:")

	// Элегантная функциональная композиция
	pipeline := Square(Generate(2, 3, 4, 5, 6))

	for v := range pipeline {
		fmt.Printf("Получен результат конвейера: %d\n", v)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:

# Получен результат конвейера: 4
# Получен результат конвейера: 9
# Получен результат конвейера: 16
# Получен результат конвейера: 25
# Получен результат конвейера: 36
```

## Под капотом

Каждая стадия работает асинхронно, передавая данные через каналы без накопления промежуточных срезов в оперативной памяти.

## Подводные камни

Если одна из стадий конвейера завершится раньше времени (например, по ошибке), входной генератор может зависнуть на записи. Для защиты передают канал отмены `done <-chan struct{}`.

## На собеседовании

**Вопрос с собеседования:** «Как предотвратить утечку горутин в конвейере при досрочном выходе потребителя?»
**Ответ:** Передавать во все стадии конвейера канал отмены `done <-chan struct{}` или `context.Context` и производить отправку через `select { case out <- v: case <-done: return }`.
