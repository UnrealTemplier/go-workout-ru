# Паттерн Done Channel: отмена долгоживущих горутин через закрытие канала

## Условие

Напиши **"done channel" pattern**: функция `LongRunning(done <-chan struct{})` читает из `done` в `select`. При получении сигнала — выходит. Покажи graceful cancellation через закрытие done-канала.

## Теория

Паттерн Done Channel (`done := make(chan struct{})`) — фундамент контекстной отмены в Go. Закрытие `close(done)` генерирует неблокирующее событие для всех горутин, слушающих `case <-done` в `select`.

## Решение по шагам

1. Создадим функцию `LongRunningWorker(done <-chan struct{}, wg *sync.WaitGroup)`.
2. Внутри в цикле с `select` обрабатываем полезную работу или `<-done`.
3. В `main` вызовем `close(done)`.
4. Дождемся корректного завершения.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

func LongRunningWorker(id int, done <-chan struct{}, wg *sync.WaitGroup) {
	defer wg.Done()
	fmt.Printf("[Worker #%d] Старт фоновой обработки...\n", id)

	ticker := time.NewTicker(10 * time.Millisecond)
	defer ticker.Stop()

	for {
		select {
		case <-done: // Срабатывает мгновенно при close(done)
			fmt.Printf("[Worker #%d] Получен сигнал отмены (Done)! Очистка ресурсов...\n", id)
			return
		case t := <-ticker.C:
			fmt.Printf("[Worker #%d] Итерация в %s\n", id, t.Format("15:04:05.000"))
		}
	}
}

func main() {
	done := make(chan struct{})
	var wg sync.WaitGroup

	// Запускаем 2 воркеров
	for i := 1; i <= 2; i++ {
		wg.Add(1)
		go LongRunningWorker(i, done, &wg)
	}

	time.Sleep(35 * time.Millisecond)

	fmt.Println("\n[Main] Отправка сигнала остановки через close(done)...")
	close(done) // Широковещательное оповещение

	wg.Wait()
	fmt.Println("[Main] Все воркеры успешно остановились!")
}
```

**`Терминал`**


## Под капотом

Тип `struct{}` имеет нулевой размер (`0 bytes`), исключая любые аллокации памяти при закрытии канала.

## Подводные камни

Всегда останавливайте тикеры `defer ticker.Stop()`, чтобы избежать утечки таймеров в рантайме.

## На собеседовании

**Вопрос с собеседования:** «Почему в сигнальных каналах всегда используют chan struct{}, а не chan bool или chan int?»
**Ответ:** Потому что `struct{}` не занимает места в памяти (`unsafe.Sizeof(struct{}{}) == 0`), что оптимизирует использование кэша процессора и подчеркивает, что важен сам факт события, а не передаваемое значение.
