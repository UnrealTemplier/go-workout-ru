# Стадия конвейера Square: трансформация потока чисел

## Условие

Напиши функцию `Square(in <-chan int) <-chan int`, читающую из входного канала, возводящую в квадрат и пишущую в выходной. Закрой выходной канал при закрытии входного. Это **pipeline stage**.

## Теория

Стадия конвейера (Pipeline Stage) — это функция, принимающая входной канал `in <-chan T` и возвращающая новый выходной канал `<-chan R`. Внутри функции запускается горутина, которая считывает `in`, выполняет преобразование и обязательно закрывает выходной канал `close(out)` по завершении.

## Решение по шагам

1. Реализуем функцию `Square(in <-chan int) <-chan int`.
2. Создадим входной канал с числами.
3. Запустим конвейер и прочитаем квадраты чисел.
4. Проверим автоматическое закрытие.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

// Pipeline Stage: возведение в квадрат
func Square(in <-chan int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out) // Закрываем выходной канал при завершении входного
		for n := range in {
			out <- n * n
		}
	}()
	return out
}

func main() {
	// Входной генератор
	in := make(chan int)
	go func() {
		for _, v := range []int{2, 3, 4, 5} {
			in <- v
		}
		close(in)
	}()

	// Подключение стадии конвейера
	squares := Square(in)

	fmt.Println("Результаты работы стадии Square:")
	for val := range squares {
		fmt.Printf(" -> %d\n", val)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Результаты работы стадии Square:
#  -> 4
#  -> 9
#  -> 16
#  -> 25
```

## Под капотом

`defer close(out)` гарантирует передачу сигнала EOF следующей стадии конвейера.

## Подводные камни

Если забыть закрыть `out`, все последующие звенья конвейера зависнут в дедлоке.

## На собеседовании

**Вопрос с собеседования:** «Каковы свойства чистой стадии Pipeline в Go?»
**Ответ:** 1) Принимает `in <-chan T` и возвращает `<-chan R`. 2) Запускает собственную горутину внутри. 3) Закрывает выходной канал `out`, когда входной канал `in` закрывается и опустошается.
