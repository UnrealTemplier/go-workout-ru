# Функция Drain: безопасное вычитывание остатка из закрытого канала

## Условие

Покажи, что **чтение из закрытого канала** возвращает zero value и `ok=false`: `v, ok := <-ch`. Напиши функцию `Drain(ch <-chan int) []int`, которая забирает все оставшиеся значения после закрытия.

## Теория

Функция `Drain` собирает все накопившиеся в буфере закрытого канала элементы в срез до тех пор, пока `ok` не станет `false`.

## Решение по шагам

1. Создадим буферизованный канал `ch := make(chan int, 5)`.
2. Запишем туда несколько чисел и закроем `close(ch)`.
3. Реализуем функцию `Drain(ch <-chan int) []int`.
4. Проверим извлечение всех элементов.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func Drain(ch <-chan int) []int {
	var result []int
	for {
		val, ok := <-ch
		if !ok {
			break // Канал закрыт и весь буфер исчерпан
		}
		result = append(result, val)
	}
	return result
}

func main() {
	ch := make(chan int, 4)

	ch <- 100
	ch <- 200
	ch <- 300
	close(ch) // Закрываем канал с данными в буфере

	items := Drain(ch)
	fmt.Printf("Вычитано из закрытого канала через Drain: %v\n", items)

	// Повторная попытка чтения из пустого закрытого канала
	val, ok := <-ch
	fmt.Printf("Повторное чтение из пустого закрытого канала: val=%d, ok=%v\n", val, ok)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Вычитано из закрытого канала через Drain: [100 200 300]
# Повторное чтение из пустого закрытого канала: val=0, ok=false
```

## Под капотом

Цикл `for range ch` под капотом разворачивается компилятором именно в конструкцию `v, ok := <-ch; if !ok { break }`.

## Подводные камни

Если передать в `Drain` незакрытый канал, функция зависнет в дедлоке в ожидании `ok=false`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие for range ch от ручного цикла for с v, ok := <-ch?»
**Ответ:** Синтаксически они эквивалентны. `for range ch` компактнее, но `v, ok := <-ch` позволяет выполнять дополнительные проверки или использовать неблокирующий `select`.
