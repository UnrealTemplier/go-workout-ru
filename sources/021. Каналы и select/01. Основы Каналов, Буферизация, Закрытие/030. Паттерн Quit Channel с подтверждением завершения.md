# Паттерн Quit Channel с подтверждением завершения (Ack Channel)

## Условие

Напиши **"quit channel"** с обратной связью: горутина получает сигнал на остановку, делает cleanup и пишет в `quit` канал подтверждение. `main` ждёт подтверждения через `select`.

## Теория

Двухсторонний протокол остановки (Graceful Shutdown with Acknowledgment): главный поток отправляет сигнал в `stopChan`, воркер сбрасывает буферы/транзакции на диск и отправляет подтверждение в `ackChan`.

## Решение по шагам

1. Создадим каналы `stopChan := make(chan struct{})` и `ackChan := make(chan struct{})`.
2. В горутине слушаем `stopChan`, выполняем очистку и пишем в `ackChan`.
3. В `main` ждем `<-ackChan` с таймаутом безопасности.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func databaseFlusher(stop <-chan struct{}, ack chan<- struct{}) {
	fmt.Println("[Flusher] Фоновый сброс данных на диск запущен...")

	for {
		select {
		case <-stop:
			fmt.Println("[Flusher] Получен сигнал STOP: фиксация несохраненных транзакций...")
			time.Sleep(20 * time.Millisecond) // Симуляция fsync
			fmt.Println("[Flusher] Все данные записаны на диск. Отправка подтверждения ACK...")
			ack <- struct{}{}
			return
		default:
			time.Sleep(5 * time.Millisecond)
		}
	}
}

func main() {
	stopChan := make(chan struct{})
	ackChan := make(chan struct{})

	go databaseFlusher(stopChan, ackChan)

	time.Sleep(15 * time.Millisecond)

	fmt.Println("[Main] Инициирование Graceful Shutdown...")
	close(stopChan)

	// Ожидание подтверждения с защитным таймаутом
	select {
	case <-ackChan:
		fmt.Println("[Main] Подтверждение получено: сервис остановлен чисто!")
	case <-time.After(1 * time.Second):
		fmt.Println("[Main] ТАЙМАУТ: воркер не успел ответить, принудительное завершение")
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Flusher] Фоновый сброс данных на диск запущен...
# [Main] Инициирование Graceful Shutdown...
# [Flusher] Получен сигнал STOP: фиксация несохраненных транзакций...
# [Flusher] Все данные записаны на диск. Отправка подтверждения ACK...
# [Main] Подтверждение получено: сервис остановлен чисто!
```

## Под капотом

Связка двух каналов гарантирует завершение всех незавершенных операций ввода-вывода до завершения процесса `main()`.

## Подводные камни

Всегда сопровождайте ожидание `<-ackChan` защитным таймаутом `time.After`, чтобы зависший воркер не заблокировал завершение процесса навсегда.

## На собеседовании

**Вопрос с собеседования:** «Как устроен Graceful Shutdown в HTTP-сервере Go (http.Server.Shutdown)?»
**Ответ:** Метод `Shutdown(ctx)` перестает принимать новые TCP-соединения, закрывает слушающие сокеты и ждет завершения всех активных HTTP-хендлеров до истечения таймаута контекста.
