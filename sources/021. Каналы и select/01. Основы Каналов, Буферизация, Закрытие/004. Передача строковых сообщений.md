# Передача строковых сообщений через небуферизированный канал chan string

## Условие

Создайте небуферизированный канал `chan string`. Основная горутина отправляет сообщение, другая принимает и печатает.

## Теория

Каналы в Go строго типизированы. Канал `chan string` передает строковые заголовки (указатель на массив байт + длину).

## Решение по шагам

1. Создадим канал `msgChan := make(chan string)`.
2. Запустим горутину-приемник.
3. Отправим сообщение `"Hello from Main Goroutine"`.
4. Дождемся синхронизации.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	msgChan := make(chan string)
	var wg sync.WaitGroup

	wg.Add(1)
	go func() {
		defer wg.Done()
		msg := <-msgChan
		fmt.Printf("[Worker] Получено текстовое сообщение: %q\n", msg)
	}()

	fmt.Println("[Main] Отправка строки в канал...")
	msgChan <- "Hello from Main Goroutine"

	wg.Wait()
	fmt.Println("[Main] Передача строки завершена успешно!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Main] Отправка строки в канал...
# [Worker] Получено текстовое сообщение: "Hello from Main Goroutine"
# [Main] Передача строки завершена успешно!
```

## Под капотом

Заголовок `string` (16 байт) копируется в приемник без копирования самого подлежащего массива символов.

## Подводные камни

Не забывайте дожидаться фоновой горутины через `sync.WaitGroup`, иначе `main()` выйдет до завершения печати.

## На собеседовании

**Вопрос с собеседования:** «Каков размер канала как типа данных в Go?»
**Ответ:** Переменная типа `chan T` является указателем `*runtime.hchan` и занимает ровно 8 байт на 64-битной платформе. При передаче канала в функции он передается по ссылке.
