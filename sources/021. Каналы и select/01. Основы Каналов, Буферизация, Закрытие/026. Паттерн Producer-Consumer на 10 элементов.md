# Паттерн Producer-Consumer на 10 элементов с for range и close()

## Условие

Используй `close(ch)` для сигнализации о завершении. Запусти горутину-продюсер, которая пишет 10 чисел и закрывает канал. В `main` читай через `for v := range ch`. Покажи, что цикл завершается при закрытии.

## Теория

Связка продюсера с `close(ch)` и потребителя с `for v := range ch` — самый лаконичный и безопасный паттерн потоковой обработки данных в Go.

## Решение по шагам

1. Создадим канал `stream := make(chan int)`.
2. В горутине запишем 10 чисел и вызовем `close(stream)`.
3. В `main` прочитаем через `for v := range stream`.
4. Убедимся в чистоте завершения.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func main() {
	stream := make(chan int)

	// Горутина-продюсер
	go func() {
		for i := 1; i <= 5; i++ {
			stream <- i * 10
		}
		close(stream) // Сигнал окончания потока
	}()

	fmt.Println("Чтение элементов через for range:")
	count := 0
	for item := range stream {
		count++
		fmt.Printf(" [%d] Получено: %d\n", count, item)
	}

	fmt.Println("Цикл for range завершился корректно!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Чтение элементов через for range:
#  [1] Получено: 10
#  [2] Получено: 20
#  [3] Получено: 30
#  [4] Получено: 40
#  [5] Получено: 50
# Цикл for range завершился корректно!
```

## Под капотом

`for range` автоматически проверяет флаг закрытия `ok` и выходит из цикла при получении `false`.

## Подводные камни

Закрывать канал должен только производитель.

## На собеседовании

**Вопрос с собеседования:** «Можно ли использовать for range с каналом только для записи (chan<- T)?»
**Ответ:** Нет! `for range` выполняет операцию чтения, поэтому компилятор требует тип `chan T` или `<-chan T`. Передача `chan<- T` вызовет ошибку компиляции.
