# Буферизованный канал: кольцевой буфер и поведение при переполнении

## Условие

**Буферизованный канал**: Создайте буферизованный канал емкостью 3 элемента `make(chan int, 3)`. Запишите туда три числа подряд в функции `main`. Заблокируется ли программа? Попробуйте записать четвертое число. Объясните разницу между поведением буферизованных и небуферизованных каналов.

## Теория

Буферизованный канал (`make(chan T, capacity)`) содержит внутреннюю кольцевую очередь в куче. Отправка `ch <- v` не блокирует поток до тех пор, пока буфер не заполнится (`len(ch) < cap(ch)`). При заполнении буфера последующая запись блокирует горутину.

## Решение по шагам

1. Создадим буферизованный канал `ch := make(chan int, 3)`.
2. Запишем числа 10, 20, 30 подряд без запуска горутин.
3. Проверим длину `len(ch)` и емкость `cap(ch)`.
4. Прочитаем значения и убедимся в порядке FIFO.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func main() {
	// Буферизованный канал на 3 элемента
	ch := make(chan int, 3)

	// Запись трех чисел подряд без блокировки
	ch <- 10
	ch <- 20
	ch <- 30

	fmt.Printf("Канал заполнен: len=%d, cap=%d\n", len(ch), cap(ch))

	// Чтение элементов в порядке очереди (FIFO)
	fmt.Printf("Извлечено: %d\n", <-ch)
	fmt.Printf("Извлечено: %d\n", <-ch)
	fmt.Printf("Извлечено: %d\n", <-ch)

	fmt.Printf("Канал освобожден: len=%d, cap=%d\n", len(ch), cap(ch))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Канал заполнен: len=3, cap=3
# Извлечено: 10
# Извлечено: 20
# Извлечено: 30
# Канал освобожден: len=0, cap=3
```

## Под капотом

Внутри `runtime.hchan` буфер представлен круговым массивом `buf unsafe.Pointer` с индексами `sendx` (куда писать) и `recvx` (откуда читать). Блокировка мьютекса `hchan.lock` сериализует операции.

## Подводные камни

Попытка записать 4-й элемент в канал `make(chan int, 3)` в том же потоке вызовет `deadlock!`.

## На собеседовании

**Вопрос с собеседования:** «Как устроен буферизованный канал внутри рантайма Go?»
**Ответ:** Это структура `hchan`, содержащая: 1) Кольцевой буфер `buf` фиксированного размера, 2) Индексы `sendx` и `recvx`, 3) Счетчики `qcount` (длина) и `dataqsiz` (емкость), 4) Очереди заблокированных горутин `sendq` и `recvq`, 5) Внутренний мьютекс `lock`.
