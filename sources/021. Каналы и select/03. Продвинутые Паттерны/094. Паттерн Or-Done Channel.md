# Паттерн Or-Done Channel: рекурсивное объединение N каналов отмены в один

## Условие

Напишите функцию `or(done <-chan interface{}, channels ...<-chan interface{}) <-chan interface{}`, которая объединяет несколько каналов "сигналов завершения" в один (закрытие любого из них закрывает результирующий).

## Теория

Паттерн Or-Channel (или Or-Done) объединяет произвольное количество каналов отмены в единый канал: как только **любой** из входных каналов закрывается (или отправляет сигнал), результирующий канал мгновенно закрывается, отменяя всю операцию.

## Решение по шагам

1. Реализуем функцию `OrDone(channels ...<-chan struct{}) <-chan struct{}` с рекурсивным деревом или `select`.
2. Создадим 3 канала отмены с разным временем срабатывания.
3. Дождемся срабатывания самого быстрого канала.
4. Проверим мгновенное закрытие результирующего канала.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

// Паттерн Or-Channel: рекурсивное объединение каналов отмены
func OrDone(channels ...<-chan struct{}) <-chan struct{} {
	switch len(channels) {
	case 0:
		return nil
	case 1:
		return channels[0]
	}

	orDone := make(chan struct{})
	go func() {
		defer close(orDone)

		switch len(channels) {
		case 2:
			select {
			case <-channels[0]:
			case <-channels[1]:
			}
		default:
			select {
			case <-channels[0]:
			case <-channels[1]:
			case <-channels[2]:
			case <-OrDone(append(channels[3:], orDone)...):
			}
		}
	}()

	return orDone
}

func sigAfter(d time.Duration) <-chan struct{} {
	c := make(chan struct{})
	go func() {
		time.Sleep(d)
		close(c)
	}()
	return c
}

func main() {
	start := time.Now()

	// 3 независимых источника отмены
	sig1 := sigAfter(100 * time.Millisecond)
	sig2 := sigAfter(25 * time.Millisecond) // Самый быстрый!
	sig3 := sigAfter(200 * time.Millisecond)

	fmt.Println("Ожидание первого сигнала через OrDone...")

	// Ждем закрытия любого из каналов
	<-OrDone(sig1, sig2, sig3)

	fmt.Printf("OrDone сработал через %v (сработал самый быстрый sig2)!\n", time.Since(start).Round(time.Millisecond))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Ожидание первого сигнала через OrDone...
# OrDone сработал через 25ms (сработал самый быстрый sig2)!
```

## Под капотом

Дерево рекурсивных `select` автоматически сворачивается при закрытии любого листа.

## Подводные камни

Для десятков каналов рекурсивный OrDone запускает \(O(N)\) горутин. В Go 1.21+ для объединения отмен используют `context.WithCancelCause`.

## На собеседовании

**Вопрос с собеседования:** «Какова практическая польза паттерна Or-Done?»
**Ответ:** Он позволяет объединять отмену по HTTP-клиенту, отмену по таймауту базы данных и отмену по сигналу завершения процесса в один общий канал `done`.
