# Паттерн Throttle: ограничение частоты пропускания событий

## Условие

Напиши **"throttle"** : пропускай события не чаще, чем раз в N миллисекунд. Если событие пришло раньше — игнорируй (или буферизуй одно). Используй `select` с `time.After`.

### Исходная формулировка

Напиши **"throttle"**: пропускай события не чаще, чем раз в N миллисекунд. Если событие пришло раньше — игнорируй (или буферизуй одно). Используй `select` с `time.After`.

## Теория

Паттерн Throttle (Дросселирование) гарантирует, что события пропускаются дальше с частотой не более одного раза в \(N\) миллисекунд, отбрасывая промежуточный спам (например, скролл страницы или нажатие кнопки отправки формы).

## Решение по шагам

1. Создадим функцию `Throttle(in <-chan int, interval time.Duration) <-chan int`.
2. Пропускаем первое событие и запускаем защитный интервал.
3. Все последующие события во время интервала отбрасываем.
4. Проверим пропуск пачки из 5 частых событий.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func Throttle(in <-chan int, interval time.Duration) <-chan int {
	out := make(chan int)

	go func() {
		defer close(out)
		var lastEmit time.Time

		for val := range in {
			now := time.Now()
			if now.Sub(lastEmit) >= interval {
				out <- val
				lastEmit = now
			} else {
				fmt.Printf("[Throttle] Событие #%d отброшено (слишком часто)\n", val)
			}
		}
	}()

	return out
}

func main() {
	events := make(chan int)
	throttled := Throttle(events, 25*time.Millisecond)

	go func() {
		// Отправляем 4 быстрых события с интервалом 5 мс
		for i := 1; i <= 4; i++ {
			events <- i
			time.Sleep(5 * time.Millisecond)
		}
		// Ждем 30 мс (интервал тишины)
		time.Sleep(30 * time.Millisecond)
		events <- 5 // Это событие должно пройти
		close(events)
	}()

	fmt.Println("Пропущенные через Throttle события:")
	for res := range throttled {
		fmt.Printf(" -> Успешно пропущено событие: %d\n", res)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Throttle] Событие #2 отброшено (слишком часто)
# [Throttle] Событие #3 отброшено (слишком часто)
# [Throttle] Событие #4 отброшено (слишком часто)
# Пропущенные через Throttle события:
#  -> Успешно пропущено событие: 1
#  -> Успешно пропущено событие: 5
```

## Под капотом

`Throttle` использует временные метки `time.Now()` и `time.Sub()` для \(O(1)\) фильтрации потока.

## Подводные камни

Не блокируйте входящий канал — входящие события должны быстро считываться и отбрасываться.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать Throttle с сохранением самого последнего значения (Trailing Throttle)?»
**Ответ:** При поступлении событий во время защитного интервала сохранять последнее значение в локальную переменную и по таймеру отправлять его в выходной канал.
