# Паттерн Done Channel (Cancellation): широковещательная отмена N воркеров

## Условие

Реализуйте паттерн "Done channel" (`done := make(chan struct{}); close(done)`), чтобы сигнализировать горутинам о необходимости завершения работы (Cancellation).

## Теория

Финальный комплексный паттерн главы: широковещательная отмена (Broadcast Cancellation) пула из \(N\) воркеров через закрытие единого канала `close(done)` с гарантией завершения всех задач через `sync.WaitGroup`.

## Решение по шагам

1. Создадим `done := make(chan struct{})`.
2. Запустим 3 параллельных воркера, слушающих `case <-done:`.
3. В `main` вызовем `close(done)`.
4. Дождемся завершения всех воркеров через `sync.WaitGroup`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

func workerNode(id int, done <-chan struct{}, wg *sync.WaitGroup) {
	defer wg.Done()
	fmt.Printf("[Worker #%d] Воркер запущен и обрабатывает очередь...\n", id)

	for {
		select {
		case <-done: // Мгновенное широковещательное пробуждение при close(done)
			fmt.Printf(" -> [Worker #%d] Получен сигнал отмены done! Очистка и выход.\n", id)
			return
		default:
			time.Sleep(10 * time.Millisecond)
		}
	}
}

func main() {
	done := make(chan struct{})
	var wg sync.WaitGroup

	const totalWorkers = 3
	wg.Add(totalWorkers)

	for i := 1; i <= totalWorkers; i++ {
		go workerNode(i, done, &wg)
	}

	time.Sleep(25 * time.Millisecond)

	fmt.Println("\n[Main] Отправка широковещательного сигнала отмены close(done)...")
	close(done) // Разблокирует абсолютно ВСЕХ воркеров одновременно!

	wg.Wait()
	fmt.Println("\n[Main] Все 3 воркера успешно остановлены. Глава 21 освоена на 100%!")
}
```

**`Терминал`**

```bash

```

## Под капотом

`close(done)` пробуждает все горутины из очереди `recvq` структуры `hchan` за один системный такт рантайма.

## Подводные камни

Никогда не отправляйте значения `done <- struct{}{}` в цикле для остановки \(N\) воркеров — всегда используйте `close(done)`.

## На собеседовании

**Вопрос с собеседования:** «Почему close(done) является фундаментальной основой пакета context в стандартной библиотеке Go?»
**Ответ:** Потому что метод `ctx.Done()` возвращает канал `<-chan struct{}`, а вызов функции отмены `cancel()` просто закрывает этот канал (`close(c.done)`), мгновенно оповещая всех слушателей без необходимости знать их количество и адреса.
