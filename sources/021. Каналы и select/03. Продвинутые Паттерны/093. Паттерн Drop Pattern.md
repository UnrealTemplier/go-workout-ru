# Паттерн Drop Pattern: сброс избыточных сообщений при заполненном буфере

## Условие

Используй `select` для отправки данных: если канал забит (буфер заполнен), срабатывает `default` (отбрасывание данных / drop pattern).

## Теория

Паттерн Drop Pattern (Отбрасывание пакетов) используется в системах телеметрии, метрик и стриминга видео: если приемник не справляется, свежие кадры или метрики отбрасываются, чтобы не создавать задержек (Lag).

## Решение по шагам

1. Создадим канал телеметрии `metrics := make(chan int, 2)`.
2. Заполним буфер первыми двумя метриками.
3. Попробуем отправить еще 2 метрики через `select default`.
4. Зафиксируем безопасный сброс.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

type MetricsBuffer struct {
	ch      chan int
	dropped int
}

func (m *MetricsBuffer) Push(val int) {
	select {
	case m.ch <- val:
		fmt.Printf("[METRICS] Записана метрика: %d\n", val)
	default:
		m.dropped++
		fmt.Printf("[DROP PATTERN] Буфер переполнен! Метрика %d отброшена (всего сброшено: %d)\n", val, m.dropped)
	}
}

func main() {
	buf := &MetricsBuffer{
		ch: make(chan int, 2),
	}

	buf.Push(100)
	buf.Push(200)
	// Буфер полон (2/2) -> следующие метрики отбрасываются
	buf.Push(300)
	buf.Push(400)

	fmt.Printf("\nИтог: В буфере готово к обработке %d элементов, отброшено %d.\n", len(buf.ch), buf.dropped)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [METRICS] Записана метрика: 100
# [METRICS] Записана метрика: 200
# [DROP PATTERN] Буфер переполнен! Метрика 300 отброшена (всего сброшено: 1)
# [DROP PATTERN] Буфер переполнен! Метрика 400 отброшена (всего сброшено: 2)
# 
# Итог: В буфере готово к обработке 2 элементов, отброшено 2.
```

## Под капотом

`select default` на заполненном канале не аллоцирует структур и завершается мгновенно.

## Подводные камни

Не используйте Drop Pattern для финансовых транзакций или платежей — только для телеметрии и логов!

## На собеседовании

**Вопрос с собеседования:** «Как реализовать неблокирующую отправку в канал с возвратом ошибки BufferOverflow?»
**Ответ:** Через функцию `func Send(ch chan<- T, val T) error { select { case ch <- val: return nil default: return ErrBufferFull } }`.
