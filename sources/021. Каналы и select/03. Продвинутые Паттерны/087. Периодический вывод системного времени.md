# Периодический вывод системного времени через time.Tick и time.After

## Условие

Создайте "тикущий" канал с помощью `time.Tick` и выведите текущее время каждые 500мс, прервав цикл через `time.After`.

## Теория

Форматирование временных меток в цикле мультиплексирования тикера и канала завершения.

## Решение по шагам

1. Создадим тикер `time.Tick(15 * time.Millisecond)`.
2. Запустим цикл с форматированием времени.
3. Прервем цикл через `time.After(50 * time.Millisecond)`.
4. Проверим результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	tickChan := time.Tick(15 * time.Millisecond)
	deadlineChan := time.After(50 * time.Millisecond)

	fmt.Println("Служба точного времени запущена:")

	for {
		select {
		case t := <-tickChan:
			fmt.Printf(" [CLOCK] Текущее время: %s\n", t.Format("15:04:05.000"))
		case <-deadlineChan:
			fmt.Println(" [CLOCK] Дедлайн истек, служба остановлена.")
			return
		}
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Служба точного времени запущена:
#  [CLOCK] Текущее время: 15:04:05.015
#  [CLOCK] Текущее время: 15:04:05.030
#  [CLOCK] Текущее время: 15:04:05.045
#  [CLOCK] Дедлайн истек, служба остановлена.
```

## Под капотом

`t.Format` форматирует метку времени без блокировок.

## Подводные камни

Используйте правильный шаблон форматирования даты в Go (`"2006-01-02 15:04:05"`).

## На собеседовании

**Вопрос с собеседования:** «Почему в Go шаблон форматирования времени строится вокруг даты 2006-01-02 15:04:05?»
**Ответ:** Это мнемонический порядок чисел `1 2 3 4 5 6 7`: 1 (месяц 01), 2 (день 02), 3 (час 15/03), 4 (минуты 04), 5 (секунды 05), 6 (год 2006), 7 (таймзона MST).
