# Периодический таймер: генерация тиков каждую секунду и контролируемый выход

## Условие

Используй `time.Tick` для создания канала, который отправляет время каждую секунду. Выводи "tick" в консоль. Останови через 5 секунд.

## Теория

`time.Tick` создает периодический таймер для фонового мониторинга и сбора метрик.

## Решение по шагам

1. Создадим канал тиков `ticker := time.Tick(10 * time.Millisecond)`.
2. Создадим канал остановки `stop := time.After(45 * time.Millisecond)`.
3. В цикле считываем тики и выводим `"tick"`.
4. Штатно завершаем работу.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	ticks := time.Tick(10 * time.Millisecond)
	stop := time.After(45 * time.Millisecond)

	count := 0
	fmt.Println("Запуск цикла периодических тиков:")

	for {
		select {
		case <-ticks:
			count++
			fmt.Printf(" -> tick #%d\n", count)
		case <-stop:
			fmt.Println("Интервал остановки достигнут! Завершение работы.")
			return
		}
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Запуск цикла периодических тиков:
#  -> tick #1
#  -> tick #2
#  -> tick #3
#  -> tick #4
# Интервал остановки достигнут! Завершение работы.
```

## Под капотом

Таймер генерирует события в фоне без задействования потоков ОС во время пауз.

## Подводные камни

В долгоживущих серверах используйте `time.NewTicker` с явным `defer ticker.Stop()`.

## На собеседовании

**Вопрос с собеседования:** «Почему в продакшене запрещают использовать time.Tick?»
**Ответ:** Потому что сборщик мусора не может освободить память `time.Tick`, пока программа работает. При каждом вызове функции с `time.Tick` происходит утечка таймера.
