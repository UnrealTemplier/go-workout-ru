# Псевдослучайное распределение выбора при одновременной готовности веток select

## Условие

**Каверзный случай**: Что произойдет, если в `select` указать несколько кейсов, которые готовы к выполнению одновременно? (Ответ: выбор случайный). Проверьте на практике.

## Теория

Экспериментальная валидация равновероятного выбора рантайма при одновременной готовности 2 веток.

## Решение по шагам

1. Создадим два буферизованных канала `ch1` и `ch2`.
2. В цикле заполним оба канала и выполним `select`.
3. Зафиксируем равное количество срабатываний.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func main() {
	ch1 := make(chan int, 1)
	ch2 := make(chan int, 1)

	c1Count, c2Count := 0, 0
	const iterations = 1000

	for i := 0; i < iterations; i++ {
		ch1 <- 1
		ch2 <- 2

		select {
		case <-ch1:
			c1Count++
			<-ch2
		case <-ch2:
			c2Count++
			<-ch1
		}
	}

	fmt.Printf("Результаты 1000 одновременных гонок в select:\n")
	fmt.Printf("Канал 1: %d раз (%.1f%%)\n", c1Count, float64(c1Count)/float64(iterations)*100)
	fmt.Printf("Канал 2: %d раз (%.1f%%)\n", c2Count, float64(c2Count)/float64(iterations)*100)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Результаты 1000 одновременных гонок в select:
# Канал 1: 504 раз (50.4%)
# Канал 2: 496 раз (49.6%)
```

## Под капотом

`runtime.fastrand()` гарантирует распределение 50/50.

## Подводные камни

Никогда не используйте порядок веток `case` в качестве логического приоритета.
