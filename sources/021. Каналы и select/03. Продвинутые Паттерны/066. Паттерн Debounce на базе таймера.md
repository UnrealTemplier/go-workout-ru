# Паттерн Debounce на базе таймера: фильтрация частых событий

## Условие

Напиши **"debounce"** через `select` + `time.After`: при поступлении события запускай таймер. Если за время таймера пришло новое событие — сбрасывай старый таймер и запускай новый. Обработай только последнее событие в серии.

## Теория

Паттерн Debounce (Устранение дребезга) откладывает выполнение действия до тех пор, пока не пройдет определенный интервал «тишины» с момента последнего события (например, автодополнение поисковой строки при вводе пользователем).

## Решение по шагам

1. Создадим функцию `Debounce(in <-chan string, delay time.Duration) <-chan string`.
2. Внутри используем `time.NewTimer` со сбросом `timer.Reset()`.
3. Запустим быструю серию событий `"g"`, `"go"`, `"gola"`, `"golang"`.
4. Убедимся, что на выходе обработано только последнее событие `"golang"`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func Debounce(in <-chan string, delay time.Duration) <-chan string {
	out := make(chan string)

	go func() {
		defer close(out)
		var timer *time.Timer
		var currentVal string
		var timerC <-chan time.Time

		for {
			select {
			case val, ok := <-in:
				if !ok {
					if timer != nil {
						timer.Stop()
					}
					return
				}
				currentVal = val

				// Останавливаем старый таймер и сбрасываем заново
				if timer != nil {
					timer.Stop()
				}
				timer = time.NewTimer(delay)
				timerC = timer.C

			case <-timerC:
				out <- currentVal
				timerC = nil // Сбрасываем канал таймера до следующего события
			}
		}
	}()

	return out
}

func main() {
	input := make(chan string)
	debounced := Debounce(input, 30*time.Millisecond)

	go func() {
		// Быстрая серия ввода пользователем (с интервалом 10мс < 30мс)
		input <- "g"
		time.Sleep(10 * time.Millisecond)
		input <- "go"
		time.Sleep(10 * time.Millisecond)
		input <- "golang" // Последнее событие
		time.Sleep(50 * time.Millisecond)
		close(input)
	}()

	fmt.Println("Результаты работы Debounce:")
	for result := range debounced {
		fmt.Printf(" -> Обработано поисковое значение: %q\n", result)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Результаты работы Debounce:
#  -> Обработано поисковое значение: "golang" 
```

## Под капотом

`timer.Stop()` удаляет таймер из системного дерева таймеров рантайма, а `timer.Reset()` перезапускает отсчет.

## Подводные камни

Обязательно очищайте `timerC = nil`, чтобы таймер не срабатывал повторно.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие Debounce от Throttle?»
**Ответ:** Debounce ожидает паузы в потоке событий и обрабатывает **последнее** событие серии. Throttle гарантирует выполнение не чаще одного раза за период времени, обрабатывая **первое** событие и игнорируя последующие.
