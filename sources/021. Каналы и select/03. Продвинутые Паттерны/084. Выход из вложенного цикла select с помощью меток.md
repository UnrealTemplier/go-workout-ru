# Выход из вложенного цикла select с помощью меток (Labeled Break)

## Условие

**[Каверзный кейс]**: Создай бесконечный цикл с `select`, который читает из двух каналов: `data` и `quit`. При получении сигнала в `quit`, выходи из цикла (используй `return` или `break` с меткой).

## Теория

Обычный оператор `break` внутри `select` прерывает только сам блок `select`, но не окружающий цикл `for`! Для выхода из цикла необходимо использовать `return` или `break LoopLabel` (Labeled Break).

## Решение по шагам

1. Создадим каналы `data` и `quit`.
2. Зададим метку внешнего цикла `EventLoop: for { select { ... } }`.
3. В ветке `case <-quit:` вызовем `break EventLoop`.
4. Убедимся в полном выходе из цикла.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	data := make(chan int)
	quit := make(chan struct{})

	go func() {
		data <- 10
		data <- 20
		time.Sleep(10 * time.Millisecond)
		close(quit) // Сигнал на выход
	}()

	fmt.Println("Запуск цикла EventLoop с Labeled Break:")

EventLoop:
	for {
		select {
		case v := <-data:
			fmt.Printf(" [Data] Обработано число: %d\n", v)
		case <-quit:
			fmt.Println(" [Quit] Получен сигнал quit -> выполняем break EventLoop")
			break EventLoop // ВЫХОДИТ ИЗ ЦИКЛА FOR, А НЕ ТОЛЬКО ИЗ SELECT!
		}
	}

	fmt.Println("Успешный выход за пределы цикла EventLoop!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Запуск цикла EventLoop с Labeled Break:
#  [Data] Обработано число: 10
#  [Data] Обработано число: 20
#  [Quit] Получен сигнал quit -> выполняем break EventLoop
# Успешный выход за пределы цикла EventLoop!
```

## Под капотом

Компилятор Go связывает метку `EventLoop` с инструкцией `JMP` за пределы цикла `for`.

## Подводные камни

Написание простого `break` внутри `case` в бесконечном цикле — распространенный баг новичков, приводящий к вечному циклу.

## На собеседовании

**Вопрос с собеседования:** «Что делает обычный оператор break внутри ветки select?»
**Ответ:** Прерывает только блок `select`, передавая управление на следующую строку за `select`. Если `select` находился внутри `for`, начнется следующая итерация цикла.
