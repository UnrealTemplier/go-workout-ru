# Инкапсуляция генератора чисел с передачей send-only канала

## Условие

Напишите функцию, которая принимает канал для записи, генерирует числа и закрывает канал по завершении.

## Теория

Прием канала для записи `out chan<- int` позволяет вызывающему коду самому контролировать создание и размер буфера канала.

## Решение по шагам

1. Создадим функцию `PopulateChannel(out chan<- int, count int)`.
2. Внутри сгенерируем числа и вызовем `close(out)`.
3. В `main` создадим буферизованный канал и передадим его в функцию.
4. Вычитаем данные.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func PopulateChannel(out chan<- int, count int) {
	defer close(out)
	for i := 1; i <= count; i++ {
		out <- i * 10
	}
}

func main() {
	ch := make(chan int, 3)

	go PopulateChannel(ch, 3)

	fmt.Println("Чтение сгенерированных элементов:")
	for item := range ch {
		fmt.Printf(" -> Элемент: %d\n", item)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Чтение сгенерированных элементов:
#  -> Элемент: 10
#  -> Элемент: 20
#  -> Элемент: 30
```

## Под капотом

`defer close(out)` выполняется даже при панике внутри генератора.

## Подводные камни

Не вызывайте `PopulateChannel` на одном канале из нескольких горутин без `sync.WaitGroup`, иначе возникнет паника двойного закрытия.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие генератора, возвращающего канал, от генератора, принимающего канал?»
**Ответ:** Возвращающий канал генератор инкапсулирует создание горутины и размер буфера внутри себя. Принимающий канал генератор дает вызывающему коду полный контроль над аллокацией канала и его буферизацией.
