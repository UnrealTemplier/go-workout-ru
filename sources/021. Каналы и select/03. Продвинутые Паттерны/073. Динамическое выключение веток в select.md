# Динамическое выключение веток в select через обнуление канала (nil channel)

## Условие

Напиши программу с `select` и **nil каналом**: динамически "выключай" case, присваивая каналу `nil`. Покажи, что case с nil каналом **никогда не выбирается** (это способ временно отключить case).

## Теория

Присваивание переменной канала значения `nil` (`ch = nil`) мгновенно и обратимо выключает соответствующую ветку `case` в конструкции `select`.

## Решение по шагам

1. Создадим два канала `ch1` и `ch2`.
2. Заполним оба канала данными.
3. Прочитав из `ch1`, присвоим `ch1 = nil`.
4. Убедимся, что на следующей итерации выбирается только `ch2`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func main() {
	ch1 := make(chan string, 1)
	ch2 := make(chan string, 1)

	ch1 <- "Сообщение из канала 1"
	ch2 <- "Сообщение из канала 2"

	// Итерация 1: Отключаем канал 1 после первого чтения
	for i := 0; i < 2; i++ {
		select {
		case msg, ok := <-ch1:
			if ok {
				fmt.Printf("1. Получено из ch1: %q -> отключаем ветку ch1 (ch1 = nil)\n", msg)
				ch1 = nil // Динамическое отключение ветки!
			}
		case msg, ok := <-ch2:
			if ok {
				fmt.Printf("2. Получено из ch2: %q -> отключаем ветку ch2 (ch2 = nil)\n", msg)
				ch2 = nil
			}
		}
	}

	fmt.Println("Оба канала успешно обработаны и отключены.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# 1. Получено из ch1: "Сообщение из канала 1" -> отключаем ветку ch1 (ch1 = nil)
# 2. Получено из ch2: "Сообщение из канала 2" -> отключаем ветку ch2 (ch2 = nil)
# Оба канала успешно обработаны и отключены.
```

## Под капотом

`nil`-канал игнорируется рантаймом `selectgo` на уровне проверки дескрипторов.

## Подводные камни

Если все каналы в `select` станут `nil`, горутина заснет навсегда (дедлок).

## На собеседовании

**Вопрос с собеседования:** «Как временно приостановить чтение из канала в select при превышении локального лимита?»
**Ответ:** Сохранить указатель на канал во временную переменную `saved := ch; ch = nil`. После спада нагрузки восстановить чтение `ch = saved`.
