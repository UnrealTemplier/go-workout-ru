# Паттерн Futures / Promises в Go на базе однократного канала

## Условие

Передайте канал в качестве аргумента функции для возврата результата (паттерн "Futures" / "Promises").

## Теория

Паттерн Future / Promise (Обещание) представляет собой дескриптор результата асинхронного вычисления. В Go объект Future реализуется обычным каналом `<-chan Result`, куда горутина единожды записывает результат.

## Решение по шагам

1. Создадим структуру `Future[T any]`.
2. Реализуем функцию `AsyncExec[T](fn func() T) <-chan T`.
3. Запустим асинхронную операцию.
4. Вычитаем результат в нужный момент.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

// Асинхронный запуск вычисления с возвратом Future (канала)
func AsyncCompute(a, b int) <-chan int {
	future := make(chan int, 1)
	go func() {
		time.Sleep(20 * time.Millisecond) // Симуляция тяжелых вычислений
		future <- a * b
	}()
	return future
}

func main() {
	fmt.Println("[Main] Запуск асинхронной задачи (Promise)...")
	promise := AsyncCompute(6, 7)

	fmt.Println("[Main] Выполняю другие независимые операции...")
	time.Sleep(10 * time.Millisecond)

	fmt.Println("[Main] Ожидание разрешения Promise (<-promise)...")
	result := <-promise

	fmt.Printf("[Main] Результат успешно получен из Future: %d\n", result)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Main] Запуск асинхронной задачи (Promise)...
# [Main] Выполняю другие независимые операции...
# [Main] Ожидание разрешения Promise (<-promise)...
# [Main] Результат успешно получен из Future: 42
```

## Под капотом

`<-promise` блокирует поток только в том случае, если вычисление еще не завершилось.

## Подводные камни

Используйте буфер емкостью 1 (`make(chan T, 1)`), чтобы горутина вычисления не зависла при досрочном отказе от ожидания результата.

## На собеседовании

**Вопрос с собеседования:** «Чем Future в Go отличается от std::future в C++ или Promise в JS?»
**Ответ:** В Go нет отдельного класса `Future` — его роль выполняет обычный канал `<-chan T`, что позволяет мультиплексировать несколько фьючерсов через стандартный `select` без дополнительных библиотек.
