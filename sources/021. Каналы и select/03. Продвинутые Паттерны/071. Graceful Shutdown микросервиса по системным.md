# Graceful Shutdown микросервиса по системным сигналам OS (SIGINT/SIGTERM)

## Условие

Напиши **"graceful shutdown"**: `select` между рабочим каналом и `os.Signal` каналом (`signal.Notify`). При получении `os.Interrupt` — закрой рабочий канал, дождись `sync.WaitGroup`, выведи `"shutting down gracefully"`.

## Теория

Корректное завершение (Graceful Shutdown) перехватывает системные сигналы ядра Linux (`SIGINT` Ctrl+C, `SIGTERM` Kubernetes pod termination) через `os/signal.Notify` и дает сервису время завершить текущие запросы перед остановкой.

## Решение по шагам

1. Создадим буферизованный канал сигналов `sigChan := make(chan os.Signal, 1)`.
2. Зарегистрируем перехват `signal.Notify(sigChan, os.Interrupt)`.
3. В воркере слушаем задачи и сигнал отмены.
4. Продемонстрируем имитацию сигнала остановки.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"os"
	"sync"
	"time"
)

func worker(id int, stopChan <-chan struct{}, wg *sync.WaitGroup) {
	defer wg.Done()
	fmt.Printf("[Worker #%d] Запущен и обрабатывает фоновые задачи...\n", id)

	for {
		select {
		case <-stopChan:
			fmt.Printf("[Worker #%d] Получен сигнал STOP -> корректное завершение\n", id)
			return
		default:
			time.Sleep(10 * time.Millisecond)
		}
	}
}

func main() {
	// Канал сигналов ОС ВСЕГДА должен иметь буфер >= 1
	sigChan := make(chan os.Signal, 1)
	stopWorkers := make(chan struct{})

	var wg sync.WaitGroup
	const totalWorkers = 2

	for i := 1; i <= totalWorkers; i++ {
		wg.Add(1)
		go worker(i, stopWorkers, &wg)
	}

	// Имитация прихода сигнала SIGINT через 25 мс
	go func() {
		time.Sleep(25 * time.Millisecond)
		sigChan <- os.Interrupt
	}()

	// Главный поток ожидает системный сигнал
	<-sigChan
	fmt.Println("\n[Main] Получен сигнал os.Interrupt! Инициирую Graceful Shutdown...")

	close(stopWorkers) // Уведомляем всех воркеров
	wg.Wait()          // Дожидаемся завершения

	fmt.Println("[Main] shutting down gracefully: Все ресурсы освобождены, выход.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Worker #1] Запущен и обрабатывает фоновые задачи...
# [Worker #2] Запущен и обрабатывает фоновые задачи...
# 
# [Main] Получен сигнал os.Interrupt! Инициирую Graceful Shutdown...
# [Worker #1] Получен сигнал STOP -> корректное завершение
# [Worker #2] Получен сигнал STOP -> корректное завершение
# [Main] shutting down gracefully: Все ресурсы освобождены, выход.
```

## Под капотом

`signal.Notify` перехватывает сигналы POSIX и перенаправляет их в Go-канал через синглтон-обработчик рантайма.

## Подводные камни

Канал для `signal.Notify` обязан иметь буфер емкостью как минимум 1 (`make(chan os.Signal, 1)`), иначе сигнал ОС будет потерян, если горутина не успела встать на чтение.

## На собеседовании

**Вопрос с собеседования:** «Почему канал для signal.Notify обязан быть буферизованным?»
**Ответ:** Потому что рантайм Go отправляет сигналы ОС неблокирующим вызовом (Non-blocking Send). Если канал небуферизован и горутина не стоит в `<-sigChan` в этот точный момент, сигнал будет безвозвратно утерян.
