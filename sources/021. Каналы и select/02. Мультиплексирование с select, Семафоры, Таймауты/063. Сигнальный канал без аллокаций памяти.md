# Сигнальный канал без аллокаций памяти: chan struct{}

## Условие

**Сигнальный канал**: Создай `done := make(chan struct{})`. Горутина-воркер делает долгую работу, а по завершении делает `done <- struct{}{}`. В `main` жди этого сигнала `<-done`. Пустая структура не занимает памяти!

## Теория

Тип `struct{}` в Go занимает ровно \(0\) байт (`unsafe.Sizeof(struct{}{}) == 0`). Создание `make(chan struct{})` формирует максимально легковесный сигнальный канал для синхронизации без нагрузки на Garbage Collector.

## Решение по шагам

1. Создадим `done := make(chan struct{})`.
2. Запустим горутину, выполняющую вычисления.
3. По завершении отправим `done <- struct{}{}`.
4. В `main` дождемся `<-done`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
	"unsafe"
)

func main() {
	fmt.Printf("Размер структуры struct{}: %d байт\n", unsafe.Sizeof(struct{}{}))

	done := make(chan struct{})

	go func() {
		fmt.Println("[Worker] Выполнение тяжелой фоновой задачи...")
		time.Sleep(20 * time.Millisecond)
		fmt.Println("[Worker] Задача завершена! Отправка нулевого сигнала синхронизации...")
		done <- struct{}{} // 0 байт накладных расходов памяти!
	}()

	fmt.Println("[Main] Ожидание завершения воркера на <-done...")
	<-done

	fmt.Println("[Main] Сигнал получен, программа успешно завершена!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Размер структуры struct{}: 0 байт
# [Main] Ожидание завершения воркера на <-done...
# [Worker] Выполнение тяжелой фоновой задачи...
# [Worker] Задача завершена! Отправка нулевого сигнала синхронизации...
# [Main] Сигнал получен, программа успешно завершена!
```

## Под капотом

Значение `struct{}{}` оптимизируется компилятором в `runtime.zerobase`.

## Подводные камни

Для широковещательного уведомления \(N\) горутин вместо `done <- struct{}{}` используют `close(done)`.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go нет отдельного типа данных Signal/Event, а используется chan struct{}?»
**Ответ:** Потому что каналы в Go ортогональны и универсальны: `chan struct{}` решает все задачи сигналов, очередей, семафоров и синхронизации без необходимости вводить новые сущности в язык.
