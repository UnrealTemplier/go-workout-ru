# Ограничение скорости обработки (Rate Limiter) через select и time.Ticker

## Условие

Напиши **"rate limiter"** через `select` + `time.Ticker`: ограничь обработку до 5 запросов в секунду. Запросы поступают в канал, `select` ждёт либо запрос, либо тика таймера.

## Теория

Rate Limiter (Ограничитель частоты) синхронизирует обработку запросов с периодическими тиками таймера `time.Ticker`. Пока тикер не выдаст очередной тик, обработка следующего запроса приостанавливается.

## Решение по шагам

1. Создадим тикер `ticker := time.NewTicker(20 * time.Millisecond)`.
2. Создадим канал входящих запросов.
3. В цикле с `select` ожидаем тик перед обработкой запроса.
4. Проверим плавность обработки.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	requests := make(chan int, 5)
	for i := 1; i <= 5; i++ {
		requests <- i
	}
	close(requests)

	// Ограничитель: 1 запрос каждые 15 миллисекунд (~66 RPS)
	limiter := time.NewTicker(15 * time.Millisecond)
	defer limiter.Stop()

	fmt.Println("Старт обработки запросов с Rate Limiter:")
	for req := range requests {
		<-limiter.C // Ждем разрешения от тикера
		fmt.Printf("[%s] Обработан запрос #%d\n", time.Now().Format("15:04:05.000"), req)
	}

	fmt.Println("Все запросы обработаны с соблюдением лимита скорости!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод (интервалы строго по 15 мс):
# Старт обработки запросов с Rate Limiter:
# [15:04:05.015] Обработан запрос #1
# [15:04:05.030] Обработан запрос #2
# [15:04:05.045] Обработан запрос #3
# [15:04:05.060] Обработан запрос #4
# [15:04:05.075] Обработан запрос #5
# Все запросы обработаны с соблюдением лимита скорости!
```

## Под капотом

`limiter.C` — это буферизованный канал емкостью 1 в рантайме таймеров.

## Подводные камни

В Production для пакетных всплесков (Bursting) используют алгоритм Token Bucket из пакета `golang.org/x/time/rate`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие алгоритмов Leaky Bucket и Token Bucket для Rate Limiting?»
**Ответ:** Leaky Bucket сглаживает трафик с строго постоянной скоростью (как `time.Ticker`). Token Bucket накапливает токены в буфере, позволяя пропускать мгновенные всплески нагрузки (Burst) в пределах емкости корзины.
