# Ловушка Busy Loop при чтении закрытого канала в select и защита

## Условие

Напиши программу с `select` и **закрытым каналом**: один из case'ов читает из закрытого канала. Покажи, что закрытый канал **всегда готов** для чтения (возвращает zero value). Это может привести к "busy loop" если не обрабатывать `ok`.

## Теория

Закрытый канал в конструкции `select` всегда сигнализирует о готовности к неблокирующему чтению. Если в цикле `for { select { case v, ok := <-ch: } }` не обнулять `ch = nil` при `!ok`, цикл начнет непрерывно крутиться, сжигая CPU.

## Решение по шагам

1. Создадим канал и закроем его `close(ch)`.
2. Покажем, как `select` мгновенно выбирает закрытый канал.
3. Продемонстрируем правильное отключение через `ch = nil`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func main() {
	ch := make(chan int)
	close(ch) // Канал закрыт

	fmt.Println("--- Демонстрация безопасного выхода из select при закрытом канале ---")

	loopCount := 0
	for ch != nil {
		loopCount++
		select {
		case val, ok := <-ch:
			if !ok {
				fmt.Printf("Итерация %d: Канал закрыт (val=%d, ok=%v) -> присваиваем ch = nil\n", loopCount, val, ok)
				ch = nil // ВЫКЛЮЧАЕМ ВЕТКУ SELECT!
				break
			}
			fmt.Printf("Получено значение: %d\n", val)
		}
	}

	fmt.Println("Цикл успешно завершен без Busy Loop!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- Демонстрация безопасного выхода из select при закрытом канале ---
# Итерация 1: Канал закрыт (val=0, ok=false) -> присваиваем ch = nil
# Цикл успешно завершен без Busy Loop!
```

## Под капотом

После `ch = nil` рантайм больше не опрашивает этот дескриптор в `selectgo`.

## Подводные камни

Если забыть `ch = nil`, в логах появится миллион пустых строк в секунду.

## На собеседовании

**Вопрос с собеседования:** «Что произойдет, если в цикле for select все опрашиваемые каналы станут nil, а ветки default нет?»
**Ответ:** Произойдет моментальный дедлок `fatal error: all goroutines are asleep - deadlock!`, так как `select` со всеми nil-каналами заблокирует горутину навсегда.
