# Функция-генератор N чисел с инкапсулированным каналом

## Условие

Напишите функцию-генератор, которая возвращает канал и горутину, записывающую в него N чисел и закрывающую канал.

### Исходная формулировка

Напиши функцию-генератор, которая возвращает канал и горутину, записывающую в него N чисел и закрывающую канал.

## Теория

Фабрика потока чисел (Number Stream Factory) возвращает только канал для чтения `<-chan int`.

## Решение по шагам

1. Создадим функцию `CountGenerator(n int) <-chan int`.
2. Внутри запустим горутину с `close(ch)`.
3. В `main` прочитаем 5 чисел.
4. Проверим чистоту завершения.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func CountGenerator(limit int) <-chan int {
	ch := make(chan int)
	go func() {
		defer close(ch)
		for i := 1; i <= limit; i++ {
			ch <- i
		}
	}()
	return ch
}

func main() {
	stream := CountGenerator(5)

	fmt.Println("Сгенерированные числа:")
	for num := range stream {
		fmt.Printf(" -> %d\n", num)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Сгенерированные числа:
#  -> 1
#  -> 2
#  -> 3
#  -> 4
#  -> 5
```

## Под капотом

Генератор работает в отдельной горутине параллельно с вызывающим кодом.

## Подводные камни

Для больших N буферизация `make(chan int, 64)` ускоряет генерацию в 2–3 раза за счет снижения числа переключений контекста.

## На собеседовании

**Вопрос с собеседования:** «Как сделать генератор бесконечным с поддержкой отмены?»
**Ответ:** Добавить аргумент `ctx context.Context` и отправлять элементы через `select { case ch <- i: case <-ctx.Done(): return }`.
