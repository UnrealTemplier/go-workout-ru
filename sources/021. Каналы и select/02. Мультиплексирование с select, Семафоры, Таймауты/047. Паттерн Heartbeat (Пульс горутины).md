# Паттерн Heartbeat (Пульс горутины): мониторинг зависания воркеров

## Условие

Напиши **"heartbeat"** pattern: горутина каждые 500ms пишет `"ping"` в канал. В `main` читай с `select` и таймаутом 1s. Если нет ping'a в течение 1s — считай, что горутина зависла.

## Теория

Паттерн Heartbeat (Пульс) позволяет супервизору отслеживать живость фоновых воркеров. Если воркер не прислал сигнал пульса за оговоренный интервал (SLA Timeout), система фиксирует сбой (Deadlock/Livelock) и перезапускает воркер.

## Решение по шагам

1. Создадим канал пульса `heartbeat := make(chan string)`.
2. Запустим воркера, отправляющего `"ping"` каждые 20 мс, а затем имитирующего зависание.
3. В `main` в цикле с `select` слушаем пульс с таймаутом 50 мс.
4. Зафиксируем предупреждение о зависании.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func workerWithHeartbeat(heartbeat chan<- string) {
	ticker := time.NewTicker(20 * time.Millisecond)
	defer ticker.Stop()

	// Отправляем 3 нормальных пульса
	for i := 1; i <= 3; i++ {
		<-ticker.C
		heartbeat <- "ping"
	}

	// Имитация зависания воркера (Deadlock / Heavy Calculation)
	fmt.Println("[Worker] Воркер завис в бесконечной блокировке...")
	time.Sleep(200 * time.Millisecond)
}

func main() {
	heartbeat := make(chan string)
	go workerWithHeartbeat(heartbeat)

	const heartbeatTimeout = 60 * time.Millisecond

	for i := 0; i < 4; i++ {
		select {
		case msg := <-heartbeat:
			fmt.Printf("[Supervisor] Пульс получен (%s) -> воркер здоров!\n", msg)
		case <-time.After(heartbeatTimeout):
			fmt.Println("[Supervisor] ВНИМАНИЕ: Пульс отсутствует более 60мс! Воркер признан зависшим.")
			return
		}
	}
}
```

**`Терминал`**

```bash
go run main.go

# [Supervisor] Пульс получен (ping) -> воркер здоров!

# [Supervisor] ВНИМАНИЕ: Пульс отсутствует более 60мс! Воркер признан зависшим.
```

## Под капотом

Heartbeat-сообщения разгружают сеть, так как передаются по локальным каналам памяти.

## Подводные камни

Канал пульса часто делают буферизованным на 1 элемент (`make(chan struct{}, 1)`), чтобы медленный супервизор не тормозил работу самого воркера.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать Heartbeat с передачей полезной нагрузки (Data + Pulse)?»
**Ответ:** Возвращать два канала: `(<-chan Heartbeat, <-chan Result)` или один канал со структурой `type Event struct { Pulse bool; Data T }`.
