# Идиоматичное чтение последовательности данных через for val := range ch

## Условие

Используй цикл `for val := range ch` для чтения данных из канала до его закрытия.

## Теория

`for val := range ch` — стандартный идиоматичный способ вычитывания элементов из канала. Цикл автоматически завершается без ошибок при закрытии канала.

## Решение по шагам

1. Создадим канал чисел `ch := make(chan int)`.
2. В горутине отправим значения 10, 20, 30 и закроем `close(ch)`.
3. В `main` прочитаем через `for val := range ch`.
4. Напечатаем сумму элементов.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func main() {
	numbers := make(chan int)

	go func() {
		for i := 1; i <= 4; i++ {
			numbers <- i * 100
		}
		close(numbers)
	}()

	totalSum := 0
	fmt.Println("Чтение значений из канала через for range:")
	for val := range numbers {
		fmt.Printf(" -> Получено число: %d\n", val)
		totalSum += val
	}

	fmt.Printf("Итоговая сумма всех элементов потока: %d\n", totalSum)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Чтение значений из канала через for range:
#  -> Получено число: 100
#  -> Получено число: 200
#  -> Получено число: 300
#  -> Получено число: 400
# Итоговая сумма всех элементов потока: 1000
```

## Под капотом

`for range` инкапсулирует `val, ok := <-ch` с немедленным выходом при `!ok`.

## Подводные камни

Если канал не будет закрыт отправителем, `for range` никогда не завершится.

## На собеседовании

**Вопрос с собеседования:** «Можно ли прервать цикл for range по каналу досрочно с помощью break?»
**Ответ:** Да, оператор `break` моментально выходит из цикла `for range`, однако если в канале еще оставались элементы, а отправитель не завершил работу, оставшиеся горутины могут зависнуть в `sendq`.
