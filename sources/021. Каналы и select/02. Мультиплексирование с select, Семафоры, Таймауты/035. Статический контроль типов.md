# Статический контроль типов: защита от чтения из send-only и записи в receive-only

## Условие

Напиши программу, демонстрирующую **"channel direction"**: функция принимает `send chan<- int` (только для записи) и `receive <-chan int` (только для чтения). Попробуй записать в `receive` — получи ошибку компиляции.

### Исходная формулировка

Напиши программу, демонстрирующую **"channel direction"**: функция принимает `send chan<- int` (только для записи) и `receive <-chan int` (только для чтения). Попробуй записать в `receive` — получи ошибку компиляции.

---

## Теория

Однонаправленные каналы формируют строгие контракты API функций:
* `send chan<- int` гарантирует, что вызываемая функция может только отправлять данные.
* `receive <-chan int` гарантирует, что функция может только читать данные.

## Решение по шагам

1. Напишем функцию `transmit(send chan<- int, val int)`.
2. Напишем функцию `receiveData(receive <-chan int) int`.
3. Соединим их через двунаправленный канал `ch := make(chan int)`.
4. Проверим компиляцию и выполнение.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func transmit(send chan<- int, val int) {
	send <- val
	// _ = <-send // ОШИБКА КОМПИЛЯЦИИ: invalid operation: cannot receive from send-only channel
}

func receiveData(receive <-chan int) int {
	// receive <- 10 // ОШИБКА КОМПИЛЯЦИИ: invalid operation: cannot send to receive-only channel
	return <-receive
}

func main() {
	ch := make(chan int, 1)

	transmit(ch, 777)
	result := receiveData(ch)

	fmt.Printf("Успешно передано и прочитано по строго типизированным каналам: %d\n", result)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Успешно передано и прочитано по строго типизированным каналам: 777
```

## Под капотом

Проверка направления канала полностью выполняется фронтендом компилятора (Type Checker) на этапе разбора AST-дерева.

## Подводные камни

Не передавайте двунаправленный `chan T` в публичные методы библиотек — всегда явно указывайте направление `chan<- T` или `<-chan T`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие <-chan T от chan<- T в синтаксисе Go?»
**Ответ:** Стрелка `<-` показывает направление движения данных: `<-chan T` (стрелка выходит из канала \(\to\) чтение), `chan<- T` (стрелка входит в канал \(\to\) запись).
