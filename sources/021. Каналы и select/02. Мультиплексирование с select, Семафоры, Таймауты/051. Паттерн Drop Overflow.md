# Паттерн Drop Overflow: отбрасывание сообщений при переполнении буфера

## Условие

Неблокирующая отправка/чтение с `default`: попробуйте отправить в канал, если он заполнен — выведите «channel full» и пропустите.

## Теория

Паттерн Drop / Load Shedding (Сброс нагрузки): если буфер очереди заполнен, система не блокирует вызывающий поток, а мгновенно отбрасывает сообщение или отправляет его в Dead Letter Queue (DLQ), сохраняя стабильность сервиса под всплеском трафика.

## Решение по шагам

1. Создадим буферизованный канал `queue := make(chan int, 2)`.
2. Заполним 2 слота.
3. Попробуем отправить 3-й элемент через `select default`.
4. Зафиксируем сообщение `"channel full"`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func trySend(ch chan<- int, val int) bool {
	select {
	case ch <- val:
		fmt.Printf("Успешно отправлено значение: %d\n", val)
		return true
	default:
		fmt.Printf("[DROP] Канал заполнен (channel full)! Элемент %d отброшен.\n", val)
		return false
	}
}

func main() {
	queue := make(chan int, 2)

	trySend(queue, 10)
	trySend(queue, 20)
	// Буфер полон (2/2) -> следующее значение будет безопасно отброшено
	trySend(queue, 30)
	trySend(queue, 40)

	fmt.Printf("\nВ буфере осталось элементов: %d / %d\n", len(queue), cap(queue))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Успешно отправлено значение: 10
# Успешно отправлено значение: 20
# [DROP] Канал заполнен (channel full)! Элемент 30 отброшен.
# [DROP] Канал заполнен (channel full)! Элемент 40 отброшен.
# 
# В буфере осталось элементов: 2 / 2
```

## Под капотом

Неблокирующая отправка `runtime.chansend(..., block=false)` при полном буфере возвращает `false` за \(O(1)\) без создания очередей ожидания.

## Подводные камни

Всегда инкрементируйте счетчик метрик Prometheus при отбрасывании сообщений для своевременного алерта инженеров.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать кольцевой буфер с вытеснением старых элементов (Ring Buffer Drop Oldest)?»
**Ответ:** Через `select`: `select { case ch <- val: default: <-ch; ch <- val }` — если буфер полон, читаем и выбрасываем самый старый элемент, после чего записываем новый.
