# Security Headers Bundle: комплексный производственный middleware

## Условие

Напишите middleware, которое добавляет все современные security headers в каждый HTTP response: HSTS, CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, Cross-Origin-Opener-Policy (COOP) и Cross-Origin-Resource-Policy (CORP). Скройте версию сервера.

### Исходная формулировка

**Security headers bundle**: Напишите middleware, которая добавляет все современные security headers в каждый response: HSTS, CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy.

## Теория

Комплексный бандл заголовков безопасности (Production Security Headers Bundle) — обязательный стандарт для прохождения аудита информационной безопасности и сертификации PCI-DSS / ISO 27001.

Полный список критических заголовков:
1. `Strict-Transport-Security`: форсирование HTTPS.
2. `Content-Security-Policy`: ограничение скриптов и стилей.
3. `X-Frame-Options`: защита от Clickjacking.
4. `X-Content-Type-Options`: блокировка MIME Sniffing.
5. `Referrer-Policy`: защита от утечки чувствительных URL-параметров.
6. `Permissions-Policy`: отключение опасных API браузера.
7. `Cross-Origin-Opener-Policy (COOP)`: изоляция контекста вкладки (защита от атак через `window.opener`).
8. `Cross-Origin-Resource-Policy (CORP)`: запрет чтения ресурсов страницы сторонними сайтами.
9. Удаление `Server` и `X-Powered-By`.

## Решение по шагам

1. Создайте структуру конфигурации `SecurityConfig` с возможностью переопределения значений.
2. Напишите функцию `NewProductionSecurityMiddleware(cfg SecurityConfig) func(http.Handler) http.Handler`.
3. В цикле обработчика выставьте все 8 обязательных заголовков.
4. Удалите идентификаторы серверного ПО.
5. Напишите unit-тест, проверяющий наличие каждого заголовка в ответах.
6. Продемонстрируйте работу middleware на тестовом сервере.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

type ProductionSecurityConfig struct {
	HSTS                    string
	CSP                     string
	FrameOptions            string
	ContentTypeOptions      string
	ReferrerPolicy          string
	PermissionsPolicy       string
	CrossOriginOpenerPolicy string
	CrossOriginResourcePolicy string
}

func DefaultProductionConfig() ProductionSecurityConfig {
	return ProductionSecurityConfig{
		HSTS:                    "max-age=63072000; includeSubDomains; preload",
		CSP:                     "default-src 'self'; script-src 'self'; object-src 'none'; frame-ancestors 'none'; base-uri 'none';",
		FrameOptions:            "DENY",
		ContentTypeOptions:      "nosniff",
		ReferrerPolicy:          "strict-origin-when-cross-origin",
		PermissionsPolicy:       "accelerometer=(), camera=(), geolocation=(), gyroscope=(), magnetometer=(), microphone=(), payment=(), usb=()",
		CrossOriginOpenerPolicy: "same-origin",
		CrossOriginResourcePolicy: "same-origin",
	}
}

func ProductionSecurityHeaders(cfg ProductionSecurityConfig) func(http.Handler) http.Handler {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			h := w.Header()

			h.Set("Strict-Transport-Security", cfg.HSTS)
			h.Set("Content-Security-Policy", cfg.CSP)
			h.Set("X-Frame-Options", cfg.FrameOptions)
			h.Set("X-Content-Type-Options", cfg.ContentTypeOptions)
			h.Set("Referrer-Policy", cfg.ReferrerPolicy)
			h.Set("Permissions-Policy", cfg.PermissionsPolicy)
			h.Set("Cross-Origin-Opener-Policy", cfg.CrossOriginOpenerPolicy)
			h.Set("Cross-Origin-Resource-Policy", cfg.CrossOriginResourcePolicy)

			// Удаляем технические маркеры платформы
			h.Del("Server")
			h.Del("X-Powered-By")

			next.ServeHTTP(w, r)
		})
	}
}

func main() {
	cfg := DefaultProductionConfig()
	middleware := ProductionSecurityHeaders(cfg)

	handler := middleware(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		_, _ = w.Write([]byte(`{"status":"high-security microservice active"}`))
	}))

	req := httptest.NewRequest(http.MethodGet, "/api/status", nil)
	rec := httptest.NewRecorder()

	handler.ServeHTTP(rec, req)

	fmt.Println("HTTP Status Code:", rec.Code)
	fmt.Println("\n=== ПРОВЕРКА PRODUCTION SECURITY HEADERS ===")
	checkHeaders := []string{
		"Strict-Transport-Security",
		"Content-Security-Policy",
		"X-Frame-Options",
		"X-Content-Type-Options",
		"Referrer-Policy",
		"Permissions-Policy",
		"Cross-Origin-Opener-Policy",
		"Cross-Origin-Resource-Policy",
	}

	for _, name := range checkHeaders {
		fmt.Printf("%-30s: %s\n", name, rec.Header().Get(name))
	}
}
```

ℹ️ Production Security Headers Bundle со всеми стандартами OWASP

## Под капотом

Что делают `Cross-Origin-Opener-Policy (COOP)` и `Cross-Origin-Resource-Policy (CORP)`?
- `Cross-Origin-Opener-Policy: same-origin`: разрывает связь `window.opener` между страницами из разных источников. Вредоносный сайт, открывший ваше приложение через `window.open()`, не может манипулировать объектом окна или измерять время отклика для атак по сторонним каналам (Cross-Window Timing Attacks).
- `Cross-Origin-Resource-Policy: same-origin`: защищает нетекстовые ресурсы (изображения, PDF, шрифты) от встраивания на сторонних сайтах через `<img src="...">`, предотвращая утечку приватных графиков и документов пользователя.

## Подводные камни

1. Выставление заголовков после `w.WriteHeader(status)`: вызов `w.WriteHeader` фиксирует заголовки и отправляет их в сетевой сокет. Любые вызовы `w.Header().Set(...)` после этого будут проигнорированы.
2. Несогласованность CSP и внешних шрифтов/CDN: при включении `default-src 'self'` браузер заблокирует загрузку внешних шрифтов (Google Fonts) или аналитики, если они явно не указаны в политике.

## На собеседовании

**Вопрос с собеседования:** Зачем нужен заголовок `Permissions-Policy` в современных веб-сервисах?
**Ответ:** `Permissions-Policy` (ранее `Feature-Policy`) предоставляет разработчикам декларативный контроль над аппаратными и браузерными API устройства пользователя.
Даже если в веб-приложение будет внедрен вредоносный JavaScript-код (через XSS или взломанную NPM/Go зависимость), политика `geolocation=(), camera=(), microphone=()` на аппаратном уровне запрещает браузеру включать веб-камеру, микрофон или считывать координаты GPS пользователя, минимизируя ущерб от компрометации.
