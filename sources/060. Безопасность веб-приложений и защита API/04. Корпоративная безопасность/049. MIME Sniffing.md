# MIME Sniffing: предотвращение атак через подмену типов контента

## Условие

Установите X-Content-Type-Options: nosniff для защиты от MIME-based атак и продемонстрируйте опасность MIME Confusion, когда загруженная картинка исполняется браузером как скрипт.

### Исходная формулировка

**MIME sniffing**: Установите `X-Content-Type-Options: nosniff` для защиты от MIME-based атак.

## Теория

MIME Confusion / MIME Sniffing атаки:
Злоумышленник загружает на сайт аватарку профиля `avatar.jpg`, внутри которой спрятан исполняемый JavaScript код:
`/* JPEG Header */ <script>alert(document.domain)</script>` (файл-полиглот / Polyglot file).

Если бэкенд:
1. Не указывает строгий заголовок `Content-Type: image/jpeg`.
2. Либо не выставляет заголовок `X-Content-Type-Options: nosniff`.
Браузер при загрузке тегом `<script src="/uploads/avatar.jpg">` пытается "угадать" тип содержимого. Если браузер видит, что файл содержит синтаксически корректный JS-код, он исполняет его в контексте домена приложения!

Заголовок `X-Content-Type-Options: nosniff` жестко фиксирует правило:
Браузер обязан исполнять скрипты (`<script>`) и стили (`<link rel="stylesheet">`) **только в том случае**, если объявленный сервером `Content-Type` в точности соответствует спецификации (`text/javascript`, `text/css`). Если тип отличается, браузер блокирует загрузку.

## Решение по шагам

1. Напишите HTTP-сервер для отдачи статических файлов.
2. Реализуйте middleware, принудительно выставляющий `X-Content-Type-Options: nosniff`.
3. Убедитесь, что для каждого файла выставляется точный `Content-Type` через `mime.TypeByExtension` или `http.DetectContentType`.
4. Продемонстрируйте блокировку выполнения полиглот-файлов браузером.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"mime"
	"net/http"
	"net/http/httptest"
	"path/filepath"
)

func NoSniffMiddleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		// Блокируем MIME Sniffing во всех браузерах
		w.Header().Set("X-Content-Type-Options", "nosniff")
		next.ServeHTTP(w, r)
	})
}

func SafeStaticServer(w http.ResponseWriter, r *http.Request) {
	filename := filepath.Base(r.URL.Path)

	// Определение корректного MIME-типа по расширению
	ext := filepath.Ext(filename)
	contentType := mime.TypeByExtension(ext)
	if contentType == "" {
		contentType = "application/octet-stream"
	}

	w.Header().Set("Content-Type", contentType)

	// Имитация вредоносного файла-полиглота (картинка с JS внутри)
	polyglotContent := []byte("GIF89a/* <script>alert('MIME XSS!')</script> */")

	w.WriteHeader(http.StatusOK)
	_, _ = w.Write(polyglotContent)
}

func main() {
	handler := NoSniffMiddleware(http.HandlerFunc(SafeStaticServer))

	// Запрос на получение загруженного файла
	req := httptest.NewRequest(http.MethodGet, "/uploads/photo.gif", nil)
	rec := httptest.NewRecorder()

	handler.ServeHTTP(rec, req)

	fmt.Println("HTTP Status Code:        ", rec.Code)
	fmt.Println("Content-Type:            ", rec.Header().Get("Content-Type"))
	fmt.Println("X-Content-Type-Options:  ", rec.Header().Get("X-Content-Type-Options"))

	if rec.Header().Get("X-Content-Type-Options") == "nosniff" {
		fmt.Println("\n🛡️ БЕЗОПАСНО: Браузер откажется исполнять данный GIF-файл через тег <script src=...>, предотвратив XSS!")
	}
}
```

ℹ️ Установка X-Content-Type-Options: nosniff для предотвращения атак MIME Confusion

## Под капотом

Спецификация WHATWG Fetch устанавливает строгие правила CORB (Cross-Origin Read Blocking) и MIME Type Checking.
Когда заголовок `X-Content-Type-Options: nosniff` установлен:
1. Запросы скриптов (`<script>`) блокируются, если MIME-тип ответа не входит в семейство JavaScript types (`text/javascript`, `application/javascript`, `application/x-javascript`).
2. Запросы стилей (`<link rel="stylesheet">`) блокируются, если MIME-тип не равен `text/css`.
Если атакующий загрузит полиглот с расширением `.png`, сервер вернет `Content-Type: image/png` + `nosniff`. При попытке подключить его как скрипт браузер выбросит в консоль ошибку:
`Refused to execute script from '...' because its MIME type ('image/png') is not executable, and strict MIME type checking is enabled.`

## Подводные камни

1. Забыть выставить явный `Content-Type`: если заголовок отсутствует, Go автоматически вызывает `http.DetectContentType`, который считывает первые 512 байт. Если файл начинается с HTML-разметки, Go сам выставит `text/html; charset=utf-8`!
2. Использование `application/octet-stream` для скриптов: при наличии `nosniff` браузер откажется исполнять такие скрипты.

## На собеседовании

**Вопрос с собеседования:** Что такое Cross-Origin Read Blocking (CORB) и как он взаимодействует с `X-Content-Type-Options: nosniff`?
**Ответ:** CORB — это встроенный в современные браузеры (Chromium) защитный механизм для изоляции сайтов (Site Isolation против атак класса Spectre).
CORB анализирует межсайтовые ответы (`cross-origin`) на запросы изображений, медиа или скриптов. Если ответ помечен как `HTML`, `JSON` или `XML`, но загружается через `<img>` или `<script>`, CORB блокирует попадание тела ответа в память процесса рендерера браузера.
Наличие заголовка `nosniff` помогает CORB мгновенно и безошибочно классифицировать ресурс по заявленному `Content-Type` без необходимости сканирования содержимого байт.
