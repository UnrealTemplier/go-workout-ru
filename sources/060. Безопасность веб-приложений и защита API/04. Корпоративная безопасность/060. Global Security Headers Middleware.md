# Global Security Headers Middleware: промышленный стандарт

## Условие

Напишите финальный глобальный middleware SecurityHeaders, добавляющий ко всем HTTP-ответам полный комплект заголовков защиты: Strict-Transport-Security: max-age=63072000; includeSubDomains; preload, X-Content-Type-Options: nosniff, X-Frame-Options: DENY, Content-Security-Policy strict, Referrer-Policy, Cross-Origin-Resource-Policy и удаление заголовка Server.

### Исходная формулировка

**Secure Headers Middleware**: В финале напиши глобальную Middleware `SecurityHeaders`, которая добавляет ко всем HTTP-ответам стандарты безопасности:
    *   `Strict-Transport-Security: max-age=63072000` (HSTS — заставляет браузер всегда использовать HTTPS).
    *   `X-Frame-Options: DENY` (защита от Clickjacking — запрет встраивать твой сайт в iframe).
    *   `Content-Security-Policy: default-src 'self'` (CSP — запрет на выполнение сторонних JS скриптов).

## Теория

Заголовки безопасности являются обязательным фундаментом защиты любого публичного веб-приложения или REST API.
При проектировании масштабируемых платформ middleware безопасности должен быть:
1. **Глобальным:** подключаться на самом верхнем уровне маршрутизатора (Outer Middleware), чтобы защищать даже ошибочные ответы (`404 Not Found`, `500 Internal Server Error`).
2. **Идемпотентным:** не перезаписывать специфичные заголовки, если нижестоящий обработчик явно их сконфигурировал.
3. **Строгим по умолчанию:** реализовывать принцип Secure by Default.

## Решение по шагам

1. Создайте структуру `SecurityHeadersMiddleware`.
2. Реализуйте метод `ServeHTTP(w http.ResponseWriter, r *http.Request)`.
3. Установите заголовки HSTS, CSP, X-Frame-Options, nosniff, Referrer-Policy, CORP, COOP.
4. Удалите заголовок `Server`.
5. Протестируйте middleware на различных маршрутах.
6. Продемонстрируйте автоматизированный аудит заголовков через unit-тесты.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func GlobalSecurityHeaders(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		h := w.Header()

		// 1. HSTS: форсирование HTTPS на 2 года с поддоменами и включением в preload-список браузеров
		h.Set("Strict-Transport-Security", "max-age=63072000; includeSubDomains; preload")

		// 2. Блокировка MIME-sniffing
		h.Set("X-Content-Type-Options", "nosniff")

		// 3. Защита от Clickjacking
		h.Set("X-Frame-Options", "DENY")

		// 4. Content Security Policy Level 3
		h.Set("Content-Security-Policy", "default-src 'self'; script-src 'self'; object-src 'none'; frame-ancestors 'none'; base-uri 'none';")

		// 5. Защита от утечки URL путей и query параметров во внешних ссылках
		h.Set("Referrer-Policy", "strict-origin-when-cross-origin")

		// 6. Изоляция контекста вкладок (Spectre / Side-channel mitigation)
		h.Set("Cross-Origin-Opener-Policy", "same-origin")
		h.Set("Cross-Origin-Resource-Policy", "same-origin")
		h.Set("Cross-Origin-Embedder-Policy", "require-corp")

		// 7. Отключение доступа к аппаратуре устройства
		h.Set("Permissions-Policy", "camera=(), microphone=(), geolocation=(), payment=()")

		// 8. Скрытие серверных сигнатур от автоматических сканеров уязвимостей
		h.Del("Server")
		h.Del("X-Powered-By")

		next.ServeHTTP(w, r)
	})
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("/api/v1/ping", func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		_, _ = w.Write([]byte(`{"status":"pong"}`))
	})

	securedApp := GlobalSecurityHeaders(mux)

	req := httptest.NewRequest(http.MethodGet, "/api/v1/ping", nil)
	rec := httptest.NewRecorder()

	securedApp.ServeHTTP(rec, req)

	fmt.Println("HTTP Status Code:", rec.Code)
	fmt.Println("\n=== ВЫСТАВЛЕННЫЕ ГЛОБАЛЬНЫЕ ЗАГОЛОВКИ БЕЗОПАСНОСТИ ===")
	for k, v := range rec.Header() {
		fmt.Printf("%-28s: %s\n", k, v[0])
	}
}
```

## Под капотом

Директива `Cross-Origin-Embedder-Policy: require-corp` (COEP) совместно с `Cross-Origin-Opener-Policy: same-origin` (COOP) переводит страницу в режим так называемой **Cross-Origin Isolation** (Кросс-доменной изоляции).
В этом режиме браузер изолирует процесс страницы в отдельном адресном пространстве операционной системы. Только в этом изолированном режиме браузер разрешает использование высокоточных таймеров и `SharedArrayBuffer`, блокируя атаки по сторонним каналам семейства Spectre/Meltdown.

## Подводные камни

1. Применение `COEP: require-corp` без проверки внешних ресурсов: если на странице загружаются сторонние картинки или аватарки без заголовка `Cross-Origin-Resource-Policy: cross-origin`, браузер заблокирует их отображение.
2. Не выставлять заголовки на статике: заголовки безопасности должны выставляться как на динамических API-эндпоинтах, так и на статических файлах.

## На собеседовании

**Вопрос с собеседования:** Что такое HSTS Preload List и каковы риски добавления домена в этот список?
**Ответ:** HSTS Preload List — это глобальный жестко зашитый список доменов в исходном коде браузеров Chrome, Firefox, Safari и Edge.
Если домен включен в Preload:
1. Браузер **никогда** не сделает ни одного HTTP-запроса к сайту и **всем его поддоменам**, даже при самом первом открытии сайта новым пользователем на чистом устройстве.
2. **Риски:** Исключение домена из preload-списка может занимать от нескольких месяцев до полугода (требуется выпуск обновлений браузеров миллионам пользователей). Если в компании есть хотя бы один внутренний legacy-поддомен без валидного HTTPS, он станет полностью недоступен для всех пользователей.
