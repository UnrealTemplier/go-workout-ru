# DNS Rebinding: Защита через net.Dialer Control на уровне сокета

## Условие

В предыдущем задании после проверки IP злоумышленник может сменить DNS-запись. Используй кастомный `net.Dialer` с `Control` функцией, которая проверяет IP-адрес прямо в момент установления TCP-соединения (на уровне сокета), блокируя приватные сети.

### Исходная формулировка

**[Каверзный кейс — DNS Rebinding]**: В предыдущем задании после проверки IP злоумышленник может сменить DNS-запись. Используй кастомный `net.Dialer` с `Control` функцией, которая проверяет IP-адрес прямо в момент установления TCP-соединения (на уровне сокета), блокируя приватные сети.

## Теория

Атака **DNS Rebinding** основана на уязвимости состояния гонки во времени (**Time-of-Check to Time-of-Use / TOCTOU**):
1. Валидатор URL делает DNS-запрос: `attacker.com` \(\to\) `93.184.216.34` (публичный IP).
2. Валидатор возвращает «URL безопасен!».
3. HTTP-клиент начинает соединение. DNS-запись имела `TTL=0`.
4. Клиент делает **второй** DNS-запрос: `attacker.com` \(\to\) `127.0.0.1` или `169.254.169.254`.
5. Сервер подключается к локальному Redis или сервису метаданных AWS!

### Решение: функция `Control` в `net.Dialer`
Спецификация Go предоставляет хук `net.Dialer.Control`:
```go
dialer.Control = func(network, address string, c syscall.RawConn) error
```
- Функция `Control` вызывается **после** того, как сетевой стек ОС срезолвил DNS и получил конкретный физический сокет, но **до** отправки первого TCP-пакета `SYN`!
- Параметр `address` содержит конкретный `IP:Port`, с которым операционная система собирается установить связь.
- Если функция `Control` возвращает ошибку, ядро ОС немедленно сбрасывает сокет без отправки единого сетевого байта! Это дает 100% гарантию иммунитета к DNS Rebinding.

## Решение по шагам

1. Реализуйте функцию `SafeSocketControl(network, address string, c syscall.RawConn) error`.
2. Извлеките IP-адрес из параметра `address` с помощью `net.SplitHostPort`.
3. Проверьте адрес методами `IsPrivate()`, `IsLoopback()`, `IsLinkLocalUnicast()`.
4. Настройте `http.Transport` с кастомным `net.Dialer` и хуком `Control`.
5. Продемонстрируйте блокировку сокета на уровне ядра при попытке соединения с локалхостом.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"errors"
	"fmt"
	"net"
	"net/http"
	"net/http/httptest"
	"syscall"
	"time"
)

// SocketSecurityControl вызывается ядром перед вызовом connect()
func SocketSecurityControl(network, address string, c syscall.RawConn) error {
	host, _, err := net.SplitHostPort(address)
	if err != nil {
		return err
	}

	ip := net.ParseIP(host)
	if ip == nil {
		return errors.New("не удалось распарсить целевой IP адрес сокета")
	}

	// Нормализация IPv4-mapped IPv6
	if ip4 := ip.To4(); ip4 != nil {
		ip = ip4
	}

	// ЖЕСТКАЯ БЛОКИРОВКА ПРИВАТНЫХ И СЛУЖЕБНЫХ ДИАПАЗОНОВ
	if ip.IsLoopback() {
		return fmt.Errorf("DNS REBINDING DETECTED: сокет попытался соединиться с Loopback IP %s", ip)
	}

	if ip.IsPrivate() {
		return fmt.Errorf("DNS REBINDING DETECTED: сокет попытался соединиться с приватной сетью %s", ip)
	}

	if ip.IsLinkLocalUnicast() || ip.IsLinkLocalMulticast() {
		return fmt.Errorf("DNS REBINDING DETECTED: сокет попытался соединиться с Link-Local (Cloud Metadata) %s", ip)
	}

	if ip.IsUnspecified() {
		return fmt.Errorf("DNS REBINDING DETECTED: сокет попытался соединиться с 0.0.0.0 (%s)", ip)
	}

	return nil
}

func NewRebindingSafeClient() *http.Client {
	dialer := &net.Dialer{
		Timeout: 5 * time.Second,
		Control: SocketSecurityControl, // Подключаем контроль сокетов!
	}

	transport := &http.Transport{
		DialContext:           dialer.DialContext,
		ResponseHeaderTimeout: 5 * time.Second,
	}

	return &http.Client{
		Transport: transport,
		Timeout:   10 * time.Second,
	}
}

func main() {
	// Поднимаем локальный тестовый сервис
	localServer := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		_, _ = w.Write([]byte("СЕКРЕТНЫЙ ОТВЕТ LOCALHOST"))
	}))
	defer localServer.Close()

	client := NewRebindingSafeClient()

	fmt.Println("=== Попытка обращения к локальному серверу через безопасный сокет ===")
	fmt.Printf("Целевой URL: %s\n", localServer.URL)

	ctx, cancel := context.WithTimeout(context.Background(), 2*time.Second)
	defer cancel()

	req, _ := http.NewRequestWithContext(ctx, "GET", localServer.URL, nil)
	resp, err := client.Do(req)
	if err != nil {
		fmt.Printf("🛡️ [УСПЕХ]: Сетевой сокет заблокирован на уровне ядра ОС!\n")
		fmt.Printf("Детали ошибки: %v\n", err)
	} else {
		resp.Body.Close()
		fmt.Println("ОШИБКА: Запрос прошел!")
	}
}
```

## Под капотом

В недрах пакета `net` вызов `dialer.Control` происходит внутри функции `fd.dial()`:
```go
// net/sock_posix.go
if ctrlCtx != nil {
    if err := ctrlCtx(fd.ctrlNetwork(), ra.String(), raw); err != nil {
        return err // Системный вызов connect() даже не вызывается!
    }
}
return fd.connect(ctx, la, ra)
```
Функция `Control` выполняется в момент, когда файловый дескриптор сокета (`fd`) уже создан, адрес уже срезолвлен в IP, но до вызова `connect()`. Возврат ошибки прерывает создание соединения без отправки сетевых пакетов.

## Подводные камни

1. **Пропуск валидации при повторных попытках (Retry):** Если транспорт делает автоматический повтор запроса, `Control` обязан вызываться на каждый отдельный сокет.
2. **Игнорирование IPv6:** Проверка должна корректно разбирать как IPv4, так и IPv6 через единый метод `net.ParseIP`.
3. **Паника при некорректном split:** Вызов `net.SplitHostPort` может вернуть ошибку, если в адресе отсутствует порт; эту ошибку необходимо обрабатывать.

## На собеседовании

**Вопрос с собеседования:** В чем архитектурное преимущество использования хука `net.Dialer.Control` перед переопределением функции `DialContext` при защите от SSRF?
**Ответ:** 1) `DialContext` требует самостоятельной реализации логики DNS-резолвинга, таймаутов и создания сокетов (что часто приводит к багам в поддержке Happy Eyeballs / Dual Stack IPv4/IPv6).
2) Хук `Control` встраивается в стандартный отлаженный механизм `net.Dialer`: Go сам резолвит IP, сам выбирает оптимальный стек (IPv4/IPv6) и параллельно пробует адреса, а хук `Control` выступает компактным шлюзом безопасности (Security Guard), проверяя уже готовый IP непосредственно перед системным вызовом `connect()` ядра.
