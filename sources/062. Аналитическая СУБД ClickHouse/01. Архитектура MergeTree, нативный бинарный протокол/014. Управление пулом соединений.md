# Управление пулом соединений и строкой подключения DSN

## Условие

**Подключение**: Используйте `github.com/ClickHouse/clickhouse-go/v2` (официальный драйвер). Подключитесь через native protocol (порт 9000) или HTTP.

## Теория

Драйвер `clickhouse-go/v2` поддерживает инициализацию как через структурированный `&clickhouse.Options{}`, так и через строку подключения (DSN URL). 

### Формат DSN:
`clickhouse://user:password@host1:9000,host2:9000/dbname?dial_timeout=200ms&max_execution_time=60&compress=lz4`

### Плюсы DSN:
- Удобно хранить в переменных окружения Kubernetes ConfigMap/Secret (`CLICKHOUSE_URL`).
- Позволяет передавать параметры кластера и тюнинга ClickHouse Settings через Query Parameters.

## Решение по шагам

1. Сформируйте DSN-строку с указанием нескольких хостов и параметров сжатия.
2. Распарсите DSN с помощью `clickhouse.ParseDSN(dsn)`.
3. Модифицируйте параметры пула (`MaxOpenConns`, `MaxIdleConns`) при необходимости.
4. Выполните `clickhouse.Open(opts)` и проверьте пинг.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"github.com/ClickHouse/clickhouse-go/v2"
)

func main() {
	// DSN строка с параметрами подключения и серверными настройками
	dsn := "clickhouse://default:@127.0.0.1:9000/default?dial_timeout=3s&compress=lz4&max_execution_time=30"

	opts, err := clickhouse.ParseDSN(dsn)
	if err != nil {
		panic(fmt.Sprintf("невалидный DSN: %v", err))
	}

	// Дополнительный тюнинг пула в Go
	opts.MaxOpenConns = 15
	opts.MaxIdleConns = 15
	opts.ConnMaxLifetime = 30 * time.Minute

	conn, err := clickhouse.Open(opts)
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	ctx, cancel := context.WithTimeout(context.Background(), 2*time.Second)
	defer cancel()

	if err := conn.Ping(ctx); err != nil {
		panic(err)
	}
	fmt.Println("Успешное подключение к ClickHouse через ParseDSN")
}
```

ℹ️ Парсинг DSN и безопасная конфигурация клиента clickhouse-go v2

**`Терминал`**

```bash
go run main.go
# Успешное подключение к ClickHouse через ParseDSN
```

## Под капотом

`clickhouse.ParseDSN` парсит URL и сопоставляет query-параметры со встроенной картой известных настроек драйвера, а все неизвестные параметры автоматически помещает в `clickhouse.Settings`, которые передаются серверу ClickHouse при каждом TCP-рукопожатии в пакете `ProtocolClientQuery`.

## Подводные камни

Если в пароле содержатся специальные символы (`@`, `:`, `/`), они должны быть корректно URL-экранированы (`url.QueryEscape`), иначе `ParseDSN` вернет ошибку некорректного формата хоста.

## На собеседовании

**Вопрос:** Как организовать отказоустойчивое подключение к кластеру ClickHouse из Go без внешнего балансировщика L4 (HAProxy)?
**Ответ:** Передать в `Options.Addr` список всех реплик кластера. Драйвер `clickhouse-go` автоматически распределяет запросы (Round-Robin или Random), а при падении одной из нод помечает ее неактивной на определенный интервал времени и переключается на рабочие реплики.
