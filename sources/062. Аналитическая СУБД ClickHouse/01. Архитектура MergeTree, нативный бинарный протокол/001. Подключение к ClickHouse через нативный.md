# Подключение к ClickHouse через нативный TCP-протокол

## Условие

Подними ClickHouse в Docker. Подключись через нативный TCP протокол (порт 9000, не HTTP 8123). Создай таблицу `events` движком `MergeTree`: `(id UUID, user_id UInt64, event_time DateTime, data String)`. Обязательно укажи `ORDER BY (event_time, user_id)`.

## Теория

Колоночная аналитическая СУБД ClickHouse поддерживает два основных сетевых интерфейса: HTTP (порт 8123) и нативный бинарный TCP-протокол (порт 9000). 

### Почему Native Protocol критичен для BigTech?
1. **Бинарная сериализация:** В нативном протоколе данные передаются блоками (Blocks), где колонки сериализованы в плоские векторы байтов без накладных расходов на разбор текстовых протоколов (JSON, CSV).
2. **Сжатие на лету:** Поддержка алгоритмов сжатия блоков (LZ4, ZSTD) непосредственно поверх сокета.
3. **Производительность:** Скорость вставки и чтения по нативному протоколу в 3–5 раз превышает HTTP-интерфейс и достигает сотен мегабайт в секунду на одно ядро процессора.

В экосистеме Go стандартом является официальный драйвер `github.com/ClickHouse/clickhouse-go/v2`. Для создания таблицы используется движок `MergeTree` — базовый движок семейства MergeTree, обеспечивающий колоночное хранение, компрессию колонок (Gorilla, DoubleDelta, LZ4) и разреженное индексирование.

## Решение по шагам

1. Подключите официальный драйвер `github.com/ClickHouse/clickhouse-go/v2`.
2. Сконфигурируйте `clickhouse.Options` с адресом `127.0.0.1:9000` (нативный TCP-порт), базой данных `default` и аутентификацией.
3. Вызовите `clickhouse.Open` и проверьте доступность узла через `conn.Ping(ctx)`.
4. Выполните DDL-запрос на создание таблицы `events` с движком `MergeTree()` и сортировкой по `(user_id, event_time)`.
5. Убедитесь в отсутствии ошибок и корректно освободите ресурсы через `conn.Close()`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"github.com/ClickHouse/clickhouse-go/v2"
	"github.com/ClickHouse/clickhouse-go/v2/lib/driver"
)

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
	defer cancel()

	opts := &clickhouse.Options{
		Addr: []string{"127.0.0.1:9000"},
		Auth: clickhouse.Auth{
			Database: "default",
			Username: "default",
			Password: "",
		},
		DialTimeout: 5 * time.Second,
		Compression: &clickhouse.Compression{
			Method: clickhouse.CompressionLZ4,
		},
		Settings: clickhouse.Settings{
			"max_execution_time": 60,
		},
	}

	conn, err := clickhouse.Open(opts)
	if err != nil {
		panic(fmt.Sprintf("ошибка инициализации клиента: %v", err))
	}
	defer func() {
		if err := conn.Close(); err != nil {
			fmt.Printf("ошибка закрытия соединения: %v\n", err)
		}
	}()

	if err := conn.Ping(ctx); err != nil {
		panic(fmt.Sprintf("ClickHouse недоступен по нативному протоколу: %v", err))
	}
	fmt.Println("Успешное подключение к ClickHouse по нативному протоколу (порт 9000)")

	createTableQuery := `
	CREATE TABLE IF NOT EXISTS events (
		id UUID,
		user_id UInt64,
		event_time DateTime,
		payload String
	) ENGINE = MergeTree()
	ORDER BY (user_id, event_time);
	`
	if err := conn.Exec(ctx, createTableQuery); err != nil {
		panic(fmt.Sprintf("ошибка создания таблицы events: %v", err))
	}
	fmt.Println("Таблица events успешно создана или уже существует")
}
```

ℹ️ Инициализация бинарного TCP-подключения к ClickHouse и создание таблицы MergeTree

**`Терминал`**

```bash
go run main.go
# Успешное подключение к ClickHouse по нативному протоколу (порт 9000)
# Таблица events успешно создана или уже существует
```

## Под капотом

Нативный протокол ClickHouse передает управляющие пакеты (Hello, Ping, Query, Data, Exception) в строго типизированном бинарном формате. Пакет `Data` состоит из заголовка блока (Block Info), метаданных схемы (имена и типы колонок) и плоских сериализованных массивов значений каждого столбца. При включенном LZ4 каждый блок сжимается независимыми чанками размером до 1 МБ.

## Подводные камни

Распространенная ошибка — попытка подключиться к HTTP-порту 8123 с использованием настроек бинарного протокола (или наоборот к порту 9000 через HTTP-клиент). Драйвер вернет ошибку некорректного рукопожатия или сброс TCP-соединения. Для HTTP используйте `Protocol: clickhouse.HTTP` и порт 8123, для TCP — `Protocol: clickhouse.Native` (по умолчанию) и порт 9000.

## На собеседовании

**Вопрос:** Почему ClickHouse требует указания ORDER BY для таблиц MergeTree, даже если PRIMARY KEY не задан явно?
**Ответ:** В MergeTree первичный ключ (`PRIMARY KEY`) по умолчанию совпадает с ключом сортировки (`ORDER BY`). Данные внутри каждого парта (part) физически упорядочиваются на диске в соответствии с `ORDER BY`. На базе этого порядка строится разреженный индекс (`primary.cidx`), сохраняющий значение ключа для каждой 8192-й строки (индексная гранулярность).
