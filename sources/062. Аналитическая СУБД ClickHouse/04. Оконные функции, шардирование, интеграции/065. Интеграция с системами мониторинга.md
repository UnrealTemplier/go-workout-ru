# Интеграция с системами мониторинга: ClickHouse и Grafana

## Условие

**ClickHouse + Grafana**: Подключите Grafana к ClickHouse через официальный datasource. Постройте real-time dashboards.

## Теория

ClickHouse — популярнейший бэкенд для хранения логов и метрик в Grafana (благодаря официальному плагину Grafana ClickHouse Datasource):

### Макросы Grafana для ClickHouse:
1. **`$__timeFilter(time_column)`:** Автоматически подставляет выбранный пользователем интервал времени в секцию `WHERE` (`time_column BETWEEN ... AND ...`).
2. **`$__timeInterval` / `$__interval`:** Автоматически подбирает гранулярность группировки времени под ширину экрана монитора пользователя (например, `toStartOfInterval(time_column, INTERVAL $__interval)`).
3. **`toUInt64(toDateTime(...))`:** Преобразование времени в формат миллисекунд/секунд для отрисовки временных рядов (Time Series).

## Решение по шагам

1. Составьте запрос, эмулирующий работу дашборда Grafana с фильтрацией по окну времени.
2. Примените округление через `toStartOfInterval(event_time, INTERVAL 5 MINUTE)`.
3. Сформируйте метрику RPS и ошибок.
4. Выполните запрос из Go и распарсите срез временного ряда.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"github.com/ClickHouse/clickhouse-go/v2"
)

type TimeSeriesPoint struct {
	Timestamp time.Time
	Requests  uint64
	Errors    uint64
}

func main() {
	ctx := context.Background()
	conn, err := clickhouse.Open(&clickhouse.Options{
		Addr: []string{"127.0.0.1:9000"},
		Auth: clickhouse.Auth{Database: "default"},
	})
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	// Запрос, имитирующий макросы Grafana Time Series Dashboard
	query := `
		SELECT 
			toStartOfInterval(event_time, INTERVAL 5 MINUTE) AS time_bucket,
			count() AS total_requests,
			countIf(payload LIKE '%error%') AS error_count
		FROM events
		WHERE event_time >= now() - INTERVAL 1 HOUR
		GROUP BY time_bucket
		ORDER BY time_bucket ASC
	`

	rows, err := conn.Query(ctx, query)
	if err != nil {
		panic(err)
	}
	defer rows.Close()

	fmt.Println("Данные для графика Grafana (5-минутные интервалы):")
	for rows.Next() {
		var p TimeSeriesPoint
		if err := rows.Scan(&p.Timestamp, &p.Requests, &p.Errors); err != nil {
			panic(err)
		}
		fmt.Printf("  Интервал: %s | RPS: %5d | Ошибок: %3d\n",
			p.Timestamp.Format("15:04"), p.Requests, p.Errors)
	}
}
```

ℹ️ Подготовка аналитических временных рядов для интеграции с Grafana дашбордами

## Под капотом

Функция `countIf(cond)` в ClickHouse компилируется в векторизованную инструкцию без ветвлений процессора (Branch-free SIMD). Маска условий вычисляется для целого блока в 65 536 строк, а суммирование единиц выполняется векторной инструкцией `POPCNT`.

## Подводные камни

Если пользователь в Grafana выберет слишком широкий интервал времени (например, 1 год) с мелкой гранулярностью (1 секунда), запрос попытается вернуть 31 миллион строк, что приведет к зависанию браузера. Всегда используйте макрос `$__interval` для автоподбора шага.

## На собеседовании

**Вопрос:** Как избежать повторных тяжелых запросов в ClickHouse при обновлении дашбордов Grafana сотнями пользователей?
**Ответ:** Настроить Materialized Views с минутными предагрегатами, включить встроенный Query Cache на уровне ClickHouse (`use_query_cache = 1`), а в Grafana настроить минимальный интервал обновления (Min Interval = 30s).
