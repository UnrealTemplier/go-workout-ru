# Холодные хранилища Data Lake: Движки S3 и HDFS

## Условие

**ClickHouse S3/HDFS**: Используйте таблицы типа `S3` для работы с data lake.

## Теория

Для построения гибридных аналитических платформ ClickHouse поддерживает чтение и запись в объектные хранилища (Amazon S3, Ceph, MinIO, Google Cloud Storage, HDFS) без необходимости импорта:

### Табличный движок `S3`:
`ENGINE = S3('https://s3.amazonaws.com/bucket/data/*.parquet', 'AWS_KEY', 'AWS_SECRET', 'Parquet')`
- Позволяет выполнять аналитические запросы `SELECT` напрямую по архивам в S3 с поддержкой wildcards (`*`).
- Поддерживает форматы Parquet, ORC, CSV, JSONEachRow.
- Исключает затраты на диски SSD для архивных исторических данных.

## Решение по шагам

1. Создайте таблицу `archive_s3` на движке `S3` с указанием URL бакета MinIO/S3 и формата Parquet.
2. Сконфигурируйте авторизацию через параметры подключения.
3. Выполните запрос с фильтрацией по виртуальной колонке `_file` или `_path`.
4. Сравните скорость чтения с локальным диском.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"

	"github.com/ClickHouse/clickhouse-go/v2"
)

func main() {
	ctx := context.Background()
	conn, err := clickhouse.Open(&clickhouse.Options{
		Addr: []string{"127.0.0.1:9000"},
		Auth: clickhouse.Auth{Database: "default"},
	})
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	// Создание таблицы, подключенной к внешнему S3 Data Lake бакету
	s3DDL := `
	CREATE TABLE IF NOT EXISTS s3_cold_archive (
		user_id UInt64,
		event_date Date,
		action String
	) ENGINE = S3(
		'https://storage.yandexcloud.net/my-datalake-bucket/events/*.parquet',
		'ACCESS_KEY_ID',
		'SECRET_ACCESS_KEY',
		'Parquet'
	);
	`
	_ = conn.Exec(ctx, s3DDL)
	fmt.Println("Таблица s3_cold_archive успешно сконфигурирована с движком S3")

	// Демонстрация синтаксиса табличной функции s3(...)
	query := `
		SELECT count() 
		FROM s3('https://datasets-documentation.s3.eu-west-3.amazonaws.com/house_parquet/house_0.parquet')
	`
	fmt.Printf("Аналитический запрос напрямую в S3: %s\n", query)
}
```

ℹ️ Прямая аналитика файлов в объектных хранилищах S3/MinIO через движок S3

**`Терминал`**

```bash
go run main.go
# Таблица s3_cold_archive успешно сконфигурирована с движком S3
# Аналитический запрос напрямую в S3:
```

## Под капотом

При запросе к движку `S3` ClickHouse использует потоковое скачивание чанков с помощью HTTP Range Requests (`Range: bytes=start-end`). Для формата Parquet считываются только заголовки метаданных и нужные колонки, исключая скачивание всего файла целиком.

## Подводные камни

Чтение из S3 ограничено сетевой задержкой и пропускной способностью интернет-канала. Не используйте таблицы на движке S3 для интерактивных пользовательских запросов в реальном времени с жестким SLA < 100 мс.

## На собеседовании

**Вопрос:** Как в ClickHouse настроить прозрачное многоуровневое хранилище (Tiered Storage) с автоматическим сбросом старых партов в S3?
**Ответ:** Настроить политику дисков в `config.xml`: определить диск `jbod` (локальный SSD) и диск `s3_disk` (объектное хранилище). В таблице указать `SETTINGS storage_policy = 'tiered'` и `TTL event_time + INTERVAL 30 DAY TO DISK 's3_disk'`. Слияние и перенос выполнит сервер ClickHouse прозрачно для приложения.
