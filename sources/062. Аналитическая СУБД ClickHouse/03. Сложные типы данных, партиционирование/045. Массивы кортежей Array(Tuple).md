# Массивы кортежей Array(Tuple) и разворачивание через arrayJoin

## Условие

**Массивы и вложенные структуры.**: Создайте таблицу с колонкой типа `Array(Tuple(String, Float64))` для хранения корзины товаров. Выполните запрос с `arrayJoin` для разворачивания массива.

## Теория

Для моделирования структур вроде «Корзина покупок» или «Список позиций заказа» ClickHouse поддерживает кортежи внутри массивов:
`Array(Tuple(product_id String, price Float64, qty UInt32))`

### Механика `arrayJoin`:
- Функция `arrayJoin(arr)` трансформирует массив в отдельные строки таблицы (эквивалент `UNNEST` в PostgreSQL или `$unwind` в MongoDB).
- Если строка содержала массив из 5 товаров, `arrayJoin` возвратит 5 плоских строк, сохранив остальные колонки заказа неизменными.

## Решение по шагам

1. Создайте таблицу `carts` с колонкой `items Array(Tuple(String, Float64))`.
2. Вставьте заказ с корзиной из трех товаров.
3. Выполните запрос с `arrayJoin(items) AS item` и извлеките поля кортежа `item.1` (название) и `item.2` (цена).
4. Выведите плоский список проданных товаров.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"

	"github.com/ClickHouse/clickhouse-go/v2"
)

type CartItem struct {
	Name  string
	Price float64
}

func main() {
	ctx := context.Background()
	conn, err := clickhouse.Open(&clickhouse.Options{
		Addr: []string{"127.0.0.1:9000"},
		Auth: clickhouse.Auth{Database: "default"},
	})
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	ddl := `
	CREATE TABLE IF NOT EXISTS carts (
		order_id UInt64,
		items Array(Tuple(String, Float64))
	) ENGINE = MergeTree()
	ORDER BY order_id;
	`
	if err := conn.Exec(ctx, ddl); err != nil {
		panic(err)
	}

	// Вставка массива кортежей
	batch, err := conn.PrepareBatch(ctx, "INSERT INTO carts")
	if err != nil {
		panic(err)
	}

	// Кортежи в clickhouse-go передаются как [][]any
	itemsTuple := [][]any{
		{"Go Programming Book", 1200.00},
		{"Mechanical Keyboard", 8500.00},
		{"USB-C Cable", 450.50},
	}
	_ = batch.Append(uint64(55001), itemsTuple)
	if err := batch.Send(); err != nil {
		panic(err)
	}

	// Разворачивание корзины в строки через arrayJoin
	query := `
		SELECT 
			order_id,
			items.1 AS product_name,
			items.2 AS product_price
		FROM carts
		ARRAY JOIN items
		WHERE order_id = 55001
	`
	rows, err := conn.Query(ctx, query)
	if err != nil {
		panic(err)
	}
	defer rows.Close()

	fmt.Println("Позиции заказа, развернутые через ARRAY JOIN:")
	for rows.Next() {
		var (
			orderID uint64
			name    string
			price   float64
		)
		if err := rows.Scan(&orderID, &name, &price); err != nil {
			panic(err)
		}
		fmt.Printf("  Заказ #%d: Товар '%s' -> %.2f руб\n", orderID, name, price)
	}
}
```

ℹ️ Работа с Array(Tuple) и разворачивание в плоские строки через ARRAY JOIN

**`Терминал`**

```bash
go run main.go
# Позиции заказа, развернутые через ARRAY JOIN:
#   Заказ #55001: Товар 'Go Programming Book' -> 1200.00 руб
#   Заказ #55001: Товар 'Mechanical Keyboard' -> 8500.00 руб
#   Заказ #55001: Товар 'USB-C Cable' -> 450.50 руб
```

## Под капотом

`Tuple(A, B)` внутри ClickHouse не создает накладных расходов: элементы кортежа физически хранятся как отдельные параллельные файлы столбцов `items.1.bin` и `items.2.bin`. Поэтому при запросе `SELECT items.1` ClickHouse считывает только названия товаров, не загружая цены с диска.

## Подводные камни

В отличие от SQL JOIN, `ARRAY JOIN` полностью отбрасывает строки с пустыми массивами (эквивалент INNER JOIN). Если требуется сохранить строки с пустой корзиной, используйте `LEFT ARRAY JOIN`.

## На собеседовании

**Вопрос:** В чем разница между `arrayJoin` и `LEFT ARRAY JOIN`?
**Ответ:** `arrayJoin` отбрасывает строки, у которых массив пустой. `LEFT ARRAY JOIN` сохраняет строку, возвращая значения элементов кортежа по умолчанию (`0` для чисел, пустая строка `""` для строк).
