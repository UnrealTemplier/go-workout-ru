# Векторные операции над массивами: arrayMap, arrayFilter и arrayReduce

## Условие

**Array operations**: Используйте `arrayMap`, `arrayFilter`, `arrayReduce`, `arrayExists`, `arrayCount`.

## Теория

ClickHouse обладает богатым набором функций высшего порядка для функциональной обработки массивов на уровне векторного движка:

1. **`arrayMap(x -> expr, arr)`:** Трансформация каждого элемента массива (эквивалент `map()`).
2. **`arrayFilter(x -> cond, arr)`:** Фильтрация элементов массива по предикату (эквивалент `filter()`).
3. **`arrayReduce('agg_fn', arr)`:** Свертка массива агрегатной функцией (`min`, `max`, `sum`, `avg`).
4. **`arrayExists(x -> cond, arr)`:** Возвращает 1, если хотя бы один элемент удовлетворяет условию.
5. **`arrayCount(x -> cond, arr)`:** Подсчитывает количество элементов, удовлетворяющих условию.

## Решение по шагам

1. Создайте таблицу заказов с массивом стоимостей `items_prices Array(Float64)`.
2. Вставьте заказы с разными наборами цен.
3. Составьте SQL-запрос с фильтрацией дорогих позиций `arrayFilter(x -> x > 1000, items_prices)` и вычислением скидки 10% через `arrayMap`.
4. Выполните запрос и выведите результаты в Go.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"

	"github.com/ClickHouse/clickhouse-go/v2"
)

func main() {
	ctx := context.Background()
	conn, err := clickhouse.Open(&clickhouse.Options{
		Addr: []string{"127.0.0.1:9000"},
		Auth: clickhouse.Auth{Database: "default"},
	})
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	_ = conn.Exec(ctx, `
		CREATE TABLE IF NOT EXISTS orders_pricing (
			order_id UInt64,
			prices Array(Float64)
		) ENGINE = MergeTree()
		ORDER BY order_id;
	`)

	batch, err := conn.PrepareBatch(ctx, "INSERT INTO orders_pricing")
	if err != nil {
		panic(err)
	}
	_ = batch.Append(uint64(901), []float64{150.0, 1200.0, 450.0, 3500.0})
	if err := batch.Send(); err != nil {
		panic(err)
	}

	// Аналитический запрос с функциями высшего порядка
	query := `
		SELECT 
			order_id,
			arrayFilter(x -> x >= 1000, prices) AS premium_prices,
			arrayMap(x -> round(x * 0.9, 2), prices) AS discounted_prices,
			arrayReduce('max', prices) AS max_price
		FROM orders_pricing
		WHERE order_id = 901
	`
	rows, err := conn.Query(ctx, query)
	if err != nil {
		panic(err)
	}
	defer rows.Close()

	for rows.Next() {
		var (
			orderID    uint64
			premium    []float64
			discounted []float64
			maxPrice   float64
		)
		if err := rows.Scan(&orderID, &premium, &discounted, &maxPrice); err != nil {
			panic(err)
		}
		fmt.Printf("Заказ #%d:\n", orderID)
		fmt.Printf("  Премиум товары (>=1000):   %v\n", premium)
		fmt.Printf("  Цены со скидкой 10%%:        %v\n", discounted)
		fmt.Printf("  Максимальная цена позиции: %.2f руб\n", maxPrice)
	}
}
```

ℹ️ Обработка массивов функциями высшего порядка arrayMap, arrayFilter и arrayReduce

```bash

```

## Под капотом

Лямбда-выражения в функциях `arrayMap` и `arrayFilter` компилируются в JIT-код на лету с использованием библиотеки LLVM. Вычисление применяется векторно ко всему блоку гранулы за один проход, обеспечивая производительность на уровне скомпилированного кода C++.

## Подводные камни

Чрезмерно сложные вложенные лямбды с несколькими аргументами (`arrayMap((x, y) -> ...`) могут отключить JIT-оптимизацию и замедлить вычисление на миллиардах строк.

## На собеседовании

**Вопрос:** Чем `arrayReduce('sum', arr)` отличается от встроенной функции `arraySum(arr)`?
**Ответ:** `arraySum` — специализированная высокооптимизированная функция для суммирования чисел. `arrayReduce` — универсальный полиморфный комбинатор, принимающий имя любой агрегатной функции в виде строки (например, `arrayReduce('quantile(0.95)', arr)`), что дает максимальную гибкость ценой небольшого оверхеда на диспетчеризацию.
