# Сопоставление сложных типов: DateTime64, IPv4, Array и Map

## Условие

**Сопоставление сложных типов данных**: Создайте таблицу логов со сложными типами данных: `DateTime64(3)`, `IPv4`, `Array(String)`, `Map(String, String)`. Напишите код записи структуры лога из Go в ClickHouse. Обеспечьте правильную конвертацию типов данных Go (например, передачу `net.IP` для колонок IP-адресов и срезов слайсов для массивов ClickHouse).

## Теория

ClickHouse обладает богатой системой встроенных типов, оптимизированных для сетевого стека и телеметрии:

1. **`DateTime64(precision)`:** Временные метки с субсекундной точностью (`DateTime64(3)` — миллисекунды, `DateTime64(6)` — микросекунды, `DateTime64(9)` — наносекунды). В Go мапится на `time.Time`.
2. **`IPv4` / `IPv6`:** Специализированные компактные бинарные типы (4 байта для IPv4, 16 байт для IPv6) вместо хранения IP-адресов строками по 15–45 байт. В Go мапятся на `net.IP` или `netip.Addr`.
3. **`Array(String)`:** Срез строк `[]string`.
4. **`Map(String, String)`:** Хэш-мапа `map[string]string`.

## Решение по шагам

1. Создайте таблицу `network_traffic` со всеми перечисленными типами.
2. Подготовьте запись с IP-адресом `net.ParseIP("192.168.1.1")` и миллисекундным временем.
3. Вставьте строку через пакетный интерфейс `batch.Append()`.
4. Выполните выборку и убедитесь в корректности типов.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"net"
	"time"

	"github.com/ClickHouse/clickhouse-go/v2"
	"github.com/google/uuid"
)

func main() {
	ctx := context.Background()
	conn, err := clickhouse.Open(&clickhouse.Options{
		Addr: []string{"127.0.0.1:9000"},
		Auth: clickhouse.Auth{Database: "default"},
	})
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	// Таблица с прецизионными типами сети и телеметрии
	ddl := `
	CREATE TABLE IF NOT EXISTS network_traffic (
		packet_id UUID,
		src_ip IPv4,
		dst_ip IPv4,
		timestamp DateTime64(3),
		protocols Array(String),
		headers Map(String, String)
	) ENGINE = MergeTree()
	ORDER BY (src_ip, timestamp);
	`
	if err := conn.Exec(ctx, ddl); err != nil {
		panic(err)
	}

	// Вставка строки со сложными сетевыми типами
	batch, err := conn.PrepareBatch(ctx, "INSERT INTO network_traffic")
	if err != nil {
		panic(err)
	}

	pktID := uuid.New()
	srcIP := net.ParseIP("10.244.1.42")
	dstIP := net.ParseIP("172.16.0.5")
	ts := time.Now()
	protocols := []string{"IP", "TCP", "TLSv1.3"}
	headers := map[string]string{
		"Host":            "api.internal.bank",
		"User-Agent":      "Go-http-client/2.0",
		"X-Forwarded-For": "203.0.113.195",
	}

	if err := batch.Append(pktID, srcIP, dstIP, ts, protocols, headers); err != nil {
		panic(fmt.Sprintf("ошибка типизации: %v", err))
	}
	if err := batch.Send(); err != nil {
		panic(err)
	}

	// Выборка и форматирование результатов
	query := `
		SELECT packet_id, src_ip, dst_ip, timestamp, protocols, headers 
		FROM network_traffic 
		WHERE packet_id = ?
	`
	var (
		resID        uuid.UUID
		resSrcIP     net.IP
		resDstIP     net.IP
		resTS        time.Time
		resProtocols []string
		resHeaders   map[string]string
	)
	if err := conn.QueryRow(ctx, query, pktID).Scan(&resID, &resSrcIP, &resDstIP, &resTS, &resProtocols, &resHeaders); err != nil {
		panic(err)
	}

	fmt.Printf("Пакет: %s\n", resID)
	fmt.Printf("  Маршрут: %s -> %s\n", resSrcIP.String(), resDstIP.String())
	fmt.Printf("  Время с миллисекундами: %s\n", resTS.Format("2006-01-02 15:04:05.000"))
	fmt.Printf("  Протоколы: %v\n", resProtocols)
	fmt.Printf("  Host заголовок: %s\n", resHeaders["Host"])
}
```

## Под капотом

Тип `IPv4` в ClickHouse хранится как беззнаковое 32-битное число `UInt32` в формате Big Endian. При выполнении функций `IPv4NumToString` или маппинге в Go драйвер выполняет битовый сдвиг и преобразует 4 байта в стандартное представление IP адреса без оверхеда на строки.

## Подводные камни

Передача в колонку `IPv4` объекта `net.IP`, содержащего IPv6-адрес (16 байт), приведет к ошибке конвертации или обрезанию байтов. Для универсального хранения обоих протоколов используйте тип `IPv6`.

## На собеседовании

**Вопрос:** Как в ClickHouse искать IP-адреса, входящие в заданную CIDR-подсеть (например, `192.168.0.0/16`)?
**Ответ:** С помощью специализированной встроенной функции `isIPAddressInRange(src_ip, '192.168.0.0/16')` или функций `IPv4CIDRToRange()`. Векторный движок ClickHouse выполняет битовую маску над целыми числами за единичные такты CPU.
