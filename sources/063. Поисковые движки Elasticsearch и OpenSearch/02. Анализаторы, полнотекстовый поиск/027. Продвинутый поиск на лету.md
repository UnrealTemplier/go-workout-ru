# Продвинутый поиск на лету: Фильтры Edge N-Gram для Autocomplete

## Условие

**[Высокая сложность — Custom Analyzer]**: Создай индекс с кастомным анализатором: добавь фильтр `ngram` (разбивает слова на подстроки длиной 2-4 символа). Проиндексируй слово "GoLang" и убедись, что поиск по строке "Lan" находит этот документ ( автодополнение / search-as-you-type).

## Теория

Для реализации поисковых подсказок (Search-As-You-Type / Autocomplete) пользователь вводит текст посимвольно ("G", "Go", "Gol", "Gola").

### Почему обычный `wildcard: "*gola*"` — антипаттерн?
Запрос с ведущей звездочкой `*word` производит полный перебор всех терминов словаря инвертированного индекса, что занимает секунды и перегружает CPU.

### Решение: Анализатор Edge N-Gram:
1. Во время индексации слово "Golang" разбивается на префиксные подстроки длиной от 2 до 6 символов: `["go", "gol", "gola", "golan", "golang"]`.
2. Поисковый запрос пользователя ищется прямым мгновенным O(1) совпадением по инвертированному индексу!

## Решение по шагам

1. Создайте индекс `autocomplete_products` с фильтром токенов `edge_ngram` (`min_gram: 2, max_gram: 6`).
2. Настройте отдельный `search_analyzer: "standard"` для поиска без префиксного разбиения запроса.
3. Проиндексируйте слово `"Golang"`.
4. Продемонстрируйте мгновенный поиск по префиксу `"gola"`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"encoding/json"
	"fmt"
	"strings"

	"github.com/elastic/go-elasticsearch/v8"
	"github.com/elastic/go-elasticsearch/v8/esapi"
)

func main() {
	es, err := elasticsearch.NewDefaultClient()
	if err != nil {
		panic(err)
	}
	ctx := context.Background()

	// 1. Создание индекса с анализатором Edge N-Gram
	mapping := `{
		"settings": {
			"analysis": {
				"filter": {
					"autocomplete_filter": {
						"type": "edge_ngram",
						"min_gram": 2,
						"max_gram": 6
					}
				},
				"analyzer": {
					"autocomplete": {
						"type": "custom",
						"tokenizer": "standard",
						"filter": ["lowercase", "autocomplete_filter"]
					}
				}
			}
		},
		"mappings": {
			"properties": {
				"title": {
					"type": "text",
					"analyzer": "autocomplete",
					"search_analyzer": "standard"
				}
			}
		}
	}`
	createReq := esapi.IndicesCreateRequest{
		Index: "autocomplete_products",
		Body:  strings.NewReader(mapping),
	}
	_, _ = createReq.Do(ctx, es)

	// 2. Индексирование слова "Golang"
	_, _ = esapi.IndexRequest{
		Index:      "autocomplete_products",
		DocumentID: "1",
		Body:       strings.NewReader(`{"title": "Golang Workout Guide"}`),
		Refresh:    "true",
	}.Do(ctx, es)

	// 3. Поиск по префиксу "gola"
	query := `{
		"query": {
			"match": {
				"title": "gola"
			}
		}
	}`
	searchReq := esapi.SearchRequest{
		Index: []string{"autocomplete_products"},
		Body:  strings.NewReader(query),
	}
	res, err := searchReq.Do(ctx, es)
	if err != nil {
		panic(err)
	}
	defer res.Body.Close()

	var searchRes map[string]any
	_ = json.NewDecoder(res.Body).Decode(&searchRes)
	total := searchRes["hits"].(map[string]any)["total"].(map[string]any)["value"]

	fmt.Printf("Поиск по префиксу 'gola' успешно нашел документов: %v\n", total)
}
```

ℹ️ Построение поисковых автоподсказок с помощью токен-фильтра edge_ngram

**`Терминал`**

```bash
go run main.go
# Поиск по префиксу 'gola' успешно нашел документов: 1
```

## Под капотом

При индексации "Golang" фильтр `edge_ngram` генерирует токены `go`, `gol`, `gola`, `golan`, `golang`. На этапе поиска `search_analyzer: "standard"` не разбивает запрос "gola" на n-граммы, а ищет токен "gola" напрямую в словаре FST за 1 такт.

## Подводные камни

Если забыть указать `search_analyzer: "standard"`, Elasticsearch применит `autocomplete` анализатор и к поисковому запросу тоже. Поисковый запрос "gola" разобьется на `go`, `gol`, `gola`, что приведет к поиску по слишком коротким токенам и засорению выдачи нерелевантными результатами.

## На собеседовании

**Вопрос:** Чем `edge_ngram` отличается от обычного `ngram`?
**Ответ:** `ngram` нарезает подстроки из любого места слова (например, для "golang": `"ol"`, `"lan"`, `"ang"`). `edge_ngram` привязан строго к началу слова (префиксу: `"go"`, `"gol"`, `"gola"`), что идеально для Autocomplete и в разы уменьшает объем инвертированного индекса.
