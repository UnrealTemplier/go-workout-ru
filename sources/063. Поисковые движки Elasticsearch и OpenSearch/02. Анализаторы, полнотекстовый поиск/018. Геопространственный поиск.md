# Геопространственный поиск: Geo Point и фильтрация по радиусу

## Условие

**Index mapping**: Создайте index с explicit mapping (не полагайтесь на dynamic mapping в production). Определите типы полей: `text`, `keyword`, `integer`, `date`, `geo_point`.

## Теория

Elasticsearch предоставляет эффективные структуры пространственного индексирования на базе BKD-деревьев (BKD-Tree):

1. **`geo_point`:** Координаты широты и долготы (`lat`, `lon`).
2. **`geo_distance`:** Фильтрация точек в заданном радиусе (например, найти всех свободных курьеров в радиусе 3 км от ресторана).
3. **`geo_bounding_box`:** Поиск точек внутри прямоугольной области экрана карты.

## Решение по шагам

1. Создайте индекс `couriers` с полем `location` типа `geo_point`.
2. Вставьте координаты курьеров.
3. Составьте фильтр `geo_distance` с радиусом `3km` от заданной точки.
4. Выполните запрос и отсортируйте результаты по возрастанию расстояния `_geo_distance`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"encoding/json"
	"fmt"
	"strings"

	"github.com/elastic/go-elasticsearch/v8"
	"github.com/elastic/go-elasticsearch/v8/esapi"
)

func main() {
	es, err := elasticsearch.NewDefaultClient()
	if err != nil {
		panic(err)
	}
	ctx := context.Background()

	// 1. Создание индекса с типом geo_point
	mapping := `{
		"mappings": {
			"properties": {
				"name": { "type": "keyword" },
				"location": { "type": "geo_point" }
			}
		}
	}`
	createReq := esapi.IndicesCreateRequest{
		Index: "couriers",
		Body:  strings.NewReader(mapping),
	}
	_, _ = createReq.Do(ctx, es)

	// 2. Вставка координат курьеров (Москва)
	courier1 := `{"name": "Иван", "location": {"lat": 55.7558, "lon": 37.6173}}` // Центр (Красная пл.)
	courier2 := `{"name": "Петр", "location": {"lat": 55.7900, "lon": 37.6200}}` // ~3.8 км к северу
	_, _ = esapi.IndexRequest{Index: "couriers", DocumentID: "c1", Body: strings.NewReader(courier1), Refresh: "true"}.Do(ctx, es)
	_, _ = esapi.IndexRequest{Index: "couriers", DocumentID: "c2", Body: strings.NewReader(courier2), Refresh: "true"}.Do(ctx, es)

	// 3. Поиск курьеров в радиусе 2 км от центра с сортировкой по расстоянию
	geoQuery := `{
		"query": {
			"bool": {
				"filter": {
					"geo_distance": {
						"distance": "2km",
						"location": {
							"lat": 55.7558,
							"lon": 37.6173
						}
					}
				}
			}
		},
		"sort": [
			{
				"_geo_distance": {
					"location": { "lat": 55.7558, "lon": 37.6173 },
					"order": "asc",
					"unit": "m"
				}
			}
		]
	}`

	req := esapi.SearchRequest{
		Index: []string{"couriers"},
		Body:  strings.NewReader(geoQuery),
	}
	res, err := req.Do(ctx, es)
	if err != nil {
		panic(err)
	}
	defer res.Body.Close()

	var searchRes map[string]any
	_ = json.NewDecoder(res.Body).Decode(&searchRes)
	hits := searchRes["hits"].(map[string]any)["hits"].([]any)

	fmt.Printf("Найдено курьеров в радиусе 2 км: %d\n", len(hits))
	for _, h := range hits {
		item := h.(map[string]any)
		src := item["_source"].(map[string]any)
		sortVal := item["sort"].([]any)[0]
		fmt.Printf("  Курьер: %s | Расстояние: %.0f метров\n", src["name"], sortVal.(float64))
	}
}
```

ℹ️ Геопространственный поиск geo_point в радиусе с сортировкой по дистанции

**`Терминал`**

```bash
go run main.go
# Найдено курьеров в радиусе 2 км: 1
#   Курьер: Иван | Расстояние: 0 метров
```

## Под капотом

В Lucene геокоординаты индексируются структурой BKD-дерева (многомерное блочное k-d дерево). Точки на сфере преобразуются в пространственные Morton-коды (Z-order curve), что позволяет отсекать нерелевантные пространственные квадранты за логарифмическое время O(log N).

## Подводные камни

В строковом формате `"location": "55.75, 37.61"` порядок координат — `"lat, lon"`. Но в формате GeoJSON Geo-массива порядок строго обратный: `[lon, lat]` (долгота первая, как ось X)! Ошибка в порядке координат приведет к выбросу точек в Индийский океан.

## На собеседовании

**Вопрос:** В чем разница между `geo_point` и `geo_shape` в Elasticsearch?
**Ответ:** `geo_point` хранит строго одиночные точки (широта/долгота). `geo_shape` хранит сложные геометрические фигуры: полигоны районов, мультиполигоны зон доставки, ломаные линии маршрутов дорог, поддерживая операции пересечения (`intersects`, `disjoint`, `within`).
