# Индексирование товаров со сложной схемой маппинга

## Условие

**Индексация документов с маппингом.**: Подключитесь к Elasticsearch через `olivere/elastic` или официальный клиент. Создайте индекс `products` с явным маппингом полей (текст с анализатором, keyword, float). Индексируйте 1000 товаров.

## Теория

Для каталога товаров E-commerce требуется комплексный маппинг:
1. `name`: Полнотекстовый поиск с анализатором русской морфологии.
2. `sku`: Точный поиск артикула (`keyword`).
3. `price`: Тип `scaled_float` с коэффициентом масштабирования `scaling_factor: 100` (хранится на диске как целое число `long`, экономя память и исключая погрешность float).
4. `tags`: Массив категорий (`keyword`).

## Решение по шагам

1. Создайте индекс `ecommerce_products` со схемой маппинга.
2. Индексируйте товары каталога.
3. Проверьте поиск по названию с русской словоформой.
4. Проверьте точный поиск по `sku`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"strings"

	"github.com/elastic/go-elasticsearch/v8"
	"github.com/elastic/go-elasticsearch/v8/esapi"
)

func main() {
	es, err := elasticsearch.NewDefaultClient()
	if err != nil {
		panic(err)
	}
	ctx := context.Background()

	// Схема маппинга каталога товаров
	mapping := `{
		"mappings": {
			"properties": {
				"sku": { "type": "keyword" },
				"name": { 
					"type": "text",
					"fields": { "raw": { "type": "keyword" } }
				},
				"price": { 
					"type": "scaled_float",
					"scaling_factor": 100
				},
				"tags": { "type": "keyword" },
				"in_stock": { "type": "boolean" }
			}
		}
	}`
	createReq := esapi.IndicesCreateRequest{
		Index: "ecommerce_products",
		Body:  strings.NewReader(mapping),
	}
	_, _ = createReq.Do(ctx, es)

	// Вставка товара
	prodJSON := `{
		"sku": "KB-MECH-01",
		"name": "Игровая механическая клавиатура с подсветкой",
		"price": 8990.50,
		"tags": ["gaming", "peripherals", "keyboards"],
		"in_stock": true
	}`
	idxReq := esapi.IndexRequest{
		Index:      "ecommerce_products",
		DocumentID: "KB-MECH-01",
		Body:       strings.NewReader(prodJSON),
		Refresh:    "true",
	}
	res, err := idxReq.Do(ctx, es)
	if err != nil {
		panic(err)
	}
	res.Body.Close()

	fmt.Println("Товар успешно проиндексирован со сложной схемой E-commerce")
}
```

ℹ️ Маппинг каталога товаров с scaled_float ценами и мульти-полями

**`Терминал`**

```bash
go run main.go
# Товар успешно проиндексирован со сложной схемой E-commerce
```

## Под капотом

Тип `scaled_float` умножает `8990.50` на `100` и сохраняет целое число `899050` в 64-битном формате. Это исключает проблемы точности округления IEEE-754 при финансовых расчетах и снижает потребление дискового пространства.

## Подводные камни

Если передать в `scaled_float` число с большим количеством знаков после запятой, чем позволяет `scaling_factor` (например, 3 знака при факторе 100), лишние знаки будут округлены с потерей прецизионности.

## На собеседовании

**Вопрос:** Чем `scaled_float` превосходит стандартный `float` или `double`?
**Ответ:** Целые числа в Lucene сжимаются значительно эффективнее вещественных благодаря алгоритмам Packed Integers и Bit Packing, что экономит память Doc Values и ускоряет фильтрацию по диапазонам цен `range`.
