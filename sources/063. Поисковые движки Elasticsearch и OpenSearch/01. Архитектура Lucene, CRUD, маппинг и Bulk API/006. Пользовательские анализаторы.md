# Пользовательские анализаторы: Токенизаторы, фильтры и стемминг русской морфологии

## Условие

**Анализаторы и токенизация.**: Создайте custom analyzer: `standard` tokenizer + `lowercase` + `russian_morphology` (или `stemmer`). Покажите `_analyze` API: как «бегущие» превращается в токен «бег». Объясните разницу `match` (analyzed) vs `term` (not analyzed) запросов.

## Теория

Процесс текстового анализа (Text Analysis) превращает сырую строку в поток токенов для инвертированного индекса:

### Три фазы анализатора (Analyzer):
1. **Character Filters:** Предварительная очистка текста (удаление HTML-тегов `html_strip`, замена символов).
2. **Tokenizer:** Разбиение строки на слова (стандартный `standard` разбивает по границам слов).
3. **Token Filters:** Модификация потока токенов:
   - `lowercase`: Приведение к нижнему регистру.
   - `russian_stop`: Удаление предлогов и союзов ("и", "в", "на").
   - `russian_stemmer` (алгоритм Snowball): Приведение слов к морфологической основе ("бегущие", "бежал", "бег" -> "бег").

## Решение по шагам

1. Создайте индекс `russian_articles` с кастомным анализатором `custom_russian`.
2. Подключите токенизатор `standard` и фильтры `lowercase`, `russian_stop`, `russian_stemmer`.
3. Протестируйте преобразование строки через эндпоинт `_analyze`.
4. Проинспектируйте полученные токены в Go.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"encoding/json"
	"fmt"
	"strings"

	"github.com/elastic/go-elasticsearch/v8"
	"github.com/elastic/go-elasticsearch/v8/esapi"
)

type AnalyzeResponse struct {
	Tokens []struct {
		Token    string `json:"token"`
		Position int    `json:"position"`
		Type     string `json:"type"`
	} `json:"tokens"`
}

func main() {
	es, err := elasticsearch.NewDefaultClient()
	if err != nil {
		panic(err)
	}
	ctx := context.Background()

	// 1. Создание индекса с русской морфологией
	mapping := `{
		"settings": {
			"analysis": {
				"filter": {
					"russian_stop": { "type": "stop", "stopwords": "_russian_" },
					"russian_stemmer": { "type": "stemmer", "language": "russian" }
				},
				"analyzer": {
					"custom_russian": {
						"type": "custom",
						"tokenizer": "standard",
						"filter": ["lowercase", "russian_stop", "russian_stemmer"]
					}
				}
			}
		},
		"mappings": {
			"properties": {
				"title": { "type": "text", "analyzer": "custom_russian" }
			}
		}
	}`
	createReq := esapi.IndicesCreateRequest{
		Index: "russian_articles",
		Body:  strings.NewReader(mapping),
	}
	_, _ = createReq.Do(ctx, es)

	// 2. Тестирование анализатора через _analyze API
	analyzeBody := `{
		"analyzer": "custom_russian",
		"text": "Быстро бегущие программисты пишут надежный микросервис на языке Go"
	}`
	analyzeReq := esapi.IndicesAnalyzeRequest{
		Index: "russian_articles",
		Body:  strings.NewReader(analyzeBody),
	}
	res, err := analyzeReq.Do(ctx, es)
	if err != nil {
		panic(err)
	}
	defer res.Body.Close()

	var resp AnalyzeResponse
	_ = json.NewDecoder(res.Body).Decode(&resp)

	fmt.Println("Результат токенизации и стемминга:")
	for _, t := range resp.Tokens {
		fmt.Printf("  Токен: %-12s (позиция: %d)\n", t.Token, t.Position)
	}
}
```

## Под капотом

Стеммер Snowball отсекает окончания и суффиксы по грамматическим правилам русского языка ("бегущие" -> "бегущ"). При поиске `match` слово "бежал" также стеммируется в ту же основу, что обеспечивает нахождение документа независимо от формы слова и падежа.

## Подводные камни

Стемминг (Stemming) не является лемматизацией (Lemmatization). Стеммер может срезать корни неправильных слов или давать одинаковые основы для разных по смыслу слов. Для точной словарной лемматизации подключают Hunspell-словари.

## На собеседовании

**Вопрос:** Что произойдет, если в маппинге указать `search_analyzer`, отличный от `analyzer` индексации?
**Ответ:** Документ будет токенизирован одним анализатором при записи, а поисковый запрос пользователя — другим анализатором при чтении. Если их правила не согласованы (например, один использует стеммер, а другой нет), искомые токены не совпадут в инвертированном индексе, и поиск ничего не найдет.
