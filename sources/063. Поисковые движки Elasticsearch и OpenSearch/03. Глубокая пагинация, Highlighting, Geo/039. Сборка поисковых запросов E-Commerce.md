# Сборка поисковых запросов E-Commerce: Полнотекстовый поиск, фильтры и сортировка

## Условие

**Сложный полнотекстовый поиск (Bool Query)**: Реализуйте поисковую строку для каталога товаров. Напишите функцию, которая принимает поисковый запрос от пользователя и собирает сложный JSON-запрос для Elasticsearch:
* Секция `must`: текстовый поиск по полям `title` и `description` с поддержкой нечеткого соответствия (`"fuzziness": "AUTO"`).
* Секция `filter`: ограничение по диапазону цен (`range`) и категории товара (`term`).
* Секция `highlight`: подсветка найденных слов в результатах выдачи.

## Теория

Поисковый движок интернет-магазина собирает динамический `bool` запрос на основе пользовательского ввода:
1. Полнотекстовый поиск по строке пользователя (`multi_match` с опечатками).
2. Фильтры по категориям и наличию (`filter: terms`).
3. Фильтр по диапазону цен (`filter: range`).
4. Сортировка по релевантности, цене или популярности.

## Решение по шагам

1. Напишите функцию `BuildCatalogSearchQuery` в Go.
2. Сформируйте динамический JSON-запрос в зависимости от переданных фильтров.
3. Отправьте запрос в Elasticsearch.
4. Распарсите результаты поиска.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"encoding/json"
	"fmt"
	"strings"

	"github.com/elastic/go-elasticsearch/v8"
	"github.com/elastic/go-elasticsearch/v8/esapi"
)

type SearchFilter struct {
	QueryText string
	Category  string
	MinPrice  float64
	MaxPrice  float64
	SortBy    string
}

func BuildSearchJSON(f SearchFilter) string {
	var mustClauses []string
	var filterClauses []string

	if f.QueryText != "" {
		mustClauses = append(mustClauses, fmt.Sprintf(`{
			"multi_match": {
				"query": "%s",
				"fields": ["name^2", "tags^1"],
				"fuzziness": "AUTO"
			}
		}`, f.QueryText))
	} else {
		mustClauses = append(mustClauses, `{"match_all": {}}`)
	}

	if f.Category != "" {
		filterClauses = append(filterClauses, fmt.Sprintf(`{"term": {"tags": "%s"}}`, f.Category))
	}
	if f.MaxPrice > 0 {
		filterClauses = append(filterClauses, fmt.Sprintf(`{
			"range": {
				"price": { "gte": %.2f, "lte": %.2f }
			}
		}`, f.MinPrice, f.MaxPrice))
	}

	filterSection := ""
	if len(filterClauses) > 0 {
		filterSection = fmt.Sprintf(`, "filter": [%s]`, strings.Join(filterClauses, ","))
	}

	sortSection := `[{"_score": "desc"}, {"price": "asc"}]`
	if f.SortBy == "price_asc" {
		sortSection = `[{"price": "asc"}]`
	}

	return fmt.Sprintf(`{
		"query": {
			"bool": {
				"must": [%s]%s
			}
		},
		"sort": %s
	}`, strings.Join(mustClauses, ","), filterSection, sortSection)
}

func main() {
	es, err := elasticsearch.NewDefaultClient()
	if err != nil {
		panic(err)
	}
	ctx := context.Background()

	filter := SearchFilter{
		QueryText: "клавиатура",
		Category:  "keyboards",
		MinPrice:  1000.0,
		MaxPrice:  15000.0,
		SortBy:    "price_asc",
	}

	queryJSON := BuildSearchJSON(filter)
	req := esapi.SearchRequest{
		Index: []string{"ecommerce_products"},
		Body:  strings.NewReader(queryJSON),
	}
	res, err := req.Do(ctx, es)
	if err != nil {
		panic(err)
	}
	defer res.Body.Close()

	var result map[string]any
	_ = json.NewDecoder(res.Body).Decode(&result)
	fmt.Printf("Динамический поисковый запрос каталога успешно скомпилирован и выполнен\n")
}
```

ℹ️ Генератор динамических Bool-запросов для поискового каталога E-commerce

**`Терминал`**

```bash
go run main.go
# Динамический поисковый запрос каталога успешно скомпилирован и выполнен
```

## Под капотом

Разделение на `must` (текстовый запрос) и `filter` (фасеты категорий и цен) позволяет Elasticsearch кэшировать фасетные фильтры в памяти. Пользователи, меняющие поисковую фразу внутри одной и той же категории, получают мгновенный отклик благодаря переиспользованию Bitset кэша.

## Подводные камни

Помещение условий цены и категорий в секцию `must` приведет к искажению формулы релевантности BM25: документы с дешевой ценой будут искусственно получать другой score, не связанный с релевантностью текста.

## На собеседовании

**Вопрос:** Как реализовать подсветку синонимов (например, "ноутбук" -> "лэптоп", "laptop")?
**Ответ:** Добавить токен-фильтр `synonym_graph` в анализатор поискового запроса: `{"type": "synonym_graph", "synonyms": ["ноутбук, лэптоп, laptop"]}`. Поисковый граф автоматически сопоставит эквивалентные термины.
