# Вычисление суммы и произведения элементов массива [7]int за один проход

## Условие

Создайте массив из 7 чисел, найдите сумму и произведение всех элементов.

## Теория

Алгоритмический проход по массиву с накоплением суммы (нейтральный элемент 0) и произведения (нейтральный элемент 1).

## Решение по шагам

1. Инициализируем массив `[7]int{2, 3, 5, 7, 11, 13, 17}`.
2. Инициализируем `sum = 0` и `product = 1`.
3. В одном цикле аккумулируем оба значения.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	primes := [7]int{2, 3, 5, 7, 11, 13, 17}

	sum := 0
	product := 1

	for _, n := range primes {
		sum += n
		product *= n
	}

	fmt.Printf("Массив:       %v\n", primes)
	fmt.Printf("Сумма:        %d\n", sum)
	fmt.Printf("Произведение: %d\n", product)
}
```

ℹ️ Сумма и произведение массива

**`Терминал`**

```bash
go run main.go
# Массив:       [2 3 5 7 11 13 17]
# Сумма:        58
# Произведение: 510510
```

ℹ️ Вывод

## Под капотом

Инструкции `ADDQ` и `IMULQ` выполняются в регистрах процессора за \(O(N)\) тактов.

## Подводные камни

- Инициализация `product = 0`: любое умножение на 0 оставит произведение нулевым.

## На собеседовании

**Вопрос с собеседования:** «Что произойдет при переполнении произведения `int` в цикле?»
**Ответ:** Произойдет тихое беззнаковое/знаковое циклическое переполнение (Wrap Around) по модулю \(2^{64}\) без генерации паники рантайма.
