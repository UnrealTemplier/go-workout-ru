# Передача массива в функцию по значению и доказательство изоляции оригинала

## Условие

Напиши функцию `SumArray(arr [5]int) int`, которая суммирует элементы массива. Внутри функции измени `arr[0] = 999`. В `main` выведи оригинальный массив до и после вызова — покажи, что массив передался **по значению** (полная копия).

## Теория

**Парадигма Pass by Value для массивов:**
- Функция `SumArray(arr [5]int)` получает **локальную копию массива**;
- Любые мутации внутри функции затрагивают только локальный стековый фрейм;
- Исходный массив вызывающей стороны гарантированно защищен от изменений.

## Решение по шагам

1. Пишем функцию `SumArray(arr [5]int) int`.
2. Внутри изменяем `arr[0] = 999`.
3. В `main` проверяем, что оригинальный массив сохранил прежние значения.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func SumArray(arr [5]int) int {
	// Мутируем локальную копию:
	arr[0] = 999
	fmt.Printf("   [Внутри SumArray] arr = %v\n", arr)

	total := 0
	for _, v := range arr {
		total += v
	}
	return total
}

func main() {
	original := [5]int{10, 20, 30, 40, 50}

	fmt.Printf("1. До вызова функции:    %v\n", original)
	sum := SumArray(original)
	fmt.Printf("2. Сумма из функции:      %d\n", sum)
	fmt.Printf("3. После вызова функции: %v (НЕ ИЗМЕНИЛСЯ!)\n", original)
}
```

ℹ️ Pass by Value для массивов

**`Терминал`**

```bash
go run main.go
# 1. До вызова функции:    [10 20 30 40 50]
#    [Внутри SumArray] arr = [999 20 30 40 50]
# 2. Сумма из функции:      1139
# 3. После вызова функции: [10 20 30 40 50] (НЕ ИЗМЕНИЛСЯ!)
```

ℹ️ Оригинал остался неизменным

## Под капотом

При вызове функции `CALL` рантайм копирует 40 байт из фрейма `main` во фрейм `SumArray`.

## Подводные камни

- Надежда на то, что функция изменит переданный массив. Если мутация необходима, передают указатель `*[5]int` или срез `[]int`.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go нет передачи параметров по ссылке (Pass by Reference), как в C++ (`void f(int& x)`)?»
**Ответ:** В Go всё передается строго по значению (Pass by Value). Передача указателя `*T` также передает значение самого адреса указателя. Это упрощает модель памяти и семантику компилятора.
