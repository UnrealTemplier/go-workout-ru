# Проверка целочисленного массива на палиндром методом Two Pointers

## Условие

Проверьте, является ли массив палиндромом (читается одинаково слева направо и справа налево).

## Теория

Алгоритм проверки симметрии массива с константной памятью \(O(1)\).

## Решение по шагам

1. Создаем функцию `IsArrayPalindrome(arr [6]int) bool`.
2. Запускаем сходящиеся счетчики `i := 0`, `j := len(arr) - 1`.
3. Сравниваем `arr[i] != arr[j]`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func IsArrayPalindrome(arr [6]int) bool {
	i, j := 0, len(arr)-1
	for i < j {
		if arr[i] != arr[j] {
			return false
		}
		i++
		j--
	}
	return true
}

func main() {
	arr1 := [6]int{1, 2, 3, 3, 2, 1}
	arr2 := [6]int{1, 2, 3, 4, 2, 1}

	fmt.Printf("Массив %v -> Палиндром: %t\n", arr1, IsArrayPalindrome(arr1))
	fmt.Printf("Массив %v -> Палиндром: %t\n", arr2, IsArrayPalindrome(arr2))
}
```

ℹ️ Проверка массива на палиндром

**`Терминал`**

```bash
go run main.go
# Массив [1 2 3 3 2 1] -> Палиндром: true
# Массив [1 2 3 4 2 1] -> Палиндром: false
```

ℹ️ Результат

## Под капотом

Алгоритм делает максимум 3 сравнения в цикле без аллокаций.

## Подводные камни

- Неправильное условие выхода `i <= j` вместо `i < j`.

## На собеседовании

**Вопрос с собеседования:** «Какова временная сложность проверки палиндрома массива размера \(N\)?»
**Ответ:** \(O(N/2) = O(N)\) в худшем случае, \(O(1)\) в лучшем (когда первые и последние элементы не совпали).
