# Три способа инициализации массива: Zero values, явный литерал и эллипсис [...]

## Условие

**Инициализация массива**: Объявите массив из 5 элементов типа `int`. Инициализируйте его тремя способами: по умолчанию (zero values), явным списком значений в литерале, и с помощью синтаксиса многоточия `[...]int{...}`.

## Теория

**Массивы (Arrays) в Go:**
1. Массив — это структура данных **фиксированной длины**, непрерывно расположенная в памяти;
2. Длина массива является **неотъемлемой частью его типа** (`[5]int` и `[10]int` — два абсолютно разных, несовместимых типа!);
3. Способы инициализации:
   - `var a [5]int` — все элементы инициализируются нулями (`Zero Values`);
   - `b := [5]int{10, 20, 30, 40, 50}` — явное перечисление;
   - `c := [...]int{1, 2, 3, 4, 5}` — компилятор сам подсчитывает количество элементов (длина равна 5).

## Решение по шагам

1. Объявляем `var a [5]int`.
2. Объявляем `b := [5]int{10, 20, 30, 40, 50}`.
3. Объявляем `c := [...]int{1, 2, 3, 4, 5}`.
4. Выводим значения и типы всех трех массивов.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	// 1. По умолчанию (zero values)
	var arr1 [5]int

	// 2. Явный литерал со всеми элементами
	arr2 := [5]int{10, 20, 30, 40, 50}

	// 3. Синтаксис многоточия (размер определяет компилятор)
	arr3 := [...]int{100, 200, 300, 400, 500}

	fmt.Printf("1. Zero values: %v (тип: %T)\n", arr1, arr1)
	fmt.Printf("2. Явный:       %v (тип: %T)\n", arr2, arr2)
	fmt.Printf("3. Эллипсис:    %v (тип: %T)\n", arr3, arr3)
}
```

ℹ️ Три способа инициализации массива

**`Терминал`**

```bash
go run main.go
# 1. Zero values: [0 0 0 0 0] (тип: [5]int)
# 2. Явный:       [10 20 30 40 50] (тип: [5]int)
# 3. Эллипсис:    [100 200 300 400 500] (тип: [5]int)
```

ℹ️ Вывод

## Под капотом

Массив выделяется единым непрерывным блоком на стеке. `[5]int` занимает ровно \(5 \times 8 = 40\) байт без служебных заголовков.

## Подводные камни

- Использование `[...]int` в качестве типа параметра функции `func f(a [...]int)`: синтаксис `[...]` разрешен **только в литералах объявления**, но запрещен в сигнатурах типов!

## На собеседовании

**Вопрос с собеседования:** «В чем отличие `[...]int{1, 2}` от `[]int{1, 2}`?»
**Ответ:** `[...]int{1, 2}` создает статический массив `[2]int` на стеке (память \(O(1)\) без аллокаций в куче). `[]int{1, 2}` создает срез — 24-байтную структуру-дескриптор `SliceHeader`, указывающую на базовый массив.
