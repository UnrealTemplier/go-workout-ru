# Гарантия инициализации Zero Values для неинициализированного массива

## Условие

Объявите массив из 5 целых чисел, не инициализируя его. Выведите значения по умолчанию (zero values).

## Теория

**Безопасность памяти в Go (Zero Initialization):**
- В Go нет концепции «мусора в памяти» (Uninitialized Memory), как в C/C++;
- При объявлении `var arr [5]int` рантайм гарантированно обнуляет все байты массива;
- Каждый элемент гарантированно равен `0`.

## Решение по шагам

1. Объявляем `var uninit [5]int`.
2. Распечатываем массив и убеждаемся, что все 5 ячеек содержат нули.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	// Неинициализированный массив
	var data [5]int

	fmt.Printf("Массив по умолчанию: %v\n", data)
	for idx, val := range data {
		fmt.Printf("  data[%d] = %d\n", idx, val)
	}
}
```

ℹ️ Zero values массива

**`Терминал`**

```bash
go run main.go
# Массив по умолчанию: [0 0 0 0 0]
#   data[0] = 0
#   data[1] = 0
#   data[2] = 0
#   data[3] = 0
#   data[4] = 0
```

ℹ️ Вывод

## Под капотом

Компилятор вставляет инструкцию обнуления памяти `DUFFZERO` или `XORPS + MOVUPS` в прологе функции.

## Подводные камни

- Попытка повторной инициализации через `data := [5]int`: создаст затенение локальной переменной.

## На собеседовании

**Вопрос с собеседования:** «Каковы Zero Values для массива булевых флагов `[3]bool` и массива строк `[2]string`?»
**Ответ:** Для `[3]bool` это `[false, false, false]`, для `[2]string` это `["", ""]` (пустые строки с `nil`-указателем и нулевой длиной).
