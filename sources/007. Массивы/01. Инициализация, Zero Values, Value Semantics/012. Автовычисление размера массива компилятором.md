# Автовычисление размера массива компилятором через синтаксис эллипсиса [...]

## Условие

Используй синтаксис `[...]int{10, 20, 30}`. Выведи длину массива.

## Теория

Синтаксис `[...]` избавляет от необходимости вручную пересчитывать количество элементов в литерале.

## Решение по шагам

1. Объявляем `items := [...]int{10, 20, 30, 40, 50, 60}`.
2. Проверяем длину `len(items)` и тип `%T`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	items := [...]int{10, 20, 30, 40, 50, 60}

	fmt.Printf("Элементы: %v\n", items)
	fmt.Printf("Длина массива: %d\n", len(items))
	fmt.Printf("Тип:           %T\n", items)
}
```

ℹ️ Синтаксис [...]

**`Терминал`**

```bash
go run main.go
# Элементы: [10 20 30 40 50 60]
# Длина массива: 6
# Тип:           [6]int
```

ℹ️ Компилятор определил тип [6]int

## Под капотом

Синтаксический парсер AST подсчитывает количество узлов `ast.Expr` в списке инициализации и подставляет константу в определение `ast.ArrayType`.

## Подводные камни

- Попытка использовать `var arr [...]int` без литерала инициализации: вызовет ошибку `use of [...] array outside of array literal`.

## На собеседовании

**Вопрос с собеседования:** «Можно ли объявить константу `const size = len(arr)` для массива `[...]int{1, 2, 3}`?»
**Ответ:** ДА! Так как длина массива вычисляется компилятором, `len(arr)` является константным выражением (Constant Expression).
