# Форматированный вывод массива и инспекция длины через len()

## Условие

Объяви массив из 5 целых чисел. Выведи его. Выведи его длину с помощью `len()`.

## Теория

Базовое форматирование `%v`, `%#v` и свойство `len()`.

## Решение по шагам

1. Создаем массив `[5]int{7, 14, 21, 28, 35}`.
2. Выводим стандартное представление `%v` и детальное представление типа `%#v`.
3. Печатаем `len(arr)`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	multiplesOfSeven := [5]int{7, 14, 21, 28, 35}

	fmt.Printf("Стандартный вывод (%%v):  %v\n", multiplesOfSeven)
	fmt.Printf("Спецификатор Go (%%#v):   %#v\n", multiplesOfSeven)
	fmt.Printf("Длина массива len():     %d\n", len(multiplesOfSeven))
}
```

ℹ️ Форматированный вывод массива

**`Терминал`**

```bash
go run main.go
# Стандартный вывод (%v):  [7 14 21 28 35]
# Спецификатор Go (%#v):   [5]int{7, 14, 21, 28, 35}
# Длина массива len():     5
```

ℹ️ Результат

## Под капотом

`%#v` формирует синтаксически валидный литерал Go с указанием точного типа `[5]int`.

## Подводные камни

- Ожидание, что у массива есть емкость `cap()`, отличающаяся от `len()`: для массивов `cap(arr) == len(arr)` всегда!

## На собеседовании

**Вопрос с собеседования:** «Чему равна емкость массива `cap(arr)` в Go?»
**Ответ:** Для массивов `cap(arr)` всегда строго равна `len(arr)` и равна фиксированному размеру массива, заданному при компиляции.
