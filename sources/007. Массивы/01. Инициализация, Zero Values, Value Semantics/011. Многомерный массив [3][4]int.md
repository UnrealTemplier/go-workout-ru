# Многомерный массив [3][4]int: координатное заполнение i*10 + j и табличный вывод

## Условие

Создай многомерный массив `[3][4]int` (матрица 3×4). Заполни его вложенными циклами значениями `i*10 + j`. Выведи в виде отформатированной таблицы.

## Теория

**Двумерный массив `[Rows][Cols]T`:**
- Представляет собой **единый непрерывный блок памяти** из \(\text{Rows} \times \text{Cols}\) элементов;
- `[3][4]int` занимает в памяти ровно \(3 \times 4 \times 8 = 96\) байт;
- В отличие от среза срезов `[][]int`, двумерный массив не имеет указателей и хранится в кэше процессора максимально компактно.

## Решение по шагам

1. Объявляем `var matrix [3][4]int`.
2. Вложенными циклами заполняем `matrix[i][j] = i*10 + j`.
3. Выводим таблицу с выравниванием `%4d`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"unsafe"
)

func main() {
	var matrix [3][4]int

	// Заполнение значениями
	for i := 0; i < 3; i++ {
		for j := 0; j < 4; j++ {
			matrix[i][j] = i*10 + j
		}
	}

	fmt.Printf("Матрица [3][4]int (размер: %d байт):\n", unsafe.Sizeof(matrix))
	for i := 0; i < 3; i++ {
		fmt.Printf("Строка [%d]: |", i)
		for j := 0; j < 4; j++ {
			fmt.Printf("%4d", matrix[i][j])
		}
		fmt.Println("  |")
	}
}
```

ℹ️ Матрица 3x4

**`Терминал`**

```bash
go run main.go
# Матрица [3][4]int (размер: 96 байт):
# Строка [0]: |   0   1   2   3  |
# Строка [1]: |  10  11  12  13  |
# Строка [2]: |  20  21  22  23  |
```

ℹ️ Вывод

## Под капотом

Элемент `matrix[i][j]` расположен по формуле смещения в памяти \(\text{Base} + (i \times 4 + j) \times 8\).

## Подводные камни

- Путаница между порядком размерностей `[Строки][Столбцы]`.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество многомерного массива `[100][100]float64` перед `[][]float64` в GameDev и Big Data?»
**Ответ:** `[100][100]float64` выделяется одной аллокацией (80 КБ) в непрерывной памяти. `[][]float64` требует 101 аллокацию (1 срез срезов + 100 строк), создает фрагментацию кучи и нагрузку на GC.
