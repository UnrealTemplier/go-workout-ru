# Динамическое заполнение матрицы 3x3 через формулу i*3 + j + 1

## Условие

Создайте двумерный массив (матрицу) 3x3 и заполните его числами от 1 до 9 с помощью вложенных циклов.

## Теория

Формула перевода двумерных координат в линейный индекс:
$$\text{Value} = i \times \text{Cols} + j + 1$$

## Решение по шагам

1. Создаем пустую матрицу `var board [3][3]int`.
2. Заполняем по формуле `board[i][j] = i*3 + j + 1`.
3. Печатаем результат.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var board [3][3]int

	// Заполнение формулой:
	for i := 0; i < 3; i++ {
		for j := 0; j < 3; j++ {
			board[i][j] = i*3 + j + 1
		}
	}

	fmt.Println("Сгенерированная матрица:")
	for _, row := range board {
		for _, cell := range row {
			fmt.Printf("%3d", cell)
		}
		fmt.Println()
	}
}
```

ℹ️ Динамическое заполнение матрицы

**`Терминал`**

```bash
go run main.go
# Сгенерированная матрица:
#   1  2  3
#   4  5  6
#   7  8  9
```

ℹ️ Результат генерации

## Под капотом

Инструкция `LEA` эффективно вычисляет линейный адрес ячейки за 1 такт CPU.

## Подводные камни

- Ошибка со смещением `+ 1`, приводящая к нумерации 0..8 вместо 1..9.

## На собеседовании

**Вопрос с собеседования:** «Почему компилятор Go может автоматически развернуть циклы (Loop Unrolling) для маленьких массивов `[3][3]int`?»
**Ответ:** Потому что размер массива константен и мал (9 итераций). Разворачивание цикла устраняет накладные расходы на инкременты счетчиков и условные переходы.
