# Квадратная матрица [3][3]int и форматированный вывод игрового поля 3x3

## Условие

**Матрицы (Двумерные массивы)**: Создайте матрицу `[3][3]int` (таблицу 3x3). Заполните её числами от 1 до 9. Напишите вложенные циклы для вывода матрицы в консоль в виде красивой таблицы.

## Теория

Моделирование двумерных игровых полей (Крестики-нолики, матрицы трансформации).

## Решение по шагам

1. Инициализируем матрицу литералом `[3][3]int`.
2. Выводим красивую таблицу с разделителями.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	grid := [3][3]int{
		{1, 2, 3},
		{4, 5, 6},
		{7, 8, 9},
	}

	fmt.Println("=== ТАБЛИЦА 3x3 ===")
	for r := 0; r < 3; r++ {
		fmt.Printf(" | %d | %d | %d |\n", grid[r][0], grid[r][1], grid[r][2])
	}
	fmt.Println("===================")
}
```

ℹ️ Форматированная сетка 3x3

**`Терминал`**

```bash
go run main.go
# === ТАБЛИЦА 3x3 ===
#  | 1 | 2 | 3 |
#  | 4 | 5 | 6 |
#  | 7 | 8 | 9 |
# ===================
```

ℹ️ Вывод

## Под капотом

Все 9 целых чисел хранятся в 72 байтах непрерывной памяти.

## Подводные камни

- Выход за пределы столбца `grid[0][3]`: вызовет ошибку компиляции или панику.

## На собеседовании

**Вопрос с собеседования:** «Как транспонировать матрицу `[3][3]int` на месте (In-Place)?»
**Ответ:** Вложенным циклом `for i := 0; i < 3; i++ { for j := i + 1; j < 3; j++ { m[i][j], m[j][i] = m[j][i], m[i][j] } }`.
