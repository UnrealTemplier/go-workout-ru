# Итерация по массиву через for index, value := range arr

## Условие

Используй `for range` для итерации по массиву. Выведи индекс и значение.

## Теория

Стандартный обход массива.

## Решение по шагам

1. Создаем массив `[4]float64{1.1, 2.2, 3.3, 4.4}`.
2. Обходим через `range`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	floats := [4]float64{1.1, 2.2, 3.3, 4.4}

	for idx, val := range floats {
		fmt.Printf("floats[%d] = %.2f\n", idx, val)
	}
}
```

ℹ️ for range по массиву

**`Терминал`**

```bash
go run main.go
# floats[0] = 1.10
# floats[1] = 2.20
# floats[2] = 3.30
# floats[3] = 4.40
```

ℹ️ Вывод

## Под капотом

Компилятор оптимизирует доступ через векторные регистры `XMM`.

## Подводные камни

- Модификация `val` не меняет элемент в `floats`.

## На собеседовании

**Вопрос с собеседования:** «Копируется ли массив `floats` при `for idx, val := range floats`?»
**Ответ:** ДА! Для статического массива `range` копирует массив целиком. Чтобы избежать копирования, итерируют по указателю `range &floats` или срезу `range floats[:]`.
