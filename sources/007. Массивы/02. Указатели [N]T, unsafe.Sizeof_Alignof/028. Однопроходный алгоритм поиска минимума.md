# Однопроходный алгоритм поиска минимума и максимума в массиве [10]int

## Условие

**Поиск экстремумов**: Заполните массив `[10]int` случайными числами. Напишите алгоритм, который находит минимальное и максимальное значения в этом массиве за один проход цикла.

## Теория

Алгоритм \(O(N)\) с инициализацией `min = arr[0]`, `max = arr[0]`.

## Решение по шагам

1. Инициализируем массив 10 чисел.
2. За 1 проход обновляем `minVal` и `maxVal`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	numbers := [10]int{45, 12, 89, 3, 77, 92, 34, -5, 60, 18}

	minVal := numbers[0]
	maxVal := numbers[0]

	for _, n := range numbers[1:] {
		if n < minVal {
			minVal = n
		}
		if n > maxVal {
			maxVal = n
		}
	}

	fmt.Printf("Массив:   %v\n", numbers)
	fmt.Printf("Минимум:  %d\n", minVal)
	fmt.Printf("Максимум: %d\n", maxVal)
}
```

ℹ️ Экстремумы массива

**`Терминал`**

```bash
go run main.go
# Массив:   [45 12 89 3 77 92 34 -5 60 18]
# Минимум:  -5
# Максимум: 92
```

ℹ️ Результат поиска

## Под капотом

Инструкции условного перемещения `CMOVL` и `CMOVG` без штрафов за ветвления.

## Подводные камни

- Инициализация нулем: для массива отрицательных чисел максимум ошибочно станет 0.

## На собеседовании

**Вопрос с собеседования:** «Каково минимальное число сравнений для нахождения Min и Max одновременно?»
**Ответ:** Для массива размера \(N\) при парном сравнении (Pairwise) требуется \(3N/2 - 2\) сравнений.
