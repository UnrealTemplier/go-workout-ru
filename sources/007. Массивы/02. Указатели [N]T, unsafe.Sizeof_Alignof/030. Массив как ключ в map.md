# Массив как ключ в map: создание RGB палитры map[[3]int]string и почему срезы запрещены

## Условие

Используйте массив как ключ в map: создайте `map[[3]int]string`, где ключ — RGB-тройка, а значение — название цвета.

## Теория

**Почему массивы могут быть ключами в `map`, а срезы нет?**
1. В Go ключом в `map[K]V` может быть **только сравнимый тип (Comparable Type)**, для которого определен оператор `==`;
2. Массивы `[3]int` являются comparable \(\rightarrow\) их можно использовать как ключи;
3. Срезы `[]int` НЕ являются comparable \(\rightarrow\) `map[[]int]string` вызовет ошибку компиляции `invalid map key type []int`.

## Решение по шагам

1. Создаем `palette := make(map[[3]int]string)`.
2. Сохраняем RGB-цвета `[3]int{255, 0, 0}: "Красный"`.
3. Извлекаем цвета по ключу-массиву.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	// Массив [3]int в роли ключа хэш-таблицы (RGB палитра):
	palette := map[[3]int]string{
		{255, 0, 0}:     "Красный",
		{0, 255, 0}:     "Зеленый",
		{0, 0, 255}:     "Синий",
		{255, 255, 255}: "Белый",
		{0, 0, 0}:       "Черный",
	}

	target := [3]int{0, 255, 0}
	if name, ok := palette[target]; ok {
		fmt.Printf("Цвет RGB %v: %s\n", target, name)
	}

	// map[[]int]string // ОШИБКА: invalid map key type []int
}
```

ℹ️ Массив [3]int как ключ map

**`Терминал`**

```bash
go run main.go
# Цвет RGB [0 255 0]: Зеленый
```

ℹ️ Вывод

## Под капотом

Хэш-функция вычисляет хэш от 24 байт массива `[3]int` напрямую через алгоритм `aeshashbody`.

## Подводные камни

- Попытка передать срез `palette[[]int{255, 0, 0}]`: вызовет ошибку несовпадения типов.

## На собеседовании

**Вопрос с собеседования:** «Как в Go использовать срез байт в качестве ключа в `map`?»
**Ответ:** Преобразовать срез в строку `string(b)` (строки comparable и поддерживают zero-copy оптимизацию компилятора при поиске `m[string(b)]`) или в массив фиксированной длины `[32]byte`.
