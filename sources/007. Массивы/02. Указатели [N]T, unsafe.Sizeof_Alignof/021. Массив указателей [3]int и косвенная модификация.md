# Массив указателей [3]*int и косвенная модификация связанных переменных

## Условие

Создай массив [3]*int (массив указателей). Заполни его адресами трёх переменных. Измени значения через массив. Покажи, что массив хранит указатели, а не сами значения.

### Исходная формулировка

Создай массив `[3]*int` (массив указателей). Заполни его адресами трёх переменных. Измени значения через массив. Покажи, что массив хранит указатели, а не сами значения.

## Теория

**Массив указателей `[N]*T`:**
- Содержит \(N\) 8-байтовых адресов памяти;
- Разыменование `*ptrs[i] = 100` меняет значение в оригинальной переменной.

## Решение по шагам

1. Объявляем переменные `x, y, z := 10, 20, 30`.
2. Создаем массив указателей `ptrs := [3]*int{&x, &y, &z}`.
3. Меняем `*ptrs[0] = 999`.
4. Проверяем, что значение `x` изменилось.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	x, y, z := 10, 20, 30

	// Массив указателей [3]*int:
	ptrs := [3]*int{&x, &y, &z}

	fmt.Printf("1. Исходные переменные: x=%d, y=%d, z=%d\n", x, y, z)
	fmt.Printf("2. Адреса в массиве:    %v\n\n", ptrs)

	// Модифицируем значения через разыменование указателей в массиве:
	*ptrs[0] = 100
	*ptrs[1] = 200
	*ptrs[2] = 300

	fmt.Printf("3. Переменные после мутации через ptrs: x=%d, y=%d, z=%d\n", x, y, z)
}
```

ℹ️ Массив указателей [3]*int

**`Терминал`**

```bash
go run main.go
# 1. Исходные переменные: x=10, y=20, z=30
# 2. Адреса в массиве:    [0xc000014070 0xc000014078 0xc000014080]
# 
# 3. Переменные после мутации через ptrs: x=100, y=200, z=300
```

ℹ️ Значения оригинальных переменных изменились

## Под капотом

Эскейп-анализ может переместить переменные `x, y, z` в кучу, если их адреса покидают область видимости функции.

## Подводные камни

- Разыменование непроинициализированного элемента `var ptrs [3]*int; *ptrs[0] = 1`: вызовет панику `nil pointer dereference`.

## На собеседовании

**Вопрос с собеседования:** «Каков размер массива `[100]*int64` на 64-битной платформе?»
**Ответ:** Ровно \(100 \times 8 = 800\) байт (100 указателей по 8 байт).
