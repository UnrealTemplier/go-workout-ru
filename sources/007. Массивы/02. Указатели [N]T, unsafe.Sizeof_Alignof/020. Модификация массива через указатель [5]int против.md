# Модификация массива через указатель *[5]int против передачи по значению [5]int

## Условие

**Передача массива в функцию**: Напишите функцию `DoubleArray(arr [5]int)`, которая удваивает каждый элемент массива. Передайте туда массив, выведите его до и после вызова функции. Убедитесь, что исходный массив снаружи не изменился. Перепишите функцию так, чтобы она принимала указатель на массив `*[5]int`, и добейтесь изменения исходного массива.

## Теория

**Передача по указателю `*[N]T`:**
- Функция получает 8-байтный указатель на адрес оригинального массива;
- Разыменование `(*arr)[i] *= 2` (или синтаксический сахар `arr[i] *= 2`) мутирует **исходный массив в памяти вызывающей стороны**;
- Объем передаваемых данных составляет ровно 8 байт независимо от размера массива (будь то `[5]int` или `[1000000]int`).

## Решение по шагам

1. Пишем функцию по значению `DoubleByValue(arr [5]int)`.
2. Пишем функцию по указателю `DoubleByPointer(arr *[5]int)`.
3. Сравниваем результаты в `main`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

// 1. Передача по значению (копирует весь массив)
func DoubleByValue(arr [5]int) {
	for i := range arr {
		arr[i] *= 2
	}
}

// 2. Передача по указателю (мутирует оригинальный массив в памяти)
func DoubleByPointer(arr *[5]int) {
	for i := range arr {
		arr[i] *= 2 // Автоматическое разыменование указателя компилятором
	}
}

func main() {
	data := [5]int{1, 2, 3, 4, 5}
	fmt.Printf("1. Исходный массив:        %v\n", data)

	DoubleByValue(data)
	fmt.Printf("2. После DoubleByValue:   %v (без изменений)\n", data)

	DoubleByPointer(&data)
	fmt.Printf("3. После DoubleByPointer: %v (УСПЕШНО ИЗМЕНЕН!)\n", data)
}
```

ℹ️ Значение vs указатель на массив

**`Терминал`**

```bash
go run main.go
# 1. Исходный массив:        [1 2 3 4 5]
# 2. После DoubleByValue:   [1 2 3 4 5] (без изменений)
# 3. После DoubleByPointer: [2 4 6 8 10] (УСПЕШНО ИЗМЕНЕН!)
```

ℹ️ Успешная мутация через указатель

## Под капотом

`arr[i]` над `*[5]int` компилируется в чтение адреса из регистра и смещение `base + i*8`.

## Подводные камни

- Передача `nil` указателя `var p *[5]int = nil; DoubleByPointer(p)`: вызовет `panic: runtime error: invalid memory address or nil pointer dereference`.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go `arr[i]` работает для `*[5]int` без явного разыменования `(*arr)[i]`?»
**Ответ:** Это встроенный синтаксический сахар языка (Implicit Pointer Dereference), который упрощает работу с указателями на массивы и структуры.
