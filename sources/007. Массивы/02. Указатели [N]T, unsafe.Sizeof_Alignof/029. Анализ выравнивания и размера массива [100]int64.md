# Анализ выравнивания и размера массива [100]int64 через unsafe.Sizeof и unsafe.Alignof

## Условие

Используйте `unsafe.Sizeof` и `unsafe.Alignof`, чтобы изучить, сколько памяти занимает массив из 100 элементов `int64` и как он располагается в памяти.

## Теория

**Выравнивание памяти (Memory Alignment):**
- `unsafe.Sizeof([100]int64)` = \(100 \times 8 = 800\) байт;
- `unsafe.Alignof([100]int64)` = \(8\) байт (выравнивание массива совпадает с выравниванием его базового типа `int64`);
- Все элементы идут подряд с шагом 8 байт.

## Решение по шагам

1. Создаем `var bigArray [100]int64`.
2. Измеряем `unsafe.Sizeof`, `unsafe.Alignof` и дистанцию между ячейками.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"unsafe"
)

func main() {
	var bigArray [100]int64

	fmt.Printf("1. Размер массива:        %d байт\n", unsafe.Sizeof(bigArray))
	fmt.Printf("2. Выравнивание массива:  %d байт\n", unsafe.Alignof(bigArray))
	fmt.Printf("3. Выравнивание элемента: %d байт\n", unsafe.Alignof(bigArray[0]))

	// Проверка шага адресов:
	addr0 := uintptr(unsafe.Pointer(&bigArray[0]))
	addr1 := uintptr(unsafe.Pointer(&bigArray[1]))
	fmt.Printf("4. Шаг между элементами:  %d байт\n", addr1-addr0)
}
```

ℹ️ Размер и выравнивание массива

**`Терминал`**

```bash
go run main.go
# 1. Размер массива:        800 байт
# 2. Выравнивание массива:  8 байт
# 3. Выравнивание элемента: 8 байт
# 4. Шаг между элементами:  8 байт
```

ℹ️ Идеальная непрерывная структура

## Под капотом

Процессор считывает массив 64-битными словами по границам, кратным 8 байтам, без пенальти невыровненного доступа (Unaligned Access).

## Подводные камни

- Путаница между `Sizeof` (размер) и `Alignof` (кратность границы адреса).

## На собеседовании

**Вопрос с собеседования:** «Чему равно выравнивание массива `[10]struct{ a byte; b int64 }`?»
**Ответ:** 8 байт (по наибольшему полю `int64` внутри структуры). Размер структуры с паддингом равен 16 байт, а весь массив займет 160 байт.
