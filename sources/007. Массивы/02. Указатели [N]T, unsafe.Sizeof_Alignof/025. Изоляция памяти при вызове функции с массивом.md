# Изоляция памяти при вызове функции с массивом по значению

## Условие

Передайте массив в функцию по значению и измените его элемент внутри. Убедитесь, что оригинальный массив в `main` остался прежним.

## Теория

Финальное закрепление независимости памяти.

## Решение по шагам

1. Создаем `arr := [3]string{"A", "B", "C"}`.
2. Передаем в `ModifyStringArray`.
3. Проверяем оригинал.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func ModifyStringArray(arr [3]string) {
	arr[0] = "MODIFIED"
}

func main() {
	data := [3]string{"Alfa", "Beta", "Gamma"}
	ModifyStringArray(data)

	fmt.Printf("Оригинальный массив: %v\n", data)
}
```

ℹ️ Изоляция строк в массиве

**`Терминал`**

```bash
go run main.go
# Оригинальный массив: [Alfa Beta Gamma]
```

ℹ️ Вывод

## Под капотом

Заголовки строк копируются на стек функции.

## Подводные камни

- Передача массива строк в надежде мутировать строки.

## На собеседовании

**Вопрос с собеседования:** «Почему строки внутри массива не копируют свои байты при `b := a`?»
**Ответ:** Потому что копируется только 16-байтный заголовок строки `StringHeader` (указатель + длина). Сами неизменяемые байты строки остаются на прежнем месте в `.rodata`.
