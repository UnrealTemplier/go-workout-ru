# Двумерная матрица нулей [3][3]int и гарантии Zero Values

## Условие

Объяви двумерный массив матрицы 3x3, заполненный нулями. Выведи его.

## Теория

Объявление `var zeroMatrix [3][3]int` гарантирует обнуление всех \(3 \times 3 = 9\) ячеек.

## Решение по шагам

1. Объявляем `var zeroMatrix [3][3]int`.
2. Выводим стандартным и строчным способом.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var zeroMatrix [3][3]int

	fmt.Printf("Матрица нулей: %v\n\n", zeroMatrix)
	for r, row := range zeroMatrix {
		fmt.Printf("Строка [%d]: %v\n", r, row)
	}
}
```

ℹ️ Матрица нулей 3x3

**`Терминал`**

```bash
go run main.go
# Матрица нулей: [[0 0 0] [0 0 0] [0 0 0]]
# 
# Строка [0]: [0 0 0]
# Строка [1]: [0 0 0]
# Строка [2]: [0 0 0]
```

## Под капотом

Инструкция `DUFFZERO` обнуляет 72 байта памяти за несколько инструкций процессора.

## Подводные камни

- Ручное обнуление через вложенные циклы: в Go это избыточно, так как компилятор делает это нативно.
