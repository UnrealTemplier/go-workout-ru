# Классическое суммирование массива через C-style цикл с индексацией

## Условие

Напишите программу, которая находит сумму элементов массива, используя классический цикл `for` с индексом, без использования `range`.

## Теория

Суммирование с явным контролем счетчика.

## Решение по шагам

1. Инициализируем массив `[6]int{10, 20, 30, 40, 50, 60}`.
2. Суммируем `total += arr[i]`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	arr := [6]int{10, 20, 30, 40, 50, 60}
	total := 0

	for i := 0; i < len(arr); i++ {
		total += arr[i]
	}

	fmt.Printf("Массив: %v | Сумма: %d\n", arr, total)
}
```

ℹ️ Классический цикл суммирования

**`Терминал`**

```bash
go run main.go
# Массив: [10 20 30 40 50 60] | Сумма: 210
```

ℹ️ Вывод

## Под капотом

`len(arr)` заменяется константой 6 на этапе компиляции.

## Подводные камни

- Использование `<=` вместо `<`: `i <= len(arr)` вызовет `panic: index out of range`.

## На собеседовании

**Вопрос с собеседования:** «Чем `for i := 0; i < len(arr); i++` эффективнее `for _, v := range arr` для массива `[1000]BigStruct`?»
**Ответ:** Прямая индексация `arr[i]` не копирует структуру `BigStruct` в промежуточную переменную.
