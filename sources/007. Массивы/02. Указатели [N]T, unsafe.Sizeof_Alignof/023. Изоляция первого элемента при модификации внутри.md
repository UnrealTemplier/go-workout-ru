# Изоляция первого элемента при модификации внутри функции

## Условие

Напиши функцию, которая принимает массив `[5]int` и изменяет его первый элемент. Выведи массив после вызова функции (убедись, что оригинал не изменился — передача по значению).

## Теория

Закрепление неизменяемости оригинала.

## Решение по шагам

1. Пишем `MutateFirst(arr [5]int)`.
2. Вызываем и проверяем оригинал.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func MutateFirst(arr [5]int) {
	arr[0] = 777
	fmt.Printf("   [Внутри MutateFirst] arr[0] = %d\n", arr[0])
}

func main() {
	numbers := [5]int{1, 2, 3, 4, 5}

	fmt.Printf("До вызова:    %v\n", numbers)
	MutateFirst(numbers)
	fmt.Printf("После вызова: %v\n", numbers)
}
```

ℹ️ Изоляция первого элемента

**`Терминал`**

```bash
go run main.go
# До вызова:    [1 2 3 4 5]
#    [Внутри MutateFirst] arr[0] = 777
# После вызова: [1 2 3 4 5]
```

ℹ️ Вывод

## Под капотом

Изолированный стек фрейм функции.
