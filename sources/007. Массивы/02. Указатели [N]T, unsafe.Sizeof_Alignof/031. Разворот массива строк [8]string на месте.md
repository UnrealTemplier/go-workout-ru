# Разворот массива строк [8]string на месте (In-Place Reverse) через указатель

## Условие

**Разворот на месте (In-place reverse)**: Напишите функцию, которая принимает указатель на массив `[8]string` и разворачивает его элементы в обратном порядке без выделения памяти под новый массив.

## Теория

Разворот массива через указатель `*[8]string` без единой аллокации в куче.

## Решение по шагам

1. Пишем функцию `ReverseArrayInPlace(arr *[8]string)`.
2. Запускаем сходящиеся указатели `i, j := 0, len(arr)-1`.
3. Меняем элементы местами.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func ReverseArrayInPlace(arr *[8]string) {
	for i, j := 0, len(arr)-1; i < j; i, j = i+1, j-1 {
		arr[i], arr[j] = arr[j], arr[i] // Атомарный swap на месте
	}
}

func main() {
	tokens := [8]string{"1", "2", "3", "4", "5", "6", "7", "8"}

	fmt.Printf("До разворота:    %v\n", tokens)
	ReverseArrayInPlace(&tokens)
	fmt.Printf("После разворота: %v\n", tokens)
}
```

ℹ️ Разворот массива на месте

**`Терминал`**

```bash
go run main.go
# До разворота:    [1 2 3 4 5 6 7 8]
# После разворота: [8 7 6 5 4 3 2 1]
```

ℹ️ Вывод

## Под капотом

Алгоритм выполняет ровно 4 обмена 16-байтных структур строк.

## Подводные камни

- Выделение нового массива внутри функции и его возврат: это создаст лишнее копирование памяти.

## На собеседовании

**Вопрос с собеседования:** «Какова сложность разворота массива из 8 элементов по времени и памяти?»
**Ответ:** Время \(O(N)\), дополнительная память \(O(1)\) (In-place).
