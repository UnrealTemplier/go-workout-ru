# Передача массива в функцию для удвоения и доказательство неизменности оригинала

## Условие

Передайте массив в функцию для модификации (удвоить каждый элемент). Убедитесь, что исходный массив не изменился.

## Теория

**Изоляция фреймов функций (Pass by Value):**
- При вызове функции с параметром `[4]int` массив копируется на стек вызываемой функции;
- Любая модификация `arr[i] *= 2` локальна и уничтожается при возврате `RET`.

## Решение по шагам

1. Пишем `DoubleElements(arr [4]int)`.
2. Удваиваем элементы внутри.
3. Проверяем неизменность оригинала в `main`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func DoubleElements(arr [4]int) {
	for i := range arr {
		arr[i] *= 2
	}
	fmt.Printf("   [Внутри функции] arr = %v\n", arr)
}

func main() {
	original := [4]int{5, 10, 15, 20}

	fmt.Printf("1. Исходный массив:       %v\n", original)
	DoubleElements(original)
	fmt.Printf("2. Оригинал после вызова: %v (НЕ ИЗМЕНИЛСЯ!)\n", original)
}
```

ℹ️ Удвоение массива по значению

**`Терминал`**

```bash
go run main.go
# 1. Исходный массив:       [5 10 15 20]
#    [Внутри функции] arr = [10 20 30 40]
# 2. Оригинал после вызова: [5 10 15 20] (НЕ ИЗМЕНИЛСЯ!)
```

ℹ️ Вывод

## Под капотом

Стек функции `DoubleElements` освобождается сразу после возврата.

## Подводные камни

- Ожидание эффекта мутации без использования указателя `*[4]int`.

## На собеседовании

**Вопрос с собеседования:** «Как вернуть измененный массив без использования указателей?»
**Ответ:** Возвращать новый массив как результат функции `func Double(arr [4]int) [4]int { ... return arr }` и переприсваивать `original = Double(original)`.
