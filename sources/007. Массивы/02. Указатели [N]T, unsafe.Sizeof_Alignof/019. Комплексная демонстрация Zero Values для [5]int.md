# Комплексная демонстрация Zero Values для [5]int, [3]bool и [2]string

## Условие

Напиши программу, которая демонстрирует **zero value** массива: объяви `var arr [5]int` без инициализации. Выведи — все элементы будут нулевыми.

## Теория

Сравнение Zero Values разных типов:
- Числовые массивы \(\rightarrow\) `0`
- Булевы массивы \(\rightarrow\) `false`
- Строковые массивы \(\rightarrow\) `""`

## Решение по шагам

1. Объявляем `var ints [5]int`, `var flags [3]bool`, `var strs [2]string`.
2. Распечатываем значения.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var ints [5]int
	var flags [3]bool
	var strs [2]string

	fmt.Printf("1. [5]int:    %v\n", ints)
	fmt.Printf("2. [3]bool:   %v\n", flags)
	fmt.Printf("3. [2]string: %q\n", strs)
}
```

ℹ️ Zero values для разных типов

**`Терминал`**

```bash
go run main.go
# 1. [5]int:    [0 0 0 0 0]
# 2. [3]bool:   [false false false]
# 3. [2]string: ["" ""]
```

ℹ️ Результаты

## Под капотом

Все байты структуры массива заполняются нулями `0x00`.

## Подводные камни

- Использование неинициализированных указателей в `[3]*int` приведет к `[nil nil nil]`.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go гарантируется zero initialization?»
**Ответ:** Это фундаментальный столб типобезопасности (Type Safety) и предотвращения уязвимостей чтения неинициализированной памяти хоста.
