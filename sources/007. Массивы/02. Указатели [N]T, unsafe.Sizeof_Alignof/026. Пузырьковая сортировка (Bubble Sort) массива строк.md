# Пузырьковая сортировка (Bubble Sort) массива строк [5]string по длине

## Условие

Отсортируйте массив строк по длине, используя ручную реализацию пузырьковой сортировки.

## Теория

**Алгоритм Bubble Sort для массивов строк:**
- Внешний цикл \(N-1\) проходов;
- Внутренний цикл сравнивает длины `len(arr[j]) > len(arr[j+1])`;
- Атомарный обмен элементов на месте `arr[j], arr[j+1] = arr[j+1], arr[j]`.

## Решение по шагам

1. Инициализируем массив `[5]string{"Go", "Kubernetes", "C", "Python", "Rust"}`.
2. Реализуем пузырьковую сортировку.
3. Выводим отсортированный массив.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func BubbleSortByLength(arr *[5]string) {
	n := len(arr)
	for i := 0; i < n-1; i++ {
		for j := 0; j < n-i-1; j++ {
			if len(arr[j]) > len(arr[j+1]) {
				arr[j], arr[j+1] = arr[j+1], arr[j]
			}
		}
	}
}

func main() {
	words := [5]string{"Kubernetes", "Go", "TypeScript", "C", "Rust"}

	fmt.Printf("До сортировки:    %v\n", words)
	BubbleSortByLength(&words)
	fmt.Printf("После сортировки: %v\n", words)
}
```

ℹ️ Сортировка пузырьком массива строк

**`Терминал`**

```bash
go run main.go
# До сортировки:    [Kubernetes Go TypeScript C Rust]
# После сортировки: [C Go Rust TypeScript Kubernetes]
```

ℹ️ Отсортировано по возрастанию длины

## Под капотом

Обмен строк меняет местами только 16-байтные заголовки без копирования содержимого строк.

## Подводные камни

- Забыть передать указатель `*[5]string`, из-за чего сортировка отработает на копии.

## На собеседовании

**Вопрос с собеседования:** «Какова временная и пространственная сложность Bubble Sort?»
**Ответ:** Время \(O(N^2)\), дополнительная память \(O(1)\) (In-place).
