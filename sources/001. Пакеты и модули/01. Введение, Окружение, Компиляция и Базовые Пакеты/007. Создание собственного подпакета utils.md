# Создание собственного подпакета utils и правила экспорта

## Условие

Создай внутри модуля поддиректорию `utils/` с пакетом `utils`. Вынеси туда функцию приветствия. Импортируй и используй её из `main`. Запусти программу.

## Теория

Как устроен импорт локальных пакетов в Go?
1. В корне модуля объявлен `module example.com/myproject`.
2. Создавая подпапку `utils/`, мы создаем пакет `utils` (объявляемый как `package utils` в файлах внутри этой папки).
3. Путь импорта для `main.go` будет равен: `<имя_модуля>/<путь_к_папке>`, то есть `"example.com/myproject/utils"`.

**Золотое правило видимости в Go:**
- Идентификатор (функция, структура, тип, константа), начинающийся с **ЗАГЛАВНОЙ** буквы (например, `SayHello`), является **экспортируемым** (public). Он виден вне своего пакета.
- Идентификатор со **строчной** буквы (например, `sayHello`) является **неэкспортируемым** (private). Он виден только внутри пакета `utils`.

## Решение по шагам

1. Создаем папку `utils/`.
2. Создаем файл `utils/greeting.go` с `package utils` и экспортируемой функцией `SayHello(name string) string`.
3. В `main.go` импортируем `"example.com/myproject/utils"`.
4. Вызываем `utils.SayHello("Мир")`.

## Код решения

**`utils/greeting.go`**

```go
package utils

import "fmt"

// SayHello экспортируется, так как начинается с большой буквы 'S'
func SayHello(name string) string {
	return fmt.Sprintf("Здравствуйте, %s! Привет из пакета utils.", name)
}
```

ℹ️ Подпакет utils

**`main.go`**

```go
package main

import (
	"fmt"
	"example.com/myproject/utils" // Полный путь импорта от корня модуля
)

func main() {
	msg := utils.SayHello("Инженер")
	fmt.Println(msg)
}
```

ℹ️ Импорт и вызов из main.go

**`Терминал`**

```bash
go run .
# Вывод:
# Здравствуйте, Инженер! Привет из пакета utils.
```

## Под капотом

При компиляции Go строит граф зависимостей пакетов (DAG — Directed Acyclic Graph). Пакет `utils` компилируется первым в объектный файл. Затем компилируется `main`, и линкер связывает ссылки на функцию `example.com/myproject/utils.SayHello`.

## Подводные камни

- **Попытка относительного импорта:** `import "./utils"` — в режиме Go Modules относительные пути запрещены и вызовут ошибку `relative import not allowed in module mode`. Всегда указывайте полный путь от имени модуля!
- **Имя функции с маленькой буквы:** Если назвать функцию `sayHello`, компилятор выдаст ошибку `cannot refer to unexported name utils.sayHello`.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go нет ключевых слов `public`, `private`, `protected`?»
**Ответ:** Простота и читаемость кода — фундаментальные ценности Go. Глядя на идентификатор в любом месте чужого кода (`pkg.DoWork()` vs `pkg.internalWork()`), вы мгновенно знаете его область видимости по первому символу без перехода к определению.
