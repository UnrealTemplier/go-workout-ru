# Инициализация модуля с каноническим доменным именем

## Условие

Инициализируйте новый модуль в пустой папке с помощью `go mod init example.com/myproject`.

## Теория

В экосистеме Go модуль идентифицируется глобальным уникальным путем. Общепринятый стандарт — использовать URL репозитория или домен вашей компании:
- `github.com/gin-gonic/gin`
- `gitlab.ozon.ru/payments/billing-service`
- `example.com/myproject`

Зачем нужен доменный префикс?
1. **Предотвращение коллизий имен:** Если тысячи людей создадут пакет `utils`, в коде они будут четко различимы (`github.com/alice/utils` vs `github.com/bob/utils`).
2. **Децентрализованное скачивание:** Go умеет автоматически скачивать зависимости по их импортному пути через VCS (Git, Mercurial, SVN).

## Решение по шагам

1. Создаем пустую папку `myproject`.
2. Выполняем `go mod init example.com/myproject`.
3. Анализируем сгенерированный файл `go.mod`.

## Код решения

**`Терминал`**

```bash
mkdir -p myproject && cd myproject
go mod init example.com/myproject
cat go.mod
```

ℹ️ Инициализация модуля и просмотр go.mod

**`go.mod`**

```text
module example.com/myproject

go 1.22.5
```

ℹ️ Содержимое go.mod

## Под капотом

Файл `go.mod` определяет корень модуля (module root). Любой подкаталог внутри `myproject` будет импортироваться относительно этого префикса, например `example.com/myproject/internal/handler`.
Директива `go 1.22.5` указывает компилятору минимальную поддерживаемую языковую спецификацию.

## Подводные камни

- Не используйте в имени модуля заглавные буквы (например, `example.com/MyProject`), так как некоторые файловые системы (macOS/Windows) регистронезависимы, что может приводить к рассинхрону чексумм в кэше модулей.

## На собеседовании

**Вопрос с собеседования:** «Что означает версия `go 1.X` в файле `go.mod` начиная с Go 1.21?»
**Ответ:** Начиная с Go 1.21, директива `go` в `go.mod` задает жесткую минимальную версию тулчейна. Если установленный компилятор Go старше (например, Go 1.20), тулчейн Go автоматически скачает нужную версию Go 1.22 через механизм Toolchain Switching!
