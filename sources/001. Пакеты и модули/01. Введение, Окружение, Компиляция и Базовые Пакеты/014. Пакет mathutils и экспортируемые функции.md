# Пакет mathutils и экспортируемые функции

## Условие

**Свой пакет**: Создай директорию `mathutils`. В ней создай пакет `mathutils` с экспортируемой функцией `Add` (начинается с большой буквы). Импортируй её в `main.go` и используй.

## Теория

Закрепляем фундаментальный принцип организации библиотечного кода:
- Имя пакета объявляется через `package mathutils`.
- Функция `Add(a, b int) int` доступна внешнему миру, потому что `A` — заглавная буква.
- При вызове из `main.go` мы пишем: `mathutils.Add(10, 20)`.

## Решение по шагам

1. Создаем папку `mathutils`.
2. Создаем `mathutils/mathutils.go`.
3. Импортируем в `main.go` и проверяем вычисление.

## Код решения

**`mathutils/mathutils.go`**

```go
package mathutils

// Add складывает два целых числа и возвращает результат
func Add(a, b int) int {
	return a + b
}
```

ℹ️ Пакет mathutils

**`main.go`**

```go
package main

import (
	"fmt"
	"hello_mod/mathutils"
)

func main() {
	sum := mathutils.Add(40, 2)
	fmt.Printf("Результат mathutils.Add: %d\n", sum)
}
```

ℹ️ Вызов Add в main.go

## Под капотом

Символ `Add` помещается компилятором в таблицу экспортируемых символов объектного файла с полным квалифицированным именем `hello_mod/mathutils.Add`.

## Подводные камни

- Забыть букву `A` в верхнем регистре (`func add`) — внешние пакеты не увидят эту функцию.

## На собеседовании

**Вопрос с собеседования:** «Экспортируются ли поля структуры, если сама структура экспортируема, а поля начинаются с маленькой буквы?»
**Ответ:** Нет. В Go экспортируемость гранулярна. Если структура `User` объявлена с полями `Name string` и `passwordHash string`, то поле `Name` будет видно вне пакета, а `passwordHash` останется доступным исключительно внутри пакета `User`.
