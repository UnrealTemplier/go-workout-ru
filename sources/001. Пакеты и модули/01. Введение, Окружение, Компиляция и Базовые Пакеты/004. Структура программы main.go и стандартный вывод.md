# Структура программы main.go и стандартный вывод

## Условие

Напишите файл `main.go` с `package main` и `func main()`, выводящий `Hello, World!`. Запустите через `go run main.go`.

## Теория

Разберем анатомию базового Go-файла:
```go
package main // 1. Объявление пакета

import "fmt" // 2. Секция импорта

func main() { // 3. Точка входа в программу
    fmt.Println("Hello, World!")
}
```

В Go стандартная библиотека предоставляет пакет `fmt` (formatting), который реализует ввод и вывод по аналогии с функциями `printf`/`scanf` из языка C, но с типобезопасностью и автоматическим определением типов через рефлексию/интерфейсы `fmt.Stringer`.

## Решение по шагам

1. Создаем минимальный файл `main.go`.
2. Запускаем команду `go run main.go`.

## Под капотом

Функция `fmt.Println` принимает вариативный интерфейсный аргумент `...any` (или `...interface{}`). Внутри она блокирует мьютекс стандартного потока вывода `os.Stdout`, форматирует аргументы в буфер и делает системный вызов `write(2)` к файловому дескриптору `1`.

## Подводные камни

- В Go открывающая фигурная скобка `{` функции **обязана** находиться на той же строке, что и объявление `func main()`. Если перенести её на новую строку, компилятор выдаст синтаксическую ошибку `syntax error: unexpected semicolon or newline before {`, так как лексер Go автоматически вставит `;` после круглых скобок!

## На собеседовании

**Вопрос с собеседования:** «Почему лексер Go вставляет точки с запятой сам и как это влияет на синтаксис языка?»
**Ответ:** Разработчики Go стремились сделать язык лаконичным без визуального шума `;`. По правилу языка, если перевод строки следует за идентификатором, базовым литералом, ключевыми словами `break`, `continue`, `fallthrough`, `return` или скобками `)`, `]`, `}`, лексер подставляет точку с запятой. Поэтому `{` нельзя переносить на новую строку.
