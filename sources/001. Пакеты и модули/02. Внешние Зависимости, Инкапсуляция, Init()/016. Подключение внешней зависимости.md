# Подключение внешней зависимости github.com/fatih/color

## Условие

Добавьте внешнюю зависимость, например `github.com/fatih/color`, выполните `go get` и используйте её для цветного вывода строки.

## Теория

В других языках зависимости устанавливаются через сторонние пакетные менеджеры (`npm install`, `composer require`, `pip install`).
В Go пакетный менеджер встроен прямо в ядро языка и управляется командой `go get`.

Когда вы выполняете `go get github.com/fatih/color`:
1. Go связывается с прокси-сервером `proxy.golang.org`.
2. Скачивает исходники библиотеки нужной версии в глобальный локальный кэш `$GOPATH/pkg/mod`.
3. Добавляет запись о библиотеке и её точной семантической версии в файл `go.mod`.
4. Записывает криптографические контрольные суммы файлов библиотеки в `go.sum`.

## Решение по шагам

1. Скачиваем библиотеку: `go get github.com/fatih/color`.
2. В `main.go` импортируем `"github.com/fatih/color"`.
3. Используем функции `color.Cyan()`, `color.Green()`, `color.Red()` для стилизации консольного вывода.
4. Запускаем программу.

## Код решения

**`Терминал`**

```bash
# Скачивание пакета
go get github.com/fatih/color
# go: added github.com/fatih/color v1.17.0
# go: added github.com/mattn/go-colorable v0.1.13
# go: added github.com/mattn/go-isatty v0.0.20
# go: added golang.org/x/sys v0.25.0
```

ℹ️ Скачивание библиотеки и её транзитивных зависимостей

**`main.go`**

```go
package main

import (
	"github.com/fatih/color"
)

func main() {
	color.Green("✔ [УСПЕХ] База данных PostgreSQL успешно подключена!")
	color.Yellow("⚠ [ВНИМАНИЕ] Высокая нагрузка на пул соединений.")
	color.Red("✖ [ОШИБКА] Не удалось отправить webhook в платёжный шлюз.")
}
```

ℹ️ Использование fatih/color

**`Терминал`**

```bash
go run .
```

ℹ️ Вывод цветных строк в терминал

## Под капотом

Библиотека `fatih/color` под капотом проверяет, подключен ли терминал (через вызов `isatty` к файловому дескриптору stdout). Если stdout перенаправлен в файл или пайп (`./app > output.log`), она автоматически отключает ANSI escape-последовательности, чтобы логи не засорялись служебными символами.

## Подводные камни

- Начиная с Go 1.18, команда `go get` используется **только для добавления/обновления зависимостей в `go.mod`**. Установка исполняемых CLI-бинарников выполняется через `go install <path>@latest`.

## На собеседовании

**Вопрос с собеседования:** «Что такое транзитивные зависимости (transitive dependencies) и как Go управляет ими?»
**Ответ:** Транзитивная зависимость — это зависимость вашей зависимости (например, `fatih/color` зависит от `mattn/go-isatty`). Тулчейн Go автоматически скачивает их и записывает в `go.mod` с комментарием `// indirect`. Go использует алгоритм MVS (Minimal Version Selection) для детерминированного выбора минимально достаточной версии.
