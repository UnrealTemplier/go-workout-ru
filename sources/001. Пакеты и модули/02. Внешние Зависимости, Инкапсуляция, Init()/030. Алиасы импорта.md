# Алиасы импорта: локальное переименование пакетов (import f "fmt")

## Условие

**Алиасы импорта**: Импортируй пакет `fmt` с псевдонимом `f` (например, `import f "fmt"`). Выведи текст, используя `f.Println`.

## Теория

При импорте пакета перед строкой пути можно указать **псевдоним (алиас)**:
```go
import (
    f "fmt"
    myrand "crypto/rand"
    fastrand "math/rand"
)
```

Зачем нужны алиасы:
1. **Разрешение коллизий имен:** если вам нужны одновременно `crypto/rand` и `math/rand`, без алиаса оба пакета назывались бы `rand`.
2. **Сокращение длинных имен:** например, `k8serrors "k8s.io/apimachinery/pkg/api/errors"`.
3. **Миграция библиотек:** можно подменить реализацию пакета без изменения сотен строк кода.

## Решение по шагам

1. В `main.go` импортируем `fmt` с алиасом `f`.
2. Вызываем `f.Println("...")`.
3. Запускаем программу.

## Код решения

**`main.go`**

```go
package main

import (
	f "fmt" // Задаем псевдоним f для пакета fmt
)

func main() {
	f.Println("Использование пакета fmt через краткий алиас f!")
}
```

ℹ️ Использование алиаса импорта

**`Терминал`**

```bash
go run .
# Вывод:
# Использование пакета fmt через краткий алиас f!
```

## Под капотом

Алиас импорта существует только на этапе компиляции в области видимости текущего файла `.go`. В других файлах того же пакета пакет `fmt` по-прежнему будет доступен под своим стандартным именем, если там не объявлен собственный алиас.

## Подводные камни

- Чрезмерное использование однобуквенных алиасов вроде `f` для стандартных пакетов снижает читаемость кода для коллег. Используйте алиасы только при реальной необходимости (коллизии имен).

## На собеседовании

**Вопрос с собеседования:** «Что означает импорт с точкой: `import . "fmt"`?»
**Ответ:** Dot-import (`.`) импортирует все экспортируемые идентификаторы пакета напрямую в текущее пространство имен файла, позволяя вызывать `Println()` вместо `fmt.Println()`. В продакшене dot-import считается антипаттерном из-за замусоривания пространства имен и риска коллизий (исключение — DSL-тесты вроде Gomega).
