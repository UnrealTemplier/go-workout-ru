# Разделение логики пакета: go run . против go run main.go helper.go

## Условие

**Разделение одного пакета**: Создайте файл `helper.go` в той же директории, где находится `main.go` (оба файла должны объявлять `package main`). Перенесите часть логики вывода в `helper.go`. Запустите проект с помощью `go run main.go helper.go` или `go run .`.

## Теория

При разработке микросервисов в одном каталоге часто находится несколько файлов.
Сравним способы запуска:
1. `go run .` — компилирует текущую директорию как единый пакет. **Это стандарт де-факто.**
2. `go run main.go helper.go` — явно передает список файлов. Неудобно, если файлов 10+.
3. `go run *.go` — подставляет файлы через shell globing, но может случайно захватить тестовые файлы или файлы сборки для другой ОС.

## Решение по шагам

1. Создаем `helper.go` с функцией `renderBanner(appName string)`.
2. В `main.go` вызываем `renderBanner`.
3. Запускаем проект через `go run .`.

## Код решения

**`helper.go`**

```go
package main

import "fmt"

func renderBanner(appName string) {
	fmt.Println("========================================")
	fmt.Printf("   СЕРВИС: %s\n", appName)
	fmt.Println("========================================")
}
```

ℹ️ Файл helper.go

**`main.go`**

```go
package main

func main() {
	renderBanner("AUTH_SERVICE_V2")
}
```

ℹ️ Файл main.go

**`Терминал`**

```bash
go run .
# Вывод:
# ========================================
#    СЕРВИС: AUTH_SERVICE_V2
# ========================================

go run main.go helper.go
# Дает аналогичный результат
```

ℹ️ Запуск программы

## Под капотом

Синтаксис точки `.` в Go обозначает путь к локальному пакету. Тулчейн Go парсит манифест пакета в текущем каталоге, отфильтровывает файлы сборки по билд-тегам и собирает проект.

## Подводные камни

- Не используйте `go run main.go` для многофайловых пакетов — это приведет к ошибке `undefined`.

## На собеседовании

**Вопрос с собеседования:** «Что означает синтаксис `./...` в командах `go test ./...` или `go vet ./...`?»
**Ответ:** `./...` — это специальный паттерн тулчейна Go, обозначающий «текущий пакет и **рекурсивно все вложенные подпакеты** проекта».
