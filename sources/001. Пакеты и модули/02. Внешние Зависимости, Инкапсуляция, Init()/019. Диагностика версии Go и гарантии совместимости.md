# Диагностика версии Go и гарантии совместимости (Go 1 Compatibility Promise)

## Условие

Проверьте версию Go, установленную в системе, используя команду `go version`.

## Теория

Команда `go version` выводит текущую версию компилятора, операционную систему и архитектуру процессора.

**Go 1 Compatibility Promise:**
Одно из величайших преимуществ Go перед другими языками — официальная гарантия обратной совместимости Go 1.
Код, написанный на Go 1.0 в 2012 году, **гарантированно скомпилируется и будет работать** на самой современной версии Go (Go 1.22+). Разработчики языка никогда не ломают обратную совместимость спецификации Go 1.

## Решение по шагам

1. Выполняем `go version` в терминале.
2. Анализируем вывод: версия тулчейна, ОС (`linux`, `darwin`, `windows`), архитектура (`amd64`, `arm64`).

## Код решения

**`Терминал`**

```bash
go version
# Вывод:
# go version go1.22.5 linux/amd64
```

ℹ️ Проверка версии Go

## Под капотом

Утилита `go` умеет определять версию любого скомпилированного Go-бинарника!
Команда `go version ./bin/server` прочитает встроенные метаданные сборки ELF/Mach-O и покажет, какой версией Go и с какими флагами был собран сторонний бинарник.

## Подводные камни

- Не путайте версию установленного компилятора Go в системе с директивой `go 1.XX` в файле `go.mod`.

## На собеседовании

**Вопрос с собеседования:** «Как в Go инспектировать метаданные зависимостей уже скомпилированного бинарника в проде?»
**Ответ:** Командой `go version -m /path/to/binary`. Go вшивает в бинарник полный список модулей, их версии и хэши коммитов, что позволяет моментально проводить аудит уязвимостей на сервере.
