# Замыкания: функция Counter() с инкрементом при каждом вызове

## Условие

**Замыкания (Closures) 1**: Напиши функцию `Counter() func() int`, которая при каждом вызове возвращает число, на 1 большее предыдущего. (Сохранение состояния в замыкании).

## Теория

Закрепление паттерна счетчика на замыкании.

## Решение по шагам

1. Пишем `Counter() func() int`.
2. Инициализируем `c := 0`.
3. Тестируем вызовы.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Counter() func() int {
	c := 0
	return func() int {
		c++
		return c
	}
}

func main() {
	cnt := Counter()
	fmt.Printf("1. Вызов: %d\n", cnt())
	fmt.Printf("2. Вызов: %d\n", cnt())
	fmt.Printf("3. Вызов: %d\n", cnt())
}
```

**`Терминал`**

```bash
go run main.go
# 1. Вызов: 1
# 2. Вызов: 2
# 3. Вызов: 3
```

## Под капотом

Переменная `c` сохраняет состояние между кадрами стека.

## Подводные камни

- Вызов `Counter()()` без сохранения переменной (каждый раз вернет 1).

## На собеседовании

**Вопрос с собеседования:** «Что вернет `Counter()()` при двух вызовах подряд?»
**Ответ:** Оба раза вернет `1`, так как каждый вызов `Counter()` создает новый счетчик.
