# Передача динамического среза в вариативную функцию Sum(nums ...int)

## Условие

Распаковка слайса: Создай обычный срез (slice) []int. Передай его в функцию Sum с помощью оператора ... (распаковка).

### Исходная формулировка

**Распаковка слайса**: Создай обычный срез (slice) `[]int`. Передай его в функцию `Sum` из упр. 56 с помощью оператора `...` (распаковка).

## Теория

Закрепление распаковки динамического среза.

## Решение по шагам

1. Пишем `Sum(nums ...int) int`.
2. Создаем `scores := []int{10, 20, 30, 40}`.
3. Передаем `Sum(scores...)`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Sum(nums ...int) int {
	res := 0
	for _, v := range nums {
		res += v
	}
	return res
}

func main() {
	scores := []int{10, 20, 30, 40}
	total := Sum(scores...)
	fmt.Printf("Сумма элементов среза %v = %d\n", scores, total)
}
```

**`Терминал`**

```bash
go run main.go
# Сумма элементов среза [10 20 30 40] = 100
```

## Под капотом

Срезовый дескриптор передается по значению.

## Подводные камни

- Попытка передать `Sum(scores)` без `...`.
