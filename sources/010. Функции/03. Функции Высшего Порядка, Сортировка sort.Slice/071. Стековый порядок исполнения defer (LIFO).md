# Стековый порядок исполнения defer (LIFO): вывод чисел 1, 2, 3

## Условие

**Порядок выполнения defer (LIFO)**: Напишите функцию, в которой друг за другом вызываются три оператора `defer` с выводом чисел 1, 2 и 3. Убедитесь в порядке их выполнения (стек).

## Теория

LIFO проверка порядка: `defer 1`, `defer 2`, `defer 3` \(\rightarrow\) вывод `3`, `2`, `1`.

## Решение по шагам

1. Регистрируем `defer 1`, `defer 2`, `defer 3`.
2. Проверяем порядок.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func TestLIFO() {
	defer fmt.Println("defer 1")
	defer fmt.Println("defer 2")
	defer fmt.Println("defer 3")
}

func main() {
	TestLIFO()
}
```

**`Терминал`**

```bash
go run main.go
# defer 3
# defer 2
# defer 1
```

## Под капотом

Стек вызовов разматывается сверху вниз.

## Подводные камни

- Ожидание порядка 1, 2, 3.

## На собеседовании

**Вопрос с собеседования:** «Что происходит со стеком `defer`, если функция завершается паникой?»
**Ответ:** Все зарегистрированные до момента паники `defer` гарантированно выполняются в обычном порядке LIFO.
