# Локальная анонимная функция немедленного вызова прямо в теле main()

## Условие

**Анонимные функции**: Объяви функцию прямо внутри `main()` без имени и тут же вызови её.

## Теория

Базовый синтаксис немедленного выполнения анонимной лямбды.

## Решение по шагам

1. Пишем `func() { fmt.Println(...) }()`.
2. Запускаем.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	func() {
		fmt.Println("Анонимная функция выполнена успешно!")
	}()
}
```

**`Терминал`**

```bash
go run main.go
# Анонимная функция выполнена успешно!
```

## Под капотом

Инлайнинг тела функции в тело `main`.

## Подводные камни

- Отсутствие `()` в конце.

## На собеседовании

**Вопрос с собеседования:** «Можно ли запустить анонимную функцию в отдельной горутине?»
**Ответ:** ДА! С помощью ключевого слова `go func() { ... }()`.
