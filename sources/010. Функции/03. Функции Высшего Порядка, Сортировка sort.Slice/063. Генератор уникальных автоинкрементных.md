# Генератор уникальных автоинкрементных идентификаторов NewIDGenerator() func() int

## Условие

**Замыкание (Closure)**: Создайте генератор идентификаторов `NewIDGenerator() func() int`. Каждый вызов возвращенной функции должен возвращать число на 1 больше предыдущего (начиная с 1).

## Теория

Инкапсуляция генератора ID через замыкание.

## Решение по шагам

1. Пишем `NewIDGenerator() func() int`.
2. Замыкаем `id := 0`.
3. При вызове возвращаем `id++`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func NewIDGenerator() func() int {
	id := 0
	return func() int {
		id++
		return id
	}
}

func main() {
	nextID := NewIDGenerator()

	fmt.Printf("ID: %d\n", nextID())
	fmt.Printf("ID: %d\n", nextID())
	fmt.Printf("ID: %d\n", nextID())
}
```

**`Терминал`**

```bash
go run main.go
# ID: 1
# ID: 2
# ID: 3
```

## Под капотом

Изолированная переменная `id` в куче.

## Подводные камни

- В конкурентной среде требует атомиков (`atomic.AddInt64`) или мьютекса.

## На собеседовании

**Вопрос с собеседования:** «Как сделать генератор ID потокобезопасным без мьютексов?»
**Ответ:** Использовать пакет `sync/atomic` и функцию `atomic.AddInt64(&id, 1)`.
