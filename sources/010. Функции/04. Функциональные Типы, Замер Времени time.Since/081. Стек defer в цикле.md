# Стек defer в цикле: строгое доказательство порядка LIFO

## Условие

**Стек defer**: Напиши цикл с `defer fmt.Println(i)`. Убедись, что `defer` вызываются в порядке LIFO (Последним пришел — первым ушел).

## Теория

Закрепление LIFO порядка в цикле от 0 до 4.

## Решение по шагам

1. В цикле `for i := 0; i < 5; i++` вызываем `defer fmt.Println(i)`.
2. Фиксируем вывод `4 3 2 1 0`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func CountDown() {
	fmt.Println("Старт цикла регистрации defer:")
	for i := 0; i < 5; i++ {
		defer fmt.Printf("  LIFO defer: %d\n", i)
	}
	fmt.Println("Цикл завершен, выход из функции...")
}

func main() {
	CountDown()
}
```

**`Терминал`**

```bash
go run main.go
# Старт цикла регистрации defer:
# Цикл завершен, выход из функции...
#   LIFO defer: 4
#   LIFO defer: 3
#   LIFO defer: 2
#   LIFO defer: 1
#   LIFO defer: 0
```

## Под капотом

Связанный список `_defer` разматывается от головы к хвосту.
