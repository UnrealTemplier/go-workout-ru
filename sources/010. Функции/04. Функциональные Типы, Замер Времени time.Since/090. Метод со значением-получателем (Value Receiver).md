# Метод со значением-получателем (Value Receiver): func (c Counter) Print()

## Условие

**Методы (база)**: Объяви свой тип `type Counter int`. Напиши для него метод `func (c Counter) Print()`, который можно будет вызвать как `myCounter.Print()`.

## Теория

Объявление метода на базовом типе со значением-получателем.

## Решение по шагам

1. Объявляем `type Counter int`.
2. Пишем метод `func (c Counter) Print()`.
3. Вызываем через точку `myCounter.Print()`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Counter int

func (c Counter) Print() {
	fmt.Printf("Значение счетчика: %d\n", c)
}

func main() {
	var myCounter Counter = 42
	myCounter.Print()
}
```

**`Терминал`**

```bash
go run main.go
# Значение счетчика: 42
```

## Под капотом

Метод компилируется в обычную функцию `Counter.Print(c Counter)`.

## Подводные камни

- Метод с Value Receiver не может изменять значение `myCounter`.
