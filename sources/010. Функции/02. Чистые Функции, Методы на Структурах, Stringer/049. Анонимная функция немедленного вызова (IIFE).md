# Анонимная функция немедленного вызова (IIFE) для фиксации текущего времени

## Условие

**Анонимная функция (IIFE)**: Напишите и сразу же вызовите анонимную функцию, которая выводит текущее время.

## Теория

Закрепление синтаксиса IIFE для форматированного вывода времени.

## Решение по шагам

1. Пишем `func() { ... }()`.
2. Получаем `time.Now()`.
3. Форматируем и выводим.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	func() {
		now := time.Now()
		fmt.Printf("⏰ Текущая дата и время: %s\n", now.Format("2006-01-02 15:04:05"))
	}()
}
```

**`Терминал`**

```bash
go run main.go
# ⏰ Текущая дата и время: 2026-09-02 15:04:05
```

## Под капотом

Локальная область видимости переменной `now`.

## Подводные камни

- Забыть вызов `()`.

## На собеседовании

**Вопрос с собеседования:** «Может ли IIFE возвращать несколько значений?»
**Ответ:** ДА! Например: `a, b := func() (int, int) { return 1, 2 }()`.
