# Создание очереди orders и базовая публикация через дефолтный обменник

## Условие

Создайте **queue** `orders` и отправьте в него сообщение через default exchange.

## Теория

Прямая отправка в очередь через безымянный обменник:
- `ch.QueueDeclare("orders", true, false, false, false, nil)`:
  - Создает постоянную очередь `orders`.
- `ch.PublishWithContext(ctx, "", "orders", ...)`:
  - Имя обменника `""` (пустая строка).
  - Поле `routing_key` в точности совпадает с именем очереди `"orders"`.
  - Самый простой и надежный способ организации очередей задач.

## Решение по шагам

1. Создайте структуру очереди `orders`.
2. Реализуйте отправку заказа с указанием `routing_key = "orders"`.
3. Убедитесь в наличии сообщения в целевой очереди.
4. Проверьте тело сообщения.

## Код решения

**`orders_default_exchange_test.go`**

```go
package main

import (
	"fmt"
	"testing"
)

func TestOrdersDefaultExchange(t *testing.T) {
	queueStorage := make(map[string][]string)

	publishToDefault := func(routingKey, body string) {
		queueStorage[routingKey] = append(queueStorage[routingKey], body)
	}

	// Отправка через default exchange в очередь orders
	payload := `{"order_id": 1005, "total": 8900.50}`
	publishToDefault("orders", payload)

	messages := queueStorage["orders"]
	if len(messages) != 1 || messages[0] != payload {
		t.Fatalf("Сообщение не попало в очередь orders: %v", messages)
	}

	fmt.Println("Сообщение успешно отправлено через Default Exchange:")
	fmt.Printf("  • Целевая очередь: orders\n")
	fmt.Printf("  • Полезная нагрузка: %s\n", messages[0])
}
```

## Под капотом

Брокер оптимизирует Default Exchange: при публикации с пустым exchange name он вообще минует фазу сопоставления правил маршрутизации и сразу помещает указатель на сообщение в память очереди `orders`.

## Подводные камни

Опечатка в routing_key: если очередь с таким именем не была создана заранее, сообщение будет молча выброшено брокером.

## На собеседовании

**Вопрос с собеседования:** «Как узнать, было ли сообщение доставлено в очередь при публикации через Default Exchange?»
**Ответ:** Установить флаг `mandatory: true` в методе публикации и подписаться на канал возврата `ch.NotifyReturn()`. Если очередь с таким routing_key отсутствует, брокер вернет сообщение обратно продюсеру в кадре `basic.return` с кодом `312 NO_ROUTE`.
