# Безопасная остановка бесконечной горутины через atomic.Bool

## Условие

Создай горутину с **бесконечным циклом** и попробуй остановить её извне через `bool` флаг (читаемый в цикле). Покажи, что без `sync/atomic` или mutex это **data race**. Исправь через `atomic.Bool` (или `atomic.Value`).

## Теория

Чтение обычного булевого флага `var running bool` в одной горутине и запись из другой горутины без синхронизации — это Data Race. Компилятор может закэшировать значение флага в регистре CPU, из-за чего горутина никогда не увидит изменение. `atomic.Bool` (Go 1.19+) гарантирует потокобезопасное чтение и запись с аппаратным барьером памяти (Memory Barrier).

## Решение по шагам

1. Объявим `var isRunning atomic.Bool`.
2. Установим `isRunning.Store(true)`.
3. В горутине крутим цикл `for isRunning.Load() { ... }`.
4. В `main` вызовем `isRunning.Store(false)` и дождемся корректной остановки.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"sync/atomic"
	"time"
)

func main() {
	var isRunning atomic.Bool
	var wg sync.WaitGroup

	isRunning.Store(true)
	wg.Add(1)

	// Фоновый воркер
	go func() {
		defer wg.Done()
		fmt.Println("[Worker] Фоновый цикл запущен")
		iterations := 0
		for isRunning.Load() {
			iterations++
			time.Sleep(10 * time.Millisecond)
		}
		fmt.Printf("[Worker] Получен сигнал остановки, итераций: %d\n", iterations)
	}()

	// Даем воркеру поработать
	time.Sleep(35 * time.Millisecond)

	fmt.Println("[Main] Отправка сигнала остановки...")
	isRunning.Store(false)

	wg.Wait()
	fmt.Println("[Main] Воркер успешно остановлен без утечек и гонок данных")
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# [Worker] Фоновый цикл запущен
# [Main] Отправка сигнала остановки...
# [Worker] Получен сигнал остановки, итераций: 3
# [Main] Воркер успешно остановлен без утечек и гонок данных
```

## Под капотом

`atomic.Bool.Store` и `Load` транслируются в атомарные процессорные инструкции `MOV` с семантикой Acquire-Release, запрещая оптимизатору кэшировать значение в регистрах.

## Подводные камни

Не используйте обычный `bool` даже для "простых флагов остановки" — флаг `-race` сразу обнаружит гонку.

## На собеседовании

**Вопрос с собеседования:** «Почему чтение bool без atomic может зависнуть в бесконечном цикле при сборке с оптимизацией -O2 / SSA compiler?»
**Ответ:** Компилятор видит, что внутри тела цикла переменная `running` не меняется, и производит оптимизацию Loop-Invariant Code Motion (LICM), вынося чтение флага за пределы цикла `if running { for {} }`.
