# Опасность вызова wg.Add(1) внутри горутины (Race Condition с Wait)

## Условие

**[Каверзный кейс]**: Используй `WaitGroup` внутри цикла. Попробуй вызвать `wg.Add(1)` внутри горутины. Поймай состояние гонки (или дедлок), когда `main` вызовет `wg.Wait()` до того, как горутины успеют сделать `Add`.

## Теория

Если вызывать `wg.Add(1)` внутри тела горутины, планировщик может не успеть запустить ни одну из них до того, как поток `main` дойдет до `wg.Wait()`. Так как счетчик равен 0, `wg.Wait()` моментально разблокируется, и программа завершится без выполнения задач.

## Решение по шагам

1. Продемонстрируем ошибочный вызов `wg.Add(1)` внутри горутины.
2. Покажем, что `wg.Wait()` срабатывает раньше.
3. Исправим код, вынеся `wg.Add(1)` в родительский поток перед `go`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup

	fmt.Println("--- ПРАВИЛЬНЫЙ ВЫЗОВ: wg.Add(1) строго ДО ключевого слова go ---")
	for i := 1; i <= 3; i++ {
		// КРИТИЧЕСКИ ВАЖНО: Add вызывается в вызывающей горутине
		wg.Add(1)
		go func(id int) {
			defer wg.Done()
			fmt.Printf("Воркер #%d выполнен гарантированно\n", id)
		}(i)
	}

	wg.Wait()
	fmt.Println("Все воркеры дождались завершения!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- ПРАВИЛЬНЫЙ ВЫЗОВ: wg.Add(1) строго ДО ключевого слова go ---
# Воркер #1 выполнен гарантированно
# Воркер #2 выполнен гарантированно
# Воркер #3 выполнен гарантированно
# Все воркеры дождались завершения!
```

## Под капотом

`wg.Add(1)` в родительском потоке гарантирует отношение Happens-Before: счетчик увеличивается до того, как выполнение дойдет до `wg.Wait()`.

## Подводные камни

Вызов `wg.Add` внутри горутины считается грубой ошибкой синхронизации и обнаруживается флагом `go run -race`.

## На собеседовании

**Вопрос с собеседования:** «Что произойдет, если вызвать wg.Add(1) параллельно с уже заблокированным wg.Wait() при переходе счетчика из 0 в 1?»
**Ответ:** Произойдет паника `panic: sync: WaitGroup misuse: Add called concurrently with Wait`.
