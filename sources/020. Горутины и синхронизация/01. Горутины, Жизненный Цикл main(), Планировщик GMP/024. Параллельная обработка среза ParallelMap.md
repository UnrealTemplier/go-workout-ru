# Параллельная обработка среза ParallelMap с сохранением порядка индексов

## Условие

Напиши функцию `ParallelMap(inputs []int, fn func(int) int) []int`, запускающую обработку каждого элемента в отдельной горутине. Собери результаты в правильном порядке (используй слайс с индексами).

## Теория

Паттерн Parallel Map распределяет обработку элементов среза по горутинам. Так как каждая горутина пишет строго в свой уникальный индекс `results[i]`, операция не требует мьютексов и сохраняет исходный порядок элементов.

## Решение по шагам

1. Создадим срез результатов `results := make([]int, len(inputs))`.
2. Запустим горутину для каждого элемента `i, val`.
3. Внутри горутины запишем `results[i] = fn(val)`.
4. Дождемся всех через `sync.WaitGroup` и вернем результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

func ParallelMap(inputs []int, fn func(int) int) []int {
	results := make([]int, len(inputs))
	var wg sync.WaitGroup

	wg.Add(len(inputs))
	for i, val := range inputs {
		go func(idx, v int) {
			defer wg.Done()
			// Каждая горутина пишет в свой изолированный индекс среза
			results[idx] = fn(v)
		}(i, val)
	}

	wg.Wait()
	return results
}

func main() {
	numbers := []int{1, 2, 3, 4, 5}

	// Возведение в квадрат с симуляцией задержки
	squared := ParallelMap(numbers, func(n int) int {
		time.Sleep(10 * time.Millisecond)
		return n * n
	})

	fmt.Printf("Исходный массив: %v\n", numbers)
	fmt.Printf("Результат ParallelMap: %v\n", squared)
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# Исходный массив: [1 2 3 4 5]
# Результат ParallelMap: [1 4 9 16 25]
```

## Под капотом

Запись в разные индексы предвыделенного среза `results[idx]` безопасна и не вызывает data race, так как элементы расположены по непересекающимся адресам памяти.

## Подводные камни

Если в `ParallelMap` вызывать `append`, возникнет гонка данных. Срез результатов обязан быть предвыделен `make([]int, len(inputs))`.

## На собеседовании

**Вопрос с собеседования:** «Почему запись в разные индексы одного среза results[i] из разных горутин потокобезопасна, а append(results, v) — нет?»
**Ответ:** `results[i]` обращается к независимому элементу массива по фиксированному смещению `ptr + i*sizeof(T)`. `append` модифицирует поле длины заголовка среза `len` и может производить реаллокацию базового массива, вызывая гонку по заголовку `SliceHeader`.
