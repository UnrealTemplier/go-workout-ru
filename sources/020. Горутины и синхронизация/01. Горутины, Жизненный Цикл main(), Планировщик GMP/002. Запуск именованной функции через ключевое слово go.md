# Запуск именованной функции через ключевое слово go

## Условие

Запусти обычную функцию как горутину (через ключевое слово `go`). Выведи "main" и "goroutine". Убедись, что программа завершается до вывода горутины (используй `time.Sleep` для временного фикса).

## Теория

Ключевое слово `go` можно ставить перед вызовом любой обычной функции `go task()`. Вызывающий поток сразу переходит к следующей инструкции, а вызов функции планируется в отдельной горутине.

## Решение по шагам

1. Объявим функцию `printGoroutine()`.
2. В `main` вызовем `go printGoroutine()`.
3. Напечатаем `"main"`.
4. Добавим временную задержку через `time.Sleep`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func printGoroutine() {
	fmt.Println("goroutine")
}

func main() {
	go printGoroutine()
	fmt.Println("main")

	time.Sleep(50 * time.Millisecond)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# main
# goroutine
```

## Под капотом

Вызов `go fn()` транслируется компилятором в вызов `runtime.newproc(fn)`.

## Подводные камни

Любые возвращаемые значения функции, запущенной через `go fn()`, игнорируются компилятором. Передавать результат наружу нужно через каналы или мьютексы.

## На собеседовании

**Вопрос с собеседования:** «Можно ли запустить через go встроенную функцию (например, append, len, make)?»
**Ответ:** Нет, спецификация Go запрещает вызов built-in функций (за исключением `recover()`, `close()`, `copy()`, `delete()`) напрямую с ключевым словом `go`. Их необходимо оборачивать в анонимную функцию `go func() { ... }()`.
