# Замыкание переменной цикла в горутинах: эволюция до и после Go 1.22

## Условие

**Замыкание переменной цикла в горутине**: Напишите цикл `for i := 0; i < 10; i++`, внутри которого запускается горутина `go func() { fmt.Println(i) }()`. Запустите код на версии Go ниже 1.22 (или смоделируйте старое поведение, передавая значение не через аргумент). Почему выводится много одинаковых чисел (например, девяток или десяток)? Исправьте это, явно передавая `i` в качестве аргумента анонимной функции: `go func(val int) { ... }(i)`.

## Теория

До Go 1.22 переменная цикла `i` объявлялась один раз на весь цикл и переиспользовалась между итерациями (Per-loop variable). Все горутины захватывали по указателю одну и ту же область памяти. К моменту их запуска цикл успевал досчитать до 10. Начиная с Go 1.22 переменная цикла создается заново на каждой итерации (Per-iteration variable). Явная передача аргументом `func(val int)(i)` остается лучшей и самой явной практикой.

## Решение по шагам

1. Создадим `var wg sync.WaitGroup`.
2. В цикле передадим значение `i` как аргумент `go func(val int) { ... }(i)`.
3. Убедимся, что напечатаны все числа от 0 до 9 без дублей.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup

	// Идиоматичный и безопасный запуск с явной передачей аргумента
	for i := 0; i < 10; i++ {
		wg.Add(1)
		go func(val int) {
			defer wg.Done()
			fmt.Printf("%d ", val)
		}(i) // Значение i копируется в аргумент val на стеке горутины
	}

	wg.Wait()
	fmt.Println("\nВсе 10 значений выведены корректно")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод (числа от 0 до 9 в произвольном порядке):
# 0 9 1 2 3 4 5 6 7 8 
# Все 10 значений выведены корректно
```

## Под капотом

При передаче `i` в аргументы анонимной функции рантайм копирует 8 байт числа на стек создаваемой горутины в момент выполнения инструкции `go`, изолируя значение от изменений в цикле.

## Подводные камни

В коде для Go < 1.22 неявный захват переменной цикла без аргументов приводил к скрытым багам в базах данных (все запросы выполнялись с последним ID).

## На собеседовании

**Вопрос с собеседования:** «Что изменилось в семантике циклов for в Go 1.22 (Loop Variable Scoping)?»
**Ответ:** В Go 1.22 изменился скоупинг: переменные цикла `for i := 0; ...` и `for k, v := range ...` теперь создают новую переменную в новой ячейке памяти на каждой итерации, устраняя классический баг замыканий.
