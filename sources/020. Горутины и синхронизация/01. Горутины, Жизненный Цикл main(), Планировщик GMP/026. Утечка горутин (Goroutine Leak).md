# Утечка горутин (Goroutine Leak) и мониторинг через runtime.NumGoroutine()

## Условие

Покажи **goroutine leak**: запусти горутину, которая пишет в канал, но никто не читает. Горутина зависнет навечно. Используй `runtime.NumGoroutine()` до и после, чтобы показать утечку.

## Теория

Утечка горутины (Goroutine Leak) происходит, когда горутина навсегда блокируется на чтении/записи в канал, ожидании мьютекса или сетевом запросе. Сборщик мусора Go (GC) **НЕ собирает** заблокированные горутины, что приводит к прогрессирующей утечке оперативной памяти.

## Решение по шагам

1. Замерим количество горутин через `runtime.NumGoroutine()`.
2. Запустим 5 горутин, которые пишут в небуферизованный канал без читателя.
3. Проверим увеличение `runtime.NumGoroutine()`.
4. Объясним, как предотвращать утечки.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"runtime"
	"time"
)

func leakingWorker() {
	ch := make(chan int) // Небуферизованный канал
	// Горутина навечно зависнет на записи, так как никто не читает из ch
	go func() {
		ch <- 42
	}()
}

func main() {
	fmt.Printf("1. Начальное число горутин: %d\n", runtime.NumGoroutine())

	// Создаем 5 заблокированных горутин
	for i := 0; i < 5; i++ {
		leakingWorker()
	}

	time.Sleep(20 * time.Millisecond)
	fmt.Printf("2. Число горутин после утечки: %d (утекло 5 горутин)\n", runtime.NumGoroutine())
	fmt.Println("Внимание: заблокированные горутины навсегда останутся в памяти!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# 1. Начальное число горутин: 1
# 2. Число горутин после утечки: 6 (утекло 5 горутин)
# Внимание: заблокированные горутины навсегда останутся в памяти!
```

## Под капотом

Заблокированная на канале горутина помещается в список ожидания `waitq` канала и остается в статусе `_Gwaiting`. GC видит активную ссылку на стек горутины и не может освободить её память.

## Подводные камни

В микросервисах утечки горутин в HTTP-хендлерах приводят к падению пода по OOM (Out Of Memory) через несколько дней работы.

## На собеседовании

**Вопрос с собеседования:** «Как на production-серверах обнаруживать утечки горутин?»
**Ответ:** 1) Экспортировать метрику `go_goroutines` в Prometheus и настроить алерт на непрерывный линейный рост. 2) Использовать профилировщик `pprof`: `GET /debug/pprof/goroutine?debug=2` для просмотра стеков всех заблокированных горутин.
