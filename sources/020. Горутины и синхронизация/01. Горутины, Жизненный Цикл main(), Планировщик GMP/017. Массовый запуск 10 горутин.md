# Массовый запуск 10 горутин и синхронизация через WaitGroup

## Условие

**Много горутин**: Запусти в цикле от 1 до 10 анонимные горутины, выводящие номер итерации. Используй `WaitGroup` для ожидания всех десяти. Обрати внимание на порядок вывода (он случайный).

## Теория

Запуск множества независимых задач в цикле — стандартный шаблон параллельной обработки в Go (например, одновременная загрузка 10 страниц сайтов).

## Решение по шагам

1. Создадим `var wg sync.WaitGroup`.
2. В цикле от 1 до 10 вызовем `wg.Add(1)`.
3. Передадим переменную итерации `i` в аргументы анонимной горутины.
4. Вызовем `wg.Wait()`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup

	const totalTasks = 10
	wg.Add(totalTasks)

	for i := 1; i <= totalTasks; i++ {
		go func(taskID int) {
			defer wg.Done()
			fmt.Printf("Выполнена итерация %d\n", taskID)
		}(i)
	}

	wg.Wait()
	fmt.Println("Все 10 горутин успешно завершены!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Выполнена итерация 10
# Выполнена итерация 1
# Выполнена итерация 2
# Выполнена итерация 3
# Выполнена итерация 4
# Выполнена итерация 5
# Выполнена итерация 6
# Выполнена итерация 7
# Выполнена итерация 8
# Выполнена итерация 9
# Все 10 горутин успешно завершены!
```

## Под капотом

Планировщик Go распределяет 10 горутин по очередям процессоров P, используя все доступные ядра процессора (`GOMAXPROCS`).

## Подводные камни

Не забывайте передавать `i` в параметры `func(taskID int)`, чтобы исключить неявное разделение переменной.

## На собеседовании

**Вопрос с собеседования:** «Каков предел количества одновременно запущенных горутин в Go?»
**Ответ:** В 64-битных системах лимит ограничен только доступным объемом оперативной памяти. Можно без проблем запускать миллионы горутин (1 млн горутин \(\approx\) 2–3 ГБ RAM).
