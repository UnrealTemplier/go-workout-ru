# Идиоматичная передача параметров цикла в аргументы горутины

## Условие

**Правильный захват**: Передай переменную `i` как аргумент в анонимную горутину: `go func(id int) { ... }(i)`. Убедись, что вывод корректен.

## Теория

Явная передача значений в сигнатуру анонимной горутины `go func(val T) { ... }(val)` — самый чистый способ изоляции контекста, исключающий любые случайные мутации.

## Решение по шагам

1. Создадим цикл от 1 до 5.
2. Передадим `i` в параметры анонимной функции `func(id int)`.
3. Дождемся через `sync.WaitGroup`.
4. В `main` проверим результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup

	for i := 1; i <= 5; i++ {
		wg.Add(1)
		// Явная передача i в аргумент горутины
		go func(id int) {
			defer wg.Done()
			fmt.Printf("Обработан элемент с ID: %d\n", id)
		}(i)
	}

	wg.Wait()
	fmt.Println("Все элементы успешно обработаны")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Обработан элемент с ID: 5
# Обработан элемент с ID: 1
# Обработан элемент с ID: 2
# Обработан элемент с ID: 3
# Обработан элемент с ID: 4
# Все элементы успешно обработаны
```

## Под капотом

Аргументы горутины аллоцируются в кадре стека вызывающей функции и копируются на стек новой горутины в функции `runtime.newproc`.

## Подводные камни

Если передать в аргументы указатель `&i`, значение все равно останется разделяемым. Передавайте базовые типы по значению.

## На собеседовании

**Вопрос с собеседования:** «В какой момент вычисляются аргументы функции при вызове go fn(computeArg())?»
**Ответ:** Аргументы вычисляются **немедленно и синхронно** в текущей горутине до создания новой горутины. И только вычисленный результат передается в стек новой горутины.
