# Принудительное завершение горутин при выходе из главной функции main

## Условие

Напишите программу, где горутины работают бесконечно, но `main` завершается. Убедитесь, что при выходе из `main` все горутины принудительно убиваются (в Go нет способа "убить" горутину извне).

## Теория

В Go нет функции вроде `goroutine.Kill()` или `goroutine.Stop()`. Горутина может завершиться только сама (через `return`, возврат из функции или `runtime.Goexit()`). Единственный способ принудительно остановить горутину — завершить весь процесс через выход из `main()` или `os.Exit()`.

## Решение по шагам

1. Запустим бесконечный цикл в горутине.
2. Дадим программе поработать 50 мс.
3. Выйдем из `main()` и убедимся в мгновенном завершении процесса.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	// Фоновый бесконечный демон
	go func() {
		for {
			fmt.Println("[Daemon] Работаю в бесконечном цикле...")
			time.Sleep(10 * time.Millisecond)
		}
	}()

	time.Sleep(35 * time.Millisecond)
	fmt.Println("[Main] Завершение main() — все фоновые горутины немедленно уничтожаются")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Daemon] Работаю в бесконечном цикле...
# [Daemon] Работаю в бесконечном цикле...
# [Daemon] Работаю в бесконечном цикле...
# [Daemon] Работаю в бесконечном цикле...
# [Main] Завершение main() — все фоновые горутины немедленно уничтожаются
```

## Под капотом

Выход из `main()` вызывает системный вызов `exit_group(0)` в Linux, закрывая адресное пространство процесса.

## Подводные камни

В боевых сервисах всегда используйте паттерн Graceful Shutdown через `context.WithCancel` или каналы, чтобы фоновые горутины успевали корректно завершить работу.

## На собеседовании

**Вопрос с собеседования:** «Почему создатели Go намеренно не добавили API для принудительного убийства горутины (goroutine.Kill)?»
**Ответ:** Потому что внезапное убийство горутины извне оставляет разделяемые структуры данных (мьютексы, каналы, структуры памяти) в поврежденном, несогласованном состоянии. Горутина должна завершаться кооперативно.
