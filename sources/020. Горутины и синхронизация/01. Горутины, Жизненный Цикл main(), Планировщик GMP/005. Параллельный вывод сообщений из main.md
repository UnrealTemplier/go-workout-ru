# Параллельный вывод сообщений из main и фоновой горутины

## Условие

Запустите горутину, которая печатает «Hello from goroutine», а main продолжает выполняться и завершается через `time.Sleep`.

## Теория

Главная функция `main` и запущенная горутина работают конкурентно. Планировщик Go распределяет их кванты времени независимо.

## Решение по шагам

1. Напечатаем сообщение о старте `main`.
2. Запустим горутину с выводом «Hello from goroutine».
3. Напечатаем сообщение о продолжении работы `main`.
4. Завершим через `time.Sleep`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	fmt.Println("Main: старт работы")

	go func() {
		fmt.Println("Hello from goroutine")
	}()

	fmt.Println("Main: продолжаю выполнение")
	time.Sleep(20 * time.Millisecond)
	fmt.Println("Main: завершение")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Main: старт работы
# Main: продолжаю выполнение
# Hello from goroutine
# Main: завершение
```

## Под капотом

Планировщик Go выполняет переключение горутин в точках прерывания (preemption points): вызовы функций, системные вызовы ввода-вывода, аллокации памяти.

## Подводные камни

Порядок строк в консоли между горутиной и `main` не гарантирован спецификацией Go.

## На собеседовании

**Вопрос с собеседования:** «Сколько оперативной памяти потребляет 10 000 горутин в Go?»
**Ответ:** Около 20–30 МБ (по ~2 КБ на стек одной горутины + накладные расходы структуры `runtime.g`). В Java или C++ 10 000 потоков ОС потребовали бы от 10 до 80 ГБ памяти.
