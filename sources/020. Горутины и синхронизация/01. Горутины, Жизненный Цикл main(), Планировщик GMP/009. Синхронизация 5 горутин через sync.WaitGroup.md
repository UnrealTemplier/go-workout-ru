# Синхронизация 5 горутин через sync.WaitGroup без гонок завершения

## Условие

Объясните, почему без синхронизации горутина может не успеть выполниться. Исправьте с помощью `sync.WaitGroup`: запустите 5 горутин, каждая печатает свой индекс, дождитесь всех.

## Теория

Без примитивов синхронизации операционная система не знает о существовании параллельных задач в пространстве пользователя. `sync.WaitGroup` переводит поток `main` в спящий режим и пробуждает его ровно в момент, когда последний воркер вызовет `Done()`.

## Решение по шагам

1. Создадим `var wg sync.WaitGroup`.
2. Запустим 5 горутин, вызывая `wg.Add(1)` перед каждым запуском.
3. Внутри горутины вызовем `defer wg.Done()`.
4. В `main` вызовем `wg.Wait()`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup

	const totalWorkers = 5
	for i := 1; i <= totalWorkers; i++ {
		wg.Add(1)
		go func(idx int) {
			defer wg.Done()
			fmt.Printf("Горутина #%d выполнена\n", idx)
		}(i)
	}

	// Блокировка до завершения всех 5 горутин
	wg.Wait()
	fmt.Println("Синхронизация завершена: все 5 горутин отработали")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Горутина #1 выполнена
# Горутина #2 выполнена
# Горутина #3 выполнена
# Горутина #4 выполнена
# Горутина #5 выполнена
# Синхронизация завершена: все 5 горутин отработали
```

## Под капотом

Когда счетчик задач обнуляется, последний вызов `Done()` вызывает `runtime_Semrelease`, который пробуждает горутину, заблокированную на `Wait()`, переводя её в состояние `_Grunnable`.

## Подводные камни

Не вызывайте `wg.Add()` с отрицательными числами (кроме внутреннего механизма `Done()`), иначе произойдет паника `sync: negative WaitGroup counter`.

## На собеседовании

**Вопрос с собеседования:** «Можно ли повторно переиспользовать один и тот же экземпляр sync.WaitGroup?»
**Ответ:** Да, но только после того, как предыдущий вызов `wg.Wait()` полностью разблокировался и счетчик стал равен 0. Нельзя вызывать `Add()` параллельно с еще не завершившимся `Wait()`.
