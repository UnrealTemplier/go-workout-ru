# Асинхронный вызов sayHello() и гонка завершения main

## Условие

Запусти функцию `sayHello()` как горутину: `go sayHello()`. Покажи, что `main` завершается раньше, чем горутина успевает выполниться. Добавь `time.Sleep` как временное решение.

## Теория

Запуск функции `sayHello()` через `go` делает её выполнение асинхронным и неблокирующим по отношению к вызывающей функции.

## Решение по шагам

1. Создадим функцию `sayHello()`.
2. Вызовем `go sayHello()`.
3. Добавим `time.Sleep(100 * time.Millisecond)` в конце `main`.
4. Запустим и проверим результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func sayHello() {
	fmt.Println("Hello from async goroutine!")
}

func main() {
	go sayHello()

	// Без этой строки программа завершится без вывода
	time.Sleep(100 * time.Millisecond)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Hello from async goroutine!
```

## Под капотом

`time.Sleep` переводит главную горутину в состояние `gopark` (таймер рантайма), освобождая логический процессор P для выполнения горутины `sayHello`.

## Подводные камни

В юнит-тестах использование `time.Sleep` приводит к замедлению CI/CD и нестабильным (flaky) тестам.

## На собеседовании

**Вопрос с собеседования:** «Что происходит с горутиной во время time.Sleep?»
**Ответ:** Горутина снимается с выполнения (состояние `_Gwaiting`), освобождая поток OS (M) для других горутин. Рантайм заносит таймер в бинарную кучу квад-дерева таймеров `timers` процессора `P`.
