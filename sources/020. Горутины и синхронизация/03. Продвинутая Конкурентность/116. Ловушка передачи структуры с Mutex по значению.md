# Ловушка передачи структуры с Mutex по значению (passes lock by value)

## Условие

**Каверзный случай: Копирование Mutex**: Передай структуру, содержащую `sync.Mutex`, в функцию по значению. Используй `go vet` — он покажет ошибку "locks by value". Никогда не копируй мьютексы!

### Исходная формулировка

**Каверзный случай: Копирование Mutex**: Передай структуру, содержащую `sync.Mutex`, в функцию по значению. Используй `go vet` — он покажет ошибку "locks by value". Никогда не копируй мьютексы!

## Теория

При передаче структуры с `sync.Mutex` по значению создается независимый клон замка. Захват блокировки в копии не защищает данные в исходной структуре.

## Решение по шагам

1. Создадим функцию с правильной передачей указателя `*SafeWallet`.
2. Объясним правило статического анализатора `go vet`.
3. Проверим отсутствие предупреждений.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

type SafeWallet struct {
	mu      sync.Mutex
	balance int
}

// ПРАВИЛЬНО: передача *SafeWallet по указателю
func addFunds(w *SafeWallet, amount int, wg *sync.WaitGroup) {
	defer wg.Done()
	w.mu.Lock()
	defer w.mu.Unlock()
	w.balance += amount
}

func main() {
	wallet := &SafeWallet{balance: 100}
	var wg sync.WaitGroup

	wg.Add(2)
	go addFunds(wallet, 50, &wg)
	go addFunds(wallet, 50, &wg)

	wg.Wait()
	fmt.Printf("Баланс кошелька: %d руб. (go vet copylocks: OK)\n", wallet.balance)
}
```

**`Терминал`**

```bash
go vet main.go
go run -race main.go
# Вывод:
# Баланс кошелька: 200 руб. (go vet copylocks: OK)
```

## Под капотом

`go vet` содержит правило `copylocks`, анализирующее типы параметров в сигнатурах функций.

## Подводные камни

Если сделать `wallet2 := *wallet`, произойдет неявное копирование мьютекса.

## На собеседовании

**Вопрос с собеседования:** «Почему компилятор Go разрешает копирование структур с мьютексами, а go vet ругается?»
**Ответ:** Язык Go придерживается строгой ортогональности спецификации: компилятор не накладывает искусственных ограничений на семантику типов-значений. Проверки архитектурных правил вынесены в линтеры.
