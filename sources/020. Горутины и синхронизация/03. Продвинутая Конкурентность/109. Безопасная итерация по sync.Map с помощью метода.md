# Безопасная итерация по sync.Map с помощью метода Range

## Условие

**Обход `sync.Map`**: Используй метод `Range` для итерации по `sync.Map`. Обрати внимание, что он принимает callback-функцию.

## Теория

Метод `sm.Range(func(key, value any) bool)` выполняет последовательный обход элементов мапы. Если callback-функция возвращает `false`, итерация немедленно прекращается.

## Решение по шагам

1. Заполним `sync.Map` элементами.
2. Реализуем полный обход всех ключей.
3. Реализуем ранний выход при нахождении нужного элемента.
4. Проверим результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var sm sync.Map

	sm.Store("USD", 92.5)
	sm.Store("EUR", 99.8)
	sm.Store("CNY", 12.8)
	sm.Store("GBP", 118.2)

	// 1. Полный обход всех валют
	fmt.Println("=== 1. Полный список курсов валют ===")
	sm.Range(func(key, value any) bool {
		fmt.Printf("Валюта: %-4s = %.2f руб.\n", key.(string), value.(float64))
		return true // Продолжаем обход
	})

	// 2. Поиск с ранним выходом (break)
	fmt.Println("\n=== 2. Поиск первой валюты дороже 100 руб. ===")
	sm.Range(func(key, value any) bool {
		rate := value.(float64)
		if rate > 100.0 {
			fmt.Printf("Найдена дорогая валюта: %s (%.2f руб.) -> прерываем обход\n", key.(string), rate)
			return false // Прерываем итерацию
		}
		return true
	})
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# === 1. Полный список курсов валют ===
# Валюта: USD  = 92.50 руб.
# Валюта: EUR  = 99.80 руб.
# Валюта: CNY  = 12.80 руб.
# Валюта: GBP  = 118.20 руб.
# 
# === 2. Поиск первой валюты дороже 100 руб. ===
# Найдена дорогая валюта: GBP (118.20 руб.) -> прерываем обход
```

## Под капотом

Метод `Range` в `sync.Map` фиксирует снимок `read` мапы или выполняет промоушен `dirty` мапы перед обходом.

## Подводные камни

Метод `Range` не гарантирует консистентный моментальный снимок (Snapshot), если во время итерации другие горутины параллельно вызывают `Store`/`Delete`.

## На собеседовании

**Вопрос с собеседования:** «Какова временная сложность метода Range в sync.Map?»
**Ответ:** В лучшем случае \(O(N)\) по `read` мапе без блокировок. В худшем (если было много записей новых ключей) \(O(N)\) с захватом мьютекса для копирования `dirty` мапы в `read`.
