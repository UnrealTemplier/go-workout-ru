# Классический перекрестный дедлок (Deadlock) двух мьютексов A и B

## Условие

**Классический дедлок (Deadlock)**: Создайте две горутины и два мьютекса `A` и `B`. Напишите код так, чтобы первая горутина блокировала мьютекс `A` и пыталась заблокировать `B`, а вторая горутина в это же время блокировала мьютекс `B` и пыталась заблокировать `A`. Запустите код и проанализируйте панику планировщика.

## Теория

Перекрестный дедлок (Deadly Embrace / Circular Wait) — классическая ошибка конкурентного программирования. Горутина 1 удерживает A и ждет B. Горутина 2 удерживает B и ждет A. Ни одна не может продолжить работу.

## Решение по шагам

1. Создадим два мьютекса `muA` и `muB`.
2. В горутине 1 захватим `muA`, сделаем паузу и попытаемся захватить `muB`.
3. В горутине 2 захватим `muB`, сделаем паузу и попытаемся захватить `muA`.
4. Продемонстрируем обнаружение дедлока планировщиком.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

func main() {
	var muA, muB sync.Mutex
	var wg sync.WaitGroup

	wg.Add(2)

	// Горутина 1: захватывает A -> затем B
	go func() {
		defer wg.Done()
		muA.Lock()
		fmt.Println("[G1] Захватил Mutex A...")
		time.Sleep(10 * time.Millisecond)

		fmt.Println("[G1] Пытаюсь захватить Mutex B...")
		muB.Lock() // Зависнет навсегда
		muB.Unlock()
		muA.Unlock()
	}()

	// Горутина 2: захватывает B -> затем A
	go func() {
		defer wg.Done()
		muB.Lock()
		fmt.Println("[G2] Захватил Mutex B...")
		time.Sleep(10 * time.Millisecond)

		fmt.Println("[G2] Пытаюсь захватить Mutex A...")
		muA.Lock() // Зависнет навсегда
		muA.Unlock()
		muB.Unlock()
	}()

	wg.Wait()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [G1] Захватил Mutex A...
# [G2] Захватил Mutex B...
# [G1] Пытаюсь захватить Mutex B...
# [G2] Пытаюсь захватить Mutex A...
# fatal error: all goroutines are asleep - deadlock!
# 
# goroutine 7 [semacquire]:
# ...
# goroutine 8 [semacquire]:
# ...
```

## Под капотом

Планировщик фиксирует, что обе горутины находятся в состоянии `_Gwaiting` на семафорах друг друга.

## Подводные камни

Правило предотвращения дедлоков: всегда захватывайте несколько мьютексов в одном и том же глобальном порядке (Lock Ordering).

## На собеседовании

**Вопрос с собеседования:** «Каковы 4 условия возникновения дедлока Коффмана (Coffman Conditions) и как их предотвратить?»
**Ответ:** 1) Взаимное исключение, 2) Удержание и ожидание (Hold and Wait), 3) Отсутствие вытеснения (No Preemption), 4) Круговое ожидание (Circular Wait). В Go проще всего разрушить 4-е условие с помощью строгого порядка захвата мьютексов (Global Lock Ordering).
