# Параллельная обработка задач с обработкой первой ошибки через errgroup

## Условие

Используйте пакет `golang.org/x/sync/errgroup`. Запустите группу горутин, которые могут вернуть ошибку.

## Теория

`errgroup.Group` позволяет запускать набор горутин `g.Go(fn)` и собирать первую возвращенную ошибку в `g.Wait()`.

## Решение по шагам

1. Создадим структуру `ErrGroup`.
2. Запустим 3 горутины, одна из которых вернет ошибку.
3. Дождемся завершения в `g.Wait()`.
4. Проверим перехват ошибки.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
	"sync"
	"time"
)

type MinimalErrGroup struct {
	wg   sync.WaitGroup
	once sync.Once
	err  error
}

func (g *MinimalErrGroup) Go(fn func() error) {
	g.wg.Add(1)
	go func() {
		defer g.wg.Done()
		if err := fn(); err != nil {
			g.once.Do(func() {
				g.err = err
			})
		}
	}()
}

func (g *MinimalErrGroup) Wait() error {
	g.wg.Wait()
	return g.err
}

func main() {
	var g MinimalErrGroup

	g.Go(func() error {
		time.Sleep(10 * time.Millisecond)
		return nil
	})

	g.Go(func() error {
		time.Sleep(15 * time.Millisecond)
		return errors.New("ошибка валидации данных пользователя")
	})

	g.Go(func() error {
		time.Sleep(20 * time.Millisecond)
		return nil
	})

	if err := g.Wait(); err != nil {
		fmt.Printf("Перехвачена ошибка группы горутин: %v\n", err)
	} else {
		fmt.Println("Все задачи завершились успешно")
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Перехвачена ошибка группы горутин: ошибка валидации данных пользователя
```

## Под капотом

`g.Wait()` ожидает завершения всех горутин группы и возвращает сохраненную в `once` ошибку.

## Подводные камни

Даже если одна горутина вернула ошибку, `g.Wait()` дожидается завершения остальных горутин группы.

## На собеседовании

**Вопрос с собеседования:** «Какую ошибку вернет errgroup.Wait(), если ошибки вернули сразу несколько горутин?»
**Ответ:** Строго **первую** по времени возврата ошибку, зафиксированную через внутренний `sync.Once`.
