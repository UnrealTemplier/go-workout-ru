# Пул тяжелых структур с фабричной функцией New в sync.Pool

## Условие

**Повторное использование с `sync.Pool`**: Создай пул тяжелых структур `pool := &sync.Pool{ New: func() any { return new(HeavyObject) } }`. Забирай объекты `pool.Get()`, работай с ними и возвращай `pool.Put()`.

## Теория

Фабричная функция `New` вызывается автоматически, когда в пуле нет доступных свободных объектов. Метод `Put(obj)` возвращает память в пул для последующих запросов.

## Решение по шагам

1. Создадим тяжелую структуру `WorkerContext`.
2. Создадим `var contextPool sync.Pool`.
3. В горутине запросим объект через `pool.Get()`.
4. Очистим и вернем через `defer pool.Put()`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

type HeavyContext struct {
	Scratchpad [16 * 1024]byte
	RequestID  string
}

func (h *HeavyContext) Reset() {
	h.RequestID = ""
}

var ctxPool = sync.Pool{
	New: func() any {
		return new(HeavyContext)
	},
}

func handleRequest(reqID string) {
	ctx := ctxPool.Get().(*HeavyContext)
	ctx.Reset()
	defer ctxPool.Put(ctx)

	ctx.RequestID = reqID
	ctx.Scratchpad[0] = 0xFF
	fmt.Printf("[Handler] Обработан запрос: %s\n", ctx.RequestID)
}

func main() {
	var wg sync.WaitGroup
	const total = 3
	wg.Add(total)

	for i := 1; i <= total; i++ {
		go func(id int) {
			defer wg.Done()
			handleRequest(fmt.Sprintf("req_id_%d", id))
		}(i)
	}

	wg.Wait()
	fmt.Println("Обработка через sync.Pool завершена успешно!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Handler] Обработан запрос: req_id_3
# [Handler] Обработан запрос: req_id_1
# [Handler] Обработан запрос: req_id_2
# Обработка через sync.Pool завершена успешно!
```

## Под капотом

`sync.Pool` локализует объекты по потокам P, снижая конкуренцию на глобальной блокировке.

## Подводные камни

Обязательно очищайте поля `Reset()` перед использованием.

## На собеседовании

**Вопрос с собеседования:** «Почему в New функции sync.Pool возвращают указатель new(T), а не значение T?»
**Ответ:** Потому что возврат значения приводит к боксингу в `any` (Heap Allocation на каждый `Get`/`Put`), сводя на нет всю пользу от пулинга. Указатель передается по ссылке без скрытых аллокаций.
