# Синхронный старт пула из 10 воркеров через sync.Cond и Broadcast()

## Условие

**Условные переменные (`sync.Cond`)**: Создай `cond := sync.NewCond(&sync.Mutex{})`. 10 воркеров вызывают `cond.Wait()` (ожидая старта). В `main` вызови `cond.Broadcast()`, чтобы мгновенно разбудить их всех.

## Теория

`cond.Broadcast()` — самый быстрый способ одновременного старта группы из N горутин после завершения фазы инициализации.

## Решение по шагам

1. Создадим `var mu sync.Mutex` и `cond := sync.NewCond(&mu)`.
2. Запустим 10 воркеров с ожиданием `for !started { cond.Wait() }`.
3. В `main` установим `started = true` и вызовем `cond.Broadcast()`.
4. Дождемся завершения через `sync.WaitGroup`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

func main() {
	var mu sync.Mutex
	cond := sync.NewCond(&mu)
	started := false

	var wg sync.WaitGroup
	const totalWorkers = 5

	for i := 1; i <= totalWorkers; i++ {
		wg.Add(1)
		go func(id int) {
			defer wg.Done()

			mu.Lock()
			for !started {
				cond.Wait()
			}
			mu.Unlock()

			fmt.Printf("[Воркер #%d] Мгновенно проснулся по Broadcast!\n", id)
		}(i)
	}

	time.Sleep(20 * time.Millisecond)

	mu.Lock()
	fmt.Println("[Main] Подготовка завершена. Отправка сигнала Broadcast()...\n")
	started = true
	cond.Broadcast()
	mu.Unlock()

	wg.Wait()
	fmt.Println("\n[Main] Все воркеры успешно завершили работу!")
}
```

## Под капотом

`Broadcast()` перемещает все горутины из очереди условной переменной в очередь связанного мьютекса.

## Подводные камни

Обязательно освобождайте мьютекс `mu.Unlock()` сразу после выхода из цикла ожидания `cond.Wait()`.

## На собеседовании

**Вопрос с собеседования:** «В каком порядке просыпаются горутины при вызове cond.Broadcast()?»
**Ответ:** Порядок пробуждения и захвата мьютекса не детерминирован и зависит от очередности планировщика Go.
