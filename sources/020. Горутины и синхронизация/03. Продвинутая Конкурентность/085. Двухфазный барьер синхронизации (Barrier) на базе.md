# Двухфазный барьер синхронизации (Barrier) на базе двух sync.WaitGroup

## Условие

Реализуй **barrier** на `sync.WaitGroup`: N горутин должны достичь точки, прежде чем все продолжат. Используй `sync.WaitGroup` дважды: первый — достижение барьера, второй — завершение.

## Теория

Двухфазный барьер на `sync.WaitGroup` делит выполнение на 2 четких этапа:
1. Фаза 1 (Сбор участников): все N горутин выполняют подготовку и вызывают `firstPhase.Done()`. Главный поток ждет `firstPhase.Wait()`.
2. Фаза 2 (Синхронный старт): главный поток дает сигнал старта через канал или вторую фазу `secondPhase.Wait()`.

## Решение по шагам

1. Создадим `var reachBarrier sync.WaitGroup` и `var finishWork sync.WaitGroup`.
2. Запустим 3 воркера.
3. Дождемся сбора всех на барьере.
4. Дождемся окончательного завершения.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

func main() {
	const total = 3
	var reachBarrier sync.WaitGroup
	var finishWork sync.WaitGroup
	startSignal := make(chan struct{}) // Канал синхронного старта

	reachBarrier.Add(total)
	finishWork.Add(total)

	for i := 1; i <= total; i++ {
		go func(id int) {
			defer finishWork.Done()

			// 1. Фаза подготовки
			time.Sleep(time.Duration(id*10) * time.Millisecond)
			fmt.Printf("[Воркер #%d] Достиг точки барьера (готов к старту)\n", id)
			reachBarrier.Done() // Сообщаем о достижении барьера

			// Ждем команды общего одновременного старта
			<-startSignal

			// 2. Фаза параллельной работы
			fmt.Printf(" -> [Воркер #%d] СТАРТОВАЛ одновременный забег!\n", id)
		}(i)
	}

	// Ждем, пока ВСЕ 3 воркера дойдут до барьера
	reachBarrier.Wait()
	fmt.Println("\n[Main] Все 3 воркера на стартовой позиции! Даем общий сигнал старта (close channel)...")
	close(startSignal) // Мгновенно разблокирует всех читателей

	// Ждем окончания работы
	finishWork.Wait()
	fmt.Println("[Main] Все воркеры успешно финишировали!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Воркер #1] Достиг точки барьера (готов к старту)
# [Воркер #2] Достиг точки барьера (готов к старту)
# [Воркер #3] Достиг точки барьера (готов к старту)
# 
# [Main] Все 3 воркера на стартовой позиции! Даем общий сигнал старта (close channel)...
#  -> [Воркер #3] СТАРТОВАЛ одновременный забег!
#  -> [Воркер #1] СТАРТОВАЛ одновременный забег!
#  -> [Воркер #2] СТАРТОВАЛ одновременный забег!
# [Main] Все воркеры успешно финишировали!
```

## Под капотом

Закрытие канала `close(startSignal)` транслируется в пробуждение всех горутин из очереди `recvq` канала за \(O(N)\) времени.

## Подводные камни

Не отправляйте значения в канал `startSignal <- struct{}{}` в цикле — используйте `close(ch)`, так как закрытый канал моментально отдает нулевые значения всем горутинам одновременно.

## На собеседовании

**Вопрос с собеседования:** «Как мгновенно разбудить 10 000 горутин одновременно одной операцией?»
**Ответ:** Закрыть пустой сигнальный канал: `close(readyChan)`. Операция закрытия канала делает его моментально доступным для неблокирующего чтения всем горутинам без очередей.
