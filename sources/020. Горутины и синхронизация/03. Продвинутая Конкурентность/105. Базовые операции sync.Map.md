# Базовые операции sync.Map: Store, Load, LoadOrStore и Delete

## Условие

**Базовый `sync.Map`**: Когда нужна конкурентная мапа (много горутин читают и пишут), используй `sync.Map`. Попробуй методы `Store`, `Load`, `LoadOrStore` и `Delete`.

## Теория

Практикум по всем 4 ключевым методам `sync.Map`:
1. `Store(key, value)` — сохранить пару ключ-значение.
2. `Load(key)` — прочитать значение.
3. `LoadOrStore(key, value)` — атомарно вернуть старое или записать новое.
4. `Delete(key)` — удалить ключ.

## Решение по шагам

1. Создадим `var m sync.Map`.
2. Продемонстрируем `Store` и `Load`.
3. Продемонстрируем работу `LoadOrStore`.
4. Продемонстрируем `Delete`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var m sync.Map

	// 1. Store & Load
	m.Store("server_name", "app-backend-01")
	val, ok := m.Load("server_name")
	fmt.Printf("1. Load: val=%v, ok=%v\n", val, ok)

	// 2. LoadOrStore (ключ уже есть -> вернет старое значение, loaded = true)
	actual1, loaded1 := m.LoadOrStore("server_name", "NEW_NAME")
	fmt.Printf("2. LoadOrStore (существующий): actual=%v, loaded=%v\n", actual1, loaded1)

	// 3. LoadOrStore (ключа нет -> запишет новое, loaded = false)
	actual2, loaded2 := m.LoadOrStore("port", 8080)
	fmt.Printf("3. LoadOrStore (новый): actual=%v, loaded=%v\n", actual2, loaded2)

	// 4. Delete
	m.Delete("server_name")
	_, exists := m.Load("server_name")
	fmt.Printf("4. После Delete('server_name'): exists=%v\n", exists)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# 1. Load: val=app-backend-01, ok=true
# 2. LoadOrStore (существующий): actual=app-backend-01, loaded=true
# 3. LoadOrStore (новый): actual=8080, loaded=false
# 4. После Delete('server_name'): exists=false
```

## Под капотом

`LoadOrStore` использует атомарные указатели на структуру `entry`, исключая дублирование записи.

## Подводные камни

В Go 1.20+ добавлены методы `Swap` и `CompareAndSwap` для `sync.Map`.

## На собеседовании

**Вопрос с собеседования:** «Что делает метод m.CompareAndDelete(key, oldVal) в sync.Map (Go 1.20+)?»
**Ответ:** Атомарно удаляет запись по ключу `key` только в том случае, если её текущее значение равно `oldVal`.
