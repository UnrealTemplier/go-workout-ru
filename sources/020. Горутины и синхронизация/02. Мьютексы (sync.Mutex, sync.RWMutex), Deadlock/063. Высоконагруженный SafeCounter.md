# Высоконагруженный SafeCounter: 1000 горутин по 1000 операций

## Условие

Реализуй `SafeCounter` с `sync.Mutex`. Методы: `Inc()`, `Dec()`, `Value() int`. Запусти 1000 горутин, каждая инкрементирует 1000 раз. Проверь через `-race`, что гонок нет.

## Теория

Тестирование структуры под экстремальной конкуренцией (1 000 000 операций) подтверждает абсолютную надежность механизма `sync.Mutex`.

## Решение по шагам

1. Создадим структуру `SafeCounter`.
2. Реализуем методы `Inc()`, `Dec()`, `Value() int`.
3. Запустим 1000 горутин по 1000 инкрементов (всего \(1\,000\,000\) операций).
4. Проверим точный результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

type SafeCounter struct {
	mu    sync.Mutex
	value int
}

func (c *SafeCounter) Inc() {
	c.mu.Lock()
	c.value++
	c.mu.Unlock()
}

func (c *SafeCounter) Dec() {
	c.mu.Lock()
	c.value--
	c.mu.Unlock()
}

func (c *SafeCounter) Value() int {
	c.mu.Lock()
	defer c.mu.Unlock()
	return c.value
}

func main() {
	counter := &SafeCounter{}
	var wg sync.WaitGroup

	const goroutines = 1000
	const opsPerGoroutine = 1000
	wg.Add(goroutines)

	for i := 0; i < goroutines; i++ {
		go func() {
			defer wg.Done()
			for j := 0; j < opsPerGoroutine; j++ {
				counter.Inc()
			}
		}()
	}

	wg.Wait()
	fmt.Printf("Итоговое значение SafeCounter: %d (из %d)\n", counter.Value(), goroutines*opsPerGoroutine)
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# Итоговое значение SafeCounter: 1000000 (из 1000000)
```

## Под капотом

Для коротких критических секций `Inc()` прямой вызов `mu.Unlock()` без `defer` работает на доли наносекунд быстрее в горячих циклах.

## Подводные камни

При 1M операциях мьютекс создает высокую конкуренцию (contention). В реальных HighLoad счетчиках применяют `atomic` или Sharded Counters.

## На собеседовании

**Вопрос с собеседования:** «Что такое Sharded Counter (Striped Mutex) и зачем он нужен?»
**Ответ:** Это массив из N независимых счетчиков (например, по числу ядер CPU). Каждая горутина инкрементирует счетчик `shard[hash % N]`, снижая конкуренцию на шине памяти почти до нуля. Итоговая сумма вычисляется суммированием всех шардов.
