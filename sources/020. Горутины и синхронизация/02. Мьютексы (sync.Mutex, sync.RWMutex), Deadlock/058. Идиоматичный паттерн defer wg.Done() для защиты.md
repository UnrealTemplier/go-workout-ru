# Идиоматичный паттерн defer wg.Done() для защиты от паник и ранних выходов

## Условие

**Анонимные функции и defer**: Используй `defer wg.Done()` внутри горутины (сразу после её начала) — это стандартный паттерн, гарантирующий, что счетчик уменьшится даже при панике внутри горутины.

## Теория

Размещение `defer wg.Done()` в первой строке тела горутины гарантирует выполнение декремента счетчика при любом исходе: успешном завершении, возврате по ошибке (`return err`) или неперехваченной панике.

## Решение по шагам

1. Создадим `var wg sync.WaitGroup`.
2. Запустим горутину с условием раннего выхода.
3. Убедимся, что `defer wg.Done()` сработал при раннем `return`.
4. Дождемся завершения в `main`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func processTask(id int, wg *sync.WaitGroup) {
	// 1. Первая строка горутины — регистрация defer Done
	defer wg.Done()

	if id == 2 {
		fmt.Printf("[Task #%d] Ранний возврат из-за ошибки валидации\n", id)
		return // defer wg.Done() все равно выполнится!
	}

	fmt.Printf("[Task #%d] Полная обработка успешно выполнена\n", id)
}

func main() {
	var wg sync.WaitGroup

	for i := 1; i <= 3; i++ {
		wg.Add(1)
		go processTask(i, &wg)
	}

	wg.Wait()
	fmt.Println("Все задачи корректно обработаны без зависаний!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Task #1] Полная обработка успешно выполнена
# [Task #2] Ранний возврат из-за ошибки валидации
# [Task #3] Полная обработка успешно выполнена
# Все задачи корректно обработаны без зависаний!
```

## Под капотом

Стек вызовов `defer` привязан к структуре `g._defer` текущей горутины и выполняется перед возвратом управления.

## Подводные камни

Если написать `wg.Done()` в самом конце функции без `defer`, любой `return` в середине приведет к вечному дедлоку `wg.Wait()`.

## На собеседовании

**Вопрос с собеседования:** «Почему defer wg.Done() считается идиоматичнее ручного вызова?»
**Ответ:** Потому что в сложных функциях с десятками ветвлений `if err != nil` легко забыть вызов `wg.Done()` в одной из веток, что приведет к скрытому дедлоку.
