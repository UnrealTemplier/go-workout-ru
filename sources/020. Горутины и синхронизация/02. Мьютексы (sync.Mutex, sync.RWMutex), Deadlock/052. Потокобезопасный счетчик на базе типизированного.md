# Потокобезопасный счетчик на базе типизированного atomic.Int64

## Условие

Реализуйте потокобезопасный счетчик (структуру `Counter` с методами `Inc()`, `Dec()`, `Val()`), используя внутри `atomic`.

## Теория

Начиная с Go 1.19, в пакете `sync/atomic` появились удобные типизированные обертки: `atomic.Int64`, `atomic.Uint64`, `atomic.Bool`, `atomic.Pointer[T]`. Они инкапсулируют выравнивание памяти и предоставляют удобные методы `Add`, `Load`, `Store`.

## Решение по шагам

1. Создадим структуру `AtomicCounter struct { val atomic.Int64 }`.
2. Реализуем методы `Inc()`, `Dec()`, `Val() int64`.
3. Запустим конкурентные инкременты и декременты.
4. Проверим точный баланс.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"sync/atomic"
)

type AtomicCounter struct {
	val atomic.Int64 // Go 1.19+ типизированный атомик
}

func (c *AtomicCounter) Inc() int64 {
	return c.val.Add(1)
}

func (c *AtomicCounter) Dec() int64 {
	return c.val.Add(-1)
}

func (c *AtomicCounter) Val() int64 {
	return c.val.Load()
}

func main() {
	counter := &AtomicCounter{}
	var wg sync.WaitGroup

	const ops = 500
	wg.Add(ops * 2)

	// 500 инкрементов
	for i := 0; i < ops; i++ {
		go func() {
			defer wg.Done()
			counter.Inc()
		}()
	}

	// 500 декрементов
	for i := 0; i < ops; i++ {
		go func() {
			defer wg.Done()
			counter.Dec()
		}()
	}

	wg.Wait()
	fmt.Printf("Итоговое значение счетчика (+500 -500): %d\n", counter.Val())
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# Итоговое значение счетчика (+500 -500): 0
```

## Под капотом

`atomic.Int64` гарантирует 8-байтное выравнивание в памяти даже на 32-битных архитектурах (ARM32/x86), защищая от паник unaligned 64-bit atomic.

## Подводные камни

Структуры, содержащие `atomic.Int64`, нельзя копировать по значению (`noCopy`).

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество atomic.Int64 перед старым atomic.AddInt64(&val, 1)?»
**Ответ:** 1) Повышение типобезопасности и читаемости API. 2) Автоматическое 64-битное выравнивание памяти в структуре (на 32-битных платформах старый `atomic.AddInt64` падал с SIGSEGV при невыровненном адресе).
