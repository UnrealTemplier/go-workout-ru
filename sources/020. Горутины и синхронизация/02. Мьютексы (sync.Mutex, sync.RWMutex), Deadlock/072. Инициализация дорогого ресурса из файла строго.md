# Инициализация дорогого ресурса из файла строго один раз через sync.Once

## Условие

`sync.Once`: инициализация дорогого ресурса (например, чтение конфигурации из файла) только один раз при конкурентных вызовах.

## Теория

`sync.Once` обеспечивает строгую линеаризацию: даже если 100 горутин одновременно обращаются к методу инициализации, чтение файла произойдет ровно 1 раз, а остальные 99 горутин дождутся завершения чтения и безопасно получат готовый результат.

## Решение по шагам

1. Создадим структуру `CertStore`.
2. Реализуем метод `LoadCertificates()` с `sync.Once`.
3. Смоделируем обращение 10 параллельных клиентов.
4. Убедимся, что загрузка файла произошла единожды.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

type TLSManager struct {
	once      sync.Once
	certChain string
}

func (m *TLSManager) GetCertificate() string {
	m.once.Do(func() {
		fmt.Println("[DISK I/O] Чтение тяжелых TLS-сертификатов с диска...")
		time.Sleep(30 * time.Millisecond) // Дорогой парсинг x509
		m.certChain = "BEGIN CERTIFICATE: RSA 4096 VALID"
	})
	return m.certChain
}

func main() {
	manager := &TLSManager{}
	var wg sync.WaitGroup

	const clients = 5
	wg.Add(clients)

	for i := 1; i <= clients; i++ {
		go func(id int) {
			defer wg.Done()
			cert := manager.GetCertificate()
			fmt.Printf("[Клиент #%d] Сертификат получен: %s\n", id, cert)
		}(i)
	}

	wg.Wait()
	fmt.Println("Инициализация TLS успешно завершена!")
}
```

## Под капотом

`sync.Once` содержит барьер памяти `atomic.StoreUint32(&o.done, 1)`, гарантируя видимость всех полей структуры `TLSManager` всем ядрам CPU.

## Подводные камни

Не вызывайте `m.GetCertificate()` рекурсивно внутри замыкания `once.Do` — это приведет к дедлоку.

## На собеседовании

**Вопрос с собеседования:** «Что будет, если вызвать once.Do внутри другого once.Do для того же самого объекта once?»
**Ответ:** Произойдет классический дедлок (Deadlock), так как внутренний вызов `once.Do` попытается захватить мьютекс `o.m`, уже удерживаемый внешним вызовом `once.Do`.
