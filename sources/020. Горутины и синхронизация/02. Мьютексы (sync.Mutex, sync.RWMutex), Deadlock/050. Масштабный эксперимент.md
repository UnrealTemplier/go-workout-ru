# Масштабный эксперимент: 1000 горутин, гонка данных и отчет go run -race

## Условие

**Состояние гонки (Race Condition)**: Создайте глобальную переменную `counter := 0`. Запустите 1000 горутин, каждая из которых инкрементирует счетчик: `counter++`. Дождитесь завершения всех горутин через `WaitGroup` и выведите `counter`. Почему результат почти никогда не равен 1000? Запустите компиляцию программы с флагом обнаружения гонок: `go run -race main.go` и изучите отчет.

## Теория

При параллельном выполнении 1000 горутин множество процессорных ядер перезаписывают регистры друг друга, приводя к потере десятков или сотен операций инкремента.

## Решение по шагам

1. Создадим глобальную переменную `counter := 0`.
2. Запустим 1000 горутин с `counter++`.
3. Дождемся всех через `sync.WaitGroup`.
4. Запустим с `-race` и зафиксируем потерю данных.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

var counter int

func main() {
	var wg sync.WaitGroup
	const total = 1000
	wg.Add(total)

	for i := 0; i < total; i++ {
		go func() {
			defer wg.Done()
			counter++ // Незащищенная запись
		}()
	}

	wg.Wait()
	fmt.Printf("Фактическое значение counter: %d (из 1000 ожидаемых)\n", counter)
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод детектора гонок:
# WARNING: DATA RACE
# Write at 0x... by goroutine ...
# Previous write at 0x... by goroutine ...
# Фактическое значение counter: 942 (из 1000 ожидаемых)
```

## Под капотом

Инструкция `INC [mem]` в x86_64 без префикса `LOCK` не гарантирует атомарности шины памяти при одновременном обращении с нескольких ядер.

## Подводные камни

В архитектурах ARM64 (Apple Silicon, AWS Graviton) эффект гонок данных выражен еще сильнее из-за слабой модели памяти (Weak Memory Model).

## На собеседовании

**Вопрос с собеседования:** «Почему счетчик равен, например, 942, а не 1000?»
**Ответ:** Потому что несколько горутин на разных ядрах CPU одновременно прочитали одно и то же значение (например, 50), локально увеличили до 51 и записали обратно в память 51, затерев инкременты друг друга.
