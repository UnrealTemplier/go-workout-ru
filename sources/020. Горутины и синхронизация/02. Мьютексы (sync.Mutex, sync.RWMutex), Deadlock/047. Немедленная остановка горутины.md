# Немедленная остановка горутины через runtime.Goexit с сохранением defer

## Условие

Используй `runtime.Goexit()` внутри горутины для её немедленной остановки. Добавь `defer` до вызова `Goexit` и убедись, что он выполняется.

## Теория

`runtime.Goexit()` немедленно прерывает выполнение текущей горутины. При этом рантайм гарантированно выполняет все зарегистрированные функции `defer` в порядке LIFO. Другие горутины продолжают работать без сбоев.

## Решение по шагам

1. Запустим горутину с `defer wg.Done()` и `defer fmt.Println(...)`.
2. Вызовем `runtime.Goexit()`.
3. Убедимся, что код после `Goexit` не выполнился, а все `defer` отработали.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"runtime"
	"sync"
)

func workerWithExit(wg *sync.WaitGroup) {
	defer wg.Done()
	defer fmt.Println("1. [DEFER] Этот defer выполнился гарантированно!")

	fmt.Println("2. Старт работы воркера...")
	fmt.Println("3. Немедленное завершение горутины через runtime.Goexit()...")

	runtime.Goexit()

	// Этот код никогда не выполнится
	fmt.Println("4. ЭТА СТРОКА НЕ БУДЕТ НАПЕЧАТАНА")
}

func main() {
	var wg sync.WaitGroup
	wg.Add(1)

	go workerWithExit(&wg)

	wg.Wait()
	fmt.Println("5. Главная программа завершилась чисто")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# 2. Старт работы воркера...
# 3. Немедленное завершение горутины через runtime.Goexit()...
# 1. [DEFER] Этот defer выполнился гарантированно!
# 5. Главная программа завершилась чисто
```

## Под капотом

`runtime.Goexit()` раскручивает стек горутины, исполняя `g._defer`, и переводит структуру `g` в состояние `_Gdead` без паники.

## Подводные камни

Если вызвать `runtime.Goexit()` в главной горутине `main()`, рантайм Go завершит `main`, но позволит остальным горутинам работать до дедлока.

## На собеседовании

**Вопрос с собеседования:** «Что произойдет, если вызвать runtime.Goexit() в главной горутине, когда фоновых горутин нет?»
**Ответ:** Произойдет фатальная ошибка рантайма: `fatal error: no goroutines (main called runtime.Goexit) - deadlock!`.
