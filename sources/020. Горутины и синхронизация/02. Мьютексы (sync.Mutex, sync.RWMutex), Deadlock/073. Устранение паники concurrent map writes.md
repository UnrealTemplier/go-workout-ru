# Устранение паники concurrent map writes: переход 50 горутин на sync.Map

## Условие

**Потокобезопасная мапа (`sync.Map`)**: Напишите программу, где 50 горутин параллельно пишут и читают данные из одной мапы. Обычная мапа упадет с паникой `concurrent map writes`. Решите эту проблему с помощью встроенной структуры `sync.Map` и её методов `Store`, `Load` и `Delete`.

## Теория

Обычная мапа в Go не содержит встроенных средств синхронизации. При параллельной записи двух горутин рантайм вызывает аварийное падение приложения `fatal error: concurrent map writes`. `sync.Map` решает эту проблему "из коробки".

## Решение по шагам

1. Создадим `var sm sync.Map`.
2. Запустим 50 горутин, одновременно выполняющих `Store`, `Load` и `Delete`.
3. Дождемся завершения всех горутин через `sync.WaitGroup`.
4. Убедимся в абсолютной стабильности под флагом `-race`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var sm sync.Map
	var wg sync.WaitGroup

	const totalWorkers = 50
	wg.Add(totalWorkers)

	for i := 0; i < totalWorkers; i++ {
		go func(id int) {
			defer wg.Done()

			// 1. Запись
			key := fmt.Sprintf("session:%d", id%10)
			sm.Store(key, id*10)

			// 2. Чтение
			_, _ = sm.Load(key)

			// 3. Удаление
			if id%5 == 0 {
				sm.Delete(key)
			}
		}(i)
	}

	wg.Wait()
	fmt.Println("Все 50 горутин успешно выполнили параллельные операции над sync.Map без сбоев!")
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# Все 50 горутин успешно выполнили параллельные операции над sync.Map без сбоев!
```

## Под капотом

Метод `Store` обновляет существующий ключ lock-free, если он уже присутствует в `read` мапе и не помечен как `expunged`.

## Подводные камни

В `sync.Map` метод `LoadOrStore(key, val)` атомарен: он возвращает существующее значение, если ключ был, или сохраняет переданное, исключая гонки повторной инициализации.

## На собеседовании

**Вопрос с собеседования:** «Что делает метод LoadOrStore в sync.Map?»
**Ответ:** Атомарно загружает существующее значение для ключа или сохраняет переданное, если ключа не было. Возвращает `(actual any, loaded bool)`, где `loaded == true` означает, что значение уже присутствовало в мапе.
