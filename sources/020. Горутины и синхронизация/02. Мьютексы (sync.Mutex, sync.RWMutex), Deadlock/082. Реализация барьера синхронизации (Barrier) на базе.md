# Реализация барьера синхронизации (Barrier) на базе sync.Cond

## Условие

Используй `sync.Cond` (условная переменная): создай `sync.Cond` с `sync.Mutex`. Одна горутина ждёт `cond.Wait()`, пока другая не вызовет `cond.Signal()` или `cond.Broadcast()`. Реализуй "очередь ожидания" или "barrier".

## Теория

Барьер синхронизации (Barrier) — примитив многопоточности, удерживающий группу из N горутин до тех пор, пока абсолютно все участники группы не достигнут контрольной точки.

## Решение по шагам

1. Создадим структуру `Barrier struct { mu sync.Mutex; cond *sync.Cond; count int; total int }`.
2. Реализуем метод `Wait()`, который увеличивает `count` и засыпает на `cond.Wait()`, если `count < total`.
3. Когда `count == total`, последний участник вызывает `cond.Broadcast()`.
4. Запустим 3 воркера и проверим одновременный старт.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

type Barrier struct {
	mu      sync.Mutex
	cond    *sync.Cond
	count   int
	total   int
	barrier bool
}

func NewBarrier(total int) *Barrier {
	b := &Barrier{total: total}
	b.cond = sync.NewCond(&b.mu)
	return b
}

func (b *Barrier) Await(workerID int) {
	b.mu.Lock()
	defer b.mu.Unlock()

	b.count++
	if b.count == b.total {
		fmt.Printf("[Worker #%d] Последний участник достиг барьера! Пробуждение всех...\n\n", workerID)
		b.barrier = true
		b.cond.Broadcast() // Пробуждаем всех
	} else {
		fmt.Printf("[Worker #%d] Достиг барьера (%d/%d), ожидаю остальных...\n", workerID, b.count, b.total)
		for !b.barrier {
			b.cond.Wait()
		}
	}
}

func main() {
	const totalParticipants = 3
	barrier := NewBarrier(totalParticipants)
	var wg sync.WaitGroup

	for i := 1; i <= totalParticipants; i++ {
		wg.Add(1)
		go func(id int) {
			defer wg.Done()
			time.Sleep(time.Duration(id*10) * time.Millisecond)
			barrier.Await(id)
			fmt.Printf(" -> [Worker #%d] Продолжил параллельное выполнение после барьера!\n", id)
		}(i)
	}

	wg.Wait()
	fmt.Println("\nВсе воркеры успешно преодолели барьер!")
}
```

## Под капотом

`b.cond.Broadcast()` переводит все ожидающие горутины из `notifyList` в очередь выполнения планировщика.

## Подводные камни

Для многократного прохождения барьера несколькими фазами требуется сбрасывать `count = 0` и `barrier = false` (CyclicBarrier).
