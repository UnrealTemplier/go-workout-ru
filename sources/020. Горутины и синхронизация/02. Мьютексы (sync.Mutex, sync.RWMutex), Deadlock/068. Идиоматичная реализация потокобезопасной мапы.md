# Идиоматичная реализация потокобезопасной мапы с методами Get, Set и Delete

## Условие

`sync.RWMutex`: `SafeMap` с методами `Get`, `Set`, `Delete`. Много читателей могут читать одновременно, писатель эксклюзивно.

## Теория

Шаблон разделяемого доступа к ресурсу: параллельные читатели и монопольный доступ писателя.

## Решение по шагам

1. Создадим структуру `ConcurrentStorage`.
2. Реализуем `Get(k string) (string, bool)`, `Set(k, v string)`, `Delete(k string)`.
3. Запустим сценарий с 10 читателями и 1 писателем.
4. Проверим согласованность данных.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

type ConcurrentStorage struct {
	mu    sync.RWMutex
	store map[string]string
}

func NewConcurrentStorage() *ConcurrentStorage {
	return &ConcurrentStorage{store: make(map[string]string)}
}

func (s *ConcurrentStorage) Get(key string) (string, bool) {
	s.mu.RLock()
	defer s.mu.RUnlock()
	val, ok := s.store[key]
	return val, ok
}

func (s *ConcurrentStorage) Set(key, value string) {
	s.mu.Lock()
	defer s.mu.Unlock()
	s.store[key] = value
}

func (s *ConcurrentStorage) Delete(key string) {
	s.mu.Lock()
	defer s.mu.Unlock()
	delete(s.store, key)
}

func main() {
	storage := NewConcurrentStorage()
	storage.Set("status", "healthy")

	var wg sync.WaitGroup
	wg.Add(4)

	// Читатели
	for i := 1; i <= 3; i++ {
		go func(id int) {
			defer wg.Done()
			val, _ := storage.Get("status")
			fmt.Printf("[Reader %d] status = %s\n", id, val)
		}(i)
	}

	// Писатель
	go func() {
		defer wg.Done()
		time.Sleep(5 * time.Millisecond)
		storage.Set("status", "maintenance")
	}()

	wg.Wait()
	finalStatus, _ := storage.Get("status")
	fmt.Printf("Финальный статус в хранилище: %s\n", finalStatus)
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# [Reader 1] status = healthy
# [Reader 2] status = healthy
# [Reader 3] status = healthy
# Финальный статус в хранилище: maintenance
```

## Под капотом

`sync.RWMutex` предотвращает панику рантайма `concurrent map read and map write`.

## Подводные камни

Не забывайте `defer s.mu.RUnlock()` в методе `Get`.

## На собеседовании

**Вопрос с собеседования:** «Можно ли вернуть из SafeMap указатель на структуру и модифицировать её поля снаружи?»
**Ответ:** НЕТ! Возврат указателя нарушает инкапсуляцию потокобезопасности: внешний код сможет мутировать поля структуры без захвата мьютекса, создавая Data Race. Нужно возвращать копию структуры по значению.
