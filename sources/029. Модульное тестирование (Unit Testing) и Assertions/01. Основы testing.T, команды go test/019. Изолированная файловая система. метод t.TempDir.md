# Изолированная файловая система: метод t.TempDir

## Условие

Используйте `t.TempDir()` для создания временной директории, которая будет автоматически удалена после завершения теста.

## Теория

До Go 1.15 работа с временными файлами в тестах требовала шаблонного кода:
```go
dir, err := os.MkdirTemp("", "test_*")
defer os.RemoveAll(dir)
```
Метод `t.TempDir()` (появился в Go 1.15):
- Создает гарантированно уникальную временную папку.
- Регистрирует функцию полного удаления `os.RemoveAll(dir)` в `t.Cleanup()`.
- Исключает мусор на диске серверов CI/CD даже при аварийном завершении теста.

## Решение по шагам

1. Вызовите `dir := t.TempDir()`.
2. Создайте внутри файл с помощью `os.WriteFile`.
3. Прочитайте данные и проверьте корректность.
4. Убедитесь, что после завершения теста папка удаляется.

## Код решения

**`file_test.go`**

```go
package main

import (
	"os"
	"path/filepath"
	"testing"
)

func TestFileCreationWithTempDir(t *testing.T) {
	// Создаем временную изолированную директорию
	tempDir := t.TempDir()
	t.Logf("Временный каталог теста: %s", tempDir)

	filePath := filepath.Join(tempDir, "config.json")
	content := []byte(`{"env": "test", "debug": true}`)

	// Записываем файл
	if err := os.WriteFile(filePath, content, 0600); err != nil {
		t.Fatalf("Не удалось записать файл: %v", err)
	}

	// Читаем и проверяем
	readBytes, err := os.ReadFile(filePath)
	if err != nil {
		t.Fatalf("Не удалось прочитать файл: %v", err)
	}

	if string(readBytes) != string(content) {
		t.Errorf("Содержимое не совпадает! Получено %s, ожидалось %s", readBytes, content)
	}
	// По выходу из теста директория tempDir гарантированно удалится автоматически!
}
```

ℹ️ Автоматическая очистка временных файлов через t.TempDir()

**`Терминал`**

```bash
go test -v file_test.go
# Вывод:
# === RUN   TestFileCreationWithTempDir
#     file_test.go:12: Временный каталог теста: /tmp/TestFileCreationWithTempDir12345/001
# --- PASS: TestFileCreationWithTempDir (0.00s)
# PASS
```

## Под капотом

`t.TempDir()` создает подпапку внутри стандартного системного каталога `os.TempDir()` (например `/tmp` в Linux), включая в имя название теста. Если метод вызывается повторно внутри подтестов, он создает нумерованные подпапки `/001`, `/002`, гарантируя отсутствие конфликтов.

## Подводные камни

Создавать временные файлы прямо в каталоге проекта `os.WriteFile("test.tmp", ...)`. Файл попадет в `git status`, может перезаписать реальный файл разработчика и вызовет конфликт при параллельном запуске тестов.

## На собеседовании

**Вопрос с собеседования:** «Что произойдет с `t.TempDir()`, если в тесте произойдет вызов `t.Fatal()`?»
**Ответ:** Директория всё равно гарантированно будет удалена! Функции очистки `t.Cleanup()` вызываются рантаймом Go даже при вызове `t.Fatal()`, `t.Skip()` или панике.
