# Сравнение создания временных директорий: t.TempDir против os.MkdirTemp

## Условие

Напиши тест с **`t.TempDir()`**: создай файл в `t.TempDir()`. Покажи, что директория автоматически удаляется после теста. Сравни с ручным `os.MkdirTemp` + `defer os.RemoveAll`.

## Теория

Сравнение двух подходов:
1. **Устаревший подход (`os.MkdirTemp` + `defer`):**
   - Требует обработки ошибок создания директории.
   - Требует явного `defer os.RemoveAll(dir)`.
   - Если тест паникует или завершается нештатно, папка может остаться неудаленной на диске.
2. **Идиоматичный подход (`t.TempDir()`):**
   - Вызывается в одну строку без возврата ошибки.
   - Гарантирует очистку даже при `t.Fatal()` и в подтестах `t.Run`.

## Решение по шагам

1. Создайте временный файл в `t.TempDir()`.
2. Запишите в него данные и прочитайте.
3. Проверьте автоматическую деаллокацию.

## Код решения

**`tempdir_test.go`**

```go
package main

import (
	"os"
	"path/filepath"
	"testing"
)

func TestTempDirIdiomatic(t *testing.T) {
	// Идиоматично: одна строка, 100% гарантия автоочистки
	dir := t.TempDir()

	testFile := filepath.Join(dir, "data.txt")
	err := os.WriteFile(testFile, []byte("Hello Go 1.22"), 0644)
	if err != nil {
		t.Fatalf("WriteFile failed: %v", err)
	}

	data, err := os.ReadFile(testFile)
	if err != nil {
		t.Fatalf("ReadFile failed: %v", err)
	}

	t.Logf("Файл успешно прочитан из временной папки: %s", string(data))
}
```

ℹ️ Лаконичная работа с временными файлами через t.TempDir

**`Терминал`**

```bash
go test -v tempdir_test.go
# Вывод:
# === RUN   TestTempDirIdiomatic
#     tempdir_test.go:23: Файл успешно прочитан из временной папки: Hello Go 1.22
# --- PASS: TestTempDirIdiomatic (0.00s)
# PASS
```

## Под капотом

`t.TempDir` вызывает `os.MkdirTemp` внутри рантайма пакета `testing` и регистрирует удаление через `t.Cleanup()`. Если при удалении возникает ошибка (например, открытый файл в Windows), Go сообщает о предупреждении в отчете теста.

## Подводные камни

Хранить путь к `t.TempDir()` в глобальной переменной для использования в других тестах: директория будет уничтожена сразу по окончании создавшего ее теста.

## На собеседовании

**Вопрос с собеседования:** «Можно ли вызывать `t.TempDir()` внутри подтеста `t.Run`?»
**Ответ:** Да! Подтест получит собственную вложенную временную папку, которая будет автоматически удалена ровно в момент завершения этого конкретного подтеста.
