# Выборочный запуск тестов через флаг -run: фильтрация TestAdd, TestSub, TestMul

## Условие

Изучи флаг `-run`. Напиши 3 теста: `TestAdd`, `TestSub`, `TestMul`. Запусти `go test -run TestAdd -v`, чтобы выполнился только один.

## Теория

Флаг `-run` — ключевой инструмент разработчика при TDD и отладке:
- Если в проекте 500 тестов, полный прогон занимает время.
- При разработке новой фичи запускают только целевой тест: `go test -run TestAdd -v`.
- Раннер пропускает все остальные тесты без их компиляции и исполнения.

## Решение по шагам

1. Создайте функции `TestAdd`, `TestSub`, `TestMul`.
2. Запустите `go test -run TestAdd -v`.
3. Убедитесь, что `TestSub` и `TestMul` не запускались.

## Код решения

**`math_filter_test.go`**

```go
package main

import "testing"

func TestAdd(t *testing.T) {
	t.Log("Выполняется TestAdd")
}

func TestSub(t *testing.T) {
	t.Log("Выполняется TestSub")
}

func TestMul(t *testing.T) {
	t.Log("Выполняется TestMul")
}
```

ℹ️ Набор тестов для проверки фильтрации

**`Терминал`**

```bash
go test -v -run TestAdd math_filter_test.go
# Вывод:
# === RUN   TestAdd
#     math_filter_test.go:6: Выполняется TestAdd
# --- PASS: TestAdd (0.00s)
# PASS
# ok      command-line-arguments  0.002s
```

## Под капотом

Если ни один тест не подошел под шаблон `-run`, утилита выводит `testing: warning: no tests to run` и возвращает успешный код 0.

## Подводные камни

Опечататься в имени флага или регулярного выражения, в результате чего тесты не запустятся, создав ложное ощущение успеха.

## На собеседовании

**Вопрос с собеседования:** «Как запустить все тесты пакета, КРОМЕ одного конкретного медленного теста?»
**Ответ:** Использовать отрицательное регулярное выражение с инверсией или отрицательным просмотром вперед, либо запустить `go test -run "^((?!TestSlow).)*$"`.
