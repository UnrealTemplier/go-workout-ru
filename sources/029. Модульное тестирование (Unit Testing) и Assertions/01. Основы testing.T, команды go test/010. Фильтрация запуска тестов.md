# Фильтрация запуска тестов: флаг -run и регулярные выражения

## Условие

Запустите тесты конкретной функции с помощью `-run TestAdd`. Используйте регулярные выражения (`-run "TestAdd|TestSubtract"`) для запуска нескольких тестов.

## Теория

Флаг `-run <regexp>` принимает регулярное выражение синтаксиса Go RE2:
- `-run TestAdd`: запустит все тесты, имя которых содержит `TestAdd` (например `TestAdd`, `TestAddPositive`).
- `-run ^TestAdd$`: запустит СТРОГО тест с именем `TestAdd` (точное совпадение).
- `-run "TestAdd|TestSubtract"`: запустит тесты сложения или вычитания.
- `-run TestMath/Positive`: запустит конкретный подтест внутри родительского теста `TestMath`.

## Решение по шагам

1. Создайте функции `TestAdd`, `TestSubtract`, `TestMultiply`.
2. Запустите только `TestAdd` через `go test -run TestAdd`.
3. Запустите `TestAdd` и `TestSubtract` через регулярное выражение с пайпом `|`.

## Код решения

**`ops_test.go`**

```go
package main

import "testing"

func TestAdd(t *testing.T) {
	t.Log("Выполняется TestAdd")
}

func TestSubtract(t *testing.T) {
	t.Log("Выполняется TestSubtract")
}

func TestMultiply(t *testing.T) {
	t.Log("Выполняется TestMultiply")
}
```

ℹ️ Несколько тестовых функций

**`Терминал`**

```bash
# 1. Запуск строго одного теста:
go test -v -run "^TestAdd$"
# Вывод:
# === RUN   TestAdd
#     ops_test.go:6: Выполняется TestAdd
# --- PASS: TestAdd (0.00s)
# PASS

# 2. Запуск двух тестов через регулярное выражение:
go test -v -run "TestAdd|TestSubtract"
# Вывод:
# === RUN   TestAdd
#     ops_test.go:6: Выполняется TestAdd
# --- PASS: TestAdd (0.00s)
# === RUN   TestSubtract
#     ops_test.go:10: Выполняется TestSubtract
# --- PASS: TestSubtract (0.00s)
# PASS
```

## Под капотом

Движок тестирования Go компилирует переданное в `-run` выражение через `regexp.Compile`. При обходе списка тестов он вызывает `re.MatchString(testName)`. Если совпадения нет, функция даже не вызывается.

## Подводные камни

Забывать экранировать спецсимволы в шелле: команда `go test -run TestA|TestB` без кавычек будет интерпретирована bash как конвейер (pipe) в программу `TestB`! Всегда берите выражение в кавычки: `go test -run "TestA|TestB"`.

## На собеседовании

**Вопрос с собеседования:** «Как запустить все тесты в текущем пакете и всех его подпакетах рекурсивно?»
**Ответ:** Командой `go test ./...`. Три точки `...` — специальный подстановочный знак в инструментарии Go, обозначающий рекурсивный обход всех дочерних пакетов репозитория.
