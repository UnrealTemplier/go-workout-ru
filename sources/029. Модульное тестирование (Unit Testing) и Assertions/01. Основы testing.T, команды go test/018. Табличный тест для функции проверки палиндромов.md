# Табличный тест для функции проверки палиндромов

## Условие

Табличные тесты: создайте таблицу тестовых случаев для функции `IsPalindrome(s string) bool`. Проверьте граничные случаи (пустая строка, один символ, пробелы).

## Теория

При тестировании бизнес-логики таблица должна проверять не только стандартные кейсы, но и экстремальные граничные условия:
- Пустая строка `""` (является ли палиндромом по определению?).
- Строка из одних пробелов `"   "`.
- Несимметричные знаки пунктуации: `"Madam, I'm Adam"`.
- Регистронезависимость: `"Anna"`.
- Односимвольные строки: `"x"`.

## Решение по шагам

1. Создайте структуру кейса `struct { name, str string, want bool }`.
2. Опишите граничные случаи.
3. Прогоните сценарии через `t.Run`.
4. Запустите `go test -v`.

## Код решения

**`palindrome.go`**

```go
package main

import (
	"strings"
	"unicode"
)

func IsPalindrome(s string) bool {
	var b strings.Builder
	for _, r := range s {
		if unicode.IsLetter(r) || unicode.IsDigit(r) {
			b.WriteRune(unicode.ToLower(r))
		}
	}

	clean := b.String()
	runes := []rune(clean)
	n := len(runes)

	for i := 0; i < n/2; i++ {
		if runes[i] != runes[n-1-i] {
			return false
		}
	}
	return true
}
```

ℹ️ Устойчивая функция проверки палиндромов

**`palindrome_test.go`**

```go
package main

import "testing"

func TestIsPalindrome_EdgeCases(t *testing.T) {
	tests := []struct {
		name string
		str  string
		want bool
	}{
		{name: "пустая строка", str: "", want: true},
		{name: "один пробел", str: " ", want: true},
		{name: "много пробелов", str: "     ", want: true},
		{name: "один символ", str: "z", want: true},
		{name: "английская фраза со знаками", str: "Madam, I'm Adam", want: true},
		{name: "русская фраза", str: "Топот", want: true},
		{name: "не палиндром", str: "Привет мир", want: false},
	}

	for _, tc := range tests {
		t.Run(tc.name, func(t *testing.T) {
			if got := IsPalindrome(tc.str); got != tc.want {
				t.Errorf("IsPalindrome(%q) = %v; want %v", tc.str, got, tc.want)
			}
		})
	}
}
```

## Под капотом

Использование `strings.Builder` и среза рун `[]rune` обеспечивает корректную работу со сложными UTF-8 символами любой длины (от 1 до 4 байт на символ).

## Подводные камни

Сравнивать байты вместо рун: английские буквы работают корректно, но на кириллице или эмодзи тест упадет из-за многобайтового представления.

## На собеседовании

**Вопрос с собеседования:** «Какова алгоритмическая сложность функции проверки палиндрома?»
**Ответ:** По времени \(O(N)\) (один проход для фильтрации и один проход до середины строки). По дополнительной памяти \(O(N)\) для хранения очищенного среза рун.
