# Вспомогательные функции тестирования и метод t.Helper

## Условие

Напиши тест с **`t.Helper()`**: создай вспомогательную функцию `assertEqual(t *testing.T, got, want int)`, вызывай `t.Helper()` в начале. Покажи, что при ошибке stack trace указывает на строку вызова `assertEqual`, а не на `t.Errorf` внутри неё.

## Теория

Когда проверки выносятся во вспомогательную функцию `assertXxx(t, ...)` без вызова `t.Helper()`, раннер сообщает об ошибке на строке внутри самой вспомогательной функции:
`helpers.go:12: values not equal`
Это крайне неудобно, так как непонятно, в каком из 50 мест вызова произошел сбой!
**Метод `t.Helper()`:**
- Помечает текущую функцию как вспомогательную (Test Helper).
- При формировании сообщения об ошибке и стектрейса Go пропускает эту функцию и указывает **точную строку в файле теста**, где был сделан вызов `assertEqual`!

## Решение по шагам

1. Напишите функцию `assertEqual(t *testing.T, got, want int)` с `t.Helper()`.
2. Вызовите её с несовпадающими значениями.
3. Убедитесь, что в отчете указан номер строки теста.

## Код решения

**`helper_test.go`**

```go
package main

import "testing"

func assertEqual(t *testing.T, got, want int) {
	t.Helper() // Инструктирует раннер связать ошибку со строкой вызова ниже!
	if got != want {
		t.Errorf("got %d; want %d", got, want)
	}
}

func TestWithHelper(t *testing.T) {
	result := 42
	assertEqual(t, result, 42) // Успешно

	// Намеренная ошибка: лог укажет на строку 17, а не на строку 8!
	assertEqual(t, result, 100)
}
```

ℹ️ Использование t.Helper для точного стектрейса

**`Терминал`**

```bash
go test -v helper_test.go
# Вывод:
# === RUN   TestWithHelper
#     helper_test.go:18: got 42; want 100
# --- FAIL: TestWithHelper (0.00s)
# FAIL
```

## Под капотом

При логировании ошибки Go вызывает `runtime.Callers()`. Если кадр стека помечен флагом `t.Helper()`, раннер сдвигает указатель кадра выше по стеку вызовов до тех пор, пока не встретит непомеченную функцию.

## Подводные камни

Забывать вызывать `t.Helper()` во вспомогательных функциях моков, фикстур и ассертов.

## На собеседовании

**Вопрос с собеседования:** «Можно ли вызывать `t.Helper()` в нескольких функциях цепочки (цепочка хелперов)?»
**Ответ:** Да! Если функция `A` вызывает `B`, и обе содержат `t.Helper()`, сообщение об ошибке укажет на строку кода, вызвавшую функцию `A`.
