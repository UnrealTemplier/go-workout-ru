# Сравнение коллекций без учета порядка: assert.ElementsMatch vs assert.Equal

## Условие

Используй `assert.ElementsMatch(t, expected, actual)` для сравнения слайсов без учёта порядка. Покажи разницу с `assert.Equal`, который требует точного порядка.

## Теория

Проблема недетерминированного порядка:
1. Запросы в SQL без `ORDER BY` возвращают строки в произвольном порядке.
2. Итерация по `map` в Go рандомизирована рантаймом.
3. Получение ключей мапы `keys := GetMapKeys(m)` возвращает элементы в случайном порядке.
Сравнение через `assert.Equal(want, got)` приведет к случайным падениям тестов (Flaky Test).
Метод `assert.ElementsMatch(t, expected, actual)`:
- Проверяет, что оба среза содержат одинаковые элементы и одинаковое их количество с учетом дубликатов, игнорируя порядок следования!

## Решение по шагам

1. Создайте функцию, возвращающую ключи мапы.
2. Продемонстрируйте падение `assert.Equal` из-за перестановки элементов.
3. Продемонстрируйте стабильный проход с `assert.ElementsMatch`.

## Код решения

**`order_test.go`**

```go
package main

import (
	"testing"

	"github.com/stretchr/testify/assert"
)

func GetPermissions() []string {
	// Возвращает элементы в произвольном порядке
	return []string{"read", "delete", "write"}
}

func TestElementsMatchComparison(t *testing.T) {
	actual := GetPermissions()
	expected := []string{"write", "read", "delete"}

	// assert.ElementsMatch проверяет состав элементов без учета порядка
	assert.ElementsMatch(t, expected, actual, "Списки прав должны содержать одинаковый набор элементов")
}
```

ℹ️ Устойчивое сравнение срезов через ElementsMatch

**`Терминал`**

```bash
go test -v order_test.go
# Вывод:
# === RUN   TestElementsMatchComparison
# --- PASS: TestElementsMatchComparison (0.00s)
# PASS
```

## Под капотом

`assert.ElementsMatch` подсчитывает частоту появления каждого элемента через хэш-таблицу или квадратичное сравнение \(O(N^2)\), гарантируя корректность даже для срезов с повторяющимися элементами (мультимножества).

## Подводные камни

Использовать `assert.ElementsMatch` для структур, содержащих нехэшируемые типы (срезы, функции), без кастомного компаратора.

## На собеседовании

**Вопрос с собеседования:** «Как проверить равенство двух неупорядоченных срезов стандартными средствами Go без внешних библиотек?»
**Ответ:** Отсортировать оба среза с помощью `slices.Sort(a)` и `slices.Sort(b)` (Go 1.21+), после чего сравнить их через `slices.Equal(a, b)`.
