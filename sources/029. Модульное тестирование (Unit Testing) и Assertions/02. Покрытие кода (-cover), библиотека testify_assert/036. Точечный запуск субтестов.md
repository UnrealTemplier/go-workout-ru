# Точечный запуск субтестов: фильтрация go test -run=TestName/subtest_name

## Условие

**Субтесты (`t.Run`)**: Перепишите ваши табличные тесты из табличных тестов с использованием метода `t.Run(name, func(t *testing.T) { ... })` [334]. Запустите тесты с флагом подробного вывода `go test -v` и посмотрите, как красиво группируются результаты для каждого тест-кейса [334]. Попробуйте запустить только один конкретный субтест с помощью флага фильтрации, например: `go test -run=TestIsPalindrome/empty_string`.

## Теория

Фильтрация субтестов синтаксисом `ParentTest/SubTest`:
- Флаг `-run=TestIsPalindrome/empty_string` запустит родительский тест `TestIsPalindrome` и выполнит внутри него ТОЛЬКО подтест с именем `empty_string`.
- Все остальные подтесты будут проигнорированы раннером.
Это ускоряет отладку конкретного сломанного сценария в тысячи раз.

## Решение по шагам

1. Создайте тест `TestIsPalindrome` с подтестами `empty_string`, `valid`, `invalid`.
2. Запустите только подтест `empty_string`.
3. Убедитесь, что остальные подтесты не запускались.

## Код решения

**`subtest_filter_test.go`**

```go
package main

import "testing"

func TestIsPalindrome(t *testing.T) {
	t.Run("empty_string", func(t *testing.T) {
		t.Log("Запущен целевой субтест: empty_string")
	})

	t.Run("valid_palindrome", func(t *testing.T) {
		t.Log("Этот тест НЕ должен запускаться")
	})

	t.Run("invalid_word", func(t *testing.T) {
		t.Log("Этот тест НЕ должен запускаться")
	})
}
```

ℹ️ Тест с несколькими субтестами

**`Терминал`**

```bash
go test -v -run=TestIsPalindrome/empty_string subtest_filter_test.go
# Вывод:
# === RUN   TestIsPalindrome
# === RUN   TestIsPalindrome/empty_string
#     subtest_filter_test.go:7: Запущен целевой субтест: empty_string
# --- PASS: TestIsPalindrome (0.00s)
#     --- PASS: TestIsPalindrome/empty_string (0.00s)
# PASS
```

## Под капотом

Раннер Go сопоставляет регулярное выражение со строкой `TestIsPalindrome/empty_string`. Поскольку подстроки `valid_palindrome` не совпали с регулярным выражением, тело этих анонимных функций даже не вызывается.

## Подводные камни

Использовать пробелы в фильтре без кавычек в терминале bash.

## На собеседовании

**Вопрос с собеседования:** «Как запустить все субтесты, содержащие слово 'error'?»
**Ответ:** Командой `go test -run="/error" ./...`. Слэш в начале выражения указывает раннеру сопоставлять паттерн на уровне субтестов любого теста.
