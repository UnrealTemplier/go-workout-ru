# Инспекция покрытия кода: флаги -cover и -coverprofile

## Условие

Запустите тесты с флагом `-cover`, чтобы увидеть процент покрытия кода тестами.

## Теория

Команда покрытия имеет расширенные режимы:
- `go test -cover`: процент покрытия в консоли.
- `go test -coverprofile=coverage.out`: сохранение детального отчета по каждой строке файла.
- `go tool cover -html=coverage.out -o coverage.html`: генерация интерактивного HTML-отчета, где зеленым подсвечены покрытые строки, а красным — непокрытые!

## Решение по шагам

1. Запустите тесты с генерацией профиля покрытия `coverage.out`.
2. Преобразуйте профиль в HTML-отчет через `go tool cover`.
3. Оцените непокрытые строки кода.

## Код решения

**`math_cov.go`**

```go
package main

func Abs(x int) int {
	if x < 0 {
		return -x
	}
	return x
}
```

ℹ️ Функция вычисления модуля числа

**`math_cov_test.go`**

```go
package main

import "testing"

func TestAbs(t *testing.T) {
	if got := Abs(-5); got != 5 {
		t.Errorf("Abs(-5) = %d; want 5", got)
	}
	if got := Abs(10); got != 10 {
		t.Errorf("Abs(10) = %d; want 10", got)
	}
}
```

ℹ️ 100% покрытие всех ветвей функции

**`Терминал`**

```bash
# Запуск с генерацией профиля покрытия:
go test -coverprofile=coverage.out math_cov_test.go math_cov.go
# Вывод:
# ok      command-line-arguments  0.002s  coverage: 100.0% of statements

# Анализ покрытия по функциям:
go tool cover -func=coverage.out
# Вывод:
# math_cov.go:3:  Abs             100.0%
# total:          (statements)    100.0%
```

## Под капотом

`go tool cover` парсит сгенерированный профиль, где указаны диапазоны строк `line.col,line.col count`. На основе этих данных строится интерактивная тепловая карта исходного кода.

## Подводные камни

Коммитить бинарный файл `coverage.out` в git-репозиторий: добавьте его в `.gitignore`.

## На собеседовании

**Вопрос с собеседования:** «Как запретить слияние Pull Request, если покрытие тестами упало ниже 80%?»
**Ответ:** Настроить Quality Gate в CI/CD (например GitHub Actions или GitLab CI), парсить `coverage.out` и прерывать пайплайн с ошибкой, если процент `total: (statements)` ниже целевого порога.
