# Проверка реализации интерфейсов: assert.Implements и runtime vs compile-time

## Условие

Используй `assert.Implements(t, (*io.Reader)(nil), obj)` для проверки, что тип реализует интерфейс. Покажи, что это runtime-проверка, а не compile-time.

### Исходная формулировка

Используй `assert.Implements(t, (*io.Reader)(nil), obj)` для проверки, что тип реализует интерфейс. Покажи, что это runtime-проверка, а не compile-time.

---

## Теория

Проверка соответствия типу интерфейса:
1. **Compile-time проверка (идиома Go):**
   `var _ io.Reader = (*MyReader)(nil)`
   Проверяется компилятором при сборке кода. Если методы не совпадают, код даже не скомпилируется.
2. **Runtime проверка (`assert.Implements`):**
   `assert.Implements(t, (*io.Reader)(nil), obj)`
   Проверяется во время выполнения через рефлексию `reflect.Type.Implements()`. Полезна при фабричных паттернах, плагинах или динамически создаваемых объектах.

## Решение по шагам

1. Создайте интерфейс `Writer` и структуру `CustomWriter`.
2. Реализуйте метод `Write(p []byte) (n int, err error)`.
3. Проверьте реализацию через `assert.Implements`.

## Код решения

**`interfaces_test.go`**

```go
package main

import (
	"io"
	"testing"

	"github.com/stretchr/testify/assert"
)

type CustomBuffer struct {
	data []byte
}

func (c *CustomBuffer) Read(p []byte) (n int, err error) {
	if len(c.data) == 0 {
		return 0, io.EOF
	}
	n = copy(p, c.data)
	c.data = c.data[n:]
	return n, nil
}

func TestImplementsInterface(t *testing.T) {
	buf := &CustomBuffer{data: []byte("test data")}

	// Runtime-проверка через testify/assert
	// Передается указатель на nil-интерфейс (*io.Reader)(nil) и проверяемый объект
	assert.Implements(t, (*io.Reader)(nil), buf, "CustomBuffer обязан реализовывать io.Reader")
}
```

ℹ️ Проверка соответствия интерфейсу через assert.Implements

**`Терминал`**

```bash
go test -v interfaces_test.go
# Вывод:
# === RUN   TestImplementsInterface
# --- PASS: TestImplementsInterface (0.00s)
# PASS
```

## Под капотом

`assert.Implements` разыменовывает тип интерфейса через `reflect.TypeOf((*io.Reader)(nil)).Elem()` и вызывает `targetType.Implements(interfaceType)`. Метод проверяет наличие всех методов интерфейса и сигнатуры параметров в таблице методов (itab).

## Подводные камни

Забыть передать указатель на структуру, если методы имеют pointer receiver `(c *CustomBuffer)`. Значение `CustomBuffer{}` не реализует интерфейс, так как методы объявлены на указателе!

## На собеседовании

**Вопрос с собеседования:** «Почему в промышленном коде Go предпочитают `var _ io.Reader = (*MyReader)(nil)` вместо тестов на `assert.Implements`?»
**Ответ:** Compile-time проверка отлавливает ошибки несовместимости интерфейсов еще на этапе компиляции в IDE и `go build`, предотвращая попадание сломанного кода в репозиторий, не требуя даже запуска тестов.
