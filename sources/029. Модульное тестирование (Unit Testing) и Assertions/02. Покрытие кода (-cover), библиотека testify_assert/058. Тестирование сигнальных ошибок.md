# Тестирование сигнальных ошибок: sentinel error ErrNotFound и assert.ErrorIs

## Условие

Напиши функцию, возвращающую sentinel error `var ErrNotFound = errors.New("not found")`. Напиши тест, проверяющий `errors.Is(err, ErrNotFound)` через `assert.ErrorIs`.

## Теория

Sentinel Errors (ошибки-метки):
Объявляются как глобальные неизменяемые переменные пакета:
`var ErrNotFound = errors.New("not found")`
Они позволяют вызывающему коду сравнивать ошибки по идентичности адреса в памяти (`==`).
Начиная с Go 1.13, прямое сравнение `err == ErrNotFound` заменяют на `errors.Is(err, ErrNotFound)`, что позволяет находить ошибку даже если она была обернута дополнительным контекстом.

## Решение по шагам

1. Объявите `var ErrNotFound = errors.New("запись не найдена")`.
2. Напишите функцию поиска в репозитории `FindUser(id int) (*User, error)`.
3. Проверьте ошибку через `assert.ErrorIs(t, err, ErrNotFound)`.

## Код решения

**`repo.go`**

```go
package main

import (
	"errors"
	"fmt"
)

var ErrNotFound = errors.New("запись не найдена")

func FindUser(id int) (string, error) {
	if id != 42 {
		// Оборачиваем sentinel error в контекст операции
		return "", fmt.Errorf("поиск пользователя %d: %w", id, ErrNotFound)
	}
	return "Алексей", nil
}
```

ℹ️ Репозиторий с sentinel error

**`repo_test.go`**

```go
package main

import (
	"errors"
	"testing"

	"github.com/stretchr/testify/assert"
)

func TestFindUserSentinel(t *testing.T) {
	// Успешный кейс
	name, err := FindUser(42)
	assert.NoError(t, err)
	assert.Equal(t, "Алексей", name)

	// Ошибочный кейс с проверкой sentinel error
	_, err = FindUser(999)
	assert.Error(t, err)

	// 1. Проверка через стандартный errors.Is
	if !errors.Is(err, ErrNotFound) {
		t.Errorf("errors.Is не нашел ErrNotFound в цепочке: %v", err)
	}

	// 2. Декларативная проверка через testify/assert
	assert.ErrorIs(t, err, ErrNotFound, "Ошибка обязана быть ErrNotFound")
}
```

## Под капотом

`assert.ErrorIs(t, err, target)` вызывает стандартную функцию `errors.Is(err, target)`. Она сравнивает ошибки по указателю, а если они не равны — проверяет наличие метода `Unwrap() error` или `Unwrap() []error` (Go 1.20+), раскручивая дерево ошибок.

## Подводные камни

Создавать новую ошибку внутри функции: `return errors.New("запись не найдена")`. Каждое создание через `errors.New` выделяет новый адрес в памяти, поэтому `errors.Is` не сможет обнаружить совпадение! Sentinel errors ОБЯЗАНЫ быть объявлены в `var` на уровне пакета.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go 1.20 расширили функцию `errors.Is` для поддержки множественного развертывания `Unwrap() []error`?»
**Ответ:** Для поддержки мульти-ошибок (Join Errors), создаваемых через `errors.Join(err1, err2)`. Функция `errors.Is` теперь способна выполнять поиск в глубину по дереву нескольких объединенных ошибок.
