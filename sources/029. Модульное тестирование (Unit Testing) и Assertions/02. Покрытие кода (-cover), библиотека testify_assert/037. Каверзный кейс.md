# Каверзный кейс: использование t.Skip для недописанных фичей

## Условие

**[Каверзный кейс]**: Используй `t.Skip("Skipping because feature is not ready")` внутри теста. Запусти `go test -v` и убедись, что тест помечен как SKIP, а не FAIL.

## Теория

При методологии TDD (Test-Driven Development) разработчик часто сначала пишет тесты на будущий функционал.
Чтобы недописанный тест не ломал мастер-ветку и CI пайплайны других разработчиков, его временно помечают вызовом `t.Skip()` с объяснением причины (например ссылкой на задачу в Jira).
В логах CI статус `--- SKIP:` сигнализирует о техническом долге, не приводя к падению сборки.

## Решение по шагам

1. Напишите тест с вызовом `t.Skip(...)`.
2. Запустите `go test -v`.
3. Убедитесь в коде завершения 0 и статусе `--- SKIP:`.

## Код решения

**`feature_test.go`**

```go
package main

import "testing"

func TestAIRecommendationEngine(t *testing.T) {
	// Каверзный кейс: фича еще в разработке (WIP)
	t.Skip("Skipping because feature is not ready (JIRA-4891)")

	// Код ниже пока не готов к проверке
	t.Fatal("Этот код никогда не вызовется!")
}
```

ℹ️ Пропуск теста функционала в разработке

**`Терминал`**

```bash
go test -v feature_test.go
# Вывод:
# === RUN   TestAIRecommendationEngine
#     feature_test.go:7: Skipping because feature is not ready (JIRA-4891)
# --- SKIP: TestAIRecommendationEngine (0.00s)
# PASS
# ok      command-line-arguments  0.002s
```

## Под капотом

`t.Skip` устанавливает код завершения процесса равным `0`. Это предотвращает блокировку релизных пайплайнов команды.

## Подводные камни

Закомментировать тело теста вместо вызова `t.Skip()`. Закомментированный код быстро устаревает (code rot) и перестает компилироваться при изменении сигнатур функций. `t.Skip()` оставляет код валидным для компилятора Go!

## На собеседовании

**Вопрос с собеседования:** «Чем `t.SkipNow()` отличается от `t.Skip()`?»
**Ответ:** `t.Skip(args...)` печатает сообщение и затем вызывает `t.SkipNow()`. `t.SkipNow()` молча прерывает текущую горутину без логирования сообщения.
