# Хелпер валидации ошибок: assertError с t.Helper и точной строкой вызова

## Условие

Напишите тест с `t.Helper()`: вспомогательная функция, которая проверяет, что ошибка равна ожидаемой, и вызывает `t.Fatal` при несовпадении. В выводе ошибки должна указываться строка вызова теста, а не хелпера.

## Теория

При тестировании сложной бизнес-логики проверка ошибок дублируется десятки раз.
Создание хелпера `assertError(t, err, targetErr)` с вызовом `t.Helper()`:
- Устраняет дублирование кода проверок.
- Корректно указывает номер строки теста в стектрейсе при ошибке.

## Решение по шагам

1. Создайте `assertError(t *testing.T, got, want error)`.
2. Добавьте в нее `t.Helper()`.
3. Вызовите хелпер в тесте и проверьте вывод стектрейса.

## Код решения

**`err_helper_test.go`**

```go
package main

import (
	"errors"
	"testing"
)

var ErrNotFound = errors.New("объект не найден")
var ErrPermissionDenied = errors.New("доступ запрещен")

func assertError(t *testing.T, got, want error) {
	t.Helper() // Ключевая директива для раннера Go!

	if !errors.Is(got, want) {
		t.Fatalf("получена ошибка %v; ожидалась %v", got, want)
	}
}

func TestHelperTrace(t *testing.T) {
	actualErr := ErrNotFound
	assertError(t, actualErr, ErrNotFound) // Успешно

	// Ошибка: лог укажет на строку 23, а не на строку 14!
	assertError(t, actualErr, ErrPermissionDenied)
}
```

ℹ️ Хелпер assertError с точным указателем строки

**`Терминал`**

```bash
go test -v err_helper_test.go
# Вывод:
# === RUN   TestHelperTrace
#     err_helper_test.go:23: получена ошибка объект не найден; ожидалась доступ запрещен
# --- FAIL: TestHelperTrace (0.00s)
# FAIL
```

## Под капотом

Без `t.Helper()` раннер напечатал бы `err_helper_test.go:14` (строка внутри хелпера). С `t.Helper()` он указывает на строку 23 файла теста, мгновенно показывая место сбоя.

## Подводные камни

Забыть написать `t.Helper()` в кастомных assertions.

## На собеседовании

**Вопрос с собеседования:** «Как работают популярные библиотеки assertions (testify, is) под капотом?»
**Ответ:** Все методы библиотек вроде `assert.Equal` или `require.NoError` первой же строчкой вызывают `t.Helper()`, чтобы отчеты об ошибках указывали на строку теста в пользовательском коде.
