# Управление временными файлами через os.CreateTemp и t.Cleanup

## Условие

**Очистка ресурсов через `t.Cleanup`**: Напишите тест, который создает временный файл на диске с помощью `os.CreateTemp`, записывает в него данные, выполняет проверку их чтения, а очистку (удаление файла) регистрирует через `t.Cleanup(func() { ... })` [336]. Напишите комментарий, чем `t.Cleanup` удобнее и безопаснее, чем обычный `defer` внутри теста [336].

## Теория

Преимущества `t.Cleanup` над обычным `defer`:
1. **Чистые хелперы:** Вспомогательная функция `createTestFile(t)` может сама зарегистрировать очистку созданного файла, избавив вызывающий тест от необходимости писать `defer os.Remove(...)`.
2. **Изоляция в подтестах:** При создании файла внутри `t.Run` вызов `defer` сработает только при выходе из `t.Run`, однако если подтест аварийно завершится или будет запущен параллельно, `t.Cleanup` гарантирует корректную последовательность освобождения ресурсов.
3. **Читаемость:** Код очистки находится непосредственно рядом с кодом инициализации ресурса.

## Решение по шагам

1. Создайте временный файл с помощью `os.CreateTemp("", "workout_*.txt")`.
2. Зарегистрируйте его удаление и закрытие через `t.Cleanup`.
3. Запишите и прочитайте тестовые данные.
4. Убедитесь в отсутствии файла на диске после завершения теста.

## Код решения

**`createtemp_test.go`**

```go
package main

import (
	"os"
	"testing"
)

// createTempFileHelper создает файл и автоматически регистрирует очистку
func createTempFileHelper(t *testing.T, initialData []byte) *os.File {
	t.Helper()

	tmpFile, err := os.CreateTemp("", "test_payload_*.bin")
	if err != nil {
		t.Fatalf("Не удалось создать временный файл: %v", err)
	}

	// Регистрируем освобождение дескриптора и удаление с диска
	t.Cleanup(func() {
		_ = tmpFile.Close()
		_ = os.Remove(tmpFile.Name())
		t.Logf("Файл %s успешно удален через t.Cleanup", tmpFile.Name())
	})

	if _, err := tmpFile.Write(initialData); err != nil {
		t.Fatalf("Ошибка записи во временный файл: %v", err)
	}

	return tmpFile
}

func TestTempFileWithCleanup(t *testing.T) {
	payload := []byte("Go Workout Testing Mastery")
	f := createTempFileHelper(t, payload)

	// Читаем данные обратно
	readData, err := os.ReadFile(f.Name())
	if err != nil {
		t.Fatalf("Ошибка чтения файла: %v", err)
	}

	if string(readData) != string(payload) {
		t.Errorf("got %s; want %s", readData, payload)
	}
}
```

ℹ️ Инкапсулированная очистка временного файла через t.Cleanup

**`Терминал`**

```bash
go test -v createtemp_test.go
# Вывод:
# === RUN   TestTempFileWithCleanup
#     createtemp_test.go:21: Файл /tmp/test_payload_123.bin успешно удален через t.Cleanup
# --- PASS: TestTempFileWithCleanup (0.00s)
# PASS
```

## Под капотом

Если бы мы использовали `defer tmpFile.Close()` внутри функции `createTempFileHelper`, файл закрылся бы немедленно при возврате из хелпера! `t.Cleanup` переносит время срабатывания на момент окончания вызвавшего теста `TestTempFileWithCleanup`.

## Подводные камни

Забыть закрыть файл `tmpFile.Close()` перед `os.Remove()` в ОС Windows: Windows блокирует удаление открытых файлов, что приведет к ошибке доступа.

## На собеседовании

**Вопрос с собеседования:** «Почему в современных версиях Go при создании файлов чаще используют `t.TempDir()` вместо `os.CreateTemp`?»
**Ответ:** `t.TempDir()` создает изолированную папку, удаляя её целиком вместе со всеми созданными файлами за один вызов `os.RemoveAll()`, избавляя разработчика от необходимости регистрировать удаление каждого отдельного файла.
