# Безопасная подмена глобального состояния: переопределение переменных с t.Cleanup

## Условие

Напишите тест, который временно переопределяет глобальную переменную (например, URL внешнего API) и восстанавливает её после завершения через `defer` или `t.Cleanup`.

### Исходная формулировка

Напишите тест, который временно переопределяет глобальную переменную (например, URL внешнего API) и восстанавливает её после завершения через `defer` или `t.Cleanup`.

## Теория

Иногда в legacy-коде или сторонних SDK базовый URL или таймаут задан глобальной переменной пакета:
`var DefaultAPIURL = "https://api.production.com"`
Для тестирования её нужно временно перенаправить на локальный тестовый мок-сервер.
**Идиоматичный паттерн восстановления:**
```go
orig := DefaultAPIURL
DefaultAPIURL = mockServer.URL
t.Cleanup(func() { DefaultAPIURL = orig })
```
Гарантирует 100% восстановление исходного URL даже при падении теста.

## Решение по шагам

1. Объявите глобальную переменную `var APIBaseURL = "https://prod.api.com"`.
2. В тесте переопределите её на тестовый эндпоинт.
3. Зарегистрируйте возврат значения через `t.Cleanup`.
4. Проверьте в следующем тесте, что переменная вернулась к исходному продакшн-значению.

## Код решения

**`client.go`**

```go
package main

var APIBaseURL = "https://api.production.internal/v1"

func FetchResourceURL(resource string) string {
	return APIBaseURL + "/" + resource
}
```

ℹ️ Клиент с глобальной переменной базового URL

**`client_test.go`**

```go
package main

import "testing"

func TestOverrideGlobalURL(t *testing.T) {
	// Сохраняем исходное значение и регистрируем автовозврат
	origURL := APIBaseURL
	t.Cleanup(func() {
		APIBaseURL = origURL
		t.Logf("Глобальный URL восстановлен: %s", APIBaseURL)
	})

	// Переопределяем на тестовый мок-сервер
	APIBaseURL = "http://127.0.0.1:8080/mock"

	expected := "http://127.0.0.1:8080/mock/orders"
	if actual := FetchResourceURL("orders"); actual != expected {
		t.Errorf("got %s; want %s", actual, expected)
	}
}

func TestVerifyGlobalURLRestored(t *testing.T) {
	// Проверяем, что исходное значение не повреждено
	expected := "https://api.production.internal/v1"
	if APIBaseURL != expected {
		t.Fatalf("Утечка глобальной переменной: %s (ожидалось %s)", APIBaseURL, expected)
	}
}
```

ℹ️ Безопасная подмена глобальной переменной с t.Cleanup

**`Терминал`**

```bash
go test -v client_test.go client.go
# Вывод:
# === RUN   TestOverrideGlobalURL
#     client_test.go:11: Глобальный URL восстановлен: https://api.production.internal/v1
# --- PASS: TestOverrideGlobalURL (0.00s)
# === RUN   TestVerifyGlobalURLRestored
# --- PASS: TestVerifyGlobalURLRestored (0.00s)
# PASS
```

## Под капотом

`t.Cleanup` выполняет функцию восстановления в той же горутине сразу после выхода из `TestOverrideGlobalURL`, гарантируя, что следующий тест `TestVerifyGlobalURLRestored` увидит строго оригинальное значение.

## Подводные камни

Запускать тесты, модифицирующие общую глобальную переменную, параллельно через `t.Parallel()`: это приведет к гонкам данных (Data Race) и случайным падениям.

## На собеседовании

**Вопрос с собеседования:** «Как избавиться от необходимости переопределять глобальные переменные в архитектуре проекта?»
**Ответ:** Применить Dependency Injection (внедрение зависимостей): обернуть конфигурацию в структуру `type Client struct { baseURL string }` и передавать её через конструктор `NewClient(baseURL)`. В этом случае тесты полностью независимы и могут спокойно выполняться параллельно с `t.Parallel()`.
