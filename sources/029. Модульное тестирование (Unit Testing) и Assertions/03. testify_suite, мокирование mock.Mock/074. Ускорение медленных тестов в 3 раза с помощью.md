# Ускорение медленных тестов в 3 раза с помощью t.Parallel

## Условие

**Параллельные тесты (`t.Parallel`)**: Создай 3 долгих теста (поставь `time.Sleep(1 * time.Second)` в каждый). Запусти `go test`. Они выполнятся за 3 секунды. Добавь `t.Parallel()` в начало каждого. Запусти снова — они должны выполниться за 1 секунду.

## Теория

Эффект масштабирования `t.Parallel()`:
- 3 последовательных теста по 100 мс требуют 300 мс процессорного времени.
- При вызове `t.Parallel()` раннер распределяет их по горутинам на разных ядрах процессора, сокращая суммарное время до времени самого длинного теста (~100 мс).
- Это ускоряет выполнение больших тестовых сьютов в разы.

## Решение по шагам

1. Создайте три теста с паузой 100 мс.
2. Добавьте `t.Parallel()` в начало каждого.
3. Запустите `go test -v` и зафиксируйте общее время ~0.10s.

## Код решения

**`speed_test.go`**

```go
package main

import (
	"testing"
	"time"
)

func TestJobOne(t *testing.T) {
	t.Parallel()
	time.Sleep(100 * time.Millisecond)
}

func TestJobTwo(t *testing.T) {
	t.Parallel()
	time.Sleep(100 * time.Millisecond)
}

func TestJobThree(t *testing.T) {
	t.Parallel()
	time.Sleep(100 * time.Millisecond)
}
```

ℹ️ Параллельные независимые тесты

**`Терминал`**

```bash
go test -v speed_test.go
# Вывод:
# === RUN   TestJobOne
# === PAUSE TestJobOne
# === RUN   TestJobTwo
# === PAUSE TestJobTwo
# === RUN   TestJobThree
# === PAUSE TestJobThree
# === CONT  TestJobOne
# === CONT  TestJobThree
# === CONT  TestJobTwo
# --- PASS: TestJobOne (0.10s)
# --- PASS: TestJobTwo (0.10s)
# --- PASS: TestJobThree (0.10s)
# PASS
# ok      command-line-arguments  0.105s
```

## Под капотом

Суммарное время выполнения трех тестов составило 0.105s вместо 0.300s благодаря параллелизму на системных тредах GMP рантайма Go.

## Подводные камни

Добавлять `t.Parallel()` в тесты, использующие несинхронизированные структуры данных или общие порты TCP.

## На собеседовании

**Вопрос с собеседования:** «Какое максимальное число параллельных тестов может быть запущено одновременно по умолчанию?»
**Ответ:** Значение равно значению `GOMAXPROCS` (число логических ядер процессора). Его можно переопределить флагом `-parallel N` (например `go test -parallel 16`).
