# Документирование методов структур: именование ExampleType_MethodName

## Условие

Создайте Example для конкретной структуры или метода: `ExampleUser_GetFullName()`.

## Теория

Соглашения об именовании в утилите `godoc`:
- Для пакета в целом: `func Example()`
- Для функции `Foo`: `func ExampleFoo()`
- Для структуры (типа) `User`: `func ExampleUser()`
- Для метода `GetFullName` типа `User`: `func ExampleUser_GetFullName()`
- Дополнительный суффикс через подчеркивание для разных сценариев: `func ExampleUser_GetFullName_withPrefix()`
Соблюдение этих правил связывает пример с нужным разделом документации.

## Решение по шагам

1. Создайте структуру `User` с методом `GetFullName() string`.
2. Создайте файл с примером `ExampleUser_GetFullName()`.
3. Добавьте директиву `// Output:`.
4. Запустите `go test`.

## Код решения

**`user_doc.go`**

```go
package main

import "fmt"

type User struct {
	FirstName string
	LastName  string
}

func (u User) GetFullName() string {
	return fmt.Sprintf("%s %s", u.FirstName, u.LastName)
}
```

ℹ️ Структура User и метод GetFullName

**`user_doc_example_test.go`**

```go
package main

import "fmt"

func ExampleUser_GetFullName() {
	u := User{
		FirstName: "Лев",
		LastName:  "Толстой",
	}

	fmt.Println(u.GetFullName())
	// Output:
	// Лев Толстой
}
```

ℹ️ Пример метода структуры с правильным именованием

**`Терминал`**

```bash
go test -v -run ExampleUser_GetFullName user_doc_example_test.go user_doc.go
# Вывод:
# === RUN   ExampleUser_GetFullName
# --- PASS: ExampleUser_GetFullName (0.00s)
# PASS
```

## Под капотом

Символ подчеркивания `_` в имени функции `Example` зарезервирован генератором документации Go как сепаратор между именем типа и именем метода.

## Подводные камни

Использовать имя `ExampleUserGetFullName` без подчеркивания: утилита документации подумает, что это пример для функции верхнего уровня с именем `UserGetFullName`.

## На собеседовании

**Вопрос с собеседования:** «Как спрятать вспомогательный код подготовки из отображения в документации Example?»
**Ответ:** Разместить код до первого пустого перевода строки, либо объявлять весь пример в теле функции. Все импорты и сама сигнатура функции `func Example...` в документации автоматически скрываются, отображая только полезное тело функции.
