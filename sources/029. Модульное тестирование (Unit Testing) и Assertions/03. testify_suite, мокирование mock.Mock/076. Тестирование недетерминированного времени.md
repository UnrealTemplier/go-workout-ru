# Тестирование недетерминированного времени: Dependency Injection через интерфейс Clock

## Условие

**Тестирование недетерминированного кода**: Напишите функцию `Greet() string`, которая возвращает `"Доброе утро"`, `"Добрый день"` или `"Добрый вечер"` в зависимости от текущего системного времени (`time.Now()`). Сделайте эту функцию тестируемой, передав интерфейс-зависимость `Clock` (с методом `Now() time.Time`) в качестве параметра. Напишите тест, передав туда фейковые (mock) часы, возвращающие фиксированное время.

## Теория

Прямой вызов `time.Now()` внутри бизнес-логики делает код недетерминированным:
- Тест, проверяющий утреннее приветствие, пройдет утром, но сломается вечером!
**Решение:** Принцип инверсии зависимостей (Dependency Injection):
1. Объявляется интерфейс `Clock { Now() time.Time }`.
2. В продакшене передается `RealClock` с реальным `time.Now()`.
3. В тестах передается `MockClock` с жестко зафиксированным временем.

## Решение по шагам

1. Объявите интерфейс `Clock`.
2. Напишите функцию `Greet(c Clock) string`.
3. Создайте мок часов `MockClock{fixedTime}`.
4. Проверьте генерацию приветствия для 8:00, 14:00 и 21:00.

## Код решения

**`greeter.go`**

```go
package main

import "time"

// Clock абстрагирует системное время
type Clock interface {
	Now() time.Time
}

type RealClock struct{}

func (RealClock) Now() time.Time {
	return time.Now()
}

func Greet(c Clock) string {
	hour := c.Now().Hour()
	if hour >= 6 && hour < 12 {
		return "Доброе утро"
	}
	if hour >= 12 && hour < 18 {
		return "Добрый день"
	}
	return "Добрый вечер"
}
```

ℹ️ Детерминированная функция с абстракцией времени

**`greeter_test.go`**

```go
package main

import (
	"testing"
	"time"
)

type MockClock struct {
	fixedTime time.Time
}

func (m MockClock) Now() time.Time {
	return m.fixedTime
}

func TestGreetDeterministic(t *testing.T) {
	tests := []struct {
		name     string
		testTime time.Time
		want     string
	}{
		{
			name:     "утро (08:30)",
			testTime: time.Date(2026, 9, 3, 8, 30, 0, 0, time.UTC),
			want:     "Доброе утро",
		},
		{
			name:     "день (15:00)",
			testTime: time.Date(2026, 9, 3, 15, 0, 0, 0, time.UTC),
			want:     "Добрый день",
		},
		{
			name:     "вечер (22:00)",
			testTime: time.Date(2026, 9, 3, 22, 0, 0, 0, time.UTC),
			want:     "Добрый вечер",
		},
	}

	for _, tc := range tests {
		t.Run(tc.name, func(t *testing.T) {
			clock := MockClock{fixedTime: tc.testTime}
			got := Greet(clock)
			if got != tc.want {
				t.Errorf("Greet() = %q; want %q", got, tc.want)
			}
		})
	}
}
```

## Под капотом

Интерфейс `Clock` превращает функцию из зависимой от внешнего состояния мира в чистую функцию (Pure Function), результат которой на 100% предсказуем по переданным аргументам.

## Подводные камни

Использовать глобальную переменную `var CurrentTime = time.Now` вместо внедрения зависимостей: в параллельных тестах изменение глобальной переменной вызовет гонки данных.

## На собеседовании

**Вопрос с собеседования:** «Как протестировать функцию с `time.Sleep` без реального ожидания секунд?»
**Ответ:** Заменить таймеры на виртуальное время через интерфейс (например библиотека `jonboulle/clockwork` или `miniredis.FastForward`), либо передавать `time.Duration` из конфигурации и выставлять в тестах микросекундные задержки.
