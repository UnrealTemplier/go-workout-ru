# Инспекция документации из консоли: утилита go doc и проверка примеров

## Условие

Сгенерируйте документацию через `go doc -all ./...` и убедитесь, что примеры отображаются корректно.

## Теория

Команда `go doc` — консольный просмотрщик документации Go:
- `go doc`: краткая сводка по текущему пакету.
- `go doc User`: документация по типу `User` со списком его методов.
- `go doc User.GetFullName`: детальная документация метода с отображением связанного примера `ExampleUser_GetFullName`!
- `go doc -all`: выводит всю документацию пакета со всеми примерами.

## Решение по шагам

1. Запустите `go doc` в каталоге с кодом и примером.
2. Убедитесь, что исходный код примера отображается в разделе EXAMPLES.
3. Проверьте форматирование.

## Код решения

**`doc_demo.go`**

```go
// Package mathutil предоставляет базовые математические утилиты.
package main

// Square возвращает квадрат целого числа.
func Square(n int) int {
	return n * n
}
```

ℹ️ Пакет с godoc комментариями

**`doc_demo_example_test.go`**

```go
package main

import "fmt"

func ExampleSquare() {
	fmt.Println(Square(6))
	// Output:
	// 36
}
```

ℹ️ Пример для функции Square

**`Терминал`**

```bash
# Просмотр документации и примера:
go doc -all Square
# Вывод:
# package main // import "."
#
# func Square(n int) int
#     Square возвращает квадрат целого числа.
#
# Examples:
#     Square
```

## Под капотом

`go doc` парсит абстрактное синтаксическое дерево (AST) файлов пакета и файлов `*_test.go`, находит узлы объявлений функций и связывает комментарии docstring с соответствующими узлами `Example`.

## Подводные камни

Писать комментарии к функции без отступа или начинать их не с имени функции: `go doc` требует, чтобы комментарий начинался строго с имени документируемого идентификатора (например `// Square возвращает...`).

## На собеседовании

**Вопрос с собеседования:** «Как запустить локальный веб-сервер с документацией всех пакетов аналогичный pkg.go.dev?»
**Ответ:** С помощью утилиты `pkgsite`: `go run golang.org/x/pkgsite/cmd/pkgsite@latest -http=:6060`. В браузере по адресу `http://localhost:6060` откроется полноценная веб-версия документации со всеми интерактивными примерами и поиском.
