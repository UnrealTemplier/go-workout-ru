# Контроль кратности вызовов: метод mock.AssertNumberOfCalls

## Условие

Проверьте, что метод был вызван ровно N раз с помощью `mock.AssertNumberOfCalls`.

## Теория

При тестировании идемпотентности, кэширования или ретраев (Retry Policy) критично проверить, сколько раз был вызван нижележащий метод:
- `mock.AssertNumberOfCalls(t, "MethodName", expectedCount)`: проверяет точное число вызовов.
- `mock.AssertNotCalled(t, "MethodName")`: гарантирует, что метод ни разу не вызывался (например, при попадании в кэш).

## Решение по шагам

1. Создайте сервис кэширования с моком источника данных.
2. Сделайте 3 запроса (1 промах кэша, 2 попадания).
3. Проверьте, что источник был вызван ровно 1 раз.

## Код решения

**`calls_test.go`**

```go
package main

import (
	"testing"

	"github.com/stretchr/testify/mock"
)

type PaymentGateway interface {
	Charge(amount int) bool
}

type MockGateway struct {
	mock.Mock
}

func (m *MockGateway) Charge(amount int) bool {
	args := m.Called(amount)
	return args.Bool(0)
}

func TestRetryAttemptsCount(t *testing.T) {
	gateway := new(MockGateway)

	// Ожидаем 3 вызова при ретраях
	gateway.On("Charge", 500).Return(false).Times(3)

	// Имитация 3 попыток оплаты
	for i := 0; i < 3; i++ {
		_ = gateway.Charge(500)
	}

	// Проверяем точную кратность вызовов
	gateway.AssertNumberOfCalls(t, "Charge", 3)
}
```

ℹ️ Проверка кратности вызовов через AssertNumberOfCalls

**`Терминал`**

```bash
go test -v calls_test.go
# Вывод:
# === RUN   TestRetryAttemptsCount
# --- PASS: TestRetryAttemptsCount (0.00s)
# PASS
```

## Под капотом

`Times(3)` на объекте вызова ожидает ровно 3 срабатывания. `AssertNumberOfCalls` фильтрует срез истории вызовов `Calls` по имени метода и сравнивает размер списка с ожидаемым числом.

## Подводные камни

Использовать вызов `AssertNumberOfCalls` без предварительной настройки `On()`.

## На собеседовании

**Вопрос с собеседования:** «Зачем проверять mock.AssertNotCalled в тестах оптимизации кэширования?»
**Ответ:** Это единственный способ математически доказать, что слой кэширования реально отработал и сервис не пошел в дорогую базу данных или внешний HTTP-эндпоинт.
