# Утверждения паники через testify: assert.Panics и require.Panics

## Условие

Проверьте, что функция паникует: используйте `assert.Panics` / `require.Panics` для функции, которая вызывает `panic` при неверных аргументах.

## Теория

Библиотека `testify` предоставляет два уровня утверждения паник:
1. `assert.Panics(t, fn)`: фиксирует факт возникновения паники. Если функция не запаниковала, тест продолжается дальше.
2. `require.Panics(t, fn)`: если функция завершилась штатно без паники, тест НЕМЕДЛЕННО останавливается. Используется при проверке безопасности конструкторов и критических инвариантов.

## Решение по шагам

1. Напишите паникующую функцию `MustParseURL(rawURL string)`.
2. Проверьте её поведение на невалидном URL через `require.Panics`.
3. Убедитесь в корректности перехвата.

## Код решения

**`url_parser.go`**

```go
package main

import "net/url"

func MustParseURL(raw string) *url.URL {
	u, err := url.Parse(raw)
	if err != nil || u.Scheme == "" {
		panic("невалидный URL адрес: " + raw)
	}
	return u
}
```

ℹ️ Функция инициализации с гарантированной паникой при ошибке

**`url_parser_test.go`**

```go
package main

import (
	"testing"

	"github.com/stretchr/testify/assert"
	"github.com/stretchr/testify/require"
)

func TestMustParseURLPanics(t *testing.T) {
	// 1. Проверяем панику при невалидном вводе через require.Panics
	require.Panics(t, func() {
		MustParseURL(":::not-a-valid-url:::")
	}, "Парсинг битого URL обязан вызвать панику")

	// 2. Проверяем штатную работу без паники через assert.NotPanics
	assert.NotPanics(t, func() {
		u := MustParseURL("https://yandex.ru/search")
		assert.Equal(t, "https", u.Scheme)
	})
}
```

ℹ️ Проверка паники через testify

**`Терминал`**

```bash
go test -v url_parser_test.go url_parser.go
# Вывод:
# === RUN   TestMustParseURLPanics
# --- PASS: TestMustParseURLPanics (0.00s)
# PASS
```

## Под капотом

Внутри `require.Panics` исполняет `defer func() { if recover() == nil { t.FailNow() } }()`, защищая раннер тестов от вылета.

## Подводные камни

Вызывать тестируемый код вне замыкания: `require.Panics(t, func() { MustParseURL(...) })`. Если написать `require.Panics(t, nil)`, тест упадет по `nil function call`.

## На собеседовании

**Вопрос с собеседования:** «Как проверить, что функция выбросила панику конкретного типа структуры (например `*CustomPanic`)?»
**Ответ:** Использовать метод `assert.PanicsWithValue(t, expectedValue, fn)` или ручной перехват через `defer recover()` с последующим `if customErr, ok := r.(*CustomPanic); ok { ... }`.
