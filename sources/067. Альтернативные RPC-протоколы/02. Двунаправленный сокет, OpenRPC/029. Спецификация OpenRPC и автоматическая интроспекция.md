# Спецификация OpenRPC и автоматическая интроспекция API (rpc.discover)

## Условие

### Исходная формулировка

**OpenRPC specification**: Изучите OpenRPC (аналог OpenAPI для JSON-RPC). Генерируйте documentation и clients из spec.

## Теория

Подобно тому, как OpenAPI (Swagger) стандартизировал описание REST API, спецификация **OpenRPC** стандартизировала описание JSON-RPC 2.0 сервисов.

Возможности OpenRPC:
1. **Машиночитаемый документ схемы:** JSON-документ, содержащий перечень методов, типы параметров (JSON Schema), форматы возвращаемых результатов и коды ошибок.
2. **Встроенный метод интроспекции `rpc.discover`:**
   - Согласно спецификации OpenRPC Service Discovery, сервер должен поддерживать стандартный метод `rpc.discover`.
   - Вызов `{"jsonrpc":"2.0","method":"rpc.discover","id":1}` возвращает полную схему всех поддерживаемых сервером методов и их сигнатур.
3. **Инструментарий:** Автоматическая генерация интерактивной документации (OpenRPC Playground, Interactive Docs) и генерация SDK.

## Решение по шагам

1. Создайте структуру документа OpenRPC (`openrpc`, `info`, `methods`).
2. Зарегистрируйте метод `rpc.discover`.
3. Опишите метаданные для одного из доменных методов (например, `math.add`).
4. Верните спецификацию OpenRPC в ответе на `rpc.discover`.

## Код решения

**`openrpc_discover.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
)

type OpenRPCSchema struct {
	OpenRPC string         `json:"openrpc"`
	Info    OpenRPCInfo    `json:"info"`
	Methods []OpenRPCMethod `json:"methods"`
}

type OpenRPCInfo struct {
	Title   string `json:"title"`
	Version string `json:"version"`
}

type OpenRPCMethod struct {
	Name        string           `json:"name"`
	Description string           `json:"description"`
	Params      []OpenRPCParam   `json:"params"`
	Result      OpenRPCResultDoc `json:"result"`
}

type OpenRPCParam struct {
	Name     string         `json:"name"`
	Required bool           `json:"required"`
	Schema   map[string]any `json:"schema"`
}

type OpenRPCResultDoc struct {
	Name   string         `json:"name"`
	Schema map[string]any `json:"schema"`
}

var spec = OpenRPCSchema{
	OpenRPC: "1.2.6",
	Info: OpenRPCInfo{
		Title:   "Financial Math API",
		Version: "1.0.0",
	},
	Methods: []OpenRPCMethod{
		{
			Name:        "math.add",
			Description: "Adds two integer numbers together",
			Params: []OpenRPCParam{
				{Name: "a", Required: true, Schema: map[string]any{"type": "integer"}},
				{Name: "b", Required: true, Schema: map[string]any{"type": "integer"}},
			},
			Result: OpenRPCResultDoc{
				Name:   "sum",
				Schema: map[string]any{"type": "integer"},
			},
		},
	},
}

func rpcDiscoveryHandler(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json")

	var req struct {
		JSONRPC string `json:"jsonrpc"`
		Method  string `json:"method"`
		ID      any    `json:"id"`
	}

	_ = json.NewDecoder(r.Body).Decode(&req)

	if req.Method == "rpc.discover" {
		_ = json.NewEncoder(w).Encode(map[string]any{
			"jsonrpc": "2.0",
			"result":  spec,
			"id":      req.ID,
		})
		return
	}

	_ = json.NewEncoder(w).Encode(map[string]any{
		"jsonrpc": "2.0",
		"error":   map[string]any{"code": -32601, "message": "Method not found"},
		"id":      req.ID,
	})
}

func main() {
	http.HandleFunc("/rpc", rpcDiscoveryHandler)
	fmt.Println("OpenRPC discovery server running on :8080/rpc")
	_ = http.ListenAndServe(":8080", nil)
}
```

ℹ️ Реализация стандарта OpenRPC Service Discovery через метод rpc.discover

## Под капотом

Метод `rpc.discover` позволяет динамическим клиентам (например, CLI-утилитам или шлюзам API) подключаться к сервису, налету вычитывать список методов и строить интерактивный интерфейс командной строки без предварительного скачивания файлов документации.

## Подводные камни

Публикация приватных внутренних методов через `rpc.discover` во внешнем контуре. Перед отдачей схемы необходимо фильтровать методы по правам доступа текущего пользователя или отдавать только публичный срез API.

## На собеседовании

В Яндекс Cloud и VK часто спрашивают: 'В чем ключевое отличие OpenRPC от gRPC Reflection?' Ответ: gRPC Reflection оперирует скомпилированными бинарными дескрипторами `FileDescriptorProto`, требующими специальной библиотеки Protobuf для парсинга. OpenRPC отдает стандартный JSON Schema документ, который легко отображается в любом браузере и интегрируется с экосистемой веб-разработки.
