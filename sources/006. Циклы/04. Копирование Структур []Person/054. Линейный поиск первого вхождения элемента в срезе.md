# Линейный поиск первого вхождения элемента в срезе с флагом отсутствия

## Условие

Напиши программу, которая ищет **первое вхождение** элемента в слайсе. Используй `for` с `break` при нахождении. Если элемент не найден — выведи сообщение после цикла (используй флаг или проверку индекса).

## Теория

Алгоритм линейного поиска \(O(N)\) с ранним прерыванием.

## Решение по шагам

1. Инициализируем `foundIndex := -1`.
2. В цикле проверяем `val == target`.
3. При нахождении сохраняем индекс и вызываем `break`.
4. После цикла проверяем `if foundIndex != -1`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func FindFirstIndex(slice []string, target string) int {
	foundIndex := -1

	for i, v := range slice {
		if v == target {
			foundIndex = i
			break // Элемент найден -> немедленный выход
		}
	}

	return foundIndex
}

func main() {
	cities := []string{"Москва", "Санкт-Петербург", "Казань", "Новосибирск"}

	idx1 := FindFirstIndex(cities, "Казань")
	if idx1 != -1 {
		fmt.Printf("Город 'Казань' найден по индексу %d\n", idx1)
	} else {
		fmt.Println("Город не найден")
	}

	idx2 := FindFirstIndex(cities, "Сочи")
	if idx2 != -1 {
		fmt.Printf("Город 'Сочи' найден по индексу %d\n", idx2)
	} else {
		fmt.Println("Город 'Сочи' отсутствует в списке")
	}
}
```

ℹ️ Линейный поиск первого вхождения

**`Терминал`**

```bash
go run main.go
# Город 'Казань' найден по индексу 2
# Город 'Сочи' отсутствует в списке
```

ℹ️ Результат

## Под капотом

Раннее прерывание через `break` делает среднюю сложность поиска равной \(N/2\).

## Подводные камни

- Использование флага `found := false` без сохранения индекса элемента.

## На собеседовании

**Вопрос с собеседования:** «Какая функция появилась в Go 1.21 в стандартном пакете `slices` для поиска индекса?»
**Ответ:** `slices.Index(s, target)` (возвращает индекс или `-1`) и `slices.IndexFunc(s, predicate)`.
