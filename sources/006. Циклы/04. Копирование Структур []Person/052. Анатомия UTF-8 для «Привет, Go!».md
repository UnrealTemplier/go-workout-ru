# Анатомия UTF-8 для «Привет, Go!»: почему string(str[i]) ломает кириллицу, а range декодирует руны

## Условие

**`Range` по строке (байты vs руны)**: Объяви строку `str := "Привет, Go!"`. Перебери её через классический цикл `for i := 0; i < len(str); i++` и выведи символы (через `string(str[i])`). Затем перебери её через `for index, char := range str`. Сравни вывод. Пойми, почему первый вариант ломает кириллицу, а `range` корректно читает руны, перескакивая через индексы (0, 2, 4...).

## Теория

**Разбор кодирования UTF-8:**
- Слово «Привет» состоит из 6 кириллических букв по 2 байта каждая = 12 байт;
- Символы «, Go!» занимают по 1 байту = 5 байт;
- Всего в строке: \(12 + 5 = 17\) байт и ровно 11 рун;
- Побайтовый цикл выполнит 17 итераций и разобьет 2-байтовые руны пополам;
- `for range` выполнит 11 итераций и вернет целые руны.

## Решение по шагам

1. Задаем `str := "Привет, Go!"`.
2. Запускаем побайтовый цикл `for i := 0; i < len(str); i++`.
3. Запускаем посимвольный цикл `for idx, r := range str`.
4. Сравниваем результаты.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	str := "Привет, Go!"
	fmt.Printf("Строка: %q | Байт: %d | Рун: %d\n\n",
		str, len(str), utf8.RuneCountInString(str))

	// 1. Побайтовый цикл:
	fmt.Println("1. Побайтовый цикл for i := 0; i < len(str); i++:")
	for i := 0; i < len(str); i++ {
		fmt.Printf("   [%2d] = 0x%02X (%s)\n", i, str[i], string(str[i]))
	}

	// 2. Посимвольный for-range:
	fmt.Println("\n2. Посимвольный цикл for index, char := range str:")
	for idx, char := range str {
		fmt.Printf("   Индекс %-2d -> Символ: %c (код: %d)\n", idx, char, char)
	}
}
```

## На собеседовании

**Вопрос с собеседования:** «Почему в Go тип `string` спроектирован как неизменяемый срез байт `[]byte`, а не срез рун `[]rune`?»
**Ответ:** Для максимальной компактности в памяти и совместимости с сетевыми сокетами, файловыми дескрипторами ОС и протоколами HTTP/JSON, которые оперируют сырыми байтами.
