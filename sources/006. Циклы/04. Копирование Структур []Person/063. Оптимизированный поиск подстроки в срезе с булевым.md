# Оптимизированный поиск подстроки в срезе с булевым флагом и ранним выходом break

## Условие

Поиск подстроки с циклом и флагом: проверьте, содержится ли слово "Go" в заранее заданном срезе строк, используя булев флаг и break для оптимизации.

### Исходная формулировка

**Поиск подстроки с циклом и флагом**: проверьте, содержится ли слово "Go" в заранее заданном срезе строк, используя булев флаг и `break` для оптимизации.

## Теория

Паттерн линейного сканирования с ранним отсечением `break`.

## Решение по шагам

1. Инициализируем `found := false`.
2. В цикле сравниваем элементы с целевым словом `"Go"`.
3. При первом совпадении выставляем `found = true` и делаем `break`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func ContainsWord(words []string, target string) bool {
	found := false

	for _, w := range words {
		if w == target {
			found = true
			break // Оптимизация: прекращаем перебор
		}
	}

	return found
}

func main() {
	stack := []string{"Docker", "Kubernetes", "Go", "PostgreSQL", "Kafka"}

	if ContainsWord(stack, "Go") {
		fmt.Println("✔ Стек содержит целевую технологию 'Go'!")
	} else {
		fmt.Println("❌ Технология отсутствует в стеке")
	}
}
```

ℹ️ Поиск с флагом и break

**`Терминал`**

```bash
go run main.go
# ✔ Стек содержит целевую технологию 'Go'!
```
