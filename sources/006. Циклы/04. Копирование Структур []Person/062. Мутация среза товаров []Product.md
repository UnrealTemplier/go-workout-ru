# Мутация среза товаров []Product: почему prod.Price = 100 не работает и как исправить

## Условие

Каверзный случай: Копирование значений в for range: Создайте срез структур []Product{{Name: "A", Price: 10}, {Name: "B", Price: 20}}. Напишите цикл for _, prod := range products { prod.Price = 100 }. Выведите исходный срез после цикла. Изменились ли цены продуктов? Напишите правильный вариант (products[i].Price = 100).

### Исходная формулировка

**Каверзный случай: Копирование значений в `for range`**: * Создайте срез структур `[]Product{{Name: "A", Price: 10}, {Name: "B", Price: 20}}`.
* Напишите цикл `for _, prod := range products { prod.Price = 100 }`.
* Выведите исходный срез после цикла. Изменились ли цены продуктов?
* Напишите правильный вариант изменения элементов среза в цикле (через обращение по индексу: `products[i].Price = 100`) и объясните, почему первый вариант не сработал (подсказка: переменная цикла `prod` получает лишь копию элемента на каждой итерации).

## Теория

Финальный разбор антипаттерна копирования структур в `range`.

## Решение по шагам

1. Создаем структуру `Product{Name string, Price int}`.
2. Демонстрируем безуспешную попытку мутации через копию `prod`.
3. Демонстрируем успешную мутацию по индексу `products[i].Price = 100`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Product struct {
	Name  string
	Price int
}

func main() {
	products := []Product{
		{Name: "Ноутбук", Price: 80000},
		{Name: "Мышь", Price: 2500},
	}
	fmt.Printf("1. Исходные цены:    %+v\n", products)

	// Попытка 1: через копию (НЕ РАБОТАЕТ)
	for _, prod := range products {
		prod.Price = 100
	}
	fmt.Printf("2. После _, prod :=: %+v (Цены НЕ изменились!)\n", products)

	// Попытка 2: через индекс (РАБОТАЕТ)
	for i := range products {
		products[i].Price = 100
	}
	fmt.Printf("3. После products[i]: %+v (Цены успешно обновлены!)\n", products)
}
```

## Под капотом

При `products[i].Price = 100` компилятор пишет константу `100` со смещением `+8` от базового адреса `i`-го элемента.

## Подводные камни

- Забыть, что `prod` — это локальная переменная.

## На собеседовании

**Вопрос с собеседования:** «Как сделать так, чтобы `for _, prod := range products` мог мутировать структуры напрямую?»
**Ответ:** Объявить срез указателей `[]*Product`. В этом случае `prod` будет хранить указатель `*Product`, и изменение `prod.Price = 100` мутирует объект в памяти.
