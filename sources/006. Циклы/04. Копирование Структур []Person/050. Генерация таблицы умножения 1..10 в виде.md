# Генерация таблицы умножения 1..10 в виде моноширинной координатной сетки

## Условие

**Вложенные циклы**: Напишите программу, которая выводит в консоль таблицу умножения от 1 до 10 в виде аккуратной сетки.

## Теория

Форматирование двумерных числовых массивов.

## Решение по шагам

1. Запускаем двойной цикл `i` (1..10) и `j` (1..10).
2. Форматируем вывод через `%4d`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	fmt.Println("=== СЕТКА ТАБЛИЦЫ УМНОЖЕНИЯ ===")
	for i := 1; i <= 10; i++ {
		for j := 1; j <= 10; j++ {
			fmt.Printf("%4d", i*j)
		}
		fmt.Println()
	}
}
```
