## Теория

**Алгоритм проверки правильной скобочной последовательности (Valid Parentheses):**
1. Используем срез `[]rune` как стек (LIFO);
2. При встрече открывающей скобки (`(`, `[`, `{`) делаем `stack = append(stack, r)` (Push);
3. При встрече закрывающей скобки:
   - Если стек пуст \(\rightarrow\) скобка не сбалансирована (`false`);
   - Снимаем верхний элемент `top := stack[len(stack)-1]` (Pop) и проверяем соответствие пар;
4. В конце строка валидна, если стек полностью пуст (`len(stack) == 0`).

## Решение по шагам

1. Пишем функцию `IsValidParentheses(s string) bool`.
2. Реализуем стек на срезе.
3. Тестируем валидные и невалидные строки.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func IsValidParentheses(s string) bool {
	var stack []rune
	matching := map[rune]rune{
		')': '(',
		']': '[',
		'}': '{',
	}

	for _, r := range s {
		switch r {
		case '(', '[', '{':
			// Push в стек
			stack = append(stack, r)
		case ')', ']', '}':
			// Проверяем соответствие закрывающей скобки
			if len(stack) == 0 {
				return false // Нет открывающей скобки
			}
			top := stack[len(stack)-1]
			stack = stack[:len(stack)-1] // Pop из стека

			if top != matching[r] {
				return false // Несовпадение типов скобок
			}
		}
	}

	return len(stack) == 0
}

func main() {
	tests := []string{
		"({[]})",
		"()[]{}",
		"(]",
		"([)]",
		"{[()]}",
		"(((",
	}

	for _, t := range tests {
		fmt.Printf("Строка %-10q -> Сбалансирована: %t\n", t, IsValidParentheses(t))
	}
}
```

## Под капотом

Срез `stack[:len(stack)-1]` уменьшает длину `len` за 1 такт CPU без перевыделения памяти.

## Подводные камни

- Забыть проверку `len(stack) == 0` в самом конце функции: для строки `"((("` без проверки функция ошибочно вернула бы `true`.

## На собеседовании

**Вопрос с собеседования:** «Какова временная и пространственная сложность проверки скобочной последовательности?»
**Ответ:** Время \(O(N)\) (один проход по строке), память \(O(N)\) в худшем случае (если все скобки открывающие).
