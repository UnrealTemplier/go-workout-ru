# Прерывание двух уровней вложенности циклов по метке break MainGrid при i == 3 && j == 3

## Условие

**Выход из вложенного цикла (Метки/Labels)**: Создайте два вложенных цикла (внешний по `i` от 1 до 5, внутренний по `j` от 1 до 5). Напишите условие: если `i == 3` и `j == 3`, нужно полностью прервать оба цикла. Используйте для этого именованную метку (label) перед внешним циклом и команду `break ИМЯ_МЕТКИ`.

## Теория

Закрепление синтаксиса `break Label`.

## Решение по шагам

1. Ставим метку `MainGrid:`.
2. Запускаем циклы 1..5.
3. При `i == 3 && j == 3` вызываем `break MainGrid`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	fmt.Println("Запуск сканирования сетки 5x5:")

MainGrid:
	for i := 1; i <= 5; i++ {
		for j := 1; j <= 5; j++ {
			fmt.Printf("Координата [%d, %d]\n", i, j)
			if i == 3 && j == 3 {
				fmt.Println("🛑 Достигнута точка остановки [3, 3]! Выход из обоих циклов!")
				break MainGrid
			}
		}
	}

	fmt.Println("Сканирование завершено.")
}
```

ℹ️ Вывод

## Под капотом

Метка формирует прямое смещение `JMP` на инструкцию после внешнего цикла.

## Подводные камни

- Использование обычного `break`, что приведет к выполнению строк 4 и 5.

## На собеседовании

**Вопрос с собеседования:** «Каковы альтернативы `break Label` при выходе из вложенных циклов?»
**Ответ:** 1) Вынос циклов в отдельную функцию и использование `return`; 2) Использование булева флага `interrupted = true`.
