# Глубокое сравнение for range по статическому массиву [5]int и динамическому срезу []int

## Условие

Напиши программу с `for-range` по **массиву** `[5]int` (не слайсу!). Покажи, что range копирует значение элемента в переменную цикла. Измени переменную внутри цикла — покажи, что оригинальный массив не меняется. Затем сделай то же с **слайсом** — покажи разницу.

## Теория

**Разница между `range arr` и `range slice`:**
1. При `for _, v := range arr` массив `[5]int` **целиком копируется** в заголовок `range` перед началом цикла;
2. При `for _, v := range slice` копируется только 24-байтный дескриптор `SliceHeader` (указатель, длина, емкость);
3. Модификация `v` ни в массиве, ни в срезе не затрагивает оригинал;
4. Модификация `arr[i] = ...` внутри `for i := range arr` меняет оригинальный массив, но не копию в заголовке `range`.

## Решение по шагам

1. Создаем массив `[5]int{1, 2, 3, 4, 5}`.
2. Проходим `for _, v := range arr` и пробуем менять `v`.
3. Создаем срез `[]int{1, 2, 3, 4, 5}` и повторяем проверку.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	// 1. Статический массив [5]int
	arr := [5]int{1, 2, 3, 4, 5}
	for _, v := range arr {
		v *= 100 // Меняет только копию v
	}
	fmt.Printf("Массив после range: %v (значения те же)\n", arr)

	// Прямая мутация массива по индексу:
	for i := range arr {
		arr[i] *= 100
	}
	fmt.Printf("Массив после arr[i]: %v (изменен!)\n", arr)

	// 2. Срез []int
	slice := []int{10, 20, 30}
	for i := range slice {
		slice[i] *= 2
	}
	fmt.Printf("Срез после slice[i]: %v (изменен!)\n", slice)
}
```

ℹ️ Сравнение массива и среза в range

**`Терминал`**

```bash
go run main.go
# Массив после range: [1 2 3 4 5] (значения те же)
# Массив после arr[i]: [100 200 300 400 500] (изменен!)
# Срез после slice[i]: [20 40 60] (изменен!)
```

## Под капотом

Для среза `range` оперирует `SliceHeader` (3 регистра), а для большого массива `[1000]int` `range` скопирует все 8 КБ данных в стек.

## Подводные камни

- Вызов `for range bigArray` для массива на 100 МБ: вызовет копирование всех 100 МБ памяти! Чтобы избежать копирования, передают срез `for range bigArray[:]` или указатель `for range &bigArray`.

## На собеседовании

**Вопрос с собеседования:** «Как безопасно итерировать большой массив `[1000000]int` без накладных расходов на копирование?»
**Ответ:** Использовать срез от массива `for i, v := range arr[:]` или указатель на массив `for i, v := range &arr`.
