# Ловушка копирования структур в for range (почему p.Age++ не меняет []Person)

## Условие

**Каверза `for range`**: создайте срез структур `[]Person`, пройдите по нему с `for _, p := range`, попробуйте изменить поле у `p` и объясните, почему оригинальный срез не изменился.

## Теория

**Копирование структур по значению (Pass by Value):**
- Переменная `p` в `for _, p := range people` является отдельной локальной копией структуры `Person`;
- Изменение `p.Age++` меняет только локальную копию в стеке и стирается на следующей итерации;
- Для реального изменения данных в срезе используют прямой доступ по индексу: `people[i].Age++` или срез указателей `[]*Person`.

## Решение по шагам

1. Создаем структуру `Person{Name string, Age int}`.
2. Создаем срез `[]Person`.
3. Показываем ошибку новичка с `p.Age = 99`.
4. Демонстрируем правильное исправление `people[i].Age = 99`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Person struct {
	Name string
	Age  int
}

func main() {
	people := []Person{
		{Name: "Иван", Age: 20},
		{Name: "Анна", Age: 25},
	}
	fmt.Printf("1. Исходный срез:   %+v\n", people)

	// ОШИБКА: p — это независимая копия структуры
	for _, p := range people {
		p.Age = 99 // Изменяется только копия!
	}
	fmt.Printf("2. После _, p :=:   %+v (НЕ изменился!)\n", people)

	// ПРАВИЛЬНО: изменение по индексу
	for i := range people {
		people[i].Age = 99 // Изменяется оригинальная структура в срезе
	}
	fmt.Printf("3. После people[i]: %+v (УСПЕШНО!)\n", people)
}
```

ℹ️ Копирование структур в range

**`Терминал`**

```bash
go run main.go
# 1. Исходный срез:   [{Name:Иван Age:20} {Name:Анна Age:25}]
# 2. После _, p :=:   [{Name:Иван Age:20} {Name:Анна Age:25}] (НЕ изменился!)
# 3. После people[i]: [{Name:Иван Age:99} {Name:Анна Age:99}] (УСПЕШНО!)
```

ℹ️ Результаты мутации

## Под капотом

При `for _, p := range` компилятор выполняет операцию побайтового копирования памяти `runtime.memmove` размера `sizeof(Person)` в стековый слот `p`.

## Подводные камни

- Попытка мутировать срез структур в цикле `for _, p := range people`.

## На собеседовании

**Вопрос с собеседования:** «Что производительнее для среза на 1 000 000 структур размером 128 байт: `for i := range` или `for _, s := range`?»
**Ответ:** `for i := range` в десятки раз быстрее, так как не тратит время и пропускную способность шины памяти на копирование 128 МБ данных на каждой итерации.
