# Бесконечный цикл for { ... } с чтением строк и прерыванием по break

## Условие

**Бесконечный цикл**: Напиши `for { ... }`. Внутри запрашивай у пользователя ввод текста. Если он ввел "exit", прерви цикл с помощью `break`.

## Теория

Интерактивный сканер строк до ввода стоп-слова.

## Решение по шагам

1. Инициализируем поток команд.
2. В цикле проверяем `"exit"`.
3. При наступлении делаем `break`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	stream := []string{"start", "status", "ping", "exit"}
	step := 0

	for {
		if step >= len(stream) {
			break
		}
		cmd := strings.ToLower(stream[step])
		step++

		fmt.Printf("Обработка команды: %q\n", cmd)
		if cmd == "exit" {
			fmt.Println("🛑 Сессия завершена через break")
			break
		}
	}
}
```

ℹ️ Бесконечный цикл с break

**`Терминал`**

```bash
go run main.go
# Обработка команды: "start"
# Обработка команды: "status"
# Обработка команды: "ping"
# Обработка команды: "exit"
# 🛑 Сессия завершена через break
```

ℹ️ Вывод

## Под капотом

Безусловный переход `JMP` на метку выхода.

## Подводные камни

- Игнорирование регистра команды (например `"EXIT"`).

## На собеседовании

**Вопрос с собеседования:** «Как сделать неблокирующее чтение в цикле `for`?»
**Ответ:** Использовать каналы и конструкцию `select` с веткой `default:` (`select { case msg := <-ch: ... default: // делаем другую работу }`).
