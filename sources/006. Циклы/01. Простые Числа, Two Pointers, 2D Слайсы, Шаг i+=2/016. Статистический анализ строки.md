# Статистический анализ строки: подсчет букв, цифр и пробелов через for range

## Условие

**`for range` по строке**: подсчитайте количество букв, цифр и пробелов в строке, используя `for _, r := range s`.

## Теория

**Посимвольный обход UTF-8 через `for _, r := range s`:**
- `r` имеет тип `rune` (`int32`);
- Пакет `unicode` предоставляет предикаты:
  - `unicode.IsLetter(r)` — буквы любых алфавитов;
  - `unicode.IsDigit(r)` — десятичные цифры;
  - `unicode.IsSpace(r)` — пробелы, табуляции и переводы строк.

## Решение по шагам

1. Инициализируем счетчики `letters`, `digits`, `spaces`, `others`.
2. В цикле `for _, r := range text` классифицируем каждую руну.
3. Выводим итоговую статистику.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"unicode"
)

type StringStats struct {
	Letters int
	Digits  int
	Spaces  int
	Others  int
}

func AnalyzeString(text string) StringStats {
	var stats StringStats

	for _, r := range text {
		switch {
		case unicode.IsLetter(r):
			stats.Letters++
		case unicode.IsDigit(r):
			stats.Digits++
		case unicode.IsSpace(r):
			stats.Spaces++
		default:
			stats.Others++
		}
	}

	return stats
}

func main() {
	sample := "Go 1.22: Релиз состоялся в 2024 году! 🚀"
	stats := AnalyzeString(sample)

	fmt.Printf("Исходный текст: %q\n", sample)
	fmt.Printf(" • Букв:    %d\n", stats.Letters)
	fmt.Printf(" • Цифр:    %d\n", stats.Digits)
	fmt.Printf(" • Пробелов:%d\n", stats.Spaces)
	fmt.Printf(" • Прочих:  %d\n", stats.Others)
}
```

## Под капотом

`for range` над строкой неявно вызывает декодер `runtime.decoderune`, возвращающий 4-байтную руну и её длину в байтах.

## Подводные камни

- Использование ручных проверок ASCII вроде `r >= 'a' && r <= 'z'`, которые проигнорируют кириллицу и другие языки мира. Всегда используйте `unicode.IsLetter`.

## На собеседовании

**Вопрос с собеседования:** «Почему эмодзи '🚀' попадает в категорию `Others`, а не букв или цифр?»
**Ответ:** Потому что в стандарте Unicode эмодзи классифицируются как графические символы `unicode.Symbol`, а не буквы или цифры.
