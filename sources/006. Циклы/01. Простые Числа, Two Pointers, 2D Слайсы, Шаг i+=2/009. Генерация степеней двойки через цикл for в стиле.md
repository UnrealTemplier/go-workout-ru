# Генерация степеней двойки через цикл for в стиле while (for n < 1000)

## Условие

**`For` как `while`**: Опусти блок инициализации и шага. Напиши цикл, который начинается с `n := 1` и умножает `n` на 2, пока `n < 1000`. (Вывод степеней двойки).

## Теория

**Синтаксис `for condition` (while-style):**
- Инициализация переменной выполняется до цикла;
- Шаг изменения переменной выполняется явно внутри тела;
- Прекращается, как только условие `n < 1000` становится ложным.

## Решение по шагам

1. Объявляем `n := 1` и `power := 0`.
2. Запускаем `for n < 1000`.
3. Печатаем текущую степень и умножаем `n *= 2`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	n := 1
	power := 0

	fmt.Println("Степени двойки (до 1000):")
	// for в роли while:
	for n < 1000 {
		fmt.Printf("2^%-2d = %4d\n", power, n)
		n *= 2
		power++
	}
}
```

ℹ️ Степени двойки через for-while

**`Терминал`**


## Под капотом

Инструкция битового сдвига `SHLQ $1, reg` умножает число на 2 за 1 такт.

## Подводные камни

- Пропуск модификации `n *= 2` внутри тела приведет к бесконечному зацикливанию.

## На собеседовании

**Вопрос с собеседования:** «Как быстро проверить, является ли положительное число степенью двойки без цикла?»
**Ответ:** Побитовым выражением `(n > 0) && (n & (n - 1) == 0)`.
