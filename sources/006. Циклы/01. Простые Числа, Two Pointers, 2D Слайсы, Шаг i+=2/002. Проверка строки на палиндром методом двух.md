# Проверка строки на палиндром методом двух указателей (Two Pointers) без аллокаций

## Условие

**Палиндром**: Напишите функцию, которая с помощью цикла (без использования `reverse`-слайсов) проверяет, является ли строка палиндромом, сравнивая символы с начала и с конца.

## Теория

**Паттерн Two Pointers (Встречные указатели):**
1. Инициализируем левый индекс `left := 0` и правый индекс `right := len(runes) - 1`;
2. На каждой итерации сравниваем символы `runes[left] != runes[right]`;
3. При несовпадении немедленно возвращаем `false`;
4. Двигаем указатели навстречу друг другу: `left++`, `right--`, пока `left < right`;
5. Память: \(O(1)\) дополнительных аллокаций для ASCII (или \(O(N)\) при конвертации в `[]rune` для Unicode).

## Решение по шагам

1. Приводим строку к нижнему регистру и преобразуем в `[]rune` для корректной поддержки UTF-8.
2. Запускаем цикл со сходящимися указателями `left` и `right`.
3. Сравниваем руны и возвращаем булев результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strings"
	"unicode"
)

func IsPalindrome(s string) bool {
	// Очищаем от пробелов и приводим к нижнему регистру
	var runes []rune
	for _, r := range strings.ToLower(s) {
		if unicode.IsLetter(r) || unicode.IsDigit(r) {
			runes = append(runes, r)
		}
	}

	left := 0
	right := len(runes) - 1

	for left < right {
		if runes[left] != runes[right] {
			return false // Символы не совпали -> не палиндром
		}
		left++
		right--
	}

	return true
}

func main() {
	phrases := []string{
		"А роза упала на лапу Азора",
		"Madam, I'm Adam",
		"Golang Workout",
		"топот",
	}

	for _, p := range phrases {
		fmt.Printf("%-30q -> Палиндром: %t\n", p, IsPalindrome(p))
	}
}
```

ℹ️ Проверка палиндрома на Two Pointers

**`Терминал`**

```bash
go run main.go
# "А роза упала на лапу Азора"    -> Палиндром: true
# "Madam, I'm Adam"              -> Палиндром: true
# "Golang Workout"               -> Палиндром: false
# "топот"                        -> Палиндром: true
```

## Под капотом

Алгоритм Two Pointers выполняет не более \(N/2\) итераций и не создает перевернутых копий строки в памяти.

## Подводные камни

- Побайтовое сравнение `s[left] != s[right]` для кириллических строк: русская буква состоит из 2 байт, поэтому побайтовый цикл сломает кодировку.

## На собеседовании

**Вопрос с собеседования:** «Какова временная и пространственная сложность проверки палиндрома без очистки строки?»
**Ответ:** Время \(O(N)\), память \(O(1)\) (если обходить байты для ASCII или декодировать руны на лету через `utf8.DecodeRune` и `utf8.DecodeLastRune`).
