# Форматированный табличный вывод двумерной матрицы (2D Slice) через вложенный for range

## Условие

**Матрица (2D слайс)**: Создайте слайс слайсов (таблицу). С помощью вложенных циклов `range` выведите её в консоль в виде ровной сетки.

## Теория

**Двумерный срез (`[][]T`):**
- В Go матрицы представляются как срез срезов («Jagged Array»);
- Внешний `for rIdx, row := range matrix` итерирует по строкам;
- Внутренний `for cIdx, val := range row` итерирует по столбцам;
- Спецификатор `%4d` обеспечивает строгую моноширинную сетку.

## Решение по шагам

1. Создаем матрицу \(3 \times 4\).
2. Внешним циклом обходим строки.
3. Внутренним циклом выводим элементы с выравниванием `fmt.Printf("%4d", val)`.
4. В конце каждой строки делаем `fmt.Println()`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func PrintMatrix(matrix [][]int) {
	for rowIdx, row := range matrix {
		fmt.Printf("Строка [%d]: |", rowIdx)
		for _, val := range row {
			fmt.Printf("%5d", val)
		}
		fmt.Println("  |")
	}
}

func main() {
	grid := [][]int{
		{1, 25, 300, 4},
		{50, 6, 70, 888},
		{9, 100, 11, 12},
	}

	fmt.Println("Вывод двумерной матрицы:")
	PrintMatrix(grid)
}
```

ℹ️ Табличный вывод 2D-среза

**`Терминал`**

```bash
go run main.go
# Вывод двумерной матрицы:
# Строка [0]: |    1   25  300    4  |
# Строка [1]: |   50    6   70  888  |
# Строка [2]: |    9  100   11   12  |
```

ℹ️ Ровная сетка матрицы

## Под капотом

`[][]int` — это срез структур `SliceHeader`, каждая из которых указывает на отдельный непрерывный блок памяти своей строки.

## Подводные камни

- Строки матрицы `[][]int` могут иметь разную длину, поэтому расчет индексов столбцов требует проверки `len(matrix[i])`.

## На собеседовании

**Вопрос с собеседования:** «Почему одномерный срез `[]int` размера \(N \times M\) эффективнее двумерного `[][]int` для высоконагруженных матричных вычислений?»
**Ответ:** Одномерный срез гарантирует 100% непрерывность в оперативной памяти (Contiguous Memory Layout), исключает фрагментацию и позволяет процессору эффективно задействовать L1/L2 кэш-линии (Cache Locality).
