# Итерация по хэш-таблице map[string]int с извлечением пар ключ-значение

## Условие

**`for range` по `map`**: пройдите по `map[string]int{"a":1, "b":2}` и выведите ключ-значение.

## Теория

**`for key, val := range m`:**
- Обходит все элементы хэш-таблицы;
- Извлекает ключ и соответствующее ему значение;
- Порядок обхода рандомизируется рантаймом.

## Решение по шагам

1. Создаем мапу `map[string]int{"a": 1, "b": 2, "c": 3}`.
2. Обходим через `for k, v := range`.
3. Выводим пары ключ-значение.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	scores := map[string]int{
		"a": 100,
		"b": 200,
		"c": 300,
	}

	for key, val := range scores {
		fmt.Printf("Ключ: %q | Значение: %d\n", key, val)
	}
}
```

ℹ️ Итерация по map

**`Терминал`**

```bash
go run main.go
# Ключ: "a" | Значение: 100
# Ключ: "b" | Значение: 200
# Ключ: "c" | Значение: 300
```

ℹ️ Вывод

## Под капотом

Рантайм использует структуру `hiter` и функцию `runtime.mapiterinit`, выбирая случайный стартовый бакет (Bucket Randomization).

## Подводные камни

- Написание кода, полагающегося на фиксированный порядок ключей в `map`.

## На собеседовании

**Вопрос с собеседования:** «Как обойти `map` в гарантированно детерминированном порядке ключей?»
**Ответ:** Собрать все ключи в срез `keys := make([]string, 0, len(m))`, отсортировать его через `slices.Sort(keys)` и итерироваться по отсортированному срезу ключей.
