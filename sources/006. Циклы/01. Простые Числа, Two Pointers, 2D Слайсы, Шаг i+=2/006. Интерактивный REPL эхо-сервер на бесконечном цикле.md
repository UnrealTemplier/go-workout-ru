# Интерактивный REPL эхо-сервер на бесконечном цикле for { ... break }

## Условие

**Бесконечный цикл с явным выходом**: `for { ... break }` – читайте ввод и выводите удвоенную строку, пока не будет введено `"exit"`.

## Теория

Паттерн бесконечного командного цикла с прерыванием по стоп-слову.

## Решение по шагам

1. Симулируем поток ввода.
2. В цикле проверяем условие `input == "exit"`.
3. При совпадении вызываем `break`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	mockInputs := []string{"hello", "golang", "workout", "exit", "ignored"}
	idx := 0

	fmt.Println("=== Запуск Эхо-сервера (введите 'exit' для остановки) ===")

	for {
		if idx >= len(mockInputs) {
			break
		}
		raw := mockInputs[idx]
		idx++

		text := strings.TrimSpace(raw)
		fmt.Printf("> Ввод: %q -> ", text)

		if text == "exit" {
			fmt.Println("Получена команда завершения. Выход из цикла.")
			break // Прерываем бесконечный цикл
		}

		// Выводим удвоенную строку
		fmt.Printf("Эхо-ответ: %s %s\n", text, text)
	}

	fmt.Println("Сервер штатно остановлен.")
}
```

ℹ️ Бесконечный цикл с break по exit

**`Терминал`**

```bash
go run main.go
# === Запуск Эхо-сервера (введите 'exit' для остановки) ===
# > Ввод: "hello" -> Эхо-ответ: hello hello
# > Ввод: "golang" -> Эхо-ответ: golang golang
# > Ввод: "workout" -> Эхо-ответ: workout workout
# > Ввод: "exit" -> Получена команда завершения. Выход из цикла.
# Сервер штатно остановлен.
```

## Под капотом

Инструкция `break` перенаправляет поток управления на адрес первой команды после закрывающей фигурной скобки `}` цикла.

## Подводные камни

- Строка `"EXIT"` или `"exit "` не совпадет с `"exit"`, если не выполнить `strings.ToLower(strings.TrimSpace(text))`.

## На собеседовании

**Вопрос с собеседования:** «Как безопасно остановить бесконечный цикл горутины извне?»
**Ответ:** Через `context.Context` (`select { case <-ctx.Done(): return }`) или канал сигналов остановки `chan struct{}`.
