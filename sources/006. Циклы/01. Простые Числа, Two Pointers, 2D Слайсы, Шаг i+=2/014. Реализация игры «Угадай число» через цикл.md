# Реализация игры «Угадай число» через цикл for с условием (while-стиль)

## Условие

Напиши программу с `for` как **while**: `for condition { ... }`. Реализуй "угадай число": компьютер загадывает число (1–100), пользователь вводит варианты, цикл продолжается до угадывания.

## Теория

Реализация через явное условие `for guess != target { ... }`.

## Решение по шагам

1. Задаем `target = 42` и `guess = 0`.
2. Запускаем `for guess != target`.
3. Внутри обновляем `guess` и выводим подсказки.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	target := 42
	guess := 0
	attempts := 0

	userInputs := []int{10, 70, 35, 45, 42}
	inputIdx := 0

	// Цикл продолжается, пока guess не совпадет с target:
	for guess != target && inputIdx < len(userInputs) {
		guess = userInputs[inputIdx]
		inputIdx++
		attempts++

		fmt.Printf("Попытка #%d: Введено %d -> ", attempts, guess)
		if guess < target {
			fmt.Println("Загаданное число больше ⬆️")
		} else if guess > target {
			fmt.Println("Загаданное число меньше ⬇️")
		} else {
			fmt.Println("🎉 Бинго! Точное совпадение!")
		}
	}
}
```

ℹ️ for condition для игры в угадывание

**`Терминал`**

```bash
go run main.go

# Попытка #4: Введено 45 -> Загаданное число меньше ⬇️

```

ℹ️ Результат

## Под капотом

Условие `guess != target` проверяется перед каждой итерацией (`CMP + JE`).

## Подводные камни

- Инициализация `guess` равным `target` до цикла: тело цикла ни разу не выполнится.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие `for condition {}` от `for {}` с `if !condition { break }`?»
**Ответ:** Функционально они эквивалентны. `for condition` чище выражает инвариант цикла прямо в заголовке.
