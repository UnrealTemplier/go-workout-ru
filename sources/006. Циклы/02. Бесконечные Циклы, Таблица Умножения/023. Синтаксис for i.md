# Синтаксис for i := range slice для получения исключительно индексов

## Условие

Напиши программу с `for-range` по слайсу, где тебе нужен **только индекс** (без значения). Покажи, что можно написать `for i := range slice` — это допустимый синтаксис.

## Теория

**Форма с одним аргументом `for i := range slice`:**
- Если указана только одна переменная, она всегда принимает **индекс**;
- Второе значение (копия элемента) не вычисляется и не копируется, экономя такты CPU для больших структур данных.

## Решение по шагам

1. Создаем срез чисел `nums`.
2. Обходим через `for i := range nums`.
3. Модифицируем оригинальный срез по индексу `nums[i] *= 2`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	nums := []int{10, 20, 30, 40, 50}

	fmt.Printf("Исходный срез:   %v\n", nums)

	// Итерация только по индексам:
	for i := range nums {
		nums[i] *= 2 // Прямая модификация по индексу!
	}

	fmt.Printf("Удвоенный срез:  %v\n", nums)
}
```

ℹ️ Итерация только по индексам

**`Терминал`**

```bash
go run main.go
# Исходный срез:   [10 20 30 40 50]
# Удвоенный срез:  [20 40 60 80 100]
```

ℹ️ Вывод

## Под капотом

Компилятор оптимизирует `for i := range slice` в `for i := 0; i < len(slice); i++` с BCE-оптимизацией.

## Подводные камни

- Заблуждение, что `for x := range slice` поместит в `x` значение элемента: в `x` попадет **индекс**! Чтобы получить значение, требуется `for _, x := range slice`.

## На собеседовании

**Вопрос с собеседования:** «Что произойдет при `for range 5` в Go 1.22+?»
**Ответ:** В Go 1.22 добавлена поддержка `range` по целым числам: `for i := range 5` итерирует `i` от 0 до 4.
