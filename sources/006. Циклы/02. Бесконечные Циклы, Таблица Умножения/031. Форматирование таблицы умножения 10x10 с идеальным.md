# Форматирование таблицы умножения 10x10 с идеальным выравниванием столбцов

## Условие

Напиши программу с **вложенными циклами**: выведи таблицу умножения 10×10. Используй форматирование `fmt.Printf("%4d", i*j)` для красивых столбцов.

## Теория

Форматирование табличных данных в консоли.

## Решение по шагам

1. Двойной цикл от 1 до 10.
2. Печать `%4d`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	for i := 1; i <= 10; i++ {
		for j := 1; j <= 10; j++ {
			fmt.Printf("%4d", i*j)
		}
		fmt.Println()
	}
}
```

ℹ️ Вывод

## Под капотом

Буферизация стандартного вывода `os.Stdout`.

## Подводные камни

- Пропуск `fmt.Println()` в конце строки.

## На собеседовании

**Вопрос с собеседования:** «Как повысить производительность многократного вывода в консоль в цикле?»
**Ответ:** Использовать `bufio.NewWriter(os.Stdout)` с обязательным `defer writer.Flush()` в конце функции.
