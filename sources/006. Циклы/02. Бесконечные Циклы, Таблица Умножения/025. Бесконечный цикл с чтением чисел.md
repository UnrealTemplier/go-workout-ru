# Бесконечный цикл с чтением чисел и терминацией по нулю (0)

## Условие

**Бесконечный цикл и `break`**: Напишите бесконечный цикл `for { ... }`. Внутри цикла считывайте числа из консоли. Если пользователь вводит число `0`, прервите цикл с помощью инструкции `break`.

## Теория

Классический паттерн суммирования потока чисел до получения терминатора `0`.

## Решение по шагам

1. Инициализируем поток чисел.
2. В цикле проверяем `val == 0`.
3. Прерываемся через `break`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	inputNumbers := []int{15, 25, -10, 50, 0, 999}
	idx := 0
	sum := 0

	fmt.Println("Суммирование потока чисел (терминатор = 0):")

	for {
		if idx >= len(inputNumbers) {
			break
		}
		n := inputNumbers[idx]
		idx++

		fmt.Printf("Введено число: %d\n", n)
		if n == 0 {
			fmt.Println("-> Получен терминатор 0. Остановка ввода.")
			break
		}

		sum += n
	}

	fmt.Printf("Итоговая сумма: %d\n", sum)
}
```

ℹ️ Остановка по 0 в бесконечном цикле

**`Терминал`**

```bash
go run main.go
# Суммирование потока чисел (терминатор = 0):
# Введено число: 15
# Введено число: 25
# Введено число: -10
# Введено число: 50
# Введено число: 0
# -> Получен терминатор 0. Остановка ввода.
# Итоговая сумма: 80
```
