# Аналог цикла while (for x < 100) с геометрическим умножением на 2

## Условие

**Аналог цикла `while`**: В Go нет ключевого слова `while`. Напишите цикл `for`, содержащий только условие (например, `for x < 100`). Пусть внутри цикла переменная `x` умножается на 2 на каждой итерации.

## Теория

Унарный цикл с предикатом:
- Проверка условия перед каждой итерацией;
- Идеален для логарифмических и экспоненциальных вычислений.

## Решение по шагам

1. Инициализируем `x := 1`.
2. Запускаем `for x < 100`.
3. Печатаем `x` и умножаем `x *= 2`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	x := 1
	step := 1

	for x < 100 {
		fmt.Printf("Итерация #%d: x = %-3d (следующее: %d)\n", step, x, x*2)
		x *= 2
		step++
	}

	fmt.Printf("Итоговое значение x (>= 100): %d\n", x)
}
```

ℹ️ Цикл for x < 100

**`Терминал`**

```bash
go run main.go
# Итерация #1: x = 1   (следующее: 2)
# Итерация #2: x = 2   (следующее: 4)
# Итерация #3: x = 4   (следующее: 8)
# Итерация #4: x = 8   (следующее: 16)
# Итерация #5: x = 16  (следующее: 32)
# Итерация #6: x = 32  (следующее: 64)
# Итерация #7: x = 64  (следующее: 128)
# Итоговое значение x (>= 100): 128
```

ℹ️ Вывод

## Под капотом

Компилятор выполняет сдвиг влево `SHL` за 1 такт CPU.

## Подводные камни

- Инициализация `x = 0`: `0 * 2 = 0`, цикл станет бесконечным.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go не стали делать отдельное ключевое слово `while`?»
**Ответ:** Это часть философии уменьшения ортогональных ключевых слов (Minimalism): в Go всего 25 ключевых слов, и `for` покрывает все виды итераций.
