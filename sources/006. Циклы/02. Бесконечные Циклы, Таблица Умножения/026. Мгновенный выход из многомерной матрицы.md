# Мгновенный выход из многомерной матрицы через Labeled Break (Метка OuterLoop:)

## Условие

**Метки и `break` (Метка выхода)**: Создай двумерный срез (матрицу чисел). Напиши два вложенных цикла для поиска числа `42`. Когда число найдено, используй метку (например, `OuterLoop:`), чтобы с помощью `break OuterLoop` выйти сразу из обоих циклов, а не только из внутреннего.

## Теория

**Именованный Break (`break Label`):**
- Обычный `break` прерывает только **самый внутренний цикл**;
- Для мгновенного выхода из нескольких уровней вложенности объявляется метка перед внешним циклом `SearchLoop: for ...`;
- Команда `break SearchLoop` немедленно завершает все вложенные циклы за одну операцию.

## Решение по шагам

1. Создаем матрицу \(4 \times 4\).
2. Объявляем метку `MatrixSearch:` перед внешним циклом.
3. При обнаружении числа `42` выполняем `break MatrixSearch`.
4. Фиксируем координаты найденного элемента.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	matrix := [][]int{
		{10, 20, 30, 40},
		{50, 60, 42, 80}, // Число 42 во второй строке
		{90, 100, 110, 120},
	}

	target := 42
	foundRow, foundCol := -1, -1

MatrixSearch:
	for r, row := range matrix {
		for c, val := range row {
			fmt.Printf("Проверка ячейки [%d][%d] = %d\n", r, c, val)
			if val == target {
				foundRow, foundCol = r, c
				fmt.Println("🎯 Число найдено! Экстренный выход через break MatrixSearch")
				break MatrixSearch // Выходим СРАЗУ из обоих циклов!
			}
		}
	}

	fmt.Printf("Результат: Число %d найдено в строке %d, столбце %d\n",
		target, foundRow, foundCol)
}
```

ℹ️ Labeled Break во вложенных циклах

**`Терминал`**

```bash

# Проверка ячейки [0][1] = 20

```

ℹ️ Мгновенный выход без обхода строки 2

## Под капотом

Метка `MatrixSearch` определяет адрес первой инструкции после закрытия внешнего цикла.

## Подводные камни

- Использование обычного `break`: приведет к тому, что внутренний цикл остановится, но внешний продолжит обходить следующие строки матрицы!

## На собеседовании

**Вопрос с собеседования:** «Является ли `break Label` аналогом `goto`?»
**Ответ:** Нет. `break Label` строго структурирован — он может переходить только на точку завершения помеченного цикла `for`, `switch` или `select`.
