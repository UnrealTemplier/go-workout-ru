# Мгновенный переход к следующей итерации внешнего цикла через continue OuterLoop

## Условие

**Метки и `continue`**: Напиши два вложенных цикла, перебирающих `i` от 1 до 3 и `j` от 1 до 3. Если `i == j`, используй `continue OuterLoop`, чтобы мгновенно перейти к следующей итерации ВНЕШНЕГО цикла. Выведи `i` и `j` и проанализируй результат.

## Теория

**Именованный Continue (`continue Label`):**
- Прерывает выполнение внутреннего цикла;
- Передает управление на инкремент `Post` **внешнего помеченного цикла**.

## Решение по шагам

1. Помещаем метку `OuterLoop:` перед внешним циклом.
2. Во внутреннем цикле проверяем `if i == j { continue OuterLoop }`.
3. Анализируем пропущенные пары.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	fmt.Println("Демонстрация continue OuterLoop:")

OuterLoop:
	for i := 1; i <= 3; i++ {
		fmt.Printf("--- Внешний цикл i = %d ---\n", i)
		for j := 1; j <= 3; j++ {
			if i == j {
				fmt.Printf("  [i=%d, j=%d]: i == j -> continue OuterLoop!\n", i, j)
				continue OuterLoop // Сразу переходим к следующему i++!
			}
			fmt.Printf("  Пара: (i=%d, j=%d)\n", i, j)
		}
	}
}
```

ℹ️ Labeled Continue

**`Терминал`**

```bash
go run main.go
# Демонстрация continue OuterLoop:
# --- Внешний цикл i = 1 ---
#   [i=1, j=1]: i == j -> continue OuterLoop!
# --- Внешний цикл i = 2 ---
#   Пара: (i=2, j=1)
#   [i=2, j=2]: i == j -> continue OuterLoop!
# --- Внешний цикл i = 3 ---
#   Пара: (i=3, j=1)
#   Пара: (i=3, j=2)
#   [i=3, j=3]: i == j -> continue OuterLoop!
```

ℹ️ Результат работы

## Под капотом

Инструкция `JMP` на метку `i++` внешнего цикла.

## Подводные камни

- Путаница между `break Label` (завершает цикл) и `continue Label` (переходит к следующему шагу).

## На собеседовании

**Вопрос с собеседования:** «Можно ли объявить метку в одной функции, а сделать `continue Label` из другой функции?»
**Ответ:** НЕТ! Область действия меток строго ограничена телом той функции, в которой они объявлены.
