# Комбинация break и continue: фильтрация нечетных чисел и остановка на числе 8

## Условие

**`break` и `continue`**: в цикле от 1 до 10 пропускайте (`continue`) нечётные числа и останавливайтесь (`break`), если встретили число 8.

## Теория

- `continue`: мгновенно завершает **текущую итерацию** и переходит к секции шага `Post`;
- `break`: мгновенно завершает **весь цикл**.

## Решение по шагам

1. Итерируем `i` от 1 до 10.
2. Если `i == 8` -> `break`.
3. Если `i % 2 != 0` -> `continue`.
4. Печатаем обработанные числа.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	fmt.Println("Демонстрация break и continue (1..10):")

	for i := 1; i <= 10; i++ {
		// Остановка при достижении 8
		if i == 8 {
			fmt.Printf("-> Достигли числа %d: BREAK\n", i)
			break
		}

		// Пропуск нечетных чисел
		if i%2 != 0 {
			continue // Переход к следующей итерации
		}

		fmt.Printf("Четное число: %d\n", i)
	}
}
```

ℹ️ Комбинация break и continue

**`Терминал`**

```bash
go run main.go
# Демонстрация break и continue (1..10):
# Четное число: 2
# Четное число: 4
# Четное число: 6
# -> Достигли числа 8: BREAK
```

ℹ️ Результат

## Под капотом

`continue` компилируется в `JMP` на секцию `i++`, а `break` — в `JMP` на адрес за пределами тела цикла.

## Подводные камни

- Помещение `i == 8` после `continue`: если бы 8 было нечетным, `break` бы никогда не сработал. Всегда размещайте условия остановки перед фильтрами пропуска.

## На собеседовании

**Вопрос с собеседования:** «Выполняется ли блок `defer` при вызове `break` или `continue`?»
**Ответ:** НЕТ! Блоки `defer` привязаны к завершению окружающей **функции**, а не тела цикла или итерации.
