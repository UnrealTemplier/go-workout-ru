# Бесконечный цикл for { ... } с обработкой стоп-команды и эхо-ответом

## Условие

Напиши программу с **бесконечным циклом** `for { ... }` и `break` по условию. Читай ввод пользователя: если введено `"exit"` — выходи из цикла, иначе эхо-вывод строки.

## Теория

**Структура консольного демона:**
1. Непрерывное ожидание команд;
2. Проверка стоп-условия через `strings.ToLower(strings.TrimSpace(cmd)) == "exit"`;
3. Досрочный выход через `break`;
4. Обработка полезной нагрузки в теле цикла.

## Решение по шагам

1. Инициализируем массив команд.
2. В цикле обрабатываем команды.
3. При получении `"exit"` делаем `break`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	commands := []string{"ping", "get_status", "help", "exit", "unreachable"}
	cursor := 0

	fmt.Println("CLI Daemon Started:")

	for {
		if cursor >= len(commands) {
			break
		}
		raw := commands[cursor]
		cursor++

		cmd := strings.ToLower(strings.TrimSpace(raw))
		fmt.Printf("Received: %-12s -> ", cmd)

		if cmd == "exit" {
			fmt.Println("🛑 Shutdown command received. Breaking loop!")
			break
		}

		fmt.Printf("Echo OK: [%s]\n", cmd)
	}

	fmt.Println("Daemon gracefully stopped.")
}
```

ℹ️ Бесконечный цикл эхо-демона

**`Терминал`**

```bash
go run main.go
# CLI Daemon Started:
# Received: ping         -> Echo OK: [ping]
# Received: get_status   -> Echo OK: [get_status]
# Received: help         -> Echo OK: [help]
# Received: exit         -> 🛑 Shutdown command received. Breaking loop!
# Daemon gracefully stopped.
```

## Под капотом

При вызове `break` управление передается за пределы базового блока `ForStmt`.

## Подводные камни

- Написание бесконечного цикла без условия выхода `break` или `return`.

## На собеседовании

**Вопрос с собеседования:** «Чем `for {}` отличается от `for true {}`?»
**Ответ:** Ничем — компилятор Go генерирует для них идентичный машинный код. `for {}` считается более идиоматичной формой.
