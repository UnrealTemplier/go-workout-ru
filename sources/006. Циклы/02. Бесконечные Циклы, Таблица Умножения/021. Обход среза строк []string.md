# Обход среза строк []string: вывод пары (индекс, значение) и игнорирование индекса через _

## Условие

Напиши программу с `for-range` по **слайсу** `[]string`. Выведи индекс и значение каждого элемента. Затем выведи только значения, игнорируя индекс (blank identifier `_`).

## Теория

Две идиоматичные формы `for range`:
1. `for idx, val := range slice` — полный доступ к индексу и значению;
2. `for _, val := range slice` — доступ только к значению (индекс отбрасывается без создания переменной).

## Решение по шагам

1. Создаем срез языков `[]string{"Go", "Rust", "Python", "C++"}`.
2. Выводим с индексами.
3. Выводим только значения через `_`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	languages := []string{"Go", "Rust", "Python", "TypeScript"}

	// 1. С индексом и значением
	fmt.Println("1. С индексом:")
	for idx, lang := range languages {
		fmt.Printf("   [%d] -> %s\n", idx, lang)
	}

	// 2. Только значения (игнорируя индекс через _)
	fmt.Println("\n2. Только значения:")
	for _, lang := range languages {
		fmt.Printf("   • %s\n", lang)
	}
}
```

ℹ️ Две формы for range по срезу

**`Терминал`**

```bash
go run main.go
# 1. С индексом:
#    [0] -> Go
#    [1] -> Rust
#    [2] -> Python
#    [3] -> TypeScript
# 
# 2. Только значения:
#    • Go
#    • Rust
#    • Python
#    • TypeScript
```

ℹ️ Вывод

## Под капотом

Бланковый идентификатор `_` оптимизируется компилятором, исключая запись регистра индекса в стек.

## Подводные камни

- Объявление `for idx, lang := range` без использования `idx`: компилятор выдаст ошибку `idx declared and not used`.

## На собеседовании

**Вопрос с собеседования:** «Какова семантика бланкового идентификатора `_` в Go?»
**Ответ:** `_` — это write-only псевдоним переменной, значение которой немедленно отбрасывается компилятором и не занимает память.
