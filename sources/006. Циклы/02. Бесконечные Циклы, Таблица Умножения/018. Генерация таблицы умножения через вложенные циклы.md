# Генерация таблицы умножения через вложенные циклы с моноширинным форматированием

## Условие

**Таблица умножения**: С помощью двух вложенных циклов `for` выведите в консоль классическую таблицу умножения, форматируя вывод через `fmt.Printf` для ровных столбцов.

## Теория

**Вложенные циклы (Nested Loops):**
- Внешний цикл `for i := 1; i <= 10; i++` отвечает за строки;
- Внутренний цикл `for j := 1; j <= 10; j++` отвечает за столбцы;
- Спецификатор `%4d` резервирует ровно 4 знакоместа под каждое число, формируя идеальную таблицу.

## Решение по шагам

1. Запускаем внешний цикл по `i` от 1 до 10.
2. Запускаем внутренний цикл по `j` от 1 до 10.
3. Печатаем произведение `i * j` с форматом `%4d`.
4. Делаем перевод строки `fmt.Println()`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func PrintMultiplicationTable() {
	fmt.Println("Таблица умножения (10x10):")
	for i := 1; i <= 10; i++ {
		for j := 1; j <= 10; j++ {
			fmt.Printf("%4d", i*j)
		}
		fmt.Println()
	}
}

func main() {
	PrintMultiplicationTable()
}
```

ℹ️ Таблица умножения 10x10

## Под капотом

Сложность \(O(N \times M)\) с вычислением произведения через инструкцию `IMULQ`.

## Подводные камни

- Использование `fmt.Print(i*j, " ")` вместо фиксированной ширины `%4d`: разряды чисел (1, 10, 100) приведут к искривлению столбцов.

## На собеседовании

**Вопрос с собеседования:** «Какова пространственная сложность генерации таблицы умножения с прямым выводом в консоль?»
**Ответ:** Пространственная сложность \(O(1)\), так как промежуточные матрицы не создаются в оперативной памяти.
