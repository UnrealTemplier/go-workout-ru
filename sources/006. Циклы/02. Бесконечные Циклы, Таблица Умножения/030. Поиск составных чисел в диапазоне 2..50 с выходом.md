# Поиск составных чисел в диапазоне 2..50 с выходом по метке OuterLoop

## Условие

**Метка и `break`**: во вложенном цикле поиска простых чисел от 2 до 50 используйте метку `outer` для выхода из внешнего цикла при нахождении составного числа.

## Теория

Демонстрация контроля внешнего цикла при анализе простых чисел.

## Решение по шагам

1. Запускаем поиск.
2. При нахождении составного числа выходим по метке.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	fmt.Println("Поиск первого составного числа > 30:")

SearchOuter:
	for n := 31; n <= 50; n++ {
		for d := 2; d*d <= n; d++ {
			if n%d == 0 {
				fmt.Printf("Число %d составное (делится на %d)! Выход по метке.\n", n, d)
				break SearchOuter
			}
		}
		fmt.Printf("Число %d — простое\n", n)
	}
}
```

ℹ️ Выход из внешнего цикла по метке

**`Терминал`**

```bash
go run main.go
# Поиск первого составного числа > 30:
# Число 31 — простое
# Число 32 составное (делится на 2)! Выход по метке.
```

## Под капотом

Метка устраняет необходимость использовать флаги `found = true` и лишние проверки `if found { break }`.

## Подводные камни

- Размещение метки внутри тела цикла вместо заголовка.
