# Синтаксис и правила именования меток Labeled Break во вложенных циклах

## Условие

Напиши программу с **`break` с меткой** (label): вложенные циклы по `i` и `j`. При выполнении условия прервай **внешний** цикл из тела внутреннего. Объясни синтаксис метки.

## Теория

**Синтаксические правила меток в Go:**
1. Метка объявляется как `LabelName:` непосредственно перед заголовком цикла `for`, `switch` или `select`;
2. Между меткой и циклом **не может быть других инструкций**;
3. Метки чувствительны к регистру (`Loop:` и `loop:` — разные метки);
4. Метка не экспортируется за пределы функции.

## Решение по шагам

1. Объявляем метку `Outer:` перед внешним циклом.
2. Во внутреннем цикле при `i == 2 && j == 2` делаем `break Outer`.
3. Проверяем остановку.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	fmt.Println("Демонстрация Labeled Break:")

Outer:
	for i := 1; i <= 4; i++ {
		for j := 1; j <= 4; j++ {
			fmt.Printf("Checking (i=%d, j=%d)\n", i, j)
			if i == 2 && j == 2 {
				fmt.Println("🎯 Trigger hit! Breaking Outer loop!")
				break Outer
			}
		}
	}

	fmt.Println("Both loops terminated.")
}
```

ℹ️ Labeled break Outer

**`Терминал`**

```bash
go run main.go
# Демонстрация Labeled Break:
# Checking (i=1, j=1)
# Checking (i=1, j=2)
# Checking (i=1, j=3)
# Checking (i=1, j=4)
# Checking (i=2, j=1)
# Checking (i=2, j=2)
# 🎯 Trigger hit! Breaking Outer loop!
# Both loops terminated.
```

ℹ️ Вывод

## Под капотом

Метка `Outer` преобразуется в смещение перехода на метку `end_of_for_1`.

## Подводные камни

- Размещение комментариев или переменных между меткой и циклом `Outer: var x = 1; for ...` — вызовет ошибку компиляции.

## На собеседовании

**Вопрос с собеседования:** «Может ли метка дублироваться в разных функциях одного пакета?»
**Ответ:** ДА! Метки имеют Function-level Scope и изолированы внутри своих функций.
