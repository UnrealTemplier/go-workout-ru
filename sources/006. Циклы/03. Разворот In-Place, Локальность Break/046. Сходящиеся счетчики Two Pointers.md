# Сходящиеся счетчики Two Pointers: for i, j := 0, 10; i < j; i, j = i+1, j-1

## Условие

Напиши программу с циклом `for` с **двумя переменными счётчика**: `for i, j := 0, 10; i < j; i, j = i+1, j-1`. Выводи `i` и `j` на каждой итерации. Покажи, как "сходятся" указатели.

## Теория

Визуализация схождения двух индексов от краев к центру.

## Решение по шагам

1. Инициализируем `i := 0`, `j := 10`.
2. Условие `i < j`.
3. Шаг `i, j = i+1, j-1`.
4. Печатаем дистанцию на каждом шаге.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	fmt.Println("Схождение двух указателей (Two Pointers):")

	step := 1
	for i, j := 0, 10; i < j; i, j = i+1, j-1 {
		fmt.Printf("Шаг #%d: i = %-2d | j = %-2d | Дистанция = %d\n",
			step, i, j, j-i)
		step++
	}

	fmt.Println("Указатели сошлись в центре!")
}
```

ℹ️ Сходящиеся счетчики

**`Терминал`**

```bash
go run main.go
# Схождение двух указателей (Two Pointers):
# Шаг #1: i = 0  | j = 10 | Дистанция = 10
# Шаг #2: i = 1  | j = 9  | Дистанция = 8
# Шаг #3: i = 2  | j = 8  | Дистанция = 6
# Шаг #4: i = 3  | j = 7  | Дистанция = 4
# Шаг #5: i = 4  | j = 6  | Дистанция = 2
# Указатели сошлись в центре!
```

ℹ️ Результат схождения

## Под капотом

Два регистра инкрементируются и декрементируются параллельно.

## Подводные камни

- Неправильный знак шага (например `i-1, j+1`), вызывающий расхождение указателей и бесконечный цикл.
