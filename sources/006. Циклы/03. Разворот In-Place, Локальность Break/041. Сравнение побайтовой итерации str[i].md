# Сравнение побайтовой итерации str[i] и посимвольной for range по строке «Привет»

## Условие

Итерация по строке (байты vs руны): Создайте строку "Привет".
- Напишите обычный цикл for i := 0; i < len(str); i++ и выведите str[i]. Обратите внимание на странные символы в выводе.
- Напишите цикл for index, runeValue := range str и выведите индекс и символ. Объясните, почему индексы идут не по порядку (0, 2, 4...) и как for range автоматически декодирует символы UTF-8.

### Исходная формулировка

**Итерация по строке (байты vs руны)**: Создайте строку `"Привет"`.
* Напишите обычный цикл `for i := 0; i < len(str); i++` и выведите `str[i]`. Обратите внимание на странные символы в выводе (так как считываются отдельные байты UTF-8).
* Напишите цикл `for index, runeValue := range str` и выведите индекс и символ. Объясните, почему индексы идут не по порядку (0, 2, 4...) и как `for range` автоматически декодирует символы UTF-8 (руны).

## Теория

**Фундаментальное отличие:**
- `len("Привет")` возвращает **12 байт** (каждая русская буква кодируется 2 байтами в UTF-8);
- `str[i]` считывает **1 сырой байт** `uint8` \(\rightarrow\) приведение `string(str[i])` ломает 2-байтовую последовательность и выводит знаки вопроса/кракозябры;
- `for range str` автоматически декодирует пару байт в 1 руну `rune` (`int32`) и сдвигает индекс на \(+2\).

## Решение по шагам

1. Итерируемся по байтам через `str[i]`.
2. Итерируемся по рунам через `for range str`.
3. Сравниваем результаты.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	word := "Привет"

	fmt.Printf("Строка: %q | len() = %d байт\n\n", word, len(word))

	// 1. Побайтовый C-style цикл (ЛОМАЕТ UTF-8):
	fmt.Println("1. Побайтовый обход str[i] (неверно):")
	for i := 0; i < len(word); i++ {
		fmt.Printf("   Байт [%d] = 0x%02X (%d)\n", i, word[i], word[i])
	}

	// 2. Идиоматичный for range (КОРРЕКТНЫЙ UTF-8):
	fmt.Println("\n2. Посимвольный обход for range (верно):")
	for idx, r := range word {
		fmt.Printf("   Индекс %-2d -> Руна: %c (код: %d)\n", idx, r, r)
	}
}
```

## Под капотом

Байты 0xD0 0x9F собираются в кодовую точку `U+041F` ('П').

## Подводные камни

- Попытка взять длину строки в символах через `len(str)`: `len("Привет") == 12`, а не 6!

## На собеседовании

**Вопрос с собеседования:** «Как получить количество символов в строке UTF-8 за \(O(N)\)?»
**Ответ:** С помощью функции `utf8.RuneCountInString(s)` из стандартного пакета `unicode/utf8`.
