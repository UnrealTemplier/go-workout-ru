# Игнорирование индекса при суммировании среза чисел (for _, val := range numbers)

## Условие

**Игнорирование переменных в `range`**: Вычисли сумму элементов среза чисел. Используй `range`, но проигнорируй индекс с помощью бланкового идентификатора (`for _, val := range numbers`).

## Теория

Чистое суммирование без мусора в области видимости.

## Решение по шагам

1. Срез чисел.
2. `for _, val := range numbers`.
3. Подсчет суммы.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	numbers := []int{100, 250, 300, 450}
	total := 0

	for _, val := range numbers {
		total += val
	}

	fmt.Printf("Числа: %v\n", numbers)
	fmt.Printf("Итоговая сумма: %d\n", total)
}
```

ℹ️ Суммирование без индекса

**`Терминал`**

```bash
go run main.go
# Числа: [100 250 300 450]
# Итоговая сумма: 1100
```

ℹ️ Вывод

## Под капотом

Регистр суммы обновляется инструкцией `ADDQ`.

## Подводные камни

- Использование `val` вне цикла.

## На собеседовании

**Вопрос с собеседования:** «Как предотвратить переполнение при суммировании очень большого среза `[]int64`?»
**Ответ:** Проверять условие `total > math.MaxInt64 - val` перед сложением или использовать `math/big.Int`.
