# Три способа суммирования среза: классический for, for range и while-стиль

## Условие

Напиши программу, которая суммирует элементы слайса `[]int` тремя способами: классический `for i := 0; i < len(s); i++`, `for-range`, и `for` с `while`-стилем. Сравни результаты.

## Теория

**Сравнительный анализ трех видов цикла `for`:**
1. `for i := 0; i < len(s); i++` — прямой доступ по индексу (C-Style);
2. `for _, v := range s` — наиболее лаконичный и безопасный (Range-Style);
3. `for i < len(s)` — гибкий цикл с ручным шагом (While-Style).

## Решение по шагам

1. Создаем тестовый срез `[]int{5, 10, 15, 20, 25}`.
2. Суммируем каждым способом.
3. Проверяем идентичность результатов.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	s := []int{5, 10, 15, 20, 25}

	// 1. Классический C-style
	sum1 := 0
	for i := 0; i < len(s); i++ {
		sum1 += s[i]
	}

	// 2. Идиоматичный for-range
	sum2 := 0
	for _, v := range s {
		sum2 += v
	}

	// 3. While-стиль
	sum3 := 0
	k := 0
	for k < len(s) {
		sum3 += s[k]
		k++
	}

	fmt.Printf("1. C-Style:    %d\n", sum1)
	fmt.Printf("2. Range-Style: %d\n", sum2)
	fmt.Printf("3. While-Style: %d\n", sum3)
}
```

ℹ️ Три способа суммирования

**`Терминал`**

```bash
go run main.go
# 1. C-Style:    75
# 2. Range-Style: 75
# 3. While-Style: 75
```

## Под капотом

Для всех трех вариантов компилятор генерирует схожие циклы на регистровой арифметике.

## Подводные камни

- Вызов `len(s)` в условии не имеет накладных расходов, так как длина среза хранится в 8-байтном поле структуры `SliceHeader`.

## На собеседовании

**Вопрос с собеседования:** «Какой способ итерации по срезу считается стандартом де-факто в Go?»
**Ответ:** `for _, v := range s` (если не требуется модификация элементов по индексу).
