# Локальность оператора break: прерывание только внутреннего цикла при i*j == 21

## Условие

Напиши программу с вложенными циклами и `break`. Покажи, что `break` прерывает только **внутренний** цикл. Найди первую пару чисел `(i, j)`, где `i*j == 21`, и выведи их.

## Теория

**Локальность `break` без метки:**
- `break` выходит **только из того цикла, внутри которого он написан**;
- Внешний цикл продолжит следующую итерацию `i++`.

## Решение по шагам

1. Вложенные циклы `i` (1..10) и `j` (1..10).
2. При `i * j == 21` печатаем пару и вызываем обычный `break`.
3. Наблюдаем продолжение работы внешнего цикла.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	fmt.Println("Поиск пар с i * j == 21 (обычный break):")

	for i := 1; i <= 7; i++ {
		for j := 1; j <= 10; j++ {
			if i*j == 21 {
				fmt.Printf("-> Найдена пара: (%d, %d). Вызываем break!\n", i, j)
				break // Прерывает ТОЛЬКО цикл по j! Внешний цикл по i продолжится!
			}
		}
		fmt.Printf("Внешний шаг i = %d завершен\n", i)
	}
}
```

ℹ️ Доказательство локальности break

**`Терминал`**

```bash
go run main.go
# Поиск пар с i * j == 21 (обычный break):
# Внешний шаг i = 1 завершен
# Внешний шаг i = 2 завершен
# -> Найдена пара: (3, 7). Вызываем break!
# Внешний шаг i = 3 завершен
# Внешний шаг i = 4 завершен
# Внешний шаг i = 5 завершен
# Внешний шаг i = 6 завершен
# -> Найдена пара: (7, 3). Вызываем break!
# Внешний шаг i = 7 завершен
```

ℹ️ Обе пары (3,7) и (7,3) были найдены

## Под капотом

Метка перехода для `break` размещается сразу за скобкой внутреннего `ForStmt`.

## Подводные камни

- Ожидание, что простой `break` завершит оба цикла.

## На собеседовании

**Вопрос с собеседования:** «Как сделать так, чтобы при нахождении первой пары `(3, 7)` программа не искала пару `(7, 3)`?»
**Ответ:** Использовать именованный `break MainLoop` или вернуть результат через `return i, j`.
