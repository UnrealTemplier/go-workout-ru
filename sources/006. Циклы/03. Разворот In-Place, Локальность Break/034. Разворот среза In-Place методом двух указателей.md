# Разворот среза In-Place методом двух указателей и множественного присваивания

## Условие

**Итерация с двумя переменными**: В классическом `for` можно делать множественные операции. Напиши цикл для разворота массива: `for i, j := 0, len(arr)-1; i < j; i, j = i+1, j-1 { ... }`.

## Теория

**In-Place Reverse (Разворот на месте):**
- Не требует выделения дополнительной памяти (\(O(1)\) по памяти);
- Множественное присваивание `arr[i], arr[j] = arr[j], arr[i]` меняет элементы местами за 1 шаг без временной переменной;
- Шаг цикла `i, j = i+1, j-1` двигает границы одновременно.

## Решение по шагам

1. Создаем срез `nums := []int{1, 2, 3, 4, 5, 6}`.
2. Запускаем цикл со сходящимися указателями `i` и `j`.
3. Меняем элементы местами.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func ReverseInPlace(arr []int) {
	for i, j := 0, len(arr)-1; i < j; i, j = i+1, j-1 {
		arr[i], arr[j] = arr[j], arr[i] // Атомарный swap
	}
}

func main() {
	numbers := []int{10, 20, 30, 40, 50, 60}
	fmt.Printf("До разворота:    %v\n", numbers)

	ReverseInPlace(numbers)
	fmt.Printf("После разворота: %v\n", numbers)
}
```

ℹ️ Разворот среза in-place

**`Терминал`**

```bash
go run main.go
# До разворота:    [10 20 30 40 50 60]
# После разворота: [60 50 40 30 20 10]
```
