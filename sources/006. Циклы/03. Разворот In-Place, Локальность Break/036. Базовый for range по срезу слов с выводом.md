# Базовый for range по срезу слов с выводом порядкового номера

## Условие

**Базовый `for range` (Массивы/Срезы)**: Создай срез слов. Проитерируйся по нему с помощью `for index, value := range words { ... }`. Выведи индекс и слово.

## Теория

Форматирование списков с пользовательской нумерацией (`index + 1`).

## Решение по шагам

1. Создаем список слов.
2. Выводим с нумерацией от 1.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	words := []string{"Go", "Concurrency", "Goroutines", "Channels"}

	for idx, word := range words {
		fmt.Printf("%d. %s\n", idx+1, word)
	}
}
```

ℹ️ Нумерация слов

**`Терминал`**

```bash
go run main.go
# 1. Go
# 2. Concurrency
# 3. Goroutines
# 4. Channels
```

ℹ️ Вывод

## Под капотом

Регистр индекса инкрементируется процессором.

## Подводные камни

- Вывод `idx` без `+ 1`, если требуется человекопонятная нумерация с 1.

## На собеседовании

**Вопрос с собеседования:** «Является ли `words` массивом или срезом?»
**Ответ:** `[]string` — это срез (динамический срез поверх базового массива), а `[4]string` — это статический массив фиксированного размера.
