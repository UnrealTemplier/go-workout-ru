# Эмуляция паттерна do-while в Go с гарантированным первым выполнением тела

## Условие

Напиши программу, которая реализует **do-while** через `for` (тело цикла выполняется хотя бы один раз). Запрашивай у пользователя положительное число — если ввод неверный, повторяй запрос.

## Теория

**Эмуляция Do-While в Go:**
Так как ключевого слова `do` в Go нет, паттерн реализуется двумя идиоматичными способами:
1. `for ok := true; ok; ok = condition { ... }`
2. `for { ... if !condition { break } }`
В обоих случаях тело цикла **гарантированно отрабатывает минимум один раз**.

## Решение по шагам

1. Запускаем бесконечный цикл `for`.
2. Считываем ввод пользователя.
3. Проверяем условие выхода `if num > 0 { break }`.
4. Если число неположительное, повторяем запрос.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	simulatedInputs := []int{-5, 0, -12, 42}
	idx := 0
	var num int

	fmt.Println("=== Эмуляция Do-While (требуется положительное число) ===")

	// do-while через for + break в конце тела:
	for {
		num = simulatedInputs[idx]
		idx++

		fmt.Printf("Ввод: %d -> ", num)
		if num > 0 {
			fmt.Println("✔ Корректное положительное число! Выход из цикла.")
			break // Условие завершения do-while
		}

		fmt.Println("❌ Ошибка: число должно быть > 0. Повтор запроса...")
	}

	fmt.Printf("Принятое значение: %d\n", num)
}
```

**`Терминал`**

```bash

# Ввод: -12 -> ❌ Ошибка: число должно быть > 0. Повтор запроса...
```

## На собеседовании

**Вопрос с собеседования:** «Какой способ реализации `do-while` предпочтительнее в продакшене Go?»
**Ответ:** `for { ... if condition { break } }`, так как он наиболее нагляден, естественен для Go и не создает лишних булевых переменных.
