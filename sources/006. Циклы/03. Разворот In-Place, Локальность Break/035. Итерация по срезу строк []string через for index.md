# Итерация по срезу строк []string через for index, value := range

## Условие

**Итерация по срезу через `for range`**: Создайте срез строк `[]string{"яблоко", "банан", "груша"}`. Используя цикл `for index, value := range slice`, выведите индекс и значение каждого элемента.

## Теория

Базовый синтаксис обхода срезов.

## Решение по шагам

1. Создаем срез фруктов.
2. Обходим через `range`.
3. Выводим пары `index` и `value`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	fruits := []string{"яблоко", "банан", "груша"}

	for index, value := range fruits {
		fmt.Printf("Фрукт #%d: %s\n", index, value)
	}
}
```

ℹ️ Обход фруктов

**`Терминал`**

```bash
go run main.go
# Фрукт #0: яблоко
# Фрукт #1: банан
# Фрукт #2: груша
```

ℹ️ Вывод

## Под капотом

Длина среза оценивается один раз при входе в заголовок `range`.

## Подводные камни

- Модификация `value` внутри цикла не меняет элементы в `fruits`.

## На собеседовании

**Вопрос с собеседования:** «Сколько раз вычисляется выражение среза в заголовке `for range`?»
**Ответ:** Ровно один раз перед началом первой итерации.
