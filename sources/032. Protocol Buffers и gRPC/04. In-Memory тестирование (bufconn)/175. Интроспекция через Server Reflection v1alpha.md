# Интроспекция через Server Reflection v1alpha: интеграция и отладка с grpcurl

## Условие

Используйте серверную рефлексию (`grpc.reflection.v1alpha.ServerReflection`) для удобной отладки с `grpcurl`.

## Теория

Совместимость версий Server Reflection:
- В экосистеме gRPC существует два протокола Reflection:
  - `grpc.reflection.v1alpha` (исторический стандарт).
  - `grpc.reflection.v1` (современный релизный стандарт gRPC v1.56+).
- Регистрация `reflection.Register(server)` автоматически активирует поддержку обоих протоколов для совместимости со старыми и новыми версиями `grpcurl`.

## Решение по шагам

1. Подключите пакет `reflection`.
2. Зарегистрируйте reflection на сервере.
3. Исследуйте сервис через вызов `grpcurl`.
4. Продемонстрируйте консольное взаимодействие.

## Код решения

**`reflection_alpha_demo.go`**

```go
package main

import (
	"fmt"
	"net"

	"google.golang.org/grpc"
	"google.golang.org/grpc/reflection"
)

func main() {
	lis, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer lis.Close()

	server := grpc.NewServer()

	// Регистрация Server Reflection
	reflection.Register(server)

	fmt.Printf("Сервер с Reflection готов на %s\n", lis.Addr().String())
	fmt.Println("grpcurl совместим с обеими версиями протокола v1 и v1alpha!")
}
```

ℹ️ Регистрация протокола рефлексии

**`Терминал`**

```bash
go run reflection_alpha_demo.go
# Вывод:
# Сервер с Reflection готов на 127.0.0.1:39105
# grpcurl совместим с обеими версиями протокола v1 и v1alpha!
```

## Под капотом

Сервер отдает proto-дескрипторы из бинарного файла `FileDescriptorProto`, сохраненного компилятором `protoc` в глобальном реестре инициализации пакета `init()`.

## Подводные камни

Использовать флаг `-plaintext` при подключении к продакшн серверу с TLS: клиент не сможет договориться о рукопожатии.

## На собеседовании

**Вопрос с собеседования:** «Зачем нужна рефлексия, если у команды уже есть git репозиторий с proto-файлами?»
**Ответ:** Для динамических балансировщиков и API-шлюзов (например Envoy gRPC-JSON transcoder). Шлюз может на лету запрашивать схемы с бэкенда через Reflection и обновлять свои правила маршрутизации без необходимости пересборки конфигов при каждом изменении контрактов.
