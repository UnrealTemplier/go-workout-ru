# Интроспекция через Server Reflection: подключение reflection.Register и работа с grpcurl

## Условие

Подключи Server Reflection (`reflection.Register(server)`). Используй утилиту `grpcurl` (поставь через brew/go install), чтобы вызвать метод твоего сервиса без написания Go-кода клиента.

## Теория

Динамическое исследование API с помощью gRPC Reflection:
- Reflection позволяет инженерам и SRE вызывать gRPC методы так же легко, как HTTP эндпоинты через curl:
  `reflection.Register(server)`
- Вызов метода через консоль:
  `grpcurl -plaintext -d '{"name": "Gopher"}' localhost:50051 greeter.v1.Greeter/SayHello`
- Утилита `grpcurl` сама запрашивает схему, валидирует типы полей и сериализует JSON в Protobuf.

## Решение по шагам

1. Подключите `google.golang.org/grpc/reflection`.
2. Вызовите `reflection.Register(server)`.
3. Продемонстрируйте вызовы команд `grpcurl`.
4. Проверьте получение ответа в формате JSON.

## Код решения

**`reflection_cli_demo.go`**

```go
package main

import (
	"fmt"
	"net"

	"google.golang.org/grpc"
	"google.golang.org/grpc/reflection"
)

func main() {
	lis, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer lis.Close()

	server := grpc.NewServer()

	// Включение Server Reflection v1:
	reflection.Register(server)

	fmt.Printf("gRPC сервер запущен на %s с включенным Server Reflection\n", lis.Addr().String())
	fmt.Println("Команды для терминала:")
	fmt.Println("  grpcurl -plaintext <HOST> list")
	fmt.Println("  grpcurl -plaintext <HOST> describe <SERVICE>")
	fmt.Println("  grpcurl -plaintext -d '{\"id\": 1}' <HOST> <SERVICE>/<METHOD>")
}
```

ℹ️ Регистрация протокола интроспекции Reflection

**`Терминал`**

```bash
# 1. Листинг зарегистрированных сервисов:
grpcurl -plaintext localhost:50051 list
# grpc.health.v1.Health
# grpc.reflection.v1alpha.ServerReflection
# store.v1.OrderService

# 2. Вызов метода с передачей JSON:
grpcurl -plaintext -d '{"order_id": "ord_99"}' localhost:50051 store.v1.OrderService/GetOrder
# {
#   "order_id": "ord_99",
#   "status": "PAID",
#   "amount": 1500.50
# }
```

## Под капотом

`grpcurl` использует библиотеку `jhump/protoreflect` для динамического построения `protoreflect.MessageDescriptor` из бинарных данных, возвращаемых сервером.

## Подводные камни

Включать reflection на серверах, смотрящих во внешний интернет: злоумышленники смогут автоматически скачать все ваши proto-схемы со всеми скрытыми полями.

## На собеседовании

**Вопрос с собеседования:** «Как протестировать gRPC сервер с веб-интерфейсом аналогично Swagger UI?»
**Ответ:** Использовать веб-инструмент **grpcui**: `grpcui -plaintext localhost:50051`. Он автоматически подключается через Server Reflection, открывает локальный веб-браузер с интерактивной HTML-формой для ввода параметров запроса и отображает отформатированный JSON ответ.
