# Единый сетевой мультиплексор ServeMux: переключение между REST и gRPC в монолите

## Условие

Реализуйте переключение между REST и gRPC в одном приложении с помощью `grpc-gateway` и `ServeMux`.

## Теория

Универсальный серверный роутер:
- Можно объединить стандартный HTTP сервер и gRPC шлюз в одном `http.ServeMux`:
  ```go
  rootMux := http.NewServeMux()
  rootMux.Handle("/api/", grpcGatewayMux) // REST маршруты
  rootMux.HandleFunc("/healthz", healthzHandler)
  rootMux.Handle("/swagger/", swaggerHandler)
  ```
- Приложение запускается единым процессом и слушает один HTTP порт.

## Решение по шагам

1. Создайте корневой `http.NewServeMux()`.
2. Примонтируйте gRPC-Gateway по префиксу `/api/`.
3. Примонтируйте системные эндпоинты `/healthz`.
4. Протестируйте маршрутизацию.

## Код решения

**`unified_serve_mux_test.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"testing"
)

func BuildUnifiedMux() *http.ServeMux {
	mux := http.NewServeMux()

	// REST API маршруты через Gateway
	mux.HandleFunc("/api/v1/status", func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		_, _ = w.Write([]byte(`{"service":"active","code":200}`))
	})

	// Системный эндпоинт Kubernetes
	mux.HandleFunc("/healthz", func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte("HEALTHY"))
	})

	return mux
}

func TestUnifiedServeMux(t *testing.T) {
	mux := BuildUnifiedMux()
	server := httptest.NewServer(mux)
	defer server.Close()

	// Проверка REST эндпоинта
	resp1, _ := http.Get(server.URL + "/api/v1/status")
	if resp1.StatusCode != http.StatusOK {
		t.Fatalf("Ошибка REST: %d", resp1.StatusCode)
	}

	// Проверка healthz
	resp2, _ := http.Get(server.URL + "/healthz")
	if resp2.StatusCode != http.StatusOK {
		t.Fatalf("Ошибка healthz: %d", resp2.StatusCode)
	}

	fmt.Println("Единый ServeMux успешно маршрутизирует и REST API, и системные healthz проверки!")
}
```

ℹ️ Маршрутизация REST и системных эндпоинтов в одном ServeMux

## Под капотом

Начиная с Go 1.22 `http.ServeMux` поддерживает сопоставление по методу `GET /api/v1/status` и шаблонные параметры `{id}`, делая стандартный роутер полноценным микрофреймворком.

## Подводные камни

Забывать закрывающий слэш `/api/` при монтировании поддеревьев: префикс `/api` без слэша приведет к неверному сопоставлению дочерних путей.

## На собеседовании

**Вопрос с собеседования:** «Как в едином HTTP сервере одновременно принимать чистый gRPC и HTTP/1.1 запросы без cmux?»
**Ответ:** Проверять заголовки `r.ProtoMajor == 2 && strings.HasPrefix(r.Header.Get("Content-Type"), "application/grpc")`. Если условие истинно, передавать запрос в `grpcServer.ServeHTTP(w, r)`, иначе направлять в `httpMux`.
