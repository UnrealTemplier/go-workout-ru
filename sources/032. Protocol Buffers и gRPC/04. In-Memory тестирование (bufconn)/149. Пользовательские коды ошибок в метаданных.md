# Пользовательские коды ошибок в метаданных: кастомный заголовок x-error-code

## Условие

Создайте кастомный error code через metadata (если стандартных `codes` не хватает для вашей бизнес-логики).

## Теория

Расширение семантики ошибок через Metadata:
- 16 стандартных кодов gRPC покрывают инфраструктурные состояния.
- Для специфических бизнес-ошибок (например `PROMO_CODE_EXPIRED`, `CARD_INSUFFICIENT_FUNDS`, `PASSPORT_BLACKLISTED`):
  - Сервер возвращает статус `codes.InvalidArgument` или `codes.FailedPrecondition`.
  - В gRPC Trailers передается заголовок `x-business-error-code: PROMO_EXPIRED`.
- Клиент:
  - Извлекает трейлеры через `grpc.Trailer(&trailerMD)`.
  - Считывает точный бизнес-код для показа локализованного экрана ошибки.

## Решение по шагам

1. Сформируйте бизнес-код ошибки в трейлерах.
2. Верните gRPC ошибку со статусом `FailedPrecondition`.
3. На стороне клиента извлеките трейлеры вызова.
4. Проверьте чтение `x-business-error-code`.

## Код решения

**`custom_error_codes_test.go`**

```go
package main

import (
	"context"
	"fmt"
	"testing"

	"google.golang.org/grpc"
	"google.golang.org/grpc/codes"
	"google.golang.org/grpc/metadata"
	"google.golang.org/grpc/status"
)

func CheckoutOrderServer(ctx context.Context) (string, metadata.MD, error) {
	// Бизнес-ошибка: карта пользователя заблокирована банком
	trailerMD := metadata.Pairs("x-business-error-code", "BANK_CARD_BLOCKED")
	err := status.Error(codes.FailedPrecondition, "оплата не может быть завершена")
	return "", trailerMD, err
}

func TestCustomErrorCodeInTrailer(t *testing.T) {
	_, trailers, err := CheckoutOrderServer(context.Background())
	if err == nil {
		t.Fatal("Ожидалась ошибка оплаты")
	}

	st := status.Convert(err)
	businessCodes := trailers.Get("x-business-error-code")

	if len(businessCodes) == 0 {
		t.Fatal("Трейлер x-business-error-code отсутствует")
	}

	fmt.Printf("Стандартный gRPC статус:  [%s] %s\n", st.Code(), st.Message())
	fmt.Printf("Кастомный бизнес-код в трейлере: %s\n", businessCodes[0])

	if businessCodes[0] != "BANK_CARD_BLOCKED" {
		t.Fatalf("got %s; want BANK_CARD_BLOCKED", businessCodes[0])
	}
}
```

## Под капотом

Трейлеры gRPC передаются в финальном HTTP/2 фрейме `HEADERS` с битом `END_STREAM`, поэтому передача кастомного кода ошибки не требует дополнительного сетевого пакета.

## Подводные камни

Изобретать собственные 3-значные числовые коды ошибок вместо строк: строковые коды `BANK_CARD_BLOCKED` самодокументируемы и предотвращают коллизии между микросервисами.

## На собеседовании

**Вопрос с собеседования:** «Почему создатели gRPC не разрешают добавлять новые числовые коды в enum codes.Code?»
**Ответ:** Чтобы не разрушить глобальную совместимость gRPC клиентов на 15 языках программирования. Добавление нового числа сломало бы сериализаторы и таблицу сопоставления с HTTP-статусами. Любые бизнес-специфичные коды передаются в метаданных или через `google.rpc.errdetails`.
