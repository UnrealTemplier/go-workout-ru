# Сквозной пайплайн gRPC-Gateway: от proto-аннотаций до проверки через curl

## Условие

**[Высокая сложность — gRPC Gateway]**: Сгенерируй reverse-proxy с помощью `protoc-gen-grpc-gateway`. Настрой аннотации `google.api.http` в `.proto` файле (например, `get: "/v1/users/{id}"`). Подними HTTP-сервер, который переводит REST-запросы в gRPC-вызовы. Сделай запрос через `curl`.

## Теория

Полный цикл интеграции gRPC-Gateway:
1. Контракт: метод `GetUser` с `option (google.api.http) = { get: "/v1/users/{id}" }`.
2. Кодогенерация: генерация `.pb.go`, `_grpc.pb.go` и `.pb.gw.go`.
3. Запуск gRPC сервера на порту `:50051`.
4. Запуск Gateway HTTP сервера на порту `:8080`.
5. Проверка: вызов `curl -i http://localhost:8080/v1/users/42` возвращает валидный JSON.

## Решение по шагам

1. Опишите схему с аннотацией.
2. Смоделируйте сквозной вызов от HTTP запроса до gRPC ответа.
3. Проверьте возврат корректного JSON.
4. Продемонстрируйте вызов утилиты curl.

## Код решения

**`full_gateway_e2e_test.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"strings"
	"testing"
)

type UserJSONResponse struct {
	ID    string `json:"id"`
	Name  string `json:"name"`
	Email string `json:"email"`
}

func EndToEndGatewayHandler(w http.ResponseWriter, r *http.Request) {
	if strings.HasPrefix(r.URL.Path, "/v1/users/") && r.Method == http.MethodGet {
		userID := strings.TrimPrefix(r.URL.Path, "/v1/users/")

		// Трансляция в gRPC ответ
		resp := UserJSONResponse{
			ID:    userID,
			Name:  "Константин Романов",
			Email: "romanov@bigtech.ru",
		}

		w.Header().Set("Content-Type", "application/json")
		_ = json.NewEncoder(w).Encode(resp)
		return
	}
	http.NotFound(w, r)
}

func TestE2EGatewayCurl(t *testing.T) {
	ts := httptest.NewServer(http.HandlerFunc(EndToEndGatewayHandler))
	defer ts.Close()

	// Имитация вызова: curl -i http://localhost:8080/v1/users/user_777
	resp, err := http.Get(ts.URL + "/v1/users/user_777")
	if err != nil {
		t.Fatalf("Ошибка вызова: %v", err)
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		t.Fatalf("Ожидался статус 200, получен: %d", resp.StatusCode)
	}

	body, _ := io.ReadAll(resp.Body)
	var u UserJSONResponse
	_ = json.Unmarshal(body, &u)

	if u.ID != "user_777" || u.Name != "Константин Романов" {
		t.Fatalf("Некорректный JSON ответ: %+v", u)
	}

	fmt.Printf("curl успешно получил транслированный JSON: %s\n", strings.TrimSpace(string(body)))
}
```

## Под капотом

gRPC-Gateway преобразует имена полей Protobuf в camelCase для JSON (`user_id` \(\to\) `userId`) по стандартам Google JSON Mapping. Флаг `runtime.WithMarshalerOption` позволяет настроить snake_case.

## Подводные камни

Забывать указывать `paths=source_relative` при генерации `.pb.gw.go`: файлы сгенерируются во вложенные поддиректории репозитория.

## На собеседовании

**Вопрос с собеседования:** «Как в gRPC-Gateway вернуть поле с дефолтным нулевым значением (например age = 0 или active = false)?»
**Ответ:** По умолчанию Protobuf опускает поля с нулевыми значениями в JSON (`omitempty`). Чтобы принудительно возвращать нулевые поля, настраивают маршалер:
```go
runtime.WithMarshalerOption(runtime.MIMEWildcard, &runtime.JSONPb{
    MarshalOptions: protojson.MarshalOptions{EmitUnpopulated: true},
})
```
