# Продвинутые Well-Known Types: Struct, Value, Any, Duration и FieldMask

## Условие

Изучите `well-known types`: `Struct`, `Value`, `ListValue`, `Any`, `Duration`, `FieldMask`.

## Теория

Продвинутые стандартные типы Protobuf:
1. **`google.protobuf.Any`:** контейнер для произвольного сообщения Protobuf с префиксом типа URL (`type.googleapis.com/...`). Замена `interface{}`.
2. **`google.protobuf.Struct` / `Value`:** динамический JSON объект в Protobuf (произвольные ключи и значения: string, number, bool, list).
3. **`google.protobuf.FieldMask`:** список путей полей для частичного обновления (`paths: ["user.email", "user.name"]`).
4. **`google.protobuf.Duration`:** длительность с наносекундной точностью.

## Решение по шагам

1. Создайте схему с типами `Any` и `FieldMask`.
2. В Go продемонстрируйте упаковку любого сообщения через `anypb.New()`.
3. Распакуйте `Any` через `any.UnmarshalTo()`.
4. Продемонстрируйте работу со `Struct` и `FieldMask`.

## Код решения

**`wkt_advanced_demo.go`**

```go
package main

import (
	"fmt"

	"google.golang.org/protobuf/types/known/anypb"
	"google.golang.org/protobuf/types/known/fieldmaskpb"
	"google.golang.org/protobuf/types/known/structpb"
)

func main() {
	// 1. Демонстрация FieldMask (маска обновления для PATCH)
	mask, err := fieldmaskpb.New(&struct{}{}, "name", "email", "status")
	if err != nil {
		panic(err)
	}
	fmt.Println("Поля для обновления в БД (FieldMask):", mask.GetPaths())

	// 2. Демонстрация динамического Struct (эквивалент map[string]any в JSON)
	dynStruct, err := structpb.NewStruct(map[string]any{
		"env":         "production",
		"max_retries": 5,
		"debug":       false,
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("Динамический JSON-конфиг (structpb): %v\n", dynStruct.AsMap())

	// 3. Демонстрация Any (полиморфный контейнер)
	anyContainer, err := anypb.New(dynStruct)
	if err != nil {
		panic(err)
	}
	fmt.Println("Any Type URL:", anyContainer.GetTypeUrl())
}
```

ℹ️ Использование FieldMask, Struct и Any в Go

**`Терминал`**

```bash
go run wkt_advanced_demo.go

# Динамический JSON-конфиг (structpb): map[debug:false env:production max_retries:5]

```

## Под капотом

`anypb.Any` хранит внутри два поля: `type_url` (строка формата `type.googleapis.com/package.MessageName`) и `value` (сырые сериализованные байты). При вызове `any.UnmarshalTo(target)` парсер находит дескриптор типа в глобальном реестре `protoregistry.GlobalTypes`.

## Подводные камни

Злоупотреблять `google.protobuf.Struct`: передача произвольного JSON внутри Protobuf уничтожает строгую типизацию схемы и замедляет парсинг. Используйте строгие контракты.

## На собеседовании

**Вопрос с собеседования:** «Как FieldMask защищает от уязвимости Mass Assignment в API?»
**Ответ:** Клиент может передать в JSON тело с полями `is_admin: true` или `balance: 1000000`. Если сервер слепо обновляет все переданные поля, произойдет взлом привилегий. При использовании `FieldMask` сервер обновляет строго те поля, которые входят в белый список разрешенных путей `mask.GetPaths()`, игнорируя недопустимые атрибуты.
