# Ассоциативные словари сложных сущностей: поле map<string, User> и его отображение в Go

## Условие

Создайте `.proto` с `map<string, User> users` и посмотрите, как это превращается в Go-мапу.

## Теория

Словари сложных сообщений в Protobuf:
- Синтаксис: `map<string, User> users = 1;`
- Значением мапы может быть любое сообщение (`message User`).
- В Go компилируется в:
  `Users map[string]*User`
- Ключи — строки, значения — **указатели на структуры**, что исключает избыточное копирование памяти при передаче объектов.

## Решение по шагам

1. Объявите `map<string, User> users = 1;` в схеме `UserDirectory`.
2. Создайте каталог пользователей в Go.
3. Добавьте элементы с указателями.
4. Продемонстрируйте быстрый поиск по строковому ключу.

## Код решения

**`user_map.proto`**

```protobuf
syntax = "proto3";

package directory.v1;

option go_package = "./directoryv1;directoryv1";

message User {
  int64 id = 1;
  string display_name = 2;
}

message UserDirectory {
  map<string, User> users = 1; // Отображение username -> User
}
```

ℹ️ Схема с мапой сложных объектов

**`user_map_demo.go`**

```go
package main

import "fmt"

type UserItem struct {
	ID          int64
	DisplayName string
}

type UserDirectoryDTO struct {
	Users map[string]*UserItem // Указатели на структуры!
}

func main() {
	dir := &UserDirectoryDTO{
		Users: make(map[string]*UserItem),
	}

	dir.Users["alex"] = &UserItem{ID: 101, DisplayName: "Алексей Инженер"}
	dir.Users["maria"] = &UserItem{ID: 102, DisplayName: "Мария Тимлид"}

	fmt.Println("Поиск пользователя по логину 'alex':")
	if user, exists := dir.Users["alex"]; exists {
		fmt.Printf("  Найден: ID=%d, Имя=%s\n", user.ID, user.DisplayName)
	}

	fmt.Printf("Всего записей в каталоге: %d\n", len(dir.Users))
}
```

ℹ️ Поиск и хранение указателей в карте пользователей

**`Терминал`**

```bash
go run user_map_demo.go
# Вывод:
# Поиск пользователя по логину 'alex':
#   Найден: ID=101, Имя=Алексей Инженер
# Всего записей в каталоге: 2
```

## Под капотом

В бинарном потоке Protobuf пара `key:value` кодируется как синтетическое сообщение. Значение `*UserItem` кодируется по правилам вложенного сообщения (Wire Type 2) с байтом длины.

## Подводные камни

Записывать в мапу `nil` указатель `dir.Users["key"] = nil`: при сериализации пустой указатель вызовет проблемы в старых версиях библиотек. Значение всегда должно быть валидным объектом.

## На собеседовании

**Вопрос с собеседования:** «Почему значениями в map[string]*User являются указатели, а не значения структуры map[string]User?»
**Ответ:** Потому что в Go элементы карты `map[K]V` неадресуемы (`&m[k]` недопустим). Если бы значения хранились по значению, нельзя было бы напрямую мутировать поля структуры `m["alex"].DisplayName = "New"`. Хранение указателя `*User` позволяет модифицировать вложенные поля напрямую без полного перезаписывания элемента карты.
