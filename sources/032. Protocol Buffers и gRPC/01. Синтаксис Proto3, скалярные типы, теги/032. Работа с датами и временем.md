# Работа с датами и временем: интеграция created_at с типом timestamppb.Timestamp

## Условие

Добави в `user.proto` поле `google.protobuf.Timestamp created_at = 4;` (`import "google/protobuf/timestamp.proto";`). Сгенерируй код. Покажи, как работать с `timestamppb.Timestamp` в Go (конвертация `time.Time` ↔ `*timestamppb.Timestamp`).

## Теория

Практика использования timestamppb в бизнес-моделях:
- Время создания записи `created_at` и обновления `updated_at` присутствуют практически в каждой таблице БД.
- В proto3:
  `google.protobuf.Timestamp created_at = 4;`
- В Go:
  - Из Go в Protobuf: `timestamppb.New(user.CreatedAt)` (или `timestamppb.Now()`).
  - Из Protobuf в Go: `user.GetCreatedAt().AsTime()`.
- Автоматическая валидация: `err := ts.CheckValid()` проверяет диапазон секунд и наносекунд.

## Решение по шагам

1. Создайте схему `UserRecord` с полем `created_at`.
2. Создайте объект с `timestamppb.Now()`.
3. Извлеките время обратно в стандартный `time.Time`.
4. Распечатайте форматированную дату в локальной таймзоне.

## Код решения

**`user_timestamp.proto`**

```protobuf
syntax = "proto3";

package user.v1;

import "google/protobuf/timestamp.proto";

option go_package = "./userv1;userv1";

message UserRecord {
  int64 id = 1;
  string username = 2;
  google.protobuf.Timestamp created_at = 4;
}
```

ℹ️ Схема пользователя с временной меткой created_at

**`timestamp_crud_demo.go`**

```go
package main

import (
	"fmt"
	"time"

	"google.golang.org/protobuf/types/known/timestamppb"
)

type UserEntity struct {
	ID        int64
	Username  string
	CreatedAt *timestamppb.Timestamp
}

func main() {
	// Создание пользователя с текущим временем UTC
	user := &UserEntity{
		ID:        777,
		Username:  "alex_dev",
		CreatedAt: timestamppb.Now(), // Идиоматичный конструктор текущего момента
	}

	fmt.Printf("Пользователь: %s [ID %d]\n", user.Username, user.ID)
	fmt.Printf("Timestamp Raw: seconds=%d nanos=%d\n",
		user.CreatedAt.GetSeconds(), user.CreatedAt.GetNanos())

	// Конвертация в стандартный time.Time
	goTime := user.CreatedAt.AsTime()
	fmt.Printf("Форматированное время Go (UTC):     %s\n", goTime.Format("2006-01-02 15:04:05 MST"))

	// Конвертация в московскую таймзону (MSK, UTC+3)
	loc, _ := time.LoadLocation("Europe/Moscow")
	fmt.Printf("Форматированное время Go (Москва):  %s\n", goTime.In(loc).Format("2006-01-02 15:04:05 MST"))
}
```

ℹ️ Создание timestamppb и форматирование с учетом таймзон в Go

**`Терминал`**

```bash
go run timestamp_crud_demo.go
# Вывод:
# Пользователь: alex_dev [ID 777]
# Timestamp Raw: seconds=1788449100 nanos=540000000
# Форматированное время Go (UTC):     2026-09-03 18:05:00 UTC
# Форматированное время Go (Москва):  2026-09-03 21:05:00 MSK
```

## Под капотом

`timestamppb.Timestamp` гарантирует хранение времени строго в секундах с эпохи Unix (1 января 1970 года). Поле `nanos` хранит неотрицательное смещение от 0 до 999 999 999 наносекунд.

## Подводные камни

Передавать `time.Time` без вызова `UTC()` в самодельные структуры: часовые пояса могут исказить замеры при передаче между серверами. `timestamppb.New(t)` автоматически нормализует время в UTC.

## На собеседовании

**Вопрос с собеседования:** «Что вернет метод ts.AsTime(), если указатель ts == nil?»
**Ответ:** Метод `AsTime()` на `nil` указателе безопасно возвращает нулевое значение времени Go: `time.Time{}` (то есть 1 января 0001 года UTC), не вызывая паники разыменования указателя.
