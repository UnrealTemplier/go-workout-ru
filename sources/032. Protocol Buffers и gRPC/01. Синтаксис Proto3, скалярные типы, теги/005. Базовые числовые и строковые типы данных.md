# Базовые числовые и строковые типы данных в Protobuf: int32, int64, string и скалярные типы

## Условие

Создай файл `user.proto`. Опиши сообщение `User` с полями `id` (int32), `name` (string), `age` (int32).

## Теория

Скалярные типы данных в proto3 и их представление в памяти Go:
| Protobuf тип | Go тип | Wire Type | Применение |
| :--- | :--- | :--- | :--- |
| `int32` / `int64` | `int32` / `int64` | 0 (Varint) | Положительные целые числа |
| `sint32` / `sint64` | `int32` / `int64` | 0 (ZigZag Varint) | Числа с частыми отрицательными значениями |
| `fixed32` / `fixed64` | `uint32` / `uint64` | 5 (32-bit) / 1 (64-bit) | Большие числа > \(2^{56}\) (хэши, ID) |
| `string` | `string` | 2 (Length-delimited) | Строки строго в кодировке UTF-8 |
| `bytes` | `[]byte` | 2 (Length-delimited) | Сырые бинарные данные, токены, сжатые блоки |
| `bool` | `bool` | 0 (Varint) | Логические флаги (0 или 1) |

## Решение по шагам

1. Создайте сообщение `User` с полями `id`, `name`, `age`.
2. Назначьте уникальные номера тегов 1, 2, 3.
3. Продемонстрируйте создание объекта в Go.
4. Проверьте сгенерированные геттеры (`GetId`, `GetName`, `GetAge`).

## Код решения

**`user.proto`**

```protobuf
syntax = "proto3";

package user.v1;

option go_package = "./userv1;userv1";

message User {
  int32 id = 1;
  string name = 2;
  int32 age = 3;
}
```

ℹ️ Схема с базовыми скалярными типами

**`scalar_types_demo.go`**

```go
package main

import "fmt"

// UserDTO эмулирует сгенерированную структуру Protobuf
type UserDTO struct {
	Id   int32
	Name string
	Age  int32
}

// Вспомогательные nil-safe геттеры, генерируемые protoc-gen-go
func (u *UserDTO) GetId() int32 {
	if u != nil {
		return u.Id
	}
	return 0
}

func (u *UserDTO) GetName() string {
	if u != nil {
		return u.Name
	}
	return ""
}

func (u *UserDTO) GetAge() int32 {
	if u != nil {
		return u.Age
	}
	return 0
}

func main() {
	user := &UserDTO{
		Id:   42,
		Name: "Елена",
		Age:  28,
	}

	fmt.Printf("User: ID=%d, Name=%s, Age=%d\n", user.GetId(), user.GetName(), user.GetAge())

	// Проверка nil-safety геттеров:
	var nilUser *UserDTO
	fmt.Printf("Nil user name: %q, age: %d (без паники!)\n", nilUser.GetName(), nilUser.GetAge())
}
```

ℹ️ Безопасное использование геттеров сгенерированных Protobuf структур

**`Терминал`**

```bash
go run scalar_types_demo.go
# Вывод:
# User: ID=42, Name=Елена, Age=28
# Nil user name: "", age: 0 (без паники!)
```

## Под капотом

Компилятор `protoc-gen-go` генерирует геттеры вида `func (x *T) GetField()`, которые проверяют `if x != nil`. Это предотвращает распространенные паники рантайма `panic: runtime error: invalid memory address or nil pointer dereference` при доступе к вложенным структурам.

## Подводные камни

Использовать тип `int32` для отрицательных чисел: стандартный `int32` кодирует отрицательные числа 10 байтами Varint. Для чисел, которые часто бывают отрицательными, ОБЯЗАТЕЛЬНО используйте `sint32` (ZigZag кодирование).

## На собеседовании

**Вопрос с собеседования:** «В чем разница между int32 и sint32 при кодировании числа -1 в Protobuf?»
**Ответ:** Число `-1` в типе `int32` знакорасширяется до 64 бит и занимает максимальные 10 байт в проводе (`0xFF 0xFF... 0x01`). Тип `sint32` применяет преобразование ZigZag `(n << 1) ^ (n >> 31)`, превращая `-1` в положительное число `1`, которое кодируется всего **1 байтом**!
