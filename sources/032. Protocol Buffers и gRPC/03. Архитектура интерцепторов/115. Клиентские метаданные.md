# Клиентские метаданные: отправка заголовков с помощью metadata.AppendToOutgoingContext

## Условие

Отправьте метаданные (аналог HTTP-заголовков) из клиента: `metadata.AppendToOutgoingContext(ctx, "authorization", "Bearer token")`.

## Теория

Безопасная инжекция клиентских заголовков:
- Функция `metadata.AppendToOutgoingContext(ctx, key, val)`:
  - Проверяет наличие существующих метаданных в контексте.
  - Добавляет новую пару ключ-значение.
  - Если ключ уже существовал, добавляет значение в срез `[]string` (множественные заголовки).
- Позволяет передавать токены, версии клиентов (`x-client-version: 2.5.0`) и флаги фиче-тогглов.

## Решение по шагам

1. Создайте контекст с несколькими заголовками.
2. Используйте `metadata.AppendToOutgoingContext`.
3. Извлеките метаданные и проверьте содержимое среза.
4. Продемонстрируйте доступ к значениям.

## Код решения

**`metadata_append_demo.go`**

```go
package main

import (
	"context"
	"fmt"

	"google.golang.org/grpc/metadata"
)

func main() {
	ctx := context.Background()

	// Добавляем токен авторизации
	ctx = metadata.AppendToOutgoingContext(ctx, "authorization", "Bearer eyJhbGciOi...")

	// Добавляем версию клиентского приложения
	ctx = metadata.AppendToOutgoingContext(ctx, "x-client-version", "v3.12.1")

	// Добавляем трассировочные заголовки
	ctx = metadata.AppendToOutgoingContext(ctx, "x-env", "staging")

	// Проверяем упакованные метаданные
	md, ok := metadata.FromOutgoingContext(ctx)
	if !ok {
		panic("метаданные не найдены")
	}

	fmt.Println("Клиентские метаданные для отправки по сети:")
	for k, v := range md {
		fmt.Printf("  %s = %v\n", k, v)
	}
}
```

ℹ️ Формирование исходящих метаданных через AppendToOutgoingContext

**`Терминал`**

```bash
go run metadata_append_demo.go
# Вывод:
# Клиентские метаданные для отправки по сети:
#   authorization = [Bearer eyJhbGciOi...]
```

## Под капотом

`metadata.MD` является псевдонимом типа `map[string][]string`. Имена ключей принудительно нормализуются в нижний регистр через `strings.ToLower`, обеспечивая совместимость со стандартом HTTP/2.

## Подводные камни

Использовать ключи с верхним регистром при ручном создании `metadata.MD{"Auth": ...}`: HTTP/2 фреймы требуют строгий lowercase, что может привести к скрытым ошибкам поиска заголовков.

## На собеседовании

**Вопрос с собеседования:** «Как передать несколько значений одного и того же заголовка в gRPC?»
**Ответ:** Передать несколько аргументов подряд: `metadata.AppendToOutgoingContext(ctx, "x-tag", "alpha", "x-tag", "beta")` или `metadata.Pairs("x-tag", "alpha", "x-tag", "beta")`. Получатель увидит срез `[]string{"alpha", "beta"}`.
