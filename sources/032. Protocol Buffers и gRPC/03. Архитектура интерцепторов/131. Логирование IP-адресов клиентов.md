# Логирование IP-адресов клиентов: извлечение сетевой информации через peer.FromContext

## Условие

Создайте middleware, который логирует IP-адрес клиента (извлекайте из `peer.Peer` в контексте).

## Теория

Сетевая идентификация вызывающей стороны:
- В gRPC сетевой адрес сокета инкапсулирован в структуру `peer.Peer`:
  `p, ok := peer.FromContext(ctx)`
- Структура `peer.Peer`:
  - `p.Addr`: сетевой адрес `net.Addr` (например `192.168.1.50:49152`).
  - `p.AuthInfo`: учетные данные TLS/mTLS.
- При наличии обратного прокси (Reverse Proxy / Load Balancer) реальный IP может находиться в метаданных `x-forwarded-for`.

## Решение по шагам

1. Создайте `PeerLoggingInterceptor`.
2. Извлеките `peer.FromContext(ctx)`.
3. Извлеките `x-forwarded-for` при наличии.
4. Протестируйте логирование сетевого адреса.

## Код решения

**`peer_ip_logger_test.go`**

```go
package main

import (
	"context"
	"fmt"
	"net"
	"testing"

	"google.golang.org/grpc"
	"google.golang.org/grpc/metadata"
	"google.golang.org/grpc/peer"
)

func ClientIPLoggingInterceptor(
	ctx context.Context,
	req any,
	info *grpc.UnaryServerInfo,
	handler grpc.UnaryHandler,
) (any, error) {
	clientIP := "unknown"

	// 1. Попытка извлечь заголовок x-forwarded-for от балансировщика
	if md, ok := metadata.FromIncomingContext(ctx); ok {
		if xff := md.Get("x-forwarded-for"); len(xff) > 0 {
			clientIP = xff[0]
		}
	}

	// 2. Если заголовка нет, берем прямой TCP-адрес сокета
	if clientIP == "unknown" {
		if p, ok := peer.FromContext(ctx); ok && p.Addr != nil {
			clientIP = p.Addr.String()
		}
	}

	fmt.Printf("[NETWORK AUDIT] Client IP: %-21s | Method: %s\n", clientIP, info.FullMethod)
	return handler(ctx, req)
}

func TestClientIPExtraction(t *testing.T) {
	dummyHandler := func(ctx context.Context, req any) (any, error) { return "OK", nil }
	info := &grpc.UnaryServerInfo{FullMethod: "/auth.v1.AuthService/Login"}

	// Симулируем соединение с TCP адресом
	tcpPeer := &peer.Peer{Addr: &net.TCPAddr{IP: net.ParseIP("203.0.113.195"), Port: 52140}}
	ctxWithPeer := peer.NewContext(context.Background(), tcpPeer)

	_, err := ClientIPLoggingInterceptor(ctxWithPeer, nil, info, dummyHandler)
	if err != nil {
		t.Fatalf("Ошибка интерцептора: %v", err)
	}
}
```

ℹ️ Извлечение прямого сокетного IP и x-forwarded-for в gRPC интерцепторе

## Под капотом

`peer.FromContext` извлекается из приватных полей контекста вызова `peerKey{}`, который заполняется сервером gRPC во время `Accept()` входящего TCP-соединения.

## Подводные камни

Слепо доверять `x-forwarded-for` от ненадежных клиентов: любой злоумышленник может подделать этот заголовок. Принимайте `x-forwarded-for` только от доверенных внутренних прокси (NGINX/Envoy).

## На собеседовании

**Вопрос с собеседования:** «Как в mTLS извлечь Subject Alternative Name (SAN) сертификата клиента из peer.AuthInfo?»
**Ответ:** Привести `p.AuthInfo` к типу `credentials.TLSInfo`:
```go
tlsInfo := p.AuthInfo.(credentials.TLSInfo)
clientCert := tlsInfo.State.PeerCertificates[0]
clientSAN := clientCert.DNSNames // или clientCert.URIs для SPIFFE ID
```
Это позволяет безопасно идентифицировать вызывающий микросервис.
