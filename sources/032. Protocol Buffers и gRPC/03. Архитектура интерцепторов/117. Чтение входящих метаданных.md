# Чтение входящих метаданных: извлечение заголовков через metadata.FromIncomingContext

## Условие

Прочитайте метаданные на сервере: `md, ok := metadata.FromIncomingContext(ctx)`.

## Теория

Аудит заголовков на сервере:
- Любой серверный метод или интерцептор может прочитать метаданные запроса:
  `md, ok := metadata.FromIncomingContext(ctx)`
- Если клиент не передал заголовки, `ok` равен `false`.
- Поиск конкретного ключа:
  `vals := md.Get("x-trace-id")`
  Метод `.Get(k)` автоматически нормализует имя в lowercase и возвращает срез строк.

## Решение по шагам

1. Смоделируйте входящий контекст с метаданными.
2. Извлеките карту заголовков через `FromIncomingContext`.
3. Прочитайте значения через метод `.Get()`.
4. Обработайте сценарий отсутствия заголовка.

## Код решения

**`incoming_metadata_reader_test.go`**

```go
package main

import (
	"context"
	"fmt"
	"testing"

	"google.golang.org/grpc/metadata"
)

func ReadClientEnvironment(ctx context.Context) (string, error) {
	md, ok := metadata.FromIncomingContext(ctx)
	if !ok {
		return "", fmt.Errorf("метаданные не переданы")
	}

	envValues := md.Get("x-client-env")
	if len(envValues) == 0 {
		return "production", nil // Дефолтное окружение
	}

	return envValues[0], nil
}

func TestReadIncomingMetadata(t *testing.T) {
	// Имитация входящего запроса со staging клиента
	md := metadata.Pairs("x-client-env", "staging")
	ctx := metadata.NewIncomingContext(context.Background(), md)

	env, err := ReadClientEnvironment(ctx)
	if err != nil {
		t.Fatalf("Ошибка: %v", err)
	}

	if env != "staging" {
		t.Fatalf("got %q; want 'staging'", env)
	}

	fmt.Printf("Сервер успешно определил окружение клиента: %s\n", env)
}
```

## Под капотом

Метод `md.Get(key)` является nil-safe: если `md == nil` или ключ отсутствует, метод возвращает `nil`-срез без паники разыменования указателя.

## Подводные камни

Использовать обращение по прямому ключу `md["X-Custom-Key"]`: из-за верхнего регистра ключ не найдется, так как в `md` все ключи приведены к lowercase. Всегда используйте `md.Get(...)`.

## На собеседовании

**Вопрос с собеседования:** «Можно ли изменить входящие метаданные FromIncomingContext на сервере?»
**Ответ:** Нет, `FromIncomingContext` возвращает неизменяемый снимок заголовков текущего запроса. Чтобы передать новые метаданные дальше по цепочке в исходящий вызов другого сервиса, создают новый контекст через `metadata.NewOutgoingContext`.
