# Логирование в Unary Server Interceptor: метод запроса, замер задержки и статус регистрации

## Условие

**Unary Server Interceptor**: Напиши функцию-логгер, которая выводит метод запроса и время его выполнения. Зарегистрируй её через `grpc.UnaryInterceptor()`.

## Теория

Канонический интерцептор замера задержек:
- Регистрация интерцептора:
  `server := grpc.NewServer(grpc.UnaryInterceptor(TimingLoggerInterceptor))`
- Логика:
  1. Старт таймера: `start := time.Now()`
  2. Вызов: `resp, err := handler(ctx, req)`
  3. Дельта: `time.Since(start)`
  4. Печать метода: `info.FullMethod`
- Идеально подходит для первичной диагностики узких мест сервиса.

## Решение по шагам

1. Напишите `TimingLoggerInterceptor`.
2. Замерьте время выполнения через `time.Since`.
3. Подключите интерцептор к серверу.
4. Проверьте вывод в консоль.

## Код решения

**`timing_logger_interceptor_test.go`**

```go
package main

import (
	"context"
	"fmt"
	"testing"
	"time"

	"google.golang.org/grpc"
)

func TimingLoggerInterceptor(
	ctx context.Context,
	req any,
	info *grpc.UnaryServerInfo,
	handler grpc.UnaryHandler,
) (any, error) {
	start := time.Now()

	resp, err := handler(ctx, req)

	duration := time.Since(start)
	fmt.Printf("[gRPC Timing] Method: %-35s | Duration: %v\n",
		info.FullMethod, duration.Round(time.Microsecond))

	return resp, err
}

func TestTimingLogger(t *testing.T) {
	mockHandler := func(ctx context.Context, req any) (any, error) {
		time.Sleep(8 * time.Millisecond) // Имитация работы хэндлера
		return "OK", nil
	}

	info := &grpc.UnaryServerInfo{FullMethod: "/catalog.v1.Catalog/GetProduct"}

	resp, err := TimingLoggerInterceptor(context.Background(), "req_data", info, mockHandler)
	if err != nil {
		t.Fatalf("Ошибка: %v", err)
	}

	if resp != "OK" {
		t.Fatalf("Некорректный ответ: %v", resp)
	}
}
```

## Под капотом

`grpc.UnaryInterceptor` передается как опция сервера `grpc.ServerOption`. Рантайм gRPC сохраняет указатель на функцию в поле `s.opts.unaryInt` структуры `grpc.Server`.

## Подводные камни

Использовать `grpc.UnaryInterceptor()` дважды: повторный вызов перезапишет первый интерцептор. Для объединения нескольких интерцепторов используйте `grpc.ChainUnaryInterceptor()`.

## На собеседовании

**Вопрос с собеседования:** «Как во UnaryInterceptor измерить задержку с наносекундной точностью?»
**Ответ:** Вызов `time.Now()` в современном Go (начиная с Go 1.9+) использует монотонные часы процессора (Monotonic Clock, `rdtsc` на x86). `time.Since(start)` вычисляет разницу по монотонному счетчику тактов, гарантируя наносекундную точность даже при корректировке времени NTP сервером.
