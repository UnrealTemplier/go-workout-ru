# Реализация Echo-сервера в Bidirectional Streaming: мгновенный возврат полученных сообщений

## Условие

**Bidirectional Streaming**: Добавь метод `Chat`, принимающий и возвращающий `stream Message`. Реализуй echo-сервер: горутина читает из `stream.Recv()` и тут же отправляет обратно через `stream.Send()`.

## Теория

Принцип работы потокового Echo-сервера:
- Метод `Chat(stream Chat_Server)`:
  - Читает сообщение из входного буфера `Recv()`.
  - Модифицирует payload (например, добавляет префикс `[Echo] ` и метку времени).
  - Сразу же отправляет обратно через `Send()`.
  - Повторяет до тех пор, пока клиент не пришлет сигнал окончания стрима `io.EOF`.

## Решение по шагам

1. Создайте метод `EchoChat`.
2. Организуйте цикл чтения `stream.Recv()`.
3. Отправьте ответ через `stream.Send()`.
4. Обработайте штатное завершение по `io.EOF`.

## Код решения

**`instant_echo_stream_test.go`**

```go
package main

import (
	"fmt"
	"io"
	"testing"
)

type ChatMessageDTO struct {
	Text string
}

type InstantEchoStream struct {
	pipe chan *ChatMessageDTO
}

func (s *InstantEchoStream) Recv() (*ChatMessageDTO, error) {
	msg, ok := <-s.pipe
	if !ok {
		return nil, io.EOF
	}
	return msg, nil
}

func (s *InstantEchoStream) Send(msg *ChatMessageDTO) error {
	fmt.Printf("  [Echo Server Send] -> %s\n", msg.Text)
	return nil
}

func RunInstantEchoServer(stream *InstantEchoStream) error {
	for {
		msg, err := stream.Recv()
		if err == io.EOF {
			fmt.Println("Клиент закрыл поток, эхо-сервер штатно завершил работу")
			return nil
		}
		if err != nil {
			return err
		}

		echoResp := &ChatMessageDTO{Text: "[Echo Server]: " + msg.Text}
		if err := stream.Send(echoResp); err != nil {
			return err
		}
	}
}

func TestInstantEchoServer(t *testing.T) {
	stream := &InstantEchoStream{pipe: make(chan *ChatMessageDTO, 5)}

	done := make(chan error)
	go func() {
		done <- RunInstantEchoServer(stream)
	}()

	stream.pipe <- &ChatMessageDTO{Text: "Сообщение 1"}
	stream.pipe <- &ChatMessageDTO{Text: "Сообщение 2"}
	close(stream.pipe)

	err := <-done
	if err != nil {
		t.Fatalf("Ошибка сервера: %v", err)
	}
}
```

## Под капотом

Отправка ответа происходит немедленно в том же контексте соединения. Задержка между приемом пакета и генерацией эхо-ответа составляет менее 20 микросекунд.

## Подводные камни

Забывать обрабатывать ошибку отправки `stream.Send(echoResp)`: если клиент отсоединился, сервер не должен продолжать цикл чтения.

## На собеседовании

**Вопрос с собеседования:** «Как измерить RTT (Round Trip Time) соединения с помощью Bidirectional Echo стрима?»
**Ответ:** Клиент перед вызовом `stream.Send()` записывает текущее наносекундное время `time.Now().UnixNano()` в поле сообщения, а при приеме эхо-ответа в `stream.Recv()` вычисляет разницу `time.Since(sentTime)`. Это позволяет непрерывно мониторить сетевой джиттер (Jitter) и RTT в production.
