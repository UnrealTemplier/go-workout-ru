# Потоковая передача по таймеру: отправка тикеров времени и отписка через отмену контекста

## Условие

Реализуйте streaming-метод, который отправляет данные по таймеру (например, тикеры времени каждую секунду). Клиент должен отписаться через отмену контекста.

## Теория

Периодический стриминг и отписка клиентов:
- Классический сценарий: передача телеметрии, пульса (Heartbeat), обновлений котировок валют.
- Сервер организует цикл по `time.NewTicker`:
  ```go
  for {
      select {
      case <-stream.Context().Done():
          return stream.Context().Err()
      case t := <-ticker.C:
          stream.Send(&TimeTick{Timestamp: timestamppb.New(t)})
      }
  }
  ```
- Клиент в любой момент вызывает `cancel()`, закрывая поток.

## Решение по шагам

1. Создайте серверный метод с `time.NewTicker`.
2. Добавьте проверку `stream.Context().Done()`.
3. Запустите чтение на клиенте.
4. Вызовите `cancel()` через несколько секунд и убедитесь в чистой остановке.

## Код решения

**`ticker_stream_demo.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"
)

type TickMessage struct {
	Timestamp string
}

func ServerTimeTicker(ctx context.Context, out chan<- *TickMessage) error {
	ticker := time.NewTicker(25 * time.Millisecond)
	defer ticker.Stop()

	for {
		select {
		case <-ctx.Done():
			fmt.Println("Сервер: получен сигнал отмены контекста, останавливаем тикер")
			return ctx.Err()
		case t := <-ticker.C:
			out <- &TickMessage{Timestamp: t.Format("15:04:05.000")}
		}
	}
}

func main() {
	// Клиент подписывается с возможностью отмены
	ctx, cancel := context.WithCancel(context.Background())
	feed := make(chan *TickMessage, 5)

	go func() {
		_ = ServerTimeTicker(ctx, feed)
		close(feed)
	}()

	fmt.Println("Клиент слушает тикер времени:")
	ticksReceived := 0
	for msg := range feed {
		fmt.Printf("  [Тик %d]: %s\n", ticksReceived+1, msg.Timestamp)
		ticksReceived++
		if ticksReceived >= 3 {
			fmt.Println("Клиент отписывается от стрима (вызов cancel())...")
			cancel()
		}
	}

	time.Sleep(30 * time.Millisecond)
	fmt.Println("Работа завершена, утечек горутин нет")
}
```

## Под капотом

Отмена контекста на клиенте генерирует фрейм `RST_STREAM`. Канал `ctx.Done()` на сервере закрывается мгновенно, прерывая `select` и останавливая `ticker.Stop()`.

## Подводные камни

Использовать `time.Tick` вместо `time.NewTicker`: функция `time.Tick` не позволяет остановить таймер, что приводит к утечке ресурсов в сборщике мусора.

**Ответ:** gRPC стриминг имеет строгий двоичный Protobuf контракт, в 5 раз более компактный заголовочный оверхед благодаря сжатию заголовков HPACK в HTTP/2 и аппаратно поддержанную мультиплексацию тысяч инструментов в одном сокете без разрыва соединений.
