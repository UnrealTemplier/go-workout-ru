# Автоматическая конфигурация флагов сборки через #cgo pkg-config

## Условие

Используйте директиву `#cgo pkg-config: libname` для автоматического получения флагов компиляции и линковки системных библиотек. Объясните, как `pkg-config` решает проблему разных путей к заголовкам и библиотекам на разных дистрибутивах Linux и macOS.

### Исходная формулировка

**pkg-config**: Используйте `#cgo pkg-config: libname` для автоматического получения флагов компиляции.

## Теория

Разные операционные системы и дистрибутивы Linux размещают заголовочные файлы и библиотеки в разных каталогах:
- Ubuntu/Debian: `/usr/include`, `/usr/lib/x86_64-linux-gnu`
- RedHat/CentOS: `/usr/lib64`
- macOS (Homebrew): `/opt/homebrew/include`, `/opt/homebrew/lib`

Утилита **pkg-config** унифицирует конфигурацию. Команда:
`pkg-config --cflags --libs sqlite3`
возвращает точные флаги для текущей ОС.
Директива CGO:
`#cgo pkg-config: sqlite3`
автоматически вызывает `pkg-config` во время компиляции Go, избавляя от жестко зашитых путей `#cgo CFLAGS: -I...`.

## Решение по шагам

1. Проверьте установку pkg-config в системе: `pkg-config --version`.
2. В преамбуле укажите `#cgo pkg-config: zlib`.
3. Подключите `<zlib.h>`.
4. В Go коде вызовите функцию `C.zlibVersion()`.
5. Преобразуйте версию в Go-строку и выведите в консоль.

## Код решения

**`main.go`**

```go
package main

/*
#cgo pkg-config: zlib
#include <zlib.h>
*/
import "C"
import "fmt"

func main() {
	// zlibVersion() возвращает const char* с версией библиотеки
	cVersion := C.zlibVersion()
	goVersion := C.GoString(cVersion)

	fmt.Printf("Версия системной библиотеки zlib: %s\n", goVersion)
	fmt.Println("Флаги компиляции и линковки получены автоматически через pkg-config!")
}
```

ℹ️ \#cgo pkg-config устраняет необходимость вручную прописывать CFLAGS и LDFLAGS.

**`Терминал`**

```bash
pkg-config --cflags --libs zlib
# Вывод: -lz

go run main.go
# Вывод:
# Версия системной библиотеки zlib: 1.2.11 (или актуальная версия)
# Флаги компиляции и линковки получены автоматически через pkg-config!
```

## Под капотом

Во время этапа анализа преамбулы CGO запускает `pkg-config --cflags zlib` и добавляет вывод к `CFLAGS`, затем запускает `pkg-config --libs zlib` и добавляет вывод к `LDFLAGS`. Метаданные считываются из файлов `.pc` в каталогах `/usr/lib/pkgconfig`.

## Подводные камни

Если на сборочном сервере не установлен dev-пакет библиотеки (например, отсутствует `zlib1g-dev`), `pkg-config` вернет ошибку `Package zlib was not found in the pkg-config search path`, и `go build` остановится.

## На собеседовании

**Вопрос с собеседования:** Как настроить поиск pkg-config библиотек, установленных в нестандартные директории (например, в CI пайплайне)?
**Ответ:** Через переменную окружения `PKG_CONFIG_PATH`: `export PKG_CONFIG_PATH=/custom/lib/pkgconfig:$PKG_CONFIG_PATH`. Компилятор CGO передаст этот путь системной утилите `pkg-config`, позволив найти нужные `.pc` файлы конфигурации.
