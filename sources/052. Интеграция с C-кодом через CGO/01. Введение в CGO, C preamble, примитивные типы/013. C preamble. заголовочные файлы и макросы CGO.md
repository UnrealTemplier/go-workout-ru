# C preamble: заголовочные файлы и макросы CGO

## Условие

Используйте C-комментарий перед `import "C"` для включения C-кода и макросов: определите константу `#define BUFFER_SIZE 1024` и статическую вспомогательную функцию. Вызовите её из Go и прочитайте значение макроса через пространство имен `C.`.

### Исходная формулировка

**C preamble**: Используйте C-комментарий перед `import "C"` для включения C-кода: `// #include <stdio.h>\nimport "C"`.

## Теория

C preamble — это не просто комментарий, а полноценная заголовочная секция языка C.
В ней разрешено:
- Подключать заголовочные файлы: `#include <stdio.h>`
- Объявлять директивы препроцессора Си: `#define MAX_LIMIT 500`
- Объявлять перечисления `enum`, объединения `union` и структуры `struct`
- Объявлять статические инлайн-функции `static inline int foo() { ... }`

Любой макрос `#define`, раскрывающийся в целочисленную константу, становится доступен в Go как типизированная константа пакета `C`.

## Решение по шагам

1. В преамбуле задайте `#define BUFFER_SIZE 1024` и `#define PROTOCOL_VERSION "2.4"`.
2. Объявите функцию `static inline int get_buffer_size() { return BUFFER_SIZE; }`.
3. Подключите `import "C"`.
4. В функции `main` прочитайте константу `C.BUFFER_SIZE`.
5. Вызовите функцию `C.get_buffer_size()` и убедитесь в совпадении значений.

## Код решения

**`main.go`**

```go
package main

/*
#define BUFFER_SIZE 1024
#define PROTOCOL_VERSION 3

static inline int get_buffer_size() {
    return BUFFER_SIZE;
}
*/
import "C"
import "fmt"

func main() {
	// Доступ к C #define макросам как к константам
	bufSize := C.BUFFER_SIZE
	protoVer := C.PROTOCOL_VERSION

	// Вызов статической Си-функции
	funcResult := C.get_buffer_size()

	fmt.Printf("Макрос C.BUFFER_SIZE:        %d\n", bufSize)
	fmt.Printf("Макрос C.PROTOCOL_VERSION:   %d\n", protoVer)
	fmt.Printf("Функция get_buffer_size():   %d\n", funcResult)
}
```

ℹ️ CGO автоматически экспортирует числовые макросы #define как константы пакета C.

**`Терминал`**

```bash
go run main.go
# Вывод:
# Макрос C.BUFFER_SIZE:        1024
# Макрос C.PROTOCOL_VERSION:   3
# Функция get_buffer_size():   1024
```

## Под капотом

Препроцессор CGO парсит AST комментариев преамбулы. Для каждого `#define NAME VALUE` генерируется скрытая константа `const _Ciconst_NAME = VALUE`. Если макрос представляет собой сложное выражение или функцию-макрос (`#define SQR(x) ((x)*(x))`), CGO не сможет преобразовать его в константу, и потребуется написать Си-функцию-обертку.

## Подводные камни

Макросы с параметрами (`#define ADD(a,b) ((a)+(b))`) недоступны через `C.ADD`. Их всегда нужно оборачивать в `static inline int add(...)`.

## На собеседовании

**Вопрос с собеседования:** Почему строковые `#define` (например, `#define APP_NAME "PaymentService"`) недоступны в Go как строковые константы `C.APP_NAME`?
**Ответ:** Потому что в Си строковый литерал имеет тип `const char*` (указатель на память секции `.rodata`), а не значение константы. CGO преобразует в Go-константы только целочисленные макросы. Строковые константы нужно экспортировать через функцию `const char* get_app_name() { return APP_NAME; }` или глобальную переменную.
