# Передача и возврат структур Си через CGO

## Условие

Объявите C-структуру `Point { double x; double y; }`, создайте её в Go, передайте в C-функцию `distance_from_origin`, которая вычисляет расстояние от начала координат через `sqrt`, и верните результат `double`.

### Исходная формулировка

**Передача и возврат сложных типов.**: Объявите C-структуру `Point { double x; double y; }`, создайте её в Go, передайте в C-функцию, которая вычисляет расстояние от начала координат, и верните результат.

## Теория

Структуры, объявленные в коде Си, проецируются компилятором CGO в структуры Go с префиксом `struct_`:
C-структура `struct Point { ... }` становится доступна в Go как `C.struct_Point`.
Если структура объявлена через `typedef struct { ... } Point;`, к ней можно обращаться как `C.Point`.

Поля структур C доступны через обычную точечную нотацию в Go, а передача структуры по значению или указателю сохраняет бинарную раскладку полей памяти в соответствии с ABI целевой платформы.

## Решение по шагам

1. В преамбуле подключите `<math.h>` и объявите `typedef struct { double x; double y; } Point;`.
2. Реализуйте Си-функцию `double distance(Point p) { return sqrt(p.x*p.x + p.y*p.y); }`.
3. В Go коде инициализируйте `pt := C.Point{ x: 3.0, y: 4.0 }`.
4. Вызовите `C.distance(pt)`.
5. Преобразуйте результат `C.double` в `float64`.

## Код решения

**`main.go`**

```go
package main

/*
#include <math.h>

typedef struct {
    double x;
    double y;
} Point;

double distance(Point p) {
    return sqrt(p.x * p.x + p.y * p.y);
}
*/
import "C"
import "fmt"

func main() {
	// Создание структуры Point в пространстве памяти Go
	var pt C.Point
	pt.x = C.double(3.0)
	pt.y = C.double(4.0)

	// Вызов Си-функции с передачей структуры
	dist := C.distance(pt)

	fmt.Printf("Координаты точки: (%.1f, %.1f)\n", float64(pt.x), float64(pt.y))
	fmt.Printf("Расстояние от (0,0): %.2f\n", float64(dist))
}
```

ℹ️ Флаг линковщика -lm автоматически подключается CGO для математических функций.

**`Терминал`**

```bash
go run main.go
# Вывод:
# Координаты точки: (3.0, 4.0)
# Расстояние от (0,0): 5.00
```

## Под капотом

Структура `C.Point` в Go имеет точно такой же размер (16 байт) и выравнивание, как в C. Передача по значению копирует 16 байт аргумента на Си-стек через регистры XMM0/XMM1 (System V AMD64 ABI). Возвращаемое значение `double` возвращается в регистре XMM0.

## Подводные камни

Битовые поля Си (`int flag : 1;`) не поддерживаются в CGO. Структуры с битовыми полями импортируются в Go с невидимыми полями или не распознаются вовсе.

## На собеседовании

**Вопрос с собеседования:** Как CGO обрабатывает объединения (union) языка C?
**Ответ:** CGO не умеет напрямую транслировать union в Go (так как в Go нет union). Вместо этого CGO генерирует массив байт `[N]byte`, размер которого равен максимальному полю объединения, с соответствующим выравниванием. Для доступа к отдельным полям union требуется каст указателя через `unsafe.Pointer`.
