# Примитивные типы и границы диапазонов: Go vs C

## Условие

Передайте `int`, `float64`, `bool` в C-функцию и получите результат обратно. Изучите маппинг типов (Go `int` ≠ C `int`, `bool` в C99 `_Bool`). Проверьте поведение при переполнении диапазонов чисел.

### Исходная формулировка

**Примитивные типы**: Передайте `int`, `float64` в C-функцию и получите результат обратно. Изучите маппинг типов (Go `int` ≠ C `int`).

## Теория

Размеры базовых типов в Go и C имеют критические различия:
- `bool` в Go занимает 1 байт. В C99 тип `_Bool` (из `<stdbool.h>`) также занимает 1 байт и мапится в `C.bool`.
- `int` в Go на 64-битных ОС равен 8 байтам (`int64`), тогда как `C.int` равен 4 байтам (`int32`).
- `float32` в Go строго равен IEEE 754 single-precision float (`C.float`).
- `float64` в Go строго равен IEEE 754 double-precision float (`C.double`).

При передаче аргументов из Go в C требуется строгое явное приведение типов, что предотвращает неявное усечение (truncation) старших байт.

## Решение по шагам

1. В преамбуле подключите `<stdbool.h>`.
2. Реализуйте Си-функцию:
   `double compute(int a, double b, bool flag) { return flag ? (a * b) : (a + b); }`.
3. В Go объявите переменные `x int = 5`, `y float64 = 2.5`, `enable bool = true`.
4. Вызовите `C.compute(C.int(x), C.double(y), C.bool(enable))`.
5. Сравните результат при `enable = true` и `enable = false`.

## Код решения

**`main.go`**

```go
package main

/*
#include <stdbool.h>

double compute(int a, double b, bool flag) {
    if (flag) {
        return a * b;
    }
    return a + b;
}
*/
import "C"
import "fmt"

func main() {
	var a int = 10
	var b float64 = 3.5

	// Вызов Си-функции с явным приведением всех типов
	resMul := C.compute(C.int(a), C.double(b), C.bool(true))
	resAdd := C.compute(C.int(a), C.double(b), C.bool(false))

	fmt.Printf("C.compute(умножение): %.2f\n", float64(resMul))
	fmt.Printf("C.compute(сложение):  %.2f\n", float64(resAdd))
}
```

ℹ️ Подключение &lt;stdbool.h> в преамбуле позволяет CGO распознавать тип C.bool.

**`Терминал`**

```bash
go run main.go
# Вывод:
# C.compute(умножение): 35.00
# C.compute(сложение):  13.50
```

## Под капотом

Регистровый ABI System V AMD64 распределяет аргументы: целочисленные аргументы (`C.int`, `C.bool`) передаются через регистры `RDI`, `RSI`, `RDX`, `RCX`, `R8`, `R9`, а аргументы с плавающей запятой (`C.double`) — через регистры `XMM0`–`XMM7`. CGO генерирует код загрузки регистров перед инструкцией `CALL`.

## Подводные камни

Если передать в `C.int` значение Go `int`, превышающее \(2^{31}-1\) (например, \(3\,000\,000\,000\)), произойдет целочисленное переполнение со сменой знака.

## На собеседовании

**Вопрос с собеседования:** Как в CGO передать беззнаковый 64-битный целый тип `uint64`?
**Ответ:** Использовать тип `C.ulonglong` или подключить `<stdint.h>` и использовать `C.uint64_t`. Тип `C.ulong` на 64-битной Windows (LLP64) 32-битный, поэтому `C.uint64_t` является наиболее переносимым типом.
