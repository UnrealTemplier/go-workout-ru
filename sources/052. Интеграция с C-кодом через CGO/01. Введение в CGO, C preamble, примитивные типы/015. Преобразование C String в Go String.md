# Преобразование C String в Go String через C.GoString

## Условие

Напиши в C-комментарии функцию, возвращающую строку `char*` (например, `"Hello from C"`). В Go вызови её и конвертируй результат в нормальную Go-строку с помощью `C.GoString()` и `C.GoStringN()`. Объясни разницу между ними.

### Исходная формулировка

**C String -> Go String**: Напиши в C-комментарии функцию, возвращающую строку `char*` (например, `"Hello from C"`). В Go вызови её и конвертируй результат в нормальную Go-строку с помощью `C.GoString()`. (Эта операция физически копирует байты из C-памяти в Go-память).

## Теория

Для преобразования C-строки в строку Go стандартный рантайм CGO предоставляет две функции:
1. `C.GoString(cStr *C.char) string` — читает байты до первого нулевого символа `\0` (null-terminated).
2. `C.GoStringN(cStr *C.char, len C.int) string` — читает ровно `len` байт независимо от наличия нулевых символов внутри.

**Важнейший нюанс памяти:** обе функции аллоцируют новую строку в **управляемой куче Go** и побайтно копируют данные из C-памяти в Go-память. После вызова `C.GoString` связь с исходным Си-буфером разрывается, и Си-буфер можно безопасно освобождать.

## Решение по шагам

1. В преамбуле объявите Си-функцию, возвращающую константную строку: `const char* get_greeting() { return "Hello from Native C!"; }`.
2. Объявите Си-функцию, возвращающую буфер с нулями: `const char* get_binary_data()`.
3. В Go вызовите `cStr := C.get_greeting()`.
4. Преобразуйте через `goStr := C.GoString(cStr)`.
5. Продемонстрируйте `C.GoStringN` для бинарных данных.

## Код решения

**`main.go`**

```go
package main

/*
const char* get_greeting() {
    return "Hello from Native C Runtime!";
}

const char* get_binary_data() {
    // Строка, содержащая нулевой байт в середине
    return "Part1\0Part2";
}
*/
import "C"
import "fmt"

func main() {
	// 1. Обычная нуль-терминированная строка
	cMsg := C.get_greeting()
	goMsg := C.GoString(cMsg)
	fmt.Printf("C.GoString результат: %s (длина: %d)\n", goMsg, len(goMsg))

	// 2. Чтение фиксированной длины через C.GoStringN
	cBin := C.get_binary_data()
	fullData := C.GoStringN(cBin, 11) // Читаем все 11 байт включая \0
	truncated := C.GoString(cBin)    // Остановится на первом \0

	fmt.Printf("C.GoStringN(11) длина: %d, байты: %v\n", len(fullData), []byte(fullData))
	fmt.Printf("C.GoString обычный длина: %d, строка: %s\n", len(truncated), truncated)
}
```

ℹ️ C.GoString всегда выполняет полное копирование байт в кучу Go.

**`Терминал`**

```bash
go run main.go
# Вывод:
# C.GoString результат: Hello from Native C Runtime! (длина: 28)
# C.GoStringN(11) длина: 11, байты: [80 97 114 116 49 0 80 97 114 116 50]
# C.GoString обычный длина: 5, строка: Part1
```

## Под капотом

`C.GoString` вызывает `runtime.gostring` (или `strlen` + `runtime.gostringn`). Рантайм Go выделяет память через `mallocgc`, копирует байты из адреса C в спан памяти Go и возвращает стандартную структуру `string { Data, Len }`. Эта операция абсолютно безопасна для сборщика мусора Go.

## Подводные камни

Передача `nil` указателя (`*C.char(nil)`) в `C.GoString` приведет к немедленной панике рантайма `panic: runtime error: cgo argument has Go pointer to unpinned Go pointer` или segfault при чтении адреса 0x0. Всегда проверяйте `cStr != nil` перед конвертацией!

## На собеседовании

**Вопрос с собеседования:** Что произойдет с Go-строкой, созданной через `C.GoString(cPtr)`, если сразу после этого вызвать `C.free(unsafe.Pointer(cPtr))`?
**Ответ:** Go-строка останется абсолютно валидной. Функция `C.GoString` выполняет глубокое копирование (deep copy) содержимого Си-памяти в новую область памяти, управляемую Go GC. Освобождение Си-памяти никак не влияет на созданную Go-строку.
