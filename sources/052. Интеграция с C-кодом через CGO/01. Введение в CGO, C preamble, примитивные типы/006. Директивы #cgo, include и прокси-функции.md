# Директивы #cgo, include и прокси-функции компилятора CGO

## Условие

Напишите минимальную программу с `cgo`: вызовите `C.printf` из Go. Объясните магию комментария `// #cgo` и `// #include`. Исследуйте сгенерированные файлы `_cgo_gotypes.go`.

### Исходная формулировка

Напишите минимальную программу с `cgo`: вызовите `C.printf` из Go. Объясните магию комментария `// #cgo` и `// #include`. Покажите сгенерированный `_cgo_.go` через `go tool cgo` и найдите функцию-прокси.

## Теория

Специальные строки с префиксом `#cgo` в C preamble служат инструкциями сборщику:
- `#cgo CFLAGS: -O3 -Wall` — флаги компилятора C при сборке C-кода.
- `#cgo LDFLAGS: -lm -lz` — флаги компоновщика для связывания библиотек.
- `#cgo pkg-config: sqlite3` — автоматическое получение флагов через утилиту `pkg-config`.

Прямой вызов вариативных C-функций (с переменным числом аргументов `printf(const char* fmt, ...)`) **напрямую из Go запрещен спецификацией CGO**, поэтому создается вспомогательная C-функция-обертка.

## Решение по шагам

1. Напишите преамбулу с директивой `#cgo CFLAGS: -O2`.
2. Подключите `<stdio.h>`.
3. Создайте невариативную обертку: `void my_printf(const char* name, int age) { printf("User %s is %d years old\n", name, age); }`.
4. Вызовите `C.my_printf` из Go.
5. Запустите и проверьте форматированный вывод.

## Код решения

**`main.go`**

```go
package main

/*
#cgo CFLAGS: -O2
#include <stdio.h>
#include <stdlib.h>

void my_printf(const char* name, int age) {
    printf("User %s is %d years old\n", name, age);
}
*/
import "C"
import "unsafe"

func main() {
	cName := C.CString("Gopher")
	defer C.free(unsafe.Pointer(cName))

	// Вызов обертки над вариативной C-функцией printf
	C.my_printf(cName, C.int(15))
}
```

ℹ️ CGO запрещает прямые вызовы C-функций с многоточием (...) из-за различий в ABI передачи аргументов.

**`Терминал`**

```bash
go run main.go
# Вывод:
# User Gopher is 15 years old
```

## Под капотом

Вариативные функции Си используют переменный фрейм стека и регистр `AL` (на x86-64) для подсчета векторных регистров. Поскольку ABI Go не формирует такие структуры, CGO запрещает вызов `C.printf(...)`. Создание статической C-обертки `my_printf` превращает вызов в стандартный вызов Си с фиксированными параметрами.

## Подводные камни

Директивы `#cgo` поддерживают флаги с ограничениями безопасности (security whitelist). Произвольные флаги могут быть отклонены `go build` в целях безопасности компиляции.

## На собеседовании

**Вопрос с собеседования:** Почему CGO не поддерживает прямой вызов вариативных функций (varargs) вроде `printf`?
**Ответ:** Потому что соглашение о вызовах (Calling Convention) System V AMD64 ABI требует передачи информации о количестве использованных регистров с плавающей запятой в регистре `%al`. Компилятор Go не генерирует код с подобной спецификой, поэтому прямой вызов Си-функций с `...` запрещен на уровне семантического анализатора `cgo`.
