# Первый вызов функции C через CGO preamble

## Условие

Напишите простую C-функцию в комментарии перед `import "C"` (например, `int add(int a, int b)`), вызовите её из Go. Скомпилируйте и запустите. Проверьте результат сложения чисел.

### Исходная формулировка

**Первый вызов C-функции.**: Напишите простую C-функцию в комментарии `import "C"` (например, `int add(int a, int b)`), вызовите её из Go. Скомпилируйте и запустите.

## Теория

Механизм **CGO** позволяет программам на Go вызывать нативный Си-код и использовать существующие библиотеки Си/Си++.
Для интеграции с Си используется специальный псевдо-пакет `import "C"`.

Текст многострочного или однострочного комментария, расположенный **непосредственно перед** строкой `import "C"`, называется **C preamble** (преамбула Си). Компилятор `cgo` передает этот комментарий компилятору C (gcc или clang) как исходный код на Си:
```go
// int add(int a, int b) { return a + b; }
import "C"
```
После этого функции и типы языка C становятся доступны в пространстве имен пакета `C`: `C.add(C.int(a), C.int(b))`.

## Решение по шагам

1. Создайте файл `main.go`.
2. Напишите комментарий с реализацией Си-функции `int add(int a, int b) { return a + b; }`.
3. Сразу на следующей строке без пустых строк добавьте `import "C"`.
4. В функции `main` вызовите `C.add(10, 25)` с приведением аргументов к `C.int`.
5. Преобразуйте результат обратно в Go `int` и выведите в консоль.

## Код решения

**`main.go`**

```go
package main

/*
int add(int a, int b) {
    return a + b;
}
*/
import "C"
import "fmt"

func main() {
	var a, b int = 15, 27

	// Вызов Си-функции через псевдо-пакет C
	cResult := C.add(C.int(a), C.int(b))

	// Приведение результата C.int к стандартному типу Go int
	goResult := int(cResult)

	fmt.Printf("Результат C.add(%d, %d) = %d\n", a, b, goResult)
}
```

ℹ️ Между закрывающим комментарием */ преамбулы и import "C" не должно быть пустых строк.

**`Терминал`**

```bash
go run main.go
# Вывод:
# Результат C.add(15, 27) = 42
```

## Под капотом

При сборке утилита `go build` запускает препроцессор `go tool cgo`. Он выделяет C preamble в отдельный `.c` файл, компилирует его через системный компилятор `gcc` в объектный файл ELF `.o`, а для Go генерирует файл обёртки `_cgo_gotypes.go` с ассемблерным мостом и переключением стека горутины на системный стек потока ОС (m-stack / g0).

## Подводные камни

Если между преамбулой Си и `import "C"` вставить пустую строку или другой импорт, компилятор посчитает преамбулу обычным комментарием, и вызов `C.add` упадет с ошибкой компиляции `could not determine kind of name for C.add`.

## На собеседовании

**Вопрос с собеседования:** Что физически происходит во время вызова функции Си из горутины Go через CGO?
**Ответ:** Рантайм Go переключает горутину: сохраняет регистры стека Go, переключается на стек ОС (g0/systemstack) связанного потока ядра (M), переводит горутину в состояние `_Gsyscall`, вызывает функцию Си, а по завершении выполняет обратный переход стеков и планирование горутины в очередь P. Этот переход занимает порядка 40–100 наносекунд.
