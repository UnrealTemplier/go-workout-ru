# Сложные структуры Си: вложенные массивы и указатели в Go

## Условие

Создайте C-структуру с фиксированными байтовыми массивами и вложенными указателями. Передайте её в Go через CGO. Объясните, как Go проецирует типы вложенных C-массивов (`char name[32]` -> `[32]C.char`) и как удобно конвертировать их в Go-типы.

### Исходная формулировка

Создайте C-структуру с вложенными массивами и указателями. Передайте её в Go через `cgo`. Объясните, как Go видит C-структуры (padding, alignment) и почему `unsafe` для доступа к полям не нужен, но `reflect` может понадобиться для сложных layout.

## Теория

При импорте структур из C:
- Фиксированные массивы `char name[32]` проецируются в Go как массивы фиксированного размера `[32]C.char`.
- Это именно массивы по значению, а не срезы (`[]byte`)!
- Для чтения текста из `[32]C.char` адрес нулевого элемента преобразуется в указатель: `C.GoString(&structVal.name[0])`.
- Указатели на дочерние структуры `struct Child* next` проецируются как `*C.struct_Child`.

## Решение по шагам

1. В преамбуле объявите `struct Node { int id; char tag[16]; struct Node* next; }`.
2. Реализуйте Си-функцию создания связного списка из двух узлов.
3. В Go прочитайте поля первого узла.
4. Преобразуйте поле `tag` в Go-строку.
5. Перейдите по указателю `next` ко второму узлу.

## Код решения

**`main.go`**

```go
package main

/*
#include <string.h>

struct Node {
    int id;
    char tag[16];
    struct Node* next;
};

struct Node second = { .id = 2, .tag = "BetaNode", .next = NULL };
struct Node first  = { .id = 1, .tag = "AlphaNode", .next = &second };

struct Node* get_root_node() {
    return &first;
}
*/
import "C"
import "fmt"

func main() {
	root := C.get_root_node()

	// 1. Читаем первый узел
	id1 := int(root.id)
	// Преобразование фиксированного массива [16]C.char в string
	tag1 := C.GoString(&root.tag[0])
	fmt.Printf("Node #%d: tag = %s\n", id1, tag1)

	// 2. Переходим по C-указателю к следующему узлу
	if root.next != nil {
		id2 := int(root.next.id)
		tag2 := C.GoString(&root.next.tag[0])
		fmt.Printf("Node #%d: tag = %s (next = %p)\n", id2, tag2, root.next.next)
	}
}
```

ℹ️ Взятие &root.tag[0] дает указатель *C.char для передачи в C.GoString.

**`Терминал`**

```bash
go run main.go
# Вывод:
# Node #1: tag = AlphaNode
# Node #2: tag = BetaNode (next = 0x0)
```

## Под капотом

В памяти структура `struct Node` занимает 32 байта: `id` (4 байта) + 4 байта padding + `tag` (16 байт) + `next` (8 байт). Массив `tag` вкомпилирован прямо в тело структуры без косвенных ссылок. В Go обращение `&root.tag[0]` возвращает указатель со смещением `+8` байт от базы структуры.

## Подводные камни

Если поле `tag` заполнено всеми 16 байтами без нулевого терминатора `\0`, `C.GoString(&root.tag[0])` пойдет читать дальше по памяти в поле `next`, порождая искажение строки. Для таких массивов безопаснее `C.GoStringN(&root.tag[0], 16)`.

## На собеседовании

**Вопрос с собеседования:** Как преобразовать массив `[N]C.char` из C-структуры в срез байт `[]byte` без аллокаций памяти?
**Ответ:** С помощью функции `unsafe.Slice`: `unsafe.Slice((*byte)(unsafe.Pointer(&structVal.tag[0])), N)`. Это создаст 24-байтный заголовок среза Go, ссылающийся прямо на физические байты внутри Си-структуры без копирования памяти.
