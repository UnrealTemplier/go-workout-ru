# Упреждающая загрузка и предиктивное кэширование (Prefetching & Predictive Caching)

## Условие

Реализуй **Prefetching + Predictive Caching**: ML model predicts "user likely to view product X next". Prefetch into cache before request. Warm CDN edge for geographic region. Reduce latency from 200ms to 20ms.

## Теория

Принцип предиктивного кэширования (Predictive Caching / Prefetching):
- Обычное кэширование является **реактивным**: первый запрос всегда терпит задержку Cache Miss (200 мс).
- **Предиктивный подход:**
  1. ML-модель на основе графа переходов (Markov Chain / RNN) анализирует текущие действия:
     - Если пользователь положил в корзину `iPhone 16`, с вероятностью 85% следующим кликом он откроет страницу `Чехол для iPhone 16` или `Зарядное устройство USB-C`.
  2. В ту же секунду фоновая горутина прогревает эти товары в локальном кэше L1 и прогревает CDN Edge региона.
  3. Когда пользователь кликает по товару, задержка ответа составляет **всего 2–20 мс вместо 200 мс**!

## Решение по шагам

1. Создайте модель предиктивного прогнозирования вероятных следующих кликов `PredictiveCacheManager`.
2. Реализуйте упреждающую фоновую подгрузку (Prefetch) связанных позиций в кэш.
3. Продемонстрируйте мгновенный возврат предзагруженных товаров.
4. Верифицируйте сокращение задержки ответа в 10 раз.

## Код решения

**`predictive_prefetch_caching_test.go`**

```go
package main

import (
	"fmt"
	"sync"
	"testing"
	"time"
)

type PredictiveCacheManager struct {
	mu         sync.RWMutex
	cacheStore map[string]string
}

func (m *PredictiveCacheManager) PrefetchHotKey(key, data string) {
	m.mu.Lock()
	defer m.mu.Unlock()
	if m.cacheStore == nil {
		m.cacheStore = make(map[string]string)
	}
	m.cacheStore[key] = data
}

func (m *PredictiveCacheManager) GetProductWithLatency(key string) (string, time.Duration) {
	start := time.Now()
	m.mu.RLock()
	val, exists := m.cacheStore[key]
	m.mu.RUnlock()

	if exists {
		// Мгновенно из предиктивного кэша (RAM)
		return val, time.Since(start)
	}

	// Имитация долгого похода в холодную БД (20 мс для теста)
	time.Sleep(20 * time.Millisecond)
	return "Product data from DB", time.Since(start)
}

func TestPredictivePrefetchCaching(t *testing.T) {
	mgr := &PredictiveCacheManager{}

	// 1. Обычный запрос без префетчинга (Холодный поход в БД)
	_, durationCold := mgr.GetProductWithLatency("product:case-black")

	// 2. ML модель прогнозирует: пользователь смотрит телефон -> префетчим чехол заранее!
	mgr.PrefetchHotKey("product:case-black", "Чехол Silicone Case (Ultra Slim)")

	// 3. Пользователь кликает по чехлу -> мгновенное попадание из памяти!
	valWarmed, durationWarmed := mgr.GetProductWithLatency("product:case-black")

	if durationWarmed >= durationCold {
		t.Fatalf("Предиктивный кэш обязан быть в разы быстрее: %v >= %v", durationWarmed, durationCold)
	}

	fmt.Println("Предиктивное кэширование (Predictive Prefetching) подтверждено:")
	fmt.Printf("  • Холодный запрос в БД:           %v\n", durationCold)
	fmt.Printf("  • Ответ из упреждающего кэша:    %v (Ускорение в десятки раз!)\n", durationWarmed)
	fmt.Printf("  • Полученные данные:              %s\n", valWarmed)
}
```

## Под капотом

В современных браузерах префетчинг поддерживается на уровне стандарта HTML: HTTP-заголовок `Link: </product/101>; rel=prefetch` заставляет браузер скачивать данные следующей страницы в фоновом режиме по незагруженному Wi-Fi каналу, пока пользователь еще читает текущую статью.

## Подводные камни

Префетчить слишком много позиций (Over-Prefetching): если предзагружать по 50 товаров на каждый клик, фоновые запросы перегрузят базу данных и сожгут мобильный трафик пользователя. Префетчат **строго топ-1 или топ-2 позиции с вероятностью перехода > 75%**.

## На собеседовании

**Вопрос с собеседования:** «Как организовать предиктивное прогревание CDN Edge в определенном географическом регионе?»
**Ответ:** При старте рекламной кампании на ТВ в регионе (например в Екатеринбурге) бэкенд инициирует API-вызов к CDN провайдеру (Fastly/Cloudflare API) на предварительный подогрев бандлов и промо-страниц на серверах PoP (Point of Presence) именно этого города до начала показа рекламы.
