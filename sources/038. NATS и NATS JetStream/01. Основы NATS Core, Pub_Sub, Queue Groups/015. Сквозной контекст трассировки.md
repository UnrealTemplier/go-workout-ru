# Сквозной контекст трассировки: передача TraceID и CorrelationID в заголовках NATS

## Условие

Добавьте **metadata в сообщения**: используйте NATS Headers (аналог HTTP-заголовков) для передачи trace ID, correlation ID.

## Теория

Распределенный трейсинг через NATS Headers:
- В распределенной архитектуре вызов проходит через десятки микросервисов:
  `Web API -> NATS -> Order Service -> NATS -> Billing -> NATS -> Email Service`.
- Чтобы собрать все логи и спаны в единый трейс (Jaeger / OpenTelemetry / Loki):
  - Продюсер упаковывает `X-Trace-ID` и `X-Span-ID` в заголовки `msg.Header`.
  - Консьюмер извлекает их, привязывает к своему логгеру `slog.With("trace_id", tid)` и передает дальше.
- Обеспечивает 100% прозрачность отладки в продакшене.

## Решение по шагам

1. Создайте структуру контекста трассировки.
2. Реализуйте инжектор метаданных в заголовки NATS.
3. Реализуйте экстрактор метаданных на стороне подписчика.
4. Проверьте сохранность сквозного Trace ID.

## Код решения

**`trace_metadata_headers_test.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"testing"
)

type TraceMetadata struct {
	TraceID string
	SpanID  string
}

func InjectTraceHeaders(h http.Header, meta TraceMetadata) {
	h.Set("X-Trace-ID", meta.TraceID)
	h.Set("X-Span-ID", meta.SpanID)
}

func ExtractTraceHeaders(h http.Header) TraceMetadata {
	return TraceMetadata{
		TraceID: h.Get("X-Trace-ID"),
		SpanID:  h.Get("X-Span-ID"),
	}
}

func TestTraceMetadataHeaders(t *testing.T) {
	headers := make(http.Header)
	origin := TraceMetadata{
		TraceID: "4bf92f3577b34da6a3ce929d0e0e4736",
		SpanID:  "00f067aa0ba902b7",
	}

	InjectTraceHeaders(headers, origin)
	extracted := ExtractTraceHeaders(headers)

	if extracted.TraceID != origin.TraceID || extracted.SpanID != origin.SpanID {
		t.Fatalf("Ошибка сквозной трассировки: %+v", extracted)
	}

	fmt.Println("Сквозной контекст трассировки успешно передан через NATS Headers:")
	fmt.Printf("  • X-Trace-ID: %s\n", extracted.TraceID)
	fmt.Printf("  • X-Span-ID:  %s\n", extracted.SpanID)
	fmt.Println("  • Логи и метрики всех микросервисов коррелируют в единый трейс!")
}
```

## Под капотом

Пакет `go.opentelemetry.io/otel` предоставляет адаптер `TextMapCarrier`, где методы `Get` и `Set` напрямую оборачивают `http.Header` сообщения NATS.

## Подводные камни

Использовать нестандартные имена заголовков без префикса: рекомендуется следовать спецификации W3C TraceContext (`traceparent`, `tracestate`).

## На собеседовании

**Вопрос с собеседования:** «Почему TraceID упаковывают в Headers, а не в тело JSON-сообщения?»
**Ответ:** Это разделяет прикладные данные и инфраструктурные метаданные. Если TraceID поместить в тело бизнес-структуры, придется менять схемы валидации DTO, а брокеры и промежуточные прокси не смогут читать метаданные без полной десериализации тела сообщения.
