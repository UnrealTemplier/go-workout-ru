# Прозрачный TCP-прокси с двусторонней передачей через io.Copy

## Условие

Создайте TCP-прокси: сервер, который принимает соединение от клиента и прозрачно проксирует все байты на другой удаленный сервер, возвращая ответ обратно (используйте `io.Copy` в двух горутинах для каждого соединения).

## Теория

Прозрачное проксирование трафика: связывание двух полнодуплексных сокетов через две горутины копирования `io.Copy(upstream, downstream)` и `io.Copy(downstream, upstream)`.

## Решение по шагам

1. Запустим Mock Upstream сервер.
2. Запустим Transparent Proxy.
3. Клиент отправляет запрос через прокси.
4. Проверим получение корректного ответа от Upstream.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net"
	"sync"
	"time"
)

func handleProxy(client net.Conn, upstreamAddr string) {
	upstream, err := net.Dial("tcp", upstreamAddr)
	if err != nil {
		client.Close()
		return
	}

	var once sync.Once
	cleanup := func() {
		once.Do(func() {
			client.Close()
			upstream.Close()
		})
	}

	go func() {
		_, _ = io.Copy(upstream, client)
		cleanup()
	}()

	go func() {
		_, _ = io.Copy(client, upstream)
		cleanup()
	}()
}

func main() {
	// 1. Upstream сервис
	upstream, _ := net.Listen("tcp", "127.0.0.1:0")
	defer upstream.Close()

	go func() {
		for {
			c, err := upstream.Accept()
			if err != nil {
				return
			}
			go func(conn net.Conn) {
				defer conn.Close()
				buf := make([]byte, 128)
				n, _ := conn.Read(buf)
				_, _ = conn.Write([]byte("Upstream response to: " + string(buf[:n])))
			}(c)
		}
	}()

	// 2. Прокси сервис
	proxy, _ := net.Listen("tcp", "127.0.0.1:0")
	defer proxy.Close()

	go func() {
		for {
			c, err := proxy.Accept()
			if err != nil {
				return
			}
			go handleProxy(c, upstream.Addr().String())
		}
	}()

	time.Sleep(10 * time.Millisecond)

	// 3. Клиент
	client, _ := net.Dial("tcp", proxy.Addr().String())
	defer client.Close()

	_, _ = client.Write([]byte("Query-A"))
	resp := make([]byte, 128)
	n, _ := client.Read(resp)

	fmt.Printf("[Transparent Proxy Result] %s\n", string(resp[:n]))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Transparent Proxy Result] Upstream response to: Query-A
```

## Под капотом

`io.Copy` блокируется до закрытия одной из сторон или возникновения ошибки сокета.

## Подводные камни

Если не вызвать `cleanup()` в обеих горутинах, разрыв соединения клиентом оставит висеть открытое соединение к апстриму.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие TCP Proxy (L4) от HTTP Proxy (L7 / Envoy / Nginx)?»
**Ответ:** L4 прокси оперирует сырыми байтами TCP-потока без парсинга прикладных протоколов, обеспечивая максимальный throughput и минимальную задержку. L7 прокси парсит HTTP/gRPC заголовки, что дает возможности умной маршрутизации, ретраев и авторизации, но требует больше CPU/RAM.
