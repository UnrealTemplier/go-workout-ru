# Базовый UDP-сервер на net.ListenUDP, ReadFromUDP и WriteToUDP

## Условие

**UDP-сервер**: UDP работает без установки соединения. Используй `net.ListenUDP`. Читай данные через `ReadFromUDP` (получишь байты и адрес отправителя) и отправляй ответ через `WriteToUDP`.

## Теория

Архитектура UDP (User Datagram Protocol): сервер слушает UDP-сокет без вызова `Accept()`. Функция `conn.ReadFromUDP(buf)` возвращает количество байт и сетевой адрес отправителя `*net.UDPAddr`. Ответ отправляется методом `conn.WriteToUDP(resp, remoteAddr)`.

## Решение по шагам

1. Создадим UDP адрес `net.ResolveUDPAddr("udp", "127.0.0.1:0")`.
2. Откроем сокет `net.ListenUDP("udp", addr)`.
3. Считаем дейтаграмму и адрес клиента через `ReadFromUDP`.
4. Отправим ответ через `WriteToUDP`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
	"strings"
	"time"
)

func runUDPEchoServer(conn *net.UDPConn) {
	defer conn.Close()
	buf := make([]byte, 1024)

	for {
		// Читаем дейтаграмму и запоминаем адрес клиента
		n, clientAddr, err := conn.ReadFromUDP(buf)
		if err != nil {
			return
		}

		incoming := string(buf[:n])
		fmt.Printf("[UDP Server] Получено от %s: %s\n", clientAddr, incoming)

		// Отправляем ответ конкретному клиенту
		reply := strings.ToUpper(incoming) + " (UDP-ACK)"
		_, _ = conn.WriteToUDP([]byte(reply), clientAddr)
	}
}

func main() {
	addr, _ := net.ResolveUDPAddr("udp", "127.0.0.1:0")
	serverConn, err := net.ListenUDP("udp", addr)
	if err != nil {
		panic(err)
	}

	serverAddr := serverConn.LocalAddr().(*net.UDPAddr)
	fmt.Printf("[UDP Server] Запущен на %s\n", serverAddr)

	go runUDPEchoServer(serverConn)
	time.Sleep(10 * time.Millisecond)

	// Клиент
	clientConn, _ := net.DialUDP("udp", nil, serverAddr)
	defer clientConn.Close()

	msg := "hello udp networking"
	_, _ = clientConn.Write([]byte(msg))

	resp := make([]byte, 1024)
	n, _, _ := clientConn.ReadFromUDP(resp)
	fmt.Printf("[UDP Client] Ответ сервера: %s\n", string(resp[:n]))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [UDP Server] Запущен на 127.0.0.1:56231
# [UDP Server] Получено от 127.0.0.1:41298: hello udp networking
# [UDP Client] Ответ сервера: HELLO UDP NETWORKING (UDP-ACK)
```

## Под капотом

`ReadFromUDP` транслируется в системный вызов `recvfrom()`, возвращающий структуру `sockaddr_in` отправителя.

## Подводные камни

Максимальный практический размер полезной нагрузки UDP пакета без фрагментации ограничен MTU сети (\(\approx 1472\) байта для Ethernet).

## На собеседовании

**Вопрос с собеседования:** «Что произойдет, если размер UDP дейтаграммы превысит MTU (1500 байт)?»
**Ответ:** IP-уровень выполнит фрагментацию пакета (IP Fragmentation). Если хотя бы один фрагмент потеряется в сети, вся исходная дейтаграмма будет отброшена операционной системой получателя, что снизит надежность передачи.
