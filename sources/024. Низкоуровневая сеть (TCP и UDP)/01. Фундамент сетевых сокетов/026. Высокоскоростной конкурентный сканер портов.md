# Высокоскоростной конкурентный сканер портов (TCP Port Scanner)

## Условие

**Конкурентный сканер портов (Port Scanner)**: Напишите утилиту, которая сканирует порты на локальном хосте (диапазон от 1 до 1024). Программа должна пытаться установить TCP-соединение с каждым портом. Чтобы сканирование не длилось вечно, используйте пул воркеров для ограничения количества параллельных проверок и таймаут соединения (например, 100 миллисекунд с помощью `net.DialTimeout`).

## Теория

Архитектура сетевого сканера безопасности (Port Scanner): пул из \(W\) горутин-воркеров забирает номера портов из очереди `ports chan int` и выполняет попытку подключения `net.DialTimeout("tcp", addr, timeout)`. Если порт открыт, сервер отвечает SYN-ACK и соединение успешно устанавливается.

## Решение по шагам

1. Откроем тестовый TCP слушатель на порту.
2. Создадим канал задач `ports` и пул из 50 воркеров.
3. Просканируем диапазон тестовых портов.
4. Выведем список обнаруженных открытых портов.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
	"strconv"
	"sync"
	"time"
)

func scanPort(port int, results chan<- int, wg *sync.WaitGroup) {
	defer wg.Done()
	target := net.JoinHostPort("127.0.0.1", strconv.Itoa(port))

	conn, err := net.DialTimeout("tcp", target, 25*time.Millisecond)
	if err == nil {
		conn.Close()
		results <- port
	}
}

func main() {
	// Поднимем тестовый сервис
	testListener, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer testListener.Close()

	_, portStr, _ := net.SplitHostPort(testListener.Addr().String())
	openTestPort, _ := strconv.Atoi(portStr)

	fmt.Printf("[Scanner] Тестовый открытый порт: %d\n", openTestPort)

	// Сканируем диапазон портов вокруг открытого
	startPort := openTestPort - 5
	endPort := openTestPort + 5

	results := make(chan int, 10)
	var wg sync.WaitGroup

	for p := startPort; p <= endPort; p++ {
		wg.Add(1)
		go scanPort(p, results, &wg)
	}

	go func() {
		wg.Wait()
		close(results)
	}()

	fmt.Println("[Scanner] Результаты сканирования:")
	for p := range results {
		fmt.Printf(" -> [OPEN PORT FOUND] 127.0.0.1:%d [TCP OPEN]\n", p)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Scanner] Тестовый открытый порт: 51923
# [Scanner] Результаты сканирования:
#  -> [OPEN PORT FOUND] 127.0.0.1:51923 [TCP OPEN]
```

## Под капотом

`net.DialTimeout` выполняет неблокирующий `connect()` и ожидает готовности дескриптора в Netpoller до истечения таймера.

## Подводные камни

Сканирование 65535 портов без ограничения параллелизма горутин исчерпает лимит открытых сокетов ОС (`too many open files`).

## На собеседовании

**Вопрос с собеседования:** «В чем отличие SYN-сканирования (Stealth Scan в nmap) от стандартного TCP Connect сканирования?»
**Ответ:** TCP Connect сканирование завершает полный 3-Way Handshake (`SYN -> SYN-ACK -> ACK`), логируясь в журналах сервера. SYN-сканирование после получения `SYN-ACK` отправляет `RST`, не завершая соединение, что делает сканирование быстрее и незаметнее.
