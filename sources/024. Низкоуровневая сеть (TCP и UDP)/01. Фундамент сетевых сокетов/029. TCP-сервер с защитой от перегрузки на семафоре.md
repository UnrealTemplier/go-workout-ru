# TCP-сервер с защитой от перегрузки на семафоре (Server Busy Reject)

## Условие

Напиши **TCP-сервер с ограничением соединений** (semaphore): `sem := make(chan struct{}, 50)`. Каждое новое соединение захватывает слот. Если слотов нет — немедленно закрой `conn` с ошибкой `"server busy"`.

## Теория

Паттерн Fast Reject (Защита от перегрузки / Backpressure): если лимит активных соединений исчерпан, сервер не ставит новые запросы в бесконечную очередь, а немедленно отправляет ответ `503 Service Unavailable / Server Busy` и сбрасывает соединение.

## Решение по шагам

1. Создадим семафор на 2 активных слота: `sem := make(chan struct{}, 2)`.
2. При подключении пробуем захватить слот через неблокирующий `select default`.
3. Если слот занят — пишем `ERR: SERVER_BUSY\n` и закрываем сокет.
4. Проверим сброс 3-го клиента.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"net"
	"sync"
	"time"
)

type LimitedServer struct {
	sem chan struct{}
}

func (s *LimitedServer) Handle(conn net.Conn) {
	// Неблокирующая проверка доступности слотов
	select {
	case s.sem <- struct{}{}:
		// Слот успешно захвачен
		defer func() {
			<-s.sem
			conn.Close()
		}()
		fmt.Printf(" [+] Соединение %s принято в обработку.\n", conn.RemoteAddr())
		time.Sleep(50 * time.Millisecond) // Имитация работы
		_, _ = conn.Write([]byte("OK: PROCESSED\n"))

	default:
		// Пул переполнен -> Fast Reject
		defer conn.Close()
		fmt.Printf(" [!] ПЕРЕГРУЗКА: Отказ соединению %s (Server Busy)!\n", conn.RemoteAddr())
		_, _ = conn.Write([]byte("ERR: SERVER_BUSY_TRY_LATER\n"))
	}
}

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	server := &LimitedServer{sem: make(chan struct{}, 2)} // Всего 2 слота!

	go func() {
		for {
			conn, err := l.Accept()
			if err != nil {
				return
			}
			go server.Handle(conn)
		}
	}()

	time.Sleep(10 * time.Millisecond)

	var wg sync.WaitGroup
	wg.Add(3)

	for i := 1; i <= 3; i++ {
		go func(id int) {
			defer wg.Done()
			conn, err := net.Dial("tcp", l.Addr().String())
			if err != nil {
				return
			}
			defer conn.Close()

			resp, _ := bufio.NewReader(conn).ReadString('\n')
			fmt.Printf(" [Client #%d Ответ] %s", id, resp)
		}(i)
	}

	wg.Wait()
	fmt.Println("[Main] Тестирование механизма Fast Reject завершено.")
}
```

## Под капотом

`select default` проверяет готовность буфера канала за \(O(1)\) без перевода горутины в состояние сна.

## Подводные камни

Не забывайте `conn.Close()` в ветке `default`, иначе отвергнутый клиент зависнет на чтении сокета.

## На собеседовании

**Вопрос с собеседования:** «Почему Fast Reject (сброс лишней нагрузки) лучше удержания клиентов в длинной очереди ожидания?»
**Ответ:** Длинная очередь накапливает задержку (Latency Inflation), приводит к таймаутам на клиентах и повторным ретраям (Retry Storm), окончательно добивая перегруженный сервис. Fast Reject сохраняет работоспособность сервера для уже принятых запросов.
