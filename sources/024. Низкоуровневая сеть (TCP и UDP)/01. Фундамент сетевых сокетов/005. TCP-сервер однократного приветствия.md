# TCP-сервер однократного приветствия (Banner Server)

## Условие

Создайте TCP-сервер на `localhost:8080`, который принимает соединения и отправляет «Hello, client!» каждому подключившемуся.

## Теория

Паттерн Greeting/Banner Server: сразу после установления TCP-сессии сервер отправляет приветственное сообщение (Banner) и закрывает соединение или переходит в режим ожидания команд.

## Решение по шагам

1. Создадим слушатель `net.Listen`.
2. При `listener.Accept()` немедленно отправляем сообщение `Hello, client!\n`.
3. Закрываем соединение `conn.Close()`.
4. Проверим получение приветствия клиентом.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"net"
	"time"
)

func runGreetingServer(l net.Listener) {
	for {
		conn, err := l.Accept()
		if err != nil {
			return
		}

		go func(c net.Conn) {
			defer c.Close()
			_, _ = c.Write([]byte("Hello, client!\n"))
		}(conn)
	}
}

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	go runGreetingServer(l)
	time.Sleep(10 * time.Millisecond)

	// Клиент
	conn, err := net.Dial("tcp", l.Addr().String())
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	greeting, _ := bufio.NewReader(conn).ReadString('\n')
	fmt.Printf("[Client] Получено приветствие от сервера: %s", greeting)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Client] Получено приветствие от сервера: Hello, client!
```

## Под капотом

Закрытие `conn.Close()` инициирует отправку TCP FIN пакета, завершая сессию 4-ступенчатым рукопожатием.

## Подводные камни

Если клиент не успеет вызвать `conn.Read()` до закрытия сокета сервером, в ОС может возникнуть ошибка `connection reset by peer` при наличии неотправленных данных.

## На собеседовании

**Вопрос с собеседования:** «Что такое TCP 4-Way Handshake при закрытии соединения?»
**Ответ:** 1. Клиент/сервер шлет `FIN`; 2. Вторая сторона отвечает `ACK`; 3. Вторая сторона шлет свой `FIN`; 4. Инициатор закрытия отвечает `ACK` и переходит в состояние `TIME_WAIT` на \(2 \times \text{MSL}\).
