# Сетевой широковещательный чат (TCP Broadcast Engine)

## Условие

Реализуйте простой чат: сервер принимает сообщения от любого клиента и рассылает их всем остальным (broadcast).

## Теория

Широковещательная сеть: все подключенные сокеты регистрируются в пуле рассылки. Каждое полученное сообщение копируется во все сокеты, кроме сокета отправителя.

## Решение по шагам

1. Создадим структуру `SimpleChat`.
2. Реализуем `Broadcast(sender, msg)`.
3. Подключим Клиента А и Клиента Б.
4. Проверим доставку сообщения.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"net"
	"sync"
	"time"
)

type SimpleChat struct {
	mu    sync.Mutex
	conns map[net.Conn]struct{}
}

func (c *SimpleChat) Broadcast(sender net.Conn, msg string) {
	c.mu.Lock()
	defer c.mu.Unlock()

	for conn := range c.conns {
		if conn != sender {
			_, _ = conn.Write([]byte(msg + "\n"))
		}
	}
}

func (c *SimpleChat) Handle(conn net.Conn) {
	c.mu.Lock()
	c.conns[conn] = struct{}{}
	c.mu.Unlock()

	defer func() {
		c.mu.Lock()
		delete(c.conns, conn)
		c.mu.Unlock()
		conn.Close()
	}()

	scanner := bufio.NewScanner(conn)
	for scanner.Scan() {
		c.Broadcast(conn, scanner.Text())
	}
}

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	chat := &SimpleChat{conns: make(map[net.Conn]struct{})}

	go func() {
		for {
			conn, err := l.Accept()
			if err != nil {
				return
			}
			go chat.Handle(conn)
		}
	}()

	time.Sleep(10 * time.Millisecond)

	// Клиент A
	cA, _ := net.Dial("tcp", l.Addr().String())
	defer cA.Close()

	// Клиент B
	cB, _ := net.Dial("tcp", l.Addr().String())
	defer cB.Close()

	time.Sleep(10 * time.Millisecond)

	// Клиент A отправляет сообщение
	_, _ = cA.Write([]byte("Привет от Клиента А!\n"))

	// Клиент B читает broadcast
	resp, _ := bufio.NewReader(cB).ReadString('\n')
	fmt.Printf("[Клиент B получил] %s", resp)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Клиент B получил] Привет от Клиента А!
```

## Под капотом

Запись в сокет `conn.Write` передает байты в системный выходной буфер сокета `SO_SNDBUF` ядра ОС.

## Подводные камни

В чатах с тысячами участников итерация по мапе под мьютексом заблокирует сервер. В HighLoad применяют каналы на каждого подписчика (Actor Model).

## На собеседовании

**Вопрос с собеседования:** «Каков размер буферов сокетов по умолчанию в Linux (SO_RCVBUF / SO_SNDBUF)?»
**Ответ:** По умолчанию ядро Linux динамически автотюнит размеры буферов (`tcp_rmem` и `tcp_wmem`) от 4 КБ до нескольких мегабайт в зависимости от полосы пропускания и сетевой задержки (BDP — Bandwidth Delay Product).
