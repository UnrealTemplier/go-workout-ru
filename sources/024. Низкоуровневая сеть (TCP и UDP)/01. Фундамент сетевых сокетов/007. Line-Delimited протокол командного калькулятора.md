# Line-Delimited протокол командного калькулятора (ADD, MUL, SUB)

## Условие

Напиши **line-delimited protocol**: сервер читает строки (`ReadString('\n')`), парсит команду (`"ADD 5 3"` → `8`, `"MUL 4 2"` → `8`), отправляет результат. Клиент отправляет команды интерактивно (чтение из `os.Stdin`).

## Теория

Текстовые командные протоколы (Command Protocols): парсинг протоколов вида `COMMAND ARG1 ARG2\n`. Сервер валидирует формат, выполняет операцию и возвращает `OK <result>\n` или `ERR <reason>\n`.

## Решение по шагам

1. Создадим функцию вычисления команд `ADD`, `MUL`, `SUB`.
2. Сервер построчно парсит запросы через `strings.Fields`.
3. Клиент отправляет 3 математические команды.
4. Проверим корректность вычислений.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"net"
	"strconv"
	"strings"
	"time"
)

func processCommand(line string) string {
	parts := strings.Fields(strings.TrimSpace(line))
	if len(parts) != 3 {
		return "ERR invalid_format\n"
	}

	cmd := strings.ToUpper(parts[0])
	a, err1 := strconv.Atoi(parts[1])
	b, err2 := strconv.Atoi(parts[2])

	if err1 != nil || err2 != nil {
		return "ERR invalid_numbers\n"
	}

	switch cmd {
	case "ADD":
		return fmt.Sprintf("OK %d\n", a+b)
	case "MUL":
		return fmt.Sprintf("OK %d\n", a*b)
	case "SUB":
		return fmt.Sprintf("OK %d\n", a-b)
	default:
		return "ERR unknown_command\n"
	}
}

func startCalcServer(l net.Listener) {
	for {
		conn, err := l.Accept()
		if err != nil {
			return
		}

		go func(c net.Conn) {
			defer c.Close()
			scanner := bufio.NewScanner(c)
			for scanner.Scan() {
				resp := processCommand(scanner.Text())
				_, _ = c.Write([]byte(resp))
			}
		}(conn)
	}
}

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	go startCalcServer(l)
	time.Sleep(10 * time.Millisecond)

	// Клиент
	conn, err := net.Dial("tcp", l.Addr().String())
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	reader := bufio.NewReader(conn)
	tests := []string{"ADD 15 25\n", "MUL 7 8\n", "SUB 100 42\n"}

	for _, req := range tests {
		_, _ = conn.Write([]byte(req))
		ans, _ := reader.ReadString('\n')
		fmt.Printf("[Calc Client] %s -> %s", req, ans)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Calc Client] ADD 15 25
#  -> OK 40
# [Calc Client] MUL 7 8
#  -> OK 56
# [Calc Client] SUB 100 42
#  -> OK 58
```

## Под капотом

`bufio.Scanner` автоматически разбивает поток байт по `\n` и обрезает `\r` (CRLF).

## Подводные камни

В `bufio.Scanner` максимальный размер строки ограничен `bufio.MaxScanTokenSize` (64 КБ). Для длинных строк настраивают `scanner.Buffer()`.
