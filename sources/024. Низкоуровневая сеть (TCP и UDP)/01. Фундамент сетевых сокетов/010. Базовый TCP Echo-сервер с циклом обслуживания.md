# Базовый TCP Echo-сервер с циклом обслуживания и defer conn.Close

## Условие

Создайте простой TCP-сервер (`net.Listen`), который принимает подключение, читает сообщение от клиента и отправляет его обратно (эхо-сервер).

## Теория

Каноническая структура сетевого обработчика: безопасная изоляция ресурсов с помощью `defer conn.Close()` гарантирует закрытие сокета даже при возникновении сетевых ошибок или паники.

## Решение по шагам

1. Создадим `net.Listen`.
2. Вызовем `conn, _ := listener.Accept()`.
3. Обернем сокет в `defer conn.Close()`.
4. Проверим эхо-ответ.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
	"time"
)

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	go func() {
		for {
			conn, err := l.Accept()
			if err != nil {
				return
			}
			go func(c net.Conn) {
				defer c.Close()
				buf := make([]byte, 1024)
				n, _ := c.Read(buf)
				_, _ = c.Write(buf[:n])
			}(conn)
		}
	}()

	time.Sleep(10 * time.Millisecond)

	conn, _ := net.Dial("tcp", l.Addr().String())
	defer conn.Close()

	_, _ = conn.Write([]byte("Echo Test Message"))
	reply := make([]byte, 1024)
	n, _ := conn.Read(reply)

	fmt.Printf("[Echo Result] %s\n", string(reply[:n]))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Echo Result] Echo Test Message
```

## Под капотом

`c.Read(buf)` возвращает количество фактически считанных байт \(n \le \text{len}(buf)\).

## Подводные камни

Всегда используйте срез `buf[:n]`, а не весь `buf`, иначе в ответ попадут нулевые байты.

## На собеседовании

**Вопрос с собеседования:** «Что возвращает conn.Read(), если размер буфера меньше пришедшего пакета?»
**Ответ:** `conn.Read()` заполняет переданный буфер целиком, возвращает `len(buf), nil`, а оставшиеся байты пакета остаются в системном буфере сокета операционной системы до следующего вызова `Read()`.
