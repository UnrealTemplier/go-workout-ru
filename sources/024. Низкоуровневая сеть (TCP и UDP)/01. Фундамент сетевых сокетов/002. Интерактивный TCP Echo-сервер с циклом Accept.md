# Интерактивный TCP Echo-сервер с циклом Accept и клиентом net.Dial

## Условие

**TCP-сервер (Echo)**: Используй `net.Listen("tcp", ":8080")`. Напиши цикл, который принимает подключения (`Accept()`). При подключении читай данные из соединения и отправляй их обратно клиенту (эхо). (Для теста используй утилиту `telnet` или `nc` в консоли).

## Теория

Архитектура TCP Client-Server: Сервер регистрирует сокет в ОС через `net.Listen`, а клиент инициирует установление TCP сессии вызовом `net.Dial("tcp", hostPort)`. Полнодуплексный канал позволяет обеим сторонам независимо передавать байты.

## Решение по шагам

1. Создадим TCP Listener.
2. В цикле `for` вызываем `listener.Accept()`.
3. Читаем входящие байты порциями и зеркально отправляем назад.
4. Проверим обмен 3 тестовыми сообщениями.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net"
	"time"
)

func startEchoService(l net.Listener) {
	for {
		conn, err := l.Accept()
		if err != nil {
			return
		}

		go func(c net.Conn) {
			defer c.Close()
			buf := make([]byte, 512)
			for {
				n, err := c.Read(buf)
				if err != nil {
					return
				}
				_, _ = c.Write(buf[:n])
			}
		}(conn)
	}
}

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	go startEchoService(l)

	time.Sleep(10 * time.Millisecond)

	// Клиент отправляет 3 запроса подряд
	conn, err := net.Dial("tcp", l.Addr().String())
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	commands := []string{"PING\n", "GET_STATUS\n", "BYE\n"}
	buf := make([]byte, 512)

	for _, cmd := range commands {
		_, _ = conn.Write([]byte(cmd))
		n, _ := conn.Read(buf)
		fmt.Printf("[Client] Sent: %q -> Echo Received: %q\n", cmd, string(buf[:n]))
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Client] Sent: "PING\n" -> Echo Received: "PING\n"
# [Client] Sent: "GET_STATUS\n" -> Echo Received: "GET_STATUS\n"
# [Client] Sent: "BYE\n" -> Echo Received: "BYE\n" 
```

## Под капотом

Вызов `net.Dial` выполняет `connect()` системный вызов ядра ОС, отправляя TCP SYN пакет и согласуя начальные Sequence Numbers (ISN) и размер скользящего окна (Window Size).

## Подводные камни

В сетевых приложениях `net.Conn` нельзя закрывать дважды, но `defer conn.Close()` защищает от утечки дескрипторов при любом завершении горутины.

## На собеседовании

**Вопрос с собеседования:** «Какое максимальное число одновременных TCP-соединений может удерживать сервер на одном порту?»
**Ответ:** Лимитируется не портом сервера, а 4-кортежем `(SrcIP, SrcPort, DstIP, DstPort)`, системным лимитом файловых дескрипторов `ulimit -n` и оперативной памятью под буферы сокетов `tcp_rmem`/`tcp_wmem` (на Linux — сотни тысяч и миллионы соединений при C1000K тюнинге).
