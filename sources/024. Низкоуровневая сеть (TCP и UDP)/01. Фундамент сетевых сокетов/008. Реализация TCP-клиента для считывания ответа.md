# Реализация TCP-клиента для считывания ответа сервера

## Условие

Реализуйте TCP-клиент, который подключается к вашему серверу, читает сообщение и выводит его.

## Теория

Клиентское сетевое программирование: метод `net.Dial` создает исходящий сокет, связывает его со свободным эфемерным портом ОС и возвращает дескриптор соединения `net.Conn`.

## Решение по шагам

1. Запустим тестовый сервер.
2. В клиенте вызовем `net.Dial("tcp", addr)`.
3. Вычитаем данные с помощью `io.ReadAll(conn)`.
4. Выведем сообщение.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net"
	"time"
)

func runSimpleServer(l net.Listener) {
	conn, err := l.Accept()
	if err != nil {
		return
	}
	defer conn.Close()
	_, _ = conn.Write([]byte("System Message: Сервер готов к работе."))
}

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	go runSimpleServer(l)
	time.Sleep(10 * time.Millisecond)

	// Реализация TCP-клиента
	conn, err := net.Dial("tcp", l.Addr().String())
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	msgBytes, err := io.ReadAll(conn)
	if err != nil {
		panic(err)
	}

	fmt.Printf("[TCP Client] Прочитано сообщение: %s\n", string(msgBytes))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [TCP Client] Прочитано сообщение: System Message: Сервер готов к работе.
```

## Под капотом

`io.ReadAll` считывает сокет порциями до тех пор, пока сервер не закроет соединение (`io.EOF`).

## Подводные камни

Использование `io.ReadAll` на незакрываемом Keep-Alive сокете приведет к бесконечной блокировке.

## На собеседовании

**Вопрос с собеседования:** «Что такое эфемерный порт (Ephemeral Port) на стороне TCP-клиента?»
**Ответ:** Это временный локальный порт из динамического диапазона ОС (например, 32768–60999 на Linux), автоматически назначаемый ядром для исходящего соединения.
