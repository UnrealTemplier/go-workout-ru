# Интерактивный TCP-клиент с чтением ввода из консоли

## Условие

**Простейший TCP-клиент**: Напишите клиентское приложение, которое подключается к вашему Echo-серверу с помощью `net.Dial("tcp", "localhost:8080")`. Клиент должен считать строку из консоли (`os.Stdin`), отправить её на сервер, дождаться ответа от сервера, вывести его на экран и завершить работу.

## Теория

Пайплайн консольного клиента: соединение `os.Stdin` (чтение пользовательского ввода) с сетевым `net.Conn` (передача данных в TCP сокет) и вывод в `os.Stdout`.

## Решение по шагам

1. Создадим Echo-сервер.
2. Подключимся через `net.Dial`.
3. Сымитируем чтение пользовательской строки.
4. Отправим в `conn` и распечатаем эхо-ответ.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"net"
	"strings"
	"time"
)

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	// Эхо-сервер
	go func() {
		conn, err := l.Accept()
		if err != nil {
			return
		}
		defer conn.Close()
		scanner := bufio.NewScanner(conn)
		if scanner.Scan() {
			_, _ = conn.Write([]byte(scanner.Text() + " [ECHO-OK]\n"))
		}
	}()

	time.Sleep(10 * time.Millisecond)

	// Клиентское приложение
	conn, err := net.Dial("tcp", l.Addr().String())
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	// Симуляция ввода пользователя
	userInput := "Hello World from Stdin!"
	fmt.Printf("[User Input] Введено: %s\n", userInput)

	_, _ = conn.Write([]byte(userInput + "\n"))

	resp, _ := bufio.NewReader(conn).ReadString('\n')
	fmt.Printf("[Client Output] Получен ответ от сервера: %s", strings.TrimSpace(resp))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [User Input] Введено: Hello World from Stdin!
# [Client Output] Получен ответ от сервера: Hello World from Stdin! [ECHO-OK]
```

## Под капотом

Символ `\n` выступает разделителем кадра в потоке байтов.

## Подводные камни

Не забывайте добавлять `\n` в конце строки, если сервер ожидает построчный протокол.

## На собеседовании

**Вопрос с собеседования:** «Почему TCP называется потоковым протоколом (Stream-Oriented)?»
**Ответ:** Потому что TCP не сохраняет границы отдельных вызовов `Write()`. Десять вызовов `Write()` по 10 байт могут быть получены одной операцией `Read()` на 100 байт или двадцатью вызовами `Read()` по 5 байт.
