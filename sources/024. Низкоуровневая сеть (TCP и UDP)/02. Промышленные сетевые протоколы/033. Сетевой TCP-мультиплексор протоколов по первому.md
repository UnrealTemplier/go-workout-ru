# Сетевой TCP-мультиплексор протоколов по первому байту (Magic Byte Multiplexing)

## Условие

Напиши **TCP multiplexer**: сервер слушает один порт. Первый байт соединения определяет протокол: `0x01` → эхо-сервис, `0x02` → time-сервис (отправляет текущее время), `0x03` → статус. Прочитай 1 байт, затем делегируй обработку.

## Теория

Паттерн Magic Byte Protocol Multiplexing (Мультиплексирование сервисов на одном порту): первый считанный байт выступает опкодом протокола (Magic Byte). В зависимости от его значения сокет передается соответствующему узкоспециализированному хендлеру (например, как в Envoy/gRPC для различения TLS, HTTP/2 и raw TCP).

## Решение по шагам

1. Считываем первый байт опкода `magicByte := buf[0]`.
2. В `switch` направляем в `handleEcho`, `handleTime` или `handleStatus`.
3. Запустим тестовых клиентов с разными опкодами.
4. Проверим диспетчеризацию.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
	"time"
)

const (
	ProtoEcho   byte = 0x01
	ProtoTime   byte = 0x02
	ProtoStatus byte = 0x03
)

func handleMuxConnection(conn net.Conn) {
	defer conn.Close()

	// Читаем Magic Byte протокола
	magic := make([]byte, 1)
	if _, err := conn.Read(magic); err != nil {
		return
	}

	switch magic[0] {
	case ProtoEcho:
		buf := make([]byte, 256)
		n, _ := conn.Read(buf)
		_, _ = conn.Write([]byte("ECHO: " + string(buf[:n])))

	case ProtoTime:
		currTime := time.Now().Format("2006-01-02 15:04:05")
		_, _ = conn.Write([]byte("TIME: " + currTime))

	case ProtoStatus:
		_, _ = conn.Write([]byte("STATUS: 200 OK (HEALTHY)"))

	default:
		_, _ = conn.Write([]byte("ERR: UNKNOWN_PROTOCOL"))
	}
}

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	go func() {
		for {
			conn, err := l.Accept()
			if err != nil {
				return
			}
			go handleMuxConnection(conn)
		}
	}()

	time.Sleep(10 * time.Millisecond)

	// Клиент 1: Запрашивает статус (0x03)
	c1, _ := net.Dial("tcp", l.Addr().String())
	_, _ = c1.Write([]byte{ProtoStatus})
	resp1 := make([]byte, 128)
	n1, _ := c1.Read(resp1)
	c1.Close()
	fmt.Printf("[Client 1 (Status)] %s\n", string(resp1[:n1]))

	// Клиент 2: Запрашивает эхо (0x01)
	c2, _ := net.Dial("tcp", l.Addr().String())
	_, _ = c2.Write(append([]byte{ProtoEcho}, []byte("Multi-protocol message")...))
	resp2 := make([]byte, 128)
	n2, _ := c2.Read(resp2)
	c2.Close()
	fmt.Printf("[Client 2 (Echo)]   %s\n", string(resp2[:n2]))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Client 1 (Status)] STATUS: 200 OK (HEALTHY)
# [Client 2 (Echo)]   ECHO: Multi-protocol message
```

## Под капотом

Если требуется вернуть считанный байт обратно в поток для стороннего хендлера (например, HTTP парсера), используют `io.MultiReader(bytes.NewReader(magic), conn)`.

## Подводные камни

Обязательно проверяйте ошибку при чтении magic byte: клиент может разорвать соединение сразу после рукопожатия.

## На собеседовании

**Вопрос с собеседования:** «Как библиотека cmux в Go разделяет трафик gRPC, HTTP/1.1 и SSH на одном TCP порту?»
**Ответ:** Она использует `io.MultiReader` и предпросмотр первых байтов соединения (Sniffing Headers): если заголовок начинается с `PRI * HTTP/2.0`, сокет уходит в gRPC; если с `GET /` — в HTTP/1.1; если с `SSH-` — в SSH-сервер.
