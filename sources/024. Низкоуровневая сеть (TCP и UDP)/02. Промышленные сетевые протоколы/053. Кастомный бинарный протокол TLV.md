# Кастомный бинарный протокол TLV (Type-Length-Value) на базе encoding/binary

## Условие

**Кастомный бинарный протокол (TLV)**: Напишите TCP-сервер и клиент, общающиеся по собственному простейшему бинарному протоколу формата Type-Length-Value (TLV). Сначала клиент отправляет 1 байт (тип сообщения), затем 4 байта в формате Big Endian (длина сообщения), а затем само сообщение. Сервер должен корректно распарсить этот поток байт с использованием пакета `encoding/binary`.

## Теория

Бинарный протокол TLV (Type-Length-Value): промышленный стандарт структурирования сетевых кадров (применяется в ASN.1, TLS, EMV картах, протоколах маршрутизации BGP/IS-IS).
* **Type (1 байт):** ID типа команды/структуры данных.
* **Length (4 байта uint32):** точный размер тела \(N\).
* **Value (\(N\) байт):** сырая полезная нагрузка (JSON, Protobuf, бинарные структуры).

## Решение по шагам

1. Создадим функции кодирования и декодирования TLV пакетов.
2. Клиент отправляет пакет с Type=0x07 (AuthPacket).
3. Сервер считывает 1 байт типа, 4 байта длины и ровно \(N\) байт через `io.ReadFull`.
4. Проверим разбор бинарного кадра.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/binary"
	"fmt"
	"io"
	"net"
	"time"
)

type TLVPacket struct {
	Type    byte
	Length  uint32
	Payload []byte
}

func writeTLV(w io.Writer, msgType byte, payload []byte) error {
	// 1. Запись Type (1 байт)
	if _, err := w.Write([]byte{msgType}); err != nil {
		return err
	}

	// 2. Запись Length (4 байта Big Endian)
	length := uint32(len(payload))
	if err := binary.Write(w, binary.BigEndian, length); err != nil {
		return err
	}

	// 3. Запись Value
	_, err := w.Write(payload)
	return err
}

func readTLV(r io.Reader) (*TLVPacket, error) {
	// 1. Читаем Type
	typeBuf := make([]byte, 1)
	if _, err := io.ReadFull(r, typeBuf); err != nil {
		return nil, err
	}

	// 2. Читаем Length
	var length uint32
	if err := binary.Read(r, binary.BigEndian, &length); err != nil {
		return nil, err
	}

	// 3. Читаем Value строго указанной длины
	payload := make([]byte, length)
	if _, err := io.ReadFull(r, payload); err != nil {
		return nil, err
	}

	return &TLVPacket{
		Type:    typeBuf[0],
		Length:  length,
		Payload: payload,
	}, nil
}

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	// Сервер декодирует TLV
	go func() {
		conn, err := l.Accept()
		if err != nil {
			return
		}
		defer conn.Close()

		packet, err := readTLV(conn)
		if err == nil {
			fmt.Println("=== СЕРВЕР РАСПАРСИЛ TLV КАДР ===")
			fmt.Printf(" -> Type:    0x%02X\n", packet.Type)
			fmt.Printf(" -> Length:  %d байт\n", packet.Length)
			fmt.Printf(" -> Payload: %s\n", string(packet.Payload))
		}
	}()

	time.Sleep(10 * time.Millisecond)

	// Клиент
	conn, err := net.Dial("tcp", l.Addr().String())
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	const MsgTypeAuth byte = 0x7F
	authData := []byte(`{"user":"admin","token":"SEC-KEY-999"}`)

	_ = writeTLV(conn, MsgTypeAuth, authData)
	time.Sleep(20 * time.Millisecond)
}
```

```bash

# Вывод:

#  -> Type:    0x7F

```

## Под капотом

Формат TLV позволяет добавлять новые типы сообщений и расширять протокол с сохранением обратной совместимости (Forward/Backward Compatibility).

## Подводные камни

Всегда проверяйте `packet.Length` на допустимый максимум, чтобы некорректный кадр не привел к панике или выделению гигабайтов памяти.
