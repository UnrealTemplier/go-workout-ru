# Сетевое взаимодействие UDP: сервер дейтаграмм и клиентский сокет

## Условие

UDP-сервер и клиент: сервер слушает на UDP-порту, клиент отправляет дейтаграмму с текстом, сервер отвечает.

## Теория

Симметрия UDP сокетов: UDP является дейтаграммным протоколом без установления постоянного логического канала. Метод `conn.ReadFrom` извлекает полезную нагрузку и IP-адрес отправителя.

## Решение по шагам

1. Запустим UDP Listener `net.ListenPacket("udp", "127.0.0.1:0")`.
2. Клиент отправляет дейтаграмму.
3. Сервер отвечает на адрес клиента.
4. Проверим прием ответа.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
	"time"
)

func main() {
	// 1. UDP Сервер на базе net.ListenPacket
	server, err := net.ListenPacket("udp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer server.Close()

	serverAddr := server.LocalAddr().String()

	go func() {
		buf := make([]byte, 1024)
		n, clientAddr, err := server.ReadFrom(buf)
		if err != nil {
			return
		}
		reply := fmt.Sprintf("SERVER_UDP_REPLY: [%s]", string(buf[:n]))
		_, _ = server.WriteTo([]byte(reply), clientAddr)
	}()

	time.Sleep(10 * time.Millisecond)

	// 2. UDP Клиент
	client, err := net.Dial("udp", serverAddr)
	if err != nil {
		panic(err)
	}
	defer client.Close()

	_, _ = client.Write([]byte("Telemetry-Packet-99"))

	resp := make([]byte, 1024)
	n, _ := client.Read(resp)
	fmt.Printf("[UDP Client] %s\n", string(resp[:n]))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [UDP Client] SERVER_UDP_REPLY: [Telemetry-Packet-99]
```

## Под капотом

Интерфейс `net.PacketConn` представляет сокет дейтаграмм без состояния (Stateless Datagram Socket).

## Подводные камни

В UDP не гарантируется порядок доставки пакетов: пакет #2 может прийти в ОС раньше пакета #1.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество интерфейса net.PacketConn перед net.Conn?»
**Ответ:** `net.PacketConn` проектировался специально для пакетных протоколов (UDP, IP, Unix Datagram) и предоставляет методы `ReadFrom` и `WriteTo` с явным указанием адреса для каждой отдельной дейтаграммы.
