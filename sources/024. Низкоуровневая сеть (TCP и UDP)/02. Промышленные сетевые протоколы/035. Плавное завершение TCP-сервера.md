# Плавное завершение TCP-сервера (TCP Graceful Shutdown) через listener.Close и WaitGroup

## Условие

Напиши **TCP graceful shutdown**: сервер слушает сигнал `os.Interrupt`, при получении вызывает `listener.Close()`. Используй `sync.WaitGroup` для ожидания завершения активных соединений. Новые соединения не принимаются, старые обрабатываются до конца.

## Теория

Graceful Shutdown низкоуровневого TCP-сервера:
1. Вызов `listener.Close()` останавливает прием новых клиентов (новые вызовы `Accept()` возвращают ошибку `net.ErrClosed`).
2. Ожидание завершения активных сессий через `sync.WaitGroup`.
3. Чистая остановка процесса без обрыва клиентских сессий.

## Решение по шагам

1. Создадим структуру `GracefulTCPServer`.
2. При `Shutdown()` закрываем `listener` и вызываем `wg.Wait()`.
3. Запустим клиента с длительной задачей.
4. Убедимся, что сервер дождался ответа клиента перед остановкой.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
	"net"
	"sync"
	"time"
)

type TCPServer struct {
	listener net.Listener
	wg       sync.WaitGroup
	quit     chan struct{}
}

func NewTCPServer(addr string) (*TCPServer, error) {
	l, err := net.Listen("tcp", addr)
	if err != nil {
		return nil, err
	}
	return &TCPServer{
		listener: l,
		quit:     make(chan struct{}),
	}, nil
}

func (s *TCPServer) Start() {
	go func() {
		for {
			conn, err := s.listener.Accept()
			if err != nil {
				if errors.Is(err, net.ErrClosed) {
					fmt.Println("[Server Listener] Слушатель сокета чисто закрыт.")
					return
				}
				return
			}

			s.wg.Add(1)
			go s.handleConn(conn)
		}
	}()
}

func (s *TCPServer) handleConn(conn net.Conn) {
	defer s.wg.Done()
	defer conn.Close()

	fmt.Println(" [+] [Server] Клиент начал долгую транзакцию (30 мс)...")
	time.Sleep(30 * time.Millisecond)
	_, _ = conn.Write([]byte("TRANSACTION_COMMITTED\n"))
	fmt.Println(" [✓] [Server] Транзакция клиента успешно зафиксирована.")
}

func (s *TCPServer) Stop() {
	_ = s.listener.Close() // Перестаем принимать новые подключения
	s.wg.Wait()            // Ждем завершения всех активных сессий
	fmt.Println("[Server] Все активные клиенты завершены. Graceful Shutdown 100% успешен!")
}

func main() {
	server, err := NewTCPServer("127.0.0.1:0")
	if err != nil {
		panic(err)
	}

	server.Start()
	serverAddr := server.listener.Addr().String()

	// Клиент подключается и выполняет операцию
	clientConn, _ := net.Dial("tcp", serverAddr)
	defer clientConn.Close()

	time.Sleep(10 * time.Millisecond)

	// Инициируем остановку сервера
	fmt.Println("\n[Main] Получен сигнал остановки сервера (Stop)...")
	server.Stop()
}
```

## Под капотом

`listener.Close()` закрывает слушающий файловый дескриптор, мгновенно разблокируя поток `Accept()`.

## Подводные камни

Всегда используйте `errors.Is(err, net.ErrClosed)` (Go 1.16+), чтобы отличать штатную остановку сервера от реальных сетевых сбоев.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать Zero-Downtime рестарт (Hot Reload) TCP-сервера на Linux?»
**Ответ:** Передать файловый дескриптор слушающего сокета `listener.File()` дочернему процессу через `exec.Command` с `ExtraFiles`, вызвать `net.FileListener` в новом процессе и затем плавно остановить старый процесс.
