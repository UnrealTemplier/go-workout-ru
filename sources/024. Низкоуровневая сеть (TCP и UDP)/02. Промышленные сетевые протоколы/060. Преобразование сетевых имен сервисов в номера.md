# Преобразование сетевых имен сервисов в номера портов: net.LookupPort

## Условие

Используй `net.LookupPort("tcp", "http")` → вернёт `80`. Покажи преобразование имени сервиса в порт.

## Теория

Служебный реестр портов IANA: функция `net.LookupPort(network, service)` считывает соответствия из системной базы данных сервисов (`/etc/services` на Linux/macOS).

## Решение по шагам

1. Преобразуем сервисы `"http"`, `"https"`, `"ssh"`, `"smtp"`.
2. Выведем соответствующие числовые порты TCP.
3. Проверим обработку неизвестного сервиса.
4. Выведем таблицу соответствий.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
)

func main() {
	services := []string{"http", "https", "ssh", "smtp", "dns"}

	fmt.Println("Сопоставление сервисов IANA с номерами TCP/UDP портов:")
	for _, s := range services {
		network := "tcp"
		if s == "dns" {
			network = "udp"
		}
		port, err := net.LookupPort(network, s)
		if err == nil {
			fmt.Printf(" -> Сервис %-6s (%s) = Порт %d\n", s, network, port)
		}
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Сопоставление сервисов IANA с номерами TCP/UDP портов:
#  -> Сервис http   (tcp) = Порт 80
#  -> Сервис https  (tcp) = Порт 443
#  -> Сервис ssh    (tcp) = Порт 22
#  -> Сервис smtp   (tcp) = Порт 25
#  -> Сервис dns    (udp) = Порт 53
```

## Под капотом

Пакет `net` кэширует таблицу `/etc/services` в памяти процесса при первом обращении.

## Подводные камни

В минималистичных Docker-контейнерах (например, `scratch` или `distroless`) файл `/etc/services` может отсутствовать.

## На собеседовании

**Вопрос с собеседования:** «Каковы диапазоны номеров портов в TCP/IP?»
**Ответ:** 1. Well-Known Ports: 0–1023 (требуют root прав); 2. Registered Ports: 1024–49151 (пользовательские сервисы); 3. Dynamic / Ephemeral Ports: 49152–65535 (клиентские исходящие сокеты).
