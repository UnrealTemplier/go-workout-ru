# Построчный TCP Echo-сервер на базе bufio.NewReader(conn).ReadString

## Условие

Напиши TCP-сервер, который читает данные построчно с помощью `bufio.NewReader(conn).ReadString('\n')` и отправляет их обратно (Echo-сервер).

## Теория

Построчное буферизованное эхо: `bufio.NewReader` считывает входящий поток байт блоками и возвращает строки по мере нахождения разделителя `\n`.

## Решение по шагам

1. Создадим `net.Listen`.
2. В цикле читаем строки через `reader.ReadString('\n')`.
3. Отправляем эхо назад.
4. Проверим работу.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"net"
	"time"
)

func main() {
	l, _ := net.Listen("tcp", "127.0.0.1:0")
	defer l.Close()

	go func() {
		conn, err := l.Accept()
		if err != nil {
			return
		}
		defer conn.Close()

		reader := bufio.NewReader(conn)
		for {
			line, err := reader.ReadString('\n')
			if err != nil {
				return
			}
			_, _ = conn.Write([]byte("ECHO: " + line))
		}
	}()

	time.Sleep(10 * time.Millisecond)

	c, _ := net.Dial("tcp", l.Addr().String())
	defer c.Close()

	_, _ = c.Write([]byte("Строка номер один\n"))
	resp, _ := bufio.NewReader(c).ReadString('\n')
	fmt.Printf("[Echo Result] %s", resp)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Echo Result] ECHO: Строка номер один
```

## Под капотом

`bufio.Reader` считывает данные из сокета в 4 КБ буфер, избавляя от побайтовых системных вызовов `read()`.

## Подводные камни

Всегда отправляйте `\n` в конце строки, иначе `ReadString('\n')` заблокируется в ожидании разделителя.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие bufio.Reader.ReadString от bufio.Reader.ReadBytes?»
**Ответ:** `ReadBytes` возвращает срез байтов `[]byte`, а `ReadString` делает дополнительное приведение `string(bytes)`, вызывая аллокацию строки в куче. В высокопроизводительном парсинге предпочитают `ReadBytes`.
