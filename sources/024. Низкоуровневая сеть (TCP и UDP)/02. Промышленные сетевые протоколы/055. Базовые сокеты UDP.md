# Базовые сокеты UDP: net.ListenUDP и net.DialUDP без логического канала

## Условие

Напиши простой UDP-сервер (`net.ListenUDP`) и UDP-клиент (`net.DialUDP`). Обрати внимание, что UDP не устанавливает соединение.

## Теория

Низкоуровневая передача дейтаграмм: сокеты UDP не имеют состояний handshake и не обмениваются подтверждениями.

## Решение по шагам

1. Создадим UDP сервер.
2. Создадим UDP клиент.
3. Передадим тестовую дейтаграмму.
4. Проверим получение ответа.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
	"time"
)

func main() {
	sAddr, _ := net.ResolveUDPAddr("udp", "127.0.0.1:0")
	server, _ := net.ListenUDP("udp", sAddr)
	defer server.Close()

	go func() {
		buf := make([]byte, 256)
		n, rAddr, _ := server.ReadFromUDP(buf)
		_, _ = server.WriteToUDP([]byte("ACK:"+string(buf[:n])), rAddr)
	}()

	time.Sleep(10 * time.Millisecond)

	client, _ := net.DialUDP("udp", nil, server.LocalAddr().(*net.UDPAddr))
	defer client.Close()

	_, _ = client.Write([]byte("PingPacket"))
	resp := make([]byte, 256)
	n, _, _ := client.ReadFromUDP(resp)

	fmt.Printf("[UDP Exchange] %s\n", string(resp[:n]))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [UDP Exchange] ACK:PingPacket
```

## Под капотом

`WriteToUDP` отправляет дейтаграмму в сетевой интерфейс без проверки существования сервера.

## Подводные камни

В UDP сокетах нет переполнения буфера отправителя как в TCP со скользящим окном.

## На собеседовании

**Вопрос с собеседования:** «Каковы поля UDP заголовка и каков его размер?»
**Ответ:** Заголовок UDP имеет фиксированный размер 8 байт и содержит 4 поля по 16 бит: Source Port, Destination Port, Length и Checksum.
