# Прием сетевого TCP соединения и извлечение RemoteAddr клиента

## Условие

Напиши TCP-сервер с помощью `net.Listen("tcp", ":9000")`. Прими соединение (`Accept()`) и выведи адрес клиента.

## Теория

Диагностика сетевых адресов: метод `conn.RemoteAddr().String()` возвращает удаленный IP и порт клиента, а `conn.RemoteAddr().Network()` возвращает тип сети (`"tcp"`).

## Решение по шагам

1. Создадим `net.Listen("tcp", "127.0.0.1:0")`.
2. Примем соединение `conn, _ := l.Accept()`.
3. Распечатаем `conn.RemoteAddr()`.
4. Закроем сокет.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
	"time"
)

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	go func() {
		conn, err := l.Accept()
		if err != nil {
			return
		}
		defer conn.Close()

		remote := conn.RemoteAddr()
		fmt.Printf("[Server Accept] Подключен клиент: Сеть=%s, Адрес=%s\n", 
			remote.Network(), remote.String())
	}()

	time.Sleep(10 * time.Millisecond)

	client, _ := net.Dial("tcp", l.Addr().String())
	defer client.Close()
	time.Sleep(10 * time.Millisecond)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Server Accept] Подключен клиент: Сеть=tcp, Адрес=127.0.0.1:54982
```

## Под капотом

`conn.RemoteAddr()` возвращает структуру `*net.TCPAddr` с полями `IP` (`net.IP`) и `Port` (`int`).

## Подводные камни

Если сервер работает за балансировщиком нагрузки (Nginx/HAProxy), `RemoteAddr` вернет IP балансировщика, а не реального клиента. Для передачи IP клиента используют протокол PROXY Protocol или HTTP заголовок `X-Forwarded-For`.

## На собеседовании

**Вопрос с собеседования:** «Что такое PROXY Protocol (HAProxy PROXY Protocol v1/v2)?»
**Ответ:** Это стандарт передачи реального IP-адреса и порта клиента на транспортном уровне (L4): балансировщик добавляет короткий префикс в самое начало TCP-потока перед передачей соединения бэкенду.
