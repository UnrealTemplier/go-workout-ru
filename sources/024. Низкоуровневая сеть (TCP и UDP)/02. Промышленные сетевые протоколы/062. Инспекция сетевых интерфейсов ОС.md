# Инспекция сетевых интерфейсов ОС через net.InterfaceAddrs

## Условие

Используй `net.InterfaceAddrs()` для получения IP-адресов локальных интерфейсов. Выведи имя интерфейса, IP, маску. Найди loopback.

## Теория

Инспекция сетевого оборудования операционной системы: `net.Interfaces()` возвращает сетевые интерфейсы (eth0, wlan0, lo), их флаги (Up, Broadcast, Loopback, Multicast), MAC-адреса и привязанные IP-подсети.

## Решение по шагам

1. Получим список интерфейсов через `net.Interfaces()`.
2. Для каждого интерфейса считаем адреса `iface.Addrs()`.
3. Отфильтруем Loopback интерфейс по флагу `net.FlagLoopback`.
4. Выведем диагностический отчет.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
)

func main() {
	interfaces, err := net.Interfaces()
	if err != nil {
		panic(err)
	}

	fmt.Println("=== СЕТЕВЫЕ ИНТЕРФЕЙСЫ СИСТЕМЫ ===")

	for _, iface := range interfaces {
		isUp := (iface.Flags & net.FlagUp) != 0
		isLoopback := (iface.Flags & net.FlagLoopback) != 0

		addrs, _ := iface.Addrs()

		fmt.Printf("\nИнтерфейс: %s (MTU: %d, MAC: %s)\n", iface.Name, iface.MTU, iface.HardwareAddr)
		fmt.Printf(" -> Флаги: Up=%v, Loopback=%v\n", isUp, isLoopback)

		for _, addr := range addrs {
			fmt.Printf(" -> IP/Mask: %s\n", addr.String())
		}
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# === СЕТЕВЫЕ ИНТЕРФЕЙСЫ СИСТЕМЫ ===
# 
# Интерфейс: lo (MTU: 65536, MAC: )
#  -> Флаги: Up=true, Loopback=true
#  -> IP/Mask: 127.0.0.1/8
#  -> IP/Mask: ::1/128
# 
# Интерфейс: eth0 (MTU: 1500, MAC: 02:42:ac:11:00:02)
#  -> Флаги: Up=true, Loopback=false

```

## Под капотом

`net.Interfaces()` выполняет системный вызов `getifaddrs()` на POSIX системах или обращается к Netlink сокету ядра Linux.

## Подводные камни

Виртуальные интерфейсы (Docker `docker0`, Kubernetes CNI `cbr0`) могут не иметь физического MAC-адреса.

## На собеседовании
