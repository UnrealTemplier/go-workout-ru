# Полнофункциональный TCP Чат-сервер на каналах и горутинах (Actor Model Hub)

## Условие

**TCP Чат-сервер**: Напишите полноценный чат-сервер.
* Несколько клиентов могут подключаться по TCP.
* При подключении сервер запрашивает имя клиента.
* Любое сообщение, отправленное одним из клиентов, должно транслироваться всем остальным активным участникам чата.
* Используйте горутины и каналы для безопасной синхронизации списка клиентов и рассылки сообщений.

## Теория

Паттерн CSP Chat Server (Модель взаимодействия акторов): центральный диспетчер управляет мапой клиентов через 3 канала (`entering`, `leaving`, `messages`) без прямых блокировок мьютексами. Каждый клиент имеет индивидуальную горутину-писатель (`clientWriter`), сбрасывающую персональный канал в TCP-сокет.

## Решение по шагам

1. Создадим структуру `client chan<- string`.
2. Реализуем центральный селектор `broadcaster()`.
3. Реализуем обработчик сессии `handleConn(conn)`.
4. Проверим параллельный диалог между двумя пользователями.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"net"
	"time"
)

type client chan<- string

var (
	entering = make(chan client)
	leaving  = make(chan client)
	messages = make(chan string)
)

func broadcaster(done <-chan struct{}) {
	clients := make(map[client]bool)
	for {
		select {
		case <-done:
			return
		case msg := <-messages:
			for cli := range clients {
				cli <- msg
			}
		case cli := <-entering:
			clients[cli] = true
		case cli := <-leaving:
			delete(clients, cli)
			close(cli)
		}
	}
}

func clientWriter(conn net.Conn, ch <-chan string) {
	for msg := range ch {
		_, _ = fmt.Fprintln(conn, msg)
	}
}

func handleChatUser(conn net.Conn) {
	ch := make(chan string, 10)
	go clientWriter(conn, ch)

	reader := bufio.NewReader(conn)
	_, _ = fmt.Fprintln(conn, "Введите ваше имя:")
	name, _ := reader.ReadString('\n')
	name = name[:len(name)-1]

	ch <- "Добро пожаловать в чат, " + name + "!"
	messages <- " [+] " + name + " присоединился к чату."
	entering <- ch

	scanner := bufio.NewScanner(conn)
	for scanner.Scan() {
		messages <- "[" + name + "]: " + scanner.Text()
	}

	leaving <- ch
	messages <- " [-] " + name + " покинул чат."
	conn.Close()
}

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	done := make(chan struct{})
	go broadcaster(done)

	go func() {
		for {
			conn, err := l.Accept()
			if err != nil {
				return
			}
			go handleChatUser(conn)
		}
	}()

	time.Sleep(10 * time.Millisecond)

	// Клиент 1 (Дмитрий)
	cDima, _ := net.Dial("tcp", l.Addr().String())
	defer cDima.Close()
	rDima := bufio.NewReader(cDima)
	_, _ = rDima.ReadString('\n') // Введите имя
	_, _ = cDima.Write([]byte("Дмитрий\n"))
	_, _ = rDima.ReadString('\n') // Welcome

	// Клиент 2 (Елена)
	cElena, _ := net.Dial("tcp", l.Addr().String())
	defer cElena.Close()
	rElena := bufio.NewReader(cElena)
	_, _ = rElena.ReadString('\n')
	_, _ = cElena.Write([]byte("Елена\n"))
	_, _ = rElena.ReadString('\n')

	time.Sleep(15 * time.Millisecond)

	// Дмитрий отправляет сообщение
	_, _ = cDima.Write([]byte("Всем отличного дня!\n"))

	// Елена читает сообщение
	msg, _ := rElena.ReadString('\n')
	fmt.Printf("[Экран Елены] %s", msg)

	close(done)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Экран Елены] [Дмитрий]: Всем отличного дня!
```

## Под капотом

Модель CSP исключает мьютексы: единственная горутина `broadcaster` последовательно владеет мапой клиентов, предотвращая Data Race.

## Подводные камни

Буферизация канала `make(chan string, 10)` в `clientWriter` защищает бродкастер от блокировки при кратковременных задержках сокета.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество архитектуры CSP (Alan Donovan / Brian Kernighan) для чат-сервера перед sync.RWMutex?»
**Ответ:** Она устраняет мьютексы и дедлоки, изолирует ввод-вывод каждого сокета в собственной горутине и позволяет легко реализовать таймауты и отмену через стандартные `select` каналы.
