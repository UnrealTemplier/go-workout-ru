# Потоковый файловый TCP-сервер с передачей содержимого через io.Copy

## Условие

Напиши **TCP-файловый сервер**: клиент отправляет имя файла, сервер открывает файл и отправляет его содержимое через `io.Copy(conn, file)`. Клиент записывает в локальный файл. Обработай ошибки (файл не найден).

## Теория

Потоковая передача файлов по TCP: использование интерфейсов `io.Reader` и `io.Writer` с функцией `io.Copy` обеспечивает передачу файлов любого объема с константным расходом оперативной памяти \(O(1)\) RAM.

## Решение по шагам

1. Создадим виртуальную файловую систему в памяти.
2. Клиент отправляет имя файла `test.txt\n`.
3. Сервер находит файл и транслирует данные через `io.Copy`.
4. Клиент принимает файл и сохраняет в буфер.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"bytes"
	"fmt"
	"io"
	"net"
	"strings"
	"time"
)

func runFileServer(l net.Listener, fileStorage map[string][]byte) {
	for {
		conn, err := l.Accept()
		if err != nil {
			return
		}

		go func(c net.Conn) {
			defer c.Close()
			reader := bufio.NewReader(c)
			filename, err := reader.ReadString('\n')
			if err != nil {
				return
			}

			filename = strings.TrimSpace(filename)
			data, exists := fileStorage[filename]
			if !exists {
				_, _ = c.Write([]byte("ERR: FILE_NOT_FOUND\n"))
				return
			}

			_, _ = c.Write([]byte("OK\n"))
			fileReader := bytes.NewReader(data)
			_, _ = io.Copy(c, fileReader) // Потоковая передача
		}(conn)
	}
}

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	storage := map[string][]byte{
		"report.pdf": []byte("%PDF-1.4 Stream Content of Large Report File"),
	}

	go runFileServer(l, storage)
	time.Sleep(10 * time.Millisecond)

	// Клиент
	conn, err := net.Dial("tcp", l.Addr().String())
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	// Запрашиваем файл
	_, _ = conn.Write([]byte("report.pdf\n"))

	reader := bufio.NewReader(conn)
	status, _ := reader.ReadString('\n')
	if strings.TrimSpace(status) == "OK" {
		var receivedFile bytes.Buffer
		_, _ = io.Copy(&receivedFile, reader)
		fmt.Printf("[File Client] Успешно скачан файл! Содержимое: %s\n", receivedFile.String())
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [File Client] Успешно скачан файл! Содержимое: %PDF-1.4 Stream Content of Large Report File
```

## Под капотом

`io.Copy` переносит байты чанками по 32 КБ без загрузки всего файла в ОЗУ.

## Подводные камни

В реальных файловых серверах валидируйте имя файла от атак Path Traversal (`filepath.Clean` и `strings.Contains(path, "..")`).

## На собеседовании

**Вопрос с собеседования:** «Как системный вызов sendfile(2) на Linux ускоряет передачу файлов по TCP?»
**Ответ:** `sendfile` копирует данные из файлового дескриптора в TCP-сокет напрямую внутри кэша страниц ядра Linux (Page Cache) без переключения контекста и без копирования страниц в пользовательский буфер (True Zero-Copy).
