# Утилита быстрой проверки списка открытых TCP-портов хоста

## Условие

Напишите сканер TCP-портов: проверьте, открыт ли список портов на заданном хосте (с использованием таймаута).

## Теория

Проверка доступности сетевых сервисов (Service Health Check): функция `checkPort(host, port, timeout)` определяет, запущен ли сетевой демон на целевом порту.

## Решение по шагам

1. Поднимем слушатель на порту `A`.
2. Подготовим список портов для проверки: `[A, B, C]`.
3. Опросим порты параллельно через `net.DialTimeout`.
4. Выведем статус каждого порта.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
	"strconv"
	"time"
)

func isPortOpen(host string, port int, timeout time.Duration) bool {
	target := net.JoinHostPort(host, strconv.Itoa(port))
	conn, err := net.DialTimeout("tcp", target, timeout)
	if err != nil {
		return false
	}
	conn.Close()
	return true
}

func main() {
	// Поднимаем один реальный тестовый порт
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	_, pStr, _ := net.SplitHostPort(l.Addr().String())
	activePort, _ := strconv.Atoi(pStr)

	candidatePorts := []int{activePort, 8088, 9099}

	fmt.Println("Проверка доступности портов на 127.0.0.1:")
	for _, p := range candidatePorts {
		status := "ЗАКРЫТ [CLOSED]"
		if isPortOpen("127.0.0.1", p, 30*time.Millisecond) {
			status = "ОТКРЫТ [OPEN/ACTIVE]"
		}
		fmt.Printf(" -> Порт %5d: %s\n", p, status)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Проверка доступности портов на 127.0.0.1:
#  -> Порт 59124: ОТКРЫТ [OPEN/ACTIVE]
#  -> Порт  8088: ЗАКРЫТ [CLOSED]
#  -> Порт  9099: ЗАКРЫТ [CLOSED]
```

## Под капотом

Если порт закрыт, ядро ОС немедленно возвращает TCP RST пакет, и `DialTimeout` завершается за доли миллисекунды.

## Подводные камни

Если между клиентом и сервером стоит фаервол, отбрасывающий пакеты (DROP вместо REJECT), `DialTimeout` будет ждать полный интервал таймаута.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие ответа сетевого экрана REJECT от DROP?»
**Ответ:** При `REJECT` фаервол сразу отправляет TCP RST или ICMP Port Unreachable (клиент мгновенно узнает об ошибке). При `DROP` фаервол молча уничтожает пакет, заставляя клиента ждать истечения таймаута соединения.
