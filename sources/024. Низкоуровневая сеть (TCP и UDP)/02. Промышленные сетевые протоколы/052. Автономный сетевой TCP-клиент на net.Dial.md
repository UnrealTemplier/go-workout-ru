# Автономный сетевой TCP-клиент на net.Dial с валидацией ответа

## Условие

**TCP-клиент**: Напиши отдельную программу. Используй `net.Dial("tcp", "localhost:8080")`. Отправь строку на сервер из упр. 326, прочитай ответ и выведи в консоль.

## Теория

Шаблон надежного сетевого клиента: инициализация через `net.DialTimeout`, отправка форматированного кадра и чтение ответа с обработкой возможных сетевых исключений.

## Решение по шагам

1. Запустим тестовый сервер.
2. Клиент подключается к `127.0.0.1`.
3. Отправляет команду `"PING_SERVER\n"`.
4. Считывает ответ и валидирует статус.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"net"
	"strings"
	"time"
)

func main() {
	// Локальный сервер
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	defer l.Close()

	go func() {
		conn, err := l.Accept()
		if err == nil {
			defer conn.Close()
			_, _ = conn.Write([]byte("PONG_SERVER_STATUS_OK\n"))
		}
	}()

	time.Sleep(10 * time.Millisecond)

	// Автономный клиент
	serverAddr := l.Addr().String()
	conn, err := net.DialTimeout("tcp", serverAddr, 100*time.Millisecond)
	if err != nil {
		fmt.Printf("[Client Error] Не удалось подключиться к %s: %v\n", serverAddr, err)
		return
	}
	defer conn.Close()

	// Отправка строки
	_, err = conn.Write([]byte("GET_STATUS\n"))
	if err != nil {
		fmt.Printf("[Client Error] Ошибка отправки: %v\n", err)
		return
	}

	// Чтение ответа
	reader := bufio.NewReader(conn)
	resp, err := reader.ReadString('\n')
	if err != nil {
		fmt.Printf("[Client Error] Ошибка чтения: %v\n", err)
		return
	}

	fmt.Printf("[TCP Client] Успешный ответ от %s: %s", serverAddr, strings.TrimSpace(resp))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [TCP Client] Успешный ответ от 127.0.0.1:53214: PONG_SERVER_STATUS_OK
```

## Под капотом

`net.DialTimeout` предотвращает блокировку клиента на время сетевого SYN-ретрансмита (до 75 секунд по умолчанию в Linux).

## Подводные камни

Всегда используйте `defer conn.Close()` сразу после успешного `net.Dial`.

## На собеседовании

**Вопрос с собеседования:** «Какое значение таймаута TCP Connect рекомендуется для микросервисов внутри одного датацентра?»
**Ответ:** Не более 50–100 миллисекунд. Внутри одного ДЦ сетевой RTT составляет \(< 1\text{ мс}\), и если сокет не открылся за 100 мс, сервер либо лежит, либо перегружен.
