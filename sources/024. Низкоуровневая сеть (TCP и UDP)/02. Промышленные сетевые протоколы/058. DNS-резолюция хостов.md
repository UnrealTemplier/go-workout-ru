# DNS-резолюция хостов: net.LookupHost и сопоставление IPv4/IPv6

## Условие

Используй `net.LookupHost("google.com")` для получения IP-адресов. Покажи IPv4 и IPv6 адреса.

## Теория

Сетевой DNS-резолвинг в Go: функция `net.LookupHost(host)` запрашивает у системного резолвера или встроенного Go DNS-клиента записи типа A (IPv4) и AAAA (IPv6).

## Решение по шагам

1. Вызовем `net.LookupHost("google.com")` (или локальный mock/localhost).
2. Разделим адреса на IPv4 и IPv6 с помощью `net.ParseIP`.
3. Проверим метод `ip.To4() != nil`.
4. Выведем списки адресов.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
)

func main() {
	host := "localhost"
	addrs, err := net.LookupHost(host)
	if err != nil {
		fmt.Printf("Ошибка DNS: %v\n", err)
		return
	}

	fmt.Printf("DNS-записи для хоста %s:\n", host)

	var ipv4List, ipv6List []string

	for _, addrStr := range addrs {
		ip := net.ParseIP(addrStr)
		if ip == nil {
			continue
		}

		if ip.To4() != nil {
			ipv4List = append(ipv4List, addrStr)
		} else {
			ipv6List = append(ipv6List, addrStr)
		}
	}

	fmt.Printf(" -> IPv4 адреса (A-записи):    %v\n", ipv4List)
	fmt.Printf(" -> IPv6 адреса (AAAA-записи): %v\n", ipv6List)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# DNS-записи для хоста localhost:
#  -> IPv4 адреса (A-записи):    [127.0.0.1]
#  -> IPv6 адреса (AAAA-записи): [::1]
```

## Под капотом

Go имеет встроенный чистый Go DNS-резолвер (Pure Go Resolver), который читает `/etc/resolv.conf`, и CGO-резолвер, использующий системный `getaddrinfo()`.

## Подводные камни

В микросервисах с частыми сетевыми вызовами прямой вызов `LookupHost` на каждый запрос перегрузит DNS-сервер. Для продакшена настраивают локальный DNS-кэш (CoreDNS / nscd).

## На собеседовании

**Вопрос с собеседования:** «Как переключить DNS-резолвер в Go между Pure Go и CGO?»
**Ответ:** С помощью переменной окружения `GODEBUG=netdns=go` (чистый Go резолвер) или `GODEBUG=netdns=cgo` (системный `getaddrinfo` через glibc).
