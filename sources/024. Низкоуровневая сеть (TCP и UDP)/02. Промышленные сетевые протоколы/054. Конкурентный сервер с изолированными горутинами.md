# Конкурентный сервер с изолированными горутинами handleConn

## Условие

**[Каверзный кейс]**: Сделай так, чтобы TCP-сервер мог принимать несколько клиентов одновременно (конкурентно). Используй горутины для каждого нового соединения (`go handleConn(conn)`).

## Теория

Изоляция сетевого контекста: передача каждого сокета в независимую горутину обеспечивает параллельную обработку без блокировок главного диспетчера.

## Решение по шагам

1. Создадим слушатель `net.Listen`.
2. В цикле `Accept()` порождаем `go handleConn(conn)`.
3. Запустим 3 параллельных клиента.
4. Проверим одновременную обработку.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
	"sync"
	"time"
)

func handleConn(conn net.Conn) {
	defer conn.Close()
	buf := make([]byte, 128)
	n, _ := conn.Read(buf)
	_, _ = conn.Write([]byte("HANDLED: " + string(buf[:n])))
}

func main() {
	l, _ := net.Listen("tcp", "127.0.0.1:0")
	defer l.Close()

	go func() {
		for {
			conn, err := l.Accept()
			if err != nil {
				return
			}
			go handleConn(conn)
		}
	}()

	time.Sleep(10 * time.Millisecond)

	var wg sync.WaitGroup
	wg.Add(3)

	for i := 1; i <= 3; i++ {
		go func(id int) {
			defer wg.Done()
			c, _ := net.Dial("tcp", l.Addr().String())
			defer c.Close()
			_, _ = c.Write([]byte(fmt.Sprintf("REQ-%d", id)))
			buf := make([]byte, 128)
			n, _ := c.Read(buf)
			fmt.Printf("[Client] %s\n", string(buf[:n]))
		}(i)
	}

	wg.Wait()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Client] HANDLED: REQ-1
# [Client] HANDLED: REQ-2
# [Client] HANDLED: REQ-3
```

## Под капотом

Каждая горутина выделяет локальный стек и дескриптор сокета, не пересекаясь по памяти с другими клиентами.

## Подводные камни

Не замыкайте переменную `conn` цикла в горутине без передачи аргументом.

## На собеседовании

**Вопрос с собеседования:** «Каковы накладные расходы на создание новой горутины под каждое сетевое соединение в Go?»
**Ответ:** Начальный размер стека горутины в Go составляет всего 2 КБ (с возможностью динамического роста). Время создания горутины — единицы наносекунд, что на несколько порядков легче создания системных потоков ОС (pthread 1–8 МБ).
