# Циклы и индексные переменные в шаблонах (range)

## Условие

**Циклы в шаблонах**: Используйте `{{range .Items}}` для итерации по слайсам/мапам. Покажите работу с переменными `$index` и `$element`, а также ветку `{{else}}` при пустом срезе.

### Исходная формулировка

**Циклы в шаблонах**: Используйте `{{range .Items}}` для итерации по слайсам/мапам.

## Теория

Конструкция `{{range}}` в `text/template`:
- Базовый синтаксис: `{{range .Items}} {{.}} {{end}}` (контекст `.` становится текущим элементом).
- Именование переменных: `{{range $idx, $elem := .Items}}`.
- Проверка первого/последнего элемента: полезно для генерации списков через запятую без висячего разделителя.
- Ветка `{{else}}`: выполняется, если срез равен `nil` или имеет нулевую длину `len == 0`.

## Решение по шагам

1. Создайте шаблон генерации аргументов функции.
2. Проитерируйтесь по срезу с переменными `$i` и `$item`.
3. Сформируйте список аргументов с запятой между элементами `{{if $i}}, {{end}}`.
4. Добавьте ветку `{{else}}` с генерацией комментария об отсутствии элементов.
5. Протестируйте на заполненном и пустом срезах.

## Код решения

**`range_demo.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"text/template"
)

type FunctionSignature struct {
	Name   string
	Params []string
}

const fnTmpl = `func {{.Name}}({{range $i, $param := .Params}}{{if $i}}, {{end}}{{$param}}{{else}}/* no parameters */{{end}}) {
	// Function body
}
`

func main() {
	tmpl := template.Must(template.New("fn").Parse(fnTmpl))

	// Случай 1: Заполненный срез параметров
	fn1 := FunctionSignature{
		Name:   "ProcessTransaction",
		Params: []string{"ctx context.Context", "id int64", "amount float64"},
	}
	var buf1 bytes.Buffer
	_ = tmpl.Execute(&buf1, fn1)
	fmt.Println("--- Case 1 (with params) ---")
	fmt.Println(buf1.String())

	// Случай 2: Пустой срез
	fn2 := FunctionSignature{
		Name:   "Ping",
		Params: nil,
	}
	var buf2 bytes.Buffer
	_ = tmpl.Execute(&buf2, fn2)
	fmt.Println("--- Case 2 (empty params) ---")
	fmt.Println(buf2.String())
}
```

ℹ️ Использование $index, запятых между элементами и ветки else в шаблоне

## Под капотом

Интерпретатор шаблона вычисляет длину среза перед входом в цикл. Если `reflect.Value.Len() == 0`, управление передается узлу `elseList` синтаксического дерева шаблона. Переменная `$i` получает индекс текущей итерации типа `int`, что позволяет легко строить условные конструкции вида `{{if $i}}, {{end}}`.

## Подводные камни

Если внутри цикла `range` обратиться к полю корневой структуры через обычную точку `{{.RootField}}`, шаблон упадет с ошибкой, так как `.` внутри цикла ссылается на элемент итерации. Всегда используйте `$.RootField` для доступа к корню данных.

## На собеседовании

**Вопрос с собеседования:** Как в `text/template` определить, является ли текущий элемент последним в цикле `range`?
**Ответ:** Стандартный `text/template` не предоставляет встроенного флага `isLast`. Общепринятый идиоматический подход — проверять первый элемент: `{{if $i}}, {{end}}{{$item}}` (запятая ставится перед каждым элементом, начиная со второго). Альтернативно передают в шаблон функцию `FuncMap` `isLast(idx, len)`.
