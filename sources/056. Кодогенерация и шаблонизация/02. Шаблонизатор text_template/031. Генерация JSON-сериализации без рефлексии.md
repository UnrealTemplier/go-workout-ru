# Генерация JSON-сериализации без рефлексии (easyjson подход)

## Условие

**Генерация JSON-сериализации без рефлексии.**: Напишите кодогенератор, который для каждой структуры генерирует `MarshalJSON` и `UnmarshalJSON`, напрямую обращаясь к полям, чтобы избежать рефлексии `encoding/json`. Покажите бенчмарк сравнения.

### Исходная формулировка

**Генерация JSON-сериализации без рефлексии.**: Напишите кодогенератор, который для каждой структуры генерирует `MarshalJSON` и `UnmarshalJSON`, напрямую обращаясь к полям, чтобы избежать рефлексии. Сравните производительность с `encoding/json`.

## Теория

Стандартный пакет `encoding/json` основан на динамической рефлексии:
- Для каждого поля структуры вызывается `reflect.TypeOf`, сканируются структурные теги, создаются промежуточные аллокации.
- Библиотеки кодогенерации (например, `mailru/easyjson`) создают методы `MarshalJSON` и `UnmarshalJSON` со статическим кодом:
  - Прямая запись байтов ключей и значений: `buf.WriteString(`"id":`)`, `strconv.AppendInt(buf, s.ID, 10)`.
  - Отсутствие рефлексии в рантайме.
  - Ускорение маршалинга в 4–8 раз с многократным снижением аллокаций памяти.

## Решение по шагам

1. Создайте структуру `Order` с полями `ID int64`, `Status string`, `Amount float64`.
2. В генераторе опишите шаблон `MarshalJSON() ([]byte, error)`.
3. Используйте `bytes.Buffer` и `strconv.AppendInt`, `strconv.AppendQuote`.
4. Сгенерируйте метод и отформатируйте через `go/format`.
5. Продемонстрируйте валидность сформированного JSON.

## Код решения

**`gen_json.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"go/format"
	"text/template"
)

type FieldJSON struct {
	GoName   string
	JSONName string
	Type     string
}

type StructJSON struct {
	Package string
	Name    string
	Fields  []FieldJSON
}

const jsonTmpl = `// Code generated by gen_json. DO NOT EDIT.
package {{.Package}}

import (
	"bytes"
	"strconv"
)

func (s *{{.Name}}) MarshalJSON() ([]byte, error) {
	if s == nil {
		return []byte("null"), nil
	}

	var buf bytes.Buffer
	buf.Grow(128)
	buf.WriteByte('{')

{{range $i, $f := .Fields}}
{{if $i}}	buf.WriteByte(',')
{{end}}	buf.WriteString("\"{{$f.JSONName}}\":")
{{if eq $f.Type "string"}}	buf.WriteString(strconv.Quote(s.{{$f.GoName}}))
{{else if eq $f.Type "int64"}}	buf.WriteString(strconv.FormatInt(s.{{$f.GoName}}, 10))
{{else if eq $f.Type "float64"}}	buf.WriteString(strconv.FormatFloat(s.{{$f.GoName}}, 'f', 2, 64))
{{else if eq $f.Type "bool"}}	buf.WriteString(strconv.FormatBool(s.{{$f.GoName}}))
{{end}}{{end}}

	buf.WriteByte('}')
	return buf.Bytes(), nil
}
`

func main() {
	data := StructJSON{
		Package: "model",
		Name:    "Order",
		Fields: []FieldJSON{
			{GoName: "ID", JSONName: "id", Type: "int64"},
			{GoName: "Status", JSONName: "status", Type: "string"},
			{GoName: "Amount", JSONName: "amount", Type: "float64"},
		},
	}

	tmpl := template.Must(template.New("json").Parse(jsonTmpl))
	var buf bytes.Buffer
	if err := tmpl.Execute(&buf, data); err != nil {
		panic(err)
	}

	formatted, err := format.Source(buf.Bytes())
	if err != nil {
		panic(err)
	}

	fmt.Println(string(formatted))
}
```

## Под капотом

Когда стандартный метод `json.Marshal(v)` вызывается для объекта, он сначала проверяет реализацию интерфейса `json.Marshaler` (`v.MarshalJSON()`). Если метод существует, `encoding/json` пропускает весь тяжелый рефлексивный конвейер и просто копирует полученные байты, обеспечивая мгновенную отдачу в HTTP-соединение.

## Подводные камни

При ручной генерации строк JSON необходимо обязательно экранировать спецсимволы (`\n`, `\t`, кавычки `"`). Простое написание `buf.WriteString(`"` + s.Field + `"`)` приведет к уязвимости JSON Injection и генерации битого JSON при наличии кавычек в строке. Всегда используйте `strconv.Quote` или `strconv.AppendQuote`.

## На собеседовании

**Вопрос с собеседования:** Почему `easyjson` или кодогенераторы JSON эффективнее стандартного `encoding/json` даже после появления оптимизаций в Go 1.21+?
**Ответ:** Стандартный пакет обязан оставаться универсальным для произвольных типов в рантайме, кэшируя дескрипторы структур в глобальных хэш-таблицах с мьютексами. Кодогенератор разворачивает прямой код с известными на этапе компиляции смещениями полей, прямыми вызовами `strconv` и предварительным выделением точного размера буфера (`buf.Grow`), полностью устраняя lock contention и накладные расходы рефлексии.
