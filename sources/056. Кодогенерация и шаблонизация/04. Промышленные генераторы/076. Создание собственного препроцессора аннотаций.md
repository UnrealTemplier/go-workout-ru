# Создание собственного препроцессора аннотаций (@inject Logger)

## Условие

**Создание собственного препроцессора аннотаций.**: Напишите инструмент, который сканирует комментарии вида `// @inject Logger` в структурах и генерирует файл с функцией, создающей структуру и автоматически внедряющей все зависимости.

### Исходная формулировка

**Создание собственного препроцессора аннотаций.**: Напишите инструмент, который сканирует комментарии вида `// @inject Logger` в структурах и генерирует файл с функцией, создающей экземпляр структуры с проставленными зависимостями (DI-контейнер).

## Теория

Препроцессинг кастомных аннотаций в комментариях (`// @inject`, `// @validate`, `// @cache`):
- Сканирование файлов через `parser.ParseDir`.
- Извлечение комментариев `ast.CommentGroup`.
- Поиск строк с префиксом `// @inject <DependencyName>`.
- Автоматическая генерация функции-конструктора `New<StructName>(dep1, dep2, ...) *<StructName>`, связывающей поля структуры с внедренными зависимостями.

## Решение по шагам

1. Создайте структуру `OrderProcessor` с комментарием `// @inject Logger` и `// @inject Metrics`.
2. Распарсите комментарии через `parser.ParseComments`.
3. Извлеките имена инжектируемых зависимостей.
4. Сгенерируйте конструктор `NewOrderProcessor(logger Logger, metrics Metrics)`.
5. Отформатируйте сгенерированный код через `format.Source`.

## Код решения

**`annotation_processor.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"go/ast"
	"go/format"
	"go/parser"
	"go/token"
	"strings"
	"text/template"
)

type InjectionMeta struct {
	Package    string
	TargetName string
	Injections []string
}

const injectTmpl = `// Code generated by annotation_processor. DO NOT EDIT.
package {{.Package}}

func New{{.TargetName}}({{range $i, $inj := .Injections}}{{if $i}}, {{end}}{{lower $inj}} {{$.Package}}.{{$inj}}{{end}}) *{{.TargetName}} {
	return &{{.TargetName}}{
{{range .Injections}}		{{lower .}}: {{lower .}},
{{end}}	}
}
`

func main() {
	src := `package service

// @inject Logger
// @inject MetricClient
type OrderProcessor struct {
	logger       Logger
	metricClient MetricClient
}
`
	fset := token.NewFileSet()
	fileNode, err := parser.ParseFile(fset, "proc.go", src, parser.ParseComments)
	if err != nil {
		panic(err)
	}

	data := InjectionMeta{
		Package:    fileNode.Name.Name,
		TargetName: "OrderProcessor",
	}

	for _, decl := range fileNode.Decls {
		gd, ok := decl.(*ast.GenDecl)
		if !ok || gd.Doc == nil {
			continue
		}

		for _, c := range gd.Doc.List {
			text := strings.TrimSpace(c.Text)
			if strings.HasPrefix(text, "// @inject") {
				dep := strings.TrimSpace(strings.TrimPrefix(text, "// @inject"))
				data.Injections = append(data.Injections, dep)
			}
		}
	}

	funcMap := template.FuncMap{
		"lower": strings.ToLower,
	}

	tmpl := template.Must(template.New("inj").Funcs(funcMap).Parse(injectTmpl))
	var buf bytes.Buffer
	if err := tmpl.Execute(&buf, data); err != nil {
		panic(err)
	}

	formatted, err := format.Source(buf.Bytes())
	if err != nil {
		panic(err)
	}

	fmt.Println(string(formatted))
}
```

ℹ️ Препроцессор аннотаций в комментариях и генерация конструктора внедрения зависимостей

## Под капотом

Синтаксис аннотаций в комментариях вида `// @tag value` не нарушает стандартный парсер Go, так как компилятор видит их как обычные комментарии. Препроцессор извлекает их из AST-списка `ast.CommentGroup.List`, открывая широкие возможности для расширения семантики языка без модификации компилятора.

## Подводные камни

В именовании зависимостей `MetricClient -> metricclient` простое приведение к нижнему регистру `strings.ToLower` ломает camelCase (`metricClient`). В реальных генераторах применяют `unicode.ToLower(rune(s[0])) + s[1:]`.

## На собеседовании

**Вопрос с собеседования:** Как устроен препроцессор аннотаций в генераторе документации Swagger / OpenAPI (`swag`)?
**Ответ:** Утилита `swag` сканирует исходники пакетов, находит комментарии вида `@Summary`, `@Param`, `@Success` перед функциями HTTP-хэндлеров, парсит их регулярными выражениями и генерирует единую спецификацию `swagger.json`, а также маршруты отдачи UI `http.Handle("/swagger/...")`.
