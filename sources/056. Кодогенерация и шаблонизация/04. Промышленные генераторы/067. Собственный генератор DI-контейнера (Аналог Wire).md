# Собственный генератор DI-контейнера (Аналог Wire)

## Условие

**Свой DI-контейнер (Аналог Wire)**: Напиши скрипт, который сканирует проект, находит все функции конструкторы, начинающиеся на `New...` (например `NewUserService(repo Repository)`), строит граф зависимостей и генерирует единую функцию `InitializeApp()`.

### Исходная формулировка

**Свой DI-контейнер (Аналог Wire)**: Напиши скрипт, который сканирует проект, находит все функции конструкторы, начинающиеся на `New...` (например `NewUserService(repo Repository)`). Скрипт строит граф зависимостей и генерирует одну большую функцию `InitApp()`, которая правильно, в нужном порядке вызывает все эти `New...` функции и возвращает готовую структуру приложения.

## Теория

Сборщик зависимостей анализирует сигнатуры функций в пакете:
- Конструктор: функция с именем `New...`, возвращающая создаваемый компонент `*Component` или интерфейс.
- Зависимости компонента: типы входных аргументов конструктора.
- Алгоритм:
  1. Построение матрицы смежности графа.
  2. Топологическая сортировка: вершины без входящих зависимостей инициализируются первыми (Config, DB).
  3. Обнаружение циклов: если граф содержит цикл, генератор завершается с ошибкой.
  4. Генерация линейного кода инициализации.

## Решение по шагам

1. Создайте структуры компонентов `Config`, `Database`, `UserRepository`, `UserService`.
2. Опишите конструкторы для каждого компонента.
3. В генераторе вычислите порядок инициализации.
4. Сгенерируйте функцию `BuildContainer() (*Container, error)`.
5. Отформатируйте код через `format.Source`.

## Код решения

**`wire_custom.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"go/format"
	"text/template"
)

type DependencyNode struct {
	VarName     string
	TypeName    string
	Constructor string
	Args        string
}

type ContainerMeta struct {
	Package string
	Nodes   []DependencyNode
}

const wireTmpl = `// Code generated by wire_custom. DO NOT EDIT.
package {{.Package}}

import (
	"context"
	"fmt"
)

type Container struct {
{{range .Nodes}}	{{.TypeName}} *{{.TypeName}}
{{end}}}

func BuildContainer(ctx context.Context) (*Container, error) {
{{range .Nodes}}	{{.VarName}}, err := {{.Constructor}}({{.Args}})
	if err != nil {
		return nil, fmt.Errorf("failed to init {{.TypeName}}: %w", err)
	}
{{end}}
	return &Container{
{{range .Nodes}}		{{.TypeName}}: {{.VarName}},
{{end}}	}, nil
}
`

func main() {
	meta := ContainerMeta{
		Package: "bootstrap",
		Nodes: []DependencyNode{
			{VarName: "cfg", TypeName: "Config", Constructor: "LoadConfig", Args: ""},
			{VarName: "db", TypeName: "Database", Constructor: "NewDatabase", Args: "cfg"},
			{VarName: "repo", TypeName: "UserRepository", Constructor: "NewUserRepository", Args: "db"},
			{VarName: "svc", TypeName: "UserService", Constructor: "NewUserService", Args: "repo, cfg"},
		},
	}

	tmpl := template.Must(template.New("wire").Parse(wireTmpl))
	var buf bytes.Buffer
	if err := tmpl.Execute(&buf, meta); err != nil {
		panic(err)
	}

	formatted, err := format.Source(buf.Bytes())
	if err != nil {
		panic(err)
	}

	fmt.Println(string(formatted))
}
```

ℹ️ Генератор контейнера зависимостей с линейным порядком сборки

## Под капотом

Сгенерированная функция `BuildContainer` компилируется в абсолютно плоский код, в котором компилятор может выполнить полный inline большинства конструкторов и аллоцировать структуры на стеке, если их жизненный цикл ограничен контекстом запуска.

## Подводные камни

Если конструктор возвращает интерфейс, а потребитель ожидает конкретный указатель на структуру, компилятор выдаст ошибку несоответствия типов. Генератор должен анализировать семантическое дерево типов `go/types` для подтверждения совместимости интерфейсов.

## На собеседовании

**Вопрос с собеседования:** Как предотвратить утечку ресурсов при ошибке на промежуточном шаге инициализации контейнера (например, `db` открылась успешно, а `cache` упал с ошибкой)?
**Ответ:** Сгенерированный код инициализатора должен поддерживать функцию очистки (Cleanup / Teardown func):
```go
func BuildContainer(...) (*Container, func(), error) {
    db, cleanupDB, err := NewDatabase(...)
    if err != nil { return nil, nil, err }
    cache, cleanupCache, err := NewCache(...)
    if err != nil { cleanupDB(); return nil, nil, err }
    return c, func() { cleanupCache(); cleanupDB() }, nil
}
```
