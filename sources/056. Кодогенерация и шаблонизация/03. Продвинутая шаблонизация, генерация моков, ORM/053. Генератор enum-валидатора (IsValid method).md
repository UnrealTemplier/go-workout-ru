# Генератор enum-валидатора (IsValid method)

## Условие

**Генератор enum-валидатора.**: Напишите tool, который для типа `type Role int` с константами генерирует метод `IsValid() bool`, проверяющий, что значение входит в допустимый диапазон/множество констант.

### Исходная формулировка

**Генератор enum-валидатора.**: Напишите tool, который для типа `type Role int` с константами генерирует метод `IsValid() bool`, проверяющий, что значение входит в допустимый диапазон. Используйте `go/constant` для вычисления значений `iota` во время генерации.

## Теория

Пользовательские целочисленные типы в Go (`type Role int`) не защищены от невалидных значений: любой внешний код может сделать приведение `Role(999)`, которое успешно пройдет компиляцию, но сломает бизнес-логику авторизации.

Генератор валидатора:
- Сканирует все константы типа `Role`.
- Если константы последовательны (\(0 \dots N\)): генерирует проверку границ `r >= RoleMin && r <= RoleMax`.
- Если константы разрежены: генерирует `switch r { case RoleAdmin, RoleUser: return true; default: return false }`.

## Решение по шагам

1. Создайте файл `role.go` с константами `RoleUser`, `RoleAdmin`, `RoleModerator`.
2. В генераторе извлеките константы.
3. Сформируйте метод `IsValid() bool`.
4. Сгенерируйте файл `role_validator_gen.go` и отформатируйте через `format.Source`.

## Код решения

**`gen_validator.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"go/format"
	"text/template"
)

type EnumValidationData struct {
	Package   string
	TypeName  string
	Constants []string
}

const validTmpl = `// Code generated by gen_validator. DO NOT EDIT.
package {{.Package}}

func (v {{.TypeName}}) IsValid() bool {
	switch v {
{{range .Constants}}	case {{.}}:
		return true
{{end}}	default:
		return false
	}
}
`

func main() {
	data := EnumValidationData{
		Package:  "auth",
		TypeName: "Role",
		Constants: []string{
			"RoleGuest",
			"RoleUser",
			"RoleModerator",
			"RoleAdmin",
		},
	}

	tmpl := template.Must(template.New("validator").Parse(validTmpl))
	var buf bytes.Buffer
	if err := tmpl.Execute(&buf, data); err != nil {
		panic(err)
	}

	formatted, err := format.Source(buf.Bytes())
	if err != nil {
		panic(err)
	}

	fmt.Println(string(formatted))
}
```

## Под капотом

Конструкция `switch` по целочисленным константам компилируется компилятором Go в прямую проверку битовой маски или проверку диапазона `CMPQ / JBE`, выполняясь за 1–2 процессорных такта без ветвлений и без выделения памяти.

## Подводные камни

Если разработчик добавляет новую константу в блок `const`, но забывает перезапустить `go generate`, метод `IsValid()` вернет `false` для валидной константы. Для защиты генератор связывают с compile-time assert из `stringer`.

## На собеседовании

**Вопрос с собеседования:** Почему в Go валидацию энумов на входе HTTP/gRPC API считают обязательным требованием информационной безопасности?
**Ответ:** Если невалидное значение энума (`Role(-1)`) просочится во внутренние сервисы, оно может обойти проверки доступа вида `if role != RoleAdmin { deny }` или вызвать непреднамеренное переполнение индексов массивов прав в рантайме, что классифицируется как уязвимость Broken Access Control (OWASP Top 10).
