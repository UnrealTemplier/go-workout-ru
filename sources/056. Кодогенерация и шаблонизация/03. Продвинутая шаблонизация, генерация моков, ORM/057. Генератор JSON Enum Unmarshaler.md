# Генератор JSON Enum Unmarshaler (парсинг строк в числовой enum)

## Условие

**Генератор JSON Enum (Unmarshaler)**: Стандартный `json.Unmarshal` парсит числа, а тебе нужно, чтобы клиент присылал строки `"PENDING"`, а в Go это превращалось в константу `1`. Напиши генератор `MarshalJSON`/`UnmarshalJSON` для enum-типа.

### Исходная формулировка

**Генератор JSON Enum (Unmarshaler)**: Стандартный `json.Unmarshal` парсит числа, а тебе нужно, чтобы клиент присылал строки `"PENDING"`, а в Go это превращалось в константу `1`. Напиши кодогенератор, который по AST констант-перечислений генерирует для них методы `MarshalJSON` и `UnmarshalJSON`.

## Теория

В REST API принято обмениваться читаемыми строковыми литералами (`"PENDING"`, `"PAID"`), а не «магическими» числами (`1`, `2`).

Реализация в Go:
- Тип `type OrderStatus int`.
- Метод `MarshalJSON() ([]byte, error)` сериализует константу в строку `"PENDING"`.
- Метод `UnmarshalJSON(data []byte)` принимает срез байт JSON, снимает кавычки, сопоставляет со строковыми константами и записывает соответствующее числовое значение в получатель `*OrderStatus`.

## Решение по шагам

1. Создайте энум `OrderStatus` с константами `StatusPending = 1`, `StatusCompleted = 2`.
2. В шаблоне сгенерируйте метод `MarshalJSON` с возвратом кавычек.
3. В методе `UnmarshalJSON` распарсите JSON-строку и выполните `switch`.
4. Отформатируйте код через `format.Source`.

## Код решения

**`gen_json_enum.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"go/format"
	"text/template"
)

type EnumItem struct {
	ConstName string
	JSONStr   string
}

type JSONEnumMeta struct {
	Package  string
	TypeName string
	Items    []EnumItem
}

const jsonEnumTmpl = `// Code generated by gen_json_enum. DO NOT EDIT.
package {{.Package}}

import (
	"bytes"
	"errors"
	"fmt"
)

var ErrUnknown{{.TypeName}} = errors.New("unknown {{.TypeName}} string value")

func (e {{.TypeName}}) MarshalJSON() ([]byte, error) {
	switch e {
{{range .Items}}	case {{.ConstName}}:
		return []byte("\"{{.JSONStr}}\""), nil
{{end}}	default:
		return nil, fmt.Errorf("invalid {{.TypeName}} value: %d", e)
	}
}

func (e *{{.TypeName}}) UnmarshalJSON(data []byte) error {
	data = bytes.Trim(data, "\"")
	switch string(data) {
{{range .Items}}	case "{{.JSONStr}}":
		*e = {{.ConstName}}
		return nil
{{end}}	default:
		return fmt.Errorf("%w: %s", ErrUnknown{{.TypeName}}, string(data))
	}
}
`

func main() {
	meta := JSONEnumMeta{
		Package:  "orders",
		TypeName: "OrderStatus",
		Items: []EnumItem{
			{ConstName: "StatusPending", JSONStr: "PENDING"},
			{ConstName: "StatusCompleted", JSONStr: "COMPLETED"},
			{ConstName: "StatusCancelled", JSONStr: "CANCELLED"},
		},
	}

	tmpl := template.Must(template.New("enum_json").Parse(jsonEnumTmpl))
	var buf bytes.Buffer
	if err := tmpl.Execute(&buf, meta); err != nil {
		panic(err)
	}

	formatted, err := format.Source(buf.Bytes())
	if err != nil {
		panic(err)
	}

	fmt.Println(string(formatted))
}
```

## Под капотом

Снятие кавычек через `bytes.Trim(data, "\"")` работает без выделения памяти в куче: возвращается суб-срез оригинального массива байт. Приведение `string(data)` в ветке `switch string(data)` оптимизируется компилятором Go, который не создает аллокацию строки при сравнении в блоке switch.

## Подводные камни

Метод `UnmarshalJSON` обязан иметь получатель по указателю `(e *OrderStatus)`. Если сделать получатель по значению `(e OrderStatus)`, изменение `*e = ...` будет происходить с локальной копией, и значение в целевой структуре останется нулевым!

## На собеседовании

**Вопрос с собеседования:** Почему вместо кастомных `MarshalJSON` и `UnmarshalJSON` для энумов часто реализуют `encoding.TextMarshaler` и `encoding.TextUnmarshaler`?
**Ответ:** Интерфейсы `MarshalText` / `UnmarshalText` универсальны: они автоматически подхватываются не только пакетом `encoding/json`, но и `gopkg.in/yaml.v3`, `encoding/xml`, а также драйверами баз данных `database/sql` и роутерами параметров URL query string, обеспечивая поддержку всех транспортов одной парой методов.
