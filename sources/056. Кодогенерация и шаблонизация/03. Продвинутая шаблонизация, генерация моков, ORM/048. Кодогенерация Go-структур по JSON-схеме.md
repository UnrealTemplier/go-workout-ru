# Кодогенерация Go-структур по JSON-схеме (JSON Schema to Go)

## Условие

**Кодогенерация Go-структур по JSON-схеме**: Напишите скрипт, который считывает входящий JSON-файл, описывающий схему базы данных или структуру API-ответа (например, имена полей и их типы), и автоматически создает `.go` файл с соответствующей Go-структурой и JSON-тегами.

### Исходная формулировка

**Кодогенерация Go-структур по JSON-схеме**: Напишите скрипт, который считывает входящий JSON-файл, описывающий схему базы данных или структуру API-ответа (например, имена полей и их типы). Скрипт должен автоматически сгенерировать валидный файл кода Go (`models.go`) с объявлением соответствующих структур и корректно расставленными тегами для JSON-сериализации (`json:"field_name"`).

## Теория

Генерация структур по контрактам (JSON Schema, OpenAPI, Protobuf, Avro) — фундамент контрактно-ориентированной разработки (Contract-First API Design).

Процесс генерации:
1. Чтение файла схемы JSON: `json.Unmarshal`.
2. Сопоставление типов JSON с типами Go:
   - `"string"` -> `string`
   - `"integer"` -> `int64`
   - `"number"` -> `float64`
   - `"boolean"` -> `bool`
   - `"array"` -> `[]<ItemType>`
3. Формирование структурных тегов `json:"fieldName"`.
4. Рендеринг шаблона и форматирование через `go/format`.

## Решение по шагам

1. Создайте файл `schema.json` с описанием сущности `UserAccount`.
2. Распарсите JSON-схему в генераторе.
3. Преобразуйте типы JSON в типы данных Go.
4. Сгенерируйте файл модели структуры с тегами.
5. Отформатируйте результат через `format.Source`.

## Код решения

**`schema_to_go.go`**

```go
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"go/format"
	"strings"
	"text/template"
)

type SchemaField struct {
	Type string `json:"type"`
}

type JSONSchema struct {
	Title      string                 `json:"title"`
	Properties map[string]SchemaField `json:"properties"`
}

type GoField struct {
	Name     string
	Type     string
	JSONName string
}

type GoStructData struct {
	Package string
	Name    string
	Fields  []GoField
}

const structTmpl = `// Code generated by schema_to_go. DO NOT EDIT.
package {{.Package}}

type {{.Name}} struct {
{{range .Fields}}	{{.Name}} {{.Type}} ` + "`" + `json:"{{.JSONName}}"` + "`" + `
{{end}}}
`

func jsonTypeToGo(t string) string {
	switch t {
	case "integer":
		return "int64"
	case "number":
		return "float64"
	case "boolean":
		return "bool"
	default:
		return "string"
	}
}

func main() {
	schemaRaw := []byte(`{
		"title": "UserProfile",
		"properties": {
			"user_id": {"type": "integer"},
			"username": {"type": "string"},
			"rating": {"type": "number"},
			"is_verified": {"type": "boolean"}
		}
	}`)

	var schema JSONSchema
	if err := json.Unmarshal(schemaRaw, &schema); err != nil {
		panic(err)
	}

	data := GoStructData{
		Package: "dto",
		Name:    schema.Title,
	}

	for fieldName, prop := range schema.Properties {
		// Преобразование snake_case в CamelCase
		parts := strings.Split(fieldName, "_")
		for i := range parts {
			parts[i] = strings.Title(parts[i])
		}
		goName := strings.Join(parts, "")

		data.Fields = append(data.Fields, GoField{
			Name:     goName,
			Type:     jsonTypeToGo(prop.Type),
			JSONName: fieldName,
		})
	}

	tmpl := template.Must(template.New("schema").Parse(structTmpl))
	var buf bytes.Buffer
	if err := tmpl.Execute(&buf, data); err != nil {
		panic(err)
	}

	formatted, err := format.Source(buf.Bytes())
	if err != nil {
		panic(err)
	}

	fmt.Println(string(formatted))
}
```

ℹ️ Генерация Go-структур с тегами из описания JSON Schema

**`Терминал`**

```bash
go run schema_to_go.go
# // Code generated by schema_to_go. DO NOT EDIT.
# package dto
# 
# type UserProfile struct {
# 	IsVerified bool    `json:"is_verified"`
# 	Rating     float64 `json:"rating"`
# 	UserId     int64   `json:"user_id"`
# 	Username   string  `json:"username"`
# }
```

## Под капотом

Для сохранения детерминизма сгенерированного кода срез `data.Fields` сортируют по алфавиту имен полей перед выполнением шаблона, так как перебор ключей `schema.Properties` мапы в рантайме Go намеренно рандомизирован.

## Подводные камни

В спецификации JSON Schema поля могут быть опциональными (`required: [...]`). Опциональные поля примитивных типов должны генерироваться как указатели `*string` или `*int64`, иначе невозможно отличить отсутствующее поле от переданного нулевого значения (`0` или `""`).

## На собеседовании

**Вопрос с собеседования:** Почему в межсервисном взаимодействии крупных enterprise-систем контракт OpenAPI/Protobuf генерирует структуры, а не наоборот (код генерирует документацию)?
**Ответ:** Принцип Single Source of Truth: схема API в репозитории контрактов является единым источником правды для бэкенда на Go, мобильных клиентов на Swift/Kotlin и фронтенда на TypeScript. Изменение схемы в одном месте и регенерация клиентов гарантирует строгую согласованность контрактов во всей компании.
