# Автоматическое форматирование сгенерированного кода (go/format)

## Условие

**Форматирование кода**: Используйте `go/format.Source()` для auto-formatting сгенерированного кода через gofmt.

## Теория

Пакет `go/format` реализует канонический алгоритм форматирования `gofmt`:
- Преобразует срез байт `src []byte` в строго форматированный Go-код.
- Автоматически выравнивает столбцы объявлений констант и полей структур.
- Заменяет пробелы в начале строк на табы (табуляция шириной 8 по спецификации Go).
- Если в коде есть синтаксическая ошибка, функция `format.Source` возвращает точное смещение ошибки в байтах и текст синтаксического расхождения.

## Решение по шагам

1. Создайте «кривой» код программы с хаотичными пробелами и отступами.
2. Передайте байты в `format.Source(ugly)`.
3. Сравните сырой и отформатированный код.
4. Проверьте обработку синтаксической ошибки.

## Код решения

**`formatter_demo.go`**

```go
package main

import (
	"fmt"
	"go/format"
)

func main() {
	uglySource := []byte(`package    main
import "fmt"
type User    struct{
ID int64
Name string
}
func (u *User)   Greet(){
fmt.Println("Hi,",u.Name)
}
`)

	cleanSource, err := format.Source(uglySource)
	if err != nil {
		panic(err)
	}

	fmt.Println("=== BEFORE FORMATTING ===")
	fmt.Println(string(uglySource))

	fmt.Println("=== AFTER go/format.Source ===")
	fmt.Println(string(cleanSource))
}
```

ℹ️ Демонстрация выравнивания синтаксиса через go/format.Source

## Под капотом

`go/format.Source` выполняет парсинг байтов через `parser.ParseFile` с флагом `parser.ParseComments`, строит синтаксическое дерево AST, а затем сериализует его с помощью `printer.Fprint` в конфигурации `printer.TabIndent | printer.UseSpaces`. Это гарантирует 100% идентичность утилите `gofmt` командной строки.

## Подводные камни

`format.Source` требует, чтобы переданный фрагмент кода был полным валидным Go-файлом (начиная с `package ...`). Если передать изолированное тело функции или выражение без объявления пакета, парсер вернет ошибку `expected 'package', found 'func'`.

## На собеседовании

**Вопрос с собеседования:** Как отформатировать изолированное выражение или отдельную функцию без `package`?
**Ответ:** Обернуть фрагмент во временную заготовку `package p; func _() { <expression> }`, передать в `format.Source`, а затем вырезать обертку из полученного среза байт, либо использовать `go/printer.Fprint` с узлом конкретного AST-выражения.
