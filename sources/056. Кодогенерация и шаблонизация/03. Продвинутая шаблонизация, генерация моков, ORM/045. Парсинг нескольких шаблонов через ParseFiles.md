# Парсинг нескольких шаблонов через ParseFiles и ParseGlob

## Условие

**Парсинг нескольких шаблонов**: Используйте `ParseFiles` или `ParseGlob` для загрузки шаблонов из файлов.

## Теория

Для модульной структуры кодогенератора файлы шаблонов группируют по папкам:
- `template.ParseFiles("tmpl/header.tmpl", "tmpl/body.tmpl", "tmpl/footer.tmpl")`: загрузка явного списка файлов.
- `template.ParseGlob("templates/*.tmpl")`: загрузка всех файлов по глоб-паттерну.
- Все распарсенные файлы объединяются в единое дерево шаблонов, где имя каждого шаблона соответствует имени файла (`filepath.Base(path)`).

## Решение по шагам

1. Создайте каталог `templates`.
2. Создайте файлы `header.gotmpl` и `entity.gotmpl`.
3. Вызовите `template.ParseGlob("templates/*.gotmpl")`.
4. Запустите выполнение корневого шаблона через `tmpl.ExecuteTemplate(wr, "entity.gotmpl", data)`.
5. Отформатируйте результат через `format.Source`.

## Код решения

**`glob_demo.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"go/format"
	"os"
	"path/filepath"
	"text/template"
)

type EntityData struct {
	Package string
	Name    string
}

func main() {
	tmpDir, err := os.MkdirTemp("", "templates_*")
	if err != nil {
		panic(err)
	}
	defer os.RemoveAll(tmpDir)

	headerContent := `// Code generated by glob_demo. DO NOT EDIT.
package {{.Package}}
`
	entityContent := `{{template "header.tmpl" .}}

type {{.Name}}DTO struct {
	ID string
}
`

	_ = os.WriteFile(filepath.Join(tmpDir, "header.tmpl"), []byte(headerContent), 0644)
	entityPath := filepath.Join(tmpDir, "entity.tmpl")
	_ = os.WriteFile(entityPath, []byte(entityContent), 0644)

	pattern := filepath.Join(tmpDir, "*.tmpl")
	tmpl, err := template.ParseGlob(pattern)
	if err != nil {
		panic(err)
	}

	data := EntityData{
		Package: "transport",
		Name:    "Payment",
	}

	var buf bytes.Buffer
	if err := tmpl.ExecuteTemplate(&buf, "entity.tmpl", data); err != nil {
		panic(err)
	}

	formatted, err := format.Source(buf.Bytes())
	if err != nil {
		panic(err)
	}

	fmt.Println(string(formatted))
}
```

## Под капотом

`ParseGlob` использует `filepath.Glob` для поиска файлов на диске. Для каждого найденного файла вызывается внутренний метод `t.New(filepath.Base(path)).Parse(content)`. При вызове `ExecuteTemplate(wr, "entity.tmpl", data)` движок ищет шаблон именно по базовому имени файла в реестре.

## Подводные камни

Если в разных подкаталогах лежат файлы с одинаковым именем (`auth/view.tmpl` и `users/view.tmpl`), вызов `ParseGlob` приведет к коллизии: второй файл перезапишет первый в реестре, так как ключом является только базовое имя `view.tmpl`. В таких случаях используют `template.ParseFS` с сохранением полных путей.

## На собеседовании

**Вопрос с собеседования:** Чем `tmpl.Execute()` отличается от `tmpl.ExecuteTemplate()`?
**Ответ:** `tmpl.Execute(wr, data)` выполняет самый первый (корневой) шаблон в наборе. Если шаблоны загружались группой через `ParseFiles` или `ParseGlob`, неизвестно, какой файл стал первым. Метод `tmpl.ExecuteTemplate(wr, "name", data)` позволяет явно указать точку входа генерации по имени шаблона.
