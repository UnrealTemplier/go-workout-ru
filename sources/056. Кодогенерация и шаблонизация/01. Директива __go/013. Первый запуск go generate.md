# Первый запуск go generate и базовый рабочий процесс

## Условие

**Первый generate**: Добавьте `//go:generate echo "Hello from generate"` в код и запустите `go generate`.

## Теория

Команда `go generate` выполняет синтаксический разбор файлов только на предмет специальных комментариев.

Особенности выполнения:
- Не выполняет компиляцию кода пакета.
- Выполняет команды от имени текущего пользователя ОС.
- Передает в дочерний процесс переменные среды Go toolchain: `$GOFILE`, `$GOPACKAGE`, `$GOLINE`.

## Решение по шагам

1. Создайте модуль `demo`.
2. Создайте файл `service.go` с комментарием `//go:generate echo "Hello from generate"`.
3. Запустите в терминале команду `go generate service.go`.
4. Убедитесь в корректном выводе строки.

## Код решения

**`service.go`**

```go
//go:generate echo "Hello from generate"
package demo

import "fmt"

func Greet() {
	fmt.Println("Service initialized")
}
```

ℹ️ Файл service.go с базовой директивой go:generate

**`Терминал`**

```bash
# Запуск генерации конкретного файла
go generate service.go
# Hello from generate

# Запуск генерации текущего пакета
go generate .
# Hello from generate
```

## Под капотом

`go generate` сканирует файл построчно до конца файла, не останавливаясь после блока `package`. Это позволяет размещать директивы `//go:generate` непосредственно над структурами, интерфейсами или константами, для которых они предназначены.

## Подводные камни

Если забыть кавычки в аргументах команды с пробелами (`//go:generate echo Hello from generate`), аргументы будут переданы как отдельные позиционные параметры `args[0] = Hello`, `args[1] = from` и т.д. Для сложных команд обязательно экранируйте строки.

## На собеседовании

**Вопрос с собеседования:** В каком порядке `go generate` обходит пакеты и файлы проекта?
**Ответ:** Порядок обхода строго детерминирован: пакеты обходятся в лексикографическом порядке их путей импорта. Внутри пакета файлы обрабатываются в алфавитном порядке имен файлов. Внутри одного файла директивы выполняются последовательно сверху вниз. Межпакетный параллелизм в `go generate` отсутствует, гарантируя предсказуемость сборки.
