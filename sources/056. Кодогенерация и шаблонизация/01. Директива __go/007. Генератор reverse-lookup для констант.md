# Генератор reverse-lookup для констант (ParseStatus и AllStatuses)

## Условие

**Генератор reverse-lookup для констант.**: Напишите генератор, который для `const` блока создаёт функцию `ParseStatus(s string) (Status, error)` и `AllStatuses() []Status`. Используйте `go/ast` для чтения и `text/template` для генерации.

## Теория

При разработке API часто требуется не только преобразовать константу в строку (`String()`), но и распарсить строку из внешнего HTTP-запроса или JSON обратно в строго типизированный энум (`ParseStatus(s string)`), а также получить полный список допустимых значений для валидации или Swagger/OpenAPI (`AllStatuses() []Status`).

Такой функционал генерируется статически:
- Срез `AllStatuses()` инициализируется предопределенным слайсом констант.
- Функция `ParseStatus` строится через конструкцию `switch s` или мапу быстрого поиска `map[string]Status`.

## Решение по шагам

1. Создайте структуру шаблона с полями `TypeName`, `Constants` и именем функции парсинга.
2. Распарсите файл с константами через `go/parser`.
3. Сформируйте имена констант и их строковые эквиваленты.
4. В шаблоне создайте функцию `Parse<Type>(s string) (<Type>, error)` с явной ошибкой `ErrInvalid<Type>`.
5. Сгенерируйте функцию `All<Type>s() []<Type>`.
6. Отформатируйте сгенерированный код через `go/format`.

## Код решения

**`gen_enum_helpers.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"go/format"
	"text/template"
)

type EnumMetadata struct {
	PackageName string
	TypeName    string
	Values      []string
}

const enumHelperTmpl = `// Code generated by gen_enum_helpers. DO NOT EDIT.
package {{.PackageName}}

import (
	"errors"
	"fmt"
)

var ErrInvalid{{.TypeName}} = errors.New("invalid {{.TypeName}} value")

func Parse{{.TypeName}}(s string) ({{.TypeName}}, error) {
	switch s {
{{range .Values}}	case "{{.}}":
		return {{.}}, nil
{{end}}	default:
		return 0, fmt.Errorf("%w: %q", ErrInvalid{{.TypeName}}, s)
	}
}

func All{{.TypeName}}s() []{{.TypeName}} {
	return []{{.TypeName}}{
{{range .Values}}		{{.}},
{{end}}	}
}
`

func main() {
	data := EnumMetadata{
		PackageName: "order",
		TypeName:    "Status",
		Values:      []string{"StatusCreated", "StatusPaid", "StatusShipped", "StatusCancelled"},
	}

	tmpl := template.Must(template.New("enum_helpers").Parse(enumHelperTmpl))
	var buf bytes.Buffer
	if err := tmpl.Execute(&buf, data); err != nil {
		panic(err)
	}

	formatted, err := format.Source(buf.Bytes())
	if err != nil {
		panic(err)
	}

	fmt.Println(string(formatted))
}
```

## Под капотом

Конструкция `switch s` по строкам компилируется компилятором Go в быстрый jump table с проверкой длины строки и первичному хэшу первых 4/8 байт (SWAR / bitwise masking), работая значительно быстрее и надежнее по памяти, чем динамическая инициализация мапы `map[string]Enum`.

## Подводные камни

Возврат среза `[]Status` из функции `AllStatuses()` возвращает новый срез с базовым массивом. Если вызывающий код модифицирует элементы среза, это безопасно только при копировании значений (так как энум — скалярный `int`). Однако для предотвращения аллокаций массива при каждом вызове в высоконагруженном коде срез кэшируют в неэкспортированной глобальной переменной.

## На собеседовании

**Вопрос с собеседования:** Как связать функцию `ParseStatus` и `String()` с интерфейсами стандартной библиотеки `encoding.TextMarshaler` и `encoding.TextUnmarshaler`?
**Ответ:** Достаточно сгенерировать методы:
```go
func (s Status) MarshalText() ([]byte, error) { return []byte(s.String()), nil }
func (s *Status) UnmarshalText(text []byte) error {
    val, err := ParseStatus(string(text))
    if err != nil { return err }
    *s = val
    return nil
}
```
Это позволит типам автоматически и безопасно сериализоваться/десериализоваться стандартными пакетами `json.Marshal`, `yaml.Marshal` и драйверами баз данных `database/sql`.
