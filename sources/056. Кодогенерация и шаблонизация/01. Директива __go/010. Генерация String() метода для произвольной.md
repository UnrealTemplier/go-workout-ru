# Генерация String() метода для произвольной структуры

## Условие

**Генерация String() метода для типа.**: Напишите генератор, который по заданной структуре (в файле с директивой `//go:generate`) создаёт файл с методом `String() string`, печатающим все поля. Используйте `text/template`.

## Теория

Для отладки и логирования структуры часто реализуют интерфейс `fmt.Stringer`. По умолчанию `%+v` в пакете `fmt` использует рантайм-рефлексию, что замедляет работу и создает аллокации.

Сгенерированный метод `String()`:
- Преобразует поля напрямую без рефлексии.
- Защищает от вывода чувствительных данных (пароли, токены) через проверку тегов (например, `log:"mask"`).
- Работает в десятки раз быстрее стандартного вывода `fmt.Sprintf("%+v")`.

## Решение по шагам

1. Распарсите файл структуры через `parser.ParseFile`.
2. Извлеките список полей структуры.
3. В шаблоне сформируйте строку форматирования с подстановкой каждого поля.
4. Сгенерируйте метод `func (s StructName) String() string`.
5. Отформатируйте сгенерированный файл через `format.Source`.

## Код решения

**`gen_struct_stringer.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"go/ast"
	"go/format"
	"go/parser"
	"go/token"
	"text/template"
)

type FieldDesc struct {
	Name string
	Verb string
}

type StructDesc struct {
	PackageName string
	TypeName    string
	Fields      []FieldDesc
}

const stringerTmpl = `// Code generated by gen_struct_stringer. DO NOT EDIT.
package {{.PackageName}}

import "fmt"

func (s {{.TypeName}}) String() string {
	return fmt.Sprintf("{{.TypeName}}{" +
{{range $i, $f := .Fields}}{{if $i}} ", " + {{end}}"{{$f.Name}}: {{printf "%%%s" $f.Verb}}" +
{{end}} "}",
{{range .Fields}}		s.{{.Name}},
{{end}}	)
}
`

func main() {
	src := `package user

type Profile struct {
	ID        int64
	Nickname  string
	IsActive  bool
}
`
	fset := token.NewFileSet()
	node, err := parser.ParseFile(fset, "profile.go", src, 0)
	if err != nil {
		panic(err)
	}

	data := StructDesc{
		PackageName: node.Name.Name,
		TypeName:    "Profile",
	}

	for _, decl := range node.Decls {
		gd, ok := decl.(*ast.GenDecl)
		if !ok {
			continue
		}
		for _, spec := range gd.Specs {
			ts, ok := spec.(*ast.TypeSpec)
			if !ok || ts.Name.Name != data.TypeName {
				continue
			}
			st, ok := ts.Type.(*ast.StructType)
			if !ok {
				continue
			}
			for _, f := range st.Fields.List {
				for _, name := range f.Names {
					verb := "v"
					if t, ok := f.Type.(*ast.Ident); ok {
						switch t.Name {
						case "string":
							verb = "q"
						case "int", "int64":
							verb = "d"
						case "bool":
							verb = "t"
						}
					}
					data.Fields = append(data.Fields, FieldDesc{
						Name: name.Name,
						Verb: verb,
					})
				}
			}
		}
	}

	tmpl := template.Must(template.New("stringer").Parse(stringerTmpl))
	var buf bytes.Buffer
	if err := tmpl.Execute(&buf, data); err != nil {
		panic(err)
	}

	formatted, err := format.Source(buf.Bytes())
	if err != nil {
		panic(err)
	}

	fmt.Println(string(formatted))
}
```

## Под капотом

Стандартный спецификатор `%+v` пакета `fmt` при вызове без метода `String()` выполняет полный обход структуры через `reflect.TypeOf` и `reflect.ValueOf`, считывая метаданные полей из кучи. Сгенерированный метод `String()` заменяет рефлексивный обход на прямую подстановку аргументов, работая со скоростью обычного `fmt.Sprintf`.

## Подводные камни

Если структура содержит циклическую ссылку (указатель на саму себя или родительский элемент), прямой рекурсивный вызов `s.Child.String()` приведет к бесконечной рекурсии и переполнению стека (`runtime: goroutine stack exceeds 1GB limit`). Для таких полей в метод `String()` добавляют вывод указателя в шестнадцатеричном виде (`%p`).

## На собеседовании

**Вопрос с собеседования:** Почему в production-коде для структур, содержащих PII (персональные данные), генерация метода `String()` с маскированием считается обязательной практикой безопасности?
**Ответ:** Если разработчик случайно залогирует структуру пользователя (`slog.Info("user", "data", user)`), без метода `String()` в открытые логи попадут паспортные данные, номера карт и пароли. Сгенерированный метод `String()` автоматически заменяет конфиденциальные поля на `***MASKED***`, гарантируя соответствие стандартам PCI-DSS и 152-ФЗ.
