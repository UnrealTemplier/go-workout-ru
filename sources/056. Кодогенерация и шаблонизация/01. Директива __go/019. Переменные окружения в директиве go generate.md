# Переменные окружения в директиве go generate ($GOFILE, $GOPACKAGE)

## Условие

**Переменные окружения в generate**: Используйте `$GOFILE`, `$GOPACKAGE`, `$GOROOT` в generate директивах.

## Теория

При запуске команд утилита `go generate` автоматически экспортирует в дочерний процесс набор служебных переменных окружения:
- `$GOFILE`: базовое имя файла, содержащего выполняемую директиву (например, `model.go`).
- `$GOPACKAGE`: имя пакета Go, которому принадлежит данный файл (например, `order`).
- `$GOLINE`: номер строки в файле, на которой объявлена данная директива `//go:generate`.
- `$DOLLAR`: символ доллара `$` (для команд, которым нужен литеральный знак доллара).
- `$GOROOT`: путь к установленной версии компилятора Go.

## Решение по шагам

1. Создайте файл `entity.go` в пакете `accounting`.
2. Напишите директиву `//go:generate echo "File: $GOFILE, Package: $GOPACKAGE, Line: $GOLINE"`.
3. Запустите `go generate entity.go`.
4. Убедитесь в автоматической подстановке переменных.

## Код решения

**`entity.go`**

```go
//go:generate echo "File: $GOFILE, Package: $GOPACKAGE, Line: $GOLINE"
package accounting

type Invoice struct {
	ID     string
	Amount int64
}
```

ℹ️ Использование стандартных переменных окружения go generate

**`Терминал`**

```bash
go generate entity.go
# File: entity.go, Package: accounting, Line: 1
```

## Под капотом

`go generate` подставляет переменные окружения в командную строку еще до запуска дочернего процесса. Переменные доступны как в аргументах команды (`go run tool.go -file=$GOFILE`), так и внутри самой программы через вызовы `os.Getenv("GOFILE")`.

## Подводные камни

В операционной системе Windows в командной строке `cmd.exe` переменные обычно обозначаются `%VAR%`, однако `go generate` унифицированно использует Unix-синтаксис `$VAR` независимо от целевой ОС.

## На собеседовании

**Вопрос с собеседования:** Зачем в `go generate` нужна переменная `$DOLLAR`?
**Ответ:** Поскольку `go generate` сам выполняет подстановку выражений `$VAR`, если сторонней утилите (например, `awk` или `sed`) требуется передать буквальный символ `$1` или `$field`, синтаксис `$DOLLAR1` защитит символ доллара от преждевременного раскрытия самим раннером `go generate`.
