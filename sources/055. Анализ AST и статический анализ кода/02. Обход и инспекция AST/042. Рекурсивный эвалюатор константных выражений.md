# Рекурсивный эвалюатор константных выражений (Constant Folding) в AST

## Условие

**[Каверзный кейс — Вычисление констант]**: В AST найди объявление `const x = 10 + 5`. Узел `*ast.BinaryExpr` содержит операцию. Напиши рекурсивную функцию-эвалюатор, которая посчитает результат выражения (`10 + 5 = 15`), используя `ast.BasicLit` и `ast.BinaryExpr`.

## Теория

Свертка констант (Constant Folding) — оптимизация компилятора, вычисляющая константные выражения на этапе компиляции, а не в рантайме:
1. Выражение `10 + 5 * 2`:
   - Представлено деревом узлов: корень `+`, слева `10`, справа бинарный узел `5 * 2`.
2. Рекурсивный алгоритм вычисления:
   - Базовый случай (`*ast.BasicLit`): парсинг строкового литерала в число через `strconv.ParseInt`.
   - Рекурсивный случай (`*ast.BinaryExpr`): рекурсивный вызов `eval(X)` и `eval(Y)`, затем применение оператора `Op` (`+`, `-`, `*`, `/`).
   - Поддержка группировки: разворачивание круглых скобок `*ast.ParenExpr`.
3. В стандартной библиотеке эту функцию выполняет пакет `go/constant`.

## Решение по шагам

1. Распарсите код с константными математическими выражениями.
2. Напишите функцию `EvalIntConstant(expr ast.Expr) (int64, error)`.
3. Реализуйте базовый случай для `*ast.BasicLit` с токеном `token.INT`.
4. Реализуйте рекурсию для `*ast.BinaryExpr` с операторами `+`, `-`, `*`, `/`.
5. Разверните `*ast.ParenExpr`.
6. Выведите вычисленные результаты констант.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"go/ast"
	"go/parser"
	"go/token"
	"strconv"
)

const mathConstantsCode = `package math

const A = 10 + 5
const B = (20 - 4) * 3
const C = 100 / (2 + 3) * 4
`

func EvalIntConstant(expr ast.Expr) (int64, error) {
	switch e := expr.(type) {
	case *ast.BasicLit:
		if e.Kind == token.INT {
			val, err := strconv.ParseInt(e.Value, 0, 64)
			if err != nil {
				return 0, err
			}
			return val, nil
		}
		return 0, fmt.Errorf("неподдерживаемый литерал: %s", e.Value)

	case *ast.ParenExpr:
		// Снимаем круглые скобки и вычисляем внутреннее выражение
		return EvalIntConstant(e.X)

	case *ast.BinaryExpr:
		left, err := EvalIntConstant(e.X)
		if err != nil {
			return 0, err
		}
		right, err := EvalIntConstant(e.Y)
		if err != nil {
			return 0, err
		}

		switch e.Op {
		case token.ADD:
			return left + right, nil
		case token.SUB:
			return left - right, nil
		case token.MUL:
			return left * right, nil
		case token.QUO:
			if right == 0 {
				return 0, fmt.Errorf("деление на ноль на этапе компиляции")
			}
			return left / right, nil
		default:
			return 0, fmt.Errorf("неподдерживаемый оператор: %s", e.Op)
		}

	default:
		return 0, fmt.Errorf("неконстантный узел: %T", expr)
	}
}

func main() {
	fset := token.NewFileSet()
	file, err := parser.ParseFile(fset, "math.go", mathConstantsCode, 0)
	if err != nil {
		panic(err)
	}

	fmt.Println("Вычисление константных выражений через AST-эвалюатор:")
	for _, decl := range file.Decls {
		gen, ok := decl.(*ast.GenDecl)
		if !ok || gen.Tok != token.CONST {
			continue
		}

		for _, spec := range gen.Specs {
			vs := spec.(*ast.ValueSpec)
			name := vs.Names[0].Name
			valExpr := vs.Values[0]

			computedVal, err := EvalIntConstant(valExpr)
			if err != nil {
				fmt.Printf("Константа %s: ошибка вычисления: %v\n", name, err)
			} else {
				fmt.Printf("Константа %-3s = %-5d (вычислено из AST без запуска кода!)\n", name, computedVal)
			}
		}
	}
}
```

## Под капотом

В компиляторе Go пакет `go/constant` выполняет точную арифметику бесконечной точности (arbitrary-precision arithmetic) для констант. Любые числовые константы до их присваивания переменной хранятся как структуры `constant.Value` (рациональные числа, большие целые числа `big.Int`), что предотвращает потерю точности и переполнения в сложных математических выражениях на этапе компиляции.

## Подводные камни

1. Забытый разбор `*ast.ParenExpr`: скобки `(20 - 4)` заворачиваются в отдельный узел, без его обработки рекурсия упадет с ошибкой «неподдерживаемый узел».
2. Деление на ноль: эвалюатор обязан проверять делитель на 0, иначе сам процесс линтера упадет с паникой `integer divide by zero`.
3. Литералы в шестнадцатеричном или восьмеричном формате (`0xFF`, `0755`): `strconv.ParseInt(val, 0, 64)` с базой 0 корректно парсит любые префиксы.

## На собеседовании

**Вопрос с собеседования:** Какая максимальная разрядность поддерживается для нетипизированных целочисленных констант в Go?
**Ответ:** Согласно спецификации языка Go, компилятор обязан поддерживать нетипизированные целочисленные константы с точностью не менее 256 бит (в официальном компиляторе `gc` используется пакет `math/big` с поддержкой до 512 бит). Это позволяет вычислять гигантские битовые маски и константы вроде `1 << 100` на этапе компиляции без переполнения `uint64`.
