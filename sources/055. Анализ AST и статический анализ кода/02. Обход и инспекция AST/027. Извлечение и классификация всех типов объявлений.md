# Извлечение и классификация всех типов объявлений функций в файле

## Условие

**Поиск всех функций**: Напишите код, который находит все `*ast.FuncDecl` в файле и выводит их имена.

## Теория

В Go все функции и методы верхнего уровня представляются типом `*ast.FuncDecl`:
1. Структура получателя метода:
   - `fn.Recv == nil`: глобальная функция пакета.
   - `fn.Recv != nil`: метод, привязанный к типу.
2. Имя получателя и целевой тип:
   - `fn.Recv.List[0].Names[0].Name`: имя переменной получателя (например `u`).
   - `fn.Recv.List[0].Type`: выражение типа получателя (`User` или `*User`).
3. Экспорт: `ast.IsExported(fn.Name.Name)`.
4. Параметры и результаты:
   - `fn.Type.Params`: список входных аргументов.
   - `fn.Type.Results`: список возвращаемых значений.

## Решение по шагам

1. Распарсите исходный файл, содержащий пакетные функции, методы по значению и по указателю.
2. Отфильтруйте узлы `*ast.FuncDecl`.
3. Извлеките имя типа получателя для методов.
4. Выведите сигнатуры в понятном читаемом формате.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"go/ast"
	"go/parser"
	"go/token"
)

const code = `package api

type Server struct{}

func NewServer() *Server { return &Server{} }
func (s Server) ListenAddr() string { return ":8080" }
func (s *Server) Shutdown() error { return nil }

func init() {}
`

func formatReceiver(recv *ast.FieldList) string {
	if recv == nil || len(recv.List) == 0 {
		return ""
	}
	field := recv.List[0]
	switch t := field.Type.(type) {
	case *ast.Ident:
		return "(" + t.Name + ")"
	case *ast.StarExpr:
		if ident, ok := t.X.(*ast.Ident); ok {
			return "(*" + ident.Name + ")"
		}
	}
	return "(?)"
}

func main() {
	fset := token.NewFileSet()
	file, err := parser.ParseFile(fset, "api.go", code, 0)
	if err != nil {
		panic(err)
	}

	fmt.Printf("%-25s %-15s %-10s\n", "Сигнатура", "Категория", "Экспорт")
	fmt.Println("----------------------------------------------------")

	for _, decl := range file.Decls {
		fn, ok := decl.(*ast.FuncDecl)
		if !ok {
			continue
		}

		recvStr := formatReceiver(fn.Recv)
		fullName := fn.Name.Name
		category := "Функция"

		if recvStr != "" {
			fullName = recvStr + " " + fn.Name.Name
			category = "Метод"
		}

		exported := "private"
		if ast.IsExported(fn.Name.Name) {
			exported = "PUBLIC"
		}

		fmt.Printf("%-25s %-15s %-10s\n", fullName, category, exported)
	}
}
```

## Под капотом

Специальные функции `init()` и `main()` в Go имеют категорию `FuncDecl`, но компилятор обрабатывает их особым образом. `init()` не может вызываться явно из кода, не принимает аргументов и не возвращает значений. В одном пакете и даже в одном файле может быть объявлено несколько функций `init()`.

## Подводные камни

1. Попытка вызвать `fn.Recv.List[0].Names[0]` без проверки длины `Names`: у анонимного получателя (`func (Server) ListenAddr()`) срез `Names` пуст!
2. Пропуск литералов функций: анонимные функции-замыкания `f := func() {}` не попадают в `file.Decls`, так как являются `*ast.FuncLit`.
3. Путаница между методами с приемником по значению и по указателю.

## На собеседовании

**Вопрос с собеседования:** Может ли метод структуры в Go быть объявлен без имени переменной-получателя?
**Ответ:** Да. Сигнатура `func (Server) ListenAddr() string` абсолютно валидна в Go. Она означает, что метод входит в method set структуры `Server`, но само значение структуры не используется внутри тела метода. В AST поле `fn.Recv.List[0].Names` в таком случае будет иметь длину 0.
