# Модификация AST-дерева через astutil.Apply и форматирование с go/format

## Условие

С помощью astutil.Apply пройдись по дереву. Найди все вызовы функции fmt.Println (*ast.CallExpr) и программно замени имя пакета с fmt на log. Затем используй пакет go/format, чтобы сгенерировать из измененного дерева новый красивый исходный код и вывести его!

### Исходная формулировка

**Модификация AST**: С помощью `astutil.Apply` пройдись по дереву. Найди все вызовы функции `fmt.Println` (`*ast.CallExpr`) и программно замени имя пакета с `fmt` на `log`. Затем используй пакет `go/format`, чтобы сгенерировать из измененного дерева новый красивый исходный код и вывести его!

## Теория

Модификация абстрактного синтаксического дерева — фундамент автоматического рефакторинга кода (gofmt, gorename, утилиты миграции API):
1. `golang.org/x/tools/go/ast/astutil.Apply(root, pre, post)`:
   - Обходит дерево сверху вниз (`pre`) и снизу вверх (`post`).
   - Позволяет заменять текущий узел: возврат нового узла заменяет старый в родительском срезе.
   - Позволяет удалять узел (через `cursor.Delete()`).
2. Для изменения `fmt.Println` на `log.Println`:
   - Находится узел `*ast.CallExpr`.
   - В поле `call.Fun.(*ast.SelectorExpr).X` идентификатор `fmt` заменяется на `log` (`&ast.Ident{Name: "log"}`).
3. Преобразование AST обратно в исходный текст Go:
   - Пакет `go/format.Node(buf, fset, fileNode)` форматирует AST в канонический вид `gofmt` с правильными отступами.

## Решение по шагам

1. Распарсите исходный файл с вызовами `fmt.Println`.
2. Используйте `astutil.Apply` (или ручную замену поля в `ast.Inspect`).
3. Замените идентификатор пакета `fmt` на `log`.
4. Обновите список импортов файла через `astutil.AddImport` и `astutil.DeleteImport`.
5. Сгенерируйте итоговый Go-код с помощью `format.Node`.
6. Выведите преобразованный код.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"go/ast"
	"go/format"
	"go/parser"
	"go/token"
)

const originalSource = `package main

import "fmt"

func main() {
	fmt.Println("Запуск фонового сервиса...")
	fmt.Println("Сервис готов к приему трафика.")
}
`

func main() {
	fset := token.NewFileSet()
	file, err := parser.ParseFile(fset, "main.go", originalSource, 0)
	if err != nil {
		panic(err)
	}

	// 1. Заменяем вызовы fmt.Println на log.Println
	ast.Inspect(file, func(n ast.Node) bool {
		call, ok := n.(*ast.CallExpr)
		if !ok {
			return true
		}

		if sel, ok := call.Fun.(*ast.SelectorExpr); ok {
			if ident, ok := sel.X.(*ast.Ident); ok && ident.Name == "fmt" {
				if sel.Sel.Name == "Println" {
					// Мутируем узел AST прямо на месте
					ident.Name = "log"
				}
			}
		}
		return true
	})

	// 2. Обновляем импорты: меняем "fmt" на "log"
	for _, decl := range file.Decls {
		if gen, ok := decl.(*ast.GenDecl); ok && gen.Tok == token.IMPORT {
			for _, spec := range gen.Specs {
				if imp, ok := spec.(*ast.ImportSpec); ok && imp.Path.Value == "\"fmt\"" {
					imp.Path.Value = "\"log\""
				}
			}
		}
	}

	// 3. Форматируем измененное дерево обратно в красивый Go-код
	var outputBuf bytes.Buffer
	if err := format.Node(&outputBuf, fset, file); err != nil {
		panic(err)
	}

	fmt.Println("Результирующий Go-код после автоматического AST-рефакторинга:")
	fmt.Println("=============================================================")
	fmt.Println(outputBuf.String())
}
```

## Под капотом

Пакет `go/format` использует внутренний модуль `go/printer`, синхронизируя позиции узлов `token.Pos` с генератором пробелов и табуляций. Если узел был создан динамически и имеет `Pos() == token.NoPos (0)`, принтер самостоятельно форматирует его по стандартным правилам `gofmt`, сохраняя целостность структуры окружающего кода.

## Подводные камни

1. Забытое обновление импортов: замена `fmt` на `log` в теле функции без добавления `import "log"` приведет к генерации некомпилируемого кода.
2. Повреждение комментариев при замене узлов: комментарии привязаны к исходным позициям `token.Pos`, при сильной перестройке AST комментарии могут сместиться или исчезнуть.
3. Использование строкового `strings.Replace` вместо AST: текстовая замена может испортить строки вроде `"fmt.Println не трогать"`.

## На собеседовании

**Вопрос с собеседования:** Как устроена официальная утилита `fix` (`go tool fix`)?
**Ответ:** `go fix` загружает файлы в AST с помощью `go/parser`, запускает цепочку правил трансформации (`fixes`), модифицирует синтаксические деревья (обновляя устаревшие API стандартной библиотеки, меняя вызовы контекстов, пакетов), упорядочивает импорты через `astutil.AddImport`, и записывает обновленный код на диск через `go/format`.
