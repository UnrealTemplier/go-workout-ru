# Инспекция полей структур (*ast.StructType): извлечение имен, типов и тегов

## Условие

Найди все узлы `*ast.StructType`. Выведи имена всех структур и список их полей.

## Теория

Объявление структуры в AST представлено узлом `*ast.StructType`:
1. Поле `Fields *ast.FieldList` содержит срез `List []*ast.Field`.
2. Каждый элемент `*ast.Field`:
   - `Names []*ast.Ident`: имена полей. Внимание: если поля объявлены через запятую (`a, b int`), срез `Names` содержит два идентификатора! Если поле анонимное (embedded), `Names` равен `nil`.
   - `Type ast.Expr`: тип поля (`*ast.Ident`, `*ast.StarExpr`, `*ast.ArrayType`, `*ast.MapType`).
   - `Tag *ast.BasicLit`: строковый литерал тега поля (например `` `json:"id"` ``).
   - `Doc *ast.CommentGroup`: комментарий перед полем.
   - `Comment *ast.CommentGroup`: построчный комментарий после поля.

## Решение по шагам

1. Распарсите код Go, содержащий несколько структурных типов.
2. Найдите все `*ast.TypeSpec`.
3. Проверьте, является ли `ts.Type` типом `*ast.StructType`.
4. Итерируйтесь по `st.Fields.List`.
5. Корректно обработайте обычные поля, множественные объявления (`X, Y int`) и встраивание (embedded).
6. Выведите структурированное описание типов.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"go/ast"
	"go/parser"
	"go/token"
)

const structDefs = `package models

type BaseEntity struct {
	ID        int64  ` + "`" + `json:"id"` + "`" + `
	CreatedAt string ` + "`" + `json:"created_at"` + "`" + `
}

type UserAccount struct {
	BaseEntity        // Embedded field
	FirstName, LastName string ` + "`" + `json:"full_name"` + "`" + `
	Age                 int    ` + "`" + `json:"age"` + "`" + `
	roles               []string
}
`

func typeToString(expr ast.Expr) string {
	switch t := expr.(type) {
	case *ast.Ident:
		return t.Name
	case *ast.StarExpr:
		return "*" + typeToString(t.X)
	case *ast.ArrayType:
		return "[]" + typeToString(t.Elt)
	case *ast.MapType:
		return fmt.Sprintf("map[%s]%s", typeToString(t.Key), typeToString(t.Value))
	default:
		return fmt.Sprintf("%T", expr)
	}
}

func main() {
	fset := token.NewFileSet()
	file, err := parser.ParseFile(fset, "models.go", structDefs, 0)
	if err != nil {
		panic(err)
	}

	for _, decl := range file.Decls {
		gen, ok := decl.(*ast.GenDecl)
		if !ok || gen.Tok != token.TYPE {
			continue
		}

		for _, spec := range gen.Specs {
			ts, ok := spec.(*ast.TypeSpec)
			if !ok {
				continue
			}

			st, ok := ts.Type.(*ast.StructType)
			if !ok {
				continue
			}

			fmt.Printf("Структура: %s\n", ts.Name.Name)

			for _, field := range st.Fields.List {
				fieldTypeStr := typeToString(field.Type)
				tagStr := ""
				if field.Tag != nil {
					tagStr = field.Tag.Value
				}

				// Если Names пусто — это встраиваемое (embedded) поле
				if len(field.Names) == 0 {
					fmt.Printf("  • [EMBEDDED] %-15s (Тег: %s)\n", fieldTypeStr, tagStr)
				} else {
					for _, nameIdent := range field.Names {
						fmt.Printf("  • Поле: %-15s Тип: %-10s (Тег: %s)\n",
							nameIdent.Name, fieldTypeStr, tagStr)
					}
				}
			}
			fmt.Println()
		}
	}
}
```

## Под капотом

Обратите внимание на поле `FirstName, LastName string`: в AST узел `*ast.Field` создается всего один, но его срез `field.Names` содержит оба идентификатора `FirstName` и `LastName`. Разработчики часто ошибаются, полагая, что `len(field.Names)` всегда равен 1. Для embedded полей `field.Names` имеет длину 0, а само имя типа хранится в `field.Type`.

## Подводные камни

1. Предположение, что `field.Names` всегда имеет один элемент: при объявлении `a, b, c int` пропуск цикла по `field.Names` потеряет 2 из 3 полей.
2. Паника при обращении к `field.Names[0]` на embedded структурах (`len(field.Names) == 0`).
3. Забытая очистка сырых обратных кавычек `field.Tag.Value` перед парсингом тега через `reflect.StructTag`.

## На собеседовании

**Вопрос с собеседования:** Как через AST определить, является ли поле структуры экспортированным (public)?
**Ответ:** Для обычного поля вызывается функция `ast.IsExported(nameIdent.Name)`. Она проверяет, начинается ли первый символ имени с заглавной буквы по правилам Unicode (`unicode.IsUpper`). Для embedded-поля инспектируется имя вложенного типа в `field.Type`.
