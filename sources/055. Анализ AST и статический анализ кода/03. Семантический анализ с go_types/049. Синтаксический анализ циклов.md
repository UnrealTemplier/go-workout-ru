# Синтаксический анализ циклов (*ast.ForStmt и *ast.RangeStmt)

## Условие

**Поиск всех циклов**: Найдите все `*ast.ForStmt`, `*ast.RangeStmt` в коде.

## Теория

В Go существует всего одно ключевое слово для циклов — `for`, но синтаксически оно представлено двумя разными типами узлов AST:
1. `*ast.ForStmt`: классический C-style цикл:
   - `Init ast.Stmt`: инициализатор (`i := 0`).
   - `Cond ast.Expr`: условие продолжения (`i < 10`).
   - `Post ast.Stmt`: шаг итерации (`i++`).
   - Если `Init`, `Cond` и `Post` равны `nil` — это бесконечный цикл `for { ... }`.
   - Если задано только `Cond` — это цикл `while` (`for ok { ... }`).
2. `*ast.RangeStmt`: цикл обхода коллекций `for k, v := range coll`:
   - `Key ast.Expr`: переменная ключа/индекса.
   - `Value ast.Expr`: переменная значения (может быть `nil`, если запрошен только ключ).
   - `Tok token.Token`: токен присваивания (`:=` или `=`).
   - `X ast.Expr`: выражение итерируемой коллекции.

## Решение по шагам

1. Распарсите код с классическими циклами, бесконечными циклами и range-циклами.
2. Обойдите узлы через `ast.Inspect`.
3. Классифицируйте циклы на `ForStmt` и `RangeStmt`.
4. Выведите тип цикла, строку и его компоненты.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"go/ast"
	"go/parser"
	"go/token"
)

const loopSource = `package loops

func RunLoops(items []string) {
	// 1. Классический for
	for i := 0; i < len(items); i++ {
		println(items[i])
	}

	// 2. Условный while-like for
	running := true
	for running {
		running = false
	}

	// 3. Бесконечный for
	for {
		break
	}

	// 4. Range for
	for idx, val := range items {
		println(idx, val)
	}
}
`

func main() {
	fset := token.NewFileSet()
	file, err := parser.ParseFile(fset, "loops.go", loopSource, 0)
	if err != nil {
		panic(err)
	}

	fmt.Println("Анализ всех циклов в исходном коде:")
	fmt.Println("==========================================")

	ast.Inspect(file, func(n ast.Node) bool {
		switch loop := n.(type) {
		case *ast.ForStmt:
			pos := fset.Position(loop.Pos())
			kind := "Классический (3-clause)"
			if loop.Init == nil && loop.Post == nil {
				if loop.Cond == nil {
					kind = "Бесконечный (for {})"
				} else {
					kind = "Условный (while-like)"
				}
			}
			fmt.Printf("Строка %-2d: *ast.ForStmt   | Тип: %s\n", pos.Line, kind)

		case *ast.RangeStmt:
			pos := fset.Position(loop.Pos())
			fmt.Printf("Строка %-2d: *ast.RangeStmt | Итерация по коллекции (%v)\n",
				pos.Line, loop.X)
		}

		return true
	})
}
```

ℹ️ Классификация видов циклов ForStmt и RangeStmt

## Под капотом

В Go 1.22 в грамматику `*ast.RangeStmt` была добавлена поддержка итерации по целочисленным счетчикам: `for i := range 10`. В AST выражение `loop.X` в таком случае является простым `*ast.BasicLit` с числом, а `loop.Value` равен `nil`.

## Подводные камни

1. Обращение к `loop.Value` без проверки на `nil`: при `for k := range m` значение `Value` равно `nil`.
2. Обращение к `loop.Cond` на бесконечном цикле: вызовет nil pointer.
3. Пропуск меток циклов (`break Label`): метка оборачивается во внешний узел `*ast.LabeledStmt`.

## На собеседовании

**Вопрос с собеседования:** Как устроен цикл `for i := range 10` в AST и рантайме Go 1.22+?
**Ответ:** В AST это узел `*ast.RangeStmt`, где `loop.Key` — переменная `i`, `loop.Value == nil`, а `loop.X` — числовой литерал `10`. Компилятор транслирует эту конструкцию в стандартный цикл со счетчиком от 0 до \(N-1\), оптимизируя проверку границ и устраняя аллокации.
