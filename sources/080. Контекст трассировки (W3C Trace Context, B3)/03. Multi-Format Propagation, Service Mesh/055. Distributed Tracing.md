# Distributed Tracing: универсальный интерфейс TraceContextCarrier

## Условие

Создайте универсальную абстракцию TraceContextCarrier, инкапсулирующую инжекцию и извлечение Trace Context для любых произвольных транспортных протоколов.

### Исходная формулировка

**Distributed Tracing Context обязателен.**: Без trace context propagation вы не сможете отладить request, который проходит через 5+ сервисов. W3C Trace Context — это standard.

## Теория

В крупных корпоративных системах трафик циркулирует через разнообразные сетевые транспорты: HTTP/1.1, HTTP/2 gRPC, AMQP RabbitMQ, Kafka, NATS, Redis Streams, WebSocket. Чтобы бизнес-код не зависел от конкретных заголовков каждого брокера, создается универсальный адаптер `TraceContextCarrier`, удовлетворяющий интерфейсу `propagation.TextMapCarrier`. Это позволяет единообразно пробрасывать контекст трассировки одной строкой кода в любом слое архитектуры.

## Решение по шагам

Реализуйте обобщенную структуру MapCarrier поверх map[string]string.
Реализуйте методы Get, Set, Keys интерфейса TextMapCarrier.
Напишите функции-хелперы InjectContext и ExtractContext.
Проверьте работу с произвольным транспортным протоколом.

## Код решения

**`universal_carrier.go`**

```go
package main

import (
	"context"
	"fmt"

	"go.opentelemetry.io/otel"
	"go.opentelemetry.io/otel/propagation"
	sdktrace "go.opentelemetry.io/otel/sdk/trace"
	"go.opentelemetry.io/otel/trace"
)

// MapCarrier реализует propagation.TextMapCarrier для универсальных ключ-значение структур
type MapCarrier map[string]string

func (m MapCarrier) Get(key string) string {
	return m[key]
}

func (m MapCarrier) Set(key, val string) {
	m[key] = val
}

func (m MapCarrier) Keys() []string {
	keys := make([]string, 0, len(m))
	for k := range m {
		keys = append(keys, k)
	}
	return keys
}

// InjectTrace инжектирует контекст в произвольную мапу
func InjectTrace(ctx context.Context, carrier MapCarrier) {
	otel.GetTextMapPropagator().Inject(ctx, carrier)
}

// ExtractTrace извлекает контекст из произвольной мапы
func ExtractTrace(ctx context.Context, carrier MapCarrier) context.Context {
	return otel.GetTextMapPropagator().Extract(ctx, carrier)
}

func main() {
	tp := sdktrace.NewTracerProvider(sdktrace.WithSampler(sdktrace.AlwaysSample()))
	otel.SetTracerProvider(tp)
	otel.SetTextMapPropagator(propagation.TraceContext{})

	tracer := otel.Tracer("custom-engine")
	ctx, span := tracer.Start(context.Background(), "ExecuteCustomTask")
	defer span.End()

	// Произвольный транспортный контейнер (например Redis payload или Custom TCP)
	payloadMetadata := make(MapCarrier)
	InjectTrace(ctx, payloadMetadata)

	fmt.Println("Injected transport metadata:", payloadMetadata)

	// На принимающей стороне восстанавливаем контекст
	remoteCtx := ExtractTrace(context.Background(), payloadMetadata)
	_, childSpan := tracer.Start(remoteCtx, "ExecuteDownstreamTask")
	defer childSpan.End()

	fmt.Printf("Trace successfully preserved! Parent: %s, Child: %s\n",
		span.SpanContext().TraceID(), childSpan.SpanContext().TraceID())
}
```

ℹ️ Универсальный TextMapCarrier для любых нестандартных протоколов

## Под капотом

Интерфейс `propagation.TextMapCarrier` специально спроектирован в OpenTelemetry минималистичным, чтобы его можно было реализовать поверх любой структуры данных всего тремя методами.

## Подводные камни

Использование ключей с разным регистром (Case Sensitivity). Некоторые протоколы меняют регистр ключей. Желательно приводить все ключи к нижнему регистру (lowercase).

## На собеседовании

Вопрос на собеседовании в Яндекс: 'Как пробросить Trace Context через сырое TCP соединение?' Ответ: 'Сериализовать пару traceparent: &lt;value> в бинарный или текстовый заголовок собственного фрейма и распарсить с помощью кастомного TextMapCarrier на принимающей стороне'.
