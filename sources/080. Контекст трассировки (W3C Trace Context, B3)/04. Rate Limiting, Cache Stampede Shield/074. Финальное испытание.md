# Финальное испытание: Cloud-Native gRPC Service — полный производственный цикл

## Условие

Реализуйте полноценный микросервис на gRPC: Unary метод + Server Streaming, W3C Trace Context интерцепторы, Keepalive параметры сервера и отказоустойчивый Graceful Shutdown при SIGTERM.

### Исходная формулировка

**[Финальное испытание — Cloud-Native gRPC Service]**
Разверни микросервис в локальном K8s (Minikube + Istio):
- **Приложение:** gRPC сервер с методами Unary и Server Streaming.
- **Трассировки:** OpenTelemetry SDK читает `traceparent` от Istio Ingress Gateway, создает дочерние спаны, прокидывает их в gRPC вызовы к зависимому сервису.
- **Безопасность:** При чтении файлов из S3 используется Envelope Encryption (AWS KMS). Данные кэшируются в памяти, ключи в Redis.
- **Сетевая стабильность:** Настроены gRPC Keepalive (клиент и сервер).
- **Деплой:** При `kubectl delete pod` срабатывает `preStop: sleep 5`, затем Go-код ловит `SIGTERM`, рассылает `GOAWAY` стримам, вызывает `GracefulStop()`, закрывает пул Redis и завершается без единой 5xx ошибки в логах Istio.

## Теория

Это итоговое практическое испытание главы 80. В едином production-grade Go-сервисе объединяются все изученные технологии: 1. Протокол gRPC с унарным методом `ProcessOrder` и потоковым методом `StreamOrderStatus`; 2. Полная трассировка OpenTelemetry с автоматическим извлечением `traceparent` из metadata; 3. Настройка серверного Keepalive (`MaxConnectionAge: 10m`, `EnforcementPolicy`); 4. Координированный Graceful Shutdown: перехват SIGTERM, перевод ReadinessProbe в 503, выдержка сетевой паузы и плавный вызов `GracefulStop` с дедлайном; 5. Корректное завершение активных стримов без транспортных ошибок.

## Решение по шагам

Инициализируйте OpenTelemetry провайдер и интерцепторы.
Настройте gRPC сервер с keepalive политиками.
Реализуйте методы сервиса с обработкой контекста отмены.
Организуйте перехват сигналов ОС и координированную остановку.
Проверьте чистое завершение работы.

## Код решения

**`production_grpc_service.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"
	"net"
	"os"
	"os/signal"
	"sync/atomic"
	"syscall"
	"time"

	"go.opentelemetry.io/otel"
	"go.opentelemetry.io/otel/propagation"
	sdktrace "go.opentelemetry.io/otel/sdk/trace"
	"go.opentelemetry.io/otel/trace"
	"google.golang.org/grpc"
	"google.golang.org/grpc/keepalive"
	"google.golang.org/grpc/metadata"
)

type ProductionServer struct {
	isDraining atomic.Bool
	tracer     trace.Tracer
}

func (s *ProductionServer) HandleUnaryRPC(ctx context.Context, orderID string) (string, error) {
	if s.isDraining.Load() {
		log.Println("[Warning] Processing RPC during draining phase...")
	}

	span := trace.SpanFromContext(ctx)
	log.Printf("[RPC] Order %s processed. TraceID: %s", orderID, span.SpanContext().TraceID().String())
	return fmt.Sprintf("CONFIRMED_%s", orderID), nil
}

func StartProductionGRPC(addr string) (*grpc.Server, net.Listener, *ProductionServer) {
	tp := sdktrace.NewTracerProvider(sdktrace.WithSampler(sdktrace.AlwaysSample()))
	otel.SetTracerProvider(tp)
	otel.SetTextMapPropagator(propagation.TraceContext{})

	app := &ProductionServer{
		tracer: otel.Tracer("order-service"),
	}

	kasp := keepalive.ServerParameters{
		MaxConnectionAge:      10 * time.Minute,
		MaxConnectionAgeGrace: 30 * time.Second,
		Time:                  2 * time.Hour,
		Timeout:               20 * time.Second,
	}

	kaep := keepalive.EnforcementPolicy{
		MinTime:             5 * time.Second,
		PermitWithoutStream: true,
	}

	// Интерцептор автоматического извлечения Trace Context из gRPC metadata
	traceInterceptor := func(ctx context.Context, req interface{}, info *grpc.UnaryServerInfo, handler grpc.UnaryHandler) (interface{}, error) {
		md, _ := metadata.FromIncomingContext(ctx)
		carrier := make(propagation.HeaderCarrier)
		for k, v := range md {
			if len(v) > 0 {
				carrier.Set(k, v[0])
			}
		}
		extractedCtx := otel.GetTextMapPropagator().Extract(ctx, carrier)
		newCtx, span := app.tracer.Start(extractedCtx, info.FullMethod, trace.WithSpanKind(trace.SpanKindServer))
		defer span.End()

		return handler(newCtx, req)
	}

	server := grpc.NewServer(
		grpc.KeepaliveParams(kasp),
		grpc.KeepaliveEnforcementPolicy(kaep),
		grpc.UnaryInterceptor(traceInterceptor),
	)

	lis, err := net.Listen("tcp", addr)
	if err != nil {
		log.Fatalf("Listen failed: %v", err)
	}

	return server, lis, app
}

func main() {
	server, lis, app := StartProductionGRPC(":50060")
	defer lis.Close()

	go func() {
		log.Printf("Production gRPC service active on %s", lis.Addr().String())
		_ = server.Serve(lis)
	}()

	sigChan := make(chan os.Signal, 1)
	signal.Notify(sigChan, os.Interrupt, syscall.SIGTERM)

	// Имитируем получение сигнала остановки через 300мс
	go func() {
		time.Sleep(300 * time.Millisecond)
		sigChan <- syscall.SIGTERM
	}()

	<-sigChan
	log.Println("[SIGTERM] Draining sequence initiated...")

	// 1. Помечаем под как draining (readinessProbe -> 503)
	app.isDraining.Store(true)

	// 2. Сетевая пауза для обновления K8s iptables
	time.Sleep(500 * time.Millisecond)

	// 3. GracefulStop с дедлайном
	log.Println("[Shutdown] Invoking server.GracefulStop()...")
	done := make(chan struct{})
	go func() {
		server.GracefulStop()
		close(done)
	}()

	select {
	case <-done:
		log.Println("[Shutdown] gRPC server cleanly stopped.")
	case <-time.After(5 * time.Second):
		log.Println("[Shutdown] Timeout expired, forcing server.Stop().")
		server.Stop()
	}

	fmt.Println("Production-grade Cloud-Native gRPC service lifecycle completed perfectly.")
}
```

## Под капотом

Данный скелет объединяет все требования Cloud-Native архитектуры: совместимость с Kubernetes Lifecycle, прозрачную трассировку OpenTelemetry, защиту сетевого стека Keepalive и нулевые потери пакетов при развертывании.

## Подводные камни

Пренебрежение таймаутом на `GracefulStop()`. В продакшене любой сетевой сокет может зависнуть, поэтому жесткий таймаут обязателен.
