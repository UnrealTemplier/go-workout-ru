# Матричная кросс-компиляция под Windows и Linux

## Условие

Соберите кросс-компиляцией бинарники для Windows и Linux с помощью `GOOS` и `GOARCH`.

## Теория

В современных пайплайнах релиза (например, в GoReleaser или GitHub Actions) сервис автоматически компилируется под матрицу платформ:
- `linux/amd64` (основные серверы)
- `linux/arm64` (AWS Graviton, Apple Silicon серверы)
- `windows/amd64` (рабочие станции Windows)
- `darwin/arm64` (macOS M-series)

## Решение по шагам

1. Пишем bash-скрипт сборки под матрицу целевых платформ.
2. Проверяем созданные бинарники в директории `dist/`.

## Код решения

**`build_matrix.sh`**

```bash
#!/usr/bin/env bash
set -e

PLATFORMS=("linux/amd64" "linux/arm64" "windows/amd64" "darwin/arm64")

mkdir -p dist

for PLATFORM in "${PLATFORMS[@]}"; do
    GOOS=${PLATFORM%/*}
    GOARCH=${PLATFORM#*/}
    OUTPUT="dist/app-${GOOS}-${GOARCH}"
    if [ "$GOOS" = "windows" ]; then
        OUTPUT+=".exe"
    fi

    echo "==> Сборка для ${GOOS}/${GOARCH}..."
    CGO_ENABLED=0 GOOS=$GOOS GOARCH=$GOARCH go build -ldflags="-s -w" -o $OUTPUT .
done

echo "==> Все бинарники успешно собраны:"
ls -lh dist/
```

ℹ️ Скрипт матричной сборки

## Под капотом

При смене `GOARCH` бэкенд компилятора подставляет соответствующий генератор машинных инструкций (например, генератор инструкций Thumb/AArch64 для ARM).

## Подводные камни

- Забыть добавить расширение `.exe` для сборок под Windows.

## На собеседовании

**Вопрос с собеседования:** «Что такое fat binary (Universal Binary в macOS) и поддерживает ли Go их создание?»
**Ответ:** Fat Binary содержит машинный код для нескольких архитектур (x86_64 и ARM64) в одном файле. Go компилирует файлы под каждую архитектуру отдельно, после чего на macOS их можно объединить системной утилитой `lipo -create app-amd64 app-arm64 -output app-universal`.
