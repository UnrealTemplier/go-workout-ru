# Форматирование всей кодовой базы через go fmt ./...

## Условие

Отформатируй свой код с помощью `go fmt ./...`.

## Теория

Паттерн `./...` указывает тулчейну Go применить команду **рекурсивно ко всем пакетам и подкаталогам** текущего проекта.
Команда `go fmt ./...` форматирует все `.go` файлы репозитория в едином каноническом стиле.

## Решение по шагам

1. Выполняем `go fmt ./...`.
2. Проверяем изменения через `git status` и `git diff`.

## Код решения

**`Терминал`**

```bash
go fmt ./...
# Выводит список измененных файлов, если они требовали форматирования
```

ℹ️ Рекурсивное форматирование

## Под капотом

`go fmt` вызывает утилиту `gofmt -l -w` для каждого обнаруженного пакета проекта.

## Подводные камни

- Запуск `go fmt` без `./...` отформатирует только файлы в текущей папке, пропустив все вложенные пакеты (`internal/`, `pkg/`).

## На собеседовании

**Вопрос с собеседования:** «Как проверить в CI, что весь код в репозитории отформатирован, не изменяя файлы на диске?»
**Ответ:** `gofmt -l .` выведет список неотформатированных файлов. Если вывод не пустой (`test -z "$(gofmt -l .)"`), шаг CI падает с ошибкой.
