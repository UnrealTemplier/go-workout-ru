# Кастомизация выходного имени бинарника через флаг go build -o

## Условие

Используй команду `go build -o myapp` для задания кастомного имени бинарнику. Запусти его.

## Теория

Флаг `-o` (output) переопределяет стандартное имя выходного файла.
Это необходимо при:
- Сборке разных микросервисов из одного репозитория (`bin/api-server`, `bin/migrator`);
- Подготовке релизных сборок с номером версии (`build/server-v1.4.0`).

## Решение по шагам

1. Выполняем `go build -o bin/myapp .`.
2. Запускаем `./bin/myapp`.

## Код решения

**`Терминал`**

```bash
mkdir -p bin
go build -o bin/myapp .
./bin/myapp
# Hello, World! Привет из компилятора Go.
```

ℹ️ Сборка с флагом -o

## Под капотом

Флаг `-o` передается линкеру `go tool link -o bin/myapp`. Если директория `bin` не существует, Go автоматически создаст её.

## Подводные камни

- Если передать флаг `-o` без значения (`go build -o .`), компилятор выдаст синтаксическую ошибку флагов.

## На собеседовании

**Вопрос с собеседования:** «Можно ли с помощью `-o` перенаправить вывод скомпилированного бинарника в `/dev/null`?»
**Ответ:** Да! Команда `go build -o /dev/null .` часто используется в CI для быстрой проверки компилируемости проекта без сохранения лишних файлов на диск.
