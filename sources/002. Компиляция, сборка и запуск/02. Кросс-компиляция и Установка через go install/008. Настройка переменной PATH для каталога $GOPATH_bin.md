# Настройка переменной PATH для каталога $GOPATH/bin

## Условие

Установи программу в системный `$GOPATH/bin` с помощью `go install`. Проверь, что она запускается из любой директории.

## Теория

Чтобы установленные через `go install` утилиты (линтеры, генераторы gRPC кода `protoc-gen-go`, mockgen) работали без указания полного пути, добавляем `export PATH=$PATH:$(go env GOPATH)/bin` в профиль вашей командной оболочки (`~/.bashrc` или `~/.zshrc`).

## Решение по шагам

1. Проверяем текущий `PATH`: `echo $PATH`.
2. Добавляем путь в `~/.bashrc`.
3. Применяем конфигурацию: `source ~/.bashrc`.

## Код решения

**`~/.bashrc (Конфигурация окружения)`**

```bash
# Добавляем бинарники Go в системный PATH
export GOPATH=$(go env GOPATH)
export PATH=$PATH:$GOPATH/bin
```

ℹ️ Настройка PATH в shell profile

**`Терминал`**

```bash
source ~/.bashrc
which hello_mod
# /home/ut/go/bin/hello_mod
```

ℹ️ Проверка доступности

## Под капотом

Оболочка Bash кэширует пути к бинарникам в хэш-таблице (команда `hash`). При добавлении пути в `PATH` поиск выполняется слева направо по всем путям переменной.

## Подводные камни

- Добавление пути без сохранения старого (`export PATH=$(go env GOPATH)/bin`) сломает стандартные утилиты Linux (`ls`, `cat`, `grep`). Всегда пишите `$PATH:$GOPATH/bin`.
