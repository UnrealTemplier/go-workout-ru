# Хронология выполнения: функция init() vs main()

## Условие

Напиши программу, в которой будет функция `init()`, выводящая "Init started", и функция `main()`, выводящая "Main started". Проверь порядок вызова.

## Теория

Функция `init()` в Go имеет фиксированное поведение:
1. Вызывается рантаймом Go автоматически до `main()`;
2. Не может быть вызвана разработчиком вручную;
3. Используется для преднастройки глобального состояния пакета.

## Решение по шагам

1. Создаем `main.go`.
2. Объявляем `func init() { fmt.Println("Init started") }`.
3. Объявляем `func main() { fmt.Println("Main started") }`.
4. Запускаем и проверяем вывод.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func init() {
	fmt.Println("Init started")
}

func main() {
	fmt.Println("Main started")
}
```

ℹ️ Хронология init и main

**`Терминал`**

```bash
go run .
# Вывод:
# Init started
# Main started
```

ℹ️ Вывод программы

## Под капотом

Компилятор регистрирует адрес функции `init` в специальной таблице инициализаторов. Главный поток рантайма обходит эту таблицу перед вызовом функции `main.main`.

## Подводные камни

- Выполнение в `init()` долгих сетевых операций без таймаутов, что может заблокировать запуск программы.

## На собеседовании

**Вопрос с собеседования:** «В каком потоке операционной системы исполняются функции `init()`?»
**Ответ:** Все функции `init()` исполняются строго последовательно в главном системном потоке `M0` (Main Thread) до запуска горутин пользовательского кода.
