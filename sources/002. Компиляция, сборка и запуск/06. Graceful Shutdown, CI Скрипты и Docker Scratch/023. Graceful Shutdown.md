# Graceful Shutdown: перехват сигналов ОС (SIGINT, SIGTERM) и мягкое завершение

## Условие

Создай программу с graceful shutdown: перехватывай сигналы `os.Interrupt`, `syscall.SIGTERM`. При получении сигнала — выведи сообщение и корректно завершись.

## Теория

**Graceful Shutdown (Мягкая остановка сервиса):**
Когда оркестратор Kubernetes останавливает под (Pod) или вы нажимаете `Ctrl+C`, процесс получает системный сигнал:
- `SIGINT` (Ctrl+C в терминале);
- `SIGTERM` (сигнал остановки от Kubernetes / Docker).

Сервер не должен обрывать соединения клиентов на полуслове!
Он обязан:
1. Прекратить прием новых HTTP-запросов;
2. Дождаться завершения уже обрабатываемых запросов (в пределах таймаута);
3. Закрыть соединения с БД и сбросить буферы логов;
4. Завершить процесс с кодом 0.

## Решение по шагам

1. Создаем канал сигналов `sigChan := make(chan os.Signal, 1)`.
2. Регистрируем перехват через `signal.Notify(sigChan, os.Interrupt, syscall.SIGTERM)`.
3. Блокируемся на чтении из канала `<-sigChan`.
4. Выполняем очистку ресурсов с таймаутом через `context.WithTimeout`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"net/http"
	"os"
	"os/signal"
	"syscall"
	"time"
)

func main() {
	server := &http.Server{
		Addr: ":8080",
		Handler: http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			time.Sleep(2 * time.Second) // Имитация долгого запроса
			fmt.Fprintln(w, "Запрос успешно обработан!")
		}),
	}

	// Запуск HTTP-сервера в фоновой горутине
	go func() {
		fmt.Println("🚀 Сервер запущен на порту :8080...")
		if err := server.ListenAndServe(); err != nil && err != http.ErrServerClosed {
			fmt.Printf("Ошибка сервера: %v\n", err)
		}
	}()

	// Канал для перехвата сигналов ОС
	quit := make(chan os.Signal, 1)
	signal.Notify(quit, os.Interrupt, syscall.SIGTERM)

	// Блокировка до получения сигнала остановки
	sig := <-quit
	fmt.Printf("\n⚠️  Получен сигнал [%v]. Начинаем Graceful Shutdown...\n", sig)

	// Даем серверу 5 секунд на завершение текущих соединений
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	if err := server.Shutdown(ctx); err != nil {
		fmt.Printf("✖ Принудительная остановка сервера по таймауту: %v\n", err)
	} else {
		fmt.Println("✔ Все клиентские соединения успешно закрыты.")
	}

	fmt.Println("🛑 Сервер корректно остановлен. Выход.")
}
```

ℹ️ Промышленный Graceful Shutdown HTTP-сервера

## Под капотом

`signal.Notify` перехватывает системные сигналы ядра Linux. Метод `server.Shutdown(ctx)` переводит внутренний слушатель сокета в закрытое состояние и ожидает завершения горутин активных HTTP-соединений.

## Подводные камни

- Создание небуферизированного канала `make(chan os.Signal)`: если сигнал придет в момент, когда горутина не читает канал, сигнал может быть потерян. Канал под сигналы **всегда создается с емкостью 1** (`make(chan os.Signal, 1)`).

## На собеседовании

**Вопрос с собеседования:** «Что происходит при деплое нового пода в Kubernetes (Zero Downtime Deployment)?»
**Ответ:** K8s посылает старому поду сигнал `SIGTERM` и одновременно удаляет его из эндпоинтов балансировщика Service. Pod выполняет Graceful Shutdown в течение `terminationGracePeriodSeconds` (по умолчанию 30с), после чего K8s принудительно убивает процесс через `SIGKILL`.
