# Парсинг аргументов CLI через стандартный пакет flag

## Условие

Напиши программу с флагами командной строки (`flag` package). Реализуй: `--name` (string), `--age` (int), `--verbose` (bool). Запусти с разными комбинациями флагов.

## Теория

Пакет `flag` — базовый инструмент создания CLI-утилит в стандартной библиотеке Go:
- `flag.StringVar(&name, "name", "Гость", "Описание")`
- `flag.IntVar(&age, "age", 18, "Описание")`
- `flag.BoolVar(&verbose, "verbose", false, "Описание")`
- Вызов `flag.Parse()` производит фактический разбор параметров.

## Решение по шагам

1. Создаем программу с тремя флагами.
2. Проверяем значения флагов и поведение булевых переключателей.
3. Тестируем различные варианты запуска.

## Код решения

**`main.go`**

```go
package main

import (
	"flag"
	"fmt"
)

func main() {
	var (
		name    string
		age     int
		verbose bool
	)

	flag.StringVar(&name, "name", "Инженер", "Имя пользователя")
	flag.IntVar(&age, "age", 25, "Возраст пользователя")
	flag.BoolVar(&verbose, "verbose", false, "Включить подробный вывод")

	flag.Parse()

	if verbose {
		fmt.Println("[DEBUG] Режим подробного логирования включен")
		fmt.Printf("[DEBUG] Количество переданных аргументов: %d\n", flag.NFlag())
	}

	fmt.Printf("Пользователь: %s, Возраст: %d лет\n", name, age)
}
```

ℹ️ Обработка параметров через пакет flag

**`Терминал`**

```bash
# 1. Запуск со значениями по умолчанию
go run .
# Пользователь: Инженер, Возраст: 25 лет

# 2. Запуск с кастомными флагами
go run . -name="Алексей" -age=30 -verbose
# [DEBUG] Режим подробного логирования включен
# [DEBUG] Количество переданных аргументов: 3
# Пользователь: Алексей, Возраст: 30 лет
```

ℹ️ Тестирование флагов

## Под капотом

`flag.Parse` обходит срез аргументов и прекращает разбор флагов при первом встреченном аргументе без префикса `-` или после разделителя `--`.

## Подводные камни

- Использование двойного тире `--` и одинарного `-`: стандартный пакет `flag` принимает оба варианта (`-name` и `--name`), но не поддерживает короткие объединенные флаги (как `-vcf`).

## На собеседовании

**Вопрос с собеседования:** «Как в пакете `flag` узнать количество реально переданных пользователем флагов?»
**Ответ:** Через функцию `flag.NFlag()`. Функция `flag.NArg()` возвращает количество оставшихся позиционных аргументов.
