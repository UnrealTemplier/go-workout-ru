# Внедрение версии и времени сборки через -ldflags (-X)

## Условие

Вставь в бинарник информацию о версии через `-ldflags`: `-X main.Version=1.2.3 -X main.BuildTime=$(date)`. Выведи эти переменные при запуске.

## Теория

Инъекция значений строковых переменных через флаг линкера `-X` позволяет вшивать в бинарник:
- Версию релиза (SemVer);
- Таймстамп сборщика;
- Хэш коммита Git.

Это исключает необходимость хардкодить версию в исходном коде перед каждым релизом.

## Решение по шагам

1. В коде объявляем переменные `var Version = "dev"` и `var BuildTime = "unknown"`.
2. Компилируем бинарник, передавая значения через `-ldflags`.
3. Запускаем скомпилированный файл.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

var (
	Version   = "dev"
	BuildTime = "unknown"
)

func main() {
	fmt.Printf("Версия приложения: %s\n", Version)
	fmt.Printf("Время сборки:      %s\n", BuildTime)
}
```

ℹ️ Файл с переменными версии

**`Терминал`**

```bash
NOW=$(date -u +"%Y-%m-%dT%H:%M:%SZ")
go build -ldflags "-X main.Version=v1.2.3 -X 'main.BuildTime=$NOW'" -o app .

./app
# Версия приложения: v1.2.3
# Время сборки:      2026-09-02T12:50:00Z
```

ℹ️ Сборка с инъекцией переменных

## Под капотом

Линкер находит строковый литерал переменной в таблице символов и перезаписывает указатель на новую константную строку.

## Подводные камни

- Если переменная содержит пробелы (например, вывод `date`), значение в `-X` обязательно нужно оборачивать в кавычки (`-X 'main.BuildTime=...'`), иначе шелл разобьет строку на несколько аргументов.

## На собеседовании

**Вопрос с собеседования:** «Можно ли через `-X` переопределить неэкспортированную переменную из другого пакета (например, `config.version`)?»
**Ответ:** Да! Формат флага: `-X 'module_path/package_name.variableName=value'`.
