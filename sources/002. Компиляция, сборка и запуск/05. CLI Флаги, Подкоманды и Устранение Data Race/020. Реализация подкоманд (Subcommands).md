# Реализация подкоманд (Subcommands) через flag.NewFlagSet

## Условие

Реализуй подкоманду через `flag`: `app add --x 5 --y 3` → 8, `app sub --x 5 --y 3` → 2. Используй `flag.NewFlagSet`.

## Теория

Для создания утилит с несколькими действиями (по аналогии с `git commit`, `git push`, `docker run`) используется **`flag.NewFlagSet`**.

Каждый `FlagSet` представляет собой независимый набор флагов со своими правилами парсинга:
- `addCmd = flag.NewFlagSet("add", flag.ExitOnError)`
- `subCmd = flag.NewFlagSet("sub", flag.ExitOnError)`

## Решение по шагам

1. Проверяем наличие подкоманды через `os.Args[1]`.
2. Используем конструкцию `switch os.Args[1]`.
3. Парсим срез `cmd.Parse(os.Args[2:])` для выбранной команды.
4. Выполняем соответствующую математическую операцию.

## Код решения

**`main.go`**

```go
package main

import (
	"flag"
	"fmt"
	"os"
)

func main() {
	if len(os.Args) < 2 {
		fmt.Println("Использование: app <add|sub> [флаги]")
		os.Exit(1)
	}

	// 1. Подкоманда add
	addCmd := flag.NewFlagSet("add", flag.ExitOnError)
	addX := addCmd.Int("x", 0, "Первое слагаемое")
	addY := addCmd.Int("y", 0, "Второе слагаемое")

	// 2. Подкоманда sub
	subCmd := flag.NewFlagSet("sub", flag.ExitOnError)
	subX := subCmd.Int("x", 0, "Уменьшаемое")
	subY := subCmd.Int("y", 0, "Вычитаемое")

	switch os.Args[1] {
	case "add":
		addCmd.Parse(os.Args[2:])
		fmt.Printf("%d + %d = %d\n", *addX, *addY, *addX+*addY)
	case "sub":
		subCmd.Parse(os.Args[2:])
		fmt.Printf("%d - %d = %d\n", *subX, *subY, *subX-*subY)
	default:
		fmt.Printf("Неизвестная команда: %s. Доступны: add, sub\n", os.Args[1])
		os.Exit(1)
	}
}
```

**`Терминал`**

```bash
# Тестирование сложения

# 15 + 27 = 42

# Тестирование вычитания
go run . sub --x=100 --y=42
# 100 - 42 = 58
```

## Под капотом

`flag.NewFlagSet` создает изолированную структуру `FlagSet` со своим словарем флагов и буфером вывода справки `Usage`.

## Подводные камни

- Передача в `cmd.Parse(os.Args[1:])` вместо `os.Args[2:]`: приведет к ошибке разбора, так как имя самой подкоманды попадет в парсер флагов.

## На собеседовании

**Вопрос с собеседования:** «Когда стоит перейти со стандартного `flag.NewFlagSet` на `github.com/spf13/cobra`?»
**Ответ:** Когда CLI разрастается до вложенных подкоманд (`app cluster node drain`), требует автодополнения (shell completion), валидации аргументов и флагов уровней `PersistentFlags` (общих для всех дочерних команд).
