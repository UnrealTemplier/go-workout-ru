# Динамическое инстанцирование объектов через reflect.New и reflect.MakeSlice

## Условие

**Динамическое создание объектов.**: Используя `reflect.New` и `reflect.MakeSlice`, создайте слайс заданного типа, переданного через `reflect.Type`. Заполните его значениями и верните как `interface{}`.

## Теория

Пакет `reflect` позволяет создавать абсолютно новые экземпляры любых типов во время выполнения программы без использования операторов `new` или `make`:

1. **`reflect.New(t reflect.Type) reflect.Value`**:
   Выделяет в куче память под значение типа `t`, обнуляет ее и возвращает `reflect.Value`, содержащий **указатель `*t`** на вновь созданный объект (аналог оператора `new(T)`).
   Чтобы получить доступ к самой созданной структуре, вызывают `.Elem()`.

2. **`reflect.MakeSlice(sliceType reflect.Type, len int, cap int) reflect.Value`**:
   Динамический аналог встроенной функции `make([]T, len, cap)`.
   В качестве первого аргумента функция ожидает именно тип среза (`sliceType.Kind() == reflect.Slice`).

3. **`reflect.Append(slice reflect.Value, elems ...reflect.Value) reflect.Value`**:
   Динамический аналог функции `append`, возвращающий новый заголовок среза.

## Решение по шагам

1. Создадим функцию `CreateAndFillSlice(elemType reflect.Type, count int) any`.
2. Сконструируем тип среза через `reflect.SliceOf(elemType)`.
3. Аллоцируем срез с помощью `reflect.MakeSlice(sliceType, 0, count)`.
4. В цикле динамически создадим элементы через `reflect.New(elemType).Elem()`.
5. Заполним элементы тестовыми данными и добавим в срез через `reflect.Append`.
6. Вернем полученный срез в виде `any` и проверим его тип.

## Код решения

**`dynamic_create.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

type Product struct {
	SKU   string
	Price float64
}

// CreateAndFillSlice динамически создает []T и наполняет N элементами
func CreateAndFillSlice(elemType reflect.Type, count int) any {
	// 1. Получаем тип слайса []T
	sliceType := reflect.SliceOf(elemType)

	// 2. Создаем срез с начальной длиной 0 и емкостью count
	sliceVal := reflect.MakeSlice(sliceType, 0, count)

	// 3. Динамически создаем и наполняем элементы
	for i := 1; i <= count; i++ {
		// reflect.New возвращает указатель *T, Elem() дает саму структуру T
		newElem := reflect.New(elemType).Elem()

		if elemType.Kind() == reflect.Int {
			newElem.SetInt(int64(i * 10))
		} else if elemType == reflect.TypeOf(Product{}) {
			newElem.FieldByName("SKU").SetString(fmt.Sprintf("SKU-%03d", i))
			newElem.FieldByName("Price").SetFloat(float64(i) * 99.9)
		}

		// Добавляем в слайс (аналог slice = append(slice, elem))
		sliceVal = reflect.Append(sliceVal, newElem)
	}

	return sliceVal.Interface()
}

func main() {
	// Создаем []int динамически
	intSliceAny := CreateAndFillSlice(reflect.TypeOf(0), 3)
	intSlice, ok := intSliceAny.([]int)
	fmt.Printf("Сгенерирован []int (ok=%v): %v\n", ok, intSlice)

	// Создаем []Product динамически
	prodSliceAny := CreateAndFillSlice(reflect.TypeOf(Product{}), 2)
	prodSlice, ok := prodSliceAny.([]Product)
	fmt.Printf("Сгенерирован []Product (ok=%v):\n", ok)
	for _, p := range prodSlice {
		fmt.Printf("  -> %+v\n", p)
	}
}
```

## Под капотом

Вызов `reflect.MakeSlice` обращается напрямую к внутренней функции аллокатора рантайма:
`runtime.makeslice(et *_type, len, cap int) unsafe.Pointer`.
Рантайм проверяет переполнение разрядной сетки (`cap * et.size`) и выделяет непрерывный блок памяти в куче через `mallocgc`. Возвращаемый `reflect.Value` упаковывает указатель на слайс-хедер `reflect.SliceHeader` (`Data`, `Len`, `Cap`).

## Подводные камни

1. **Передача elemType вместо sliceType в MakeSlice:** Если передать `reflect.TypeOf(0)` вместо `reflect.SliceOf(reflect.TypeOf(0))`, `MakeSlice` упадет с паникой: `reflect.MakeSlice of non-slice type`.

## На собеседовании

**Вопрос с собеседования в Т-Банк:** «Как в ORM (например, GORM) устроен метод db.Find(&users), если users передан как пустой срез любого типа?»
**Ответ:** ORM берет `reflect.ValueOf(users).Elem()`, получает тип среза, проверяет `Kind() == reflect.Slice` и извлекает тип элемента через `sliceType.Elem()`. 
По мере чтения строк из SQL-результата (`sql.Rows`) ORM создает новые структуры через `reflect.New(elemType)`, мапит колонки на поля структуры, а затем добавляет готовые структуры в срез через `reflect.Append` либо прямую запись по индексу `slice.Index(i)`.
