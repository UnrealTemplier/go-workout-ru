# Закон №1: Извлечение типа и проверка базового Kind

## Условие

**Закон №1 (Interface -> Reflection Object)**: Объяви переменную `x float64 = 3.4`. Используй `reflect.TypeOf(x)` и `reflect.ValueOf(x)`. Выведи их. Вызови метод `Kind()` у типа, чтобы убедиться, что базовый вид — это именно `float64`.

## Теория

Первый закон рефлексии гласит: *Рефлексия переходит от интерфейсного значения к объекту рефлексии*.

При вызове функции с параметром `interface{}`:
```go
func TypeOf(i any) Type
```
Значение `x float64 = 3.4` копируется и оборачивается в интерфейс.
- `reflect.Type` — это интерфейс, описывающий статические свойства типа.
- `reflect.Value` — конкретная структура, хранящая данные значения и тип.
Метод `Kind()` можно вызывать как у `reflect.Type`, так и у `reflect.Value`. В обоих случаях он возвращает константу типа `reflect.Kind` (`reflect.Float64`).

## Решение по шагам

1. Объявим переменную `x float64 = 3.4`.
2. Вызовем `reflect.TypeOf(x)` и сохраним в `t`.
3. Вызовем `reflect.ValueOf(x)` и сохраним в `v`.
4. Сравним `t.Kind()` и `v.Kind()` с константой `reflect.Float64`.
5. Выведем детальный отчет об объектах.

## Код решения

**`law1_float.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

func main() {
	var x float64 = 3.4

	// Извлекаем Type и Value
	t := reflect.TypeOf(x)
	v := reflect.ValueOf(x)

	fmt.Printf("Тип (reflect.Type):    %v\n", t)
	fmt.Printf("Значение (reflect.Value): %v\n", v)

	// Проверяем Kind у типа и значения
	typeKind := t.Kind()
	valKind := v.Kind()

	fmt.Printf("t.Kind(): %v (константа: %d)\n", typeKind, int(typeKind))
	fmt.Printf("v.Kind(): %v (константа: %d)\n", valKind, int(valKind))

	if typeKind == reflect.Float64 && valKind == reflect.Float64 {
		fmt.Println("Проверка пройдена: базовый вид переменной строго равен reflect.Float64.")
	}
}
```

## Под капотом

При вызове `reflect.TypeOf(x)` компилятор подставляет тип `float64` в метаданные вызова. В рантайме создается объект `*reflect.rtype`, который реализует интерфейс `reflect.Type`.
Поскольку `float64` является примитивным скалярным типом, он представляется глобальной статической структурой в сегменте данных бинарного файла, поэтому вызов `TypeOf` для базовых скаляров не требует динамического выделения памяти в куче.

## Подводные камни

1. **Сравнение типов через == вместо Kind:** Сравнение `t == reflect.TypeOf(float64(0))` проверяет строгое равенство типов. Если у вас объявлен `type MyFloat float64`, проверка на равенство типу вернет `false`, а проверка `t.Kind() == reflect.Float64` вернет `true`.

## На собеседовании

**Вопрос с собеседования в Wildberries:** «Что быстрее при проверке типа в горячем цикле: v.Kind() == reflect.String или v.Type().String() == "string"?»
**Ответ:** `v.Kind() == reflect.String` в сотни раз быстрее. Метод `Kind()` выполняет одну битовую операцию маскирования над целым числом флага `v.flag`. Метод `t.String()` генерирует строку, что может вызвать аллокацию памяти и строковое сравнение байт за байтом.
