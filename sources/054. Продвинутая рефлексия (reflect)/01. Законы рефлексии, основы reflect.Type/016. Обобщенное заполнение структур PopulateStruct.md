# Обобщенное заполнение структур PopulateStruct с маппингом полей и конвертацией типов

## Условие

**Динамическое заполнение структур**: Напишите обобщенную функцию `PopulateStruct(obj any, data map[string]any) error`. Функция должна с помощью рефлексии обходить поля структуры `obj` (переданной по указателю) и заполнять их значениями из мапы `data`, если имена ключей совпадают с именами полей или значениями тегов `db` (например, `db:"user_id"`). Обеспечьте базовую конвертацию несовместимых числовых типов (например, `int` из мапы в `int64` структуры).

## Теория

Функция динамического заполнения структур из словаря (`map[string]any` -> `struct`) — основа всех баз данных (ORM), HTTP-биндинга параметров и декодеров конфигураций (`viper`, `mapstructure`).

### Ключевые требования к промышленному Hydrator:
1. **Проверка адресуемости:** `obj` обязан быть ненулевым указателем на структуру (`val.Kind() == reflect.Pointer && val.Elem().Kind() == reflect.Struct`).
2. **Разрешение имен полей:** Поиск значения в мапе производится сначала по тегу (например, `db:"user_id"`), а если тег отсутствует — по оригинальному имени поля структуры.
3. **Безопасная конвертация типов:** Значение из мапы может иметь тип `int`, а поле структуры — `int64` или `uint32`. Нельзя просто вызвать `field.Set()`, так как возникнет паника несовпадения типов. Необходимо проверить `val.Type().ConvertibleTo(targetType)` и применить `val.Convert(targetType)`.
4. **Пропуск неэкспортированных полей:** Проверка `field.CanSet()` защищает от попыток записи в приватные поля.

## Решение по шагам

1. Создадим функцию `PopulateStruct(obj any, data map[string]any) error`.
2. Проверим, что `obj` — валидный указатель на структуру.
3. Получим `reflect.Value` разыменованной структуры через `.Elem()`.
4. Проитерируемся по полям структуры.
5. Для каждого поля определим ключ поиска (из тега `db` или имени поля).
6. Если ключ есть в мапе, проверим совпадение или конвертируемость типов и запишем значение через `.Set()`.
7. Протестируем на структуре `UserProfile` со смешанными типами (`int` -> `int64`).

## Код решения

**`populate_struct.go`**

```go
package main

import (
	"errors"
	"fmt"
	"reflect"
)

type UserProfile struct {
	ID       int64  `db:"user_id"`
	Username string `db:"username"`
	Rating   float64
	Active   bool `db:"is_active"`
}

// PopulateStruct заполняет поля структуры значениями из мапы
func PopulateStruct(obj any, data map[string]any) error {
	v := reflect.ValueOf(obj)
	if v.Kind() != reflect.Pointer || v.IsNil() {
		return errors.New("obj должен быть ненулевым указателем на структуру")
	}

	elem := v.Elem()
	if elem.Kind() != reflect.Struct {
		return errors.New("obj должен указывать на структуру")
	}

	elemType := elem.Type()

	for i := 0; i < elem.NumField(); i++ {
		fieldVal := elem.Field(i)
		fieldType := elemType.Field(i)

		// Пропускаем неэкспортированные поля
		if !fieldVal.CanSet() {
			continue
		}

		// Определяем ключ поиска: из тега `db` или имя поля
		lookupKey := fieldType.Name
		if tagVal, ok := fieldType.Tag.Lookup("db"); ok && tagVal != "" && tagVal != "-" {
			lookupKey = tagVal
		}

		mapVal, exists := data[lookupKey]
		if !exists {
			continue
		}

		if mapVal == nil {
			continue
		}

		srcVal := reflect.ValueOf(mapVal)
		targetType := fieldVal.Type()

		// Если типы идентичны - прямое присваивание
		if srcVal.Type().AssignableTo(targetType) {
			fieldVal.Set(srcVal)
			continue
		}

		// Если типы можно сконвертировать (например, int -> int64 или float32 -> float64)
		if srcVal.Type().ConvertibleTo(targetType) {
			convertedVal := srcVal.Convert(targetType)
			fieldVal.Set(convertedVal)
			continue
		}

		return fmt.Errorf("невозможно присвоить ключ %q типа %v в поле %s типа %v",
			lookupKey, srcVal.Type(), fieldType.Name, targetType)
	}

	return nil
}

func main() {
	var profile UserProfile

	rawMap := map[string]any{
		"user_id":   1001, // int в мапе, но int64 в структуре!
		"username":  "ivan_petrov",
		"Rating":    4.95,
		"is_active": true,
	}

	if err := PopulateStruct(&profile, rawMap); err != nil {
		fmt.Printf("Ошибка гидратации: %v\n", err)
		return
	}

	fmt.Printf("Успешно заполнено: %+v\n", profile)
	fmt.Printf("ID тип: %T, значение: %d\n", profile.ID, profile.ID)
}
```

ℹ️ Универсальный заполнитель структур с поддержкой тегов и конвертации типов

**`Терминал`**

```bash
go run populate_struct.go
# Успешно заполнено: {ID:1001 Username:ivan_petrov Rating:4.95 Active:true}
# ID тип: int64, значение: 1001
```

## Под капотом

Внутри метода `srcVal.Convert(targetType)` рантайм Go обращается к таблице конвертации типов.
Если оба типа числовые (целые или с плавающей точкой), компилятор эмулирует машинные инструкции ассемблера:
- `MOVSLQ` для расширения знака при конвертации `int32` -> `int64`.
- `CVTSD2SS` для конвертации чисел с плавающей точкой `float64` -> `float32`.
При этом сохраняются все семантические правила языка Go (включая возможное усечение старших бит при сужающих преобразованиях).

## Подводные камни

1. **Неожиданное усечение при переполнении:** Конвертация `int64(100000)` в поле структуры типа `int8` через `Convert()` завершится успешно без ошибки, но значение переполнится и станет искаженным. Для надежности промышленный код добавляет проверку диапазона значений перед конвертацией.

## На собеседовании

**Вопрос с собеседования в Ozon:** «Как работает популярная библиотека github.com/mitchellh/mapstructure? Почему стандартный json.Unmarshal не справляется со структурой map[string]any?»
**Ответ:** Стандартный `json.Unmarshal` распаковывает числа в `float64` (по спецификации JSON). Если в структуре поле `int64`, попытка десериализации без рефлексивной адаптации завершится ошибкой типов.
`mapstructure` через рефлексию обходит поля структуры, сопоставляет ключи мапы с тегами и выполняет умную слабую конвертацию (Weak Decoding): строки парсит в числа через `strconv`, `float64` приводит к `int64` и декодирует вложенные структуры рекурсивно.
