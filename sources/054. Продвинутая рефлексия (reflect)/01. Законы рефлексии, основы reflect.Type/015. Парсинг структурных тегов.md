# Парсинг структурных тегов и декларативная валидация полей

## Условие

**Структурные теги.**: Создайте структуру с полями, помеченными кастомными тегами: `db:"column_name" validate:"required,min=5"`. Напишите парсер, который извлекает эти теги через `reflect.Type.Field(i).Tag` и валидирует значения полей без использования `encoding/json`. Объясните, почему теги — это просто строки, и как `reflect` их не интерпретирует.

## Теория

**Структурные теги (Struct Tags)** в Go — это обычные строковые литералы (`string`), ассоциированные с полями структуры во время компиляции.

### Синтаксис соглашения о тегах (Convention):
Компилятор Go не накладывает ограничений на содержимое тега — это может быть любая строка. Однако стандартная библиотека Go (`reflect.StructTag`) задает общепринятый формат ключ-значение:
```text
key1:"val1,val2" key2:"val3"
```
Ключ отделяется двоеточием, а значение заключается в двойные кавычки.

### Методы работы с тегами:
1. **`tag.Get(key string) string`**: Возвращает значение по ключу. Если ключ отсутствует или тег пуст, возвращает `""`.
2. **`tag.Lookup(key string) (string, bool)`**: Рекомендуемый метод. Позволяет отличить случай, когда ключ отсутствует (`ok == false`), от случая, когда ключ присутствует, но имеет пустое значение `key:""` (`ok == true`).

Рефлексия **не интерпретирует** теги автоматически. Вся семантика валидации, маппинга БД или сериализации пишется разработчиком вручную.

## Решение по шагам

1. Определим структуру `Account` с тегами `db` и `validate`.
2. Реализуем функцию `ValidateStruct(v any) []error`.
3. Извлечем тип структуры через `reflect.TypeOf(v)`.
4. В цикле обойдем поля структуры с помощью `t.NumField()` и `t.Field(i)`.
5. Извлечем тег `validate` с помощью `field.Tag.Lookup("validate")`.
6. Реализуем проверку правил `required` (не пустое) и `min=N` (минимальная длина строки).

## Код решения

**`struct_tags_validator.go`**

```go
package main

import (
	"fmt"
	"reflect"
	"strconv"
	"strings"
)

type UserAccount struct {
	Username string `db:"username" validate:"required,min=5"`
	Email    string `db:"email" validate:"required"`
	Age      int    `db:"age" validate:"min=18"`
}

func ValidateStruct(obj any) []error {
	var errs []error
	val := reflect.ValueOf(obj)
	typ := reflect.TypeOf(obj)

	// Если передан указатель, разыменовываем
	if typ.Kind() == reflect.Pointer {
		val = val.Elem()
		typ = typ.Elem()
	}

	if typ.Kind() != reflect.Struct {
		return []error{fmt.Errorf("ожидалась структура, получено %v", typ.Kind())}
	}

	for i := 0; i < typ.NumField(); i++ {
		field := typ.Field(i)
		fieldVal := val.Field(i)

		ruleStr, ok := field.Tag.Lookup("validate")
		if !ok {
			continue // Тег отсутствует
		}

		rules := strings.Split(ruleStr, ",")
		for _, rule := range rules {
			rule = strings.TrimSpace(rule)

			// Проверка required
			if rule == "required" {
				if fieldVal.IsZero() {
					errs = append(errs, fmt.Errorf("поле %s обязательно для заполнения (required)", field.Name))
				}
			}

			// Проверка min=N
			if strings.HasPrefix(rule, "min=") {
				minLimit, _ := strconv.Atoi(strings.TrimPrefix(rule, "min="))
				if fieldVal.Kind() == reflect.String {
					if len(fieldVal.String()) < minLimit {
						errs = append(errs, fmt.Errorf("длина поля %s (%d) меньше минимума %d", field.Name, len(fieldVal.String()), minLimit))
					}
				} else if fieldVal.Kind() == reflect.Int {
					if fieldVal.Int() < int64(minLimit) {
						errs = append(errs, fmt.Errorf("значение поля %s (%d) меньше допустимого %d", field.Name, fieldVal.Int(), minLimit))
					}
				}
			}
		}
	}

	return errs
}

func main() {
	invalidUser := UserAccount{
		Username: "bob", // меньше 5 символов
		Email:    "",    // пустое (required)
		Age:      16,    // меньше 18
	}

	errs := ValidateStruct(invalidUser)
	fmt.Printf("Обнаружено ошибок валидации: %d\n", len(errs))
	for _, err := range errs {
		fmt.Printf("  [Ошибка] %v\n", err)
	}

	validUser := UserAccount{
		Username: "alexander",
		Email:    "alex@bigtech.ru",
		Age:      25,
	}
	validErrs := ValidateStruct(validUser)
	fmt.Printf("\nВалидный пользователь: ошибок %d\n", len(validErrs))
}
```

## Под капотом

Внутри бинарного файла Go теги полей структуры компилируются в единую таблицу метаданных типов в секции `.rodata`.
Метод `field.Tag.Get(key)` сканирует строку тега с помощью парсера регулярных правил: ищет подстроку `key:"value"`, обрабатывает экранированные символы `\"` и возвращает срез байт. Метод не кэширует результаты, поэтому в высоконагруженных библиотеках (например, `go-playground/validator`) метаданные тегов парсятся один раз и сохраняются во внутренний кэш мапы.

## Подводные камни

1. **Опечатка в формате тега:** Если написать `validate: "required"` (с пробелом после двоеточия), парсер `Tag.Get` или `Tag.Lookup` не сможет распарсить тег и вернет пустую строку, так как пробел нарушает спецификацию формата.

## На собеседовании

**Вопрос с собеседования в Wildberries:** «Почему метод Tag.Lookup предпочтительнее Tag.Get при написании собственных сериализаторов?»
**Ответ:** Метод `Get` возвращает пустую строку как при отсутствии тега, так и при наличии пустого тега: `json:""`. 
Метод `Lookup` возвращает второй булев флаг `ok`. Это критично, например, для флага `omitempty` или когда пустое значение тега имеет особое значение (например, `db:"-"` для исключения поля или `env:",required"`).
