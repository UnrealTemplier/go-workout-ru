# Универсальный динамический сеттер полей структуры SetFieldByName

## Условие

**Универсальный сеттер.**: Напишите функцию, которая принимает указатель на структуру, имя поля в виде строки и значение. Используя рефлексию, установите значение поля (с обработкой ошибок типов и несуществующих полей).

## Теория

Разработка универсального сеттера — классическая задача при создании конфигураторов, валидаторов и ORM.

### Требования к надежному сеттеру:
1. **Проверка указателя:** Аргумент обязан быть указателем (`Kind() == reflect.Pointer`), иначе изменить данные в вызывающем коде невозможно.
2. **Поиск поля:** Метод `elem.FieldByName(fieldName)` ищет поле по строковому имени. Если поле отсутствует, метод возвращает нулевой `Value` (`!field.IsValid()`).
3. **Проверка прав записи:** Если поле не экспортировано (начинается со строчной буквы), `field.CanSet()` вернет `false`.
4. **Контроль типов данных:** Тип передаваемого значения обязан либо в точности совпадать с типом поля (`AssignableTo`), либо поддерживать динамическое приведение (`ConvertibleTo`).

## Решение по шагам

1. Определим функцию `SetFieldByName(target any, fieldName string, value any) error`.
2. Проверим валидность структуры по указателю.
3. Найдем поле и проверим `IsValid()` и `CanSet()`.
4. Проверим совместимость типов и выполним конвертацию при необходимости.
5. Запишем значение через `field.Set()`.
6. Протестируем на структуре с обработкой штатных и ошибочных ситуаций.

## Код решения

**`generic_setter.go`**

```go
package main

import (
	"errors"
	"fmt"
	"reflect"
)

type AppSettings struct {
	AppName    string
	Port       int
	MaxClients uint32
	privateKey string
}

// SetFieldByName динамически изменяет поле структуры по имени
func SetFieldByName(target any, fieldName string, value any) error {
	v := reflect.ValueOf(target)
	if v.Kind() != reflect.Pointer || v.IsNil() {
		return errors.New("target должен быть ненулевым указателем на структуру")
	}

	elem := v.Elem()
	if elem.Kind() != reflect.Struct {
		return errors.New("target должен указывать на структуру")
	}

	field := elem.FieldByName(fieldName)
	if !field.IsValid() {
		return fmt.Errorf("поле %q не существует в структуре %s", fieldName, elem.Type().Name())
	}

	if !field.CanSet() {
		return fmt.Errorf("поле %q неэкспортировано и недоступно для изменения", fieldName)
	}

	valToSet := reflect.ValueOf(value)
	if !valToSet.IsValid() {
		// Передан nil
		field.Set(reflect.Zero(field.Type()))
		return nil
	}

	targetType := field.Type()

	// 1. Прямая совместимость
	if valToSet.Type().AssignableTo(targetType) {
		field.Set(valToSet)
		return nil
	}

	// 2. Возможность конвертации (например, int в uint32)
	if valToSet.Type().ConvertibleTo(targetType) {
		converted := valToSet.Convert(targetType)
		field.Set(converted)
		return nil
	}

	return fmt.Errorf("несовместимые типы: невозможно присвоить %v в поле %s типа %v",
		valToSet.Type(), fieldName, targetType)
}

func main() {
	cfg := AppSettings{AppName: "OldApp", Port: 3000}
	fmt.Printf("До изменений: %+v\n", cfg)

	// Успешная модификация
	_ = SetFieldByName(&cfg, "AppName", "ProductionGateway")
	_ = SetFieldByName(&cfg, "Port", 8080)
	_ = SetFieldByName(&cfg, "MaxClients", 5000) // Конвертация int -> uint32

	fmt.Printf("После успешных изменений: %+v\n", cfg)

	// Обработка ошибок
	err1 := SetFieldByName(&cfg, "NonExistentField", "test")
	fmt.Printf("Ошибка 1: %v\n", err1)

	err2 := SetFieldByName(&cfg, "privateKey", "secret")
	fmt.Printf("Ошибка 2: %v\n", err2)

	err3 := SetFieldByName(&cfg, "Port", "not-a-number")
	fmt.Printf("Ошибка 3: %v\n", err3)
}
```

ℹ️ Универсальный и безопасный сеттер полей структуры с валидацией ошибок

# До изменений: {AppName:OldApp Port:3000 MaxClients:0 privateKey:}
# После успешных изменений: {AppName:ProductionGateway Port:8080 MaxClients:5000 privateKey:}

# Ошибка 2: поле "privateKey" неэкспортировано и недоступно для изменения

## Под капотом

Метод `field.Set(val)` производит бинарное копирование содержимого `val.ptr` в `field.ptr` через низкоуровневую функцию рантайма `typedmemmove(typ, dst, src)`.
Если тип содержит указатели, рантайм дополнительно активирует write barrier для сборщика мусора GC, чтобы обеспечить консистентность триколорной раскраски объектов.

## Подводные камни

1. **Присваивание nil без reflect.Zero:** Если передать `value = nil`, вызов `reflect.ValueOf(nil)` вернет невалидный `Value`. Попытка сделать `field.Set(valToSet)` вызовет панику. Для обнуления поля используют `reflect.Zero(field.Type())`.

## На собеседовании

**Вопрос с собеседования в VK:** «Как сбросить поле структуры любого типа в его дефолтное нулевое значение с помощью reflect?»
**Ответ:** 
```go
field.Set(reflect.Zero(field.Type()))
```
Метод `reflect.Zero(t)` возвращает неизменяемое нулевое значение указанного типа, которое безопасно передается в `field.Set()`.
