# Динамическое управление хеш-таблицами: MakeMap, SetMapIndex и итерация MapRange

## Условие

**Динамическое создание map.**: Создайте `map[string]int` через `reflect.MakeMap`, заполните через `SetMapIndex`, обойдите через `MapRange`. Объясните, почему `MapRange` не позволяет модифицировать map во время итерации (runtime проверка), и как это отличается от `for range` в нативном Go.

## Теория

Работа с хеш-таблицами через рефлексию опирается на три ключевых системных вызова рантайма:
1. **`reflect.MakeMap(t reflect.Type) reflect.Value`**:
   Создает новую пустую мапу типа `t` (где `t.Kind() == reflect.Map`).
2. **`v.SetMapIndex(key, elem reflect.Value)`**:
   Устанавливает значение для ключа. Если `elem` равен нулевому `reflect.Value{}` (`!elem.IsValid()`), соответствующий ключ **удаляется** из мапы (аналог встроенной функции `delete(m, k)`).
3. **`v.MapRange() *reflect.MapIter`**:
   Инициализирует итератор. Метод `iter.Next()` переходит к следующему элементу.

### Семантика модификации во время итерации:
В нативном Go цикл `for k, v := range m` разрешает добавлять и удалять элементы во время итерации (при этом добавленные элементы могут как появиться, так и не появиться в текущей итерации согласно спецификации).
Однако при конкурентной модификации мапы из разных горутин рантайм Go немедленно аварийно завершает процесс с фатальной паникой `fatal error: concurrent map iteration and map write` (контролируется флагом `hmap.flags & hashWriting`). Рефлексивный метод `SetMapIndex` подчиняется тем же жестким правилам безопасности памяти.

## Решение по шагам

1. Создадим тип мапы `mapType := reflect.TypeOf(map[string]int{})`.
2. Аллоцируем мапу через `reflect.MakeMap(mapType)`.
3. Заполним мапу элементами с помощью `SetMapIndex`.
4. Удалим один элемент, передав нулевой `reflect.Value{}` в качестве значения.
5. Выполним итерацию через `MapRange` и выведем оставшиеся ключи и значения.

## Код решения

**`map_dynamic_ops.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

func main() {
	// 1. Определение типа и создание мапы
	mapType := reflect.TypeOf(map[string]int{})
	mapVal := reflect.MakeMap(mapType)

	fmt.Printf("Создана динамическая мапа типа: %s\n", mapVal.Type())

	// 2. Вставка значений через SetMapIndex
	mapVal.SetMapIndex(reflect.ValueOf("CPU"), reflect.ValueOf(8))
	mapVal.SetMapIndex(reflect.ValueOf("RAM"), reflect.ValueOf(64))
	mapVal.SetMapIndex(reflect.ValueOf("SSD"), reflect.ValueOf(1024))
	mapVal.SetMapIndex(reflect.ValueOf("GPU"), reflect.ValueOf(2))

	fmt.Printf("После вставки (длина %d): %v\n", mapVal.Len(), mapVal.Interface())

	// 3. Удаление ключа "GPU" (передача нулевого reflect.Value)
	mapVal.SetMapIndex(reflect.ValueOf("GPU"), reflect.Value{})
	fmt.Printf("После удаления ключа 'GPU' (длина %d): %v\n\n", mapVal.Len(), mapVal.Interface())

	// 4. Итерация через MapRange
	fmt.Println("Итерация через MapRange:")
	iter := mapVal.MapRange()
	for iter.Next() {
		k := iter.Key()
		v := iter.Value()
		fmt.Printf("  • %-5s => %d (Type: %s)\n",
			k.String(), v.Int(), v.Type())
	}
}
```

**`Терминал`**

```bash
go run map_dynamic_ops.go
# Создана динамическая мапа типа: map[string]int
# После вставки (длина 4): map[CPU:8 GPU:2 RAM:64 SSD:1024]

# 
# Итерация через MapRange:
#   • CPU   => 8 (Type: int)

#   • SSD   => 1024 (Type: int)
```

## Под капотом

Под капотом `mapVal.SetMapIndex(k, v)` вызывает рантайм-функцию:
`runtime.mapassign(t, h, key)` или `runtime.mapdelete(t, h, key)`.
Если передан нулевой `reflect.Value`, рантайм проверяет флаг `hashWriting` и вызывает удаление ключа из бакета мапы `runtime.mapdelete`. Это подтверждает, что рефлексия не изобретает отдельный механизм хранения, а является прямым программным интерфейсом к ядру рантайма Go.

## Подводные камни

1. **Удаление ключа через nil:** Попытка удалить ключ передачей `reflect.ValueOf(nil)` приведет к панике, так как `ValueOf(nil)` создает invalid `Value`, но компилятор требует явный нулевой литерал `reflect.Value{}`.

## На собеседовании

**Вопрос с собеседования в Wildberries:** «Как удалить ключ из мапы через reflect.Value, если в пакете reflect нет метода DeleteMapIndex?»
**Ответ:** Для удаления ключа вызывают метод `SetMapIndex(key, reflect.Value{})`. Передача пустого неинициализированного объекта `reflect.Value{}` служит для рантайма сигналом вызвать внутреннюю функцию `mapdelete`.
