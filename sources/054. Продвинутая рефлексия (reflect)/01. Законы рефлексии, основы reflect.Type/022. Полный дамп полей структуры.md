# Полный дамп полей структуры через reflect.ValueOf.NumField()

## Условие

**[Чтение структуры]**: Передай структуру в функцию. Используй `reflect.ValueOf(v).NumField()` и `Field(i)`, чтобы вывести имена всех полей и их значения.

## Теория

Для извлечения значений полей структуры объект `reflect.Value` предоставляет метод:
- **`v.Field(i int) reflect.Value`**: Возвращает значение \(i\)-го поля.
Важно учитывать:
1. `reflect.Value.NumField()` возвращает число полей только для значения типа `Struct`.
2. Чтобы узнать имя поля, необходимо обратиться к дескриптору типа: `v.Type().Field(i).Name`.
3. Для безопасного чтения неэкспортированных полей нельзя вызывать `.Interface()`, но можно проверять флаг `fieldVal.CanInterface()`.

## Решение по шагам

1. Определим структуру `FlightInfo` со смешанными типами полей.
2. Реализуем функцию `DumpStruct(v any)`.
3. Извлечем `reflect.ValueOf(v)` и проверим, что это структура.
4. Проитерируемся по полям, получив имена из `t.Field(i)` и значения из `v.Field(i)`.
5. Выведем результат в консоль.

## Код решения

**`dump_struct.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

type FlightInfo struct {
	FlightNumber string
	Altitude     int
	SpeedKmh     float64
	IsOnSchedule bool
}

func DumpStruct(v any) {
	val := reflect.ValueOf(v)
	if val.Kind() == reflect.Pointer {
		val = val.Elem()
	}

	if val.Kind() != reflect.Struct {
		fmt.Printf("Ошибка: ожидалась структура, получено %v\n", val.Kind())
		return
	}

	typ := val.Type()
	fmt.Printf("Дамп структуры [%s] (всего полей: %d):\n", typ.Name(), val.NumField())

	for i := 0; i < val.NumField(); i++ {
		fieldMeta := typ.Field(i)
		fieldVal := val.Field(i)

		var displayVal any = "<unexported>"
		if fieldVal.CanInterface() {
			displayVal = fieldVal.Interface()
		}

		fmt.Printf("  • %-15s (%-8s) = %v\n",
			fieldMeta.Name, fieldMeta.Type.String(), displayVal)
	}
}

func main() {
	flight := FlightInfo{
		FlightNumber: "SU-100",
		Altitude:     10500,
		SpeedKmh:     850.5,
		IsOnSchedule: true,
	}

	DumpStruct(flight)
}
```

ℹ️ Универсальный дамп полей и значений структуры

**`Терминал`**

```bash
go run dump_struct.go
# Дамп структуры [FlightInfo] (всего полей: 4):
#   • FlightNumber    (string  ) = SU-100
#   • Altitude        (int     ) = 10500
#   • SpeedKmh        (float64 ) = 850.5
#   • IsOnSchedule    (bool    ) = true
```

## Под капотом

Метод `val.Field(i)` вычисляет адрес поля структуры в памяти со смещением:
`fieldPtr = unsafe.Pointer(uintptr(val.ptr) + fieldMeta.Offset)`.
Возвращаемый `reflect.Value` связывается с дескриптором типа поля и наследует флаги доступности от родительской структуры.

## Подводные камни

1. **Передача структуры по указателю без Elem():** Если передать `&flight`, вызов `val.NumField()` немедленно приведет к панике: `reflect: call of reflect.Value.NumField on ptr Value`.

## На собеседовании

**Вопрос с собеседования в Т-Банк:** «Как в Go реализован вывод %+v в пакете fmt? Использует ли он рефлексию?»
**Ответ:** Да, функция `fmt.Printf("%+v", structVal)` использует пакет `reflect` под капотом. Она определяет `v.Kind() == reflect.Struct`, обходит поля через `NumField()` и выводит пары `ИмяПоля:Значение`, форматируя каждое поле рекурсивно.
