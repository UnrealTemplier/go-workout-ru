# Базовый универсальный инспектор типов Inspect(v interface{})

## Условие

**[База]**: Напиши функцию `Inspect(v interface{})`, которая принимает любой аргумент. Используй `reflect.TypeOf` и `reflect.ValueOf`, чтобы вывести имя типа, категорию (Kind: struct, int, string) и значение.

## Теория

При исследовании типов в Go критически важно различать две базовые концепции пакета `reflect`:
1. **Тип (`reflect.Type`):** Представляет собой конкретное определение типа в коде программы. Например: `main.User`, `int`, `time.Duration`, `[]string`. Метод `t.Name()` возвращает короткое имя типа, а `t.String()` — его полное представление с пакетом.
2. **Категория / Базовый вид (`reflect.Kind`):** Перечисление базовых строительных блоков системы типов Go. Определено в `reflect.Kind` как набор констант: `reflect.Int`, `reflect.String`, `reflect.Slice`, `reflect.Struct`, `reflect.Func` и т.д.

Различные типы могут иметь один и тот же `Kind`. Например, определенный пользователем тип `type UserID int64` имеет `Type == "main.UserID"`, но его базовый вид `Kind == reflect.Int64`.

## Решение по шагам

1. Объявим функцию `Inspect(v interface{})`.
2. Проверим случай `v == nil`.
3. Извлечем `reflect.TypeOf(v)` и определим имя типа.
4. Извлечем `reflect.ValueOf(v)` и определим `v.Kind()`.
5. Выведем текущее значение через форматирование или `v.Interface()`.
6. Проверим работу функции на базовых типах и кастомных структурах.

## Код решения

**`base_inspector.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

type CustomStatus int

type User struct {
	ID   int
	Name string
}

func Inspect(v interface{}) {
	if v == nil {
		fmt.Println("Значение: nil, Тип: <nil>, Kind: Invalid")
		return
	}

	t := reflect.TypeOf(v)
	val := reflect.ValueOf(v)

	typeName := t.Name()
	if typeName == "" {
		typeName = t.String() // Для составных и анонимных типов
	}

	fmt.Printf("Имя типа: %-15s | Категория (Kind): %-12s | Значение: %v\n",
		typeName, val.Kind(), val.Interface())
}

func main() {
	Inspect(100)
	Inspect("Backend Go")
	Inspect(CustomStatus(2))
	Inspect(User{ID: 1, Name: "Алексей"})
	Inspect([]string{"A", "B", "C"})
	Inspect(nil)
}
```

## Под капотом

Каждое значение интерфейса содержит указатель на глобальную статическую структуру метаданных `runtime._type`. 
Поле `_type.kind` представляет собой 8-битный беззнаковый целочисленный дескриптор:
- Нижние 5 бит задают категорию типа (`KindMask = 0x1f`).
- Верхние биты используются как внутренние флаги рантайма (`kindDirectIface`, `kindGCProg`).
Метод `Type.Kind()` маскирует верхние служебные биты и возвращает чистый `reflect.Kind`.

## Подводные камни

1. **Алиасы типов:** В Go `byte` является псевдонимом для `uint8`, а `rune` — для `int32`. `reflect.TypeOf(byte(1)).Name()` вернет `"uint8"`, так как для компилятора это абсолютно один и тот же тип.
2. **Игнорирование nil:** Передача `nil` в `reflect.TypeOf(v)` без проверки приведет к возврату `nil`, а попытка вызвать `t.Name()` выбросит nil pointer dereference.

## На собеседовании

**Вопрос с собеседования в Т-Банк:** «Как в Go определить, что переданный в функцию интерфейс v any является слайсом произвольного типа ([]int, []string, []User)?»
**Ответ:** Проверить через свитч типов `v.(type)` для всех возможных типов невозможно. Единственный корректный способ — использовать рефлексию:
```go
if v != nil && reflect.TypeOf(v).Kind() == reflect.Slice {
    // v гарантированно является срезом
}
```
