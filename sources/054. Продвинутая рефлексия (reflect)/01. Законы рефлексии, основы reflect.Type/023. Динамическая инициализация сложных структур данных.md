# Динамическая инициализация сложных структур данных: New, MakeSlice, MakeMap, MakeChan

## Условие

**Создание новых значений**: Используйте `reflect.New(typ)` для создания указателя на новый zero-value. Используйте `reflect.MakeSlice`, `reflect.MakeMap`, `reflect.MakeChan`.

## Теория

Пакет `reflect` предоставляет исчерпывающий инструментарий для динамического создания любых типов данных в рантайме:
1. **`reflect.New(t Type) Value`**: Создает новое значение в куче, обнуляет его и возвращает указатель `*t`.
2. **`reflect.MakeSlice(sliceType Type, len, cap int) Value`**: Создает срез `[]T`.
3. **`reflect.MakeMap(mapType Type) Value`** или **`MakeMapWithSize`**: Инициализирует новую хеш-таблицу `map[K]V`.
4. **`reflect.MakeChan(chanType Type, buffer int) Value`**: Создает канал `chan T` с указанным размером буфера.

Все эти функции принимают дескриптор типа `reflect.Type` и возвращают полноценный объект `reflect.Value`, готовый к передаче в функции и манипуляциям.

## Решение по шагам

1. Динамически создадим указатель на структуру через `reflect.New`.
2. Динамически создадим срез через `reflect.MakeSlice`.
3. Динамически создадим мапу через `reflect.MakeMap` и запишем пару ключ-значение через `SetMapIndex`.
4. Динамически создадим буферизованный канал через `reflect.MakeChan` и отправим в него сообщение через `Send`.
5. Проверим полученные структуры данных в стандартном коде Go.

## Код решения

**`dynamic_allocations.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

type ServerNode struct {
	ID string
}

func main() {
	// 1. reflect.New (создание указателя на zero-value)
	ptrVal := reflect.New(reflect.TypeOf(ServerNode{}))
	fmt.Printf("1. reflect.New: тип %s, значение: %+v\n",
		ptrVal.Type(), ptrVal.Interface())

	// 2. reflect.MakeSlice
	sliceType := reflect.TypeOf([]string{})
	sliceVal := reflect.MakeSlice(sliceType, 2, 5)
	sliceVal.Index(0).SetString("Alpha")
	sliceVal.Index(1).SetString("Beta")
	fmt.Printf("2. reflect.MakeSlice: тип %s, срез: %v (len=%d, cap=%d)\n",
		sliceVal.Type(), sliceVal.Interface(), sliceVal.Len(), sliceVal.Cap())

	// 3. reflect.MakeMap
	mapType := reflect.TypeOf(map[string]int{})
	mapVal := reflect.MakeMap(mapType)
	mapVal.SetMapIndex(reflect.ValueOf("MetricA"), reflect.ValueOf(100))
	mapVal.SetMapIndex(reflect.ValueOf("MetricB"), reflect.ValueOf(200))
	fmt.Printf("3. reflect.MakeMap: тип %s, мапа: %v\n",
		mapVal.Type(), mapVal.Interface())

	// 4. reflect.MakeChan
	chanType := reflect.TypeOf(make(chan int))
	chanVal := reflect.MakeChan(chanType, 2) // буфер 2
	chanVal.Send(reflect.ValueOf(42))
	msgVal, ok := chanVal.Recv()
	fmt.Printf("4. reflect.MakeChan: получено из канала: %d (ok=%v)\n",
		msgVal.Int(), ok)
}
```

ℹ️ Динамическая аллокация структур, слайсов, мап и каналов

**`Терминал`**

```bash
go run dynamic_allocations.go
# 1. reflect.New: тип *main.ServerNode, значение: &{ID:}
# 2. reflect.MakeSlice: тип []string, срез: [Alpha Beta] (len=2, cap=5)
# 3. reflect.MakeMap: тип map[string]int, мапа: map[MetricA:100 MetricB:200]
# 4. reflect.MakeChan: получено из канала: 42 (ok=true)
```

## Под капотом

Каждая фабричная функция пакета `reflect` напрямую вызывает соответствующую внутреннюю функцию рантайма Go:
- `reflect.New` -> `runtime.newobject(t)`
- `reflect.MakeSlice` -> `runtime.makeslice(t, len, cap)`
- `reflect.MakeMap` -> `runtime.makemap(t, cap, nil)`
- `reflect.MakeChan` -> `runtime.makechan(t, size)`
Это означает, что динамически созданные объекты полностью идентичны объектам, созданным операторами `new` и `make`, и управляются стандартным Garbage Collector.

## Подводные камни

1. **Небуферизованный канал и Send:** Если создать небуферизованный канал `MakeChan(chanType, 0)` и вызвать `chanVal.Send()`, текущая горутина заблокируется навечно, если никто не читает из другого конца.

## На собеседовании

**Вопрос с собеседования в Ozon:** «Можно ли с помощью рефлексии создать канал, направление которого ограничено только отправкой (chan<- int)?»
**Ответ:** Да. Для этого создают тип канала через `reflect.ChanOf(reflect.SendDir, reflect.TypeOf(0))`, а затем инициализируют дескриптор через `reflect.MakeChan`.
