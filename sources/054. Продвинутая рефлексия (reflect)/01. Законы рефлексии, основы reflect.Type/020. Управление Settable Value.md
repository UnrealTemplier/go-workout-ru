# Управление Settable Value и модификация целых чисел через SetInt

## Условие

**Settable value**: Используйте `reflect.ValueOf(&x).Elem()` для получения settable value. Измените значение через `SetInt(20)`.

## Теория

Для целочисленных типов пакет `reflect` предоставляет метод `SetInt(x int64)`.

Особенности `SetInt`:
1. Метод принимает аргумент наибольшей разрядности — `int64`.
2. Метод работает со всеми знаковыми целочисленными типами Go: `int`, `int8`, `int16`, `int32`, `int64`.
3. Для беззнаковых типов (`uint`, `uint8`, `uint64`) необходимо использовать парный метод `SetUint(x uint64)`. Вызов `SetInt` на беззнаковом значении вызовет панику.
4. Значение автоматически усекается до разрядности целевого типа с проверкой на переполнение.

## Решение по шагам

1. Объявим переменную `x int = 10`.
2. Получим `v := reflect.ValueOf(&x).Elem()`.
3. Проверим `v.CanSet()`.
4. Вызовем `v.SetInt(20)`.
5. Проверим результат на переменных разных знаковых разрядностей (`int8`, `int32`).

## Код решения

**`set_int_demo.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

func main() {
	var x int = 10
	var small int8 = 5

	fmt.Printf("До изменения: x=%d, small=%d\n", x, small)

	// Модифицируем int
	vx := reflect.ValueOf(&x).Elem()
	if vx.CanSet() {
		vx.SetInt(20)
	}

	// Модифицируем int8 через универсальный SetInt(int64)
	vSmall := reflect.ValueOf(&small).Elem()
	if vSmall.CanSet() {
		vSmall.SetInt(127) // Максимальное значение для int8
	}

	fmt.Printf("После изменения: x=%d, small=%d\n", x, small)
}
```

ℹ️ Корректная мутация знаковых целых чисел через SetInt

**`Терминал`**

```bash
go run set_int_demo.go
# До изменения: x=10, small=5
# После изменения: x=20, small=127
```

## Под капотом

Внутри `reflect/value.go` метод `SetInt` проверяет переполнение:
```go
func (v Value) SetInt(x int64) {
    v.mustBeAssignable()
    switch k := v.kind(); k {
    case Int:
        *(*int)(v.ptr) = int(x)
    case Int8:
        *(*int8)(v.ptr) = int8(x)
    // ...
    }
}
```
Функция `mustBeAssignable()` валидирует флаг `flagAddr` и отсутствие `flagRO`.

## Подводные камни

1. **Вызов SetInt на uint:** Вызов `SetInt` на беззнаковом типе `uint` вызовет панику: `reflect: call of reflect.Value.SetInt on uint Value`. Всегда проверяйте `v.Kind()` перед выбором между `SetInt` и `SetUint`.

## На собеседовании

**Вопрос с собеседования в Авито:** «Почему SetInt принимает int64, а не int? Как это влияет на производительность?»
**Ответ:** Чтобы не плодить десяток специализированных методов (`SetInt8`, `SetInt16`, `SetInt32`), авторы Go выбрали наибольший 64-битный контейнер. Передача `int64` по регистру на 64-битных процессорах не создает накладных расходов и позволяет одним методом обновлять любые знаковые типы данных.
