# Паттерн Field Index Caching: ускорение рефлексии в 10 раз

## Условие

**Кэширование индексов полей**: Сохраните индексы полей (`Type.FieldByName()` возвращает `StructField` с `Index`) при первой обработке типа. Используйте `Value.FieldByIndex()` для последующих обращений. Это в 10x быстрее.

## Теория

В реальных Enterprise-приложениях на Go кэширование метаданных — ключевой инструмент оптимизации.

### Архитектурный паттерн Metadata Precomputing:
1. При старте приложения структура анализируется один раз.
2. Для каждого поля сохраняются:
   - Имя поля.
   - Срез индексов `Index []int` (включая вложенные структуры).
   - Дескриптор типа.
3. Метаданные сохраняются в компактную неизменяемую структуру или массив.
4. В рантайме обработчик обращается к полю через `v.FieldByIndex(cachedMeta.Index)`.

Это переводит поиск полей из класса сложности \(O(N)\) (строковое сканирование) в \(O(1)\) (прямой доступ по смещению массива).

## Решение по шагам

1. Создадим структуру `OrderEvent` с вложенными метаданными.
2. Реализуем кэш `FastFieldAccessor` на базе предварительно вычисленных `StructField.Index`.
3. Сравним время доступа 1 000 000 раз через `FieldByName` и через кэшированный `FieldByIndex`.
4. Подтвердим 10-кратное ускорение.

## Код решения

**`cached_field_accessor.go`**

```go
package main

import (
	"fmt"
	"reflect"
	"time"
)

type Metadata struct {
	TraceID string
}

type OrderEvent struct {
	Meta    Metadata
	OrderID int64
	Amount  float64
}

// FastFieldAccessor хранит предварительно вычисленные индексы полей
type FastFieldAccessor struct {
	indices map[string][]int
}

func NewFastAccessor(t reflect.Type) *FastFieldAccessor {
	if t.Kind() == reflect.Pointer {
		t = t.Elem()
	}

	acc := &FastFieldAccessor{
		indices: make(map[string][]int),
	}

	// Обходим все поля, включая поля вложенных структур
	var scanFields func(curType reflect.Type, parentIndex []int)
	scanFields = func(curType reflect.Type, parentIndex []int) {
		for i := 0; i < curType.NumField(); i++ {
			field := curType.Field(i)
			fullIndex := append(append([]int{}, parentIndex...), field.Index...)

			acc.indices[field.Name] = fullIndex

			if field.Type.Kind() == reflect.Struct {
				scanFields(field.Type, fullIndex)
			}
		}
	}

	scanFields(t, nil)
	return acc
}

func (a *FastFieldAccessor) Get(v reflect.Value, fieldName string) reflect.Value {
	idx, ok := a.indices[fieldName]
	if !ok {
		return reflect.Value{}
	}
	return v.FieldByIndex(idx)
}

func main() {
	event := OrderEvent{
		Meta:    Metadata{TraceID: "trace-xyz-999"},
		OrderID: 777001,
		Amount:  12500.50,
	}

	val := reflect.ValueOf(event)
	accessor := NewFastAccessor(val.Type())

	const N = 1_000_000

	// 1. Поиск через медленный FieldByName
	start := time.Now()
	var sum1 float64
	for i := 0; i < N; i++ {
		sum1 += val.FieldByName("Amount").Float()
	}
	tSlow := time.Since(start)

	// 2. Доступ через кэшированный FieldByIndex
	start = time.Now()
	var sum2 float64
	for i := 0; i < N; i++ {
		sum2 += accessor.Get(val, "Amount").Float()
	}
	tFast := time.Since(start)

	fmt.Printf("Контрольные суммы: %.2f == %.2f\n\n", sum1, sum2)
	fmt.Printf("FieldByName (без кэша):    %10v (%.2f нс/оп)\n", tSlow, float64(tSlow.Nanoseconds())/N)
	fmt.Printf("FieldByIndex (с кэшем):    %10v (%.2f нс/оп)\n\n", tFast, float64(tFast.Nanoseconds())/N)

	fmt.Printf("Фактическое ускорение: в %.1f раз!\n", float64(tSlow)/float64(tFast))
}
```

## Под капотом

Срез `field.Index` содержит плоский список целочисленных смещений в иерархии типов.
Когда вызывается `v.FieldByIndex([]int{0, 1})`, рантайм заменяет дорогостоящий строковый поиск на две тривиальные операции индексации среза. Это полностью исключает выделение памяти в куче и делает доступ предсказуемым по времени.

## Подводные камни

1. **Изменение емкости при append(parentIndex, ...):** При рекурсивном сканировании необходимо копировать срез индексов `append([]int{}, ...)`, иначе вызовы `append` в дочерних ветках могут перезаписать родительский срез памяти.

## На собеседовании

**Вопрос с собеседования в Касперский:** «Как организовать потокобезопасный кэш аксессоров для произвольных структур в продакшене?»
**Ответ:** Используют `sync.Map` или паттерн RCU (Read-Copy-Update) с `sync.RWMutex`:
```go
var cache sync.Map // map[reflect.Type]*FastFieldAccessor
func GetAccessor(t reflect.Type) *FastFieldAccessor {
    if acc, ok := cache.Load(t); ok {
        return acc.(*FastFieldAccessor)
    }
    newAcc := NewFastAccessor(t)
    actual, _ := cache.LoadOrStore(t, newAcc)
    return actual.(*FastFieldAccessor)
}
```
