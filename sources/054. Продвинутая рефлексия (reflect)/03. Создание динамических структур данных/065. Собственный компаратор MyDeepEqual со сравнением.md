# Собственный компаратор MyDeepEqual со сравнением приватных полей

## Условие

**DeepEqual своими руками**: Стандартный `reflect.DeepEqual` медленный. Напиши свою функцию `MyDeepEqual(a, b any) bool`, которая через рефлексию сравнивает две структуры по полям. Поддержи сравнение даже неэкспортируемых (приватных) полей.

## Теория

Стандартный `reflect.DeepEqual` является универсальным, но страдает от высоких накладных расходов:
1. Выделяет память под карту `visited` при каждом сравнении.
2. Проверяет интерфейсы и циклические ссылки даже там, где их заведомо нет.
3. Не позволяет тонко настраивать логику (например, игнорировать служебные поля кэша).

### Сравнение приватных полей:
При обычном обращении к приватному полю через `val.Field(i)` метод `CanInterface()` возвращает `false`, а вызов `.Interface()` приводит к панике.
Однако в собственном компараторе мы можем безопасно читать примитивные значения неэкспортированных полей через специализированные типизированные геттеры:
- `field.Int()` — для целых чисел.
- `field.String()` — для строк.
- `field.Bool()` — для булевых значений.
- `field.Float()` — для чисел с плавающей точкой.
Это позволяет полноценно сравнивать даже приватные поля структур без паник и без использования небезопасного пакета `unsafe`!

## Решение по шагам

1. Создадим функцию `MyDeepEqual(a, b any) bool`.
2. Проверим совпадение типов через `reflect.TypeOf`.
3. Для структур обойдем все поля от `0` до `NumField()-1`.
4. Для каждого поля вызовем сравнение с поддержкой приватных полей через типизированные геттеры.
5. Протестируем на структуре с приватными полями `account` и проверим корректность детекции различий.

## Код решения

**`my_deep_equal.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

type SecureUser struct {
	ID       int64
	Username string
	password string // Приватное поле
	salt     string // Приватное поле
}

func MyDeepEqual(a, b any) bool {
	if a == nil || b == nil {
		return a == b
	}

	va := reflect.ValueOf(a)
	vb := reflect.ValueOf(b)

	if va.Type() != vb.Type() {
		return false
	}

	return compareValues(va, vb)
}

func compareValues(v1, v2 reflect.Value) bool {
	if !v1.IsValid() || !v2.IsValid() {
		return v1.IsValid() == v2.IsValid()
	}

	switch v1.Kind() {
	case reflect.Struct:
		for i := 0; i < v1.NumField(); i++ {
			f1 := v1.Field(i)
			f2 := v2.Field(i)
			if !compareValues(f1, f2) {
				return false
			}
		}
		return true

	case reflect.Int, reflect.Int8, reflect.Int16, reflect.Int32, reflect.Int64:
		// Безопасное чтение даже неэкспортированных целых чисел
		return v1.Int() == v2.Int()

	case reflect.Uint, reflect.Uint8, reflect.Uint16, reflect.Uint32, reflect.Uint64:
		return v1.Uint() == v2.Uint()

	case reflect.String:
		// Безопасное чтение даже неэкспортированных строк
		return v1.String() == v2.String()

	case reflect.Bool:
		return v1.Bool() == v2.Bool()

	case reflect.Float32, reflect.Float64:
		return v1.Float() == v2.Float()

	case reflect.Slice:
		if v1.IsNil() || v2.IsNil() {
			return v1.IsNil() == v2.IsNil()
		}
		if v1.Len() != v2.Len() {
			return false
		}
		for i := 0; i < v1.Len(); i++ {
			if !compareValues(v1.Index(i), v2.Index(i)) {
				return false
			}
		}
		return true

	default:
		if v1.CanInterface() && v2.CanInterface() {
			return v1.Interface() == v2.Interface()
		}
		return false
	}
}

func main() {
	u1 := SecureUser{
		ID:       101,
		Username: "gopher",
		password: "secret_hash_A",
		salt:     "salt_1",
	}

	u2 := SecureUser{
		ID:       101,
		Username: "gopher",
		password: "secret_hash_A",
		salt:     "salt_1",
	}

	u3 := SecureUser{
		ID:       101,
		Username: "gopher",
		password: "DIFFERENT_HASH",
		salt:     "salt_1",
	}

	fmt.Printf("u1 и u2 равны: %v (ожидается true)\n", MyDeepEqual(u1, u2))
	fmt.Printf("u1 и u3 равны: %v (ожидается false: приватные поля не совпали!)\n", MyDeepEqual(u1, u3))
}
```

ℹ️ Полноценный DeepEqual с корректным сравнением приватных полей без unsafe

**`Терминал`**

```bash
go run my_deep_equal.go
# u1 и u2 равны: true (ожидается true)
# u1 и u3 равны: false (ожидается false: приватные поля не совпали!)
```

## Под капотом

Методы `v.Int()`, `v.String()` и др. считывают данные непосредственно по указателю `v.ptr` структуры без создания промежуточного интерфейса `any`.
Флаг `flagRO` блокирует только экспорт в интерфейс `Interface()`, но не блокирует чтение базовых типов, что делает специализированные геттеры идеальным инструментом безопасной инспекции памяти.

## Подводные камни

1. **Попытка сравнить приватное поле типа slice:** Если приватное поле является срезом или мапой, вызов `f1.Interface()` приведет к панике. Для приватных срезов необходимо обходить элементы через `f1.Index(i)` вручную.

## На собеседовании

**Вопрос с собеседования в Яндекс:** «Почему v.String() не паникует на приватном строковом поле структуры, а v.Interface() паникует?»
**Ответ:** `v.String()` возвращает примитивное значение `string`, не нарушая типобезопасности рантайма. 
`v.Interface()` упаковывает данные в интерфейс `any`. Если бы рантайм разрешил вызов `Interface()` на приватном поле, пользователь мог бы через утверждение типа или рефлексию получить прямой доступ к инкапсулированному типу чужого пакета, нарушив границы видимости.
