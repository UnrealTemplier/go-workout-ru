# Идентификация пакета объявления типа через Type.PkgPath()

## Условие

**PkgPath**: Изучите `Type.PkgPath()` для получения пакета, где определён тип (пустая строка для built-in типов).

## Теория

Метод `reflect.Type.PkgPath() string`:
Возвращает полностью определенный путь импорта (Import Path) пакета, в котором был объявлен данный тип.

### Правила возврата PkgPath:
1. **Пользовательские типы из пакетов:** Возвращает полный путь пакета (например, `github.com/gin-gonic/gin`, `main`, `time`).
2. **Встроенные примитивные типы (Built-in Types):** Для типов `int`, `string`, `bool`, `float64`, `error` метод возвращает **пустую строку `""`**!
3. **Безымянные составные типы (Unnamed Types):** Для указателей (`*User`), срезов (`[]int`), мап (`map[string]string`) метод также возвращает **пустую строку `""`**. Чтобы узнать пакет типа за указателем или элемента среза, необходимо сначала вызвать `t.Elem().PkgPath()`.

## Решение по шагам

1. Объявим кастомный тип `type LocalToken string`.
2. Исследуем `PkgPath()` для встроенного `string`, кастомного `LocalToken`, библиотечного `time.Time` и указателя `*time.Time`.
3. Реализуем функцию `IsBuiltinType(t reflect.Type) bool`.
4. Выведем результаты проверки.

## Код решения

**`pkg_path_demo.go`**

```go
package main

import (
	"fmt"
	"reflect"
	"time"
)

type LocalToken string

// IsBuiltinType определяет, является ли тип встроенным примитивом Go
func IsBuiltinType(t reflect.Type) bool {
	// Встроенные типы имеют непустое Name(), но пустой PkgPath()
	return t.PkgPath() == "" && t.Name() != ""
}

func main() {
	var s string = "test"
	var tok LocalToken = "tok-123"
	var tm time.Time = time.Now()
	var tmPtr *time.Time = &tm
	var slc []int = []int{1, 2}

	samples := []struct {
		label string
		t     reflect.Type
	}{
		{"Встроенный string", reflect.TypeOf(s)},
		{"Кастомный LocalToken", reflect.TypeOf(tok)},
		{"Библиотечный time.Time", reflect.TypeOf(tm)},
		{"Указатель *time.Time", reflect.TypeOf(tmPtr)},
		{"Срез []int", reflect.TypeOf(slc)},
	}

	fmt.Printf("%-25s | %-12s | %-15s | %s\n", "Описание", "Name()", "IsBuiltin?", "PkgPath()")
	fmt.Println("--------------------------------------------------------------------------------")

	for _, sample := range samples {
		t := sample.t
		fmt.Printf("%-25s | %-12q | %-15v | %q\n",
			sample.label, t.Name(), IsBuiltinType(t), t.PkgPath())
	}
}
```

ℹ️ Анализ путей импорта пакетов и выявление встроенных типов через PkgPath

**`Терминал`**

```bash
go run pkg_path_demo.go
# Описание                  | Name()       | IsBuiltin?      | PkgPath()
# --------------------------------------------------------------------------------
# Встроенный string         | "string"     | true            | ""
# Кастомный LocalToken      | "LocalToken" | false           | "main"
# Библиотечный time.Time    | "Time"       | false           | "time"
# Указатель *time.Time      | ""           | false           | ""
# Срез []int                | ""           | false           | ""
```

## Под капотом

В бинарном представлении Go строковые имена пакетов выносятся в общую секцию интернированных строк. В дескрипторе типа `rtype` поле смещения `pkgpath` ссылается на эту строку. Для безымянных типов и примитивов поле смещения равно нулю, что экономит память в заголовках исполняемого файла.

## Подводные камни

1. **Ошибочное определение составных типов как встроенных:** Если проверять только `t.PkgPath() == ""`, то срез `[]MyStruct` будет ошибочно признан встроенным типом, так как у него `PkgPath() == ""`. Обязательно проверяйте наличие `t.Name() != ""`.

## На собеседовании

**Вопрос с собеседования в Ozon:** «Как в генераторе документации Swagger / OpenAPI по типу определить, в каком пакете проекта объявлена DTO-модель?»
**Ответ:** Для разыменованного типа структуры вызывают `t.PkgPath()`. Он возвращает канонический путь импорта модуля Go (например, `gitlab.mycompany.ru/project/internal/dto`), что позволяет однозначно предотвратить коллизии имен моделей из разных пакетов в генерируемой OpenAPI-спецификации.
