# Рекурсивный валидатор DeepEqualReflect с поддержкой всех типов

## Условие

**Сравнение двух значений через рефлексию.**: Напишите функцию `DeepEqualReflect(a, b interface{}) bool`, которая сравнивает значения разных типов, обрабатывая указатели, слайсы, мапы и структуры рекурсивно.

## Теория

При реализации промышленного рефлексивного компаратора необходимо учитывать:
1. **Проверка nil-интерфейсов:** `a == nil || b == nil`.
2. **Проверка динамических типов:** Значения разных типов считаются неравными (`a.Type() != b.Type()`).
3. **Разрешение указателей:** Рекурсивный спуск по `Elem()`.
4. **Итерация по структурам:** Обход всех полей структуры через `v.Field(i)`.
5. **Итерация по слайсам и мапам:** Поэлементное сопоставление длин и содержимого.

## Решение по шагам

1. Реализуем функцию `DeepEqualReflect(a, b any) bool`.
2. Реализуем глубокое рекурсивное сравнение структур со сложными типами.
3. Протестируем на вложенных структурах, содержащих слайсы и указатели.
4. Убедимся в корректности обработки равенства и неравенства.

## Код решения

**`deep_equal_reflect.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

func DeepEqualReflect(a, b any) bool {
	if a == nil || b == nil {
		return a == b
	}

	va := reflect.ValueOf(a)
	vb := reflect.ValueOf(b)

	if va.Type() != vb.Type() {
		return false
	}

	return deepCompare(va, vb)
}

func deepCompare(v1, v2 reflect.Value) bool {
	if !v1.IsValid() || !v2.IsValid() {
		return v1.IsValid() == v2.IsValid()
	}

	switch v1.Kind() {
	case reflect.Pointer:
		if v1.IsNil() || v2.IsNil() {
			return v1.IsNil() == v2.IsNil()
		}
		return deepCompare(v1.Elem(), v2.Elem())

	case reflect.Struct:
		for i := 0; i < v1.NumField(); i++ {
			if !deepCompare(v1.Field(i), v2.Field(i)) {
				return false
			}
		}
		return true

	case reflect.Slice:
		if v1.IsNil() || v2.IsNil() {
			return v1.IsNil() == v2.IsNil()
		}
		if v1.Len() != v2.Len() {
			return false
		}
		for i := 0; i < v1.Len(); i++ {
			if !deepCompare(v1.Index(i), v2.Index(i)) {
				return false
			}
		}
		return true

	case reflect.Map:
		if v1.IsNil() || v2.IsNil() {
			return v1.IsNil() == v2.IsNil()
		}
		if v1.Len() != v2.Len() {
			return false
		}
		iter := v1.MapRange()
		for iter.Next() {
			v2Val := v2.MapIndex(iter.Key())
			if !v2Val.IsValid() || !deepCompare(iter.Value(), v2Val) {
				return false
			}
		}
		return true

	default:
		// Сравнение примитивных скаляров через Interface() ==
		return v1.Interface() == v2.Interface()
	}
}

type ComplexPayload struct {
	Title string
	Tags  []string
	Meta  map[string]int
}

func main() {
	p1 := ComplexPayload{
		Title: "Архитектура Go",
		Tags:  []string{"highload", "runtime"},
		Meta:  map[string]int{"v": 1},
	}

	p2 := ComplexPayload{
		Title: "Архитектура Go",
		Tags:  []string{"highload", "runtime"},
		Meta:  map[string]int{"v": 1},
	}

	p3 := ComplexPayload{
		Title: "Архитектура Go",
		Tags:  []string{"highload", "different"},
		Meta:  map[string]int{"v": 1},
	}

	fmt.Printf("DeepEqualReflect(p1, p2): %v (ожидается true)\n", DeepEqualReflect(p1, p2))
	fmt.Printf("DeepEqualReflect(p1, p3): %v (ожидается false)\n", DeepEqualReflect(p1, p3))
}
```

ℹ️ Универсальное глубокое сравнение любых структур данных

**`Терминал`**

```bash

# DeepEqualReflect(p1, p2): true (ожидается true)
# DeepEqualReflect(p1, p3): false (ожидается false)
```

## Под капотом

Для простых скаляров (int, string, bool) функция выполняет прямое сравнение через оператор `==`. Для составных типов спуск по дереву объектов продолжается до тех пор, пока не будут проверены все терминальные скаляры. Это обеспечивает полную детерминированность валидации.

## Подводные камни

1. **Сравнение неэкспортированных полей через Interface():** В ветке default вызов `v1.Interface()` упадет, если поле неэкспортировано. Для защиты проверяют `v1.CanInterface()` или сравнивают скаляры через свитч по `v1.Kind()`.

## На собеседовании

**Вопрос с собеседования в VK:** «Почему рекурсивный DeepEqualReflect может работать медленнее нативного сравнения в 100 раз?»
**Ответ:** Нативный код сравнивает структуры блоками машинных слов (`MEMCMP`). Рефлексивный компаратор выполняет десятки вызовов функций, свитчей по `Kind()`, аллокаций интерфейсов и проверок границ на каждое отдельное поле.
