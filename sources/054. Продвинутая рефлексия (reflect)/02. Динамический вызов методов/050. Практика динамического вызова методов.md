# Практика динамического вызова методов: структура со Shout

## Условие

**[Динамический вызов методов]**: Создай структуру с методом `Shout(msg string) string`. Получи метод через `reflect.ValueOf(v).MethodByName("Shout")`. Подготовь аргументы как `[]reflect.Value` и вызови `method.Call(args)`. Выведи результат.

## Теория

При динамическом вызове метода через `MethodByName`:
1. Рефлексия выполняет поиск в таблице методов типа получателя.
2. Возвращаемый объект `reflect.Value` представляет собой связанный метод (Bound Method), в котором получатель уже подставлен в первый невидимый параметр.
3. Аргументы функции передаются как срез `[]reflect.Value`.
4. Результат работы метода возвращается в виде среза `[]reflect.Value`, соответствующего списку возвращаемых параметров.

## Решение по шагам

1. Создадим структуру `Speaker` с методом `Shout(msg string) string`.
2. Получим `reflect.ValueOf(Speaker{})`.
3. Извлечем метод `Shout` через `MethodByName`.
4. Подготовим входной срез аргументов `in := []reflect.Value{reflect.ValueOf("внимание")}`.
5. Выполним вызов `method.Call(in)`.
6. Распакуем строковый результат через `.String()` или `.Interface()`.

## Код решения

**`speaker_shout.go`**

```go
package main

import (
	"fmt"
	"reflect"
	"strings"
)

type Speaker struct{}

func (s Speaker) Shout(msg string) string {
	return strings.ToUpper(msg) + "!!!"
}

func main() {
	sp := Speaker{}

	// 1. Получаем объект рефлексии
	v := reflect.ValueOf(sp)

	// 2. Ищем метод по имени
	method := v.MethodByName("Shout")
	if !method.IsValid() {
		panic("Метод Shout не найден!")
	}

	// 3. Подготавливаем аргументы
	args := []reflect.Value{
		reflect.ValueOf("рефлексия в действии"),
	}

	// 4. Вызываем метод
	results := method.Call(args)

	// 5. Выводим результат
	shoutedMsg := results[0].String()
	fmt.Printf("Результат вызова Shout: %s\n", shoutedMsg)
}
```

ℹ️ Пошаговый динамический вызов метода структуры

**`Терминал`**

```bash
go run speaker_shout.go
# Результат вызова Shout: РЕФЛЕКСИЯ В ДЕЙСТВИИ!!!
```

## Под капотом

Когда метод объявлен с value receiver `func (s Speaker) Shout(...)`, компилятор генерирует функцию `main.Speaker.Shout(s Speaker, msg string) string`.
Метод `v.MethodByName("Shout")` оборачивает указатель на функцию и копию значения `sp` в структуру `makeFuncImpl`. Вызов `.Call(args)` транслируется в обычный машинный вызов функции с передачей `sp` в качестве первого скрытого параметра.

## Подводные камни

1. **Неэкспортированный метод:** Если назвать метод `shout` со строчной буквы, `MethodByName` вернет нулевой `Value`, так как рефлексия видит только публичные методы.

## На собеседовании

**Вопрос с собеседования в VK:** «Что произойдет, если метод Shout вызовет panic() во время исполнения через reflect.Call?»
**Ответ:** Паника не перехватывается внутри `reflect.Call`. Она поднимется вверх по стеку в вызывающий код точно так же, как и при прямом вызове. Для перехвата паники вызов `method.Call` необходимо оборачивать в стандартный блок `defer recover()`.
