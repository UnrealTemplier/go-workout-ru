# Обобщенное добавление элементов в срез через reflect.Append

## Условие

**Append к срезу через reflect**: Реализуйте функцию, которая добавляет элемент к срезу любого типа через `reflect.Append(slice, value)`.

## Теория

Функция `reflect.Append` позволяет добавлять новые элементы в срез произвольного динамического типа.

### Сигнатура:
```go
func Append(s Value, x ...Value) Value
```
### Требования и правила:
1. Значение `s` обязано иметь `Kind() == reflect.Slice`.
2. Каждый добавляемый элемент `x` обязан быть совместим по типу с типом элементов среза (`s.Type().Elem()`).
3. Функция `Append` возвращает **новый объект `reflect.Value`**, инкапсулирующий обновленный заголовок среза. Как и в случае со стандартным `append(s, item)`, исходный `reflect.Value` среза не изменяется автоматически, если вместимости массива было недостаточно.
4. Чтобы модифицировать срез, переданный вызывающей стороной по указателю, необходимо присвоить возвращенное значение обратно в целевую ячейку: `sliceVal.Set(newSliceVal)`.

## Решение по шагам

1. Создадим универсальную функцию `GenericAppend(slicePtr any, item any) error`.
2. Проверим, что `slicePtr` — ненулевой указатель на срез (`reflect.Pointer` -> `reflect.Slice`).
3. Разыменуем указатель через `.Elem()`.
4. Проверим, что тип добавляемого элемента `item` соответствует типу элементов среза `s.Type().Elem()`.
5. Вызовем `reflect.Append(sliceVal, itemVal)`.
6. Присвоим результат обратно в срез через `sliceVal.Set()`.
7. Протестируем на срезах разных типов (`[]int` и `[]string`).

## Код решения

**`generic_append.go`**

```go
package main

import (
	"errors"
	"fmt"
	"reflect"
)

// GenericAppend добавляет элемент к срезу произвольного типа по указателю
func GenericAppend(slicePtr any, item any) error {
	vPtr := reflect.ValueOf(slicePtr)
	if vPtr.Kind() != reflect.Pointer || vPtr.IsNil() {
		return errors.New("ожидается ненулевой указатель на срез")
	}

	sliceVal := vPtr.Elem()
	if sliceVal.Kind() != reflect.Slice {
		return errors.New("указатель должен ссылаться на срез")
	}

	expectedElemType := sliceVal.Type().Elem()
	itemVal := reflect.ValueOf(item)

	if !itemVal.Type().AssignableTo(expectedElemType) {
		return fmt.Errorf("невозможно добавить элемент типа %v в срез типа %v",
			itemVal.Type(), sliceVal.Type())
	}

	// Выполняем добавление и обновляем заголовок среза
	newSlice := reflect.Append(sliceVal, itemVal)
	sliceVal.Set(newSlice)

	return nil
}

func main() {
	numbers := []int{10, 20}
	fmt.Printf("Исходный срез чисел: %v\n", numbers)
	_ = GenericAppend(&numbers, 30)
	_ = GenericAppend(&numbers, 40)
	fmt.Printf("После GenericAppend:  %v\n", numbers)

	words := []string{"Go", "Rust"}
	fmt.Printf("\nИсходный срез строк: %v\n", words)
	_ = GenericAppend(&words, "Zig")
	fmt.Printf("После GenericAppend: %v\n", words)

	// Ошибка типов
	err := GenericAppend(&numbers, "не число")
	fmt.Printf("\nОжидаемая ошибка типов: %v\n", err)
}
```

ℹ️ Универсальное добавление элементов в слайсы произвольного типа

## Под капотом

Под капотом `reflect.Append` считывает поля внутреннего заголовка `sliceHeader`. Если `len + 1 > cap`, рантайм вызывает процедуру `runtime.growslice`, выделяя новый расширенный массив в куче с коэффициентом роста (обычно x2 до 256 элементов и ~1.25x далее), копирует старые байты и добавляет новый элемент.
Вызов `sliceVal.Set(newSlice)` перезаписывает локальный заголовок `SliceHeader` по адресу указателя `slicePtr`.

## Подводные камни

1. **Передача среза по значению вместо указателя:** Если передать `numbers` вместо `&numbers`, внутри функции срез будет расширен, но вызывающий код изменений не увидит, так как заголовок среза был передан как копия.

## На собеседовании

**Вопрос с собеседования в VK:** «Как реализовать функцию reflect.AppendSlice, чтобы добавить один срез в конец другого?»
**Ответ:** Для объединения срезов в пакете `reflect` есть готовая функция `reflect.AppendSlice(s, t Value) Value`. Она эквивалентна нативной конструкции `s = append(s, t...)` и выполняет блочное копирование байт из среза `t` в срез `s` за одну операцию `typedmemmove`.
