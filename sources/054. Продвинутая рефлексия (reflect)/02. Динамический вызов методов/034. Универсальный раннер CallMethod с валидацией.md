# Универсальный раннер CallMethod с валидацией сигнатур

## Условие

**Вызов методов по имени.**: Создайте структуру с несколькими методами. Напишите функцию `CallMethod(obj interface{}, methodName string, args ...interface{}) ([]interface{}, error)`, которая ищет метод, проверяет аргументы и вызывает его.

## Теория

Надежная функция `CallMethod` должна реализовывать строгий контракт проверки предусловий:
1. Проверка существования метода по имени.
2. Проверка соответствия арности (количества аргументов).
3. Валидация типов каждого входного параметра: аргумент должен быть присваиваем (`AssignableTo`) целевому типу параметра функции.
4. Вызов метода и распаковка возвращаемых значений из `[]reflect.Value` в `[]any`.

## Решение по шагам

1. Объявим структуру `TextProcessor` с методами различной сигнатуры.
2. Реализуем функцию `CallMethod(obj any, methodName string, args ...any) ([]any, error)`.
3. Реализуем пошаговую валидацию аргументов.
4. Протестируем успешный вызов метода с параметрами и возвращаемым значением.
5. Протестируем ошибки: неверное имя, неверное число параметров, неверный тип аргумента.

## Код решения

**`call_method_runner.go`**

```go
package main

import (
	"errors"
	"fmt"
	"reflect"
	"strings"
)

type TextProcessor struct{}

func (t TextProcessor) Concat(a, b string) string {
	return a + " " + b
}

func (t TextProcessor) Repeat(s string, count int) string {
	return strings.Repeat(s, count)
}

// CallMethod универсально находит, проверяет и вызывает метод
func CallMethod(obj any, methodName string, args ...any) ([]any, error) {
	v := reflect.ValueOf(obj)
	if !v.IsValid() {
		return nil, errors.New("передан невалидный объект nil")
	}

	method := v.MethodByName(methodName)
	if !method.IsValid() {
		return nil, fmt.Errorf("метод %q не найден у типа %s", methodName, v.Type())
	}

	methodType := method.Type()
	if methodType.NumIn() != len(args) {
		return nil, fmt.Errorf("метод %s ожидает %d аргументов, передано %d",
			methodName, methodType.NumIn(), len(args))
	}

	in := make([]reflect.Value, len(args))
	for i, arg := range args {
		if arg == nil {
			in[i] = reflect.Zero(methodType.In(i))
			continue
		}

		argVal := reflect.ValueOf(arg)
		targetType := methodType.In(i)

		if !argVal.Type().AssignableTo(targetType) {
			return nil, fmt.Errorf("аргумент #%d имеет тип %v, ожидается %v",
				i, argVal.Type(), targetType)
		}
		in[i] = argVal
	}

	rawOut := method.Call(in)
	results := make([]any, len(rawOut))
	for i, out := range rawOut {
		results[i] = out.Interface()
	}

	return results, nil
}

func main() {
	proc := TextProcessor{}

	// Успешный вызов Concat
	res1, err := CallMethod(proc, "Concat", "Hello", "World")
	fmt.Printf("Concat: %v (ошибка: %v)\n", res1, err)

	// Успешный вызов Repeat
	res2, err := CallMethod(proc, "Repeat", "Go!", 3)
	fmt.Printf("Repeat: %v (ошибка: %v)\n", res2, err)

	// Ошибка в типах аргументов
	_, errType := CallMethod(proc, "Repeat", "Go!", "не число")
	fmt.Printf("Ошибка типа: %v\n", errType)

	// Ошибка в количестве аргументов
	_, errCount := CallMethod(proc, "Repeat", "Go!")
	fmt.Printf("Ошибка арности: %v\n", errCount)
}
```

ℹ️ Универсальный раннер методов с детальной валидацией ошибок

**`Терминал`**

```bash
go run call_method_runner.go
# Concat: [Hello World] (ошибка: <nil>)
# Repeat: [Go!Go!Go!] (ошибка: <nil>)
# Ошибка типа: аргумент #1 имеет тип string, ожидается int
# Ошибка арности: метод Repeat ожидает 2 аргументов, передано 1
```

## Под капотом

Метод `methodType.In(i)` возвращает дескриптор типа для \(i\)-го входного параметра. Метод `methodType.NumIn()` сообщает точное число параметров.
Если функция принимает переменное число параметров (variadic, `...T`), метод `methodType.IsVariadic()` возвращает `true`, а последний параметр представляется как срез `[]T`.

## Подводные камни

1. **Variadic методы:** Для вызова variadic-методов со слайсом параметров в рефлексии используют специализированный метод `method.CallSlice(in)` вместо `method.Call(in)`.

## На собеседовании

**Вопрос с собеседования в Ozon:** «Как вызвать функцию с переменным числом аргументов (variadic func) через рефлексию, не распаковывая каждый элемент вручную?»
**Ответ:** Для этого в `reflect.Value` предусмотрен метод `CallSlice(in []reflect.Value)`. Он ожидает, что последний элемент среза `in` является готовым слайсом целевого типа, и ядро рантайма передает его напрямую без дополнительной переупаковки.
