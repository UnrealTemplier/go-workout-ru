# Динамический синтез структур через reflect.StructOf и ограничения

## Условие

**`reflect.StructOf` и ограничения.**: Создайте динамическую структуру с полями `Name string` и `Age int` через `reflect.StructOf`. Создайте экземпляр, заполните поля. Объясните, почему полученный тип не может иметь методы, почему embedding не поддерживается полноценно, и как это ограничивает применение.

## Теория

Функция **`reflect.StructOf(fields []StructField) Type`** позволяет динамически во время выполнения программы сконструировать абсолютно новый тип структуры `struct`!

### Синтаксис:
Каждое поле описывается структурой `reflect.StructField`:
- `Name`: имя поля (обязано начинаться с заглавной буквы для экспорта).
- `Type`: дескриптор типа поля.
- `Tag`: строковый структурный тег (например, `json:"name"`).

### Фундаментальные ограничения reflect.StructOf:
1. **Невозможность добавления методов:** Полученный тип не может иметь методов (`t.NumMethod() == 0`), так как методы компилируются статически.
2. **Отсутствие статического имени:** Полученный тип является анонимным. Его нельзя использовать в type assertion: `val.(GeneratedStruct)` невозможно написать, так как этого типа не существует в коде до компиляции.
3. **Ограничения встраивания:** Анонимные поля создаются, но методы встроенных структур не промоутятся в динамический тип.

## Решение по шагам

1. Сформируем срез `[]reflect.StructField` для полей `Name string` и `Age int` с JSON-тегами.
2. Сконструируем тип через `reflect.StructOf`.
3. Создадим экземпляр новой структуры через `reflect.New(dynStructType).Elem()`.
4. Заполним поля значениями.
5. Выведем структуру и убедимся в правильности смещений и тегов.

## Код решения

**`struct_of_demo.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

func main() {
	// 1. Описываем поля будущей структуры
	fields := []reflect.StructField{
		{
			Name: "Name",
			Type: reflect.TypeOf(""),
			Tag:  `json:"user_name"`,
		},
		{
			Name: "Age",
			Type: reflect.TypeOf(0),
			Tag:  `json:"user_age"`,
		},
	}

	// 2. Создаем динамический тип структуры
	dynType := reflect.StructOf(fields)

	fmt.Printf("Динамический тип: %s\n", dynType.String())
	fmt.Printf("Размер в памяти:  %d байт\n", dynType.Size())
	fmt.Printf("Количество полей: %d\n\n", dynType.NumField())

	// 3. Создаем экземпляр этой структуры
	instance := reflect.New(dynType).Elem()

	// 4. Заполняем поля
	instance.FieldByName("Name").SetString("Анна")
	instance.FieldByName("Age").SetInt(27)

	// 5. Выводим данные
	fmt.Printf("Созданный объект: %+v\n", instance.Interface())
	for i := 0; i < dynType.NumField(); i++ {
		f := dynType.Field(i)
		fmt.Printf("  • Поле %s (%s) тег: %s = %v\n",
			f.Name, f.Type, f.Tag, instance.Field(i).Interface())
	}
}
```

ℹ️ Синтез типов структур в рантайме с помощью reflect.StructOf

**`Терминал`**

```bash
go run struct_of_demo.go
# Динамический тип: struct { Name string "json:\"user_name\""; Age int "json:\"user_age\"" }
# Размер в памяти:  24 байт
# Количество полей: 2
# 
# Созданный объект: {Name:Анна Age:27}
#   • Поле Name (string) тег: json:"user_name" = Анна
#   • Поле Age (int) тег: json:"user_age" = 27
```

## Под капотом

Внутри `reflect.StructOf` рантайм Go рассчитывает размер и выравнивание каждого поля:
1. Вычисляются смещения `Offset` с учетом выравнивания типов (8 байт для указателей/чисел на x86_64).
2. Генерируется GC-карта указателей (`gcdata`), чтобы Garbage Collector корректно сканировал поля созданной структуры.
3. Возвращается новый объект `structType`.

## Подводные камни

1. **Неэкспортированные поля в StructOf:** Если задать имя поля со строчной буквы (например, `name`), компилятор рантайма завершится ошибкой или создаст приватное поле, которое нельзя будет заполнить извне.

## На собеседовании

**Вопрос с собеседования в Wildberries:** «Где на практике может пригодиться reflect.StructOf, если к нему нельзя привязать методы?»
**Ответ:** `reflect.StructOf` активно используется в динамических драйверах баз данных и ORM при парсинге произвольных SQL-запросов (`SELECT col1, col2, ... FROM ...`). Если разработчик не объявил структуру заранее, ORM динамически конструирует тип структуры с нужными именами колонок и типами данных для последующей десериализации строк.
