# Рекурсивное глубокое клонирование структур данных (DeepCopy)

## Условие

**Копирование структуры через рефлексию.**: Реализуйте глубокое копирование структуры (включая вложенные слайсы и структуры) с помощью `reflect`, без использования сериализации/десериализации.

## Теория

Проблема глубокого копирования (Deep Copy) возникает, когда структура содержит ссылочные типы (срезы, мапы, указатели). Простое присваивание `clone := original` выполняет мелкое копирование (Shallow Copy): копируются только заголовки срезов и адреса указателей, в результате чего модификация данных в клоне ломает оригинал.

Использование `json.Marshal` + `json.Unmarshal` для клонирования считается грубым антипаттерном в HighLoad:
- Теряются типы данных (например, `time.Time` превращается в строку).
- Не копируются приватные поля.
- Огромные накладные расходы на парсинг текста.

Истинный `DeepCopy` через рефлексию рекурсивно выделяет новые участки памяти под каждый срез, мапу и вложенную структуру.

## Решение по шагам

1. Создадим рекурсивную функцию `DeepCopy(src any) any`.
2. Реализуем функцию копирования `deepCopyValue(v reflect.Value) reflect.Value`.
3. Поддержим базовые типы, структуры, слайсы и мапы.
4. Продемонстрируем, что изменение среза в клонированном объекте не затрагивает оригинал.

## Код решения

**`deep_copy_engine.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

type InnerConfig struct {
	Options []string
}

type ServiceConfig struct {
	Name  string
	Inner InnerConfig
	Tags  map[string]string
}

func DeepCopy(src any) any {
	if src == nil {
		return nil
	}
	val := reflect.ValueOf(src)
	return copyRecursive(val).Interface()
}

func copyRecursive(val reflect.Value) reflect.Value {
	if !val.IsValid() {
		return reflect.Value{}
	}

	switch val.Kind() {
	case reflect.Pointer:
		if val.IsNil() {
			return reflect.Zero(val.Type())
		}
		newPtr := reflect.New(val.Type().Elem())
		newPtr.Elem().Set(copyRecursive(val.Elem()))
		return newPtr

	case reflect.Slice:
		if val.IsNil() {
			return reflect.Zero(val.Type())
		}
		newSlice := reflect.MakeSlice(val.Type(), val.Len(), val.Cap())
		for i := 0; i < val.Len(); i++ {
			newSlice.Index(i).Set(copyRecursive(val.Index(i)))
		}
		return newSlice

	case reflect.Map:
		if val.IsNil() {
			return reflect.Zero(val.Type())
		}
		newMap := reflect.MakeMap(val.Type())
		iter := val.MapRange()
		for iter.Next() {
			kCopy := copyRecursive(iter.Key())
			vCopy := copyRecursive(iter.Value())
			newMap.SetMapIndex(kCopy, vCopy)
		}
		return newMap

	case reflect.Struct:
		newStruct := reflect.New(val.Type()).Elem()
		for i := 0; i < val.NumField(); i++ {
			f := val.Field(i)
			if newStruct.Field(i).CanSet() {
				newStruct.Field(i).Set(copyRecursive(f))
			}
		}
		return newStruct

	default:
		// Скалярные типы копируются по значению
		return val
	}
}

func main() {
	orig := ServiceConfig{
		Name: "AuthService",
		Inner: InnerConfig{
			Options: []string{"opt-A", "opt-B"},
		},
		Tags: map[string]string{"env": "prod"},
	}

	// Выполняем глубокое клонирование
	cloned := DeepCopy(orig).(ServiceConfig)

	// Модифицируем клон
	cloned.Inner.Options[0] = "MODIFIED-IN-CLONE"
	cloned.Tags["env"] = "staging"

	fmt.Println("=== Проверка независимости оригинала и клона ===")
	fmt.Printf("Оригинал Options[0]: %s (не изменился!)\n", orig.Inner.Options[0])
	fmt.Printf("Клон     Options[0]: %s\n", cloned.Inner.Options[0])

	fmt.Printf("Оригинал Tags[env]:   %s\n", orig.Tags["env"])
	fmt.Printf("Клон     Tags[env]:   %s\n", cloned.Tags["env"])
}
```

## Под капотом

Для каждого среза `reflect.MakeSlice` выделяет свежий сегмент кучи через `runtime.makeslice`. Для каждой хеш-таблицы создается новый заголовок `hmap` через `runtime.makemap`. Элементы глубоко копируются рекурсивно, разрывая любые связи по физическим адресам между оригиналом и копией.

## Подводные камни

1. **Циклические структуры:** Если в структурах присутствуют взаимные указатели (например, `nodeA.Next = nodeB; nodeB.Next = nodeA`), рекурсивный `copyRecursive` уйдет в бесконечный цикл. В production-клонерах передают мапу `visited map[uintptr]reflect.Value` для сохранения уже клонированных инстансов.

## На собеседовании

**Вопрос с собеседования в Т-Банк:** «В чем преимущество самописного рефлексивного DeepCopy перед кодированием в JSON и декодированием обратно?»
**Ответ:** 
1. **Скорость:** Рефлексивный обход в 5–15 раз быстрее, так как не переводит бинарные данные в текст JSON и обратно в парсере.
2. **Точность типов:** Сохраняются типы каналов, указатели, байтовые срезы и специальные структуры (`time.Time`, `net.IP`), которые при сериализации в JSON теряют исходный тип.
