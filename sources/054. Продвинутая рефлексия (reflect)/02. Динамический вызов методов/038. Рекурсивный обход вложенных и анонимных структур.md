# Рекурсивный обход вложенных и анонимных структур

## Условие

**Работа со вложенными и анонимными структурами**: Добавь в `User` анонимное поле `Address` (структуру). Напиши рекурсивную функцию на рефлексии, которая выводит плоский список всех полей, проваливаясь внутрь анонимных структур (проверяй `Kind() == reflect.Struct` и `Anonymous == true`).

## Теория

В языке Go композиция заменяет классическое наследование. Встраивание структуры без указания имени поля называется **анонимным / встраиваемым полем (Embedded / Anonymous Field)**:
```go
type Address struct { City string }
type User struct {
    Name string
    Address // анонимное встраивание
}
```
В коде на Go поля встроенной структуры промоутятся (Promoted Fields), и к ним можно обращаться напрямую: `u.City`.

### Рефлексивный анализ:
1. `fieldMeta.Anonymous == true`: указывает, что поле является встраиваемым.
2. `fieldMeta.Type.Kind() == reflect.Struct`: указывает, что встроенное поле является структурой.
3. Чтобы получить плоский список всех доступных полей, алгоритм обязан рекурсивно обойти дочернюю структуру, конкатенируя пути доступа (например, `User.Address.City`).

## Решение по шагам

1. Объявим структуры `GeoCoords`, `Address` (со встроенным `GeoCoords`) и `UserProfile` (со встроенным `Address`).
2. Напишем рекурсивную функцию `FlattenStructFields(t reflect.Type, prefix string)`.
3. Проверим `field.Anonymous && field.Type.Kind() == reflect.Struct`.
4. Для обычных полей выведем полное составное имя и тип.
5. Для анонимных — рекурсивно вызовем инспекцию дочернего типа.

## Код решения

**`flatten_embedded_structs.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

type Coordinates struct {
	Latitude  float64
	Longitude float64
}

type DeliveryAddress struct {
	City        string
	Street      string
	Coordinates // Анонимное встраивание второго уровня
}

type OrderUser struct {
	ID              int64
	Name            string
	DeliveryAddress // Анонимное встраивание первого уровня
}

// PrintFlattenedFields рекурсивно распечатывает плоский список всех полей
func PrintFlattenedFields(t reflect.Type, prefix string) {
	if t.Kind() == reflect.Pointer {
		t = t.Elem()
	}

	if t.Kind() != reflect.Struct {
		return
	}

	for i := 0; i < t.NumField(); i++ {
		field := t.Field(i)
		fullName := field.Name
		if prefix != "" {
			fullName = prefix + "." + field.Name
		}

		// Проверяем, является ли поле встроенной анонимной структурой
		if field.Anonymous && field.Type.Kind() == reflect.Struct {
			fmt.Printf(" [Embedded Scope] -> %s (%s)\n", fullName, field.Type.Name())
			PrintFlattenedFields(field.Type, fullName)
		} else {
			fmt.Printf("  • %-30s | Тип: %-10s | Offset: %d\n",
				fullName, field.Type.String(), field.Offset)
		}
	}
}

func main() {
	userType := reflect.TypeOf(OrderUser{})

	fmt.Printf("Иерархическая структура полей типа %s:\n\n", userType.Name())
	PrintFlattenedFields(userType, "")
}
```

## Под капотом

В рантайме Go встроенная структура хранится непосредственно внутри родительской структуры как непрерывный блок памяти.
Поле `field.Index []int` в `reflect.StructField` сохраняет последовательность индексов, необходимых для доступа к полю. Например, для доступа к `Latitude` индексная цепочка будет `[]int{2, 2, 0}`.
Метод `val.FieldByIndex([]int{2, 2, 0})` позволяет получить доступ к глубоко вложенному полю за один вызов без ручного цикла рекурсии!

## Подводные камни

1. **Коллизии имен встраиваемых полей (Field Shadowing):** Если внешняя структура объявляет поле с тем же именем, что и встроенная (`Name`), внешнее поле затеняет внутреннее. `val.FieldByName("Name")` вернет внешнее поле. Для доступа к затененному полю требуется явная цепочка индексов.

## На собеседовании

**Вопрос с собеседования в Wildberries:** «Как быстро получить значение глубоко вложенного поля структуры без написания рекурсивных циклов обхода?»
**Ответ:** Используют метод `reflect.Value.FieldByIndex(index []int)`. 
Метаданные структуры `reflect.Type.FieldByName` возвращают структуру `StructField`, содержащую поле `Index []int` (индексный путь). Передав этот срез в `v.FieldByIndex(field.Index)`, можно мгновенно адресовать поле любой глубины вложенности.
