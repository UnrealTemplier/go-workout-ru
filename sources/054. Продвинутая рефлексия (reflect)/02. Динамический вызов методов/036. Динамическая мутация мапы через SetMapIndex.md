# Динамическая мутация мапы через SetMapIndex

## Условие

**Модификация мапы**: Добавьте новую пару в мапу через `Value.SetMapIndex(key, value)`.

## Теория

Для модификации ассоциативного массива `map` в пакете `reflect` не требуется разыменовывать указатель через `.Elem()`.

Поскольку мапа в Go сама по себе является ссылочным типом (указателем на структуру `runtime.hmap`), `reflect.ValueOf(myMap)` уже позволяет производить запись:
- **`v.SetMapIndex(k, val)`**:
  - Если ключ не существует, он добавляется в мапу.
  - Если ключ уже существует, его значение перезаписывается.
  - Если передать неинициализированный `reflect.Value{}`, ключ удаляется.
Единственное строгое требование: типы ключа и значения обязаны строго соответствовать типам `mapType.Key()` и `mapType.Elem()`.

## Решение по шагам

1. Создадим мапу `cache := make(map[string]string)`.
2. Получим `v := reflect.ValueOf(cache)`.
3. Добавим новую пару ключ-значение через `v.SetMapIndex()`.
4. Обновим существующее значение.
5. Проверим содержимое исходной мапы в коде Go.

## Код решения

**`mutate_map.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

func main() {
	cache := map[string]string{
		"session_1": "user_alice",
	}

	v := reflect.ValueOf(cache)

	fmt.Printf("Исходная мапа: %v\n", cache)

	// 1. Добавление новой пары
	newKey := reflect.ValueOf("session_2")
	newVal := reflect.ValueOf("user_bob")
	v.SetMapIndex(newKey, newVal)

	// 2. Обновление существующей пары
	v.SetMapIndex(reflect.ValueOf("session_1"), reflect.ValueOf("user_alice_VIP"))

	fmt.Printf("Мапа после рефлексивной мутации: %v\n", cache)
	fmt.Printf("Значение session_2: %q\n", cache["session_2"])
}
```

ℹ️ Добавление и обновление записей в мапе через SetMapIndex

**`Терминал`**

```bash
go run mutate_map.go
# Исходная мапа: map[session_1:user_alice]
# Мапа после рефлексивной мутации: map[session_1:user_alice_VIP session_2:user_bob]
# Значение session_2: "user_bob"
```

## Под капотом

Вызов `v.SetMapIndex` обращается к хеш-функции типа ключа `t.Key().Hasher(key.ptr, seed)`. Вычисляется хеш ключа, определяется целевой бакет в `hmap.buckets`, и данные копируются в слот бакета.
Если количество элементов превышает `loadFactor` (6.5), рантайм Go инициирует автоматическую эвакуацию бакетов и увеличение размера мапы в 2 раза (`hashGrow`).

## Подводные камни

1. **Запись в nil-мапу:** Если мапа не была инициализирована (`var m map[string]int = nil`), вызов `SetMapIndex` вызовет стандартную панику рантайма `panic: assignment to entry in nil map`.

## На собеседовании

**Вопрос с собеседования в Т-Банк:** «Почему для изменения среза через рефлексию нужно передавать указатель &slice, а для изменения мапы достаточно передать саму мапу map?»
**Ответ:** Срез представлен структурой заголовка `SliceHeader{Data, Len, Cap}`. Если мы хотим изменить `len` или переаллоцировать слайс, нам нужно модифицировать сам заголовок, что требует указателя.
Мапа в Go — это скрытый указатель `*runtime.hmap`. При передаче по значению копируется лишь указатель на хеш-таблицу в куче, поэтому `SetMapIndex` напрямую модифицирует внутреннее состояние единой таблицы.
