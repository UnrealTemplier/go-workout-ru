# Реализация собственного компаратора CustomDeepEqual

## Условие

**Custom DeepEqual**: Напишите собственную реализацию `DeepEqual` для образовательных целей.

## Теория

Написание собственного компаратора глубокого равенства раскрывает всю мощь рекурсивного анализа структуры данных в Go.

### Алгоритм CustomDeepEqual:
1. **Базовые проверки:**
   - Если оба значения равны `nil` -> `true`.
   - Если одно из них `nil` -> `false`.
   - Если типы не совпадают (`v1.Type() != v2.Type()`) -> `false`.
2. **Сравнение по Kind:**
   - **Скаляры (Int, String, Float, Bool):** прямое сравнение значений.
   - **Указатели (Pointer):** если оба `nil` — равны; если один — не равны; иначе разыменовываем и рекурсивно сравниваем `Elem()`.
   - **Слайсы (Slice):** если длины не равны — `false`. Поэлементно сравниваем `Index(i)`.
   - **Мапы (Map):** если длины не равны — `false`. Для каждого ключа ищем пару в другой мапе и сравниваем значения.
   - **Структуры (Struct):** рекурсивно сравниваем каждое поле `Field(i)`.

## Решение по шагам

1. Создадим функцию `CustomDeepEqual(a, b any) bool`.
2. Реализуем вспомогательную рекурсивную функцию `equalRecursive(v1, v2 reflect.Value) bool`.
3. Обработаем все ключевые виды `Kind`.
4. Проверим работу на сложных вложенных структурах и слайсах.

## Код решения

**`custom_deep_equal.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

// CustomDeepEqual выполняет глубокое сравнение двух любых значений Go
func CustomDeepEqual(a, b any) bool {
	if a == nil || b == nil {
		return a == b
	}

	v1 := reflect.ValueOf(a)
	v2 := reflect.ValueOf(b)

	if v1.Type() != v2.Type() {
		return false
	}

	return equalRecursive(v1, v2)
}

func equalRecursive(v1, v2 reflect.Value) bool {
	if !v1.IsValid() || !v2.IsValid() {
		return v1.IsValid() == v2.IsValid()
	}

	switch v1.Kind() {
	case reflect.Bool:
		return v1.Bool() == v2.Bool()
	case reflect.Int, reflect.Int8, reflect.Int16, reflect.Int32, reflect.Int64:
		return v1.Int() == v2.Int()
	case reflect.Uint, reflect.Uint8, reflect.Uint16, reflect.Uint32, reflect.Uint64:
		return v1.Uint() == v2.Uint()
	case reflect.Float32, reflect.Float64:
		return v1.Float() == v2.Float()
	case reflect.String:
		return v1.String() == v2.String()

	case reflect.Pointer:
		if v1.IsNil() || v2.IsNil() {
			return v1.IsNil() == v2.IsNil()
		}
		return equalRecursive(v1.Elem(), v2.Elem())

	case reflect.Slice:
		if v1.IsNil() || v2.IsNil() {
			return v1.IsNil() == v2.IsNil()
		}
		if v1.Len() != v2.Len() {
			return false
		}
		for i := 0; i < v1.Len(); i++ {
			if !equalRecursive(v1.Index(i), v2.Index(i)) {
				return false
			}
		}
		return true

	case reflect.Map:
		if v1.IsNil() || v2.IsNil() {
			return v1.IsNil() == v2.IsNil()
		}
		if v1.Len() != v2.Len() {
			return false
		}
		iter := v1.MapRange()
		for iter.Next() {
			k := iter.Key()
			val1 := iter.Value()
			val2 := v2.MapIndex(k)
			if !val2.IsValid() || !equalRecursive(val1, val2) {
				return false
			}
		}
		return true

	case reflect.Struct:
		for i := 0; i < v1.NumField(); i++ {
			if !equalRecursive(v1.Field(i), v2.Field(i)) {
				return false
			}
		}
		return true
	}

	return false
}

type Address struct {
	City string
}

type Customer struct {
	Name    string
	Addr    *Address
	Hobbies []string
}

func main() {
	c1 := Customer{
		Name:    "Илья",
		Addr:    &Address{City: "Москва"},
		Hobbies: []string{"Go", "Алгоритмы"},
	}

	c2 := Customer{
		Name:    "Илья",
		Addr:    &Address{City: "Москва"},
		Hobbies: []string{"Go", "Алгоритмы"},
	}

	c3 := Customer{
		Name:    "Илья",
		Addr:    &Address{City: "СПб"},
		Hobbies: []string{"Go", "Алгоритмы"},
	}

	fmt.Printf("CustomDeepEqual(c1, c2): %v (ожидается true)\n", CustomDeepEqual(c1, c2))
	fmt.Printf("CustomDeepEqual(c1, c3): %v (ожидается false)\n", CustomDeepEqual(c1, c3))
}
```

ℹ️ Учебная реализация алгоритма глубокого сравнения произвольных типов

**`Терминал`**

```bash
go run custom_deep_equal.go
# CustomDeepEqual(c1, c2): true (ожидается true)
# CustomDeepEqual(c1, c3): false (ожидается false)
```

## Под капотом

В отличие от поверхностного сравнения указателей `c1.Addr == c2.Addr` (которое вернет `false`, так как адреса в куче разные), рекурсивный алгоритм спускается внутрь структуры `Address` и сравнивает строковое поле `City`. Это фундаментальная основа assertion-библиотек (`testify/assert.Equal`).

## Подводные камни

1. **Пропуск IsNil для срезов:** Если не проверить `v1.IsNil() == v2.IsNil()`, алгоритм ошибочно посчитает `nil`-срез и срез нулевой длины `[]int{}` абсолютно равными.

## На собеседовании

**Вопрос с собеседования в Касперский:** «Как в CustomDeepEqual защититься от зависания при передаче циклического списка?»
**Ответ:** Необходимо завести карту посещенных указателей `visited map[[2]uintptr]bool`. Перед сравнением пары указателей проверяют, есть ли ключ `[2]uintptr{v1.Pointer(), v2.Pointer()}` в карте. Если есть, возвращают `true`. Если нет — добавляют ключ в карту перед рекурсивным вызовом.
