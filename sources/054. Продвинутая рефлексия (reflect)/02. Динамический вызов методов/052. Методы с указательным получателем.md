# Методы с указательным получателем (Pointer Receiver) в таблице методов

## Условие

**Method on pointer receiver**: Изучите разницу: методы с pointer receiver доступны только через `reflect.ValueOf(&obj)`, а не `reflect.ValueOf(obj)`.

## Теория

В языке Go действует строгое правило формирования множества методов типа (**Method Set**):
1. **Для значения типа `T`:** Множество методов включает **только те методы**, которые объявлены с value receiver `(t T)`.
2. **Для указателя типа `*T`:** Множество методов включает **все методы** — объявленные как с pointer receiver `(t *T)`, так и с value receiver `(t T)`.

### Следствие для рефлексии:
- Если метод объявлен как `func (u *User) SetAge(age int)`, то вызов:
  `reflect.ValueOf(u).MethodByName("SetAge")`
  вернет **нулевой объект `Value{}` (`IsValid() == false`)**! Рефлексия не может найти этот метод, так как у значения `User` его просто нет в таблице типов.
- Чтобы метод был найден и мог быть вызван, объект обязан передаваться по указателю: `reflect.ValueOf(&u).MethodByName("SetAge")`.

## Решение по шагам

1. Определим структуру `Account` с двумя методами: `GetBalance()` (value receiver) и `Deposit(amount int)` (pointer receiver).
2. Исследуем методы через `reflect.TypeOf(acc)` и `reflect.TypeOf(&acc)`.
3. Попробуем найти `Deposit` через `reflect.ValueOf(acc)` и зафиксируем неудачу.
4. Найдем и успешно вызовем `Deposit` через `reflect.ValueOf(&acc)`.
5. Проверим, что баланс структуры изменился.

## Код решения

**`pointer_receiver_methods.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

type BankAccount struct {
	Balance int
}

// Value receiver
func (b BankAccount) GetBalance() int {
	return b.Balance
}

// Pointer receiver
func (b *BankAccount) Deposit(amount int) {
	b.Balance += amount
}

func main() {
	acc := BankAccount{Balance: 1000}

	tVal := reflect.TypeOf(acc)
	tPtr := reflect.TypeOf(&acc)

	fmt.Printf("Количество методов у BankAccount  (value): %d\n", tVal.NumMethod())
	fmt.Printf("Количество методов у *BankAccount (pointer): %d\n\n", tPtr.NumMethod())

	// 1. Попытка вызова Deposit на значении
	vVal := reflect.ValueOf(acc)
	mVal := vVal.MethodByName("Deposit")
	fmt.Printf("vVal.MethodByName('Deposit').IsValid(): %v (метод НЕ найден!)\n", mVal.IsValid())

	// 2. Вызов Deposit на указателе
	vPtr := reflect.ValueOf(&acc)
	mPtr := vPtr.MethodByName("Deposit")
	fmt.Printf("vPtr.MethodByName('Deposit').IsValid(): %v (метод успешно найден!)\n", mPtr.IsValid())

	if mPtr.IsValid() {
		args := []reflect.Value{reflect.ValueOf(500)}
		mPtr.Call(args)
		fmt.Printf("Баланс после вызова через рефлексию: %d\n", acc.Balance)
	}
}
```

ℹ️ Различия Method Set для значений и указателей в пакете reflect

**`Терминал`**

```bash
go run pointer_receiver_methods.go
# Количество методов у BankAccount  (value): 1
# Количество методов у *BankAccount (pointer): 2
# 
# vVal.MethodByName('Deposit').IsValid(): false (метод НЕ найден!)
# vPtr.MethodByName('Deposit').IsValid(): true (метод успешно найден!)
# Баланс после вызова через рефлексию: 1500
```

## Под капотом

Компилятор Go генерирует две разные таблицы методов в метаданных бинарного файла:
- Для типа `main.BankAccount`: массив методов содержит только `GetBalance`.
- Для типа `*main.BankAccount`: компилятор автоматически генерирует обертку-переходник для `GetBalance` и включает `Deposit`, поэтому таблица содержит оба метода.
Рантайм `reflect` просто считывает длину массива `uncommonType.xcount` соответствующего дескриптора.

## Подводные камни

1. **Невидимость методов в интерфейсах:** Если структура передается в `any` по значению `var i any = acc`, то `reflect.TypeOf(i).Implements(...)` вернет `false` для любого интерфейса, требующего методы с pointer receiver.

## На собеседовании

**Вопрос с собеседования в Яндекс:** «Почему компилятор Go разрешает вызвать acc.Deposit(500) на значении переменной, но reflect.ValueOf(acc).MethodByName("Deposit") возвращает invalid Value?»
**Ответ:** Компилятор видит, что переменная `acc` адресуема, и выполняет неявный синтаксический сахар: переписывает вызов `acc.Deposit(500)` в `(&acc).Deposit(500)`. 
Но когда `acc` передается в `reflect.ValueOf(acc)`, происходит боксинг копии значения в интерфейс `any`. Копия внутри интерфейса неадресуема, компилятор не может взять ее адрес, поэтому в рантайме доступен строго набор методов для типа `T` без методов `*T`.
