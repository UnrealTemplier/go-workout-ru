# Создание map с динамическими типами ключей и значений

## Условие

Напишите функцию, которая по заданным reflect.Type ключа и значения создаёт и возвращает пустую map[K]V через рефлексию. Добавьте в неё элементы с помощью reflect.Value.SetMapIndex.

### Исходная формулировка

**Создание карты с динамическими типами ключей и значений.**: Напишите функцию, которая по заданным `reflect.Type` ключа и значения создаёт и возвращает пустую `map[K]V` через рефлексию. Добавьте в неё элементы.

## Теория

В Go динамическое инстанцирование хэш-таблицы произвольного типа во время выполнения производится с помощью функции `reflect.MapOf(keyType, elemType reflect.Type) reflect.Type` и последующего вызова `reflect.MakeMap(mapType)` или `reflect.MakeMapWithSize(mapType, size)`.

Ключевые аспекты:
1. `reflect.MapOf` требует, чтобы `keyType.Comparable()` возвращал `true`. Если передать несравнимый тип (слайс, мапу, функцию), рантайм запаникует: `panic: reflect.MapOf: invalid key type`.
2. `reflect.MakeMap(mapType)` инициализирует внутреннюю структуру `runtime.hmap` и возвращает `reflect.Value`, содержащий валидную мапу (не `nil`).
3. Для модификации мапы вызывается `val.SetMapIndex(keyVal, elemVal)`. Если `elemVal` валидный, ключ связывается со значением. Если `elemVal` равен `reflect.Value{}` (zero Value), ключ удаляется из мапы (эквивалент `delete(m, k)`).
4. Чтение осуществляется через `val.MapIndex(keyVal)`, возвращающий `reflect.Value`. Если ключ отсутствует, возвращается невалидный `reflect.Value` (проверяется через `.IsValid()`).

## Решение по шагам

1. Создайте `reflect.Type` для ключа (например, `reflect.TypeOf("")`) и значения (`reflect.TypeOf(0)`).
2. Проверьте `keyType.Comparable()`.
3. Сконструируйте `mapType := reflect.MapOf(keyType, elemType)`.
4. Создайте мапу: `mapVal := reflect.MakeMap(mapType)`.
5. Добавьте элементы: `mapVal.SetMapIndex(reflect.ValueOf("latency_ms"), reflect.ValueOf(42))`.
6. Выведите содержимое и тип через `mapVal.Interface()`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

func CreateMap(keyType, valType reflect.Type) (reflect.Value, error) {
	if !keyType.Comparable() {
		return reflect.Value{}, fmt.Errorf("тип ключа %v не является сравнимым (comparable)", keyType)
	}

	mapType := reflect.MapOf(keyType, valType)
	m := reflect.MakeMap(mapType)
	return m, nil
}

func main() {
	kType := reflect.TypeOf("")
	vType := reflect.TypeOf(int64(0))

	mVal, err := CreateMap(kType, vType)
	if err != nil {
		panic(err)
	}

	mVal.SetMapIndex(reflect.ValueOf("cpu_usage"), reflect.ValueOf(int64(78)))
	mVal.SetMapIndex(reflect.ValueOf("memory_mb"), reflect.ValueOf(int64(1024)))

	iter := mVal.MapRange()
	for iter.Next() {
		fmt.Printf("Key: %v, Val: %v (Type: %v)\n", iter.Key(), iter.Value(), iter.Value().Type())
	}

	nativeMap := mVal.Interface()
	fmt.Printf("Результат Interface(): %T -> %v\n", nativeMap, nativeMap)
}
```

ℹ️ Динамическое создание map[string]int64 через reflect.MapOf и reflect.MakeMap

**`Терминал`**

```bash
go run main.go
# Вывод:
# Key: cpu_usage, Val: 78 (Type: int64)
# Key: memory_mb, Val: 1024 (Type: int64)
# Результат Interface(): map[string]int64 -> map[cpu_usage:78 memory_mb:1024]
```

## Под капотом

`reflect.MapOf` находит или создает `runtime.maptype` в таблице типов рантайма. `reflect.MakeMap` вызывает рантаймовую функцию `runtime.makemap`, аллоцируя структуру `hmap` и первичный массив бакетов `bmap`. Метод `SetMapIndex` вызывает `runtime.mapassign`, копируя байты ключа и значения в бакет хэш-таблицы с учетом хэш-функции типа. Удаление элемента передачей `reflect.Value{}` вызывает `runtime.mapdelete`.

## Подводные камни

1. Попытка передать несравнимый тип (например, `reflect.TypeOf([]byte{})`) в `reflect.MapOf` приводит к немедленной панике.
2. Несоответствие типа ключа или значения при `SetMapIndex`: если тип ключа не совпадает в точности с `keyType`, произойдет паника `reflect: map index key type mismatch`.
3. Конкурентная запись через `SetMapIndex` в одну мапу из разных горутин вызовет fatal error: `concurrent map writes`, так как рефлексия не накладывает мьютексов.

## На собеседовании

**Вопрос с собеседования:** Как удалить ключ из `reflect.Value` мапы?
**Ответ:** Для удаления ключа вызывается `mapVal.SetMapIndex(keyVal, reflect.Value{})`. Передача zero `reflect.Value` в качестве значения транслируется рантаймом в вызов `runtime.mapdelete`. Начиная с Go 1.12, также доступен `mapVal.MapRange()`, но безопасное удаление ключей во время итерации гарантируется семантикой мап Go.
