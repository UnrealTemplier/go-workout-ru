# Парсинг HTTP-форм (application/x-www-form-urlencoded) по тегам form

## Условие

Парсите application/x-www-form-urlencoded данные в структуру по тегам form:"field_name".

### Исходная формулировка

**Напишите form parser**: Парсите `application/x-www-form-urlencoded` данные в структуру по тегам `form:"field_name"`.

## Теория

При получении данных формы из `r.PostForm` или парсинге `url.Values` ключи и значения представлены строками (`map[string][]string`).
Для биндинга формы в строго типизированную структуру Go:
1. Функция принимает целевой указатель на структуру `dst any`.
2. Проверяется, что `dst` — адресуемый указатель на структуру.
3. Итерируются поля структуры; считывается тег `form:"name"`.
4. Из `url.Values` по ключу `tag` извлекается строковое значение.
5. Строковое значение конвертируется в целевой тип поля:
   - `reflect.String`: прямая запись `field.SetString(val)`.
   - `reflect.Int*`: `strconv.ParseInt` + `field.SetInt`.
   - `reflect.Bool`: `strconv.ParseBool` + `field.SetBool`.
   - `reflect.Slice`: заполнение среза несколькими значениями из `values[tag]`.

## Решение по шагам

1. Определите функцию `ParseForm(form url.Values, dst any) error`.
2. Разыменуйте указатель: `val := reflect.ValueOf(dst).Elem()`.
3. Обойдите поля, считайте тег `form`.
4. Если параметр присутствует в `form`, конвертируйте строку в тип поля.
5. Установите значение через `field.Set*`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/url"
	"reflect"
	"strconv"
)

type FilterRequest struct {
	Query    string   `form:"q"`
	Page     int      `form:"page"`
	Limit    int      `form:"limit"`
	IsActive bool     `form:"active"`
	Tags     []string `form:"tag"`
}

func ParseForm(form url.Values, dst any) error {
	val := reflect.ValueOf(dst)
	if val.Kind() != reflect.Pointer || val.Elem().Kind() != reflect.Struct {
		return fmt.Errorf("dst должен быть указателем на структуру")
	}

	val = val.Elem()
	typ := val.Type()

	for i := 0; i < val.NumField(); i++ {
		fieldVal := val.Field(i)
		sf := typ.Field(i)

		tag := sf.Tag.Get("form")
		if tag == "" || !fieldVal.CanSet() {
			continue
		}

		formVals, exists := form[tag]
		if !exists || len(formVals) == 0 {
			continue
		}

		firstVal := formVals[0]

		switch fieldVal.Kind() {
		case reflect.String:
			fieldVal.SetString(firstVal)
		case reflect.Int, reflect.Int32, reflect.Int64:
			num, err := strconv.ParseInt(firstVal, 10, 64)
			if err != nil {
				return fmt.Errorf("ошибка парсинга int для поля %s: %w", sf.Name, err)
			}
			fieldVal.SetInt(num)
		case reflect.Bool:
			b, err := strconv.ParseBool(firstVal)
			if err != nil {
				return fmt.Errorf("ошибка парсинга bool для поля %s: %w", sf.Name, err)
			}
			fieldVal.SetBool(b)
		case reflect.Slice:
			if fieldVal.Type().Elem().Kind() == reflect.String {
				sliceVal := reflect.MakeSlice(fieldVal.Type(), len(formVals), len(formVals))
				for j, strVal := range formVals {
					sliceVal.Index(j).SetString(strVal)
				}
				fieldVal.Set(sliceVal)
			}
		default:
			return fmt.Errorf("неподдерживаемый тип поля %s (%v)", sf.Name, fieldVal.Kind())
		}
	}

	return nil
}

func main() {
	formData := url.Values{
		"q":      []string{"golang microservices"},
		"page":   []string{"2"},
		"limit":  []string{"50"},
		"active": []string{"true"},
		"tag":    []string{"backend", "k8s", "grpc"},
	}

	var req FilterRequest
	if err := ParseForm(formData, &req); err != nil {
		panic(err)
	}

	fmt.Printf("Parsed Request: %+v\n", req)
}
```

## Под капотом

Механизм `url.Values` представляет собой `map[string][]string`. Рефлексивный маппер извлекает слайс строк и через `CanSet()` проверяет адресуемость поля структуры. Преобразования строк выполняются пакетом `strconv`, возвращающим ошибки парсинга без паники, что критично для безопасности HTTP-обработчиков.

## Подводные камни

1. Передача значения вместо указателя (`ParseForm(form, req)`): вызовет ошибку, так как значение невозможно изменить.
2. Необработанные ошибки парсинга `strconv.ParseInt`: некорректный ввод пользователя (например `page=abc`) должен возвращать клиенту 400 Bad Request, а не паниковать.
3. Отсутствие поддержки множественных значений (слайсов) при одинаковых ключах формы (`tag=a&tag=b`).

## На собеседовании

**Вопрос с собеседования:** В чем разница между `r.Form` и `r.PostForm` в стандартной библиотеке `net/http`?
**Ответ:** `r.PostForm` парсит только тело HTTP-запроса (POST, PUT, PATCH с MIME-типом `application/x-www-form-urlencoded`). `r.Form` объединяет параметры как из query-строки URL (`?a=1`), так и из тела POST-запроса. Если параметр присутствует и в URL, и в теле, в `r.Form` значение из тела запроса будет идти первым.
