# Глубокое копирование объектов (DeepCopy) через рефлексию

## Условие

Напиши функцию DeepCopy(src, dst interface{}), которая с помощью рефлексии рекурсивно копирует структуру, включая слайсы и мапы, выделяя под них новую память.

### Исходная формулировка

**[Высокая сложность — Глубокое копирование]**: Напиши функцию `DeepCopy(src, dst interface{})`, которая с помощью рефлексии рекурсивно копирует структуру, включая слайсы и мапы, выделяя под них новую память.

## Теория

Поверхностное копирование (`dst = src` или `dstVal.Set(srcVal)`) для ссылочных типов (слайсы, мапы, указатели) копирует только дескриптор, оставляя общую память. Изменение элемента в копии изменит оригинал.

Глубокое копирование (`DeepCopy`) рекурсивно обходит структуру:
1. `reflect.Pointer`: аллоцирует новую память `reflect.New(src.Elem().Type())` и рекурсивно копирует разыменованное значение.
2. `reflect.Slice`: аллоцирует новый слайс `reflect.MakeSlice(src.Type(), src.Len(), src.Cap())` и копирует каждый элемент через `dst.Index(i).Set(DeepCopy(src.Index(i)))`.
3. `reflect.Map`: аллоцирует новую мапу `reflect.MakeMapWithSize(src.Type(), src.Len())` и итерируется по ключам, глубоко копируя ключи и значения.
4. `reflect.Struct`: создает новый экземпляр и копирует каждое поле рекурсивно.
5. Примитивные типы (`Int`, `String`, `Bool`): копируются по значению (`dst.Set(src)`).
6. Защита от циклических ссылок: карта посещенных адресов `map[uintptr]reflect.Value`.

## Решение по шагам

1. Создайте сигнатуру `DeepCopy(src any) any` или `DeepCopyInto(src, dst any) error`.
2. Реализуйте рекурсивную функцию `deepCopyValue(v reflect.Value, visited map[uintptr]reflect.Value) reflect.Value`.
3. Обработайте `Kind()` для указателей, слайсов, мап, структур и примитивов.
4. Убедитесь, что для слайсов создается новый буфер с копированием данных.
5. Протестируйте независимость мутации оригинала и копии.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

func DeepCopy(src any) any {
	if src == nil {
		return nil
	}
	srcVal := reflect.ValueOf(src)
	visited := make(map[uintptr]reflect.Value)
	return deepCopyValue(srcVal, visited).Interface()
}

func deepCopyValue(v reflect.Value, visited map[uintptr]reflect.Value) reflect.Value {
	switch v.Kind() {
	case reflect.Pointer:
		if v.IsNil() {
			return reflect.Zero(v.Type())
		}
		ptr := v.Pointer()
		if existing, ok := visited[ptr]; ok {
			return existing
		}
		newVal := reflect.New(v.Type().Elem())
		visited[ptr] = newVal
		newVal.Elem().Set(deepCopyValue(v.Elem(), visited))
		return newVal

	case reflect.Slice:
		if v.IsNil() {
			return reflect.Zero(v.Type())
		}
		newSlice := reflect.MakeSlice(v.Type(), v.Len(), v.Cap())
		for i := 0; i < v.Len(); i++ {
			newSlice.Index(i).Set(deepCopyValue(v.Index(i), visited))
		}
		return newSlice

	case reflect.Map:
		if v.IsNil() {
			return reflect.Zero(v.Type())
		}
		newMap := reflect.MakeMapWithSize(v.Type(), v.Len())
		iter := v.MapRange()
		for iter.Next() {
			k := deepCopyValue(iter.Key(), visited)
			val := deepCopyValue(iter.Value(), visited)
			newMap.SetMapIndex(k, val)
		}
		return newMap

	case reflect.Struct:
		newStruct := reflect.New(v.Type()).Elem()
		for i := 0; i < v.NumField(); i++ {
			f := v.Field(i)
			if newStruct.Field(i).CanSet() {
				newStruct.Field(i).Set(deepCopyValue(f, visited))
			}
		}
		return newStruct

	case reflect.Interface:
		if v.IsNil() {
			return reflect.Zero(v.Type())
		}
		return deepCopyValue(v.Elem(), visited)

	default:
		return v
	}
}

type Node struct {
	ID    int
	Tags  []string
	Attrs map[string]string
	Next  *Node
}

func main() {
	original := &Node{
		ID:    101,
		Tags:  []string{"cache", "read-only"},
		Attrs: map[string]string{"env": "prod"},
		Next:  &Node{ID: 102},
	}

	copied := DeepCopy(original).(*Node)

	// Модифицируем копию
	copied.Tags[0] = "mutated"
	copied.Attrs["env"] = "dev"
	copied.Next.ID = 999

	fmt.Printf("Оригинал: Tag=%s, Attr=%s, NextID=%d\n", original.Tags[0], original.Attrs["env"], original.Next.ID)
	fmt.Printf("Копия:    Tag=%s, Attr=%s, NextID=%d\n", copied.Tags[0], copied.Attrs["env"], copied.Next.ID)
}
```


## Под капотом

Рекурсивный `DeepCopy` копирует память на гранулярном уровне. Таблица `visited` хранит `uintptr` исходных указателей, предотвращая зацикливание при циклических графах объектов (например, двусвязных списках). Без `visited` рекурсия приведет к `runtime: goroutine stack exceeds 1000000000-byte limit` (stack overflow).

## Подводные камни

1. Попытка установить неэкспортированные поля (`CanSet() == false`) без использования `unsafe` приведет к панике.
2. Недопустимость глубокого копирования каналов и мьютексов (`sync.Mutex`): копирование заблокированного мьютекса или открытого канала нарушает инварианты рантайма.
3. Высокая вычислительная сложность и множественные аллокации памяти по сравнению с кодогенерацией (например, `deepcopy-gen` в Kubernetes).

## На собеседовании

**Вопрос с собеседования:** Почему в Kubernetes для типов API ресурсов не используют рефлексивный `DeepCopy`, а генерируют метод `DeepCopyInto` утилитой `deepcopy-gen`?
**Ответ:** Производительность. Рефлексивный `DeepCopy` создает сотни промежуточных `reflect.Value`, производит type switches и десятки мелких аллокаций на каждый объект. В кластере с десятками тысяч Pods это приведет к колоссальной деградации etcd/API-server. Сгенерированный компилируемый метод `DeepCopyInto` выполняет прямое выделение памяти без участия рантайм-рефлексии.
