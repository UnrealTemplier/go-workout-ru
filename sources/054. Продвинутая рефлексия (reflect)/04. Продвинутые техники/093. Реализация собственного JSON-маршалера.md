# Реализация собственного JSON-маршалера через reflect и теги

## Условие

Реализуйте собственную функцию, которая маршалит структуру в JSON, используя имена полей из тегов json:"name".

### Исходная формулировка

**Напишите JSON маппер**: Реализуйте собственную функцию, которая маршалит структуру в JSON, используя имена полей из тегов `json:"name"`.

## Теория

Стандартный пакет `encoding/json` использует рефлексию для сериализации структур в формат JSON:
1. `reflect.ValueOf(v)` определяет тип аргумента.
2. Если аргумент — структура, метод `NumField()` обходит её поля.
3. Тег `json:"field_name,omitempty"` извлекается через `sf.Tag.Get("json")`.
4. Имя поля нормализуется: если тег отсутствует, берется имя поля Go. Если тег равен `"-"`, поле игнорируется.
5. Для каждого типа значения рекурсивно формируется текстовое JSON-представление: числа и булевы значения форматируются напрямую, строки экранируются кавычками `"..."`, слайсы оборачиваются в `[...]`, структуры — в `{...}`.

## Решение по шагам

1. Напишите рекурсивную функцию `MarshalJSONCustom(v any) ([]byte, error)`.
2. Вспомогательная функция `marshalValue(val reflect.Value) (string, error)` проверяет `val.Kind()`.
3. Для `reflect.Struct` обходите поля, считывайте тег `json`.
4. Пропускайте поля с тегом `"-"` или неэкспортированные поля.
5. Собирайте строковый буфер вида `{"key":value,...}`.
6. Возвращайте результирующий срез байт.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"reflect"
	"strconv"
	"strings"
)

func MarshalJSONCustom(v any) ([]byte, error) {
	val := reflect.ValueOf(v)
	if val.Kind() == reflect.Pointer {
		val = val.Elem()
	}
	s, err := marshalValue(val)
	if err != nil {
		return nil, err
	}
	return []byte(s), nil
}

func marshalValue(val reflect.Value) (string, error) {
	switch val.Kind() {
	case reflect.String:
		return strconv.Quote(val.String()), nil
	case reflect.Int, reflect.Int8, reflect.Int16, reflect.Int32, reflect.Int64:
		return strconv.FormatInt(val.Int(), 10), nil
	case reflect.Bool:
		return strconv.FormatBool(val.Bool()), nil
	case reflect.Slice:
		var items []string
		for i := 0; i < val.Len(); i++ {
			s, err := marshalValue(val.Index(i))
			if err != nil {
				return "", err
			}
			items = append(items, s)
		}
		return "[" + strings.Join(items, ",") + "]", nil
	case reflect.Struct:
		typ := val.Type()
		var pairs []string
		for i := 0; i < val.NumField(); i++ {
			sf := typ.Field(i)
			if !sf.IsExported() {
				continue
			}

			tag := sf.Tag.Get("json")
			if tag == "-" {
				continue
			}

			key := sf.Name
			if tag != "" {
				parts := strings.Split(tag, ",")
				if parts[0] != "" {
					key = parts[0]
				}
			}

			fieldStr, err := marshalValue(val.Field(i))
			if err != nil {
				return "", err
			}
			pairs = append(pairs, fmt.Sprintf("%q:%s", key, fieldStr))
		}
		return "{" + strings.Join(pairs, ",") + "}", nil
	default:
		return "", fmt.Errorf("неподдерживаемый тип: %v", val.Kind())
	}
}

type Order struct {
	ID        int      `json:"order_id"`
	Customer  string   `json:"client_name"`
	IsPaid    bool     `json:"paid"`
	Items     []string `json:"items"`
	secretKey string   `json:"secret"`
}

func main() {
	ord := Order{
		ID:        45021,
		Customer:  "Alice Cooper",
		IsPaid:    true,
		Items:     []string{"Laptop", "Mouse"},
		secretKey: "super_secret_token",
	}

	data, err := MarshalJSONCustom(ord)
	if err != nil {
		panic(err)
	}

	fmt.Println("Custom JSON:")
	fmt.Println(string(data))
}
```

ℹ️ Собственный JSON-сериализатор на базе reflect.Value и тегов json

**`Терминал`**

```bash
go run main.go
# Вывод:
# Custom JSON:
# {"order_id":45021,"client_name":"Alice Cooper","paid":true,"items":["Laptop","Mouse"]}
```

## Под капотом

Стандартный `encoding/json` использует кодировщики полей (`encodeState`), компилируя список доступных полей структуры при первом обращении (`typeFields(t reflect.Type)`). Функция `typeFields` строит и кэширует плоский список полей с учетом вложенности (`embedding`), прецедентов скрытия полей и опций `,omitempty` и `,string`.

## Подводные камни

1. Забытая проверка `sf.IsExported()`: неэкспортированные поля нельзя сериализовать в JSON, попытка чтения может вызвать ошибку.
2. Игнорирование опции `,omitempty`: если поле zero-value и указан omitempty, оно должно опускаться.
3. Циклические структуры (указатель сам на себя) вызовут бесконечную рекурсию и stack overflow без трекинга посещенных указателей.

## На собеседовании

**Вопрос с собеседования:** Почему `json-iterator/go` или `sonic` работают в разы быстрее стандартного `encoding/json`?
**Ответ:** Стандартный `encoding/json` использует интерфейс `any` и `reflect` для рантайм-инспекции полей при каждой сериализации. Высокопроизводительные библиотеки (например, `sonic` от ByteDance) используют JIT-компиляцию в машинный код на лету (через asm/AVX2) или генерируют статический ассемблерный парсер, избегая вызовов `reflect.Value` и лишних аллокаций в куче.
