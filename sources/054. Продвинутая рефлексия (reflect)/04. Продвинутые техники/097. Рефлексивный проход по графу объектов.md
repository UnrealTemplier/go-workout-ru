# Рефлексивный проход по графу объектов с модификацией строк (Uppercase)

## Условие

Создайте функцию, которая обходит структуру (и вложенные структуры, слайсы, мапы) и заменяет все строки на их заглавные версии (uppercase) с помощью reflect.

### Исходная формулировка

**Рефлексивный проход по графу объектов.**: Создайте функцию, которая обходит структуру (и вложенные структуры, слайсы, мапы) и заменяет все строки на их заглавные версии (uppercase) с помощью `reflect`.

## Теория

Трансформация данных произвольной структуры (санитизация HTML, тримминг пробелов, маскирование персональных данных PII) часто реализуется через универсальный рефлексивный visitor:
1. Функция принимает указатель на объект для обеспечения адресуемости (`CanSet() == true`).
2. Для каждого узла проверяется `Kind()`:
   - `reflect.String`: если поле адресуемо, вызывается `val.SetString(strings.ToUpper(val.String()))`.
   - `reflect.Struct`: обход всех полей структуры.
   - `reflect.Slice`: обход элементов слайса по индексам.
   - `reflect.Map`: поскольку значения в мапе напрямую не адресуемы через `Index()`, необходимо извлечь значение, модифицировать его и перезаписать в мапу через `SetMapIndex(k, newV)`.
   - `reflect.Pointer`: переход к `val.Elem()`.

## Решение по шагам

1. Напишите функцию `UppercaseAllStrings(v any) error`.
2. Проверьте `val.Kind() == reflect.Pointer`.
3. Напишите рекурсивную функцию `transformStrings(val reflect.Value)`.
4. Для мап используйте `MapRange()` и перезапись `SetMapIndex`.
5. Для слайсов и структур изменяйте строковые поля на месте.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"reflect"
	"strings"
)

func UppercaseAllStrings(v any) {
	val := reflect.ValueOf(v)
	if val.Kind() != reflect.Pointer {
		return
	}
	transformStrings(val.Elem())
}

func transformStrings(val reflect.Value) {
	if !val.IsValid() {
		return
	}

	switch val.Kind() {
	case reflect.String:
		if val.CanSet() {
			val.SetString(strings.ToUpper(val.String()))
		}
	case reflect.Pointer, reflect.Interface:
		if !val.IsNil() {
			transformStrings(val.Elem())
		}
	case reflect.Struct:
		for i := 0; i < val.NumField(); i++ {
			f := val.Field(i)
			if f.CanSet() {
				transformStrings(f)
			}
		}
	case reflect.Slice:
		for i := 0; i < val.Len(); i++ {
			transformStrings(val.Index(i))
		}
	case reflect.Map:
		iter := val.MapRange()
		for iter.Next() {
			k := iter.Key()
			v := iter.Value()
			if v.Kind() == reflect.String {
				upperVal := reflect.ValueOf(strings.ToUpper(v.String()))
				val.SetMapIndex(k, upperVal)
			} else if v.Kind() == reflect.Pointer || v.Kind() == reflect.Interface || v.Kind() == reflect.Map || v.Kind() == reflect.Slice {
				transformStrings(v)
			}
		}
	}
}

type Profile struct {
	Bio   string
	City  string
	Interests []string
	Notes map[string]string
}

type UserAccount struct {
	Username string
	Profile  Profile
}

func main() {
	user := UserAccount{
		Username: "gopher_ninja",
		Profile: Profile{
			Bio:       "distributed systems engineer",
			City:      "saint petersburg",
			Interests: []string{"golang", "raft", "linux"},
			Notes: map[string]string{
				"status": "ready to hire",
				"tier":   "senior",
			},
		},
	}

	UppercaseAllStrings(&user)

	fmt.Printf("Username: %s\n", user.Username)
	fmt.Printf("Bio:      %s\n", user.Profile.Bio)
	fmt.Printf("City:     %s\n", user.Profile.City)
	fmt.Printf("Tags:     %v\n", user.Profile.Interests)
	fmt.Printf("Notes:    %v\n", user.Profile.Notes)
}
```

## Под капотом

Значения внутри `map` в Go не адресуемы: вызов `val.MapIndex(k).CanSet()` всегда возвращает `false`. Причина кроется в устройстве хэш-таблицы: при эвакуации бакетов (росте мапы) элементы перемещаются в памяти, поэтому взятие прямого указателя на элемент мапы запрещено компилятором. Единственный способ изменить значение в мапе — перезапись пары через `val.SetMapIndex(k, newVal)`.

## Подводные камни

1. Попытка вызвать `SetString()` на элементе мапы: паника `reflect: reflect.Value.SetString using unaddressable value`.
2. Неэкспортированные строковые поля структуры: `CanSet()` возвращает `false`, попытка вызова `SetString()` завершится паникой.
3. Бесконечная рекурсия при циклических указателях в структуре без списка посещенных адресов.

## На собеседовании

**Вопрос с собеседования:** Почему в Go элементы слайса адресуемы (`slice[i]`), а элементы мапы (`m[key]`) — нет?
**Ответ:** Слайс — это непрерывный блок памяти фиксированного адреса; адрес `&slice[i]` детерминирован формулой `base_ptr + i * sizeof(T)`. Мапа — динамическая хэш-таблица (`hmap`), которая при заполнении перестраивается и перемещает бакеты (`evacuation`). Если бы язык разрешал брать указатель на элемент мапы, он стал бы невалидным (dangling pointer) при следующем росте мапы.
