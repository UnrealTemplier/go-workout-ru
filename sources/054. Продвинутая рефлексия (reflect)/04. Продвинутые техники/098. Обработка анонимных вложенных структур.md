# Обработка анонимных вложенных структур (Anonymous fields / Embedding)

## Условие

Корректно обрабатывайте embedded структуры при парсинге тегов.

### Исходная формулировка

**Anonymous fields (embedding)**: Корректно обрабатывайте embedded структуры при парсинге тегов.

## Теория

В Go встраивание структур (`struct embedding`) реализует композицию:
```go
type BaseModel struct { ID int `json:"id"` }
type User struct { BaseModel; Name string `json:"name"` }
```
При рефлексии:
1. `field.Anonymous` возвращает `true`, если поле является встраиваемым (embedded).
2. Метод `typ.FieldByName("ID")` автоматически находит поле даже во встроенной структуре (shallow search), если нет коллизий имен.
3. Поле `StructField.Index` содержит срез индексов для доступа: например, `[]int{0, 0}` означает `user.BaseModel.ID`.
4. Для глубокого доступа `val.FieldByIndex(sf.Index)` извлекает значение в один вызов.
5. Правило затенения полей (shadowing): поле внешней структуры затеняет одноименное поле встроенной структуры на более глубоком уровне.

## Решение по шагам

1. Объявите встраиваемую структуру `BaseEntity` и целевую `Order`.
2. Получите `reflect.Type` целевой структуры.
3. Проверьте свойство `sf.Anonymous` у каждого поля.
4. Обойдите поля, используя `FieldByIndex` для плоского сбора тегов.
5. Продемонстрируйте механизм затенения полей.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

type AuditInfo struct {
	CreatedAt string `json:"created_at"`
	CreatedBy string `json:"created_by"`
}

type Identity struct {
	ID   int64  `json:"id"`
	Slug string `json:"slug"`
}

type Product struct {
	Identity  // Embedded struct
	AuditInfo // Embedded struct
	Title     string `json:"title"`
	Price     int64  `json:"price_rub"`
}

func InspectEmbeddedFields(v any) {
	typ := reflect.TypeOf(v)
	if typ.Kind() == reflect.Pointer {
		typ = typ.Elem()
	}

	val := reflect.ValueOf(v)
	if val.Kind() == reflect.Pointer {
		val = val.Elem()
	}

	fmt.Printf("Инспекция структуры %s (NumField: %d):\n", typ.Name(), typ.NumField())

	for i := 0; i < typ.NumField(); i++ {
		sf := typ.Field(i)
		fmt.Printf("  Field[%d]: Name=%-10s Anonymous=%-5v Type=%-15s Tag=%s\n",
			i, sf.Name, sf.Anonymous, sf.Type.String(), sf.Tag.Get("json"))
	}

	fmt.Println("\nДоступ ко всем полям через FieldByName / FieldByIndex:")
	targetFields := []string{"ID", "Slug", "CreatedAt", "CreatedBy", "Title", "Price"}

	for _, name := range targetFields {
		sf, found := typ.FieldByName(name)
		if !found {
			fmt.Printf("  Поле %s не найдено!\n", name)
			continue
		}
		fieldVal := val.FieldByIndex(sf.Index)
		fmt.Printf("  Поле %-10s | Index Path: %-8v | Значение: %v | JSON Tag: %s\n",
			name, sf.Index, fieldVal.Interface(), sf.Tag.Get("json"))
	}
}

func main() {
	p := Product{
		Identity: Identity{
			ID:   1001,
			Slug: "macbook-m3",
		},
		AuditInfo: AuditInfo{
			CreatedAt: "2026-09-04T12:00:00Z",
			CreatedBy: "admin",
		},
		Title: "MacBook Pro M3 Max",
		Price: 350000,
	}

	InspectEmbeddedFields(p)
}
```

## Под капотом

Метод `typ.FieldByName` реализует поиск в ширину (BFS). Сначала проверяются поля текущего уровня. Если совпадений нет, алгоритм спускается на уровень встроенных структур. Если поле с одним и тем же именем найдено на одном уровне в двух разных встроенных структурах (коллизия), `FieldByName` возвращает `found = false` (ambiguous selector), в полном соответствии со спецификацией языка Go.

## Подводные камни

1. Прямой перебор `NumField()` без рекурсивной обработки или `FieldByIndex`: встроенные поля будут считаться отдельной структурой, а их внутренние теги проигнорируются.
2. Коллизия имен: при наличии поля `ID` в двух embedded структурах прямой вызов `FieldByName("ID")` вернет `false`.
3. Embedded указатели: если поле `*AuditInfo` встроено как указатель и равно `nil`, вызов `val.FieldByIndex(sf.Index)` запаникует при разыменовании nil pointer.

## На собеседовании

**Вопрос с собеседования:** Что произойдет, если внешняя структура `A` имеет поле `X`, и встроенная структура `B` тоже имеет поле `X`?
**Ответ:** Произойдет затенение поля (shadowing). `a.X` обратится к полю внешней структуры `A`. Поле встроенной структуры `B.X` останется доступно через явное обращение `a.B.X`. В рефлексии `typ.FieldByName("X")` вернет поле внешней структуры `A`, так как оно находится на глубине 0 (`Index: [0]`).
