# Использование reflect.StructOf для создания динамических структур

## Условие

Используйте reflect.StructOf([]reflect.StructField{...}) (ограниченная функциональность) для создания структур. Изучите ограничения (не работают методы, tags имеют особенности).

### Исходная формулировка

**reflect.StructOf**: Используйте `reflect.StructOf([]reflect.StructField{...})` (ограниченная функциональность) для создания структур. Изучите ограничения (не работают методы, tags имеют особенности).

## Теория

Функция `reflect.StructOf(fields []reflect.StructField) reflect.Type` появилась в Go 1.7. Она позволяет конструировать анонимные типы структур программно:
1. `reflect.StructField`:
   - `Name string`: имя поля (обязано быть экспортированным с заглавной буквы, если `PkgPath` не пуст).
   - `Type reflect.Type`: тип поля.
   - `Tag reflect.StructTag`: метаданные тегов (например `json:"column"`).
   - `Anonymous bool`: является ли поле встраиваемым (embedded).
2. Сконструированный тип можно использовать в `reflect.New(t)` для выделения памяти.
3. Экземпляр можно передавать в стандартные сериализаторы `json.Marshal`, `json.Unmarshal` или сторонние драйверы баз данных, так как они работают со структурой через рефлексию!

## Решение по шагам

1. Сформируйте срез полей `[]reflect.StructField` по схеме из внешнего источника (например, JSON-схемы или таблицы БД).
2. Вызовите `t := reflect.StructOf(fields)`.
3. Создайте экземпляр `val := reflect.New(t).Elem()`.
4. Заполните поля значениями через `val.Field(i).Set(...)`.
5. Передайте созданный объект в `json.Marshal` и убедитесь в корректности сериализации по тегам.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"reflect"
)

// SchemaColumn описывает схему динамической колонки
type SchemaColumn struct {
	Name string
	Type reflect.Type
	JSON string
}

func CreateDynamicRecord(cols []SchemaColumn) (reflect.Value, error) {
	var fields []reflect.StructField

	for _, c := range cols {
		fields = append(fields, reflect.StructField{
			Name: c.Name,
			Type: c.Type,
			Tag:  reflect.StructTag(fmt.Sprintf(`json:"%s"`, c.JSON)),
		})
	}

	structType := reflect.StructOf(fields)
	return reflect.New(structType), nil
}

func main() {
	// Конфигурация схемы на лету
	columns := []SchemaColumn{
		{Name: "MetricID", Type: reflect.TypeOf(int64(0)), JSON: "metric_id"},
		{Name: "Host", Type: reflect.TypeOf(""), JSON: "host_name"},
		{Name: "Value", Type: reflect.TypeOf(float64(0)), JSON: "value"},
	}

	recordPtr, err := CreateDynamicRecord(columns)
	if err != nil {
		panic(err)
	}

	record := recordPtr.Elem()
	record.FieldByName("MetricID").SetInt(9001)
	record.FieldByName("Host").SetString("node-ams-01.infra")
	record.FieldByName("Value").SetFloat(99.98)

	// Сериализуем через стандартный encoding/json
	jsonData, err := json.MarshalIndent(recordPtr.Interface(), "", "  ")
	if err != nil {
		panic(err)
	}

	fmt.Println("Сгенерированный JSON из динамической структуры:")
	fmt.Println(string(jsonData))
}
```

ℹ️ Создание динамической структуры и её сериализация через стандартный encoding/json

**`Терминал`**

```bash
go run main.go
# Вывод:
# Сгенерированный JSON из динамической структуры:
# {
#   "metric_id": 9001,
#   "host_name": "node-ams-01.infra",
#   "value": 99.98
# }
```

## Под капотом

`encoding/json` принимает `any`, получает его `reflect.Type` и `reflect.Value`. Так как созданный `reflect.StructOf` тип структуры содержит корректные дескрипторы полей `StructField` и строковые теги, `json.Marshal` успешно инспектирует структуру, читает теги `json:"host_name"` и извлекает значения по смещениям полей без каких-либо ошибок.

## Подводные камни

1. Создание полей с маленькой буквы (неэкспортированные): `reflect.StructOf` требует явного указания `PkgPath` для unexported полей, иначе возникнет паника `reflect.StructOf: field "xxx" is unexported but has no PkgPath`.
2. Повторное создание одинаковых структур в цикле приводит к росту таблицы типов рантайма.
3. Невозможность явного приведения типа: `recordPtr.Interface().(MyStruct)` невозможно написать в исходном коде, так как типа `MyStruct` не существует при компиляции.

## На собеседовании

**Вопрос с собеседования:** Где на практике в BigTech применяется `reflect.StructOf`?
**Ответ:** В динамических шлюзах данных (Data Gateways), ETL-конвейерах, коннекторах к гибким схемам (например, ClickHouse / BigQuery / Parquet) и в тестах. Он позволяет десериализовать и сериализовать данные переменной схемы (schema-on-read) через стандартные интерфейсы `json.Unmarshal` или `sql.Rows.Scan` без генерации временных `.go` файлов на диске.
