# Анатомия разметки в рантайме: gcDrain() и scanobject()

## Условие

Изучите исходный код src/runtime/mgcmark.go. Объясните функции gcDrain() и scanobject(): как происходит извлечение указателей из объекта, маркировка в gcmarkBits и переход объекта из серого в черное состояние.

### Исходная формулировка

Прочитайте `src/runtime/mgcmark.go`. Найдите функцию `gcDrain()` и объясните разницу между `scanobject` (серый → чёрный) и `greyobject` (белый → серый). Напишите псевдокод этих функций.

## Теория

Две ключевые функции ядра разметки (`src/runtime/mgcmark.go`):

1. **`gcDrain(gcw *gcWork, flags gcDrainFlags)`:**
   * Главный рабочий цикл горутины-маркера (`gcBgMarkWorker`) и горутин в режиме `Mark Assist`.
   * Извлекает серые объекты из локального буфера `gcw.tryGet()` или глобальной очереди.
   * Для каждого серого объекта вызывает `scanobject(b, gcw)`.
   * Регулярно проверяет флаги прерывания (вытеснение, тайм-аут квоты, завершение разметки).

2. **`scanobject(b uintptr, gcw *gcWork)`:**
   * Принимает адрес объекта `b`.
   * Читает информацию о типе (`_type`) или битовую карту кучи (`heapBits`) для объекта `b`.
   * Находит все поля, являющиеся указателями.
   * Для каждого найденного указателя вызывает функцию `greyobject(obj, ...)`:
     * Находит спан `mspan`.
     * Проверяет и атомарно устанавливает бит в `gcmarkBits`.
     * Добавляет найденный дочерний объект в буфер серых объектов `gcw`.
   * Сам объект `b` считается полностью исследованным и становится **Черным**.

## Код решения

**`gcdrain_anatomy.go`**

```go
package main

import "fmt"

type RuntimeObject struct {
	Addr       uintptr
	IsPointer  []bool // Битмап указателей структуры (heapBits)
	ChildAddrs []uintptr
	MarkBit    bool // gcmarkBits
}

type GCWorkBuffer struct {
	queue []uintptr
}

func (w *GCWorkBuffer) Put(addr uintptr) {
	w.queue = append(w.queue, addr)
}

func (w *GCWorkBuffer) TryGet() (uintptr, bool) {
	if len(w.queue) == 0 {
		return 0, false
	}
	addr := w.queue[0]
	w.queue = w.queue[1:]
	return addr, true
}

var heapMap = make(map[uintptr]*RuntimeObject)

// scanobject исследует поля объекта и красит дочерние объекты в серый
func scanobject(addr uintptr, gcw *GCWorkBuffer) {
	obj := heapMap[addr]
	fmt.Printf("scanobject(0x%x): исследование полей...\n", addr)

	for i, isPtr := range obj.IsPointer {
		if isPtr && i < len(obj.ChildAddrs) {
			childAddr := obj.ChildAddrs[i]
			childObj := heapMap[childAddr]
			if childObj != nil && !childObj.MarkBit {
				// greyobject: помечаем бит и кладем в серую очередь
				childObj.MarkBit = true
				gcw.Put(childAddr)
				fmt.Printf("  -> Найден дочерний указатель 0x%x: помечен Серым\n", childAddr)
			}
		}
	}
	// Объект addr теперь ЧЕРНЫЙ
	fmt.Printf("scanobject(0x%x): завершено -> объект стал ЧЕРНЫМ\n", addr)
}

// gcDrain извлекает серые объекты, пока буфер не опустеет
func gcDrain(gcw *GCWorkBuffer) {
	fmt.Println(">>> Старт gcDrain() <<<")
	for {
		addr, ok := gcw.TryGet()
		if !ok {
			break
		}
		scanobject(addr, gcw)
	}
	fmt.Println(">>> gcDrain() завершен: серая очередь пуста <<<")
}

func main() {
	// Инициализируем объекты
	heapMap[0x1000] = &RuntimeObject{Addr: 0x1000, IsPointer: []bool{true}, ChildAddrs: []uintptr{0x2000}}
	heapMap[0x2000] = &RuntimeObject{Addr: 0x2000, IsPointer: []bool{true}, ChildAddrs: []uintptr{0x3000}}
	heapMap[0x3000] = &RuntimeObject{Addr: 0x3000, IsPointer: []bool{false}}

	gcw := &GCWorkBuffer{}
	// Корень 0x1000 стал серым
	heapMap[0x1000].MarkBit = true
	gcw.Put(0x1000)

	gcDrain(gcw)
}
```

ℹ️ Программная реконструкция алгоритма gcDrain и scanobject из mgcmark.go

## Под капотом

В реальном рантайме функция `scanobject` оптимизирована на ассемблере и SIMD: она читает маску указателей словами по 64 бита (`heapBits`), мгновенно пропуская непрерывные диапазоны скалярных полей (`int`, `float`, байты) без проверок каждого отдельного смещения.

## Подводные камни

Если структура содержит миллионы указателей, один вызов `scanobject` может занять слишком много времени. Для предотвращения задержек планировщика `gcDrain` проверяет флаги вытеснения горутины каждые несколько сотен просканированных объектов.

## На собеседовании

**Вопрос:** Какую роль выполняет функция gcDrain в рантайме Go?
**Ответ:** gcDrain — это главный цикл конкурентной разметки. Она в цикле извлекает серые указатели из локальных и глобальных очередей gcWork, вызывает scanobject для каждого объекта (обход полей-указателей и добавление новых потомков в очередь) до тех пор, пока вся работа по разметке не будет полностью завершена.
