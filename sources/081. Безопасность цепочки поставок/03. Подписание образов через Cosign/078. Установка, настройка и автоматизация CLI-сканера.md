# Установка, настройка и автоматизация CLI-сканера Syft

## Условие

Напишите скрипт автоматической установки актуальной версии Anchore Syft с верификацией контрольных сумм и запустите сканирование локального скомпилированного Go-бинарника.

### Исходная формулировка

**Syft installation**: Установите `syft` через `go install github.com/anchore/syft/cmd/syft@latest`.

## Теория

Утилита `syft` от Anchore является де-факто стандартом командной строки для извлечения SBOM из файлов, папок и контейнеров. В безопасном CI/CD пайплайне установка сторонних CLI-инструментов должна сопровождаться обязательной проверкой криптографической контрольной суммы (SHA-256) дистрибутива перед запуском.

## Решение по шагам

Скачайте официальный архив релиза Syft с GitHub Releases.
Загрузите сопровождающий файл контрольных сумм `checksums.txt`.
Сверьте SHA-256 хеш скачанного бинарника с эталоном через `sha256sum --check`.
Выполните тестовое сканирование: `syft packages dir:. -o table`.

## Код решения

**`install_syft.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

SYFT_VERSION="v1.0.1"
echo "[SYFT] Безопасная установка Syft ${SYFT_VERSION}..."

# Скачивание официальным скриптом с проверкой контрольных сумм
curl -sSfL https://raw.githubusercontent.com/anchore/syft/main/install.sh | sh -s -- -b /tmp ${SYFT_VERSION}

/tmp/syft --version
echo "[OK] Syft успешно установлен и готов к генерации SBOM."
```

ℹ️ Установка Syft с проверкой ревизии и версионирования

## Под капотом

Syft содержит встроенные каталогизаторы (catalogers) для Go (`cataloger/golang`), которые ищут `go.mod`, `go.sum`, а также декодируют секцию `.go.buildinfo` в ELF-заголовках бинарников.

## Подводные камни

Скачивание скрипта установки через `curl | sh` без указания точного тега версии может привести к неожиданной поломке CI при выходе несовместимой мажорной версии.

## На собеседовании

В enterprise-контурах запуск внешних скриптов из сети заблокирован: все бинарники сборщиков должны браться из внутреннего доверенного репозитория артефактов (Nexus/Artifactory).
