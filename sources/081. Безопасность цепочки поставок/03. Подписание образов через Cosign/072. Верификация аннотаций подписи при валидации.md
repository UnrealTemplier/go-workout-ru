# Верификация аннотаций подписи при валидации OCI-образов

## Условие

Разработайте Go-скрипт проверки подписи Cosign с обязательной проверкой аннотаций (проверка окружения, ветки Git и идентификатора пайплайна).

### Исходная формулировка

**Verify annotations**: Верифицируйте annotations при signature verification.

## Теория

Команда `cosign verify -a <key>=<value>` проверяет не только криптографическую валидность открытого ключа, но и соответствие заявленных аннотаций. Если образ подписан доверенным ключом, но аннотация `environment` содержит значение `staging` вместо `production`, валидатор отклоняет образ, предотвращая проникновение тестовых артефактов в бой.

## Решение по шагам

Сконфигурируйте вызов утилиты cosign с флагом `-a` для каждой обязательной аннотации.
Реализуйте обработку вывода cosign verify в Go.
Проверьте сценарий отказа, когда ключ валиден, но аннотация не совпадает.
Логируйте результат аудита в структурированном виде.

## Код решения

**`verify_ann.go`**

```go
package main

import (
	"context"
	"fmt"
	"os/exec"
	"time"
)

func VerifyImageWithAnnotations(image, pubKey string, requiredAnn map[string]string) error {
	ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
	defer cancel()

	args := []string{"verify", "--key", pubKey}
	for k, v := range requiredAnn {
		args = append(args, "-a", fmt.Sprintf("%s=%s", k, v))
	}
	args = append(args, image)

	cmd := exec.CommandContext(ctx, "cosign", args...)
	out, err := cmd.CombinedOutput()
	if err != nil {
		return fmt.Errorf("ошибка проверки аннотаций cosign: %v, вывод: %s", err, string(out))
	}
	fmt.Printf("[OK] Образ успешно валидирован со всеми требуемыми аннотациями!\n")
	return nil
}

func main() {
	req := map[string]string{
		"environment": "production",
		"org":         "MyCompany",
	}
	fmt.Printf("[VERIFY] Требуемые аннотации для допуска: %v\n", req)
	// Вызов валидатора (симуляция)
	_ = VerifyImageWithAnnotations
}
```

ℹ️ Проверка совпадения аннотаций OCI-подписи в CI/CD

## Под капотом

Cosign декодирует полезную нагрузку подписи (JSON SimpleSigning payload), находит карту `critical.identity` и сверяет все заданные флаги `-a` на точное побайтовое совпадение строк.

## Подводные камни

Регистрозависимость: аннотации `Production` и `production` будут признаны несовпадающими.

## На собеседовании

Как не допустить выкатку staging-образа в production-кластер Kubernetes? Ответ: Проверять аннотацию `env=prod` в Admission Webhook при верификации подписи Cosign.
