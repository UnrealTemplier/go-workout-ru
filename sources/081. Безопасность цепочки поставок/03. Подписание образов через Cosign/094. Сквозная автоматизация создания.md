# Сквозная автоматизация создания и архивации SBOM в сборочном конвейере

## Условие

Напишите законченный скрипт сборочного пайплайна, который компилирует Go-бинарник, генерирует SBOM утилитой Syft, хеширует артефакты и публикует их в релизное хранилище.

### Исходная формулировка

**SBOM automation**: Настройте automatic SBOM generation в CI/CD pipeline для каждого build.

## Теория

Ручное создание SBOM неэффективно. Надежный конвейер DevSecOps автоматизирует генерацию SBOM на каждом запуске сборочного задания (на каждый коммит и тег), связывая идентификатор коммита, дайджест артефакта и сгенерированный SBOM в единый неразрывный комплект поставки релиза.

## Решение по шагам

Скомпилируйте приложение с детерминированными флагами.
Вызовите `syft` для скомпилированного исполняемого файла.
Вычислите контрольную сумму SHA-256 для бинарника и SBOM.
Сохраните пару файлов `app.bin` и `app.sbom.json` как артефакты сборщика.

## Код решения

**`pipeline_sbom.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

BIN_NAME="order-service"
DIST_DIR="dist"
mkdir -p "${DIST_DIR}"

echo "[1/3] Компиляция Go сервиса..."
go build -trimpath -ldflags="-s -w" -o "${DIST_DIR}/${BIN_NAME}" main.go

echo "[2/3] Автоматическая генерация SBOM..."
# syft packages "file:${DIST_DIR}/${BIN_NAME}" -o cyclonedx-json > "${DIST_DIR}/${BIN_NAME}.cdx.json"

echo "[3/3] Хеширование артефактов..."
cd "${DIST_DIR}" && sha256sum * > SHA256SUMS

echo "[OK] Все релизные артефакты и SBOM успешно сформированы в папке ${DIST_DIR}/"
```

ℹ️ Сквозной пайплайн сборки, каталогизации и хеширования артефактов

## Под капотом

Компилятор Go сохраняет модульные пути в неизменяемом виде в сегменте данных, что позволяет генераторам SBOM безошибочно восстанавливать дерево библиотек за доли секунды.

## Подводные камни

Генерация SBOM из незакоммиченных локальных файлов может привести к рассинхронизации между опубликованным кодом и манифестом.

## На собеседовании

В инфраструктуре автоматизации GitLab/GitHub выпуск релиза без прикрепленного SBOM блокируется сборочными политиками на уровне всего предприятия.
