# Усиление безопасности сборочных пайплайнов GitHub Actions

## Условие

Сконфигурируйте защищенный workflow: фиксация действий по полному SHA-хешу коммита (immutable pinning), отключение сохранения токенов git (persist-credentials: false) и ограничение permissions.

### Исходная формулировка

**GitHub Actions Hardening.**: Настройте workflow: `actions/checkout` с `persist-credentials: false`, `pin` actions по SHA (не по floating tag), `dependabot` для GitHub Actions. Объясните supply chain атаки на CI/CD (compromised action, typosquatting в marketplace).

## Теория

Компрометация сборочного раннера в CI/CD — распространенный вектор атак на Supply Chain. Злоумышленник, получивший контроль над сторонним Action из Marketplace, может выпустить вредоносный тег `v2`. Использование плавающих тегов (`@v2`, `@master`) недопустимо в enterprise. Все действия должны фиксироваться по полному 40-символьному хэшу коммита (`@abc123...`). Также флаг `persist-credentials: false` предотвращает кражу токена `GITHUB_TOKEN` последующими шагами сборки.

## Решение по шагам

Укажите строгие минимальные права на уровне всего workflow: `permissions: contents: read`.
Замените все теги версий в `uses:` на полные SHA коммитов.
Установите `persist-credentials: false` в блоке `actions/checkout`.
Настройте Dependabot для автоматического отслеживания новых коммитов зафиксированных Actions.

## Код решения

**`hardened_ci.yml`**

```yaml
name: Hardened Go CI
on: [push, pull_request]

# Принцип наименьших привилегий (Least Privilege)
permissions:
  contents: read

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository
        # Пиннинг по полному SHA-хешу коммита коммита v4.1.7
        uses: actions/checkout@692973e3d937129bcbf40652eb9f2f61becf3332
        with:
          persist-credentials: false

      - name: Setup Go Toolchain
        # Пиннинг v5.0.1
        uses: actions/setup-go@0a12ed9d6a96ab950c8f026ed9f722fe0da7ef32
        with:
          go-version: '1.22'
          cache: true

      - name: Run Tests
        run: go test -v -race ./...
```

ℹ️ Защищенный манифест CI/CD с фиксацией Actions по SHA

## Под капотом

Git-тег является мутабельной ссылкой: владелец репозитория может в любой момент перезаписать его на другой коммит. Хеш SHA-1 коммита криптографически неизменяем.

## Подводные камни

Фиксация по SHA усложняет чтение кода workflow; для решения этой проблемы комментарием рядом всегда указывают человекочитаемую версию (например `# v4.1.7`).

## На собеседовании

Атака на SolarWinds и инцидент Codecov произошли именно из-за компрометации сборочного скрипта в CI. В BigTech жестко запрещено использовать сторонние Actions без аудита исходников сотрудниками ИБ.
