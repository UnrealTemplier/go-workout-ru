# Управление Go-зависимостями в корпоративном репозитории JFrog Artifactory

## Условие

Изучите архитектуру виртуальных репозиториев Go в JFrog Artifactory (Local, Remote, Virtual), объясните механизм работы с Xray для поиска уязвимостей и настройте GOPROXY.

### Исходная формулировка

**JFrog Artifactory**: Настройте Artifactory как Go registry. Изучите отличия от Athens.

## Теория

JFrog Artifactory — enterprise-стандарт хранения артефактов. Для Go он предоставляет 3 типа репозиториев:
1. Local: для внутренних модулей компании.
2. Remote: кэширующее зеркало публичных репозиториев (`proxy.golang.org`).
3. Virtual: объединяющий эндпоинт, инкапсулирующий Local и Remote в единый URL `GOPROXY`.
Интегрированный сканер JFrog Xray автоматически блокирует загрузку модулей, содержащих критические уязвимости или запрещенные лицензии.

## Решение по шагам

Создайте Virtual Go Repository `go-virtual` в панели Artifactory.
Объедините в нем внутренний репозиторий `go-local` и удаленный `go-remote`.
Сконфигурируйте политику Xray на блокировку CVE с CVSS > 8.0.
Настройте разработчиков на единый эндпоинт `GOPROXY=https://artifactory.corp/artifactory/api/go/go-virtual`.

## Код решения

**`artifactory_config.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

ARTIFACTORY_URL="https://artifactory.company.internal/artifactory/api/go/go-virtual"

echo "[ARTIFACTORY] Настройка Go toolchain на enterprise виртуальный репозиторий..."
export GOPROXY="${ARTIFACTORY_URL}"
export GONOSUMDB="*" # Проверка сумм выполняется на стороне Artifactory

echo "[ENV] GOPROXY=${GOPROXY}"
echo "[ENV] GONOSUMDB=${GONOSUMDB}"
echo "[OK] Все зависимости прозрачно контролируются шлюзом JFrog Xray."
```

ℹ️ Подключение Go к виртуальному корпоративному репозиторию JFrog Artifactory

## Под капотом

Artifactory перехватывает запросы пакетов, за доли секунды сверяет PURL с базой JFrog Xray и возвращает HTTP 403 Forbidden с описанием уязвимости, если пакет заблокирован политикой безопасности.

## Подводные камни

Отключение `GONOSUMDB=*` при использовании Artifactory приведет к ошибкам при обращении к внутренним приватным модулям компании через Google SumDB.

## На собеседовании

В чем главное отличие между Athens и JFrog Artifactory? Athens — это специализированный легковесный open-source прокси, а Artifactory — универсальная enterprise-платформа с RBAC, аудитом, сканированием Xray и поддержкой десятков экосистем.
