# Аутентификация и контроль доступа к Go Module Proxy

## Условие

Настройте аутентификацию на базе Bearer токенов или Basic Auth для Athens Proxy и сконфигурируйте файл ~/.netrc на рабочих станциях разработчиков.

### Исходная формулировка

**Athens + authentication**: Настройте basic auth или token-based auth для Athens.

## Теория

Чтобы ограничить доступ к корпоративному прокси и защитить приватные модули компании, Athens настраивают с аутентификацией. Инструмент `go` автоматически считывает учетные данные из файла `~/.netrc` (в Linux/macOS) или `%USERPROFILE%/_netrc` (в Windows) при обращении к защищенным HTTP-эндпоинтам.

## Решение по шагам

Включите базовую аутентификацию в конфигурации прокси.
Создайте учетную запись пользователя с токеном доступа.
Настройте файл `~/.netrc` со строками `machine athens.corp.internal login ci-user password <token>`.
Установите права `chmod 600 ~/.netrc` для предотвращения чтения другими пользователями ОС.

## Код решения

**`setup_netrc.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

NETRC_FILE="${HOME}/.netrc"
PROXY_HOST="athens.company.internal"
USER_LOGIN="corp-developer"
SECRET_TOKEN="ghp_secureTokenForAthens2026"

echo "[NETRC] Настройка учетных данных для защищенного GOPROXY..."
touch "${NETRC_FILE}"
chmod 600 "${NETRC_FILE}"

cat >> "${NETRC_FILE}" << EOF
machine ${PROXY_HOST}
  login ${USER_LOGIN}
  password ${SECRET_TOKEN}
EOF

echo "[OK] Файл ~/.netrc успешно обновлен с правами 0600."
```

ℹ️ Безопасная настройка файла .netrc для доступа к защищенному GOPROXY

## Под капотом

Go toolchain использует пакет `net/http`, который при наличии файла `.netrc` автоматически добавляет заголовок `Authorization: Basic ...` к каждому запросу к указанному хосту.

## Подводные камни

Если права на `.netrc` шире, чем `0600`, утилиты (например, curl или git) могут отказаться его использовать из соображений безопасности.

## На собеседовании

Как безопасно передать учетные данные в Go toolchain внутри Docker-контейнера? Ответ: Использовать Docker BuildKit secret mounts (`--mount=type=secret,id=netrc,target=/root/.netrc`).
