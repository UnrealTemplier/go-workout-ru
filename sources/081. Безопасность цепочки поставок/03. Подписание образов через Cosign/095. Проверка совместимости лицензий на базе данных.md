# Проверка совместимости лицензий на базе данных SBOM

## Условие

Реализуйте Go-утилиту, парсящую секцию лицензий в CycloneDX SBOM и проверяющую отсутствие конфликтующих лицензий (GPLv2 vs Apache-2.0, AGPL в коммерческом коде).

### Исходная формулировка

**SBOM + license compliance**: Используйте SBOM для license compliance checking (GPL, MIT, Apache compatibility).

## Теория

Лицензионная совместимость — сложная юридическая область. Некоторые открытые лицензии несовместимы друг с другом (например, оригинальная лицензия Apache 2.0 и GPLv2). Парсер SBOM позволяет сопоставить каждую лицензию компонента с матрицей допустимых сочетаний компании и предотвратить судебные разбирательства о нарушении авторских прав до релиза продукта.

## Решение по шагам

Определите матрицу несовместимых пар лицензий.
Распарсите поле `licenses` каждого компонента в файле CycloneDX JSON.
Выявите компоненты с отсутствующими или конфликтующими лицензиями.
Сформируйте заключение аудита соответствия (Compliance Status).

## Код решения

**`license_checker.go`**

```go
package main

import (
	"fmt"
	"strings"
)

var ForbiddenLicenses = map[string]string{
	"GPL-3.0":  "Копилефтная лицензия, запрещенная в проприетарных сервисах",
	"AGPL-3.0": "Сетевой копилефт, запрещен политикой компании",
}

func CheckLicense(pkgName, licenseID string) error {
	for forbidden, reason := range ForbiddenLicenses {
		if strings.Contains(strings.ToUpper(licenseID), forbidden) {
			return fmt.Errorf("пакет %s нарушает политику: %s (%s)", pkgName, licenseID, reason)
		}
	}
	return nil
}

func main() {
	pkg := "github.com/some/network-tool"
	lic := "AGPL-3.0-or-later"

	if err := CheckLicense(pkg, lic); err != nil {
		fmt.Printf("[LEGAL REJECT] %v\n", err)
	} else {
		fmt.Println("[OK] Лицензия пакета одобрена.")
	}
}
```

ℹ️ Контроль допустимости типов лицензий Open Source компонентов

## Под капотом

Многие пакеты используют составные выражения SPDX, такие как `(MIT OR Apache-2.0)` или `GPL-2.0-with-classpath-exception`. Валидатор должен поддерживать логические операторы SPDX выражения.

## Подводные камни

Ложное срабатывание на дуальные лицензии: если библиотека лицензирована как `MIT OR GPL-3.0`, проект имеет право выбрать пермиссивную лицензию MIT.

## На собеседовании

Крупные ИТ-компании держат штат юристов по Open Source; кандидатов на роль Tech Lead часто спрашивают о рисках применения библиотек под лицензией GNU AGPLv3.
