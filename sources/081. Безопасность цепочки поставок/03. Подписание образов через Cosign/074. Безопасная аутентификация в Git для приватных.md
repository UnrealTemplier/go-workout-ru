# Безопасная аутентификация в Git для приватных Go-модулей

## Условие

Настройте директивы git config insteadOf для прозрачной подмены протокола HTTPS на SSH или внедрения персональных токенов доступа (PAT) в CI/CD без раскрытия секретов в коде.

### Исходная формулировка

**Git authentication для private modules**: Настройте Git credentials для private repos:
```bash
git config --global url."https://token@github.com/".insteadOf "https://github.com/"
```

## Теория

Приватные модули компании (например, `gitlab.corp.com/team/auth`) требуют аутентификации при загрузке через `go get`. Поскольку Go toolchain выполняет вызовы Git по протоколу HTTPS без интерактивного ввода пароля, в окружении CI настраивают перенаправление URL через `git config --global url."...".insteadOf`. Для SSH используется ключ deploy key, а для HTTPS — эфемерный токен доступа раннера.

## Решение по шагам

Сконфигурируйте SSH-аутентификацию: `git config --global url."git@gitlab.corp.com:".insteadOf "https://gitlab.corp.com/"`.
Для HTTPS настройте внедрение токена: `git config --global url."https://oauth2:${CI_JOB_TOKEN}@gitlab.corp.com/".insteadOf "https://gitlab.corp.com/"`.
Установите `GOPRIVATE=gitlab.corp.com/*`.
Проверьте бесшовную загрузку модулей командой `go mod download`.

## Код решения

**`setup_git_auth.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

TOKEN="${CI_ACCESS_TOKEN:-x-access-token}"
CORP_HOST="github.company.internal"

echo "[GIT-AUTH] Настройка безопасного доступа к приватным модулям..."
# Настройка подмены HTTPS URL с токеном доступа
git config --global url."https://${TOKEN}@${CORP_HOST}/".insteadOf "https://${CORP_HOST}/"

# Исключение приватных модулей из публичных кэшей и баз сумм
export GOPRIVATE="${CORP_HOST}/*"

echo "[OK] Git сконфигурирован. Тестирование go mod download..."
# go mod download
```

ℹ️ Автоматическая настройка учетных данных Git для Go toolchain

## Под капотом

Утилита `go get` делегирует клонирование репозиториев системному клиенту `git`. Правило `insteadOf` перехватывает сгенерированный URL до установления сетевого соединения, прозрачно добавляя заголовки авторизации.

## Подводные камни

Логирование вывода команды `git config --list` в общедоступные логи сборки может привести к утечке секретного токена в открытом виде.

## На собеседовании

В GitLab CI для безопасного скачивания приватных подмодулей используется встроенный эфемерный токен `CI_JOB_TOKEN`, который инвалидируется сразу после завершения пайплайна.
