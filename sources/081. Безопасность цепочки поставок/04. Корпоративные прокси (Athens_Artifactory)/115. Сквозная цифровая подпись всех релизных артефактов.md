# Сквозная цифровая подпись всех релизных артефактов (Binary, Image, SBOM)

## Условие

Реализуйте унифицированный сборочный скрипт, подписывающий утилитой Cosign исполняемый бинарный файл, Docker-образ и сгенерированный файл SBOM.

### Исходная формулировка

**Подписывайте все артефакты.**: Docker images, binaries, SBOMs — всё должно быть подписано через cosign. Verifiers должны проверять signatures перед использованием.

## Теория

Подпись одного только Docker-образа оставляет уязвимыми бинарные файлы и сопровождающие документы. Концепция комплексной защиты цепочки поставок (Total Artifact Signing) требует подписывать абсолютно все выходные артефакты: бинарник (`cosign sign-blob`), OCI-образ (`cosign sign`) и документ SBOM (`cosign attest` или `cosign sign-blob`).

## Решение по шагам

Скомпилируйте бинарный файл приложения.
Сгенерируйте и опубликуйте Docker-образ.
Сгенерируйте документ SBOM.
Подпишите каждый артефакт единой доверенной ключевой парой Cosign.

## Код решения

**`sign_all_artifacts.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

KEY="cosign.key"

echo "[1/3] Подписание бинарного файла..."
# cosign sign-blob --key "${KEY}" --output-signature app.bin.sig app.bin

echo "[2/3] Подписание контейнерного образа в реестре..."
# cosign sign --key "${KEY}" myregistry.corp/app:v1.0.0

echo "[3/3] Подписание и аттестация SBOM..."
# cosign attest --key "${KEY}" --predicate sbom.json --type cyclonedx myregistry.corp/app:v1.0.0

echo "[SUCCESS] Все артефакты релиза защищены криптографическими подписями!"
```

ℹ️ Сквозное подписание всех компонентов сборки

## Под капотом

Команда `sign-blob` генерирует отдельный файл подписи `.sig`, а `cosign sign` для контейнера публикует подпись прямо в OCI-реестр как артефакт.

## Подводные камни

Потеря или повреждение отдельного файла подписи `.sig` для бинарника сделает невозможной офлайн-проверку на сервере клиента.

## На собеседовании

В чем разница между sign-blob и sign в Cosign? `sign` ориентирован на реестры OCI и сохраняет подпись в реестре, а `sign-blob` подписывает любой локальный файл на диске.
