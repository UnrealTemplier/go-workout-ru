# Экспорт лицензионных файлов зависимостей для юридического комплаенса

## Условие

Настройте утилиту go-licenses для извлечения и сохранения всех файлов лицензий сторонних модулей в каталог vendor-licenses/ перед сборкой дистрибутива.

### Исходная формулировка

**Vendor licensing**: Включите license files в vendor для compliance:
```bash
go-licenses save ./... --save_path=vendor-licenses
```

## Теория

Большинство свободных лицензий (MIT, Apache 2.0, BSD) требуют обязательного включения оригинального текста лицензии и уведомления об авторских правах (Notice) в состав распространяемого бинарника или документации продукта. Утилита `go-licenses save` автоматически находит все файлы лицензий в дереве зависимостей и копирует их в указанную директорию для юристов.

## Решение по шагам

Установите утилиту: `go install github.com/google/go-licenses@latest`.
Запустите экспорт: `go-licenses save ./... --save_path=./THIRD_PARTY_LICENSES`.
Проверьте, что каталог содержит лицензии всех используемых библиотек.
Включите сгенерированную директорию в состав архива релиза.

## Код решения

**`save_licenses.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

OUTPUT_DIR="dist/THIRD_PARTY_LICENSES"
mkdir -p "${OUTPUT_DIR}"

echo "[LEGAL] Сохранение лицензий всех зависимостей для релиза..."
# go-licenses save ./... --save_path="${OUTPUT_DIR}" --force

echo "[OK] Юридический каталог сформирован:"
# ls -la "${OUTPUT_DIR}"
echo "[SUCCESS] Уведомления об авторских правах соблюдены."
```

ℹ️ Сбор и упаковка текстов лицензий сторонних библиотек

## Под капотом

go-licenses сканирует корень каждого пакета в поисках файлов, удовлетворяющих регулярным выражениям `LICENSE*`, `COPYING*`, `NOTICE*`.

## Подводные камни

Если зависимость использует кастомный или переименованный файл лицензии (например, `COPYRIGHT.txt`), утилита может выдать предупреждение о неустановленной лицензии.

## На собеседовании

Поставка коммерческого софта крупным клиентам (B2B) без сформированного каталога Open Source Notices является нарушением договоров поставки и лицензионных соглашений.
