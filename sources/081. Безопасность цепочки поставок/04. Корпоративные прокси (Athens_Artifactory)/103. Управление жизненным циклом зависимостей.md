# Управление жизненным циклом зависимостей через каталог vendor

## Условие

Создайте и структурируйте каталог vendor/ для микросервиса с несколькими внешними библиотеками, проверьте консистентность зависимостей и выполните сборку в изолированном окружении.

### Исходная формулировка

**Vendoring**: Используйте `go mod vendor` для создания `vendor/` directory со всеми dependencies. Это делает builds reproducible и independent от network.

## Теория

Команда `go mod vendor` материализует все внешние зависимости в локальной директории `vendor/` проекта. Это делает репозиторий полностью самодостаточным: для сборки больше не требуется доступ к публичным реестрам, Git-хостингам или кэшу модулей. Такой подход исключает риск сбоев при падении внешних сервисов (GitHub, proxy.golang.org) и защищает проект от внезапного удаления библиотек их авторами.

## Решение по шагам

Инициализируйте зависимости проекта с помощью `go get`.
Выполните `go mod tidy` для удаления неиспользуемых модулей.
Сформируйте локальный вендор командой `go mod vendor`.
Соберите проект с флагом `-mod=vendor` и проверьте автономность компиляции.

## Код решения

**`vendor_cycle.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

echo "[1/3] Очистка неиспользуемых зависимостей..."
go mod tidy

echo "[2/3] Выгрузка зависимостей в каталог vendor/..."
go mod vendor

echo "[3/3] Сборка с принудительным использованием vendor..."
go build -mod=vendor -v -o service_app main.go

echo "[SUCCESS] Проект успешно собран из локального каталога vendor."
```

ℹ️ Базовый жизненный цикл вендоринга проекта на Go

## Под капотом

Go сохраняет в файле `vendor/modules.txt` хеши и версии каждого модуля, гарантируя, что компилятор скомпонует в итоговый бинарник именно проверенные исходники.

## Подводные камни

Если изменить исходный код внутри vendor/ вручную без фиксации, следующий вызов `go mod vendor` молча перезапишет все ваши изменения.

## На собеседовании

В enterprise-разработке вендоринг часто применяется для критических микросервисов банковских систем, где недопустима даже секундная задержка сборщика из-за сети.
