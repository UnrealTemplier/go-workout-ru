# Достижение уровня защищенности SLSA Level 3 в промышленной среде

## Условие

Опишите архитектурные требования и настройте сборочный раннер для соответствия требованиям SLSA Level 3: герметичность сборки, изоляция раннера и неизменяемость Provenance.

### Исходная формулировка

**SLSA Level 3 минимум.**: Для production software стремитесь к SLSA Level 3 (isolated, hermetic builds). Это защищает от build system compromise.

## Теория

SLSA Level 3 является золотым стандартом для промышленного ПО. Он гарантирует:
1. Сборка выполняется на защищенной изолированной платформе (Hosted Build Platform).
2. Герметичность (Hermetic): сборка не имеет доступа к сети во время компиляции, а все зависимости зафиксированы и хешированы.
3. Неизменяемость среды (Isolated): раннеры эфемерны и уничтожаются сразу после выполнения задания.
4. Неподделываемый манифест происхождения (Non-falsifiable Provenance), генерируемый доверенным сервисом платформы.

## Решение по шагам

Сконфигурируйте эфемерные раннеры в Kubernetes через Actions Runner Controller (ARC).
Отключите сетевой интерфейс на шаге компиляции бинарника.
Используйте доверенный сборочный генератор для создания Provenance.
Проверьте аттестат утилитой `slsa-verifier`.

## Код решения

**`slsa_verify.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

BINARY="app-linux-amd64"
PROVENANCE="app-linux-amd64.intoto.jsonl"
SOURCE_REPO="github.com/my-corp/secure-service"

echo "[SLSA-VERIFY] Проверка соответствия бинарника стандарту SLSA Level 3..."
# slsa-verifier verify-artifact "${BINARY}" \
#   --provenance-path "${PROVENANCE}" \
#   --source-uri "${SOURCE_REPO}"

echo "[OK] Бинарник успешно подтвердил происхождение от доверенного источника."
```

ℹ️ Проверка SLSA Level 3 происхождения артефакта через slsa-verifier

## Под капотом

slsa-verifier извлекает криптографическую подпись Fulcio, сверяет идентичность OIDC сборочного раннера и проверяет хеш коммита в защищенном журнале Rekor.

## Подводные камни

Запуск сборщика с правами root на постоянной виртуальной машине не позволяет претендовать на SLSA L3 из-за риска скрытого заражения хоста.

## На собеседовании

В компании Google безопасность бинарников обеспечивается системой Binary Authorization for Borg (BAB), вдохновившей создание стандарта SLSA.
