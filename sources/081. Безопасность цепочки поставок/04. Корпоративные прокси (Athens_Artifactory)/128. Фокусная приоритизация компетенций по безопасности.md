# Фокусная приоритизация компетенций по безопасности распределенных систем

## Условие

Реализуйте модульную систему оценки зрелости подсистем безопасности микросервиса (интеграция очередей, баз данных, TLS и сетевого контура) с определением критических приоритетов.

### Исходная формулировка

Пропусти то, что не относится к твоей текущей работе (например, если ты не работаешь с Kafka, сделай минимум по RabbitMQ/NATS).

## Теория

При разработке распределенных систем важно соблюдать принцип разумной достаточности: если в архитектуре не используется Kafka, тратить время на SASL/SCRAM харднинг брокера не имеет смысла, пока не закрыты базовые риски сетевого периметра и аутентификации в Redis/PostgreSQL. Архитектурная оценка безопасности определяет скоуп работ на основе модели угроз конкретной системы.

## Решение по шагам

Определите используемые в проекте компоненты инфраструктуры.
Составьте чек-лист обязательных требований безопасности для каждого активного компонента.
Отфильтруйте неактуальные технологии.
Сформируйте фокусированный план задач для инженерной команды.

## Код решения

**`sec_evaluator.go`**

```go
package main

import "fmt"

type ComponentAudit struct {
	Name     string
	InUse    bool
	Priority string
	Checks   []string
}

func FilterPriorityTasks(audit []ComponentAudit) {
	for _, c := range audit {
		if !c.InUse {
			continue // Пропускаем неактуальные для текущей архитектуры компоненты
		}
		fmt.Printf("[AUDIT] Компонент %s (Приоритет: %s):\n", c.Name, c.Priority)
		for _, check := range c.Checks {
			fmt.Printf("   - %s\n", check)
		}
	}
}

func main() {
	infrastructure := []ComponentAudit{
		{
			Name:     "PostgreSQL",
			InUse:    true,
			Priority: "CRITICAL",
			Checks:   []string{"TLS соединение (sslmode=verify-full)", "Connection pool limits", "Параметризованные запросы"},
		},
		{
			Name:     "Kafka",
			InUse:    false, // Не используется в текущем проекте
			Priority: "LOW",
			Checks:   []string{"mTLS auth", "ACL topics"},
		},
	}
	FilterPriorityTasks(infrastructure)
}
```

ℹ️ Фильтрация приоритетных мер безопасности на основе архитектурного профиля
