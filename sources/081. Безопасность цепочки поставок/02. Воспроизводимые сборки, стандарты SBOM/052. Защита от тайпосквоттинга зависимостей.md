# Защита от тайпосквоттинга зависимостей

## Условие

Напишите Go-утилиту или CI-валидатор, который парсит go.mod, сверяет домены и префиксы импортов со списком разрешенных доверенных организаций (допустимые префиксы / белый список) и выявляет подозрительные модули с похожими именами (тайпосквоттинг, например sirupsen vs sirupsem).

### Исходная формулировка

**Typosquatting (Опечатки)**: Хакеры создают пакеты вроде `github.com/sirupsen/logrus` (вместо `sirupsen`). Напиши CI-баш-скрипт, который парсит `go.mod` и ищет подозрительные домены или запрещает скачивание пакетов, не входящих во внутренний "белый список" компании.

## Теория

Тайпосквоттинг (Typosquatting) — вектор атаки на цепочку поставок, при котором злоумышленник регистрирует пакет с именем, визуально или фонетически схожим с популярной библиотекой (например, github.com/sirupsen/logrus заменяется на github.com/slrupsen/logrus или github.com/sirupsen-logrus/logger). В Go модули именуются URL-подобными путями. Корпоративные системы безопасности внедряют политики разрешенных доменов/организаций (allowlist) и вычисляют расстояние Левенштейна или сопоставляют префиксы в go.mod, чтобы не допустить случайного внедрения вредоносной подделки.

## Решение по шагам

Считайте и распарсите файл go.mod с помощью golang.org/x/mod/modfile или строкового анализатора.
Определите белый список доверенных префиксов организаций (например, github.com/google, github.com/uber-go, golang.org/x).
Проанализируйте расстояние Левенштейна до известных критических библиотек для выявления потенциальных опечаток.
Заблокируйте сборку с ненулевым кодом выхода при обнаружении подозрительных зависимостей.

## Код решения

**`validator.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"math"
	"os"
	"strings"
)

func levenshtein(a, b string) int {
	d := make([][]int, len(a)+1)
	for i := range d {
		d[i] = make([]int, len(b)+1)
		d[i][0] = i
	}
	for j := 0; j <= len(b); j++ {
		d[0][j] = j
	}
	for i := 1; i <= len(a); i++ {
		for j := 1; j <= len(b); j++ {
			cost := 1
			if a[i-1] == b[j-1] {
				cost = 0
			}
			d[i][j] = int(math.Min(float64(d[i-1][j]+1),
				math.Min(float64(d[i][j-1]+1), float64(d[i-1][j-1]+cost))))
		}
	}
	return d[len(a)][len(b)]
}

func main() {
	canonicalLibs := []string{
		"github.com/sirupsen/logrus",
		"go.uber.org/zap",
		"github.com/gin-gonic/gin",
	}

	rawMod := `
module myproject
go 1.22
require (
	github.com/slrupsen/logrus v1.9.3
	go.uber.org/zap v1.27.0
)
`
	scanner := bufio.NewScanner(strings.NewReader(rawMod))
	foundSuspicious := false

	for scanner.Scan() {
		line := strings.TrimSpace(scanner.Text())
		if strings.HasPrefix(line, "github.com/") || strings.HasPrefix(line, "go.uber.org/") {
			parts := strings.Fields(line)
			modPath := parts[0]
			for _, canonical := range canonicalLibs {
				dist := levenshtein(modPath, canonical)
				if dist > 0 && dist <= 2 {
					fmt.Printf("[ALERT] Подозрение на тайпосквоттинг: '%s' похож на '%s' (дистанция %d)\n",
						modPath, canonical, dist)
					foundSuspicious = true
				}
			}
		}
	}

	if foundSuspicious {
		fmt.Println("[FAIL] Обнаружены неавторизованные или подозрительные модули!")
		os.Exit(1)
	}
	fmt.Println("[OK] Зависимости проверены.")
}
```

ℹ️ Детектор тайпосквоттинга на базе расстояния Левенштейна в CI

## Под капотом

Go toolchain не выполняет фонетическую или орфографическую проверку имен пакетов. Любой синтаксически валидный модуль будет скачан через GOPROXY. Валидаторы в pre-commit хуках и CI-пайплайнах пресекают внедрение пакетов-клонов до того, как они попадут в vendor или кэш сборки.

## Подводные камни

Слишком низкий порог схожести (например, дистанция 3-4) может давать ложные срабатывания на официальные форки или схожие по структуре репозитории одной компании.

## На собеседовании

В Ozon и Авито используется корпоративный прокси Athens с белым списком разрешенных пространств имен, а сторонние PR строго проверяются линтером go.mod на попытки подмены доверенных репозиториев.
