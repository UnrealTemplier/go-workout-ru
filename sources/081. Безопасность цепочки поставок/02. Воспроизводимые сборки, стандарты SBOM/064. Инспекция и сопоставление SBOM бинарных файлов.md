# Инспекция и сопоставление SBOM бинарных файлов утилитой Syft

## Условие

Напишите Go-утилиту, которая парсит JSON-отчет Syft для скомпилированного Go-бинарника и проверяет наличие компонентов без фиксированной версии или с нелицензионным кодом.

### Исходная формулировка

**[SBOM (Software Bill of Materials)]**: Сгенерируй SBOM для своего бинарника с помощью утилиты `syft`. Это JSON/XML файл со списком всех зависимостей и их версий. Изучи, зачем это нужно энтерпрайзу (для быстрого поиска уязвимостей по списку CVE, не разбирая исходники).

## Теория

Утилита Syft от Anchore умеет извлекать SBOM непосредственно из скомпилированных Go-бинарников благодаря анализу секции BuildInfo, внедряемой компилятором Go. В корпоративной разработке полученный SBOM сопоставляется с внутренними политиками Legal/Compliance для обнаружения вирусных лицензий (GPLv3 в закрытом проприетарном сервисе) и устаревших зависимостей.

## Решение по шагам

Скомпилируйте Go-приложение с флагами оптимизации.
Сгенерируйте отчет командой `syft packages file:app.bin -o json`.
Разработайте Go-парсер артефакта Syft для валидации лицензий и версий.
Выведите предупреждения при обнаружении несовместимых лицензий.

## Код решения

**`syft_parser.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"strings"
)

type SyftArtifact struct {
	Artifacts []struct {
		Name     string   `json:"name"`
		Version  string   `json:"version"`
		Type     string   `json:"type"`
		Licenses []string `json:"licenses"`
	} `json:"artifacts"`
}

func main() {
	rawSyftJSON := `{
		"artifacts": [
			{"name": "github.com/google/uuid", "version": "v1.6.0", "type": "go-module", "licenses": ["BSD-3-Clause"]},
			{"name": "github.com/unknown/copyleft-lib", "version": "v0.1.0", "type": "go-module", "licenses": ["GPL-3.0-only"]}
		]
	}`

	var report SyftArtifact
	if err := json.Unmarshal([]byte(rawSyftJSON), &report); err != nil {
		panic(err)
	}

	for _, art := range report.Artifacts {
		for _, lic := range art.Licenses {
			if strings.HasPrefix(lic, "GPL") {
				fmt.Printf("[LEGAL ALERT] Обнаружена копилефтная лицензия %s в пакете %s!\n", lic, art.Name)
			}
		}
	}
	fmt.Println("[AUDIT] Анализ лицензий завершен.")
}
```

ℹ️ Аудит лицензионной чистоты компонентов из отчета Syft

## Под капотом

Syft считывает таблицу символов и встроенный блок `ÿ Go buildinf:` внутри ELF/Mach-O/PE исполняемого файла, извлекая модуль, ревизию и список зависимостей без декомпиляции машинного кода.

## Подводные камни

Если бинарник собран со стриппингом метаданных (`-ldflags="-s -w"`), некоторые утилиты не могут восстановить BuildInfo, поэтому для аудита рекомендуется использовать `syft dir:.` на этапе CI.

## На собеседовании

В юротделах BigTech компаний (Авито, Ozon) автоматический аудит SBOM блокирует merge request, если в зависимостях обнаружена лицензия AGPLv3.
