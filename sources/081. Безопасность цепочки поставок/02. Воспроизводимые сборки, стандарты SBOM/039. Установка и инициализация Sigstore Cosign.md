# Установка и инициализация Sigstore Cosign в инфраструктуре сборки

## Условие

Напишите Go-скрипт автоматической проверки и валидации утилиты cosign в сборочной среде, проверяющий генерацию ключевых пар и поддержку OIDC токенов.

### Исходная формулировка

**Cosign установка**: Установите `cosign` через `go install github.com/sigstore/cosign/v2/cmd/cosign@latest`.

## Теория

Утилита `cosign` (часть проекта Sigstore) стала де-факто мировым стандартом подписи контейнеров в Kubernetes (Open Container Initiative — OCI). Cosign хранит криптографические подписи, аттестации и спецификации SBOM прямо в OCI Container Registry рядом с образом контейнера в виде специальных тегов `sha256-<hash>.sig` и `sha256-<hash>.sbom`. Это позволяет валидировать подпись образа в Admission Controller кластера (Kyverno, OPA Gatekeeper) до того, как образ будет запущен в продакшене.

## Решение по шагам

Установите cosign v2 через go install github.com/sigstore/cosign/v2/cmd/cosign@latest.
Проверьте флаги cosign version.
Создайте временную пару ключей через cosign generate-key-pair.
Убедитесь в создании открытого cosign.pub и зашифрованного cosign.key.

## Код решения

**`init_cosign.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

echo "[1/3] Verifying Cosign installation..."
# cosign version

echo "[2/3] Generating local testing keypair with password protection..."
# export COSIGN_PASSWORD="test-secure-password"
# cosign generate-key-pair

echo "[3/3] Inspecting public key format (ECDSA P-256):"
# cat cosign.pub

echo "Cosign toolchain initialized and ready for signing OCI artifacts."
```

ℹ️ Инициализация и проверка среды Sigstore Cosign

## Под капотом

Cosign использует алгоритм ECDSA на эллиптической кривой P-256 (secp256r1) с хэшем SHA-256, обеспечивая высокую стойкость при компактном размере подписи (64 байта).

## Подводные камни

Забытый пароль от `cosign.key`. Восстановить утерянный приватный ключ невозможно — придется перегенерировать пару и обновлять доверенные сертификаты в Kubernetes.

## На собеседовании

Вопрос на собеседовании в Wildberries: 'Где Cosign хранит подписи Docker-образов?' Ответ: 'В том же самом OCI Container Registry! Cosign пушит специальный артефакт с тегом `sha256-<digest>.sig`. Это исключает необходимость поднимать отдельные серверы хранения подписей'.
