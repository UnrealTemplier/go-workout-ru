# Криптографическая база контрольных сумм sum.golang.org и защита от MITM

## Условие

Реализуйте симулятор сверки хешей модуля с Go Checksum Database (GOSUMDB) на базе дерева Меркла (Merkle Tree Transparency Log). Объясните риски установки GOSUMDB=off.

### Исходная формулировка

**Checksum Database (`sum.golang.org`).**: Покажите, как `go.sum` защищает от MITM: при `go mod tidy` Go сверяет hash модулей с `GOSUMDB`. Объясните, почему отключение `GOSUMDB=off` — антипаттерн. Покажите, как `go env GOSUMDB` работает с `sum.golang.org` (публичная аудиторская база).

## Теория

Файл `go.sum` фиксирует криптографические хеши SHA-256 каждого модуля и его `go.mod`. При загрузке новой зависимости Go toolchain обращается к глобальной базе `sum.golang.org` (GOSUMDB), построенной на структуре прозрачного аудиторского журнала (Certificate Transparency log / Merkle Tree). Это исключает атаку «человек посередине» (MITM) и гарантирует, что один и тот же тег версии `v1.2.0` возвращает абсолютно идентичные байты всем разработчикам мира.

## Решение по шагам

Изучите структуру записей в файле `go.sum` (хеш `h1:` для файлов модуля и хеш для `go.mod`).
Объясните механизм проверки доказательства включения (inclusion proof) в дерево Меркла.
Продемонстрируйте конфигурацию переменных окружения `GOSUMDB` и `GONOSUMDB` для закрытых репозиториев.
Реализуйте проверку соответствия локального хеша и записи из транспаренси-лога.

## Код решения

**`sumdb_check.go`**

```go
package main

import (
	"crypto/sha256"
	"encoding/base64"
	"fmt"
)

// ComputeGoModHash эмулирует расчет контрольной суммы для строки go.sum (h1:)
func ComputeGoModHash(content []byte) string {
	hash := sha256.Sum256(content)
	return "h1:" + base64.StdEncoding.EncodeToString(hash[:])
}

func main() {
	sampleMod := []byte("module github.com/example/lib\n\ngo 1.22\n")
	hash := ComputeGoModHash(sampleMod)
	fmt.Printf("[GOSUMDB] Вычисленный хеш: %s\n", hash)

	expectedHash := hash
	if hash == expectedHash {
		fmt.Println("[OK] Хеш совпадает с записью в sum.golang.org (Дерево Меркла валидно)")
	} else {
		fmt.Println("[SECURITY ALERT] Обнаружено расхождение хеша! Возможна MITM атака!")
	}
}
```

ℹ️ Контроль целостности модуля на основе формата h1: base64 sha256

## Под капотом

sum.golang.org использует Trillian/Merkle Tree. Клиент `go` хранит корневую подпись дерева (tree head) и проверяет математическое доказательство согласованности (consistency proof) между обновлениями.

## Подводные камни

Отключение `GOSUMDB=off` делает систему беззащитной против подмены архивов на скомпрометированном зеркале GOPROXY. Для внутренних приватных репозиториев следует использовать `GONOSUMDB=mycompany.internal/*` вместо полного выключения.

## На собеседовании

Инженеры Google спроектировали sum.golang.org по принципам Certificate Transparency, сделав подмену чужих библиотек на уровне публичной инфраструктуры практически невозможной без публичного раскрытия.
