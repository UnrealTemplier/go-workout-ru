# Настройка корпоративного Private Module Proxy (Athens / Artifactory)

## Условие

Сконфигурируйте и опишите архитектуру корпоративного Go-прокси в изолированном контуре (Air-Gapped) с поддержкой GOPROXY, GONOSUMDB и фильтрацией приватных модулей.

### Исходная формулировка

**Private Module Proxy (Athens/Artifactory).**: Настройте `GOPROXY=https://athens.company.com,https://proxy.golang.org,direct`. Покажите, что приватные модули кэшируются и проверяются внутри perimeter. Объясните air-gapped сценарий: `GOPROXY=https://athens.company.com` (без fallback) + `GONOSUMDB=*` + `GONOPROXY=*`.

## Теория

Публичный `proxy.golang.org` не имеет доступа к внутренним репозиториям компании (GitLab, Bitbucket) и может раскрывать пути приватных модулей через запросы контрольных сумм. Для защиты конфиденциальности и надежности в корпоративной сети развертывают собственный прокси (Athens, JFrog Artifactory, Nexus). Переменные окружения настраиваются так:
`GOPROXY=https://athens.corp.internal,https://proxy.golang.org,direct`
`GONOSUMDB=git.corp.internal/*`
`GONOPROXY=git.corp.internal/*`.

## Решение по шагам

Разверните локальный экземпляр Athens Proxy с персистентным хранилищем (S3/MinIO).
Сконфигурируйте список исключений для приватных доменов через `GONOPROXY` и `GONOSUMDB`.
Протестируйте поведение `go get` при недоступности интернета (работа через корпоративный кэш).
Напишите Go-тест для валидации правильности настройки переменных окружения сборщика.

## Код решения

**`proxy_checker.go`**

```go
package main

import (
	"fmt"
	"os"
	"strings"
)

func main() {
	goproxy := os.Getenv("GOPROXY")
	gonosumdb := os.Getenv("GONOSUMDB")

	fmt.Printf("[ENV] GOPROXY=%s\n", goproxy)
	fmt.Printf("[ENV] GONOSUMDB=%s\n", gonosumdb)

	if !strings.Contains(goproxy, "corp.internal") && goproxy != "" {
		fmt.Println("[WARN] Корпоративный прокси Athens не обнаружен в цепочке GOPROXY!")
	}

	if gonosumdb == "" {
		fmt.Println("[CRITICAL] Переменная GONOSUMDB пуста! Риск утечки внутренних путей модулей в Google!")
	} else {
		fmt.Println("[OK] Приватные модули исключены из публичной базы сумм.")
	}
}
```

ℹ️ Валидация переменных окружения Go toolchain для корпоративной безопасности

## Под капотом

Athens кэширует неизменяемые архивы `.zip`, `.mod` и `.info` модулей. Даже если автор публичной библиотеки удалит свой репозиторий с GitHub, локальный кэш Athens продолжит отдавать зафиксированную версию.

## Подводные камни

Забытый `GONOSUMDB` приведет к тому, что `go` попытается запросить контрольную сумму приватного модуля `git.mycorp.ru/auth/secret` у серверов Google (`sum.golang.org`), что приведет к ошибке 404 и утечке названия модуля.

## На собеседовании

В Т-Банке и Сбере весь внешний трафик разработчиков строго изолирован, а сборка пайплайнов происходит исключительно через внутренний кэширующий зеркальный кластер Artifactory.
