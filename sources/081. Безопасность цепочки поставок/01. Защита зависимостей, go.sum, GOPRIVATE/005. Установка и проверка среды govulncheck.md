# Установка и проверка среды govulncheck

## Условие

Напишите Go-скрипт, проверяющий установку и версию утилиты govulncheck в системе, а также доступность сервера уязвимостей vuln.go.dev.

### Исходная формулировка

**govulncheck установка**: Установите `govulncheck` через `go install golang.org/x/vuln/cmd/govulncheck@latest`. Это официальный инструмент от Go team.

## Теория

Для интеграции утилит сканирования в локальные dev-контейнеры и CI/CD раннеры необходимо гарантировать наличие установленного бинарника `govulncheck` и сетевую связность с официальным зеркалом базы данных `https://vuln.go.dev`. В изолированных контурах (Air-gapped / Private Cloud) прямой доступ к vuln.go.dev может быть закрыт firewall. В этом случае база уязвимостей зеркалируется локально, а утилита запускается с переменной окружения `GOVULNDB`.

## Решение по шагам

Используйте exec.LookPath для проверки наличия govulncheck в PATH.
Проверьте версию скомпилированного бинарника через govulncheck -version.
Выполните HTTP HEAD / GET запрос к https://vuln.go.dev/index/modules.json.
Сформируйте диагностический отчет готовности среды.

## Код решения

**`check_govulncheck_env.go`**

```go
package main

import (
	"context"
	"fmt"
	"net/http"
	"os/exec"
	"time"
)

func CheckToolchainHealth() {
	// 1. Проверяем наличие бинарника в PATH
	path, err := exec.LookPath("govulncheck")
	if err != nil {
		fmt.Println("[WARN] govulncheck binary not found in PATH (install via: go install golang.org/x/vuln/cmd/govulncheck@latest)")
	} else {
		fmt.Printf("[OK] Found govulncheck at: %s\n", path)
	}

	// 2. Проверяем сетевой доступ к Go Vulnerability Database
	ctx, cancel := context.WithTimeout(context.Background(), 3*time.Second)
	defer cancel()

	req, _ := http.NewRequestWithContext(ctx, "HEAD", "https://vuln.go.dev", nil)
	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		fmt.Printf("[NETWORK ERROR] Cannot reach https://vuln.go.dev: %v (Private mirror or proxy required)\n", err)
		return
	}
	defer resp.Body.Close()

	if resp.StatusCode == http.StatusOK || resp.StatusCode == http.StatusFound {
		fmt.Println("[OK] Connection to official Go Vulnerability Database (vuln.go.dev) is active.")
	}
}

func main() {
	CheckToolchainHealth()
}
```

ℹ️ Скрипт проверки окружения и сетевой доступности vuln.go.dev

## Под капотом

База `vuln.go.dev` спроектирована как статическое файловое хранилище (Google Cloud Storage bucket). Она отдает легковесные предгенерированные JSON файлы с gzip-сжатием, что позволяет кэшировать ответы на любом CDN прокси.

## Подводные камни

Установка старой версии govulncheck. Формат базы OSV развивается. Устаревший бинарник может некорректно парсить свежие схемы уязвимостей.

## На собеседовании

Вопрос на собеседовании в Kasperskу: 'Как запустить govulncheck в закрытом корпоративном контуре без доступа в интернет?' Ответ: 'Поднять внутреннее зеркало базы уязвимостей (с помощью утилиты gcp-audit или клонированием репозитория vuln) и настроить переменную окружения `export GOVULNDB=http://internal-mirror.corp/vulndb`'.
