# Модульный прокси: GOPROXY=https://proxy.golang.org,direct и защита от исчезновения кода

## Условие

Изучите устройство протокола Go Module Proxy. Напишите HTTP-сервер, реализующий базовые эндпоинты протокола GOPROXY (.info, .mod, .zip) для кэширования модулей.

### Исходная формулировка

**Module proxy**: Используйте `GOPROXY=https://proxy.golang.org,direct` (default) для кэширования modules. Это защищает от disappearing modules.

## Теория

Исторически в других языках удаление автором репозитория из GitHub приводило к падению сборок по всему миру (Left-Pad Incident). В Go эта проблема решена на уровне архитектуры: по умолчанию включен `GOPROXY=https://proxy.golang.org,direct`. Прокси-сервер Google кэширует неизменяемые архивы всех когда-либо опубликованных публичных модулей. Даже если автор удалит свой аккаунт на GitHub или сотрет репозиторий, `proxy.golang.org` продолжит вечно отдавать кэшированные zip-архивы и файлы `go.mod`. Суффикс `,direct` означает: 'Если модуль не найден на прокси, попытаться скачать напрямую из системы контроля версий (Git)'

## Решение по шагам

Изучите спецификацию протокола Go Module Proxy.
Реализуйте HTTP эндпоинты /$base/@v/list, .info, .mod.
Проверьте отдачу метаданных версии модуля в JSON формате.
Сформулируйте гарантии доступности зависимостей через проксирование.

## Код решения

**`mini_goproxy.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"log"
	"net/http"
	"net/http/httptest"
	"strings"
	"time"
)

// ModuleInfo представляет структуру ответа эндпоинта .info в протоколе GOPROXY
type ModuleInfo struct {
	Version string    `json:"Version"`
	Time    time.Time `json:"Time"`
}

// MiniGoProxy реализует протокол Go Module Proxy для кэширования модулей
func MiniGoProxy() http.Handler {
	mux := http.NewServeMux()

	// 1. Эндпоинт списка версий: /<module>/@v/list
	// 2. Эндпоинт метаданных:   /<module>/@v/<version>.info
	// 3. Эндпоинт манифеста:    /<module>/@v/<version>.mod
	mux.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
		path := r.URL.Path
		log.Printf("[GOPROXY Request] %s %s", r.Method, path)

		if strings.HasSuffix(path, ".info") {
			w.Header().Set("Content-Type", "application/json")
			info := ModuleInfo{
				Version: "v1.0.0",
				Time:    time.Now().UTC(),
			}
			_ = json.NewEncoder(w).Encode(info)
			return
		}

		if strings.HasSuffix(path, ".mod") {
			w.Header().Set("Content-Type", "text/plain; charset=utf-8")
			_, _ = w.Write([]byte("module github.com/mycorp/cached-lib\n\ngo 1.23\n"))
			return
		}

		if strings.HasSuffix(path, "/@v/list") {
			w.Header().Set("Content-Type", "text/plain; charset=utf-8")
			_, _ = w.Write([]byte("v1.0.0\nv1.0.1\n"))
			return
		}

		http.NotFound(w, r)
	})

	return mux
}

func main() {
	proxy := httptest.NewServer(MiniGoProxy())
	defer proxy.Close()

	fmt.Printf("Custom Go Module Proxy listening at: %s\n", proxy.URL)

	// Тестовый запрос эндпоинта версии
	resp, err := http.Get(proxy.URL + "/github.com/mycorp/cached-lib/@v/v1.0.0.info")
	if err != nil {
		log.Fatalf("Proxy call failed: %v", err)
	}
	defer resp.Body.Close()

	var info ModuleInfo
	_ = json.NewDecoder(resp.Body).Decode(&info)
	fmt.Printf("Received cached module info: Version=%s, PublishedAt=%s\n", info.Version, info.Time.Format(time.RFC3339))
}
```

ℹ️ Реализация протокола Go Module Proxy для защиты от исчезновения библиотек

## Под капотом

Протокол GOPROXY исключительно прост: это обычный статический веб-сервер, раздающий файлы через HTTP GET. Внутри архива `.zip` лежит файловое дерево модуля с префиксом `<module>@<version>/`.

## Подводные камни

Использование `GOPROXY=direct` в production CI пайплайнах. Прямое скачивание из Git требует установленных утилит git/svn/hg, работает в 5-10 раз медленнее и ломается при падении GitHub.
