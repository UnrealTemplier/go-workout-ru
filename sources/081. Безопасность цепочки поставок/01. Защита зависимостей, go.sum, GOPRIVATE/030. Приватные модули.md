# Приватные модули: настройка GOPRIVATE, GONOPROXY и корпоративных репозиториев

## Условие

Настройте работу Go с закрытым корпоративным репозиторием (например, gitlab.corp.internal). Напишите инструкцию по настройке Git SSH/HTTPS аутентификации для go get.

### Исходная формулировка

**Приватные модули (GOPRIVATE)**: У тебя есть приватная библиотека на GitLab. По умолчанию `go get` попытается проверить её через публичный `sum.golang.org` и получит 404 (или сольет название твоей секретной либы в логи Google). Настрой `GOPRIVATE=gitlab.mycompany.com/*`, чтобы Go качал этот код напрямую (используя SSH/Git ключи), минуя публичные прокси и базы хэшей.

## Теория

По умолчанию `go get` пытается скачать модуль через HTTPS без авторизации. Для приватных репозиториев на GitLab/GitHub это вызывает ошибку `401 Unauthorized` или `404 Not Found`. Решение состоит из двух шагов: 1) Настройка `GOPRIVATE=gitlab.corp.internal/*`, чтобы Go не пытался искать приватный модуль на `proxy.golang.org`; 2) Настройка Git для автоматической замены протокола HTTPS на SSH: `git config --global url."git@gitlab.corp.internal:".insteadOf "https://gitlab.corp.internal/"`. После этого `go get` будет прозрачно использовать локальные SSH-ключи разработчика или токен `CI_JOB_TOKEN` в пайплайне.

## Решение по шагам

Сконфигурируйте переменную go env -w GOPRIVATE.
Настройте правило git insteadOf для перенаправления HTTPS в SSH.
Проверьте разрешение имени модуля через go get.
Обеспечьте безопасную авторизацию раннеров в CI/CD.

## Код решения

**`setup_private_gitlab.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

CORP_DOMAIN="gitlab.mycompany.internal"

echo "[1/2] Disabling public proxy and sumdb for corporate domain:"
go env -w GOPRIVATE="${CORP_DOMAIN}/*"

echo "[2/2] Configuring git to rewrite HTTPS to authenticated SSH:"
# Тулчейн Go всегда инициирует HTTPS, а git прозрачно заменит URL на SSH с ключами разработчика
git config --global url."git@${CORP_DOMAIN}:".insteadOf "https://${CORP_DOMAIN}/"

echo "Configuration completed. You can now run: go get ${CORP_DOMAIN}/security/auth-sdk"
```

ℹ️ Скрипт интеграции Go Modules с корпоративным приватным GitLab через SSH

## Под капотом

Когда тулчейн Go скачивает модуль напрямую (`GOPRIVATE`), он вызывает утилиту `git` под капотом. Правило `insteadOf` перехватывает системный вызов Git и меняет URL протокола.

## Подводные камни

Забыть добавить слеш на конце в URL `insteadOf`. Неправильный синтаксис `url."git@...".insteadOf` приведет к склеиванию путей и ошибке репозитория.
