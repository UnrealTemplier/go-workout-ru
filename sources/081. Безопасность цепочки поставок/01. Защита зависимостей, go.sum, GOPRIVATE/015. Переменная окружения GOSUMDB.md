# Переменная окружения GOSUMDB: sum.golang.org, GONOSUMDB и Private Modules

## Условие

Настройте переменные окружения GOSUMDB, GOPRIVATE и GONOSUMDB для безопасной сборки проектов, использующих как публичные модули, так и закрытые корпоративные библиотеки.

### Исходная формулировка

**GOSUMDB environment variable**: Настройте `GOSUMDB=sum.golang.org` (default) или отключите через `GOSUMDB=off` для private modules.

## Теория

По умолчанию `GOSUMDB=sum.golang.org`. При скачивании любого пакета Go отправляет хэш и имя модуля на сервер Google `sum.golang.org`. Но что произойдет, если проект использует приватный корпоративный репозиторий `gitlab.corp.mybank.ru/payments/core`? 1) Google вернет ошибку 404 (он не имеет доступа к вашей приватной сети); 2) Вы допустите утечку внутренней архитектуры и приватных названий модулей во внешнюю сеть! Для решения этой проблемы Go предоставляет переменные: `GOPRIVATE=gitlab.corp.mybank.ru/*` — автоматически отключает как прокси (GOPROXY), так и проверку контрольных сумм (GOSUMDB) для корпоративных доменов; `GONOSUMDB=gitlab.corp.mybank.ru/*` — гранулярно отключает только проверку Checksum DB.

## Решение по шагам

Изучите назначение GOPRIVATE, GOSUMDB, GONOSUMDB, GONOPROXY.
Сконфигурируйте локальный go env для работы с приватными репозиториями.
Проверьте маски доменов (wildcards).
Обеспечьте защиту от утечки корпоративных путей импорта в публичный интернет.

## Код решения

**`configure_private_modules.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

# Конфигурация для Enterprise разработки:
# 1. Задаем приватные домены (отключает proxy и sumdb для внутренних репозиториев)
go env -w GOPRIVATE="gitlab.mycorp.ru/*,github.com/mycorp-enterprise/*"

# 2. Публичные модули продолжают проверяться через официальный Transparency Log
go env -w GOSUMDB="sum.golang.org"

# 3. Публичные модули кэшируются через Google Proxy или корпоративный Nexus
go env -w GOPROXY="https://proxy.golang.org,direct"

echo "Current Go Modules Security Configuration:"
go env GOPRIVATE GOSUMDB GOPROXY GONOSUMDB
```

ℹ️ Безопасная настройка GOPRIVATE и GOSUMDB для корпоративных репозиториев

## Под капотом

Переменная `GOPRIVATE` является синтаксическим сахаром: она одновременно устанавливает значения по умолчанию для `GONOPROXY` и `GONOSUMDB`, минимизируя вероятность ошибки конфигурирования.

## Подводные камни

Установка `GOSUMDB=off` глобально на машине разработчика. Это полностью отключает проверку подлинности публичных модулей, делая систему уязвимой к атакам подмены тегов и отравления зависимостей.

## На собеседовании

Вопрос на собеседовании в Тинькофф: 'Что произойдет, если не настроить GOPRIVATE для закрытого корпоративного модуля?' Ответ: 'Команда `go get` попытается обратиться к публичному сервису Google sum.golang.org. Во-первых, сборка упадет с ошибкой 404. Во-вторых, внутренние приватные пути пакетов утекут в логи внешнего сервиса'.
