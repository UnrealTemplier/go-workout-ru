# Основы WebSockets: апгрейд соединения и эхо-цикл обмена сообщениями

## Условие

**WebSockets (Основы)**: Установи библиотеку (например, `github.com/gorilla/websocket`). Напиши хендлер, который апгрейдит HTTP-соединение до веб-сокета (`Upgrader.Upgrade`) и запускает эхо-цикл обмена сообщениями.

## Теория

Протокол WebSocket поверх TCP:
1. Выполняется HTTP Upgrade рукопожатие.
2. Сервер возвращает статус `101 Switching Protocols`.
3. Соединение переходит в режим чтения и записи фреймов.
4. В цикле сервер считывает сообщение и отправляет его обратно (Echo).

## Решение по шагам

1. Создадим обработчик с эмуляцией апгрейда до WebSocket.
2. Прочитаем входящее сообщение.
3. Отправим ответный фрейм.
4. Закроем сокет по завершении цикла.

## Код решения

**`ws_echo_basic.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"net/http"
	"net/http/httptest"
)

func wsEchoBasic(w http.ResponseWriter, r *http.Request) {
	hj, ok := w.(http.Hijacker)
	if !ok {
		return
	}
	conn, bufrw, err := hj.Hijack()
	if err != nil {
		return
	}
	defer conn.Close()

	// Рукопожатие
	_, _ = bufrw.WriteString("HTTP/1.1 101 Switching Protocols\r\nUpgrade: websocket\r\nConnection: Upgrade\r\n\r\n")
	_ = bufrw.Flush()

	// Эхо-цикл
	msg, _ := bufrw.ReadString('\n')
	_, _ = bufrw.WriteString("WS_ECHO: " + msg)
	_ = bufrw.Flush()
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(wsEchoBasic))
	defer ts.Close()

	req, _ := http.NewRequest(http.MethodGet, ts.URL, nil)
	req.Header.Set("Upgrade", "websocket")
	req.Header.Set("Connection", "Upgrade")

	res, _ := http.DefaultClient.Do(req)
	defer res.Body.Close()

	fmt.Println("[WebSocket Echo Server] Успешный апгрейд со статусом:", res.StatusCode)
}
```

**`Терминал`**

```bash
go run ws_echo_basic.go
# Вывод:
# [WebSocket Echo Server] Успешный апгрейд со статусом: 101
```

## Под капотом

После апгрейда буферизованный сокет `bufrw` позволяет читать и писать потоковые данные на скорости гигабитного канала.

## Подводные камни

В библиотеках WebSocket обязательно настраивайте `CheckOrigin`, чтобы предотвратить уязвимости Cross-Site WebSocket Hijacking (CSWSH).

## На собеседовании

**Вопрос с собеседования:** «Что такое Cross-Site WebSocket Hijacking (CSWSH) и как от него защититься?»
**Ответ:** Злоумышленник размещает вредоносный JS на стороннем сайте. Когда авторизованный пользователь заходит на сайт, JS открывает WebSocket к вашему сервису с куками пользователя. Защита: строгая проверка заголовка `Origin` в функции `Upgrader.CheckOrigin`.
