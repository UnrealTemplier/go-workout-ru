# Архитектура HTTP/2: встроенная поддержка в Go и Cleartext HTTP/2 (h2c)

## Условие

Изучите HTTP/2: убедитесь, что ваш HTTPS-сервер автоматически поддерживает HTTP/2. Попробуйте настроить Cleartext HTTP/2 (h2c) для внутренних сервисов без шифрования.

## Теория

Протокол HTTP/2 в Go:
1. В HTTPS серверах (`ListenAndServeTLS`) протокол HTTP/2 включен по умолчанию.
2. Протокол **h2c** (HTTP/2 Cleartext) — это HTTP/2 поверх обычного незашифрованного TCP без TLS. Он используется внутри закрытых кластеров Kubernetes между подами для снижения нагрузки на CPU.
Для поддержки h2c стандартный мультиплексор оборачивают через `golang.org/x/net/http2/h2c`.

## Решение по шагам

1. Создадим TLS-сервер и убедимся в согласовании `Proto == "HTTP/2.0"`.
2. Покажем концепцию настройки h2c для бессертификатных соединений.
3. Проверим версию протокола клиента.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func protocolCheckHandler(w http.ResponseWriter, r *http.Request) {
	fmt.Fprintf(w, "Использован протокол: %s", r.Proto)
}

func main() {
	// Стандартный TLS сервер автоматически включает HTTP/2!
	server := httptest.NewTLSServer(http.HandlerFunc(protocolCheckHandler))
	defer server.Close()

	client := server.Client()
	resp, err := client.Get(server.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	fmt.Printf("[Client Verification] Протокол ответа: %s\n", resp.Proto)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Client Verification] Протокол ответа: HTTP/2.0
```

## Под капотом

Во время TLS хэндшейка клиент и сервер обмениваются расширением ALPN со списком `["h2", "http/1.1"]`. Если обе стороны поддерживают `h2`, соединение сразу начинает передавать фреймы HTTP/2.

## Подводные камни

Браузеры (Chrome, Safari, Firefox) принципиально НЕ поддерживают h2c (Cleartext HTTP/2) и требуют обязательного TLS шифрования для работы по HTTP/2.

## На собеседовании

**Вопрос с собеседования:** «Зачем использовать Cleartext HTTP/2 (h2c) внутри Kubernetes кластера?»
**Ответ:** Межсервисный трафик внутри приватного периметра K8s не требует шифрования каждого вызова. H2c дает все преимущества HTTP/2 (мультиплексирование запросов по одному TCP сокету, бинарный фрейминг, сжатие HPACK), экономя до 20-30% тактов CPU на операциях шифрования/дешифрования TLS.
