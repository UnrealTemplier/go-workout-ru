# Низкоуровневый Hijacking TCP-соединения для внедрения кастомного бинарного протокола

## Условие

**Перехватчик соединения (Hijacking)**: *Сложное!* Используй интерфейс `http.Hijacker`, чтобы получить сырой `net.Conn` прямо из `http.ResponseWriter`. Напиши в него свой кастомный протокол, в обход HTTP. (Так "под капотом" работает апгрейд до WebSockets).

## Теория

Переход на уровень L4 сокетов из веб-хендлера:
Интерфейс `http.Hijacker` разрывает связь со стандартным HTTP-обработчиком:
`conn, bufrw, err := w.(http.Hijacker).Hijack()`
После этого разработчик получает полный контроль над чтением и записью байт в TCP-сокет.

## Решение по шагам

1. Проверим интерфейс `http.Hijacker`.
2. Заберем сырой `net.Conn`.
3. Отправим бинарный кастомный кадр (например, 4 байта длины + данные).
4. Закроем сокет вручную.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"net/http"
	"net/http/httptest"
)

func customRawProtocolHandler(w http.ResponseWriter, r *http.Request) {
	hj, ok := w.(http.Hijacker)
	if !ok {
		http.Error(w, "Hijacking unsupported", http.StatusInternalServerError)
		return
	}

	conn, bufrw, err := hj.Hijack()
	if err != nil {
		return
	}
	defer conn.Close()

	// Отправляем кастомный заголовок и бинарное сообщение
	_, _ = bufrw.WriteString("RAW_PROTOCOL_V1\n")
	_, _ = bufrw.WriteString("DATA: MAGIC_PACKET_9988\n")
	_ = bufrw.Flush()
}

func main() {
	server := httptest.NewServer(http.HandlerFunc(customRawProtocolHandler))
	defer server.Close()

	resp, _ := http.Get(server.URL)
	defer resp.Body.Close()

	scanner := bufio.NewScanner(resp.Body)
	for scanner.Scan() {
		fmt.Println("[Client Read]:", scanner.Text())
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Client Read]: RAW_PROTOCOL_V1
# [Client Read]: DATA: MAGIC_PACKET_9988
```

## Под капотом

После вызова `Hijack()` стандартный `http.Server` прекращает управлять дедлайнами сокета и больше не пытается парсить последующие HTTP-запросы в этом соединении.

## Подводные камни

Если забыть вызвать `defer conn.Close()`, файловый дескриптор сокета утечет в ОС навсегда (Socket leak).

## На собеседовании

**Вопрос с собеседования:** «Можно ли использовать http.Hijacker при работе по HTTP/2?»
**Ответ:** Нет. В HTTP/2 одно TCP-соединение мультиплексирует множество независимых запросов-стримов. Захват сокета одним хендлером разрушил бы передачу данных всех остальных параллельных клиентов на этом сокете. Поэтому `w.(http.Hijacker)` в HTTP/2 возвращает `false`.
