# Сложная фильтрация и сортировка коллекций в HTTP API через slices.SortFunc

## Условие

Напиши **HTTP API с sorting и filtering**: `GET /items?sort=price&order=desc&category=books&min_price=10`. Реализуй парсинг query-параметров, фильтрацию слайса, сортировку через `sort.Slice`.

## Теория

Реализация гибких параметров выборки:
- Фильтры: `category`, `min_price`.
- Сортировка: `sort` (price, name) и `order` (asc, desc).
В Go 1.21+ для высокопроизводительной сортировки используют функцию `slices.SortFunc` с лямбдой сравнения.

## Решение по шагам

1. Опишем структуру товара `Product { ID, Name, Category, Price }`.
2. Извлечем параметры фильтрации из query.
3. Отфильтруем срез товаров.
4. Отсортируем срез по цене в порядке убывания.
5. Вернем JSON.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"slices"
	"strconv"
)

type Product struct {
	ID       int     `json:"id"`
	Name     string  `json:"name"`
	Category string  `json:"category"`
	Price    float64 `json:"price"`
}

var catalog = []Product{
	{1, "Go в действии", "books", 35.50},
	{2, "Архитектура микросервисов", "books", 55.00},
	{3, "Кофемашина", "appliances", 250.00},
	{4, "Go на практике", "books", 15.00},
}

func filterHandler(w http.ResponseWriter, r *http.Request) {
	q := r.URL.Query()
	cat := q.Get("category")
	minPrice, _ := strconv.ParseFloat(q.Get("min_price"), 64)
	sortBy := q.Get("sort")
	order := q.Get("order")

	var result []Product
	for _, p := range catalog {
		if (cat == "" || p.Category == cat) && p.Price >= minPrice {
			result = append(result, p)
		}
	}

	if sortBy == "price" {
		slices.SortFunc(result, func(a, b Product) int {
			if order == "desc" {
				if a.Price < b.Price {
					return 1
				} else if a.Price > b.Price {
					return -1
				}
				return 0
			}
			if a.Price < b.Price {
				return -1
			} else if a.Price > b.Price {
				return 1
			}
			return 0
		})
	}

	w.Header().Set("Content-Type", "application/json")
	_ = json.NewEncoder(w).Encode(result)
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(filterHandler))
	defer ts.Close()

	resp, _ := http.Get(ts.URL + "?category=books&min_price=20&sort=price&order=desc")
	body, _ := io.ReadAll(resp.Body)
	resp.Body.Close()

	fmt.Println(string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [{"id":2,"name":"Архитектура микросервисов","category":"books","price":55},{"id":1,"name":"Go в действии","category":"books","price":35.5}]
```

## Под капотом

`slices.SortFunc` в Go 1.21 использует гибридный алгоритм pdqsort (Pattern-Defeating Quicksort), работающий за время \(O(N \log N)\) без выделения дополнительной памяти.

## Подводные камни

Никогда не выполняйте сложную сортировку и фильтрацию миллионов записей в памяти веб-сервера — переносите эти операции на уровень индексов SQL СУБД (`WHERE ... ORDER BY ...`).

## На собеседовании

**Вопрос с собеседования:** «Почему в Go 1.21 добавили пакет slices вместо использования sort.Slice?»
**Ответ:** `sort.Slice` использовал интерфейс `sort.Interface` и внутреннюю рефлексию `reflect.Swapper`, что приводило к аллокациям памяти и накладным расходам на вызовы функций. Дженерик-функция `slices.SortFunc` компилируется в прямой инлайненный код без аллокаций в 2-3 раза быстрее.
