# Content Negotiation: поддержка форматов JSON, XML и Text по заголовку Accept

## Условие

Напиши **HTTP API с Content Negotiation**: проверяй `Accept` заголовок. Если `application/json` — верни JSON, если `text/xml` — верни XML (`encoding/xml`), если `text/plain` — простой текст. Иначе `406 Not Acceptable`.

## Теория

Согласование контента (Content Negotiation, RFC 7231):
Клиент указывает предпочитаемый формат в заголовке `Accept`:
- `application/json` -> JSON
- `text/xml` / `application/xml` -> XML
- `text/plain` -> обычный текст
Если сервер не поддерживает ни один из запрошенных форматов, возвращается статус `406 Not Acceptable`.

## Решение по шагам

1. Опишем структуру `UserDTO` с тегами `json` и `xml`.
2. Проанализируем заголовок `r.Header.Get("Accept")`.
3. Сериализуем данные в запрошенный формат.
4. Проверим возврат ошибки 406 на неподдерживаемый формат.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"encoding/xml"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"strings"
)

type Profile struct {
	XMLName xml.Name `xml:"profile" json:"-"`
	ID      int      `xml:"id" json:"id"`
	Name    string   `xml:"name" json:"name"`
}

func contentNegotiationHandler(w http.ResponseWriter, r *http.Request) {
	accept := r.Header.Get("Accept")
	data := Profile{ID: 42, Name: "Алексей"}

	switch {
	case strings.Contains(accept, "application/json") || accept == "*/*" || accept == "":
		w.Header().Set("Content-Type", "application/json")
		_ = json.NewEncoder(w).Encode(data)
	case strings.Contains(accept, "text/xml") || strings.Contains(accept, "application/xml"):
		w.Header().Set("Content-Type", "text/xml; charset=utf-8")
		_ = xml.NewEncoder(w).Encode(data)
	case strings.Contains(accept, "text/plain"):
		w.Header().Set("Content-Type", "text/plain; charset=utf-8")
		fmt.Fprintf(w, "ID: %d, Name: %s", data.ID, data.Name)
	default:
		http.Error(w, "406 Not Acceptable: поддерживаются только JSON, XML, PlainText", http.StatusNotAcceptable)
	}
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(contentNegotiationHandler))
	defer ts.Close()

	// 1. Запрос JSON
	reqJSON, _ := http.NewRequest(http.MethodGet, ts.URL, nil)
	reqJSON.Header.Set("Accept", "application/json")
	res1, _ := http.DefaultClient.Do(reqJSON)
	b1, _ := io.ReadAll(res1.Body)
	res1.Body.Close()
	fmt.Printf("[JSON] %s", string(b1))

	// 2. Запрос XML
	reqXML, _ := http.NewRequest(http.MethodGet, ts.URL, nil)
	reqXML.Header.Set("Accept", "text/xml")
	res2, _ := http.DefaultClient.Do(reqXML)
	b2, _ := io.ReadAll(res2.Body)
	res2.Body.Close()
	fmt.Printf("[XML]  %s\n", string(b2))

	// 3. Неподдерживаемый формат (406)
	reqBad, _ := http.NewRequest(http.MethodGet, ts.URL, nil)
	reqBad.Header.Set("Accept", "image/png")
	res3, _ := http.DefaultClient.Do(reqBad)
	fmt.Printf("[406]  Status: %d\n", res3.StatusCode)
	res3.Body.Close()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [JSON] {"id":42,"name":"Алексей"}
# [XML]  <profile><id>42</id><name>Алексей</name></profile>
# [406]  Status: 406
```

## Под капотом

Заголовок `Accept` может содержать весовые коэффициенты предпочтения качества (Quality Values): `Accept: text/html, application/xhtml+xml, application/xml;q=0.9, */*;q=0.8`.

## Подводные камни

Многие клиенты по умолчанию шлют `Accept: */*`. Сервер обязан трактовать это как готовность принять JSON по умолчанию, а не возвращать 406.

## На собеседовании

**Вопрос с собеседования:** «Зачем нужна структура xml.Name в моделях Go?»
**Ответ:** Поле `XMLName xml.Name` определяет имя корневого XML-тега при сериализации (`<profile>`). Если поле отсутствует, `xml.Encoder` по умолчанию использует имя Go-структуры.
