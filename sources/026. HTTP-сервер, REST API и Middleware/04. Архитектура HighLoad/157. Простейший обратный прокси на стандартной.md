# Простейший обратный прокси на стандартной библиотеке с прозрачной трансляцией

## Условие

**Простейший HTTP Reverse-Proxy**: Напишите прокси-сервер на стандартной библиотеке. Сервер должен слушать порт `8080`, перехватывать все входящие запросы, пересылать их на какой-то другой работающий веб-сервер (например, `localhost:9090` или внешний API), получать оттуда ответы и полностью возвращать их клиенту (включая заголовки и статус-коды).

## Теория

Прозрачный реверс-прокси:
1. Принимает запрос на порту 8080.
2. Подменяет адрес назначения на порт 9090.
3. Пробрасывает статус ответа, тело и все заголовки бэкенда клиенту.

## Решение по шагам

1. Создадим целевой сервер (порт 9090).
2. Создадим прокси-сервер на стандартном `httputil.ReverseProxy`.
3. Отправим запрос на входной порт.
4. Проверим точное совпадение всех заголовков.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"net/http/httputil"
	"net/url"
)

func main() {
	// 1. Целевой веб-сервер (например, бэкенд на порту 9090)
	targetServer := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("X-Custom-Backend", "Microservice-Alpha")
		w.WriteHeader(http.StatusAccepted) // 202
		fmt.Fprint(w, "Прозрачный ответ целевого сервиса")
	}))
	defer targetServer.Close()

	targetURL, _ := url.Parse(targetServer.URL)

	// 2. Реверс-прокси (на порту 8080)
	proxy := httputil.NewSingleHostReverseProxy(targetURL)
	proxyServer := httptest.NewServer(proxy)
	defer proxyServer.Close()

	// 3. Клиент обращается к прокси
	resp, _ := http.Get(proxyServer.URL + "/api/v1/orders")
	body, _ := io.ReadAll(resp.Body)
	resp.Body.Close()

	fmt.Printf("[Статус ответа]:        %d\n", resp.StatusCode)
	fmt.Printf("[Заголовок бэкенда]:    %s\n", resp.Header.Get("X-Custom-Backend"))
	fmt.Printf("[Тело ответа]:          %s\n", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Статус ответа]:        202
# [Заголовок бэкенда]:    Microservice-Alpha
# [Тело ответа]:          Прозрачный ответ целевого сервиса
```

## Под капотом

`ReverseProxy` копирует поток ответа чанками по 32 КБ, поддерживая потоковую передачу данных без ожидания полной загрузки файла.

## Подводные камни

Если бэкенд возвращает заголовок `Location` при редиректе (301/302), он может содержать внутренний IP-адрес. В `ModifyResponse` такие заголовки необходимо переписывать на внешний домен прокси.

## На собеседовании

**Вопрос с собеседования:** «Что делает поле FlushInterval в структуре httputil.ReverseProxy?»
**Ответ:** `FlushInterval` задает периодичность принудительного сброса буфера клиенту при стриминге ответов от бэкенда (например, SSE). Отрицательное значение означает мгновенный сброс после каждого прочитанного чанка.
