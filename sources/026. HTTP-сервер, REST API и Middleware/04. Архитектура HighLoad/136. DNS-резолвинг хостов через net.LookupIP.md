# DNS-резолвинг хостов через net.LookupIP с обработкой сетевых ошибок

## Условие

Выполните DNS-запрос: программа принимает доменное имя, получает все A-записи и выводит IP-адреса. Обработайте ошибки.

## Теория

Пакет `net` предоставляет функции для DNS-резолвинга:
- `net.LookupIP(host)` — возвращает срез всех IPv4 и IPv6 адресов хоста.
- `net.LookupHost(host)` — возвращает срез строковых представлений IP.
Рантайм Go может использовать встроенный чистый Go-резолвер (Go DNS resolver) или системный cgo `getaddrinfo`.

## Решение по шагам

1. Создадим функцию резолвинга хоста.
2. Проверим успешное получение IP для `localhost`.
3. Обработаем ошибку несуществующего домена.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
)

func resolveDomain(domain string) {
	ips, err := net.LookupIP(domain)
	if err != nil {
		fmt.Printf("[DNS Error] Домен %s не найден: %v\n", domain, err)
		return
	}

	fmt.Printf("Домен %s разрешен в IP-адреса:\n", domain)
	for _, ip := range ips {
		fmt.Printf("  • %-15s (IPv4: %v)\n", ip.String(), ip.To4() != nil)
	}
}

func main() {
	resolveDomain("localhost")
	resolveDomain("non-existing-domain-xyz-99.invalid")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Домен localhost разрешен в IP-адреса:
#   • 127.0.0.1       (IPv4: true)
#   • ::1             (IPv4: false)
# [DNS Error] Домен non-existing-domain-xyz-99.invalid не найден: ...
```

## Под капотом

Go использует файл `/etc/resolv.conf` для получения адресов серверов имен (nameserver). Режим работы можно переключать флагом `GODEBUG=netdns=go` или `netdns=cgo`.

## Подводные камни

DNS-запросы по умолчанию могут зависать при сбоях в сети. Для продакшена всегда используйте `net.Resolver{}.LookupIP(ctx, "ip4", host)` с контекстом и таймаутом.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие чистого Go DNS-резолвера от cgo-резолвера?»
**Ответ:** Чистый Go-резолвер не блокирует системные OS-треды (M), а использует неблокирующий ввод-вывод через Netpoller. Cgo-резолвер вызывает системную функцию C `getaddrinfo()`, которая блокирует OS-тред, что при зависании DNS может исчерпать лимит потоков рантайма (10 000 тредов).
