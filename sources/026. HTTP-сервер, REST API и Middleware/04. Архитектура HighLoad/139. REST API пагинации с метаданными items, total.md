# REST API пагинации с метаданными items, total, page и total_pages

## Условие

Напиши **HTTP API с pagination**: `GET /items?page=1&limit=20`. Верни `{"items": [...], "total": 100, "page": 1, "pages": 5}`. Реализуй limit/offset в in-memory слайсе.

## Теория

Формат ответа пагинации:
```json
{
  "items": [...],
  "total": 100,
  "page": 1,
  "pages": 5
}
```
Хендлер аккуратно отсекает срез массива без выхода за пределы допустимого диапазона.

## Решение по шагам

1. Создадим срез из 100 тестовых записей.
2. Спарсим параметры `page` и `limit`.
3. Рассчитаем безопасные индексы среза `start` и `end`.
4. Вернем JSON-ответ с метаданными.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"strconv"
)

type PaginatedResult struct {
	Items []string `json:"items"`
	Total int      `json:"total"`
	Page  int      `json:"page"`
	Pages int      `json:"pages"`
}

func main() {
	var dataset []string
	for i := 1; i <= 100; i++ {
		dataset = append(dataset, fmt.Sprintf("Элемент #%d", i))
	}

	mux := http.NewServeMux()
	mux.HandleFunc("GET /items", func(w http.ResponseWriter, r *http.Request) {
		page, _ := strconv.Atoi(r.URL.Query().Get("page"))
		if page < 1 {
			page = 1
		}
		limit, _ := strconv.Atoi(r.URL.Query().Get("limit"))
		if limit < 1 || limit > 50 {
			limit = 20
		}

		total := len(dataset)
		pages := (total + limit - 1) / limit

		start := (page - 1) * limit
		if start > total {
			start = total
		}
		end := start + limit
		if end > total {
			end = total
		}

		res := PaginatedResult{
			Items: dataset[start:end],
			Total: total,
			Page:  page,
			Pages: pages,
		}

		w.Header().Set("Content-Type", "application/json")
		_ = json.NewEncoder(w).Encode(res)
	})

	ts := httptest.NewServer(mux)
	defer ts.Close()

	resp, _ := http.Get(ts.URL + "/items?page=2&limit=3")
	body, _ := io.ReadAll(resp.Body)
	resp.Body.Close()

	fmt.Println(string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"items":["Элемент #4","Элемент #5","Элемент #6"],"page":2,"pages":34,"total":100}
```

## Под капотом

Срез `dataset[start:end]` выполняется за \(O(1)\) без аллокаций новых строк в памяти.

## Подводные камни

Если пользователь запросит страницу `page=9999`, без проверки `start > total` возникнет паника `slice bounds out of range`.

## На собеседовании

**Вопрос с собеседования:** «Почему в BigTech ограничивают максимальный limit (например, limit <= 100)?»
**Ответ:** Без ограничения лимита недобросовестный клиент запросит `limit=1000000`. Сервер попытается выгрузить миллион строк из БД в память, что приведет к резкому скачку расхода RAM и падению процесса от Linux OOM Killer.
