# Роутинг Single Page Application (SPA): возврат index.html для несуществующих путей

## Условие

**Single Page Application (SPA)**: Напиши хендлер, который для всех неизвестных путей (включая `/login`, `/profile`, которых нет физически на диске, но они есть во Vue/React роутинге) отдает файл `index.html`.

## Теория

Маршрутизация одностраничных приложений (SPA Fallback):
Во Vue/React/Angular роутинг выполняется на стороне клиента через Browser History API (`/dashboard`, `/profile`). Когда пользователь обновляет страницу по F5, сервер должен отдать файл `index.html` (вместо ошибки 404), чтобы клиентский JavaScript загрузился и сам отрендерил нужную страницу.

## Решение по шагам

1. Создадим структуру SPA-хендлера с корневым файлом `index.html`.
2. Если файл существует на диске — отдаем файл.
3. Если файл не найден — отдаем `index.html`.
4. Проверим запросы к `/login` и `/profile`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"os"
	"path/filepath"
)

func SPAHandler(staticRoot string) http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		path := filepath.Join(staticRoot, r.URL.Path)

		// Проверяем, существует ли реальный файл на диске
		fi, err := os.Stat(path)
		if os.IsNotExist(err) || fi.IsDir() {
			// SPA Fallback: отдаем index.html для клиентского роутера
			http.ServeFile(w, r, filepath.Join(staticRoot, "index.html"))
			return
		}

		http.ServeFile(w, r, path)
	}
}

func main() {
	tmpDir, _ := os.MkdirTemp("", "spa_test_*")
	defer os.RemoveAll(tmpDir)

	_ = os.WriteFile(filepath.Join(tmpDir, "index.html"), []byte("<div id='app'>React App Loaded</div>"), 0644)

	ts := httptest.NewServer(SPAHandler(tmpDir))
	defer ts.Close()

	// Запрашиваем несуществующий в файловой системе путь /user/profile
	resp, _ := http.Get(ts.URL + "/user/profile")
	body, _ := io.ReadAll(resp.Body)
	resp.Body.Close()

	fmt.Printf("[SPA Response] Status: %d, Content: %s\n", resp.StatusCode, string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [SPA Response] Status: 200, Content: <div id='app'>React App Loaded</div>
```

## Под капотом

`http.ServeFile` автоматически выставляет заголовки `Content-Type: text/html` и валидирует путь, исключая Path Traversal.

## Подводные камни

Запросы к API (`/api/...`) не должны попадать под SPA Fallback: для них сервер обязан возвращать реальный 404 Not Found.

## На собеседовании

**Вопрос с собеседования:** «Как в Nginx настраивается SPA Fallback?»
**Ответ:** Директивой `try_files $uri $uri/ /index.html;`. Nginx сначала ищет реальный файл или папку, а если они отсутствуют, отдает `index.html`.
