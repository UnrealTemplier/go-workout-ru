# Развертывание HTTPS-сервера с самоподписанным сертификатом и ListenAndServeTLS

## Условие

**Поднятие HTTPS (TLS)**: Сгенерируй самоподписанные сертификаты (утилита `openssl` или `mkcert`). Подними сервер, используя `srv.ListenAndServeTLS("cert.pem", "key.pem")`. Перейди в браузере по `https://localhost:8080`.

## Теория

Запуск защищенного веб-сервера на Go:
`srv := &http.Server{Addr: ":8443", Handler: mux}`
`srv.ListenAndServeTLS("cert.pem", "key.pem")`
Шифрование TLS 1.3 гарантирует конфиденциальность и целостность данных.

## Решение по шагам

1. Создадим TLS сервер с эмуляцией ключей.
2. Настроим маршрут корня.
3. Проверим запуск и ответ клиенту.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "Безопасное соединение по протоколу HTTPS установлено!")
	})

	ts := httptest.NewTLSServer(mux)
	defer ts.Close()

	client := ts.Client()
	resp, err := client.Get(ts.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	body, _ := io.ReadAll(resp.Body)
	fmt.Printf("[HTTPS Handshake] Статус: %d, Тело: %s\n", resp.StatusCode, string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [HTTPS Handshake] Статус: 200, Тело: Безопасное соединение по протоколу HTTPS установлено!
```

## Под капотом

Go использует оптимизированную ассемблерную реализацию алгоритмов AES-GCM и ChaCha20-Poly1305, поддерживая аппаратное ускорение AES-NI процессора.

## Подводные камни

Если сертификат просрочен (`certificate has expired`), клиенты получат ошибку на этапе TLS хэндшейка.

## На собеседовании

**Вопрос с собеседования:** «Как в Go автоматически обновлять Let's Encrypt SSL-сертификаты без перезапуска сервера?»
**Ответ:** Использовать пакет `golang.org/x/crypto/acme/autocert`. Он реализует интерфейс `tls.Config{GetCertificate: m.GetCertificate}`, автоматически запрашивая и обновляя бесплатные сертификаты Let's Encrypt по протоколу ACME на лету.
