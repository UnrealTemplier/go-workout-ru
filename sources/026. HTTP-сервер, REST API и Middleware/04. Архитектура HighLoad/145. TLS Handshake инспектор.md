# TLS Handshake инспектор: проверка сертификата и извлечение Subject, Issuer и срока действия

## Условие

Напишите программу, которая подключается к серверу по TLS, проверяет сертификат и выводит его детали (subject, issuer, срок действия).

## Теория

Пакет `crypto/tls` метод `tls.Dial("tcp", addr, config)`:
Возвращает структуру `*tls.Conn`. Метод `conn.ConnectionState()` дает доступ к полной информации о сертификатах сервера:
- `PeerCertificates[0].Subject` — владелец.
- `PeerCertificates[0].Issuer` — удостоверяющий центр.
- `PeerCertificates[0].NotAfter` — срок экспирации.

## Решение по шагам

1. Поднимем локальный `httptest.NewTLSServer`.
2. Выполним `tls.Dial` к серверу.
3. Извлечем параметры сертификата.
4. Выведем данные на консоль.

## Код решения

**`main.go`**

```go
package main

import (
	"crypto/tls"
	"fmt"
	"net/http"
	"net/http/httptest"
	"strings"
)

func main() {
	server := httptest.NewTLSServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {}))
	defer server.Close()

	addr := strings.TrimPrefix(server.URL, "https://")

	conn, err := tls.Dial("tcp", addr, &tls.Config{InsecureSkipVerify: true})
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	state := conn.ConnectionState()
	cert := state.PeerCertificates[0]

	fmt.Println("Инспекция TLS сертификата сервера:")
	fmt.Printf("  • Владелец (Subject): %s\n", cert.Subject.CommonName)
	fmt.Printf("  • Издатель (Issuer):  %s\n", cert.Issuer.CommonName)
	fmt.Printf("  • Срок действия до:   %s\n", cert.NotAfter.Format("2006-01-02 15:04:05"))
	fmt.Printf("  • Версия TLS шифра:   0x%04x\n", state.CipherSuite)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Инспекция TLS сертификата сервера:
#   • Владелец (Subject): ...
#   • Издатель (Issuer):  ...
#   • Срок действия до:   ...
#   • Версия TLS шифра:   ...
```

## Под капотом

`conn.ConnectionState()` кэширует результаты завершенного TLS Handshake, позволяя анализировать параметры сессии без дополнительных сетевых вызовов.

## Подводные камни

Перед обращением к `PeerCertificates[0]` обязательно проверяйте длину среза `len(PeerCertificates) > 0` во избежание паники.

## На собеседовании

**Вопрос с собеседования:** «Как в Go написать алерт об истечении SSL-сертификатов на продакшене?»
**Ответ:** Раз в сутки подключаться через `tls.Dial` ко всем доменам компании и проверять `time.Until(cert.NotAfter) < 14*24*time.Hour`. Если до окончания срока осталось меньше 14 дней — слать алерт в Telegram/PagerDuty дежурному инженеру.
