# Prometheus Metrics Middleware со счетчиками запросов и эндпоинтом /metrics

## Условие

Напиши **Metrics middleware** (Prometheus-style): счётчики `requests_total`, `request_duration_seconds`. Используй `atomic` для счётчиков и `sync.Map` для хранилища. Endpoint `/metrics` возвращает текст в формате Prometheus.

## Теория

Формат метрик Prometheus (OpenMetrics):
Каждая метрика экспортируется в виде плоского текста:
`metric_name{label1="val1"} value timestamp`
Эндпоинт `/metrics` опрашивается скрапером Prometheus каждые 15 секунд.

## Решение по шагам

1. Создадим структуру счетчиков с `atomic.Uint64`.
2. Напишем middleware, инкрементирующее счетчик запросов.
3. Зарегистрируем маршрут `GET /metrics`.
4. Проверим скрапинг метрик клиентом.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"sync/atomic"
)

type PrometheusCollector struct {
	requestsTotal atomic.Uint64
}

func (pc *PrometheusCollector) Middleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if r.URL.Path != "/metrics" {
			pc.requestsTotal.Add(1)
		}
		next.ServeHTTP(w, r)
	})
}

func (pc *PrometheusCollector) MetricsHandler(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "text/plain; version=0.0.4")
	total := pc.requestsTotal.Load()

	fmt.Fprintf(w, "# HELP http_requests_total Total number of HTTP requests\n")
	fmt.Fprintf(w, "# TYPE http_requests_total counter\n")
	fmt.Fprintf(w, "http_requests_total{handler=\"api\"} %d\n", total)
}

func main() {
	collector := &PrometheusCollector{}
	mux := http.NewServeMux()

	mux.HandleFunc("/api/data", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "data")
	})
	mux.HandleFunc("/metrics", collector.MetricsHandler)

	server := httptest.NewServer(collector.Middleware(mux))
	defer server.Close()

	// Имитируем 3 запроса к API
	for i := 0; i < 3; i++ {
		res, _ := http.Get(server.URL + "/api/data")
		res.Body.Close()
	}

	// Скрапим /metrics
	metricRes, _ := http.Get(server.URL + "/metrics")
	body, _ := io.ReadAll(metricRes.Body)
	metricRes.Body.Close()

	fmt.Println(string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# # HELP http_requests_total Total number of HTTP requests
# # TYPE http_requests_total counter
# http_requests_total{handler="api"} 3
```

## Под капотом

Счетчики `atomic.Uint64` используют атомарные операции процессора, обеспечивая нулевые накладные расходы при миллионах запросов.

## Подводные камни

Никогда не используйте динамические параметры (например, User ID или UUID запроса) в качестве лейблов метрик Prometheus! Это вызовет взрыв кардинальности (High Cardinality) и уронит базу данных Prometheus (OOM).

## На собеседовании

**Вопрос с собеседования:** «Что такое кардинальность метрик (Cardinality) и как её контролировать?»
**Ответ:** Кардинальность — это число уникальных комбинаций лейблов временного ряда. Если добавить лейбл `user_id` при миллионе пользователей, Prometheus создаст миллион отдельных временных рядов в памяти. Для контроля лейблы ограничивают строго статическими значениями: `method`, `status_code`, `path_pattern`.
