# REST API в стандарте HATEOAS: гипермедиа-навигация и структура _links

## Условие

Напиши **HTTP API с HATEOAS** (упрощённый): в ответе на `GET /users/1` включи ссылки `{"_links": {"self": "/users/1", "orders": "/users/1/orders"}}`. Покажи концепцию гипермедиа.

## Теория

HATEOAS (Hypermedia As The Engine Of Application State) — высший уровень зрелости REST API (Richardson Maturity Model Level 3):
Вместе с данными ресурса сервер возвращает блок `_links` с относительными URL допустимых действий над этим ресурсом, избавляя клиент от необходимости «хардкодить» шаблоны URL.

## Решение по шагам

1. Опишем структуру `UserResource` со структурой `_links`.
2. Реализуем обработчик `GET /users/{id}`.
3. Вернем JSON с гипермедиа-ссылками.
4. Проверим структуру ответа.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

type Link struct {
	Href   string `json:"href"`
	Method string `json:"method"`
}

type UserHATEOAS struct {
	ID    int             `json:"id"`
	Name  string          `json:"name"`
	Email string          `json:"email"`
	Links map[string]Link `json:"_links"`
}

func userHateoasHandler(w http.ResponseWriter, r *http.Request) {
	id := r.PathValue("id")

	user := UserHATEOAS{
		ID:    1,
		Name:  "Михаил",
		Email: "m@company.ru",
		Links: map[string]Link{
			"self":   {Href: fmt.Sprintf("/users/%s", id), Method: "GET"},
			"orders": {Href: fmt.Sprintf("/users/%s/orders", id), Method: "GET"},
			"delete": {Href: fmt.Sprintf("/users/%s", id), Method: "DELETE"},
		},
	}

	w.Header().Set("Content-Type", "application/hal+json")
	_ = json.NewEncoder(w).Encode(user)
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /users/{id}", userHateoasHandler)

	ts := httptest.NewServer(mux)
	defer ts.Close()

	resp, _ := http.Get(ts.URL + "/users/1")
	body, _ := io.ReadAll(resp.Body)
	resp.Body.Close()

	fmt.Println(string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"id":1,"name":"Михаил","email":"m@company.ru","_links":{"delete":{"href":"/users/1","method":"DELETE"},"orders":{"href":"/users/1/orders","method":"GET"},"self":{"href":"/users/1","method":"GET"}}}
```

## Под капотом

MIME-тип `application/hal+json` (Hypertext Application Language) — общепринятый стандарт оформления HATEOAS гиперссылок.

## Подводные камни

HATEOAS увеличивает размер полезной нагрузки (payload) JSON. В мобильных сетях и HighLoad сервисах чаще используют плоские структуры без ссылок.

## На собеседовании

**Вопрос с собеседования:** «Каковы 4 уровня модели зрелости Ричардсона (Richardson Maturity Model)?»
**Ответ:** Уровень 0: The Swamp of POX (один эндпоинт POST, как в SOAP/XML-RPC). Уровень 1: Resources (индивидуальные URI ресурсов). Уровень 2: HTTP Verbs (использование GET/POST/PUT/DELETE и статус-кодов). Уровень 3: HATEOAS (гипермедиа-навигация через ссылки).
