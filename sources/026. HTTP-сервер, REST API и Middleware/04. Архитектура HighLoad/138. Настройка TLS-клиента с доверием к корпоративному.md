# Настройка TLS-клиента с доверием к корпоративному RootCA без уязвимостей

## Условие

Настройте HTTP-клиент так, чтобы он доверял вашему самоподписанному сертификату (добавив его в кастомный `tls.Config` с `RootCAs` и `InsecureSkipVerify: false`).

## Теория

Безопасная конфигурация HTTP-клиента в микросервисах:
Сертификат сервера добавляется в пул `RootCAs`, а `InsecureSkipVerify` остается `false`. Это гарантирует, что клиент подключается исключительно к авторизованному корпоративному серверу.

## Решение по шагам

1. Запустим локальный TLS-сервер.
2. Создадим `x509.NewCertPool()`.
3. Добавим сертификат сервера.
4. Выполним защищенный запрос.

## Код решения

**`main.go`**

```go
package main

import (
	"crypto/tls"
	"crypto/x509"
	"fmt"
	"net/http"
	"net/http/httptest"
)

func main() {
	server := httptest.NewTLSServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "Secure Response")
	}))
	defer server.Close()

	// Настройка доверия
	pool := x509.NewCertPool()
	pool.AddCert(server.Certificate())

	client := &http.Client{
		Transport: &http.Transport{
			TLSClientConfig: &tls.Config{
				RootCAs:            pool,
				InsecureSkipVerify: false, // Строгая верификация!
			},
		},
	}

	res, err := client.Get(server.URL)
	if err != nil {
		panic(err)
	}
	defer res.Body.Close()

	fmt.Printf("[Verified Connection] Status: %d\n", res.StatusCode)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Verified Connection] Status: 200
```

## Под капотом

Пул `x509.CertPool` хранит хэш-таблицу сертификатов, быстро проверяя соответствие по полю `AuthorityKeyId`.

## Подводные камни

Если сертификат сервера изменится (ротация ключей), клиент со старым пулом вернет ошибку проверки подписи. Для динамического обновления используют кастомный `GetClientCertificate`.

## На собеседовании

**Вопрос с собеседования:** «Как обновить Root CA сертификат в работающем Go-приложении без перезапуска?»
**Ответ:** Использовать поле `tls.Config{GetConfigForClient: ...}` на сервере или атомарно подменять указатель `*tls.Config` в кастомном `http.RoundTripper` через `atomic.Pointer[tls.Config]` на клиенте при изменении файла на диске (fsnotify).
