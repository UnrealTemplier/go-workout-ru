# Парсинг JSON-тела с обработкой ошибок десериализации и статусом 400

## Условие

**Парсинг JSON-тела**: Напиши роут `POST /users`. Внутри используй `json.NewDecoder(r.Body).Decode(&user)`. Верни клиенту статус 400 (`http.Error`), если JSON оказался невалидным.

## Теория

Прием JSON-запросов требует обязательной проверки возвращаемой ошибки `err := json.NewDecoder(r.Body).Decode(&dst)`. Возможные типы ошибок:
- `*json.SyntaxError` — синтаксическая ошибка в JSON.
- `io.EOF` — пустое тело запроса.
- `*json.UnmarshalTypeError` — несоответствие типов (например, строка вместо числа).

## Решение по шагам

1. Создадим обработчик `POST /users`.
2. Ограничим размер входного потока `http.MaxBytesReader`.
3. Распарсим тело в структуру `User`.
4. Вернем 400 Bad Request при любой ошибке.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

type UserPayload struct {
	Name  string `json:"name"`
	Score int    `json:"score"`
}

func createUser(w http.ResponseWriter, r *http.Request) {
	defer r.Body.Close()

	var u UserPayload
	if err := json.NewDecoder(r.Body).Decode(&u); err != nil {
		http.Error(w, fmt.Sprintf("Невалидный JSON: %v", err), http.StatusBadRequest)
		return
	}

	w.WriteHeader(http.StatusCreated)
	fmt.Fprintf(w, "Пользователь %s зарегистрирован со счетом %d", u.Name, u.Score)
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("POST /users", createUser)

	ts := httptest.NewServer(mux)
	defer ts.Close()

	// Отправляем поврежденный JSON
	invalidJSON := `{"name": "test", score: "not-a-number"}`
	res, _ := http.Post(ts.URL+"/users", "application/json", bytes.NewBufferString(invalidJSON))
	body, _ := io.ReadAll(res.Body)
	res.Body.Close()

	fmt.Printf("[Status] %d\n", res.StatusCode)
	fmt.Printf("[Error]  %s", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Status] 400
# [Error]  Невалидный JSON: invalid character 's' looking for beginning of object key string
```

## Под капотом

`json.NewDecoder` читает входной поток побайтово через лексер без предварительной вычитки всего содержимого в память.

## Подводные камни

Если в теле запроса передано два валидных JSON подряд (`{"a":1}{"b":2}`), одиночный `Decode` прочитает только первый и завершится без ошибки, проигнорировав «хвост».

## На собеседовании

**Вопрос с собеседования:** «Как проверить, что в теле запроса содержится ровно один JSON-объект без лишнего мусора в конце?»
**Ответ:** После первого вызова `dec.Decode(&dst)` вызвать `dec.Decode(&struct{}{})` и убедиться, что второй вызов возвращает строго ошибку `io.EOF`.
