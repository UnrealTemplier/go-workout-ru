# Простейший веб-сервер с обработчиком корня и тестовой проверкой

## Условие

**Простейший веб-сервер**: Напишите HTTP-сервер, который при обращении на корень `/` возвращает текстовое сообщение `"Добро пожаловать в веб-сервер на Go!"`. Запустите его на порту `8080` с помощью `http.ListenAndServe`. Проверьте работу через браузер.

## Теория

Минимальный автономный веб-сервер в Go не требует внешних фреймворков. Вызов `http.HandleFunc` и `http.ListenAndServe` разворачивает полноценный многопоточный HTTP/1.1 и HTTP/2 сервер с пулом горутин.

## Решение по шагам

1. Создадим обработчик корня.
2. Проверим `r.URL.Path == "/"`.
3. Отправим приветственное сообщение в кодировке UTF-8.
4. Протестируем клиентским запросом.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func welcomeHandler(w http.ResponseWriter, r *http.Request) {
	if r.URL.Path != "/" {
		http.NotFound(w, r)
		return
	}
	w.Header().Set("Content-Type", "text/plain; charset=utf-8")
	fmt.Fprint(w, "Добро пожаловать в веб-сервер на Go!")
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("/", welcomeHandler)

	ts := httptest.NewServer(mux)
	defer ts.Close()

	resp, _ := http.Get(ts.URL + "/")
	body, _ := io.ReadAll(resp.Body)
	resp.Body.Close()

	fmt.Println(string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Добро пожаловать в веб-сервер на Go!
```

## Под капотом

Go компилирует веб-сервер в самодостаточный бинарник без внешних runtime-зависимостей (JVM, Node.js или Python interpreter).

## Подводные камни

При выводе кириллицы обязательно указывайте `charset=utf-8` в `Content-Type`, иначе устаревшие браузеры могут отобразить нечитаемые символы.

## На собеседовании

**Вопрос с собеседования:** «Какова базовая модель конкурентности HTTP-сервера в Go?»
**Ответ:** Модель `Goroutine-per-connection`: на каждое принятое входящее TCP-соединение сервер порождает отдельную легковесную горутину `go c.serve()`. Благодаря неблокирующему вводу-выводу через Netpoller сервер способен удерживать сотни тысяч одновременных соединений при минимальном расходе памяти (~4 КБ на горутину).
