# Перехват системного сигнала os.Interrupt для Graceful Shutdown HTTP-сервера

## Условие

**Graceful Shutdown**: Напишите сервер, который перехватывает сигнал ОС (`os.Interrupt`), перестает принимать новые подключения (`server.Shutdown(ctx)`) и ждет завершения текущих активных запросов.

## Теория

При получении `os.Interrupt` (SIGINT / Ctrl+C) или `syscall.SIGTERM` сервер не должен немедленно завершаться через `os.Exit(0)`. Необходимо вызвать `server.Shutdown(ctx)` с таймаутом, чтобы все текущие запросы успели завершиться.

## Решение по шагам

1. Создадим канал сигналов `sigChan := make(chan os.Signal, 1)`.
2. Подпишемся на `signal.Notify(sigChan, os.Interrupt)`.
3. Запустим сервер в фоновой горутине.
4. При сигнале вызовем `srv.Shutdown(ctx)`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"net/http"
	"os"
	"time"
)

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("/work", func(w http.ResponseWriter, r *http.Request) {
		time.Sleep(30 * time.Millisecond)
		fmt.Fprint(w, "Готово")
	})

	srv := &http.Server{
		Addr:    "127.0.0.1:9011",
		Handler: mux,
	}

	go func() {
		_ = srv.ListenAndServe()
	}()

	// Канал для сигналов
	stop := make(chan os.Signal, 1)
	// Имитируем отправку прерывания через 40 мс
	go func() {
		time.Sleep(40 * time.Millisecond)
		stop <- os.Interrupt
	}()

	<-stop
	fmt.Println("[Shutdown] Получен сигнал остановки, останавливаем прием новых запросов...")

	ctx, cancel := context.WithTimeout(context.Background(), 2*time.Second)
	defer cancel()

	if err := srv.Shutdown(ctx); err != nil {
		fmt.Printf("Ошибка остановки: %v\n", err)
	} else {
		fmt.Println("[Shutdown] Сервер плавно остановлен!")
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Shutdown] Получен сигнал остановки, останавливаем прием новых запросов...
# [Shutdown] Сервер плавно остановлен!
```

## Под капотом

Канал сигналов `make(chan os.Signal, 1)` обязан иметь размер буфера не менее 1, чтобы не потерять сигнал, если горутина не успела встать на чтение.

## Подводные камни

Никогда не используйте небуферизированный канал `make(chan os.Signal)` для сигналов операционной системы.

## На собеседовании

**Вопрос с собеседования:** «Что произойдет, если в Shutdown истечет контекст с таймаутом?»
**Ответ:** `srv.Shutdown` вернет ошибку `context.DeadlineExceeded` и принудительно закроет все оставшиеся зависшие TCP-соединения, позволив процессу корректно завершиться.
