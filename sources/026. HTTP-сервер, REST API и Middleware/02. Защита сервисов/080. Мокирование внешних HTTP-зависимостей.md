# Мокирование внешних HTTP-зависимостей через кастомный RoundTripper

## Условие

Создайте мок для внешней зависимости (например, стороннего API), подменяя `http.Client.Transport` на кастомный `RoundTripper`, который возвращает заранее заготовленные ответы.

## Теория

Интерфейс `http.RoundTripper`:
```go
type RoundTripper interface {
    RoundTrip(*Request) (*Response, error)
}
```
Подменяя `client.Transport` в тестах, можно полностью перехватить исходящие HTTP-запросы и вернуть синтетический `*http.Response` без реальных сетевых вызовов.

## Решение по шагам

1. Создадим тип-адаптер `RoundTripFunc`.
2. Подменим `client.Transport` мок-транспортом.
3. Вернем сгенерированный `http.Response` с JSON.
4. Проверим чтение ответа клиентом.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"net/http"
)

type MockTransport func(req *http.Request) (*http.Response, error)

func (m MockTransport) RoundTrip(req *http.Request) (*http.Response, error) {
	return m(req)
}

func main() {
	// Подменяем сетевой транспорт мок-функцией
	mockClient := &http.Client{
		Transport: MockTransport(func(req *http.Request) (*http.Response, error) {
			fmt.Printf("[Mock Interceptor] Перехвачен запрос к: %s\n", req.URL.String())

			mockJSON := `{"payment_status": "APPROVED", "transaction_id": "tx_8899"}`
			resp := &http.Response{
				StatusCode: http.StatusOK,
				Status:     "200 OK",
				Body:       io.NopCloser(bytes.NewBufferString(mockJSON)),
				Header:     make(http.Header),
				Request:    req,
			}
			resp.Header.Set("Content-Type", "application/json")
			return resp, nil
		}),
	}

	// Клиент делает запрос на внешний недоступный домен
	resp, err := mockClient.Get("https://api.payment-gateway.com/charge")
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	body, _ := io.ReadAll(resp.Body)
	fmt.Printf("[Client Received]: %s\n", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Mock Interceptor] Перехвачен запрос к: https://api.payment-gateway.com/charge
# [Client Received]: {"payment_status": "APPROVED", "transaction_id": "tx_8899"}
```

## Под капотом

`io.NopCloser` оборачивает `*bytes.Buffer` в интерфейс `io.ReadCloser` с пустым методом `Close()`, идеально подходя для создания синтетических `resp.Body`.

## Подводные камни

В возвращаемом `http.Response` поле `Request` обязательно должно указывать на исходный `req`, иначе сторонние парсеры могут запаниковать.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество мокирования через RoundTripper по сравнению с httptest.NewServer?»
**Ответ:** Мокирование через `RoundTripper` выполняется полностью в памяти (In-Memory) без выделения портов TCP и сетевых сокетов, работает мгновенно и не требует перенастройки базовых URL клиентов.
