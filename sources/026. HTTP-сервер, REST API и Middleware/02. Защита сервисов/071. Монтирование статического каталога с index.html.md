# Монтирование статического каталога с index.html через http.FileServer

## Условие

**Раздача статики**: Создай папку `static` с файлом `index.html`. Используй `http.FileServer(http.Dir("static"))`, чтобы твой сервер отдавал файлы прямо в браузер.

## Теория

Если клиент запрашивает корень директории (`/`), `http.FileServer` автоматически проверяет наличие файла `index.html` и отдает его содержимое со статусом `200 OK`.

## Решение по шагам

1. Создадим временную папку `static` с файлом `index.html`.
2. Запустим `http.FileServer(http.Dir(dir))`.
3. Выполним GET-запрос к корню `/`.
4. Проверим получение HTML-страницы.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"os"
	"path/filepath"
)

func main() {
	staticDir, _ := os.MkdirTemp("", "web_static_*")
	defer os.RemoveAll(staticDir)

	htmlContent := "<html><body><h1>Go Web App</h1></body></html>"
	_ = os.WriteFile(filepath.Join(staticDir, "index.html"), []byte(htmlContent), 0644)

	fs := http.FileServer(http.Dir(staticDir))
	ts := httptest.NewServer(fs)
	defer ts.Close()

	resp, _ := http.Get(ts.URL + "/")
	body, _ := io.ReadAll(resp.Body)
	resp.Body.Close()

	fmt.Printf("[Status]       %d\n", resp.StatusCode)
	fmt.Printf("[Content-Type] %s\n", resp.Header.Get("Content-Type"))
	fmt.Printf("[HTML]         %s\n", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Status]       200
# [Content-Type] text/html; charset=utf-8
# [HTML]         <html><body><h1>Go Web App</h1></body></html>
```

## Под капотом

`FileServer` определяет тип контента по расширению `.html` через таблицу соответствий в стандартном пакете `mime`.

## Подводные камни

Если `index.html` отсутствует, `FileServer` сгенерирует HTML-листинг файлов каталога, что может раскрыть конфиденциальные файлы.

## На собеседовании

**Вопрос с собеседования:** «Как запретить листинг директорий в стандартном http.FileServer?»
**Ответ:** Реализовать собственную обертку над `http.FileSystem`: переопределить метод `Open(name string)` и, если `file.Stat().IsDir()`, проверять наличие `index.html`. Если его нет — возвращать ошибку `os.ErrNotExist` (404 Not Found).
