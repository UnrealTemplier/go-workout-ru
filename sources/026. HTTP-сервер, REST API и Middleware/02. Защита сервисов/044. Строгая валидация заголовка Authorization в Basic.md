# Строгая валидация заголовка Authorization в Basic Auth Middleware

## Условие

Реализуйте middleware для базовой HTTP-аутентификации (Basic Auth), проверяя заголовок `Authorization`.

## Теория

Прямой разбор заголовка `Authorization: Basic <credentials>`:
1. Заголовок должен начинаться со слова `Basic `.
2. Подстрока после префикса декодируется из Base64.
3. Полученная строка разделяется на `username` и `password` по первому двоеточию `:`.
4. Сравнение выполняется в константное время.

## Решение по шагам

1. Напишем ручной парсинг заголовка `Authorization`.
2. Декодируем base64 через `base64.StdEncoding.DecodeString`.
3. Разделим через `strings.Cut(credentials, ":")`.
4. Проверим работу обработчика.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/base64"
	"fmt"
	"net/http"
	"net/http/httptest"
	"strings"
)

func ManualBasicAuth(expectedUser, expectedPass string, next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		auth := r.Header.Get("Authorization")
		if !strings.HasPrefix(auth, "Basic ") {
			w.Header().Set("WWW-Authenticate", `Basic realm="Protected Area"`)
			http.Error(w, "Требуется авторизация", http.StatusUnauthorized)
			return
		}

		payload, err := base64.StdEncoding.DecodeString(strings.TrimPrefix(auth, "Basic "))
		if err != nil {
			http.Error(w, "Некорректный base64", http.StatusBadRequest)
			return
		}

		user, pass, found := strings.Cut(string(payload), ":")
		if !found || user != expectedUser || pass != expectedPass {
			http.Error(w, "Доступ запрещен", http.StatusUnauthorized)
			return
		}

		next.ServeHTTP(w, r)
	})
}

func main() {
	handler := ManualBasicAuth("devops", "k8s-secret", http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "Доступ разрешен!")
	}))

	ts := httptest.NewServer(handler)
	defer ts.Close()

	req, _ := http.NewRequest(http.MethodGet, ts.URL, nil)
	rawCreds := base64.StdEncoding.EncodeToString([]byte("devops:k8s-secret"))
	req.Header.Set("Authorization", "Basic "+rawCreds)

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	fmt.Printf("Код ответа: %d\n", resp.StatusCode)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Код ответа: 200
```

## Под капотом

Функция `strings.Cut` в Go 1.18+ выполняет поиск первого вхождения разделителя без дополнительных аллокаций памяти под срез строк, в отличие от `strings.Split`.

## Подводные камни

Пароль пользователя может сам содержать символ `:`, поэтому разбивать строку нужно строго по первому разделителю (как делает `strings.Cut`), а не по всем.

## На собеседовании

**Вопрос с собеседования:** «Почему strings.Cut эффективнее strings.SplitN при разборе заголовков HTTP?»
**Ответ:** `strings.SplitN` аллоцирует в куче срез `[]string` из двух элементов. `strings.Cut` возвращает три значения на стеке (`before, after string, found bool`), не совершая ни единой аллокации памяти.
