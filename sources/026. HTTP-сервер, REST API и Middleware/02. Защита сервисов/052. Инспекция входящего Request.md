# Инспекция входящего Request: метод, путь, User-Agent и сетевые свойства

## Условие

**Чтение Request**: Выведи в консоль информацию о входящем запросе: `r.Method`, `r.URL.Path`, `r.UserAgent()`.

## Теория

Структура `http.Request` инкапсулирует полное состояние входящего HTTP-сообщения: метод запроса, путь, заголовки, параметры сокета, контекст и тело сообщения.

## Решение по шагам

1. Создадим обработчик `inspectHandler`.
2. Извлечем и распечатаем основные свойства запроса.
3. Отправим запрос с кастомным `User-Agent`.
4. Проверим вывод.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func inspectHandler(w http.ResponseWriter, r *http.Request) {
	fmt.Printf("[Request Info]\n")
	fmt.Printf("  • Метод:      %s\n", r.Method)
	fmt.Printf("  • Путь URL:   %s\n", r.URL.Path)
	fmt.Printf("  • User-Agent: %s\n", r.UserAgent())
	fmt.Printf("  • Протокол:   %s\n", r.Proto)
	fmt.Printf("  • Хост:       %s\n", r.Host)
	fmt.Fprint(w, "OK")
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(inspectHandler))
	defer ts.Close()

	req, _ := http.NewRequest(http.MethodGet, ts.URL+"/api/v1/metrics", nil)
	req.Header.Set("User-Agent", "PrometheusScraper/2.45")

	res, _ := http.DefaultClient.Do(req)
	res.Body.Close()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Request Info]
#   • Метод:      GET
#   • Путь URL:   /api/v1/metrics
#   • User-Agent: PrometheusScraper/2.45
#   • Протокол:   HTTP/1.1
#   • Хост:       127.0.0.1:...
```

## Под капотом

Метод `r.UserAgent()` — это удобный аксессор к `r.Header.Get("User-Agent")`.

## Подводные камни

Поле `r.URL.Host` на стороне сервера часто бывает пустым! Вместо него для определения запрошенного хоста всегда используйте поле `r.Host`.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между r.Host и r.URL.Host на стороне HTTP-сервера в Go?»
**Ответ:** По спецификации HTTP/1.1 клиент шлет заголовок `Host: example.com`, а в строке запроса передает относительный путь `GET /index.html`. Сервер Go помещает значение заголовка в `r.Host`. Поле `r.URL.Host` заполняется только в прокси-запросах или на стороне HTTP-клиента.
