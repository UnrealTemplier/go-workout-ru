# Реализация собственного ServeMux на чистой мапе с обработкой 404

## Условие

Напиши **custom ServeMux**: реализуй `http.Handler` с `map[string]http.Handler` и методом `Handle(pattern string, handler http.Handler)`. Обработай `404` для неизвестных путей. Покажи, что `http.ServeMux` — это тоже просто `http.Handler`.

## Теория

Любой маршрутизатор в Go — это обычная структура, реализующая интерфейс `http.Handler`. Внутри метода `ServeHTTP(w, r)` роутер анализирует `r.URL.Path` и делегирует выполнение найденному дочернему обработчику.

## Решение по шагам

1. Создадим структуру `CustomRouter` с мапой `routes map[string]http.Handler`.
2. Реализуем метод `Handle(pattern, handler)`.
3. В `ServeHTTP` найдем хендлер по точному совпадению или отдадим 404.
4. Проверим работу кастомного роутера.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"sync"
)

type CustomRouter struct {
	mu     sync.RWMutex
	routes map[string]http.Handler
}

func NewCustomRouter() *CustomRouter {
	return &CustomRouter{routes: make(map[string]http.Handler)}
}

func (cr *CustomRouter) Handle(path string, h http.Handler) {
	cr.mu.Lock()
	defer cr.mu.Unlock()
	cr.routes[path] = h
}

func (cr *CustomRouter) ServeHTTP(w http.ResponseWriter, r *http.Request) {
	cr.mu.RLock()
	handler, exists := cr.routes[r.URL.Path]
	cr.mu.RUnlock()

	if exists {
		handler.ServeHTTP(w, r)
		return
	}
	http.NotFound(w, r)
}

func main() {
	router := NewCustomRouter()
	router.Handle("/ping", http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "custom pong")
	}))

	ts := httptest.NewServer(router)
	defer ts.Close()

	res1, _ := http.Get(ts.URL + "/ping")
	res1.Body.Close()
	fmt.Println("Route /ping status:", res1.StatusCode)

	res2, _ := http.Get(ts.URL + "/missing")
	res2.Body.Close()
	fmt.Println("Route /missing status:", res2.StatusCode)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Route /ping status: 200
# Route /missing status: 404
```

## Под капотом

Стандартный `http.ServeMux` устроен аналогично, но вместо плоской мапы использует дерево префиксов для поддержки поддеревьев маршрутов (`/static/`) и параметров Go 1.22.

## Подводные камни

Мапа без мьютекса при динамической регистрации роутов во время работы сервера вызовет панику из-за конкурентного доступа.

## На собеседовании

**Вопрос с собеседования:** «Какую структуру данных используют высокопроизводительные HTTP-роутеры вроде Chi, Gin или Echo?»
**Ответ:** Radix Tree (сжатое префиксное дерево / Patricia Trie). Оно обеспечивает поиск маршрута за время \(O(k)\), где \(k\) — длина строки URL, эффективно поддерживает path-переменные (`/users/:id`) и wildcard-маршруты (`/*filepath`) с нулевыми аллокациями памяти на запрос.
