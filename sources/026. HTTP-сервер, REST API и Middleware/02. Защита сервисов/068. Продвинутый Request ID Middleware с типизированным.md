# Продвинутый Request ID Middleware с типизированным контекстным ключом

## Условие

**[Высокая сложность]**: Напиши middleware, который добавляет ID запроса (Request ID) в контекст запроса (`r.WithContext`), чтобы его можно было извлечь в логгере позже.

## Теория

Для исключения коллизий контекстных ключей в Go объявляют специальный неэкспортируемый тип:
```go
type contextKey struct{}
var reqIDKey = contextKey{}
```
Middleware генерирует ID, обогащает контекст и пробрасывает обновленный `*http.Request` дальше.

## Решение по шагам

1. Объявим приватный тип ключа.
2. Создадим функции `ContextWithRequestID` и `RequestIDFromContext`.
3. Реализуем `RequestIDMiddleware`.
4. Проверим извлечение ID внутри хендлера.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"crypto/rand"
	"encoding/hex"
	"fmt"
	"net/http"
	"net/http/httptest"
)

type reqKeyType struct{}

var reqKey = reqKeyType{}

func ContextWithRequestID(ctx context.Context, id string) context.Context {
	return context.WithValue(ctx, reqKey, id)
}

func RequestIDFromContext(ctx context.Context) string {
	if id, ok := ctx.Value(reqKey).(string); ok {
		return id
	}
	return ""
}

func RequestIDMiddleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		buf := make([]byte, 6)
		_, _ = rand.Read(buf)
		reqID := hex.EncodeToString(buf)

		w.Header().Set("X-Request-ID", reqID)
		ctx := ContextWithRequestID(r.Context(), reqID)
		next.ServeHTTP(w, r.WithContext(ctx))
	})
}

func handler(w http.ResponseWriter, r *http.Request) {
	id := RequestIDFromContext(r.Context())
	fmt.Printf("[Business Service] Обработка транзакции с CorrelationID: %s\n", id)
	fmt.Fprint(w, "DONE")
}

func main() {
	ts := httptest.NewServer(RequestIDMiddleware(http.HandlerFunc(handler)))
	defer ts.Close()

	resp, _ := http.Get(ts.URL)
	resp.Body.Close()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Business Service] Обработка транзакции с CorrelationID: ...
```

## Под капотом

`context.WithValue` создает узел связного списка контекстов `valueCtx`. Поиск значения выполняется вверх по дереву контекстов за \(O(D)\), где \(D\) — глубина вложенности.

## Подводные камни

Не помещайте слишком много значений в `context.WithValue`: поиск по длинной цепочке замедляет работу. Для группы параметров лучше использовать единую структуру.

## На собеседовании

**Вопрос с собеседования:** «Каковы лучшие практики хранения данных в context.Context?»
**Ответ:** В контексте хранят данные с областью видимости запроса (Request-scoped): ID трассировки, данные аутентифицированного пользователя, дедлайны отмены. Нельзя хранить необязательные параметры бизнес-логики или зависимости сервисов (БД, клиенты).
