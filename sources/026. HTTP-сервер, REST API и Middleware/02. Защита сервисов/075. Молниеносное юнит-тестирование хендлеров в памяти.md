# Молниеносное юнит-тестирование хендлеров в памяти через httptest.NewRecorder

## Условие

Используйте `httptest.NewRecorder()` для тестирования HTTP-хендлеров "в памяти" без реального запуска сети, сокетов и портов.

## Теория

`httptest.ResponseRecorder` реализует интерфейс `http.ResponseWriter`, перехватывая статус-код, заголовки и тело в буфер памяти. В связке с `httptest.NewRequest` это позволяет запускать тысячи тестов хендлеров за доли секунды.

## Решение по шагам

1. Создадим целевую функцию-хендлер.
2. Создадим фиктивный запрос `req := httptest.NewRequest(...)`.
3. Создадим рекордер `rec := httptest.NewRecorder()`.
4. Вызовем метод `handler(rec, req)` и проверим `rec.Code` и `rec.Body`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func Greeter(w http.ResponseWriter, r *http.Request) {
	user := r.URL.Query().Get("user")
	if user == "" {
		http.Error(w, "missing user parameter", http.StatusBadRequest)
		return
	}
	w.WriteHeader(http.StatusOK)
	fmt.Fprintf(w, "Hello, %s!", user)
}

func main() {
	// 1. Тест успешного сценария
	req1 := httptest.NewRequest(http.MethodGet, "/greet?user=Gopher", nil)
	rec1 := httptest.NewRecorder()

	Greeter(rec1, req1)

	fmt.Printf("[Test 1: Success] Code: %d, Body: %s\n", rec1.Code, rec1.Body.String())

	// 2. Тест сценария с ошибкой 400
	req2 := httptest.NewRequest(http.MethodGet, "/greet", nil)
	rec2 := httptest.NewRecorder()

	Greeter(rec2, req2)

	fmt.Printf("[Test 2: Failure] Code: %d, Body: %s", rec2.Code, rec2.Body.String())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Test 1: Success] Code: 200, Body: Hello, Gopher!
# [Test 2: Failure] Code: 400, Body: missing user parameter
```

## Под капотом

`httptest.NewRecorder()` не совершает сетевых вызовов `socket()`, `bind()`, `listen()`. Он пишет данные в обычный `bytes.Buffer` в куче.

## Подводные камни

Рекордер не эмулирует разрыв сети клиентом — для тестирования отмены контекста нужно явно передавать отмененный контекст в `req`.

## На собеседовании

**Вопрос с собеседования:** «Как протестировать хендлер, использующий r.PathValue("id"), с помощью httptest?»
**Ответ:** Начиная с Go 1.22, при вызове хендлера напрямую через `handler.ServeHTTP(rec, req)` контекст роутера отсутствует. Чтобы параметры пути заполнились, нужно либо тестировать хендлер через роутер `mux.ServeHTTP(rec, req)`, либо использовать `r.SetPathValue("id", "123")`.
