# Хиджекинг TCP-соединения через интерфейс http.Hijacker для кастомных протоколов

## Условие

Напиши **HTTP handler с `http.Hijacker`**: "upgrade" соединения до raw TCP. После хиджека отправь произвольное сообщение по TCP и закрой. Объясни, когда это нужно (WebSocket вручную, проксирование).

## Теория

Интерфейс `http.Hijacker` позволяет обработчику перехватить управление сырым сетевым сокетом `net.Conn` и буфером `bufio.ReadWriter` у стандартного HTTP-сервера. После вызова `Hijack()` стандартный HTTP-движок полностью отключается от управления сокетом и больше не закрывает его автоматически.

## Решение по шагам

1. Проверим поддержку интерфейса: `hijacker, ok := w.(http.Hijacker)`.
2. Вызовем `conn, bufrw, err := hijacker.Hijack()`.
3. Отправим кастомные байты прямо в TCP-сокет.
4. Вручную закроем соединение `defer conn.Close()`.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"net/http"
	"net/http/httptest"
)

func hijackHandler(w http.ResponseWriter, r *http.Request) {
	hijacker, ok := w.(http.Hijacker)
	if !ok {
		http.Error(w, "Сервер не поддерживает Hijacking", http.StatusInternalServerError)
		return
	}

	// Перехватываем контроль над сырым TCP сокетом
	conn, bufrw, err := hijacker.Hijack()
	if err != nil {
		http.Error(w, err.Error(), http.StatusInternalServerError)
		return
	}
	defer conn.Close() // Обязательно закрываем сокет вручную!

	// Пишем кастомный raw-ответ прямо в сокет в обход протокола HTTP
	_, _ = bufrw.WriteString("HTTP/1.1 101 Switching Protocols\r\n")
	_, _ = bufrw.WriteString("Upgrade: CustomRawProto\r\n")
	_, _ = bufrw.WriteString("Connection: Upgrade\r\n\r\n")
	_, _ = bufrw.WriteString("RAW_BINARY_STREAM_READY\n")
	_ = bufrw.Flush()
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(hijackHandler))
	defer ts.Close()

	resp, err := http.Get(ts.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	scanner := bufio.NewScanner(resp.Body)
	if scanner.Scan() {
		fmt.Println("[Client received]:", scanner.Text())
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Client received]: RAW_BINARY_STREAM_READY
```

## Под капотом

Метод `Hijack()` изолирует сокет от внутреннего пула сервера `http.Server`. Буфер `bufrw` может содержать еще не прочитанные байты от клиента, поэтому читать нужно через него, а не напрямую из `conn`.

## Подводные камни

В HTTP/2 протоколе `http.Hijacker` не поддерживается (попытка приведения типа вернет `false`), так как по одному TCP-соединению мультиплексируются десятки независимых HTTP/2 стримов.

## На собеседовании

**Вопрос с собеседования:** «Почему библиотека Gorilla WebSocket или Coder WebSocket требует http.Hijacker при рукопожатии (Handshake)?»
**Ответ:** WebSocket начинается с HTTP GET запроса с заголовком `Upgrade: websocket`. Сервер подтверждает апгрейд кодом 101, после чего вызывает `Hijack()`, забирает сырой `net.Conn` и начинает обмениваться бинарными WebSocket-фреймами в полнодуплексном режиме.
