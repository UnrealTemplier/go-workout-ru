# Сериализация сложных вложенных структур и слайсов в форматированный JSON

## Условие

Сериализуйте сложную структуру (вложенные объекты, слайсы) в JSON и отправьте как ответ сервера. Клиент должен десериализовать её и красиво вывести.

## Теория

Сложные модели данных в API:
- Вложенные структуры (композиция).
- Слайсы дочерних сущностей.
- Теги `json:"name,omitempty"`.
Использование `json.NewEncoder(w).Encode(obj)` автоматически поддерживает рекурсивную сериализацию произвольной глубины вложенности.

## Решение по шагам

1. Опишем структуры `Company`, `Department`, `Employee`.
2. Заполним иерархическую структуру.
3. Отправим JSON-ответ клиенту.
4. Клиент десериализует и выведет данные.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/http/httptest"
)

type Employee struct {
	ID   int    `json:"id"`
	Name string `json:"name"`
	Role string `json:"role"`
}

type Department struct {
	Name  string     `json:"name"`
	Staff []Employee `json:"staff"`
}

type Organization struct {
	OrgName string       `json:"org_name"`
	Depts   []Department `json:"departments"`
}

func orgHandler(w http.ResponseWriter, r *http.Request) {
	org := Organization{
		OrgName: "FinTech Holdings",
		Depts: []Department{
			{
				Name: "Core Backend",
				Staff: []Employee{
					{1, "Дмитрий", "Tech Lead"},
					{2, "Анна", "Senior Go Dev"},
				},
			},
		},
	}

	w.Header().Set("Content-Type", "application/json")
	_ = json.NewEncoder(w).Encode(org)
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(orgHandler))
	defer ts.Close()

	resp, _ := http.Get(ts.URL)
	defer resp.Body.Close()

	var result Organization
	_ = json.NewDecoder(resp.Body).Decode(&result)

	fmt.Println("Организация:", result.OrgName)
	for _, d := range result.Depts {
		fmt.Println(" Отдел:", d.Name)
		for _, e := range d.Staff {
			fmt.Printf("   • [%d] %s (%s)\n", e.ID, e.Name, e.Role)
		}
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Организация: FinTech Holdings
#  Отдел: Core Backend
#    • [1] Дмитрий (Tech Lead)
#    • [2] Анна (Senior Go Dev)
```

## Под капотом

Рефлексивный энкодер Go рекурсивно обходит поля структур, следуя указателям и тегам сериализации.

## Подводные камни

Циклические ссылки в структурах вызовут бесконечную рекурсию и панику `runtime: goroutine stack exceeds limit` при маршалинге в JSON.

## На собеседовании

**Вопрос с собеседования:** «Зачем нужен тег `json:",omitempty"` и когда он может навредить?»
**Ответ:** `omitempty` скрывает поле в JSON, если оно равно нулевому значению типа (`false`, `0`, `""`, `nil`). Он может навредить в boolean полях: например, если клиент передает `is_active: false`, поле с `omitempty` будет пропущено и сервер не сможет отличить «не передано» от «передано false». Решение — использовать указатель `*bool`.
