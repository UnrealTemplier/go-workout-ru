# Реализация вспомогательной функции-компоновщика Middleware Chain

## Условие

Создай цепочку из трех middleware (Логирование -> Авторизация -> Сам обработчик). Напиши функцию-помощник для их объединения.

## Теория

Для устранения глубокой вложенности вызовов (`M1(M2(M3(handler)))`) создают функцию-компоновщик `Chain(handlers ...Middleware) Middleware`, которая последовательно связывает слои в цикле справа налево.

## Решение по шагам

1. Объявим тип `type Middleware func(http.Handler) http.Handler`.
2. Реализуем хелпер `CreateChain(mws ...Middleware) Middleware`.
3. Соберем цепочку из трех компонентов.
4. Проверим аккуратный декларативный синтаксис.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

type Middleware func(http.Handler) http.Handler

func Chain(mws ...Middleware) Middleware {
	return func(final http.Handler) http.Handler {
		for i := len(mws) - 1; i >= 0; i-- {
			final = mws[i](final)
		}
		return final
	}
}

func Logger(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Println("[Step 1] Logger executed")
		next.ServeHTTP(w, r)
	})
}

func Authenticator(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Println("[Step 2] Authenticator executed")
		next.ServeHTTP(w, r)
	})
}

func Tracer(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Println("[Step 3] Tracer executed")
		next.ServeHTTP(w, r)
	})
}

func main() {
	coreHandler := http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "Core logic")
	})

	// Элегантная сборка без вложенных скобок
	stack := Chain(Logger, Authenticator, Tracer)

	ts := httptest.NewServer(stack(coreHandler))
	defer ts.Close()

	res, _ := http.Get(ts.URL)
	res.Body.Close()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Step 1] Logger executed
# [Step 2] Authenticator executed
# [Step 3] Tracer executed
```

## Под капотом

Итерация в обратном порядке `len(mws)-1 down to 0` гарантирует, что первое указанное в списке middleware будет вызвано первым при поступлении запроса.

## Подводные камни

Если развернуть цикл слева направо без реверса, порядок выполнения инвертируется, что сломает логику авторизации.

## На собеседовании

**Вопрос с собеседования:** «Чем самописный Chain отличается от популярной библиотеки justinas/alice?»
**Ответ:** По сути `justinas/alice` реализует ровно этот же паттерн сворачивания (fold right) среза `[]Constructor`, добавляя методы `Append` и `Extend` для удобного объединения наборов middleware.
