# Инициализация производственного http.Server с жесткими сетевыми таймаутами

## Условие

**Кастомный `http.Server`**: Вместо `ListenAndServe` создай структуру `srv := &http.Server{Addr: ":8080", Handler: mux, ReadTimeout: 5 * time.Second, WriteTimeout: 10 * time.Second}`. Это защитит сервер от "медленных клиентов" (Slowloris attack).

## Теория

Запуск `http.ListenAndServe(":8080", nil)` — частая ошибка новичков, так как сервер создается с бесконечными таймаутами. В продакшене обязательно создается экземпляр `&http.Server` со строгой конфигурацией.

## Решение по шагам

1. Создадим экземпляр `http.Server`.
2. Зададим `ReadTimeout`, `WriteTimeout` и `IdleTimeout`.
3. Запустим сервер и проверим доступность.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

func NewProductionServer(handler http.Handler) *http.Server {
	return &http.Server{
		Handler:           handler,
		ReadHeaderTimeout: 2 * time.Second,
		ReadTimeout:       5 * time.Second,
		WriteTimeout:      10 * time.Second,
		IdleTimeout:       60 * time.Second,
	}
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("/health", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "healthy")
	})

	srv := NewProductionServer(mux)
	ts := httptest.NewServer(srv.Handler)
	defer ts.Close()

	res, _ := http.Get(ts.URL + "/health")
	defer res.Body.Close()

	fmt.Println("Промышленный сервер успешно ответил со статусом:", res.StatusCode)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Промышленный сервер успешно ответил со статусом: 200
```

## Под капотом

Таймауты сокетов транслируются в таймеры рантайма, интегрированные с Netpoller.

## Подводные камни

Слишком маленький `WriteTimeout` может оборвать отправку тяжелого файла легитимному клиенту с медленным мобильным интернетом.

## На собеседовании

**Вопрос с собеседования:** «Почему линтер gosec ругается на вызовы http.ListenAndServe?»
**Ответ:** Правило `G114 (CWE-676)` предупреждает о риске DoS: вызов `http.ListenAndServe` не позволяет задать `ReadHeaderTimeout`, что делает сервис уязвимым перед Slowloris атаками. Линтер требует явного создания `&http.Server`.
