# Интеграционное тестирование через httptest.NewServer на динамическом локальном порту

## Условие

Используйте `net/http/httptest.NewServer`, чтобы поднять реальный мок-сервер на случайном порту для тестирования вашего HTTP-клиента.

## Теория

`httptest.NewServer(handler)` запускает реальный HTTP-сервер на случайно выделенном свободном порту петлевого интерфейса `127.0.0.1`. Это исключает конфликты номеров портов при параллельном запуске сотен тестов `go test -p 8 ./...`.

## Решение по шагам

1. Создадим `httptest.NewServer` с тестовым обработчиком.
2. Проверим динамический адрес `server.URL`.
3. Выполним реальный сетевой запрос через `http.Client`.
4. Закроем сервер через `defer server.Close()`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func main() {
	// Поднимаем изолированный сервер на случайном свободном порту
	mockServer := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		fmt.Fprint(w, `{"status":"mocked_ok"}`)
	}))
	defer mockServer.Close()

	fmt.Printf("[TestServer] Сервер запущен на адресе: %s\n", mockServer.URL)

	resp, err := http.Get(mockServer.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	body, _ := io.ReadAll(resp.Body)
	fmt.Printf("[Client] Ответ получен: %s\n", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [TestServer] Сервер запущен на адресе: http://127.0.0.1:...
# [Client] Ответ получен: {"status":"mocked_ok"}
```

## Под капотом

`httptest.NewServer` использует системный вызов `net.Listen("tcp", "127.0.0.1:0")`. Порт `0` указывает ядру ОС выделить первый доступный непривилегированный порт (эфемеридный порт).

## Подводные камни

Всегда вызывайте `defer server.Close()`, иначе останутся незакрытые TCP-листенеры и горутины.

## На собеседовании

**Вопрос с собеседования:** «Когда использовать httptest.NewServer, а когда httptest.NewRecorder?»
**Ответ:** `NewRecorder` быстрее, так как не открывает сокеты и тестирует хендлер в памяти (для юнит-тестов обработчиков). `NewServer` нужен, когда требуется протестировать реальное сетевое взаимодействие, HTTP-клиент, работу с пулом соединений или редиректы.
