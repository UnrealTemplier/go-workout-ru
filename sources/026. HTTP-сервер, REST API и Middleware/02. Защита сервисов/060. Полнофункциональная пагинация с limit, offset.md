# Полнофункциональная пагинация с limit, offset и расчетом total_pages

## Условие

Реализуйте пагинацию в методе `GET /tasks`, принимая параметры `limit` и `offset` (или `cursor`), и отдавайте метаданные о общем количестве страниц.

## Теория

Промышленный стандарт постраничного вывода (Offset-based Pagination):
- `limit` — количество запрашиваемых записей на страницу.
- `offset` — смещение от начала списка.
- `total` — общее число записей.
- `total_pages = (total + limit - 1) / limit` (целочисленное округление вверх).

## Решение по шагам

1. Создадим обработчик `GET /tasks`.
2. Извлечем и валидируем `limit` и `offset`.
3. Вычислим срез элементов и общее количество страниц.
4. Вернем структурированный ответ с метаданными.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"strconv"
)

type TaskItem struct {
	ID    int    `json:"id"`
	Title string `json:"title"`
}

type PagedResponse struct {
	Limit      int        `json:"limit"`
	Offset     int        `json:"offset"`
	Total      int        `json:"total"`
	TotalPages int        `json:"total_pages"`
	Items      []TaskItem `json:"items"`
}

func main() {
	var allTasks []TaskItem
	for i := 1; i <= 25; i++ {
		allTasks = append(allTasks, TaskItem{ID: i, Title: fmt.Sprintf("Задача #%d", i)})
	}

	mux := http.NewServeMux()
	mux.HandleFunc("GET /tasks", func(w http.ResponseWriter, r *http.Request) {
		limit, _ := strconv.Atoi(r.URL.Query().Get("limit"))
		if limit <= 0 || limit > 100 {
			limit = 10
		}
		offset, _ := strconv.Atoi(r.URL.Query().Get("offset"))
		if offset < 0 {
			offset = 0
		}

		total := len(allTasks)
		start := offset
		if start > total {
			start = total
		}
		end := start + limit
		if end > total {
			end = total
		}

		totalPages := (total + limit - 1) / limit

		resp := PagedResponse{
			Limit:      limit,
			Offset:     offset,
			Total:      total,
			TotalPages: totalPages,
			Items:      allTasks[start:end],
		}

		w.Header().Set("Content-Type", "application/json")
		_ = json.NewEncoder(w).Encode(resp)
	})

	ts := httptest.NewServer(mux)
	defer ts.Close()

	res, _ := http.Get(ts.URL + "/tasks?limit=5&offset=10")
	body, _ := io.ReadAll(res.Body)
	res.Body.Close()

	fmt.Println(string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"items":[{"id":11,"title":"Задача #11"},{"id":12,"title":"Задача #12"},{"id":13,"title":"Задача #13"},{"id":14,"title":"Задача #14"},{"id":15,"title":"Задача #15"}],"limit":5,"offset":10,"total":25,"total_pages":5}
```

## Под капотом

Формула `(total + limit - 1) / limit` в целочисленной арифметике Go заменяет медленный `math.Ceil(float64(total)/float64(limit))` без конвертации в числа с плавающей точкой.

## Подводные камни

При динамическом добавлении данных в БД между запросами клиент при постраничной пагинации по offset может увидеть дублирование элементов. Для лент новостей используют Cursor Pagination.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество формулы `(total + limit - 1) / limit` над `math.Ceil`?»
**Ответ:** Целочисленная формула выполняется за 1 инструкцию процессора без переключения регистров FPU и риска потери точности на больших 64-битных числах.
