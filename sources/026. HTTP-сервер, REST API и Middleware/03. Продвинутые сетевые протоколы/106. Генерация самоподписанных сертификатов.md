# Генерация самоподписанных сертификатов для локальной разработки через mkcert и openssl

## Условие

Сгенерируй самоподписанный сертификат (self-signed certificate) с помощью `openssl` или утилиты `mkcert` (погугли, как это сделать в консоли). У тебя должны быть файлы `cert.pem` и `key.pem`.

## Теория

Утилиты генерации сертификатов:
1. `mkcert` — локальный центр сертификации: автоматически устанавливает доверенный корневой CA в системное хранилище ОС и браузеров, позволяя работать с `https://localhost` без предупреждений безопасности.
2. `openssl req -x509 -newkey rsa:2048 -nodes -keyout key.pem -out cert.pem -days 365` — классический способ генерации для Linux-серверов.

## Решение по шагам

1. Создадим структуру валидации сертификатов в Go.
2. Проверим загрузку PEM-блоков ключа и сертификата через `tls.X509KeyPair`.
3. Покажем, как парсить срок действия `cert.NotAfter`.
4. Убедимся в валидности пары ключей.

## Код решения

**`check_certs.go`**

```go
package main

import (
	"crypto/rand"
	"crypto/rsa"
	"crypto/tls"
	"crypto/x509"
	"crypto/x509/pkix"
	"encoding/pem"
	"fmt"
	"math/big"
	"time"
)

func generateCertsInMemory() (tls.Certificate, error) {
	key, _ := rsa.GenerateKey(rand.Reader, 2048)
	template := x509.Certificate{
		SerialNumber: big.NewInt(42),
		Subject:      pkix.Name{CommonName: "localhost"},
		NotBefore:    time.Now(),
		NotAfter:     time.Now().Add(365 * 24 * time.Hour),
		KeyUsage:     x509.KeyUsageDigitalSignature,
	}

	certDER, _ := x509.CreateCertificate(rand.Reader, &template, &template, &key.PublicKey, key)

	certPEM := pem.EncodeToMemory(&pem.Block{Type: "CERTIFICATE", Bytes: certDER})
	keyPEM := pem.EncodeToMemory(&pem.Block{Type: "RSA PRIVATE KEY", Bytes: x509.MarshalPKCS1PrivateKey(key)})

	return tls.X509KeyPair(certPEM, keyPEM)
}

func main() {
	cert, err := generateCertsInMemory()
	if err != nil {
		panic(err)
	}

	parsed, err := x509.ParseCertificate(cert.Certificate[0])
	if err != nil {
		panic(err)
	}

	fmt.Printf("[Certificate Loaded] CommonName: %s\n", parsed.Subject.CommonName)
	fmt.Printf("[Certificate Loaded] Срок до:    %s\n", parsed.NotAfter.Format("2006-01-02"))
}
```

**`Терминал`**

```bash
go run check_certs.go
# Вывод:
# [Certificate Loaded] CommonName: localhost
# [Certificate Loaded] Срок до:    ...
```

## Под капотом

Формат PEM представляет собой Base64-кодирование бинарной ASN.1 DER структуры, обрамленное текстовыми заголовками `-----BEGIN CERTIFICATE-----`.

## Подводные камни

Хранение приватных ключей `key.pem` в публичных git-репозиториях — грубейшее нарушение информационной безопасности.

## На собеседовании

**Вопрос с собеседования:** «В чем ключевое отличие утилиты mkcert от openssl при локальной разработке?»
**Ответ:** `openssl` создает недоверенный самоподписанный сертификат (браузеры показывают красный экран предупреждения). `mkcert` создает локальный доверенный корневой удостоверяющий центр (Root CA) и регистрирует его в хранилище доверенных сертификатов ОС и браузеров, делая разработку по HTTPS бесшовной.
