# Генерация Self-Signed X.509 сертификата и запуск HTTPS-сервера в чистом Go

## Условие

Сгенерируй **self-signed сертификат** через Go (`crypto/rsa`, `crypto/x509`, `crypto/x509/pkix`, `math/big`, `time`, `encoding/pem`). Сохрани `cert.pem` и `key.pem`. Напиши HTTPS-сервер, использующий их.

## Теория

Пакет `crypto/x509` в Go позволяет программно сгенерировать самоподписанный TLS-сертификат без использования утилит OpenSSL:
1. Генерация RSA-ключа: `rsa.GenerateKey(rand.Reader, 2048)`.
2. Заполнение шаблона `x509.Certificate` (Subject, NotBefore, NotAfter, IPAddresses).
3. Создание сертификата: `x509.CreateCertificate(...)`.
4. Сериализация в PEM-блоки `encoding/pem`.

## Решение по шагам

1. Сгенерируем приватный RSA ключ.
2. Создадим X.509 сертификат для `127.0.0.1`.
3. Запишем файлы `cert.pem` и `key.pem`.
4. Запустим тестовый TLS-сервер.

## Код решения

**`main.go`**

```go
package main

import (
	"crypto/rand"
	"crypto/rsa"
	"crypto/tls"
	"crypto/x509"
	"crypto/x509/pkix"
	"encoding/pem"
	"fmt"
	"math/big"
	"net"
	"net/http"
	"net/http/httptest"
	"os"
	"time"
)

func generateSelfSignedCerts() (certFile, keyFile string, err error) {
	priv, err := rsa.GenerateKey(rand.Reader, 2048)
	if err != nil {
		return "", "", err
	}

	template := x509.Certificate{
		SerialNumber: big.NewInt(1),
		Subject: pkix.Name{
			Organization: []string{"Go Test Org"},
			CommonName:   "127.0.0.1",
		},
		NotBefore:             time.Now(),
		NotAfter:              time.Now().Add(24 * time.Hour),
		KeyUsage:              x509.KeyUsageKeyEncipherment | x509.KeyUsageDigitalSignature,
		ExtKeyUsage:           []x509.ExtKeyUsage{x509.ExtKeyUsageServerAuth},
		BasicConstraintsValid: true,
		IPAddresses:           []net.IP{net.ParseIP("127.0.0.1")},
	}

	derBytes, err := x509.CreateCertificate(rand.Reader, &template, &template, &priv.PublicKey, priv)
	if err != nil {
		return "", "", err
	}

	certOut, _ := os.CreateTemp("", "cert_*.pem")
	_ = pem.Encode(certOut, &pem.Block{Type: "CERTIFICATE", Bytes: derBytes})
	certOut.Close()

	keyOut, _ := os.CreateTemp("", "key_*.pem")
	_ = pem.Encode(keyOut, &pem.Block{Type: "RSA PRIVATE KEY", Bytes: x509.MarshalPKCS1PrivateKey(priv)})
	keyOut.Close()

	return certOut.Name(), keyOut.Name(), nil
}

func main() {
	certFile, keyFile, err := generateSelfSignedCerts()
	if err != nil {
		panic(err)
	}
	defer os.Remove(certFile)
	defer os.Remove(keyFile)

	fmt.Println("Сгенерированы сертификаты:", certFile, keyFile)

	// Проверяем загрузку пары ключей
	cert, err := tls.LoadX509KeyPair(certFile, keyFile)
	if err != nil {
		panic(err)
	}

	server := httptest.NewUnstartedServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "HTTPS Secure Response")
	}))
	server.TLS = &tls.Config{Certificates: []tls.Certificate{cert}}
	server.StartTLS()
	defer server.Close()

	// Клиент с доверием к тестовому сертификату
	client := server.Client()
	resp, err := client.Get(server.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	fmt.Printf("[HTTPS Success] Статус ответа: %d\n", resp.StatusCode)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Сгенерированы сертификаты: /tmp/cert_... /tmp/key_...
# [HTTPS Success] Статус ответа: 200
```

## Под капотом

`tls.LoadX509KeyPair` парсит ASN.1 DER байты внутри PEM-контейнеров и собирает структуру `tls.Certificate` для SSL/TLS рукопожатия.

## Подводные камни

В современных версиях Go поле `CommonName` считается устаревшим: браузеры требуют обязательного указания IP или DNS в `IPAddresses` или `DNSNames` (Subject Alternative Name, SAN).

## На собеседовании

**Вопрос с собеседования:** «Почему в Go 1.15+ валидатор сертификатов отклоняет сертификаты без поля Subject Alternative Name (SAN)?»
**Ответ:** По стандарту RFC 2818 поле Common Name признано устаревшим и уязвимым к подделке имен. Go форсирует проверку SAN для соответствия современным стандартам безопасности TLS.
