# Механика Upgrade HTTP-соединения до WebSocket по протоколу RFC 6455

## Условие

Реализуйте HTTP-хендлер, который "апгрейдит" HTTP-соединение до WebSocket (`websocket.Accept`).

## Теория

Протокол рукопожатия WebSocket (Handshake):
1. Клиент шлет HTTP GET запрос с заголовками `Upgrade: websocket` и `Connection: Upgrade`, а также случайным ключом `Sec-WebSocket-Key`.
2. Сервер рассчитывает ответный ключ `Sec-WebSocket-Accept = base64(sha1(key + GUID))`.
3. Сервер возвращает статус `101 Switching Protocols`.
4. Соединение переключается в режим обмена фреймами.

## Решение по шагам

1. Создадим HTTP-хендлер `/ws`.
2. Проверим заголовки рукопожатия.
3. Рассчитаем хеш SHA-1 по стандарту RFC 6455.
4. Отправим ответ 101 Switching Protocols.

## Код решения

**`main.go`**

```go
package main

import (
	"crypto/sha1"
	"encoding/base64"
	"fmt"
	"net/http"
	"net/http/httptest"
	"strings"
)

const websocketGUID = "258EAFA5-E914-47DA-95CA-C5AB0DC85B11"

func computeAcceptKey(clientKey string) string {
	h := sha1.New()
	h.Write([]byte(clientKey + websocketGUID))
	return base64.StdEncoding.EncodeToString(h.Sum(nil))
}

func wsUpgradeHandler(w http.ResponseWriter, r *http.Request) {
	if !strings.EqualFold(r.Header.Get("Upgrade"), "websocket") {
		http.Error(w, "Expected Upgrade: websocket", http.StatusBadRequest)
		return
	}

	clientKey := r.Header.Get("Sec-WebSocket-Key")
	if clientKey == "" {
		http.Error(w, "Missing Sec-WebSocket-Key", http.StatusBadRequest)
		return
	}

	acceptKey := computeAcceptKey(clientKey)

	// Отправляем рукопожатие апгрейда 101
	w.Header().Set("Upgrade", "websocket")
	w.Header().Set("Connection", "Upgrade")
	w.Header().Set("Sec-WebSocket-Accept", acceptKey)
	w.WriteHeader(http.StatusSwitchingProtocols)
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(wsUpgradeHandler))
	defer ts.Close()

	req, _ := http.NewRequest(http.MethodGet, ts.URL, nil)
	req.Header.Set("Upgrade", "websocket")
	req.Header.Set("Connection", "Upgrade")
	req.Header.Set("Sec-WebSocket-Key", "dGhlIHNhbXBsZSBub25jZQ==")

	res, _ := http.DefaultClient.Do(req)
	defer res.Body.Close()

	fmt.Printf("[Статус рукопожатия] %d (%s)\n", res.StatusCode, res.Status)
	fmt.Printf("[Sec-WebSocket-Accept] %s\n", res.Header.Get("Sec-WebSocket-Accept"))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Статус рукопожатия] 101 (101 Switching Protocols)
# [Sec-WebSocket-Accept] s3pPLMBiTxaQ9kYGzzhZRbK+xOo=
```

## Под капотом

Магическая константа GUID `"258EAFA5-..."` зафиксирована в спецификации RFC 6455 для подтверждения того, что сервер действительно понимает протокол WebSocket.

## Подводные камни

Заголовок `Upgrade` регистронезависим, поэтому проверять его нужно через `strings.EqualFold(h, "websocket")`.

## На собеседовании

**Вопрос с собеседования:** «Зачем нужен расчет Sec-WebSocket-Accept через SHA-1 хэш от ключа клиента?»
**Ответ:** Чтобы исключить ложный апгрейд старыми кэширующими прокси-серверами, которые могли бы по ошибке вернуть закэшированный ответ 101 на обычный HTTP-запрос.
