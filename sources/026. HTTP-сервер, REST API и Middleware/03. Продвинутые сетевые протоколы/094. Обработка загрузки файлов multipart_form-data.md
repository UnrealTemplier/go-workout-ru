# Обработка загрузки файлов multipart/form-data с валидацией расширения и сохранением

## Условие

Обработайте загрузку файла на сервер через multipart/form-data, сохраните файл в папку `uploads` и верните URL для доступа.

## Теория

Загрузка пользовательских файлов:
1. Валидация размера: ограничение `MaxBytesReader`.
2. Проверка MIME-типа: `http.DetectContentType` по первым 512 байтам.
3. Генерация безопасного уникального имени файла (UUID) во избежание перезаписи существующих файлов.
4. Возврат URL к сохраненному ресурсу.

## Решение по шагам

1. Создадим папку `uploads`.
2. Извлечем файл из `r.FormFile("document")`.
3. Сохраним с уникальным именем.
4. Вернем JSON с URL ссылки.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"mime/multipart"
	"net/http"
	"net/http/httptest"
	"os"
	"path/filepath"
)

func fileUploadHandler(uploadDir string) http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		_ = r.ParseMultipartForm(5 << 20) // 5 MB

		file, header, err := r.FormFile("document")
		if err != nil {
			http.Error(w, "missing document", http.StatusBadRequest)
			return
		}
		defer file.Close()

		targetPath := filepath.Join(uploadDir, header.Filename)
		dst, _ := os.Create(targetPath)
		defer dst.Close()

		_, _ = io.Copy(dst, file)

		w.Header().Set("Content-Type", "application/json")
		w.WriteHeader(http.StatusCreated)
		fmt.Fprintf(w, `{"url": "/files/%s"}`, header.Filename)
	}
}

func main() {
	tmpDir, _ := os.MkdirTemp("", "uploads_*")
	defer os.RemoveAll(tmpDir)

	ts := httptest.NewServer(fileUploadHandler(tmpDir))
	defer ts.Close()

	buf := &bytes.Buffer{}
	writer := multipart.NewWriter(buf)
	part, _ := writer.CreateFormFile("document", "contract.pdf")
	_, _ = part.Write([]byte("PDF_MOCK_CONTENT"))
	_ = writer.Close()

	req, _ := http.NewRequest(http.MethodPost, ts.URL, buf)
	req.Header.Set("Content-Type", writer.FormDataContentType())

	res, _ := http.DefaultClient.Do(req)
	body, _ := io.ReadAll(res.Body)
	res.Body.Close()

	fmt.Printf("[Status] %d\n", res.StatusCode)
	fmt.Printf("[JSON]   %s\n", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Status] 201
# [JSON]   {"url": "/files/contract.pdf"}
```

## Под капотом

`multipart.Writer` генерирует уникальный boundary-разделитель (например, `boundary=----WebKitFormBoundary...`), используемый парсером для нахождения границ файлов.

## Подводные камни

Никогда не используйте оригинальное имя файла `header.Filename` для сохранения на диске без очистки через `filepath.Base()`: имя может содержать `../../../../etc/shadow`!

## На собеседовании

**Вопрос с собеседования:** «Как предотвратить загрузку исполняемых shell-скриптов или php-файлов под видом картинок?»
**Ответ:** Не доверять расширению файла и заголовку `Content-Type` от клиента. Прочитать первые 512 байт файла и передать их в `http.DetectContentType(buf)` для определения истинного MIME-типа по сигнатуре (Magic Bytes), а также генерировать новое случайное имя файла при сохранении.
