# Классическое юнит-тестирование хендлера через httptest.NewRequest и NewRecorder

## Условие

**Тестирование Хендлера (`httptest`)**: Импортируй `net/http/httptest`. Создай фейковый запрос `httptest.NewRequest`. Создай `rec := httptest.NewRecorder()`. Передай их в свой хендлер. Проверь `rec.Code` (ожидаем 200) и `rec.Body.String()`.

## Теория

Юнит-тестирование веб-хендлеров без сетевого стека:
1. `httptest.NewRequest("GET", "/path", body)` создает синтетический `*http.Request`.
2. `httptest.NewRecorder()` перехватывает все записи в памяти.
3. Проверка `rec.Code == http.StatusOK` и проверка заголовков.

## Решение по шагам

1. Напишем функцию `PingHandler`.
2. Создадим тестовый запрос и рекордер.
3. Вызовем `PingHandler(rec, req)`.
4. Проверим код и тело.

## Код решения

**`ping_test.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func PingHandler(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(http.StatusOK)
	_, _ = w.Write([]byte(`{"status":"pong"}`))
}

func main() {
	req := httptest.NewRequest(http.MethodGet, "/ping", nil)
	rec := httptest.NewRecorder()

	PingHandler(rec, req)

	res := rec.Result()
	defer res.Body.Close()

	fmt.Printf("[Test Check] Code:         %d\n", res.StatusCode)
	fmt.Printf("[Test Check] Content-Type: %s\n", res.Header.Get("Content-Type"))
	fmt.Printf("[Test Check] Body:         %s\n", rec.Body.String())
}
```

**`Терминал`**

```bash
go run ping_test.go
# Вывод:
# [Test Check] Code:         200
# [Test Check] Content-Type: application/json
# [Test Check] Body:         {"status":"pong"}
```

## Под капотом

`rec.Result()` возвращает полноценную структуру `*http.Response`, отражающую финальное состояние ответа.

## Подводные камни

Не забывайте вызывать `res.Body.Close()`, если используете `rec.Result()`, для очистки ресурсов.

## На собеседовании

**Вопрос с собеседования:** «Как протестировать контекст с дедлайном в httptest.NewRequest?»
**Ответ:** Создать контекст через `ctx, cancel := context.WithTimeout(context.Background(), 10*time.Millisecond)` и привязать его к запросу через `req = req.WithContext(ctx)` перед вызовом хендлера.
