# Реализация легковесного прокси-сервера на стандартном http.Transport

## Условие

Напишите простой прокси-сервер: принимает HTTP-запросы, перенаправляет их на целевой сервер, возвращает ответ клиенту.

## Теория

Простейший HTTP Forwarding Proxy без сторонних библиотек:
1. Хендлер копирует входящий запрос `r`.
2. Перенаправляет запрос на целевой сервер через `http.DefaultTransport.RoundTrip(outReq)`.
3. Копирует полученные заголовки и статус в `w`.
4. Копирует тело через `io.Copy(w, resp.Body)`.

## Решение по шагам

1. Запустим целевой сервер.
2. Реализуем проксирующий обработчик.
3. Скопируем статус, заголовки и тело.
4. Проверим прозрачность проксирования.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"net/url"
)

func SimpleProxyHandler(target *url.URL) http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		outReq := r.Clone(r.Context())
		outReq.URL.Scheme = target.Scheme
		outReq.URL.Host = target.Host
		outReq.Host = target.Host
		outReq.RequestURI = "" // Очищаем для client.Do

		resp, err := http.DefaultTransport.RoundTrip(outReq)
		if err != nil {
			http.Error(w, "Proxy Error", http.StatusBadGateway)
			return
		}
		defer resp.Body.Close()

		// Копируем заголовки ответа
		for k, vv := range resp.Header {
			for _, v := range vv {
				w.Header().Add(k, v)
			}
		}
		w.WriteHeader(resp.StatusCode)
		_, _ = io.Copy(w, resp.Body)
	}
}

func main() {
	targetServer := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("X-Backend-Version", "v1.0.0")
		fmt.Fprint(w, "Ответ от конечного целевого сервера")
	}))
	defer targetServer.Close()

	targetURL, _ := url.Parse(targetServer.URL)
	proxyServer := httptest.NewServer(SimpleProxyHandler(targetURL))
	defer proxyServer.Close()

	resp, _ := http.Get(proxyServer.URL)
	body, _ := io.ReadAll(resp.Body)
	resp.Body.Close()

	fmt.Printf("[Status]            %d\n", resp.StatusCode)
	fmt.Printf("[X-Backend-Version] %s\n", resp.Header.Get("X-Backend-Version"))
	fmt.Printf("[Body]              %s\n", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Status]            200
# [X-Backend-Version] v1.0.0
# [Body]              Ответ от конечного целевого сервера
```

## Под капотом

Метод `r.Clone(ctx)` создает глубокую копию структуры `http.Request`, включая клонирование карты заголовков `Header`.

## Подводные камни

Поле `RequestURI` в исходящем `http.Request` клиента обязано быть пустым, иначе `RoundTrip` вернет ошибку `http: Request.RequestURI can't be set in client requests`.

## На собеседовании

**Вопрос с собеседования:** «Зачем очищать RequestURI перед вызовом RoundTrip?»
**Ответ:** `RequestURI` используется сервером только для чтения сырой строки запроса из TCP-сокета. На стороне клиента URL запроса берется строго из структуры `req.URL`. Наличие `RequestURI` вызывает ошибку валидации в рантайме Go.
