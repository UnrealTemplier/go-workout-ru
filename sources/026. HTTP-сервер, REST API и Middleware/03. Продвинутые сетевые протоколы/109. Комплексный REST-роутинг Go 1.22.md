# Комплексный REST-роутинг Go 1.22+: список, извлечение по ID и создание

## Условие

**Современная маршрутизация (Go 1.22+)**: В версии Go 1.22 стандартный маршрутизатор `http.ServeMux` получил встроенную поддержку методов и параметров пути. Напишите сервер с использованием нового синтаксиса маршрутов:
* `GET /users` — список пользователей.
* `GET /users/{id}` — получение конкретного пользователя. Извлеките параметр `{id}` из пути с помощью метода `req.PathValue("id")`.
* `POST /users` — создание пользователя.

## Теория

Go 1.22+ унифицирует проектирование REST API:
- Точный паттерн метода: `"GET /users"`, `"POST /users"`.
- Шаблон переменной: `"GET /users/{id}"`.
- Извлечение: `req.PathValue("id")`.

## Решение по шагам

1. Создадим `mux := http.NewServeMux()`.
2. Зарегистрируем все три маршрута.
3. Проверим работу каждого метода.
4. Протестируем извлечение `{id}`.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func main() {
	mux := http.NewServeMux()

	// 1. GET /users
	mux.HandleFunc("GET /users", func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		fmt.Fprint(w, `[{"id":1,"name":"Alice"},{"id":2,"name":"Bob"}]`)
	})

	// 2. GET /users/{id}
	mux.HandleFunc("GET /users/{id}", func(w http.ResponseWriter, r *http.Request) {
		userID := r.PathValue("id")
		w.Header().Set("Content-Type", "application/json")
		fmt.Fprintf(w, `{"id":%s,"name":"User %s"}`, userID, userID)
	})

	// 3. POST /users
	mux.HandleFunc("POST /users", func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusCreated)
		fmt.Fprint(w, `{"status":"user created"}`)
	})

	ts := httptest.NewServer(mux)
	defer ts.Close()

	// Проверка GET /users
	r1, _ := http.Get(ts.URL + "/users")
	b1, _ := io.ReadAll(r1.Body)
	r1.Body.Close()
	fmt.Printf("[1. Список]  %s\n", string(b1))

	// Проверка GET /users/42
	r2, _ := http.Get(ts.URL + "/users/42")
	b2, _ := io.ReadAll(r2.Body)
	r2.Body.Close()
	fmt.Printf("[2. По ID]   %s\n", string(b2))

	// Проверка POST /users
	r3, _ := http.Post(ts.URL+"/users", "application/json", bytes.NewBufferString("{}"))
	b3, _ := io.ReadAll(r3.Body)
	r3.Body.Close()
	fmt.Printf("[3. Создан]  %s\n", string(b3))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [1. Список]  [{"id":1,"name":"Alice"},{"id":2,"name":"Bob"}]
# [2. По ID]   {"id":42,"name":"User 42"}
# [3. Создан]  {"status":"user created"}
```

## Под капотом

`ServeMux` автоматически разрешает пересечение путей `/users` и `/users/{id}` благодаря более высокой специфичности точного пути `/users`.

## Подводные камни

Пробел между методом и путем обязателен: запись `"GET/users"` зарегистрирует метод с некорректным путем.

## На собеседовании

**Вопрос с собеседования:** «Как в Go 1.22+ задать обработчик для всех методов одновременно?»
**Ответ:** Опустить указание метода в шаблоне: `mux.HandleFunc("/users/{id}", handler)`. В этом случае хендлер будет вызываться на любые методы (GET, POST, PUT, DELETE, PATCH).
