# Логирующий Middleware: извлечение IP-клиента через RemoteAddr и замер Latency

## Условие

**Логирующий Middleware**: Напишите функцию-декоратор (Middleware) для вашего сервера. Она должна оборачивать любые HTTP-обработчики и записывать в лог: метод запроса, запрашиваемый путь, IP-адрес клиента и время, затраченное на обработку запроса.

## Теория

Извлечение IP-адреса:
Поле `r.RemoteAddr` содержит строку `"IP:port"`. Для чистого получения IP-адреса используется функция `net.SplitHostPort(r.RemoteAddr)`.

## Решение по шагам

1. Напишем `AccessLogMiddleware`.
2. Извлечем IP через `net.SplitHostPort`.
3. Замерим время выполнения запроса.
4. Проверим форматированный вывод.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net"
	"net/http"
	"net/http/httptest"
	"time"
)

func AccessLogMiddleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		start := time.Now()

		ip, _, err := net.SplitHostPort(r.RemoteAddr)
		if err != nil {
			ip = r.RemoteAddr
		}

		next.ServeHTTP(w, r)

		duration := time.Since(start)
		fmt.Printf("[ACCESS LOG] IP: %-15s | %-4s %-12s | Time: %v\n",
			ip, r.Method, r.URL.Path, duration.Round(time.Microsecond))
	})
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("/users", func(w http.ResponseWriter, r *http.Request) {
		time.Sleep(2 * time.Millisecond)
		fmt.Fprint(w, "Users List")
	})

	server := httptest.NewServer(AccessLogMiddleware(mux))
	defer server.Close()

	res, _ := http.Get(server.URL + "/users")
	res.Body.Close()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [ACCESS LOG] IP: 127.0.0.1       | GET  /users       | Time: 2ms
```

## Под капотом

`net.SplitHostPort` корректно обрабатывает как IPv4 (`127.0.0.1:1234`), так и IPv6 (`[::1]:1234`) адреса.

## Подводные камни

Попытка разделить адрес по обычному двоеточию `strings.Split(r.RemoteAddr, ":")` ломает IPv6-адреса, содержащие множество двоеточий.

## На собеседовании

**Вопрос с собеседования:** «Как получить настоящий IP-адрес клиента, если сервис стоит за Cloudflare или Nginx?»
**Ответ:** Проверять заголовки `CF-Connecting-IP`, `X-Real-IP` или первый IP-адрес из цепочки `X-Forwarded-For`, но строго доверяя этим заголовкам только в том случае, если запрос пришел от доверенного внутреннего балансировщика.
