# Хендлер статуса системы /status с отдачей JSON и метрик аптайма

## Условие

**Формирование JSON-ответов**: Напишите обработчик `/status`, который возвращает клиенту JSON-объект вида `{"status": "ok", "uptime": "120s"}`. Убедитесь, что вы отправляете правильный заголовок ответа `w.Header().Set("Content-Type", "application/json")` и статус-код `200 OK` перед записью тела.

## Теория

Эндпоинт `/status` — базовый компонент мониторинга. Он возвращает состояние сервиса, время непрерывной работы (uptime) и версию сборки.

## Решение по шагам

1. Зафиксируем время старта приложения `startTime := time.Now()`.
2. Создадим обработчик `/status`.
3. Установим `Content-Type: application/json` и статус 200.
4. Рассчитаем текущий аптайм и вернем структурированный JSON.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"time"
)

var startTime = time.Now()

type StatusReport struct {
	Status string `json:"status"`
	Uptime string `json:"uptime"`
}

func statusHandler(w http.ResponseWriter, r *http.Request) {
	report := StatusReport{
		Status: "ok",
		Uptime: time.Since(startTime).Round(time.Millisecond).String(),
	}

	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(http.StatusOK)
	_ = json.NewEncoder(w).Encode(report)
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /status", statusHandler)

	ts := httptest.NewServer(mux)
	defer ts.Close()

	time.Sleep(10 * time.Millisecond)

	res, _ := http.Get(ts.URL + "/status")
	body, _ := io.ReadAll(res.Body)
	res.Body.Close()

	fmt.Printf("[Status Code]  %d\n", res.StatusCode)
	fmt.Printf("[Content-Type] %s\n", res.Header.Get("Content-Type"))
	fmt.Printf("[JSON Body]    %s", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Status Code]  200
# [Content-Type] application/json
# [JSON Body]    {"status":"ok","uptime":"10ms"}
```

## Под капотом

Вызов `time.Since` возвращает длительность `time.Duration`, строковое представление которой форматируется как `"10ms"`, `"2h4m"`.

## Подводные камни

Не забывайте, что `json.NewEncoder` добавляет символ перевода строки `\n` в конец вывода, что соответствует стандартам UNIX.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие метрик uptime от heartbeats в распределенных системах?»
**Ответ:** `uptime` показывает непрерывное время работы конкретного экземпляра процесса с момента старта (помогает выявлять внезапные перезапуски OOMKilled). `Heartbeat` — это периодический сигнал живости сервиса в Service Registry (Consul, etcd), используемый для обнаружения сетевых изоляций (Split-Brain).
