# Первая Middleware: измерение времени ответа и структурированное логирование

## Условие

**Первая Middleware (Логирование)**: Middleware — это паттерн декоратора (функция принимает хендлер и возвращает хендлер). Напиши функцию `LoggingMiddleware`, которая замеряет время начала запроса, вызывает `next.ServeHTTP(w, r)` и логирует время выполнения, метод и URL. Оберни в неё свой роутер.

## Теория

Паттерн Декоратор (Decorator / Middleware):
Функция декорирует интерфейс `http.Handler`, выполняя замер `start := time.Now()` перед вызовом и `time.Since(start)` после возврата управления.

## Решение по шагам

1. Напишем `LoggingMiddleware`.
2. Замерим длительность через `time.Since`.
3. Обернем `mux`.
4. Выполним проверочный запрос.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

func LoggingMiddleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		start := time.Now()

		next.ServeHTTP(w, r)

		elapsed := time.Since(start)
		fmt.Printf("[HTTP Request] %s %s -> Завершено за %v\n", r.Method, r.URL.Path, elapsed.Round(time.Microsecond))
	})
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("/calc", func(w http.ResponseWriter, r *http.Request) {
		time.Sleep(5 * time.Millisecond)
		fmt.Fprint(w, "calculated")
	})

	server := httptest.NewServer(LoggingMiddleware(mux))
	defer server.Close()

	resp, _ := http.Get(server.URL + "/calc")
	resp.Body.Close()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [HTTP Request] GET /calc -> Завершено за 5ms
```

## Под капотом

Вызов `time.Since(start)` использует монотонные часы процессора (Monotonic Clock), что защищает замер от скачков системного времени при синхронизации через NTP.

## Подводные камни

Не используйте тяжелые строковые конкатенации в горячих путях логгера: форматируйте логи через структурированный `log/slog`.

## На собеседовании

**Вопрос с собеседования:** «Почему time.Now() в Go возвращает и настенные, и монотонные часы?»
**Ответ:** Настенные часы (Wall clock) показывают реальное время суток и могут сдвигаться назад оператором или NTP. Монотонные часы (Monotonic clock) всегда идут строго вперед с константной скоростью тактов CPU, гарантируя корректность замеров `time.Since`.
