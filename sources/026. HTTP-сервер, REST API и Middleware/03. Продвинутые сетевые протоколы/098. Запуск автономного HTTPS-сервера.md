# Запуск автономного HTTPS-сервера с ListenAndServeTLS на самоподписанном сертификате

## Условие

Настройте HTTPS-сервер с самоподписанным сертификатом (используя `http.ListenAndServeTLS` и сгенерированные ключи).

## Теория

Функция `http.ListenAndServeTLS(addr, certFile, keyFile, handler)` поднимает полноценный HTTPS-сервер:
- Принимает TLS соединения.
- Автоматически согласует протокол HTTP/2 через ALPN (Application-Layer Protocol Negotiation).
- Шифрует трафик с помощью надежных шифронаборов.

## Решение по шагам

1. Создадим тестовый TLS-сервер через `httptest.NewTLSServer`.
2. Проверим заголовок `TLS` в запросе.
3. Проверим используемую версию протокола TLS 1.3.

## Код решения

**`main.go`**

```go
package main

import (
	"crypto/tls"
	"fmt"
	"net/http"
	"net/http/httptest"
)

func tlsInfoHandler(w http.ResponseWriter, r *http.Request) {
	if r.TLS != nil {
		fmt.Fprintf(w, "TLS активен! Версия TLS: 0x%04x, ServerName: %s",
			r.TLS.Version, r.TLS.ServerName)
	} else {
		fmt.Fprint(w, "Обычный незашифрованный HTTP")
	}
}

func main() {
	server := httptest.NewTLSServer(http.HandlerFunc(tlsInfoHandler))
	defer server.Close()

	client := server.Client()
	resp, err := client.Get(server.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	fmt.Printf("[TLS Server Status]: %d\n", resp.StatusCode)
	fmt.Printf("[Protocol Used]:     %s\n", resp.Proto)
	_ = tls.VersionTLS13
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [TLS Server Status]: 200
# [Protocol Used]:     HTTP/2.0
```

## Под капотом

В Go поддержка HTTP/2 включается автоматически для любых TLS-серверов при вызове `ListenAndServeTLS`.

## Подводные камни

Файл приватного ключа `key.pem` на сервере обязан иметь строгие права доступа в ОС `chmod 600`, защищая ключ от чтения другими процессами.

## На собеседовании

**Вопрос с собеседования:** «Что такое ALPN в TLS рукопожатии?»
**Ответ:** ALPN (Application-Layer Protocol Negotiation) — расширение TLS, позволяющее клиенту и серверу в процессе одного TLS-рукопожатия договориться о протоколе прикладного уровня (`h2` для HTTP/2 или `http/1.1`) без дополнительных сетевых RTT.
