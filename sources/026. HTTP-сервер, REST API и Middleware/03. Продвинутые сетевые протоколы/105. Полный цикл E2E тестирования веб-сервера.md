# Полный цикл E2E тестирования веб-сервера через httptest.NewServer

## Условие

**Тестирование Сервера целиком**: Используй `ts := httptest.NewServer(mux)` в тестах. Он поднимет сервер на случайном локальном порту (узнать можно через `ts.URL`). Сделай к нему реальный `http.Get` и проверь ответ. Не забудь `ts.Close()`.

## Теория

End-to-End тестирование HTTP-сервера:
Поднятие реального сервера через `httptest.NewServer(mux)` позволяет протестировать полный сетевой стек, включая маршрутизацию, все middleware, сериализацию заголовков, сжатие gzip и закрытие соединений.

## Решение по шагам

1. Создадим рабочий `mux := http.NewServeMux()`.
2. Запустим `ts := httptest.NewServer(mux)`.
3. Выполним реальный `http.Get(ts.URL + "/health")`.
4. Проверим статус-код и тело ответа.

## Код решения

**`e2e_server_test.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func BuildApp() http.Handler {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /health", func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		fmt.Fprint(w, `{"status":"UP"}`)
	})
	return mux
}

func main() {
	// Поднимаем полноценный сервер для E2E теста
	ts := httptest.NewServer(BuildApp())
	defer ts.Close() // Гарантированное освобождение ресурсов

	fmt.Println("[E2E Test] Сервер слушает динамический адрес:", ts.URL)

	resp, err := http.Get(ts.URL + "/health")
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	body, _ := io.ReadAll(resp.Body)

	fmt.Printf("[E2E Test] Статус ответа: %d (Ожидается 200)\n", resp.StatusCode)
	fmt.Printf("[E2E Test] Тело ответа:   %s\n", string(body))
}
```

**`Терминал`**

```bash
go run e2e_server_test.go
# Вывод:
# [E2E Test] Сервер слушает динамический адрес: http://127.0.0.1:...
# [E2E Test] Статус ответа: 200 (Ожидается 200)
# [E2E Test] Тело ответа:   {"status":"UP"}
```

## Под капотом

`httptest.NewServer` запускает полноценный `http.Server` в отдельной фоновой горутине и использует реальный сетевой стек TCP петлевого интерфейса Loopback.

## Подводные камни

Если в тестовом коде забыть вызвать `ts.Close()`, порт останется занятым, а фоновые горутины сервера утекут в память тестового раннера.

## На собеседовании

**Вопрос с собеседования:** «Как протестировать клиентские таймауты с помощью httptest.NewServer?»
**Ответ:** Создать `httptest.NewServer` с хендлером, содержащим `time.Sleep(500 * time.Millisecond)`, а в клиенте настроить таймаут `Timeout: 50 * time.Millisecond` и проверить возврат ошибки `os.ErrDeadlineExceeded`.
