# Комбинирование Path-параметров и Query-параметров пагинации

## Условие

Извлеките значение переменной пути (`id` через `r.PathValue("id")`) и query-параметры (`?page=2&sort=desc` через `r.URL.Query()`).

## Теория

В реальных API параметры идентификации ресурса помещают в путь (`/categories/{id}/items`), а параметры представления и фильтрации — в query-строку (`?page=2&sort=desc&limit=20`).

## Решение по шагам

1. Зарегистрируем маршрут `GET /categories/{id}/products`.
2. Извлечем категорию через `r.PathValue("id")`.
3. Извлечем query-параметры `page` и `sort` через `r.URL.Query()`.
4. Сформируем и вернем комплексный JSON-ответ.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

type QueryInfo struct {
	CategoryID string `json:"category_id"`
	Page       string `json:"page"`
	Sort       string `json:"sort"`
}

func main() {
	mux := http.NewServeMux()

	mux.HandleFunc("GET /categories/{id}/products", func(w http.ResponseWriter, r *http.Request) {
		categoryID := r.PathValue("id")
		q := r.URL.Query()
		page := q.Get("page")
		if page == "" {
			page = "1"
		}
		sortOrder := q.Get("sort")
		if sortOrder == "" {
			sortOrder = "asc"
		}

		info := QueryInfo{
			CategoryID: categoryID,
			Page:       page,
			Sort:       sortOrder,
		}

		w.Header().Set("Content-Type", "application/json")
		_ = json.NewEncoder(w).Encode(info)
	})

	ts := httptest.NewServer(mux)
	defer ts.Close()

	resp, _ := http.Get(ts.URL + "/categories/electronics/products?page=3&sort=desc")
	body, _ := io.ReadAll(resp.Body)
	resp.Body.Close()

	fmt.Println(string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# {"category_id":"electronics","page":"3","sort":"desc"}
```

## Под капотом

`r.PathValue("key")` считывает значение из внутреннего контекста `http.Request`, которое туда поместил роутер при сопоставлении шаблона пути.

## Подводные камни

`r.PathValue` возвращает строку. Если ожидается число, обязательно выполняйте конвертацию через `strconv.Atoi` с обработкой ошибок.

## На собеседовании

**Вопрос с собеседования:** «Когда передавать параметры через Path, а когда через Query?»
**Ответ:** Через Path передают уникальные идентификаторы иерархии ресурсов (`/orders/123/items/4`). Через Query передают необязательные параметры: фильтры, сортировку, пагинацию, проекцию полей (`?status=paid&limit=10`).
