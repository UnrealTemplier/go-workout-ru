# Custom http.ResponseWriter для точного захвата реального статус-кода и размера ответа

## Условие

Напиши **custom http.ResponseWriter** для захвата статус-кода: `type responseRecorder struct { status int; http.ResponseWriter }`. Переопредели `WriteHeader`. Используй в middleware для логирования реального статуса (даже если handler его не пишет явно, по умолчанию 200).

## Теория

Стандартный интерфейс `http.ResponseWriter` не имеет метода `StatusCode() int` для чтения уже отправленного кода. Чтобы логгер или сборщик метрик Prometheus мог зафиксировать статус ответа, создают структуру-шпион, оборачивающую исходный `ResponseWriter` и перехватывающую вызовы `WriteHeader` и `Write`.

## Решение по шагам

1. Создадим структуру `ResponseRecorder` с полями `status` и `bytesWritten`.
2. Переопределим методы `WriteHeader(int)` и `Write([]byte) (int, error)`.
3. Напишем middleware, логирующее точный статус и число байт.
4. Проверим работу на маршруте без явного вызова `WriteHeader`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

type ResponseRecorder struct {
	http.ResponseWriter
	StatusCode   int
	BytesWritten int
}

func (r *ResponseRecorder) WriteHeader(code int) {
	r.StatusCode = code
	r.ResponseWriter.WriteHeader(code)
}

func (r *ResponseRecorder) Write(b []byte) (int, error) {
	n, err := r.ResponseWriter.Write(b)
	r.BytesWritten += n
	return n, err
}

func MetricLogger(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		rec := &ResponseRecorder{
			ResponseWriter: w,
			StatusCode:     http.StatusOK, // Дефолтный статус при вызове Write
		}

		next.ServeHTTP(rec, r)

		fmt.Printf("[Метрики] Путь: %-6s | Статус: %d | Байт отдано: %d\n",
			r.URL.Path, rec.StatusCode, rec.BytesWritten)
	})
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("/implicit", func(w http.ResponseWriter, r *http.Request) {
		// Не вызываем WriteHeader явно -> статус 200
		_, _ = w.Write([]byte("Hello Implicit"))
	})
	mux.HandleFunc("/explicit", func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusAccepted)
		_, _ = w.Write([]byte("Accepted"))
	})

	server := httptest.NewServer(MetricLogger(mux))
	defer server.Close()

	res1, _ := http.Get(server.URL + "/implicit")
	res1.Body.Close()

	res2, _ := http.Get(server.URL + "/explicit")
	res2.Body.Close()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Метрики] Путь: /implicit | Статус: 200 | Байт отдано: 14
# [Метрики] Путь: /explicit | Статус: 202 | Байт отдано: 8
```

## Под капотом

Если хендлер просто вызывает `w.Write()`, поле `StatusCode` останется равным `http.StatusOK`, что полностью отражает поведение спецификации HTTP в Go.

## Подводные камни

Обязательно сохраняйте дефолтное значение `http.StatusOK` в `StatusCode`, иначе при записи без явного `WriteHeader` статус ошибочно залогируется как 0.

## На собеседовании

**Вопрос с собеседования:** «Как обернуть ResponseWriter и не потерять поддержку http.Hijacker для WebSocket?»
**Ответ:** Реализовать метод `Hijack() (net.Conn, *bufio.ReadWriter, error)` на структуре `ResponseRecorder`, который проверяет приведение внутреннего `r.ResponseWriter.(http.Hijacker)` и вызывает его.
