# Раздача статических файлов с помощью встроенного http.FileServer

## Условие

Раздавай статические файлы (например, HTML или картинки) из папки `./static` с помощью `http.FileServer(http.Dir("./static"))`.

## Теория

`http.FileServer(root)` реализует полноценный веб-сервер статики:
- Автоматически рассчитывает `Content-Type` по расширению файла.
- Поддерживает заголовки кэширования `ETag` и `Last-Modified` (HTTP 304 Not Modified).
- Поддерживает частичные диапазоны байтов `Accept-Ranges: bytes` (HTTP 206 Partial Content).
- Исключает уязвимости Directory Traversal (`../../etc/passwd`).

## Решение по шагам

1. Создадим временную директорию с тестовым файлом `style.css`.
2. Настроим `http.FileServer(http.Dir(dir))`.
3. Запросим файл через HTTP GET.
4. Проверим статус 200 и заголовок `Content-Type`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"os"
	"path/filepath"
)

func main() {
	tempDir, err := os.MkdirTemp("", "static_test_*")
	if err != nil {
		panic(err)
	}
	defer os.RemoveAll(tempDir)

	// Создаем тестовый статический файл
	cssPath := filepath.Join(tempDir, "style.css")
	_ = os.WriteFile(cssPath, []byte("body { background: #000; color: #fff; }"), 0644)

	fileServer := http.FileServer(http.Dir(tempDir))
	ts := httptest.NewServer(fileServer)
	defer ts.Close()

	resp, err := http.Get(ts.URL + "/style.css")
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	body, _ := io.ReadAll(resp.Body)
	fmt.Printf("[Status]       %d\n", resp.StatusCode)
	fmt.Printf("[Content-Type] %s\n", resp.Header.Get("Content-Type"))
	fmt.Printf("[Body]         %s\n", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Status]       200
# [Content-Type] text/css; charset=utf-8
# [Body]         body { background: #000; color: #fff; }
```

## Под капотом

`http.Dir` реализует интерфейс `http.FileSystem`. При обращении к директории без файла `FileServer` отдает сгенерированный HTML со списком файлов или `index.html`, если он есть.

## Подводные камни

Если в продакшене не отключить листинг директорий, пользователи смогут просматривать структуру всех файлов на сервере.

## На собеседовании

**Вопрос с собеседования:** «Как в Go 1.16+ встроить статические файлы прямо в бинарник (Single Binary Deployment)?»
**Ответ:** Использовать пакет `embed` и директиву `//go:embed static/* var staticFS embed.FS`. Затем обернуть её через `http.FS(staticFS)` и передать в `http.FileServer`.
