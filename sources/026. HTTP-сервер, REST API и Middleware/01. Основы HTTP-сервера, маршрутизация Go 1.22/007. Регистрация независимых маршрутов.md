# Регистрация независимых маршрутов и разграничение путей в ServeMux

## Условие

Зарегистрируйте несколько хендлеров с помощью `http.HandleFunc` для разных путей (`/home`, `/about`).

## Теория

`http.ServeMux` сопоставляет входящие запросы по правилу наибольшего совпадения (Longest Prefix Match). Если зарегистрированы маршруты `/home` и `/about`, каждый запрос направляется строго в свой обработчик.

## Решение по шагам

1. Создадим `mux := http.NewServeMux()`.
2. Зарегистрируем `/home` с описанием главной страницы.
3. Зарегистрируем `/about` с информацией о сервисе.
4. Протестируем оба маршрута.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func main() {
	mux := http.NewServeMux()

	mux.HandleFunc("/home", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "Домашняя страница портала")
	})

	mux.HandleFunc("/about", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "О компании: разрабатываем HighLoad сервисы на Go")
	})

	ts := httptest.NewServer(mux)
	defer ts.Close()

	for _, endpoint := range []string{"/home", "/about"} {
		res, _ := http.Get(ts.URL + endpoint)
		b, _ := io.ReadAll(res.Body)
		res.Body.Close()
		fmt.Printf("%-7s -> %s\n", endpoint, string(b))
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# /home   -> Домашняя страница портала
# /about  -> О компании: разрабатываем HighLoad сервисы на Go
```

## Под капотом

`ServeMux` хранит список шаблонов путей в отсортированном виде и проверяет совпадение через префиксное сканирование.

## Подводные камни

Слэш в конце маршрута имеет значение: `/about/` матчит все пути с префиксом `/about/...` (поддерево), тогда как `/about` требует точного совпадения.

## На собеседовании

**Вопрос с собеседования:** «Что происходит при переходе по URL без замыкающего слэша, если хендлер зарегистрирован со слэшем (например, /images/)?»
**Ответ:** Стандартный `http.ServeMux` автоматически отправляет клиенту постоянный редирект `301 Moved Permanently` с URL `/images` на `/images/`.
