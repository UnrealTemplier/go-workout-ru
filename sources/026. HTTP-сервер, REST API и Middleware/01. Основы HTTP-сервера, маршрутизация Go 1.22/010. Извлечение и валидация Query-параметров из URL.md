# Извлечение и валидация Query-параметров из URL запроса

## Условие

Извлеки query-параметры из входящего запроса: `r.URL.Query().Get("name")`. Выведи приветствие с этим именем.

## Теория

Строка запроса (Query String) передается после знака `?` в формате `k1=v1&k2=v2`. Метод `r.URL.Query()` возвращает тип `url.Values` (`map[string][]string`). Метод `Get(key)` возвращает первое значение параметра или пустую строку `""`, если параметр не был передан.

## Решение по шагам

1. Создадим обработчик `/greet`.
2. Извлечем параметр `name` через `r.URL.Query().Get("name")`.
3. Если имя не задано, используем дефолтное значение `"Гость"`.
4. Протестируем вызовы с параметром и без него.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func greetHandler(w http.ResponseWriter, r *http.Request) {
	name := r.URL.Query().Get("name")
	if name == "" {
		name = "Гость"
	}
	fmt.Fprintf(w, "Добро пожаловать, %s!", name)
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("/greet", greetHandler)

	ts := httptest.NewServer(mux)
	defer ts.Close()

	// Запрос с параметром
	r1, _ := http.Get(ts.URL + "/greet?name=Алексей")
	b1, _ := io.ReadAll(r1.Body)
	r1.Body.Close()
	fmt.Println(string(b1))

	// Запрос без параметра
	r2, _ := http.Get(ts.URL + "/greet")
	b2, _ := io.ReadAll(r2.Body)
	r2.Body.Close()
	fmt.Println(string(b2))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Добро пожаловать, Алексей!
# Добро пожаловать, Гость!
```

## Под капотом

`r.URL.Query()` каждый раз парсит сырую строку `r.URL.RawQuery`. Для оптимизации при многократном чтении параметров в рамках одного запроса результат вызова сохраняют в локальную переменную.

## Подводные камни

Метод `Get()` возвращает только первое значение. Если параметр передан несколько раз (`?tag=go&tag=web`), для получения всех значений нужно обращаться к мапе напрямую: `r.URL.Query()["tag"]`.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между r.URL.Query().Get("key") и r.FormValue("key")?»
**Ответ:** `r.URL.Query()` читает параметры только из строки URL (GET). `r.FormValue("key")` проверяет и строку URL, и тело запроса `application/x-www-form-urlencoded` (POST/PUT), автоматически вызывая `r.ParseMultipartForm` при необходимости.
