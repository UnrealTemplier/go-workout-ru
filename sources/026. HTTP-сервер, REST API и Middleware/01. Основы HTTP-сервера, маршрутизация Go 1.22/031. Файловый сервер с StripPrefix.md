# Файловый сервер с StripPrefix и тестирование защиты от Directory Traversal

## Условие

Напиши **file server**: `http.FileServer(http.Dir("./static"))`. Настрой обработку `/static/` через `http.StripPrefix`. Проверь доступ к файлам, попробуй directory traversal (`../../etc/passwd`) — покажи, что `http.FileServer` защищён от этого.

## Теория

При монтировании файлового сервера на префикс (например, `/static/`) необходимо убирать этот префикс из пути запроса с помощью `http.StripPrefix("/static/", fileServer)`, иначе сервер будет искать файлы по пути `./static/static/file.txt`.
Рантайм Go нормализует путь с помощью `path.Clean` и предотвращает любые попытки выхода за пределы корня через `../`.

## Решение по шагам

1. Создадим тестовую папку `test_static` с файлом `data.txt`.
2. Зарегистрируем маршрут `/static/` с `http.StripPrefix`.
3. Проверим чтение легитимного файла.
4. Отправим запрос с Path Traversal `../../` и убедимся, что он пресекается.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"os"
	"path/filepath"
)

func main() {
	tempDir, _ := os.MkdirTemp("", "sec_static_*")
	defer os.RemoveAll(tempDir)

	_ = os.WriteFile(filepath.Join(tempDir, "data.txt"), []byte("Public Static Content"), 0644)

	mux := http.NewServeMux()
	fileHandler := http.StripPrefix("/static/", http.FileServer(http.Dir(tempDir)))
	mux.Handle("/static/", fileHandler)

	ts := httptest.NewServer(mux)
	defer ts.Close()

	// 1. Легитимный запрос
	res1, _ := http.Get(ts.URL + "/static/data.txt")
	body, _ := io.ReadAll(res1.Body)
	res1.Body.Close()
	fmt.Printf("[GET /static/data.txt] Status: %d, Content: %s\n", res1.StatusCode, string(body))

	// 2. Попытка Directory Traversal
	res2, _ := http.Get(ts.URL + "/static/../../../../etc/passwd")
	res2.Body.Close()
	fmt.Printf("[GET Traversal Attack] Status: %d (Сервер защищен от выхода из корня!)\n", res2.StatusCode)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [GET /static/data.txt] Status: 200, Content: Public Static Content
# [GET Traversal Attack] Status: 404 (Сервер защищен от выхода из корня!)
```

## Под капотом

`http.Dir.Open` проверяет путь через `filepath.Rel` и отклоняет любые пути, начинающиеся с `..` или содержащие ссылки вне базового каталога.

## Подводные камни

Если забыть замыкающий слэш в `http.StripPrefix("/static/", ...)`, префикс будет обрезан некорректно.

## На собеседовании

**Вопрос с собеседования:** «Почему в продакшене отдачу тяжелой статики (картинки, видео) переносят на Nginx или S3/CDN вместо Go FileServer?»
**Ответ:** Nginx использует системный вызов `sendfile()` (zero-copy передача из дискового кэша ядра Linux напрямую в сетевую карту) и снимает нагрузку с рантайма и сборщика мусора Go. CDN кэширует контент на периферии ближе к пользователю.
