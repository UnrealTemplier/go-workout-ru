# Архитектурная концепция Middleware: сигнатура и функция высшего порядка

## Условие

Напишите концепцию Middleware: функцию, которая принимает `http.Handler` и возвращает новый `http.Handler`, оборачивая логику.

## Теория

Middleware в Go — это функция высшего порядка следующей сигнатуры:
`func(http.Handler) http.Handler`
Она декорирует поведение входного обработчика, добавляя логику до и после вызова `next.ServeHTTP`.

## Решение по шагам

1. Создадим тип `type Middleware func(http.Handler) http.Handler`.
2. Напишем тестовое middleware, добавляющее заголовок `X-Powered-By: Golang`.
3. Обернем конечный хендлер.
4. Проверим заголовок в ответе.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

type Middleware func(http.Handler) http.Handler

func HeaderDecoratorMiddleware(headerName, headerVal string) Middleware {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			w.Header().Set(headerName, headerVal)
			next.ServeHTTP(w, r)
		})
	}
}

func main() {
	handler := http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "Core Application Response")
	})

	mw := HeaderDecoratorMiddleware("X-Platform", "Go-Workout-Engine")
	decoratedHandler := mw(handler)

	ts := httptest.NewServer(decoratedHandler)
	defer ts.Close()

	resp, _ := http.Get(ts.URL)
	defer resp.Body.Close()

	fmt.Printf("Статус: %d\n", resp.StatusCode)
	fmt.Printf("X-Platform заголовок: %s\n", resp.Header.Get("X-Platform"))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Статус: 200
# X-Platform заголовок: Go-Workout-Engine
```

## Под капотом

Замыкание удерживает параметры `headerName` и `headerVal`, позволяя создавать параметризованные middleware фабрики.

## Подводные камни

Не изменяйте глобальные переменные внутри функции-обработчика middleware, так как она вызывается конкурентно в сотнях параллельных горутин.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать функцию Chain(middlewares ...Middleware) Middleware для сборки цепочки без вложенных скобок?»
**Ответ:** Написать цикл, сворачивающий срез middleware справа налево:
```go
func Chain(middlewares ...Middleware) Middleware {
    return func(final http.Handler) http.Handler {
        for i := len(middlewares) - 1; i >= 0; i-- {
            final = middlewares[i](final)
        }
        return final
    }
}
```
