# Спецификация роутов Go 1.22+: разграничение методов и PathValue

## Условие

**Новый роутинг (Go 1.22+)**: Начиная с Go 1.22 стандартный роутер стал мощным. Зарегистрируй роут с указанием метода и переменной пути: `mux.HandleFunc("GET /users/{id}", handler)`. Внутри функции достань `id` через `r.PathValue("id")`.

## Теория

Новый роутинг в Go 1.22 решает большинство задач без необходимости сторонних библиотек:
- `"GET /items/{id}"` матчит только GET-запросы.
- `"POST /items"` матчит только POST-запросы.
- Метод `r.PathValue("id")` возвращает сегмент пути по имени метки.

## Решение по шагам

1. Создадим `mux := http.NewServeMux()`.
2. Зарегистрируем `"GET /orders/{order_id}"`.
3. Извлечем значение через `r.PathValue("order_id")`.
4. Отправим проверочный запрос.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func getOrderHandler(w http.ResponseWriter, r *http.Request) {
	orderID := r.PathValue("order_id")
	fmt.Fprintf(w, "Заказ #%s находится в обработке", orderID)
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /orders/{order_id}", getOrderHandler)

	ts := httptest.NewServer(mux)
	defer ts.Close()

	resp, _ := http.Get(ts.URL + "/orders/ORD-7744")
	body, _ := io.ReadAll(resp.Body)
	resp.Body.Close()

	fmt.Printf("Ответ сервера: %s\n", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Ответ сервера: Заказ #ORD-7744 находится в обработке
```

## Под капотом

Под капотом `r.PathValue` обращается к встроенной мапе параметров пути в `http.Request`, которая заполняется роутером в O(1).

## Подводные камни

Имена переменных пути чувствительны к регистру: `{id}` и `{ID}` — разные ключи.

## На собеседовании

**Вопрос с собеседования:** «Как в Go 1.22+ разрешаются конфликты маршрутов (Precedence Rules)?»
**Ответ:** Более точный маршрут всегда имеет больший приоритет над менее точным (Exact match > Path with variable > Wildcard/Subtree). Если два маршрута эквивалентны по специфичности, `ServeMux` запаникует на этапе регистрации.
