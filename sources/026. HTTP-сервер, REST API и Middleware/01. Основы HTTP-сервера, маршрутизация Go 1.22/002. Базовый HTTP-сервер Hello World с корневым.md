# Базовый HTTP-сервер Hello World с корневым обработчиком

## Условие

Запустите HTTP-сервер с одним обработчиком `/`, возвращающим «Hello, World!».

## Теория

Корневой паттерн `/` в стандартном `http.ServeMux` до Go 1.22 работал как catch-all префикс: любой путь, для которого не нашлось более точного совпадения, попадал в обработчик `/`. С Go 1.22 точное совпадение корня можно задать как `/{$}` или проверять `r.URL.Path == "/"`, чтобы не отвечать "Hello, World!" на любые случайные URL.

## Решение по шагам

1. Создадим явный роутер `http.NewServeMux()`.
2. Зарегистрируем функцию для корня `/`.
3. Добавим проверку пути `if r.URL.Path != "/"` для возврата 404 на сторонние пути.
4. Отправим запросы к `/` и `/unknown`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func rootHandler(w http.ResponseWriter, r *http.Request) {
	if r.URL.Path != "/" {
		http.NotFound(w, r)
		return
	}
	fmt.Fprint(w, "Hello, World!")
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("/", rootHandler)

	ts := httptest.NewServer(mux)
	defer ts.Close()

	resp, _ := http.Get(ts.URL + "/")
	body, _ := io.ReadAll(resp.Body)
	resp.Body.Close()
	fmt.Println("[GET /]        Status:", resp.StatusCode, "Body:", string(body))

	resp404, _ := http.Get(ts.URL + "/something")
	resp404.Body.Close()
	fmt.Println("[GET /something] Status:", resp404.StatusCode)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [GET /]        Status: 200 Body: Hello, World!
# [GET /something] Status: 404
```

## Под капотом

В Go `http.NotFound(w, r)` — это вспомогательная функция, вызывающая `http.Error(w, "404 page not found", http.StatusNotFound)`.

## Подводные камни

Если зарегистрировать `mux.HandleFunc("/", ...)` и не проверить `r.URL.Path != "/"`, сервер отдаст 200 OK на любой несуществующий URL (`/api/v1/unknown`, `/favicon.ico` и т.д.).

## На собеседовании

**Вопрос с собеседования:** «Как в Go 1.22+ зарегистрировать строгий корень без catch-all поведения?»
**Ответ:** Использовать паттерн `mux.HandleFunc("GET /{$}", handler)`. Символ `{$}` в Go 1.22 означает конец пути и запрещает совпадение с дочерними маршрутами.
