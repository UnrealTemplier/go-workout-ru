# Прием и сохранение файлов через multipart/form-data с ParseMultipartForm

## Условие

Напиши **upload handler**: `POST /upload`. Парсь `multipart/form-data` через `r.ParseMultipartForm(10 << 20)` (10MB). Сохрани загруженный файл на диск. Верни имя сохранённого файла.

## Теория

Загрузка файлов на сервер:
1. `r.ParseMultipartForm(maxMemory)` парсит тело запроса, удерживая в RAM до `maxMemory` байт, а остальное сбрасывая во временные файлы на диск.
2. `r.FormFile("file")` возвращает интерфейс `multipart.File` и метаданные `*multipart.FileHeader`.
3. Сохранение осуществляется потоковым копированием через `io.Copy(dest, src)`.

## Решение по шагам

1. Создадим обработчик `uploadHandler`.
2. Ограничим лимит 10 МБ.
3. Откроем полученный файл и скопируем в целевой файл в папке `tempDir`.
4. Протестируем загрузку через `multipart.Writer` на стороне клиента.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"mime/multipart"
	"net/http"
	"net/http/httptest"
	"os"
	"path/filepath"
)

func uploadHandler(w http.ResponseWriter, r *http.Request) {
	if r.Method != http.MethodPost {
		http.Error(w, "Метод не поддерживается", http.StatusMethodNotAllowed)
		return
	}

	// 10 МБ в памяти, остальное — во временные файлы
	if err := r.ParseMultipartForm(10 << 20); err != nil {
		http.Error(w, "Ошибка разбора формы", http.StatusBadRequest)
		return
	}

	file, header, err := r.FormFile("avatar")
	if err != nil {
		http.Error(w, "Поле 'avatar' не найдено", http.StatusBadRequest)
		return
	}
	defer file.Close()

	// Сохраняем файл
	outPath := filepath.Join(os.TempDir(), "uploaded_"+header.Filename)
	dst, err := os.Create(outPath)
	if err != nil {
		http.Error(w, "Не удалось сохранить файл", http.StatusInternalServerError)
		return
	}
	defer dst.Close()

	written, _ := io.Copy(dst, file)
	defer os.Remove(outPath)

	w.WriteHeader(http.StatusCreated)
	fmt.Fprintf(w, "Файл %s успешно сохранен (%d байт)", header.Filename, written)
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(uploadHandler))
	defer ts.Close()

	// Клиентская отправка multipart формы
	body := &bytes.Buffer{}
	writer := multipart.NewWriter(body)
	part, _ := writer.CreateFormFile("avatar", "profile.png")
	_, _ = part.Write([]byte("fake png binary data"))
	_ = writer.Close()

	req, _ := http.NewRequest(http.MethodPost, ts.URL, body)
	req.Header.Set("Content-Type", writer.FormDataContentType())

	resp, _ := http.DefaultClient.Do(req)
	respBody, _ := io.ReadAll(resp.Body)
	resp.Body.Close()

	fmt.Printf("[Status] %d\n", resp.StatusCode)
	fmt.Printf("[Response] %s\n", string(respBody))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Status] 201
# [Response] Файл profile.png успешно сохранен (20 байт)
```

## Под капотом

`ParseMultipartForm` создает временные файлы с помощью `os.CreateTemp` в каталоге ОС, если размер файла превышает лимит оперативной памяти.

## Подводные камни

Всегда очищайте ресурсы формы вызовом `r.MultipartForm.RemoveAll()` после завершения обработки, чтобы удалить временные файлы с диска сервера.

## На собеседовании

**Вопрос с собеседования:** «Как обработать загрузку файла размером 50 ГБ без исчерпания памяти и диска сервера?»
**Ответ:** Не вызывать `ParseMultipartForm`. Использовать `r.MultipartReader()`, который построчно читает части формы потоком. При нахождении нужного part копировать его напрямую в S3 хранилище (`s3manager.Upload`) или внешнее хранилище через `io.Copy`.
