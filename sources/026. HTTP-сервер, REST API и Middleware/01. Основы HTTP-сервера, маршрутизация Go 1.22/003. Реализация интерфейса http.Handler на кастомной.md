# Реализация интерфейса http.Handler на кастомной структуре

## Условие

Реализуй интерфейс `http.Handler` на своей структуре (метод `ServeHTTP(w, r)`). Передай эту структуру в `http.ListenAndServe`.

## Теория

Интерфейс `http.Handler` — центральный фундамент всей веб-экосистемы Go:
```go
type Handler interface {
    ServeHTTP(ResponseWriter, *Request)
}
```
Любой тип, реализующий метод `ServeHTTP`, может выступать в качестве сервера, роутера или middleware. Реализация интерфейса на структуре позволяет передавать зависимости (БД, кэш, логгеры, конфигурацию) прямо в поля структуры.

## Решение по шагам

1. Объявим структуру `AppServer` с зависимостями (например, `appName` и `version`).
2. Реализуем метод `ServeHTTP(w http.ResponseWriter, r *http.Request)`.
3. Передадим экземпляр `&AppServer{}` как главный обработчик.
4. Протестируем через `httptest.NewServer`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

type AppServer struct {
	AppName string
	Version string
}

func (s *AppServer) ServeHTTP(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "text/plain; charset=utf-8")
	w.WriteHeader(http.StatusOK)
	fmt.Fprintf(w, "Сервис: %s, Версия: %s, Путь: %s\n", s.AppName, s.Version, r.URL.Path)
}

func main() {
	app := &AppServer{
		AppName: "BillingService",
		Version: "v1.4.2",
	}

	ts := httptest.NewServer(app)
	defer ts.Close()

	resp, err := http.Get(ts.URL + "/health")
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	body, _ := io.ReadAll(resp.Body)
	fmt.Print(string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Сервис: BillingService, Версия: v1.4.2, Путь: /health
```

## Под капотом

`http.Server` внутри цикла приема соединений `Accept()` запускает горутину `go c.serve(connCtx)` и вызывает `server.Handler.ServeHTTP(w, w.req)`. Если `server.Handler == nil`, используется `http.DefaultServeMux`.

## Подводные камни

Экземпляр структуры используется конкурентно всеми входящими горутинами, поэтому поля структуры должны быть неизменяемыми (read-only) либо защищаться мьютексами/атомиками.

## На собеседовании

**Вопрос с собеседования:** «Почему Dependency Injection через структуры с ServeHTTP предпочтительнее глобальных переменных?»
**Ответ:** Передача зависимостей в поля структуры исключает состояние гонки при параллельном тестировании, позволяет легко подменять зависимости моками в тестах и изолировать несколько экземпляров сервисов с разными конфигурациями в одном процессе.
