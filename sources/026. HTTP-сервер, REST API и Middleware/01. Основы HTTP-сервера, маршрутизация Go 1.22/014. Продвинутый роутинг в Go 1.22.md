# Продвинутый роутинг в Go 1.22+: сопоставление метода и переменной пути

## Условие

**[Сложный роутинг (Go 1.22+)]**: Используй новый синтаксис роутинга: `mux.HandleFunc("GET /users/{id}", ...)`. Извлеки `id` из `r.PathValue("id")`.

## Теория

С выходом Go 1.22 стандартный `http.ServeMux` получил революционное обновление:
1. Задание HTTP-метода в начале шаблона: `"GET /path"`, `"POST /path"`.
2. Поддержка параметров в фигурных скобках: `"/users/{id}"`.
3. Поддержка остаточных путей (wildcard): `"/files/{path...}"`.
4. Извлечение через `r.PathValue(name)`.

## Решение по шагам

1. Зарегистрируем `GET /users/{id}`.
2. Зарегистрируем `POST /users/{id}/activate`.
3. Проверим автоматический возврат `405 Method Not Allowed`, если запросить POST на GET-маршрут.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func main() {
	mux := http.NewServeMux()

	mux.HandleFunc("GET /users/{id}", func(w http.ResponseWriter, r *http.Request) {
		id := r.PathValue("id")
		fmt.Fprintf(w, "Профиль пользователя #%s", id)
	})

	mux.HandleFunc("POST /users/{id}/activate", func(w http.ResponseWriter, r *http.Request) {
		id := r.PathValue("id")
		w.WriteHeader(http.StatusOK)
		fmt.Fprintf(w, "Пользователь #%s активирован", id)
	})

	ts := httptest.NewServer(mux)
	defer ts.Close()

	// 1. Успешный GET
	res1, _ := http.Get(ts.URL + "/users/42")
	b1, _ := io.ReadAll(res1.Body)
	res1.Body.Close()
	fmt.Printf("[GET /users/42] %d: %s\n", res1.StatusCode, string(b1))

	// 2. Неверный метод POST на GET-маршрут (автоматический 405 Method Not Allowed!)
	res2, _ := http.Post(ts.URL+"/users/42", "text/plain", nil)
	res2.Body.Close()
	fmt.Printf("[POST /users/42] Ожидается 405 -> Получен: %d %s\n", res2.StatusCode, res2.Status)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [GET /users/42] 200: Профиль пользователя #42
# [POST /users/42] Ожидается 405 -> Получен: 405 405 Method Not Allowed
```

## Под капотом

Если маршрут совпал по пути, но метод не подошел, `ServeMux` автоматически формирует ответ `405 Method Not Allowed` с заголовком `Allow`, перечисляющим разрешенные методы.

## Подводные камни

Синтаксис `"GET /users/{id}"` требует ровно одного пробела между методом и путем.

## На собеседовании

**Вопрос с собеседования:** «Что означает шаблон вида /files/{filepath...} в Go 1.22+?»
**Ответ:** Это подстановочный знак (wildcard), который матчит весь остаток пути включая наклонные черты `/`. Значение извлекается через `r.PathValue("filepath")` (идеально для файловых серверов и проксирования).
