# Клиентский HTTP-запрос к API с проверкой статуса

## Условие

Реализуйте HTTP-клиент, делающий GET-запрос к публичному API (например, `https://api.github.com`) и выводящий статус ответа.

## Теория

Для взаимодействия между микросервисами используется `http.Client`. Надежный клиент всегда настраивает таймаут `Timeout`, проверяет ошибки сети `err != nil` и обязательно закрывает `resp.Body.Close()`.

## Решение по шагам

1. Создадим мок-сервер для имитации внешнего API.
2. Сконфигурируем `http.Client` с таймаутом.
3. Выполним GET-запрос и выведем статус ответа.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

func main() {
	mockAPI := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("X-RateLimit-Remaining", "59")
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte(`{"message": "API Active"}`))
	}))
	defer mockAPI.Close()

	client := &http.Client{
		Timeout: 5 * time.Second,
	}

	resp, err := client.Get(mockAPI.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	fmt.Printf("[Клиент] Ответ получен от: %s\n", mockAPI.URL)
	fmt.Printf("[Клиент] Статус: %d (%s)\n", resp.StatusCode, resp.Status)
	fmt.Printf("[Клиент] Лимит запросов оставшийся: %s\n", resp.Header.Get("X-RateLimit-Remaining"))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Клиент] Ответ получен от: http://127.0.0.1:...
# [Клиент] Статус: 200 (200 OK)
# [Клиент] Лимит запросов оставшийся: 59
```

## Под капотом

`client.Get` оборачивает вызов `client.Do(req)`, инициализируя транспорт `http.Transport` с пулом Keep-Alive соединений.

## Подводные камни

Использование `http.Get` без таймаута в микросервисах может вызвать зависание горутин при сетевом сбое на стороне поставщика API.

## На собеседовании

**Вопрос с собеседования:** «Зачем клиенту вычитывать resp.Body, даже если само тело ответа не нужно?»
**Ответ:** Если не вычитать тело до конца (`io.Copy(io.Discard, resp.Body)`), TCP-соединение не сможет вернуться в пул Keep-Alive и будет разорвано, что заставит следующий запрос открывать новый сокет и делать TLS-хэндшейк заново.
