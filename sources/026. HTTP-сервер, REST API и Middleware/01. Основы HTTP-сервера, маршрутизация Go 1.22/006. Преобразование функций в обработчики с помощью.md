# Преобразование функций в обработчики с помощью адаптера http.HandlerFunc

## Условие

Используй `http.HandlerFunc` для привязки обычной функции к маршруту.

## Теория

`http.HandlerFunc` — это тип-адаптер в стандартной библиотеке Go:
```go
type HandlerFunc func(ResponseWriter, *Request)

func (f HandlerFunc) ServeHTTP(w ResponseWriter, r *Request) {
    f(w, r)
}
```
Он позволяет обычную функцию превратить в интерфейс `http.Handler`. Метод `mux.Handle(pattern, handler)` принимает интерфейс `http.Handler`, поэтому обычную функцию туда передают через приведение типа: `mux.Handle("/path", http.HandlerFunc(myFunc))`.

## Решение по шагам

1. Объявим функцию `greet(w, r)`.
2. Приведем ее к `http.HandlerFunc(greet)`.
3. Зарегистрируем через `mux.Handle("/greet", http.HandlerFunc(greet))`.
4. Проверим вызов через клиент.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func greet(w http.ResponseWriter, r *http.Request) {
	fmt.Fprint(w, "Привет через HandlerFunc адаптер!")
}

func main() {
	mux := http.NewServeMux()

	// Приведение функции к типу http.HandlerFunc, удовлетворяющему интерфейсу http.Handler
	var handler http.Handler = http.HandlerFunc(greet)
	mux.Handle("/greet", handler)

	ts := httptest.NewServer(mux)
	defer ts.Close()

	resp, _ := http.Get(ts.URL + "/greet")
	body, _ := io.ReadAll(resp.Body)
	resp.Body.Close()

	fmt.Printf("[Ответ] %s\n", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Ответ] Привет через HandlerFunc адаптер!
```

## Под капотом

Вызов `mux.HandleFunc(pattern, fn)` внутри себя выполняет ровно то же действие: `mux.Handle(pattern, HandlerFunc(fn))`.

## Подводные камни

Не путайте тип `http.HandlerFunc` (тип-адаптер функции) и метод `mux.HandleFunc` (метод регистрации маршрута на мультиплексоре).

## На собеседовании

**Вопрос с собеседования:** «Зачем нужен адаптер http.HandlerFunc, если есть mux.HandleFunc?»
**Ответ:** `HandlerFunc` позволяет передавать обычные функции в middleware и любые внешние библиотеки, которые ожидают на вход строгий интерфейс `http.Handler` (например, `mux.Handle`, декораторы и цепочки middleware).
