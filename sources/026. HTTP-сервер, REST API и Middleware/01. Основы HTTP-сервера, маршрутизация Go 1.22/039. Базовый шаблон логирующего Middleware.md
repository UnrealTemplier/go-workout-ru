# Базовый шаблон логирующего Middleware на функции-обертке

## Условие

Напиши простейший middleware-функцию: `func LoggingMiddleware(next http.Handler) http.Handler`. Она должна выводить в консоль метод и URL запроса, а затем вызывать `next.ServeHTTP(w, r)`.

## Теория

Базовый паттерн функции Middleware:
```go
func Middleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        // До вызова
        next.ServeHTTP(w, r)
        // После вызова
    })
}
```
Это простейший способ внедрения сквозной функциональности.

## Решение по шагам

1. Реализуем функцию `LoggingMiddleware`.
2. В теле функции выведем `r.Method` и `r.URL.String()`.
3. Делегируем вызов следующему обработчику `next.ServeHTTP(w, r)`.
4. Проверим работу.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func LoggingMiddleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Printf("[Incoming Request] Метод: %s, URL: %s, UserAgent: %s\n",
			r.Method, r.URL.String(), r.UserAgent())
		next.ServeHTTP(w, r)
	})
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("/info", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "Информация о системе")
	})

	loggedMux := LoggingMiddleware(mux)
	ts := httptest.NewServer(loggedMux)
	defer ts.Close()

	resp, _ := http.Get(ts.URL + "/info?debug=true")
	resp.Body.Close()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Incoming Request] Метод: GET, URL: /info?debug=true, UserAgent: Go-http-client/1.1
```

## Под капотом

Адаптер `http.HandlerFunc` оборачивает анонимную функцию в интерфейс `http.Handler` без необходимости создавать отдельную именованную структуру.

## Подводные камни

Не забывайте вызывать `next.ServeHTTP(w, r)`. Если вызов пропущен, цепочка оборвется и клиент зависнет или получит пустой ответ.

## На собеседовании

**Вопрос с собеседования:** «Можно ли мутировать поля r *http.Request внутри Middleware?»
**Ответ:** Прямая мутация полей указателя `*http.Request` не рекомендуется, так как запрос может параллельно обрабатываться или передаваться другим компонентам. Для изменения контекста создают копию через `r.WithContext(ctx)`, а для изменения URL — через `r.Clone(ctx)`.
