# Создание первого обработчика времени с форматом RFC3339

## Условие

Создай обработчик `/time`, который возвращает текущее время в формате `time.Now().Format(time.RFC3339)`.

## Теория

В Go базовый обработчик реализуется через функцию с сигнатурой `func(w http.ResponseWriter, r *http.Request)`. Интерфейс `http.ResponseWriter` используется для отправки заголовков и записи тела ответа клиенту. Стандартный формат `time.RFC3339` (ISO 8601) является общепринятым стандартом передачи временных меток в веб-сервисах и API.

## Решение по шагам

1. Создадим кастомный мультиплексор `mux := http.NewServeMux()`.
2. Зарегистрируем маршрут `/time` через `mux.HandleFunc`.
3. В обработчике отформатируем `time.Now()` в RFC3339 и запишем в `w` через `fmt.Fprint` или `w.Write`.
4. Проверим работу обработчика с помощью `httptest.NewServer`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"time"
)

func timeHandler(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "text/plain; charset=utf-8")
	currentTime := time.Now().Format(time.RFC3339)
	fmt.Fprint(w, currentTime)
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("/time", timeHandler)

	server := httptest.NewServer(mux)
	defer server.Close()

	resp, err := http.Get(server.URL + "/time")
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	body, _ := io.ReadAll(resp.Body)
	fmt.Printf("[Status] %d %s\n", resp.StatusCode, resp.Status)
	fmt.Printf("[Body]   %s\n", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Status] 200 200 OK
# [Body]   2026-09-03T13:48:00+04:00
```

## Под капотом

Когда вызывается `fmt.Fprint(w, ...)`, рантайм `net/http` буферизует запись и, если заголовки еще не были отправлены явно через `WriteHeader`, автоматически вызывает `w.WriteHeader(http.StatusOK)` и вычисляет `Content-Type`, если он не задан.

## Подводные камни

Забытый вызов установки `Content-Type` заставляет Go определять MIME-тип с помощью `http.DetectContentType`, что может быть неэффективно или привести к нежелательному типу данных.

## На собеседовании

**Вопрос с собеседования:** «Почему в микросервисах временные метки передают исключительно в UTC формате RFC3339/ISO 8601?»
**Ответ:** Передача локального времени чревата рассинхронизацией из-за переходов на летнее/зимнее время и разных часовых поясов серверов и клиентов. UTC в стандарте RFC3339 однозначно фиксирует момент времени во вселенной без двусмысленности.
