# Симметричная обработка: десериализация и подтверждение эхо-ответом

## Условие

Отправьте POST-запрос с JSON-телом на свой сервер. Сервер должен распарсить тело в структуру и вернуть её обратно с подтверждением.

## Теория

Паттерн Echo-Validation: сервер принимает запрос, валидирует схему и возвращает обогащенную структуру с подтверждением приема (Acknowledgement).

## Решение по шагам

1. Создадим структуру `OrderRequest { OrderID, Amount, Currency }`.
2. Создадим ответ `OrderAck { OrderRequest, Processed: true, Timestamp }`.
3. Отправим POST-запрос из клиента и распарсим подтверждение.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

type OrderRequest struct {
	OrderID  string  `json:"order_id"`
	Amount   float64 `json:"amount"`
	Currency string  `json:"currency"`
}

type OrderAck struct {
	Order     OrderRequest `json:"order"`
	Processed bool         `json:"processed"`
	Timestamp string       `json:"timestamp"`
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		var req OrderRequest
		if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
			http.Error(w, err.Error(), http.StatusBadRequest)
			return
		}
		defer r.Body.Close()

		ack := OrderAck{
			Order:     req,
			Processed: true,
			Timestamp: time.Now().UTC().Format(time.RFC3339),
		}

		w.Header().Set("Content-Type", "application/json")
		_ = json.NewEncoder(w).Encode(ack)
	}))
	defer ts.Close()

	order := OrderRequest{OrderID: "ORD-9912", Amount: 2450.50, Currency: "RUB"}
	data, _ := json.Marshal(order)

	res, err := http.Post(ts.URL, "application/json", bytes.NewReader(data))
	if err != nil {
		panic(err)
	}
	defer res.Body.Close()

	var ack OrderAck
	_ = json.NewDecoder(res.Body).Decode(&ack)

	fmt.Printf("[Сервер подтвердил заказ] ID: %s | Сумма: %.2f %s | Время: %s\n",
		ack.Order.OrderID, ack.Order.Amount, ack.Order.Currency, ack.Timestamp)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Сервер подтвердил заказ] ID: ORD-9912 | Сумма: 2450.50 RUB | Время: 2026-09-03T09:48:00Z
```

## Под капотом

`bytes.NewReader(data)` реализует `io.Reader`, позволяя отправлять байты в тело запроса без дополнительных копирований.

## Подводные камни

Если не установить `Content-Type: application/json` на клиенте, серверы на других языках или со строгими middleware отклонят запрос с кодом `415 Unsupported Media Type`.

## На собеседовании

**Вопрос с собеседования:** «Как обработать ситуацию, когда клиент шлет заголовок Content-Encoding: gzip?»
**Ответ:** Необходимо проверить заголовок `r.Header.Get("Content-Encoding") == "gzip"`, и если он присутствует, обернуть `r.Body` в `gzip.NewReader(r.Body)` перед передачей в `json.NewDecoder`.
