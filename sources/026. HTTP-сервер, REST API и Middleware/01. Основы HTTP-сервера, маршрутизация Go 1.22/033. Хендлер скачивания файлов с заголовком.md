# Хендлер скачивания файлов с заголовком Content-Disposition attachment

## Условие

Создай обработчик, который скачивает файл клиенту. Установи заголовок `Content-Disposition: attachment; filename="file.txt"` и отправь байты в `w`.

## Теория

Заголовок `Content-Disposition: attachment; filename="..."` указывает веб-браузеру не открывать файл во встроенном просмотрщике, а вызвать системное диалоговое окно «Сохранить файл как...» с заданным именем.

## Решение по шагам

1. Создадим обработчик `/download`.
2. Установим заголовки `Content-Disposition`, `Content-Type` и `Content-Length`.
3. Отправим бинарные или текстовые данные в `w`.
4. Проверим заголовки клиентом.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func downloadHandler(w http.ResponseWriter, r *http.Request) {
	fileContent := []byte("Финансовый отчет за 2026 год. Конфиденциально.")

	w.Header().Set("Content-Disposition", `attachment; filename="report-2026.txt"`)
	w.Header().Set("Content-Type", "text/plain; charset=utf-8")
	w.Header().Set("Content-Length", fmt.Sprintf("%d", len(fileContent)))

	w.WriteHeader(http.StatusOK)
	_, _ = w.Write(fileContent)
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(downloadHandler))
	defer ts.Close()

	resp, _ := http.Get(ts.URL)
	defer resp.Body.Close()

	fmt.Printf("[Status]              %d\n", resp.StatusCode)
	fmt.Printf("[Content-Disposition] %s\n", resp.Header.Get("Content-Disposition"))
	fmt.Printf("[Content-Length]      %s байт\n", resp.Header.Get("Content-Length"))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Status]              200
# [Content-Disposition] attachment; filename="report-2026.txt"
# [Content-Length]      79 байт
```

## Под капотом

Если используется значение `inline` вместо `attachment`, браузер пытается отобразить файл прямо на вкладке (для PDF, PNG, MP4).

## Подводные камни

В именах файлов с не-ASCII символами (кириллица, пробелы) по стандарту RFC 5987 следует использовать кодирование: `filename*=UTF-8''%D0%BE...`.

## На собеседовании

**Вопрос с собеседования:** «Как безопасно отдавать файлы с диска пользователям, защитившись от XSS при загрузке вредоносного HTML?»
**Ответ:** Устанавливать заголовки `Content-Disposition: attachment`, `Content-Type: application/octet-stream` и `X-Content-Type-Options: nosniff`, запрещая браузеру интерпретировать загружаемый файл как исполняемый HTML/JavaScript.
