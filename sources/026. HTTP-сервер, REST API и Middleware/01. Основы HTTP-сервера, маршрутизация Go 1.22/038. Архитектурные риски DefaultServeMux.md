# Архитектурные риски DefaultServeMux и запуск изолированного экземпляра

## Условие

**Мультиплексор (ServeMux)**: Использовать глобальный роутер (`nil` в `ListenAndServe`) — плохая практика (могут вклиниться сторонние пакеты). Создай `mux := http.NewServeMux()`. Зарегистрируй пути на нём и передай `mux` в `ListenAndServe`.

## Теория

Глобальное состояние — источник уязвимостей и сложноуловимых багов. `http.DefaultServeMux` является глобальной переменной пакета `net/http`. Любой сторонний пакет может неявно выполнить `http.HandleFunc("/debug/vars", ...)` при импорте через функцию `init()`.

## Решение по шагам

1. Создадим локальный `mux := http.NewServeMux()`.
2. Зарегистрируем изолированные маршруты.
3. Передадим `mux` в структуру `http.Server`.
4. Проверим запуск.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func main() {
	// Явное создание изолированного роутера
	mux := http.NewServeMux()

	mux.HandleFunc("/api/v1/ping", func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "text/plain")
		fmt.Fprint(w, "pong")
	})

	server := &http.Server{
		Handler: mux, // Никакого nil!
	}

	ts := httptest.NewServer(server.Handler)
	defer ts.Close()

	res, _ := http.Get(ts.URL + "/api/v1/ping")
	defer res.Body.Close()

	fmt.Printf("[Безопасный роутинг] Статус: %d\n", res.StatusCode)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Безопасный роутинг] Статус: 200
```

## Под капотом

Когда в `http.Server{Handler: nil}` передается `nil`, метод `server.Serve` выполняет `handler := server.Handler; if handler == nil { handler = DefaultServeMux }`.

## Подводные камни

Случайный импорт `_ "net/http/pprof"` автоматически открывает профилировщик рантайма Go на `DefaultServeMux`. Если сервер использует глобальный роутер, отладочная информация утекает в сеть.

## На собеседовании

**Вопрос с собеседования:** «Какую опасность несет импорт `_ "net/http/pprof"` при использовании http.DefaultServeMux?»
**Ответ:** Пакет в `init()` регистрирует эндпоинты `/debug/pprof/*` в `DefaultServeMux`. Злоумышленник может скачать дампы памяти кучи (`heap`), стеки горутин (`goroutine`) с паролями и токенами или вызвать DoS профилированием CPU.
