# Строгая десериализация JSON с DisallowUnknownFields для защиты API

## Условие

Напишите хендлер, который принимает JSON в теле запроса, десериализует его в структуру (используйте `json.Decoder` и `DisallowUnknownFields`) и возвращает JSON-ответ.

## Теория

По умолчанию `encoding/json` в Go молча игнорирует неизвестные поля, пришедшие в JSON. Это опасно: опечатка в поле (например, `user_nmae` вместо `username`) оставит поле пустым без сообщения об ошибке. Метод `decoder.DisallowUnknownFields()` заставляет декодер возвращать ошибку при обнаружении любого непредусмотренного схемой поля.

## Решение по шагам

1. Создадим декодер `dec := json.NewDecoder(r.Body)`.
2. Включим строгий режим `dec.DisallowUnknownFields()`.
3. Отправим запрос с лишним полем `admin: true`.
4. Убедимся, что сервер отклонил такой запрос.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

type StrictUser struct {
	Username string `json:"username"`
	Email    string `json:"email"`
}

func strictHandler(w http.ResponseWriter, r *http.Request) {
	defer r.Body.Close()

	dec := json.NewDecoder(r.Body)
	dec.DisallowUnknownFields() // Запрещаем неизвестные поля!

	var user StrictUser
	if err := dec.Decode(&user); err != nil {
		http.Error(w, fmt.Sprintf("Ошибка схемы: %v", err), http.StatusBadRequest)
		return
	}

	w.WriteHeader(http.StatusOK)
	fmt.Fprintf(w, "Пользователь %s успешно принят", user.Username)
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(strictHandler))
	defer ts.Close()

	// Попытка отправить несанкционированное поле "is_admin"
	badJSON := `{"username": "hacker", "email": "h@sec.ru", "is_admin": true}`
	res, _ := http.Post(ts.URL, "application/json", bytes.NewBufferString(badJSON))
	body, _ := io.ReadAll(res.Body)
	res.Body.Close()

	fmt.Printf("[Status] %d\n", res.StatusCode)
	fmt.Printf("[Error]  %s\n", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Status] 400
# [Error]  Ошибка схемы: json: unknown field "is_admin" 
```

## Под капотом

`DisallowUnknownFields` сравнивает ключи JSON с именами экспортируемых полей и их тегами `json:"..."`. Если ключ не найден, парсер прерывается с ошибкой.

## Подводные камни

В микросервисной архитектуре `DisallowUnknownFields` может усложнить эволюцию API, если старые сервисы перестанут принимать ответы с новыми добавленными полями (нарушение Postel's Law).

## На собеседовании

**Вопрос с собеседования:** «Как DisallowUnknownFields защищает от уязвимостей Mass Assignment?»
**Ответ:** Без этой опции злоумышленник может передать скрытые поля вроде `role: "admin"` или `balance: 99999`. Если структура используется повторно или мапится в БД без фильтрации, это может привести к несанкционированному повышению привилегий.
