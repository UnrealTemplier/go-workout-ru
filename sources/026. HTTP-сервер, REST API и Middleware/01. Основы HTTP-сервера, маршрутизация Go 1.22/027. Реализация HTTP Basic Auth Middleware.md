# Реализация HTTP Basic Auth Middleware со стандартом RFC 7617

## Условие

Напиши **HTTP Basic Auth middleware**: проверяй `Authorization: Basic <base64>`. Декодируй через `base64.StdEncoding.DecodeString`. Если логин/пароль неверны — `401` с заголовком `WWW-Authenticate: Basic realm="Restricted"`.

## Теория

HTTP Basic Authentication (RFC 7617) кодирует пару `username:password` в Base64. В стандартной библиотеке Go для этого есть готовый метод `r.BasicAuth()`, который автоматически декодирует заголовок и возвращает пользователя, пароль и булев флаг наличия заголовка.

## Решение по шагам

1. Напишем `BasicAuthMiddleware`.
2. Используем `r.BasicAuth()` для извлечения креденшелов.
3. При несовпадении вернем заголовок `WWW-Authenticate: Basic realm="Restricted"` и код 401.
4. Протестируем вызовы без авторизации и с верным паролем.

## Код решения

**`main.go`**

```go
package main

import (
	"crypto/subtle"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func BasicAuthMiddleware(expectedUser, expectedPass string, next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		user, pass, ok := r.BasicAuth()
		if !ok || subtle.ConstantTimeCompare([]byte(user), []byte(expectedUser)) != 1 ||
			subtle.ConstantTimeCompare([]byte(pass), []byte(expectedPass)) != 1 {
			w.Header().Set("WWW-Authenticate", `Basic realm="Restricted"`)
			http.Error(w, "Unauthorized", http.StatusUnauthorized)
			return
		}
		next.ServeHTTP(w, r)
	})
}

func adminDashboard(w http.ResponseWriter, r *http.Request) {
	fmt.Fprint(w, "Секретная панель управления")
}

func main() {
	handler := BasicAuthMiddleware("admin", "super-secret-pass", http.HandlerFunc(adminDashboard))
	ts := httptest.NewServer(handler)
	defer ts.Close()

	// 1. Без авторизации
	r1, _ := http.Get(ts.URL)
	fmt.Printf("[1. Запрос] Status: %d, Header: %s\n", r1.StatusCode, r1.Header.Get("WWW-Authenticate"))
	r1.Body.Close()

	// 2. С правильной авторизацией
	req, _ := http.NewRequest(http.MethodGet, ts.URL, nil)
	req.SetBasicAuth("admin", "super-secret-pass")
	r2, _ := http.DefaultClient.Do(req)
	b2, _ := io.ReadAll(r2.Body)
	r2.Body.Close()
	fmt.Printf("[2. Запрос] Status: %d, Body: %s\n", r2.StatusCode, string(b2))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [1. Запрос] Status: 401, Header: Basic realm="Restricted"
# [2. Запрос] Status: 200, Body: Секретная панель управления
```

## Под капотом

`subtle.ConstantTimeCompare` предотвращает атаки по времени (Timing Attacks), сравнивая срезы байтов за константное время вне зависимости от того, в каком символе расхождение.

## Подводные камни

Basic Auth передает логин и пароль в открытом виде (Base64 — это кодирование, а не шифрование!). Использование Basic Auth допустимо строго поверх защищенного канала HTTPS.

## На собеседовании

**Вопрос с собеседования:** «Почему строки паролей в middleware сравнивают через subtle.ConstantTimeCompare, а не через оператор ==?»
**Ответ:** Обычное сравнение строк `==` прерывается на первом несовпадающем байте. Измеряя наносекундное время ответа сервера, злоумышленник может посимвольно подобрать правильный пароль. `ConstantTimeCompare` выполняется строго за фиксированное время.
