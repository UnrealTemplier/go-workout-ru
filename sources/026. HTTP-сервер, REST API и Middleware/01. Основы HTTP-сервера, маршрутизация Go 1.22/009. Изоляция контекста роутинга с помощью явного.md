# Изоляция контекста роутинга с помощью явного http.NewServeMux

## Условие

Используйте `http.ServeMux` (созданный явно через `http.NewServeMux()`, а не глобальный `http.DefaultServeMux`) для изоляции роутинга.

## Теория

Использование локальных экземпляров `ServeMux` — ключевой архитектурный паттерн безопасного кода в Go. Каждый микросервис или юнит-тест обязан иметь свой собственный независимый экземпляр роутера, исключая побочные эффекты через глобальное состояние.

## Решение по шагам

1. Создадим два независимых мультиплексора: `adminMux` и `publicMux`.
2. Зарегистрируем на них разные маршруты.
3. Убедимся, что маршруты одного мультиплексора недоступны на другом.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func main() {
	// Публичный роутер
	publicMux := http.NewServeMux()
	publicMux.HandleFunc("/catalog", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "Каталог товаров")
	})

	// Административный роутер
	adminMux := http.NewServeMux()
	adminMux.HandleFunc("/metrics", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "Метрики сервера")
	})

	tsPublic := httptest.NewServer(publicMux)
	defer tsPublic.Close()

	tsAdmin := httptest.NewServer(adminMux)
	defer tsAdmin.Close()

	res1, _ := http.Get(tsPublic.URL + "/catalog")
	res1.Body.Close()
	fmt.Println("PublicServer /catalog:", res1.StatusCode)

	res2, _ := http.Get(tsPublic.URL + "/metrics")
	res2.Body.Close()
	fmt.Println("PublicServer /metrics (должен быть 404):", res2.StatusCode)

	res3, _ := http.Get(tsAdmin.URL + "/metrics")
	res3.Body.Close()
	fmt.Println("AdminServer /metrics:", res3.StatusCode)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# PublicServer /catalog: 200
# PublicServer /metrics (должен быть 404): 404
# AdminServer /metrics: 200
```

## Под капотом

`http.NewServeMux()` выделяет новую структуру `ServeMux` с собственной приватной мапой шаблонов `tree`, полностью изолированной в памяти.

## Подводные камни

Вызов `http.HandleFunc(...)` вместо `mux.HandleFunc(...)` неявно пишет в `DefaultServeMux`, нарушая изоляцию.

## На собеседовании

**Вопрос с собеседования:** «Как в одном бинарнике Go запустить публичный API на порту 8080 и админку/метрики на порту 9090?»
**Ответ:** Создать два разных `ServeMux`: `apiMux` и `adminMux`, привязать их к двум структурам `http.Server{Addr: ":8080", Handler: apiMux}` и `http.Server{Addr: ":9090", Handler: adminMux}`, и запустить каждый сервер в своей отдельной горутине.
