# Потоковая отдача больших файлов через io.Copy с O(1) расходом памяти

## Условие

Напиши **streaming response**: handler читает большой файл и пишет его в `http.ResponseWriter` через `io.Copy`. Не загружай файл целиком в память. Добавь `Content-Type: application/octet-stream` и `Content-Disposition`.

## Теория

Потоковая отдача (Streaming I/O): передача данных чанками фиксированного размера (по 32 КБ) через `io.Copy(w, file)`. Память сервера расходуется в объеме \(O(1)\) независимо от того, весит файл 10 МБ или 100 ГБ.

## Решение по шагам

1. Создадим тестовый файл размером 5 МБ.
2. В обработчике откроем файл через `os.Open`.
3. Установим `Content-Type: application/octet-stream`.
4. Выполним потоковую передачу через `io.Copy(w, file)`.
5. Проверим скачивание клиентом.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"os"
	"path/filepath"
)

func streamHandler(filePath string) http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		f, err := os.Open(filePath)
		if err != nil {
			http.NotFound(w, r)
			return
		}
		defer f.Close()

		stat, _ := f.Stat()
		w.Header().Set("Content-Type", "application/octet-stream")
		w.Header().Set("Content-Disposition", fmt.Sprintf(`attachment; filename="%s"`, filepath.Base(filePath)))
		w.Header().Set("Content-Length", fmt.Sprintf("%d", stat.Size()))

		// Потоковая передача с фиксированным буфером 32КБ (Zero OOM risk!)
		written, err := io.Copy(w, f)
		if err != nil {
			return
		}
		_ = written
	}
}

func main() {
	tmpFile, _ := os.CreateTemp("", "large_*.bin")
	filePath := tmpFile.Name()
	defer os.Remove(filePath)

	// Записываем 2 МБ тестовых данных
	chunk := bytes.Repeat([]byte("A"), 1024*1024*2)
	_, _ = tmpFile.Write(chunk)
	_ = tmpFile.Close()

	ts := httptest.NewServer(streamHandler(filePath))
	defer ts.Close()

	resp, _ := http.Get(ts.URL)
	defer resp.Body.Close()

	// Читаем поток клиентом
	var received bytes.Buffer
	n, _ := io.Copy(&received, resp.Body)

	fmt.Printf("[Stream Test] Успешно скачано: %.2f МБ (%d байт)\n", float64(n)/(1024*1024), n)
	fmt.Printf("[Заголовки]   Content-Type: %s\n", resp.Header.Get("Content-Type"))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Stream Test] Успешно скачано: 2.00 МБ (2097152 байт)
# [Заголовки]   Content-Type: application/octet-stream
```

## Под капотом

`io.Copy` перекачивает данные блоками. Если `w` поддерживает `io.ReaderFrom`, рантайм Go может задействовать оптимизацию Linux `sendfile(2)` для нулевого копирования данных в пользовательское пространство.

## Подводные камни

Если клиент внезапно разорвет соединение во время стриминга, `io.Copy` вернет ошибку `broken pipe` или `connection reset by peer`, которую не следует логировать как критическую ошибку сервера.

## На собеседовании

**Вопрос с собеседования:** «Как системный вызов sendfile(2) ускоряет отдачу файлов по HTTP?»
**Ответ:** `sendfile` копирует страницы данных напрямую из Page Cache диска в буфер сокета сетевой карты ядра Linux. Данные не копируются в память процесса Go и обратно, экономя такты CPU и полосу пропускания оперативной памяти.
