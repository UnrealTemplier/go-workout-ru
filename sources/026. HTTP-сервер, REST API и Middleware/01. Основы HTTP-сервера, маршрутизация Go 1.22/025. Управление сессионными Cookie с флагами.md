# Управление сессионными Cookie с флагами безопасности HttpOnly, Secure и SameSite

## Условие

Реализуйте хендлер, который устанавливает `HttpOnly` и `Secure` Cookie в браузер клиента.

## Теория

Защита аутентификационных сессий требует обязательной установки атрибутов безопасности кук:
- `HttpOnly: true` — запрещает доступ к cookie через JavaScript (`document.cookie`), блокируя кражу сессии при XSS-атаках.
- `Secure: true` — предписывает передавать cookie исключительно по зашифрованному протоколу HTTPS.
- `SameSite: http.SameSiteStrictMode` — защищает от межсайтовой подделки запросов (CSRF).

## Решение по шагам

1. Создадим структуру `http.Cookie` со всеми параметрами безопасности.
2. Вызовем `http.SetCookie(w, &cookie)`.
3. Клиентом прочитаем заголовок `Set-Cookie` из ответа.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

func setSessionHandler(w http.ResponseWriter, r *http.Request) {
	cookie := http.Cookie{
		Name:     "session_token",
		Value:    "xyz789_secure_token",
		Path:     "/",
		Expires:  time.Now().Add(24 * time.Hour),
		MaxAge:   86400,
		HttpOnly: true,                  // Защита от XSS
		Secure:   true,                  // Только HTTPS
		SameSite: http.SameSiteLaxMode,  // Защита от CSRF
	}

	http.SetCookie(w, &cookie)
	w.WriteHeader(http.StatusOK)
	fmt.Fprint(w, "Сессионная кука успешно установлена")
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(setSessionHandler))
	defer ts.Close()

	resp, _ := http.Get(ts.URL)
	defer resp.Body.Close()

	cookies := resp.Cookies()
	for _, c := range cookies {
		fmt.Printf("Кука: %s=%s | HttpOnly: %v | Secure: %v | SameSite: %v\n",
			c.Name, c.Value, c.HttpOnly, c.Secure, c.SameSite)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Кука: session_token=xyz789_secure_token | HttpOnly: true | Secure: true | SameSite: 2
```

## Под капотом

`http.SetCookie` форматирует строку заголовка `Set-Cookie` по спецификации RFC 6265 и добавляет её в `w.Header().Add("Set-Cookie", ...)`.

## Подводные камни

Для удаления куки на клиенте необходимо установить `MaxAge: -1` или истекшую дату в поле `Expires`.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между SameSite=Strict и SameSite=Lax?»
**Ответ:** При `SameSite=Strict` cookie никогда не отправляется при переходе со стороннего сайта (даже по обычной ссылке). При `SameSite=Lax` кука отправляется только при безопасных навигационных переходах верхнего уровня (Top-Level GET navigation), обеспечивая баланс безопасности и UX.
