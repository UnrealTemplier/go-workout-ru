# Валидация подписи на стороне приемника: надежный HTTP-обработчик

## Условие

25. **Валидация подписи на стороне приемника**: Напишите HTTP-обработчик на стороне сервиса-приемника (клиента), который принимает вебхуки от вашей платформы.

### Исходная формулировка

**Валидация подписи на стороне приемника**: Напишите HTTP-обработчик на стороне сервиса-приемника (клиента), который принимает вебхуки от вашей платформы.
* Извлеките временную метку и подпись из заголовков.
* Проверьте, что временная метка отличается от текущего времени не более чем на 5 минут (защита от устаревания запросов).
* Самостоятельно вычислите ожидаемую сигнатуру и сравните её с присланной в заголовке за константное время с помощью `crypto/subtle.ConstantTimeCompare` [578], чтобы предотвратить атаки по времени (Timing Attacks) [578].

## Теория

Приемный HTTP-хэндлер клиентского микросервиса должен быть устойчив к любым типам некорректных запросов:
1. Проверка наличия заголовков `X-Webhook-Timestamp` и `X-Webhook-Signature`.
2. Валидация формата timestamp и проверка допустимого окна расхождения (5 минут).
3. Потоковое чтение `r.Body` с защитой от OOM (`io.LimitReader`).
4. Повторное вычисление подписи и константное по времени сравнение (`subtle.ConstantTimeCompare`).
5. Десериализация JSON только после подтверждения подлинности подписи.
6. Немедленный возврат статуса `200 OK` до начала длительной бизнес-логики (тяжелые задачи ставятся во внутреннюю очередь).

## Решение по шагам

1. Создайте структуру хэндлера `WebhookReceiverHandler` с клиентским секретом.
2. В методе `ServeHTTP` выполните строгую валидацию заголовков, таймстемпа и подписи.
3. При любой ошибке возвращайте информативный код ошибки (`400 Bad Request` или `401 Unauthorized`).
4. Протестируйте хэндлер с помощью `httptest.ResponseRecorder`.

## Код решения

**`robust_receiver_handler.go`**

```go
package main

import (
	"crypto/hmac"
	"crypto/sha256"
	"crypto/subtle"
	"encoding/hex"
	"encoding/json"
	"fmt"
	"io"
	"math"
	"net/http"
	"net/http/httptest"
	"strconv"
	"strings"
	"time"
)

type WebhookReceiverHandler struct {
	secret string
}

func NewWebhookReceiverHandler(secret string) *WebhookReceiverHandler {
	return &WebhookReceiverHandler{secret: secret}
}

func (h *WebhookReceiverHandler) ServeHTTP(w http.ResponseWriter, r *http.Request) {
	if r.Method != http.MethodPost {
		http.Error(w, "Method Not Allowed", http.StatusMethodNotAllowed)
		return
	}

	tsHeader := r.Header.Get("X-Webhook-Timestamp")
	sigHeader := r.Header.Get("X-Webhook-Signature")

	if tsHeader == "" || sigHeader == "" {
		http.Error(w, "Missing security headers", http.StatusBadRequest)
		return
	}

	// 1. Проверка допустимости времени
	reqTime, err := strconv.ParseInt(tsHeader, 10, 64)
	if err != nil {
		http.Error(w, "Invalid timestamp format", http.StatusBadRequest)
		return
	}

	now := time.Now().UTC().Unix()
	if math.Abs(float64(now-reqTime)) > 300 {
		http.Error(w, "Request timestamp expired", http.StatusBadRequest)
		return
	}

	// 2. Чтение тела запроса с ограничением в 512 КБ
	body, err := io.ReadAll(io.LimitReader(r.Body, 512*1024))
	if err != nil {
		http.Error(w, "Error reading body", http.StatusInternalServerError)
		return
	}
	defer r.Body.Close()

	// 3. Вычисление и проверка подписи: HMAC(secret, timestamp + "." + body)
	mac := hmac.New(sha256.New, []byte(h.secret))
	mac.Write([]byte(tsHeader + "."))
	mac.Write(body)
	expectedSig := hex.EncodeToString(mac.Sum(nil))

	cleanSig := strings.TrimPrefix(sigHeader, "sha256=")
	if subtle.ConstantTimeCompare([]byte(cleanSig), []byte(expectedSig)) != 1 {
		http.Error(w, "Signature verification failed", http.StatusUnauthorized)
		return
	}

	// 4. Парсинг валидированного JSON
	var payload map[string]any
	if err := json.Unmarshal(body, &payload); err != nil {
		http.Error(w, "Invalid JSON structure", http.StatusBadRequest)
		return
	}

	fmt.Printf("[Receiver] Webhook verified and accepted: event=%v\n", payload["event"])
	w.WriteHeader(http.StatusOK)
	_, _ = w.Write([]byte(`{"status":"acknowledged"}`))
}

func main() {
	secret := "whsec_client_secret_demo"
	handler := NewWebhookReceiverHandler(secret)

	now := strconv.FormatInt(time.Now().UTC().Unix(), 10)
	body := `{"event":"order.completed","order_id":"ord_8811"}`

	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write([]byte(now + "." + body))
	sig := hex.EncodeToString(mac.Sum(nil))

	req := httptest.NewRequest(http.MethodPost, "/webhook", strings.NewReader(body))
	req.Header.Set("X-Webhook-Timestamp", now)
	req.Header.Set("X-Webhook-Signature", "sha256="+sig)
	rec := httptest.NewRecorder()

	handler.ServeHTTP(rec, req)
	fmt.Printf("HTTP Status: %d | Body: %s\n", rec.Code, rec.Body.String())
}
```

## Под капотом

Сравнение `subtle.ConstantTimeCompare` предотвращает утечку по времени при проверке подписи. Кроме того, чтение тела через `io.LimitReader` выполняется строго до вызова `json.Unmarshal`. Если попытаться распарсить JSON через `json.NewDecoder(r.Body).Decode(&payload)` до проверки HMAC, то злоумышленник сможет устроить DoS атаку на CPU сложными глубоко вложенными объектами без валидной подписи.

## Подводные камни

1. Парсинг JSON до проверки HMAC-подписи: открывает уязвимость для DoS-атак невалидными или гигантскими JSON-структурами. Сначала всегда валидируется подпись!
2. Возврат подробного описания криптографических ошибок наружу: сообщение `expected hex 4a..., got 9b...` дает подсказки злоумышленнику. Возвращайте обезличенное `Signature verification failed`.
3. Забытый `defer r.Body.Close()`: утечка файловых дескрипторов сокетов.

## На собеседовании

**Вопрос (Shopify/Ozon):** Почему приемник вебхуков должен ответить `200 OK` максимально быстро (за < 200 мс), а не выполнять обработку синхронно?
**Ответ:** Платформы отправки вебхуков выставляют жесткие таймауты (обычно 5–10 секунд). Если сервер интегратора начнет синхронно в HTTP-запросе генерировать PDF-счет, отправлять email и делать тяжелые транзакции в БД, запрос отвалится по таймауту платформы. Платформа сочтет доставку неудачной и отправит дубликат! Правильный паттерн: проверить подпись, сохранить payload во внутреннюю очередь (RabbitMQ/Redis/Канал) и мгновенно вернуть 200 OK.
