### Исходная формулировка

**[Верификация (Приемник)]**: Напиши HTTP-сервер, который принимает вебхук. Прочитай тело запроса (`io.ReadAll`), вычисли HMAC и сравни с заголовком. Используй `hmac.Equal` для защиты от тайминг-атак. Если подпись неверна — верни `401 Unauthorized`.

## Теория

Для облегчения интеграции ведущие технологические платформы (Stripe, GitHub, Slack) выпускают официальные библиотеки SDK для различных языков программирования (Go SDK, Python SDK, Java SDK).
В Go каноничная библиотека верификации должна предоставлять простой, идиоматичный и безопасный API:
`event, err := webhook.ConstructEvent(payloadBytes, sigHeader, secret, tolerance)`
Функция скрывает от разработчика интегратора все сложности:
- Парсинг формата `t=...,v1=...`.
- Проверку Clock Skew.
- Безопасное вычисление HMAC с постоянным по времени сравнением (`subtle.ConstantTimeCompare`).
- Десериализацию в типизированную структуру `Event`.

## Решение по шагам

1. Создайте пакет/модуль `webhooksdk`.
2. Реализуйте функцию `ConstructEvent(payload []byte, header string, secret string, tolerance time.Duration) (*Event, error)`.
3. Обеспечьте покрытие крайних случаев: пустой заголовок, поврежденный hex, расхождение времени.
4. Продемонстрируйте использование SDK в клиентском приложении в 3 строки кода.

## Код решения

**`webhook_sdk.go`**

```go
package main

import (
	"crypto/hmac"
	"crypto/sha256"
	"crypto/subtle"
	"encoding/hex"
	"encoding/json"
	"errors"
	"fmt"
	"math"
	"strconv"
	"strings"
	"time"
)

type Event struct {
	ID        string          `json:"id"`
	Type      string          `json:"type"`
	CreatedAt int64           `json:"created_at"`
	Data      json.RawMessage `json:"data"`
}

var (
	ErrNoSignaturesFound = errors.New("no valid v1 signatures found in header")
	ErrInvalidHeader     = errors.New("malformed signature header")
	ErrTooOld            = errors.New("timestamp is outside the tolerance window")
)

// ConstructEvent — эталонный метод Go SDK для безопасной верификации вебхука
func ConstructEvent(payload []byte, sigHeader string, secret string, tolerance time.Duration) (*Event, error) {
	parts := strings.Split(sigHeader, ",")
	var tsStr string
	var signatures []string

	for _, part := range parts {
		kv := strings.SplitN(part, "=", 2)
		if len(kv) != 2 {
			continue
		}
		key, val := strings.TrimSpace(kv[0]), strings.TrimSpace(kv[1])
		if key == "t" {
			tsStr = val
		} else if key == "v1" {
			signatures = append(signatures, val)
		}
	}

	if tsStr == "" || len(signatures) == 0 {
		return nil, ErrInvalidHeader
	}

	ts, err := strconv.ParseInt(tsStr, 10, 64)
	if err != nil {
		return nil, ErrInvalidHeader
	}

	if tolerance > 0 {
		diff := math.Abs(float64(time.Now().UTC().Unix() - ts))
		if diff > tolerance.Seconds() {
			return nil, ErrTooOld
		}
	}

	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write([]byte(tsStr + "."))
	mac.Write(payload)
	expectedMAC := hex.EncodeToString(mac.Sum(nil))

	matched := false
	for _, sig := range signatures {
		if subtle.ConstantTimeCompare([]byte(sig), []byte(expectedMAC)) == 1 {
			matched = true
			break
		}
	}

	if !matched {
		return nil, ErrNoSignaturesFound
	}

	var evt Event
	if err := json.Unmarshal(payload, &evt); err != nil {
		return nil, fmt.Errorf("failed to unmarshal verified payload: %w", err)
	}

	return &evt, nil
}

func main() {
	secret := "whsec_client_sdk_token"
	rawJSON := []byte(`{"id":"evt_554433","type":"customer.subscription.deleted","created_at":1718000000,"data":{"plan":"pro"}}`)
	nowStr := strconv.FormatInt(time.Now().UTC().Unix(), 10)

	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write([]byte(nowStr + "."))
	mac.Write(rawJSON)
	validSig := hex.EncodeToString(mac.Sum(nil))
	header := fmt.Sprintf("t=%s,v1=%s", nowStr, validSig)

	// Использование SDK клиентом:
	event, err := ConstructEvent(rawJSON, header, secret, 5*time.Minute)
	if err != nil {
		panic(err)
	}

	fmt.Println("SDK Verification Succeeded!")
	fmt.Printf("Event ID: %s | Type: %s | Data: %s\n", event.ID, event.Type, string(event.Data))
}
```

ℹ️ Проверка работы SDK

## Под капотом

Использование `json.RawMessage` для поля `Data` в структуре `Event` позволяет библиотеке SDK безопасно распарсить общие поля конверта, оставив доменное тело в виде сырых байт. Разработчик интеграции может впоследствии десериализовать `Data` в свои собственные внутренние структуры бизнес-логики без лишних аллокаций памяти.

## Подводные камни

1. Требование передачи строки `string` вместо слайса байт `[]byte`: в Go преобразование `string(payload)` может аллоцировать память и нарушить байтовую консистентность при невалидном UTF-8.
2. Игнорирование погрешности `tolerance == 0`: для модульных тестов должна быть предусмотрена возможность отключения проверки времени (передачей `tolerance = 0`).
3. Паника при некорректном заголовке: SDK обязан возвращать ошибки `error`, а не паниковать.

## На собеседовании

**Вопрос (Stripe/Shopify):** Почему предоставление официального SDK для верификации подписи вебхуков является критически важным для безопасности экосистемы платформы?
**Ответ:** Более 70% сторонних разработчиков при самостоятельной реализации проверки подписи допускают грубые уязвимости:
1. Сравнивают подписи небезопасным оператором `==` вместо постоянного времени `subtle.ConstantTimeCompare` (Timing Attacks).
2. Забывают проверять Timestamp (уязвимость к Replay Attacks).
3. Сначала парсят JSON, а затем сериализуют обратно перед вычислением HMAC, из-за чего подпись ложно бракуется.
Официальный SDK с методом `ConstructEvent` исключает эти ошибки на корню.
