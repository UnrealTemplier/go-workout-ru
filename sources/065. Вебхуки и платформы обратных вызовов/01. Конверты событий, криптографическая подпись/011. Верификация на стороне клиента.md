# Верификация на стороне клиента: использование hmac.Equal и middleware

## Условие

11. **Верификация на стороне клиента**: Реализуйте Go-клиент, который получает webhook, проверяет timestamp (не старше 5 минут), вычисляет HMAC и сравнивает через `hmac.Equal` (constant-time).

### Исходная формулировка

**Верификация на стороне клиента**: Реализуйте Go-клиент, который получает webhook, проверяет timestamp (не старше 5 минут), вычисляет HMAC и сравнивает через `hmac.Equal` (constant-time).

## Теория

Приемный HTTP-сервис клиента обязан безопасно верифицировать входящие запросы до выполнения бизнес-логики.
В Go стандартный пакет `crypto/hmac` предоставляет функцию `hmac.Equal(mac1, mac2 []byte) bool`.
`hmac.Equal` реализует постоянное по времени сравнение (`subtle.ConstantTimeCompare`), гарантируя защиту от тайминг-атак.
Правильная последовательность действий на стороне получателя:
1. Прочитать `X-Webhook-Timestamp` и проверить разницу с `time.Now().Unix() <= 300s`.
2. Прочитать `X-Webhook-Signature`.
3. Считать всё тело запроса `r.Body`.
4. Вычислить `mac = hmac.New(sha256.New, secret)`. Записать в него `timestamp + "." + body`.
5. Сравнить вычисленный дайджест с декодированным из шестнадцатеричной строки входящим хэшем с помощью `hmac.Equal`.
6. Восстановить `r.Body` для обработчиков бизнес-логики через `io.NopCloser`.

## Решение по шагам

1. Создайте middleware `WebhookAuthMiddleware(secret string) func(http.Handler) http.Handler`.
2. Извлеките заголовки времени и подписи. При их отсутствии верните `401 Unauthorized`.
3. Выполните проверку дельты времени не более 300 секунд.
4. Вычислите HMAC от `timestamp + "." + body` и декодируйте входящий hex-хэш.
5. Вызовите `hmac.Equal(computedSig, incomingSigBytes)` и пропустите запрос дальше при успехе.

## Код решения

**`client_receiver.go`**

```go
package main

import (
	"bytes"
	"crypto/hmac"
	"crypto/sha256"
	"encoding/hex"
	"fmt"
	"io"
	"math"
	"net/http"
	"net/http/httptest"
	"strconv"
	"time"
)

func WebhookAuthMiddleware(secret string) func(http.Handler) http.Handler {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			tsHeader := r.Header.Get("X-Webhook-Timestamp")
			sigHeader := r.Header.Get("X-Webhook-Signature")

			if tsHeader == "" || sigHeader == "" {
				http.Error(w, "Missing security headers", http.StatusUnauthorized)
				return
			}

			// 1. Проверка Clock Skew (до 5 минут)
			ts, err := strconv.ParseInt(tsHeader, 10, 64)
			if err != nil || math.Abs(float64(time.Now().UTC().Unix()-ts)) > 300 {
				http.Error(w, "Timestamp invalid or expired", http.StatusBadRequest)
				return
			}

			// 2. Чтение тела запроса с ограничением
			bodyBytes, err := io.ReadAll(io.LimitReader(r.Body, 1024*1024))
			if err != nil {
				http.Error(w, "Cannot read request body", http.StatusInternalServerError)
				return
			}
			_ = r.Body.Close()

			// 3. Вычисление ожидаемого HMAC
			toSign := []byte(fmt.Sprintf("%s.%s", tsHeader, string(bodyBytes)))
			mac := hmac.New(sha256.New, []byte(secret))
			mac.Write(toSign)
			expectedMAC := mac.Sum(nil)

			// 4. Декодирование входящей hex-подписи
			incomingMAC, err := hex.DecodeString(sigHeader)
			if err != nil || !hmac.Equal(expectedMAC, incomingMAC) {
				http.Error(w, "Invalid HMAC signature", http.StatusUnauthorized)
				return
			}

			// 5. Восстанавливаем Body для целевого хэндлера
			r.Body = io.NopCloser(bytes.NewReader(bodyBytes))
			next.ServeHTTP(w, r)
		})
	}
}

func main() {
	secret := "whsec_client_shared_secret_777"

	handler := WebhookAuthMiddleware(secret)(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		body, _ := io.ReadAll(r.Body)
		fmt.Printf("Business logic executed: %s\n", string(body))
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte(`{"status":"processed"}`))
	}))

	ts := httptest.NewServer(handler)
	defer ts.Close()

	// Тестовый запрос
	now := strconv.FormatInt(time.Now().UTC().Unix(), 10)
	payload := `{"order_id":"123","status":"paid"}`
	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write([]byte(now + "." + payload))
	signature := hex.EncodeToString(mac.Sum(nil))

	req, _ := http.NewRequest(http.MethodPost, ts.URL, bytes.NewReader([]byte(payload)))
	req.Header.Set("X-Webhook-Timestamp", now)
	req.Header.Set("X-Webhook-Signature", signature)

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()
	fmt.Printf("Receiver returned status: %d\n", resp.StatusCode)
}
```

## Под капотом

Функция `hmac.Equal(mac1, mac2)` в исходном коде Go вызывает `subtle.ConstantTimeCompare(mac1, mac2)`. Применение `hmac.Equal` безопаснее ручного сравнения hex-строк, так как устраняет не только тайминг-атаки, но и потенциальные ошибки приведения регистра букв в hex-строках (lowercase vs uppercase).

## Подводные камни

1. Забытое восстановление `r.Body`: без вызова `r.Body = io.NopCloser(bytes.NewReader(bodyBytes))` следующий вызов `json.NewDecoder(r.Body).Decode(...)` вернет ошибку `EOF`.
2. Отсутствие ограничения размера входящего тела (`io.LimitReader`): позволяет злоумышленнику переполнить RAM веб-сервера отправкой HTTP-запроса гигабайтного размера.
3. Проверка подписи после парсинга JSON: если сначала распарсить JSON, а затем сериализовать обратно для проверки HMAC, подпись никогда не сойдется из-за перестановки полей.

## На собеседовании

**Вопрос (Shopify/VK):** Чем отличается `hmac.Equal` от оператора `bytes.Equal`?
**Ответ:** `bytes.Equal` оптимизирован на максимальную скорость выполнения с использованием векторных SIMD-инструкций ассемблера и завершает работу на первом же байте, который отличается (`early exit`). Это делает `bytes.Equal` критически уязвимым к Timing Attacks в криптографических проверках. `hmac.Equal` гарантирует постоянное время выполнения независимо от содержимого байтов.
