# Простая распределенная блокировка на Redis с использованием go-redis/v9

## Условие

### Исходная формулировка

**Простая распределенная блокировка на Redis (один экземпляр).**: Реализуйте блокировку с `SET NX PX`, используя `go-redis`. Захватите блокировку с уникальным токеном (UUID), выполните критическую секцию, освободите с проверкой токена (Lua-скрипт).

## Теория

Промышленный шаблон реализации распределенного мьютекса с использованием официального драйвера `github.com/redis/go-redis/v9`:

Ключевые методы `go-redis/v9`:
1. **Захват блокировки**:
   ```go
   ok, err := rdb.SetNX(ctx, key, token, ttl).Result()
   ```
   - Метод возвращает булево значение: `true`, если ключ был успешно записан, `false`, если ключ уже существовал.
2. **Освобождение блокировки через `Eval`**:
   ```go
   const unlockScript = `
       if redis.call("get", KEYS[1]) == ARGV[1] then
           return redis.call("del", KEYS[1])
       else
           return 0
       end`
   res, err := rdb.Eval(ctx, unlockScript, []string{key}, token).Result()
   ```
   - Проверяет равенство токена и атомарно удаляет ключ.
   - Использование `rdb.EvalSha` с предварительным хешированием скрипта через `ScriptLoad` снижает сетевой трафик.

## Решение по шагам

1. Создайте структуру `RedisLockManager` с клиентом `*redis.Client` (или моком).
2. Реализуйте метод `Acquire(ctx, key, ttl)` с генерацией UUIDv4.
3. Реализуйте метод `Release(ctx, key, token)` через атомарный Lua-скрипт.
4. Продемонстрируйте исполнение критической секции под защитой мьютекса.
5. Проверьте возврат ошибки при попытке освобождения просроченного или чужого ключа.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"crypto/rand"
	"encoding/hex"
	"errors"
	"fmt"
	"sync"
	"time"
)

var (
	ErrLockHeld = errors.New("lock already held by another instance")
)

type GoRedisMock struct {
	mu   sync.Mutex
	data map[string]string
	exp  map[string]time.Time
}

func NewGoRedisMock() *GoRedisMock {
	return &GoRedisMock{
		data: make(map[string]string),
		exp:  make(map[string]time.Time),
	}
}

// Emulates rdb.SetNX(ctx, key, val, ttl)
func (r *GoRedisMock) SetNX(ctx context.Context, key string, val any, expiration time.Duration) (bool, error) {
	select {
	case <-ctx.Done():
		return false, ctx.Err()
	default:
	}

	r.mu.Lock()
	defer r.mu.Unlock()

	now := time.Now()
	if expireAt, exists := r.exp[key]; exists && now.After(expireAt) {
		delete(r.data, key)
		delete(r.exp, key)
	}

	if _, exists := r.data[key]; exists {
		return false, nil // key exists, not acquired
	}

	r.data[key] = fmt.Sprintf("%v", val)
	r.exp[key] = now.Add(expiration)
	return true, nil
}

// Emulates rdb.Eval(ctx, unlockScript, []string{key}, val)
func (r *GoRedisMock) Eval(ctx context.Context, script string, keys []string, args ...any) (int64, error) {
	select {
	case <-ctx.Done():
		return 0, ctx.Err()
	default:
	}

	r.mu.Lock()
	defer r.mu.Unlock()

	key := keys[0]
	token := fmt.Sprintf("%v", args[0])

	if r.data[key] == token {
		delete(r.data, key)
		delete(r.exp, key)
		return 1, nil
	}
	return 0, nil
}

type SimpleRedisLock struct {
	client *GoRedisMock
	key    string
	token  string
	ttl    time.Duration
}

func AcquireSimpleLock(ctx context.Context, client *GoRedisMock, key string, ttl time.Duration) (*SimpleRedisLock, error) {
	b := make([]byte, 16)
	_, _ = rand.Read(b)
	token := hex.EncodeToString(b)

	ok, err := client.SetNX(ctx, key, token, ttl)
	if err != nil {
		return nil, err
	}
	if !ok {
		return nil, ErrLockHeld
	}

	return &SimpleRedisLock{
		client: client,
		key:    key,
		token:  token,
		ttl:    ttl,
	}, nil
}

func (l *SimpleRedisLock) Release(ctx context.Context) error {
	const unlockScript = `if redis.call("get",KEYS[1]) == ARGV[1] then return redis.call("del",KEYS[1]) else return 0 end`
	res, err := l.client.Eval(ctx, unlockScript, []string{l.key}, l.token)
	if err != nil {
		return err
	}
	if res == 0 {
		return errors.New("lock release failed: token mismatch or expired")
	}
	return nil
}

func main() {
	rdb := NewGoRedisMock()
	ctx := context.Background()
	lockKey := "lock:inventory:sku-404"

	fmt.Println("--- 1. Acquiring Lock with go-redis style API ---")
	lock, err := AcquireSimpleLock(ctx, rdb, lockKey, 5*time.Second)
	if err != nil {
		panic(err)
	}
	fmt.Printf("✅ Lock acquired! Resource: '%s', Token: %s\n", lock.key, lock.token)

	// Critical section
	fmt.Println("Performing safe inventory decrement under lock...")
	time.Sleep(50 * time.Millisecond)

	// Release lock
	if err := lock.Release(ctx); err != nil {
		fmt.Println("Release error:", err)
	} else {
		fmt.Println("✅ Lock released cleanly.")
	}

	// Try release again -> should fail
	err = lock.Release(ctx)
	fmt.Printf("Second release attempt correctly failed: %v\n", err)
}
```

## Под капотом

Оптимизация сетевых пакетов:
В `go-redis/v9` для исполнения Lua-скриптов используется обертка `redis.NewScript(src)`.
Метод `script.Run(ctx, rdb, keys, args...)` сначала автоматически пытается выполнить команду `EVALSHA <sha1>`.
Если Redis отвечает ошибкой `NOSCRIPT No matching script`, клиент прозрачно загружает скрипт на сервер через `EVAL` и кеширует SHA1. Это исключает передачу сырого текста скрипта по сети при каждом вызове `Release`.

## Подводные камни

- **Отсутствие `defer lock.Release(ctx)`**: Любая паника или ранний `return` оставит ключ в Redis до истечения TTL, замедляя конвейер.
- **Использование `context.Background()` для снятия**: При шатдауне сервиса контекст может быть уже отменен. Для операции `Release` часто используют отдельный короткий контекст `ctx, cancel := context.WithTimeout(context.Background(), 2*time.Second)`.

## На собеседовании

В Lamoda и Ozon на собеседовании Senior Go разработчика часто спрашивают: *«Как в `go-redis` корректно освободить распределенную блокировку в функции с `defer`, если родительский контекст запроса уже отменен по таймауту?»*
**Ответ**: Если передать в `Release(ctx)` уже отмененный родительский контекст, вызов `rdb.Eval` мгновенно вернет ошибку `context canceled` и даже не отправит сетевой пакет в Redis! Ключ останется заблокированным до истечения TTL. Правильный паттерн в `defer`:
```go
defer func() {
    unlockCtx, cancel := context.WithTimeout(context.Background(), 2*time.Second)
    defer cancel()
    _ = lock.Release(unlockCtx)
}()
```
Это гарантирует отправку команды разблокировки через новый чистый контекст.
