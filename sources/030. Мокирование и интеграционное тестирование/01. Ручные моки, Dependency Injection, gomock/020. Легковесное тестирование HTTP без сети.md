# Легковесное тестирование HTTP без сети: HealthHandler и httptest.ResponseRecorder

## Условие

Напиши HTTP-обработчик `HealthHandler(w http.ResponseWriter, r *http.Request)`. В тесте используй `httptest.NewRequest("GET", "/health", nil)` и `httptest.NewRecorder()`. Вызови обработчик и проверь статус-код 200.

## Теория

Стандартный пакет `net/http/httptest`:
- `httptest.NewRequest(method, url, body)` создает имитацию клиентского HTTP-запроса.
- `httptest.NewRecorder()` создает структуру `*ResponseRecorder`, которая буферизирует статус-код, заголовки и тело в памяти.
- Скорость: выполнение занимает менее 1 микросекунды (в 1000 раз быстрее, чем поднятие реального TCP сокета).

## Решение по шагам

1. Создайте хэндлер `HealthHandler`.
2. В тесте сформируйте `GET /health`.
3. Передайте `rec` и `req` в хэндлер.
4. Проверьте `rec.Code == 200`.

## Код решения

**`health.go`**

```go
package main

import (
	"fmt"
	"net/http"
)

func HealthHandler(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(http.StatusOK)
	fmt.Fprint(w, `{"status":"ok","uptime":"ready"}`)
}
```

ℹ️ HTTP эндпоинт проверки здоровья сервиса

**`health_test.go`**

```go
package main

import (
	"net/http"
	"net/http/httptest"
	"testing"
)

func TestHealthHandler(t *testing.T) {
	req := httptest.NewRequest(http.MethodGet, "/health", nil)
	rec := httptest.NewRecorder()

	HealthHandler(rec, req)

	if rec.Code != http.StatusOK {
		t.Fatalf("Status = %d; want 200 OK", rec.Code)
	}

	expected := `{"status":"ok","uptime":"ready"}`
	if rec.Body.String() != expected {
		t.Errorf("Body = %q; want %q", rec.Body.String(), expected)
	}
}
```

ℹ️ In-memory тестирование HTTP обработчика

**`Терминал`**

```bash
go test -v health_test.go health.go
# Вывод:
# === RUN   TestHealthHandler
# --- PASS: TestHealthHandler (0.00s)
# PASS
```

## Под капотом

`httptest.ResponseRecorder` реализует интерфейс `http.ResponseWriter`. При вызове `WriteHeader(code)` он сохраняет число в поле `Code`, а при вызове `Write(b)` пишет байты в `bytes.Buffer`.

## Подводные камни

Забыть вызвать метод `HealthHandler(rec, req)`: частая ошибка новичков — создать рекордер и сразу проверять `rec.Code` (он будет равен дефолтному 200, даже если хэндлер ничего не сделал).

## На собеседовании

**Вопрос с собеседования:** «Какой дефолтный HTTP код у ResponseRecorder, если хэндлер вообще не вызвал WriteHeader?»
**Ответ:** По спецификации `http.ResponseWriter` в Go, если `WriteHeader` не был вызван явно, но был вызван `Write()`, статус-код автоматически считается равным `http.StatusOK` (200). Если хэндлер не вызвал ни `Write`, ни `WriteHeader`, `rec.Code` также равен 200.
