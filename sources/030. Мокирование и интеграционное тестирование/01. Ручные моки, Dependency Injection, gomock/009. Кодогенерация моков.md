# Кодогенерация моков: утилита mockgen и генерация MockCache для интерфейса

## Условие

Установи `go install github.com/golang/mock/mockgen@latest`. Создай интерфейс `Cache` с методами `Get(key string) (string, error)`, `Set(key, value string, ttl time.Duration) error`. Сгенерируй мок: `mockgen -source=cache.go -destination=mock_cache.go -package=mocks`.

## Теория

Библиотека `gomock` (исторически `github.com/golang/mock`, сейчас поддерживается как `go.uber.org/mock`):
- Официальный промышленный стандарт кодогенерации моков в экосистеме Go.
- Утилита `mockgen` анализирует AST-дерево интерфейса и генерирует строго типизированный код мока с методами `EXPECT()`.
- Исключает человеческий фактор: при изменении сигнатуры интерфейса запуск `go generate` автоматически перегенерирует моки.

## Решение по шагам

1. Создайте файл `cache.go` с интерфейсом `Cache`.
2. Добавьте директиву `//go:generate mockgen ...`.
3. Ознакомьтесь с архитектурой сгенерированного файла `mock_cache.go`.

## Код решения

**`cache.go`**

```go
package main

import "time"

//go:generate mockgen -source=cache.go -destination=mocks/mock_cache.go -package=mocks

type Cache interface {
	Get(key string) (string, error)
	Set(key, value string, ttl time.Duration) error
}
```

ℹ️ Интерфейс с директивой go:generate для mockgen

**`Терминал`**

```bash
# Установка утилиты mockgen:
go install go.uber.org/mock/mockgen@latest

# Генерация мока:
mockgen -source=cache.go -destination=mock_cache.go -package=main
# Файл mock_cache.go создан! Он содержит структуру MockCache с методами EXPECT()
```

## Под капотом

`mockgen` поддерживает два режима работы:
1. **Source mode (`-source=cache.go`):** парсит исходный `.go` файл как обычный текст через синтаксический анализатор Go.
2. **Reflect mode (`mockgen package_name InterfaceName`):** компилирует временную программу с рефлексией типов, что позволяет генерировать моки для интерфейсов из внешних библиотек.

## Подводные камни

Коммитить устаревшие сгенерированные моки: если интерфейс изменился, а мок не перегенерирован, CI упадет с ошибкой компиляции. В CI включают линтер проверки свежести генерации.

## На собеседовании

**Вопрос с собеседования:** «Почему проект github.com/golang/mock перешел в статус deprecated и переместился в go.uber.org/mock?»
**Ответ:** Команда Google прекратила активную поддержку репозитория `golang/mock` в 2023 году. Сообщество и компания Uber взяли на себя дальнейшее развитие проекта под именем `go.uber.org/mock`, обеспечив поддержку дженериков Go 1.18+ и оптимизацию скорости генерации.
