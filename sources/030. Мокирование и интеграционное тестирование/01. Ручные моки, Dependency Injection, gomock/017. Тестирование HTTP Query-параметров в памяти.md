# Тестирование HTTP Query-параметров в памяти: httptest.NewRequest и r.URL.Query

## Условие

Напиши тест для handler'а с query-параметрами: `req := httptest.NewRequest("GET", "/search?q=test", nil)`. Проверь, что handler корректно парсит `r.URL.Query()`.

## Теория

Тестирование HTTP GET запросов с фильтрами поиска:
- Утилита `httptest.NewRequest(method, target, body)` создает полноценный объект `*http.Request`.
- Парсинг query-параметров происходит стандартным методом `r.URL.Query().Get("q")`.
- `httptest.NewRecorder()` перехватывает сгенерированный HTTP-ответ в памяти без открытия реальных сокетов.

## Решение по шагам

1. Напишите HTTP-хэндлер `SearchHandler(w http.ResponseWriter, r *http.Request)`.
2. Создайте запрос `httptest.NewRequest("GET", "/search?q=golang&limit=10", nil)`.
3. Вызовите хэндлер с рекордером.
4. Проверьте тело ответа.

## Код решения

**`search_handler.go`**

```go
package main

import (
	"fmt"
	"net/http"
)

func SearchHandler(w http.ResponseWriter, r *http.Request) {
	query := r.URL.Query().Get("q")
	if query == "" {
		http.Error(w, "параметр q обязателен", http.StatusBadRequest)
		return
	}

	limit := r.URL.Query().Get("limit")
	if limit == "" {
		limit = "20" // дефолт
	}

	w.WriteHeader(http.StatusOK)
	fmt.Fprintf(w, "Поиск: %s (лимит: %s)", query, limit)
}
```

ℹ️ Обработчик поиска с query-параметрами

**`search_handler_test.go`**

```go
package main

import (
	"net/http"
	"net/http/httptest"
	"testing"
)

func TestSearchHandlerQueryParams(t *testing.T) {
	// Создаем запрос с query параметрами
	req := httptest.NewRequest(http.MethodGet, "/search?q=golang&limit=5", nil)
	rec := httptest.NewRecorder()

	SearchHandler(rec, req)

	if rec.Code != http.StatusOK {
		t.Fatalf("Status = %d; want 200", rec.Code)
	}

	expectedBody := "Поиск: golang (лимит: 5)"
	if rec.Body.String() != expectedBody {
		t.Errorf("Body = %q; want %q", rec.Body.String(), expectedBody)
	}
}
```

## Под капотом

`httptest.NewRequest` парсит переданный URL через `url.ParseRequestURI()`, формируя структуру `url.URL` со всеми сырыми строками запроса `RawQuery`.

## Подводные камни

Забывать кодировать специальные символы (пробелы, `&`, кириллицу) в query-строке: для генерации сложных URL используйте `url.Values` и метод `.Encode()`.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между r.URL.Query().Get("key") и r.FormValue("key")?»
**Ответ:** `r.URL.Query().Get()` парсит ТОЛЬКО строку запроса из URL. `r.FormValue()` парсит как URL query-параметры, так и тело POST-запроса с типом `application/x-www-form-urlencoded`, что может привести к непреднамеренному смешиванию данных.
