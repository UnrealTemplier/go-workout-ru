# Тестирование цепочки логирования: интеграция LoggingMiddleware и HealthHandler

## Условие

**[Тестирование мидлвара]**: Напиши middleware для логирования. Оберни им `HealthHandler` в тесте и убедись, что запрос проходит через цепочку.

## Теория

Структурированное тестирование полного пайплайна обработки:
- Реальный HTTP-хэндлер оборачивается в middleware логирования.
- Middleware перехватывает время выполнения и статус-код.
- Тест проверяет, что тело ответа не повредилось и дошло до клиента, а в журнал была сделана запись.

## Решение по шагам

1. Создайте `LoggingMiddleware` с записью в буфер.
2. Оберните `HealthHandler`.
3. Отправьте запрос и проверьте успешность прохождения.

## Код решения

**`log_mw.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"net/http"
	"time"
)

func BuildLoggingMiddleware(logBuf *bytes.Buffer) func(http.Handler) http.Handler {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			start := time.Now()
			next.ServeHTTP(w, r)
			fmt.Fprintf(logBuf, "[LOG] %s %s completed in %v\n", r.Method, r.URL.Path, time.Since(start))
		})
	}
}
```

ℹ️ Middleware логирования с выводом в перехватываемый буфер

**`log_mw_test.go`**

```go
package main

import (
	"bytes"
	"net/http"
	"net/http/httptest"
	"strings"
	"testing"
)

func TestLoggingMiddlewareIntegration(t *testing.T) {
	logBuffer := new(bytes.Buffer)
	loggingMW := BuildLoggingMiddleware(logBuffer)

	// Оборачиваем HealthHandler
	pipeline := loggingMW(http.HandlerFunc(HealthHandler))

	req := httptest.NewRequest(http.MethodGet, "/health", nil)
	rec := httptest.NewRecorder()

	pipeline.ServeHTTP(rec, req)

	// 1. Проверяем HTTP статус
	if rec.Code != http.StatusOK {
		t.Fatalf("Status = %d; want 200", rec.Code)
	}

	// 2. Проверяем лог
	logOutput := logBuffer.String()
	if !strings.Contains(logOutput, "[LOG] GET /health") {
		t.Errorf("В логе отсутствует запись: %s", logOutput)
	}
}
```

## Под капотом

Передача `bytes.Buffer` в фабрику `BuildLoggingMiddleware` позволяет тесту валидировать форматирование логов без перехвата глобального `os.Stdout`.

## Подводные камни

Использовать глобальный `log.Println`: тесты невозможно запустить параллельно из-за общего состояния вывода.

## На собеседовании

**Вопрос с собеседования:** «Как логировать тело POST запроса в Middleware, если r.Body можно прочитать только один раз?»
**Ответ:** Прочитать тело через `io.ReadAll(r.Body)`, залогировать, а затем восстановить `r.Body = io.NopCloser(bytes.NewBuffer(bodyBytes))` перед вызовом `next.ServeHTTP`.
