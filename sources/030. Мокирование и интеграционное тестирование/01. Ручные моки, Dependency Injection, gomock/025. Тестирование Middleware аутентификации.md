# Тестирование Middleware аутентификации: отсечка 401 Unauthorized и пропуск с Bearer

## Условие

Протестируйте обработчик с middleware (логирование, аутентификация): проверьте, что middleware добавляет заголовок или блокирует запрос без токена.

## Теория

Тестирование Auth Middleware:
- Проверяет наличие заголовка `Authorization: Bearer <token>`.
- Если заголовок отсутствует или токен невалиден: немедленный ответ HTTP 401 Unauthorized, вызов `next.ServeHTTP` блокируется.
- Если токен валиден: данные пользователя извлекаются и кладутся в контекст запроса `r.Context()`, управление передается дальше.

## Решение по шагам

1. Напишите `AuthMiddleware(next http.Handler) http.Handler`.
2. Протестируйте запрос без токена (ожидается 401).
3. Протестируйте запрос с валидным токеном (ожидается 200).

## Код решения

**`auth_middleware.go`**

```go
package main

import (
	"net/http"
	"strings"
)

func AuthMiddleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		authHeader := r.Header.Get("Authorization")
		if authHeader == "" || !strings.HasPrefix(authHeader, "Bearer ") {
			http.Error(w, "Unauthorized: missing bearer token", http.StatusUnauthorized)
			return
		}

		token := strings.TrimPrefix(authHeader, "Bearer ")
		if token != "secret-token-123" {
			http.Error(w, "Forbidden: invalid token", http.StatusForbidden)
			return
		}

		next.ServeHTTP(w, r)
	})
}
```

ℹ️ Middleware проверки токена авторизации

**`auth_middleware_test.go`**

```go
package main

import (
	"net/http"
	"net/http/httptest"
	"testing"
)

func TestAuthMiddlewareSecurity(t *testing.T) {
	dummyNext := http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte("ACCESS_GRANTED"))
	})

	securedHandler := AuthMiddleware(dummyNext)

	// 1. Тест: Запрос без заголовка Authorization -> 401 Unauthorized
	t.Run("без токена", func(t *testing.T) {
		req := httptest.NewRequest(http.MethodGet, "/secure", nil)
		rec := httptest.NewRecorder()

		securedHandler.ServeHTTP(rec, req)

		if rec.Code != http.StatusUnauthorized {
			t.Errorf("Status = %d; want 401 Unauthorized", rec.Code)
		}
	})

	// 2. Тест: Запрос с валидным токеном -> 200 OK
	t.Run("с валидным токеном", func(t *testing.T) {
		req := httptest.NewRequest(http.MethodGet, "/secure", nil)
		req.Header.Set("Authorization", "Bearer secret-token-123")
		rec := httptest.NewRecorder()

		securedHandler.ServeHTTP(rec, req)

		if rec.Code != http.StatusOK {
			t.Errorf("Status = %d; want 200 OK", rec.Code)
		}
		if rec.Body.String() != "ACCESS_GRANTED" {
			t.Errorf("Body = %q; want ACCESS_GRANTED", rec.Body.String())
		}
	})
}
```

## Под капотом

Тест проверяет защитный барьер (Guard): при ошибке 401 тело `dummyNext` даже не начинает выполняться, защищая бизнес-логику от неавторизованного доступа.

## Подводные камни

Забыть написать `return` после вызова `http.Error(w, ...)`: выполнение продолжится, и `next.ServeHTTP` все равно вызовется!

## На собеседовании

**Вопрос с собеседования:** «Как передать извлеченные данные пользователя (ID, роли) из Auth Middleware в целевой хэндлер?»
**Ответ:** Через контекст запроса с типизированным ключом:
```go
type contextKey struct{}
ctx := context.WithValue(r.Context(), contextKey{}, userClaims)
next.ServeHTTP(w, r.WithContext(ctx))
```
