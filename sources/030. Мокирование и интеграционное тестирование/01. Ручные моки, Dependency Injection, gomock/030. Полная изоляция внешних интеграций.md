# Полная изоляция внешних интеграций: подмена внешних API через httptest.NewServer

## Условие

**[Высокая сложность]**: Создай фейковый сервер с помощью `httptest.NewServer`. Напиши HTTP-клиент, который делает запрос к этому серверу. В тесте используй фейковый сервер вместо реального внешнего API.

## Теория

Паттерн Fake External API Server:
- Сервер мокирует весь жизненный цикл внешнего REST API (авторизация по токену, пагинация, обработка ошибок).
- Клиентская библиотека выполняет реальные сетевые вызовы к локальному сокету.
- Тест проверяет поведение системы в боевых условиях без затрат на внешнюю инфраструктуру.

## Решение по шагам

1. Создайте фейковый сервер с проверкой токена `Bearer`.
2. Реализуйте клиент с отправкой токена.
3. Проверьте обработку успешных ответов и ошибок 401.

## Код решения

**`crm_client.go`**

```go
package main

import (
	"errors"
	"fmt"
	"net/http"
)

type CRMClient struct {
	endpoint string
	apiKey   string
}

func NewCRMClient(endpoint, apiKey string) *CRMClient {
	return &CRMClient{endpoint: endpoint, apiKey: apiKey}
}

func (c *CRMClient) SyncContact(contactID string) error {
	req, err := http.NewRequest(http.MethodPost, c.endpoint+"/contacts/sync", nil)
	if err != nil {
		return err
	}
	req.Header.Set("X-API-Key", c.apiKey)

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		return err
	}
	defer resp.Body.Close()

	if resp.StatusCode == http.StatusUnauthorized {
		return errors.New("невалидный API ключ CRM")
	}
	if resp.StatusCode != http.StatusOK {
		return fmt.Errorf("CRM ошибка: HTTP %d", resp.StatusCode)
	}
	return nil
}
```

ℹ️ Клиент синхронизации с внешней CRM

**`crm_client_test.go`**

```go
package main

import (
	"net/http"
	"net/http/httptest"
	"testing"
)

func TestCRMClientSync(t *testing.T) {
	// Фейковый сервер внешней CRM системы
	fakeCRM := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if r.Header.Get("X-API-Key") != "valid-crm-secret" {
			http.Error(w, "invalid key", http.StatusUnauthorized)
			return
		}
		w.WriteHeader(http.StatusOK)
	}))
	t.Cleanup(fakeCRM.Close)

	// Тест 1: Успешная синхронизация
	clientOk := NewCRMClient(fakeCRM.URL, "valid-crm-secret")
	if err := clientOk.SyncContact("contact-42"); err != nil {
		t.Fatalf("SyncContact failed: %v", err)
	}

	// Тест 2: Ошибка авторизации
	clientBad := NewCRMClient(fakeCRM.URL, "wrong-key")
	if err := clientBad.SyncContact("contact-42"); err == nil {
		t.Fatal("Ожидалась ошибка авторизации для неверного ключа")
	}
}
```

## На собеседовании

**Вопрос с собеседования:** «Как протестировать клиент, если внешний сервис возвращает chunked transfer encoding (потоковый ответ)?»
**Ответ:** В обработчике `httptest.NewServer` использовать приведение к `http.Flusher`:
`flusher, _ := w.(http.Flusher); w.Write(chunk); flusher.Flush()`
Это сбрасывает фрагменты данных в сеть немедленно, имитируя потоковую передачу данных (Server-Sent Events / SSE или gRPC-Web).
