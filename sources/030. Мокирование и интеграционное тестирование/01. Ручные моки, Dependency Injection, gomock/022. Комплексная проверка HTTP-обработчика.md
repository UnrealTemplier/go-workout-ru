# Комплексная проверка HTTP-обработчика: статус, заголовки и тело через httptest

## Условие

Напишите тест для HTTP-обработчика с использованием `httptest.NewRecorder` и `httptest.NewRequest`. Проверьте статус и тело ответа.

## Теория

При тестировании REST эндпоинтов важно проверять триаду HTTP-ответа:
1. **Status Code:** точный код согласно стандартам REST (200, 201, 400, 404, 500).
2. **Headers:** `Content-Type: application/json`, CORS-заголовки, токены кэширования.
3. **Payload:** семантическая корректность сериализованной структуры JSON.

## Решение по шагам

1. Создайте обработчик `GetUserProfileHandler`.
2. Обработайте случай успешного ответа.
3. Проверьте статус, Content-Type и JSON в тесте.

## Код решения

**`user_api.go`**

```go
package main

import (
	"encoding/json"
	"net/http"
)

type UserDTO struct {
	ID    int    `json:"id"`
	Email string `json:"email"`
}

func GetUserProfileHandler(w http.ResponseWriter, r *http.Request) {
	user := UserDTO{ID: 7, Email: "user7@yandex.ru"}

	w.Header().Set("Content-Type", "application/json; charset=utf-8")
	w.WriteHeader(http.StatusOK)
	_ = json.NewEncoder(w).Encode(user)
}
```

ℹ️ Обработчик отдачи профиля

**`user_api_test.go`**

```go
package main

import (
	"encoding/json"
	"net/http"
	"net/http/httptest"
	"strings"
	"testing"
)

func TestGetUserProfileHandlerComplete(t *testing.T) {
	req := httptest.NewRequest(http.MethodGet, "/api/v1/user", nil)
	rec := httptest.NewRecorder()

	GetUserProfileHandler(rec, req)

	// 1. Статус код
	if rec.Code != http.StatusOK {
		t.Fatalf("Status = %d; want 200", rec.Code)
	}

	// 2. Заголовки
	ct := rec.Header().Get("Content-Type")
	if !strings.HasPrefix(ct, "application/json") {
		t.Errorf("Content-Type = %q; want application/json", ct)
	}

	// 3. Тело ответа
	var u UserDTO
	if err := json.Unmarshal(rec.Body.Bytes(), &u); err != nil {
		t.Fatalf("Невалидный JSON ответа: %v", err)
	}
	if u.ID != 7 || u.Email != "user7@yandex.ru" {
		t.Errorf("Неверные данные пользователя: %+v", u)
	}
}
```

## Под капотом

`rec.Body.Bytes()` возвращает срез байт напрямую из внутреннего буфера, позволяя декодировать JSON без конвертации в промежуточную строку `string(b)`.

## Подводные камни

Использовать строковое сравнение `rec.Body.String() == "..."` с жесткими переводами строк `\n`, добавляемыми `json.NewEncoder`.

## На собеседовании

**Вопрос с собеседования:** «Почему json.NewEncoder добавляет символ перевода строки \n в конце вывода?»
**Ответ:** Чтобы при потоковой передаче нескольких JSON-объектов подряд через TCP сокет (формат NDJSON / JSON Lines) клиент мог легко разделять объекты построчно через `bufio.Scanner`.
