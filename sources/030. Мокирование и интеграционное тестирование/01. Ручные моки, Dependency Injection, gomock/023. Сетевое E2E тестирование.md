# Сетевое E2E тестирование: реальный сервер httptest.NewServer на случайном порту

## Условие

Напиши **end-to-end HTTP тест**: `httptest.NewServer(handler)`. Сделай реальный `http.Get(server.URL + "/path")`. Проверь статус и тело. Покажи, что сервер слушает на `127.0.0.1:random-port`.

## Теория

Различие между `httptest.NewRecorder` и `httptest.NewServer`:
- `ResponseRecorder`: вызывает функцию в памяти напрямую без открытия сетевых портов.
- `httptest.NewServer(handler)`:
  1. Запускает **полноценный реальный HTTP сервер** в фоновой горутине.
  2. Операционная система выделяет свободный случайный порт (Ephemeral Port) на `127.0.0.1`.
  3. Сервер доступен по адресу `server.URL` (например `http://127.0.0.1:42189`).
  4. Запросы проходят полный сетевой стек ОС (TCP рукопожатие, HTTP-парсинг, буферы сокетов).
  5. Обязательное закрытие через `defer server.Close()` или `t.Cleanup(server.Close)`.

## Решение по шагам

1. Запустите `server := httptest.NewServer(handler)`.
2. Зарегистрируйте закрытие в `t.Cleanup()`.
3. Отправьте запрос через `http.Get(server.URL + "/ping")`.
4. Проверьте сетевой ответ.

## Код решения

**`e2e_server_test.go`**

```go
package main

import (
	"io"
	"net/http"
	"net/http/httptest"
	"testing"
)

func PingPongHandler(w http.ResponseWriter, r *http.Request) {
	w.WriteHeader(http.StatusOK)
	_, _ = w.Write([]byte("PONG"))
}

func TestE2EHTTPServer(t *testing.T) {
	// Поднимаем реальный HTTP-сервер на случайном свободном порту loopback
	server := httptest.NewServer(http.HandlerFunc(PingPongHandler))
	t.Cleanup(server.Close)

	t.Logf("Тестовый HTTP-сервер слушает на реальном сокете: %s", server.URL)

	// Выполняем реальный сетевой HTTP-запрос
	resp, err := http.Get(server.URL + "/ping")
	if err != nil {
		t.Fatalf("Сетевой запрос провален: %v", err)
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		t.Errorf("StatusCode = %d; want 200", resp.StatusCode)
	}

	body, err := io.ReadAll(resp.Body)
	if err != nil {
		t.Fatalf("Ошибка чтения тела ответа: %v", err)
	}

	if string(body) != "PONG" {
		t.Errorf("Body = %q; want PONG", string(body))
	}
}
```

## Под капотом

`httptest.NewServer` открывает сокет `net.Listen("tcp", "127.0.0.1:0")`. Порт `0` сигнализирует ядру ОС Linux/macOS выделить любой свободный непривилегированный порт из диапазона 32768–60999, полностью исключая конфликты портов при параллельном запуске тестов.

## Подводные камни

Забыть закрыть `resp.Body.Close()`: утечка дескрипторов сокетов и памяти в пуле соединений `http.DefaultClient`.

## На собеседовании

**Вопрос с собеседования:** «Когда нужно использовать httptest.NewServer вместо ResponseRecorder?»
**Ответ:** Когда тестируется сам HTTP-клиент (Retry логика, парсинг редиректов, поддержка mTLS, сжатие Gzip, кастомные RoundTripper), либо когда клиентский SDK является черным ящиком и принимает только базовый URL сервиса.
