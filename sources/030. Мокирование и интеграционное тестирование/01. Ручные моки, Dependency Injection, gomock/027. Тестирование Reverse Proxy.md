# Тестирование Reverse Proxy: проксирование запросов через httptest и httputil

## Условие

Напиши тест для **reverse proxy**: `httptest.NewServer(httputil.NewSingleHostReverseProxy(targetURL))`. Проверь, что запрос проксируется на target и ответ возвращается.

### Исходная формулировка

Напиши тест для **reverse proxy**: `httptest.NewServer(httputil.NewSingleHostReverseProxy(targetURL))`. Проверь, что запрос проксируется на target и ответ возвращается.

## Теория

Тестирование обратного прокси (Reverse Proxy / API Gateway):
- В микросервисах API Gateway маршрутизирует трафик на бэкенд-сервисы.
- Стандартная библиотека Go содержит готовый компонент `net/http/httputil.NewSingleHostReverseProxy(targetURL)`.
- Для изолированного тестирования поднимают **два** сервера `httptest.NewServer`:
  1. `backendServer`: эмулирует целевой сервис.
  2. `proxyServer`: запускает Reverse Proxy, перенаправляющий трафик на URL бэкенда.
- Клиент отправляет запрос в прокси и проверяет корректность прозрачного проброса.

## Решение по шагам

1. Поднимите целевой сервер `backendServer` с возвратом `"Hello from Backend"`.
2. Создайте прокси через `httputil.NewSingleHostReverseProxy(backendURL)`.
3. Поднимите `proxyServer`.
4. Отправьте запрос на прокси и убедитесь в получении ответа бэкенда.

## Код решения

**`proxy_test.go`**

```go
package main

import (
	"io"
	"net/http"
	"net/http/httptest"
	"net/http/httputil"
	"net/url"
	"testing"
)

func TestReverseProxyForwarding(t *testing.T) {
	// 1. Целевой сервер (Backend)
	backendServer := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("X-Backend-Processed", "true")
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte("Ответ бэкенд-сервера"))
	}))
	t.Cleanup(backendServer.Close)

	// 2. Создаем Reverse Proxy на адрес бэкенда
	backendURL, err := url.Parse(backendServer.URL)
	if err != nil {
		t.Fatalf("Ошибка парсинга URL бэкенда: %v", err)
	}
	proxy := httputil.NewSingleHostReverseProxy(backendURL)

	// 3. Сервер прокси
	proxyServer := httptest.NewServer(proxy)
	t.Cleanup(proxyServer.Close)

	// 4. Клиент делает запрос на прокси
	resp, err := http.Get(proxyServer.URL + "/api/orders")
	if err != nil {
		t.Fatalf("Запрос к прокси упал: %v", err)
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		t.Fatalf("StatusCode = %d; want 200", resp.StatusCode)
	}

	if resp.Header.Get("X-Backend-Processed") != "true" {
		t.Error("Заголовок бэкенда не был проброшен через прокси!")
	}

	body, _ := io.ReadAll(resp.Body)
	if string(body) != "Ответ бэкенд-сервера" {
		t.Errorf("Получено тело %q; want Ответ бэкенд-сервера", string(body))
	}
}
```

## Под капотом

`httputil.ReverseProxy` автоматически модифицирует заголовки `X-Forwarded-For`, очищает hop-by-hop заголовки (Connection, Keep-Alive) и выполняет двунаправленный стриминг тела запроса и ответа.

## Подводные камни

Забывать закрывать оба сервера `httptest.NewServer`: всегда регистрируйте `t.Cleanup()` для каждого поднятого тестового сервера.

## На собеседовании

**Вопрос с собеседования:** «Как в httputil.ReverseProxy модифицировать ответ бэкенда до отдачи клиенту?»
**Ответ:** С помощью поля `proxy.ModifyResponse = func(resp *http.Response) error`. Внутри функции можно добавлять или удалять заголовки безопасности, логировать статус или подменять тело ответа при ошибках.
