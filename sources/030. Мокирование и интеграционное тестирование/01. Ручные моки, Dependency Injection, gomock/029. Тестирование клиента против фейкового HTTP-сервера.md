# Тестирование клиента против фейкового HTTP-сервера с фиксированным JSON

## Условие

Создайте тестовый HTTP-сервер с `httptest.NewServer`, который возвращает фиксированный JSON. Напишите клиента и протестируйте его работу, направляя запросы на тестовый сервер.

## Теория

Изоляция интеграционных тестов HTTP-клиента:
- Если клиент запрашивает внешний API (например `https://api.weather.com`), тест зависит от интернета, квот и доступности чужого сервера.
- Решение: клиент принимает `baseURL string` в конструкторе.
- В тесте создается `httptest.NewServer` с заготовленным JSON-ответом, адрес которого передается в клиент.

## Решение по шагам

1. Создайте структуру клиента `WeatherClient`.
2. Поднимите `httptest.NewServer` с фиксированным ответом погоды.
3. Передайте `server.URL` в конструктор клиента.
4. Проверьте парсинг данных клиентом.

## Код решения

**`weather_client.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
)

type WeatherData struct {
	City        string  `json:"city"`
	Temperature float64 `json:"temperature"`
}

type WeatherClient struct {
	baseURL    string
	httpClient *http.Client
}

func NewWeatherClient(baseURL string) *WeatherClient {
	return &WeatherClient{
		baseURL:    baseURL,
		httpClient: &http.Client{Timeout: 2 * time.Second},
	}
}

func (c *WeatherClient) GetTemperature(city string) (float64, error) {
	url := fmt.Sprintf("%s/weather?city=%s", c.baseURL, city)
	resp, err := c.httpClient.Get(url)
	if err != nil {
		return 0, err
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		return 0, fmt.Errorf("сервер вернул статус %d", resp.StatusCode)
	}

	var data WeatherData
	if err := json.NewDecoder(resp.Body).Decode(&data); err != nil {
		return 0, err
	}
	return data.Temperature, nil
}
```

ℹ️ Клиент с настраиваемым базовым URL

**`weather_client_test.go`**

```go
package main

import (
	"net/http"
	"net/http/httptest"
	"testing"
	"time"
)

func TestWeatherClient_GetTemperature(t *testing.T) {
	// Поднимаем фейковый сервер погоды
	fakeServer := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if r.URL.Query().Get("city") != "Moscow" {
			http.Error(w, "город не найден", http.StatusNotFound)
			return
		}

		w.Header().Set("Content-Type", "application/json")
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte(`{"city":"Moscow","temperature":21.5}`))
	}))
	t.Cleanup(fakeServer.Close)

	client := NewWeatherClient(fakeServer.URL)
	temp, err := client.GetTemperature("Moscow")

	if err != nil {
		t.Fatalf("GetTemperature failed: %v", err)
	}
	if temp != 21.5 {
		t.Errorf("temp = %v; want 21.5", temp)
	}
}
```

## На собеседовании

**Вопрос с собеседования:** «Как протестировать HTTPS клиент с проверкой сертификатов на тестовом сервере?»
**Ответ:** Использовать `server := httptest.NewTLSServer(handler)`. Тестовый сервер генерирует самоподписанный TLS-сертификат, а клиент настраивают через `client := server.Client()`, который уже содержит корневой сертификат тестового сервера в доверенном хранилище `RootCAs`.
