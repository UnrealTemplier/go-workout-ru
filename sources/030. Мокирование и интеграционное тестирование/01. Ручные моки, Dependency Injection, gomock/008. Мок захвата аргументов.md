# Мок захвата аргументов: фиксация параметров вызова EmailSender

## Условие

Напиши `MockEmailSender` (просто структуру, которая записывает аргументы в свои поля и возвращает `nil`). Используй его в тесте для `UserService`.

## Теория

Захват аргументов (Argument Captor):
Когда метод интерфейса не возвращает данных (`error` или `void`), проверка его корректности возможна только через валидацию переданных аргументов.
Структура мока сохраняет аргументы в свои поля:
`type MockEmailSender struct { CapturedTo string; CapturedSubject string }`
Тест проверяет правильность формирования текста письма бизнес-логикой сервиса.

## Решение по шагам

1. Объявите интерфейс `EmailSender`.
2. Создайте `MockEmailSender`, сохраняющий получателя и тему.
3. Напишите метод сервиса отправки уведомления о смене пароля.
4. Проверьте корректность сформированных аргументов.

## Код решения

**`email_sender.go`**

```go
package main

import "fmt"

type EmailSender interface {
	Send(to, subject, body string) error
}

type AccountService struct {
	mailer EmailSender
}

func NewAccountService(m EmailSender) *AccountService {
	return &AccountService{mailer: m}
}

func (s *AccountService) ResetPassword(userEmail, resetToken string) error {
	subject := "Восстановление пароля"
	body := fmt.Sprintf("Ваш токен безопасности: %s", resetToken)
	return s.mailer.Send(userEmail, subject, body)
}
```

ℹ️ Сервис аккаунтов с отправкой писем

**`email_sender_test.go`**

```go
package main

import (
	"strings"
	"testing"
)

type MockEmailSender struct {
	CapturedTo      string
	CapturedSubject string
	CapturedBody    string
}

func (m *MockEmailSender) Send(to, subject, body string) error {
	m.CapturedTo = to
	m.CapturedSubject = subject
	m.CapturedBody = body
	return nil
}

func TestAccountService_ResetPasswordPayload(t *testing.T) {
	mockMailer := &MockEmailSender{}
	svc := NewAccountService(mockMailer)

	token := "xyz-987-secret"
	err := svc.ResetPassword("admin@company.ru", token)
	if err != nil {
		t.Fatalf("ResetPassword failed: %v", err)
	}

	// Проверяем захваченные аргументы
	if mockMailer.CapturedTo != "admin@company.ru" {
		t.Errorf("CapturedTo = %q; want admin@company.ru", mockMailer.CapturedTo)
	}
	if mockMailer.CapturedSubject != "Восстановление пароля" {
		t.Errorf("CapturedSubject = %q; want Восстановление пароля", mockMailer.CapturedSubject)
	}
	if !strings.Contains(mockMailer.CapturedBody, token) {
		t.Errorf("Тело письма не содержит токена безопасности: %q", mockMailer.CapturedBody)
	}
}
```

## Под капотом

Захват аргументов позволяет валидировать соответствие бизнес-требованиям безопасности: например, что секретные токены не выводятся в открытом виде в логи или что ссылки содержат HTTPS.

## Подводные камни

Использовать одно поле для захвата, если метод вызывается несколько раз в цикле: последнее значение перезапишет предыдущие. Для множественных вызовов сохраняйте срез структур: `[]CallRecord`.
