# Проверка тела ответа через recorder.Body.String и буферизацию

## Условие

В тесте из предыдущего задания проверь тело ответа с помощью `recorder.Body.String()`.

## Теория

Инспекция тела ответа в тестах:
- `recorder.Body` — это указатель на `*bytes.Buffer`.
- Метод `recorder.Body.String()` возвращает все накопленные байты ответа в виде строки.
- Это позволяет легко проверять точные тексты ошибок (например `"Unauthorized: missing bearer token\n"`).

## Решение по шагам

1. Вызовите защищенный хэндлер без авторизации.
2. Считайте тело ошибки через `rec.Body.String()`.
3. Проверьте точный текст сообщения об ошибке.

## Код решения

**`body_inspect_test.go`**

```go
package main

import (
	"net/http"
	"net/http/httptest"
	"strings"
	"testing"
)

func TestAuthErrorMessageBody(t *testing.T) {
	dummyNext := http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {})
	handler := AuthMiddleware(dummyNext)

	req := httptest.NewRequest(http.MethodGet, "/admin", nil)
	rec := httptest.NewRecorder()

	handler.ServeHTTP(rec, req)

	// Проверяем точное тело ошибки через recorder.Body.String()
	body := rec.Body.String()
	expectedFragment := "Unauthorized: missing bearer token"

	if !strings.Contains(body, expectedFragment) {
		t.Errorf("Тело ответа %q не содержит ожидаемого сообщения %q", body, expectedFragment)
	}
}
```

## Под капотом

`rec.Body.String()` не очищает буфер (в отличие от чтения через `io.ReadAll(rec.Body)`), поэтому к `rec.Body.String()` можно безопасно обращаться несколько раз подряд в одном тесте.

## Подводные камни

Функция `http.Error()` автоматически добавляет в конец сообщения символ переноса строки `\n`. Сравнение `rec.Body.String() == "text"` упадет; используйте `strings.TrimSpace(rec.Body.String())` или `strings.Contains()`.

## На собеседовании

**Вопрос с собеседования:** «Почему повторный вызов io.ReadAll(rec.Body) возвращает пустой срез байт?»
**Ответ:** Потому что `bytes.Buffer` реализует интерфейс `io.Reader`, сдвигая внутренний указатель чтения до конца буфера (`off == len(buf)`). При повторном чтении буфер сообщает `io.EOF`.
