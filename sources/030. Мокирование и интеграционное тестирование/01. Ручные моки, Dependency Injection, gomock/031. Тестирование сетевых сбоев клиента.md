# Тестирование сетевых сбоев клиента: эмуляция HTTP 500 и обрыва TCP соединения

## Условие

Проверьте поведение клиента при ошибках сети: используйте `httptest.NewServer` с обработчиком, который закрывает соединение или возвращает 500.

## Теория

Тестирование отказоустойчивости (Fault Injection):
Клиент должен корректно реагировать на два типа сбоев:
1. **Протокольные ошибки (HTTP 500/502/504):** сервер отвечает, но сообщает о внутренней ошибке.
2. **Низкоуровневые сетевые катастрофы (TCP Reset / Drop):** соединение разрывается до отправки заголовков. В Go для принудительного сброса сокета используют `hijacker, ok := w.(http.Hijacker); conn, _, _ := hijacker.Hijack(); conn.Close()`.

## Решение по шагам

1. Поднимите сервер с возвратом HTTP 500.
2. Поднимите сервер с аварийным закрытием сокета через Hijacker.
3. Проверьте, что клиент возвращает типизированные ошибки.

## Код решения

**`fault_injection_test.go`**

```go
package main

import (
	"net/http"
	"net/http/httptest"
	"testing"
)

func TestClientHandles500Error(t *testing.T) {
	// 1. Эмуляция ошибки HTTP 500
	server500 := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		http.Error(w, "Внутренний сбой СУБД", http.StatusInternalServerError)
	}))
	t.Cleanup(server500.Close)

	resp, err := http.Get(server500.URL)
	if err != nil {
		t.Fatalf("Сетевой запрос провалился: %v", err)
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusInternalServerError {
		t.Errorf("StatusCode = %d; want 500", resp.StatusCode)
	}
}

func TestClientHandlesAbruptTCPClose(t *testing.T) {
	// 2. Эмуляция внезапного обрыва TCP соединения через Hijack
	crashServer := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		hj, ok := w.(http.Hijacker)
		if !ok {
			t.Fatal("Сервер не поддерживает интерфейс Hijacker")
		}
		conn, _, _ := hj.Hijack()
		_ = conn.Close() // Аварийный разрыв сокета без отправки HTTP заголовков!
	}))
	t.Cleanup(crashServer.Close)

	_, err := http.Get(crashServer.URL)
	if err == nil {
		t.Fatal("Ожидалась сетевая ошибка EOF при обрыве сокета, получен nil")
	}
	t.Logf("Успешно зафиксирован сетевой сбой: %v", err)
}
```

ℹ️ Тестирование обработки протокольных ошибок и обрыва сокетов


## Под капотом

Метод `http.Hijacker.Hijack()` отбирает управление низкоуровневым TCP соединением `net.Conn` у HTTP-сервера, позволяя сымитировать падение процесса сервера (Kernel Panic, OOM Killer) с немедленным закрытием сокета.

## Подводные камни

Считать, что `err != nil` возвращается при ответе HTTP 500: метод `http.Get()` возвращает `err == nil`, если HTTP-протокол был соблюден, а статус-код 500 находится внутри `resp.StatusCode`!

## На собеседовании

**Вопрос с собеседования:** «В каких случаях вызов http.Client.Do() возвращает ненулевую ошибку err != nil?»
**Ответ:** Только при физических сбоях сетевого стека: DNS резолвинг не удался, отказ в TCP подключении (Connection Refused), обрыв соединения (EOF / Connection Reset by Peer), превышение таймаута (Deadline Exceeded) или невалидный URL. Любой ответ сервера (даже 404 или 500) возвращает `err == nil`.
