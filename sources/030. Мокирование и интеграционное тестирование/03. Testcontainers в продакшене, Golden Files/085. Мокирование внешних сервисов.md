# Мокирование внешних сервисов: эмуляция Telegram Bot API через httptest.Server

## Условие

**Мокирование внешнего API (`httptest.Server`)**: Твой код делает запросы к стороннему API (например, к Telegram). В тесте создай `ts := httptest.NewServer(http.HandlerFunc(func(w, r) { w.Write([]byte(`{"status": "ok"}`)) }))`. Переопредели URL в твоем клиенте на `ts.URL`. Теперь код делает реальные HTTP-запросы, но обращается к твоему локальному тестовому серверу.

## Теория

Тестирование интеграции с Telegram Bot API:
- Продакшн URL: `https://api.telegram.org/bot<token>/sendMessage`.
- Если обращаться к реальному API, тесты требуют реального бота, спамят в чаты и падают при блокировках сети.
- **Решение:**
  1. `ts := httptest.NewServer(...)` перехватывает POST-запросы.
  2. Клиент настраивается адресом `ts.URL`.
  3. Проверяется форматирование сообщения, parse_mode (Markdown/HTML) и chat_id.

## Решение по шагам

1. Создайте `TelegramClient` с параметром `apiURL`.
2. Запустите `httptest.NewServer` с эмуляцией ответа Telegram.
3. Отправьте тестовое сообщение.
4. Проверьте тело запроса и статус ответа.

## Код решения

**`telegram_bot.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"strings"
)

type SendMessagePayload struct {
	ChatID string `json:"chat_id"`
	Text   string `json:"text"`
}

type TelegramClient struct {
	apiBaseURL string
	botToken   string
}

func NewTelegramClient(apiBaseURL, token string) *TelegramClient {
	return &TelegramClient{apiBaseURL: apiBaseURL, botToken: token}
}

func (c *TelegramClient) SendAlert(chatID, text string) error {
	url := fmt.Sprintf("%s/bot%s/sendMessage", c.apiBaseURL, c.botToken)
	payload, _ := json.Marshal(SendMessagePayload{ChatID: chatID, Text: text})

	resp, err := http.Post(url, "application/json", strings.NewReader(string(payload)))
	if err != nil {
		return err
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		return fmt.Errorf("telegram API error: %d", resp.StatusCode)
	}
	return nil
}
```

**`telegram_bot_test.go`**

```go
package main

import (
	"encoding/json"
	"net/http"
	"net/http/httptest"
	"testing"
)

func TestTelegramClientSendAlert(t *testing.T) {
	// Поднимаем локальный мок-сервер Telegram
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if r.URL.Path != "/botsecret-token/sendMessage" {
			http.Error(w, "invalid token endpoint", http.StatusUnauthorized)
			return
		}

		var payload SendMessagePayload
		_ = json.NewDecoder(r.Body).Decode(&payload)

		if payload.ChatID != "123456" || payload.Text != "Пожар на проде!" {
			http.Error(w, "bad payload", http.StatusBadRequest)
			return
		}

		w.Header().Set("Content-Type", "application/json")
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte(`{"ok": true, "result": {"message_id": 999}}`))
	}))
	t.Cleanup(ts.Close)

	client := NewTelegramClient(ts.URL, "secret-token")
	err := client.SendAlert("123456", "Пожар на проде!")

	if err != nil {
		t.Fatalf("SendAlert failed: %v", err)
	}
}
```

## Под капотом

Тест проверяет формирование точного URL `/bot<token>/sendMessage` и сериализацию структуры `SendMessagePayload` без реального взаимодействия с серверами Telegram.

## Подводные камни

Оставлять хардкод `https://api.telegram.org` в коде клиента: всегда выносите базовый URL в конфигурируемое поле структуры.
