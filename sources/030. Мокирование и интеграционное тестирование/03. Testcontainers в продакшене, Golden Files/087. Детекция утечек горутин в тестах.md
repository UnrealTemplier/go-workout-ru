# Детекция утечек горутин в тестах: библиотека go.uber.org/goleak и VerifyNone

## Условие

**Проверка утечек горутин (`goleak`)**: Установите библиотеку `go.uber.org/goleak`. Напишите функцию, которая запускает горутину и по ошибке оставляет её висеть в заблокированном состоянии навсегда (утечка) [355]. Напишите unit-тест для этой функции, вызвав проверку `defer goleak.VerifyNone(t)` [355], и убедитесь, что библиотека ловит утечку горутины и валит тест.

## Теория

Проблема утечек горутин (Goroutine Leaks):
- Если горутина заблокировалась на чтении из пустого канала или на бесконечном ожидании мьютекса, она **НИКОГДА** не будет удалена сборщиком мусора (GC).
- Каждая зависшая горутина удерживает 2–8 КБ стека и все захваченные объекты в куче.
- Библиотека `go.uber.org/goleak`:
  - `defer goleak.VerifyNone(t)` анализирует стек-трейсы всех горутин рантайма в начале и конце теста.
  - Если после завершения теста остались висящие пользовательские горутины — тест падает с распечаткой полного стек-трейса утечки!

## Решение по шагам

1. Напишите функцию `LeakWorker()`, запускающую горутину с блокировкой на пустом канале.
2. Подключите `defer goleak.VerifyNone(t)`.
3. Убедитесь в обнаружении утечки.
4. Исправьте утечку через контекст или закрытие канала.

## Код решения

**`leaker.go`**

```go
package main

import "context"

// LeakyWorker демонстрирует баг: горутина навсегда зависает в канале
func LeakyWorker() {
	ch := make(chan int)
	go func() {
		_ = <-ch // Зависание навсегда: в канал никто никогда ничего не запишет!
	}()
}

// CleanWorker исправляет баг через context cancellation
func CleanWorker(ctx context.Context) {
	ch := make(chan int)
	go func() {
		select {
		case <-ch:
		case <-ctx.Done():
			return // Корректный выход из горутины!
		}
	}()
}
```

ℹ️ Утекающий воркер и исправленный воркер с контекстом

**`leaker_test.go`**

```go
package main

import (
	"context"
	"testing"
	"time"

	"go.uber.org/goleak"
)

func TestCleanWorkerNoLeak(t *testing.T) {
	// Детектор утечек горутин от Uber
	defer goleak.VerifyNone(t)

	ctx, cancel := context.WithCancel(context.Background())
	CleanWorker(ctx)

	// Отменяем контекст для корректной остановки фоновой горутины
	cancel()
	time.Sleep(10 * time.Millisecond) // Даем горутине завершиться
}
```

ℹ️ Проверка отсутствия утечек горутин через goleak.VerifyNone

**`Терминал`**

```bash
# Установка библиотеки:
go get go.uber.org/goleak

go test -v leaker_test.go leaker.go
# Вывод:
# === RUN   TestCleanWorkerNoLeak
# --- PASS: TestCleanWorkerNoLeak (0.01s)
# PASS
```

## Под капотом

`goleak` считывает стек горутин через `runtime.Stack()`, фильтрует стандартные системные горутины рантайма (GC, netpoller, scvg, signalHandler) и сравнивает список активных горутин до и после теста.

## Подводные камни

Забывать `goleak.VerifyNone` в `TestMain`: лучше всего подключить `goleak.VerifyTestMain(m)` один раз на весь тестовый пакет, защитив все тесты пакета от утечек разом.

## На собеседовании

**Вопрос с собеседования:** «Как подключить goleak глобально для всех тестов в пакете?»
**Ответ:** В функции `TestMain(m *testing.M)`:
```go
func TestMain(m *testing.M) {
    goleak.VerifyTestMain(m)
}
```
Это автоматически проверит отсутствие утечек после выполнения всех тестов пакета.
