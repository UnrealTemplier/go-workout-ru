# Плавная деградация (Graceful Degradation): fallback на устаревший кэш при сбое API

## Условие

Напиши **"test for graceful degradation"**: функция зависит от внешнего API. Если API недоступен — функция должна вернуть stale-данные из кеша, а не ошибку. Замокай API на ошибку, проверь fallback.

## Теория

Паттерн Graceful Degradation (Stale-While-Revalidate):
- Если внешний сервис (курсы валют, рекомендации, погода) падает с ошибкой 500 или таймаутом, приложение не должно выдавать ошибку 500 конечному пользователю.
- Логика устойчивости:
  1. Попытка запроса к основному внешнему API.
  2. Если API вернул ошибку — обращение к запасному слою кэша (Fallback Stale Cache).
  3. Если в кэше есть старые данные — вернуть их с пометкой `IsDegraded: true`.
- Пользователь видит страницу с небольшим устареванием данных вместо экрана фатальной ошибки.

## Решение по шагам

1. Создайте интерфейсы внешнего API и кэша.
2. Напишите сервис с логикой отката к кэшу при сбое API.
3. Замокируйте ошибку API.
4. Проверьте возврат stale-данных из кэша.

## Код решения

**`degraded_service.go`**

```go
package main

import (
	"errors"
)

type RateProvider interface {
	FetchRate(currency string) (float64, error)
}

type StaleCache interface {
	GetLastKnownRate(currency string) (float64, bool)
	SaveRate(currency string, rate float64)
}

type CurrencyService struct {
	api   RateProvider
	cache StaleCache
}

func NewCurrencyService(api RateProvider, cache StaleCache) *CurrencyService {
	return &CurrencyService{api: api, cache: cache}
}

func (s *CurrencyService) GetExchangeRate(currency string) (float64, bool, error) {
	// 1. Пытаемся получить свежий курс из API
	rate, err := s.api.FetchRate(currency)
	if err == nil {
		s.cache.SaveRate(currency, rate)
		return rate, false, nil // Свежие данные (isDegraded = false)
	}

	// 2. АВАРИЙНЫЙ РЕЖИМ (Fallback): читаем старые данные из кэша
	if staleRate, found := s.cache.GetLastKnownRate(currency); found {
		return staleRate, true, nil // Данные из кэша (isDegraded = true)
	}

	// 3. Если и кэш пуст — только тогда возвращаем ошибку
	return 0, false, errors.New("все источники курсов валют недоступны")
}
```

ℹ️ Сервис с плавной деградацией на stale-кэш

**`degraded_service_test.go`**

```go
package main

import (
	"errors"
	"testing"
)

type FailingAPIStub struct{}

func (FailingAPIStub) FetchRate(currency string) (float64, error) {
	return 0, errors.New("503 Gateway Timeout")
}

type PreloadedStaleCache struct {
	rate float64
}

func (p *PreloadedStaleCache) GetLastKnownRate(currency string) (float64, bool) {
	return p.rate, true
}

func (p *PreloadedStaleCache) SaveRate(currency string, rate float64) {}

func TestCurrencyServiceGracefulDegradation(t *testing.T) {
	// API всегда падает с ошибкой
	failingAPI := FailingAPIStub{}

	// В кэше лежит старый курс 92.50 руб.
	staleCache := &PreloadedStaleCache{rate: 92.50}

	svc := NewCurrencyService(failingAPI, staleCache)

	rate, isDegraded, err := svc.GetExchangeRate("USD")

	// Ошибки быть НЕ ДОЛЖНО — сервис обязан плавно деградировать!
	if err != nil {
		t.Fatalf("Неожиданная ошибка деградации: %v", err)
	}

	if !isDegraded {
		t.Error("Флаг isDegraded обязан быть true при падении внешнего API")
	}

	if rate != 92.50 {
		t.Errorf("rate = %v; want 92.50 (из stale-кэша)", rate)
	}
}
```

## Под капотом

Флаг `isDegraded: true` передается в UI или API Gateway, позволяя интерфейсу показать пользователю предупреждающую плашку «Данные могут быть неактуальны», не ломая пользовательский сценарий.

## Подводные камни

Не логировать факт сбоя API при успешном fallback: мониторинг должен зафиксировать падение зависимости через метрики Prometheus.
