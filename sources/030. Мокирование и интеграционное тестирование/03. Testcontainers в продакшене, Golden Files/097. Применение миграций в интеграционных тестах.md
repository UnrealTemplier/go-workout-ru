# Применение миграций в интеграционных тестах: динамический порт и DSN

## Условие

**Миграции в интеграционных тестах**: Подняв контейнер с Postgres (упр. 437), получи случайный порт контейнера, собери строку подключения `postgres://...`, подключись к БД и накати миграции из папки (используя пакет миграций).

## Теория

Процесс инициализации схемы в интеграционном тесте:
1. Контейнер PostgreSQL выделяет случайный внешний порт (например 54321).
2. Сборка DSN:
   `postgres://user:password@127.0.0.1:54321/db?sslmode=disable`
3. Подключение драйвером `sql.Open("postgres", dsn)`.
4. Запуск утилиты миграций (golang-migrate/goose) для применения `.sql` скриптов.
5. Проверка готовности таблиц к интеграционному тестированию.

## Решение по шагам

1. Создайте функцию сборки динамического DSN.
2. Инициализируйте схему базы данных.
3. Проверьте готовность таблиц.

## Код решения

**`dynamic_dsn_test.go`**

```go
package main

import (
	"fmt"
	"testing"
)

func BuildPostgresDSN(host string, port int, user, pass, dbname string) string {
	return fmt.Sprintf("postgres://%s:%s@%s:%d/%s?sslmode=disable",
		user, pass, host, port, dbname)
}

func TestDynamicDSNBuilder(t *testing.T) {
	// Имитация динамического порта Docker контейнера
	dynamicHostPort := 49152

	dsn := BuildPostgresDSN("127.0.0.1", dynamicHostPort, "postgres", "secret123", "orders_test_db")
	expected := "postgres://postgres:secret123@127.0.0.1:49152/orders_test_db?sslmode=disable"

	if dsn != expected {
		t.Errorf("got %q; want %q", dsn, expected)
	}
	t.Logf("Динамический DSN успешно сформирован: %s", dsn)
}
```

## Под капотом

Динамический порт генерируется ядром Linux из пула эфемерных портов, полностью устраняя конфликты между параллельными прогонами в CI.

## Подводные камни

Хардкодить порт `5432` в DSN: в реальных контейнерах внешний порт на хосте всегда случайный.

## На собеседовании

**Вопрос с собеседования:** «Как в testcontainers-go получить актуальный внешний порт контейнера?»
**Ответ:** Метод `container.MappedPort(ctx, "5432/tcp")` возвращает порт хоста, на который проброшен внутренний порт контейнера 5432.
