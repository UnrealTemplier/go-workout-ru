# Снимочное тестирование (Golden Files): сравнение сложных структур с флагом -update

## Условие

Напиши **"golden file" тест**: функция генерирует сложный вывод (например, SQL-дамп или JSON). Сохрани ожидаемый вывод в `testdata/expected.json`. Тест сравнивает `assert.Equal(t, expected, actual)`. При изменении — обнови golden file через флаг `-update`.

### Исходная формулировка

Напиши **"golden file" тест**: функция генерирует сложный вывод (например, SQL-дамп или JSON). Сохрани ожидаемый вывод в `testdata/expected.json`. Тест сравнивает `assert.Equal(t, expected, actual)`. При изменении — обнови golden file через флаг `-update`.

## Теория

Паттерн Golden File (Snapshot Testing):
- Применяется, когда функция генерирует огромный текстовый документ (HTML, многостраничный JSON, SQL-дамп, YAML).
- Хардкодить такой текст в теле Go-теста непрактично (код становится нечитаемым).
- **Решение:**
  1. Эталон сохраняется в `testdata/output.golden`.
  2. Тест читает golden-файл и сравнивает через `assert.Equal` (или `assert.JSONEq`).
  3. Если формат вывода намеренно изменился, разработчик запускает `go test -update`, и тест сам перезаписывает golden-файл новыми данными!

## Решение по шагам

1. Объявите флаг `var update = flag.Bool("update", false, "обновить golden файлы")`.
2. Напишите функцию генерации JSON отчета.
3. Реализуйте сравнение и перезапись файла при `*update`.

## Код решения

**`golden_demo.go`**

```go
package main

import (
	"encoding/json"
)

type AuditReport struct {
	Title       string   `json:"title"`
	TotalPassed int      `json:"total_passed"`
	Tags        []string `json:"tags"`
}

func GenerateReportJSON() ([]byte, error) {
	rep := AuditReport{
		Title:       "Security Compliance Audit 2026",
		TotalPassed: 108,
		Tags:        []string{"compliance", "iso27001", "pci-dss"},
	}
	return json.MarshalIndent(rep, "", "  ")
}
```

ℹ️ Функция генерации форматированного отчета

**`golden_demo_test.go`**

```go
package main

import (
	"flag"
	"os"
	"path/filepath"
	"testing"
)

var update = flag.Bool("update", false, "обновить golden файлы эталонов")

func TestGenerateReportGolden(t *testing.T) {
	actualBytes, err := GenerateReportJSON()
	if err != nil {
		t.Fatalf("GenerateReportJSON failed: %v", err)
	}

	goldenPath := filepath.Join("testdata", "report_expected.json")

	// Если передан флаг -update, перезаписываем эталонный golden файл
	if *update {
		_ = os.MkdirAll("testdata", 0755)
		if err := os.WriteFile(goldenPath, actualBytes, 0644); err != nil {
			t.Fatalf("Не удалось обновить golden файл: %v", err)
		}
		t.Log("Golden файл успешно обновлен новыми данными!")
		return
	}

	// Читаем эталон
	expectedBytes, err := os.ReadFile(goldenPath)
	if err != nil {
		t.Fatalf("Golden файл не найден (%s). Запустите с флагом -update для его создания: %v", goldenPath, err)
	}

	if string(actualBytes) != string(expectedBytes) {
		t.Errorf("Вывод не совпадает с golden файлом!\nGot:\n%s\nWant:\n%s", string(actualBytes), string(expectedBytes))
	}
}
```

ℹ️ Golden File тест с поддержкой флага -update

**`Терминал`**

```bash
# Создание/обновление golden файла:
go test -v golden_demo_test.go golden_demo.go -update

# Обычный прогон валидации:
go test -v golden_demo_test.go golden_demo.go
# Вывод:
# === RUN   TestGenerateReportGolden
# --- PASS: TestGenerateReportGolden (0.00s)
# PASS
```

## Под капотом

Пакет `flag` в тестах парсится раннером `go test` автоматически. Флаги, объявленные в файлах `*_test.go`, становятся доступными как аргументы командной строки `go test -update`.

## Подводные камни

Коммитить golden-файлы с платформозависимыми переводами строк `\r\n` (Windows CRLF): на Linux CI тест упадет из-за различия байт перевода строки. Всегда нормализуйте переносы строк к `\n`.

## На собеседовании

**Вопрос с собеседования:** «В чем опасность бездумного запуска go test -update?»
**Ответ:** Разработчик может случайно обновить golden-файл при возникновении реального бага в бизнес-логике, тем самым узаконив сломанное поведение как новый эталон. Изменения в `.golden` файлах всегда требуют внимательной проверки diff на Code Review.
