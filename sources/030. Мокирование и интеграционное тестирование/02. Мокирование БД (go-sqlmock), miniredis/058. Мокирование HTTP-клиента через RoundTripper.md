# Мокирование HTTP-клиента через RoundTripper: перехват запросов без открытия портов

## Условие

Создайте mock HTTP-клиента, подменяя `http.RoundTripper`. Возвращайте разные ответы (успех, таймаут, 500) для разных тестов.

## Теория

Паттерн Custom RoundTripper Mock:
- Интерфейс `http.RoundTripper` (`RoundTrip(*http.Request) (*http.Response, error)`) — сердцевина `http.Client`.
- Подменяя поле `client.Transport`, мы перехватываем HTTP-запрос ДО выхода в операционную систему.
- Позволяет сымитировать:
  1. Успешный JSON ответ с любыми заголовками.
  2. Внутреннюю ошибку сервера HTTP 500.
  3. Сетевой сбой или таймаут: `return nil, errors.New("context deadline exceeded")`.
- Не открывает сокетов, работает на 100% в RAM.

## Решение по шагам

1. Создайте тип `RoundTripFunc func(req *http.Request) (*http.Response, error)`.
2. Реализуйте метод `RoundTrip`.
3. Создайте `http.Client{Transport: RoundTripFunc(...)}`.
4. Проверьте перехват запросов.

## Код решения

**`roundtripper_test.go`**

```go
package main

import (
	"bytes"
	"io"
	"net/http"
	"testing"
)

// RoundTripFunc преобразует обычную функцию в реализацию http.RoundTripper
type RoundTripFunc func(req *http.Request) (*http.Response, error)

func (f RoundTripFunc) RoundTrip(req *http.Request) (*http.Response, error) {
	return f(req)
}

func TestMockHTTPClientViaRoundTripper(t *testing.T) {
	// Создаем тестовый клиент с моковым транспортом
	client := &http.Client{
		Transport: RoundTripFunc(func(req *http.Request) (*http.Response, error) {
			// Проверяем URL запроса
			if req.URL.Path == "/api/ok" {
				return &http.Response{
					StatusCode: http.StatusOK,
					Header:     make(http.Header),
					Body:       io.NopCloser(bytes.NewBufferString(`{"status":"success"}`)),
				}, nil
			}

			// Возвращаем HTTP 500 для всех остальных путей
			return &http.Response{
				StatusCode: http.StatusInternalServerError,
				Header:     make(http.Header),
				Body:       io.NopCloser(bytes.NewBufferString(`{"error":"server crashed"}`)),
			}, nil
		}),
	}

	// 1. Успешный запрос
	resp, err := client.Get("http://example.internal/api/ok")
	if err != nil || resp.StatusCode != http.StatusOK {
		t.Fatalf("Ожидался статус 200, получено: %v, err: %v", resp.StatusCode, err)
	}
	body, _ := io.ReadAll(resp.Body)
	resp.Body.Close()
	if string(body) != `{"status":"success"}` {
		t.Errorf("got %s; want success", string(body))
	}

	// 2. Сбойный запрос
	resp500, err := client.Get("http://example.internal/api/crash")
	if err != nil || resp500.StatusCode != http.StatusInternalServerError {
		t.Fatalf("Ожидался статус 500, получено: %v", resp500.StatusCode)
	}
	resp500.Body.Close()
}
```

## Под капотом

`io.NopCloser` оборачивает обычный байтовый буфер `bytes.Buffer` в интерфейс `io.ReadCloser` с пустым методом `Close()`, идеально подходя для создания фиктивных тел `http.Response.Body`.

## Подводные камни

Возвращать `resp.Body = nil`: стандартный клиент Go паникует при попытке закрыть `resp.Body.Close()`. Всегда инициализируйте тело через `io.NopCloser(bytes.NewBufferString(""))`.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество RoundTripper мока перед httptest.NewServer?»
**Ответ:** `RoundTripper` не использует сетевой стек ОС, не аллоцирует порты, работает в 10 раз быстрее и позволяет вернуть ошибку `error` на уровне транспортного протокола (например, сымитировать разрыв TLS рукопожатия или DNS таймаут).
