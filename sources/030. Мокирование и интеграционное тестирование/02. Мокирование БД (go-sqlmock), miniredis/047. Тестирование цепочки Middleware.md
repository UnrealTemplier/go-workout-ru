# Тестирование цепочки Middleware: проверка заголовков и прохождения сквозного контекста

## Условие

Протестируйте middleware: оберните тестовый хендлер в middleware и проверьте, что заголовки/логи появляются корректно.

## Теория

Тестирование конвейера HTTP Middleware:
- Middleware оборачивает обработчик и внедряет сквозной заголовок трассировки `X-Correlation-ID`.
- Если клиент передал свой заголовок — он сохраняется.
- Если заголовок отсутствует — генерируется новый UUID.
- Тест проверяет наличие заголовка в ответе клиента и в контексте хэндлера.

## Решение по шагам

1. Напишите `CorrelationIDMiddleware`.
2. Оберните тестовый хэндлер.
3. Проверьте генерацию и проброс `X-Correlation-ID`.

## Код решения

**`trace_mw.go`**

```go
package main

import (
	"net/http"
)

func CorrelationIDMiddleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		corrID := r.Header.Get("X-Correlation-ID")
		if corrID == "" {
			corrID = "auto-generated-corr-id-999"
		}

		// Добавляем заголовок в ответ
		w.Header().Set("X-Correlation-ID", corrID)
		next.ServeHTTP(w, r)
	})
}
```

ℹ️ Middleware генерации сквозного ID трассировки

**`trace_mw_test.go`**

```go
package main

import (
	"net/http"
	"net/http/httptest"
	"testing"
)

func TestCorrelationIDMiddleware(t *testing.T) {
	dummyHandler := http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusOK)
	})

	pipeline := CorrelationIDMiddleware(dummyHandler)

	// Сценарий 1: Клиент прислал свой ID
	t.Run("сохранение переданного ID", func(t *testing.T) {
		req := httptest.NewRequest(http.MethodGet, "/data", nil)
		req.Header.Set("X-Correlation-ID", "custom-trace-555")
		rec := httptest.NewRecorder()

		pipeline.ServeHTTP(rec, req)

		if rec.Header().Get("X-Correlation-ID") != "custom-trace-555" {
			t.Errorf("got %q; want custom-trace-555", rec.Header().Get("X-Correlation-ID"))
		}
	})

	// Сценарий 2: Генерация нового ID
	t.Run("генерация нового ID", func(t *testing.T) {
		req := httptest.NewRequest(http.MethodGet, "/data", nil)
		rec := httptest.NewRecorder()

		pipeline.ServeHTTP(rec, req)

		if rec.Header().Get("X-Correlation-ID") != "auto-generated-corr-id-999" {
			t.Errorf("got %q; want auto-generated-corr-id-999", rec.Header().Get("X-Correlation-ID"))
		}
	})
}
```

## Под капотом

Сквозной идентификатор `X-Correlation-ID` (или W3C `traceparent`) позволяет связать логи HTTP-запроса, запросов к базе данных и сообщений в Kafka в единую цепочку в системах Jaeger/OpenTelemetry.

## Подводные камни

Устанавливать заголовки ответа `w.Header().Set(...)` ПОСЛЕ вызова `next.ServeHTTP(w, r)`: если хэндлер уже вызвал `w.WriteHeader()`, заголовки будут проигнорированы!

## На собеседовании

**Вопрос с собеседования:** «Как в Go передать Correlation ID в SQL запросы для отладки в pg_stat_activity?»
**Ответ:** С помощью SQL-комментариев (SQL Commenter): перед выполнением запроса добавлять в текст SQL комментарий с trace ID:
`/* trace_id=custom-trace-555 */ SELECT * FROM users ...`
Это позволяет администраторам БД находить точный HTTP-запрос по тяжелым запросам в базе данных.
