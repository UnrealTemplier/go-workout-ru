# Тестирование HTTP эндпоинта /ping без запуска сервера: httptest.NewRequest и Recorder

## Условие

**Тестирование HTTP-обработчиков (`httptest`)**: Напишите HTTP-обработчик `/ping`, который возвращает статус `200 OK` и строку `"pong"`. Напишите для него unit-тест без реального запуска веб-сервера. Используйте пакет `net/http/httptest` [350]: создайте виртуальный запрос с помощью `httptest.NewRequest` [350] и запишите ответ в `httptest.NewRecorder` [350]. Сделайте проверку статус-кода и тела ответа.

## Теория

Стандарт проверки жизнеспособности сервиса (Liveness Probe в Kubernetes):
- Эндпоинт `/ping` возвращает `200 OK` и `"pong"`.
- Пакет `net/http/httptest`:
  1. `httptest.NewRequest(http.MethodGet, "/ping", nil)` создает виртуальный запрос.
  2. `httptest.NewRecorder()` перехватывает сгенерированный ответ.
  3. `PingEndpointHandler(rec, req)` вызывается напрямую.
  4. Проверяется `rec.Code == http.StatusOK` и `rec.Body.String() == "pong"`.

## Решение по шагам

1. Создайте обработчик `PingEndpointHandler`.
2. В тесте сформируйте виртуальный запрос `httptest.NewRequest`.
3. Создайте виртуальный рекордер ответа `httptest.NewRecorder`.
4. Вызовите обработчик и проверьте статус и тело.

## Код решения

**`ping_handler.go`**

```go
package main

import (
	"fmt"
	"net/http"
)

func PingEndpointHandler(w http.ResponseWriter, r *http.Request) {
	w.WriteHeader(http.StatusOK)
	fmt.Fprint(w, "pong")
}
```

ℹ️ HTTP эндпоинт /ping

**`ping_handler_test.go`**

```go
package main

import (
	"net/http"
	"net/http/httptest"
	"testing"
)

func TestPingEndpointHandler(t *testing.T) {
	// 1. Создаем виртуальный запрос с помощью httptest.NewRequest
	req := httptest.NewRequest(http.MethodGet, "/ping", nil)

	// 2. Создаем рекордер ответа httptest.NewRecorder
	rec := httptest.NewRecorder()

	// 3. Вызываем обработчик напрямую
	PingEndpointHandler(rec, req)

	// 4. Проверяем статус-код 200 OK
	if rec.Code != http.StatusOK {
		t.Errorf("StatusCode = %d; want %d", rec.Code, http.StatusOK)
	}

	// 5. Проверяем тело ответа "pong"
	if rec.Body.String() != "pong" {
		t.Errorf("Body = %q; want %q", rec.Body.String(), "pong")
	}
}
```

## Под капотом

Тест исполняется синхронно в той же самой горутине, что исключает Data Race при проверке полей рекордера `rec.Code` и `rec.Body`.

## Подводные камни

Использовать проверку `strings.Contains(rec.Body.String(), "pong")` вместо строгого равенства `rec.Body.String() == "pong"`, если требуется гарантировать отсутствие паразитных символов.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие /ping (liveness probe) от /ready (readiness probe) в Kubernetes?»
**Ответ:** `/ping` (Liveness) сообщает, что процесс жив и event loop не завис (если падает — K8s перезапускает контейнер). `/ready` (Readiness) проверяет готовность сервиса принимать трафик: проверяет соединение с БД и кэшем Redis (если падает — K8s исключает под из балансировщика, но не убивает процесс).
