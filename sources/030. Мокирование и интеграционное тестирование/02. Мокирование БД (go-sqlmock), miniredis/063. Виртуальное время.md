# Виртуальное время: интерфейс Clock с методами Now() и Sleep() для быстрых тестов

## Условие

Реализуйте fake time через `clockwork` или собственный интерфейс `Clock` с методами `Now()` и `Sleep()`, чтобы тестировать таймауты без реального ожидания.

## Теория

Тестирование временных пауз (Timeouts & Delays):
Если в коде есть задержка `time.Sleep(30 * time.Second)`, юнит-тест будет ждать 30 секунд реального времени.
**Решение:** интерфейс виртуальных часов:
```go
type Clock interface {
    Now() time.Time
    Sleep(d time.Duration)
}
```
В тестах `FakeClock.Sleep()` мгновенно увеличивает счетчик виртуального времени на 30 секунд без реальной паузы!

## Решение по шагам

1. Объявите интерфейс `Clock` с методами `Now()` и `Sleep()`.
2. Реализуйте `RealClock` для продакшена.
3. Реализуйте `FakeClock` для тестов.
4. Проверьте мгновенный сдвиг времени.

## Код решения

**`virtual_clock.go`**

```go
package main

import "time"

type VirtualClock interface {
	Now() time.Time
	Sleep(d time.Duration)
}

type RealClock struct{}

func (RealClock) Now() time.Time {
	return time.Now()
}

func (RealClock) Sleep(d time.Duration) {
	time.Sleep(d)
}

type RateLimiter struct {
	clock       VirtualClock
	lastRequest time.Time
	interval    time.Duration
}

func NewRateLimiter(clock VirtualClock, interval time.Duration) *RateLimiter {
	return &RateLimiter{clock: clock, interval: interval}
}

func (r *RateLimiter) Allow() bool {
	now := r.clock.Now()
	if now.Sub(r.lastRequest) >= r.interval {
		r.lastRequest = now
		return true
	}
	return false
}
```

ℹ️ Рейт-лимитер на базе виртуальных часов

**`virtual_clock_test.go`**

```go
package main

import (
	"testing"
	"time"
)

type FakeClock struct {
	currentTime time.Time
}

func (f *FakeClock) Now() time.Time {
	return f.currentTime
}

func (f *FakeClock) Sleep(d time.Duration) {
	f.currentTime = f.currentTime.Add(d) // Мгновенная перемотка времени!
}

func TestRateLimiterWithInstantFakeClock(t *testing.T) {
	initialTime := time.Date(2026, 9, 3, 10, 0, 0, 0, time.UTC)
	fake := &FakeClock{currentTime: initialTime}

	limiter := NewRateLimiter(fake, 10*time.Minute)

	// 1. Первый запрос разрешен
	if !limiter.Allow() {
		t.Fatal("Первый запрос обязан быть разрешен")
	}

	// 2. Запрос через 2 минуты запрещен (интервал 10 мин)
	fake.Sleep(2 * time.Minute)
	if limiter.Allow() {
		t.Fatal("Запрос через 2 минуты должен быть отклонен лимитером")
	}

	// 3. Перематываем еще на 9 минут (суммарно прошло 11 мин) -> запрос разрешен!
	fake.Sleep(9 * time.Minute)
	if !limiter.Allow() {
		t.Fatal("Запрос через 11 минут обязан быть разрешен")
	}
}
```

ℹ️ Мгновенное тестирование 10-минутного интервала

**`Терминал`**

```bash
go test -v virtual_clock_test.go virtual_clock.go
# Вывод:

# --- PASS: TestRateLimiterWithInstantFakeClock (0.00s)

```

## Под капотом

Тест проверяет логику 11 минут ожидания за 0.0001 секунды, экономя часы процессорного времени при прогонах в CI.

## Подводные камни

Использовать в коде `time.After()` напрямую: для отмены по таймерам нужно передавать абстракцию контекста или виртуального таймера.

## На собеседовании

**Вопрос с собеседования:** «Какая библиотека виртуального времени официально рекомендована в экосистеме Uber?»
**Ответ:** Библиотека `go.uber.org/atomic` и `github.com/jonboulle/clockwork` (или `benbjohnson/clock`). Они предоставляют `clockwork.NewFakeClock()`, поддерживающий каналы `After()` и таймеры с возможностью ручного шага `clock.Advance(duration)`.
