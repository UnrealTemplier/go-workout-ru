# Тестирование HTTPS с самоподписанным сертификатом: httptest.NewTLSServer

## Условие

Используйте `httptest.NewTLSServer` для тестирования HTTPS-клиента с самоподписанным сертификатом.

## Теория

Тестирование безопасного протокола HTTPS:
- При попытке отправить запрос на самоподписанный HTTPS сервер обычный клиент упадет с ошибкой `x509: certificate signed by unknown authority`.
- Метод `httptest.NewTLSServer(handler)`:
  1. Генерирует на лету временный X.509 сертификат и закрытый ключ в RAM.
  2. Запускает TLS листенер `https://127.0.0.1:port`.
  3. Предоставляет преднастроенный клиент `server.Client()`, в хранилище доверенных сертификатов которого уже добавлен этот временный сертификат!

## Решение по шагам

1. Запустите `server := httptest.NewTLSServer(handler)`.
2. Получите доверенный клиент `client := server.Client()`.
3. Отправьте HTTPS-запрос.
4. Проверьте шифрованный обмен.

## Код решения

**`tls_server_test.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"strings"
	"testing"
)

func TestHTTPSClientWithTLS(t *testing.T) {
	// Поднимаем HTTPS сервер с самоподписанным TLS сертификатом
	server := httptest.NewTLSServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusOK)
		fmt.Fprintf(w, "SECURE_DATA_ENCRYPTED")
	}))
	t.Cleanup(server.Close)

	// Убеждаемся, что URL начинается с https://
	if !strings.HasPrefix(server.URL, "https://") {
		t.Fatalf("URL сервера обязан начинаться с https://, получено: %s", server.URL)
	}

	// server.Client() возвращает *http.Client, доверяющий самоподписанному сертификату
	client := server.Client()

	resp, err := client.Get(server.URL)
	if err != nil {
		t.Fatalf("HTTPS запрос провален: %v", err)
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		t.Errorf("StatusCode = %d; want 200", resp.StatusCode)
	}

	body, _ := io.ReadAll(resp.Body)
	if string(body) != "SECURE_DATA_ENCRYPTED" {
		t.Errorf("body = %q; want SECURE_DATA_ENCRYPTED", string(body))
	}
}
```

## Под капотом

`server.Client()` клонирует `http.DefaultTransport` и конфигурирует поле `TLSClientConfig.RootCAs`, добавляя в него сертификат `server.Certificate()`.

## Подводные камни

Использовать `http.Get(server.URL)` вместо `server.Client().Get(server.URL)`: дефолтный клиент не знает о самоподписанном сертификате и упадет с ошибкой валидации X.509.

## На собеседовании

**Вопрос с собеседования:** «Как протестировать взаимную TLS аутентификацию (mTLS), когда сервер требует клиентский сертификат?»
**Ответ:** Сконфигурировать `server.TLS.ClientAuth = tls.RequireAndVerifyClientCert` и передать в `client.Transport.(*http.Transport).TLSClientConfig.Certificates` сгенерированную пару клиентского сертификата и ключа.
