# Автоматическая кодогенерация моков: mockery и go.uber.org/mock

## Условие

Используйте `gomock` (или `mockery`) для автоматической генерации моков из интерфейсов.

## Теория

Инструменты кодогенерации моков в Go:
1. `mockgen` (Uber gomock): строгий синтаксис `EXPECT()`, строгие типы аргументов, квантификаторы `Times(N)`, `InOrder()`.
2. `mockery`: генерирует моки на базе `testify/mock`. Поддерживает конфигурацию через файл `.mockery.yaml`, генерацию моков для всех интерфейсов репозитория одной командой `mockery --all`.
Директива `//go:generate` автоматизирует синхронизацию моков при `go generate ./...`.

## Решение по шагам

1. Объявите интерфейс `PaymentProcessor`.
2. Добавьте директиву кодогенерации `//go:generate`.
3. Ознакомьтесь с синтаксисом генерации через mockery.

## Код решения

**`processor.go`**

```go
package main

import "context"

//go:generate mockery --name=PaymentProcessor --output=mocks --outpkg=mocks --case=underscore

type PaymentProcessor interface {
	Authorize(ctx context.Context, accountID string, amount float64) (string, error)
	Capture(ctx context.Context, authCode string) error
}
```

ℹ️ Интерфейс с директивой mockery

**`Терминал`**

```bash
# Установка mockery:
go install github.com/vektra/mockery/v2@latest

# Генерация моков для всего проекта:
mockery --all --output=mocks --case=underscore
# Файл mocks/payment_processor.go успешно сгенерирован!
```

## Под капотом

`mockery` парсит AST пакета, извлекает все типы интерфейсов и компилирует исходный код мока со встроенным `mock.Mock` из `testify`, реализуя каждый метод с вызовом `_m.Called(args...)`.

## Подводные камни

Редактировать сгенерированные файлы `mocks/*.go` вручную: при следующем запуске `go generate` все правки будут безвозвратно затерты.

## На собеседовании

**Вопрос с собеседования:** «Где в репозитории следует хранить сгенерированные моки?»
**Ответ:** Либо в подпакете `mocks/` рядом с интерфейсом, либо в приватной директории `internal/mocks`. Хранение моков в `internal/` защищает внешних потребителей библиотеки от случайного импорта тестовых дублеров.
