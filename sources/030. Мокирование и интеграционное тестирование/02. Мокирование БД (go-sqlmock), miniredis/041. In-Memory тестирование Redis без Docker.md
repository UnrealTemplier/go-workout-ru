# In-Memory тестирование Redis без Docker: библиотека alicebob/miniredis

## Условие

Используйте `miniredis` (in-memory Redis) для unit-тестирования логики, зависящей от Redis, без реального сервера.

## Теория

Библиотека `github.com/alicebob/miniredis/v2`:
- Чистая реализация Redis-сервера на Go, работающая на 100% в оперативной памяти.
- Поддерживает команды Strings, Hashes, Lists, Sets, Sorted Sets, Pub/Sub, транзакции и TTL.
- Запуск занимает 1–2 миллисекунды: `s := miniredis.RunT(t)`.
- Позволяет тестировать истечение TTL без реального ожидания с помощью метода `s.FastForward(duration)`!

## Решение по шагам

1. Запустите `miniredis` в тесте.
2. Подключите стандартный клиент `redis.NewClient`.
3. Запишите ключ со сроком жизни.
4. Проверьте чтение данных.

## Код решения

**`miniredis_demo_test.go`**

```go
package main

import (
	"context"
	"testing"
	"time"

	"github.com/alicebob/miniredis/v2"
	"github.com/redis/go-redis/v9"
)

func TestMiniredisOperations(t *testing.T) {
	// 1. Запуск легковесного in-memory Redis сервера
	s := miniredis.RunT(t)

	// 2. Подключаем стандартный go-redis клиент к адресу miniredis
	client := redis.NewClient(&redis.Options{
		Addr: s.Addr(),
	})
	t.Cleanup(func() {
		_ = client.Close()
	})

	ctx := context.Background()

	// 3. Сохраняем токен авторизации на 5 минут
	err := client.Set(ctx, "session:token_999", "user_admin", 5*time.Minute).Err()
	if err != nil {
		t.Fatalf("Redis SET failed: %v", err)
	}

	// 4. Проверяем чтение ключа
	val, err := client.Get(ctx, "session:token_999").Result()
	if err != nil {
		t.Fatalf("Redis GET failed: %v", err)
	}
	if val != "user_admin" {
		t.Errorf("got %q; want user_admin", val)
	}

	// 5. Перематываем виртуальное время вперед на 6 минут (TTL истек!)
	s.FastForward(6 * time.Minute)

	// 6. Проверяем, что ключ автоматически удалился
	_, err = client.Get(ctx, "session:token_999").Result()
	if err != redis.Nil {
		t.Errorf("Ожидался redis.Nil после истечения TTL, получено: %v", err)
	}
}
```

ℹ️ Тестирование Redis с перемоткой времени через miniredis

**`Терминал`**

```bash
go test -v miniredis_demo_test.go
# Вывод:
# === RUN   TestMiniredisOperations
# --- PASS: TestMiniredisOperations (0.00s)
# PASS
```

## Под капотом

Метод `s.FastForward()` мгновенно сдвигает внутренние часы `miniredis` без реального вызова `time.Sleep()`, что позволяет мгновенно тестировать логику кэшей с TTL в несколько дней или месяцев.

## Подводные камни

Использовать miniredis для тестирования сложных Lua-скриптов или Redis Streams: miniredis поддерживает не все команды Redis 7+. Для сложных сценариев используют Testcontainers с официальным образом Redis.

## На собеседовании

**Вопрос с собеседования:** «Как miniredis.RunT(t) управляет жизненным циклом сервера?»
**Ответ:** Метод `RunT(t)` регистрирует закрытие сервера через `t.Cleanup(s.Close)`, гарантируя остановку фонового сетевого листенера при любом исходе теста без утечек горутин.
