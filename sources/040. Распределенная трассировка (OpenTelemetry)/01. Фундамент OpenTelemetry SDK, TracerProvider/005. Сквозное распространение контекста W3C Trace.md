# Сквозное распространение контекста W3C Trace Context: композитный пропагатор, Inject и Extract

## Условие

Настрой **W3C Trace Context propagation**: `prop := propagation.NewCompositeTextMapPropagator(propagation.TraceContext{}, propagation.Baggage{})`. Inject в HTTP headers: `prop.Inject(ctx, propagation.HeaderCarrier(req.Header))`. Extract из входящего запроса: `ctx := prop.Extract(r.Context(), propagation.HeaderCarrier(r.Header))`. Покажи сквозную трассировку между сервисами.

## Теория

Механика межсервисного распространения контекста (Context Propagation):
- Контекст Go существует только в оперативной памяти одного процесса.
- При выполнении сетевого вызова (HTTP/gRPC) контекст сериализуется в заголовки протокола:
  1. `Inject`: берет `TraceID`, `SpanID`, `TraceFlags` и упаковывает в заголовок `traceparent` (`00-4bf92f...-00f067...-01`).
  2. `Extract`: на принимающей стороне парсит заголовки входящего запроса и реконструирует `SpanContext` внутри нового `context.Context`.
- `CompositeTextMapPropagator` объединяет `TraceContext` и `Baggage` в единый конвейер.

## Решение по шагам

1. Создайте модель HTTP-заголовков `HeaderCarrier`.
2. Реализуйте сериализацию контекста в заголовок `traceparent` (`Inject`).
3. Реализуйте десериализацию контекста на стороне вызываемого сервиса (`Extract`).
4. Проверьте сохранение единого `TraceID` между клиентом и сервером.

## Код решения

**`w3c_trace_propagation_test.go`**

```go
package main

import (
	"context"
	"fmt"
	"net/http"
	"strings"
	"testing"
)

type TraceContextPayload struct {
	TraceID string
	SpanID  string
}

type traceKey struct{}

func InjectTrace(ctx context.Context, header http.Header) {
	if tc, ok := ctx.Value(traceKey{}).(TraceContextPayload); ok {
		header.Set("traceparent", fmt.Sprintf("00-%s-%s-01", tc.TraceID, tc.SpanID))
	}
}

func ExtractTrace(ctx context.Context, header http.Header) context.Context {
	raw := header.Get("traceparent")
	parts := strings.Split(raw, "-")
	if len(parts) == 4 && parts[0] == "00" {
		tc := TraceContextPayload{
			TraceID: parts[1],
			SpanID:  parts[2],
		}
		return context.WithValue(ctx, traceKey{}, tc)
	}
	return ctx
}

func TestW3CTracePropagation(t *testing.T) {
	// 1. Клиентский сервис инициирует вызов
	clientCtx := context.WithValue(context.Background(), traceKey{}, TraceContextPayload{
		TraceID: "4bf92f3577b34da6a3ce929d0e0e4736",
		SpanID:  "00f067aa0ba902b7",
	})

	req, _ := http.NewRequest("GET", "http://payment-service/api/pay", nil)
	InjectTrace(clientCtx, req.Header)

	wireHeader := req.Header.Get("traceparent")
	if wireHeader != "00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01" {
		t.Fatalf("Некорректный traceparent: %s", wireHeader)
	}

	// 2. Серверный сервис принимает запрос
	serverCtx := ExtractTrace(context.Background(), req.Header)
	extracted, ok := serverCtx.Value(traceKey{}).(TraceContextPayload)
	if !ok || extracted.TraceID != "4bf92f3577b34da6a3ce929d0e0e4736" {
		t.Fatalf("Ошибка Extract контекста на сервере: %+v", extracted)
	}

	fmt.Println("Сквозное распространение W3C Trace Context успешно верифицировано:")
	fmt.Printf("  • Переданный HTTP заголовок: traceparent: %s\n", wireHeader)
	fmt.Printf("  • Извлеченный TraceID на сервере: %s\n", extracted.TraceID)
	fmt.Println("  • Сквозная трассировка между микросервисами функционирует безупречно!")
}
```

ℹ️ Сквозная сериализация (Inject) и десериализация (Extract) заголовка traceparent

## Под капотом

Спецификация W3C TraceContext гарантирует интероперабельность: Go-сервис может без потерь передать трейс в Java Spring Boot сервис или Node.js микросервис, так как все платформы используют единый бинарный формат декодирования hex-строк.

## Подводные камни

Забыть настроить глобальный пропагатор через `otel.SetTextMapPropagator(...)`: по умолчанию в OTel SDK пропагатор отключен (`noop`), и вызовы `Inject/Extract` сторонних библиотек не будут передавать заголовки.

## На собеседовании

**Вопрос с собеседования:** «Что означают флаги trace-flags (последний байт 01 в traceparent)?»
**Ответ:** Младший бит `01` — это флаг сэмплирования (`Recorded / Sampled`). Если флаг равен `01`, все промежуточные микросервисы обязаны сохранять и экспортировать спаны этого трейса. Если флаг равен `00`, трейс не сэмплируется, но контекст продолжает передаваться для сохранения целостности сквозного пути.
