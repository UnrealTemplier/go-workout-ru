# Пользовательские теги спана: фильтрация и структурированный поиск по user.id в UI Jaeger

## Условие

Добавь атрибуты (теги) к спану: `span.SetAttributes(attribute.String("user.id", "123"))`.

## Теория

Практика индексации атрибутов в Distributed Tracing:
- В Jaeger и Grafana Tempo окно поиска поддерживает фильтрацию:
  `tags: user.id=123 AND http.status_code=500`
- Вызов `span.SetAttributes`:
  - Может вызываться многократно в любой момент жизни спана до `span.End()`.
  - Атрибуты перезаписываются при совпадении ключа.
  - Позволяет связывать технический трейс с бизнес-сущностями (ID заказа, ID клиента, версия A/B теста).

## Решение по шагам

1. Создайте спан с поддержкой установки атрибутов.
2. Зафиксируйте атрибут `user.id = "123"`.
3. Смоделируйте поиск по тегам в поисковом движке Jaeger.
4. Проверьте точность фильтрации спанов.

## Код решения

**`span_custom_tags_search_test.go`**

```go
package main

import (
	"fmt"
	"testing"
)

type TaggedSpanRecord struct {
	TraceID string
	Tags    map[string]string
}

func MatchJaegerSearch(spans []TaggedSpanRecord, key, val string) []TaggedSpanRecord {
	var res []TaggedSpanRecord
	for _, s := range spans {
		if s.Tags[key] == val {
			res = append(res, s)
		}
	}
	return res
}

func TestSpanCustomTagsSearch(t *testing.T) {
	dataset := []TaggedSpanRecord{
		{TraceID: "t-001", Tags: map[string]string{"user.id": "123", "env": "prod"}},
		{TraceID: "t-002", Tags: map[string]string{"user.id": "456", "env": "prod"}},
		{TraceID: "t-003", Tags: map[string]string{"user.id": "123", "env": "staging"}},
	}

	found := MatchJaegerSearch(dataset, "user.id", "123")

	if len(found) != 2 {
		t.Fatalf("Ожидалось 2 совпадения по user.id=123, получено: %d", len(found))
	}

	fmt.Println("Пользовательские теги и поиск в Jaeger успешно подтверждены:")
	fmt.Printf("  • Критерий поиска: tags: user.id=123\n")
	for _, match := range found {
		fmt.Printf("  • Найден TraceID: %s (Env: %s)\n", match.TraceID, match.Tags["env"])
	}
	fmt.Println("  • Инженер мгновенно находит трейсы конкретного пользователя при обращении в поддержку!")
}
```

## Под капотом

В Grafana Tempo язык запросов TraceQL компилируется в распределенный сканирующий запрос: фильтр `{.user.id == "123"}` эффективно фильтрует паркетные колонки блоков памяти без полного чтения тел спанов.

## Подводные камни

Использовать ключи без пространства имен (`id` вместо `user.id` или `order.id`): это приведет к коллизиям между разными подсистемами приложения.

## На собеседовании

**Вопрос с собеседования:** «Каковы лучшие практики именования атрибутов в соответствии с OTel Semantic Conventions?»
**Ответ:** Использовать точечную нотацию в нижнем регистре с префиксом предметной области: `<namespace>.<entity>.<property>` (например `payment.provider.name`, `order.delivery.type`, `http.request.header.x_custom`). Это исключает конфликты имен при объединении трейсов разных команд.
