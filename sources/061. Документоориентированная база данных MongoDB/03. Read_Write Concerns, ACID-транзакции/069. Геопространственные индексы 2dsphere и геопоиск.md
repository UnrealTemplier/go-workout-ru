# Геопространственные индексы 2dsphere и геопоиск

## Условие

Создайте `2dsphere` индекс для geo-запросов. Используйте `$near`, `$geoWithin`, `$geoIntersects`.

### Исходная формулировка

**Geospatial index**: Создайте `2dsphere` индекс для geo-запросов. Используйте `$near`, `$geoWithin`, `$geoIntersects`.

## Теория

Для геолокационных сервисов (такси, доставка, поиск ближайших курьеров/ресторанов) MongoDB поддерживает геопространственные индексы **`2dsphere`**, учитывающие сферическую геометрию Земли (модель WGS84).

### Формат GeoJSON:
Координаты **обязаны** задаваться строго в порядке: `[долгота (Longitude), широта (Latitude)]`!
```json
{
    "location": {
        "type": "Point",
        "coordinates": [37.6173, 55.7558] // Москва: [lon, lat]
    }
}
```

### Гео-операторы:
- **`$near`:** находит ближайшие объекты к точке с автоматической сортировкой по расстоянию и лимитом `$maxDistance` в метрах.
- **`$geoWithin`:** находит объекты внутри замкнутого полигона (`Polygon`).
- **`$geoIntersects`:** находит пересечения геометрий.

## Решение по шагам

1. Объявите модель с GeoJSON структурой `GeoPoint`.
2. Создайте индекс `2dsphere` по полю `location`.
3. Заполните координаты нескольких объектов (точек интереса).
4. Выполните поиск ближайших объектов в радиусе 5 000 метров через `$near` и `$maxDistance`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

type GeoLocation struct {
	Type        string    `bson:"type"`
	Coordinates []float64 `bson:"coordinates"` // [Долгота/lon, Широта/lat]
}

type Restaurant struct {
	Name     string      `bson:"name"`
	Location GeoLocation `bson:"location"`
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("geo").Collection("places")
	_ = coll.Drop(ctx)

	// 1. Создание индекса 2dsphere
	idxName, err := coll.Indexes().CreateOne(ctx, mongo.IndexModel{
		Keys: bson.D{{Key: "location", Value: "2dsphere"}},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("2dsphere индекс успешно зарегистрирован: %s\n", idxName)

	// Заполняем рестораны в Москве: [lon, lat]
	_, _ = coll.InsertMany(ctx, []interface{}{
		Restaurant{
			Name: "Кафе у Кремля",
			Location: GeoLocation{Type: "Point", Coordinates: []float64{37.6173, 55.7558}},
		},
		Restaurant{
			Name: "Ресторан на Арбате",
			Location: GeoLocation{Type: "Point", Coordinates: []float64{37.5925, 55.7500}},
		},
		Restaurant{
			Name: "Загородный клуб (за МКАД)",
			Location: GeoLocation{Type: "Point", Coordinates: []float64{37.3000, 55.7000}}, // Далеко
		},
	})

	// 2. Поиск ближайших мест в радиусе 3000 метров от Красной площади
	userLocation := []float64{37.6184, 55.7512} // Текущие координаты пользователя
	geoQuery := bson.M{
		"location": bson.M{
			"$near": bson.M{
				"$geometry": bson.M{
					"type":        "Point",
					"coordinates": userLocation,
				},
				"$maxDistance": 3000, // Радиус в метрах
			},
		},
	}

	cur, err := coll.Find(ctx, geoQuery)
	if err != nil {
		panic(err)
	}
	defer cur.Close(ctx)

	fmt.Println("Ближайшие рестораны в радиусе 3 км ($near):")
	for cur.Next(ctx) {
		var r Restaurant
		_ = cur.Decode(&r)
		fmt.Printf("  - %s (Координаты: %v)\n", r.Name, r.Location.Coordinates)
	}
}
```

ℹ️ Геопоиск ближайших точек интереса через 2dsphere индекс и оператор $near

**`Терминал`**

```bash
go run main.go
# 2dsphere индекс успешно зарегистрирован: location_2dsphere
# Ближайшие рестораны в радиусе 3 км ($near):
#   - Кафе у Кремля (Координаты: [37.6173 55.7558])
#   - Ресторан на Арбате (Координаты: [37.5925 55.75])
```

## Под капотом

Индекс `2dsphere` использует иерархическую сетку ячеек кривой Гильберта (S2 Geometry Library от Google). Земной шар проецируется на грани куба с рекурсивным разбиением на четырехдольные ячейки (Quad-tree). Поиск по расстоянию сводится к сканированию одномерных диапазонов ключей кривой Гильберта.

## Подводные камни

Самая частая ошибка новичков — перепутать порядок координат: указать `[latitude, longitude]` вместо `[longitude, latitude]`. Долгота (Longitude) ВСЕГДА идет первой!

## На собеседовании

**Вопрос:** В чем разница между оператором $near и $geoWithin?
**Ответ:** `$near` требует обязательного наличия индекса `2dsphere`, возвращает результаты отсортированными по расстоянию от ближайшего к дальнему и поддерживает лимиты `$minDistance` / `$maxDistance`. `$geoWithin` может работать даже без индекса (хотя с индексом значительно быстрее), возвращает все точки внутри заданной геометрической фигуры (полигона или окружности), но не выполняет сортировку по расстоянию.
