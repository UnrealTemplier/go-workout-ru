# TTL-индексы по точному времени экспирации (expireAt)

## Условие

Создайте TTL-индекс на поле `expireAt`. Вставьте документы с временем истечения, убедитесь, что они удаляются через указанный промежуток.

### Исходная формулировка

**TTL-индексы для автоматического удаления.**: Создайте TTL-индекс на поле `expireAt`. Вставьте документы с временем истечения, убедитесь, что они удаляются через указанный промежуток.

## Теория

Классический TTL-индекс с `expireAfterSeconds: 3600` удаляет все документы через одинаковый интервал от момента создания.
Однако в реальных системах разным документам требуется **разное время жизни**:
- Временная блокировка аккаунта на 15 минут.
- Подписка на 30 дней.
- Сессия до конца текущего дня.

### Паттерн ExpireAt (expireAfterSeconds: 0):
Индекс создается с нулевой задержкой:
```go
options.Index().SetExpireAfterSeconds(0)
```
В поле `expireAt` документа записывается **точная будущая дата и время**, когда документ должен быть удален. База данных удаляет документ, как только `time.Now() >= document.expireAt`!

## Решение по шагам

1. Создайте индекс по полю `expireAt` с опцией `SetExpireAfterSeconds(0)`.
2. Вставьте документ с временем жизни 10 секунд и документ с временем жизни 24 часа.
3. Проверьте логику работы фонового потока TTL.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

type DynamicTTLDoc struct {
	Description string    `bson:"desc"`
	ExpireAt    time.Time `bson:"expireAt"` // Точная дата экспирации
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("cache").Collection("dynamic_ttl")
	_ = coll.Drop(ctx)

	// TTL индекс с expireAfterSeconds = 0
	ttlModel := mongo.IndexModel{
		Keys: bson.D{{Key: "expireAt", Value: 1}},
		Options: options.Index().
			SetExpireAfterSeconds(0).
			SetName("idx_dynamic_expire_at"),
	}

	_, err = coll.Indexes().CreateOne(ctx, ttlModel)
	if err != nil {
		panic(err)
	}
	fmt.Println("Динамический TTL-индекс (expireAfterSeconds: 0) успешно создан.")

	now := time.Now().UTC()

	// Документ 1: истекает через 30 минут
	doc1 := DynamicTTLDoc{
		Description: "Временная блокировка логина (30 мин)",
		ExpireAt:    now.Add(30 * time.Minute),
	}

	// Документ 2: истекает через 7 дней
	doc2 := DynamicTTLDoc{
		Description: "Промокод нового пользователя (7 дней)",
		ExpireAt:    now.Add(7 * 24 * time.Hour),
	}

	_, _ = coll.InsertMany(ctx, []interface{}{doc1, doc2})

	fmt.Println("Документы с индивидуальными сроками жизни успешно записаны:")
	fmt.Printf("  1. %s -> удалится в %s\n", doc1.Description, doc1.ExpireAt.Format(time.RFC3339))
	fmt.Printf("  2. %s -> удалится в %s\n", doc2.Description, doc2.ExpireAt.Format(time.RFC3339))
}
```

ℹ️ Паттерн динамического времени жизни через SetExpireAfterSeconds(0)

**`Терминал`**

```bash
go run main.go
# Динамический TTL-индекс (expireAfterSeconds: 0) успешно создан.
# Документы с индивидуальными сроками жизни успешно записаны:
#   1. Временная блокировка логина (30 мин) -> удалится в 2026-09-04T16:45:00Z
#   2. Промокод нового пользователя (7 дней) -> удалится в 2026-09-11T16:15:00Z
```

## Под капотом

Фоновый демон TTL выполняет поиск `expireAt <= ISODate()` по B-дереву. Документы, срок которых наступил, удаляются пачками.

## Подводные камни

Если в поле `expireAt` передать дату из прошлого, документ будет удален при первом же срабатывании фонового потока TTL. Если же передать не `time.Time`, а число или строку, документ никогда не удалится.

## На собеседовании

**Вопрос:** Можно ли отменить удаление документа с TTL-индексом?
**Ответ:** Да! Поскольку TTL отслеживает значение поля `expireAt`, можно в любой момент выполнить `UpdateOne` и обновить `expireAt` на более позднюю дату (продление сессии) либо применить `$unset: { expireAt: "" }`, сделав документ персистентным и навсегда исключив его из TTL.
