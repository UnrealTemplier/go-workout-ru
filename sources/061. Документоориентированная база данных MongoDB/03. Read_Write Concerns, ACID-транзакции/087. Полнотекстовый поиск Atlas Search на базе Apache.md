# Полнотекстовый поиск Atlas Search на базе Apache Lucene

## Условие

Используйте Atlas Search (на основе Lucene) для advanced full-text search с facets, highlighting, autocomplete.

### Исходная формулировка

**Atlas Search**: Используйте Atlas Search (на основе Lucene) для advanced full-text search с facets, highlighting, autocomplete.

## Теория

В облачной версии MongoDB Atlas и современных enterprise-инсталляциях доступен **Atlas Search** — глубокая интеграция движка полнотекстового поиска **Apache Lucene** прямо в ядро MongoDB:
- В отличие от стандартного текстового индекса `$text`, Atlas Search работает через специализированную стадию агрегации **`$search`**.
- Поддерживает морфологию, стемминг (Snowball), нечеткий поиск (Fuzzy matching с расстоянием Левенштейна), автодополнение (Autocomplete) и подсветку найденных фрагментов (Highlighting).
- Стадия `$search` **обязана быть строго первой стадией** конвейера агрегации!

## Решение по шагам

1. Постройте конвейер агрегации со стадией `$search`.
2. Задайте оператор поиска `autocomplete` с нечетким соответствием `fuzzy`.
3. Добавьте стадию подсчета релевантности через `score: { $meta: "searchScore" }`.
4. Распечатайте результаты полнотекстового ранжирования.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

type SearchResultItem struct {
	Title string  `bson:"title"`
	Score float64 `bson:"score"`
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("knowledge_base").Collection("articles")

	// Конвейер Atlas Search ($search на базе Lucene)
	searchPipeline := mongo.Pipeline{
		// Стадия 1: $search ОБЯЗАНА быть первой!
		{{Key: "$search", Value: bson.D{
			{Key: "index", Value: "default"},
			{Key: "autocomplete", Value: bson.D{
				{Key: "query", Value: "gofmt"},
				{Key: "path", Value: "title"},
				{Key: "fuzzy", Value: bson.D{{Key: "maxEdits", Value: 1}}},
			}},
		}}},
		// Стадия 2: Проекция поискового скора релевантности Lucene
		{{Key: "$project", Value: bson.D{
			{Key: "_id", Value: 0},
			{Key: "title", Value: 1},
			{Key: "score", Value: bson.D{{Key: "$meta", Value: "searchScore"}}},
		}}},
		{{Key: "$limit", Value: 5}},
	}

	fmt.Println("Конфигурация конвейера Atlas Search ($search):")
	fmt.Println("  1. Полнотекстовый поиск по индексу Lucene с нечетким сопоставлением (Fuzzy)")
	fmt.Println("  2. Извлечение searchScore для ранжирования по релевантности")
	_ = searchPipeline
	_ = coll
}
```

## Под капотом

Atlas Search запускает процесс `mongot` (на базе Java/Lucene) рядом с процессом `mongod`. Изменения из oplog транслируются в инвертированный индекс Lucene в реальном времени.

## Подводные камни

Стадия `$search` не работает в стандартном standalone community сервере без предварительно настроенного процесса Atlas/mongot.

## На собеседовании

**Вопрос:** В чем разница между классическим текстовым индексом $text и Atlas Search ($search)?
**Ответ:** Классический `$text` медленный, ограничен одним индексом на коллекцию, не умеет искать с опечатками (Fuzzy), не поддерживает автодополнение и сильно нагружает CPU базы при больших текстах. Atlas Search построен на полноценном движке Lucene с инвертированными списками и ранжированием BM25.
