# Базовая агрегация: $match и $group по городу

## Условие

Напиши агрегацию, которая группирует пользователей по городу и считает их средний возраст. Этапы: `$match` (возраст > 18), `$group` (`_id: "$city"`, `avgAge: {$avg: "$age"}`).

### Исходная формулировка

**[Aggregation Pipeline]**: Напиши агрегацию, которая группирует пользователей по городу и считает их средний возраст. Этапы: `$match` (возраст > 18), `$group` (`_id: "$city"`, `avgAge: {$avg: "$age"}`).

## Теория

Aggregation Framework — это конвейерная система обработки данных в MongoDB, заменяющая устаревший MapReduce и превосходящая по выразительности традиционный SQL `GROUP BY`.

### Конвейер (Pipeline):
Данные проходят через последовательность стадий (stages), где выход предыдущего этапа является входом для следующего:
1. **`$match`:** фильтрует поток документов (аналог `WHERE` в SQL). Фильтрует документы как можно раньше для отсечения лишних данных.
2. **`$group`:** группирует документы по ключу `_id` (аналог `GROUP BY` в SQL) и применяет аккумуляторы:
   - `$avg: "$field"` — вычисляет среднее арифметическое.
   - `$sum: 1` — подсчитывает количество документов (`COUNT(*)`).
   - `$sum: "$field"` — суммирует числовые значения.

## Решение по шагам

1. Заполните коллекцию пользователями с городами и возрастами.
2. Сконструируйте пайплайн из двух стадий `bson.D` (`$match` и `$group`).
3. Вызовите `coll.Aggregate(ctx, pipeline)`.
4. Десериализуйте результат через курсор в структуру отчета.
5. Выведите средний возраст по каждому городу.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

type CityAgeReport struct {
	City      string  `bson:"_id"`
	AvgAge    float64 `bson:"avgAge"`
	UserCount int     `bson:"userCount"`
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("analytics").Collection("residents")
	_ = coll.Drop(ctx)

	_, _ = coll.InsertMany(ctx, []interface{}{
		bson.M{"name": "Иван", "city": "Москва", "age": 25},
		bson.M{"name": "Анна", "city": "Москва", "age": 35},
		bson.M{"name": "Михаил", "city": "Москва", "age": 16}, // Должен быть отфильтрован
		bson.M{"name": "Сергей", "city": "СПб", "age": 20},
		bson.M{"name": "Ольга", "city": "СПб", "age": 30},
	})

	// Pipeline: $match (age > 18) -> $group (by city)
	pipeline := mongo.Pipeline{
		{{Key: "$match", Value: bson.D{
			{Key: "age", Value: bson.D{{Key: "$gt", Value: 18}}},
		}}},
		{{Key: "$group", Value: bson.D{
			{Key: "_id", Value: "$city"},
			{Key: "avgAge", Value: bson.D{{Key: "$avg", Value: "$age"}}},
			{Key: "userCount", Value: bson.D{{Key: "$sum", Value: 1}}},
		}}},
	}

	cur, err := coll.Aggregate(ctx, pipeline)
	if err != nil {
		panic(err)
	}
	defer cur.Close(ctx)

	var reports []CityAgeReport
	if err := cur.All(ctx, &reports); err != nil {
		panic(err)
	}

	fmt.Println("Результаты агрегации (совершеннолетние по городам):")
	for _, r := range reports {
		fmt.Printf("  Город: %-8s | Средний возраст: %.1f лет | Пользователей: %d\n",
			r.City, r.AvgAge, r.UserCount)
	}
}
```

ℹ️ Конвейерная обработка данных через mongo.Pipeline с этапами $match и $group

**`Терминал`**

```bash
go run main.go
# Результаты агрегации (совершеннолетние по городам):
#   Город: Москва   | Средний возраст: 30.0 лет | Пользователей: 2
#   Город: СПб      | Средний возраст: 25.0 лет | Пользователей: 2
```

## Под капотом

Движок Aggregation Pipeline написан на C++ и оптимизирует порядок стадий. Если стадия `$match` находится в начале конвейера, MongoDB использует имеющиеся индексы коллекции для начальной фильтрации (Index Scan). После этапа `$group` поток документов перегруппировывается в хэш-таблице в оперативной памяти mongod.

## Подводные камни

Если в `$group` забыть знак доллара перед именем поля (`_id: "city"` вместо `_id: "$city"`), MongoDB сгруппирует все документы в одну группу с литеральным строковым ключом `"city"`!

## На собеседовании

**Вопрос:** Что произойдет, если размер промежуточных данных на этапе $group превысит 100 МБ?
**Ответ:** По умолчанию MongoDB выбросит ошибку: `Exceeded memory limit for $group, but didn't allowExternalSorting: true`. Для разрешения сброса промежуточных бакетов на диск необходимо явно передать опцию `options.Aggregate().SetAllowDiskUse(true)`.
