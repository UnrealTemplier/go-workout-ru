# Парсинг Connection String и конфигурация опций

## Условие

Изучите все параметры connection string: `replicaSet`, `authSource`, `readPreference`, `w`, `maxPoolSize`. Используйте `mongo.Options` для programmatic configuration.

### Исходная формулировка

**Connection string parsing**: Изучите все параметры connection string: `replicaSet`, `authSource`, `readPreference`, `w`, `maxPoolSize`. Используйте `mongo.Options` для programmatic configuration.

## Теория

Строка подключения MongoDB (Connection String URI) соответствует стандарту RFC 3986 и спецификации MongoDB Connection String Spec:
`mongodb://[username:password@]host1[:port1][,...hostN[:portN]][/[defaultauthdb][?options]]`

### Ключевые параметры URI:
- **`replicaSet=rs0`:** Имя набора реплик. Драйвер опрашивает указанные хосты и автоматически находит всех членов реплика-сета.
- **`authSource=admin`:** База данных, хранящая учетную запись пользователя.
- **`readPreference=secondaryPreferred`:** Направляет запросы чтения на реплики, разгружая мастер.
- **`w=majority`:** Write Concern: операция записи подтверждается большинством реплик перед ответом клиенту.
- **`wtimeoutMS=5000`:** Таймаут подтверждения записи репликами.
- **`maxPoolSize=100`:** Емкость пула TCP-соединений.

Драйвер позволяет конфигурировать опции как через URI строку, так и программно через методы `options.Client()` (программные опции переопределяют значения из URI).

## Решение по шагам

1. Сформируйте URI строку со всеми enterprise-параметрами.
2. Примените ее через `options.Client().ApplyURI(uri)`.
3. Дополнительно программно сконфигурируйте `WriteConcern` и `ReadPreference`.
4. Распечатайте активные параметры клиента для валидации конфигурации.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
	"go.mongodb.org/mongo-driver/mongo/readpref"
	"go.mongodb.org/mongo-driver/mongo/writeconcern"
)

func main() {
	uri := "mongodb://appuser:securepass@mongo1:27017,mongo2:27017,mongo3:27017/shop_db" +
		"?replicaSet=rsProd&authSource=admin&readPreference=secondaryPreferred&maxPoolSize=150"

	// Программная конфигурация с переопределением параметров
	wc := writeconcern.Majority()
	rp := readpref.SecondaryPreferred()

	clientOpts := options.Client().
		ApplyURI(uri).
		SetWriteConcern(wc).
		SetReadPreference(rp).
		SetConnectTimeout(10 * time.Second).
		SetMaxConnIdleTime(10 * time.Minute)

	fmt.Println("Конфигурация параметров MongoDB Client успешно создана:")
	fmt.Printf("MaxPoolSize: %d\n", *clientOpts.MaxPoolSize)
	fmt.Printf("ReplicaSet: %s\n", *clientOpts.ReplicaSet)
	fmt.Printf("ReadPreference Mode: %v\n", clientOpts.ReadPreference.Mode())

	// Проверяем инициализацию структуры клиента
	_ = clientOpts.Validate()
	ctx, cancel := context.WithTimeout(context.Background(), 1*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, clientOpts)
	if err == nil {
		_ = client.Disconnect(context.Background())
	}
}
```

ℹ️ Программное конфигурирование параметров клиента MongoDB и валидация настроек

**`Терминал`**

```bash

# Конфигурация параметров MongoDB Client успешно создана:
# MaxPoolSize: 150
# ReplicaSet: rsProd
# ReadPreference Mode: secondaryPreferred
```

## Под капотом

Метод `ApplyURI` парсит строку через регулярные выражения и внутренний парсер URI драйвера. При указании параметра `replicaSet` драйвер включает режим автообнаружения топологии: даже если в строке указан только один seed-хост, драйвер выполнит команду `hello` и динамически добавит все остальные узлы реплика-сета в свой внутренний список серверов.

## Подводные камни

Спецсимволы в пароле (например, `@`, `:`, `/`, `?`) в URI строке ОБЯЗАНЫ быть процент-кодированы (URL encoded через `url.QueryEscape`), иначе парсер URI вернет ошибку синтаксиса либо неправильно обрежет пароль.

## На собеседовании

**Вопрос:** Что произойдет при w=majority, если в реплика-сете из 3 нод упали 2 ноды? Какой таймаут сработает?
**Ответ:** Для подтверждения большинства (majority) из 3 узлов требуется подтверждение минимум от 2 узлов (\(3/2 + 1 = 2\)). Если 2 ноды упали, доступен только 1 узел, и кворум записи не может быть собран. Запрос заблокируется и завершится с ошибкой `wtimeout` (если был задан `wtimeoutMS`) либо по таймауту контекста Go.
