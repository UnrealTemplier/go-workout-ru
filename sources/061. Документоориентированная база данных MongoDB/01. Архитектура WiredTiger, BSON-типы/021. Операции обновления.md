# Операции обновления: UpdateOne, UpdateMany и ReplaceOne

## Условие

Используйте `UpdateOne`, `UpdateMany`, `ReplaceOne`. Изучите операторы `$set`, `$unset`, `$inc`, `$push`, `$pull`, `$addToSet`.

### Исходная формулировка

**Update operations**: Используйте `UpdateOne`, `UpdateMany`, `ReplaceOne`. Изучите операторы `$set`, `$unset`, `$inc`, `$push`, `$pull`, `$addToSet`.

## Теория

Модификация документов в MongoDB выполняется тремя методами:
- **`UpdateOne(ctx, filter, update)`:** обновляет первый найденный документ.
- **`UpdateMany(ctx, filter, update)`:** обновляет все подходящие под фильтр документы в рамках единого сетевого запроса.
- **`ReplaceOne(ctx, filter, replacement)`:** полностью заменяет тело документа (сохраняя неизменным только первичный ключ `_id`).

### Справочник операторов обновления:
- **`$set`:** устанавливает значение поля (создает его, если не существовало).
- **`$unset`:** удаляет поле из документа.
- **`$inc`:** инкрементирует числовое поле на положительное/отрицательное значение.
- **`$push`:** добавляет элемент в массив (допускает дубликаты).
- **`$addToSet`:** добавляет элемент в массив, только если такого значения там еще нет (множество уникальных значений).
- **`$pull`:** удаляет из массива элементы, соответствующие критерию.

## Решение по шагам

1. Создайте тестовые записи пользователей.
2. Примените `$set` и `$inc` через `UpdateOne`.
3. Примените `$addToSet` для добавления уникального тега.
4. Примените `$pull` для удаления тега.
5. Примените `$unset` для удаления устаревшего поля.
6. Примените `ReplaceOne` для полной перезаписи документа.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("test").Collection("user_settings")
	_ = coll.Drop(ctx)

	// Создаем исходный документ
	_, _ = coll.InsertOne(ctx, bson.M{
		"username":  "vladimir",
		"logins":    5,
		"tags":      []string{"golang", "docker"},
		"temp_flag": true,
	})

	// 1. UpdateOne с $set, $inc, $unset
	update1 := bson.M{
		"$inc":   bson.M{"logins": 1},
		"$set":   bson.M{"theme": "dark"},
		"$unset": bson.M{"temp_flag": ""},
	}
	_, err = coll.UpdateOne(ctx, bson.M{"username": "vladimir"}, update1)
	if err != nil {
		panic(err)
	}

	// 2. $addToSet (гарантирует уникальность в массиве)
	update2 := bson.M{
		"$addToSet": bson.M{"tags": "kubernetes"},
	}
	_, _ = coll.UpdateOne(ctx, bson.M{"username": "vladimir"}, update2)

	// Повторный addToSet не добавит дубликат
	_, _ = coll.UpdateOne(ctx, bson.M{"username": "vladimir"}, update2)

	// 3. $pull (удаление элемента из массива)
	update3 := bson.M{
		"$pull": bson.M{"tags": "docker"},
	}
	_, _ = coll.UpdateOne(ctx, bson.M{"username": "vladimir"}, update3)

	var doc bson.M
	_ = coll.FindOne(ctx, bson.M{"username": "vladimir"}).Decode(&doc)
	fmt.Printf("Документ после мутаций: %+v\n", doc)

	// 4. ReplaceOne: полная замена тела документа
	newContent := bson.M{
		"username": "vladimir",
		"status":   "archived",
	}
	_, err = coll.ReplaceOne(ctx, bson.M{"username": "vladimir"}, newContent)
	if err != nil {
		panic(err)
	}

	var replacedDoc bson.M
	_ = coll.FindOne(ctx, bson.M{"username": "vladimir"}).Decode(&replacedDoc)
	fmt.Printf("Документ после ReplaceOne: %+v\n", replacedDoc)
}
```

**`Терминал`**

```bash
go run main.go
# Документ после мутаций: map[_id:ObjectID(...) logins:6 tags:[golang kubernetes] theme:dark username:vladimir]
# Документ после ReplaceOne: map[_id:ObjectID(...) status:archived username:vladimir]
```

## Под капотом

Оператор `$addToSet` сканирует массив в документе. Если значение уже найдено, операция завершается без записи в WAL, а `ModifiedCount` возвращается равным 0. Если значение отсутствует, массив расширяется.

## Подводные камни

Случайный вызов `ReplaceOne` вместо `UpdateOne` удалит все существующие поля документа, заменив их новой структурой (сохранится только `_id`). Для частичных изменений всегда используйте `UpdateOne` с явными операторами обновления.

## На собеседовании

**Вопрос:** Чем $push отличается от $addToSet с точки зрения производительности при больших массивах?
**Ответ:** `$push` просто добавляет элемент в конец массива за O(1). `$addToSet` требует последовательного сравнения добавляемого значения со всеми уже существующими элементами массива O(N). На массивах из тысяч элементов `$addToSet` создает заметную нагрузку на CPU сервера.
