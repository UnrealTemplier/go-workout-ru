# Тонкая настройка BSON Tags в Go-структурах

## Условие

Создай структуру, где поле `Email` в Go мапится на поле `email_address` в MongoDB. Поле `Password` должно игнорироваться при сохранении (`bson:"-"`).

### Исходная формулировка

**[BSON Tags]**: Создай структуру, где поле `Email` в Go мапится на поле `email_address` в MongoDB. Поле `Password` должно игнорироваться при сохранении (`bson:"-"`).

## Теория

BSON-сериализатор драйвера анализирует теги структур с помощью пакета `reflect`.

### Полная спецификация BSON-тегов:
- `bson:"custom_name"`: задает кастомное имя поля в документе BSON.
- `bson:"-"`: полностью исключает поле из сериализации и десериализации (идеально для приватных полей, хешей паролей или временных данных сессии).
- `bson:",omitempty"`: опускает поле, если оно имеет нулевое значение (nil, пустая строка, 0, false).
- `bson:",inline"`: встраивает поля вложенной структуры на верхний уровень текущего документа (вместо создания вложенного субдокумента).

## Решение по шагам

1. Объявите структуру `Account` с полями `ID`, `Email`, `PasswordHash`, `InternalToken`.
2. Настройте тег `bson:"email_address"` для поля `Email`.
3. Установите тег `bson:"-"` для `PasswordHash` и `InternalToken`.
4. Сериализуйте структуру в `bson.Raw` и проверьте полученный JSON/BSON документ.
5. Убедитесь, что пароль не сохраняется в MongoDB.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/bson/primitive"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

type SecureUserAccount struct {
	ID            primitive.ObjectID `bson:"_id,omitempty"`
	Username      string             `bson:"username"`
	Email         string             `bson:"email_address"` // Переименование поля
	PasswordHash  string             `bson:"-"`             // Игнорируется драйвером
	SessionSecret string             `bson:"-"`             // Игнорируется драйвером
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("auth_service").Collection("accounts")
	_ = coll.Drop(ctx)

	user := SecureUserAccount{
		Username:      "cyber_gopher",
		Email:         "gopher@golang.org",
		PasswordHash:  "$2a$12$e8Y...super_secret_hash",
		SessionSecret: "jwt_token_memory_only",
	}

	res, err := coll.InsertOne(ctx, user)
	if err != nil {
		panic(err)
	}

	// Считываем сырой документ из базы как bson.M
	var rawDoc bson.M
	err = coll.FindOne(ctx, bson.M{"_id": res.InsertedID}).Decode(&rawDoc)
	if err != nil {
		panic(err)
	}

	fmt.Println("Сырой документ, сохраненный в MongoDB:")
	for k, v := range rawDoc {
		fmt.Printf("  %s: %v\n", k, v)
	}

	if _, exists := rawDoc["PasswordHash"]; exists {
		panic("ОШИБКА: Поле PasswordHash попало в базу данных!")
	}
	if _, exists := rawDoc["password_hash"]; exists {
		panic("ОШИБКА: Поле password_hash попало в базу данных!")
	}
	fmt.Println("\nПроверка безопасности пройдена: приватные поля гарантированно исключены из BSON.")
}
```

ℹ️ Использование тегов bson:"-" и переименования полей

## Под капотом

При запуске программы BSON-энкодер строит внутренний `structDescription` кэш для каждого типа, используя рефлексию один раз. Поля с дефисом `"-"` отсекаются на этапе построения дескриптора, поэтому при последующих сериализациях циклы `Marshal` вообще не тратят процессорное время на обработку игнорируемых полей.

## Подводные камни

Если указать тег `bson:"-"` с пробелом или другими символами (например, `bson:"- ,omitempty"`), драйвер воспримет дефис как буквальное имя поля в документе, и в базе появится документ с полем `"-"`!

## На собеседовании

**Вопрос:** В чем разница между bson:",inline" и обычным вложенным полем структуры?
**Ответ:** По умолчанию вложенная структура `type Address struct` превращается во вложенный BSON субдокумент `{address: {city: "Moscow", zip: 101000}}`. Тег `bson:",inline"` разворачивает поля вложенной структуры на верхний уровень: `{city: "Moscow", zip: 101000}` без создания промежуточного объекта.
