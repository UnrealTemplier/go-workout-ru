# Продвинутая десериализация BSON: omitempty, inline и minsize

## Условие

Используйте `cursor.Decode(&struct)` с `bson` тегами. Изучите `omitempty`, `inline`, `minsize` теги.

### Исходная формулировка

**Decode в структуру**: Используйте `cursor.Decode(&struct)` с `bson` тегами. Изучите `omitempty`, `inline`, `minsize` теги.

## Теория

При десериализации BSON в структуры Go драйвер сопоставляет типы данных и учитывает специализированные теги:
- **`omitempty`:** при маршалинге опускает поле с нулевым значением (уменьшает размер документа в БД).
- **`inline`:** разворачивает поля вложенной структуры на верхний уровень родительского документа без создания субдокумента.
- **`minsize`:** заставляет числовой тип `int64` или `uint64` сохраняться в BSON как 32-битное число `int32`, если значение помещается в 4 байта (экономит 4 байта на каждое число).
- **`truncate`:** разрешает десериализацию `float64` в целочисленные поля Go с отбрасыванием дробной части без ошибки переполнения.

## Решение по шагам

1. Создайте вложенную структуру `AuditMetadata` и встройте ее с тегом `bson:",inline"`.
2. Добавьте поле со счетчиком с тегом `bson:",minsize"`.
3. Добавьте опциональные строковые поля с тегом `bson:",omitempty"`.
4. Вставьте документ и прочитайте его через `Decode`.
5. Проинспектируйте сырой BSON для проверки экономии байт.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

type AuditInfo struct {
	CreatedBy string    `bson:"created_by"`
	CreatedAt time.Time `bson:"created_at"`
}

type ArticleDoc struct {
	Title       string    `bson:"title"`
	Description string    `bson:"desc,omitempty"` // Опускается, если пустая строка
	ViewCount   int64     `bson:"views,minsize"`  // Сохраняется как int32, если число маленькое
	Audit       AuditInfo `bson:",inline"`        // Разворачивается на верхний уровень
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("publishing").Collection("articles")
	_ = coll.Drop(ctx)

	art := ArticleDoc{
		Title:       "Архитектура Go 1.22",
		Description: "", // Пустая строка -> omitempty сработает
		ViewCount:   42, // Маленькое число -> minsize сохранит как int32
		Audit: AuditInfo{
			CreatedBy: "chief_editor",
			CreatedAt: time.Now().UTC().Truncate(time.Second),
		},
	}

	res, err := coll.InsertOne(ctx, art)
	if err != nil {
		panic(err)
	}

	// Читаем сырой документ bson.M
	var raw bson.M
	_ = coll.FindOne(ctx, bson.M{"_id": res.InsertedID}).Decode(&raw)

	fmt.Println("Сырой документ в MongoDB:")
	for k, v := range raw {
		fmt.Printf("  %s: %v (%T)\n", k, v, v)
	}

	// Проверяем инлайн: поля created_by лежат на верхнем уровне
	if _, ok := raw["created_by"]; ok {
		fmt.Println("\nТег inline сработал: поле created_by находится на верхнем уровне документа.")
	}
	if _, ok := raw["desc"]; !ok {
		fmt.Println("Тег omitempty сработал: пустое поле desc отсутствует в BSON.")
	}
}
```

## Под капотом

При использовании `minsize` BSON-энкодер проверяет диапазон: если значение типа `int64` лежит в интервале \([-2^{31}, 2^{31}-1]\), тип BSON элемента выставляется в `0x10` (32-bit integer) вместо `0x12` (64-bit integer), сохраняя 4 байта на каждое поле. В терабайтных базах это экономит сотни гигабайт памяти.

## Подводные камни

Осторожно с `omitempty` для булевых и числовых полей: если значение равно `false` или `0`, поле будет полностью удалено из сохраняемого документа! Если нужно сохранять нулевые значения, используйте указатели `*bool` и `*int` либо не добавляйте `omitempty`.

## На собеседовании

**Вопрос:** Почему вложенные структуры без тега inline могут усложнять построение индексов?
**Ответ:** Без тега `inline` создается вложенный субдокумент `{audit: {created_by: "admin"}}`. Для индексации придется создавать составной ключ по точечной нотации `audit.created_by`. Тег `inline` разворачивает поля, делая их свойствами первого уровня документа, что упрощает запросы и обеспечивает совместимость с плоскими табличными моделями.
