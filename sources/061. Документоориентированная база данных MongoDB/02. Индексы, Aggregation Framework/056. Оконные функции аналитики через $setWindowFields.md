# Оконные функции аналитики через $setWindowFields

## Условие

Используйте `$setWindowFields` (MongoDB 5.0+) для window operations: `$rank`, `$denseRank`, `$documentNumber`, `$shift`.

### Исходная формулировка

**Window functions**: Используйте `$setWindowFields` (MongoDB 5.0+) для window operations: `$rank`, `$denseRank`, `$documentNumber`, `$shift`.

## Теория

Начиная с MongoDB 5.0, Aggregation Pipeline поддерживает полнофункциональные оконные функции (**Window Functions**) через стадию `$setWindowFields`.

### Синтаксис стадии:
```text
$setWindowFields: {
    partitionBy: "$department",
    sortBy: { salary: -1 },
    output: {
        rank: { $denseRank: {} },
        docNum: { $documentNumber: {} },
        prevSalary: { $shift: { output: "$salary", by: -1 } }
    }
}
```
Оконные функции позволяют вычислять ранги, скользящие средние (Rolling Averages) и разницы со следующей/предыдущей строкой без схлопывания строк в группы (в отличие от `$group`).

## Решение по шагам

1. Заполните коллекцию сотрудниками с зарплатами по отделам.
2. Сконструируйте `$setWindowFields` с партиционированием по `department` и сортировкой по `salary` DESC.
3. Вычислите ранг `$denseRank` и разницу с предыдущей зарплатой через `$shift`.
4. Запустите агрегацию и выведите аналитическую табель.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

type RankedEmployee struct {
	Name       string   `bson:"name"`
	Department string   `bson:"department"`
	Salary     float64  `bson:"salary"`
	Rank       int      `bson:"salary_rank"`
	DiffPrev   *float64 `bson:"diff_from_previous"`
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("hr").Collection("salaries")
	_ = coll.Drop(ctx)

	_, _ = coll.InsertMany(ctx, []interface{}{
		bson.M{"name": "Иван", "department": "IT", "salary": 300000.0},
		bson.M{"name": "Мария", "department": "IT", "salary": 300000.0},
		bson.M{"name": "Петр", "department": "IT", "salary": 250000.0},
		bson.M{"name": "Анна", "department": "Sales", "salary": 180000.0},
		bson.M{"name": "Егор", "department": "Sales", "salary": 140000.0},
	})

	// Стадия $setWindowFields
	pipeline := mongo.Pipeline{
		{{Key: "$setWindowFields", Value: bson.D{
			{Key: "partitionBy", Value: "$department"},
			{Key: "sortBy", Value: bson.D{{Key: "salary", Value: -1}}},
			{Key: "output", Value: bson.D{
				{Key: "salary_rank", Value: bson.D{{Key: "$denseRank", Value: bson.D{}}}},
				{Key: "prev_salary", Value: bson.D{{Key: "$shift", Value: bson.D{
					{Key: "output", Value: "$salary"},
					{Key: "by", Value: -1}, // Предыдущий документ в окне
				}}}},
			}},
		}}},
		// Вычисляем разницу с предыдущей зарплатой
		{{Key: "$addFields", Value: bson.D{
			{Key: "diff_from_previous", Value: bson.D{
				{Key: "$subtract", Value: bson.A{"$salary", "$prev_salary"}},
			}},
		}}},
	}

	cur, err := coll.Aggregate(ctx, pipeline)
	if err != nil {
		panic(err)
	}
	defer cur.Close(ctx)

	var results []RankedEmployee
	_ = cur.All(ctx, &results)

	fmt.Println("Аналитический рейтинг зарплат по отделам ($setWindowFields):")
	for _, e := range results {
		diffStr := "N/A (топ отдела)"
		if e.DiffPrev != nil {
			diffStr = fmt.Sprintf("%.2f руб.", *e.DiffPrev)
		}
		fmt.Printf("  Отдел: %-5s | Ранг: %d | %-6s (%.0f руб.) | Разница с лидером: %s\n",
			e.Department, e.Rank, e.Name, e.Salary, diffStr)
	}
}
```

ℹ️ Использование $setWindowFields для ранжирования $denseRank и сдвига $shift


## Под капотом

Движок конвейера группирует входной поток по ключу `partitionBy` в памяти и применяет оконные вычисления на лету. В отличие от SQL баз данных, где требуется материализация временных таблиц, MongoDB выполняет конвейерный расчет за один проход, если входные данные отсортированы по индексу.

## Подводные камни

В `$setWindowFields` использование окна `window: { documents: ["unbounded", "current"] }` на больших коллекциях накапливает документы в памяти mongod, поэтому для скользящих окон всегда задавайте границы числом строк, например `[-5, 0]`.

## На собеседовании

**Вопрос:** В чем разница между $rank и $denseRank в оконных функциях?
**Ответ:** При наличии одинаковых значений (ties): `$rank` пропускает последующие ранги (например: 1, 1, 3); `$denseRank` не образует пропусков в нумерации рангов (например: 1, 1, 2).
