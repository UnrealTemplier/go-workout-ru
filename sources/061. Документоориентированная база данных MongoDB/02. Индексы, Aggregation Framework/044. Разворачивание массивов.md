# Разворачивание массивов: стадия $unwind и preserveNullAndEmptyArrays

## Условие

Используйте `$unwind` для "разворачивания" массивов в отдельные документы. Поймите `preserveNullAndEmptyArrays`.

### Исходная формулировка

**$unwind**: Используйте `$unwind` для "разворачивания" массивов в отдельные документы. Поймите `preserveNullAndEmptyArrays`.

## Теория

Стадия `$unwind` выполняет деконструкцию поля-массива в документе. Для каждого элемента массива создается отдельная копия документа.

### Опция `preserveNullAndEmptyArrays`:
По умолчанию (`false`):
- Если массив пуст (`[]`) — документ полностью удаляется.
- Если поле отсутствует (`missing`) — документ удаляется.
- Если поле равно `null` — документ удаляется.

При значении `true`:
Документы с пустыми массивами или отсутствующими полями сохраняются в потоке (поле становится `null`), что критически важно при имитации SQL **LEFT OUTER JOIN** после стадии `$lookup`!

## Решение по шагам

1. Создайте пользователей: с заполненными хобби, с пустым массивом и без поля вообще.
2. Примените `$unwind` без опции: покажите потерю документов.
3. Примените `$unwind` с `preserveNullAndEmptyArrays: true` и сохраните всех пользователей.
4. Проанализируйте различия в количестве и структуре документов.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("test").Collection("unwind_demo")
	_ = coll.Drop(ctx)

	// Заполняем 3 документа с разным состоянием массива
	_, _ = coll.InsertMany(ctx, []interface{}{
		bson.M{"name": "Илья", "skills": []string{"Go", "Docker"}},
		bson.M{"name": "Петр", "skills": []string{}}, // Пустой массив!
		bson.M{"name": "Антон"},                       // Поля нет вообще!
	})

	// 1. $unwind по умолчанию (preserveNullAndEmptyArrays: false)
	pipeDefault := mongo.Pipeline{
		{{Key: "$unwind", Value: "$skills"}},
	}
	cur1, _ := coll.Aggregate(ctx, pipeDefault)
	var resDefault []bson.M
	_ = cur1.All(ctx, &resDefault)
	fmt.Printf("[Обычный $unwind] Документов на выходе: %d\n", len(resDefault))
	for _, r := range resDefault {
		fmt.Printf("  - %s -> %v\n", r["name"], r["skills"])
	}

	// 2. $unwind с preserveNullAndEmptyArrays: true
	pipePreserve := mongo.Pipeline{
		{{Key: "$unwind", Value: bson.D{
			{Key: "path", Value: "$skills"},
			{Key: "preserveNullAndEmptyArrays", Value: true},
		}}},
	}
	cur2, _ := coll.Aggregate(ctx, pipePreserve)
	var resPreserve []bson.M
	_ = cur2.All(ctx, &resPreserve)
	fmt.Printf("\n[preserveNullAndEmptyArrays: true] Документов на выходе: %d\n", len(resPreserve))
	for _, r := range resPreserve {
		fmt.Printf("  - %s -> %v\n", r["name"], r["skills"])
	}
}
```

ℹ️ Разворачивание массивов с сохранением документов с пустыми полями

**`Терминал`**

```bash
go run main.go
# [Обычный $unwind] Документов на выходе: 2
#   - Илья -> Go
#   - Илья -> Docker
# 
# [preserveNullAndEmptyArrays: true] Документов на выходе: 4
#   - Илья -> Go
#   - Илья -> Docker
#   - Петр -> <nil>
#   - Антон -> <nil>
```

## Под капотом

Стадия `$unwind` поддерживает дополнительную опцию `includeArrayIndex: "idx"`. Если ее задать, MongoDB автоматически добавит в каждый выходной документ целое число с порядковым номером элемента в исходном срезе (начиная с 0), что позволяет точно восстановить исходную последовательность данных.

## Подводные камни

Забытый флаг `preserveNullAndEmptyArrays: true` после `$lookup` превращает предполагаемый LEFT JOIN в INNER JOIN, тихо отбрасывая пользователей без заказов или статьи без комментариев.

## На собеседовании

**Вопрос:** Что произойдет, если передать в $unwind поле, которое не является массивом, а содержит обычную строку или число?
**Ответ:** Если значением поля является скаляр (строка, число, объект), `$unwind` обработает его как массив из одного элемента и вернет ровно один документ без изменений. Ошибка возникает только если указать неверный тип синтаксиса пути.
