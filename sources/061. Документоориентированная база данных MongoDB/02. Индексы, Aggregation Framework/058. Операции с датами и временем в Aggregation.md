# Операции с датами и временем в Aggregation Pipeline

## Условие

Используйте `$year`, `$month`, `$dayOfMonth`, `$dateToString`, `$dateAdd`, `$dateDiff` для работы с датами.

### Исходная формулировка

**Date operations**: Используйте `$year`, `$month`, `$dayOfMonth`, `$dateToString`, `$dateAdd`, `$dateDiff` для работы с датами.

## Теория

MongoDB предоставляет богатый набор операторов для манипуляции датами и временем в часовых поясах:
- **`$dateToString`:** форматирует BSON Date в строку по шаблону (например, `"%Y-%m-%d"`).
- **`$year`, `$month`, `$dayOfMonth`, `$hour`:** извлекают компоненты даты с учетом `timezone`.
- **`$dateAdd` / `$dateSubtract`:** прибавляют или вычитают временные интервалы (`unit: "day"`, `"hour"`, `"month"`).
- **`$dateDiff`:** вычисляет разницу между двумя датами в заданных единицах измерения (дни, часы, секунды).

## Решение по шагам

1. Создайте коллекцию подписок пользователей с датами начала и окончания.
2. Сконструируйте конвейер с `$dateDiff` для расчета оставшихся дней подписки.
3. Добавьте стадию `$dateToString` для форматирования дат в формат ДД.ММ.ГГГГ.
4. Выведите аналитический отчет по активным подпискам.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

type SubscriptionReport struct {
	UserID        int64  `bson:"user_id"`
	StartDateStr  string `bson:"start_date_formatted"`
	DaysRemaining int64  `bson:"days_remaining"`
	ExpiryYear    int    `bson:"expiry_year"`
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("saas").Collection("subscriptions")
	_ = coll.Drop(ctx)

	now := time.Now().UTC()
	_, _ = coll.InsertMany(ctx, []interface{}{
		bson.M{"user_id": int64(101), "started_at": now.AddDate(0, -2, 0), "expires_at": now.AddDate(0, 10, 0)},
		bson.M{"user_id": int64(102), "started_at": now.AddDate(0, -1, 0), "expires_at": now.AddDate(0, 0, 15)},
	})

	// Pipeline с операциями дат: $dateDiff, $dateToString, $year
	pipeline := mongo.Pipeline{
		{{Key: "$project", Value: bson.D{
			{Key: "_id", Value: 0},
			{Key: "user_id", Value: 1},
			// Форматирование даты
			{Key: "start_date_formatted", Value: bson.D{
				{Key: "$dateToString", Value: bson.D{
					{Key: "format", Value: "%d.%m.%Y"},
					{Key: "date", Value: "$started_at"},
					{Key: "timezone", Value: "Europe/Moscow"},
				}},
			}},
			// Разница между expires_at и текущим моментом в днях
			{Key: "days_remaining", Value: bson.D{
				{Key: "$dateDiff", Value: bson.D{
					{Key: "startDate", Value: "$$NOW"},
					{Key: "endDate", Value: "$expires_at"},
					{Key: "unit", Value: "day"},
				}},
			}},
			// Извлечение года
			{Key: "expiry_year", Value: bson.D{{Key: "$year", Value: "$expires_at"}}},
		}}},
	}

	cur, err := coll.Aggregate(ctx, pipeline)
	if err != nil {
		panic(err)
	}
	defer cur.Close(ctx)

	var reports []SubscriptionReport
	_ = cur.All(ctx, &reports)

	fmt.Println("Анализ дат подписок пользователей ($dateDiff, $dateToString):")
	for _, r := range reports {
		fmt.Printf("  User #%d: Старт=%s | Осталось дней: %d | Истекает в %d году\n",
			r.UserID, r.StartDateStr, r.DaysRemaining, r.ExpiryYear)
	}
}
```

ℹ️ Операции $dateDiff, $dateToString и $$NOW для работы с временными рядами

**`Терминал`**

```bash
go run main.go
# Анализ дат подписок пользователей ($dateDiff, $dateToString):
#   User #101: Старт=04.07.2026 | Осталось дней: 304 | Истекает в 2027 году
#   User #102: Старт=04.08.2026 | Осталось дней: 15 | Истекает в 2026 году
```

## Под капотом

Системная переменная `$$NOW` возвращает текущую временную метку кластера в формате UTC. Она вычисляется один раз в начале выполнения конвейера, гарантируя одинаковое значение времени для всех документов независимо от длительности выполнения запроса.

## Подводные камни

Если не указывать параметр `timezone`, MongoDB по умолчанию форматирует дату в UTC `+00:00`. Это может привести к сдвигу даты на 1 день назад для пользователей в восточных часовых поясах при переходе через полночь.

## На собеседовании

**Вопрос:** Чем отличается $dateTrunc от округления дат через форматирование строк?
**Ответ:** `$dateTrunc` округляет саму дату BSON `Date` до начала часа, дня или месяца (например, `unit: "month"`), сохраняя тип данных `Date`. Это позволяет индексировать и сортировать результат гораздо быстрее, чем при строковом преобразовании через `$dateToString`.
