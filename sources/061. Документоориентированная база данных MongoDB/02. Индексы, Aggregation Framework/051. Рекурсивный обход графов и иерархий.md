# Рекурсивный обход графов и иерархий через $graphLookup

## Условие

Используйте для рекурсивного обхода графов (например, иерархия категорий, org chart).

### Исходная формулировка

**$graphLookup**: Используйте для рекурсивного обхода графов (например, иерархия категорий, org chart).

## Теория

Стадия **`$graphLookup`** выполняет рекурсивный поиск в глубину/ширину по коллекции, моделируя графовые и древовидные структуры (деревья категорий, организационная структура компании, социальные связи).

### Ключевые параметры $graphLookup:
- **`from`:** целевая коллекция для поиска (может быть той же самой коллекцией).
- **`startWith`:** начальное выражение (например, ID руководителя).
- **`connectFromField`:** поле в найденном документе, по которому строится следующий переход.
- **`connectToField`:** поле в целевом документе, с которым сравнивается `connectFromField`.
- **`as`:** имя поля-массива для накопления результатов обхода.
- **`maxDepth`:** ограничение глубины рекурсии (защита от зацикливания).
- **`depthField`:** имя поля, в которое MongoDB запишет глубину уровня (0 — прямой подчиненный, 1 — подчиненный второго уровня и т.д.).

## Решение по шагам

1. Создайте коллекцию `employees` с иерархией подчинения через поле `reports_to`.
2. Сконструируйте `$graphLookup` для нахождения всей цепочки подчиненных конкретного менеджера.
3. Задайте `depthField: "level"` и ограничение `maxDepth: 3`.
4. Запустите агрегацию и выведите дерево подчиненных.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

type Subordinate struct {
	Name      string `bson:"name"`
	Title     string `bson:"title"`
	DepthLevel int    `bson:"level"`
}

type ManagerOrgChart struct {
	Name         string        `bson:"name"`
	Title        string        `bson:"title"`
	Subordinates []Subordinate `bson:"subordinates"`
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("company").Collection("org_structure")
	_ = coll.Drop(ctx)

	// Иерархия: CEO -> CTO -> Tech Lead -> Dev
	_, _ = coll.InsertMany(ctx, []interface{}{
		bson.M{"name": "Игорь", "title": "CEO", "reports_to": nil},
		bson.M{"name": "Артем", "title": "CTO", "reports_to": "Игорь"},
		bson.M{"name": "Сергей", "title": "Tech Lead", "reports_to": "Артем"},
		bson.M{"name": "Ольга", "title": "Go Developer", "reports_to": "Сергей"},
		bson.M{"name": "Дмитрий", "title": "Frontend Lead", "reports_to": "Артем"},
	})

	// Находим CTO (Артем) и рекурсивно поднимаем всех его подчиненных ($graphLookup)
	pipeline := mongo.Pipeline{
		{{Key: "$match", Value: bson.D{{Key: "name", Value: "Артем"}}}},
		{{Key: "$graphLookup", Value: bson.D{
			{Key: "from", Value: "org_structure"},
			{Key: "startWith", Value: "$name"},
			{Key: "connectFromField", Value: "name"},
			{Key: "connectToField", Value: "reports_to"},
			{Key: "as", Value: "subordinates"},
			{Key: "maxDepth", Value: 2},
			{Key: "depthField", Value: "level"},
		}}},
	}

	cur, err := coll.Aggregate(ctx, pipeline)
	if err != nil {
		panic(err)
	}
	defer cur.Close(ctx)

	var charts []ManagerOrgChart
	_ = cur.All(ctx, &charts)

	ctoChart := charts[0]
	fmt.Printf("Руководитель: %s (%s)\n", ctoChart.Name, ctoChart.Title)
	fmt.Printf("Все подчиненные (прямые и непрямые через $graphLookup): %d чел.\n", len(ctoChart.Subordinates))
	for _, sub := range ctoChart.Subordinates {
		indent := "  "
		for i := 0; i <= sub.DepthLevel; i++ {
			indent += "--"
		}
		fmt.Printf("%s [Уровень %d] %s (%s)\n", indent, sub.DepthLevel, sub.Name, sub.Title)
	}
}
```

ℹ️ Рекурсивный обход иерархии подчинения в компании с вычислением depthField

**`Терминал`**

```bash

# Все подчиненные (прямые и непрямые через $graphLookup): 3 чел.
#   -- [Уровень 0] Сергей (Tech Lead)
#   -- [Уровень 0] Дмитрий (Frontend Lead)
#   ---- [Уровень 1] Ольга (Go Developer)
```

## Под капотом

Движок `$graphLookup` использует алгоритм BFS (Breadth-First Search) в оперативной памяти. Для каждого посещенного узла запоминается его идентификатор для предотвращения бесконечных циклов в циклических графах.

## Подводные камни

Если в поле `connectToField` отсутствует индекс, на каждом шаге рекурсии MongoDB будет выполнять COLLSCAN всей коллекции, что мгновенно 'положит' CPU сервера при глубоких графах.
