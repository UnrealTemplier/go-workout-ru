# Продвинутая стадия $group и все аккумуляторы

## Условие

Используйте `$group` для агрегации по `_id` с `$sum`, `$avg`, `$min`, `$max`, `$push`, `$addToSet`.

### Исходная формулировка

**$group stage**: Используйте `$group` для агрегации по `_id` с `$sum`, `$avg`, `$min`, `$max`, `$push`, `$addToSet`.

## Теория

Стадия `$group` является вычислительным ядром аналитики MongoDB.

### Полный арсенал аккумуляторов:
- **`$sum: <expr>`:** сумма числовых значений (или `$sum: 1` для подсчета количества).
- **`$avg: <expr>`:** среднее арифметическое.
- **`$min` / `$max`:** нахождение экстремумов (минимального и максимального значения в группе).
- **`$push: <expr>`:** накапливает значения всех документов группы в массив (сохраняет дубликаты и порядок).
- **`$addToSet: <expr>`:** накапливает только уникальные значения в массив (автоматическая дедупликация).
- **`$first` / `$last`:** возвращает значение из первого или последнего документа группы (эффективно в сочетании с предшествующей стадией `$sort`).

## Решение по шагам

1. Заполните коллекцию логами покупок в интернет-магазине.
2. Сконструируйте стадию `$group` по категории товара `_id: "$category"`.
3. Примените аккумуляторы: выручка (`$sum`), средний чек (`$avg`), мин/макс цена, список всех артикулов (`$push`) и список уникальных брендов (`$addToSet`).
4. Выполните агрегацию и выведите сводный аналитический отчет.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

type CategorySummary struct {
	Category      string   `bson:"_id"`
	TotalRevenue  float64  `bson:"total_revenue"`
	AveragePrice  float64  `bson:"avg_price"`
	MinPrice      float64  `bson:"min_price"`
	MaxPrice      float64  `bson:"max_price"`
	AllItems      []string `bson:"all_items"`
	UniqueBrands  []string `bson:"unique_brands"`
	TotalSalesQty int      `bson:"sales_count"`
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("shop_analytics").Collection("sales")
	_ = coll.Drop(ctx)

	// Заполняем продажи
	_, _ = coll.InsertMany(ctx, []interface{}{
		bson.M{"category": "Электроника", "brand": "Sony", "model": "WH-1000XM5", "price": 35000.0},
		bson.M{"category": "Электроника", "brand": "Apple", "model": "AirPods Pro", "price": 22000.0},
		bson.M{"category": "Электроника", "brand": "Sony", "model": "PlayStation 5", "price": 55000.0},
		bson.M{"category": "Книги", "brand": "O'Reilly", "model": "Designing Data-Intensive Apps", "price": 4500.0},
		bson.M{"category": "Книги", "brand": "Питер", "model": "Go на практике", "price": 1800.0},
	})

	pipeline := mongo.Pipeline{
		{{Key: "$group", Value: bson.D{
			{Key: "_id", Value: "$category"},
			{Key: "total_revenue", Value: bson.D{{Key: "$sum", Value: "$price"}}},
			{Key: "avg_price", Value: bson.D{{Key: "$avg", Value: "$price"}}},
			{Key: "min_price", Value: bson.D{{Key: "$min", Value: "$price"}}},
			{Key: "max_price", Value: bson.D{{Key: "$max", Value: "$price"}}},
			{Key: "all_items", Value: bson.D{{Key: "$push", Value: "$model"}}},
			{Key: "unique_brands", Value: bson.D{{Key: "$addToSet", Value: "$brand"}}},
			{Key: "sales_count", Value: bson.D{{Key: "$sum", Value: 1}}},
		}}},
	}

	cur, err := coll.Aggregate(ctx, pipeline)
	if err != nil {
		panic(err)
	}
	defer cur.Close(ctx)

	var summaries []CategorySummary
	if err := cur.All(ctx, &summaries); err != nil {
		panic(err)
	}

	fmt.Println("Сводная статистика по товарным категориям:")
	for _, s := range summaries {
		fmt.Printf("Категория: %s (Продаж: %d)\n", s.Category, s.TotalSalesQty)
		fmt.Printf("  Выручка:     %.2f руб. (Средний чек: %.2f руб.)\n", s.TotalRevenue, s.AveragePrice)
		fmt.Printf("  Диапазон цен:%.2f ... %.2f руб.\n", s.MinPrice, s.MaxPrice)
		fmt.Printf("  Все товары:  %v\n", s.AllItems)
		fmt.Printf("  Уникальные бренды: %v\n\n", s.UniqueBrands)
	}
}
```

## Под капотом

При выполнении `$group` MongoDB инициализирует в памяти хэш-таблицу. Ключом выступает вычисленный `_id`, а значением — структура аккумуляторов. Для `$addToSet` используется внутренняя хэш-таблица уникальных значений, тогда как `$push` просто добавляет элементы в динамический массив без проверок.

## Подводные камни

Накопление массивов через `$push` в группе с миллионами элементов может превысить лимит размера BSON-документа (16 МБ) на выходе стадии `$group`, что вызовет фатальную ошибку `BSONObjectTooLarge`.

## На собеседовании

**Вопрос:** Как сгруппировать вообще ВСЕ документы коллекции в одну группу для подсчета общих итогов?
**Ответ:** В поле `_id` стадии `$group` передается значение `nil`: `bson.D{{"_id", nil}}`. В этом случае все входные документы конвейера попадают в один глобальный бакет, позволяя вычислить общую сумму, среднее или экстремумы по всей коллекции.
