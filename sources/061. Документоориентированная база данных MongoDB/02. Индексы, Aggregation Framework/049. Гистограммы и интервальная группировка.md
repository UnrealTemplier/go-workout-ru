# Гистограммы и интервальная группировка: $bucket и $bucketAuto

## Условие

Используйте `$bucket` и `$bucketAuto` для создания гистограмм и диапазонов.

### Исходная формулировка

**$bucket и $bucketAuto**: Используйте для создания гистограмм и диапазонов.

## Теория

Для построения распределений данных (гистограмм цен, возраста пользователей, распределения времени отклика API) используются две специализированные стадии:
1. **`$bucket`:** группирует документы по явно заданным границам диапазонов (`boundaries`, например: `[0, 5000, 20000, 100000]`).
2. **`$bucketAuto`:** автоматически вычисляет оптимальные границы интервалов для заданного количества бакетов (`buckets: N`), стремясь распределить документы по бакетам равномерно (квантили).

## Решение по шагам

1. Заполните коллекцию товарами с ценами от 500 до 150 000 руб.
2. Сконструируйте стадию `$bucket` с границами: до 10 000 (бюджет), 10 000–50 000 (средний), 50 000+ (премиум).
3. Примените аккумуляторы для подсчета количества и среднего чека в каждом бакете.
4. Выполните агрегацию и постройте сводную гистограмму цен.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

type PriceBucketResult struct {
	RangeMin float64 `bson:"_id"`
	Count    int     `bson:"count"`
	AvgPrice float64 `bson:"avg_price"`
	Titles   []string`bson:"titles"`
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("analytics").Collection("products_bucket")
	_ = coll.Drop(ctx)

	_, _ = coll.InsertMany(ctx, []interface{}{
		bson.M{"title": "Чехол для телефона", "price": 800.0},
		bson.M{"title": "Кабель Type-C", "price": 1200.0},
		bson.M{"title": "Наушники Bluetooth", "price": 4500.0},
		bson.M{"title": "Умные часы", "price": 15000.0},
		bson.M{"title": "Планшет", "price": 35000.0},
		bson.M{"title": "Игровой ноутбук", "price": 140000.0},
	})

	// Стадия $bucket: границы [0, 5000), [5000, 50000), [50000, 200000)
	pipeline := mongo.Pipeline{
		{{Key: "$bucket", Value: bson.D{
			{Key: "groupBy", Value: "$price"},
			{Key: "boundaries", Value: bson.A{0.0, 5000.0, 50000.0, 200000.0}},
			{Key: "default", Value: "Other"},
			{Key: "output", Value: bson.D{
				{Key: "count", Value: bson.D{{Key: "$sum", Value: 1}}},
				{Key: "avg_price", Value: bson.D{{Key: "$avg", Value: "$price"}}},
				{Key: "titles", Value: bson.D{{Key: "$push", Value: "$title"}}},
			}},
		}}},
	}

	cur, err := coll.Aggregate(ctx, pipeline)
	if err != nil {
		panic(err)
	}
	defer cur.Close(ctx)

	var buckets []PriceBucketResult
	if err := cur.All(ctx, &buckets); err != nil {
		panic(err)
	}

	fmt.Println("Гистограмма распределения цен ($bucket):")
	for _, b := range buckets {
		var categoryName string
		switch b.RangeMin {
		case 0.0:
			categoryName = "Бюджетный сегмент (0 - 5 000 руб.)"
		case 5000.0:
			categoryName = "Средний сегмент   (5 000 - 50 000 руб.)"
		case 50000.0:
			categoryName = "Премиум сегмент   (50 000+ руб.)"
		default:
			categoryName = "Прочие товары"
		}
		fmt.Printf("%s:\n", categoryName)
		fmt.Printf("  Количество: %d шт. | Средняя цена: %.2f руб.\n", b.Count, b.AvgPrice)
		fmt.Printf("  Товары: %v\n\n", b.Titles)
	}
}
```

## Под капотом

Массив `boundaries` обязан быть строго отсортирован по возрастанию и содержать минимум 2 элемента одного типа. Каждая корзина включает нижнюю границу и исключает верхнюю: `[нижняя, верхняя)`. Документы, выходящие за пределы диапазона, попадают в специальную корзину `default`.

## Подводные камни

Если документ содержит значение `price`, превышающее максимальную границу `boundaries` (или меньшее минимальной), а параметр `default` не задан, запрос завершится фатальной ошибкой `The field ... is not contained within the boundaries`.

## На собеседовании

**В чем разница между $bucket и $bucketAuto?**
**Ответ:** В `$bucket` инженер вручную жестко задает границы интервалов (например, для фиксированных тарифных сеток или возрастных категорий). В `$bucketAuto` указывается только желаемое число корзин `N`: сервер автоматически рассчитывает границы на основе квантилей распределения данных, пытаясь наполнить корзины равным количеством документов.
