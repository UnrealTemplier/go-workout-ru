# Многомерная аналитика и фасетный поиск через $facet

## Условие

Используйте `$facet` для выполнения нескольких aggregations в одном запросе (например, для facet-фильтров в e-commerce).

### Исходная формулировка

**$facet**: Используйте `$facet` для выполнения нескольких aggregations в одном запросе (например, для facet-фильтров в e-commerce).

## Теория

Стадия **`$facet`** позволяет внутри единого запроса к базе разветвить конвейер обработки на несколько независимых параллельных подконвейеров над одним и тем же входящим потоком документов!

### Типовой сценарий в E-Commerce:
Когда пользователь вводит поисковый запрос (например, «ноутбук»), интернет-магазину нужно одновременно за **один round-trip**:
1. Посчитать количество товаров по брендам (Apple: 15, Dell: 12, Asus: 30) для бокового фильтра.
2. Посчитать статистику цен (минимальная, максимальная, средняя).
3. Вернуть пагинированную первую страницу товаров (первые 10 товаров с сортировкой по рейтингу).

Без `$facet` бэкенду пришлось бы делать 3 отдельных тяжелых запроса к базе!

## Решение по шагам

1. Заполните коллекцию товаров с полями `brand`, `price`, `rating`.
2. Сконструируйте стадию `$facet` с тремя ветками:
   - `by_brand`: `$group` по бренду с подсчетом количества.
   - `price_stats`: вычисление min/max/avg цен.
   - `paginated_items`: `$sort` по рейтингу и `$limit: 2`.
3. Запустите конвейер и разберите многомерный результат.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

type BrandBucket struct {
	Brand string `bson:"_id"`
	Count int    `bson:"count"`
}

type PriceStats struct {
	MinPrice float64 `bson:"min"`
	MaxPrice float64 `bson:"max"`
	AvgPrice float64 `bson:"avg"`
}

type ProductItem struct {
	Name   string  `bson:"name"`
	Price  float64 `bson:"price"`
	Rating float64 `bson:"rating"`
}

type FacetSearchResult struct {
	ByBrand        []BrandBucket `bson:"by_brand"`
	PriceStats     []PriceStats  `bson:"price_stats"`
	PaginatedItems []ProductItem `bson:"paginated_items"`
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("catalog").Collection("gadgets")
	_ = coll.Drop(ctx)

	_, _ = coll.InsertMany(ctx, []interface{}{
		bson.M{"name": "MacBook Air", "brand": "Apple", "price": 110000.0, "rating": 4.9},
		bson.M{"name": "MacBook Pro", "brand": "Apple", "price": 240000.0, "rating": 5.0},
		bson.M{"name": "Dell XPS 13", "brand": "Dell", "price": 160000.0, "rating": 4.7},
		bson.M{"name": "Dell Inspiron", "brand": "Dell", "price": 75000.0, "rating": 4.3},
		bson.M{"name": "Asus ZenBook", "brand": "Asus", "price": 95000.0, "rating": 4.6},
	})

	// Стадия $facet с 3 независимыми подпайплайнами
	pipeline := mongo.Pipeline{
		{{Key: "$facet", Value: bson.D{
			// Ветка 1: Фасет по брендам
			{Key: "by_brand", Value: mongo.Pipeline{
				{{Key: "$group", Value: bson.D{
					{Key: "_id", Value: "$brand"},
					{Key: "count", Value: bson.D{{Key: "$sum", Value: 1}}},
				}}},
				{{Key: "$sort", Value: bson.D{{Key: "count", Value: -1}}}},
			}},
			// Ветка 2: Статистика цен
			{Key: "price_stats", Value: mongo.Pipeline{
				{{Key: "$group", Value: bson.D{
					{Key: "_id", Value: nil},
					{Key: "min", Value: bson.D{{Key: "$min", Value: "$price"}}},
					{Key: "max", Value: bson.D{{Key: "$max", Value: "$price"}}},
					{Key: "avg", Value: bson.D{{Key: "$avg", Value: "$price"}}},
				}}},
			}},
			// Ветка 3: Пагинированный список лучших товаров
			{Key: "paginated_items", Value: mongo.Pipeline{
				{{Key: "$sort", Value: bson.D{{Key: "rating", Value: -1}}}},
				{{Key: "$limit", Value: 2}},
			}},
		}}},
	}

	cur, err := coll.Aggregate(ctx, pipeline)
	if err != nil {
		panic(err)
	}
	defer cur.Close(ctx)

	var results []FacetSearchResult
	if err := cur.All(ctx, &results); err != nil {
		panic(err)
	}

	facet := results[0]
	fmt.Println("=== 1. Фасетные фильтры по брендам ===")
	for _, b := range facet.ByBrand {
		fmt.Printf("  - %-6s: %d товаров\n", b.Brand, b.Count)
	}

	fmt.Println("\n=== 2. Статистика диапазона цен ===")
	if len(facet.PriceStats) > 0 {
		ps := facet.PriceStats[0]
		fmt.Printf("  Мин: %.2f руб. | Макс: %.2f руб. | Средняя: %.2f руб.\n",
			ps.MinPrice, ps.MaxPrice, ps.AvgPrice)
	}

	fmt.Println("\n=== 3. Топ-2 товара каталога по рейтингу ===")
	for _, it := range facet.PaginatedItems {
		fmt.Printf("  - %-15s (Цена: %.2f руб., Рейтинг: %.1f)\n", it.Name, it.Price, it.Rating)
	}
}
```

ℹ️ Многомерная фасетная агрегация в один запрос через $facet

## Под капотом

Движок конвейера считывает входящие документы и направляет их копии в каждый подконвейер стадии `$facet`. Выходной документ стадии `$facet` всегда строго один и содержит поля-массивы с результатами каждого подпайплайна.

## Подводные камни

Каждая ветка `$facet` ограничена лимитом памяти 100 МБ. Если один из подпайплайнов накапливает гигантский объем документов в оперативной памяти, весь `$facet` завершится ошибкой. Перед `$facet` обязательно применяйте строгий `$match`.

## На собеседовании

**Вопрос:** Можно ли использовать стадию $indexStats или другие специальные стадии внутри веток $facet?
**Ответ:** Нет. Внутри подконвейеров `$facet` запрещены стадии `$facet`, `$out`, `$merge`, `$changeStream`, `$collStats` и `$indexStats`.
