# Добавление вычисляемых полей через стадию $addFields

## Условие

Используйте `$addFields` для добавления вычисляемых полей без удаления существующих.

### Исходная формулировка

**$addFields**: Используйте `$addFields` для добавления вычисляемых полей без удаления существующих.

## Теория

В отличие от `$project`, где необходимо явно перечислять **все** сохраняемые поля (иначе неперечисленные поля отбрасываются), стадия **`$addFields`** (синоним `$set` в aggregation pipeline):
- Сохраняет абсолютно все существующие поля документа.
- Добавляет новые вычисляемые поля.
- Перезаписывает существующие поля новыми вычисленными значениями при совпадении имени.

Это идеальный инструмент для расчета динамических полей (НДС, маржа, форматирование дат, конкатенация строк) в середине конвейера.

## Решение по шагам

1. Создайте коллекцию с ценами товаров без учета налога.
2. Сконструируйте стадию `$addFields` с вычислением НДС (20%) и итоговой цены через `$multiply` и `$add`.
3. Добавьте вычисляемое строковое поле статуса через `$concat`.
4. Выполните агрегацию и проверьте сохранение исходных полей.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"

	"go.mongodb.org/mongo-driver/bson"
	"go.mongodb.org/mongo-driver/mongo"
	"go.mongodb.org/mongo-driver/mongo/options"
)

type ProductWithTax struct {
	SKU         string  `bson:"sku"`
	BasePrice   float64 `bson:"base_price"`
	VatAmount   float64 `bson:"vat_amount"`
	FinalPrice  float64 `bson:"final_price"`
	DisplayCode string  `bson:"display_code"`
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	client, err := mongo.Connect(ctx, options.Client().ApplyURI("mongodb://localhost:27017"))
	if err != nil {
		panic(err)
	}
	defer client.Disconnect(ctx)

	coll := client.Database("retail").Collection("pricing")
	_ = coll.Drop(ctx)

	_, _ = coll.InsertMany(ctx, []interface{}{
		bson.M{"sku": "SSD-1TB", "base_price": 8000.0},
		bson.M{"sku": "RAM-32GB", "base_price": 12000.0},
	})

	// Pipeline с $addFields:
	// vat_amount = base_price * 0.20
	// final_price = base_price + vat_amount
	// display_code = "ITEM-" + sku
	pipeline := mongo.Pipeline{
		{{Key: "$addFields", Value: bson.D{
			{Key: "vat_amount", Value: bson.D{{Key: "$multiply", Value: bson.A{"$base_price", 0.20}}}},
			{Key: "display_code", Value: bson.D{{Key: "$concat", Value: bson.A{"ITEM-", "$sku"}}}},
		}}},
		{{Key: "$addFields", Value: bson.D{
			{Key: "final_price", Value: bson.D{{Key: "$add", Value: bson.A{"$base_price", "$vat_amount"}}}},
		}}},
	}

	cur, err := coll.Aggregate(ctx, pipeline)
	if err != nil {
		panic(err)
	}
	defer cur.Close(ctx)

	var items []ProductWithTax
	if err := cur.All(ctx, &items); err != nil {
		panic(err)
	}

	fmt.Println("Товары с вычисленным НДС и финальной ценой ($addFields):")
	for _, it := range items {
		fmt.Printf("  Код: %-12s | Базовая: %8.2f | НДС(20%%): %7.2f | Итоговая: %8.2f руб.\n",
			it.DisplayCode, it.BasePrice, it.VatAmount, it.FinalPrice)
	}
}
```

ℹ️ Использование $addFields для обогащения документов новыми вычисляемыми полями

**`Терминал`**

```bash

# Товары с вычисленным НДС и финальной ценой ($addFields):
#   Код: ITEM-SSD-1TB | Базовая:  8000.00 | НДС(20%): 1600.00 | Итоговая:  9600.00 руб.
#   Код: ITEM-RAM-32GB| Базовая: 12000.00 | НДС(20%): 2400.00 | Итоговая: 14400.00 руб.
```

## Под капотом

Движок конвейера оптимизирует стадию `$addFields`, добавляя новые значения в эфемерную виртуальную BSON-структуру в оперативной памяти без повторного копирования неизмененных байтовых срезов документа.

## Подводные камни

Если в рамках одного блока `$addFields` попытаться использовать только что вычисленное в этом же блоке поле (например, `final_price: {$add: ["$base_price", "$vat_amount"]}`), MongoDB вернет `null`, так как выражения внутри одной стадии вычисляются параллельно. Для зависимости полей необходимо разносить их на две последовательные стадии `$addFields`.

## На собеседовании

**Вопрос:** В чем принципиальная разница между $project и $addFields?
**Ответ:** `$project` пересоздает форму документа заново (white-listing): все не указанные явно поля удаляются. `$addFields` (или `$set`) сохраняет исходную форму документа и производит точечное добавление или мутацию указанных полей, что значительно надежнее при частых изменениях схемы и добавлении новых колонок.
