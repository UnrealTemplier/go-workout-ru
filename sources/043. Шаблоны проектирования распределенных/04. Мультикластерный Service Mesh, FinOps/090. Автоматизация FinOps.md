# Автоматизация FinOps: выявление аномалий облачных расходов и устранение неиспользуемых ресурсов

## Условие

Реализуй **FinOps Automation**: automated anomaly detection in cloud spend, rightsizing recommendations, waste elimination. Детектор аномалий: alert if daily spend > 1.5 * moving_avg(30d). Waste cleaner: delete unattached EBS volumes, idle ELBs.

### Исходная формулировка

**Service Mesh (Istio/Linkerd)**: Внедрите service mesh для mTLS, traffic management, observability без изменения кода.

## Теория

Автоматизация контроля облачного бюджета (FinOps Waste Elimination):
- В крупных компаниях со 100 командами разработки до 35% облачного счета тратится впустую:
  - Забытые тестовые балансировщики (ELB/ALB), генерирующие $30/мес каждый.
  - Неприкрепленные диски (Unattached EBS Volumes) после удаления подов, стоящие сотни долларов в месяц.
  - Утечки памяти в фоновых циклах, вызывающие несанкционированный автоскейлинг до 50 нод.
- **FinOps Automation Bot на Go:**
  1. Ежедневно сканирует AWS/Yandex Cloud API.
  2. Обнаруживает диски со статусом `available` (не прикреплены к серверам) старше 7 дней и отправляет их в архив/удаляет.
  3. Детектирует финансовые аномалии: `daily_spend > 1.5 * moving_average(30 days)`.

## Решение по шагам

1. Создайте структуру детектора аномалий расходов.
2. Реализуйте алгоритм сравнения с 30-дневной скользящей средней.
3. Смоделируйте обнаружение забытых дисков (Cloud Waste).
4. Верифицируйте корректность финансовых алертов.

## Код решения

**`finops_anomaly_waste_test.go`**

```go
package main

import (
	"fmt"
	"testing"
)

type UnattachedVolume struct {
	VolumeID     string
	SizeGB       int
	DaysDetached int
}

func DetectCloudSpendAnomaly(todaySpend float64, movingAvg30d float64) (bool, string) {
	// Аномалия: суточный расход превышает средний более чем в 1.5 раза
	threshold := 1.5 * movingAvg30d
	if todaySpend > threshold {
		return true, fmt.Sprintf("FINOPS CRITICAL ALERT: Today spend $%.2f exceeds 1.5x threshold ($%.2f)",
			todaySpend, threshold)
	}
	return false, "SPEND_NORMAL"
}

func PurgeUnattachedVolumes(volumes []UnattachedVolume) []string {
	var deletedIDs []string
	for _, v := range volumes {
		// Диски, открепленные более 7 дней, считаются забытыми (Waste)
		if v.DaysDetached > 7 {
			deletedIDs = append(deletedIDs, v.VolumeID)
		}
	}
	return deletedIDs
}

func TestFinOpsAnomalyWaste(t *testing.T) {
	// 1. Детекция аномалии (разработчик забыл выключить GPU-кластер на ночь)
	isAnomaly, alertMsg := DetectCloudSpendAnomaly(4500.0, 2000.0)
	if !isAnomaly {
		t.Fatal("Скачок расходов обязан вызвать финансовый алерт")
	}

	// 2. Очистка бесхозных дисков
	volumes := []UnattachedVolume{
		{VolumeID: "vol-active-1", SizeGB: 100, DaysDetached: 2},
		{VolumeID: "vol-waste-99", SizeGB: 500, DaysDetached: 14}, // забытый диск!
	}

	purged := PurgeUnattachedVolumes(volumes)
	if len(purged) != 1 || purged[0] != "vol-waste-99" {
		t.Fatalf("Некорректная очистка дисков: %v", purged)
	}

	fmt.Println("Автоматизация FinOps (Anomaly Detection & Waste Elimination) подтверждена:")
	fmt.Printf("  • Обнаружена аномалия счета: %s\n", alertMsg)
	fmt.Printf("  • Удалены забытые диски:     %v (Сэкономлено на 500 ГБ SSD в месяц)\n", purged)
}
```

ℹ️ Автоматическое обнаружение финансовых аномалий облака и удаление неиспользуемых дисков

## Под капотом

В AWS утилита Cloud Custodian на базе правил YAML и бессерверных лямбд перехватывает события AWS CloudTrail: если диск открепляется от инстанса, ему вешается тег `mark_for_deletion: now + 7 days`, давая инженеру неделю на сохранение данных.

## Подводные камни

Удалять неприкрепленные диски немедленно в момент отсоединения: при плановой перезагрузке инстанса или переключении пода диск отсоединяется на 30 секунд. Немедленное удаление уничтожит боевые данные.

## На собеседовании

**Вопрос с собеседования:** «Что такое Commitment Based Discounts (Savings Plans / Reserved Instances)?»
**Ответ:** Это долгосрочное обязательство компании выкупать определенный объем вычислительных мощностей (например 500 CPU ядер) непрерывно в течение 1–3 лет. Облачный провайдер предоставляет за это скидку от 40% до 60% по сравнению с почасовым тарифом On-Demand.
