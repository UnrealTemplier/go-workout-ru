# Системный дизайн видеоплатформы (Netflix-like): пайплайн транскодирования, DRM и адаптивный стриминг

## Условие

Спроектируй **Video Streaming Platform** (Netflix-like):
- Upload: raw video → transcoding pipeline (multiple resolutions, codecs) → storage
- Playback: CDN edge nodes, adaptive bitrate (HLS/DASH), DRM
- Recommendation: real-time + batch ML, A/B testing
- Scale: 200M users, 10M concurrent streams, 4K HDR
- Architecture: microservices, chaos engineering, multi-region

## Теория

Архитектура глобального онлайн-кинотеатра масштаба 200M пользователей:
1. **Транскодирование контента (Ingest & Transcoding Pipeline):**
   - Сырой мастер-файл в формате ProRes (500 ГБ) заливается в защищенный S3.
   - Микросервис нарезки режет видео на двухминутные сцены.
   - Сотни Spot-воркеров на GPU параллельно перекодируют сцены в форматы AV1, HEVC, H.264 во всех разрешениях (от 360p до 4K HDR).
2. **DRM & Защита контента:**
   - Чанки видео шифруются стандартом Common Encryption (CENC).
   - Лицензионный сервер отдает сессионные ключи дешифрования через Apple FairPlay / Google Widevine.
3. **Open Connect CDN:**
   - Физические серверы кэширования (Netflix OCA) устанавливаются прямо внутри дата-центров местных интернет-провайдеров.

package main

import (
	"fmt"
	"testing"
)

type TranscodeVariant struct {
	Codec      string
	Resolution string
	TargetBandwidthMbps float64
}

func GetStreamingEncodings() []TranscodeVariant {
	return []TranscodeVariant{
		{"AV1", "3840x2160 (4K HDR)", 12.0},
		{"HEVC", "1920x1080 (FHD)", 4.5},
		{"H.264", "1280x720 (HD)", 2.0},
		{"H.264", "854x480 (SD)", 0.8},
	}
}

func TestNetflixArchitecture(t *testing.T) {
	encodings := GetStreamingEncodings()

	if len(encodings) != 4 {
		t.Fatal("Ожидалось 4 профиля кодирования")
	}

	fmt.Println("Архитектурный проект глобального видеостриминга (Netflix-like):")
	for _, e := range encodings {
		fmt.Printf("  • Кодек: %-6s | Разрешение: %-20s | Битрейт: %.1f Мбит/с\n",
			e.Codec, e.Resolution, e.TargetBandwidthMbps)
	}
	fmt.Println("  • Open Connect CDN раздает 95% трафика непосредственно из сетей провайдеров")
}

## Под капотом

Netflix использует технологию **Dynamic Optimizer (Per-Title & Per-Shot Encoding)**: сложность сцен анализируется покадрово. Статичные сцены кодируются с минимальным битрейтом, а динамичные экшн-сцены — с повышенным, экономя до 30% мирового интернет-трафика.

## Подводные камни

Транскодировать видео целиком в один поток: двухчасовой фильм в 4K будет кодироваться 5 часов. Видео режут на чанки по сценам и параллельно распределяют на 200 GPU-нод в облаке, получая готовый фильм за 4 минуты.

## На собеседовании

**Вопрос с собеседования:** «Как работает предварительный прогрев CDN перед выходом популярного сериала (Pre-positioning)?»
**Ответ:** За 24 часа до мировой премьеры ночью (во время спада трафика) файлы сериала проактивно закачиваются на тысячи серверов Open Connect CDN по всему миру. В момент релиза 100% зрителей смотрят видео из локального кэша без нагрузки на транскодеры.
