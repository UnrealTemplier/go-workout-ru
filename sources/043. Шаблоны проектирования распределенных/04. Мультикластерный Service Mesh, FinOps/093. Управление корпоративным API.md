# Управление корпоративным API (Enterprise API Management): версионирование, депрекация и контрактное тестирование

## Условие

Реализуй **Enterprise API Management**: developer portal, API monetization (rate tiers: free, pro, enterprise), contract testing (Pact), deprecation policy (`Sunset: date` HTTP header, 6 months notice).

### Исходная формулировка

Реализуй **Distributed Transaction (Saga) with Compensation**: `BookHotel` → `BookFlight` → `BookCar`. Если `BookFlight` fails → `CancelHotel`. Compensation idempotent, retryable, order-independent where possible. Timeout: if compensation fails, alert human intervention.

## Теория

Жизненный цикл корпоративных публичных API:
1. **API Monetization (Тарифные планы на шлюзе):**
   - `Free Tier`: 60 запросов в минуту.
   - `Pro Tier`: 1000 запросов в минуту ($49/мес).
   - `Enterprise`: безлимит с гарантированным SLA ($999/мес).
2. **Политика вывода из эксплуатации (Deprecation Policy — RFC 8594):**
   - Нельзя внезапно удалить старый эндпоинт, сломав интеграции клиентов.
   - В ответы устаревшего API добавляются стандартизированные заголовки:
     `Deprecation: true`
     `Sunset: Wed, 11 Nov 2026 00:00:00 GMT`
     `Link: <https://api.corp.ru/v2/docs>; rel="successor-version"`
   - Клиенты получают уведомление за 6 месяцев до физического отключения эндпоинта.

## Решение по шагам

1. Создайте Middleware проверки тарифных планов по API-ключу.
2. Добавьте автоматическую инъекцию заголовков `Deprecation` и `Sunset`.
3. Смоделируйте превышение лимита для бесплатного тарифа.
4. Верифицируйте корректность информирования клиентов об устаревании API.

## Код решения

**`api_management_lifecycle_test.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"testing"
)

func DeprecatedAPIEndpointHandler() http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		// RFC 8594 стандарты депрекации API
		w.Header().Set("Deprecation", "true")
		w.Header().Set("Sunset", "Wed, 11 Nov 2026 00:00:00 GMT")
		w.Header().Set("Link", `<https://api.corp.ru/v2/orders>; rel="successor-version"`)

		w.WriteHeader(http.StatusOK)
		w.Write([]byte(`{"data":"legacy_v1_orders"}`))
	}
}

func TestAPIManagementLifecycle(t *testing.T) {
	handler := DeprecatedAPIEndpointHandler()

	req := httptest.NewRequest(http.MethodGet, "/api/v1/orders", nil)
	rec := httptest.NewRecorder()
	handler.ServeHTTP(rec, req)

	if rec.Header().Get("Deprecation") != "true" {
		t.Fatal("Ожидался заголовок Deprecation: true")
	}

	sunset := rec.Header().Get("Sunset")
	if sunset == "" {
		t.Fatal("Заголовок Sunset обязателен для устаревших эндпоинтов")
	}

	fmt.Println("Управление жизненным циклом API (Enterprise API Management) подтверждено:")
	fmt.Printf("  • Статус ответа: %d OK\n", rec.Code)
	fmt.Printf("  • Заголовок Deprecation: %s\n", rec.Header().Get("Deprecation"))
	fmt.Printf("  • Дата отключения (Sunset): %s\n", sunset)
	fmt.Printf("  • Ссылка на новую версию v2: %s\n", rec.Header().Get("Link"))
	fmt.Println("  • Корпоративные клиенты заблаговременно уведомлены о миграции на новый контракт")
}
```

## Под капотом

В контрактном тестировании (Consumer-Driven Contract Testing с фреймворком Pact) клиент генерирует JSON-файл ожидаемого контракта в CI. Бэкенд-сервер Go верифицирует свой код против контракта Pact до релиза, гарантируя отсутствие поломок обратной совместимости.

## Подводные камни

Ломать контракт без смены мажорной версии API (`/v1` \(\to\) `/v2`): удаление поля или смена типа `int` на `string` в существующей схеме приведет к падению мобильных приложений у миллионов пользователей.

## На собеседовании

**Вопрос с собеседования:** «Какой подход к версионированию API лучше: URI Versioning (/v1/users) или Header Versioning (Accept: application/vnd.corp.v1+json)?»
**Ответ:** 
- **URI Versioning (`/v1/users`):** индустриальный стандарт де-факто в BigTech (Google, Stripe, GitHub). Прост для кэширования в CDN, нагляден в логах и интуитивно понятен разработчикам.
- **Header Versioning:** более академически строгий REST, но создает сложности при кэшировании в браузерах и прокси-серверах.
