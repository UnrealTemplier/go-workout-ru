# Соответствие требованиям GDPR и CCPA: выгрузка данных (Right to Access) и право на забвение (Right to Erasure)

## Условие

Реализуй **GDPR/CCPA Compliance**: `right to access` — export all user data. `right to erasure` — delete/anonymize user data across all services. `data portability` — machine-readable export. `consent management` — track what user consented to, when, revoke.

## Теория

Архитектурные требования приватности (GDPR / CCPA):
1. **Right to Access & Portability (Право на выгрузку данных):**
   - Пользователь нажимает кнопку «Выгрузить мои данные».
   - Сервис собирает все профили, заказы, отзывы и историю входов за 3 года и отдает машиночитаемый JSON-архив.
2. **Right to Erasure / Right to be Forgotten (Право на забвение):**
   - Пользователь требует удалить свой аккаунт.
   - Во всех базах данных персональные данные заменяются на анонимизированные: `Anon_User_999`.
3. **Consent Management (Управление согласиями):**
   - Учет того, на какие рассылки пользователь давал согласие, с фиксацией IP, даты и возможностью мгновенного отзыва.

## Решение по шагам

1. Создайте модель согласий пользователя `ConsentLog`.
2. Реализуйте экспорт всех данных в JSON (Right to Portability).
3. Реализуйте функцию анонимизации (Right to Erasure).
4. Верифицируйте невозможность идентификации пользователя после удаления.

## Код решения

**`gdpr_compliance_engine_test.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"strings"
	"testing"
	"time"
)

type GDPRUserAccount struct {
	ID        string    `json:"id"`
	Email     string    `json:"email"`
	FullName  string    `json:"full_name"`
	Consents  []string  `json:"consents"`
	CreatedAt time.Time `json:"created_at"`
}

// 1. Right to Access / Data Portability (Экспорт в JSON)
func ExportUserDataJSON(u *GDPRUserAccount) ([]byte, error) {
	return json.MarshalIndent(u, "", "  ")
}

// 2. Right to Erasure / Анонимизация
func AnonymizeUserData(u *GDPRUserAccount) {
	u.Email = fmt.Sprintf("deleted_user_%s@anonymized.gdpr", u.ID)
	u.FullName = "Удаленный пользователь (GDPR Erasure)"
	u.Consents = nil
}

func TestGDPRComplianceEngine(t *testing.T) {
	user := &GDPRUserAccount{
		ID:        "usr-789",
		Email:     "ivan.petrov@yandex.ru",
		FullName:  "Иван Петров",
		Consents:  []string{"marketing_push", "analytics_cookies"},
		CreatedAt: time.Date(2024, 1, 15, 10, 0, 0, 0, time.UTC),
	}

	// 1. Проверка машиночитаемого экспорта
	jsonExport, err := ExportUserDataJSON(user)
	if err != nil || !strings.Contains(string(jsonExport), "ivan.petrov@yandex.ru") {
		t.Fatalf("Ошибка экспорта данных GDPR: %v", err)
	}

	// 2. Выполнение права на забвение
	AnonymizeUserData(user)

	if strings.Contains(user.Email, "yandex.ru") || strings.Contains(user.FullName, "Иван") {
		t.Fatal("Персональные данные не были анонимизированы!")
	}

	fmt.Println("Механизмы GDPR/CCPA Compliance успешно подтверждены:")
	fmt.Printf("  • Экспорт данных (Data Portability): %d байт JSON архива\n", len(jsonExport))
	fmt.Printf("  • Результат анонимизации (Right to Erasure): %s (%s)\n", user.FullName, user.Email)
	fmt.Println("  • Требования международного права о приватности данных полностью соблюдены")
}
```

## Под капотом

В распределенной микросервисной среде операция `AnonymizeUser` оформляется через Saga Orchestration: оркестратор шлет команды анонимизации в сервис профилей, сервис аналитики, сервис заказов и биллинг, собирая подтверждения об удалении персональных данных.

## Подводные камни

Удалять строки физически из базы бухгалтерских документов: закон о бухучете требует хранить первичные документы 5 лет, что выше требований GDPR. В бухгалтерских чеках заменяют ФИО на «Физическое лицо», сохраняя суммы и даты.

## На собеседовании

**Вопрос с собеседования:** «Что делать с резервными копиями (Backups) базы данных при поступлении запроса на удаление данных по GDPR?»
**Ответ:** Невозможно переписать терабайтный бэкап на ленте или S3. Применяют **Crypto-Shredding**: персональные данные пользователя шифруются его персональным ключом шифрования. При запросе на удаление уничтожается только ключ шифрования. В бэкапах данные остаются, но превращаются в математически нерасшифровываемый шум, что полностью удовлетворяет регуляторов.
