# Получатели методов: IncrementValue() (значение) vs IncrementPointer() (указатель) для Counter

## Условие

Получатели методов: Для структуры Counter (поле value int) напишите два метода: IncrementValue() с получателем-значением ((c Counter)) и IncrementPointer() с получателем-указателем ((c *Counter)). Вызовите оба метода и проверьте, какой из них действительно увеличивает счетчик в исходном объекте.

### Исходная формулировка

**Получатели методов**: Для структуры `Counter` (поле `value int`) напишите два метода:
* `IncrementValue()` с получателем-значением (`(c Counter)`).
* `IncrementPointer()` с получателем-указателем (`(c *Counter)`).
Вызовите оба метода и проверьте, какой из них действительно увеличивает счетчик в исходном объекте.

## Теория

Практическое сравнение поведения счетчиков при разных получателях.

## Решение по шагам

1. Создаем структуру `Counter{value int}`.
2. Пишем `(c Counter) IncrementValue()`.
3. Пишем `(c *Counter) IncrementPointer()`.
4. Сравниваем результаты.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Counter struct {
	value int
}

func (c Counter) IncrementValue() {
	c.value++ // Изменяет копию
}

func (c *Counter) IncrementPointer() {
	c.value++ // Изменяет оригинал
}

func main() {
	cnt := Counter{value: 10}

	cnt.IncrementValue()
	fmt.Printf("1. После IncrementValue:   %d (не изменился)\n", cnt.value)

	cnt.IncrementPointer()
	fmt.Printf("2. После IncrementPointer: %d (УВЕЛИЧЕН!)\n", cnt.value)
}
```

**`Терминал`**

```bash
go run main.go
# 1. После IncrementValue:   10 (не изменился)
# 2. После IncrementPointer: 11 (УВЕЛИЧЕН!)
```

## Под капотом

`IncrementPointer` изменяет ячейку памяти напрямую по адресу.

## Подводные камни

- Вызов метода на копии.

## На собеседовании

**Ответ:** Да, линтер `govet` (проверка `copylocks` и `lostcancel`) и `staticcheck` предупреждают о бесполезных присваиваниях в Value Receiver.
