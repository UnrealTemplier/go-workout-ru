# Теги структуры type User struct { Name string `json:'name'` } и валидация схемы

## Условие

Создай структуру с тегами (struct tags) `type User struct { Name string `json:"name"` }`.

## Теория

Базовое объявление структуры с тегами сериализации.

## Решение по шагам

1. Создаем структуру с тегами.
2. Маршалим в JSON.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
)

type User struct {
	Name string `json:"name"`
}

func main() {
	u := User{Name: "Gopher"}
	data, _ := json.Marshal(u)
	fmt.Printf("JSON: %s\n", string(data))
}
```

**`Терминал`**

```bash
go run main.go
# JSON: {"name":"Gopher"}
```
