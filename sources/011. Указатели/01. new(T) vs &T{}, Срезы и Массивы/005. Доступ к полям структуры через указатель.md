# Доступ к полям структуры через указатель: синтаксический сахар u.Name vs (*u).Name

## Условие

Создайте структуру `User` с полями `Name` и `Age`. Создайте указатель на неё и измените поля, используя как оператор `.`, так и разыменование `(*u).Name`.

## Теория

**Автоматическое разыменование структур в Go:**
- В C++ для указателей на структуры используется оператор стрелочки `u->Name`;
- В Go оператора `->` нет! Компилятор автоматически подставляет разыменование при обращении через точку: `u.Name` \(\equiv\) `(*u).Name`.

## Решение по шагам

1. Создаем структуру `User{Name string, Age int}`.
2. Создаем `u := &User{Name: "Дмитрий", Age: 30}`.
3. Меняем поля через `(*u).Age` и `u.Name`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type User struct {
	Name string
	Age  int
}

func main() {
	u := &User{Name: "Дмитрий", Age: 30}

	// 1. Явное разыменование:
	(*u).Age = 31

	// 2. Идиоматичный синтаксический сахар Go (неявное разыменование):
	u.Name = "Дмитрий Владимирович"

	fmt.Printf("Обновленный профиль: %+v\n", *u)
}
```

**`Терминал`**

```bash
go run main.go
# Обновленный профиль: {Name:Дмитрий Владимирович Age:31}
```

## Под капотом

Смещение полей `Age` вычисляется компилятором на этапе компиляции (offset 16 байт после строки `Name`).

## Подводные камни

- Написание `*u.Age`: из-за приоритета операторов это парсится как `*(u.Age)` (ошибка компиляции, если `Age` не указатель).

## На собеседовании

**Вопрос с собеседования:** «Почему создатели Go отказались от оператора `->`?»
**Ответ:** Для упрощения синтаксиса языка: компилятор Go всегда знает тип переменной и автоматически разыменовывает указатель при доступе к полю или вызове метода.
