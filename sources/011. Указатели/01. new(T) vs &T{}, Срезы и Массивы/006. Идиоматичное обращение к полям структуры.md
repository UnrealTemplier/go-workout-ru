# Идиоматичное обращение к полям структуры без явного разыменования ptr.Name

## Условие

Используйте указатель на структуру, обратитесь к полям без явного разыменования (`ptr.Name`).

## Теория

Закрепление чистого идиоматичного стиля работы со структурами через указатели.

## Решение по шагам

1. Создаем структуру `ServerConfig`.
2. Инициализируем через `&ServerConfig{...}`.
3. Читаем и меняем поля через `ptr.Field`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type ServerConfig struct {
	Host string
	Port int
	TLS  bool
}

func main() {
	cfg := &ServerConfig{
		Host: "localhost",
		Port: 8080,
		TLS:  true,
	}

	// Прямой доступ к полям через указатель:
	fmt.Printf("Подключение к %s:%d (TLS: %t)\n", cfg.Host, cfg.Port, cfg.TLS)

	cfg.Port = 443
	fmt.Printf("Обновленный порт: %d\n", cfg.Port)
}
```

**`Терминал`**

```bash
go run main.go
# Подключение к localhost:8080 (TLS: true)
# Обновленный порт: 443
```

## Под капотом

Прямая инструкция `MOVL $443, 16(AX)`.

## Подводные камни

- Вызов `cfg.Port` при `cfg == nil` вызовет панику `nil pointer dereference`.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество передачи конфигурации `*Config` в конструкторы сервисов?»
**Ответ:** Избегание копирования памяти и возможность использования синглтон-паттерна с централизованным обновлением настроек.
