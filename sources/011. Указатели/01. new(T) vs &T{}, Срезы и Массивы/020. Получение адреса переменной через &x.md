# Получение адреса переменной через &x и форматированный вывод указателя %p

## Условие

**Получение адреса**: Объяви переменную `x := 42`. Получи её адрес в памяти через оператор `&` и выведи его.

## Теория

Спецификатор `%p` выводит адрес в шестнадцатеричном формате с префиксом `0x`.

## Решение по шагам

1. Создаем `x := 42`.
2. Выводим `fmt.Printf("%p
", &x)`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	x := 42
	fmt.Printf("Значение: %d | Адрес в памяти: %p\n", x, &x)
}
```

**`Терминал`**

```bash
go run main.go
# Значение: 42 | Адрес в памяти: 0xc000018030
```

## Под капотом

Форматирование 64-битного беззнакового целого `uintptr`.

## Подводные камни

- Печать указателя через `%d` (ошибка линтера `go vet`).

## На собеседовании

**Вопрос с собеседования:** «Какой глагол `fmt` выводит адрес переменной?»
**Ответ:** Спецификатор `%p`.
