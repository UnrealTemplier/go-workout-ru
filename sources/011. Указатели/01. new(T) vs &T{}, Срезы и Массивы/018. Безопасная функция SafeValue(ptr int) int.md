# Безопасная функция SafeValue(ptr *int) int со значением по умолчанию (Nil-Safety Helper)

## Условие

Проверьте указатель на `nil` перед разыменованием; реализуйте безопасную функцию получения значения по указателю.

## Теория

**Паттерн Nil-Safe Value Helper:**
- Часто применяется при парсинге JSON/Protobuf/GraphQL;
- Возвращает значение по указателю или дефолтное значение (Zero Value), если указатель равен `nil`.

## Решение по шагам

1. Пишем generic-функцию `ValueOrDefault[T any](ptr *T, def T) T`.
2. Тестируем на `nil` и валидном указателе.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func ValueOrDefault[T any](ptr *T, def T) T {
	if ptr == nil {
		return def
	}
	return *ptr
}

func main() {
	var nilScore *int
	validScore := 85

	fmt.Printf("1. nilScore:   %d (дефолт)\n", ValueOrDefault(nilScore, 0))
	fmt.Printf("2. validScore: %d\n", ValueOrDefault(&validScore, 0))
}
```

**`Терминал`**

```bash
go run main.go
# 1. nilScore:   0 (дефолт)
# 2. validScore: 85
```

## Под капотом

Условный переход `TESTQ AX, AX; JZ default`.
