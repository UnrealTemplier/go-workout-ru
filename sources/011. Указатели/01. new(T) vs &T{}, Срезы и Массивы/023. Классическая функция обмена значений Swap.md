# Классическая функция обмена значений Swap(a, b *int) через указатели

## Условие

Напиши функцию `Swap(a, b *int)`, которая меняет значения двух переменных через указатели. Проверь работу.

## Теория

Обмен значений в памяти по адресам: `*a, *b = *b, *a`.

## Решение по шагам

1. Пишем `Swap(a, b *int)`.
2. Проверяем `a != nil && b != nil`.
3. Меняем значения местами.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Swap(a, b *int) {
	if a == nil || b == nil {
		return
	}
	*a, *b = *b, *a // Множественное присваивание в Go
}

func main() {
	x, y := 100, 200
	fmt.Printf("До Swap:    x = %d, y = %d\n", x, y)

	Swap(&x, &y)

	fmt.Printf("После Swap: x = %d, y = %d\n", x, y)
}
```

**`Терминал`**

```bash
go run main.go
# До Swap:    x = 100, y = 200
# После Swap: x = 200, y = 100
```

## Под капотом

Значения временно сохраняются в регистрах CPU перед записью по адресам.

## Подводные камни

- Вызов `Swap(nil, &y)` без проверки на `nil`.

## На собеседовании

**Вопрос с собеседования:** «Нужна ли временная переменная `tmp` при обмене `*a, *b = *b, *a`?»
**Ответ:** Нет, компилятор Go использует регистры процессора для одновременного обмена.
