# Реализация swap(a, b *int) и сравнение со swap кортежем a, b = b, a

## Условие

Реализуйте классический `swap(a, b *int)`.

## Теория

Сравнение локального свопа `x, y = y, x` и межфункционального `swap(&x, &y)`.

## Решение по шагам

1. Демонстрируем оба подхода.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func swap(a, b *int) {
	*a, *b = *b, *a
}

func main() {
	// 1. Локальный swap без функций:
	a, b := 1, 2
	a, b = b, a
	fmt.Printf("Локальный swap: a=%d, b=%d\n", a, b)

	// 2. Через функцию и указатели:
	swap(&a, &b)
	fmt.Printf("Через swap(&a, &b): a=%d, b=%d\n", a, b)
}
```

**`Терминал`**

```bash
go run main.go
# Локальный swap: a=2, b=1
# Через swap(&a, &b): a=1, b=2
```

## Под капотом

Инлайнинг функции `swap`.

## Подводные камни

- Попытка передать `swap(a, b)` без `&`.
