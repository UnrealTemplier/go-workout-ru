# Перенаправление указателя на другую переменную через **int

## Условие

Функция, принимающая `*int`, должна изменить сам указатель на другую переменную — понадобится `**int`.

## Теория

Сравнение передачи `*int` (копия адреса) и `**int` (ссылка на переменную указателя).

## Решение по шагам

1. Создаем переменные `a := 10`, `b := 20`.
2. Пишем функцию `Redirect(target **int, newTarget *int)`.
3. Меняем целевую переменную.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Redirect(target **int, newTarget *int) {
	*target = newTarget // Меняем адрес в оригинальном указателе
}

func main() {
	a, b := 10, 20
	ptr := &a

	fmt.Printf("1. ptr указывает на a: *ptr = %d (адрес: %p)\n", *ptr, ptr)

	Redirect(&ptr, &b)

	fmt.Printf("2. ptr указывает на b: *ptr = %d (адрес: %p)\n", *ptr, ptr)
}
```

**`Терминал`**

```bash
go run main.go
# 1. ptr указывает на a: *ptr = 10 (адрес: 0xc000018030)
# 2. ptr указывает на b: *ptr = 20 (адрес: 0xc000018038)
```

## Под капотом

Запись адреса `&b` в переменную `ptr`.

## Подводные камни

- Попытка сделать `target = newTarget` внутри `func Foo(target *int)`: изменит только локальную копию указателя.

## На собеседовании

**Вопрос с собеседования:** «Передаются ли указатели в Go по значению?»
**Ответ:** ДА! Все аргументы в Go передаются СТРОГО по значению (указатель копируется как 8-байтный адрес).
