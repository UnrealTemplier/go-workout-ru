# Выделение памяти через new(int) и модификация значения через указатель

## Условие

Используй встроенную функцию `new()` для создания указателя на `int` со значением 0. Измени значение через указатель.

## Теория

Закрепление `new(T)` и оператора `*p = ...`.

## Решение по шагам

1. Создаем `p := new(int)`.
2. Присваиваем `*p = 500`.
3. Печатаем результат.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	p := new(int)
	fmt.Printf("1. После new:  *p = %d\n", *p)

	*p = 500
	fmt.Printf("2. После *p=500: *p = %d\n", *p)
}
```

**`Терминал`**

```bash
go run main.go
# 1. После new:  *p = 0
# 2. После *p=500: *p = 500
```

## Под капотом

Зануление памяти аллокатором.

## Подводные камни

- Забыть оператор разыменования `*p`.

## На собеседовании

**Вопрос с собеседования:** «Чем `var x int; p := &x` отличается от `p := new(int)`?»
**Ответ:** Ничем, они дают абсолютно одинаковый результат и ассемблерный код.
