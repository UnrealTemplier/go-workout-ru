# Операторы адресации & и разыменования * в языке Go

## Условие

Создайте переменную, получите её адрес с помощью `&`, сохраните его в указатель и выведите значение указателя и значение по адресу (`*`).

## Теория

**Базовые операции с указателями:**
- `&x`: оператор взятия адреса памяти переменной `x` (возвращает `*T`);
- `*p`: оператор разыменования (доступ к значению, хранящемуся по адресу `p`).

## Решение по шагам

1. Объявляем `x := 42`.
2. Сохраняем `ptr := &x`.
3. Печатаем адрес `ptr` и разыменованное значение `*ptr`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	score := 42
	ptr := &score // ptr имеет тип *int

	fmt.Printf("1. Значение score:            %d\n", score)
	fmt.Printf("2. Адрес в памяти (&score):   %p\n", &score)
	fmt.Printf("3. Значение указателя ptr:    %p\n", ptr)
	fmt.Printf("4. Разыменование (*ptr):      %d\n", *ptr)

	// Изменяем значение по адресу:
	*ptr = 100
	fmt.Printf("5. score после *ptr = 100:    %d\n", score)
}
```

**`Терминал`**

```bash
go run main.go
# 1. Значение score:            42
# 2. Адрес в памяти (&score):   0xc000018030
# 3. Значение указателя ptr:    0xc000018030
# 4. Разыменование (*ptr):      42
# 5. score после *ptr = 100:    100
```

## Под капотом

Инструкция процессора `MOVQ (ptr), RAX` читает 8 байт по адресу из регистра.

## Подводные камни

- Попытка взять адрес константы `&42` или `&"hello"` (ошибка компиляции `cannot take the address of literal`).

## На собеседовании

**Вопрос с собеседования:** «Можно ли в Go выполнять адресную арифметику `ptr++` как в C/C++?»
**Ответ:** В стандартном Go — НЕТ (для безопасности памяти). Адресная арифметика разрешена только через пакет `unsafe` и тип `unsafe.Pointer`.
