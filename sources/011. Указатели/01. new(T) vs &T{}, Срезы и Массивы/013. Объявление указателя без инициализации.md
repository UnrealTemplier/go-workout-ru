# Объявление указателя без инициализации и проверка на nil

## Условие

Объяви указатель на `int` без начального значения. Выведи его (должен быть `<nil>`).

## Теория

Zero Value указателя любого типа в Go — это `nil`.

## Решение по шагам

1. Объявляем `var p *int`.
2. Печатаем значение и адрес.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var p *int
	fmt.Printf("Указатель p: %v\n", p)
	fmt.Printf("Проверка на nil: %t\n", p == nil)
}
```

**`Терминал`**

```bash
go run main.go
# Указатель p: <nil>
# Проверка на nil: true
```

## Под капотом

8 байт нулей в стековом слоте.

## Подводные камни

- Разыменование `*p` без проверки.

## На собеседовании

**Вопрос с собеседования:** «Каково zero value любого указателя?»
**Ответ:** `nil`.
