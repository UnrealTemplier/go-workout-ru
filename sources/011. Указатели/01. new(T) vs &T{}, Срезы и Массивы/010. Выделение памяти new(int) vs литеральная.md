# Выделение памяти new(int) vs литеральная инициализация &Person{}

## Условие

Создайте переменные через `new(int)` и `&int{}` (для структур `&Person{}`), объясните разницу.

## Теория

Сравнение примитивных указателей и указателей на составные типы.

## Решение по шагам

1. Создаем `pInt := new(int)`.
2. Создаем `pPerson := &Person{Name: "Илья"}`.
3. Сравниваем работу.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Person struct {
	Name string
}

func main() {
	// Для примитивных типов:
	pInt := new(int)
	*pInt = 42

	// Для структур:
	pPerson := &Person{Name: "Илья"}

	fmt.Printf("pInt:    %T -> %d\n", pInt, *pInt)
	fmt.Printf("pPerson: %T -> %+v\n", pPerson, *pPerson)
}
```

**`Терминал`**

```bash
go run main.go
# pInt:    *int -> 42
# pPerson: *main.Person -> {Name:Илья}
```

## Под капотом

Аллокация в стеке или куче в зависимости от escape-анализа.

## Подводные камни

- Попытка написать `&int{42}` — синтаксическая ошибка (в Go нет литералов примитивных типов через `{}`).

## На собеседовании

**Вопрос с собеседования:** «Как в Go лаконично получить указатель на примитивное значение (например `*string` или `*bool`)?»
**Ответ:** Через вспомогательную generic-функцию `func Ptr[T any](v T) *T { return &v }`.
