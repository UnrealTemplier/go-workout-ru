# Типы указателей *int, *string, *bool и строгая типизация

## Условие

**Типы указателей**: Создайте переменные типов `int`, `string`, `bool`. Создайте для каждой из них указатель. Выведите типы этих указателей с помощью `%T`.

## Теория

**Строгая типизация указателей в Go:**
- Указатели на разные типы (`*int` и `*string`) являются **несовместимыми типами**;
- Нельзя присвоить `*int` переменной типа `*string` без `unsafe.Pointer`.

## Решение по шагам

1. Создаем `i := 10`, `s := "Go"`, `b := true`.
2. Получаем указатели `pi`, `ps`, `pb`.
3. Печатаем типы через `%T`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	i := 10
	s := "Go"
	b := true

	pi := &i
	ps := &s
	pb := &b

	fmt.Printf("Тип pi: %-10T | Значение: %d\n", pi, *pi)
	fmt.Printf("Тип ps: %-10T | Значение: %s\n", ps, *ps)
	fmt.Printf("Тип pb: %-10T | Значение: %t\n", pb, *pb)
}
```

**`Терминал`**

```bash
go run main.go
# Тип pi: *int       | Значение: 10
# Тип ps: *string    | Значение: Go
# Тип pb: *bool      | Значение: true
```

## Под капотом

Информация о типе проверяется компилятором статически.

## Подводные камни

- Попытка неявного приведения указателей `pi = ps` (ошибка компиляции).

## На собеседовании

**Вопрос с собеседования:** «Различаются ли размеры `*int` и `*string` в памяти?»
**Ответ:** НЕТ! Любой указатель в 64-битной архитектуре занимает ровно 8 байт.
