# Создание указателя p на переменную x и чтение значения через *p

## Условие

Создай указатель `p`, который хранит адрес `x`. Выведи значение по этому указателю (`*p`).

## Теория

Базовое упражнение на синтаксис `*p`.

## Решение по шагам

1. Создаем `x := 99`.
2. Создаем `p := &x`.
3. Выводим `*p`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	x := 99
	p := &x

	fmt.Printf("Значение x:  %d\n", x)
	fmt.Printf("Через *p:    %d\n", *p)
}
```

**`Терминал`**

```bash
go run main.go
# Значение x:  99
# Через *p:    99
```

## Под капотом

Связь переменной и адреса в стековом кадре.

## Подводные камни

- Опечатка `fmt.Println(p)` вместо `fmt.Println(*p)`.

## На собеседовании

**Вопрос с собеседования:** «Какой тип имеет выражение `&x`, если `x` имеет тип `int`?»
**Ответ:** Тип `*int`.
