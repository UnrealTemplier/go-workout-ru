# Указатель на указатель **int: изменение внешнего адреса внутри функции

## Условие

Реализуйте функцию, принимающую `**int`, выделите память и измените внешний указатель.

## Теория

**Двойной указатель `**T` (Pointer to Pointer):**
- Позволяет функции изменить **сам адрес**, на который указывает внешний указатель `*T`;
- Применяется в низкоуровневых структурах данных и CGo.

## Решение по шагам

1. Пишем `Allocate(pp **int, val int)`.
2. Выделяем `*pp = new(int)`.
3. Записываем `**pp = val`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Allocate(pp **int, val int) {
	*pp = new(int) // Перенаправляем внешний указатель на новый адрес памяти
	**pp = val     // Записываем значение по новому адресу
}

func main() {
	var ptr *int // Изначально nil

	fmt.Printf("1. До Allocate:  ptr = %v\n", ptr)

	Allocate(&ptr, 42)

	fmt.Printf("2. После Allocate: ptr = %p -> значение = %d\n", ptr, *ptr)
}
```

**`Терминал`**

```bash
go run main.go
# 1. До Allocate:  ptr = <nil>
# 2. После Allocate: ptr = 0xc000018030 -> значение = 42
```

## Под капотом

Двойное разыменование компилируется в две инструкции косвенной адресации `MOVQ (AX), BX; MOVQ (BX), CX`.

## Подводные камни

- Переусложнение архитектуры: в идиоматичном Go функцию лучше спроектировать с возвратом `func Allocate(val int) *int`.

## На собеседовании

**Вопрос с собеседования:** «Где в Go практически необходимы указатели на указатели `**T`?»
**Ответ:** При интеграции с C-библиотеками через CGo (например `sqlite3_open(const char *filename, sqlite3 **ppDb)`).
