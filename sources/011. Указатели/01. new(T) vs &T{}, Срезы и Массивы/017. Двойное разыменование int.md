# Двойное разыменование **int и мутация базовой переменной

## Условие

Создайте указатель на указатель (`**int`), измените значение оригинальной переменной через двойное разыменование.

## Теория

Цепочка адресации `x <- ptr <- pptr`.

## Решение по шагам

1. Создаем `val := 10`.
2. Создаем `ptr := &val` и `pptr := &ptr`.
3. Присваиваем `**pptr = 999`.
4. Проверяем `val`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	val := 10
	ptr := &val
	pptr := &ptr

	fmt.Printf("1. Исходное val:     %d\n", val)

	**pptr = 999

	fmt.Printf("2. После **pptr=999: %d (val изменился!)\n", val)
}
```

**`Терминал`**

```bash
go run main.go
# 1. Исходное val:     10
# 2. После **pptr=999: 999 (val изменился!)
```

## Под капотом

Косвенная запись через регистры.

## Подводные камни

- Разыменование при `pptr == nil` или `*pptr == nil`.

## На собеседовании

**Вопрос с собеседования:** «Какой тип имеет `&pptr`?»
**Ответ:** `***int` (тройной указатель).
