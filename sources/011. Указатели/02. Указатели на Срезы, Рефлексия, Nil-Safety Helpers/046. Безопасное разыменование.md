# Безопасное разыменование: паттерн Guard Clause if p != nil

## Условие

Безопасное разыменование: Защити код проверки указателя проверкой if p != nil перед разыменованием.

### Исходная формулировка

**Безопасное разыменование**: Защити код из упр. 83 проверкой `if p != nil` перед разыменованием.

## Теория

Шаблон защитных условий (Guard Clauses) для исключения паник в бизнес-логике.

## Решение по шагам

1. Пишем функцию `SafePrint(p *int)`.
2. Добавляем проверку `if p == nil { fmt.Println("указатель nil"); return }`.
3. Печатаем значение.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func SafePrint(p *int) {
	if p == nil {
		fmt.Println("⚠️ Значение недоступно (указатель nil)")
		return
	}
	fmt.Printf("Значение: %d\n", *p)
}

func main() {
	var nilPtr *int
	val := 42

	SafePrint(nilPtr)
	SafePrint(&val)
}
```

**`Терминал`**

```bash
go run main.go
# ⚠️ Значение недоступно (указатель nil)
# Значение: 42
```
