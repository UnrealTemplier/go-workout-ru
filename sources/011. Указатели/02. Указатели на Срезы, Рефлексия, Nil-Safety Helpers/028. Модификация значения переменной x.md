# Модификация значения переменной x через разыменование указателя *p = 100

## Условие

**Разыменование**: Создайте указатель на переменную `x`. Через этот указатель измените значение `x` на `100`. Выведите `x` и проверьте, что оно изменилось.

## Теория

Прямой доступ к памяти через оператор `*`.

## Решение по шагам

1. Создаем `x := 10`.
2. `p := &x`.
3. `*p = 100`.
4. Печатаем `x`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	x := 10
	p := &x

	fmt.Printf("Исходный x:         %d\n", x)

	*p = 100 // Запись 100 по адресу в указателе p

	fmt.Printf("Обновленный x:      %d (УСПЕШНО ИЗМЕНЕН!)\n", x)
}
```

**`Терминал`**

```bash
go run main.go
# Исходный x:         10
# Обновленный x:      100 (УСПЕШНО ИЗМЕНЕН!)
```

## Под капотом

Запись 8 байт по адресу `p`.

## Подводные камни

- Присвоение `p = 100` (ошибка компиляции `cannot use 100 as *int`).

## На собеседовании

**Вопрос с собеседования:** «В чем отличие `p` от `*p`?»
**Ответ:** `p` — это сам указатель (адрес в памяти), а `*p` — это значение, расположенное по этому адресу.
