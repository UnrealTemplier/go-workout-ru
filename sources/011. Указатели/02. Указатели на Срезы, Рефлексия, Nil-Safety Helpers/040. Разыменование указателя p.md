# Разыменование указателя *p и чтение значения из памяти

## Условие

**Разыменование (Dereferencing)**: Имея указатель из упр. 76, получи значение по этому адресу, используя оператор `*`, и выведи его.

## Теория

Закрепление синтаксиса разыменования.

## Решение по шагам

1. Создаем переменную `target := 888`.
2. Получаем указатель `p := &target`.
3. Разыменовываем `*p`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	target := 888
	p := &target

	fmt.Printf("Разыменованное значение: %d\n", *p)
}
```

**`Терминал`**

```bash
go run main.go
# Разыменованное значение: 888
```

## Под капотом

Чтение из памяти по адресу.

## Подводные камни

- Опечатки в синтаксисе.

## На собеседовании

**Вопрос с собеседования:** «Каков приоритет унарного оператора `*`?»
**Ответ:** Такой же, как у унарного `&` и `!`.
