# Fault Injection: Эмуляция сетевого сбоя и восстановление загрузки через ListParts API

## Условие

Эмулируйте обрыв сети, сохранив `UploadId`. Реализуйте функцию, которая возобновляет загрузку с незавершённых частей (запрос `ListParts`, проверка уже загруженных, догрузка остальных).

### Исходная формулировка

**Resume Multipart Upload после сбоя.**: Эмулируйте обрыв сети, сохранив `UploadId`. Реализуйте функцию, которая возобновляет загрузку с незавершённых частей (запрос `ListParts`, проверка уже загруженных, догрузка остальных).

## Теория

При тестировании надежности распределенных систем применяется подход Chaos Engineering: искусственное внедрение сбоев (Fault Injection) для проверки механизмов самовосстановления.

### Сценарий тестирования возобновления:
1. Запуск загрузки 4 частей.
2. Искусственный сбой сети после загрузки частей 1 и 2.
3. Сохранение `UploadId` в долговременное хранилище (State Store).
4. Восстановление: запрос `ListParts(UploadId)` к S3 возвращает части 1 и 2.
5. Докачка частей 3 и 4 и вызов `CompleteMultipartUpload`.

## Решение по шагам

1. Реализуйте симулятор сетевого сбоя `FaultyS3Client`.
2. Имитируйте обрыв соединения на середине загрузки.
3. Реализуйте запрос `ListParts` для получения карты уже загруженных частей.
4. Догрузите оставшиеся части и проверьте целостность итогового объекта.

## Код решения

**`fault_injection_resume.go`**

```go
package main

import (
	"crypto/md5"
	"encoding/hex"
	"errors"
	"fmt"
	"sort"
	"sync"
)

type S3PartState struct {
	PartNum int
	ETag    string
}

type ChaosS3Storage struct {
	mu      sync.Mutex
	uploads map[string]map[int]string
}

func NewChaosS3Storage() *ChaosS3Storage {
	return &ChaosS3Storage{uploads: make(map[string]map[int]string)}
}

func (s *ChaosS3Storage) CreateUpload(id string) {
	s.mu.Lock()
	defer s.mu.Unlock()
	s.uploads[id] = make(map[int]string)
}

func (s *ChaosS3Storage) UploadPart(id string, partNum int, data []byte, injectFailure bool) (string, error) {
	s.mu.Lock()
	defer s.mu.Unlock()

	if injectFailure {
		return "", errors.New("CHAOS_FAULT: Network pipe broken (connection reset by peer)")
	}

	hash := md5.Sum(data)
	etag := fmt.Sprintf("\"%s\"", hex.EncodeToString(hash[:]))
	s.uploads[id][partNum] = etag
	return etag, nil
}

func (s *ChaosS3Storage) ListParts(id string) []S3PartState {
	s.mu.Lock()
	defer s.mu.Unlock()

	var list []S3PartState
	for pNum, etag := range s.uploads[id] {
		list = append(list, S3PartState{PartNum: pNum, ETag: etag})
	}
	return list
}

func main() {
	storage := NewChaosS3Storage()
	uploadID := "resilient-session-chaos-1"
	storage.CreateUpload(uploadID)

	chunks := [][]byte{
		[]byte("Part 1: OK"),
		[]byte("Part 2: OK"),
		[]byte("Part 3: OK"),
		[]byte("Part 4: OK"),
	}

	fmt.Println("--- Этап 1: Первая попытка загрузки (внедряем сбой на части #3) ---")
	for i := 0; i < len(chunks); i++ {
		partNum := i + 1
		fail := (partNum == 3) // Сбой на 3-й части!
		etag, err := storage.UploadPart(uploadID, partNum, chunks[i], fail)
		if err != nil {
			fmt.Printf("  [FAULT] Ошибка загрузки части #%d: %v\n", partNum, err)
			break
		}
		fmt.Printf("  Часть #%d успешно загружена. ETag: %s\n", partNum, etag)
	}

	fmt.Println("\n--- Этап 2: Возобновление после аварии через ListParts ---")
	existingParts := storage.ListParts(uploadID)
	existingMap := make(map[int]string)
	for _, p := range existingParts {
		existingMap[p.PartNum] = p.ETag
	}
	fmt.Printf("Найдено ранее загруженных частей в S3: %d\n", len(existingMap))

	for i := 0; i < len(chunks); i++ {
		partNum := i + 1
		if _, ok := existingMap[partNum]; ok {
			fmt.Printf("  Часть #%d уже в S3. Пропускаем.\n", partNum)
			continue
		}
		fmt.Printf("  Докачиваем часть #%d...\n", partNum)
		etag, _ := storage.UploadPart(uploadID, partNum, chunks[i], false)
		existingMap[partNum] = etag
	}

	// Финализация
	var finalParts []S3PartState
	for pNum, etag := range existingMap {
		finalParts = append(finalParts, S3PartState{PartNum: pNum, ETag: etag})
	}
	sort.Slice(finalParts, func(i, j int) bool { return finalParts[i].PartNum < finalParts[j].PartNum })

	fmt.Printf("\n--- Этап 3: Загрузка финализирована! Всего частей: %d ---\n", len(finalParts))
	for _, p := range finalParts {
		fmt.Printf("  Part %d: %s\n", p.PartNum, p.ETag)
	}
}
```

## Под капотом

Механика реализации 'Fault Injection: Эмуляция сетевого сбоя и восстановление загрузки через ListParts API':
В рантайме Go и сетевом стеке низкоуровневые операции ввода-вывода абстрагируются через интерфейсы `io.Reader` и `io.Writer`. При работе с криптографическими алгоритмами задействуются аппаратные инструкции процессора (AES-NI / CLMUL на x86-64 и ARM Cryptography Extensions), что обеспечивает скорость обработки до 3–5 ГБ/с на ядро CPU с околонулевым оверхедом планировщика GMP.

## Подводные камни

Типичная ошибка при проектировании: утечка неуправляемых ресурсов и памяти. При работе с S3 сетевыми потоками обязателен вызов `defer response.Body.Close()`, иначе сокеты TCP останутся в состоянии CLOSE_WAIT, что приведет к исчерпанию лимита файловых дескрипторов ОС (`too many open files`). Также недопустимо сохранять открытые криптографические ключи в глобальных структурах данных.
