# Экстернализация настроек микросервиса через ConfigMap

## Условие

**Конфигурация (ConfigMap)**: Зашивать настройки в Docker-образ — антипаттерн. Создай `configmap.yaml` со словарем (ключ `SERVER_PORT: 8080`). Прокинь это значение внутрь пода как переменную окружения (Env Var). Сделай так, чтобы твое Go-приложение читало порт из `os.Getenv()`.

## Теория

Зашивание настроек (порты, таймауты, флаги функционала) в Docker-образ — грубый антипаттерн, нарушающий переносимость:
- Один и тот же образ должен запускаться на локальной машине, тестовом стенде и в боевом кластере.
- `ConfigMap` выносит параметры во внешний декларативный YAML.

## Решение по шагам

1. Создайте `configmap.yaml` с портами и переменными.
2. Подключите ConfigMap в `deployment.yaml`.
3. В коде Go прочитайте значения параметров.
4. Примените конфигурацию: `kubectl apply -f .`.
5. Убедитесь в корректности примененных настроек.

## Код решения

**`configmap.yaml`**

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: server-params
data:
  HTTP_PORT: "8080"
  APP_ENV: "production"
  METRICS_ENABLED: "true" 
```

**`main.go`**

```go
package main

import (
	"fmt"
	"os"
)

func main() {
	port := os.Getenv("HTTP_PORT")
	env := os.Getenv("APP_ENV")
	metrics := os.Getenv("METRICS_ENABLED")

	fmt.Printf("Конфигурация [Env: %s, Port: %s, Metrics: %s]\n", env, port, metrics)
}
```

## Под капотом

Kubelet связывает переменные процесса с etcd-деревом в момент создания контейнера.

## Подводные камни

1. Хранение секретов в ConfigMap.
2. Несоответствие имен ключей.
3. Отсутствие значений по умолчанию в коде Go.

## На собеседовании

**Вопрос с собеседования:** Как валидировать конфигурацию ConfigMap в CI/CD до ее попадания в кластер?
**Ответ:** Используются инструменты статического анализа манифестов:
1. `kubeconform` для проверки базовой схемы K8s.
2. **`conftest` (Open Policy Agent)** для проверки корпоративных политик (например, «запретить значение `APP_ENV=prod` без TLS»).
3. Юнит-тесты на Go, которые парсят и валидируют структуру конфигурационного файла с помощью JSON/YAML Schema.
