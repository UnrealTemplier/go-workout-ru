# Обобщенная структура Matrix[T]: Add, Transpose

## Условие

Реализуй `Matrix[T constraints.Signed | constraints.Float]` — двумерный слайс. Методы: `Add(other Matrix[T]) Matrix[T]`, `Subtract(other Matrix[T]) Matrix[T]`, `Multiply(other Matrix[T]) Matrix[T]` (матричное умножение), `Transpose() Matrix[T]`, `Dimensions() (rows, cols int)`.

## Теория

Матрица \(M \times N\) представляется как срезы строк. Операция транспонирования \(M^T\) меняет строки и столбцы местами.

## Решение по шагам

1. Объявим `type Matrix[T Numeric] [][]T`.
2. Реализуем `NewMatrix`, `Add`, `Transpose`.
3. В `main` сложим две матрицы 2x2.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Number interface {
	~int | ~int64 | ~float64
}

type Matrix[T Number] struct {
	rows, cols int
	data       [][]T
}

func NewMatrix[T Number](rows, cols int) *Matrix[T] {
	data := make([][]T, rows)
	for i := range data {
		data[i] = make([]T, cols)
	}
	return &Matrix[T]{rows: rows, cols: cols, data: data}
}

func (m *Matrix[T]) Add(other *Matrix[T]) *Matrix[T] {
	res := NewMatrix[T](m.rows, m.cols)
	for r := 0; r < m.rows; r++ {
		for c := 0; c < m.cols; c++ {
			res.data[r][c] = m.data[r][c] + other.data[r][c]
		}
	}
	return res
}

func (m *Matrix[T]) Transpose() *Matrix[T] {
	res := NewMatrix[T](m.cols, m.rows)
	for r := 0; r < m.rows; r++ {
		for c := 0; c < m.cols; c++ {
			res.data[c][r] = m.data[r][c]
		}
	}
	return res
}

func main() {
	m1 := NewMatrix[int](2, 2)
	m1.data[0] = []int{1, 2}
	m1.data[1] = []int{3, 4}

	m2 := NewMatrix[int](2, 2)
	m2.data[0] = []int{10, 20}
	m2.data[1] = []int{30, 40}

	sum := m1.Add(m2)
	fmt.Println("Сумма матриц:")
	for _, row := range sum.data {
		fmt.Println(" ", row)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Сумма матриц:
#   [11 22]
#   [33 44]
```

Операции над матрицей мономорфизируются в быстрые инструкции без динамических интерфейсов.

## На собеседовании

**Вопрос с собеседования:** «Как оптимизировать хранение матрицы в Go для кэшей CPU?»
**Ответ:** Хранить матрицу в одном плоском срезе `data []T` длины `rows * cols` с индексацией `data[r*cols + c]`, что исключает фрагментацию памяти и разыменование указателей.
