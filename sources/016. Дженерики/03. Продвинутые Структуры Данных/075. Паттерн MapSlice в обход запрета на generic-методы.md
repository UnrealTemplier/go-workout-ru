# Паттерн MapSlice в обход запрета на generic-методы

## Условие

**Обходной путь (Map для Слайса)**: Реализуй функциональность из упр. 245 в виде отдельной функции: `MapSlice[T, U any](slice []T, fn func(T) U) []U`. Это паттерн Map из функционального программирования.

## Теория

Так как Go запрещает generic-методы на структурах, отдельная функция `MapSlice[T, U any]` является стандартным идиоматичным паттерном в экосистеме языка.

## Решение по шагам

1. Объявим `MapSlice[T, U any](slice []T, fn func(T) U) []U`.
2. В `main` преобразуем слайс температур по Цельсию в Фаренгейты.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func MapSlice[T, U any](slice []T, fn func(T) U) []U {
	res := make([]U, len(slice))
	for i, v := range slice {
		res[i] = fn(v)
	}
	return res
}

func main() {
	celsius := []float64{0.0, 20.0, 36.6, 100.0}
	fahrenheit := MapSlice(celsius, func(c float64) float64 {
		return c*9/5 + 32
	})

	for i, c := range celsius {
		fmt.Printf("%.1f°C = %.1f°F\n", c, fahrenheit[i])
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# 0.0°C = 32.0°F
# 20.0°C = 68.0°F
# 36.6°C = 97.9°F
# 100.0°C = 212.0°F
```

## Под капотом

`MapSlice` выполняет мономорфизацию для пар `(float64, float64)` с прямой записью в память.

## Подводные камни

Всегда используйте функции верхнего уровня для преобразования между коллекциями разных типов.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go не используется синтаксис методов расширения (Extension Methods)?»
**Ответ:** Go стремится к простоте и прозрачности вызовов: все доступные методы типа явно видны в пакете объявления типа, исключая скрытую магию.
