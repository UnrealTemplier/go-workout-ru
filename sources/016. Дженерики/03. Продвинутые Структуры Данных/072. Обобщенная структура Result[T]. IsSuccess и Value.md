# Обобщенная структура Result[T]: IsSuccess и Value

## Условие

Создайте параметризованную структуру `Result[T any]`, которая может хранить либо значение типа `T`, либо ошибку. Реализуйте методы `IsSuccess() bool`, `Value() (T, error)`. Это отличная альтернатива стандартному возвращению `(T, error)`.

## Теория

`Result[T any]` инкапсулирует значение или ошибку в единую структуру, удобную для передачи в каналы.

## Решение по шагам

1. Объявим `type Result[T any] struct { val T; err error }`.
2. Реализуем `Success[T any](v T) Result[T]` и `Failure[T any](e error) Result[T]`.
3. Реализуем `IsSuccess()` и `Value() (T, error)`.
4. Проверим в `main`.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type Result[T any] struct {
	val T
	err error
}

func Success[T any](v T) Result[T]  { return Result[T]{val: v} }
func Failure[T any](e error) Result[T] { return Result[T]{err: e} }

func (r Result[T]) IsSuccess() bool { return r.err == nil }
func (r Result[T]) Value() (T, error) {
	return r.val, r.err
}

func parsePort(p int) Result[int] {
	if p < 1 || p > 65535 {
		return Failure[int](errors.New("невалидный номер порта"))
	}
	return Success(p)
}

func main() {
	r1 := parsePort(8080)
	if val, err := r1.Value(); err == nil {
		fmt.Println("Порт валиден:", val)
	}

	r2 := parsePort(99999)
	fmt.Println("Успех r2:", r2.IsSuccess())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Порт валиден: 8080
# Успех r2: false
```

## Под капотом

`Result[T]` отлично подходит для передачи результатов через каналы `chan Result[T]` при параллельных вычислениях.

## Подводные камни

Не забывайте обрабатывать `err` при извлечении `Value()`.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go каналы часто типизируют как chan Result[T]?»
**Ответ:** Потому что канал в Go может передавать только один тип за раз (`chan (T, error)` невалиден). Структура `Result[T]` объединяет полезную нагрузку и ошибку в одно сообщение.
