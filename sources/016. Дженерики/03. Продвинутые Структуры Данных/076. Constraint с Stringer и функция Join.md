# Constraint с Stringer и функция Join

## Условие

Констрейнт с методами: `Stringer` (`~string | interface{ String() string }`). Функция `Join[T Stringer](elems []T, sep string) string`.

## Теория

Constraint объединяет базовые строки `~string` и любые структуры, реализующие `String() string`.

## Решение по шагам

1. Объявим `type Stringer interface { ~string | fmt.Stringer }` (через type switch/helper).
2. Реализуем функцию `Join`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strings"
)

type Stringable interface {
	fmt.Stringer
}

type User struct {
	Name string
}

func (u User) String() string {
	return u.Name
}

func JoinStringers[T Stringable](elems []T, sep string) string {
	parts := make([]string, len(elems))
	for i, e := range elems {
		parts[i] = e.String()
	}
	return strings.Join(parts, sep)
}

func main() {
	users := []User{{Name: "Анна"}, {Name: "Борис"}, {Name: "Виктор"}}
	fmt.Println("Пользователи:", JoinStringers(users, ", "))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Пользователи: Анна, Борис, Виктор
```

## Под капотом

`strings.Join` предварительно вычисляет длину итоговой строки и делает ровно одну аллокацию памяти.

## Подводные камни

Не используйте конкатенацию строк в цикле через `+=`, это приводит к \(O(N^2)\) аллокациям.

## На собеседовании

**Вопрос с собеседования:** «Как оптимизирована функция strings.Join?»
**Ответ:** Она суммирует длины всех строк и разделителей, выделяет буфер `make([]byte, totalLen)` и копирует байты через `copy()`, гарантируя ровно одну аллокацию памяти.
