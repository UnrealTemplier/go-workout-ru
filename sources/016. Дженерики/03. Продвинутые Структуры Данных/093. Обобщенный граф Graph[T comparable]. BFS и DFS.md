# Обобщенный граф Graph[T comparable]: BFS и DFS

## Условие

Реализуй `Graph[T comparable]` через список смежности `map[T][]T`. Методы: `AddEdge(from, to T)`, `HasEdge(from, to T) bool`, `Neighbors(v T) []T`, `BFS(start T) []T`, `DFS(start T) []T`.

## Теория

Граф на списке смежности `map[T][]T` поддерживает алгоритмы поиска в ширину (BFS с очередью) и поиска в глубину (DFS со стеком).

## Решение по шагам

1. Объявим `type Graph[T comparable] struct { adj map[T][]T }`.
2. Реализуем `AddEdge`, `Neighbors`, `BFS`, `DFS`.
3. В `main` построим граф зависимостей микросервисов.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Graph[T comparable] struct {
	adj map[T][]T
}

func NewGraph[T comparable]() *Graph[T] {
	return &Graph[T]{adj: make(map[T][]T)}
}

func (g *Graph[T]) AddEdge(from, to T) {
	g.adj[from] = append(g.adj[from], to)
}

func (g *Graph[T]) BFS(start T) []T {
	visited := make(map[T]bool)
	var order []T
	queue := []T{start}
	visited[start] = true

	for len(queue) > 0 {
		curr := queue[0]
		queue = queue[1:]
		order = append(order, curr)

		for _, neighbor := range g.adj[curr] {
			if !visited[neighbor] {
				visited[neighbor] = true
				queue = append(queue, neighbor)
			}
		}
	}
	return order
}

func main() {
	g := NewGraph[string]()
	g.AddEdge("Gateway", "AuthService")
	g.AddEdge("Gateway", "OrderService")
	g.AddEdge("OrderService", "PaymentService")
	g.AddEdge("OrderService", "InventoryService")

	fmt.Println("Порядок обхода BFS от Gateway:", g.BFS("Gateway"))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Порядок обхода BFS от Gateway: [Gateway AuthService OrderService PaymentService InventoryService]
```

## Под капотом

Мапа `visited` исключает бесконечные циклы в графах с циклами.

## Подводные камни

Для вершин графа обязателен constraint `comparable` для работы мапы посещений.

## На собеседовании

**Вопрос с собеседования:** «Какова сложность BFS графа?»
**Ответ:** Время \(O(V + E)\) (вершины + ребра), память \(O(V)\) под очередь и множество visited.
