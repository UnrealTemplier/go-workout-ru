# Constraint для всех целочисленных типов AnyInteger

## Условие

Создай constraint для **всех целых типов** с `~` (tilde):
```go
type AnyInteger interface {
    ~int | ~int8 | ~int16 | ~int32 | ~int64 |
    ~uint | ~uint8 | ~uint16 | ~uint32 | ~uint64 | ~uintptr
}
```
Напиши `BitwiseOr[T AnyInteger](a, b T) T`. Покажи, что `AnyInteger` включает и signed, и unsigned.

## Теория

`AnyInteger` объединяет абсолютно все целочисленные типы с тильдой, гарантируя поддержку побитовых операций (`|`, `&`, `^`).

## Решение по шагам

1. Объявим `type AnyInteger interface { ... }`.
2. Напишем `BitwiseOr[T AnyInteger](a, b T) T { return a | b }`.
3. В `main` проверим со знаковыми `int` и беззнаковыми `uint32`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type AnyInteger interface {
	~int | ~int8 | ~int16 | ~int32 | ~int64 |
		~uint | ~uint8 | ~uint16 | ~uint32 | ~uint64 | ~uintptr
}

func BitwiseOr[T AnyInteger](a, b T) T {
	return a | b
}

func main() {
	var s1 int = 1
	var s2 int = 2
	fmt.Printf("Signed OR:   %d (%03b)\n", BitwiseOr(s1, s2), BitwiseOr(s1, s2))

	var u1 uint32 = 4
	var u2 uint32 = 8
	fmt.Printf("Unsigned OR: %d (%04b)\n", BitwiseOr(u1, u2), BitwiseOr(u1, u2))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Signed OR:   3 (011)
# Unsigned OR: 12 (1100)
```

## Под капотом

Компилятор подставляет машинную инструкцию `ORQ` / `ORL` процессора.

## Подводные камни

Не пытайтесь смешивать signed и unsigned в одном вызове `BitwiseOr(int(1), uint(2))` — аргументы обязаны иметь одинаковый тип.

## На собеседовании

**Вопрос с собеседования:** «Почему в AnyInteger включен uintptr?»
**Ответ:** `uintptr` — это целочисленный беззнаковый тип достаточного размера для хранения адреса памяти. Он поддерживает все целочисленные и побитовые операции.
