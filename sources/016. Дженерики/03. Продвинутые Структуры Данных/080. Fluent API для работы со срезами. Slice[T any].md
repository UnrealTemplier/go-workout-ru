# Fluent API для работы со срезами: Slice[T any]

## Условие

Реализуй `Slice[T any]` — тип с **fluent API**: `Map(fn func(T) T) Slice[T]`, `Filter(fn func(T) bool) Slice[T]`, `Reduce(init T, fn func(T, T) T) T`, `Contains(v T) bool`, `IndexOf(v T) int`, `Reverse() Slice[T]`. Каждый метод возвращает новый `Slice` (immutable).

## Теория

Fluent API предоставляет удобные цепочки вызовов методов в функциональном стиле (Method Chaining).

## Решение по шагам

1. Объявим `type Slice[T any] []T`.
2. Реализуем методы `Filter`, `Map`, `Reverse`, `ToRaw`.
3. В `main` построим цепочку операций.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Slice[T any] []T

func (s Slice[T]) Filter(predicate func(T) bool) Slice[T] {
	res := make(Slice[T], 0, len(s))
	for _, v := range s {
		if predicate(v) {
			res = append(res, v)
		}
	}
	return res
}

func (s Slice[T]) Map(fn func(T) T) Slice[T] {
	res := make(Slice[T], len(s))
	for i, v := range s {
		res[i] = fn(v)
	}
	return res
}

func (s Slice[T]) Reverse() Slice[T] {
	n := len(s)
	res := make(Slice[T], n)
	for i, v := range s {
		res[n-1-i] = v
	}
	return res
}

func main() {
	numbers := Slice[int]{1, 2, 3, 4, 5, 6, 7, 8}

	// Цепочка: Оставить четные -> Умножить на 10 -> Развернуть
	result := numbers.
		Filter(func(n int) bool { return n%2 == 0 }).
		Map(func(n int) int { return n * 10 }).
		Reverse()

	fmt.Println("Результат цепочки:", []int(result))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Результат цепочки: [80 60 40 20]
```

## Под капотом

Каждый метод создает новый независимый срез, гарантируя неизменяемость исходной коллекции.

## Подводные камни

Цепочки методов порождают промежуточные аллокации. В критических путях по производительности используйте единый цикл `for`.

## На собеседовании

**Вопрос с собеседования:** «В чем недостаток Fluent API в Go по сравнению с Rust Iterator или Java Streams?»
**Ответ:** В Rust и Java итераторы являются ленивыми (Lazy Evaluation) и компилируются в один слитный цикл без промежуточных аллокаций памяти. В Go методы срезов выполняются энергично (Eager Evaluation), создавая временные слайсы в куче.
