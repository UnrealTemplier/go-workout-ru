# Ошибки типов при явном инстанцировании

## Условие

Явное инстанцирование: вызови `Print[int]("hello")` (передача аргумента не того типа при явном указании дженерика). Поймай ошибку компиляции.

## Теория

При явном инстанцировании `Print[int]` компилятор жестко фиксирует сигнатуру как `func(val int)`. Передача строки `"hello"` вызовет ошибку `cannot use "hello" (untyped string constant) as int value`.

## Решение по шагам

1. Объявим `Print[T any](v T)`.
2. В `main` покажем корректный вызов `Print[string]("hello")`.
3. В комментариях зафиксируем ошибку для `Print[int]("hello")`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Print[T any](v T) {
	fmt.Println("Значение:", v)
}

func main() {
	Print[string]("hello")
	Print[int](42)

	// Следующий вызов вызовет ошибку компиляции:
	// Print[int]("hello")
	// Ошибка: cannot use "hello" (untyped string constant) as int value in argument to Print[int]
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Значение: hello
# Значение: 42
```

## Под капотом

Явное указание `[int]` отключает фазу вывода типов аргументов, форсируя проверку типа параметров `int`.

## Подводные камни

Явное инстанцирование используется, когда автоматический вывод типов не может выбрать тип однозначно.

## На собеседовании

**Вопрос с собеседования:** «Когда компилятор Go требует явного указания типа дженерика?»
**Ответ:** Когда параметр типа не фигурирует в типах входных аргументов (например `make([]T, 0)`) или при передаче нетипизированных `nil` констант.
