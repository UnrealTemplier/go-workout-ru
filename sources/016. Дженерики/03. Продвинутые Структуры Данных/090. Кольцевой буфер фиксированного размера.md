# Кольцевой буфер фиксированного размера: RingBuffer[T any]

## Условие

Реализуй `RingBuffer[T any]` — кольцевой буфер фиксированного размера. Методы: `Write(v T) bool` (false если полон), `Read() (T, bool)` (false если пуст), `IsFull()`, `IsEmpty()`, `Len()`, `Cap()`.

## Теория

Кольцевой буфер (Circular Ring Buffer) реализует FIFO очередь на массиве фиксированной емкости без перемещения элементов.

## Решение по шагам

1. Объявим `type RingBuffer[T any] struct { buf []T; head, tail, size int }`.
2. Реализуем `Write`, `Read`, `IsFull`, `IsEmpty`, `Len`, `Cap`.
3. В `main` протестируем кольцевую запись и чтение.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type RingBuffer[T any] struct {
	buf        []T
	head, tail int
	size, cap  int
}

func NewRingBuffer[T any](capacity int) *RingBuffer[T] {
	return &RingBuffer[T]{buf: make([]T, capacity), cap: capacity}
}

func (r *RingBuffer[T]) Write(v T) bool {
	if r.size == r.cap {
		return false
	}
	r.buf[r.tail] = v
	r.tail = (r.tail + 1) % r.cap
	r.size++
	return true
}

func (r *RingBuffer[T]) Read() (T, bool) {
	if r.size == 0 {
		var zero T
		return zero, false
	}
	val := r.buf[r.head]
	var zero T
	r.buf[r.head] = zero
	r.head = (r.head + 1) % r.cap
	r.size--
	return val, true
}

func (r *RingBuffer[T]) IsFull() bool  { return r.size == r.cap }
func (r *RingBuffer[T]) IsEmpty() bool { return r.size == 0 }

func main() {
	rb := NewRingBuffer[int](3)
	rb.Write(10)
	rb.Write(20)
	rb.Write(30)
	fmt.Println("Полон:", rb.IsFull())

	v1, _ := rb.Read()
	fmt.Println("Прочитано:", v1)
	rb.Write(40)

	for !rb.IsEmpty() {
		v, _ := rb.Read()
		fmt.Println("Извлечено:", v)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Полон: true
# Прочитано: 10
# Извлечено: 20
# Извлечено: 30
# Извлечено: 40
```

## Под капотом

Индексы `head` и `tail` циклически зацикливаются через оператор остатка `% r.cap`, исключая сдвиги элементов.

## Подводные камни

Зануляйте `r.buf[r.head] = zero` при чтении, чтобы не удерживать память под удаленными объектами.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество кольцевого буфера перед слайсом для очередей?»
**Ответ:** Кольцевой буфер работает с нулевыми аллокациями памяти (\(O(1)\) вставка и извлечение) и не требует сдвигов массива.
