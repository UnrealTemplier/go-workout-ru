# Stack[T] для структур User и примитивов int

## Условие

**Обобщенный Стек (Stack)**: Реализуйте структуру `Stack[T any]` на базе среза. Напишите методы `Push(val T)`, `Pop() (T, bool)` и `Len() int`. Проверьте работу стека для хранения структур `User` и обычных чисел `int`.

## Теория

Один и тот же шаблон структуры `Stack[T]` без дублирования кода работает как со структурами `User`, так и с примитивными числами.

## Решение по шагам

1. Объявим структуру `Stack[T any]`.
2. Реализуем `Push`, `Pop`, `Len`.
3. В `main` проверим со стеком `User` и `int`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type User struct {
	ID   int
	Role string
}

type Stack[T any] struct {
	data []T
}

func (s *Stack[T]) Push(v T) { s.data = append(s.data, v) }

func (s *Stack[T]) Pop() (T, bool) {
	if len(s.data) == 0 {
		var zero T
		return zero, false
	}
	idx := len(s.data) - 1
	v := s.data[idx]
	s.data = s.data[:idx]
	return v, true
}

func (s *Stack[T]) Len() int { return len(s.data) }

func main() {
	userStack := &Stack[User]{}
	userStack.Push(User{ID: 1, Role: "Admin"})
	userStack.Push(User{ID: 2, Role: "Member"})

	u, _ := userStack.Pop()
	fmt.Printf("Pop User: %+v\n", u)

	intStack := &Stack[int]{}
	intStack.Push(99)
	n, _ := intStack.Pop()
	fmt.Println("Pop Int:", n)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Pop User: {ID:2 Role:Member}
# Pop Int: 99
```

## Под капотом

Для `Stack[User]` выделяется непрерывный массив под размер структуры `User`.

## Подводные камни

Для структур больших размеров храните в стеке указатели `*User`.

## На собеседовании

**Вопрос с собеседования:** «Когда стоит использовать Stack[*T] вместо Stack[T]?»
**Ответ:** Когда размер структуры `T` превышает 64–128 байт, чтобы избежать дорогостоящего побайтового копирования при каждом `Push`/`Pop`.
