# Слияние двух мап: MergeMaps[K, V]

## Условие

Создай дженерик-функцию `MergeMaps[K comparable, V any](m1, m2 map[K]V) map[K]V`, которая объединяет две мапы (при конфликте ключей выигрывает вторая мапа).

## Теория

Слияние двух мап создает новую хэш-таблицу с объединенными парами ключ-значение.

## Решение по шагам

1. Объявим `MergeMaps[K comparable, V any](m1, m2 map[K]V) map[K]V`.
2. Создадим мапу `res := make(map[K]V, len(m1)+len(m2))`.
3. Заполним из `m1`, затем из `m2`.
4. В `main` объединим мапы.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func MergeMaps[K comparable, V any](m1, m2 map[K]V) map[K]V {
	res := make(map[K]V, len(m1)+len(m2))
	for k, v := range m1 {
		res[k] = v
	}
	for k, v := range m2 {
		res[k] = v
	}
	return res
}

func main() {
	base := map[string]int{"a": 1, "b": 2}
	override := map[string]int{"b": 99, "c": 3}

	merged := MergeMaps(base, override)
	fmt.Printf("Merged map: %+v\n", merged)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Merged map: map[a:1 b:99 c:3]
```

## Под капотом

`make(map[K]V, len(m1)+len(m2))` резервирует хэш-бакеты для исключения рехэширования.

## Подводные камни

Вторая мапа перезаписывает значения ключей первой мапы.

## На собеседовании

**Вопрос с собеседования:** «Как работает maps.Copy в стандартной библиотеке Go 1.21+?»
**Ответ:** `maps.Copy(dst, src)` копирует все пары из `src` в существующую мапу `dst` (in-place мутация без создания новой мапы).
