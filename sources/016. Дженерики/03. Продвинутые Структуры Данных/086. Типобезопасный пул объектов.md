# Типобезопасный пул объектов: Pool[T any] над sync.Pool

## Условие

Реализуй `Pool[T any]` — пул объектов. Методы: `Get() T`, `Put(T)`. Внутри используй `sync.Pool` (хранит `interface{}`, делай type assertion). Обсуди ограничения `sync.Pool` с generics.

## Теория

`sync.Pool` в стандартной библиотеке оперирует `any` (`interface{}`). Дженерик-обёртка `Pool[T any]` инкапсулирует runtime type assertion, предоставляя типобезопасный интерфейс `Get() *T` и `Put(*T)`.

## Решение по шагам

1. Объявим `type Pool[T any] struct { p sync.Pool }`.
2. Конструктор `NewPool[T any](newFn func() *T) *Pool[T]`.
3. Методы `Get() *T` и `Put(*T)`.
4. В `main` переиспользуем буферы `bytes.Buffer`.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"sync"
)

type Pool[T any] struct {
	p sync.Pool
}

func NewPool[T any](newFn func() *T) *Pool[T] {
	return &Pool[T]{
		p: sync.Pool{
			New: func() any {
				return newFn()
			},
		},
	}
}

func (p *Pool[T]) Get() *T {
	return p.p.Get().(*T)
}

func (p *Pool[T]) Put(item *T) {
	p.p.Put(item)
}

func main() {
	bufPool := NewPool(func() *bytes.Buffer {
		return new(bytes.Buffer)
	})

	buf := bufPool.Get()
	buf.WriteString("HighLoad Go Workout")
	fmt.Println("Буфер:", buf.String())

	buf.Reset()
	bufPool.Put(buf)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Буфер: HighLoad Go Workout
```

## Под капотом

`sync.Pool` сбрасывается каждым циклом Garbage Collection. Объекты хранятся в локальных пулах процессоров `P` (local pool caches) без блокировок.

## Подводные камни

Всегда сбрасывайте состояние объекта (`buf.Reset()`) перед возвратом в `Put`.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go не переписали sync.Pool на чистые дженерики?»
**Ответ:** `sync.Pool` тесно интегрирован с рантаймом Go и планировщиком GMP (хранит структуры в массиве per-P `poolLocal`). Дженерик-обертка дает 100% типобезопасность на уровне компилятора без изменения низкоуровневого рантайма.
