# Слияние нескольких мап: MergeMaps[K, V]

## Условие

`MergeMaps[K comparable, V any](maps ...map[K]V) map[K]V` — объединение карт (последний побеждает).

## Теория

Функция `MergeMaps` объединяет вариативный список мап. При конфликте ключей побеждает значение из более поздней мапы.

## Решение по шагам

1. Объявим `MergeMaps[K comparable, V any](maps ...map[K]V) map[K]V`.
2. Создадим результирующую мапу.
3. Проитерируемся по каждой мапе и запишем ключи.
4. В `main` объединим настройки по умолчанию и переопределения.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func MergeMaps[K comparable, V any](maps ...map[K]V) map[K]V {
	result := make(map[K]V)
	for _, m := range maps {
		for k, v := range m {
			result[k] = v
		}
	}
	return result
}

func main() {
	defaultConfig := map[string]string{
		"host": "localhost",
		"port": "8080",
		"mode": "development",
	}

	prodConfig := map[string]string{
		"host": "api.production.com",
		"mode": "production",
	}

	finalConfig := MergeMaps(defaultConfig, prodConfig)
	fmt.Printf("Итоговая конфигурация: %+v\n", finalConfig)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Итоговая конфигурация: map[host:api.production.com mode:production port:8080]
```

## Под капотом

Вариативный параметр `maps ...map[K]V` передается как срез мап `[]map[K]V`.

## Подводные камни

Помните, что `nil` мапы в списке `maps` безопасно итерируются циклом `for range` без паники.

## На собеседовании

**Вопрос с собеседования:** «Что происходит при for k, v := range nilMap в Go?»
**Ответ:** Цикл `for range` по `nil` мапе выполняет ровно 0 итераций и не вызывает панику.
