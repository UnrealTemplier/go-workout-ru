# Обобщенная Min-Heap очередь с приоритетом PriorityQueue[T]

## Условие

Реализуй `PriorityQueue[T constraints.Ordered]` — min-heap на слайсе. Методы: `Push(v T)`, `Pop() (T, bool)`, `Peek() (T, bool)`. Не используй `container/heap` (реализуй sift-up/sift-down самостоятельно для практики).

### Исходная формулировка

Реализуй `PriorityQueue[T constraints.Ordered]` — min-heap на слайсе. Методы: `Push(v T)`, `Pop() (T, bool)`, `Peek() (T, bool)`. Не используй `container/heap` (реализуй sift-up/sift-down самостоятельно для практики).

## Теория

Двоичная min-куча (Binary Min-Heap) гарантирует извлечение наименьшего элемента за \(O(\log N)\) с помощью алгоритмов `siftUp` и `siftDown`.

## Решение по шагам

1. Объявим `type PriorityQueue[T cmp.Ordered] struct { heap []T }`.
2. Реализуем `siftUp` (при вставке) и `siftDown` (при извлечении).
3. В `main` проверим извлечение элементов в порядке возрастания.

## Код решения

**`main.go`**

```go
package main

import (
	"cmp"
	"fmt"
)

type PriorityQueue[T cmp.Ordered] struct {
	heap []T
}

func (pq *PriorityQueue[T]) Push(v T) {
	pq.heap = append(pq.heap, v)
	pq.siftUp(len(pq.heap) - 1)
}

func (pq *PriorityQueue[T]) Pop() (T, bool) {
	if len(pq.heap) == 0 {
		var zero T
		return zero, false
	}
	minVal := pq.heap[0]
	lastIdx := len(pq.heap) - 1
	pq.heap[0] = pq.heap[lastIdx]
	pq.heap = pq.heap[:lastIdx]
	if len(pq.heap) > 0 {
		pq.siftDown(0)
	}
	return minVal, true
}

func (pq *PriorityQueue[T]) siftUp(i int) {
	for i > 0 {
		parent := (i - 1) / 2
		if pq.heap[i] < pq.heap[parent] {
			pq.heap[i], pq.heap[parent] = pq.heap[parent], pq.heap[i]
			i = parent
		} else {
			break
		}
	}
}

func (pq *PriorityQueue[T]) siftDown(i int) {
	n := len(pq.heap)
	for {
		left := 2*i + 1
		right := 2*i + 2
		smallest := i

		if left < n && pq.heap[left] < pq.heap[smallest] {
			smallest = left
		}
		if right < n && pq.heap[right] < pq.heap[smallest] {
			smallest = right
		}
		if smallest != i {
			pq.heap[i], pq.heap[smallest] = pq.heap[smallest], pq.heap[i]
			i = smallest
		} else {
			break
		}
	}
}

func (pq *PriorityQueue[T]) Len() int { return len(pq.heap) }

func main() {
	pq := &PriorityQueue[int]{}
	for _, n := range []int{42, 10, 85, 3, 27} {
		pq.Push(n)
	}

	fmt.Print("Извлечение min-heap: ")
	for pq.Len() > 0 {
		v, _ := pq.Pop()
		fmt.Printf("%d ", v)
	}
	fmt.Println()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Извлечение min-heap: 3 10 27 42 85
```

## Под капотом

Куча хранится в непрерывном срезе: для узла `i` левый потомок `2i+1`, правый `2i+2`, родитель `(i-1)/2`.

## Подводные камни

Для максимальной кучи (Max-Heap) измените оператор сравнения на `>`.

## На собеседовании

**Вопрос с собеседования:** «Почему PriorityQueue на куче эффективнее отсортированного слайса?»
**Ответ:** Вставка в кучу стоит \(O(\log N)\), а в отсортированный срез — \(O(N)\) из-за необходимости сдвигать элементы массива.
