# Пересечение множеств: Intersect[T comparable]

## Условие

Напишите дженерик-функцию `Intersect[T comparable](set1, set2 Set[T]) Set[T]`, которая находит пересечение двух множеств.

## Теория

Пересечение множеств находит только те элементы, которые одновременно присутствуют в обоих множествах.

## Решение по шагам

1. Объявим `type Set[T comparable] map[T]struct{}`.
2. Реализуем `Intersect[T comparable](s1, s2 Set[T]) Set[T]`.
3. Оптимизируем: обходим меньшее по размеру множество.
4. В `main` найдем пересечение.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Set[T comparable] map[T]struct{}

func NewSet[T comparable](items ...T) Set[T] {
	s := make(Set[T])
	for _, item := range items {
		s[item] = struct{}{}
	}
	return s
}

func Intersect[T comparable](s1, s2 Set[T]) Set[T] {
	// Оптимизация: итерируемся по меньшему множеству
	if len(s1) > len(s2) {
		s1, s2 = s2, s1
	}
	result := make(Set[T])
	for k := range s1 {
		if _, ok := s2[k]; ok {
			result[k] = struct{}{}
		}
	}
	return result
}

func main() {
	usersGroupA := NewSet("user1", "user2", "user3")
	usersGroupB := NewSet("user2", "user3", "user4")

	common := Intersect(usersGroupA, usersGroupB)
	fmt.Print("Общие пользователи: ")
	for u := range common {
		fmt.Print(u, " ")
	}
	fmt.Println()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Общие пользователи: user2 user3
```

## Под капотом

Своп `if len(s1) > len(s2)` сокращает количество чтений из хэш-таблицы до \(\min(|s1|, |s2|)\).

## Подводные камни

Не забывайте инициализировать `result := make(Set[T])` перед вставкой элементов.

## На собеседовании

**Вопрос с собеседования:** «Какова асимптотика Intersect двух множеств?»
**Ответ:** Время \(O(\min(N, M))\) в среднем, память \(O(\min(N, M))\).
