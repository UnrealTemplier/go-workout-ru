# Обобщенное преобразование слайса Map: числа в строки

## Условие

**Обобщенное преобразование (Map)**: Напишите функцию `Map[T, U any](slice []T, f func(T) U) []U`. Функция должна преобразовывать срез одного типа в срез другого типа с помощью функции `f`. Протестируйте, преобразовав срез целых чисел в срез их строковых представлений.

## Теория

Функция `Map[T, U any]` позволяет трансформировать типы коллекций с сохранением строгой статической типизации.

## Решение по шагам

1. Объявим `Map[T, U any](slice []T, f func(T) U) []U`.
2. Выделим память `make([]U, len(slice))`.
3. Преобразуем `[]int` в `[]string` через `strconv.Itoa`.
4. В `main` выведем результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strconv"
)

func Map[T, U any](slice []T, f func(T) U) []U {
	res := make([]U, len(slice))
	for i, v := range slice {
		res[i] = f(v)
	}
	return res
}

func main() {
	numbers := []int{10, 20, 30, 40}
	strList := Map(numbers, func(n int) string {
		return "num_" + strconv.Itoa(n)
	})
	fmt.Printf("Результат: %v (%T)\n", strList, strList)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Результат: [num_10 num_20 num_30 num_40] ([]string)
```

## Под капотом

Выделяется ровно один блок памяти под `res` без повторных аллокаций.

## Подводные камни

Заполняйте массив по прямому индексу `res[i]`, а не через `append`.

## На собеседовании

**Вопрос с собеседования:** «Каковы преимущества Map над циклом с append?»
**Ответ:** Предварительное выделение точного размера исключает накладные расходы на ступенчатую реаллокацию базового массива.
