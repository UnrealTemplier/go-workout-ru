# Обобщенная структура Pair[K, V] и метод GetValues

## Условие

**Обобщенная структура (Контейнер)**: Создайте обобщенную структуру `Pair[K, V any]` с полями `First K` и `Second V`. Напишите для неё метод `GetValues() (K, V)`. Инициализируйте пару со типами `[string, int]` и пару со типами `[bool, float64]`.

## Теория

Обобщенные структуры инкапсулируют поля разных типов и предоставляют методы доступа.

## Решение по шагам

1. Объявим `type Pair[K, V any] struct { First K; Second V }`.
2. Реализуем метод `(p Pair[K, V]) GetValues() (K, V)`.
3. В `main` создадим `Pair[string, int]` и `Pair[bool, float64]`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Pair[K, V any] struct {
	First  K
	Second V
}

func (p Pair[K, V]) GetValues() (K, V) {
	return p.First, p.Second
}

func main() {
	p1 := Pair[string, int]{First: "MaxRetries", Second: 5}
	k1, v1 := p1.GetValues()
	fmt.Printf("Пара 1: %s = %d\n", k1, v1)

	p2 := Pair[bool, float64]{First: true, Second: 99.9}
	k2, v2 := p2.GetValues()
	fmt.Printf("Пара 2: %v, %.1f\n", k2, v2)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Пара 1: MaxRetries = 5
# Пара 2: true, 99.9
```

## Под капотом

Размер структуры `Pair` рассчитывается компилятором с учетом выравнивания полей (alignment padding).

## Подводные камни

Порядок полей в структурах влияет на общий размер из-за паддингов.

## На собеседовании

**Вопрос с собеседования:** «Как размер структуры Pair[bool, int64] отличается от Pair[int64, int64]?»
**Ответ:** `Pair[bool, int64]` занимает 16 байт (1 байт bool + 7 байт padding + 8 байт int64), то есть ровно столько же, сколько `Pair[int64, int64]` (8 + 8 = 16 байт).
