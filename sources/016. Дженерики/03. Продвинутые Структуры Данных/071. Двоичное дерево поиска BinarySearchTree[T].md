# Двоичное дерево поиска BinarySearchTree[T cmp.Ordered]

## Условие

Реализуй `BinarySearchTree[T constraints.Ordered]` с методами `Insert(v T)`, `Search(v T) bool`, `InOrder() []T`, `Min() (T, bool)`, `Max() (T, bool)`.

## Теория

Бинарное дерево поиска (BST) организует элементы по свойству: левое поддерево содержит меньшие элементы, правое — большие или равные. Обход In-Order возвращает элементы в отсортированном порядке.

## Решение по шагам

1. Объявим `TreeNode[T cmp.Ordered]` и `BST[T cmp.Ordered]`.
2. Реализуем рекурсивные методы `Insert`, `Search`, `InOrder`, `Min`, `Max`.
3. В `main` вставим элементы и проверим обход.

## Код решения

**`main.go`**

```go
package main

import (
	"cmp"
	"fmt"
)

type TreeNode[T cmp.Ordered] struct {
	Value T
	Left  *TreeNode[T]
	Right *TreeNode[T]
}

type BST[T cmp.Ordered] struct {
	root *TreeNode[T]
}

func (b *BST[T]) Insert(v T) {
	b.root = insertNode(b.root, v)
}

func insertNode[T cmp.Ordered](node *TreeNode[T], v T) *TreeNode[T] {
	if node == nil {
		return &TreeNode[T]{Value: v}
	}
	if v < node.Value {
		node.Left = insertNode(node.Left, v)
	} else {
		node.Right = insertNode(node.Right, v)
	}
	return node
}

func (b *BST[T]) Search(v T) bool {
	curr := b.root
	for curr != nil {
		if v == curr.Value {
			return true
		} else if v < curr.Value {
			curr = curr.Left
		} else {
			curr = curr.Right
		}
	}
	return false
}

func (b *BST[T]) InOrder() []T {
	var res []T
	var traverse func(n *TreeNode[T])
	traverse = func(n *TreeNode[T]) {
		if n == nil {
			return
		}
		traverse(n.Left)
		res = append(res, n.Value)
		traverse(n.Right)
	}
	traverse(b.root)
	return res
}

func main() {
	tree := &BST[int]{}
	for _, v := range []int{50, 30, 70, 20, 40, 60, 80} {
		tree.Insert(v)
	}

	fmt.Println("In-Order обход (отсортировано):", tree.InOrder())
	fmt.Println("Поиск 40:", tree.Search(40))
	fmt.Println("Поиск 99:", tree.Search(99))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# In-Order обход (отсортировано): [20 30 40 50 60 70 80]
# Поиск 40: true
# Поиск 99: false
```

## Под капотом

Сравнение `v < node.Value` мономорфизируется компилятором под скалярный тип `int`.

## Подводные камни

Несбалансированное дерево при монотонной вставке может выродиться в связный список с \(O(N)\) поиском. Для гарантии \(O(\log N)\) используют AVL или Красно-черные деревья.

## На собеседовании

**Вопрос с собеседования:** «Какова сложность In-Order обхода дерева?»
**Ответ:** Время \(O(N)\), так как каждый узел посещается ровно один раз. Память \(O(H)\) под стек рекурсии, где \(H\) — высота дерева.
