# Разделение слайса по предикату: Partition[T any]

## Условие

**[Высокая сложность]**: Напиши дженерик-функцию `Partition[T any](slice []T, predicate func(T) bool) ([]T, []T)`, которая разделяет слайс на два: те, что прошли проверку, и те, что нет.

## Теория

`Partition` делит исходную коллекцию на две непересекающиеся группы за один линейный проход (\(O(N)\)).

## Решение по шагам

1. Объявим `Partition[T any](slice []T, predicate func(T) bool) ([]T, []T)`.
2. Создадим срезы `passed` и `failed`.
3. В цикле распределим элементы.
4. В `main` разделим пользователей на активных и заблокированных.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Account struct {
	Username string
	Active   bool
}

func Partition[T any](slice []T, predicate func(T) bool) ([]T, []T) {
	passed := make([]T, 0, len(slice)/2)
	failed := make([]T, 0, len(slice)/2)
	for _, v := range slice {
		if predicate(v) {
			passed = append(passed, v)
		} else {
			failed = append(failed, v)
		}
	}
	return passed, failed
}

func main() {
	accounts := []Account{
		{Username: "alice", Active: true},
		{Username: "bob", Active: false},
		{Username: "carol", Active: true},
		{Username: "dave", Active: false},
	}

	active, inactive := Partition(accounts, func(a Account) bool {
		return a.Active
	})

	fmt.Printf("Активные (%d):   %+v\n", len(active), active)
	fmt.Printf("Неактивные (%d): %+v\n", len(inactive), inactive)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Активные (2):   [{Username:alice Active:true} {Username:carol Active:true}]
# Неактивные (2): [{Username:bob Active:false} {Username:dave Active:false}]
```

## Под капотом

Предвыделение емкости `len(slice)/2` оптимизирует аллокации для равномерно распределенных предикатов.

## Подводные камни

Исходный слайс не мутируется, сохраняя ссылочную прозрачность.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать Partition in-place без выделения новых срезов?»
**Ответ:** Использовать алгоритм разбиения Ломуто или Хоара с двумя указателями (как в Quicksort), меняя элементы местами.
