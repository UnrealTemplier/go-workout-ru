# Связный список LinkedList[T]: Append, Prepend, ToSlice, Find

## Условие

Реализуй `LinkedList[T any]` с узлом `Node[T] struct { Value T; Next *Node[T] }`. Методы: `Append(v T)`, `Prepend(v T)`, `Len() int`, `ToSlice() []T`, `Find(predicate func(T) bool) *Node[T]`.

## Теория

Полнофункциональный связный список поддерживает добавление как в начало (`Prepend` за \(O(1)\)), так и в конец (`Append` за \(O(1)\)).

## Решение по шагам

1. Объявим `Node[T any]` и `LinkedList[T any]`.
2. Реализуем `Append`, `Prepend`, `Len`, `ToSlice`, `Find`.
3. В `main` протестируем список чисел.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Node[T any] struct {
	Value T
	Next  *Node[T]
}

type LinkedList[T any] struct {
	head, tail *Node[T]
	size       int
}

func (l *LinkedList[T]) Append(v T) {
	node := &Node[T]{Value: v}
	if l.head == nil {
		l.head, l.tail = node, node
	} else {
		l.tail.Next = node
		l.tail = node
	}
	l.size++
}

func (l *LinkedList[T]) Prepend(v T) {
	node := &Node[T]{Value: v, Next: l.head}
	l.head = node
	if l.tail == nil {
		l.tail = node
	}
	l.size++
}

func (l *LinkedList[T]) Len() int { return l.size }

func (l *LinkedList[T]) ToSlice() []T {
	res := make([]T, 0, l.size)
	curr := l.head
	for curr != nil {
		res = append(res, curr.Value)
		curr = curr.Next
	}
	return res
}

func (l *LinkedList[T]) Find(pred func(T) bool) *Node[T] {
	curr := l.head
	for curr != nil {
		if pred(curr.Value) {
			return curr
		}
		curr = curr.Next
	}
	return nil
}

func main() {
	list := &LinkedList[int]{}
	list.Append(20)
	list.Append(30)
	list.Prepend(10)

	fmt.Println("Срез списка:", list.ToSlice())
	found := list.Find(func(v int) bool { return v == 20 })
	if found != nil {
		fmt.Println("Найдено значение:", found.Value)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Срез списка: [10 20 30]
# Найдено значение: 20
```

## Под капотом

Поддержание `head` и `tail` дает \(O(1)\) для обеих операций вставки.

## Подводные камни

При вставке `Prepend` в пустой список не забывайте устанавливать `tail = node`.

## На собеседовании

**Вопрос с собеседования:** «Как удалить элемент из односвязного списка за O(1)?»
**Ответ:** В односвязном списке без знания предыдущего узла можно скопировать данные из `node.Next` в текущий узел и переставить `node.Next = node.Next.Next` (если удаляемый узел не последний).
