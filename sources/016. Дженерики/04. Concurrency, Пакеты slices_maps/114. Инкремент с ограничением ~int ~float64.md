# Инкремент с ограничением ~int | ~float64

## Условие

`Increment[T ~int | ~float64](v T) T` — увеличивает на 1 значение любого разрешённого базового типа.

## Теория

Оператор сложения `v + 1` работает для `~int | ~float64`, так как нетипизированная константа `1` приводится к типу `T`.

## Решение по шагам

1. Объявим `Increment[T ~int | ~float64](v T) T { return v + 1 }`.
2. Создадим `type Count int` и `type Ratio float64`.
3. В `main` вызовем `Increment` для обоих типов.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Count int
type Ratio float64

func Increment[T ~int | ~float64](v T) T {
	return v + 1
}

func main() {
	var c Count = 99
	var r Ratio = 3.14

	fmt.Printf("Increment(Count): %d (%T)\n", Increment(c), Increment(c))
	fmt.Printf("Increment(Ratio): %.2f (%T)\n", Increment(r), Increment(r))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Increment(Count): 100 (main.Count)
# Increment(Ratio): 4.14 (main.Ratio)
```

## Под капотом

Константа `1` адаптируется под размер типа `T` без явных конверсий.

## Подводные камни

Нетипизированные константы должны быть представимы в типе `T`.

## На собеседовании

**Вопрос с собеседования:** «Почему выражение v + 1 работает для обоих типов int и float64?»
**Ответ:** Литерал `1` — нетипизированная константа. Компилятор приводит её к типу `T` во время мономорфизации функции.
