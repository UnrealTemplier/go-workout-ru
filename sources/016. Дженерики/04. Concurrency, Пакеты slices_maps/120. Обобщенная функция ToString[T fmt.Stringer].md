# Обобщенная функция ToString[T fmt.Stringer]

## Условие

**[Высокая сложность]**: Создай интерфейс `Stringer` с методом `String() string`. Напиши дженерик-функцию `ToString[T Stringer](val T) string`. Передай в неё структуру, реализующую этот интерфейс.

## Теория

`ToString[T Stringer]` демонстрирует минимальный параметризованный метод форматирования.

## Решение по шагам

1. Объявим `type Stringer interface { String() string }`.
2. Реализуем `ToString[T Stringer](val T) string { return val.String() }`.
3. В `main` вызовем для структуры `ServerInfo`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Stringer interface {
	String() string
}

type ServerInfo struct {
	IP   string
	Port int
}

func (s ServerInfo) String() string {
	return fmt.Sprintf("%s:%d", s.IP, s.Port)
}

func ToString[T Stringer](val T) string {
	return val.String()
}

func main() {
	srv := ServerInfo{IP: "192.168.1.1", Port: 8080}
	fmt.Println("Адрес сервера:", ToString(srv))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Адрес сервера: 192.168.1.1:8080
```

## Под капотом

Прямой вызов `val.String()` оптимизируется компилятором.

## Подводные камни

Любой тип без метода `String()` вызовет ошибку компиляции.

## На собеседовании

**Вопрос с собеседования:** «Может ли ToString инлайниться?»
**Ответ:** Да, компилятор Go инлайнит простые generic-функции и прямые методы при статической мономорфизации.
