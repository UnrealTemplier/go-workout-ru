# Тип Result[T any] с методом Unwrap() (T, error)

## Условие

Тип `Result[T any]` с полями `Value T` и `Err error`, метод `Unwrap() (T, error)`.

## Теория

`Result[T any]` инкапсулирует результат операции и возвращает стандартную пару `(T, error)` через метод `Unwrap()`.

## Решение по шагам

1. Объявим `type Result[T any] struct { Value T; Err error }`.
2. Реализуем `(r Result[T]) Unwrap() (T, error)`.
3. В `main` протестируем парсер.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type Result[T any] struct {
	Value T
	Err   error
}

func (r Result[T]) Unwrap() (T, error) {
	return r.Value, r.Err
}

func safeDivide(a, b int) Result[int] {
	if b == 0 {
		return Result[int]{Err: errors.New("деление на ноль")}
	}
	return Result[int]{Value: a / b}
}

func main() {
	r := safeDivide(10, 2)
	val, err := r.Unwrap()
	if err != nil {
		fmt.Println("Ошибка:", err)
	} else {
		fmt.Println("Результат safeDivide:", val)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Результат safeDivide: 5
```

## Под капотом

Структура `Result[int]` занимает 24 байта на стеке (8 байт int + 16 байт error interface) без аллокаций в куче.

## Подводные камни

Всегда проверяйте `Err != nil` перед использованием `Value`.

## На собеседовании

**Вопрос с собеседования:** «Каков размер интерфейса error в Go?»
**Ответ:** 16 байт (на 64-битной архитектуре): 8 байт указатель на `itab` и 8 байт указатель на данные объекта `data`.
