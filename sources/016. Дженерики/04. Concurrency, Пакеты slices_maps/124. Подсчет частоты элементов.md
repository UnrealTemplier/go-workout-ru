# Подсчет частоты элементов: CountOccurrences[T comparable]

## Условие

Напиши `CountOccurrences[T comparable](s []T) map[T]int`. Покажи, что `comparable` даёт операторы `==` и `!=`, но не `<` или `>`.

## Теория

`CountOccurrences` подсчитывает частоту появления каждого элемента в коллекции, используя `map[T]int`. `comparable` разрешает `==`, но запрещает `<`, `>`.

## Решение по шагам

1. Объявим `CountOccurrences[T comparable](s []T) map[T]int`.
2. В цикле увеличим счетчик `counts[v]++`.
3. В `main` подсчитаем символы и числа.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func CountOccurrences[T comparable](s []T) map[T]int {
	counts := make(map[T]int)
	for _, v := range s {
		counts[v]++
	}
	return counts
}

func main() {
	words := []string{"apple", "banana", "apple", "cherry", "banana", "apple"}
	fmt.Println("Частоты слов:", CountOccurrences(words))

	ids := []int{10, 20, 10, 30, 20, 10}
	fmt.Println("Частоты ID:  ", CountOccurrences(ids))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Частоты слов: map[apple:3 banana:2 cherry:1]
# Частоты ID:   map[10:3 20:2 30:1]
```

## Под капотом

`counts[v]++` для отсутствующего ключа читает zero value (`0`) и увеличивает до `1` без проверок существования.

## Подводные камни

Внутри функции нельзя использовать `if s[0] < s[1]`, так как `comparable` не включает оператор порядка `<`.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между comparable и cmp.Ordered?»
**Ответ:** `comparable` дает только `==` и `!=` (подходит для хэш-мап). `cmp.Ordered` дает `<`, `<=`, `>`, `>=` (подходит для сортировки). Не все comparable типы упорядочены (например, структуры и булевы флаги).
