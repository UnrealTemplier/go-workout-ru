# Стандартный пакет slices в Go 1.21+

## Условие

**Пакет `slices` (Стандартная библиотека)**: С версии Go 1.21 в стандартной библиотеке есть пакет `slices`. Импортируй его. Создай срез строк, отсортируй его через `slices.Sort(s)`. Проверь наличие элемента через `slices.Contains(s, "go")`. Посмотри исходный код этих функций в IDE — они написаны на дженериках!

## Теория

Пакет `slices` стандартной библиотеки Go 1.21+ полностью построен на дженериках: `slices.Sort[S ~[]E, E cmp.Ordered](x S)` и `slices.Contains[S ~[]E, E comparable](s S, v E) bool`.

## Решение по шагам

1. Импортируем `"slices"`.
2. Создадим срез строк `tags`.
3. Отсортируем через `slices.Sort(tags)`.
4. Проверим наличие через `slices.Contains`.
5. В `main` выведем результаты.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"slices"
)

func main() {
	tags := []string{"kubernetes", "docker", "golang", "grpc", "redis"}

	// Проверка наличия
	fmt.Println("Содержит 'golang':", slices.Contains(tags, "golang"))
	fmt.Println("Содержит 'java':  ", slices.Contains(tags, "java"))

	// Сортировка in-place
	slices.Sort(tags)
	fmt.Println("Отсортировано:   ", tags)

	// Бинарный поиск
	idx, found := slices.BinarySearch(tags, "grpc")
	fmt.Printf("BinarySearch 'grpc': индекс=%d, найдено=%v\n", idx, found)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Содержит 'golang': true
# Содержит 'java':   false
# Отсортировано:    [docker golang grpc kubernetes redis]
# BinarySearch 'grpc': индекс=2, найдено=true
```

## Под капотом

`slices.Sort` использует алгоритм pdqsort (Pattern-Defeating Quicksort) с мономорфизацией под тип элементов.

## Подводные камни

`slices.BinarySearch` требует предварительно отсортированного среза.

## На собеседовании

**Вопрос с собеседования:** «Почему slices.Sort быстрее sort.Slice?»
**Ответ:** `sort.Slice` использует рефлексию и swap-функцию через замыкание, а `slices.Sort` инлайнит прямое побайтовое сравнение и своп без аллокаций памяти и вызовов функций.
