# Сложение матриц Matrix[T Integer]

## Условие

Создайте параметризованную структуру `Matrix[T constraints.Integer]` и реализуйте для нее метод сложения двух матриц.

## Теория

Матрица над целочисленными типами `Integer` обеспечивает строгое поэлементное сложение \(C_{ij} = A_{ij} + B_{ij}\).

## Решение по шагам

1. Объявим `type Integer interface { ~int | ~int64 }`.
2. Реализуем `Matrix[T Integer]` с методом `Add`.
3. В `main` сложим две целочисленные матрицы.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Integer interface {
	~int | ~int8 | ~int16 | ~int32 | ~int64 |
		~uint | ~uint8 | ~uint16 | ~uint32 | ~uint64
}

type Matrix[T Integer] struct {
	Rows, Cols int
	Data       [][]T
}

func NewMatrix[T Integer](r, c int) *Matrix[T] {
	d := make([][]T, r)
	for i := range d {
		d[i] = make([]T, c)
	}
	return &Matrix[T]{Rows: r, Cols: c, Data: d}
}

func (m *Matrix[T]) Add(other *Matrix[T]) *Matrix[T] {
	res := NewMatrix[T](m.Rows, m.Cols)
	for i := 0; i < m.Rows; i++ {
		for j := 0; j < m.Cols; j++ {
			res.Data[i][j] = m.Data[i][j] + other.Data[i][j]
		}
	}
	return res
}

func main() {
	m1 := NewMatrix[int](2, 2)
	m1.Data[0] = []int{1, 2}
	m1.Data[1] = []int{3, 4}

	m2 := NewMatrix[int](2, 2)
	m2.Data[0] = []int{5, 6}
	m2.Data[1] = []int{7, 8}

	sum := m1.Add(m2)
	fmt.Printf("Matrix sum: %v\n", sum.Data)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Matrix sum: [[6 8] [10 12]]
```

## Под капотом

Сложение мономорфизируется в быстрые инструкции `ADDQ` без упаковки в интерфейсы.

## Подводные камни

Перед сложением проверяйте совпадение размерностей `Rows` и `Cols`.

## На собеседовании

**Вопрос с собеседования:** «Как SIMD-инструкции ускоряют сложение матриц?»
**Ответ:** Компилятор может векторизовать цикл (Auto-Vectorization), складывая до 8 целых чисел за одну инструкцию `VPADDQ` (AVX-512).
