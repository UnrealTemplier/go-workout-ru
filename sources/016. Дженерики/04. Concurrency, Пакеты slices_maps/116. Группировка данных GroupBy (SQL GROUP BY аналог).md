# Группировка данных GroupBy (SQL GROUP BY аналог)

## Условие

Создайте дженерик-функцию `GroupBy[T any, K comparable](s []T, keyFunc func(T) K) map[K][]T` (аналог `GROUP BY` в SQL).

## Теория

`GroupBy` разбивает срез элементов на группы по ключу `K`, возвращая мапу срезов `map[K][]T`.

## Решение по шагам

1. Объявим `GroupBy[T any, K comparable](s []T, keyFunc func(T) K) map[K][]T`.
2. Создадим мапу `groups := make(map[K][]T)`.
3. В цикле распределим элементы: `groups[k] = append(groups[k], item)`.
4. В `main` сгруппируем пользователей по городам.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Person struct {
	Name string
	City string
}

func GroupBy[T any, K comparable](s []T, keyFunc func(T) K) map[K][]T {
	groups := make(map[K][]T)
	for _, item := range s {
		k := keyFunc(item)
		groups[k] = append(groups[k], item)
	}
	return groups
}

func main() {
	people := []Person{
		{Name: "Иван", City: "Москва"},
		{Name: "Анна", City: "СПб"},
		{Name: "Сергей", City: "Москва"},
		{Name: "Елена", City: "СПб"},
		{Name: "Олег", City: "Казань"},
	}

	byCity := GroupBy(people, func(p Person) string {
		return p.City
	})

	for city, members := range byCity {
		fmt.Printf("Город %-7s (%d чел): ", city, len(members))
		for _, m := range members {
			fmt.Printf("%s ", m.Name)
		}
		fmt.Println()
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Город Москва  (2 чел): Иван Сергей 
# Город СПб     (2 чел): Анна Елена 
# Город Казань  (1 чел): Олег
```

## Под капотом

`GroupBy` выполняется за \(O(N)\) времени и \(O(N)\) памяти.

## Подводные камни

Ключ `K` обязан быть `comparable` для использования в качестве ключа мапы.

## На собеседовании

**Вопрос с собеседования:** «Какова сложность GroupBy?»
**Ответ:** Время \(O(N)\) в среднем благодаря хэш-таблице, память \(O(N)\) для хранения ссылок на элементы.
