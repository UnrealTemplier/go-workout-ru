# Методы generic типов: Clone[T] и наследование параметров

## Условие

Напиши **generic метод** на generic типе:
```go
func (s *Stack[T]) Clone() *Stack[T] {
    // создаёт независимую копию
}
```
Покажи, что методы generic типа **наследуют** параметры типа структуры и могут их использовать.

## Теория

Методы обобщенных структур автоматически наследуют параметры типов `[T]`, объявленные в самой структуре, и могут создавать новые экземпляры `*Stack[T]`.

## Решение по шагам

1. Объявим `type Stack[T any] struct { items []T }`.
2. Реализуем `(s *Stack[T]) Clone() *Stack[T]`.
3. В `main` клонируем стек и проверим независимость копий.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Stack[T any] struct {
	items []T
}

func (s *Stack[T]) Push(v T) {
	s.items = append(s.items, v)
}

// Clone создает глубокую копию стека с независимым срезом.
func (s *Stack[T]) Clone() *Stack[T] {
	copied := make([]T, len(s.items))
	copy(copied, s.items)
	return &Stack[T]{items: copied}
}

func (s *Stack[T]) Items() []T {
	return s.items
}

func main() {
	original := &Stack[int]{}
	original.Push(10)
	original.Push(20)

	cloned := original.Clone()
	cloned.Push(30) // изменяем только клон

	fmt.Println("Оригинал:", original.Items())
	fmt.Println("Клон:    ", cloned.Items())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Оригинал: [10 20]
# Клон:     [10 20 30]
```

## Под капотом

`copy(copied, s.items)` выделяет независимый базовый массив в памяти.

## Подводные камни

Если элементы `T` — это указатели, `Clone` создаст поверхностную копию (Shallow Copy указателей).

## На собеседовании

**Вопрос с собеседования:** «Может ли метод структуры менять параметр типа (например из Stack[int] в Stack[string])?»
**Ответ:** Нет, методы структур не могут вводить новые параметры типа `[U]`. Для изменения типа структуры используется внешняя функция.
