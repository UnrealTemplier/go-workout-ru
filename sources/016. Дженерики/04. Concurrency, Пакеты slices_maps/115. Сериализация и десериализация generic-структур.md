# Сериализация и десериализация generic-структур в JSON

## Условие

Сериализуй generic-тип `Stack[int]` в JSON через `encoding/json`. Затем десериализуй обратно. Объясни, почему это работает: JSON-пакет видит **concrete type** во время выполнения через reflection, а type parameter — это compile-time концепция.

## Теория

Пакет `encoding/json` работает через рефлексию в рантайме. Инстанцированный generic-тип `Stack[int]` во время выполнения является полноценным конкретным типом `main.Stack[int]` с конкретными полями.

## Решение по шагам

1. Объявим `type Stack[T any] struct { Items []T json:"items" }`.
2. Заполним `Stack[int]`.
3. Сериализуем через `json.Marshal` и десериализуем через `json.Unmarshal`.
4. В `main` выведем JSON и восстановленный стек.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
)

type Stack[T any] struct {
	Items []T `json:"items"`
}

func main() {
	s := Stack[int]{Items: []int{10, 20, 30}}

	// Сериализация в JSON
	data, err := json.Marshal(s)
	if err != nil {
		panic(err)
	}
	fmt.Println("JSON:", string(data))

	// Десериализация обратно
	var restored Stack[int]
	if err := json.Unmarshal(data, &restored); err != nil {
		panic(err)
	}
	fmt.Printf("Восстановленный стек: %+v (тип %T)\n", restored, restored)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# JSON: {"items":[10,20,30]}
# Восстановленный стек: {Items:[10 20 30]} (тип main.Stack[int])
```

## Под капотом

Во время выполнения рантайм Go видит готовый тип `main.Stack[int]`, рефлексия парсит поля структуры по тэгам `json:"items"`.

## Подводные камни

Поля дженерик-структуры обязаны быть экспортируемыми (с заглавной буквы), иначе `json.Marshal` проигнорирует их.

## На собеседовании

**Вопрос с собеседования:** «Как дженерики взаимодействуют с reflect и encoding/json?»
**Ответ:** Дженерики в Go инстанцируются во время компиляции. В рантайме `Stack[int]` ничем не отличается от обычной структуры, объявленной вручную.
