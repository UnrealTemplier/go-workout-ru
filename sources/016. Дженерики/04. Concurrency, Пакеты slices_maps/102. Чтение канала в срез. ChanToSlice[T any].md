# Чтение канала в срез: ChanToSlice[T any]

## Условие

Реализуйте дженерик-функцию `ChanToSlice[T any](ch <-chan T) []T`, которая читает канал до его закрытия и собирает данные в слайс.

## Теория

`ChanToSlice` вычитывает все значения из закрывающегося канала `ch` в слайс `[]T`.

## Решение по шагам

1. Объявим `ChanToSlice[T any](ch <-chan T) []T`.
2. Проитерируемся `for v := range ch`.
3. В `main` передадим закрытый канал.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func ChanToSlice[T any](ch <-chan T) []T {
	var result []T
	for v := range ch {
		result = append(result, v)
	}
	return result
}

func main() {
	ch := make(chan string, 3)
	ch <- "alpha"
	ch <- "beta"
	ch <- "gamma"
	close(ch)

	slice := ChanToSlice(ch)
	fmt.Printf("Срез из канала: %v (len=%d)\n", slice, len(slice))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Срез из канала: [alpha beta gamma] (len=3)
```

## Под капотом

Цикл `for range ch` читает из `hchan` до установки флага `closed`.

## Подводные камни

Если канал не будет закрыт отправителем, функция заблокируется навсегда (Goroutine Leak / Deadlock).

## На собеседовании

**Вопрос с собеседования:** «Что произойдет при чтении из nil-канала?»
**Ответ:** Чтение из `nil`-канала блокирует горутину навсегда.
