# Эффект Shared Underlying Array в generic append

## Условие

Покажи, что generic `append` имеет тот же эффект **shared underlying array**: создай функцию `AppendAll[T any](s []T, items ...T) []T`, возвращающую `append(s, items...)`. В `main` создай слайс с `len == cap`, передай в функцию, измени возвращённый слайс — покажи, что оригинал **не** изменился (реаллокация). Затем с `cap > len` — покажи, что оригинал **изменился** (тот же массив).

## Теория

Generic-слайсы `[]T` под капотом ведут себя в точности как обычные слайсы: `append` мутирует общий базовый массив, если `cap > len`, и аллоцирует новый массив при `len == cap`.

## Решение по шагам

1. Объявим `AppendAll[T any](s []T, items ...T) []T`.
2. Протестируем сценарий `len == cap` (происходит реаллокация).
3. Протестируем сценарий `cap > len` (мутируется общий массив).

## Код решения

**`main.go`**

```go
package main

import "fmt"

func AppendAll[T any](s []T, items ...T) []T {
	return append(s, items...)
}

func main() {
	// Сценарий 1: len == cap (реаллокация, массивы РАЗДЕЛЬНЫЕ)
	s1 := make([]int, 2, 2)
	s1[0], s1[1] = 10, 20
	res1 := AppendAll(s1, 30)
	res1[0] = 999
	fmt.Printf("len==cap -> s1[0]=%d, res1[0]=%d (не изменился)\n", s1[0], res1[0])

	// Сценарий 2: cap > len (тот же массив, МУТАЦИЯ)
	s2 := make([]int, 2, 5)
	s2[0], s2[1] = 10, 20
	res2 := AppendAll(s2, 30)
	res2[0] = 999
	fmt.Printf("cap>len  -> s2[0]=%d, res2[0]=%d (ИЗМЕНИЛСЯ!)\n", s2[0], res2[0])
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# len==cap -> s1[0]=10, res1[0]=999 (не изменился)
# cap>len  -> s2[0]=999, res2[0]=999 (ИЗМЕНИЛСЯ!)
```

## Под капотом

Заголовок слайса `SliceHeader` передается по значению, но указывает на общий участок памяти `Data`.

## Подводные камни

Опасность мутации базового массива — частый источник багов в конкурентных сервисах. Используйте 3-индексный срез `s[0:2:2]` для защиты емкости.

## На собеседовании

**Вопрос с собеседования:** «Как защитить срез от модификации функции Append?»
**Ответ:** Использовать Full Slice Expression (3-index slice) `s[:len:len]`, что устанавливает `cap == len` и гарантирует создание нового массива при любом `append`.
