# Constraint с набором методов Method Set: Stringer

## Условие

Напиши generic-функцию с constraint, требующим метод:
```go
type Stringer interface { String() string }
func PrintString[T Stringer](v T) { fmt.Println(v.String()) }
```
Передай тип без метода `String()` — получи ошибку компиляции. Покажи, что constraint может включать **method set**.

## Теория

Ограничение может состоять из интерфейса с методами. Тип `T` обязан реализовывать указанный интерфейс.

## Решение по шагам

1. Объявим `type Stringer interface { String() string }`.
2. Реализуем `PrintString[T Stringer](v T)`.
3. Создадим `User` с методом `String()`.
4. В `main` покажем вызов.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Stringer interface {
	String() string
}

type User struct {
	Name string
}

func (u User) String() string {
	return "User: " + u.Name
}

func PrintString[T Stringer](v T) {
	fmt.Println(v.String())
}

func main() {
	u := User{Name: "Дмитрий"}
	PrintString(u)

	// Следующая строка вызовет ошибку компиляции:
	// PrintString(100) // ОШИБКА: int does not satisfy Stringer (missing method String)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# User: Дмитрий
```

## Под капотом

Компилятор вызывает `v.String()` по прямому адресу метода без накладных расходов на `itab` lookup.

## Подводные камни

Если метод объявлен на указателе `(u *User) String()`, передавать нужно `*User`.

## На собеседовании

**Вопрос с собеседования:** «Почему PrintString\[T Stringer](v T) быстрее PrintString(v Stringer)?»
**Ответ:** Дженерик выполняет прямой статический вызов функции (direct call) и позволяет компилятору заинлайнить метод, а интерфейс выполняет косвенный вызов через указатель в `itab` (indirect call).
