# Сравнение элементов AreEqual и поэлементная эквивалентность слайсов

## Условие

Напиши функцию `AreEqual[T comparable](a, b T) bool`. Используй её для сравнения двух слайсов (слайсы сравнимы через `==`, если их элементы сравнимы).

## Теория

Хотя сами слайсы `[]T` не являются `comparable`, их можно сравнивать поэлементно: сначала длина `len(s1) == len(s2)`, затем попарное равенство элементов `s1[i] == s2[i]`.

## Решение по шагам

1. Реализуем `AreEqual[T comparable](a, b T) bool { return a == b }`.
2. Реализуем `EqualSlices[T comparable](s1, s2 []T) bool`.
3. В `main` сравним два слайса чисел и строк.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func AreEqual[T comparable](a, b T) bool {
	return a == b
}

func EqualSlices[T comparable](s1, s2 []T) bool {
	if len(s1) != len(s2) {
		return false
	}
	for i := range s1 {
		if !AreEqual(s1[i], s2[i]) {
			return false
		}
	}
	return true
}

func main() {
	a := []int{1, 2, 3}
	b := []int{1, 2, 3}
	c := []int{1, 2, 4}

	fmt.Println("a == b:", EqualSlices(a, b))
	fmt.Println("a == c:", EqualSlices(a, c))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# a == b: true
# a == c: false
```

## Под капотом

В Go 1.21+ аналогичная функция `slices.Equal` мономорфизируется с оптимизацией проверок длины.

## Подводные камни

`EqualSlices` возвращает `true` при сравнении `nil` слайса и пустого среза `[]int{}`, так как их длины равны 0.

## На собеседовании

**Вопрос с собеседования:** «Равны ли var s1 []int = nil и s2 := []int{} с точки зрения slices.Equal?»
**Ответ:** Да. `slices.Equal` проверяет совпадение длины и элементов. У обоих срезов длина 0 и 0 элементов, поэтому `slices.Equal(s1, s2)` возвращает `true`.
