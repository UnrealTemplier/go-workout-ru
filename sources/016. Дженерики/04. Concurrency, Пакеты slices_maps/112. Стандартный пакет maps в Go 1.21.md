# Стандартный пакет maps в Go 1.21+

## Условие

**Пакет `maps` (Стандартная библиотека)**: Импортируй стандартный пакет `maps`. Используй `maps.Clone()` для глубокого (shallow) копирования мапы. Посмотри, как красиво работают дженерики "из коробки".

## Теория

Пакет `maps` стандартной библиотеки Go 1.21+ предоставляет generic-функции `maps.Clone[M ~map[K]V, K comparable, V any](m M) M`, `maps.Equal` и `maps.DeleteFunc`.

## Решение по шагам

1. Импортируем `"maps"`.
2. Создадим мапу `original`.
3. Выполним `copyMap := maps.Clone(original)`.
4. Изменим копию и убедимся, что оригинал не изменился.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"maps"
)

func main() {
	original := map[string]int{"cpu": 4, "ram": 16}
	cloned := maps.Clone(original)

	// Модифицируем клон:
	cloned["ram"] = 32
	cloned["gpu"] = 1

	fmt.Println("Оригинал: ", original)
	fmt.Println("Клон:     ", cloned)
	fmt.Println("Равны:    ", maps.Equal(original, cloned))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Оригинал:  map[cpu:4 ram:16]
# Клон:      map[cpu:4 gpu:1 ram:32]
# Равны:     false
```

## Под капотом

`maps.Clone` создает новую мапу с предвыделенными бакетами емкостью `len(m)` и копирует ключи и значения.

## Подводные камни

`maps.Clone` выполняет shallow copy (поверхностное копирование). Если значение `V` — указатель или слайс, они останутся общими.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие shallow copy от deep copy для maps.Clone?»
**Ответ:** `maps.Clone` копирует только саму хэш-таблицу. Если значение `V` — это `*User` или `[]string`, обе мапы будут указывать на один и тот же объект в куче.
