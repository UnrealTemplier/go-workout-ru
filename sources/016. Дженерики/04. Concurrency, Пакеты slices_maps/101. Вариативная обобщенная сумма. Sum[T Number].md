# Вариативная обобщенная сумма: Sum[T Number]

## Условие

Напиши generic-функцию с **variadic** параметром: `Sum[T Number](nums ...T) T`. Вызови `Sum(1, 2, 3, 4)` и `Sum[int](1, 2, 3)`.

## Теория

Go позволяет комбинировать параметры типов и вариативные параметры: `func Sum[T Number](nums ...T) T`.

## Решение по шагам

1. Объявим `type Number interface { ~int | ~float64 }`.
2. Реализуем `Sum[T Number](nums ...T) T`.
3. В `main` вызовем `Sum(1, 2, 3, 4)` и `Sum[int](10, 20)`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Number interface {
	~int | ~int64 | ~float64
}

func Sum[T Number](nums ...T) T {
	var total T
	for _, n := range nums {
		total += n
	}
	return total
}

func main() {
	// Неявный вызов:
	fmt.Println("Sum(1, 2, 3, 4) =", Sum(1, 2, 3, 4))

	// Явный вызов:
	fmt.Println("Sum[int](10, 20) =", Sum[int](10, 20))

	// С вещественными числами:
	fmt.Println("Sum(1.5, 2.5, 3.5) =", Sum(1.5, 2.5, 3.5))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Sum(1, 2, 3, 4) = 10
# Sum[int](10, 20) = 30
# Sum(1.5, 2.5, 3.5) = 7.5
```

## Под капотом

Вариативный параметр `...T` транслируется в срез `[]T` под капотом.

## Подводные камни

При вызове без аргументов `Sum()` вернет zero value (`0`).

## На собеседовании

**Вопрос с собеседования:** «Аллоцирует ли память вызов Sum(1, 2, 3)?»
**Ответ:** Компилятор размещает вариативный срез фиксированной длины на стеке, если аргументы не утекают в кучу (0 allocations).
