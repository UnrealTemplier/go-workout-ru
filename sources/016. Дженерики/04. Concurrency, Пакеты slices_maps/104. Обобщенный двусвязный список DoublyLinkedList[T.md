# Обобщенный двусвязный список DoublyLinkedList[T any]

## Условие

**Обобщенный двусвязный список**: Создайте структуру `ListNode[T any]` с полями `Value T`, `Next *ListNode[T]`, `Prev *ListNode[T]`. Создайте структуру `LinkedList[T any]` с методами добавления элемента в конец и обхода списка.

## Теория

Двусвязный список хранит ссылки на предыдущий `Prev` и следующий `Next` узлы, позволяя выполнять удаление за \(O(1)\) при наличии указателя на узел.

## Решение по шагам

1. Объявим `ListNode[T any]` и `DoublyLinkedList[T any]`.
2. Реализуем `PushBack` и `PrintForward`.
3. В `main` протестируем работу.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type ListNode[T any] struct {
	Value T
	Next  *ListNode[T]
	Prev  *ListNode[T]
}

type DoublyLinkedList[T any] struct {
	head, tail *ListNode[T]
	len        int
}

func (d *DoublyLinkedList[T]) PushBack(v T) {
	newNode := &ListNode[T]{Value: v, Prev: d.tail}
	if d.tail != nil {
		d.tail.Next = newNode
	} else {
		d.head = newNode
	}
	d.tail = newNode
	d.len++
}

func (d *DoublyLinkedList[T]) PrintForward() {
	curr := d.head
	for curr != nil {
		fmt.Printf("[%v] <-> ", curr.Value)
		curr = curr.Next
	}
	fmt.Println("nil")
}

func main() {
	dll := &DoublyLinkedList[string]{}
	dll.PushBack("Node A")
	dll.PushBack("Node B")
	dll.PushBack("Node C")

	dll.PrintForward()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Node A] <-> [Node B] <-> [Node C] <-> nil
```

## Под капотом

Указатели `Next` и `Prev` связывают элементы в двунаправленную цепочку памяти.

## Подводные камни

При удалении узла аккуратно обновляйте ссылки обоих соседей `node.Prev.Next` и `node.Next.Prev`.

## На собеседовании

**Вопрос с собеседования:** «Как реализован LRU-кэш в BigTech?»
**Ответ:** Комбинацией `map[Key]*ListNode[Entry]` для поиска за \(O(1)\) и `DoublyLinkedList` для мгновенного перемещения недавно использованного элемента в начало за \(O(1)\).
