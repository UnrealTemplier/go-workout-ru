# Объединение методов и типов: StringableNumeric

## Условие

**Объединение методов и типов в ограничениях**: Создайте интерфейс-ограничение `StringableNumeric`, который требует, чтобы тип наследовал ограничение `Numeric` (из задачи №221) **и** реализовывал метод `String() string`. Напишите функцию, использующую это ограничение.

## Теория

`StringableNumeric` объединяет числовой Type Set и строковый Method Set.

## Решение по шагам

1. Объявим `type StringableNumeric interface { ~int | ~float64; String() string }`.
2. Создадим `type Measurement float64` с методом `String()`.
3. Напишем `FormatDouble[T StringableNumeric](v T) string`.
4. Проверим в `main`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type StringableNumeric interface {
	~int | ~float64
	String() string
}

type Measurement float64

func (m Measurement) String() string {
	return fmt.Sprintf("%.2f kg", m)
}

func FormatDouble[T StringableNumeric](v T) string {
	doubled := v * 2
	return fmt.Sprintf("Оригинал: %s | Удвоенное: %s", v.String(), doubled.String())
}

func main() {
	var m Measurement = 12.5
	fmt.Println(FormatDouble(m))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Оригинал: 12.50 kg | Удвоенное: 25.00 kg
```

## Под капотом

Компилятор разрешает оператор `*` благодаря `~float64` и вызов метода `String()` благодаря Method Set.

## Подводные камни

Встроенный `float64` не может быть передан, так как у него нет метода `String()`.

## На собеседовании

**Вопрос с собеседования:** «Как StringableNumeric гарантирует безопасность операций?»
**Ответ:** Компилятор статически гарантирует, что к значению можно применить арифметические операторы и вызвать метод `String()` без runtime-проверок.
