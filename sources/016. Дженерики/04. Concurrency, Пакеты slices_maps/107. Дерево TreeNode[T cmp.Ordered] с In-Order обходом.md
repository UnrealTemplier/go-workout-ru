# Дерево TreeNode[T cmp.Ordered] с In-Order обходом

## Условие

Создайте параметризованную структуру `TreeNode[T any]` для бинарного дерева с методами вставки и обхода (in-order traversal).

## Теория

Бинарное дерево поиска структурирует данные для быстрого поиска за \(O(\log N)\).

## Решение по шагам

1. Объявим `TreeNode[T cmp.Ordered]`.
2. Реализуем `Insert` и `InOrder`.
3. В `main` выведем строки в отсортированном порядке.

## Код решения

**`main.go`**

```go
package main

import (
	"cmp"
	"fmt"
)

type TreeNode[T cmp.Ordered] struct {
	Val   T
	Left  *TreeNode[T]
	Right *TreeNode[T]
}

func (n *TreeNode[T]) Insert(v T) *TreeNode[T] {
	if n == nil {
		return &TreeNode[T]{Val: v}
	}
	if v < n.Val {
		n.Left = n.Left.Insert(v)
	} else {
		n.Right = n.Right.Insert(v)
	}
	return n
}

func (n *TreeNode[T]) InOrder() []T {
	if n == nil {
		return nil
	}
	var res []T
	res = append(res, n.Left.InOrder()...)
	res = append(res, n.Val)
	res = append(res, n.Right.InOrder()...)
	return res
}

func main() {
	var root *TreeNode[string]
	for _, s := range []string{"mango", "apple", "peach", "banana"} {
		root = root.Insert(s)
	}

	fmt.Println("In-Order:", root.InOrder())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# In-Order: [apple banana mango peach]
```

## Под капотом

In-Order обход бинарного дерева поиска гарантирует лексикографический порядок элементов.

## Подводные камни

Рекурсивный `InOrder` с `append(res, ...)` создает лишние слайсы; для оптимизации передавайте аккумулятор `*[]T`.

## На собеседовании

**Вопрос с собеседования:** «Как избежать рекурсивных аллокаций при обходе дерева?»
**Ответ:** Использовать итеративный обход со стеком или передавать слайс-аккумулятор по указателю.
