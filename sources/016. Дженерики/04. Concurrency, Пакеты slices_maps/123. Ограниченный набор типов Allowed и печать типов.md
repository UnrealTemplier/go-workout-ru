# Ограниченный набор типов Allowed и печать типов

## Условие

Ограниченный набор типов: `Allowed = int | string | bool`. Функция `Print[T Allowed](v T)` печатает значение и тип.

## Теория

Интерфейс `Allowed` создает замкнутое объединение допустимых типов.

## Решение по шагам

1. Объявим `type Allowed interface { ~int | ~string | ~bool }`.
2. Реализуем `PrintAllowed[T Allowed](v T)`.
3. В `main` вызовем для каждого разрешенного типа.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Allowed interface {
	~int | ~string | ~bool
}

func PrintAllowed[T Allowed](v T) {
	fmt.Printf("Значение: %-10v | Тип: %T\n", v, v)
}

func main() {
	PrintAllowed(42)
	PrintAllowed("Gopher")
	PrintAllowed(true)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Значение: 42         | Тип: int
# Значение: Gopher     | Тип: string
# Значение: true       | Тип: bool
```

## Под капотом

Компилятор создает три специализированные копии функции под каждый тип.

## Подводные камни

Попытка передать `3.14` вызовет ошибку `float64 missing in Allowed`.

## На собеседовании

**Вопрос с собеседования:** «Как ограничить дженерик только определенным перечнем типов?»
**Ответ:** Использовать Type Union оператор `|` в интерфейсе-ограничении (`~int | ~string | ~bool`).
