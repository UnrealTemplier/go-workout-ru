## Теория

Generic Repository `Repository[T Identifiable]` предоставляет единый слой абстракции для сущностей, имеющих первичный ключ `GetID() int`.

## Решение по шагам

1. Объявим `type Identifiable interface { GetID() int }`.
2. Реализуем `Repository[T Identifiable]` с `Save`, `GetByID`, `GetAll`.
3. Создадим сущности `User` и `Product`.
4. В `main` сохраним и получим сущности.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type Identifiable interface {
	GetID() int
}

type Repository[T Identifiable] struct {
	items []T
}

func (r *Repository[T]) Save(item T) {
	for i, existing := range r.items {
		if existing.GetID() == item.GetID() {
			r.items[i] = item
			return
		}
	}
	r.items = append(r.items, item)
}

func (r *Repository[T]) GetByID(id int) (T, error) {
	for _, item := range r.items {
		if item.GetID() == id {
			return item, nil
		}
	}
	var zero T
	return zero, errors.New("entity not found")
}

func (r *Repository[T]) GetAll() []T {
	return r.items
}

type User struct {
	ID   int
	Name string
}

func (u User) GetID() int { return u.ID }

type Product struct {
	ID    int
	Title string
	Price float64
}

func (p Product) GetID() int { return p.ID }

func main() {
	userRepo := &Repository[User]{}
	userRepo.Save(User{ID: 1, Name: "Алексей"})
	userRepo.Save(User{ID: 2, Name: "Мария"})

	u, _ := userRepo.GetByID(1)
	fmt.Printf("User: %+v\n", u)

	productRepo := &Repository[Product]{}
	productRepo.Save(Product{ID: 101, Title: "Клавиатура", Price: 4500})
	p, _ := productRepo.GetByID(101)
	fmt.Printf("Product: %+v\n", p)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# User: {ID:1 Name:Алексей}
# Product: {ID:101 Title:Клавиатура Price:4500}
```

## Под капотом

`Repository[User]` и `Repository[Product]` компилируются в две независимые типизированные структуры.

## Подводные камни

Сущности обязаны реализовывать метод `GetID() int`.
