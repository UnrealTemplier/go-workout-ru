# Обобщённая min-куча Heap[T cmp.Ordered]

## Условие

Обобщённая min-куча `Heap[T constraints.Ordered]` со срезом, методы `Insert`, `ExtractMin`.

### Исходная формулировка

Обобщённая min-куча `Heap[T constraints.Ordered]` со срезом, методы `Insert`, `ExtractMin`.

## Теория

Min-куча хранит наименьший элемент в корне `tree[0]` и обеспечивает извлечение минимума за \(O(\log N)\).

## Решение по шагам

1. Объявим `type Heap[T cmp.Ordered] struct { items []T }`.
2. Реализуем `Insert(v T)` и `ExtractMin() (T, bool)`.
3. В `main` вставим числа и извлечем минимум.

## Код решения

**`main.go`**

```go
package main

import (
	"cmp"
	"fmt"
)

type Heap[T cmp.Ordered] struct {
	items []T
}

func (h *Heap[T]) Insert(v T) {
	h.items = append(h.items, v)
	i := len(h.items) - 1
	for i > 0 {
		parent := (i - 1) / 2
		if h.items[i] < h.items[parent] {
			h.items[i], h.items[parent] = h.items[parent], h.items[i]
			i = parent
		} else {
			break
		}
	}
}

func (h *Heap[T]) ExtractMin() (T, bool) {
	if len(h.items) == 0 {
		var zero T
		return zero, false
	}
	min := h.items[0]
	last := len(h.items) - 1
	h.items[0] = h.items[last]
	h.items = h.items[:last]

	i := 0
	n := len(h.items)
	for {
		left := 2*i + 1
		right := 2*i + 2
		smallest := i

		if left < n && h.items[left] < h.items[smallest] {
			smallest = left
		}
		if right < n && h.items[right] < h.items[smallest] {
			smallest = right
		}
		if smallest != i {
			h.items[i], h.items[smallest] = h.items[smallest], h.items[i]
			i = smallest
		} else {
			break
		}
	}
	return min, true
}

func (h *Heap[T]) Len() int { return len(h.items) }

func main() {
	h := &Heap[int]{}
	h.Insert(50)
	h.Insert(10)
	h.Insert(30)
	h.Insert(5)

	fmt.Print("Извлечение из кучи: ")
	for h.Len() > 0 {
		v, _ := h.ExtractMin()
		fmt.Printf("%d ", v)
	}
	fmt.Println()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Извлечение из кучи: 5 10 30 50
```

## Под капотом

Массив элементов сжимается `h.items[:last]`, сохраняя выделенную память `cap`.

## Подводные камни

При пустой куче метод возвращает `(zero, false)`.

## На собеседовании

**Вопрос с собеседования:** «Какова сложность построения кучи из готового массива?»
**Ответ:** Линейная \(O(N)\) при использовании алгоритма Floyd's Heapify (sift-down от середины массива к началу).
