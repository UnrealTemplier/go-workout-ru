# Преобразование коллекции в строки: Stringify[T fmt.Stringer]

## Условие

**Сложное ограничение (Constraint с методами)**: Напиши функцию `Stringify[T fmt.Stringer](slice []T) []string`, которая принимает срез любых объектов, реализующих метод `String()`, и возвращает срез готовых строк.

## Теория

`Stringify` преобразует срез любых объектов, удовлетворяющих `fmt.Stringer`, в срез строк `[]string`.

## Решение по шагам

1. Объявим `Stringify[T fmt.Stringer](slice []T) []string`.
2. Создадим структуру `Product`.
3. В `main` преобразуем срез продуктов в строки.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Product struct {
	Name  string
	Price int
}

func (p Product) String() string {
	return fmt.Sprintf("%s (%d руб)", p.Name, p.Price)
}

func Stringify[T fmt.Stringer](slice []T) []string {
	res := make([]string, len(slice))
	for i, v := range slice {
		res[i] = v.String()
	}
	return res
}

func main() {
	products := []Product{
		{Name: "Ноутбук", Price: 75000},
		{Name: "Мышь", Price: 2500},
	}

	strs := Stringify(products)
	for _, s := range strs {
		fmt.Println("->", s)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# -> Ноутбук (75000 руб)
# -> Мышь (2500 руб)
```

## Под капотом

`Stringify` мономорфизируется под структуру `Product` с прямыми статическими вызовами метода.

## Подводные камни

Если `String()` объявлен на `*Product`, используйте `[]*Product`.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между Stringify\[T fmt.Stringer]([]T) и Stringify([]fmt.Stringer)?»
**Ответ:** `[]Product` нельзя передать в `[]fmt.Stringer` без конверсии, а в дженерик `[]T` он передается напрямую без аллокаций.
