# Type Switch и type parameter: обход через any(v).(type)

## Условие

Покажи, что **type switch не работает** с type parameter напрямую:
```go
func TypeName[T any](v T) string {
    switch v.(type) { // ОШИБКА!
    }
}
```
Обход: `switch any(v).(type)`. Объясни, почему так (type parameter — не конкретный тип во время компиляции для type switch).

## Теория

Конструкция `switch v.(type)` в Go разрешена только для значений интерфейсного типа. Поскольку параметр типа `T` — это абстрактный тип, прямой type switch вызывает ошибку компиляции `cannot use type switch on non-interface value v`.

Обход: привести значение к интерфейсу `any(v)`:
```go
switch val := any(v).(type) {
case int: ...
case string: ...
}
```

## Решение по шагам

1. Объявим функцию `TypeName[T any](v T) string`.
2. Внутри выполним `switch any(v).(type)`.
3. В `main` проверим вызов с `int`, `string`, `bool`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strconv"
)

// TypeName определяет строковое представление типа через switch any(v).(type)
func TypeName[T any](v T) string {
	// switch v.(type) - ОШИБКА КОМПИЛЯЦИИ!
	// Правильный обход через any(v):
	switch val := any(v).(type) {
	case int:
		return "Integer (" + strconv.Itoa(val) + ")"
	case string:
		return "String (\"" + val + "\")"
	case bool:
		return "Boolean (" + strconv.FormatBool(val) + ")"
	default:
		return fmt.Sprintf("Unknown (%T)", val)
	}
}

func main() {
	fmt.Println(TypeName(100))
	fmt.Println(TypeName("Gopher"))
	fmt.Println(TypeName(true))
	fmt.Println(TypeName(3.14))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Integer (100)
# String ("Gopher")
# Boolean (true)
# Unknown (float64)
```

## Под капотом

`any(v)` упаковывает значение в `eface`, позволяя рантайму динамически сопоставить поле `_type`.

## Подводные камни

Частое использование type switch внутри дженериков является код-смеллом: если вам нужен разный код под каждый тип, возможно дженерик здесь избыточен.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go запретили прямой switch v.(type) для параметров типов?»
**Ответ:** В Go дженерики предназначены для параметрического полиморфизма (одинаковый код для всех типов). Ветка `switch` — это ad-hoc полиморфизм. Разработчики намеренно требуют явного боксинга в `any(v)`, подчеркивая накладные расходы на dynamic type assertion.
