# In-place разворот слайса Reverse[T any]

## Условие

Напишите параметризованную функцию `Reverse[T any](s []T) []T`, которая разворачивает слайс любого типа in-place.

## Теория

In-place разворот выполняется за \(O(N/2)\) шагов с \(O(1)\) памяти через перестановку симметричных элементов.

## Решение по шагам

1. Объявим `ReverseInPlace[T any](s []T) []T`.
2. Запустим цикл с двумя индексами `i` и `j`.
3. В `main` развернем срез чисел и строк.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func ReverseInPlace[T any](s []T) []T {
	for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1 {
		s[i], s[j] = s[j], s[i]
	}
	return s
}

func main() {
	nums := []int{1, 2, 3, 4, 5}
	ReverseInPlace(nums)
	fmt.Println("Развернутые числа:", nums)

	words := []string{"Go", "is", "fast"}
	ReverseInPlace(words)
	fmt.Println("Развернутые строки:", words)
}
```

ℹ️ Разворот in-place без аллокаций

**`Терминал`**

```bash
go run main.go
# Вывод:
# Развернутые числа: [5 4 3 2 1]
# Развернутые строки: [fast is Go]
```

## Под капотом

In-place разворот не выделяет память в куче (0 allocations).

## Подводные камни

Функция меняет оригинальный массив, что может вызвать побочные эффекты при совместном доступе.

## На собеседовании

**Вопрос с собеседования:** «Какова сложность slices.Reverse?»
**Ответ:** Время \(O(N)\), память \(O(1)\).
