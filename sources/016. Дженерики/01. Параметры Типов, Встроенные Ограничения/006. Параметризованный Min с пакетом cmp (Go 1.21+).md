# Параметризованный Min с пакетом cmp (Go 1.21+)

## Условие

Напишите параметризованную функцию `Min[T cmp.Ordered](a, b T) T` (используя пакет `cmp` из Go 1.21+), которая возвращает меньшее из двух значений.

## Теория

Пакет `cmp` стал частью стандартной библиотеки в Go 1.21. Он предоставляет интерфейс `cmp.Ordered` и функции `cmp.Less` и `cmp.Compare`.

## Решение по шагам

1. Импортируем `"cmp"`.
2. Реализуем `Min[T cmp.Ordered](a, b T) T` через `cmp.Less(a, b)`.
3. В `main` вызовем `Min` для чисел и строк.

## Код решения

**`main.go`**

```go
package main

import (
	"cmp"
	"fmt"
)

func Min[T cmp.Ordered](a, b T) T {
	if cmp.Less(a, b) {
		return a
	}
	return b
}

func main() {
	fmt.Println("Min(10, 20) =", Min(10, 20))
	fmt.Println("Min(99.9, 12.3) =", Min(99.9, 12.3))
	fmt.Println("Min(\"Go\", \"Rust\") =", Min("Go", "Rust"))
}
```

ℹ️ Стандартный пакет cmp из Go 1.21+

**`Терминал`**

```bash
go run main.go
# Вывод:
# Min(10, 20) = 10
# Min(99.9, 12.3) = 12.3
# Min("Go", "Rust") = Go
```

## Под капотом

`cmp.Less` корректно обрабатывает `NaN` для чисел с плавающей точкой, гарантируя строгое отношение порядка.

## Подводные камни

Не используйте устаревший внешний пакет `golang.org/x/exp/constraints` в проектах Go 1.21+.

## На собеседовании

**Вопрос с собеседования:** «Как cmp.Compare обрабатывает NaN?»
**Ответ:** `cmp.Compare(NaN, x)` возвращает `-1`, а `cmp.Compare(NaN, NaN)` возвращает `0`, обеспечивая детерминированную работу алгоритмов сортировки `slices.Sort`.
