# Поиск первого совпадения Find[T any] и нулевое значение

## Условие

Напиши `Find[T any](slice []T, predicate func(T) bool) (T, bool)`. Найди первый элемент, удовлетворяющий предикату. Верни zero value и `false`, если не найден.

## Теория

Для возврата zero value произвольного типа `T` в Go используется паттерн `var zero T; return zero, false`.

## Решение по шагам

1. Объявим `Find[T any](slice []T, predicate func(T) bool) (T, bool)`.
2. Если `predicate(v)` истинно, возвращаем `(v, true)`.
3. После цикла объявляем `var zero T` и возвращаем `(zero, false)`.
4. В `main` найдем первое четное число и число > 100.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Find[T any](slice []T, predicate func(T) bool) (T, bool) {
	for _, v := range slice {
		if predicate(v) {
			return v, true
		}
	}
	var zero T
	return zero, false
}

func main() {
	nums := []int{7, 13, 24, 35, 48}

	if val, ok := Find(nums, func(n int) bool { return n%2 == 0 }); ok {
		fmt.Printf("Найдено первое четное: %d\n", val)
	}

	if val, ok := Find(nums, func(n int) bool { return n > 100 }); ok {
		fmt.Printf("Найдено: %d\n", val)
	} else {
		fmt.Printf("Элемент > 100 не найден. Zero value: %d\n", val)
	}
}
```

ℹ️ Идиоматичный возврат zero value

**`Терминал`**

```bash
go run main.go
# Вывод:
# Найдено первое четное: 24
# Элемент > 100 не найден. Zero value: 0
```

## Под капотом

`var zero T` зануляет область памяти размером `sizeof(T)`.

## Подводные камни

Попытка написать `return nil, false` вызовет ошибку компиляции `cannot use nil as T value`.

## На собеседовании

**Вопрос с собеседования:** «Как получить нулевое значение параметризованного типа в одну строку?»
**Ответ:** Через разыменование свежевыделенного указателя `*new(T)`.
