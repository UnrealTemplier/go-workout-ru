# Иммутабельный разворот слайса Reverse[T any]

## Условие

Напиши `Reverse[T any](s []T) []T`. Верни **новый** слайс в обратном порядке (не меняя оригинал).

## Теория

Иммутабельный разворот создает новый массив в памяти, гарантируя отсутствие побочных эффектов.

## Решение по шагам

1. Объявим `Reverse[T any](s []T) []T`.
2. Выделим `res := make([]T, len(s))`.
3. Заполним `res[n - 1 - i] = s[i]`.
4. В `main` развернем срез строк.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Reverse[T any](s []T) []T {
	n := len(s)
	res := make([]T, n)
	for i, v := range s {
		res[n-1-i] = v
	}
	return res
}

func main() {
	original := []string{"первый", "второй", "третий", "четвертый"}
	reversed := Reverse(original)

	fmt.Println("Оригинал:  ", original)
	fmt.Println("Развернутый:", reversed)
}
```

ℹ️ Иммутабельный разворот слайса

**`Терминал`**

```bash
go run main.go
# Вывод:
# Оригинал:   [первый второй третий четвертый]
# Развернутый: [четвертый третий второй первый]
```

## Под капотом

Новый слайс получает независимый базовый массив в памяти кучи.

## Подводные камни

Для экономии памяти используйте in-place разворот `slices.Reverse`.

## На собеседовании

**Вопрос с собеседования:** «Когда предпочесть иммутабельный Reverse, а когда in-place slices.Reverse?»
**Ответ:** Иммутабельный — при многопоточном доступе без мьютексов. In-place — в высоконагруженных циклах для исключения аллокаций памяти.
