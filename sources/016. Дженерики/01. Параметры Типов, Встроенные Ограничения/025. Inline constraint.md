# Inline constraint: объединение типов прямо в сигнатуре

## Условие

Напиши дженерик-функцию `Sum[T int | float64](slice []T) T`, которая суммирует числа. Используй inline constraint (объединение типов прямо в сигнатуре).

## Теория

Inline constraint позволяет объединять типы прямо в объявлении функции `[T int | float64]`.

## Решение по шагам

1. Объявим `Sum[T int | float64](slice []T) T`.
2. Сложим элементы в цикле.
3. В `main` проверим `[]int` и `[]float64`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Sum[T int | float64](slice []T) T {
	var total T
	for _, v := range slice {
		total += v
	}
	return total
}

func main() {
	intSum := Sum([]int{10, 20, 30})
	floatSum := Sum([]float64{1.5, 2.5, 3.5})

	fmt.Printf("Int Sum: %d\n", intSum)
	fmt.Printf("Float Sum: %.2f\n", floatSum)
}
```

ℹ️ Inline constraints

**`Терминал`**

```bash
go run main.go
# Вывод:
# Int Sum: 60
# Float Sum: 7.50
```

## Под капотом

Парсер преобразует `[T int | float64]` в анонимный интерфейс.

## Подводные камни

Inline constraint без `~` не примет `type MyInt int`.

## На собеседовании

**Вопрос с собеседования:** «Когда писать inline constraint?»
**Ответ:** Для простых однократных функций из 2-3 типов. Для переиспользуемых ограничений объявляют именованный интерфейс.
