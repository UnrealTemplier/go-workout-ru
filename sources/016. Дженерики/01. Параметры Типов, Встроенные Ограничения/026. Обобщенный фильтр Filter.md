# Обобщенный фильтр Filter: четные числа и длинные строки

## Условие

**Обобщенный фильтр (Filter)**: Напишите функцию `Filter[T any](slice []T, predicate func(T) bool) []T`. Функция должна возвращать новый срез, содержащий только элементы, для которых функция `predicate` вернула `true`. Протестируйте на срезе чисел (фильтрация четных) и срезе строк (фильтрация строк длиннее 5 символов).

## Теория

`Filter` возвращает строго типизированный срез элементов, прошедших предикат.

## Решение по шагам

1. Реализуем `Filter[T any](slice []T, predicate func(T) bool) []T`.
2. В `main` отфильтруем четные числа и строки длиннее 5 символов.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Filter[T any](slice []T, predicate func(T) bool) []T {
	res := make([]T, 0, len(slice))
	for _, item := range slice {
		if predicate(item) {
			res = append(res, item)
		}
	}
	return res
}

func main() {
	nums := []int{1, 2, 3, 4, 5, 6, 7, 8}
	evens := Filter(nums, func(n int) bool { return n%2 == 0 })
	fmt.Println("Четные числа:", evens)

	words := []string{"Go", "Kubernetes", "Docker", "Git"}
	longWords := Filter(words, func(w string) bool { return len(w) > 5 })
	fmt.Println("Длинные слова:", longWords)
}
```

ℹ️ Практический Filter

**`Терминал`**

```bash
go run main.go
# Вывод:
# Четные числа: [2 4 6 8]
# Длинные слова: [Kubernetes Docker]
```

## Под капотом

`make([]T, 0, len(slice))` предотвращает множественные реаллокации памяти.

## Подводные камни

Используйте `slices.Clip` для освобождения избыточной емкости, если отфильтровано мало элементов.

## На собеседовании

**Вопрос с собеседования:** «Что делает slices.Clip?»
**Ответ:** Уменьшает емкость среза до текущей длины (`cap = len`), позволяя освободить неиспользуемую память.
