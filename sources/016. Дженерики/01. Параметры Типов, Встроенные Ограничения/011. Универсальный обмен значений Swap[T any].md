# Универсальный обмен значений Swap[T any]

## Условие

Напиши `Swap[T any](a, b *T)`. Обменяй значения двух переменных любого типа (например, строк и чисел) одной функцией.

## Теория

`Swap[T any](a, b *T)` компилируется в прямой обмен значений по указателям через регистры CPU без рефлексии и аллокаций.

## Решение по шагам

1. Объявим `Swap[T any](a, b *T)`.
2. Выполним `*a, *b = *b, *a`.
3. В `main` обменяем числа, строки и структуры.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Swap[T any](a, b *T) {
	*a, *b = *b, *a
}

type Coords struct {
	Lat, Lon float64
}

func main() {
	x, y := 100, 200
	Swap(&x, &y)
	fmt.Printf("Числа после Swap: x=%d, y=%d\n", x, y)

	s1, s2 := "Alpha", "Omega"
	Swap(&s1, &s2)
	fmt.Printf("Строки после Swap: s1=%s, s2=%s\n", s1, s2)

	c1 := Coords{Lat: 55.75, Lon: 37.61}
	c2 := Coords{Lat: 59.93, Lon: 30.33}
	Swap(&c1, &c2)
	fmt.Printf("Структуры: c1=%v, c2=%v\n", c1, c2)
}
```

ℹ️ Универсальный Swap без рефлексии

**`Терминал`**

```bash
go run main.go
# Вывод:
# Числа после Swap: x=200, y=100
# Строки после Swap: s1=Omega, s2=Alpha
# Структуры: c1={59.93 30.33}, c2={55.75 37.61}
```

## Под капотом

Компилятор инлайнит `Swap`, превращая вызов в 2-3 инструкции `MOVQ` без создания стекового фрейма.

## Подводные камни

Передавайте указатели `&x, &y`, иначе будет ошибка компиляции.

## На собеседовании

**Вопрос с собеседования:** «Утекают ли переменные в кучу при вызове `Swap(&a, &b)`?»
**Ответ:** Нет, если функция инлайнится и указатели не сохраняются во внешние структуры, переменные остаются на стеке.
