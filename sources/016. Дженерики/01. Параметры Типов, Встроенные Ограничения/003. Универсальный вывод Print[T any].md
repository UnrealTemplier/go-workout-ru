# Универсальный вывод Print[T any]

## Условие

Напиши дженерик-функцию `Print[T any](val T)`, которая просто выводит значение через `fmt.Println`. Вызови её с числом, строкой и структурой.

## Теория

Ограничение `any` позволяет функции принимать аргумент произвольного типа, сохраняя при этом информацию о типе на этапе компиляции.

## Решение по шагам

1. Объявим структуру `User` с полями `Name string` и `Age int`.
2. Объявим функцию `Print[T any](val T)`.
3. Выведем значение и тип через `fmt.Printf`.
4. В `main` вызовем `Print` с числом, строкой и структурой `User`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type User struct {
	Name string
	Age  int
}

func Print[T any](val T) {
	fmt.Printf("Тип: %-15T | Значение: %v\n", val, val)
}

func main() {
	Print(42)
	Print("Hello, Go Generics!")
	Print(User{Name: "Алексей", Age: 29})
}
```

ℹ️ Параметризованная функция печати

**`Терминал`**

```bash
go run main.go
# Вывод:
# Тип: int             | Значение: 42
# Тип: string          | Значение: Hello, Go Generics!
# Тип: main.User       | Значение: {Алексей 29}
```

## Под капотом

Значение `val T` передается в функцию по регистрам/стеку без динамической упаковки до момента передачи в вариативный срез `fmt.Printf`.

## Подводные камни

Не путайте `[T any](v T)` и `(v any)`: в первом случае компилятор знает точный тип при возврате, во втором происходит стирание типа до динамического интерфейса.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие any от interface{} в Go 1.18+?»
**Ответ:** Никакого отличия в рантайме нет. `any` — это встроенный type alias для `interface{}` (`type any = interface{}`).
