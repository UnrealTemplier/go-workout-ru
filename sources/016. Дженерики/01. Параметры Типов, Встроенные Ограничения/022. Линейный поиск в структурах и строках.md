# Линейный поиск в структурах и строках

## Условие

Напиши `Contains[T comparable](slice []T, item T) bool`. Реализуй линейный поиск. Протестируй с `[]string` и `[]struct{ X, Y int }`.

## Теория

Структуры с comparable полями поддерживают оператор `==` автоматически.

## Решение по шагам

1. Объявим `type Point struct{ X, Y int }`.
2. Реализуем `Contains[T comparable](slice []T, item T) bool`.
3. Проверим поиск в `[]Point` и `[]string`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Point struct {
	X, Y int
}

func Contains[T comparable](slice []T, item T) bool {
	for _, v := range slice {
		if v == item {
			return true
		}
	}
	return false
}

func main() {
	tags := []string{"backend", "golang", "k8s"}
	fmt.Println("Contains 'golang':", Contains(tags, "golang"))

	points := []Point{
		{X: 0, Y: 0},
		{X: 10, Y: 20},
	}
	target := Point{X: 10, Y: 20}
	fmt.Println("Contains target Point:", Contains(points, target))
}
```

ℹ️ Поиск по структурам и строкам

**`Терминал`**

```bash
go run main.go
# Вывод:
# Contains 'golang': true
# Contains target Point: true
```

## Под капотом

Сравнение структуры размером 16 байт выполняется за 2 машинные инструкции.

## Подводные камни

Добавление поля `[]string` лишит структуру статуса `comparable`.

## На собеседовании

**Вопрос с собеседования:** «Как выравнивание полей структуры влияет на оператор ==?»
**Ответ:** При наличии байтов паддинга компилятор сравнивает поля структуры по отдельности, чтобы избежать ложных несовпадений из-за мусора в паддингах.
