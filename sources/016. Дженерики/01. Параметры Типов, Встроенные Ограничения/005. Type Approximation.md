# Type Approximation: оператор тильды ~ для пользовательских типов

## Условие

Напиши `Min[T constraints.Ordered]`. Протестируй с пользовательским типом `type Score int` — покажи, что работает благодаря **type approximation** в `constraints.Ordered`.

## Теория

Если тип объявлен как `type Score int`, его базовый тип (underlying type) равен `int`.

Символ тильды `~int` в интерфейсе-ограничении означает: разрешить использование `int` и любых пользовательских типов, у которых базовым типом является `int`.

## Решение по шагам

1. Объявим `type Score int` и `type Temperature float64`.
2. Объявим функцию `Min[T cmp.Ordered](a, b T) T`.
3. В `main` вызовем `Min` с переменными типа `Score` и `Temperature`.
4. Убедимся, что возвращаемое значение сохраняет свой точный тип `Score`.

## Код решения

**`main.go`**

```go
package main

import (
	"cmp"
	"fmt"
)

type Score int
type Temperature float64

func Min[T cmp.Ordered](a, b T) T {
	if a < b {
		return a
	}
	return b
}

func main() {
	s1, s2 := Score(85), Score(92)
	minScore := Min(s1, s2)
	fmt.Printf("Min Score: %d (тип: %T)\n", minScore, minScore)

	t1, t2 := Temperature(36.6), Temperature(38.2)
	minTemp := Min(t1, t2)
	fmt.Printf("Min Temp: %.1f (тип: %T)\n", minTemp, minTemp)
}
```

ℹ️ Type approximation для кастомных типов

**`Терминал`**

```bash
go run main.go
# Вывод:
# Min Score: 85 (тип: main.Score)
# Min Temp: 36.6 (тип: main.Temperature)
```

## Под капотом

Компилятор проверяет `Score.Underlying() == types.Basic(int)`, подтверждая соответствие `~int`.

## Подводные камни

Тильду `~` можно применять только к базовым типам. Нельзя писать `~Score` или `~MyInterface`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие type definition от type alias в контексте дженериков?»
**Ответ:** `type ID = int` (alias) идентичен `int` и не требует `~`. `type ID int` (definition) создает новый именованный тип, требующий `~int` в constraint.
