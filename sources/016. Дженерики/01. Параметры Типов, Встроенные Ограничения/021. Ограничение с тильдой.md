# Ограничение с тильдой: интерфейс Number и функция Sum

## Условие

Ограничение с тильдой: интерфейс `Number` (`~int | ~float64`). Функция `Sum[T Number](nums []T) T`, вычисляющая сумму.

## Теория

Объединение типов с тильдой `~int | ~float64` разрешает базовые и производные типы.

## Решение по шагам

1. Объявим `type Number interface { ~int | ~float64 }`.
2. Объявим `type Meters int` и `type Weight float64`.
3. Реализуем `Sum[T Number](nums []T) T`.
4. В `main` просуммируем `[]Meters` и `[]Weight`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Number interface {
	~int | ~float64
}

type Meters int
type Weight float64

func Sum[T Number](nums []T) T {
	var total T
	for _, n := range nums {
		total += n
	}
	return total
}

func main() {
	ints := []int{1, 2, 3, 4, 5}
	fmt.Printf("Sum ints: %d (%T)\n", Sum(ints), Sum(ints))

	meters := []Meters{10, 20, 30}
	fmt.Printf("Sum meters: %d (%T)\n", Sum(meters), Sum(meters))

	weights := []Weight{75.5, 82.3}
	fmt.Printf("Sum weights: %.1f (%T)\n", Sum(weights), Sum(weights))
}
```

ℹ️ Суммирование с type approximation

**`Терминал`**

```bash
go run main.go
# Вывод:
# Sum ints: 15 (int)
# Sum meters: 60 (main.Meters)
# Sum weights: 157.8 (main.Weight)
```

## Под капотом

Компилятор создает специализированные версии функций под аппаратные регистры `RAX` и `XMM0`.

## Подводные камни

В `Number` нельзя использовать операторы, отсутствующие у одного из типов (например `%` для float64).

## На собеседовании

**Вопрос с собеседования:** «Можно ли объявить переменную var x Number = 5?»
**Ответ:** Нет. Интерфейсы с Type Elements могут использоваться исключительно как generic constraints, но не как динамические типы переменных.
