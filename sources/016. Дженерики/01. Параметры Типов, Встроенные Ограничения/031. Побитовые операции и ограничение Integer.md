# Побитовые операции и ограничение Integer

## Условие

Создай constraint `Integer` с `~int | ~int8 | ... | ~uint64` (без float). Используй для generic-функции битовых операций: `BitwiseAnd[T Integer](a, b T) T`.

## Теория

Побитовые операции определены только для целочисленных типов языка Go.

## Решение по шагам

1. Объявим `Integer interface { ~int | ... | ~uint64 }`.
2. Напишем `BitwiseAnd` и `BitwiseOr`.
3. В `main` проверим битовые флаги прав доступа.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Integer interface {
	~int | ~int8 | ~int16 | ~int32 | ~int64 |
		~uint | ~uint8 | ~uint16 | ~uint32 | ~uint64 | ~uintptr
}

func BitwiseAnd[T Integer](a, b T) T { return a & b }
func BitwiseOr[T Integer](a, b T) T  { return a | b }

const (
	ReadPermission  = 1 << 0
	WritePermission = 1 << 1
	ExecPermission  = 1 << 2
)

func main() {
	perms := BitwiseOr(ReadPermission, WritePermission)
	fmt.Printf("Права: %03b\n", perms)

	fmt.Println("Чтение:", BitwiseAnd(perms, ReadPermission) != 0)
	fmt.Println("Выполнение:", BitwiseAnd(perms, ExecPermission) != 0)
}
```

ℹ️ Побитовые операции с ограничением Integer

**`Терминал`**

```bash
go run main.go
# Вывод:
# Права: 011
# Чтение: true
# Выполнение: false
```

## Под капотом

Компилируется в ассемблерную инструкцию `ANDQ` процессора.

## Подводные камни

Правый операнд сдвигов обязан быть `uint` или нетипизированной константой.

## На собеседовании

**Вопрос с собеседования:** «Что делает оператор &^ в Go?»
**Ответ:** `x &^ y` (AND NOT) очищает биты: сбрасывает в `0` те биты `x`, которые установлены в `1` в `y`.
