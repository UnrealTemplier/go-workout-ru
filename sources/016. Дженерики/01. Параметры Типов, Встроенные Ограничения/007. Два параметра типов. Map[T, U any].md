# Два параметра типов: Map[T, U any]

## Условие

Напиши `Map[T, U any](s []T, fn func(T) U) []U`. Преобразуй `[]int` в `[]string` (числа → строки). Покажи работу с **двумя type parameters**.

## Теория

Функции могут принимать несколько независимых параметров типов `[T, U any]`, позволяя безопасно преобразовывать коллекции сущностей.

## Решение по шагам

1. Объявим `Map[T, U any](s []T, fn func(T) U) []U`.
2. Выделим слайс `res := make([]U, len(s))`.
3. Заполним элементы `res[i] = fn(v)`.
4. В `main` преобразуем `[]int` в `[]string` и `[]string` в `[]int` (длины).

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strconv"
)

func Map[T, U any](s []T, fn func(T) U) []U {
	result := make([]U, len(s))
	for i, v := range s {
		result[i] = fn(v)
	}
	return result
}

func main() {
	numbers := []int{10, 25, 42, 100}

	strings := Map(numbers, func(n int) string {
		return "ID-" + strconv.Itoa(n)
	})
	fmt.Printf("Числа в строки: %v (%T)\n", strings, strings)

	words := []string{"Go", "Generics", "Backend"}
	lengths := Map(words, func(w string) int {
		return len(w)
	})
	fmt.Printf("Длины слов: %v (%T)\n", lengths, lengths)
}
```

ℹ️ Трансформация типов через Map

**`Терминал`**

```bash
go run main.go
# Вывод:
# Числа в строки: [ID-10 ID-25 ID-42 ID-100] ([]string)
# Длины слов: [2 8 7] ([]int)
```

## Под капотом

Компилятор автоматически выводит `T = int` из слайса и `U = string` из сигнатуры переданной лямбды.

## Подводные камни

Всегда используйте `make([]U, len(s))` вместо `append`, так как длина результирующего слайса известна заранее.

## На собеседовании

**Вопрос с собеседования:** «Как работает Unification Algorithm при выводе нескольких параметров типа?»
**Ответ:** Компилятор сопоставляет типы аргументов с сигнатурой функции и решает систему типовых равенств. Если тип `T` выведен как `int`, а замыкание `func(int) string` возвращает `string`, то `U` однозначно разрешается в `string`.
