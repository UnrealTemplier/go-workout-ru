# Метод IsEmpty для обобщенной структуры Stack[T]

## Условие

Напиши метод для дженерик-структуры: добавь метод `IsEmpty()` для `Stack[T]`.

## Теория

Методы структур объявляются с параметром типа в ресивере `(s *Stack[T])`.

## Решение по шагам

1. Объявим `Stack[T any]`.
2. Реализуем `(s *Stack[T]) IsEmpty() bool`.
3. Проверим в `main`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Stack[T any] struct {
	items []T
}

func (s *Stack[T]) Push(v T) {
	s.items = append(s.items, v)
}

func (s *Stack[T]) IsEmpty() bool {
	return len(s.items) == 0
}

func main() {
	s := &Stack[int]{}
	fmt.Println("Пуст:", s.IsEmpty())
	s.Push(10)
	fmt.Println("Пуст после Push:", s.IsEmpty())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Пуст: true
# Пуст после Push: false
```

## Под капотом

Параметр `T` передается в скрытый дескриптор метода структуры.

## Подводные камни

Обязательно указывайте `[T]` в ресивере: `(s *Stack[T])`.

## На собеседовании

**Вопрос с собеседования:** «Почему в ресивере метода обязательно указывать [T]?»
**Ответ:** Потому что `Stack` без параметров — это обобщенный шаблон типа, а `Stack[T]` — конкретный инстанцированный тип.
