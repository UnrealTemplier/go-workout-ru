# Извлечение ключей мапы: Keys[K comparable, V any]

## Условие

Создай constraint `MapKey` как `comparable`. Напиши `Keys[K MapKey, V any](m map[K]V) []K`, извлекающий все ключи мапы в слайс.

## Теория

Извлечение всех ключей мапы — частая задача. Сигнатура `Keys[K comparable, V any](m map[K]V) []K` принимает мапу с любым сравнимым ключом и любым значением.

## Решение по шагам

1. Объявим `type MapKey comparable`.
2. Напишем `Keys[K MapKey, V any](m map[K]V) []K`.
3. Выделим память `make([]K, 0, len(m))`.
4. В `main` извлечем ключи из `map[string]int` и `map[int]string`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type MapKey comparable

func Keys[K MapKey, V any](m map[K]V) []K {
	keys := make([]K, 0, len(m))
	for k := range m {
		keys = append(keys, k)
	}
	return keys
}

func main() {
	userAges := map[string]int{
		"Alice": 28,
		"Bob":   34,
		"Carol": 22,
	}
	fmt.Printf("Ключи userAges: %v\n", Keys(userAges))

	errorCodes := map[int]string{
		400: "Bad Request",
		404: "Not Found",
	}
	fmt.Printf("Ключи errorCodes: %v\n", Keys(errorCodes))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Ключи userAges: [Alice Bob Carol]
# Ключи errorCodes: [400 404]
```

## Под капотом

Итератор мапы начинает обход со случайного смещения в массиве бакетов `hmap`.

## Подводные камни

Порядок элементов в возвращенном слайсе не гарантирован и меняется между запусками программы.

## На собеседовании

**Вопрос с собеседования:** «Почему итерация по map в Go рандомизирована?»
**Ответ:** Чтобы исключить зависимость логики приложения от внутреннего порядка бакетов хэш-таблицы.
