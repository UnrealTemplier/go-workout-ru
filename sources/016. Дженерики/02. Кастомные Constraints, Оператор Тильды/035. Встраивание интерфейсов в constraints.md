# Встраивание интерфейсов в constraints: OrderedStringer

## Условие

Создай constraint через embedding:
```go
type OrderedStringer interface {
    cmp.Ordered
    fmt.Stringer
}
```
Напиши `PrintSorted[T OrderedStringer](items []T)`, которая сортирует (используя `<`) и выводит через `String()`.

### Исходная формулировка

Создай constraint через embedding:
```go
type OrderedStringer interface {
    constraints.Ordered
    fmt.Stringer
}
```
Напиши `PrintSorted[T OrderedStringer](items []T)`, которая сортирует (используя `<`) и выводит через `String()`.

## Теория

Интерфейс-ограничение может объединять требования к типам (`cmp.Ordered`) и набору методов (`fmt.Stringer`) через Embedding. Тип `T` обязан быть упорядоченным числом/строкой И иметь метод `String() string`.

## Решение по шагам

1. Объявим `type OrderedStringer interface { cmp.Ordered; fmt.Stringer }`.
2. Создадим `type Priority int` с методом `String() string`.
3. Напишем `PrintSorted[T OrderedStringer](items []T)`.
4. В `main` протестируем со срезом `[]Priority`.

## Код решения

**`main.go`**

```go
package main

import (
	"cmp"
	"fmt"
	"slices"
)

type OrderedStringer interface {
	cmp.Ordered
	fmt.Stringer
}

type Priority int

func (p Priority) String() string {
	switch p {
	case 1:
		return "HIGH (1)"
	case 2:
		return "MEDIUM (2)"
	case 3:
		return "LOW (3)"
	default:
		return fmt.Sprintf("UNKNOWN (%d)", p)
	}
}

func PrintSorted[T OrderedStringer](items []T) {
	sorted := slices.Clone(items)
	slices.SortFunc(sorted, func(a, b T) int {
		return cmp.Compare(a, b)
	})
	for _, item := range sorted {
		fmt.Printf("-> %s\n", item.String())
	}
}

func main() {
	tasks := []Priority{3, 1, 2, 1, 3}
	PrintSorted(tasks)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# -> HIGH (1)
# -> HIGH (1)
# -> MEDIUM (2)
# -> LOW (3)
# -> LOW (3)
```

## Под капотом

Компилятор выполняет прямой статический вызов метода `item.String()` без поиска по таблице `itab`.

## Подводные камни

Базовый тип `int` не имеет метода `String()`, поэтому `PrintSorted([]int{1, 2})` вызовет ошибку компиляции.

## На собеседовании

**Вопрос с собеседования:** «Вызываются ли методы в дженериках через динамическую таблицу интерфейсов (itab)?»
**Ответ:** Нет, компилятор выполняет прямой статический вызов функции (direct call), что исключает накладные расходы на виртуальную диспетчеризацию.
