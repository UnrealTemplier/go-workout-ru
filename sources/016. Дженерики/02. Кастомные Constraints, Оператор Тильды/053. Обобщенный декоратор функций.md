# Обобщенный декоратор функций: WrapWithLogging[T any]

## Условие

Обобщённый метод структуры: `Service.WrapWithLogging[T any](fn func() T) func() T`, логирующая до и после вызова.

## Теория

Generic-декоратор оборачивает функцию логированием, сохраняя строгий тип возвращаемого значения.

## Решение по шагам

1. Объявим `WrapWithLogging[T any](name string, fn func() T) func() T`.
2. Замерим время выполнения `time.Since(start)`.
3. В `main` обернем функции.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func WrapWithLogging[T any](name string, fn func() T) func() T {
	return func() T {
		fmt.Printf("[%s] Старт...\n", name)
		start := time.Now()
		result := fn()
		fmt.Printf("[%s] Финиш за %v. Результат: %v\n", name, time.Since(start), result)
		return result
	}
}

func main() {
	compute := func() int { return 100 + 200 }
	logged := WrapWithLogging("Compute", compute)
	res := logged()
	fmt.Println("Итог:", res)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Compute] Старт...
# [Compute] Финиш за ... Результат: 300
# Итог: 300
```

## Под капотом

Замыкание генерирует специализированный входной фрейм под тип `T`.

## Подводные камни

Для функций с ошибками используйте пару `(T, error)`.
