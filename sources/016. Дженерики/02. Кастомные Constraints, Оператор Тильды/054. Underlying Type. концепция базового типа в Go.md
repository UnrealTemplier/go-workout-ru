# Underlying Type: концепция базового типа в Go

## Условие

Создай `type MyFloat float64`. Покажи, что constraint с `~float64` принимает `MyFloat`, а без `~` — только строго `float64`. Объясни **underlying type** concept.

## Теория

`type MyFloat float64` имеет базовый тип `float64`. Тильда `~float64` разрешает любые производные типы.

## Решение по шагам

1. Объявим `type MyFloat float64`.
2. Напишем `Abs[T ~float64](v T) T`.
3. В `main` протестируем с `float64` и `MyFloat`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type MyFloat float64

func Abs[T ~float64](v T) T {
	if v < 0 {
		return -v
	}
	return v
}

func main() {
	var f float64 = -3.14
	var mf MyFloat = -99.9

	fmt.Printf("Abs(float64): %.2f (%T)\n", Abs(f), Abs(f))
	fmt.Printf("Abs(MyFloat): %.2f (%T)\n", Abs(mf), Abs(mf))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Abs(float64): 3.14 (float64)
# Abs(MyFloat): 99.90 (main.MyFloat)
```

## Под капотом

Оператор унарного минуса `-v` разрешен, так как он поддерживается базовым типом `float64`.

## Подводные камни

`~float64` не принимает `float32`, так как это разные базовые типы.

## На собеседовании

**Вопрос с собеседования:** «Каков underlying type у цепочки type A int; type B A; type C B?»
**Ответ:** Underlying type для всех трех типов — примитивный `int`.
