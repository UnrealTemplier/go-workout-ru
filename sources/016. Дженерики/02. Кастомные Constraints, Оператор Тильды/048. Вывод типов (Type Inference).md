# Вывод типов (Type Inference): явное vs неявное инстанцирование

## Условие

**Вывод типов (Type Inference)**: Вызови функцию `Sum` из упр. 240 двумя способами: с явным указанием типа `Sum[float64](1.5, 2.5)` и без него `Sum(1.5, 2.5)` — позволь компилятору самому догадаться.

## Теория

Type Inference выводит параметры типов из типов аргументов вызова функции во время компиляции.

## Решение по шагам

1. Объявим `Sum[T ~float64 | ~int](a, b T) T { return a + b }`.
2. Вызовем с явным `[float64]` и с неявным выводом.
3. Сравним в `main`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Sum[T ~float64 | ~int](a, b T) T {
	return a + b
}

func main() {
	res1 := Sum[float64](1.5, 2.5)
	fmt.Printf("Явный вызов: %.2f (%T)\n", res1, res1)

	res2 := Sum(1.5, 2.5)
	fmt.Printf("Авто вывод:  %.2f (%T)\n", res2, res2)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Явный вызов: 4.00 (float64)
# Авто вывод:  4.00 (float64)
```

## Под капотом

Оба варианта компилируются в идентичный машинный код.

## Подводные камни

Если аргументы имеют разные типы (`Sum(1, 2.5)`), автовывод вызовет ошибку `mismatched types`.

## На собеседовании

**Вопрос с собеседования:** «Когда явное инстанцирование [T] строго обязательно?»
**Ответ:** Когда параметр типа `T` используется только как возвращаемое значение (например `func New[T any]() *T`).
