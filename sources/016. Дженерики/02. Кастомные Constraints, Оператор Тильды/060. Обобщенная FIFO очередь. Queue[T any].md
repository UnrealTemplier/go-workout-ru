# Обобщенная FIFO очередь: Queue[T any]

## Условие

Реализуй `Queue[T any]` на слайсе (или через кольцевой буфер) с методами `Enqueue(v T)`, `Dequeue() (T, bool)`, `Len() int`.

## Теория

Очередь работает по принципу FIFO. Зануление первого элемента перед срезкой защищает от утечек памяти.

## Решение по шагам

1. Объявим `type Queue[T any] struct { items []T }`.
2. Реализуем `Enqueue` и `Dequeue`.
3. В `main` проверим обработку элементов.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Queue[T any] struct {
	items []T
}

func (q *Queue[T]) Enqueue(v T) {
	q.items = append(q.items, v)
}

func (q *Queue[T]) Dequeue() (T, bool) {
	if len(q.items) == 0 {
		var zero T
		return zero, false
	}
	val := q.items[0]
	var zero T
	q.items[0] = zero
	q.items = q.items[1:]
	return val, true
}

func (q *Queue[T]) Len() int {
	return len(q.items)
}

func main() {
	q := &Queue[string]{}
	q.Enqueue("Msg 1")
	q.Enqueue("Msg 2")

	for q.Len() > 0 {
		msg, _ := q.Dequeue()
		fmt.Println("Обработано:", msg)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Обработано: Msg 1
# Обработано: Msg 2
```

## Под капотом

Зануление `q.items[0] = zero` позволяет GC освободить объект из памяти.

## Подводные камни

Постоянная срезка `q.items[1:]` оставляет неиспользуемое начало базового массива. Для тяжелых очередей применяйте кольцевой буфер.

## На собеседовании

**Вопрос с собеседования:** «Как сделать очередь с \(O(1)\) Dequeue без утечек памяти?»
**Ответ:** Использовать Ring Buffer фиксированного размера или очередь на двух стеках (`in` и `out`).
