# Поиск максимума по критерию: MaxBy[T, U]

## Условие

Реализуйте функцию `MaxBy[T any, U cmp.Ordered](s []T, f func(T) U) T`, которая находит элемент в слайсе, имеющий максимальное значение по заданному критерию (например, найти `User` с максимальным `Age`).

## Теория

`MaxBy` находит элемент за один проход (\(O(N)\)), извлекая ключ сортировки через функцию `f(item)`.

## Решение по шагам

1. Объявим `MaxBy[T any, U cmp.Ordered](s []T, f func(T) U) T`.
2. В цикле сравним ключи `f(v) > maxKey`.
3. В `main` найдем пользователя с наибольшим возрастом.

## Код решения

**`main.go`**

```go
package main

import (
	"cmp"
	"fmt"
)

type User struct {
	Name string
	Age  int
}

func MaxBy[T any, U cmp.Ordered](s []T, f func(T) U) T {
	if len(s) == 0 {
		var zero T
		return zero
	}
	best := s[0]
	maxKey := f(s[0])
	for _, v := range s[1:] {
		key := f(v)
		if key > maxKey {
			maxKey = key
			best = v
		}
	}
	return best
}

func main() {
	users := []User{
		{Name: "Иван", Age: 25},
		{Name: "Елена", Age: 34},
		{Name: "Дмитрий", Age: 29},
	}
	oldest := MaxBy(users, func(u User) int { return u.Age })
	fmt.Printf("Самый старший: %s (%d лет)\n", oldest.Name, oldest.Age)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Самый старший: Елена (34 лет)
```

## Под капотом

Сравнение мономорфизируется под тип `int` без аллокаций в куче.

## Подводные камни

Сохраняйте значение `key := f(v)` в локальную переменную, чтобы не вычислять его дважды.
