# Связный список LinkedList[T] с Add и PrintAll

## Условие

Реализуйте параметризованный связный список `LinkedList[T any]` с методами `Add(T)` и `PrintAll()`.

## Теория

Связный список хранит элементы последовательно через указатели `Next`.

## Решение по шагам

1. Объявим `LinkedList[T any] struct { head, tail *Node[T] }`.
2. Реализуем `Add` и `PrintAll`.
3. В `main` проверим вывод.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Node[T any] struct {
	Val  T
	Next *Node[T]
}

type LinkedList[T any] struct {
	head, tail *Node[T]
}

func (l *LinkedList[T]) Add(v T) {
	newNode := &Node[T]{Val: v}
	if l.head == nil {
		l.head = newNode
		l.tail = newNode
		return
	}
	l.tail.Next = newNode
	l.tail = newNode
}

func (l *LinkedList[T]) PrintAll() {
	curr := l.head
	for curr != nil {
		fmt.Printf("[%v] -> ", curr.Val)
		curr = curr.Next
	}
	fmt.Println("nil")
}

func main() {
	list := &LinkedList[int]{}
	list.Add(10)
	list.Add(20)
	list.Add(30)
	list.PrintAll()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [10] -> [20] -> [30] -> nil
```

## Под капотом

Указатель `tail` позволяет добавлять элементы в конец за \(O(1)\).

## Подводные камни

Обновляйте `tail` при вставке первого элемента в пустой список.

## На собеседовании

**Вопрос с собеседования:** «Какова сложность поиска в связном списке?»
**Ответ:** Время \(O(N)\), память \(O(1)\).
