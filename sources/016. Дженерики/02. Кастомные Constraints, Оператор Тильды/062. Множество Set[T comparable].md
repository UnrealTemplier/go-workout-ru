# Множество Set[T comparable]: Union, Intersection, ToSlice

## Условие

Реализуй `Set[T comparable]` на мапе с методами `Add(v T)`, `Remove(v T)`, `Contains(v T) bool`, `Union(other Set[T]) Set[T]`, `Intersection(other Set[T]) Set[T]`, `Len() int`, `ToSlice() []T`.

## Теория

Множество на `map[T]struct{}` обеспечивает математические операции объединения и пересечения.

## Решение по шагам

1. Реализуем `Set[T comparable]`.
2. Реализуем `Union` и `Intersection`.
3. В `main` проверим операции над множествами.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Set[T comparable] struct {
	data map[T]struct{}
}

func NewSet[T comparable](items ...T) *Set[T] {
	s := &Set[T]{data: make(map[T]struct{})}
	for _, item := range items {
		s.Add(item)
	}
	return s
}

func (s *Set[T]) Add(v T)           { s.data[v] = struct{}{} }
func (s *Set[T]) Contains(v T) bool { _, ok := s.data[v]; return ok }

func (s *Set[T]) Union(other *Set[T]) *Set[T] {
	res := NewSet[T]()
	for k := range s.data {
		res.Add(k)
	}
	for k := range other.data {
		res.Add(k)
	}
	return res
}

func (s *Set[T]) Intersection(other *Set[T]) *Set[T] {
	res := NewSet[T]()
	for k := range s.data {
		if other.Contains(k) {
			res.Add(k)
		}
	}
	return res
}

func (s *Set[T]) ToSlice() []T {
	res := make([]T, 0, len(s.data))
	for k := range s.data {
		res = append(res, k)
	}
	return res
}

func main() {
	s1 := NewSet(1, 2, 3)
	s2 := NewSet(2, 3, 4)

	fmt.Println("Union:       ", s1.Union(s2).ToSlice())
	fmt.Println("Intersection:", s1.Intersection(s2).ToSlice())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Union:        [1 2 3 4]
# Intersection: [2 3]
```

## Под капотом

`struct{}` занимает 0 байт памяти в значениях мапы.

## Подводные камни

Порядок в `ToSlice()` случайный из-за рандомизации мапы.

## На собеседовании

**Вопрос с собеседования:** «Как оптимизировать Intersection двух больших множеств?»
**Ответ:** Итерироваться по меньшему множеству, проверяя наличие в большем.
