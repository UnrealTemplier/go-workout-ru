# Обобщенная пара Pair[T, U] с методами Swap и Equal

## Условие

Реализуй `Pair[T, U any]` с полями `First T`, `Second U`. Методы: `Swap() Pair[U, T]`, `String() string`, `Equal(other Pair[T, U]) bool` (требует `T, U comparable` — добавь это ограничение на метод или сделай отдельный метод).

## Теория

`Pair[T, U]` хранит пару разнотипных значений. Сравнение пар `EqualPairs` требует ограничения `comparable` на оба типа.

## Решение по шагам

1. Объявим `Pair[T, U any] struct { First T; Second U }`.
2. Реализуем `Swap() Pair[U, T]` и `String() string`.
3. Напишем `EqualPairs[T, U comparable](p1, p2 Pair[T, U]) bool`.
4. В `main` протестируем пару.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Pair[T, U any] struct {
	First  T
	Second U
}

func (p Pair[T, U]) Swap() Pair[U, T] {
	return Pair[U, T]{First: p.Second, Second: p.First}
}

func (p Pair[T, U]) String() string {
	return fmt.Sprintf("Pair(%v, %v)", p.First, p.Second)
}

func EqualPairs[T, U comparable](p1, p2 Pair[T, U]) bool {
	return p1.First == p2.First && p1.Second == p2.Second
}

func main() {
	p1 := Pair[string, int]{First: "UserCount", Second: 42}
	fmt.Println("Оригинал:", p1)
	fmt.Println("Swap:    ", p1.Swap())

	p2 := Pair[string, int]{First: "UserCount", Second: 42}
	fmt.Println("p1 == p2:", EqualPairs(p1, p2))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Оригинал: Pair(UserCount, 42)
# Swap:     Pair(42, UserCount)
# p1 == p2: true
```

## Под капотом

`Pair[string, int]` и `Pair[int, string]` — разные типы с разной раскладкой полей.

## Подводные камни

Поскольку generic-методы на структурах запрещены, сравнение вынесено в отдельную функцию `EqualPairs`.

## На собеседовании

**Вопрос с собеседования:** «Почему нельзя добавить метод Equal на структуру Pair[T, U any]?»
**Ответ:** Потому что `any` не гарантирует наличие оператора `==`. Для метода `Equal` ограничение `comparable` должно быть наложено на саму структуру.
