# Анализ ошибок несоответствия ограничений компилятора

## Условие

Попробуйте передать в дженерик-функцию структуру, которая не удовлетворяет constraint (например, слайс в `Contains`). Изучите понятную ошибку компилятора.

## Теория

При нарушении ограничений компилятор Go генерирует подробные сообщения об ошибках с указанием точной причины (несравнимость, отсутствие метода).

## Решение по шагам

1. Объявим `Contains[T comparable](s []T, v T) bool`.
2. В `main` покажем успешный вызов с `[]int`.
3. В комментариях зафиксируем ошибку для среза срезов `[][]int`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Contains[T comparable](s []T, v T) bool {
	for _, item := range s {
		if item == v {
			return true
		}
	}
	return false
}

func main() {
	fmt.Println("Contains int:", Contains([]int{1, 2, 3}, 2))

	// matrix := [][]int{{1, 2}, {3, 4}}
	// Contains(matrix, []int{1, 2})
	// Ошибка: []int does not satisfy comparable
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Contains int: true
```

## Под капотом

Проверка ограничений происходит на этапе статического анализа дерева типов `types2`.

## Подводные камни

Для несравнимых типов используйте предикат `ContainsFunc`.

## На собеседовании

**Вопрос с собеседования:** «Как найти элемент в слайсе несравнимых структур?»
**Ответ:** Использовать предикат `ContainsFunc[T any](s []T, eq func(T) bool)`.
