# Полнофункциональный Stack[T] с Peek и IsEmpty

## Условие

Реализуй `Stack[T any]` на слайсе с методами `Push(v T)`, `Pop() (T, bool)`, `Peek() (T, bool)`, `IsEmpty() bool`.

## Теория

`Peek` просматривает верхний элемент без извлечения. Сигнатура `(T, bool)` сигнализирует об успехе.

## Решение по шагам

1. Объявим `Stack[T any] struct { items []T }`.
2. Реализуем `Push`, `Pop`, `Peek`, `IsEmpty`.
3. Проверим в `main`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Stack[T any] struct {
	items []T
}

func (s *Stack[T]) Push(v T) {
	s.items = append(s.items, v)
}

func (s *Stack[T]) Pop() (T, bool) {
	if len(s.items) == 0 {
		var zero T
		return zero, false
	}
	lastIdx := len(s.items) - 1
	val := s.items[lastIdx]
	s.items = s.items[:lastIdx]
	return val, true
}

func (s *Stack[T]) Peek() (T, bool) {
	if len(s.items) == 0 {
		var zero T
		return zero, false
	}
	return s.items[len(s.items)-1], true
}

func (s *Stack[T]) IsEmpty() bool {
	return len(s.items) == 0
}

func main() {
	s := &Stack[string]{}
	s.Push("first")
	s.Push("second")

	top, _ := s.Peek()
	fmt.Println("Peek top:", top)

	for !s.IsEmpty() {
		v, _ := s.Pop()
		fmt.Println("Pop:", v)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Peek top: second
# Pop: second
# Pop: first
```

## Под капотом

`Peek` возвращает значение по индексу без аллокаций памяти.

## Подводные камни

Для потокобезопасности используйте `sync.Mutex`.

## На собеседовании

**Вопрос с собеседования:** «Какова амортизированная сложность Push в стек на слайсе?»
**Ответ:** \(O(1)\) амортизированная, так как базовый массив удваивается при заполнении.
