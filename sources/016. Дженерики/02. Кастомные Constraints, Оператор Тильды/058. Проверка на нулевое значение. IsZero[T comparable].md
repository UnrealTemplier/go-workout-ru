# Проверка на нулевое значение: IsZero[T comparable]

## Условие

`IsZero[T comparable](v T) bool` — проверка на нулевое значение (сравнение с `*new(T)`).

## Теория

Сравнение `var zero T; return v == zero` проверяет, равно ли значение своему дефолтному состоянию.

## Решение по шагам

1. Объявим `IsZero[T comparable](v T) bool`.
2. В `main` проверим числа, строки и структуры.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func IsZero[T comparable](v T) bool {
	var zero T
	return v == zero
}

type Point struct {
	X, Y int
}

func main() {
	fmt.Println("IsZero(0):", IsZero(0))
	fmt.Println("IsZero(42):", IsZero(42))
	fmt.Println("IsZero(\"\"):", IsZero(""))
	fmt.Println("IsZero(Point{0, 0}):", IsZero(Point{0, 0}))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# IsZero(0): true
# IsZero(42): false
# IsZero(""): true
# IsZero(Point{0, 0}): true
```

## Под капотом

Компилятор выполняет прямое побитовое сравнение со статической zero-памятью.

## Подводные камни

Слайсы не поддерживают `==`, для них проверяйте `len(s) == 0`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие IsZero от reflect.ValueOf(v).IsZero()?»
**Ответ:** Дженерик выполняется статически за \(O(1)\) без аллокаций, а рефлексия выполняет динамический анализ в рантайме.
