# Ограничение Numeric и умножение чисел

## Условие

**Кастомные интерфейсы-ограничения**: Объявите интерфейс-ограничение `Numeric`:
```go
type Numeric interface {
    ~int | ~int64 | ~float64
}
```
Напишите функцию `Multiply[T Numeric](a, b T) T`. Объясните в комментариях роль знака тильды `~` (поддержка производных кастомных типов, например `type MyInt int`).

## Теория

`Numeric` ограничивает допустимые типы тремя базовыми. Тильда `~` разрешает пользовательские типы вроде `type Price int64`.

## Решение по шагам

1. Объявим `type Numeric interface { ~int | ~int64 | ~float64 }`.
2. Создадим `type Price int64`.
3. Реализуем `Multiply[T Numeric](a, b T) T { return a * b }`.
4. В `main` перемножим `Price`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Numeric interface {
	~int | ~int64 | ~float64
}

type Price int64

func Multiply[T Numeric](a, b T) T {
	return a * b
}

func main() {
	var unitPrice Price = 1500
	var count Price = 3
	total := Multiply(unitPrice, count)
	fmt.Printf("Итоговая цена: %d (тип %T)\n", total, total)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Итоговая цена: 4500 (тип main.Price)
```

## Под капотом

Компилятор подставляет инструкцию `IMUL` для целых чисел и `MULSD` для чисел с плавающей точкой.

## Подводные камни

Аргументы должны быть строго одинакового типа `(a, b T)`.

## На собеседовании

**Вопрос с собеседования:** «Почему типы Rubles и Dollars нельзя случайно перемножить в Multiply?»
**Ответ:** Так как сигнатура требует одинаковый тип `T`, компилятор блокирует вызов `Multiply(rubles, dollars)` на этапе сборки.
