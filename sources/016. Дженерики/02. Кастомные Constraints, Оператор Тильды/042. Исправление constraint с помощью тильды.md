# Исправление constraint с помощью тильды ~

## Условие

**Символ тильды (`~`)**: Создай свой тип `type MyInt int`. Попробуй передать переменную этого типа в функцию `Sum` из упр. 240. Получишь ошибку. Исправь интерфейс `Number`, добавив `~` (`~int | ...`), чтобы разрешить использование любых типов, базовым для которых является `int`.

## Теория

Добавление тильды `~int` позволяет функции принимать производные типы `type MyInt int`.

## Решение по шагам

1. Объявим `type Number interface { ~int | ~float64 }`.
2. Создадим `type MyInt int`.
3. Реализуем `Sum2[T Number](a, b T) T`.
4. В `main` сложим переменные `MyInt`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Number interface {
	~int | ~float64
}

type MyInt int

func Sum2[T Number](a, b T) T {
	return a + b
}

func main() {
	var a MyInt = 15
	var b MyInt = 25
	fmt.Printf("Результат Sum2: %d (тип %T)\n", Sum2(a, b), Sum2(a, b))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Результат Sum2: 40 (тип main.MyInt)
```

## Под капотом

Вызов мономорфизируется в функцию, возвращающую строгий тип `MyInt`.

## Подводные камни

`~int` не совместим с `int64`, так как это разные базовые типы.

## На собеседовании

**Вопрос с собеседования:** «Каков underlying type у type Alias = int и type NewType int?»
**Ответ:** У `Alias` базовый тип буквально `int`. У `NewType` создается новый именованный тип с базовым типом `int`.
