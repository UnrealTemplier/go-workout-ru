# Дженерик-тип мапы: GenericMap[K, V]

## Условие

Создай дженерик-мапу: `type GenericMap[K comparable, V any] map[K]V`. Напиши функцию `GetKeys[K comparable, V any](m GenericMap[K, V]) []K`, которая возвращает все ключи.

## Теория

Go позволяет объявлять именованные типы поверх мап с параметрами типов: `type GenericMap[K comparable, V any] map[K]V` и навешивать на них методы.

## Решение по шагам

1. Объявим `type GenericMap[K comparable, V any] map[K]V`.
2. Реализуем метод `(m GenericMap[K, V]) Keys() []K`.
3. В `main` протестируем работу метода.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type GenericMap[K comparable, V any] map[K]V

func (m GenericMap[K, V]) Keys() []K {
	keys := make([]K, 0, len(m))
	for k := range m {
		keys = append(keys, k)
	}
	return keys
}

func main() {
	cache := GenericMap[string, int]{
		"cpu": 45,
		"ram": 78,
	}
	fmt.Println("Ключи cache:", cache.Keys())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Ключи cache: [cpu ram]
```

## Под капотом

`GenericMap` является ссылочным типом, передача ресивера копирует только 8-байтный указатель.

## Подводные камни

Методы на `GenericMap` не могут объявлять собственные независимые параметры типов.

## На собеседовании

**Вопрос с собеседования:** «Почему методы не могут объявлять собственные параметры типов?»
**Ответ:** Это сделало бы невозможным построение интерфейсных таблиц (itab) во время компиляции.
