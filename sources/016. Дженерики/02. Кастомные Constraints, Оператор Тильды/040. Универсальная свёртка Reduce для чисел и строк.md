# Универсальная свёртка Reduce для чисел и строк

## Условие

Напишите функцию `Reduce[T, U any](s []T, initial U, f func(U, T) U) U` (свертка списка). Используйте её для подсчета суммы или конкатенации строк.

## Теория

`Reduce` аккумулирует элементы среза в единый результат типа `U`.

## Решение по шагам

1. Объявим `Reduce[T, U any](s []T, initial U, f func(U, T) U) U`.
2. В `main` подсчитаем суммарную длину всех строк.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Reduce[T, U any](s []T, initial U, f func(U, T) U) U {
	acc := initial
	for _, v := range s {
		acc = f(acc, v)
	}
	return acc
}

func main() {
	words := []string{"Go", "Generics", "Workout"}
	totalLen := Reduce(words, 0, func(acc int, w string) int {
		return acc + len(w)
	})
	fmt.Printf("Общая длина: %d символов\n", totalLen)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Общая длина: 17 символов
```

## Под капотом

Типы `T` (`string`) и `U` (`int`) типизируются компилятором независимо без аллокаций в куче.

## Подводные камни

Передача тяжелых структур по значению может вызывать затраты на копирование.

## На собеседовании

**Вопрос с собеседования:** «Каковы накладные расходы на вызов анонимной функции в цикле Reduce?»
**Ответ:** Если замыкание не инлайнится, каждый косвенный вызов через указатель занимает несколько наносекунд.
