# Constraint с интерфейсом Closer и функция CloseAll

## Условие

Создай constraint с интерфейсом, имеющим метод: `type Closer interface { Close() error }`. Напиши `CloseAll[T Closer](items []T) []error`, закрывающий всё и собирающий ошибки.

### Исходная формулировка

Создай constraint с интерфейсом, имеющим метод: `type Closer interface { Close() error }`. Напиши `CloseAll[T Closer](items []T) []error`, закрывающий всё и собирающий ошибки.

---

## Теория

`CloseAll[T Closer](items []T)` принимает срез любых объектов с методом `Close() error` без промежуточных аллокаций `[]io.Closer`.

## Решение по шагам

1. Объявим `type Closer interface { Close() error }`.
2. Создадим структуры `FakeFile` и `FakeSocket`.
3. Реализуем `CloseAll[T Closer](items []T) []error`.
4. В `main` закроем файлы и сокеты.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Closer interface {
	Close() error
}

type FakeFile struct {
	Name string
}

func (f *FakeFile) Close() error {
	fmt.Printf("Файл %s закрыт\n", f.Name)
	return nil
}

type FakeSocket struct {
	Port int
}

func (s *FakeSocket) Close() error {
	fmt.Printf("Сокет %d закрыт\n", s.Port)
	return nil
}

func CloseAll[T Closer](items []T) []error {
	var errs []error
	for _, item := range items {
		if err := item.Close(); err != nil {
			errs = append(errs, err)
		}
	}
	return errs
}

func main() {
	files := []*FakeFile{{Name: "app.log"}, {Name: "data.db"}}
	CloseAll(files)

	sockets := []*FakeSocket{{Port: 8080}}
	CloseAll(sockets)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Файл app.log закрыт
# Файл data.db закрыт
# Сокет 8080 закрыт
```

## Под капотом

Дженерик принимает срез указателей `[]*FakeFile` напрямую без создания промежуточного слайса интерфейсов.

## Подводные камни

Если метод объявлен на указателе `*FakeFile`, передавайте срез указателей `[]*FakeFile`.

## На собеседовании

**Вопрос с собеседования:** «В чем плюс CloseAll\[T Closer]([]T) перед CloseAll([]Closer)?»
**Ответ:** В Go срез `[]*FakeFile` нельзя передать в `[]Closer` без полного копирования. Дженерик решает это с 0 аллокаций.
