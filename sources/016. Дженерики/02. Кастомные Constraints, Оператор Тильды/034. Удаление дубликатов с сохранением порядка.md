# Удаление дубликатов с сохранением порядка: Unique[T comparable]

## Условие

Используйте дженерики для создания функции `Unique[T comparable](s []T) []T`, которая удаляет дубликаты из слайса с сохранением порядка.

## Теория

Удаление дубликатов с сохранением порядка (Stable Deduplication) использует множество `seen := make(map[T]struct{})`. Ограничение `T comparable` необходимо, чтобы тип `T` мог служить ключом мапы. Алгоритмическая сложность: время \(O(N)\), память \(O(K)\).

## Решение по шагам

1. Объявим `Unique[T comparable](s []T) []T`.
2. Создадим мапу `seen := make(map[T]struct{})` и срез `result := make([]T, 0, len(s))`.
3. Для каждого элемента проверим `if _, ok := seen[v]; !ok`: добавим в `seen` и в `result`.
4. В `main` протестируем на слайсе чисел и строк.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Unique[T comparable](s []T) []T {
	seen := make(map[T]struct{})
	result := make([]T, 0, len(s))
	for _, v := range s {
		if _, ok := seen[v]; !ok {
			seen[v] = struct{}{}
			result = append(result, v)
		}
	}
	return result
}

func main() {
	nums := []int{1, 2, 2, 3, 4, 3, 5, 1, 6}
	fmt.Println("Уникальные числа:", Unique(nums))

	tags := []string{"go", "docker", "k8s", "go", "grpc", "docker"}
	fmt.Println("Уникальные теги: ", Unique(tags))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Уникальные числа: [1 2 3 4 5 6]
# Уникальные теги:  [go docker k8s grpc]
```

## Под капотом

Мапа `seen` аллоцирует бакеты под размер типа `T`. При \(N < 16\) линейный скан слайса может быть быстрее, но для произвольных \(N\) мапа дает гарантированное \(O(N)\).

## Подводные камни

Помните, что `Unique` создает новый слайс. Для in-place удаления в отсортированном срезе лучше использовать `slices.Compact`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие Unique от slices.Compact в Go 1.21+?»
**Ответ:** `slices.Compact` удаляет только последовательные дубликаты (требует сортировки) с \(O(1)\) памяти, а `Unique` работает с неотсортированными данными за \(O(N)\) памяти.
