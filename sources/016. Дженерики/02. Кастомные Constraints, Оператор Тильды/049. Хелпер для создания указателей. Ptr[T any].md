# Хелпер для создания указателей: Ptr[T any]

## Условие

Напишите параметризованную функцию `Ptr[T any](val T) *T`, которая возвращает указатель на переданное значение. Это очень удобный хелпер для тестов и заполнения структур.

## Теория

В Go нельзя взять адрес от литерала напрямую (`&42` — ошибка). Функция `Ptr[T any](val T) *T` создает указатель на значение любого типа.

## Решение по шагам

1. Объявим `func Ptr[T any](val T) *T { return &val }`.
2. Создадим структуру `UserConfig` с указателями.
3. В `main` заполним поля через `Ptr`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Ptr[T any](val T) *T {
	return &val
}

type UserConfig struct {
	Host    *string
	Port    *int
	Debug   *bool
	Timeout *float64
}

func main() {
	cfg := UserConfig{
		Host:    Ptr("localhost"),
		Port:    Ptr(8080),
		Debug:   Ptr(true),
		Timeout: Ptr(5.5),
	}

	fmt.Printf("Host: %s, Port: %d, Debug: %v, Timeout: %.1f\n",
		*cfg.Host, *cfg.Port, *cfg.Debug, *cfg.Timeout)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Host: localhost, Port: 8080, Debug: true, Timeout: 5.5
```

## Под капотом

Escape Analysis компилятора аллоцирует значение в куче или инлайнит создание объекта.

## Подводные камни

Не используйте указатели на примитивы без необходимости.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go нельзя взять адрес &100?»
**Ответ:** Литералы являются неадресуемыми значениями (unaddressable) и не имеют постоянного адреса в памяти.
