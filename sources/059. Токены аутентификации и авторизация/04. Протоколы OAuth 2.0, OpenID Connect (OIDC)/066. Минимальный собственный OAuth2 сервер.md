# Минимальный собственный OAuth2 сервер (Client Credentials & Protected API)

## Условие

Создайте сервер, выдающий access token по client credentials grant. Используйте библиотеку `go-oauth2/oauth2`. Защитите ресурс, требующий валидный токен.

### Исходная формулировка

**Реализация собственного OAuth2-сервера (минимального).**: Создайте сервер, выдающий access token по client credentials grant. Используйте библиотеку `go-oauth2/oauth2`. Защитите ресурс, требующий валидный токен.

## Теория

Завершающий шаг в освоении авторизации — проектирование **полнофункционального сервера авторизации и защищенного API** на чистом Go:

### Полная архитектура системы:
1. **Реестр клиентов (Client Registry):**
   Хранит авторизованные микросервисы (`client_id`, `client_secret`, разрешенные скоупы `scopes`).
2. **Эндпоинт `/token`:**
   - Поддерживает `grant_type=client_credentials`.
   - Проверяет учетные данные клиентов в константное время.
   - Фильтрует запрошенные скоупы.
   - Выпускает защищенный Bearer токен с коротким TTL.
3. **Хранилище активных токенов (Token Cache):**
   Потокобезопасное хранилище токенов с автоматической проверкой срока жизни.
4. **Защищенный Ресурсный API (`/api/v1/metrics`):**
   - HTTP Middleware проверяет наличие заголовка `Authorization: Bearer <token>`.
   - Валидирует статус и срок годности токена.
   - Проверяет требуемый скоуп `metrics:read`.
   - Возвращает защищенные бизнес-данные или стандартные коды ошибок 401/403.

## Решение по шагам

1. Создайте структуры данных для клиентов, токенов и ответов сервера.
2. Реализуйте эндпоинт `/token` с поддержкой аутентификации через Basic Auth и Body Form.
3. Реализуйте middleware проверки Bearer токенов и скоупов.
4. Реализуйте защищенный бизнес-эндпоинт `/api/v1/metrics`.
5. Продемонстрируйте полный сценарий: получение токена клиентом, успешный доступ к метрикам и отказ при нехватке прав.

## Код решения

**`main.go`**

```go
package main

import (
	"crypto/rand"
	"crypto/subtle"
	"encoding/hex"
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"net/url"
	"strings"
	"sync"
	"time"
)

type ClientInfo struct {
	Secret string
	Scopes []string
}

type ActiveTokenInfo struct {
	ClientID  string
	Scopes    map[string]bool
	ExpiresAt time.Time
}

// CustomOAuth2Server — компактный OAuth 2.0 сервер
type CustomOAuth2Server struct {
	mu      sync.RWMutex
	clients map[string]ClientInfo
	tokens  map[string]ActiveTokenInfo
}

func NewCustomOAuth2Server() *CustomOAuth2Server {
	return &CustomOAuth2Server{
		clients: map[string]ClientInfo{
			"monitoring_prometheus": {
				Secret: "super_secret_prom_key_99",
				Scopes: []string{"metrics:read"},
			},
			"unauthorized_app": {
				Secret: "guest_secret",
				Scopes: []string{"public:read"},
			},
		},
		tokens: make(map[string]ActiveTokenInfo),
	}
}

// HandleToken обрабатывает grant_type=client_credentials
func (s *CustomOAuth2Server) HandleToken(w http.ResponseWriter, r *http.Request) {
	if r.Method != http.MethodPost {
		http.Error(w, "Method Not Allowed", http.StatusMethodNotAllowed)
		return
	}

	clientID, clientSecret, ok := r.BasicAuth()
	if !ok {
		clientID = r.FormValue("client_id")
		clientSecret = r.FormValue("client_secret")
	}

	s.mu.RLock()
	client, exists := s.clients[clientID]
	s.mu.RUnlock()

	// Сравнение секрета в константное время
	if !exists || subtle.ConstantTimeCompare([]byte(client.Secret), []byte(clientSecret)) != 1 {
		w.Header().Set("Content-Type", "application/json")
		w.WriteHeader(http.StatusUnauthorized)
		_, _ = w.Write([]byte(`{"error":"invalid_client"}`))
		return
	}

	if r.FormValue("grant_type") != "client_credentials" {
		w.WriteHeader(http.StatusBadRequest)
		_, _ = w.Write([]byte(`{"error":"unsupported_grant_type"}`))
		return
	}

	// Генерация 256-битного криптографического токена
	b := make([]byte, 32)
	_, _ = io.ReadFull(rand.Reader, b)
	token := hex.EncodeToString(b)

	scopeMap := make(map[string]bool)
	for _, sc := range client.Scopes {
		scopeMap[sc] = true
	}

	s.mu.Lock()
	s.tokens[token] = ActiveTokenInfo{
		ClientID:  clientID,
		Scopes:    scopeMap,
		ExpiresAt: time.Now().Add(1 * time.Hour),
	}
	s.mu.Unlock()

	w.Header().Set("Content-Type", "application/json")
	_ = json.NewEncoder(w).Encode(map[string]interface{}{
		"access_token": token,
		"token_type":   "Bearer",
		"expires_in":   3600,
		"scope":        strings.Join(client.Scopes, " "),
	})
}

// RequireBearerToken middleware для защиты API
func (s *CustomOAuth2Server) RequireBearerToken(requiredScope string, next http.HandlerFunc) http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		auth := r.Header.Get("Authorization")
		if !strings.HasPrefix(auth, "Bearer ") {
			w.Header().Set("WWW-Authenticate", `Bearer error="invalid_token"`)
			http.Error(w, `{"error":"unauthorized"}`, http.StatusUnauthorized)
			return
		}

		token := strings.TrimPrefix(auth, "Bearer ")

		s.mu.RLock()
		info, exists := s.tokens[token]
		s.mu.RUnlock()

		if !exists || time.Now().After(info.ExpiresAt) {
			w.Header().Set("WWW-Authenticate", `Bearer error="invalid_token"`)
			http.Error(w, `{"error":"invalid_or_expired_token"}`, http.StatusUnauthorized)
			return
		}

		if !info.Scopes[requiredScope] {
			w.Header().Set("WWW-Authenticate", fmt.Sprintf(`Bearer error="insufficient_scope", scope="%s"`, requiredScope))
			http.Error(w, `{"error":"forbidden_insufficient_scope"}`, http.StatusForbidden)
			return
		}

		next(w, r)
	}
}

func main() {
	srv := NewCustomOAuth2Server()
	mux := http.NewServeMux()
	mux.HandleFunc("/oauth/token", srv.HandleToken)

	// Защищенный бизнес-эндпоинт
	metricsHandler := func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		_, _ = w.Write([]byte(`{"rps":125000,"goroutines":4820,"memory_mb":512}`))
	}
	mux.HandleFunc("/api/v1/metrics", srv.RequireBearerToken("metrics:read", metricsHandler))

	ts := httptest.NewServer(mux)
	defer ts.Close()

	// 1. Успешное получение токена доверенным сервисом (Prometheus)
	fmt.Println("=== 1. Получение токена по Client Credentials Grant ===")
	form := url.Values{"grant_type": {"client_credentials"}}
	reqToken, _ := http.NewRequest("POST", ts.URL+"/oauth/token", strings.NewReader(form.Encode()))
	reqToken.Header.Set("Content-Type", "application/x-www-form-urlencoded")
	reqToken.SetBasicAuth("monitoring_prometheus", "super_secret_prom_key_99")

	respToken, _ := http.DefaultClient.Do(reqToken)
	var tr map[string]interface{}
	_ = json.NewDecoder(respToken.Body).Decode(&tr)
	respToken.Body.Close()

	accessToken := tr["access_token"].(string)
	fmt.Printf("Access Token получен: %s...\n", accessToken[:20])
	fmt.Printf("Scopes:               %s\n\n", tr["scope"])

	// 2. Успешный запрос к защищенному API с Bearer токеном
	fmt.Println("=== 2. Запрос к защищенному эндпоинту /api/v1/metrics ===")
	reqMetrics, _ := http.NewRequest("GET", ts.URL+"/api/v1/metrics", nil)
	reqMetrics.Header.Set("Authorization", "Bearer "+accessToken)
	respMetrics, _ := http.DefaultClient.Do(reqMetrics)
	bodyMetrics, _ := io.ReadAll(respMetrics.Body)
	respMetrics.Body.Close()
	fmt.Printf("HTTP Status: %d\nОтвет API:   %s\n\n", respMetrics.StatusCode, string(bodyMetrics))

	// 3. Попытка запроса сервисом с недостаточными правами
	fmt.Println("=== 3. Проверка Scope Middleware (Insufficient Scope) ===")
	reqTokenGuest, _ := http.NewRequest("POST", ts.URL+"/oauth/token", strings.NewReader(form.Encode()))
	reqTokenGuest.Header.Set("Content-Type", "application/x-www-form-urlencoded")
	reqTokenGuest.SetBasicAuth("unauthorized_app", "guest_secret")
	respGuest, _ := http.DefaultClient.Do(reqTokenGuest)
	var trGuest map[string]interface{}
	_ = json.NewDecoder(respGuest.Body).Decode(&trGuest)
	respGuest.Body.Close()

	reqBadScope, _ := http.NewRequest("GET", ts.URL+"/api/v1/metrics", nil)
	reqBadScope.Header.Set("Authorization", "Bearer "+trGuest["access_token"].(string))
	respBadScope, _ := http.DefaultClient.Do(reqBadScope)
	fmt.Printf("HTTP Status:      %d (Forbidden)\n", respBadScope.StatusCode)
	fmt.Printf("WWW-Authenticate: %s\n", respBadScope.Header.Get("WWW-Authenticate"))
	respBadScope.Body.Close()
}
```

## Под капотом

В полномасштабных фреймворках (например, `github.com/go-oauth2/oauth2/v4`) сервер разделен на менеджер `oauth2.Manager`, клиентское хранилище `models.ClientStore` и генератор токенов `generate.AuthorizeGenerate`. Механизм Client Credentials grant полностью автономен: он не требует сессий пользователей, а валидация Bearer токенов на ресурсном сервере может использовать как прямую интроспекцию в Redis, так и асимметричную проверку JWT подписи без обращения к БД.

## Подводные камни

1. **Игнорирование тайминговых атак при проверке секрета:** Сравнение `client.Secret == secret` позволяет восстановить секрет посимвольно. Обязательно `subtle.ConstantTimeCompare`.
2. **Отсутствие WWW-Authenticate заголовка при ошибках:** Спецификации RFC 6750 и RFC 6749 требуют наличия заголовка `WWW-Authenticate` с атрибутами ошибки.
3. **Хранение токенов без TTL:** В оперативной памяти или Redis каждый выданный токен обязан иметь время автоматического удаления, предотвращающее утечки памяти.

## На собеседовании

**Вопрос с собеседования:** Как архитектурно защитить сам эндпоинт `/oauth/token` собственного Authorization Server от DDoS-атак и попыток подбора учетных данных клиентов?
**Ответ:** 1) **Distributed Rate Limiting (Token Bucket / Leaky Bucket) в Redis:** Ограничение количества запросов по IP-адресу (например, не более 5 RPS) и по `client_id` (не более 20 RPS).
2) **Exponential Backoff:** Задержка ответа при неверном пароле (например, 100 мс, 200 мс, 400 мс), делающая перебор математически неэффективным.
3) **mTLS на уровне инфраструктуры:** Для критических M2M-интеграций вход на эндпоинт `/oauth/token` закрывается на уровне периметра Mutual TLS сертификатами, что отсекает весь недоверенный трафик до попадания в приложение Go.
