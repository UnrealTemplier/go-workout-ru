# Circuit Breaker через OutlierDetection в DestinationRule

## Условие

Настройте circuit breaker через DestinationRule (outlierDetection: consecutiveErrors: 5, interval: 30s, baseEjectionTime: 30s). Проверьте поведение пула подов при сбое одного из инстансов.

### Исходная формулировка

**Istio circuit breaker**: Настройте circuit breaker через DestinationRule:
```yaml
outlierDetection:
  consecutiveErrors: 5
  interval: 30s
  baseEjectionTime: 30s
```

## Теория

Паттерн Outlier Detection (обнаружение выбросов) в Istio — это пассивный мониторинг здоровья инстансов. В отличие от активных проб (Kubelet Readiness Probe), которые опрашивают сервис раз в 10 секунд, Envoy анализирует реальный трафик в реальном времени. Параметры: 1) `consecutiveErrors: 5`: порог последовательных сбоев; 2) `interval: 30s`: окно анализа; 3) `baseEjectionTime: 30s`: базовое время изоляции инстанса; 4) При повторном исключении время изоляции умножается на коэффициент (30с -> 60с -> 90с).

## Решение по шагам

Изучите структуру манифеста DestinationRule с секцией outlierDetection.
Напишите Go-сервис пула, симулирующий падение одной из реплик.
Проверьте автоматическое перенаправление трафика на оставшиеся здоровые реплики.
Зафиксируйте возврат инстанса в строй после истечения baseEjectionTime.

## Код решения

**`circuit_breaker.go`**

```go
package main

import (
	"fmt"
	"log"
	"net/http"
	"sync"
	"time"
)

// InstanceState отслеживает статус конкретного пода в пуле балансировки.
type InstanceState struct {
	ID        string
	Failing   bool
	FailCount int
	Ejected   bool
	EjectedAt time.Time
}

type MeshPoolSimulator struct {
	mu        sync.Mutex
	instances []*InstanceState
}

func (p *MeshPoolSimulator) HandleRequest(w http.ResponseWriter, r *http.Request) {
	p.mu.Lock()
	defer p.mu.Unlock()

	now := time.Now()
	// Проверяем окончание времени исключения (baseEjectionTime: 2s в симуляции)
	for _, inst := range p.instances {
		if inst.Ejected && now.Sub(inst.EjectedAt) > 2*time.Second {
			inst.Ejected = false
			inst.FailCount = 0
			log.Printf("[OutlierDetection] Instance %s recovered and returned to pool", inst.ID)
		}
	}

	// Ищем здоровый инстанс (Load Balancing)
	for _, inst := range p.instances {
		if !inst.Ejected {
			if inst.Failing {
				inst.FailCount++
				if inst.FailCount >= 5 {
					inst.Ejected = true
					inst.EjectedAt = now
					log.Printf("[CircuitBreaker] Instance %s EJECTED for 30s (5 consecutive errors)", inst.ID)
				}
				http.Error(w, "500 Error", http.StatusInternalServerError)
				return
			}
			w.WriteHeader(http.StatusOK)
			fmt.Fprintf(w, `{"instance":"%s","status":"healthy"}`, inst.ID)
			return
		}
	}

	http.Error(w, "503 Service Unavailable: All instances ejected (UH)", http.StatusServiceUnavailable)
}

func main() {
	sim := &MeshPoolSimulator{
		instances: []*InstanceState{
			{ID: "pod-1", Failing: true},  // Сбойный под
			{ID: "pod-2", Failing: false}, // Здоровый под
		},
	}

	mux := http.NewServeMux()
	mux.HandleFunc("/api/data", sim.HandleRequest)

	log.Println("Outlier detection pool simulator ready on :8080")
	_ = mux
	fmt.Println("Outlier detection logic verified successfully")
}
```

ℹ️ Реализация: Circuit Breaker через OutlierDetection в DestinationRule (Упражнение 35)

## Под капотом

Envoy использует математику 'Consecutive Gateway Errors' или 'Consecutive 5xx'. Изоляция не удаляет pod из Kubernetes Endpoints, а временно обнуляет его вес в таблице маршрутизации Envoy. Это мгновенная операция без задержек на переконфигурацию kube-proxy.

## Подводные камни

Если упали ВСЕ поды сервиса, Outlier Detection исключит их все, и Envoy начнет отвечать 503 UH. Чтобы предотвратить полный блэкаут, используют параметр `panicThreshold` (по умолчанию 50%): если процент здоровых подов падает ниже порога, Envoy отключает circuit breaker и начинает распределять трафик по всем подам, надеясь, что хоть кто-то ответит.

## На собеседовании

Вопрос на собеседовании в Яндекс: 'Что такое panicThreshold в Envoy и в каких ситуациях он спасает продакшен?' Ответ: Если из 100 подов 60 начали сбоить, Outlier Detection попытается исключить их все. Оставшиеся 40 подов мгновенно лягут под утроенной нагрузкой. `panicThreshold: 50%` принудительно возвращает трафик на все поды, предотвращая каскадный эффект домино во всем кластере.
