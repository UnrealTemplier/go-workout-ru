## Теория

Service Mesh предоставляет стандартизированную телеметрию 'из коробки' без добавления клиентских библиотек в Go-код. Envoy sidecar экспортирует метрики на порту 15090 (`/stats/prometheus`). Ключевые метрики: 1) `istio_requests_total` (счетчик запросов с лейблами `response_code`, `source_workload`, `destination_workload`); 2) `istio_request_duration_milliseconds` (гистограмма времени отклика); 3) `istio_tcp_connections_opened_total` (метрики L4). Это так называемые 'Golden Signals' (Latency, Traffic, Errors, Saturation), измеряемые объективно на границе сервисов.

## Код решения

**`server.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"io"
	"log"
	"net/http"
	"strings"
	"time"
)

// MetricSample хранит распарсенную строку метрики Prometheus.
type MetricSample struct {
	Name   string
	Labels map[string]string
	Value  string
}

// ScrapeEnvoyMetrics опрашивает порт телеметрии Envoy sidecar.
func ScrapeEnvoyMetrics(envoyMetricsURL string) ([]MetricSample, error) {
	client := &http.Client{Timeout: 3 * time.Second}
	resp, err := client.Get(envoyMetricsURL)
	if err != nil {
		return nil, fmt.Errorf("failed to scrape envoy: %w", err)
	}
	defer resp.Body.Close()

	var samples []MetricSample
	scanner := bufio.NewScanner(resp.Body)
	for scanner.Scan() {
		line := strings.TrimSpace(scanner.Text())
		if strings.HasPrefix(line, "#") || line == "" {
			continue // Пропускаем комментарии HELP/TYPE
		}

		if strings.HasPrefix(line, "istio_requests_total") {
			// Пример: istio_requests_total{response_code="200",reporter="destination"} 1420
			parts := strings.Split(line, " ")
			if len(parts) == 2 {
				samples = append(samples, MetricSample{
					Name:  "istio_requests_total",
					Value: parts[1],
				})
			}
		}
	}
	return samples, scanner.Err()
}

func main() {
	// В реальном поде порт Envoy Prometheus: http://127.0.0.1:15090/stats/prometheus
	log.Println("Querying Istio sidecar telemetry endpoint...")
	samples, err := ScrapeEnvoyMetrics("http://127.0.0.1:15090/stats/prometheus")
	if err != nil {
		log.Printf("[Scrape Info] Service Mesh port not available locally (expected outside K8s): %v", err)
		return
	}

	fmt.Printf("Successfully scraped %d Istio Golden Signal metric points\n", len(samples))
}
```

ℹ️ Реализация: Распределенные метрики Service Mesh и Prometheus ServiceMonitor (Упражнение 12)

## Под капотом

Envoy хранит счетчики и гистограммы в кольцевых буферах Shared Memory, оптимизированных под многопоточность lock-free атомиками. Когда Prometheus агент опрашивает порт 15090, Envoy форматирует данные в текстовый формат OpenMetrics без блокировки основных worker-тредов обработки трафика.

## Подводные камни

Высокая кардинальность (High Cardinality) метрик: если разработчики передают уникальные ID в URL (например, `/users/123456`), Envoy по умолчанию может агрегировать это в отдельные временные ряды, что приводит к исчерпанию памяти Prometheus. В Istio необходимо настраивать Telemetry API или регекс-нормализацию путей.

## На собеседовании

Вопрос на собеседовании в Wildberries: 'Чем отличаются метрики reporter=source от reporter=destination в istio_requests_total?' Ответ: `reporter=source` измеряется на стороне вызывающего sidecar и отражает реальную задержку сети + очереди + обработки. `reporter=destination` измеряется на стороне принимающего sidecar. Если запрос был отклонен сетевым фильтром (например, сброшен по таймауту в сети), source покажет ошибку, а destination может вообще не зафиксировать запрос.
