# Иммутабельные структуры данных (Value Object): Counter с возвратом новой копии WithValue

## Условие

Реализуй **immutable** структуру `Counter`: поля неэкспортируемые, методы `WithValue(v int) Counter` возвращают **новую копию**, не меняя оригинал. Покажи, что оригинал остаётся неизменным.

## Теория

Паттерн Value Object: любые модификации порождают новый неизменяемый объект.

## Решение по шагам

1. Создаем Counter{val int}.
2. Реализуем метод (c Counter) WithValue(v int) Counter.
3. Показываем неизменность оригинала c1 после вызова c2 := c1.WithValue(20).

## Код решения

**`main.go`**

```go
package main

import "fmt"

type ImmutableCounter struct {
	val int
}

func NewImmutableCounter(v int) ImmutableCounter {
	return ImmutableCounter{val: v}
}

func (c ImmutableCounter) Value() int {
	return c.val
}

// WithValue возвращает НОВЫЙ экземпляр, оригинал не меняется:
func (c ImmutableCounter) WithValue(v int) ImmutableCounter {
	return ImmutableCounter{val: v}
}

func main() {
	c1 := NewImmutableCounter(10)
	c2 := c1.WithValue(50)

	fmt.Printf("Оригинал c1: %d\n", c1.Value())
	fmt.Printf("Новый c2:     %d\n", c2.Value())
}
```

**`Терминал`**

```bash
go run main.go
# Оригинал c1: 10
# Новый c2:     50
```

## Под капотом

Структура копируется по значению в регистрах процессора.

## Подводные камни

- Случайное использование pointer receiver, разрушающее иммутабельность.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество иммутабельных структур в конкурентном Go-коде?»
**Ответ:** Иммутабельные структуры на 100% потокобезопасны без мьютексов, так как горутины только читают неизменяемые данные.
