# Многоуровневая цепочка встраивания A -> B -> C и глубокое всплытие методов (Deep Promotion)

## Условие

Создай цепочку встраивания: `A` встраивает `B`, `B` встраивает `C`. `C` имеет метод `Hello()`. Покажи, что `Hello` доступен напрямую на `A` (**deep promotion**).

## Теория

Go рекурсивно продвигает методы по всей цепочке встраивания любой глубины.

## Решение по шагам

1. Создаем C{ Msg string } с методом Hello().
2. Создаем B{ C } и A{ B }.
3. Вызываем a.Hello().

## Код решения

**`main.go`**

```go
package main

import "fmt"

type C struct{ Msg string }
func (c C) Hello() string { return "Привет от C: " + c.Msg }

type B struct{ C }
type A struct{ B }

func main() {
	a := A{B: B{C: C{Msg: "Deep Promotion работает!"}}}
	fmt.Println(a.Hello()) // a -> b -> c -> Hello()
}
```

**`Терминал`**

```bash
go run main.go
# Привет от C: Deep Promotion работает!
```

## Под капотом

Компилятор производит поиск в ширину (BFS) по графу встраивания.

## Подводные камни

- Слишком глубокие цепочки встраивания ухудшают читаемость кода.

## На собеседовании

**Вопрос с собеседования:** «Какова максимальная глубина встраивания в Go?»
**Ответ:** Язык не ограничивает глубину, но на практике глубже 2 уровней встраивание не рекомендуется.
