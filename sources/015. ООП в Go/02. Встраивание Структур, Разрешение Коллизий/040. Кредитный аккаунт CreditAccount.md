# Кредитный аккаунт CreditAccount: расширение базовой структуры Account и поле CreditLimit

## Условие

"Наследование" через композицию (Embedding): Создай структуру CreditAccount. Встрой в неё структуру account анонимным полем. Добавь поле CreditLimit float64.

### Исходная формулировка

**"Наследование" через композицию (Embedding)**: Создай структуру `CreditAccount`. Встрой в неё структуру `account` (из упр. 223) анонимным полем. Добавь поле `CreditLimit float64`.

## Теория

Расширение модели данных путем добавления новых полей к встроенной структуре.

## Решение по шагам

1. Создаем базовый Account.
2. Создаем CreditAccount со встраиванием Account и CreditLimit.
3. Тестируем.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Account struct{ Balance float64 }

type CreditAccount struct {
	Account
	CreditLimit float64
}

func (c *CreditAccount) AvailableFunds() float64 {
	return c.Balance + c.CreditLimit
}

func main() {
	ca := CreditAccount{Account: Account{Balance: 1000}, CreditLimit: 5000}
	fmt.Printf("Доступно средств: %.2f руб.\n", ca.AvailableFunds())
}
```

**`Терминал`**

```bash
go run main.go
# Доступно средств: 6000.00 руб.
```

## Под капотом

Поле Balance лежит внутри подструктуры Account в непрерывной памяти.
