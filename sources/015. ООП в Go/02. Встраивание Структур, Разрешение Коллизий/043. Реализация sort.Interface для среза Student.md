# Реализация sort.Interface для среза Student: сортировка по убыванию успеваемости

## Условие

Интерфейс `sort.Interface`: реализуйте его для слайса структур `Student` (поля `Name`, `Grade`), чтобы сортировать по убыванию успеваемости. Используйте `sort.Sort`.

## Теория

Классическая сортировка через Len, Less, Swap.

## Решение по шагам

1. Создаем Student{Name, Grade}.
2. Объявляем type ByGrade []Student.
3. Реализуем Len, Less, Swap.
4. Сортируем через sort.Sort.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sort"
)

type Student struct {
	Name  string
	Grade float64
}

type ByGrade []Student

func (b ByGrade) Len() int           { return len(b) }
func (b ByGrade) Less(i, j int) bool { return b[i].Grade > b[j].Grade } // Убывание
func (b ByGrade) Swap(i, j int)      { b[i], b[j] = b[j], b[i] }

func main() {
	students := ByGrade{
		{"Анна", 4.5},
		{"Борис", 4.9},
		{"Виктор", 3.8},
	}
	sort.Sort(students)
	for _, s := range students {
		fmt.Printf("• %-8s: %.1f\n", s.Name, s.Grade)
	}
}
```

**`Терминал`**

```bash
go run main.go
# • Борис   : 4.9
# • Анна    : 4.5
# • Виктор  : 3.8
```

## Под капотом

Алгоритм QuickSort/Pattern-defeating Quicksort работает на срезе без аллокаций.

## Подводные камни

- Неправильный знак в Less для сортировки по убыванию.

## На собеседовании

**Вопрос с собеседования:** «Что быстрее: sort.Sort или slices.SortFunc?»
**Ответ:** slices.SortFunc быстрее за счет дженериков и отсутствия интерфейсного оверхеда.
