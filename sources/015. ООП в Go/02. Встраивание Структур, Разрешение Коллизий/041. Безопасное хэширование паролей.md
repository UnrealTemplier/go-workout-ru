# Безопасное хэширование паролей: сеттер SetPassword(raw string) с crypto/sha256

## Условие

Создайте структуру `User` с полями `Email` и `PasswordHash`. Сделайте сеттер `SetPassword(raw string)`, который внутри хэширует пароль (используйте `crypto/sha256`) перед сохранением, чтобы сырой пароль никогда не хранился в памяти.

## Теория

Инкапсуляция криптографической обработки внутри сеттера.

## Решение по шагам

1. Создаем User{Email, passwordHash}.
2. Реализуем SetPassword с sha256.Sum256.
3. Реализуем CheckPassword.

## Код решения

**`main.go`**

```go
package main

import (
	"crypto/sha256"
	"encoding/hex"
	"fmt"
)

type User struct {
	Email        string
	passwordHash string
}

func (u *User) SetPassword(raw string) {
	hash := sha256.Sum256([]byte(raw))
	u.passwordHash = hex.EncodeToString(hash[:])
}

func (u *User) CheckPassword(raw string) bool {
	hash := sha256.Sum256([]byte(raw))
	return u.passwordHash == hex.EncodeToString(hash[:])
}

func main() {
	u := &User{Email: "dev@yandex.ru"}
	u.SetPassword("super_secret_123")
	fmt.Println("Пароль верен?", u.CheckPassword("super_secret_123"))
	fmt.Println("Пароль неверен?", u.CheckPassword("wrong_pass"))
}
```

**`Терминал`**

```bash
go run main.go
# Пароль верен? true
# Пароль неверен? false
```

## Под капотом

Сырой пароль удаляется сборщиком мусора, в структуре хранится только хэш.

## Подводные камни

- Хранение сырого пароля в публичном поле.

## На собеседовании

**Вопрос с собеседования:** «Что используют для хэширования паролей в продакшене?»
**Ответ:** bcrypt или argon2id с солью (salt) для защиты от радужных таблиц.
