# Полиморфизм: интерфейс Describer с методом Describe() для Circle и Rectangle

## Условие

Полиморфизм: интерфейс `Describer` с методом `Describe() string`. Реализуйте для `Circle` и `Rectangle`. Функция `PrintAll(desc []Describer)` выводит описание каждого.

## Теория

Полиморфизм подтипов на основе общего интерфейса.

## Решение по шагам

1. Объявляем Describer.
2. Реализуем Describe() для Circle и Rectangle.
3. Пишем PrintAll(desc []Describer).

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Describer interface {
	Describe() string
}

type Circle struct{ R float64 }
func (c Circle) Describe() string { return fmt.Sprintf("Круг радиусом %.1f", c.R) }

type Rectangle struct{ W, H float64 }
func (r Rectangle) Describe() string { return fmt.Sprintf("Прямоугольник %.1fx%.1f", r.W, r.H) }

func PrintAll(items []Describer) {
	for _, item := range items {
		fmt.Println("•", item.Describe())
	}
}

func main() {
	shapes := []Describer{Circle{5}, Rectangle{4, 6}}
	PrintAll(shapes)
}
```

**`Терминал`**

```bash
go run main.go
# • Круг радиусом 5.0
# • Прямоугольник 4.0x6.0
```
