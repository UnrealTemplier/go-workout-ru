# Расширение типа time.Time: кастомный тип type MyTime time.Time и метод IsWeekend()

## Условие

Создайте тип `type MyTime time.Time` и добавьте к нему метод `IsWeekend() bool`.

## Теория

Добавление доменных методов к типам стандартной библиотеки.

## Решение по шагам

1. Объявляем type MyTime time.Time.
2. Реализуем метод IsWeekend() bool.
3. Тестируем на субботе и понедельнике.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

type MyTime time.Time

func (t MyTime) IsWeekend() bool {
	w := time.Time(t).Weekday()
	return w == time.Saturday || w == time.Sunday
}

func main() {
	saturday := MyTime(time.Date(2026, 9, 5, 12, 0, 0, 0, time.UTC))
	monday := MyTime(time.Date(2026, 9, 7, 12, 0, 0, 0, time.UTC))

	fmt.Println("Суббота выходной? ", saturday.IsWeekend())
	fmt.Println("Понедельник выходной?", monday.IsWeekend())
}
```

**`Терминал`**

```bash
go run main.go
# Суббота выходной?  true
# Понедельник выходной? false
```

## Под капотом

Каст time.Time(t) имеет нулевую стоимость в рантайме.

## Подводные камни

- Потеря методов time.Time на MyTime (их нужно вызывать через приведение к time.Time(t)).

## На собеседовании

**Вопрос с собеседования:** «Почему MyTime не наследует методы time.Time?»
**Ответ:** Defined type не наследует methods базового типа. Чтобы сохранить методы, используют встраивание struct { time.Time }.
