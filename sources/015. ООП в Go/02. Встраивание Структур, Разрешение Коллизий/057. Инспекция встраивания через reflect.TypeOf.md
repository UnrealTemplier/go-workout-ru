# Инспекция встраивания через reflect.TypeOf: флаг field.Anonymous == true

## Условие

Используй `reflect.TypeOf` на структуре с embedded полем. Покажи, что embedded struct видно как отдельное поле с именем типа, у которого `Anonymous = true`.

## Теория

Рефлексия различает явные поля и анонимно встроенные структуры с помощью флага Anonymous.

## Решение по шагам

1. Создаем Base и Container со встраиванием Base.
2. Обходим поля через reflect.TypeOf(c).Field(i).
3. Выводим field.Name и field.Anonymous.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

type Base struct{ ID int }
type Container struct {
	Base   // Anonymous embedded
	Title  string
}

func main() {
	c := Container{Base: Base{101}, Title: "Тест"}
	t := reflect.TypeOf(c)
	for i := 0; i < t.NumField(); i++ {
		f := t.Field(i)
		fmt.Printf("Поле #%d: %-8s (Тип: %-12s, Anonymous: %t)\n", i, f.Name, f.Type, f.Anonymous)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Поле #0: Base     (Тип: main.Base   , Anonymous: true)
# Поле #1: Title    (Тип: string      , Anonymous: false)
```

## Под капотом

В метаданных рантайма поле имеет флаг StructField.Anonymous.

## Подводные камни

- Попытка искать promoted поля через t.Field(i) на первом уровне (они находятся внутри вложенного t.Field(0).Type).
