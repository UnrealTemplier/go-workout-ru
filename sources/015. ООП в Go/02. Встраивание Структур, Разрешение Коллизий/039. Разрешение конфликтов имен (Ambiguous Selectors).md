# Разрешение конфликтов имен (Ambiguous Selectors) при встраивании GPS и MobilePhone в SmartCar

## Условие

**Конфликты имен при композиции**: Создайте две структуры: `GPS` (с методом `GetCoordinates()`) и `MobilePhone` (с методом `GetCoordinates()`). Создайте структуру `SmartCar`, встроив в неё обе эти структуры. Попробуйте вызвать `smartCar.GetCoordinates()`. Разберитесь в ошибке компиляции (ambiguous selector) и решите её, вызвав методы явно через имена встроенных типов.

## Теория

Коллизия имен при множественном встраивании устраняется явной квалификацией имени встроенного типа.

## Решение по шагам

1. Создаем GPS и MobilePhone с методом GetCoordinates().
2. Создаем SmartCar со встраиванием обеих структур.
3. Показываем ошибку ambiguous selector и исправляем через smartCar.GPS.GetCoordinates().

## Код решения

**`main.go`**

```go
package main

import "fmt"

type GPS struct{}
func (GPS) GetCoordinates() string { return "55.7558° N, 37.6173° E (GPS)" }

type MobilePhone struct{}
func (MobilePhone) GetCoordinates() string { return "55.7512° N, 37.6184° E (GSM)" }

type SmartCar struct {
	GPS
	MobilePhone
}

func main() {
	car := SmartCar{}

	// ❌ ОШИБКА: car.GetCoordinates() -> ambiguous selector car.GetCoordinates

	// ✅ Явное разрешение конфликта:
	fmt.Println("Координаты GPS:", car.GPS.GetCoordinates())
	fmt.Println("Координаты GSM:", car.MobilePhone.GetCoordinates())
}
```

**`Терминал`**

```bash
go run main.go
# Координаты GPS: 55.7558° N, 37.6173° E (GPS)
# Координаты GSM: 55.7512° N, 37.6184° E (GSM)
```

## Под капотом

Компилятор видит два кандидата на одном уровне глубины в дереве селекторов и останавливает сборку.

## Подводные камни

- Попытка вызвать неоднозначный метод напрямую.

## На собеседовании

**Вопрос с собеседования:** «Как компилятор Go разрешает совпадение имен при встраивании на разной глубине?»
**Ответ:** Метод с меньшей глубиной вложенности затеняет (shadows) метод с большей глубиной. Ошибка возникает только при совпадении на одинаковой глубине.
