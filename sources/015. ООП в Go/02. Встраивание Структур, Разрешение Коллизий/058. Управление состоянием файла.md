# Управление состоянием файла: структура File с методами Open, Read, Close (Pointer Receiver)

## Условие

Создайте структуру `File` и добавьте к ней методы `Open()`, `Read()`, `Close()`. Используйте `pointer receiver` для всех методов, изменяющих состояние (например, флаг `isOpen`).

## Теория

Pointer Receiver для синхронизации и изменения внутреннего флага состояния.

## Решение по шагам

1. Создаем File{name string, isOpen bool}.
2. Реализуем Open(), Read(), Close().
3. Проверяем переходы состояний.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type VirtualFile struct {
	name   string
	isOpen bool
}

func (f *VirtualFile) Open() error {
	if f.isOpen { return errors.New("файл уже открыт") }
	f.isOpen = true
	fmt.Printf("Файл %q открыт\n", f.name)
	return nil
}

func (f *VirtualFile) Close() error {
	if !f.isOpen { return errors.New("файл уже закрыт") }
	f.isOpen = false
	fmt.Printf("Файл %q закрыт\n", f.name)
	return nil
}

func main() {
	f := &VirtualFile{name: "app.log"}
	_ = f.Open()
	_ = f.Close()
}
```

**`Терминал`**

```bash
go run main.go
# Файл "app.log" открыт
# Файл "app.log" закрыт
```

## Под капотом

Мутация флага isOpen происходит напрямую по адресу структуры.

## Подводные камни

- Использование Value Receiver, из-за чего флаг isOpen останется неизменным.

## На собеседовании

**Вопрос с собеседования:** «Почему в io.Closer метод Close() обычно требует Pointer Receiver?»
**Ответ:** Потому что закрытие ресурса изменяет внутреннее состояние структуры и освобождает системный дескриптор.
