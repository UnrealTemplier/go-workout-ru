# Анонимное встраивание Engine в Car и прямой вызов car.Start()

## Условие

Создай структуру `Engine` с методом `Start()`. Создай структуру `Car`, которая *анонимно встраивает* `Engine`. Вызови `car.Start()` напрямую у структуры `Car` (встраивание полей и методов).

## Теория

Всплытие методов через композицию.

## Решение по шагам

1. Создаем Engine с методом Start().
2. Создаем Car со встраиванием Engine.
3. Вызываем car.Start().

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Engine struct{ Type string }
func (e Engine) Start() { fmt.Printf("Двигатель %s запущен!\n", e.Type) }

type Car struct {
	Engine
	Brand string
}

func main() {
	c := Car{Engine: Engine{"V8 Turbo"}, Brand: "Porsche"}
	c.Start()
}
```

**`Терминал`**

```bash
go run main.go
# Двигатель V8 Turbo запущен!
```

## Под капотом

Синтаксис c.Start() преобразуется в c.Engine.Start().

## Подводные камни

- Ожидание, что Engine знает о структуре Car.

## На собеседовании

**Вопрос с собеседования:** «Можно ли переопределить метод Start в Car?»
**Ответ:** Да, тогда вызовется Car.Start, а к Engine.Start можно обратиться явно через c.Engine.Start().
