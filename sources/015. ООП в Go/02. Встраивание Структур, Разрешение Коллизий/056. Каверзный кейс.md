# Каверзный кейс: перекрытие одинаковых полей Name в структуре B со встроенной A

## Условие

**[Каверзный кейс]**: Создай структуру `A` с полем `Name string` и структуру `B`, встраивающую `A`. У `B` тоже есть поле `Name`. Создай экземпляр `B`. Выведи `b.Name` и `b.A.Name` (покажи, как работает разрешение конфликтов имен при встраивании).

## Теория

Собственное поле структуры b.Name затеняет встроенное поле b.A.Name.

## Решение по шагам

1. Создаем A{Name string}.
2. Создаем B{A, Name string}.
3. Инициализируем и выводим b.Name и b.A.Name.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type A struct{ Name string }
type B struct {
	A
	Name string
}

func main() {
	b := B{
		A:    A{Name: "Родительское Имя"},
		Name: "Собственное Имя",
	}
	fmt.Println("b.Name:   ", b.Name)
	fmt.Println("b.A.Name: ", b.A.Name)
}
```

**`Терминал`**

```bash
go run main.go
# b.Name:    Собственное Имя
# b.A.Name:  Родительское Имя
```

## Под капотом

Компилятор находит поле Name на глубине 0 и останавливает поиск.

## Подводные камни

- Думать, что b.Name перезаписывает b.A.Name (это два разных участка памяти).

## На собеседовании

**Вопрос с собеседования:** «Сколько байт занимает структура B?»
**Ответ:** 32 байта (два string по 16 байт каждый: b.A.Name и b.Name).
