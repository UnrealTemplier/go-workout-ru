# Приватные методы: вызов неэкспортируемого метода из публичного API структуры

## Условие

Создайте приватный метод (начинается с маленькой буквы) внутри структуры и вызовите его из публичного метода этой же структуры.

## Теория

Вспомогательные методы инкапсулируют внутреннюю логику.

## Решение по шагам

1. Создаем OrderProcessor.
2. Реализуем приватный метод validate() bool.
3. Вызываем его из публичного Process().

## Код решения

**`main.go`**

```go
package main

import "fmt"

type OrderProcessor struct {
	OrderID int
	Amount  float64
}

func (op *OrderProcessor) validate() bool {
	return op.OrderID > 0 && op.Amount > 0
}

func (op *OrderProcessor) Process() error {
	if !op.validate() {
		return fmt.Errorf("заказ %d не прошел валидацию", op.OrderID)
	}
	fmt.Printf("Заказ #%d на сумму %.2f успешно обработан!\n", op.OrderID, op.Amount)
	return nil
}

func main() {
	op := &OrderProcessor{OrderID: 101, Amount: 4500}
	_ = op.Process()
}
```

**`Терминал`**

```bash
go run main.go
# Заказ #101 на сумму 4500.00 успешно обработан!
```

## Под капотом

Приватный метод не экспортируется в заголовки пакета.

## Подводные камни

- Дублирование валидации в нескольких публичных методах вместо выноса в приватный.

## На собеседовании

**Вопрос с собеседования:** «Доступны ли приватные методы структуры в тестах?»
**Ответ:** Да, если тест находится в том же пакете.
