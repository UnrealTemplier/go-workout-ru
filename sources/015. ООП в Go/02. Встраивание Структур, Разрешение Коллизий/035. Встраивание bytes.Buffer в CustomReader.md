# Встраивание bytes.Buffer в CustomReader и автоматическое всплытие потоковых методов

## Условие

Создай структуру `CustomReader`, **встроив** в неё `bytes.Buffer`. Покажи, что методы `Buffer` (`Write`, `WriteString`, `Bytes` и т.д.) **продвигаются** (promoted) и доступны напрямую на `CustomReader`.

## Теория

Встраивание стандартных типов передает все их методы внешней структуре.

## Решение по шагам

1. Создаем CustomReader{ bytes.Buffer, ID string }.
2. Вызываем WriteString и Bytes напрямую на CustomReader.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
)

type CustomReader struct {
	bytes.Buffer // Встраивание
	ID           string
}

func main() {
	cr := &CustomReader{ID: "stream_1"}
	cr.WriteString("Данные потока") // Promoted method
	fmt.Printf("[%s] Прочитано: %s\n", cr.ID, cr.String())
}
```

**`Терминал`**

```bash
go run main.go
# [stream_1] Прочитано: Данные потока
```

## Под капотом

Компилятор генерирует прокси-вызовы к встроенному полю Buffer.

## Подводные камни

- Копирование структуры со встроенным Buffer (bytes.Buffer нельзя копировать после использования!).

## На собеседовании

**Вопрос с собеседования:** «Почему bytes.Buffer нельзя передавать по значению?»
**Ответ:** Buffer содержит внутренний срез и массив-буфер; копирование приведет к повреждению памяти при росте буфера.
