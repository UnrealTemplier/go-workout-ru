# Встраивание интерфейса io.Reader в структуру MyProcessor и делегирование чтения

## Условие

Встрой интерфейс `io.Reader` в структуру `MyProcessor`. Покажи, что `MyProcessor` **автоматически удовлетворяет** `io.Reader`, если встроенное поле инициализировано типом, реализующим `io.Reader`.

## Теория

Встраивание интерфейса в структуру автоматически делегирует все методы интерфейса вложенному полю.

## Решение по шагам

1. Создаем MyProcessor{ io.Reader, Name string }.
2. Передаем MyProcessor в io.ReadAll.
3. Проверяем чтение.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"strings"
)

type MyProcessor struct {
	io.Reader // Встраивание интерфейса
	Name      string
}

func main() {
	p := MyProcessor{
		Reader: strings.NewReader("Привет от встроенного интерфейса!"),
		Name:   "MainProcessor",
	}
	data, _ := io.ReadAll(p) // p реализует io.Reader!
	fmt.Println(string(data))
}
```

**`Терминал`**

```bash
go run main.go
# Привет от встроенного интерфейса!
```

## Под капотом

Вызов p.Read делегируется вызову метода внутри поля Reader.

## Подводные камни

- Вызов Read при Reader == nil приведет к панике nil pointer dereference.

## На собеседовании

**Вопрос с собеседования:** «Зачем встраивать интерфейсы в структуры?»
**Ответ:** Для переопределения части методов (декораторы) без ручной реализации всех остальных методов интерфейса.
