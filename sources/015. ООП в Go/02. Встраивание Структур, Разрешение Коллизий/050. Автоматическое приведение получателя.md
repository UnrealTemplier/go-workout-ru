# Автоматическое приведение получателя: авто-взятие адреса и разыменование в Point

## Условие

**Автоматическое приведение получателя**: Создайте структуру `Point` с методом-указателем `MoveX(dx int)` и методом-значением `GetX() int`.
* Создайте значение переменной `p := Point{X: 1}` и вызовите `p.MoveX(5)`.
* Создайте указатель `pPtr := &Point{X: 1}` и вызовите `pPtr.GetX()`.
Объясните, как компилятор Go автоматически подставляет взятие адреса (`&`) или разыменование (`*`) для удобного вызова методов.

## Теория

Синтаксический сахар компилятора Go устраняет необходимость вручную писать (*ptr) и (&val).

## Решение по шагам

1. Создаем Point{X int}.
2. Реализуем (p *Point) MoveX(dx int).
3. Реализуем (p Point) GetX() int.
4. Тестируем авто-взятие адреса и авто-разыменование.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Point struct{ X int }

func (p *Point) MoveX(dx int) { p.X += dx }
func (p Point) GetX() int     { return p.X }

func main() {
	// 1. Авто-взятие адреса (&p).MoveX(5):
	p := Point{X: 1}
	p.MoveX(5)
	fmt.Println("После MoveX:", p.GetX())

	// 2. Авто-разыменование (*pPtr).GetX():
	pPtr := &Point{X: 100}
	fmt.Println("GetX через указатель:", pPtr.GetX())
}
```

**`Терминал`**

```bash
go run main.go
# После MoveX: 6
# GetX через указатель: 100
```

## Под капотом

Компилятор анализирует тип переменной и сигнатуру метода в AST.

## Подводные камни

- Думать, что вызов GetX на указателе меняет копию.

## На собеседовании

**Вопрос с собеседования:** «Когда автоматическое взятие адреса невозможно?»
**Ответ:** Для неадресуемых выражений (литералы, возвращаемые значения функций, значения мап).
