# Композиция интерфейсов: объединение io.Reader, io.Writer и io.Closer в ReadWriteCloser

## Условие

Композиция интерфейсов: определите `ReadWriteCloser`, объединяющий `io.Reader`, `io.Writer`, `io.Closer`. Реализуйте в своей обёртке над файлом.

## Теория

Интерфейсная композиция формирует богатые абстракции из маленьких контрактов.

## Решение по шагам

1. Объявляем интерфейс ReadWriteCloser.
2. Создаем MockFileSession.
3. Реализуем Read, Write, Close.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
)

type ReadWriteCloser interface {
	io.Reader
	io.Writer
	io.Closer
}

type MockFileSession struct {
	closed bool
}

func (m *MockFileSession) Read(p []byte) (int, error)  { return 0, io.EOF }
func (m *MockFileSession) Write(p []byte) (int, error) { return len(p), nil }
func (m *MockFileSession) Close() error                 { m.closed = true; return nil }

func main() {
	var rwc ReadWriteCloser = &MockFileSession{}
	_, _ = rwc.Write([]byte("лог"))
	_ = rwc.Close()
	fmt.Println("Сессия закрыта успешно!")
}
```

**`Терминал`**

```bash
go run main.go
# Сессия закрыта успешно!
```

## На собеседовании

**Вопрос с собеседования:** «В чем польза композиции маленьких интерфейсов?»
**Ответ:** Соблюдение Interface Segregation Principle (ISP) — клиенты зависят только от тех методов, которые им реально нужны.
