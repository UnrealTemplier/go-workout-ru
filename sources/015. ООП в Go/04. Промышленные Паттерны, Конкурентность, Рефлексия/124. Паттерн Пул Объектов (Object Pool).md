# Паттерн Пул Объектов (Object Pool): ConnectionPool с ограничением соединений через буферизированный канал

## Условие

Паттерн Object Pool: структура ConnectionPool с методами Acquire() (*Connection, error), Release(*Connection). Инкапсуляция управления ресурсами с ограничением максимального количества соединений.

### Исходная формулировка

**Анти-паттерн "Большой интерфейс"**: Создай интерфейс `GodObject` с 10 методами. Затем разбей его на 5 маленьких интерфейсов по 1-2 метода (ISP - Interface Segregation Principle). Почувствуй разницу в удобстве мокирования.

## Теория

Инкапсуляция пула соединений через буферизированный канал `chan *Connection`.

## Решение по шагам

1. Создаем Connection{ID int}.
2. Создаем ConnectionPool{ pool chan *Connection }.
3. Реализуем Acquire и Release.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type Connection struct{ ID int }

type ConnectionPool struct {
	conns chan *Connection
}

func NewConnectionPool(size int) *ConnectionPool {
	cp := &ConnectionPool{conns: make(chan *Connection, size)}
	for i := 1; i <= size; i++ {
		cp.conns <- &Connection{ID: i}
	}
	return cp
}

func (cp *ConnectionPool) Acquire() (*Connection, error) {
	select {
	case conn := <-cp.conns:
		return conn, nil
	default:
		return nil, errors.New("пул исчерпан")
	}
}

func (cp *ConnectionPool) Release(conn *Connection) {
	cp.conns <- conn
}

func main() {
	pool := NewConnectionPool(2)
	c1, _ := pool.Acquire()
	fmt.Printf("Захвачено соединение #%d\n", c1.ID)
	pool.Release(c1)
	fmt.Println("Соединение успешно возвращено в пул!")
}
```

**`Терминал`**

```bash
go run main.go
# Захвачено соединение #1
# Соединение успешно возвращено в пул!
```

## Под капотом

Буферизированный канал реализует потокобезопасную очередь без дополнительных мьютексов.

## Подводные камни

- Забыть освободить соединение `defer pool.Release(conn)` (утечка соединений).

## На собеседовании

**Вопрос с собеседования:** «В чем отличие кастомного пула от `sync.Pool`?»
**Ответ:** `sync.Pool` предназначен только для кэширования памяти и может быть очищен GC в любой момент; кастомный пул на каналах гарантирует сохранение активных соединений.
