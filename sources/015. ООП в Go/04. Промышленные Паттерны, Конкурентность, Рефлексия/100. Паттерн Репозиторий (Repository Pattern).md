# Паттерн Репозиторий (Repository Pattern): абстракция хранения данных в InMemoryUserRepository

## Условие

Паттерн Репозиторий (Repository Pattern): интерфейс UserRepository с методами Create(u *User) error, FindByID(id int) (*User, error), Update(u *User) error, Delete(id int) error. Реализация InMemoryUserRepository с защитой мьютексом.

### Исходная формулировка

Реализуй **Observer** (Publisher-Subscriber): интерфейс `Observer` с методом `Update(event string)`. Структура `Subject` с методами `Subscribe`, `Unsubscribe`, `Notify`. Подпиши несколько наблюдателей и вызови `Notify`.

## Теория

Изоляция бизнес-логики от деталей персистентного хранения.

## Решение по шагам

1. Создаем User{ID int, Name string}.
2. Объявляем интерфейс UserRepository.
3. Реализуем InMemoryUserRepository с sync.RWMutex.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
	"sync"
)

type User struct {
	ID   int
	Name string
}

type UserRepository interface {
	Create(u *User) error
	FindByID(id int) (*User, error)
}

type InMemoryUserRepository struct {
	mu    sync.RWMutex
	users map[int]*User
}

func NewInMemoryUserRepository() *InMemoryUserRepository {
	return &InMemoryUserRepository{users: make(map[int]*User)}
}

func (r *InMemoryUserRepository) Create(u *User) error {
	m.mu.Lock()
	defer m.mu.Unlock()
	r.users[u.ID] = u
	return nil
}

func (r *InMemoryUserRepository) FindByID(id int) (*User, error) {
	m.mu.RLock()
	defer m.mu.RUnlock()
	u, ok := r.users[id]
	if !ok { return nil, errors.New("пользователь не найден") }
	return u, nil
}

func main() {
	var repo UserRepository = NewInMemoryUserRepository()
	_ = repo.Create(&User{ID: 1, Name: "Артем"})
	u, _ := repo.FindByID(1)
	fmt.Println("Найден пользователь:", u.Name)
}
```

**`Терминал`**

```bash
go run main.go
# Найден пользователь: Артем
```
