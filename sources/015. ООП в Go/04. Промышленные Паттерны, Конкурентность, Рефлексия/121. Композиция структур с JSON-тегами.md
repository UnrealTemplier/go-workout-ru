# Композиция структур с JSON-тегами: встраивание BaseModel в Product и User

## Условие

Композиция структур с тегами: структура BaseModel (ID uint, CreatedAt time.Time, UpdatedAt time.Time) с json-тегами. Встрой её в Product и User. Проверь сериализацию в JSON через json.Marshal.

### Исходная формулировка

Создайте структуру `EventEmitter` с методами `On(event string, callback func())` и `Emit(event string)`.

## Теория

JSON-маршалер автоматически считывает теги встроенных структур и сериализует их на верхнем уровне объекта.

## Решение по шагам

1. Создаем BaseModel с тегами `json:"id"` и `json:"created_at"`.
2. Создаем Product со встраиванием BaseModel.
3. Сериализуем через json.MarshalIndent.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"time"
)

type BaseModel struct {
	ID        uint      `json:"id"`
	CreatedAt time.Time `json:"created_at"`
}

type Product struct {
	BaseModel
	Title string  `json:"title"`
	Price float64 `json:"price"`
}

func main() {
	p := Product{
		BaseModel: BaseModel{ID: 42, CreatedAt: time.Date(2026, 9, 2, 12, 0, 0, 0, time.UTC)},
		Title:     "Go In Action Book",
		Price:     3500.50,
	}

	data, _ := json.MarshalIndent(p, "", "  ")
	fmt.Println(string(data))
}
```

**`Терминал`**

```bash
go run main.go
# {
#   "id": 42,
#   "created_at": "2026-09-02T12:00:00Z",
#   "title": "Go In Action Book",
#   "price": 3500.5
# }
```

## Под капотом

Пакет `encoding/json` производит слияние полей встроенных структур в единый JSON-объект.

## Подводные камни

- Добавление тега `json:"base"` к анонимному полю (тогда создастся вложенный JSON `{ "base": { ... } }`).

## На собеседовании

**Вопрос с собеседования:** «Как сделать так, чтобы встроенная структура создала вложенный JSON-объект?»
**Ответ:** Явно указать имя поля в теге `BaseModel BaseModel json:"base"` вместо анонимного встраивания.
