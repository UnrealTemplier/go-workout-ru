# Делегирование через встроенный интерфейс HTTPDoer: декоратор LoggedHTTPClient с замером времени

## Условие

Делегирование через embedded interface: структура LoggedHTTPClient встраивает интерфейс HTTPDoer (метод Do(req *http.Request) (*http.Response, error)). Добавь логирование времени выполнения запроса вокруг вызова Do.

### Исходная формулировка

Создай структуру с **собственным** полем `Name` и **встроенным** типом, тоже имеющим поле `Name`. Покажи **shadowing**: доступ к собственному `Name` через `.Name`, к встроенному — через `.EmbeddedType.Name`.

## Теория

Декоратор сетевого клиента замеряет длительность вызова вокруг встроенного интерфейса.

## Решение по шагам

1. Объявляем интерфейс HTTPDoer.
2. Создаем LoggedHTTPClient со встраиванием HTTPDoer.
3. Переопределяем метод Do с замером time.Since.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"time"
)

type HTTPDoer interface {
	Do(req *http.Request) (*http.Response, error)
}

type MockClient struct{}
func (MockClient) Do(req *http.Request) (*http.Response, error) {
	time.Sleep(20 * time.Millisecond)
	return &http.Response{StatusCode: 200}, nil
}

type LoggedHTTPClient struct {
	HTTPDoer
}

func (c *LoggedHTTPClient) Do(req *http.Request) (*http.Response, error) {
	start := time.Now()
	resp, err := c.HTTPDoer.Do(req)
	fmt.Printf("[HTTP LOG] %s %s -> %v (длительность: %v)\n", req.Method, req.URL, resp.StatusCode, time.Since(start))
	return resp, err
}

func main() {
	client := &LoggedHTTPClient{HTTPDoer: MockClient{}}
	req, _ := http.NewRequest("GET", "https://api.ozon.ru/ping", nil)
	_, _ = client.Do(req)
}
```

**`Терминал`**

```bash
go run main.go
# [HTTP LOG] GET https://api.ozon.ru/ping -> 200 (длительность: 20ms)
```

## Под капотом

Декоратор прозрачно оборачивает вызов Do без изменения вызывающего кода.

## Подводные камни

- Не закрывать тело ответа `resp.Body.Close()` при реальных сетевых вызовах.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать Retry и Circuit Breaker для HTTP-клиента в Go?»
**Ответ:** Обернуть `http.RoundTripper` или `HTTPDoer` в цепочку декораторов.
