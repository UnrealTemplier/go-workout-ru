# Паттерн Functional Options с валидацией: промышленная конфигурация ServerConfig

## Условие

Паттерн Functional Options: ServerConfig с WithHost, WithPort, WithMaxConnections, WithTLS(cert, key). Валидация в опциях (порт 1-65535, host не пустой). Конструктор возвращает (*Server, error).

### Исходная формулировка

**Принцип подстановки Барбары Лисков (LSP)**: Напишите программу, демонстрирующую соблюдение LSP. Создайте интерфейс `Bird` с методом `Fly()`. Попробуйте реализовать его для структуры `Ostrich` (страус). Объясните в комментариях, почему страус, возвращающий ошибку или панику в методе `Fly`, нарушает принцип LSP, и как правильно перепроектировать интерфейсы (например, разделить на `Bird` и `FlyingBird`).

## Теория

Паттерн Functional Options с возможностью возврата ошибки из опций.

## Решение по шагам

1. Объявляем type Option func(*Server) error.
2. Реализуем WithHost, WithPort с валидацией.
3. В NewServer применяем опции и возвращаем ошибку при сбое.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type Server struct {
	Host    string
	Port    int
	MaxConn int
}

type Option func(*Server) error

func WithHost(h string) Option {
	return func(s *Server) error {
		if h == "" { return errors.New("host не может быть пустым") }
		s.Host = h
		return nil
	}
}

func WithPort(p int) Option {
	return func(s *Server) error {
		if p < 1 || p > 65535 { return fmt.Errorf("неверный порт: %d", p) }
		s.Port = p
		return nil
	}
}

func NewServer(opts ...Option) (*Server, error) {
	srv := &Server{Host: "127.0.0.1", Port: 8080, MaxConn: 100}
	for _, opt := range opts {
		if err := opt(srv); err != nil {
			return nil, err
		}
	}
	return srv, nil
}

func main() {
	s, err := NewServer(WithHost("0.0.0.0"), WithPort(9000))
	if err != nil { panic(err) }
	fmt.Printf("Сервер успешно сконфигурирован: %s:%d\n", s.Host, s.Port)
}
```

**`Терминал`**

```bash
go run main.go
# Сервер успешно сконфигурирован: 0.0.0.0:9000
```

## Под капотом

Валидация выполняется до аллокации сетевых дескрипторов.

## Подводные камни

- Игнорирование ошибки от opt(srv).

## На собеседовании

**Вопрос с собеседования:** «Как поддержать откат настроек при ошибке в середине списка Functional Options?»
**Ответ:** Применять опции к временной копии конфигурации и переносить в целевую структуру только после успешного выполнения всех опций.
