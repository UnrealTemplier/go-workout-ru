# Рефлексия и ООП: инспекция полей и методов структуры с помощью StructInfo(v any)

## Условие

Рефлексия и ООП: функция StructInfo(v any), выводящая список методов типа, список полей (включая вложенные) и их типы. Покажи, как рефлексия видит ООП-структуры в рантайме.

### Исходная формулировка

**Паттерн Functional Options (Функциональные опции - золотой стандарт Go)**: Перепиши упр. 232 по-гошному. Создай тип `type ServerOption func(*ServerConfig)`. Напиши функции `WithHost(h string) ServerOption`. Конструктор должен выглядеть так: `NewServer(opts ...ServerOption) *ServerConfig`. Внутри конструктора примени все опции в цикле `for _, opt := range opts { opt(cfg) }`.

## Теория

Пакет reflect позволяет исследовать структуры, методы и интерфейсы во время выполнения программы.

## Решение по шагам

1. Пишем функцию StructInfo(v any).
2. Извлекаем reflect.TypeOf(v).
3. Итерируемся по NumField() и NumMethod().

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"reflect"
)

type Device struct {
	Model string
	Price float64
}

func (d Device) Info() string { return d.Model }
func (d Device) Discount()    {}

func StructInfo(v any) {
	t := reflect.TypeOf(v)
	fmt.Println("=== Тип:", t.Name(), "===")
	fmt.Println("Поля:")
	for i := 0; i < t.NumField(); i++ {
		f := t.Field(i)
		fmt.Printf("  - %-8s : %s\n", f.Name, f.Type)
	}
	fmt.Println("Методы:")
	for i := 0; i < t.NumMethod(); i++ {
		m := t.Method(i)
		fmt.Printf("  - %s()\n", m.Name)
	}
}

func main() {
	StructInfo(Device{Model: "MacBook M3", Price: 200000})
}
```

**`Терминал`**

```bash
go run main.go
# === Тип: Device ===
# Поля:
#   - Model    : string
#   - Price    : float64
# Методы:
#   - Discount()
#   - Info()
```

## Под капотом

Рефлексия считывает заголовки типов из секции .rodata бинарника.

## Подводные камни

- Передача не структуры в StructInfo (NumField() упадет в панику, если Kind != Struct).

## На собеседовании

**Вопрос с собеседования:** «Почему reflect.TypeOf видит только публичные методы?»
**Ответ:** Для безопасности и оптимизации: неэкспортируемые методы не включаются в таблицу методов структуры, если на них нет явных ссылок.
