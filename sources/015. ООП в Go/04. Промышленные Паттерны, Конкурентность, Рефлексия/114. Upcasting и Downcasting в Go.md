# Upcasting и Downcasting в Go: неявная упаковка в интерфейс и безопасный Type Assertion

## Условие

Upcast / Downcast в Go: покажи, как интерфейс Animal приводится к конкретному типу *Dog через type assertion (d, ok := a.(*Dog)), и как конкретный тип упаковывается в интерфейс (upcast — неявный, downcast — явный через type assertion / type switch).

### Исходная формулировка

**Внедрение зависимостей (Dependency Injection)**: Создайте структуру `UserService`, которая для работы требует доступ к базе данных. Вместо конкретной структуры базы данных добавьте в `UserService` поле типа-интерфейса `DatabaseReader` (с методом `GetUserByID`). Напишите тест или демонстрационный код, куда передается "моковая" (mock) реализация интерфейса базы данных.

## Теория

Upcast происходит автоматически при присваивании; Downcast требует проверки через форму с запятой (comma-ok idiom).

## Решение по шагам

1. Объявляем Animal{ Sound() string }.
2. Реализуем Dog{ Breed string }.
3. Упаковываем Dog в Animal (Upcast).
4. Распаковываем через d, ok := a.(*Dog) (Downcast).

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Animal interface { Sound() string }

type Dog struct{ Breed string }
func (d *Dog) Sound() string { return "Гав!" }

func main() {
	dog := &Dog{Breed: "Корги"}

	// 1. Upcast (неявный):
	var a Animal = dog
	fmt.Println("Звук:", a.Sound())

	// 2. Downcast (явный через type assertion comma-ok):
	if realDog, ok := a.(*Dog); ok {
		fmt.Printf("Успешный downcast: порода %s\n", realDog.Breed)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Звук: Гав!
# Успешный downcast: порода Корги
```

## Под капотом

Type Assertion сравнивает указатель `_type` внутри `iface` с типом `*Dog`.

## Подводные камни

- Использование одиночного утверждения `a.(*Dog)` без `ok` (вызовет панику в рантайме при несовпадении типов).

## На собеседовании

**Вопрос с собеседования:** «В чем отличие type assertion от type conversion?»
**Ответ:** Type conversion (`float64(i)`) меняет представление значения в памяти; Type assertion (`i.(string)`) лишь проверяет и извлекает динамический тип из интерфейса.
