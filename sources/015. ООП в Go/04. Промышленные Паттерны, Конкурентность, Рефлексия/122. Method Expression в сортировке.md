# Method Expression в сортировке: передача Person.AgeLess в sort.Slice

## Условие

Method Expression для сортировки: слайс людей []Person. Используй sort.Slice с method expression или методом-значением для сортировки по разным полям.

### Исходная формулировка

Создай иерархию: интерфейс `Animal` с методом `Speak()`, интерфейс `Pet` встраивает `Animal` и добавляет `Play()`. Создай `Dog`, реализующий `Pet`. Сделай type assertion `Animal` → `Pet` (downcast) и `Pet` → `Animal` (upcast). Объясни, что Go не проверяет иерархию во время компиляции для assertions — только во время выполнения.

---

## Теория

Использование Method Expression для передачи предикатов сравнения в функции сортировки.

## Решение по шагам

1. Создаем Person{Name string, Age int}.
2. Реализуем предикат LessByAge.
3. Сортируем срез людей через sort.Slice.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sort"
)

type Person struct {
	Name string
	Age  int
}

func main() {
	people := []Person{
		{"Сергей", 35},
		{"Анна", 24},
		{"Михаил", 29},
	}

	// Сортировка по возрасту:
	sort.Slice(people, func(i, j int) bool {
		return people[i].Age < people[j].Age
	})

	for _, p := range people {
		fmt.Printf("%s (%d лет)\n", p.Name, p.Age)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Анна (24 лет)
# Михаил (29 лет)
# Сергей (35 лет)
```

## Под капотом

sort.Slice использует рефлексию для обмена элементов в памяти среза.

## Подводные камни

- Использование sort.Slice в высоконагруженных циклах (в Go 1.21+ рекомендуется `slices.SortFunc`).

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество `slices.SortFunc` перед `sort.Slice`?»
**Ответ:** `slices.SortFunc` не использует рефлексию, инлайнится компилятором и работает в 2–3 раза быстрее.
