# Паттерн Event Emitter: потокобезопасная шина событий с методами On, Emit, Off

## Условие

Паттерн Event Emitter: структура EventEmitter с методами On(event string, handler func(data any)), Emit(event string, data any), Off(event string). Поддержка нескольких обработчиков на одно событие.

### Исходная формулировка

**Паттерн "Одиночка" (Singleton)**: Создайте пакет с приватной структурой и публичной функцией `GetInstance()`, используя `sync.Once` для потокобезопасной ленивой инициализации.

## Теория

Асинхронная или синхронная шина событий для слабой связанности микросервисных компонентов.

## Решение по шагам

1. Создаем EventEmitter{ handlers map[string][]func(any) }.
2. Реализуем On, Emit, Off с sync.RWMutex.
3. Тестируем отправку события нескольким подписчикам.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

type EventEmitter struct {
	mu       sync.RWMutex
	handlers map[string][]func(data any)
}

func NewEventEmitter() *EventEmitter {
	return &EventEmitter{handlers: make(map[string][]func(any))}
}

func (e *EventEmitter) On(event string, fn func(any)) {
	e.mu.Lock()
	defer e.mu.Unlock()
	e.handlers[event] = append(e.handlers[event], fn)
}

func (e *EventEmitter) Emit(event string, data any) {
	e.mu.RLock()
	defer e.mu.RUnlock()
	for _, fn := range e.handlers[event] {
		fn(data)
	}
}

func main() {
	emitter := NewEventEmitter()

	emitter.On("order_created", func(d any) { fmt.Println("📧 Email сервис: заказ", d) })
	emitter.On("order_created", func(d any) { fmt.Println("📦 Склад: зарезервирован товар для заказа", d) })

	emitter.Emit("order_created", 1045)
}
```

**`Терминал`**

```bash
go run main.go
# 📧 Email сервис: заказ 1045
# 📦 Склад: зарезервирован товар для заказа 1045
```

## Под капотом

Мапа со срезом функций-обработчиков защищена RWMutex.

## Подводные камни

- Паника внутри обработчика, ломающая вызов последующих подписчиков (нужен recover).

## На собеседовании

**Вопрос с собеседования:** «Как изолировать обработчики в Event Emitter от взаимного влияния?»
**Ответ:** Запускать каждый обработчик в отдельной горутине `go func() { defer recover(); fn(data) }()`.
