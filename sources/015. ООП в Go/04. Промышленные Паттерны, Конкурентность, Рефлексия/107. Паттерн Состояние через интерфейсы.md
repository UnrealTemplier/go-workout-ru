# Паттерн Состояние через интерфейсы: конечный автомат светофора TrafficLight (Red -> Green -> Yellow)

## Условие

State pattern через интерфейсы: структура TrafficLight с интерфейсом TrafficLightState. Состояния RedState, YellowState, GreenState. Метод Next() переключает состояние и возвращает текущий цвет.

### Исходная формулировка

**Паттерн Strategy**: Напиши структуру `Sorter` с полем `strategy func([]int)`. Напиши методы для сортировки пузырьком и быстрой сортировки, меняй стратегию на лету в `main`.

## Теория

Полиморфная реализация состояний: каждое состояние инкапсулирует правило перехода к следующему состоянию.

## Решение по шагам

1. Объявляем State{ Next() State; Color() string }.
2. Реализуем RedState, GreenState, YellowState.
3. Создаем TrafficLight{ current State } и тестируем переключение.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type LightState interface {
	Next() LightState
	Color() string
}

type RedState struct{}
func (RedState) Next() LightState { return GreenState{} }
func (RedState) Color() string    { return "КРАСНЫЙ" }

type GreenState struct{}
func (GreenState) Next() LightState { return YellowState{} }
func (GreenState) Color() string    { return "ЗЕЛЕНЫЙ" }

type YellowState struct{}
func (YellowState) Next() LightState { return RedState{} }
func (YellowState) Color() string    { return "ЖЕЛТЫЙ" }

type TrafficLight struct{ state LightState }

func (tl *TrafficLight) Next() {
	tl.state = tl.state.Next()
	fmt.Printf("🚦 Светофор переключился на: %s\n", tl.state.Color())
}

func main() {
	tl := &TrafficLight{state: RedState{}}
	tl.Next() // Зеленый
	tl.Next() // Желтый
	tl.Next() // Красный
}
```

**`Терминал`**

```bash
go run main.go
# 🚦 Светофор переключился на: ЗЕЛЕНЫЙ
# 🚦 Светофор переключился на: ЖЕЛТЫЙ
# 🚦 Светофор переключился на: КРАСНЫЙ
```

## На собеседовании

**Вопрос с собеседования:** «Когда State pattern лучше классического switch-case?»
**Ответ:** Когда количество состояний велико, логика каждого состояния сложна, и нужно добавлять новые состояния без изменения существующего кода.
