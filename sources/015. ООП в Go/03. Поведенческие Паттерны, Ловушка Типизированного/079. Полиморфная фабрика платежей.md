# Полиморфная фабрика платежей: функция GetPaymentMethod и интерфейс PaymentMethod

## Условие

Фабрика с полиморфизмом: GetPaymentMethod(mtype string) (PaymentMethod, error), где PaymentMethod — интерфейс с методом Pay(amount float64) error. Реализации: CardPayment, CryptoPayment. Вызов оплаты через интерфейс.

### Исходная формулировка

Попробуйте инициализировать `AdminUser` через литерал структуры, учитывая синтаксис вложенности встроенных структур.

## Теория

Фабрика возвращает интерфейс, скрывая конкретные структуры за полиморфным контрактом.

## Решение по шагам

1. Создаем интерфейс PaymentMethod{ Pay(float64) error }.
2. Реализуем CardPayment и CryptoPayment.
3. Пишем фабрику GetPaymentMethod.
4. Вызываем оплату.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

type PaymentMethod interface {
	Pay(amount float64) error
}

type CardPayment struct{}
func (CardPayment) Pay(amt float64) error {
	fmt.Printf("Списание %.2f руб. с банковской карты\n", amt)
	return nil
}

type CryptoPayment struct{}
func (CryptoPayment) Pay(amt float64) error {
	fmt.Printf("Транзакция %.2f USDT отправлена в блокчейн\n", amt)
	return nil
}

func GetPaymentMethod(mType string) (PaymentMethod, error) {
	switch mType {
	case "card":
		return CardPayment{}, nil
	case "crypto":
		return CryptoPayment{}, nil
	default:
		return nil, fmt.Errorf("неизвестный метод оплаты: %s", mType)
	}
}

func main() {
	method, _ := GetPaymentMethod("crypto")
	_ = method.Pay(150.0)
}
```

**`Терминал`**

```bash
go run main.go
# Транзакция 150.00 USDT отправлена в блокчейн
```
