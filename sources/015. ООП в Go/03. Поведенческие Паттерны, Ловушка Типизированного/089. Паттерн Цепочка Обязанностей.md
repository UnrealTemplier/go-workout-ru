# Паттерн Цепочка Обязанностей (Chain of Responsibility): последовательная обработка запроса

## Условие

Паттерн Chain of Responsibility: интерфейс Handler с методами SetNext(Handler) Handler и Handle(req *Request) error. Реализуй цепочку: AuthHandler -> RateLimitHandler -> BusinessHandler.

### Исходная формулировка

Напишите функцию `PrintShapeInfo(s Shape)`, которая принимает интерфейс и выводит площадь. Передайте туда разные структуры, чтобы увидеть полиморфизм в действии.

## Теория

Паттерн позволяет передавать запрос по цепочке потенциальных обработчиков.

## Решение по шагам

1. Объявляем интерфейс Handler.
2. Реализуем AuthHandler, RateLimitHandler, BusinessHandler.
3. Связываем через SetNext и запускаем запрос.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Request struct {
	User  string
	Limit int
}

type Handler interface {
	SetNext(Handler) Handler
	Handle(*Request) error
}

type BaseHandler struct {
	next Handler
}

func (b *BaseHandler) SetNext(h Handler) Handler { b.next = h; return h }

type AuthHandler struct{ BaseHandler }
func (a *AuthHandler) Handle(r *Request) error {
	if r.User == "" { return fmt.Errorf("ошибка авторизации") }
	fmt.Println("✅ Авторизация пройдена")
	if a.next != nil { return a.next.Handle(r) }
	return nil
}

type BusinessHandler struct{ BaseHandler }
func (b *BusinessHandler) Handle(r *Request) error {
	fmt.Println("🚀 Бизнес-логика выполнена для", r.User)
	return nil
}

func main() {
	auth := &AuthHandler{}
	biz := &BusinessHandler{}
	auth.SetNext(biz)

	_ = auth.Handle(&Request{User: "Дмитрий"})
}
```

**`Терминал`**

```bash
go run main.go
# ✅ Авторизация пройдена
# 🚀 Бизнес-логика выполнена для Дмитрий
```

## Под капотом

Запросы последовательно обходят связный список обработчиков.

## Подводные камни

- Бесконечный цикл при циклической ссылке в SetNext.

## На собеседовании

**Вопрос с собеседования:** «Где паттерн Chain of Responsibility применяется в веб-серверах?»
**Ответ:** В цепочках HTTP-фильтров, перехватчиках gRPC Interceptors и конвейерах обработки сообщений.
