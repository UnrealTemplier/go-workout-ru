# Встраивание Animal в Dog: продвижение метода Breathe() и собственный метод Bark()

## Условие

Встраивание: Animal (Breathe()), Dog встраивает Animal и добавляет Bark(). Создайте экземпляр Dog и вызовите dog.Breathe() и dog.Bark().

### Исходная формулировка

**Композиция (Встраивание)**: Создайте структуру `Animal` с методом `Breathe()`. Создайте структуру `Dog`, которая *встраивает* `Animal`. Вызовите `dog.Breathe()`.

## Теория

Композиция поведения: базовая функциональность наследуется через встраивание, а доменная добавляется напрямую.

## Решение по шагам

1. Создаем Animal с методом Breathe().
2. Создаем Dog со встраиванием Animal и методом Bark().
3. Вызываем оба метода.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Animal struct{ Species string }
func (a Animal) Breathe() { fmt.Printf("[%s] Дышит кислородом\n", a.Species) }

type Dog struct {
	Animal
	Breed string
}
func (d Dog) Bark() { fmt.Printf("[%s] Гав-гав!\n", d.Breed) }

func main() {
	d := Dog{Animal: Animal{Species: "Млекопитающее"}, Breed: "Хаски"}
	d.Breathe() // Promoted method
	d.Bark()
}
```

**`Терминал`**

```bash
go run main.go
# [Млекопитающее] Дышит кислородом
# [Хаски] Гав-гав!
```

## Под капотом

Компилятор генерирует прямое обращение d.Animal.Breathe().

## Подводные камни

- Думать, что Animal может вызвать Bark().

## На собеседовании

**Ответ:** Нет, встроенная структура изолирована и ничего не знает о типе, в который она встроена.
