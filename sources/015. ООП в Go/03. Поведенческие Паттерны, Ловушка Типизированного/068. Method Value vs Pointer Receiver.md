# Method Value vs Pointer Receiver: поведение замыкания f := myGreeter.Greet при изменении объекта

## Условие

Method value: type Greeter struct { Name string }, метод Greet(). Создай f := myGreeter.Greet, вызови f(). Измени myGreeter.Name. Вызови f() снова. Объясни разницу между value receiver и pointer receiver в этом сценарии.

### Исходная формулировка

**Method Values (Значения методов)**: Создай структуру `Greeter{Name string}` с методом `Greet()`. Присвой метод переменной: `f := myGreeter.Greet` (без скобок!). Вызови `f()`. Заметь, что состояние (значение полей структуры) "захватилось" в эту переменную.

## Теория

Method Value копирует значение объекта при Value Receiver, но сохраняет ссылку при Pointer Receiver.

## Решение по шагам

1. Создаем GreeterValue и GreeterPtr.
2. Создаем замыкания fnVal и fnPtr.
3. Меняем Name и сравниваем повторные вызовы.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type GreeterVal struct{ Name string }
func (g GreeterVal) Greet() { fmt.Println("Val:", g.Name) }

type GreeterPtr struct{ Name string }
func (g *GreeterPtr) Greet() { fmt.Println("Ptr:", g.Name) }

func main() {
	gv := GreeterVal{Name: "Алиса"}
	fnVal := gv.Greet
	gv.Name = "Боб"
	fnVal() // Напечатает 'Алиса' (копия!)

	gp := &GreeterPtr{Name: "Алиса"}
	fnPtr := gp.Greet
	gp.Name = "Боб"
	fnPtr() // Напечатает 'Боб' (указатель!)
}
```

**`Терминал`**

```bash
go run main.go
# Val: Алиса
# Ptr: Боб
```

## Под капотом

При Value Receiver замыкание захватывает копию данных; при Pointer Receiver — адрес памяти.

## Подводные камни

- Ожидание актуального состояния от Value Receiver замыкания.
