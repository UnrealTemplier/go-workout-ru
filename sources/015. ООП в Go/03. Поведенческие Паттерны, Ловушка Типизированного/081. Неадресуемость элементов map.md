# Неадресуемость элементов map: почему m["a"].ChangeName() не работает и решение через map[string]*User

## Условие

Неадресуемость элементов map: создай map[string]User. Попробуй вызвать m["a"].ChangeName("Bob") (где ChangeName — pointer receiver). Получи ошибку компиляции. Объясни, почему элементы map неадресуемы (эвакуация бакетов). Исправь, используя map[string]*User.

### Исходная формулировка

**Полиморфная фабрика**: Создайте интерфейс `PaymentMethod` с методом `Pay(amount float64)`. Реализуйте его для структур `CreditCard` и `PayPal`. Напишите функцию-фабрику `GetPaymentMethod(methodType string) PaymentMethod`. Продемонстрируйте полиморфизм, обрабатывая платежи без знания конкретной реализации платежной системы.

## Теория

Элементы map не имеют фиксированного адреса в памяти, так как при расширении хэш-таблицы бакеты перемещаются. Решение — хранить в карте указатели map[string]*User.

## Решение по шагам

1. Создаем User{Name string} с методом (u *User) ChangeName(n string).
2. Показываем ошибку m["a"].ChangeName("Bob").
3. Исправляем на map[string]*User.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type User struct{ Name string }
func (u *User) ChangeName(newName string) { u.Name = newName }

func main() {
	// 1. Ошибка на map со значениями: map[string]User
	// m := map[string]User{"u1": {"Алиса"}}
	// m["u1"].ChangeName("Боб") // ❌ cannot call pointer method ChangeName on User

	// 2. Исправление через map с указателями: map[string]*User
	users := map[string]*User{
		"u1": &User{Name: "Алиса"},
	}

	users["u1"].ChangeName("Боб") // ✅ Успех!
	fmt.Println("Новое имя пользователя:", users["u1"].Name)
}
```

**`Терминал`**

```bash
go run main.go
# Новое имя пользователя: Боб
```

## Под капотом

Указатель `*User` указывает на постоянный адрес в куче, не зависящий от реорганизации бакетов мапы `hmap`.

## Подводные камни

- Попытка изменить поле структуры в map[string]Struct через прямое присваивание `m["key"].Field = val`.

## На собеседовании

**Вопрос с собеседования:** «Почему компилятор Go запрещает брать адрес элемента мапы `&m["key"]`?»
**Ответ:** Потому что при добавлении новых ключей мапа производит рехэширование (эвакуацию бакетов), и адрес старого слота становится инвалидным, что привело бы к висячим указателям (Dangling Pointers).
