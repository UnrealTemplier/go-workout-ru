# Глубокое клонирование (Deep Copy): метод Clone() для структур со срезами и указателями

## Условие

Метод Clone(): структура Profile (Name string, Tags []string, Meta *Metadata). Метод Clone() *Profile создаёт глубокую копию (deep copy) — модификация срезов и указателей в клоне не влияет на оригинал.

### Исходная формулировка

Приватный метод в интерфейсе? Попробуйте через интерфейс вызвать неэкспортируемый метод из другого пакета — объясните, почему нельзя.

## Теория

Поверхностное копирование (Shallow Copy) копирует указатели на те же срезы; Deep Copy выделяет независимую память.

## Решение по шагам

1. Создаем Profile{Name, Tags []string, Meta *Metadata}.
2. Реализуем Clone() с созданием копий среза и указателя.
3. Проверяем независимость мутаций.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Metadata struct{ Score int }

type Profile struct {
	Name string
	Tags []string
	Meta *Metadata
}

func (p *Profile) Clone() *Profile {
	if p == nil { return nil }
	
	// 1. Копируем срез тегов:
	tagsCopy := make([]string, len(p.Tags))
	copy(tagsCopy, p.Tags)

	// 2. Копируем структуру метаданных:
	var metaCopy *Metadata
	if p.Meta != nil {
		metaCopy = &Metadata{Score: p.Meta.Score}
	}

	return &Profile{Name: p.Name, Tags: tagsCopy, Meta: metaCopy}
}

func main() {
	p1 := &Profile{Name: "Илья", Tags: []string{"go", "k8s"}, Meta: &Metadata{Score: 100}}
	p2 := p1.Clone()

	p2.Tags[0] = "python"
	p2.Meta.Score = 50

	fmt.Println("Оригинал p1:", p1.Tags, p1.Meta.Score)
	fmt.Println("Клон     p2:", p2.Tags, p2.Meta.Score)
}
```

**`Терминал`**

```bash
go run main.go
# Оригинал p1: [go k8s] 100
# Клон     p2: [python k8s] 50
```
