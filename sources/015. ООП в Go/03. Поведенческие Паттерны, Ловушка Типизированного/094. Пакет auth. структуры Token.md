# Пакет auth: структуры Token и Session с инкапсуляцией времени жизни и валидации

## Условие

Пакет auth: структуры Token (значение, expiresAt) и Session (userID, token). Методы IsExpired() bool, IsValid() bool. Инкапсулируй проверку времени жизни токена.

### Исходная формулировка

Создайте слайс интерфейсов `[]Shape` и заполните его разными фигурами. Пройдитесь по нему циклом и вычислите общую площадь всех фигур.

## Теория

Инкапсуляция валидации токенов авторизации внутри доменного метода.

## Решение по шагам

1. Создаем Token{Value, ExpiresAt time.Time}.
2. Создаем Session{UserID, Token}.
3. Реализуем IsExpired() и IsValid().

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

type Token struct {
	Value     string
	ExpiresAt time.Time
}

func (t Token) IsExpired() bool {
	return time.Now().After(t.ExpiresAt)
}

type Session struct {
	UserID int
	Token  Token
}

func (s Session) IsValid() bool {
	return s.UserID > 0 && !s.Token.IsExpired()
}

func main() {
	sess := Session{
		UserID: 42,
		Token: Token{
			Value:     "jwt_secure_token",
			ExpiresAt: time.Now().Add(1 * time.Hour),
		},
	}
	fmt.Println("Сессия активна?", sess.IsValid())
}
```

**`Терминал`**

```bash
go run main.go
# Сессия активна? true
```

## Под капотом

Сравнение времени через time.Now().After().

## Подводные камни

- Игнорирование часовых поясов при сравнении времени.

## На собеседовании

**Вопрос с собеседования:** «Как тестировать методы, зависящие от `time.Now()`?»
**Ответ:** Инжектировать интерфейс часов `Clock { Now() time.Time }` или передавать текущее время аргументом.
