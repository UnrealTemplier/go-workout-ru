# Метод-выражение (Method Expression): явная передача получателя f := Greeter.Greet(g)

## Условие

Метод-выражение (Method Expression): type Greeter struct { Name string }, метод Greet(). Создай f := Greeter.Greet (выражение метода, где тип — func(Greeter)). Вызови f(myGreeter). Объясни, чем method expression отличается от method value.

### Исходная формулировка

**Паттерн "Стратегия" (Strategy)**: Создайте структуру `TextProcessor` с полем `formatter Formatter` (интерфейс с методом `Format(string) string`). Реализуйте две стратегии форматирования: `JSONFormatter` и `PlainTextFormatter`. Напишите метод `Process(text string)` в `TextProcessor`, который использует текущую стратегию. Продемонстрируйте динамическую смену стратегии во время работы программы.

## Теория

Method Expression Greeter.Greet превращает метод в обычную функцию func(Greeter), требующую явной передачи получателя первым аргументом.

## Решение по шагам

1. Создаем Greeter{Name string}.
2. Получаем Method Expression fn := Greeter.Greet.
3. Вызываем fn(Greeter{"Мария"}).

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Greeter struct{ Name string }

func (g Greeter) Greet(greeting string) {
	fmt.Printf("%s, %s!\n", greeting, g.Name)
}

func main() {
	// Method Expression: тип func(Greeter, string)
	fn := Greeter.Greet

	g1 := Greeter{Name: "Мария"}
	g2 := Greeter{Name: "Иван"}

	fn(g1, "Привет")
	fn(g2, "Добрый день")
}
```

**`Терминал`**

```bash
go run main.go
# Привет, Мария!
# Добрый день, Иван!
```

## Под капотом

Компилятор раскрывает синтаксис в вызов функции main.Greeter.Greet(g1, "Привет").

## Подводные камни

- Путаница между Method Expression (от типа: Type.Method) и Method Value (от экземпляра: instance.Method).
