# Инициализация вложенных структур: фабричный конструктор NewCar(model, engine)

## Условие

Инициализация вложенных структур: Car содержит Engine (структура). Напиши конструктор NewCar(model string, hp int) Car, который корректно инициализирует и внешнюю, и внутреннюю структуру.

### Исходная формулировка

Реализуй **Strategy pattern**: интерфейс `Sorter` с методом `Sort([]int) []int`. Реализации: `BubbleSorter`, `QuickSorter`, `NativeSorter` (использует `sort.Ints`). Функция `SortData(data []int, strategy Sorter) []int` принимает стратегию как аргумент.

## Теория

Явная инициализация всех уровней композиции в конструкторе.

## Решение по шагам

1. Создаем Engine{HP int}.
2. Создаем Car{Model string, Engine Engine}.
3. Пишем NewCar.
4. Тестируем.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Engine struct{ HorsePower int }

type Car struct {
	Model  string
	Engine Engine
}

func NewCar(model string, hp int) Car {
	return Car{
		Model:  model,
		Engine: Engine{HorsePower: hp},
	}
}

func main() {
	c := NewCar("BMW M5", 600)
	fmt.Printf("Авто: %s, Мощность: %d л.с.\n", c.Model, c.Engine.HorsePower)
}
```

**`Терминал`**

```bash
go run main.go
# Авто: BMW M5, Мощность: 600 л.с.
```

## Под капотом

Конструктор собирает структуру в единый непрерывный блок памяти.

## Подводные камни

- Оставлять поля Engine неинициализированными (нулевыми).

## На собеседовании

**Вопрос с собеседования:** «Что возвращать из конструктора: значение `Car` или указатель `*Car`?»
**Ответ:** Значение `Car`, если структура маленькая и не содержит мьютексов; указатель `*Car`, если структура крупная, содержит мьютексы или требует мутации через методы.
