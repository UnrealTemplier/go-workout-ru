# Паттерн Адаптер (Adapter Pattern): адаптация LegacyPrinter к интерфейсу ModernPrinter

## Условие

Паттерн «Адаптер» (Adapter): есть устаревший LegacyPrinter (метод PrintOld(text string)). Новый код ожидает интерфейс ModernPrinter (метод PrintFormatted(header, body string)). Напиши адаптер PrinterAdapter.

### Исходная формулировка

**[Каверзный кейс]**: Создай мапу `m := map[string]User{}` (где `User` — структура). Попробуй вызвать метод с pointer receiver у элемента мапы `m["a"].ChangeName("Bob")`. Поймай ошибку компиляции (элементы мапы не адресуемы). Объясни, почему так, и найди решение (например, хранить в мапе указатели `map[string]*User`).

## Теория

Адаптер преобразует интерфейс одного класса в интерфейс, ожидаемый клиентами.

## Решение по шагам

1. Создаем LegacyPrinter{ PrintOld(string) }.
2. Объявляем интерфейс ModernPrinter.
3. Создаем PrinterAdapter со встраиванием LegacyPrinter.
4. Реализуем PrintFormatted.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type LegacyPrinter struct{}

func (LegacyPrinter) PrintOld(text string) {
	fmt.Println("=== LEGACY PRINT ===\n" + text)
}

type ModernPrinter interface {
	PrintFormatted(header, body string)
}

type PrinterAdapter struct {
	legacy LegacyPrinter
}

func (a PrinterAdapter) PrintFormatted(header, body string) {
	formatted := fmt.Sprintf("[%s]\n%s", header, body)
	a.legacy.PrintOld(formatted)
}

func main() {
	var p ModernPrinter = PrinterAdapter{legacy: LegacyPrinter{}}
	p.PrintFormatted("Отчет", "Все системы работают стабильно")
}
```

**`Терминал`**

```bash
go run main.go
# === LEGACY PRINT ===
# [Отчет]
# Все системы работают стабильно
```

## Под капотом

Адаптер инкапсулирует вызов устаревшего API внутри нового контракта.

## Подводные камни

- Прямая модификация устаревшего кода вместо написания адаптера.

## На собеседовании

**Вопрос с собеседования:** «Когда в Go необходим паттерн Адаптер?»
**Ответ:** При интеграции внешних SDK или при постепенном рефакторинге легаси систем.
