# Встраивание неэкспортируемой структуры: Car встраивает engine, видимость методов снаружи

## Условие

Встраивание неэкспортируемой структуры: пакет vehicle содержит приватную структуру engine с публичным методом Start(). Экспортируемая структура Car встраивает engine. Покажи, что метод Start доступен снаружи пакета, хотя сам тип engine невидим.

### Исходная формулировка

**Паттерн Builder (Строитель)**: Создай структуру `ServerConfig` (host, port, timeout, maxConns). Напиши "текучий интерфейс" (fluent interface) для её сборки: методы `WithHost(h string)`, `WithPort(p int)` и т.д., возвращающие указатель на самого себя (`*ServerConfig`). В конце вызови `b.WithHost("...").WithPort(80).Build()`.

## Теория

Методы встроенного приватного типа всплывают наружу, если они экспортированы (начинаются с заглавной буквы).

## Решение по шагам

1. Моделируем приватный тип internalEngine с методом Start().
2. Экспортируем Car со встраиванием internalEngine.
3. Вызываем car.Start() из main.

## Код решения

**`main.go`**

```go
package main

import "fmt"

// Имитация пакета vehicle:
type internalEngine struct{}

// Метод Start() экспортируемый (с заглавной буквы)!
func (internalEngine) Start() {
	fmt.Println("🚀 Двигатель запущен через promoted метод!")
}

type Car struct {
	internalEngine // Приватное встраивание
	Model          string
}

func main() {
	c := Car{Model: "Tesla"}

	// Снаружи пакета метод Start() доступен напрямую:
	c.Start()

	// Но обратиться к c.internalEngine напрямую нельзя (оно неэкспортировано)!
}
```

**`Терминал`**

```bash
go run main.go
# 🚀 Двигатель запущен через promoted метод!
```

## Под капотом

Компилятор экспортирует метод Start в таблице символов структуры Car.

## Подводные камни

- Попытка объявить метод неэкспортируемым `start()` в надежде, что он станет публичным.

## На собеседовании

**Вопрос с собеседования:** «Зачем встраивать приватные структуры с публичными методами?»
**Ответ:** Чтобы скрыть внутреннюю реализацию и имя типа, но предоставить готовый интерфейс (например, `sync.Mutex.Lock()`).
