# Паттерн Functional Options: гибкая конфигурация Server через WithPort и WithTimeout

## Условие

Паттерн Functional Options: структура Server (host, port, timeout, maxConns). Конструктор NewServer(opts ...Option) с дефолтными значениями. Опции WithPort(p int), WithTimeout(d time.Duration). Создайте сервер с кастомным портом и таймаутом.

### Исходная формулировка

Переопределите (shadow) встроенный метод: добавьте метод `Breathe()` в `Dog`, который переопределяет метод `Animal`. Как явно вызвать оригинальный `Animal.Breathe()` через объект `Dog`?

## Теория

Золотой стандарт конфигурации в экосистеме Go (Rob Pike / Dave Cheney).

## Решение по шагам

1. Создаем Server с приватными полями.
2. Объявляем type Option func(*Server).
3. Реализуем WithPort, WithTimeout.
4. Пишем NewServer с дефолтными значениями.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

type Server struct {
	Host    string
	Port    int
	Timeout time.Duration
}

type Option func(*Server)

func WithPort(port int) Option {
	return func(s *Server) { s.Port = port }
}

func WithTimeout(d time.Duration) Option {
	return func(s *Server) { s.Timeout = d }
}

func NewServer(opts ...Option) *Server {
	srv := &Server{Host: "0.0.0.0", Port: 8080, Timeout: 30 * time.Second}
	for _, opt := range opts {
		opt(srv)
	}
	return srv
}

func main() {
	s := NewServer(WithPort(9090), WithTimeout(5*time.Second))
	fmt.Printf("Сервер: %s:%d (Таймаут: %v)\n", s.Host, s.Port, s.Timeout)
}
```

**`Терминал`**

```bash
go run main.go
# Сервер: 0.0.0.0:9090 (Таймаут: 5s)
```

## Под капотом

Замыкания применяются последовательно к структуре сервера.

## Подводные камни

- Передача nil опции в NewServer.

## На собеседовании

**Вопрос с собеседования:** «Почему Functional Options предпочтительнее передачи структуры Config?»
**Ответ:** Functional Options сохраняют 100% обратную совместимость при добавлении новых опций, не требуют заполнения нулями дефолтных полей и инкапсулируют валидацию параметров.
