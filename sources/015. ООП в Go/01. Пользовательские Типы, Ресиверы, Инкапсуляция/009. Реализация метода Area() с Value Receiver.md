# Реализация метода Area() с Value Receiver для структуры Rectangle

## Условие

Создай структуру `Rectangle` с полями `Width, Height float64`. Напиши для нее метод `Area()` с value receiver. Вызови метод.

## Теория

Вычисление площади через метод со значением-получателем.

## Решение по шагам

1. Объявляем структуру Rectangle.
2. Реализуем метод Area().
3. Вызываем в main.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Rectangle struct {
	Width, Height float64
}

func (r Rectangle) Area() float64 {
	return r.Width * r.Height
}

func main() {
	rect := Rectangle{Width: 12.5, Height: 4.0}
	fmt.Printf("Площадь прямоугольника: %.2f кв. ед.\n", rect.Area())
}
```

**`Терминал`**

```bash
go run main.go
# Площадь прямоугольника: 50.00 кв. ед.
```

## Под капотом

Структура передается в регистры как пара float64.

## Подводные камни

- Попытка мутировать поля внутри метода с Value Receiver.

## На собеседовании

**Вопрос с собеседования:** «Является ли вызов метода rect.Area() сахаром над функцией?»
**Ответ:** Да, это эквивалентно Rectangle.Area(rect).
