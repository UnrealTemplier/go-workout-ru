# Метод Value() с Value Receiver для безопасного чтения состояния объекта

## Условие

Добавьте метод `Value()` с **value receiver** для безопасного чтения текущего состояния.

## Теория

Безопасное чтение гарантирует иммутабельность вызывающего объекта.

## Решение по шагам

1. Создаем структуру Score.
2. Реализуем метод (s Score) Value() int.
3. Вызываем в main.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Score struct {
	points int
}

func (s Score) Value() int {
	return s.points
}

func main() {
	s := Score{points: 95}
	fmt.Printf("Текущие баллы: %d\n", s.Value())
}
```

**`Терминал`**

```bash
go run main.go
# Текущие баллы: 95
```

## Под капотом

Чтение без захвата указателя.

## Подводные камни

- Использование Value Receiver для структур со срезами (мутация слайса затронет оригинал!).

## На собеседовании

**Вопрос с собеседования:** «Защищает ли Value Receiver от всех мутаций?»
**Ответ:** Нет, если структура содержит указатели, срезы или мапы, их внутреннее состояние может быть изменено.
