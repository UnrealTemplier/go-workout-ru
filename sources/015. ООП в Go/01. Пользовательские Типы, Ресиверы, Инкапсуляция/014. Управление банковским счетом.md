# Управление банковским счетом: геттер Balance(), методы Deposit() и Withdraw() с защитой от овердрафта

## Условие

**Геттеры и действия**: Добавь к `account` методы `Balance() float64` (геттер), `Deposit(amount float64)` и `Withdraw(amount float64) error`. Убедись, что снять денег больше, чем есть на балансе, нельзя.

## Теория

Инкапсуляция бизнес-правил внутри структуры.

## Решение по шагам

1. Объявляем Account.
2. Реализуем Balance, Deposit, Withdraw.
3. Проверяем овердрафт.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type Account struct {
	balance float64
}

func (a *Account) Balance() float64 { return a.balance }

func (a *Account) Deposit(amount float64) error {
	if amount <= 0 {
		return errors.New("сумма пополнения должна быть больше 0")
	}
	a.balance += amount
	return nil
}

func (a *Account) Withdraw(amount float64) error {
	if amount > a.balance {
		return errors.New("недостаточно средств")
	}
	a.balance -= amount
	return nil
}

func main() {
	acc := &Account{balance: 500}
	_ = acc.Deposit(200)
	fmt.Printf("Баланс: %.2f руб.\n", acc.Balance())

	if err := acc.Withdraw(1000); err != nil {
		fmt.Println("❌ Ошибка:", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Баланс: 700.00 руб.
# ❌ Ошибка: недостаточно средств
```

## Под капотом

Все операции проверяют инвариант до записи в память.

## Подводные камни

- Работа с деньгами через float64 без округления.
