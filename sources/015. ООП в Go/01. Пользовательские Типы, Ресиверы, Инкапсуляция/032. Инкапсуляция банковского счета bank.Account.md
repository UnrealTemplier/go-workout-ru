# Инкапсуляция банковского счета bank.Account с контролем отрицательного баланса

## Условие

Реализуйте инкапсуляцию: создайте пакет `bank` со структурой `Account`. Сделайте поле `balance` приватным. Добавьте методы `Deposit()` и `Withdraw()`, которые не дают балансу уйти в минус (возвращая ошибку при нехватке средств).

## Теория

Инкапсуляция защищает баланс от овердрафта.

## Решение по шагам

1. Создаем Account с приватным balance.
2. Реализуем методы с проверками.
3. Тестируем.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type Account struct{ balance int }

func (a *Account) Deposit(amt int) error {
	if amt <= 0 { return errors.New("неверная сумма") }
	a.balance += amt
	return nil
}

func (a *Account) Withdraw(amt int) error {
	if amt > a.balance { return errors.New("недостаточно средств") }
	a.balance -= amt
	return nil
}

func main() {
	acc := &Account{balance: 1000}
	_ = acc.Deposit(500)
	_ = acc.Withdraw(300)
	fmt.Println("Баланс:", acc.balance)
}
```

**`Терминал`**

```bash
go run main.go
# Баланс: 1200
```

## Под капотом

Баланс модифицируется только через проверенные методы.

## Подводные камни

- Использование float без округления для денег.

## На собеседовании

**Вопрос с собеседования:** «Как сделать счет потокобезопасным?»
**Ответ:** Добавить sync.Mutex внутри Account.
