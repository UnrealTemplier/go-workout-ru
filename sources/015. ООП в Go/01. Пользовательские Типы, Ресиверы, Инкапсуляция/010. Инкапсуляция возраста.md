# Инкапсуляция возраста: структура Person, валидация в SetAge(age int) error и геттер GetAge()

## Условие

Структура `Person` с приватным полем `age` (неэкспортируемое). Экспортируемые методы `SetAge(age int) error` (с проверкой >0) и `GetAge() int`. Продемонстрируйте инкапсуляцию.

## Теория

Геттеры и сеттеры с валидацией инвариантов возраста.

## Решение по шагам

1. Создаем Person с приватным age int.
2. Реализуем SetAge(age int) error.
3. Реализуем GetAge() int.
4. Тестируем валидацию.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type Person struct {
	Name string
	age  int
}

func (p *Person) SetAge(age int) error {
	if age <= 0 || age > 150 {
		return errors.New("некорректный возраст")
	}
	p.age = age
	return nil
}

func (p *Person) GetAge() int {
	return p.age
}

func main() {
	p := &Person{Name: "Алексей"}
	_ = p.SetAge(28)
	fmt.Printf("Пользователь: %s, Возраст: %d\n", p.Name, p.GetAge())

	if err := p.SetAge(-5); err != nil {
		fmt.Println("❌ Ошибка валидации:", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Пользователь: Алексей, Возраст: 28
# ❌ Ошибка валидации: некорректный возраст
```

## На собеседовании

**Вопрос с собеседования:** «Почему в Go геттеры называют без префикса Get?»
**Ответ:** По соглашению Effective Go геттеры называют именем свойства (Age()), а префикс Get используют только для ресурсоемких операций.
