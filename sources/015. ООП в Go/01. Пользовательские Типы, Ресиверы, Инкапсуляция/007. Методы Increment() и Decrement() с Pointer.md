# Методы Increment() и Decrement() с Pointer Receiver для управления состоянием структуры

## Условие

Добавьте к `Counter` методы `Increment()` и `Decrement()` с **pointer receiver** (`*Counter`), чтобы они могли изменять состояние структуры.

## Теория

Pointer Receiver для методов, изменяющих внутреннее состояние.

## Решение по шагам

1. Объявляем структуру Counter{count int}.
2. Реализуем методы Increment и Decrement с *Counter получателем.
3. Проверяем вызовы.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Counter struct {
	count int
}

func (c *Counter) Increment() { c.count++ }
func (c *Counter) Decrement() { c.count-- }

func main() {
	c := &Counter{count: 0}
	c.Increment()
	c.Increment()
	c.Decrement()
	fmt.Printf("Текущее значение: %d\n", c.count)
}
```

**`Терминал`**

```bash
go run main.go
# Текущее значение: 1
```

## Под капотом

Мутация полей выполняется напрямую по адресу памяти.

## Подводные камни

- Пропуск звездочки * в получателе, из-за чего изменится временная копия.

## На собеседовании

**Вопрос с собеседования:** «Можно ли смешивать value receiver и pointer receiver у одной структуры?»
**Ответ:** Технически можно, но рекомендуется придерживаться единообразия (Pointer Receiver для всех методов, если хотя бы один метод мутирует состояние).
