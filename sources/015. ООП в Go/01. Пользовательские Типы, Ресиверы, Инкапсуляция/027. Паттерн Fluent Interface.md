# Паттерн Fluent Interface: каскадная конфигурация точки p.WithX(10).WithY(20).String()

## Условие

Реализуй **method chaining** (fluent interface): `type Point struct { x, y float64 }`, методы `WithX(x float64) *Point`, `WithY(y float64) *Point`, `String() string`. Каждый метод возвращает `*Point` для цепочки: `p.WithX(10).WithY(20).String()`.

## Теория

Fluent Interface с возвратом указателя *Point.

## Решение по шагам

1. Создаем Point.
2. Реализуем WithX, WithY, String.
3. Собираем цепочку вызовов.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Point struct{ x, y float64 }

func (p *Point) WithX(x float64) *Point { p.x = x; return p }
func (p *Point) WithY(y float64) *Point { p.y = y; return p }
func (p *Point) String() string          { return fmt.Sprintf("Point(%.1f, %.1f)", p.x, p.y) }

func main() {
	p := &Point{}
	fmt.Println(p.WithX(10).WithY(20).String())
}
```

**`Терминал`**

```bash
go run main.go
# Point(10.0, 20.0)
```

## Под капотом

Адрес объекта передается через регистры CPU.
