# Инкапсуляция и сокрытие данных: защита поля balance от прямого доступа из внешних пакетов

## Условие

**Инкапсуляция (Скрытие данных)**: Создайте пакет `bank`. Внутри пакета объявите структуру `Account` с приватным (неэкспортируемым) полем `balance float64`. Напишите публичные методы `Deposit(amount float64)` и `Withdraw(amount float64) error` для изменения баланса с валидацией, а также метод-геттер `Balance() float64`. Попробуйте получить доступ к полю `balance` напрямую из пакета `main` и зафиксируйте ошибку компиляции.

## Теория

Инкапсуляция защищает инварианты сущностей от некорректного вмешательства извне.

## Решение по шагам

1. Создаем BankAccount с приватным balance.
2. Реализуем публичные методы доступа.
3. Тестируем.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type BankAccount struct {
	balance float64
}

func NewBankAccount(init float64) *BankAccount { return &BankAccount{balance: init} }
func (b *BankAccount) Balance() float64        { return b.balance }
func (b *BankAccount) Withdraw(amt float64) error {
	if amt > b.balance {
		return errors.New("недостаточно средств")
	}
	b.balance -= amt
	return nil
}

func main() {
	acc := NewBankAccount(500)
	_ = acc.Withdraw(150)
	fmt.Printf("Баланс: %.2f руб.\n", acc.Balance())
}
```

**`Терминал`**

```bash
go run main.go
# Баланс: 350.00 руб.
```
