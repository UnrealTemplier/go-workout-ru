# Композиция вместо наследования: анонимное встраивание структуры Engine в структуру Car

## Условие

**Композиция вместо наследования**: Создайте структуру `Engine` с методом `Start()`. Создайте структуру `Car`, встроив в неё `Engine` анонимно. Продемонстрируйте вызов метода `car.Start()`. Объясните, как композиция заменяет наследование классов.

## Теория

Встраивание структур (Embedding) обеспечивает всплытие методов (Method Promotion).

## Решение по шагам

1. Создаем Engine{HP int} с методом Start().
2. Создаем Car со встраиванием Engine.
3. Вызываем car.Start().

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Engine struct{ HP int }
func (e Engine) Start() { fmt.Printf("Двигатель %d л.с. запущен!\n", e.HP) }

type Car struct {
	Engine
	Model string
}

func main() {
	c := Car{Engine: Engine{HP: 200}, Model: "Sedan"}
	c.Start() // Method Promotion
}
```

**`Терминал`**

```bash
go run main.go
# Двигатель 200 л.с. запущен!
```

## Под капотом

Вызов c.Start() преобразуется в c.Engine.Start().

## На собеседовании

**Вопрос с собеседования:** «Почему в Go нет наследования классов?»
**Ответ:** Композиция безопаснее, исключает жесткую связанность и проблему хрупкого базового класса.
