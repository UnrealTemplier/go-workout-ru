# Вычисление расстояния Distance(other Point) и автоматическое разыменование получателя

## Условие

Объяви тип `Point` с методом `Distance(other Point) float64` (**value receiver**). Вычисли расстояние между двумя точками. Покажи, что метод можно вызвать и на значении, и на указателе (Go автоматически разыменовывает/берёт адрес).

## Теория

**Value Receiver и автоматическое разыменование (Automatic Dereferencing):**
- Метод с Value Receiver (p Point) получает полную копию структуры в момент вызова;
- Если метод вызывается на указателе ptr := &Point{}, компилятор Go автоматически преобразует вызов ptr.Distance(p2) в (*ptr).Distance(p2).

## Решение по шагам

1. Создаем структуру Point с полями X, Y float64.
2. Реализуем метод (p Point) Distance(other Point) float64 с формулой Евклидова расстояния.
3. Создаем значение p1 и указатель pPtr := &p1.
4. Демонстрируем эквивалентность вызовов.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"math"
)

type Point struct {
	X, Y float64
}

func (p Point) Distance(other Point) float64 {
	dx := p.X - other.X
	dy := p.Y - other.Y
	return math.Sqrt(dx*dx + dy*dy)
}

func main() {
	p1 := Point{X: 0, Y: 0}
	p2 := Point{X: 3, Y: 4}

	d1 := p1.Distance(p2)
	fmt.Printf("Расстояние (вызов на значении):   %.2f\n", d1)

	pPtr := &p1
	d2 := pPtr.Distance(p2)
	fmt.Printf("Расстояние (вызов на указателе): %.2f\n", d2)
}
```

**`Терминал`**

```bash
go run main.go
# Расстояние (вызов на значении):   5.00
# Расстояние (вызов на указателе): 5.00
```

## Под капотом

Компилятор анализирует AST и вставляет инструкцию загрузки значения из памяти перед вызовом.

## Подводные камни

- Использование Value Receiver для структур большого размера (>128 байт), что приводит к лишним аллокациям и копированию памяти при каждом вызове.

## На собеседовании

**Вопрос с собеседования:** «Когда следует выбирать Value Receiver, а когда Pointer Receiver?»
**Ответ:** Value Receiver выбирают для маленьких иммутабельных типов (примитивы, маленькие структуры <= 16 байт). Pointer Receiver обязателен, если метод мутирует состояние или структура содержит мьютексы (sync.Mutex).
