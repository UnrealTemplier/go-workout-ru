# Ad-hoc Interface (Анонимный интерфейс по месту использования) для функции MakeSound

## Условие

Объяви два типа `Dog` и `Cat` с одинаковым методом `Speak() string`. Напиши функцию `MakeSound(speaker interface{ Speak() string })`, принимающую любой тип с методом `Speak`. Покажи **ad-hoc interface** (неявный интерфейс) в действии.

## Теория

Анонимные интерфейсы прямо в параметрах функций.

## Решение по шагам

1. Создаем Dog и Cat с методом Speak().
2. Пишем MakeSound(speaker interface{ Speak() string }).
3. Передаем обе структуры.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Dog struct{}
func (Dog) Speak() string { return "Гав!" }

type Cat struct{}
func (Cat) Speak() string { return "Мяу!" }

func MakeSound(speaker interface{ Speak() string }) {
	fmt.Println(speaker.Speak())
}

func main() {
	MakeSound(Dog{})
	MakeSound(Cat{})
}
```

**`Терминал`**

```bash
go run main.go
# Гав!
# Мяу!
```

## На собеседовании

**Вопрос с собеседования:** «Когда использовать ad-hoc интерфейс?»
**Ответ:** Для локальных утилит с одним методом без необходимости экспорта.
