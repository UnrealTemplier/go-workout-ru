# Безопасная печать связного списка: метод PrintValue() на nil-указателе структуры Node

## Условие

**Nil-ресиверы**: Создай структуру `Node` (элемент связного списка). Напиши метод `func (n *Node) PrintValue()`. Внутри метода в самом начале напиши `if n == nil { fmt.Println("nil"); return }`. В `main` объяви `var n *Node = nil` и вызови `n.PrintValue()`. Убедись, что паники нет! (В Go методы можно безопасно вызывать у `nil`-указателей, если внутри есть проверка).

## Теория

Nil-получатели защищают методы от крашей.

## Решение по шагам

1. Создаем Node{val int}.
2. Реализуем (n *Node) PrintValue() с проверкой nil.
3. Вызываем на nil.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Node struct{ val int }

func (n *Node) PrintValue() {
	if n == nil {
		fmt.Println("nil")
		return
	}
	fmt.Println("Value:", n.val)
}

func main() {
	var n *Node = nil
	n.PrintValue()
}
```

**`Терминал`**

```bash
go run main.go
# nil
```

## Под капотом

Рантайм передает адрес 0x0 в качестве первого аргумента.

- Разыменование полей до проверки на nil.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go не падает вызов nil.Method()?»
**Ответ:** Потому что вызовы методов статические, а не через vtable объекта.
