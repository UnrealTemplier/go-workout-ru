# Методы на функциональных типах: type Handler func(string) string и реализация интерфейсов

## Условие

Объяви тип Handler func(string) string. Создай метод (h Handler) Process(s string) string. Покажи, что функциональные типы тоже могут иметь методы, и Handler удовлетворяет интерфейсу с методом Process.

### Исходная формулировка

Объяви тип `Handler func(string) string`. Создай метод `(h Handler) Process(s string) string`. Покажи, что **функциональные типы** тоже могут иметь методы, и `Handler` удовлетворяет интерфейсу с методом `Process`.

## Теория

Паттерн Function Adapter: методы на функциональных типах.

## Решение по шагам

1. Объявляем интерфейс Processor{ Process(string) string }.
2. Объявляем type Handler func(string) string.
3. Реализуем метод Process.
4. Адаптируем функцию к интерфейсу.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strings"
)

type Processor interface {
	Process(string) string
}

type Handler func(string) string

func (h Handler) Process(s string) string {
	return h(s)
}

func main() {
	fn := Handler(func(s string) string { return strings.ToUpper(s) })
	var p Processor = fn
	fmt.Println(p.Process("golang oop"))
}
```

**`Терминал`**

```bash
go run main.go
# GOLANG OOP
```

## Под капотом

Функция упаковывается в интерфейс iface с таблицей методов Handler.

## Подводные камни

- Забыть вызвать h(s) внутри Process.
