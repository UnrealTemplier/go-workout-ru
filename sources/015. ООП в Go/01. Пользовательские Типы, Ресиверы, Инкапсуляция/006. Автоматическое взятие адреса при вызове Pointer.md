# Автоматическое взятие адреса при вызове Pointer Receiver метода на значении

## Условие

Объяви тип `Counter` с методом `Increment()` (**pointer receiver**). Создай переменную `var c Counter` (не указатель), вызови `c.Increment()`. Покажи, что Go автоматически передаёт адрес для pointer receiver. Убедись, что оригинал изменился.

## Теория

Компилятор автоматически преобразует c.Increment() в (&c).Increment(), если c адресуемо.

## Решение по шагам

1. Объявляем структуру Counter{val int}.
2. Реализуем (c *Counter) Increment().
3. Вызываем метод на переменной-значении.
4. Проверяем изменение оригинала.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Counter struct {
	val int
}

func (c *Counter) Increment() {
	c.val++
}

func main() {
	var c Counter
	c.val = 10
	c.Increment()
	c.Increment()
	fmt.Printf("Оригинал изменился: %d (ожидалось 12)\n", c.val)
}
```

**`Терминал`**

```bash
go run main.go
# Оригинал изменился: 12 (ожидалось 12)
```

## Под капотом

Компилятор генерирует взятие адреса переменной в стеке.

## Подводные камни

- Попытка вызвать pointer-метод на неадресуемом литерале Counter{val: 10}.Increment().
