# Method Set для T и *T: сравнение Area() (Value) и Scale() (Pointer) у структуры Rectangle

## Условие

Объяви тип `Rectangle` с методами `Area() float64` (**value receiver**) и `Scale(factor float64)` (**pointer receiver**). Покажи, что `Area` работает на value и pointer, а `Scale` требует addressable value или указатель. Объясни **method set** `T` vs `*T`.

## Теория

**Спецификация Method Sets:**
- Type T содержит только методы с получателем (t T);
- Type *T содержит методы с получателем (t T) И (t *T).

## Решение по шагам

1. Создаем структуру Rectangle.
2. Реализуем Area() с Value Receiver.
3. Реализуем Scale() с Pointer Receiver.
4. Демонстрируем вызовы на значении и указателе.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Rectangle struct {
	Width, Height float64
}

func (r Rectangle) Area() float64 {
	return r.Width * r.Height
}

func (r *Rectangle) Scale(factor float64) {
	r.Width *= factor
	r.Height *= factor
}

func main() {
	r1 := Rectangle{Width: 10, Height: 5}
	fmt.Printf("Area на значении: %.1f\n", r1.Area())
	r1.Scale(2.0)
	fmt.Printf("После Scale: Width=%.1f, Height=%.1f\n", r1.Width, r1.Height)

	r2 := &Rectangle{Width: 4, Height: 3}
	fmt.Printf("Area на указателе: %.1f\n", r2.Area())
	r2.Scale(3.0)
	fmt.Printf("После Scale r2: Width=%.1f, Height=%.1f\n", r2.Width, r2.Height)
}
```

**`Терминал`**

```bash
go run main.go
# Area на значении: 50.0
# После Scale: Width=20.0, Height=10.0
# Area на указателе: 12.0
# После Scale r2: Width=12.0, Height=9.0
```

## Под капотом

Method set определяет совместимость с интерфейсами.

## Подводные камни

## На собеседовании

**Вопрос с собеседования:** «Почему Rectangle{10, 20}.Scale(2) запрещен?»
**Ответ:** Литерал структуры неадресуем; взятие адреса временного значения бессмысленно.
