# Авто-взятие адреса компилятором при вызове pointer-метода на переменной r Rectangle

## Условие

Изучите авто-взятие адреса: создайте переменную `r Rectangle` (не указатель) и попробуйте вызвать `r.Area()`, если метод требует `*Rectangle`. Объясните, как компилятор делает это за вас.

## Теория

Автоматическое взятие адреса (&r).Method() при вызове на адресуемой переменной.

## Решение по шагам

1. Создаем Rectangle.
2. Реализуем (r *Rectangle) Area() float64.
3. Вызываем на значении r Rectangle.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Rectangle struct {
	Width, Height float64
}

func (r *Rectangle) Area() float64 {
	return r.Width * r.Height
}

func main() {
	r := Rectangle{5, 4}
	res := r.Area() // Компилятор подставляет (&r).Area()
	fmt.Printf("Площадь: %.1f\n", res)
}
```

**`Терминал`**

```bash
go run main.go
# Площадь: 20.0
```

## Под капотом

Фаза компилятора трансформирует AST узел в взятие адреса.

## Подводные камни

- Вызов на неадресуемом литерале Rectangle{5, 4}.Area().

## На собеседовании

**Ответ:** Нет, интерфейс требует точного соответствия method set.
