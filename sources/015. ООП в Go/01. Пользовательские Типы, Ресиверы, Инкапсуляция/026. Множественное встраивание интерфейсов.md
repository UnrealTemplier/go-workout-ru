# Множественное встраивание интерфейсов: композиция io.Reader и io.Writer в кастомном буфере

## Условие

Множественное встраивание: структура `ReadWriter` встраивает `io.Reader` и `io.Writer`. Реализуйте для своего типа (например, буфер), удовлетворяющего обоим интерфейсам.

## Теория

Композиция стандартных потоковых контрактов.

## Решение по шагам

1. Создаем CustomReadWriter с bytes.Buffer.
2. Реализуем Read и Write.
3. Проверяем совместимость с io.ReadWriter.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
)

type CustomReadWriter struct {
	buf bytes.Buffer
}

func (c *CustomReadWriter) Read(p []byte) (int, error)  { return c.buf.Read(p) }
func (c *CustomReadWriter) Write(p []byte) (int, error) { return c.buf.Write(p) }

func main() {
	var rw io.ReadWriter = &CustomReadWriter{}
	fmt.Fprintf(rw, "Привет, Поток!")
	out, _ := io.ReadAll(rw)
	fmt.Printf("Прочитано: %q\n", string(out))
}
```

**`Терминал`**

```bash
go run main.go
# Прочитано: "Привет, Поток!"
```

## Под капотом

Композитный интерфейс объединяет таблицы методов io.Reader и io.Writer.

## Подводные камни

- Не возвращать io.EOF в конце потока чтения.

## На собеседовании

**Вопрос с собеседования:** «Как устроен io.ReadWriter?»
**Ответ:** Как встраивание интерфейсов type ReadWriter interface { Reader; Writer }.
