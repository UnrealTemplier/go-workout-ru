# Методы на кастомных срезах: type IntSlice []int и безопасное суммирование nil-среза

## Условие

Реализуй метод на **nil slice**: `type IntSlice []int`, метод `(s IntSlice) Sum() int`. Вызови `(IntSlice(nil)).Sum()` — покажи, что nil slice ведёт себя как пустой слайс внутри метода.

## Теория

Срез nil имеет len=0 и cap=0, обход через for range выполняется 0 раз без паники.

## Решение по шагам

1. Объявляем type IntSlice []int.
2. Реализуем метод Sum() int.
3. Вызываем на IntSlice(nil).

## Код решения

**`main.go`**

```go
package main

import "fmt"

type IntSlice []int

func (s IntSlice) Sum() int {
	total := 0
	for _, v := range s {
		total += v
	}
	return total
}

func main() {
	var s IntSlice = nil
	fmt.Printf("Сумма nil slice: %d\n", s.Sum())
}
```

**`Терминал`**

```bash
go run main.go
# Сумма nil slice: 0
```

## Под капотом

Дескриптор среза {Data: 0, Len: 0, Cap: 0} передается в функцию.

## Подводные камни

- Прямое обращение s[0] на nil слайсе.

## На собеседовании

**Вопрос с собеседования:** «Почему len(nil) равен 0?»
**Ответ:** Поле Len заголовка nil-слайса равно 0.
