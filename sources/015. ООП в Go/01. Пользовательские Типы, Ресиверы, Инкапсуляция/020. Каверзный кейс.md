# Каверзный кейс: почему значение Rectangle не удовлетворяет интерфейсу с Pointer-методом Scale

## Условие

**[Каверзный кейс]**: Создай интерфейс `Geometry` с методом `Area()`. Попробуй присвоить переменной типа `Geometry` значение `Rectangle` (а не указатель). Пойми, почему метод `Scale` не входит в интерфейс для значения (Method Sets: `*T` включает методы `T` и `*T`, а `T` включает только методы `T`).

## Теория

Method sets определяют возможность удовлетворения интерфейсов.

## Решение по шагам

1. Создаем интерфейс Transformer{ Scale(float64) }.
2. Создаем Rectangle с (r *Rectangle) Scale.
3. Демонстрируем ошибку при присвоении значения.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Transformer interface {
	Scale(factor float64)
}

type Rectangle struct {
	Width, Height float64
}

func (r *Rectangle) Scale(factor float64) {
	r.Width *= factor
	r.Height *= factor
}

func main() {
	var t Transformer = &Rectangle{10, 5} // ✅ Успех
	t.Scale(2.0)
	fmt.Println("Трансформация выполнена успешно!")
}
```

**`Терминал`**

```bash
go run main.go
# Трансформация выполнена успешно!
```
