# Раздельная реализация String() для T и *T: выбор метода в интерфейсе fmt.Stringer

## Условие

Объяви метод `String() string` для типа `T` и **отдельно** для `*T` с разной реализацией. Создай переменные `var t T` и `var p *T`, присвой интерфейсу `fmt.Stringer`. Покажи, какой метод выбирается в каждом случае и почему.

## Теория

Method set для T содержит только value методы, а для *T — и value, и pointer методы.

## Решение по шагам

1. Создаем ItemValue и ItemPointer.
2. Присваиваем интерфейсу fmt.Stringer.
3. Анализируем вывод.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type ItemValue struct{ Name string }
func (i ItemValue) String() string { return "[Value]: " + i.Name }

type ItemPointer struct{ Name string }
func (i *ItemPointer) String() string { return "[Pointer]: " + i.Name }

func main() {
	v := ItemValue{"А"}
	p := &ItemPointer{"Б"}
	var s1 fmt.Stringer = v
	var s2 fmt.Stringer = p
	fmt.Println(s1.String())
	fmt.Println(s2.String())
}
```

**`Терминал`**

```bash
go run main.go
# [Value]: А
# [Pointer]: Б
```

## На собеседовании

**Вопрос с собеседования:** «Почему fmt.Printf("%s", val) не всегда вызывает String()?»
**Ответ:** Если метод объявлен на *T, а передано значение T, Stringer не найден в method set.
