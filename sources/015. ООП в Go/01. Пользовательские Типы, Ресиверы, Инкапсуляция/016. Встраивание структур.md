# Встраивание структур: переопределение методов (Method Shadowing) у Employee и Person

## Условие

Встраивание: `Employee` встраивает `Person`. Вызовите метод `GetAge` напрямую у `Employee`. Добавьте в `Employee` свой метод `GetAge` (переопределение) и покажите разницу.

## Теория

Затенение встроенных методов при объявлении метода с тем же именем.

## Решение по шагам

1. Создаем Person с GetAge().
2. Создаем Employee со встраиванием Person и собственным GetAge().
3. Сравниваем вызовы emp.GetAge() и emp.Person.GetAge().

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Person struct {
	Age int
}

func (p Person) GetAge() int {
	return p.Age
}

type Employee struct {
	Person
	Position string
}

func (e Employee) GetAge() int {
	return e.Age + 100 // Затенение
}

func main() {
	emp := Employee{Person: Person{Age: 30}, Position: "Dev"}
	fmt.Printf("emp.GetAge():        %d\n", emp.GetAge())
	fmt.Printf("emp.Person.GetAge(): %d\n", emp.Person.GetAge())
}
```

**`Терминал`**

```bash
go run main.go
# emp.GetAge():        130
# emp.Person.GetAge(): 30
```

## Под капотом

Компилятор разрешает имена методов с минимальной глубиной вложенности.

## Подводные камни

- Думать, что в Go работает динамический полиморфизм наследования классов.

## На собеседовании

**Вопрос с собеседования:** «Является ли встраивание структур наследованием?»
**Ответ:** Нет, это композиция с синтаксическим сахаром делегирования.
