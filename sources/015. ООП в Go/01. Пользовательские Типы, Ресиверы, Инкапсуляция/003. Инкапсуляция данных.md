# Инкапсуляция данных: приватная структура bank.account и публичный конструктор NewAccount

## Условие

**Инкапсуляция (Private/Public)**: Создай пакет `bank`. В нём структуру `account` (с маленькой буквы) с приватным полем `balance float64`. Напиши публичную функцию `NewAccount(initialBalance float64) *account`, которая выступает конструктором.

## Теория

**Инкапсуляция на уровне пакетов в Go:**
- Видимость определяется регистром первой буквы идентификатора (строчная — приватный для пакета, заглавная — публичный экспортируемый);
- Создание приватной структуры с публичным конструктором гарантирует невозможность создания невалидного объекта в обход правил валидации.

## Решение по шагам

1. Моделируем структуру с неэкспортируемым балансом.
2. Экспортируем конструктор NewAccount.
3. Добавляем методы доступа Balance() и Deposit().

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"math"
)

type internalAccount struct {
	balance float64
}

func NewInternalAccount(init float64) *internalAccount {
	if init < 0 {
		init = 0
	}
	return &internalAccount{balance: init}
}

func (a *internalAccount) Balance() float64 { return a.balance }
func (a *internalAccount) Deposit(amount float64) {
	if amount > 0 {
		a.balance += amount
	}
}

func main() {
	acc := NewInternalAccount(1000.50)
	acc.Deposit(500.25)
	fmt.Printf("Текущий баланс счета: %.2f руб.\n", math.Round(acc.Balance()*100)/100)
}
```

**`Терминал`**

```bash
go run main.go
# Текущий баланс счета: 1500.75 руб.
```
