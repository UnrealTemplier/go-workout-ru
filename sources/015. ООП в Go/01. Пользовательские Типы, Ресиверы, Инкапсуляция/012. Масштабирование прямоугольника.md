# Масштабирование прямоугольника: метод Scale(factor float64) с Pointer Receiver

## Условие

Создай метод `Scale(factor float64)` для `Rectangle` с pointer receiver, который умножает ширину и высоту на `factor`. Проверь, что оригинал изменился.

## Теория

Мутация полей через указатель.

## Решение по шагам

1. Создаем структуру Rectangle.
2. Реализуем метод Scale(factor float64).
3. Вызываем на прямоугольнике.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Rectangle struct {
	Width, Height float64
}

func (r *Rectangle) Scale(factor float64) {
	if r == nil || factor <= 0 {
		return
	}
	r.Width *= factor
	r.Height *= factor
}

func main() {
	rect := Rectangle{Width: 10, Height: 20}
	rect.Scale(2.5)
	fmt.Printf("После масштабирования: %.1f x %.1f\n", rect.Width, rect.Height)
}
```

**`Терминал`**

```bash
go run main.go
# После масштабирования: 25.0 x 50.0
```

## Под капотом

Прямая мутация полей по адресу памяти.

## Подводные камни

- Вызов Scale(0) без проверки.

## На собеседовании

**Вопрос с собеседования:** «Что будет при вызове Scale на nil-указателе?»
**Ответ:** С проверкой if r == nil вызов безопасен, без проверки произойдет nil pointer dereference.
