# Изоляция состояния структуры Counter с приватным полем value int в отдельном пакете

## Условие

Создайте структуру `Counter` с приватным полем `value int` (вынесите её в отдельный пакет `counter`, чтобы поле было действительно приватным для `main`).

## Теория

Инкапсуляция внутреннего поля структуры и доступ через экспортируемые методы.

## Решение по шагам

1. Объявляем структуру с полем value int.
2. Добавляем конструктор и методы Get/Add.
3. Проверяем работу.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type SafeCounter struct {
	value int
}

func NewSafeCounter(start int) *SafeCounter {
	return &SafeCounter{value: start}
}

func (c *SafeCounter) Add(delta int) { c.value += delta }
func (c *SafeCounter) Get() int       { return c.value }

func main() {
	cnt := NewSafeCounter(100)
	cnt.Add(25)
	cnt.Add(-10)
	fmt.Printf("Состояние счетчика: %d\n", cnt.Get())
}
```

**`Терминал`**

```bash
go run main.go
# Состояние счетчика: 115
```

## Под капотом

Приватное поле имеет смещение 0, но защищено компилятором.

## Подводные камни

- Экспорт поля с заглавной буквы при необходимости строгого контроля инварианта.

## На собеседовании

**Вопрос с собеседования:** «Как сделать структуру потокобезопасной?»
**Ответ:** Использовать sync.Mutex или атомики atomic.Int64.
