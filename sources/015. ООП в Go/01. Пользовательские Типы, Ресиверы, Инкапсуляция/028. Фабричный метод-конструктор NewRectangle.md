# Фабричный метод-конструктор NewRectangle(w, h float64) с валидацией геометрических размеров

## Условие

Создайте фабричный метод (конструктор) `NewRectangle(w, h float64) *Rectangle`, который валидирует входные данные (ширина и высота > 0) и возвращает `error`, если они невалидны.

## Теория

Конструктор с проверкой инвариантов и возвратом error.

## Решение по шагам

1. Создаем Rectangle.
2. Пишем NewRectangle(w, h) (*Rectangle, error).
3. Проверяем валидные и невалидные параметры.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type Rectangle struct{ w, h float64 }

func NewRectangle(w, h float64) (*Rectangle, error) {
	if w <= 0 || h <= 0 {
		return nil, errors.New("размеры должны быть больше 0")
	}
	return &Rectangle{w: w, h: h}, nil
}

func main() {
	r, err := NewRectangle(10, 5)
	if err != nil {
		panic(err)
	}
	fmt.Printf("Прямоугольник: %.1f x %.1f\n", r.w, r.h)
}
```

**`Терминал`**

```bash
go run main.go
# Прямоугольник: 10.0 x 5.0
```

## Под капотом

При ошибке возвращается nil-указатель.

## Подводные камни

- Возврат неинициализированной структуры вместо nil.
