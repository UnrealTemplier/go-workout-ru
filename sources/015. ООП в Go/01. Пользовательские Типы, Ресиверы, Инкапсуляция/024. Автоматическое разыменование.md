# Автоматическое разыменование: вызов Value Receiver метода у указателя на структуру

## Условие

Изучите обратный случай: можно ли вызвать метод с value receiver у указателя на структуру? Проверьте на практике.

## Теория

Вызов ptr.ValueMethod() компилируется в (*ptr).ValueMethod().

## Решение по шагам

1. Создаем Config{Host string, Port int}.
2. Реализуем Address() string с Value Receiver.
3. Вызываем на указателе &Config{}.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Config struct {
	Host string
	Port int
}

func (c Config) Address() string {
	return fmt.Sprintf("%s:%d", c.Host, c.Port)
}

func main() {
	ptr := &Config{Host: "127.0.0.1", Port: 8080}
	fmt.Printf("Адрес: %s\n", ptr.Address())
}
```

**`Терминал`**

```bash
go run main.go
# Адрес: 127.0.0.1:8080
```

## Под капотом

Компилятор вставляет инструкцию загрузки структуры из памяти.

## Подводные камни

- Вызов на nil-указателе приведет к панике при разыменовании.

## На собеседовании

**Вопрос с собеседования:** «Почему вызов value-метода на nil-указателе падает?»
**Ответ:** Для создания копии значения рантайм обязан разыменовать указатель *ptr.
