# Методы для кастомных типов на базе примитивов: type MyDuration int и правило локальности пакета

## Условие

Создайте кастомный тип на базе встроенного: type MyDuration int. Напишите для него метод ToMinutes() float64 и ToSeconds() int. Проверьте вызов методов на переменной этого типа. Объясните, почему нельзя объявлять методы для базовых типов (например, напрямую для int) или для типов из чужих пакетов.

### Исходная формулировка

**Методы для неконкретных типов (алиасов)**: Создайте кастомный тип на базе встроенного: `type MyDuration int`. Напишите для него метод `ToMinutes() float64` и `ToSeconds() int`. Проверьте вызов методов на переменной этого типа. Объясните, почему нельзя объявлять методы для базовых типов (например, напрямую для `int`) или для типов из чужих пакетов.

## Теория

**Методы на пользовательских типах (Defined Types) и Receiver в Go:**
- В Go методы можно объявлять для любого именованного типа, объявленного в том же пакете, кроме базовых встроенных примитивов (int, string, float64) и указателей *T;
- Синтаксис type MyDuration int создает совершенно новый определенный тип (Defined Type), сохраняющий базовое представление памяти int, но изолирующий набор методов (Method Set);
- **Правило локальности пакета (Package Locality Rule):** Запрещено добавлять методы к типам, объявленным в других пакетах (например, time.Duration или http.Request). Это предотвращает коллизии методов (Orphan Rule) и обеспечивает модульность.

## Решение по шагам

1. Объявляем тип type MyDuration int (время в миллисекундах).
2. Реализуем метод (d MyDuration) ToSeconds() int с получателем-значением (Value Receiver).
3. Реализуем метод (d MyDuration) ToMinutes() float64.
4. В main создаем переменную d := MyDuration(150000) и вызываем методы.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type MyDuration int

func (d MyDuration) ToSeconds() int {
	return int(d) / 1000
}

func (d MyDuration) ToMinutes() float64 {
	return float64(d) / 60000.0
}

func main() {
	d := MyDuration(150000)
	fmt.Printf("Длительность: %d мс\n", d)
	fmt.Printf("В секундах:   %d с\n", d.ToSeconds())
	fmt.Printf("В минутах:    %.2f мин\n", d.ToMinutes())
}
```

**`Терминал`**

```bash
go run main.go
# Длительность: 150000 мс
# В секундах:   150 с
# В минутах:    2.50 мин
```

## Под капотом

На уровне ассемблера метод func (d MyDuration) ToSeconds() int компилируется в обычную функцию main.MyDuration.ToSeconds(d MyDuration) int, где получатель (receiver) передается как первый скрытый параметр.

## Подводные камни

- Попытка вызвать метод кастомного типа на литерале базового типа без явного приведения: (150000).ToSeconds() вызовет ошибку cannot call pointer method or field on untyped int.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go запрещено определять методы для типов из импортированных пакетов (например, func (t time.Time) CustomFormat())?»
**Ответ:** Это фундаментальное архитектурное решение (Package Locality). Если бы два независимых пакета добавили метод с одинаковым именем CustomFormat() к time.Time, возник бы неразрешимый конфликт при линковке в третьем пакете.
