# Цепочка вызовов (Method Chaining / Fluent Interface) для кастомного типа Counter

## Условие

Создайте тип `Counter` на основе `int`. Реализуйте методы `Inc()`, `Dec()`, `Value() int` с получателем-указателем. Сделайте цепочку вызовов: `c.Inc().Inc().Dec()`.

## Теория

**Method Chaining в Go:**
- Чтобы связать вызовы в цепочку, метод обязан возвращать указатель на получателя *Counter.

## Решение по шагам

1. Объявляем type Counter int.
2. Реализуем Inc() *Counter и Dec() *Counter.
3. Реализуем Value() int.
4. Собираем цепочку c.Inc().Inc().Dec().

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Counter int

func (c *Counter) Inc() *Counter {
	*c++
	return c
}

func (c *Counter) Dec() *Counter {
	*c--
	return c
}

func (c *Counter) Value() int {
	return int(*c)
}

func main() {
	var c Counter = 10
	c.Inc().Inc().Inc().Dec()
	fmt.Printf("Итоговое значение счетчика: %d\n", c.Value())
}
```

**`Терминал`**

```bash
go run main.go
# Итоговое значение счетчика: 12
```

## Под капотом

Адрес получателя возвращается в регистре RAX для следующего вызова.

## Подводные камни

- Возврат значения Counter вместо указателя при попытке мутации.
