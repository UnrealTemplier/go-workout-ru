# Извлечение метаданных в глубоких слоях и антипаттерны передачи бизнес-логики

## Условие

Передайте значение в контекст с помощью `context.WithValue`. Извлеките его в глубокой функции без передачи аргументов. (Обсудите, почему использовать контекст для передачи бизнес-данных — это антипаттерн).

## Теория

Передача значений через `context.WithValue` предназначена исключительно для cross-cutting concerns (трассировка, аутентификационные клеймы JWT, идентификаторы транзакций). Использование контекста для передачи обычных аргументов функций (`taxRate`, `itemsList`) превращает контекст в скрытый глобальный объект (God Object), ломает читаемость кода и делает рефакторинг невозможным.

## Решение по шагам

1. Создадим типизированный ключ `tenantIDKey`.
2. Положим `tenantID` в контекст в HTTP-мидлваре.
3. Пробросим `ctx` через сервис в репозиторий.
4. Извлечем значение в SQL-запросе.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
)

type tenantKey struct{}

func WithTenantID(ctx context.Context, tenantID string) context.Context {
	return context.WithValue(ctx, tenantKey{}, tenantID)
}

func TenantIDFromContext(ctx context.Context) string {
	if val, ok := ctx.Value(tenantKey{}).(string); ok {
		return val
	}
	return "public"
}

func ExecuteMultiTenantQuery(ctx context.Context, query string) {
	tenant := TenantIDFromContext(ctx)
	fmt.Printf("[SQL Engine] Выполнение запроса %q для Tenant: %q (Схема: schema_%s)\n", 
		query, tenant, tenant)
}

func main() {
	// Имитация запроса от Enterprise-клиента
	ctx := WithTenantID(context.Background(), "enterprise_corp_42")

	ExecuteMultiTenantQuery(ctx, "SELECT * FROM orders WHERE status = 'pending'")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [SQL Engine] Выполнение запроса "SELECT * FROM orders WHERE status = 'pending'" для Tenant: "enterprise_corp_42" (Схема: schema_enterprise_corp_42)
```

## Под капотом

`valueCtx` хранит указатель на родителя и пару ключ-значение.

## Подводные камни

Хранение изменяемых мутабельных структур (`*MyStruct` или `map`) в `context.WithValue` приводит к Data Race при параллельном доступе из горутин.

## На собеседовании

**Вопрос с собеседования:** «Почему значения внутри context.WithValue обязаны быть неизменяемыми (Immutable)?»
**Ответ:** Потому что один и тот же `context.Context` может параллельно читаться десятками горутин. Мутация объекта внутри контекста без мьютекса приведет к фатальной гонке данных (Data Race).
