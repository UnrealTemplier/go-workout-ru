# Паттерн Parallel Fetch with Context: параллельные запросы с ранней отменой

## Условие

Напиши **"parallel fetch with context"**: запускаешь 5 HTTP-запросов (или `time.Sleep` как симуляцию) в горутинах. Если один упал с ошибкой или таймаут — отменяй остальные через `cancel()`. Собери первую ошибку или все результаты.

## Теория

Паттерн Hedged Requests / Parallel Fetch: конкурентный запуск нескольких реплик запроса. Как только одна реплика завершается с ошибкой (или успехом), функция `cancel()` отменяет остальные параллельные горутины, экономя трафик и вычислительные ресурсы.

## Решение по шагам

1. Создадим контекст `ctx, cancel := context.WithCancel(context.Background())`.
2. Запустим 5 параллельных горутин с симуляцией сетевых вызовов.
3. При первой ошибке вызываем `cancel()`.
4. Убедимся, что оставшиеся 4 горутины мгновенно отменились.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"sync"
	"time"
)

func fetchReplica(ctx context.Context, id int, fail bool, wg *sync.WaitGroup, cancel context.CancelFunc) {
	defer wg.Done()

	select {
	case <-time.After(time.Duration(id*15) * time.Millisecond):
		if fail {
			fmt.Printf("[Replica #%d] ОШИБКА: Сбой узла! Вызываю cancel()...\n", id)
			cancel() // Отменяем все остальные реплики!
			return
		}
		fmt.Printf("[Replica #%d] Успешно получены данные.\n", id)
	case <-ctx.Done():
		fmt.Printf(" -> [Replica #%d] Отменена по общему сигналу: %v\n", id, ctx.Err())
	}
}

func main() {
	ctx, cancel := context.WithCancel(context.Background())
	defer cancel()

	var wg sync.WaitGroup
	const totalReplicas = 5

	for i := 1; i <= totalReplicas; i++ {
		wg.Add(1)
		shouldFail := (i == 2) // Реплика #2 сымитирует сбой
		go fetchReplica(ctx, i, shouldFail, &wg, cancel)
	}

	wg.Wait()
	fmt.Println("[Main] Параллельный опрос реплик завершен.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Replica #1] Успешно получены данные.
# [Replica #2] ОШИБКА: Сбой узла! Вызываю cancel()...
#  -> [Replica #3] Отменена по общему сигналу: context canceled
#  -> [Replica #4] Отменена по общему сигналу: context canceled
#  -> [Replica #5] Отменена по общему сигналу: context canceled
# [Main] Параллельный опрос реплик завершен.
```

## Под капотом

`cancel()` разблокирует каналы `Done()` во всех незавершенных репликах.

## Подводные камни

В продакшене для параллельных задач с отменой по первой ошибке используют библиотеку `golang.org/x/sync/errgroup`.

## На собеседовании

**Вопрос с собеседования:** «Как errgroup.WithContext(ctx) реализует отмену при первой ошибке?»
**Ответ:** `errgroup` создает дочерний контекст с `WithCancel`. При возврате `non-nil` ошибки из любой горутины группа вызывает `cancel()`, сохраняет первую ошибку и отменяет остальные горутины.
