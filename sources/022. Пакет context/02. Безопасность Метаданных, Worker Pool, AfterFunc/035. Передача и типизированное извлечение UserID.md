# Передача и типизированное извлечение UserID в context.WithValue

## Условие

**Передача данных (`WithValue`)**: Добавь в контекст UserID: `ctx = context.WithValue(ctx, "userID", 42)`. Достань его в воркере: `id := ctx.Value("userID")`.

## Теория

Сквозная идентификация пользователя (User Context): передача `UserID` в контексте позволяет слою логирования и аудита автоматически добавлять `user_id` во все структурированные логи.

## Решение по шагам

1. Создадим `ctx = context.WithValue(context.Background(), "userID", 42)`.
2. Передадим `ctx` в функцию `auditWorker`.
3. Извлечем значение с проверкой типа.
4. Проверим результат.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
)

func auditWorker(ctx context.Context) {
	// Извлечение значения по ключу
	rawVal := ctx.Value("userID")
	if rawVal == nil {
		fmt.Println("[Audit] UserID не передан в контексте")
		return
	}

	userID, ok := rawVal.(int)
	if !ok {
		fmt.Println("[Audit] Ошибка: некорректный тип UserID")
		return
	}

	fmt.Printf("[Audit] Действие авторизовано для UserID: %d\n", userID)
}

func main() {
	ctx := context.WithValue(context.Background(), "userID", 42)
	auditWorker(ctx)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Audit] Действие авторизовано для UserID: 42
```

## Под капотом

`ctx.Value` возвращает `interface{}` (`any`).

## Подводные камни

В реальном коде вместо `"userID"` используйте неэкспортируемый тип `type key struct{}`.

## На собеседовании

**Вопрос с собеседования:** «Что вернет ctx.Value("key"), если ключ не найден ни в одном узле дерева?»
**Ответ:** Метод `Value` дойдет до корня (`emptyCtx`) и вернет `nil`.
