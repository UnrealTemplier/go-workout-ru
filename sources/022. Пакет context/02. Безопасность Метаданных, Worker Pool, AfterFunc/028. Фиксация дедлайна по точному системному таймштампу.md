# Фиксация дедлайна по точному системному таймштампу (WithDeadline)

## Условие

`context.WithDeadline`: аналогично таймауту, но задайте конкретное время завершения.

## Теория

`WithDeadline` используется для привязки к внешним дедлайнам (например, дедлайн gRPC-запроса, переданный в заголовках `grpc-timeout`).

## Решение по шагам

1. Создадим абсолютное время `exactTime := time.Now().Add(30 * time.Millisecond)`.
2. Создадим `context.WithDeadline`.
3. Обработаем дедлайн в горутине.
4. Выведем результат.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"
)

func main() {
	targetTime := time.Now().Add(30 * time.Millisecond)
	ctx, cancel := context.WithDeadline(context.Background(), targetTime)
	defer cancel()

	fmt.Printf("[Timer] Установлен дедлайн: %s\n", targetTime.Format("15:04:05.000"))

	select {
	case <-time.After(100 * time.Millisecond):
		fmt.Println("Задача завершилась")
	case <-ctx.Done():
		fmt.Printf("[Timer] Дедлайн истек в %s! Ошибка: %v\n", 
			time.Now().Format("15:04:05.000"), ctx.Err())
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Timer] Установлен дедлайн: 15:04:05.030
# [Timer] Дедлайн истек в 15:04:05.030! Ошибка: context deadline exceeded
```

## Под капотом

`WithDeadline` создает `timerCtx` с вычислением дельты времени.

## Подводные камни

Всегда учитывайте возможность дрейфа системного времени NTP при работе с удаленными дедлайнами.

## На собеседовании

**Вопрос с собеседования:** «Как gRPC передает дедлайн между серверами на разных машинах?»
**Ответ:** gRPC передает оставшееся относительное время (`time.Until(deadline)`) в заголовке `grpc-timeout`, а принимающий сервер вычисляет новый локальный дедлайн `time.Now().Add(receivedDuration)`, нивелируя рассинхронизацию часов между серверами.
