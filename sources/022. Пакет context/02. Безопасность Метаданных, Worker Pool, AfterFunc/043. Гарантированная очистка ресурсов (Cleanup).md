# Гарантированная очистка ресурсов (Cleanup) при аварийной отмене контекста

## Условие

Переопределите поведение при отмене контекста: запустите горутину, которая делает "cleanup" (например, удаляет временные файлы) при срабатывании `ctx.Done()`.

## Теория

Паттерн Safe Cleanup: при получении сигнала отмены горутина переходит в режим очистки (удаление временных файлов на диске, откат незавершенной транзакции) с таймаутом на саму процедуру очистки.

## Решение по шагам

1. Создадим временный файл.
2. Запустим горутину, слушающую `<-ctx.Done()`.
3. При сигнале отмены удалим временный файл.
4. Убедимся в чистоте диска.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"sync"
	"time"
)

func fileWorker(ctx context.Context, filename string, wg *sync.WaitGroup) {
	defer wg.Done()
	fmt.Printf("[Worker] Создан временный файл %s, идет запись...\n", filename)

	select {
	case <-time.After(1 * time.Second):
		fmt.Println("[Worker] Запись завершена штатно")
	case <-ctx.Done():
		fmt.Printf("[Worker] Получен сигнал отмены (%v)! Запуск процедуры Cleanup...\n", ctx.Err())
		// Симуляция безопасного удаления временного файла
		fmt.Printf(" -> [Cleanup] Файл %s успешно удален с диска.\n", filename)
	}
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 20*time.Millisecond)
	defer cancel()

	var wg sync.WaitGroup
	wg.Add(1)
	go fileWorker(ctx, "/tmp/temp_upload_981.bin", &wg)

	wg.Wait()
	fmt.Println("[Main] Процесс корректно завершен без оставленных временных файлов.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Worker] Создан временный файл /tmp/temp_upload_981.bin, идет запись...
# [Worker] Получен сигнал отмены (context deadline exceeded)! Запуск процедуры Cleanup...
#  -> [Cleanup] Файл /tmp/temp_upload_981.bin успешно удален с диска.
# [Main] Процесс корректно завершен без оставленных временных файлов.
```

## Под капотом

Событие `Done()` позволяет выполнить локальный `defer/cleanup` до выхода из горутины.

## Подводные камни

Если cleanup обращается к сети, используйте `context.WithoutCancel` с собственным коротким таймаутом.

## На собеседовании

**Вопрос с собеседования:** «Как выполнить сетевой запрос во время Cleanup, если родительский контекст уже отменен?»
**Ответ:** Создать независимый контекст с собственным таймаутом: `cleanupCtx, cancel := context.WithTimeout(context.WithoutCancel(parentCtx), 5*time.Second)` (в Go 1.21+) или `context.WithTimeout(context.Background(), 5*time.Second)`.
