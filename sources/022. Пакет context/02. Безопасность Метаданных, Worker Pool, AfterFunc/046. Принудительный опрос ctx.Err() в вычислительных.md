# Принудительный опрос ctx.Err() в вычислительных CPU-bound циклах

## Условие

**Принудительная проверка в цикле**: В долгоиграющем цикле (который не использует каналы) добавь `if ctx.Err() != nil { return ctx.Err() }`, чтобы не делать лишнюю работу, если клиент отвалился.

## Теория

Вычислительные задачи (парсинг JSON, хеширование, расчет матриц) не используют каналы и `select`. Единственный способ сделать такой алгоритм отменяемым — периодическая проверка `ctx.Err() != nil` внутри тела цикла.

## Решение по шагам

1. Создадим функцию `HeavyComputation(ctx context.Context, iterations int) error`.
2. Внутри цикла добавим `if err := ctx.Err(); err != nil { return err }`.
3. Проверим остановку вычислений при таймауте.
4. Выведем результат.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"
)

func HeavyComputation(ctx context.Context, totalSteps int) error {
	for i := 1; i <= totalSteps; i++ {
		// ПРИНУДИТЕЛЬНАЯ ПРОВЕРКА ОТМЕНЫ В CPU-BOUND ЦИКЛЕ
		if err := ctx.Err(); err != nil {
			return fmt.Errorf("вычисления прерваны на шаге %d из %d: %w", i, totalSteps, err)
		}

		time.Sleep(5 * time.Millisecond) // Имитация тяжелого шага
	}
	return nil
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 18*time.Millisecond)
	defer cancel()

	err := HeavyComputation(ctx, 100)
	if err != nil {
		fmt.Printf("[CPU Task] %v\n", err)
	} else {
		fmt.Println("[CPU Task] Все вычисления завершены успешно")
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [CPU Task] вычисления прерваны на шаге 4 из 100: context deadline exceeded
```

## Под капотом

`ctx.Err()` производит неблокирующее атомарное чтение указателя ошибки.

## Подводные камни

В очень быстрых циклах проверяйте `ctx.Err()` раз в \(N\) итераций (`if i % 256 == 0`), чтобы избежать накладных расходов.

## На собеседовании

**Вопрос с собеседования:** «Почему проверка ctx.Err() в цикле называется Cooperative Cancellation (кооперативной отменой)?»
**Ответ:** Потому что горутина не может быть принудительно убита рантаймом извне — она сама обязана добровольно проверять флаг отмены и корректно освобождать занятые ресурсы.
