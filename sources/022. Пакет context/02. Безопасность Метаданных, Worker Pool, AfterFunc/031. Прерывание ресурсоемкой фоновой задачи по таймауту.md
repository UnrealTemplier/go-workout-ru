# Прерывание ресурсоемкой фоновой задачи по таймауту WithTimeout

## Условие

Используй `context.WithTimeout(ctx, 1*time.Second)`. Запусти горутину с долгой работой (sleep 5s). Горутина должна завершиться по таймауту контекста, выведя "Context cancelled".

## Теория

Предотвращение бесконечной работы горутин: при наступлении таймаута горутина получает сигнал и очищает ресурсы.

## Решение по шагам

1. Создадим `ctx, cancel := context.WithTimeout(context.Background(), 20*time.Millisecond)`.
2. Запустим горутину с симуляцией 200 мс работы.
3. Горутина считывает `<-ctx.Done()`.
4. Выведем сообщение `"Context cancelled"`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"sync"
	"time"
)

func heavyTask(ctx context.Context, wg *sync.WaitGroup) {
	defer wg.Done()
	fmt.Println("[Task] Начало тяжелой обработки...")

	select {
	case <-time.After(200 * time.Millisecond):
		fmt.Println("[Task] Задача успешно завершена")
	case <-ctx.Done():
		fmt.Printf("[Task] Context cancelled: задача прервана по таймауту (%v)\n", ctx.Err())
	}
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 20*time.Millisecond)
	defer cancel()

	var wg sync.WaitGroup
	wg.Add(1)
	go heavyTask(ctx, &wg)

	wg.Wait()
	fmt.Println("[Main] Программа завершена.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Task] Начало тяжелой обработки...
# [Task] Context cancelled: задача прервана по таймауту (context deadline exceeded)
# [Main] Программа завершена.
```

## Под капотом

`<-ctx.Done()` пробуждает горутину из `select`.

## Подводные камни

Не забывайте `wg.Wait()`.

## На собеседовании

**Вопрос с собеседования:** «Что возвращает метод ctx.Done() у контекста context.Background()?»
**Ответ:** Он возвращает `nil`. Чтение из `nil`-канала блокируется навсегда, поэтому в `select` ветка `case <-ctx.Done():` для `context.Background()` никогда не выполнится.
