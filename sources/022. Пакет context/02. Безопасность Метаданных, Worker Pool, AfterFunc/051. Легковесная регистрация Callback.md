# Легковесная регистрация Callback через context.AfterFunc (Go 1.21+)

## Условие

**`context.AfterFunc` (Go 1.21+)**: Зарегистрируй функцию, которая вызовется автоматически, когда контекст будет отменен (без необходимости писать горутину с `select`).

### Исходная формулировка

**`context.AfterFunc` (Go 1.21+)**: Зарегистрируй функцию, которая вызовется автоматически, когда контекст будет отменен (без необходимости писать горутину с `select`).

---

## Теория

`context.AfterFunc` позволяет регистрировать синхронизирующие хуки (например, отмену контекста другого пакета или прерывание ожидания) без расхода памяти на отдельную заблокированную горутину.

## Решение по шагам

1. Создадим контекст с отменой `ctx, cancel := context.WithCancel(...)`.
2. Зарегистрируем хук через `context.AfterFunc`.
3. Вызовем `cancel()`.
4. Зафиксируем выполнение хука.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"sync"
	"time"
)

func main() {
	ctx, cancel := context.WithCancel(context.Background())
	var wg sync.WaitGroup

	wg.Add(1)
	// Регистрация колбэка
	stop := context.AfterFunc(ctx, func() {
		defer wg.Done()
		fmt.Printf("[Callback] Сигнал отмены зафиксирован: %v\n", ctx.Err())
	})
	defer stop()

	time.Sleep(10 * time.Millisecond)

	fmt.Println("[Main] Вызов cancel()...")
	cancel()

	wg.Wait()
	fmt.Println("[Main] Колбэк успешно выполнился в фоновом режиме.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Main] Вызов cancel()...
# [Callback] Сигнал отмены зафиксирован: context canceled
# [Main] Колбэк успешно выполнился в фоновом режиме.
```

## Под капотом

`AfterFunc` добавляется в список слушателей `cancelCtx`.

## Подводные камни

Функция `f` выполняется в отдельной горутине — учитывайте потокобезопасность изменяемых данных внутри нее.

## На собеседовании

**Вопрос с собеседования:** «Что возвращает функция stop() из context.AfterFunc?»
**Ответ:** Она возвращает `true`, если вызов `stop()` успел отменить регистрацию колбэка до его запуска, и `false`, если контекст уже был отменен и колбэк уже выполнился или выполняется прямо сейчас.
