# Трехуровневая цепочка: ctx -> ctx2 (Timeout) -> ctx3 с каскадной отменой корня

## Условие

Создай дерево контекстов: корень `ctx`, от него `ctx2` (с таймаутом 2s), от `ctx2` — `ctx3`. Отметь, что отмена `ctx` отменяет и `ctx2`, и `ctx3`.

## Теория

Каскадное закрытие всей цепочки: ручная отмена корня `ctx` аннулирует таймер `ctx2` и мгновенно закрывает канал `ctx3.Done()`.

## Решение по шагам

1. Создадим `ctx, rootCancel := context.WithCancel(context.Background())`.
2. Создадим `ctx2, cancel2 := context.WithTimeout(ctx, 2*time.Second)`.
3. Создадим `ctx3, cancel3 := context.WithCancel(ctx2)`.
4. Вызовем `rootCancel()` и убедимся, что все 3 контекста отменились за миллисекунды.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"
)

func main() {
	// 1. Корень
	ctx, rootCancel := context.WithCancel(context.Background())
	
	// 2. Второй уровень (с таймаутом на 2 секунды)
	ctx2, cancel2 := context.WithTimeout(ctx, 2*time.Second)
	defer cancel2()

	// 3. Третий уровень
	ctx3, cancel3 := context.WithCancel(ctx2)
	defer cancel3()

	time.Sleep(10 * time.Millisecond)

	fmt.Println("[Main] Отменяем КОРНЕВОЙ контекст rootCancel()...")
	rootCancel()

	fmt.Printf("Статус ctx  (Root):     %v\n", ctx.Err())
	fmt.Printf("Статус ctx2 (L2-Timer): %v\n", ctx2.Err())
	fmt.Printf("Статус ctx3 (L3-Leaf):  %v\n", ctx3.Err())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Main] Отменяем КОРНЕВОЙ контекст rootCancel()...
# Статус ctx  (Root):     context canceled
# Статус ctx2 (L2-Timer): context canceled
# Статус ctx3 (L3-Leaf):  context canceled
```

## Под капотом

`rootCancel` каскадно проходит по цепочке `ctx -> ctx2 -> ctx3`.

## Подводные камни

Всегда вызывайте `defer cancel2()` и `defer cancel3()` для корректной очистки памяти.

## На собеседовании

**Вопрос с собеседования:** «Что происходит с системным таймером ctx2 при отмене корневого контекста?»
**Ответ:** Метод `cancel` контекста `ctx2` автоматически вызывает `c.timer.Stop()`, предотвращая холостое срабатывание таймера в будущем.
