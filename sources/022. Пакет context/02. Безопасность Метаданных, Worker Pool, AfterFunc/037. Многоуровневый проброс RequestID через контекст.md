# Многоуровневый проброс RequestID через контекст для логирования

## Условие

`context.WithValue`: передайте идентификатор запроса через контекст в несколько вложенных вызовов. Логируйте его при обработке.

## Теория

Практикум структурированного логирования: контекст передается через слои Handler -> Service -> Repository с извлечением RequestID в каждом логе.

## Решение по шагам

1. Объявим ключ `type reqKey struct{}`.
2. Реализуем хелперы для `reqID`.
3. Залогируем на каждом уровне.
4. Проверим вывод.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
)

type reqIDKey struct{}

func logWithContext(ctx context.Context, layer, message string) {
	reqID := "N/A"
	if val, ok := ctx.Value(reqIDKey{}).(string); ok {
		reqID = val
	}
	fmt.Printf("[%s] [RequestID: %s] %s\n", layer, reqID, message)
}

func Step3Repository(ctx context.Context) {
	logWithContext(ctx, "Repository", "INSERT INTO audit_log VALUES (...)")
}

func Step2Service(ctx context.Context) {
	logWithContext(ctx, "Service", "Бизнес-валидация платежа")
	Step3Repository(ctx)
}

func Step1Handler(ctx context.Context) {
	logWithContext(ctx, "Handler", "Принят HTTP POST /api/pay")
	Step2Service(ctx)
}

func main() {
	ctx := context.WithValue(context.Background(), reqIDKey{}, "req-777-prod-eu")
	Step1Handler(ctx)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Handler] [RequestID: req-777-prod-eu] Принят HTTP POST /api/pay
# [Service] [RequestID: req-777-prod-eu] Бизнес-валидация платежа
# [Repository] [RequestID: req-777-prod-eu] INSERT INTO audit_log VALUES (...)
```

## Под капотом

Слой логирования читает контекст без модификации.

## Подводные камни

Не логируйте пароли и чувствительные персональные данные (PII) из контекста.

## На собеседовании

**Вопрос с собеседования:** «Как пакет slog в Go 1.21 интегрирован с context.Context?»
**Ответ:** Методы `slog.InfoContext(ctx, msg, ...)` и `slog.ErrorContext(ctx, msg, ...)` автоматически передают `ctx` в зарегистрированный `slog.Handler`, который может автоматически извлекать TraceID/SpanID и добавлять их во все JSON-логи.
