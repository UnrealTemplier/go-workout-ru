# Интеграция контекста с HTTP-клиентом: http.NewRequestWithContext

## Условие

**Контекст в HTTP-клиенте**: Напишите простой HTTP-запрос к медленному серверу с помощью пакета `net/http`. Привяжите к HTTP-запросу контекст с таймаутом в 500 миллисекунд с помощью `http.NewRequestWithContext`. Проверьте, как клиент обрывает соединение, если сервер не ответил вовремя.

## Теория

Привязка контекста к HTTP-запросу через `http.NewRequestWithContext(ctx, method, url, body)` гарантирует, что сетевой стек Go (`net.Dialer`, TLS-хендшейк, чтение HTTP Body) автоматически закроет TCP-сокет при наступлении таймаута.

## Решение по шагам

1. Запустим тестовый локальный HTTP-сервер с искусственной задержкой 200 мс.
2. Создадим HTTP-запрос с контекстом таймаута 30 мс.
3. Вызовем `http.DefaultClient.Do(req)`.
4. Убедимся в мгновенном обрыве соединения по таймауту.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

func main() {
	// 1. Медленный тестовый HTTP-сервер
	server := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		time.Sleep(100 * time.Millisecond) // Медленный ответ
		fmt.Fprintln(w, "OK: Sensitive Data")
	}))
	defer server.Close()

	// 2. Создаем контекст с таймаутом 25 мс
	ctx, cancel := context.WithTimeout(context.Background(), 25*time.Millisecond)
	defer cancel()

	// 3. Привязываем контекст к запросу
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, server.URL, nil)
	if err != nil {
		panic(err)
	}

	fmt.Println("[HTTP Client] Отправка GET-запроса с таймаутом 25мс...")
	_, err = http.DefaultClient.Do(req)
	if err != nil {
		fmt.Printf("[HTTP Client] Соединение успешно разорвано по дедлайну:\n  -> %v\n", err)
	} else {
		fmt.Println("Запрос выполнен успешно")
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [HTTP Client] Отправка GET-запроса с таймаутом 25мс...
# [HTTP Client] Соединение успешно разорвано по дедлайну:
#   -> Get "...": context deadline exceeded
```

## Под капотом

`net/http` транспорт запускает горутину, которая слушает `req.Context().Done()` и закрывает подлежащий дескриптор сокета через `net.Conn.Close()`.

## Подводные камни

Устаревший метод `http.NewRequest()` без контекста не защищает от бесконечных зависаний при сетевых сбоях.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие http.Client.Timeout от контекста в http.NewRequestWithContext?»
**Ответ:** `http.Client.Timeout` задает глобальный таймаут на весь жизненный цикл запроса (включая редиректы и чтение body). Контекст запроса позволяет динамически управлять отменой с уровня вызывающего бизнес-хендлера с передачей единого дедлайна по всей цепочке вызовов.
