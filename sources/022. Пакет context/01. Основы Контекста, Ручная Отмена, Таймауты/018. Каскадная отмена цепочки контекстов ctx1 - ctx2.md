# Каскадная отмена цепочки контекстов ctx1 -> ctx2

## Условие

**Каскадная отмена**: Создай `ctx1` (с отменой). От него создай `ctx2` (с отменой). Передай `ctx2` в воркер. Отмени **первый** контекст `ctx1`. Убедись, что `ctx2` тоже автоматически отменился.

## Теория

Принцип наследования отмены: дочерний контекст `ctx2` слушает жизненный цикл родителя `ctx1` и немедленно закрывается при отмене родителя.

## Решение по шагам

1. Создадим `ctx1, cancel1 := context.WithCancel(...)`.
2. Создадим `ctx2, cancel2 := context.WithCancel(ctx1)`.
3. Запустим горутину с `ctx2`.
4. Вызовем `cancel1()` и зафиксируем отмену обоих контекстов.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"sync"
	"time"
)

func subWorker(ctx context.Context, wg *sync.WaitGroup) {
	defer wg.Done()
	select {
	case <-ctx.Done():
		fmt.Printf("[SubWorker] Получен сигнал отмены через ctx2: %v\n", ctx.Err())
	case <-time.After(1 * time.Second):
		fmt.Println("[SubWorker] Ошибка")
	}
}

func main() {
	ctx1, cancel1 := context.WithCancel(context.Background())
	defer cancel1()

	ctx2, cancel2 := context.WithCancel(ctx1)
	defer cancel2()

	var wg sync.WaitGroup
	wg.Add(1)
	go subWorker(ctx2, &wg)

	time.Sleep(15 * time.Millisecond)

	fmt.Println("[Main] Отменяю ПЕРВЫЙ контекст (cancel1)...")
	cancel1()

	wg.Wait()
	fmt.Printf("[Main] Статус ctx1: %v\n", ctx1.Err())
	fmt.Printf("[Main] Статус ctx2: %v (каскадно отменен!)\n", ctx2.Err())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Main] Отменяю ПЕРВЫЙ контекст (cancel1)...
# [SubWorker] Получен сигнал отмены через ctx2: context canceled
# [Main] Статус ctx1: context canceled
# [Main] Статус ctx2: context canceled (каскадно отменен!)
```

## Под капотом

`cancel1()` находит `ctx2` в своей мапе детей и вызывает его метод `cancel`.

## Подводные камни

Вызов `cancel2()` не отменил бы `ctx1`.

## На собеседовании

**Вопрос с собеседования:** «Какую ошибку ctx.Err() возвращает дочерний контекст при отмене родителя?»
**Ответ:** Дочерний контекст возвращает ту же ошибку, с которой был отменен родитель (`context.Canceled` или `context.DeadlineExceeded`).
