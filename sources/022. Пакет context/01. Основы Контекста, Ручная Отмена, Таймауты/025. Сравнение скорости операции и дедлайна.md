# Сравнение скорости операции и дедлайна: досрочное срабатывание WithTimeout

## Условие

**Таймаут (`WithTimeout`)**: Создай `ctx, cancel := context.WithTimeout(context.Background(), 1*time.Second)`. Обязательно добавь `defer cancel()`. Воркер должен спать 3 секунды. Проверь, что `ctx.Done()` срабатывает раньше завершения работы воркера.

## Теория

Тестирование опережения: когда время выполнения задачи (3 сек) превышает таймаут (1 сек), канал `ctx.Done()` гарантированно разблокирует ожидающий поток первым.

## Решение по шагам

1. Создадим контекст с таймаутом 20 мс.
2. Запустим задачу, длящуюся 100 мс.
3. Зафиксируем время прерывания.
4. Проверим результат.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"
)

func main() {
	start := time.Now()

	// Таймаут 20 мс
	ctx, cancel := context.WithTimeout(context.Background(), 20*time.Millisecond)
	defer cancel()

	taskDone := make(chan struct{})

	// Воркер спит 100 мс
	go func() {
		time.Sleep(100 * time.Millisecond)
		close(taskDone)
	}()

	select {
	case <-taskDone:
		fmt.Println("Воркер успел завершиться")
	case <-ctx.Done():
		fmt.Printf("ctx.Done() сработал раньше воркера (прошло %v)! Ошибка: %v\n", 
			time.Since(start).Round(time.Millisecond), ctx.Err())
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ctx.Done() сработал раньше воркера (прошло 20ms)! Ошибка: context deadline exceeded
```

## Под капотом

`select` выбирает первый готовый канал.

## Подводные камни

Не забывайте `defer cancel()`.
