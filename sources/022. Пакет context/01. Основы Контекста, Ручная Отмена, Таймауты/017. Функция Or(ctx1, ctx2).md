# Функция Or(ctx1, ctx2): слияние каналов отмены двух контекстов

## Условие

Напиши функцию `Or(ctx1, ctx2 context.Context) context.Context`, возвращающую контекст, который отменяется, когда отменяется **любой** из входных. Используй горутину + `select` на `ctx1.Done()` и `ctx2.Done()`.

## Теория

Комбинатор контекстов `Or(ctx1, ctx2)` позволяет объединить два независимых источника отмены (например, таймаут HTTP-клиента и сигнал остановки сервера `serverStopCtx`). В Go 1.21+ для этой цели появился стандартный `context.WithCancelCause`.

## Решение по шагам

1. Реализуем функцию `Or(ctx1, ctx2 context.Context) context.Context`.
2. Внутри создадим `ctx, cancel := context.WithCancel(context.Background())`.
3. Запустим горутину с `select` на `<-ctx1.Done()` и `<-ctx2.Done()`.
4. Проверим срабатывание при отмене любого из них.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"
)

func Or(ctx1, ctx2 context.Context) (context.Context, context.CancelFunc) {
	outCtx, cancel := context.WithCancel(context.Background())

	go func() {
		select {
		case <-ctx1.Done():
			cancel()
		case <-ctx2.Done():
			cancel()
		case <-outCtx.Done():
			// Выход, если результирующий контекст отменили вручную
			return
		}
	}()

	return outCtx, cancel
}

func main() {
	// ctx1: таймаут 20 мс (быстрый)
	ctx1, cancel1 := context.WithTimeout(context.Background(), 20*time.Millisecond)
	defer cancel1()

	// ctx2: таймаут 100 мс (медленный)
	ctx2, cancel2 := context.WithTimeout(context.Background(), 100*time.Millisecond)
	defer cancel2()

	combinedCtx, combinedCancel := Or(ctx1, ctx2)
	defer combinedCancel()

	start := time.Now()
	<-combinedCtx.Done()

	fmt.Printf("Объединенный контекст Or(ctx1, ctx2) отменился через %v (сработал быстрый ctx1)!\n", time.Since(start).Round(time.Millisecond))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Объединенный контекст Or(ctx1, ctx2) отменился через 20ms (сработал быстрый ctx1)!
```

## Под капотом

Горутина в `Or` слушает оба канала и немедленно пробрасывает сигнал в результирующий контекст.

## Подводные камни

В горутине `Or` обязательно добавляйте `case <-outCtx.Done():` для предотвращения утечки горутины при ручном вызове `combinedCancel()`.

## На собеседовании

**Вопрос с собеседования:** «Как в Go 1.21+ объединить несколько контекстов без запуска отдельной горутины?»
**Ответ:** С помощью функции `context.AfterFunc`: зарегистрировать `context.AfterFunc(ctx1, cancel)` и `context.AfterFunc(ctx2, cancel)`, что позволяет избежать создания дополнительной горутины.
