# Сквозное логирование Trace/Request ID через цепочку вызовов с context.WithValue

## Условие

Используй `context.WithValue()` для передачи `requestID` через цепочку вызовов. Напиши middleware, который извлекает `requestID` из `ctx` и логирует. Покажи, что значение доступно во всех дочерних функциях.

## Теория

Распределенная трассировка (Distributed Tracing): `RequestID` генерируется на входе в API Gateway и пробрасывается через все уровни приложения в контексте для сквозного логирования.

## Решение по шагам

1. Создадим типизированный ключ `type traceKey string`.
2. Реализуем функцию обогащения контекста `WithRequestID`.
3. Реализуем функцию извлечения `GetRequestID`.
4. Продемонстрируем доступность на всех слоях сервиса.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
)

type traceKey struct{}

func WithRequestID(ctx context.Context, reqID string) context.Context {
	return context.WithValue(ctx, traceKey{}, reqID)
}

func GetRequestID(ctx context.Context) string {
	if val, ok := ctx.Value(traceKey{}).(string); ok {
		return val
	}
	return "unknown"
}

func ServiceLayer(ctx context.Context) {
	fmt.Printf("[Service] Вызов бизнес-логики | TraceID: %s\n", GetRequestID(ctx))
	RepositoryLayer(ctx)
}

func RepositoryLayer(ctx context.Context) {
	fmt.Printf("[Repository] Выполнение SQL-запроса | TraceID: %s\n", GetRequestID(ctx))
}

func main() {
	ctx := context.Background()
	tracedCtx := WithRequestID(ctx, "trace-abc-123-xyz")

	ServiceLayer(tracedCtx)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Service] Вызов бизнес-логики | TraceID: trace-abc-123-xyz
# [Repository] Выполнение SQL-запроса | TraceID: trace-abc-123-xyz
```

## Под капотом

Использование анонимной структуры `type traceKey struct{}` в качестве ключа занимает 0 байт памяти и гарантирует абсолютную изоляцию ключа.

## Подводные камни

Не забывайте проверять успешность приведения типа `.(string)` через идиому comma-ok.

## На собеседовании

**Вопрос с собеседования:** «Почему type key struct{} считается идеальным ключом для context.WithValue?»
**Ответ:** Потому что пустая структура `struct{}` имеет нулевой размер в памяти, а благодаря приватности типа ни один внешний пакет не сможет прочитать или подделать это значение без экспортированных хелперов.
