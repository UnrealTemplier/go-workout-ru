# Абсолютный дедлайн против относительного таймаута: context.WithDeadline

## Условие

Используй `context.WithDeadline()`. Установи дедлайн на `time.Now().Add(5 * time.Second)`. Покажи разницу между `deadline` и `timeout` (deadline — абсолютное время, timeout — относительное).

## Теория

* `context.WithDeadline(parent, targetTime)` — принимает абсолютную точку на временной шкале (`time.Time`).
* `context.WithTimeout(parent, duration)` — принимает относительный интервал (`time.Duration`) и вычисляет `time.Now().Add(duration)`.

## Решение по шагам

1. Создадим абсолютный дедлайн: `targetDeadline := time.Now().Add(30 * time.Millisecond)`.
2. Создадим `ctx, cancel := context.WithDeadline(context.Background(), targetDeadline)`.
3. Извлечем дедлайн через `d, ok := ctx.Deadline()`.
4. Проверим срабатывание.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"
)

func main() {
	// Устанавливаем точное абсолютное время дедлайна
	exactDeadline := time.Now().Add(30 * time.Millisecond)
	ctx, cancel := context.WithDeadline(context.Background(), exactDeadline)
	defer cancel()

	// Проверяем наличие и значение дедлайна
	deadlineTime, ok := ctx.Deadline()
	if ok {
		fmt.Printf("Абсолютный дедлайн установлен на: %s (через %v)\n", 
			deadlineTime.Format("15:04:05.000"), time.Until(deadlineTime).Round(time.Millisecond))
	}

	select {
	case <-time.After(100 * time.Millisecond):
		fmt.Println("Успех")
	case <-ctx.Done():
		fmt.Printf("Дедлайн наступил в %s! Ошибка: %v\n", 
			time.Now().Format("15:04:05.000"), ctx.Err())
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Абсолютный дедлайн установлен на: 15:04:05.030 (через 30ms)
# Дедлайн наступил в 15:04:05.030! Ошибка: context deadline exceeded
```

## Под капотом

Если у родительского контекста уже установлен более ранний дедлайн, `WithDeadline` наследует более жесткий дедлайн родителя.

## Подводные камни

Нельзя продлить дедлайн дочернего контекста дальше, чем дедлайн родителя.

## На собеседовании

**Вопрос с собеседования:** «Что вернет childCtx.Deadline(), если у родителя дедлайн через 5 секунд, а ребенку задали дедлайн через 10 секунд?»
**Ответ:** Ровно 5 секунд (дедлайн родителя). Дочерний контекст никогда не может жить дольше своего родителя.
