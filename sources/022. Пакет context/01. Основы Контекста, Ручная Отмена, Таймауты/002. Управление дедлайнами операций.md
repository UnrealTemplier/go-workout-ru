# Управление дедлайнами операций: context.WithTimeout и context.DeadlineExceeded

## Условие

**Таймаут операции (`context.WithTimeout`)**: Напишите функцию, имитирующую тяжелый сетевой запрос, занимающий 5 секунд. Вызовите эту функцию с контекстом, у которого установлен таймаут в 2 секунды. Функция должна вернуть ошибку `context.DeadlineExceeded` по истечении таймаута.

## Теория

`context.WithTimeout(parent, duration)` автоматически инициирует отмену по истечении заданного интервала времени. Метод `ctx.Err()` в этом случае возвращает стандартную ошибку-синглтон `context.DeadlineExceeded`.

## Решение по шагам

1. Создадим функцию `slowNetworkCall(ctx context.Context) error`.
2. Внутри функции используем `select` между `time.After(...)` и `ctx.Done()`.
3. В `main` вызовем функцию с таймаутом 40 мс.
4. Проверим тип и текст ошибки через `errors.Is(err, context.DeadlineExceeded)`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"errors"
	"fmt"
	"time"
)

func slowNetworkCall(ctx context.Context) error {
	fmt.Println("[Client] Отправка тяжелого RPC-запроса (требуется ~200мс)...")

	select {
	case <-time.After(200 * time.Millisecond):
		fmt.Println("[Client] Ответ от сервера успешно получен!")
		return nil
	case <-ctx.Done(): // Срабатывает по истечении таймаута контекста
		return ctx.Err()
	}
}

func main() {
	// Контекст с жестким таймаутом 40 мс
	ctx, cancel := context.WithTimeout(context.Background(), 40*time.Millisecond)
	defer cancel()

	err := slowNetworkCall(ctx)
	if err != nil {
		if errors.Is(err, context.DeadlineExceeded) {
			fmt.Printf("[Main] ОШИБКА: Превышен таймаут операции: %v\n", err)
		} else {
			fmt.Printf("[Main] Ошибка запроса: %v\n", err)
		}
	} else {
		fmt.Println("[Main] Запрос выполнен успешно.")
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Client] Отправка тяжелого RPC-запроса (требуется ~200мс)...
# [Main] ОШИБКА: Превышен таймаут операции: context deadline exceeded
```

## Под капотом

`context.WithTimeout` внутри оборачивает `context.WithDeadline(parent, time.Now().Add(timeout))` и запускает системный таймер `time.AfterFunc`.

## Подводные камни

Всегда проверяйте ошибки контекста через `errors.Is(err, context.DeadlineExceeded)`, а не строковым сравнением `err.Error() == "..."`.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между context.Canceled и context.DeadlineExceeded?»
**Ответ:** `context.Canceled` возвращается при явном ручном вызове функции `cancel()`. `context.DeadlineExceeded` возвращается, когда автоматически истек дедлайн или таймаут контекста.
