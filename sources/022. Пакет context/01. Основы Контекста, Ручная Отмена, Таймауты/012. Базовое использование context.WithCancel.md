# Базовое использование context.WithCancel для отмены горутины

## Условие

Создайте контекст с отменой `context.WithCancel`. Передайте его в горутину и отмените выполнение из `main`.

## Теория

Практикум по связыванию `context.WithCancel` с управляемым воркером.

## Решение по шагам

1. Создадим контекст `ctx, cancel := context.WithCancel(context.Background())`.
2. Запустим горутину с таймером.
3. Отменим контекст.
4. Проверим корректность.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"sync"
	"time"
)

func processOrders(ctx context.Context, wg *sync.WaitGroup) {
	defer wg.Done()
	for {
		select {
		case <-ctx.Done():
			fmt.Printf("[Orders] Обработка прервана: %v\n", ctx.Err())
			return
		default:
			time.Sleep(5 * time.Millisecond)
		}
	}
}

func main() {
	ctx, cancel := context.WithCancel(context.Background())
	var wg sync.WaitGroup

	wg.Add(1)
	go processOrders(ctx, &wg)

	time.Sleep(15 * time.Millisecond)
	cancel() // Отмена

	wg.Wait()
	fmt.Println("[Main] Все заказы успешно синхронизированы.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Orders] Обработка прервана: context canceled
# [Main] Все заказы успешно синхронизированы.
```

## Под капотом

`cancel()` закрывает внутренний канал `<-ctx.Done()`.

## Подводные камни

Всегда вызывайте `defer cancel()`, даже если вы вызываете `cancel()` вручную выше по коду.

## На собеседовании

**Вопрос с собеседования:** «Безопасно ли передавать один и тот же контекст сразу в 1000 горутин?»
**Ответ:** Да, абсолютно безопасно! Контексты в Go неизменяемы (Immutable) после создания, а закрытие канала `Done()` через `cancel()` мгновенно и безопасно разбудит все 1000 горутин одновременно.
