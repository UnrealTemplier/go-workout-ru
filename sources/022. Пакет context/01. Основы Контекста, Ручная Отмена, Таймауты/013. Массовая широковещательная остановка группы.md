# Массовая широковещательная остановка группы горутин по единому контексту

## Условие

`context.WithCancel`: main отменяет контекст через 3 секунды, все горутины, получившие контекст, должны корректно завершиться.

## Теория

Один вызов `cancel()` производит широковещательное оповещение (Broadcast) неограниченного числа горутин, читающих общий `ctx.Done()`.

## Решение по шагам

1. Создадим пул из 3 воркеров, использующих общий `ctx`.
2. Запустим их через `sync.WaitGroup`.
3. В `main` вызовем `cancel()`.
4. Убедимся в завершении всех 3 воркеров.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"sync"
	"time"
)

func taskWorker(ctx context.Context, id int, wg *sync.WaitGroup) {
	defer wg.Done()
	for {
		select {
		case <-ctx.Done():
			fmt.Printf("[Worker #%d] Остановлен по общему сигналу отмены!\n", id)
			return
		default:
			time.Sleep(10 * time.Millisecond)
		}
	}
}

func main() {
	ctx, cancel := context.WithCancel(context.Background())
	var wg sync.WaitGroup

	const totalWorkers = 3
	wg.Add(totalWorkers)

	for i := 1; i <= totalWorkers; i++ {
		go taskWorker(ctx, i, &wg)
	}

	time.Sleep(25 * time.Millisecond)

	fmt.Println("[Main] Отправка единого сигнала отмены для всех воркеров...")
	cancel() // Один вызов останавливает ВСЕХ воркеров!

	wg.Wait()
	fmt.Println("[Main] Все воркеры пула успешно завершили работу.")
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# [Main] Отправка единого сигнала отмены для всех воркеров...
# [Worker #1] Остановлен по общему сигналу отмены!
# [Worker #2] Остановлен по общему сигналу отмены!
# [Worker #3] Остановлен по общему сигналу отмены!
# [Main] Все воркеры пула успешно завершили работу.
```

## Под капотом

Закрытие канала разблокирует все горутины в очереди `recvq` за один проход.

## Подводные камни

Не передавайте разные контексты, если требуется одновременная синхронная остановка пула.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать паттерн Fan-Out с контекстной отменой?»
**Ответ:** Передать общий `ctx` во все дочерние воркеры. Если хотя бы один воркер обнаружил фатальную ошибку или получен сигнал извне, вызов `cancel()` мгновенно останавливает всю группу.
