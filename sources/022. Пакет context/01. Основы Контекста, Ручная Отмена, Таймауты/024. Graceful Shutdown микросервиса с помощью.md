# Graceful Shutdown микросервиса с помощью signal.NotifyContext

## Условие

Напиши **"graceful shutdown with context"**: `main` создаёт `ctx` с `signal.NotifyContext`. При `Ctrl+C` — контекст отменяется. Все worker'ы читают `ctx.Done()`, завершают текущую работу, делают cleanup и выходят.

## Теория

Функция `signal.NotifyContext(parent, signals...)` (добавлена в Go 1.16) — современный стандарт корректного завершения приложений. Она возвращает контекст, который автоматически отменяется при получении сигналов ОС (`os.Interrupt`, `syscall.SIGTERM`).

## Решение по шагам

1. Создадим контекст завершения `ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt)`.
2. Обязательно вызовем `defer stop()`.
3. Запустим пул воркеров.
4. Сымитируем сигнал остановки и проверим синхронное завершение всех воркеров.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"os"
	"os/signal"
	"sync"
	"time"
)

func serviceWorker(ctx context.Context, id int, wg *sync.WaitGroup) {
	defer wg.Done()
	fmt.Printf("[Worker #%d] Фоновый воркер запущен...\n", id)

	for {
		select {
		case <-ctx.Done():
			fmt.Printf(" -> [Worker #%d] Получен сигнал отмены ОС! Сброс буферов и выход.\n", id)
			return
		default:
			time.Sleep(10 * time.Millisecond)
		}
	}
}

func main() {
	// Автоматическая отмена контекста по сигналу SIGINT (Ctrl+C)
	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt)
	defer stop()

	var wg sync.WaitGroup
	const totalWorkers = 2

	for i := 1; i <= totalWorkers; i++ {
		wg.Add(1)
		go serviceWorker(ctx, i, &wg)
	}

	time.Sleep(30 * time.Millisecond)

	// Имитация поступления сигнала завершения
	fmt.Println("\n[OS] Поступил системный сигнал SIGINT...")
	stop() // Вызов stop() отменяет контекст и восстанавливает дефолтное поведение сигналов

	wg.Wait()
	fmt.Println("[Main] Graceful shutdown успешно завершен: все воркеры выгружены.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Worker #1] Фоновый воркер запущен...
# [Worker #2] Фоновый воркер запущен...
# 
# [OS] Поступил системный сигнал SIGINT...
#  -> [Worker #1] Получен сигнал отмены ОС! Сброс буферов и выход.
#  -> [Worker #2] Получен сигнал отмены ОС! Сброс буферов и выход.
# [Main] Graceful shutdown успешно завершен: все воркеры выгружены.
```

## Под капотом

`signal.NotifyContext` регистрирует системный канал сигналов и автоматически вызывает `cancel()` в обработчике сигнала.

## Подводные камни

Всегда вызывайте `defer stop()`, чтобы снять регистрацию обработчика сигналов ОС при выходе из `main()`.

## На собеседовании

**Вопрос с собеседования:** «Почему signal.NotifyContext лучше ручной работы с chan os.Signal?»
**Ответ:** `signal.NotifyContext` устраняет шаблонный код создания канала сигналов и фоновой горутины, естественным образом интегрируя завершение ОС с экосистемой стандартного `context.Context`.
