# Идиома первого аргумента ctx context.Context в сигнатурах функций

## Условие

**Базовый контекст**: Создай `ctx := context.Background()`. Напиши воркер, который принимает `ctx` первым аргументом (это стандарт) и крутится в `for { select { case <-ctx.Done(): return default: ... } }`.

## Теория

По официальному Code Review Comments руководству Go: `context.Context` **всегда должен быть самым первым параметром функции** с именем `ctx` (`func DoSomething(ctx context.Context, arg1 string, ...) error`). Никогда не сохраняйте контекст в полях структур.

## Решение по шагам

1. Объявим функцию `runWorker(ctx context.Context, workerID int)`.
2. Внутри реализуем цикл `for select`.
3. Передадим отменяемый контекст.
4. Проверим остановку воркера.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"time"
)

// ИДИОМА GO: ctx ВСЕГДА идет самым первым аргументом!
func runWorker(ctx context.Context, workerID int) {
	fmt.Printf("[Worker #%d] Старт цикла обработки...\n", workerID)

	for {
		select {
		case <-ctx.Done():
			fmt.Printf("[Worker #%d] Завершение работы по сигналу ctx.Done(): %v\n", workerID, ctx.Err())
			return
		default:
			// Полезная работа
			time.Sleep(10 * time.Millisecond)
		}
	}
}

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 25*time.Millisecond)
	defer cancel()

	go runWorker(ctx, 1)

	time.Sleep(40 * time.Millisecond)
	fmt.Println("[Main] Программа завершена.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Worker #1] Старт цикла обработки...
# [Worker #1] Завершение работы по сигналу ctx.Done(): context deadline exceeded
# [Main] Программа завершена.
```

## Под капотом

Передача `ctx` первым параметром позволяет стандартным линтерам (`govet`, `golangci-lint`) контролировать передачу дедлайнов по всему стеку.

## Подводные камни

Не сохраняйте `ctx` внутри структуры `type Service struct { ctx context.Context }` — контекст должен передаваться динамически в каждый метод.

## На собеседовании

**Вопрос с собеседования:** «Почему нельзя хранить context.Context внутри полей структур?»
**Ответ:** Потому что структура становится непереиспользуемой между разными конкурентными запросами: время жизни структуры обычно дольше времени жизни одного HTTP-запроса, что приведет к гонкам данных и использованию мертвого/отмененного контекста.
