# Финальный босс: High-Performance Message Passing Framework

## Условие

Создайте полноценный production-grade фреймворк передачи сообщений высокой производительности (`FastMsgFramework`), объединяющий SPSC и MPMC кольцевые буферы, пакетную передачу, zero-copy указатели, настраиваемый backpressure, lock-free сборщик метрик и корректное плавное завершение (Graceful Shutdown).

### Исходная формулировка

**Финальный босс (High-Performance Message Passing Framework):**
    Создайте production-grade message passing framework:

    **Architecture:**
    * **SPSC ring buffers** для dedicated producer-consumer pairs
    * **MPMC ring buffers** для shared queues
    * **Lock-free counters** для statistics
    * **Cache-friendly structures** для message payloads

    **Features:**
    * **Zero-copy messaging:** Messages передаются через pointers, не copy
    * **Batch operations:** Producer и consumer могут batch process
    * **Backpressure:** Configurable strategy (block/drop/error)
    * **Metrics:** Lock-free counters для throughput, latency, queue depth
    * **Monitoring:** Prometheus metrics export

    **Performance targets:**
    * SPSC: 100M messages/sec на core
    * MPMC: 10M messages/sec на core
    * Latency: <100ns для SPSC, <1μs для MPMC
    * Zero allocations в hot path

    **Use cases:**
    * **High-frequency trading:** Order book updates через SPSC ring buffers
    * **Real-time analytics:** Event streaming через MPMC ring buffers
    * **Logging framework:** High-throughput logging через ring buffers
    * **Metrics collection:** Lock-free metrics aggregation

    **Optimizations:**
    * **Cache line padding** для избежания false sharing
    * **Power-of-2 sizing** для fast modulo через bitmask
    * **Memory alignment** для SIMD operations
    * **Huge pages** для снижения TLB misses
    * **NUMA-aware allocation** для multi-socket servers

    **Testing:**
    * **Correctness tests:** Все messages доставлены в правильном порядке
    * **Performance tests:** Throughput и latency benchmarks
    * **Stress tests:** High contention, burst traffic
    * **Chaos tests:** Producer/consumer crashes, recovery

    **Production features:**
    * **Graceful shutdown:** Drain ring buffers перед shutdown
    * **Monitoring:** Real-time metrics и alerting
    * **Configuration:** Dynamic sizing, backpressure strategy
    * **Multi-tenancy:** Isolated ring buffers per tenant

## Теория

В финальном задании темы объединяются все ключевые концепции lock-free инженерии:
1. **Гибридная топология очередей**:
   - Выделенные пары Producer-Consumer общаются через ультрабыстрые **SPSC Ring Buffers** без единого CAS.
   - Общие задачи распределяются через промышленную **Vyukov Bounded MPMC Queue**.
2. **Нулевые аллокации (Zero-Copy)**: передача сообщений по указателям через переиспользуемый пул объектов (`sync.Pool`).
3. **Пакетная обработка (Batch Processing)**: амортизация барьеров памяти при высоких нагрузках.
4. **Настраиваемый Backpressure**: стратегии блокировки, сброса или отказа при переполнении.
5. **Lock-Free телеметрия**: атомарный подсчет переданных сообщений, дропов и задержек.
6. **Graceful Shutdown**: гарантированный вычет всех остаточных сообщений перед выходом.

## Решение по шагам

1. Разработайте интерфейс `Message` и пул повторного использования сообщений.
2. Реализуйте структуры каналов `SPSCChannel` и `MPMCChannel` с выравниванием кэш-линий.
3. Инкапсулируйте логику во фреймворк `Engine` с реестром очередей.
4. Добавьте сбор метрик задержки и пропускной способности.
5. Продемонстрируйте передачу 2 000 000 сообщений между десятками горутин с выводом итогового отчета.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
	"runtime"
	"sync"
	"sync/atomic"
	"time"
)

var (
	ErrQueueFull   = errors.New("channel ring buffer is full")
	ErrQueueClosed = errors.New("engine is shutting down")
)

type Payload struct {
	ID        int64
	Timestamp int64
	Data      [64]byte
}

// SPSC Channel с Cache-line padding
type SPSCChannel struct {
	buffer   []*Payload
	mask     uint64
	capacity uint64
	_pad0    [40]byte

	head uint64
	_pad1 [56]byte

	tail uint64
	_pad2 [56]byte
}

func NewSPSCChannel(size uint64) *SPSCChannel {
	if size == 0 || (size&(size-1)) != 0 {
		panic("size must be power of 2")
	}
	return &SPSCChannel{
		buffer:   make([]*Payload, size),
		mask:     size - 1,
		capacity: size,
	}
}

func (q *SPSCChannel) Push(p *Payload) bool {
	h := atomic.LoadUint64(&q.head)
	t := atomic.LoadUint64(&q.tail)
	if h-t >= q.capacity {
		return false
	}
	q.buffer[h&q.mask] = p
	atomic.StoreUint64(&q.head, h+1)
	return true
}

func (q *SPSCChannel) Pop() (*Payload, bool) {
	t := atomic.LoadUint64(&q.tail)
	h := atomic.LoadUint64(&q.head)
	if t >= h {
		return nil, false
	}
	p := q.buffer[t&q.mask]
	q.buffer[t&q.mask] = nil
	atomic.StoreUint64(&q.tail, t+1)
	return p, true
}

// Vyukov MPMC Channel
type Slot struct {
	sequence uint64
	msg      *Payload
}

type MPMCChannel struct {
	buffer   []Slot
	mask     uint64
	capacity uint64
	_pad0    [40]byte
	head     uint64
	_pad1    [56]byte
	tail     uint64
	_pad2    [56]byte
}

func NewMPMCChannel(size uint64) *MPMCChannel {
	if size == 0 || (size&(size-1)) != 0 {
		panic("size must be power of 2")
	}
	q := &MPMCChannel{
		buffer:   make([]Slot, size),
		mask:     size - 1,
		capacity: size,
	}
	for i := uint64(0); i < size; i++ {
		q.buffer[i].sequence = i
	}
	return q
}

func (q *MPMCChannel) Push(p *Payload) bool {
	var head uint64
	var slot *Slot
	for {
		head = atomic.LoadUint64(&q.head)
		slot = &q.buffer[head&q.mask]
		seq := atomic.LoadUint64(&slot.sequence)
		diff := int64(seq) - int64(head)

		if diff == 0 {
			if atomic.CompareAndSwapUint64(&q.head, head, head+1) {
				break
			}
		} else if diff < 0 {
			return false // full
		}
	}
	slot.msg = p
	atomic.StoreUint64(&slot.sequence, head+1)
	return true
}

func (q *MPMCChannel) Pop() (*Payload, bool) {
	var tail uint64
	var slot *Slot
	for {
		tail = atomic.LoadUint64(&q.tail)
		slot = &q.buffer[tail&q.mask]
		seq := atomic.LoadUint64(&slot.sequence)
		diff := int64(seq) - int64(tail+1)

		if diff == 0 {
			if atomic.CompareAndSwapUint64(&q.tail, tail, tail+1) {
				break
			}
		} else if diff < 0 {
			return nil, false // empty
		}
	}
	p := slot.msg
	slot.msg = nil
	atomic.StoreUint64(&slot.sequence, tail+q.capacity)
	return p, true
}

// Engine объединяет каналы, пул и метрики
type Engine struct {
	pool       sync.Pool
	spsc       *SPSCChannel
	mpmc       *MPMCChannel
	totalSent  uint64
	totalRecv  uint64
	totalDrops uint64
	closed     uint32
}

func NewEngine(spscCap, mpmcCap uint64) *Engine {
	return &Engine{
		pool: sync.Pool{
			New: func() interface{} {
				return &Payload{}
			},
		},
		spsc: NewSPSCChannel(spscCap),
		mpmc: NewMPMCChannel(mpmcCap),
	}
}

func (e *Engine) SendDirect(id int64) error {
	if atomic.LoadUint32(&e.closed) == 1 {
		return ErrQueueClosed
	}

	p := e.pool.Get().(*Payload)
	p.ID = id
	p.Timestamp = time.Now().UnixNano()

	if !e.spsc.Push(p) {
		e.pool.Put(p)
		atomic.AddUint64(&e.totalDrops, 1)
		return ErrQueueFull
	}
	atomic.AddUint64(&e.totalSent, 1)
	return nil
}

func (e *Engine) SendShared(id int64) error {
	if atomic.LoadUint32(&e.closed) == 1 {
		return ErrQueueClosed
	}

	p := e.pool.Get().(*Payload)
	p.ID = id
	p.Timestamp = time.Now().UnixNano()

	if !e.mpmc.Push(p) {
		e.pool.Put(p)
		atomic.AddUint64(&e.totalDrops, 1)
		return ErrQueueFull
	}
	atomic.AddUint64(&e.totalSent, 1)
	return nil
}

func (e *Engine) Shutdown() {
	atomic.StoreUint32(&e.closed, 1)
}

func main() {
	const totalMessages = 1000000
	engine := NewEngine(8192, 8192)

	var wg sync.WaitGroup
	start := time.Now()

	// 1. Dedicated SPSC Consumer
	wg.Add(1)
	go func() {
		defer wg.Done()
		for {
			p, ok := engine.spsc.Pop()
			if ok {
				atomic.AddUint64(&engine.totalRecv, 1)
				engine.pool.Put(p)
			} else {
				if atomic.LoadUint32(&engine.closed) == 1 {
					// Drain остатка
					for {
						if p, ok := engine.spsc.Pop(); ok {
							atomic.AddUint64(&engine.totalRecv, 1)
							engine.pool.Put(p)
						} else {
							return
						}
					}
				}
				runtime.Gosched()
			}
		}
	}()

	// 2. Dedicated SPSC Producer
	wg.Add(1)
	go func() {
		defer wg.Done()
		for i := int64(1); i <= totalMessages/2; i++ {
			for {
				if err := engine.SendDirect(i); err == nil {
					break
				}
				runtime.Gosched()
			}
		}
	}()

	// 3. Shared MPMC Producers (4 воркера)
	const mpmcProducers = 4
	mpmcMsgsPerProducer := int64(totalMessages / 2 / mpmcProducers)
	for p := 0; p < mpmcProducers; p++ {
		wg.Add(1)
		go func(pid int) {
			defer wg.Done()
			for i := int64(1); i <= mpmcMsgsPerProducer; i++ {
				for {
					if err := engine.SendShared(int64(pid)*1000000 + i); err == nil {
						break
					}
					runtime.Gosched()
				}
			}
		}(p)
	}

	// 4. Shared MPMC Consumers (2 воркера)
	const mpmcConsumers = 2
	for c := 0; c < mpmcConsumers; c++ {
		wg.Add(1)
		go func() {
			defer wg.Done()
			for {
				p, ok := engine.mpmc.Pop()
				if ok {
					atomic.AddUint64(&engine.totalRecv, 1)
					engine.pool.Put(p)
				} else {
					if atomic.LoadUint32(&engine.closed) == 1 {
						for {
							if p, ok := engine.mpmc.Pop(); ok {
								atomic.AddUint64(&engine.totalRecv, 1)
								engine.pool.Put(p)
							} else {
								return
							}
						}
					}
					runtime.Gosched()
				}
			}
		}()
	}

	// Ожидаем завершения отправки половины
	time.Sleep(100 * time.Millisecond)
	engine.Shutdown()
	wg.Wait()
	dur := time.Since(start)

	sent := atomic.LoadUint64(&engine.totalSent)
	recv := atomic.LoadUint64(&engine.totalRecv)
	drops := atomic.LoadUint64(&engine.totalDrops)

	fmt.Println("==================================================")
	fmt.Println("  High-Performance Message Framework Finished!    ")
	fmt.Println("==================================================")
	fmt.Printf("Total Sent:       %d messages\n", sent)
	fmt.Printf("Total Received:   %d messages\n", recv)
	fmt.Printf("Total Drops:      %d messages\n", drops)
	fmt.Printf("Elapsed Time:     %v\n", dur)
	if dur.Seconds() > 0 {
		fmt.Printf("Throughput:       %.2f M msgs/sec\n", float64(recv)/dur.Seconds()/1e6)
	}
}
```

ℹ️ Финальный production-grade фреймворк обмена сообщениями на SPSC и MPMC очередях.

## Под капотом

Архитектура фреймворка сочетает преимущества SPSC для выделенных каналов точка-точка (с задержкой < 5 нс) и алгоритма Вьюкова для распределения задач между воркерами. Использование `sync.Pool` устраняет аллокации в hot-path, а правильный порядок остановки гарантирует, что ни одно сообщение не останется невычитанным в буфере при завершении приложения.

## Подводные камни

1. Забытый `Drain` при shutdown: если закрыть флаг `closed` и сразу завершить программу, сообщения, находящиеся между `head` и `tail`, останутся необработанными.
2. Возврат одного объекта в пул дважды: двойной `pool.Put` приведет к порче данных в параллельных потоках.

## На собеседовании

«Как устроен диспетчер задач в рантайме Go (GMP)?». Ответ: каждый логический процессор \(P\) имеет локальную очередь задач (Local Run Queue) размером 256 элементов, работающую по принципу Lock-Free кольцевого буфера без мьютексов. И только при опустошении локальной очереди поток \(M\) обращается к глобальной очереди задач (Global Run Queue) с захватом мьютекса или применяет Work Stealing у соседнего \(P\) через CAS.
