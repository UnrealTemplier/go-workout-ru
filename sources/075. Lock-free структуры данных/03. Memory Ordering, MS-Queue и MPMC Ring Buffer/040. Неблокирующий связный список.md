# Неблокирующий связный список (Harris Lock-Free Linked List)

## Условие

Реализуйте неблокирующий упорядоченный связный список по алгоритму Тимоти Харриса (Timothy Harris Lock-Free Linked List). Реализуйте двухфазное логическое и физическое удаление узлов с использованием битовой маркировки указателей (Marked Pointer).

### Исходная формулировка

**Lock-free linked list**: Реализуйте lock-free singly-linked list с insert и delete. Используйте CAS для pointer updates.

## Теория

Удаление узла из связного списка в конкурентной среде — сложнейшая задача:
Если поток 1 удаляет узел \(B\) (`A -> B -> C`), а параллельный поток 2 вставляет узел \(X\) после \(B\) (`B -> X -> C`), обычный CAS может привести к тому, что узел \(X\) окажется потерян!

**Алгоритм Тимоти Харриса (Timothy Harris, 2001)** решает эту проблему через **двухфазное удаление**:
1. **Логическое удаление (Logical Deletion)**:
   * Поток помечает младший бит указателя `B.next` специальным флагом (Marked Bit).
   * Адреса структур в памяти выровнены по 8 байтам, поэтому младшие 3 бита всегда равны 0. Установка младшего бита в 1 сообщает всем потокам: «Этот узел помечен на удаление! Вставлять за ним ничего нельзя!».
   * Попытка потока 2 вставить узел после помеченного провалится в CAS.
2. **Физическое удаление (Physical Deletion)**:
   * Поток перелинковывает `A.next` на `C` через CAS. Если поток прервется, любой другой проходящий поток, заметив помеченный узел, поможет физически отлинковать его (Helping Technique).

## Решение по шагам

1. Создайте структуру `ListNode` со значением и полем `next atomic.Uintptr`.
2. Реализуйте функции для работы с битом маркировки: `isMarked`, `getPointer`, `markPointer`.
3. Реализуйте метод `Insert(val int) bool`.
4. Реализуйте двухфазный метод `Delete(val int) bool`.
5. Протестируйте конкурентную вставку и удаление из 10 горутин.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"math"
	"sync"
	"sync/atomic"
	"unsafe"
)

const MarkMask = uintptr(1)
const PtrMask = ^MarkMask

type HarrisNode struct {
	value int
	next  atomic.Uintptr
}

func isMarked(ptr uintptr) bool {
	return (ptr & MarkMask) != 0
}

func getCleanPointer(ptr uintptr) *HarrisNode {
	return (*HarrisNode)(unsafe.Pointer(ptr & PtrMask))
}

func makeMarked(ptr uintptr) uintptr {
	return ptr | MarkMask
}

type HarrisList struct {
	head *HarrisNode
	tail *HarrisNode
}

func NewHarrisList() *HarrisList {
	tail := &HarrisNode{value: math.MaxInt}
	head := &HarrisNode{value: math.MinInt}
	head.next.Store(uintptr(unsafe.Pointer(tail)))
	return &HarrisList{head: head, tail: tail}
}

func (l *HarrisList) Search(val int) (prev, curr *HarrisNode, succ *HarrisNode) {
retry:
	for {
		prev = l.head
		curr = getCleanPointer(prev.next.Load())

		for {
			succRaw := curr.next.Load()
			succ = getCleanPointer(succRaw)

			// Если узел помечен на удаление — помогаем физически отлинковать его
			for isMarked(succRaw) {
				if !prev.next.CompareAndSwap(uintptr(unsafe.Pointer(curr)), uintptr(unsafe.Pointer(succ))) {
					continue retry
				}
				curr = succ
				succRaw = curr.next.Load()
				succ = getCleanPointer(succRaw)
			}

			if curr.value >= val {
				return prev, curr, succ
			}
			prev = curr
			curr = succ
		}
	}
}

func (l *HarrisList) Insert(val int) bool {
	newNode := &HarrisNode{value: val}
	for {
		prev, curr, _ := l.Search(val)
		if curr.value == val {
			return false // Уже есть
		}
		newNode.next.Store(uintptr(unsafe.Pointer(curr)))
		if prev.next.CompareAndSwap(uintptr(unsafe.Pointer(curr)), uintptr(unsafe.Pointer(newNode))) {
			return true
		}
	}
}

func (l *HarrisList) Delete(val int) bool {
	for {
		prev, curr, succ := l.Search(val)
		if curr.value != val {
			return false // Не найден
		}

		// Фаза 1: Логическое удаление (установка бита маркировки)
		succRaw := uintptr(unsafe.Pointer(succ))
		if !curr.next.CompareAndSwap(succRaw, makeMarked(succRaw)) {
			continue
		}

		// Фаза 2: Физическое отлинковывание
		prev.next.CompareAndSwap(uintptr(unsafe.Pointer(curr)), succRaw)
		return true
	}
}

func main() {
	list := NewHarrisList()
	const workers = 10
	const ops = 1000

	var wg sync.WaitGroup
	wg.Add(workers)

	// Конкурентные вставки
	for w := 0; w < workers; w++ {
		wID := w
		go func() {
			defer wg.Done()
			for i := 0; i < ops; i++ {
				list.Insert(wID*ops + i)
			}
		}()
	}
	wg.Wait()

	// Конкурентные удаления
	wg.Add(workers)
	for w := 0; w < workers; w++ {
		wID := w
		go func() {
			defer wg.Done()
			for i := 0; i < ops; i++ {
				list.Delete(wID*ops + i)
			}
		}()
	}
	wg.Wait()

	fmt.Println("Harris Lock-Free Linked List: стресс-тест двухфазного удаления пройден успешно!")
}
```

ℹ️ Список Харриса использует младший бит указателя для атомарного логического удаления узлов.

## Под капотом

В алгоритме Харриса логическая пометка узла `curr.next.CAS(succ, succ | 1)` атомарно блокирует любые вставки после узла `curr`, так как любой конкурентный `Insert` проверяет чистый адрес `curr.next`. При последующем обходе читающие и пишущие потоки, обнаружив установленный бит маркировки, самостоятельно завершают физическое отлинковывание через `prev.next.CAS(curr, succ)`.

## Подводные камни

1. Разыменование помеченного указателя: попытка обратиться по адресу `ptr | 1` вызовет аппаратное прерывание SIGSEGV, так как адрес не выровнен. Перед разыменованием обязательно маскирование: `ptr &^ 1`.
2. Зависание в цикле Search при тяжелом контеншне.

## На собеседовании

Вопрос: «Как удалить узел из lock-free связного списка без риска потерять параллельно вставленный узел?». Ответ: алгоритм Тимоти Харриса с двухфазным удалением (Marked Pointers). Сначала атомарно маркируется младший бит указателя next удаляемого узла, что предотвращает новые вставки за ним, а затем узел физически отлинковывается от предыдущего элемента.
