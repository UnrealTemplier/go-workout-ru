# Хранение списков в массивах PostgreSQL: тип text[] и адаптер pq.Array

## Условие

**Arrays**: Сохраните слайс строк (теги) в колонку типа `text[]`. Используйте пакет `pq.Array` или нативную поддержку массивов в `pgx`.

### Исходная формулировка

**Arrays**: Сохраните слайс строк (теги) в колонку типа `text[]`. Используйте пакет `github.com/lib/pq` и функцию `pq.Array()` для корректного сканирования массива из БД в Go-слайс.

## Теория

Массивы в PostgreSQL:
PostgreSQL поддерживает нативные одномерные и многомерные массивы (`text[]`, `int[]`, `uuid[]`). Драйверы позволяют маппить срез Go `[]string` напрямую в колонку `text[]` без промежуточной сериализации в JSON.

## Решение по шагам

1. Создадим таблицу `tagged_posts (id SERIAL, title TEXT, tags TEXT[])`.
2. Используем `pq.Array(slice)` или нативный срез в `pgx`.
3. Вставим запись с массивом тегов.
4. Отсканируем массив обратно в `[]string`.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
	"github.com/lib/pq"
)

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	_, _ = db.Exec(`
	CREATE TABLE IF NOT EXISTS tagged_posts (
		id SERIAL PRIMARY KEY,
		title TEXT NOT NULL,
		tags TEXT[] NOT NULL
	);`)

	tags := []string{"golang", "postgresql", "backend", "docker"}

	// 1. Вставка среза через pq.Array
	query := "INSERT INTO tagged_posts (title, tags) VALUES ($1, $2) RETURNING id"
	var postID int
	err := db.QueryRow(query, "Архитектура Go сервисов", pq.Array(tags)).Scan(&postID)
	if err != nil {
		panic(err)
	}

	// 2. Сканирование массива обратно в []string
	var fetchedTags []string
	err = db.QueryRow("SELECT tags FROM tagged_posts WHERE id = $1", postID).Scan(pq.Array(&fetchedTags))
	if err != nil {
		panic(err)
	}

	fmt.Printf("✔ Успешно сохранен пост #%d с массивом тегов (%d шт.):\n", postID, len(fetchedTags))
	for _, t := range fetchedTags {
		fmt.Printf("  • #%s\n", t)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Успешно сохранен пост #1 с массивом тегов (4 шт.):
#   • #golang
#   • #postgresql
#   • #backend
#   • #docker
```

## Под капотом

В PostgreSQL массивы сериализуются в строковый формат вида `{"val1","val2"}`. `pq.Array` реализует интерфейсы `sql.Scanner` и `driver.Valuer` для прозрачной конвертации.

## Подводные камни

Попытка передать сырой `[]string` без обертки `pq.Array` в стандартном `database/sql` вызовет ошибку `sql: converting Exec argument #1 type: unsupported type []string`.

## На собеседовании

**Вопрос с собеседования:** «Как эффективно искать записи по вхождению элемента в массив PostgreSQL (например, посты с тегом #golang)?»
**Ответ:** Использовать оператор включения массивов `WHERE tags @> ARRAY['golang']::text[]` в сочетании с GIN-индексом: `CREATE INDEX idx_posts_tags ON tagged_posts USING gin(tags)`. Запрос выполняется мгновенно по инвертированному списку.
