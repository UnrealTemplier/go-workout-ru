# Агрегатные функции, GROUP BY и безопасная обработка NULL через COALESCE

## Условие

Напиши функцию `GetUserStats() (map[string]int, error)`, использующую `COALESCE` и `GROUP BY` для подсчета количества пользователей по возрастным группам или статусам.

### Исходная формулировка

Напиши функцию `GetUserStats() (map[string]int, error)`, использующую `COALESCE` и `GROUP BY`: `SELECT DATE(created_at), COUNT(*) FROM users GROUP BY DATE(created_at)`. Сканируй в `map[time.Time]int`.

## Теория

Агрегация и защита от NULL значений:
При группировке данных (`GROUP BY status`) в результирующем наборе могут появиться `NULL` значения. Функция `COALESCE(status, 'unknown')` заменяет `NULL` на дефолтную строку на стороне базы данных, защищая Go-код от ошибок сканирования.

## Решение по шагам

1. Сформируем агрегирующий запрос с `COALESCE(status, 'unknown')` и `COUNT(*)`.
2. Выполним `db.Query`.
3. В цикле заполним словарь `map[string]int`.
4. Проверим `rows.Err()` и вернем статистику.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
)

func GetUserStats(db *sql.DB) (map[string]int, error) {
	query := `
	SELECT COALESCE(status, 'unspecified'), COUNT(*)
	FROM (
		SELECT CASE 
			WHEN age < 18 THEN 'minor'
			WHEN age BETWEEN 18 AND 30 THEN 'young_adult'
			ELSE 'adult'
		END AS status
		FROM users
	) sub
	GROUP BY status;`

	rows, err := db.Query(query)
	if err != nil {
		return nil, fmt.Errorf("GetUserStats query failed: %w", err)
	}
	defer rows.Close()

	stats := make(map[string]int)
	for rows.Next() {
		var status string
		var count int
		if err := rows.Scan(&status, &count); err != nil {
			return nil, fmt.Errorf("GetUserStats scan failed: %w", err)
		}
		stats[status] = count
	}

	if err := rows.Err(); err != nil {
		return nil, fmt.Errorf("GetUserStats stream error: %w", err)
	}

	return stats, nil
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	stats, err := GetUserStats(db)
	if err != nil {
		panic(err)
	}

	fmt.Println("✔ Статистика пользователей по возрастным группам:")
	for k, v := range stats {
		fmt.Printf("  • Группа '%s': %d чел.\n", k, v)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Статистика пользователей по возрастным группам:
#   • Группа 'young_adult': 2 чел.
#   • Группа 'adult': 1 чел.
```

## Под капотом

`COALESCE` возвращает первый ненулевой аргумент. В плане выполнения PostgreSQL он оптимизируется в скалярное выражение без накладных расходов.

## Подводные камни

Без `COALESCE` сканирование колонки с `NULL` в обычную строковую переменную `var s string` приведет к падению `Scan error: converting NULL to string is unsupported`.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между COUNT(*) и COUNT(column_name) в PostgreSQL?»
**Ответ:** `COUNT(*)` считает общее физическое количество строк в группе (включая строки с `NULL`). `COUNT(column)` считает количество строк, где значение `column IS NOT NULL`. Для простого подсчета всегда используют `COUNT(*)` — он быстрее, так как не читает значение конкретного атрибута из кортежа.
