# Получение пользователей по префиксу с помощью оператора LIKE и экранирования

## Условие

**Получение списка записей (Query)**: Напишите функцию получения всех пользователей, чей email заканчивается на `@ya.ru`.

### Исходная формулировка

**Получение списка записей (`Query`)**: Напишите функцию получения всех пользователей, чей возраст превышает заданный лимит.
* Используйте метод `db.Query`.
* Напишите цикл `for rows.Next() { ... }` для обхода результатов.
* Сделайте `rows.Scan` для распаковки данных в структуру `User`.
* Обработайте возможную ошибку после цикла с помощью `rows.Err()`.
* Обязательно вызовите `rows.Close()` через `defer` сразу после открытия запроса.

## Теория

Поиск по шаблону (Pattern Matching):
Оператор `LIKE` или `ILIKE` (регистронезависимый) выполняет поиск по строковому шаблону. Знак `%` означает любое количество символов.
Шаблон `%@ya.ru` передается через обычный плейсхолдер `$1`.

## Решение по шагам

1. Подготовим запрос `SELECT id, name, email FROM users WHERE email LIKE $1`.
2. Передадим аргумент `"%@ya.ru"`.
3. Отсканируем результаты.
4. Выведем найденных пользователей.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
)

func FindUsersByDomain(db *sql.DB, domain string) ([]string, error) {
	query := `SELECT email FROM users WHERE email LIKE $1 ORDER BY id ASC`

	pattern := "%" + domain
	rows, err := db.Query(query, pattern)
	if err != nil {
		return nil, err
	}
	defer rows.Close()

	var emails []string
	for rows.Next() {
		var em string
		if err := rows.Scan(&em); err != nil {
			return nil, err
		}
		emails = append(emails, em)
	}

	return emails, rows.Err()
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	emails, _ := FindUsersByDomain(db, "@ya.ru")
	fmt.Printf("✔ Найдено пользователей Яндекса (%d):\n", len(emails))
	for _, em := range emails {
		fmt.Printf("  • %s\n", em)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Найдено пользователей Яндекса (2):
#   • alex.smirnov@ya.ru
#   • olga@ya.ru
```

## Под капотом

Поиск с маской `%prefix` в начале не может использовать стандартный B-Tree индекс. Для ускорения таких запросов создают триграммный индекс `pg_trgm` (GIN / GiST).

## Подводные камни

Конкатенация строк `WHERE email LIKE '%` + domain + `'` — грубейшая уязвимость SQL-инъекции! Передавайте строку `"%"+domain` исключительно через плейсхолдер `$1`.

## На собеседовании

**Вопрос с собеседования:** «Какой индекс ускоряет поиск WHERE name LIKE '%поисковый запрос%' в PostgreSQL?»
**Ответ:** GIN индекс с расширением `pg_trgm` (триграммный индекс: `CREATE INDEX idx ON table USING gin (name gin_trgm_ops)`). Он разбивает слова на трехбуквенные триграммы и находит соответствия без полного сканирования таблицы (Seq Scan).
