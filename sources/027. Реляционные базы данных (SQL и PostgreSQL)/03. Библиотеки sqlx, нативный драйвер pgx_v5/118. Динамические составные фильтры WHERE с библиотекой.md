# Динамические составные фильтры WHERE с библиотекой squirrel

## Условие

Напиши динамический WHERE через squirrel: `q := sq.Select("*").From("users")`. Если `name != ""` добавь `Where(sq.Eq{"name": name})`, если `age > 0` добавь `Where(sq.Gt{"age": age})`.

### Исходная формулировка

Напиши динамический WHERE через squirrel: `q := sq.Select("*").From("users")`. Если `name != ""` — `q = q.Where(sq.ILike{"name": "%" + name + "%"}`). Если `minAge > 0` — `q = q.Where(sq.GtOrEq{"age": minAge})`. Собери запрос.

## Теория

Условное конструирование фильтров:
В интернет-магазинах фильтрация каталога динамическая: пользователь может выбрать только категорию, только цену или оба фильтра одновременно. Squirrel позволяет цепочкой добавлять условия в зависимости от параметров запроса.

## Решение по шагам

1. Создадим базовый билдер `sq.Select(...)`.
2. Добавим условия через `if` проверки.
3. Сгенерируем финальный SQL с плейсхолдерами.
4. Выполним запрос.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	sq "github.com/Masterminds/squirrel"
	_ "github.com/jackc/pgx/v5/stdlib"
)

type UserFilter struct {
	Name string
	MinAge int
}

func SearchUsers(db *sql.DB, f UserFilter) error {
	psql := sq.StatementBuilder.PlaceholderFormat(sq.Dollar)
	q := psql.Select("id", "name", "age").From("users")

	if f.Name != "" {
		q = q.Where(sq.Eq{"name": f.Name})
	}
	if f.MinAge > 0 {
		q = q.Where(sq.GtOrEq{"age": f.MinAge})
	}

	sqlStr, args, err := q.ToSql()
	if err != nil {
		return err
	}

	fmt.Printf("✔ Динамический SQL: %s\n  Параметры: %v\n", sqlStr, args)
	return nil
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	// Тест 1: только возраст
	_ = SearchUsers(db, UserFilter{MinAge: 20})

	// Тест 2: имя и возраст
	_ = SearchUsers(db, UserFilter{Name: "Ольга", MinAge: 18})
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Динамический SQL: SELECT id, name, age FROM users WHERE age >= $1
#   Параметры: [20]
# ✔ Динамический SQL: SELECT id, name, age FROM users WHERE name = $1 AND age >= $2
#   Параметры: [Ольга 18]
```

## Под капотом

Squirrel объединяет несколько вызовов `Where()` через логический оператор `AND`.

## Подводные камни

Поскольку билдер возвращает новый объект `q = q.Where(...)`, незаписанный результат `q.Where(...)` приведет к потере условия.

## На собеседовании

**Вопрос с собеседования:** «Как в Squirrel объединить условия через OR?»
**Ответ:** Использовать конструкцию `sq.Or{sq.Eq{"status": "new"}, sq.Eq{"status": "pending"}}`. Squirrel автоматически обернет условия в скобки `(status = $1 OR status = $2)`, сохраняя приоритет логических операторов.
