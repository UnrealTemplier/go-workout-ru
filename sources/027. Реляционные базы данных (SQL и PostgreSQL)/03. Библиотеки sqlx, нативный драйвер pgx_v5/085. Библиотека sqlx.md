# Библиотека sqlx: маппинг строк в структуры через Get, Select и StructScan

## Условие

Используйте `github.com/jmoiron/sqlx` для упрощённого сканирования структур: напишите выборку одиночной записи через `db.Get` и списка записей через `db.Select`.

### Исходная формулировка

Используйте `sqlx` для упрощённого сканирования структур: `Select`, `Get`, `NamedExec`.

## Теория

Преимущества библиотеки sqlx над database/sql:
`sqlx` — популярное легковесное расширение над стандартным пакетом:
- Метод `db.Get(&struct, query, args...)`: заменяет громоздкий `QueryRow().Scan(&a, &b, &c)`.
- Метод `db.Select(&slice, query, args...)`: заменяет цикл `for rows.Next()` и `rows.Scan`.
- Автоматический маппинг колонок в поля структур по тегам `db:"column_name"`.

## Решение по шагам

1. Установим `sqlx` и подключимся через `sqlx.Connect("pgx", dsn)`.
2. Выберем одну запись через `db.Get`.
3. Выберем срез записей через `db.Select`.
4. Оценим краткость кода.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
	"github.com/jmoiron/sqlx"
)

type User struct {
	ID    int    `db:"id"`
	Name  string `db:"name"`
	Age   int    `db:"age"`
	Email string `db:"email"`
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, err := sqlx.Connect("pgx", dsn)
	if err != nil {
		panic(err)
	}
	defer db.Close()

	// 1. Чтение одиночной записи в структуру в одну строчку (Get)
	var singleUser User
	err = db.Get(&singleUser, "SELECT id, name, age, email FROM users WHERE id = $1", 1)
	if err != nil {
		panic(err)
	}
	fmt.Printf("✔ sqlx.Get: %+v\n", singleUser)

	// 2. Чтение списка записей в срез без циклов и scan (Select)
	var users []User
	err = db.Select(&users, "SELECT id, name, age, email FROM users ORDER BY id ASC LIMIT 3")
	if err != nil {
		panic(err)
	}

	fmt.Printf("✔ sqlx.Select вычитал %d пользователей:\n", len(users))
	for _, u := range users {
		fmt.Printf("  • [%d] %s (%s)\n", u.ID, u.Name, u.Email)
	}
}
```

**`Терминал`**

```bash
go get github.com/jmoiron/sqlx
go run main.go
# Вывод:
# ✔ sqlx.Get: {ID:1 Name:Алексей Смирнов Age:29 Email:alex.smirnov@ya.ru}
# ✔ sqlx.Select вычитал 3 пользователей:

#   • [2] Ольга (olga@ya.ru)

```

## Под капотом

`sqlx` использует пакет `reflect` и парсит теги `db:"..."` при старте, кэшируя соответствие колонок смещениям полей структуры.

## Подводные камни

Если в SELECT запросе указать колонку, которой нет в полях структуры, `sqlx` упадет с ошибкой `missing destination name in struct`. Чтобы игнорировать лишние поля, используют `db.Unsafe()`.

## На собеседовании

**Вопрос с собеседования:** «В чем накладные расходы sqlx по сравнению с чистым database/sql?»
**Ответ:** `sqlx` использует рефлексию (`reflect.Value`), создавая незначительные дополнительные аллокации памяти при первом разборе типов. Однако он сохраняет полную скорость работы за счет кэширования метаданных структур и исключает человеческие ошибки сканирования аргументов по неверным индексам.
