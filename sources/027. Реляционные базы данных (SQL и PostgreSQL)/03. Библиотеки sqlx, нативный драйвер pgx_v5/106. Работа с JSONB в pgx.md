# Работа с JSONB в pgx: сканирование в map[string]any и пользовательские структуры

## Условие

Используй `pgx` с **JSONB**: колонка `data JSONB`. Сканируй напрямую в `map[string]any` или в структуру с тегами `json:"..."` без промежуточных конвертаций строк.

### Исходная формулировка

Используй `pgx` с **JSONB**: колонка `data JSONB`. Сканируй в `map[string]any` или структуру с `json` тегами. Вставляй структуру — pgx сериализует в JSON.

## Теория

Десериализация JSONB в pgx:
`pgx` автоматически декодирует бинарный JSONB в любую структуру Go, реализующую стандартные правила `encoding/json`, или в динамический `map[string]any`.

## Решение по шагам

1. Создадим таблицу с колонкой `payload JSONB`.
2. Сохраним объект конфигурации.
3. Считаем напрямую в `map[string]any`.
4. Проверим извлеченные ключи.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"

	"github.com/jackc/pgx/v5/pgxpool"
)

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	ctx := context.Background()
	pool, err := pgxpool.New(ctx, dsn)
	if err != nil {
		panic(err)
	}
	defer pool.Close()

	_, _ = pool.Exec(ctx, `
	CREATE TABLE IF NOT EXISTS jsonb_pgx (
		id SERIAL PRIMARY KEY,
		payload JSONB NOT NULL
	);`)

	inputMap := map[string]any{
		"service": "auth-service",
		"port":    8080,
		"active":  true,
	}

	var id int
	// pgx автоматически маршалит map в JSONB
	err = pool.QueryRow(ctx, "INSERT INTO jsonb_pgx (payload) VALUES ($1) RETURNING id", inputMap).Scan(&id)
	if err != nil {
		panic(err)
	}

	// Сканируем напрямую в map[string]any
	var outputMap map[string]any
	err = pool.QueryRow(ctx, "SELECT payload FROM jsonb_pgx WHERE id = $1", id).Scan(&outputMap)
	if err != nil {
		panic(err)
	}

	fmt.Printf("✔ pgx автоматически десериализовал JSONB в map: %+v\n", outputMap)
	fmt.Printf("  Сервис: %v (тип %T)\n", outputMap["service"], outputMap["service"])
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ pgx автоматически десериализовал JSONB в map: map[active:true port:8080 service:auth-service]
#   Сервис: auth-service (тип string)
```

## Под капотом

Драйвер `pgx` проверяет тип приемника: если это указатель на `map` или `struct`, он направляет поток байтов прямо во встроенный декодер `json.Unmarshal`.

## Подводные камни

Числа в `map[string]any` по умолчанию десериализуются как `float64`, поэтому `outputMap["port"]` имеет тип float64, а не int.

## На собеседовании

**Вопрос с собеседования:** «Как проиндексировать вложенное поле JSONB документа в PostgreSQL?»
**Ответ:** Создать функциональный B-Tree индекс на конкретное поле: `CREATE INDEX idx_port ON jsonb_pgx (((payload->>'port')::int))`. При запросе `WHERE (payload->>'port')::int = 8080` СУБД выполнит мгновенный `Index Scan` вместо разбора всех JSON-документов.
