# Построитель динамических SQL-запросов: библиотека squirrel с синтаксисом $1

## Условие

Используй `github.com/Masterminds/squirrel` для построения SQL: `sq.Select("id", "name").From("users").Where(sq.Eq{"status": "active"}).PlaceholderFormat(sq.Dollar)`.

### Исходная формулировка

Используй `github.com/Masterminds/squirrel` для построения SQL: `sq.Select("id", "name").From("users").Where(sq.Eq{"id": 1}).ToSql()`. Покажи, что builder предотвращает SQL-инъекции и делает код читаемым.

## Теория

Query Builder Squirrel:
Конкатенация строк в Go для динамических фильтров (`if name != "" { query += ... }`) приводит к ошибкам в расстановке пробелов и плейсхолдеров.
Библиотека `squirrel` предоставляет Fluent API для безопасной сборки параметризованных SQL-запросов.

## Решение по шагам

1. Создадим строитель с форматом долларов `sq.StatementBuilder.PlaceholderFormat(sq.Dollar)`.
2. Сформируем запрос через методы `Select`, `From`, `Where`.
3. Скомпилируем в SQL и аргументы через `ToSql()`.
4. Выполним запрос в базе.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	sq "github.com/Masterminds/squirrel"
	_ "github.com/jackc/pgx/v5/stdlib"
)

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	// Строитель запросов с поддержкой синтаксиса $1, $2 для PostgreSQL
	psql := sq.StatementBuilder.PlaceholderFormat(sq.Dollar)

	queryBuilder := psql.Select("id", "name", "email").
		From("users").
		Where(sq.Gt{"age": 18}).
		OrderBy("id ASC").
		Limit(2)

	sqlString, args, err := queryBuilder.ToSql()
	if err != nil {
		panic(err)
	}

	fmt.Printf("✔ Сгенерированный Squirrel SQL: %s\n", sqlString)
	fmt.Printf("  Аргументы: %v\n", args)

	rows, err := db.Query(sqlString, args...)
	if err != nil {
		panic(err)
	}
	defer rows.Close()

	for rows.Next() {
		var id int
		var name, email string
		_ = rows.Scan(&id, &name, &email)
		fmt.Printf("  • [%d] %s (%s)\n", id, name, email)
	}
}
```

**`Терминал`**

```bash
go get github.com/Masterminds/squirrel
go run main.go
# Вывод:

#   • [1] Алексей (Обновлен) (alex.smirnov@ya.ru)

```

## Под капотом

Squirrel собирает дерево выражений и при вызове `ToSql()` обходит его, нумеруя плейсхолдеры `$1, $2...` и наполняя срез аргументов.

## Подводные камни

Забытый `PlaceholderFormat(sq.Dollar)` приведет к генерации знаков вопроса `?` (MySQL формат), что завершится ошибкой в PostgreSQL.

## На собеседовании

**Вопрос с собеседования:** «Почему в BigTech предпочитают Query Builder (squirrel) полноценным ORM (GORM, Ent)?»
**Ответ:** Полноценные ORM скрывают реальный SQL, генерируют неоптимальные планы, используют тяжелую рефлексию и скрытые неявные транзакции. Query Builder дает 100% контроль над текстом SQL, безопасность параметров и нулевой оверхед на скрытые запросы.
