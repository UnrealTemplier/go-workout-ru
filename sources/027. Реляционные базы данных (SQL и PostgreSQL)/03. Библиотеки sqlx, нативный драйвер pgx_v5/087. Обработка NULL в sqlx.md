# Обработка NULL в sqlx: теги db и структуры sql.NullString

## Условие

**NULL значения в sqlx**: Создайте колонку, которая может быть `NULL`. Просканируйте строку с помощью `sqlx.Get` в структуру с `sql.NullString`.

### Исходная формулировка

**NULL значения**: Создайте колонку, которая может быть `NULL`. Попробуйте просканировать её в обычный `string` и получите панику. Используйте `sql.NullString` или `sql.NullInt64`.

## Теория

Маппинг NULL в sqlx:
При использовании `sqlx.Get` или `sqlx.Select` сканирование колонки со значением `NULL` в обычное поле `string` вызовет ошибку. В модели данных используют структуры `sql.NullString`, `sql.NullInt64` или указатели `*string`.

## Решение по шагам

1. Опишем структуру `UserProfile` с полем `Bio sql.NullString`.
2. Выполним выборку через `db.Get`.
3. Проверим флаг `Bio.Valid`.
4. Выведем результат.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
	"github.com/jmoiron/sqlx"
)

type UserProfile struct {
	ID   int            `db:"id"`
	Name string         `db:"name"`
	Bio  sql.NullString `db:"bio"`
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sqlx.Connect("pgx", dsn)
	defer db.Close()

	var p UserProfile
	err := db.Get(&p, "SELECT id, name, bio FROM users WHERE email = $1", "anon@mail.ru")
	if err != nil {
		panic(err)
	}

	fmt.Printf("✔ sqlx успешно смаппил nullable строку в UserProfile:\n")
	fmt.Printf("  • Имя: %s\n", p.Name)
	if p.Bio.Valid {
		fmt.Printf("  • Биография: %s\n", p.Bio.String)
	} else {
		fmt.Println("  • Биография: [NULL]")
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ sqlx успешно смаппил nullable строку в UserProfile:
#   • Имя: Аноним
#   • Биография: [NULL]
```

## Под капотом

`sqlx` распознает, что `sql.NullString` реализует интерфейс `sql.Scanner`, и делегирует сканирование методу `Scan` этой структуры.

## Подводные камни

Если в структуре объявить `Bio string` вместо `sql.NullString`, запрос завершится ошибкой конвертации при первом же пользователе с пустым профилем.

## На собеседовании

**Вопрос с собеседования:** «Как sqlx обрабатывает вложенные структуры (Embedded Structs)?»
**Ответ:** По умолчанию `sqlx` «разворачивает» поля вложенных анонимных структур на верхний уровень кортежа, сопоставляя их тегам колонок базы данных. Это позволяет переиспользовать общие структуры (например, `type AuditFields struct { CreatedAt, UpdatedAt time.Time }`).
