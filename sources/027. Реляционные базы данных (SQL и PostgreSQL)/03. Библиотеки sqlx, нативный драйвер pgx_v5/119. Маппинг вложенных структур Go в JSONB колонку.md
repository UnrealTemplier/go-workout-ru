# Маппинг вложенных структур Go в JSONB колонку: имплементация Scanner и Valuer

## Условие

**Работа с JSONB**: Создай в базе колонку типа `JSONB`. В Go создай вложенную структуру. Реализуй методы `Scan` и `Value` для прозрачной записи и чтения без ручного json.Marshal.

### Исходная формулировка

**Работа с JSONB**: Создай в базе колонку типа `JSONB`. В Go создай вложенную структуру. При вставке передай её напрямую (pgx сам сериализует её в JSON, если правильно настроить, или используй ручной Marshal). При чтении распарси JSONB обратно в структуру.

## Теория

Паттерн Transparent JSONB Entity:
Если структура реализует `driver.Valuer` и `sql.Scanner`, ее можно передавать напрямую в `db.Exec`, `db.QueryRow` и сканировать в `.Scan(&entity)` как обычный примитивный тип Go.

## Решение по шагам

1. Объявим структуру `type MetaData struct { IP, UserAgent string }`.
2. Реализуем метод `Value() (driver.Value, error)` через `json.Marshal`.
3. Реализуем метод `Scan(src any) error` через `json.Unmarshal`.
4. Выполним прямую запись и чтение.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"database/sql/driver"
	"encoding/json"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
)

type DeviceInfo struct {
	OS      string `json:"os"`
	Browser string `json:"browser"`
}

// Value прозрачно конвертирует структуру в JSONB байты для СУБД
func (d DeviceInfo) Value() (driver.Value, error) {
	return json.Marshal(d)
}

// Scan прозрачно читает JSONB байты из базы в структуру Go
func (d *DeviceInfo) Scan(src any) error {
	if src == nil {
		return nil
	}
	bytes, ok := src.([]byte)
	if !ok {
		return fmt.Errorf("cannot scan %T into DeviceInfo", src)
	}
	return json.Unmarshal(bytes, d)
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	_, _ = db.Exec(`CREATE TABLE IF NOT EXISTS audit_logs (id SERIAL, device JSONB);`)

	dev := DeviceInfo{OS: "Linux Ubuntu", Browser: "Chrome 128"}

	// Запись напрямую (срабатывает dev.Value())
	var id int
	_ = db.QueryRow("INSERT INTO audit_logs (device) VALUES ($1) RETURNING id", dev).Scan(&id)

	// Чтение напрямую (срабатывает readDev.Scan())
	var readDev DeviceInfo
	_ = db.QueryRow("SELECT device FROM audit_logs WHERE id = $1", id).Scan(&readDev)

	fmt.Printf("✔ Прозрачный маппинг вложенной структуры в JSONB:\n  OS: %s | Browser: %s\n",
		readDev.OS, readDev.Browser)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Прозрачный маппинг вложенной структуры в JSONB:
#   OS: Linux Ubuntu | Browser: Chrome 128
```

## Под капотом

Драйвер проверяет тип аргумента через интерфейсы стандартной библиотеки, автоматически запуская маршалинг и демаршалинг.

## Подводные камни

Если в структуре есть приватные неэкспортируемые поля (с маленькой буквы), стандартный `json.Marshal` проигнорирует их.

## На собеседовании

**Вопрос с собеседования:** «Почему в микросервисах часто хранят нестабильные метаданные в JSONB вместо создания 20 отдельных колонок?»
**Ответ:** Это снижает стоимость изменения схемы (Schema Evolution). Добавление нового атрибута трекинга или параметров платежной системы не требует блокирующих миграций `ALTER TABLE`. Документ просто расширяется новыми JSON-ключами.
