# Динамические срезы в WHERE IN запросах: sqlx.In и безопасная интерполяция

## Условие

**sqlx.In**: Решите проблему динамического `IN (...)` запроса, используя `sqlx.In` для автоматического разворачивания слайса в плейсхолдеры `$1, $2, $3`.

### Исходная формулировка

**sqlx.In**: Решите проблему динамического `IN (...)` запроса, используя `sqlx.In` для автоматического расширения плейсхолдеров.

## Теория

Проблема оператора IN в SQL:
SQL не позволяет написать `WHERE id IN ($1)` и передать срез `[]int{1, 2, 3}` как один параметр. Требуется динамически сгенерировать `$1, $2, $3` по размеру среза.
Функция `sqlx.In(query, slice)` разворачивает срез в нужное количество знаков `?`, а метод `db.Rebind(query)` транслирует `?` в позиционные `$1, $2, $3` для PostgreSQL.

## Решение по шагам

1. Сформируем запрос с плейсхолдером `WHERE id IN (?)`.
2. Вызовем `query, args, err := sqlx.In(query, ids)`.
3. Переведем в синтаксис PostgreSQL через `db.Rebind(query)`.
4. Выполним выборку через `db.Select`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
	"github.com/jmoiron/sqlx"
)

type UserItem struct {
	ID   int    `db:"id"`
	Name string `db:"name"`
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, err := sqlx.Connect("pgx", dsn)
	if err != nil {
		panic(err)
	}
	defer db.Close()

	targetIDs := []int{1, 2, 3}

	// 1. Запрос со знаком '?'
	rawQuery := "SELECT id, name FROM users WHERE id IN (?) ORDER BY id ASC"

	// 2. sqlx.In разворачивает срез в '?, ?, ?'
	query, args, err := sqlx.In(rawQuery, targetIDs)
	if err != nil {
		panic(err)
	}

	// 3. Rebind транслирует '?' в '$1, $2, $3' для PostgreSQL
	query = db.Rebind(query)

	var users []UserItem
	err = db.Select(&users, query, args...)
	if err != nil {
		panic(err)
	}

	fmt.Printf("✔ sqlx.In успешно сформировал запрос: %s\n", query)
	for _, u := range users {
		fmt.Printf("  • [%d] %s\n", u.ID, u.Name)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ sqlx.In успешно сформировал запрос: SELECT id, name FROM users WHERE id IN ($1, $2, $3) ORDER BY id ASC
#   • [1] Алексей (Обновлен)
#   • [2] Ольга
#   • [3] Сергей Петров
```

## Под капотом

`sqlx.In` использует инспекцию типов через рефлексию, разбирает срез и возвращает плоский срез `[]any`.

## Подводные камни

Если передать в `sqlx.In` пустой срез `[]int{}`, сформируется невалидный SQL `IN ()`. Перед вызовом всегда проверяйте `if len(slice) == 0`.

## На собеседовании

**Вопрос с собеседования:** «Как в PostgreSQL сделать WHERE id IN (...) без использования sqlx.In?»
**Ответ:** Использовать конструкцию `WHERE id = ANY($1)` и передать срез напрямую в драйвер (через `pq.Array(ids)` или нативный срез в `pgx`). Запрос всегда имеет ровно один плейсхолдер `$1`, независимо от количества элементов в слайсе, что эффективнее и не требует динамической генерации SQL.
