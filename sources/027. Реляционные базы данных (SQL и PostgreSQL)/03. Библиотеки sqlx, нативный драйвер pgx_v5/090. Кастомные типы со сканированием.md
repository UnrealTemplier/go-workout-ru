# Кастомные типы со сканированием: реализация интерфейсов sql.Scanner и driver.Valuer

## Условие

**Кастомные Null-типы**: Реализуйте собственный тип `type CustomDate string`, реализующий `sql.Scanner` и `driver.Valuer` для сериализации/десериализации дат в формате ДД.ММ.ГГГГ.

### Исходная формулировка

**Кастомные Null-типы**: Реализуйте собственные типы (например, `NullTime`), которые реализуют интерфейсы `sql.Scanner` и `driver.Valuer` для более удобной работы с `null` в JSON-сериализации (чтобы `null` отдавался как `null`, а не как `{"Time": "...", "Valid": true}`).

## Теория

Контракты интеграции пользовательских типов в database/sql:
- `driver.Valuer`: метод `Value() (driver.Value, error)` указывает, как преобразовать Go-тип в понятный СУБД тип (int, string, []byte, nil).
- `sql.Scanner`: метод `Scan(src any) error` указывает, как десериализовать пришедшие из базы сырые байты в структуру Go.

## Решение по шагам

1. Объявим тип `type RuDate time.Time`.
2. Реализуем метод `Value()` для конвертации в timestamp базы.
3. Реализуем метод `Scan()` для разбора даты.
4. Проверим запись и чтение.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"database/sql/driver"
	"fmt"
	"time"

	_ "github.com/jackc/pgx/v5/stdlib"
)

type RuDate time.Time

// Value реализует driver.Valuer (Go -> SQL)
func (d RuDate) Value() (driver.Value, error) {
	return time.Time(d), nil
}

// Scan реализует sql.Scanner (SQL -> Go)
func (d *RuDate) Scan(src any) error {
	if src == nil {
		*d = RuDate(time.Time{})
		return nil
	}
	t, ok := src.(time.Time)
	if !ok {
		return fmt.Errorf("cannot scan %T into RuDate", src)
	}
	*d = RuDate(t)
	return nil
}

func (d RuDate) String() string {
	return time.Time(d).Format("02.01.2006")
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	date := RuDate(time.Date(2026, 9, 3, 0, 0, 0, 0, time.UTC))

	var fetchedDate RuDate
	err := db.QueryRow("SELECT $1::timestamptz", date).Scan(&fetchedDate)
	if err != nil {
		panic(err)
	}

	fmt.Printf("✔ Кастомный тип RuDate успешно сериализован и прочитан: %s\n", fetchedDate)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Кастомный тип RuDate успешно сериализован и прочитан: 03.09.2026
```

## Под капотом

Драйвер использует type assertion `v, ok := val.(driver.Valuer)` перед отправкой параметра и `s, ok := dest.(sql.Scanner)` при декодировании строки.

## Подводные камни

Метод `Scan` ОБЯЗАН иметь получатель-указатель `(d *RuDate)`, иначе изменения запишутся в копию и потеряются.

## На собеседовании

**Вопрос с собеседования:** «Почему метод Scan требует pointer receiver, а метод Value — value receiver?»
**Ответ:** `Scan` модифицирует внутреннее состояние вызывающего объекта, записывая разобранные данные — для этого требуется мутация по указателю. `Value` только считывает данные для сериализации, поэтому ему достаточно работать со значением (Value Receiver), защищая объект от непреднамеренной модификации.
