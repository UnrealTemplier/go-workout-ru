# Выполнение DDL запросов: функция initDB с созданием таблицы users через db.Exec

## Условие

**Создание таблицы через Go**: Напиши функцию `initDB()`, которая выполняет `CREATE TABLE IF NOT EXISTS users (id SERIAL PRIMARY KEY, name TEXT, age INT, email TEXT UNIQUE)`. Используй `db.Exec()`.

### Исходная формулировка

Напиши функцию `CreateUser(name, email string) error`, использующую `db.Exec("INSERT INTO users(name, email) VALUES($1, $2)", name, email)`. Проверь `sql.Result` — `LastInsertId()` (не работает в PostgreSQL!) и `RowsAffected()`.

## Теория

Метод `db.Exec(query, args...)` предназначен для запросов, не возвращающих строки данных (DDL: `CREATE`, `DROP`, `ALTER`, и DML: `INSERT`, `UPDATE`, `DELETE`).
Он возвращает интерфейс `sql.Result`, содержащий методы `RowsAffected()` и `LastInsertId()`.

## Решение по шагам

1. Напишем функцию `initDB(db *sql.DB) error`.
2. Сформируем строковый DDL запрос с условием `IF NOT EXISTS`.
3. Вызовем `db.Exec(query)`.
4. Проверим статус выполнения.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
)

func initDB(db *sql.DB) error {
	query := `
	CREATE TABLE IF NOT EXISTS users (
		id SERIAL PRIMARY KEY,
		name TEXT NOT NULL,
		age INT NOT NULL CHECK (age >= 0),
		email TEXT UNIQUE NOT NULL
	);`

	_, err := db.Exec(query)
	if err != nil {
		return fmt.Errorf("initDB exec error: %w", err)
	}
	return nil
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, err := sql.Open("pgx", dsn)
	if err != nil {
		panic(err)
	}
	defer db.Close()

	if err := initDB(db); err != nil {
		fmt.Printf("Ошибка: %v\n", err)
		return
	}

	fmt.Println("✔ Таблица users успешно создана или уже существует!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Таблица users успешно создана или уже существует!
```

## Под капотом

`db.Exec` отправляет серверу PostgreSQL простой протокол `Q` (Simple Query), который на сервере парсится, планируется и сразу коммитится в системном каталоге `pg_class`.

## Подводные камни

В проде автомиграции через `db.Exec(CREATE TABLE)` в коде сервиса считаются антипаттерном. Для миграций используют специализированные утилиты `golang-migrate`, `pressly/goose` или `atlas`.

## На собеседовании

**Вопрос с собеседования:** «Почему CREATE TABLE IF NOT EXISTS в PostgreSQL все равно может заблокировать другие запросы?»
**Ответ:** Даже если таблица уже существует, `CREATE TABLE IF NOT EXISTS` захватывает эксклюзивную блокировку `AccessExclusiveLock` на системный каталог `pg_class`, что может вызвать очередь ожидания (lock contention) при одновременном старте 50 подов в Kubernetes.
