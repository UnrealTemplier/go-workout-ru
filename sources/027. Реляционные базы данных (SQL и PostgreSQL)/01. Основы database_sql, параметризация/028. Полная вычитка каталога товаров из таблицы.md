# Полная вычитка каталога товаров из таблицы products через db.Query

## Условие

**db.Query и rows.Next()**: Прочитай все товары из таблицы `products`.

### Исходная формулировка

Извлеките всех пользователей в слайс структур, используя `rows.Scan`. Выведите их в консоль.

## Теория

Чтение каталога:
При вычитке списков важно предусмотреть предварительное выделение емкости среза (Pre-allocation), если количество записей заранее известно или ограничено `LIMIT`.

## Решение по шагам

1. Запросим товары `SELECT id, title, price, in_stock FROM products`.
2. Проитерируемся через `rows.Next()`.
3. Сохраним товары в срез.
4. Проверим отсутствие ошибок итератора.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
)

type CatalogItem struct {
	ID      int
	Title   string
	Price   float64
	InStock bool
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	rows, err := db.Query("SELECT id, title, price, in_stock FROM products")
	if err != nil {
		panic(err)
	}
	defer rows.Close()

	var catalog []CatalogItem
	for rows.Next() {
		var item CatalogItem
		if err := rows.Scan(&item.ID, &item.Title, &item.Price, &item.InStock); err != nil {
			panic(err)
		}
		catalog = append(catalog, item)
	}

	if err := rows.Err(); err != nil {
		panic(err)
	}

	fmt.Printf("Загружен каталог товаров (%d поз.):\n", len(catalog))
	for _, it := range catalog {
		fmt.Printf("  • ID %d: %-25s | $%.2f | На складе: %v\n", it.ID, it.Title, it.Price, it.InStock)
	}
}
```

**`Терминал`**


## Под капотом

Драйвер считывает ответ порциями по сетевым буферам TCP, не загружая миллионы строк в память процесса одномоментно.

## Подводные камни

Чтение огромных таблиц без `LIMIT` может привести к Out Of Memory (OOM) процесса Go.

## На собеседовании

**Вопрос с собеседования:** «Как обработать миллион строк из базы без переполнения оперативной памяти Go-сервиса?»
**Ответ:** Использовать курсор на уровне БД (`DECLARE cur CURSOR FOR SELECT ...` и `FETCH 1000 FROM cur`) или серверный стриминг `pgx` без загрузки всего набора в слайс, обрабатывая каждую строку поточно прямо в цикле `rows.Next()`.
