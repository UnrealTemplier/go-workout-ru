# Унифицированный интерфейс database/sql: независимость бизнес-логики от СУБД

## Условие

Установите драйвер `pgx` (или `lib/pq`), подключитесь к локальному PostgreSQL с использованием `database/sql`. Проверьте соединение `db.Ping()`.

## Теория

Паттерн Dependency Injection и `database/sql`:
В Go бизнес-логика (репозитории, сервисы) оперирует интерфейсом `*sql.DB` или `DBTX` (абстракция над `*sql.DB` и `*sql.Tx`), не завися от конкретного драйвера. Подмена драйвера (например, со `stdlib` на мок `sqlmock`) выполняется без изменения доменного слоя.

## Решение по шагам

1. Создадим фабричную функцию `NewDB(driverName, dsn)`.
2. Выполним пинг в единой точке входа.
3. Проверим абстракцию в `main()`.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"
	"time"

	_ "github.com/jackc/pgx/v5/stdlib"
)

func ConnectToPostgres(dsn string) (*sql.DB, error) {
	db, err := sql.Open("pgx", dsn)
	if err != nil {
		return nil, fmt.Errorf("open failed: %w", err)
	}

	// Настройка таймаута проверки связи
	db.SetConnMaxLifetime(5 * time.Minute)
	if err := db.Ping(); err != nil {
		_ = db.Close()
		return nil, fmt.Errorf("ping failed: %w", err)
	}

	return db, nil
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, err := ConnectToPostgres(dsn)
	if err != nil {
		fmt.Printf("Подключение не удалось: %v\n", err)
		return
	}
	defer db.Close()

	fmt.Println("✔ Соединение успешно инкапсулировано через ConnectToPostgres()!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Соединение успешно инкапсулировано через ConnectToPostgres()!
```

## Под капотом

Внутри `sql.DB` хранится ссылка на интерфейс `driver.Connector`. При вызове `db.Ping()` вызывается метод `connector.Connect(ctx)`.

## Подводные камни

Если при ошибке `db.Ping()` забыть вызвать `db.Close()`, фоновые ресурсы структуры пула не очистятся.

## На собеседовании

**Вопрос с собеседования:** «Является ли *sql.DB потокобезопасным?»
**Ответ:** Да. `*sql.DB` потокобезопасен и спроектирован для конкурентного использования сотнями горутин. Каждая горутина берет свободное соединение из пула и возвращает его после завершения запроса.
