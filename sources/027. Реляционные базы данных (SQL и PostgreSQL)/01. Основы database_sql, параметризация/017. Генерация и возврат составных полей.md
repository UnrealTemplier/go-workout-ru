# Генерация и возврат составных полей через RETURNING при добавлении товара

## Условие

**RETURNING id**: Добавь продукт и получи сгенерированный `id` через `QueryRow` и `RETURNING id`.

### Исходная формулировка

Создайте таблицу `users` (id, email, created_at) с помощью `db.ExecContext`. Изучите разницу между `Exec` (для INSERT/UPDATE/DELETE) и `Query` (для SELECT).

## Теория

Возврат вычисляемых полей через RETURNING:
Предложение `RETURNING` может возвращать не только `id`, но и любые сгенерированные БД значения: дефолтные метки времени, результаты триггеров или целую строку целиком:
`INSERT INTO products (...) VALUES (...) RETURNING id, in_stock, price`.

## Решение по шагам

1. Выполним вставку с `RETURNING id, in_stock`.
2. Сканируем оба возвращенных значения в переменные.
3. Проверим корректность заполнения полей.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
)

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	var productID int
	var inStock bool

	query := `INSERT INTO products (title, price) VALUES ($1, $2) RETURNING id, in_stock`
	err := db.QueryRow(query, "Игровое кресло", 280.00).Scan(&productID, &inStock)
	if err != nil {
		fmt.Printf("Ошибка: %v\n", err)
		return
	}

	fmt.Printf("✔ Создан продукт #%d (В наличии: %v)\n", productID, inStock)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Создан продукт #101 (В наличии: true)
```

## Под капотом

`db.QueryRow` автоматически запрашивает ровно одну строку и закрывает внутренний `*sql.Rows`, гарантируя отсутствие утечек соединений.

## Подводные камни

Порядок переменных в `.Scan(&a, &b)` обязан строго совпадать с порядком колонок в `RETURNING a, b`.

## На собеседовании

**Вопрос с собеседования:** «Можно ли вернуть всю созданную строку целиком одной командой?»
**Ответ:** Да, используя синтаксис `RETURNING *`. Все колонки таблицы возвращаются в порядке их объявления в DDL схеме.
