# Чтение товара по первичному ключу с типизированным сканированием цены

## Условие

**Чтение одной строки (QueryRow)**: Прочитай товар по `id` из таблицы `products`.

### Исходная формулировка

**Безопасная вставка (INSERT) с плейсхолдерами**: Напишите функцию добавления нового пользователя в базу данных. Передайте имя, email и возраст в качестве аргументов. Используйте плейсхолдеры `$1`, `$2`, `$3` вместо конкатенации строк, чтобы предотвратить угрозу SQL-инъекций [308].

## Теория

Сканирование числовых типов:
При чтении данных из таблицы `products` колонка `price NUMERIC(10, 2)` может сканироваться в `float64`, `string` или специализированный тип `decimal.Decimal`.

## Решение по шагам

1. Опишем структуру `Product { ID, Title, Price, InStock }`.
2. Подготовим запрос `SELECT id, title, price, in_stock FROM products WHERE id = $1`.
3. Отсканируем поля в структуру.
4. Проверим корректность типов.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
)

type Product struct {
	ID      int
	Title   string
	Price   float64
	InStock bool
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	var p Product
	query := `SELECT id, title, price, in_stock FROM products WHERE id = $1`

	err := db.QueryRow(query, 1).Scan(&p.ID, &p.Title, &p.Price, &p.InStock)
	if err != nil {
		fmt.Println("Ошибка чтения товара:", err)
		return
	}

	fmt.Printf("✔ Товар: [%d] %s — $%.2f (В наличии: %v)\n", p.ID, p.Title, p.Price, p.InStock)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Товар: [1] Клавиатура Механическая — $149.99 (В наличии: true)
```

## Под капотом

`pgx/v5` сопоставляет OID типа PostgreSQL (`numeric`, OID 1700) с Go-типом `float64`, выполняя безопасное двоичное преобразование.

## Подводные камни

Если сканировать в переменную не того типа (например, строку в int), `Scan` вернет ошибку `sql: Scan error on column index 1: converting driver.Value type string to a int`.

## На собеседовании

**Вопрос с собеседования:** «Как работает метод Scan под капотом?»
**Ответ:** Метод `Scan` использует рефлексию или проверку интерфейса `sql.Scanner`. Если передаваемый аргумент реализует метод `Scan(value any) error`, вызывается кастомная логика парсинга, иначе рантайм `database/sql` применяет стандартные правила приведения типов.
