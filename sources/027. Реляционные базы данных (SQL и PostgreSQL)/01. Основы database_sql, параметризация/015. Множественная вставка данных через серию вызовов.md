# Множественная вставка данных через серию вызовов db.Exec

## Условие

**db.Exec с параметрами**: Добавь 3 товара в таблицу `products` с разными ценами и названиями.

### Исходная формулировка

Напишите функцию, которая выполняет простейший `SELECT 1` и возвращает результат, чтобы убедиться в работоспособности коннекта.

## Теория

Серийная вставка записей:
Для вставки небольшого количества строк (2-5 записей) допустимо выполнить цикл `db.Exec` в рамках одного открытого соединения или подготовить один многострочный запрос `INSERT INTO ... VALUES (...), (...), (...)`.

## Решение по шагам

1. Опишем срез DTO товаров.
2. Проитерируемся по срезу и выполним вставку.
3. Подсчитаем общее количество добавленных записей.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
)

type ProductDTO struct {
	Title   string
	Price   float64
	InStock bool
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	items := []ProductDTO{
		{"Мышь оптическая", 29.90, true},
		{"Монитор 27' 4K", 499.00, true},
		{"Коврик для мыши", 12.50, false},
	}

	query := `INSERT INTO products (title, price, in_stock) VALUES ($1, $2, $3)`

	totalInserted := 0
	for _, it := range items {
		res, err := db.Exec(query, it.Title, it.Price, it.InStock)
		if err != nil {
			fmt.Printf("Ошибка вставки %s: %v\n", it.Title, err)
			continue
		}
		n, _ := res.RowsAffected()
		totalInserted += int(n)
	}

	fmt.Printf("✔ Успешно сохранено %d товаров в базу!\n", totalInserted)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Успешно сохранено 3 товаров в базу!
```

## Под капотом

Каждый вызов `db.Exec` в цикле по умолчанию выполняется в отдельной неявной автотранзакции СУБД, требующей fsync на диск для WAL-лога.

## Подводные камни

Вставка 1000 записей в цикле через одиночные `db.Exec` будет выполняться очень медленно (1000 сетевых RTT и 1000 fsync). Для тысяч строк используют пакетную вставку или `pgx.CopyFrom`.

## На собеседовании

**Вопрос с собеседования:** «Почему множественный INSERT в цикле без явной транзакции работает медленно?»
**Ответ:** По умолчанию PostgreSQL работает в режиме автокоммита (Autocommit). Каждый `db.Exec` инициирует отдельную транзакцию и принудительно сбрасывает журнал упреждающей записи (WAL) на диск через синхронный системный вызов `fdatasync`, что жестко упирается в IOPS диска.
