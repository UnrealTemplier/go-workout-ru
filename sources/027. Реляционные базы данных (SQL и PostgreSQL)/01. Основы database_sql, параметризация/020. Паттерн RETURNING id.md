# Паттерн RETURNING id: эталонная реализация вставки для продакшен-кода

## Условие

**RETURNING id**: Добавь пользователя и получи его `id`.

### Исходная формулировка

Вставь новую запись в таблицу `users` используя `db.ExecContext`. Обрати внимание, как экранировать переменные (плейсхолдеры `$1, $2` в PostgreSQL, а не `?`).

## Теория

Стандартизация слоя хранения (Data Access Layer):
В Go принято инкапсулировать SQL-запросы в методы репозитория, возвращающие доменную структуру с уже проставленным ID:
`func (r *Repo) Save(ctx, user *User) error`.

## Решение по шагам

1. Объявим структуру модели `User { ID, Name, Age, Email }`.
2. Напишем метод создания записи с заполнением `user.ID`.
3. Проверим результат.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
)

type User struct {
	ID    int
	Name  string
	Age   int
	Email string
}

func InsertUserAndHydrate(db *sql.DB, u *User) error {
	query := `INSERT INTO users (name, age, email) VALUES ($1, $2, $3) RETURNING id`
	return db.QueryRow(query, u.Name, u.Age, u.Email).Scan(&u.ID)
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	user := &User{
		Name:  "Сергей Петров",
		Age:   35,
		Email: "sergey@mail.ru",
	}

	if err := InsertUserAndHydrate(db, user); err != nil {
		fmt.Printf("Ошибка: %v\n", err)
		return
	}

	fmt.Printf("✔ Пользователь создан: ID=%d, Name=%s\n", user.ID, user.Name)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Пользователь создан: ID=108, Name=Сергей Петров
```

## Под капотом

Передача указателя `*User` в функцию позволяет модифицировать структуру на месте (In-Place Mutation), экономя аллокации памяти в куче.

## Подводные камни

Если передать в `Scan` значение по значению `Scan(u.ID)` вместо указателя `Scan(&u.ID)`, компилятор не сможет записать данные и рантайм вернет ошибку `sql: Scan error on column index 0: destination not a pointer`.

## На собеседовании

**Вопрос с собеседования:** «Почему Scan требует только указатели в качестве аргументов?»
**Ответ:** Go передает аргументы в функции по значению (копированием). Чтобы метод `Scan` мог записать десериализованные данные из сокета в ваши локальные переменные, ему необходимо передать адреса памяти этих переменных (`&var`).
