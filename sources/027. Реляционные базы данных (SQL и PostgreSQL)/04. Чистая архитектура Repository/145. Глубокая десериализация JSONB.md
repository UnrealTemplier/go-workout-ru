# Глубокая десериализация JSONB: сканирование в сложные вложенные структуры Go

## Условие

Прочитай `JSONB` данные из БД и десериализуй их обратно в структуру Go со вложенными срезами и мапами.

### Исходная формулировка

Прочитай `JSONB` данные из БД и десериализуй их обратно в структуру Go.

## Теория

Маппинг сложных документов:
JSONB в PostgreSQL может содержать сколь угодно глубокие древовидные структуры. В Go они отображаются во вложенные структуры со срезами объектов.

## Решение по шагам

1. Опишем многоуровневую структуру `OrderDetails`.
2. Считаем колонку `metadata JSONB` через драйвер.
3. Распарсим в структуру и обратимся к вложенным полям.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"encoding/json"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
)

type CartItem struct {
	SKU   string  `json:"sku"`
	Qty   int     `json:"qty"`
	Price float64 `json:"price"`
}

type OrderMetadata struct {
	CustomerIP string     `json:"customer_ip"`
	Discount   float64    `json:"discount"`
	Items      []CartItem `json:"items"`
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	var rawJSON []byte
	query := `SELECT '{"customer_ip": "192.168.1.1", "discount": 0.15, "items": [{"sku": "MACBOOK", "qty": 1, "price": 1999.99}, {"sku": "MOUSE", "qty": 2, "price": 49.50}]}'::jsonb`
	err := db.QueryRow(query).Scan(&rawJSON)
	if err != nil {
		panic(err)
	}

	var meta OrderMetadata
	if err := json.Unmarshal(rawJSON, &meta); err != nil {
		panic(err)
	}

	fmt.Printf("✔ JSONB успешно десериализован во вложенную модель:\\n")
	fmt.Printf("  • IP клиента: %s (Скидка: %.0f%%)\\n", meta.CustomerIP, meta.Discount*100)
	fmt.Printf("  • Товары (%d поз.):\\n", len(meta.Items))
	for _, it := range meta.Items {
		fmt.Printf("    - %s x%d = $%.2f\n", it.SKU, it.Qty, it.Price)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ JSONB успешно десериализован во вложенную модель:
#   • IP клиента: 192.168.1.1 (Скидка: 15%)
#   • Товары (2 поз.):
#     - MACBOOK x1 = $1999.99
#     - MOUSE x2 = $49.50
```

## Под капотом

`json.Unmarshal` парсит JSON-байты и распределяет значения по полям структур Go.

## Подводные камни

Поля структур обязаны быть экспортируемыми (с заглавной буквы).

## На собеседовании

**Вопрос с собеседования:** «Как обновить одно вложенное поле JSONB без перезаписи всего документа?»
**Ответ:** Использовать функцию `jsonb_set(target, path, new_value)`: `UPDATE orders SET metadata = jsonb_set(metadata, '{discount}', '0.20') WHERE id = 1`. Это изменяет конкретный узел дерева без десериализации всего объекта.
