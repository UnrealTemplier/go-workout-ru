# Встраивание миграций в бинарник через go:embed и iofs

## Условие

Напишите Go-скрипт, который читает миграции из встроенной папки `//go:embed` и применяет их к БД при старте приложения.

### Исходная формулировка

Напишите Go-скрипт, который читает миграции из папки и применяет их к БД при старте приложения.

## Теория

Паттерн Embedded Migrations:
Директива `//go:embed migrations/*.sql` компилирует все SQL-файлы в бинарный файл. При деплое в Kubernetes в контейнере нет файловой системы с исходниками, но сервис всегда имеет доступ к миграциям.

## Решение по шагам

1. Объявим переменную `//go:embed migrations/*.sql var migrationsFS embed.FS`.
2. Создадим источник `iofs.New(migrationsFS, "migrations")`.
3. Применим миграции к базе данных.
4. Проверим результат.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"embed"
	"errors"
	"fmt"

	"github.com/golang-migrate/migrate/v4"
	"github.com/golang-migrate/migrate/v4/database/postgres"
	"github.com/golang-migrate/migrate/v4/source/iofs"
	_ "github.com/jackc/pgx/v5/stdlib"
)

//go:embed migrations/*.sql
var migrationFiles embed.FS

func ApplyEmbeddedMigrations(db *sql.DB) error {
	d, err := iofs.New(migrationFiles, "migrations")
	if err != nil {
		return err
	}

	driver, err := postgres.WithInstance(db, &postgres.Config{})
	if err != nil {
		return err
	}

	m, err := migrate.NewWithInstance("iofs", d, "postgres", driver)
	if err != nil {
		return err
	}

	if err := m.Up(); err != nil && !errors.Is(err, migrate.ErrNoChange) {
		return err
	}

	fmt.Println("✔ Встроенные //go:embed миграции успешно применены!")
	return nil
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	_ = ApplyEmbeddedMigrations(db)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Встроенные //go:embed миграции успешно применены!
```

## Под капотом

`embed.FS` реализует стандартный интерфейс `io/fs.FS`, читая сжатые байты прямо из сегмента `.rodata` скомпилированного бинарника Go.

## Подводные камни

Директива `//go:embed` требует указания относительного пути без ведущего слэша.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество embed.FS перед внешними файлами в микросервисах?»
**Ответ:** Полная самодостаточность контейнера: образ Docker строится `FROM scratch` или `distroless` без утилит ОС, и один бинарник содержит внутри и сервер, и веб-ассеты, и миграции базы данных.
