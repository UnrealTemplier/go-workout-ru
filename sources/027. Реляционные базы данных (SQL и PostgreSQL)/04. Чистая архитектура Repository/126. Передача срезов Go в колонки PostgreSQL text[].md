# Передача срезов Go в колонки PostgreSQL text[] через нативный pgx

## Условие

**Массивы в БД**: Создай в базе колонку `tags text[]`. Передай из Go обычный срез `[]string` в `pool.Exec`, без использования сторонних библиотек.

### Исходная формулировка

**Массивы в БД**: Создай в базе колонку `tags text[]`. Передай из Go обычный срез `[]string{"go", "backend", "sql"}`. `pgx` нативно поддерживает массивы Postgres, в отличие от `lib/pq`.

## Теория

Нативная поддержка массивов pgx/v5:
В `pgx/v5` не нужны адаптеры `pq.Array`: срез `[]string` автоматически упаковывается в бинарный формат массива `text[]` PostgreSQL.

## Решение по шагам

1. Создадим таблицу `items_with_tags (id SERIAL, tags TEXT[])`.
2. Вставим срез строк `[]string{"k8s", "docker"}`.
3. Прочитаем срез обратно.
4. Проверим совпадение элементов.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"

	"github.com/jackc/pgx/v5/pgxpool"
)

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	ctx := context.Background()
	pool, _ := pgxpool.New(ctx, dsn)
	defer pool.Close()

	_, _ = pool.Exec(ctx, "CREATE TABLE IF NOT EXISTS items_with_tags (id SERIAL, tags TEXT[])")

	tags := []string{"golang", "highload", "microservices"}

	var id int
	err := pool.QueryRow(ctx, "INSERT INTO items_with_tags (tags) VALUES ($1) RETURNING id", tags).Scan(&id)
	if err != nil {
		panic(err)
	}

	var fetchedTags []string
	_ = pool.QueryRow(ctx, "SELECT tags FROM items_with_tags WHERE id = $1", id).Scan(&fetchedTags)

	fmt.Printf("✔ Нативный срез []string сохранен и прочитан из text[]: %v\n", fetchedTags)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Нативный срез []string сохранен и прочитан из text[]: [golang highload microservices]
```

## Под капотом

Драйвер передает массив в бинарном формате OID 1009 (`TEXTARRAYOID`).

## Подводные камни

В `database/sql` этот код не скомпилируется без обертки `pq.Array`.

## На собеседовании

**Вопрос с собеседования:** «Как найти строки, содержащие хотя бы один тег из переданного списка?»
**Ответ:** Использовать оператор пересечения массивов `WHERE tags && $1` (например, `ARRAY['k8s', 'go']`). Запрос эффективно ускоряется GIN-индексом.
