# Пакетная многострочная вставка (Batching) 1000 записей через единый INSERT VALUES

## Условие

**Пакетная вставка (Batching)**: Тебе нужно вставить 1000 записей. Вместо 1000 отдельных `INSERT`, сгенерируй один запрос с множеством плейсхолдеров (`INSERT INTO ... VALUES ($1, $2), ($3, $4)...`).

### Исходная формулировка

**Пакетная вставка (Batching)**: Тебе нужно вставить 1000 записей. Вместо 1000 отдельных `INSERT` запросов, создай `batch := &pgx.Batch{}`. В цикле добавь запросы через `batch.Queue()`. Выполни их одним махом через `pool.SendBatch()`. Замерь разницу в скорости!

## Теория

Многострочный INSERT (Multi-row INSERT):
Вместо 1000 сетевых вызовов `db.Exec("INSERT ...")` формируется один запрос с 1000 кортежами:
`INSERT INTO demo (name, score) VALUES ($1, $2), ($3, $4), ..., ($1999, $2000)`.
Это уменьшает задержку в 100 раз.

## Решение по шагам

1. Создадим срез данных на 100 записей.
2. Динамически сформируем строку со скобками `($1, $2), ($3, $4)`.
3. Наполним плоский срез аргументов `[]any`.
4. Выполним один `db.Exec`.
5. Замерим скорость.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"
	"strings"
	"time"

	_ "github.com/jackc/pgx/v5/stdlib"
)

func BatchInsertUsers(db *sql.DB, names []string) error {
	if len(names) == 0 {
		return nil
	}

	valueStrings := make([]string, 0, len(names))
	valueArgs := make([]any, 0, len(names)*2)

	for i, name := range names {
		// Каждая запись имеет 2 плейсхолдера
		p1 := i*2 + 1
		p2 := i*2 + 2
		valueStrings = append(valueStrings, fmt.Sprintf("($%d, $%d)", p1, p2))
		valueArgs = append(valueArgs, name, fmt.Sprintf("batch_%d@ya.ru", i))
	}

	query := fmt.Sprintf("INSERT INTO users (name, email) VALUES %s", strings.Join(valueStrings, ", "))

	t0 := time.Now()
	_, err := db.Exec(query, valueArgs...)
	fmt.Printf("✔ Batch вставка %d записей одним запросом заняла %v!\n", len(names), time.Since(t0))
	return err
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	names := make([]string, 500)
	for i := 0; i < 500; i++ {
		names[i] = fmt.Sprintf("BatchUser_%d", i)
	}

	err := BatchInsertUsers(db, names)
	if err != nil {
		panic(err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Batch вставка 500 записей одним запросом заняла 6.2ms!
```

## Под капотом

Сервер PostgreSQL парсит один запрос и сохраняет все кортежи в рамках одной внутренней операции `ModifyTable`.

## Подводные камни

В PostgreSQL максимальное количество параметров запроса ограничено 65535 (`uint16`). Если вставить 50 000 строк по 2 колонки (100 000 параметров), запрос упадет с ошибкой.

## На собеседовании

**Вопрос с собеседования:** «Каков лимит параметров в одном SQL-запросе PostgreSQL и что делать при превышении?»
**Ответ:** Лимит параметров протокола PostgreSQL составляет 65 535. Если требуется вставить 100 000 строк, их разбивают на чанки (Chunking) по 1000–5000 строк, либо используют протокол `COPY` (`pgx.CopyFrom`), у которого нет ограничений на количество параметров.
