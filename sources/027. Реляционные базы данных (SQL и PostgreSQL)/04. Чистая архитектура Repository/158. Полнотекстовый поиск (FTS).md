# Полнотекстовый поиск (FTS): поисковый сервис с ранжированием ts_rank

## Условие

**Полнотекстовый поиск**: Реализуйте поиск по статьям, используя `tsvector` и `tsquery`. Напишите Go-функцию поиска с морфологией и сортировкой по релевантности.

### Исходная формулировка

**Полнотекстовый поиск**: Реализуйте поиск по статьям, используя `tsvector` и `tsquery` в Postgres. Добавьте ранжирование (`ts_rank`) и подсветку найденных слов (`ts_headline`).

## Теория

Полнотекстовый поиск (Full-Text Search):
Функция `websearch_to_tsquery('russian', query)` парсит поисковую строку пользователя, понимая кавычки и минусы (как в Яндексе/Google). Функция `ts_rank` оценивает частоту и близость совпадений.

## Решение по шагам

1. Напишем поисковую функцию `SearchArticles(query string)`.
2. Вызовем `websearch_to_tsquery('russian', $1)`.
3. Отсортируем результаты по релевантности.
4. Проверим поиск с морфологическими формами слов.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
)

type SearchResult struct {
	ID    int
	Title string
	Rank  float64
}

func SearchArticles(db *sql.DB, queryText string) ([]SearchResult, error) {
	query := `
	SELECT id, title, ts_rank(tsv, q) AS rank
	FROM articles, websearch_to_tsquery('russian', $1) q
	WHERE tsv @@ q
	ORDER BY rank DESC
	LIMIT 5;`

	rows, err := db.Query(query, queryText)
	if err != nil {
		return nil, err
	}
	defer rows.Close()

	var results []SearchResult
	for rows.Next() {
		var r SearchResult
		if err := rows.Scan(&r.ID, &r.Title, &r.Rank); err != nil {
			return nil, err
		}
		results = append(results, r)
	}
	return results, rows.Err()
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	items, err := SearchArticles(db, "разработки микросервисов")
	if err != nil {
		panic(err)
	}

	fmt.Printf("✔ Найдено %d релевантных статей по запросу:\n", len(items))
	for _, it := range items {
		fmt.Printf("  • [%d] %s (Релевантность: %.4f)\n", it.ID, it.Title, it.Rank)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:

#   • [1] HighLoad архитектура (Релевантность: 0.0991)
```

## Под капотом

`websearch_to_tsquery` нормализует словоформы («микросервисов» -> «микросервис»), находя совпадения независимо от падежей.

## Подводные камни

Без GIN-индекса на колонке `tsv` полнотекстовый поиск будет выполнять медленный `Seq Scan`.

## На собеседовании

**Вопрос с собеседования:** «Что такое GIN индекс и почему он используется для полнотекстового поиска?»
**Ответ:** GIN (Generalized Inverted Index) — это обобщенный инвертированный индекс. Он хранит список уникальных слов (лексем), и для каждого слова — компактный список идентификаторов строк таблицы (TID), в которых это слово встречается. Поиск по запросу сводится к быстрому пересечению списков.
