# Продвинутая выборка в sqlx: массовый StructScan без ручного сканирования колонок

## Условие

Используй библиотеку `github.com/jmoiron/sqlx`. Выведи данные из таблицы `users` сразу в срез структур, отфильтровав пользователей старше 20 лет.

### Исходная формулировка

Используй библиотеку `github.com/jmoiron/sqlx`. Выведи данные из таблицы `users` сразу в слайс структур `[]User` с помощью `db.SelectContext(&users, query)`. Оцени, насколько меньше стало boilerplate-кода по сравнению с ручным `Scan`.

## Теория

Эффективность sqlx.Select:
Пакет `sqlx` парсит срез типов и наполняет его через отражение метаданных колонок, выполняя ровно один сетевой запрос и закрывая курсор автоматически.

## Решение по шагам

1. Опишем модель `UserRow`.
2. Выполним выборку `db.Select(&list, query, minAge)`.
3. Распечатаем результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
	"github.com/jmoiron/sqlx"
)

type UserRow struct {
	ID    int    `db:"id"`
	Name  string `db:"name"`
	Email string `db:"email"`
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, err := sqlx.Connect("pgx", dsn)
	if err != nil {
		panic(err)
	}
	defer db.Close()

	var result []UserRow
	query := "SELECT id, name, email FROM users WHERE age >= $1 ORDER BY id ASC LIMIT 3"
	err = db.Select(&result, query, 20)
	if err != nil {
		panic(err)
	}

	fmt.Printf("✔ sqlx.Select отфильтровал %d пользователей:\\n", len(result))
	for _, u := range result {
		fmt.Printf("  • ID %d: %-20s <%s>\n", u.ID, u.Name, u.Email)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ sqlx.Select отфильтровал 3 пользователей:
#   • ID 1: Алексей (Обновлен)   <alex.smirnov@ya.ru>
#   • ID 2: Ольга                <olga@ya.ru>
#   • ID 3: Сергей Петров        <sergey@mail.ru>
```

## Под капотом

`sqlx.Select` сам вызывает `defer rows.Close()` и проверяет `rows.Err()`, исключая утечки соединений.

## Подводные камни

Если запрос вернул 0 строк, `db.Select` не возвращает ошибку, а оставляет срез пустым (`len == 0`). Метод `db.Get` при 0 строках вернет `sql.ErrNoRows`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие поведения sqlx.Get и sqlx.Select при отсутствии строк?»
**Ответ:** `sqlx.Get` ожидает ровно одну строку: если найдено 0 строк, он возвращает `sql.ErrNoRows`. `sqlx.Select` ожидает список строк: если найдено 0 строк, он возвращает `nil` ошибку и пустой слайс `len=0`.
