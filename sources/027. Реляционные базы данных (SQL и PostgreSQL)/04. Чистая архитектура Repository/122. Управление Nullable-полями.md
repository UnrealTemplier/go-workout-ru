# Управление Nullable-полями: добавление колонки bio и проверка sql.NullString

## Условие

Добавь в таблицу `users` колонку `bio TEXT` (которая может быть `NULL`). Попробуй отсканировать её в обычную строку `string` (получи ошибку) и исправь через `sql.NullString`.

### Исходная формулировка

Добавь в таблицу `users` колонку `bio TEXT` (которая может быть `NULL`). Попробуй отсканировать её в обычную `string` (поймай ошибку сканирования `NULL` в string). Используй тип `sql.NullString` для решения проблемы.

## Теория

Природа ошибки Scan error on NULL:
При попытке записать `NULL` в обычный тип `string` стандартный драйвер выдает фатальную ошибку:
`sql: Scan error on column index 1, name "bio": converting NULL to string is unsupported`.
Тип `sql.NullString` состоит из двух полей: `String string` и `Valid bool`. Если в базе `NULL`, `Valid` равен `false`.

## Решение по шагам

1. Добавим колонку `bio TEXT` в `users`.
2. Создадим пользователя с `bio = NULL`.
3. Попытаемся отсканировать в `string` и перехватим ошибку.
4. Отсканируем в `sql.NullString` и успешно прочитаем данные.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
)

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	_, _ = db.Exec("ALTER TABLE users ADD COLUMN IF NOT EXISTS bio TEXT;")

	// Создаем пользователя без биографии (NULL)
	var nullUserID int
	_ = db.QueryRow("INSERT INTO users (name, email, bio) VALUES ('Без Био', 'nobio@ya.ru', NULL) RETURNING id").Scan(&nullUserID)

	// Попытка 1: чтение в обычный string (ошибка!)
	var rawString string
	err := db.QueryRow("SELECT bio FROM users WHERE id = $1", nullUserID).Scan(&rawString)
	if err != nil {
		fmt.Printf("✔ ОЖИДАЕМЫЙ СБОЙ: %v\n", err)
	}

	// Попытка 2: чтение в sql.NullString (успех!)
	var safeBio sql.NullString
	err = db.QueryRow("SELECT bio FROM users WHERE id = $1", nullUserID).Scan(&safeBio)
	if err != nil {
		panic(err)
	}

	fmt.Printf("✔ Безопасное чтение через sql.NullString: Valid=%v, Value='%s'\n", safeBio.Valid, safeBio.String)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ ОЖИДАЕМЫЙ СБОЙ: sql: Scan error on column index 0, name "bio": converting NULL to string is unsupported
# ✔ Безопасное чтение через sql.NullString: Valid=false, Value=''
```

## Под капотом

`sql.NullString` реализует интерфейс `sql.Scanner`. Внутри метода `Scan` проверяется `if src == nil { s.Valid = false; return nil }`.

## Подводные камни

Сериализация `sql.NullString` в JSON через `json.Marshal` выдает неудобный объект `{"String":"","Valid":false}` вместо `null`.

## На собеседовании

**Вопрос с собеседования:** «Как сериализовать nullable-поле в красивый JSON вида "bio": null?»
**Ответ:** Использовать указатель `*string` вместо `sql.NullString`. Если значение в базе `NULL`, указатель равен `nil`, что в JSON сериализуется как `null`.
