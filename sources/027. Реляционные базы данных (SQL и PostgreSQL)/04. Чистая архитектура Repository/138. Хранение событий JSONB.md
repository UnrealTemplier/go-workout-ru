# Хранение событий JSONB: вставка произвольного объекта конфигурации

## Условие

Создай таблицу `events` с колонкой `data JSONB`. Вставь в неё JSON-объект, используя структуру Go и драйвер базы данных.

### Исходная формулировка

Создай таблицу `events` с колонкой `data JSONB`. Вставь в неё JSON-объект, используя структуру Go и `[]byte`.

## Теория

Паттерн Event Store на JSONB:
В архитектурах Event Sourcing события имеют разную структуру полей. Колонка `JSONB` позволяет хранить гетерогенные события без изменения схемы таблиц.

## Решение по шагам

1. Создадим таблицу `event_store (id SERIAL, event_type TEXT, payload JSONB)`.
2. Опишем структуру события.
3. Сохраним событие через `json.Marshal`.
4. Проверим запись.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"encoding/json"
	"fmt"

	_ "github.com/jackc/pgx/v5/stdlib"
)

type UserRegisteredEvent struct {
	UserID int    `json:"user_id"`
	Email  string `json:"email"`
	IP     string `json:"ip"`
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	_, _ = db.Exec(`CREATE TABLE IF NOT EXISTS event_store (id SERIAL, event_type TEXT, payload JSONB);`)

	evt := UserRegisteredEvent{UserID: 42, Email: "boss@ya.ru", IP: "127.0.0.1"}
	rawJSON, _ := json.Marshal(evt)

	var id int
	err := db.QueryRow("INSERT INTO event_store (event_type, payload) VALUES ($1, $2) RETURNING id",
		"UserRegistered", rawJSON).Scan(&id)
	if err != nil {
		panic(err)
	}

	fmt.Printf("✔ Событие #%d успешно сохранено в JSONB Event Store!\n", id)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Событие #1 успешно сохранено в JSONB Event Store!
```

## Под капотом

PostgreSQL валидирует JSON-синтаксис при вставке и сохраняет бинарное дерево парсинга.

## Подводные камни

Вставка невалидного JSON вызовет ошибку `22P02: invalid input syntax for type json`.

## На собеседовании

**Вопрос с собеседования:** «Каковы преимущества хранения аудит-лога в JSONB по сравнению со строковым JSON?»
**Ответ:** JSONB исключает избыточные пробелы, сжимает данные и позволяет выполнять быстрые аналитические выборки прямо в SQL через выражения `payload->>'user_id'` без извлечения всей строки в клиентское приложение.
