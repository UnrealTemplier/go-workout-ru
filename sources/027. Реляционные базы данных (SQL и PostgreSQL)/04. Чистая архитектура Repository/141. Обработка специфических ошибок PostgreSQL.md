# Обработка специфических ошибок PostgreSQL: перехват кода 23505 unique_violation

## Условие

**Обработка специфических ошибок БД**: Напишите обработчик ошибки дублирования уникального поля (email). Распарсите ошибку драйвера и верните кастомную ошибку `ErrDuplicateEmail`.

### Исходная формулировка

**Обработка специфических ошибок БД**: Напишите обработчик ошибки дублирования уникального значения (например, при попытке зарегистрировать пользователя с уже существующим email). Используйте проверку типа ошибки драйвера (например, приведя ошибку к типу `*pgconn.PgError` при использовании драйвера `pgx`), чтобы извлечь код ошибки PostgreSQL `23505` (unique_violation) и вернуть клиенту понятное сообщение.

## Теория

Коды ошибок SQLSTATE в pgconn.PgError:
Вместо ненадежного парсинга строк вида `strings.Contains(err.Error(), "duplicate key")`, драйвер `pgx` предоставляет структурированную ошибку `*pgconn.PgError`.
Код ошибки дубликата уникального ключа в стандарте SQLSTATE: `23505` (`unique_violation`).

## Решение по шагам

1. Объявим ошибку `var ErrDuplicateEmail = errors.New(\"пользователь с таким email уже существует\")`.
2. Вставим пользователя с дубликатом email.
3. Проверим ошибку через `errors.As(err, &pgErr)` и проверим `pgErr.Code == \"23505\"`.
4. Вернем понятную бизнес-ошибку.

## Код решения

**`main.go`**

```go
package main

import (
	"database/sql"
	"errors"
	"fmt"

	"github.com/jackc/pgx/v5/pgconn"
	_ "github.com/jackc/pgx/v5/stdlib"
)

var ErrDuplicateEmail = errors.New("пользователь с таким email уже зарегистрирован")

func RegisterUser(db *sql.DB, name, email string) error {
	query := "INSERT INTO users (name, email) VALUES ($1, $2)"
	_, err := db.Exec(query, name, email)
	if err != nil {
		var pgErr *pgconn.PgError
		if errors.As(err, &pgErr) {
			// 23505 = unique_violation в стандарте SQL
			if pgErr.Code == "23505" {
				return ErrDuplicateEmail
			}
		}
		return err
	}
	return nil
}

func main() {
	dsn := "postgres://postgres:postgres@localhost:5432/testdb?sslmode=disable"
	db, _ := sql.Open("pgx", dsn)
	defer db.Close()

	// Первый раз — ок
	_ = RegisterUser(db, "Иван", "ivan_dup@ya.ru")

	// Второй раз — ловим дубликат
	err := RegisterUser(db, "Иван Двойник", "ivan_dup@ya.ru")
	if errors.Is(err, ErrDuplicateEmail) {
		fmt.Printf("✔ Ошибка СУБД успешно транслирована в бизнес-домен: %v\n", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# ✔ Ошибка СУБД успешно транслирована в бизнес-домен: пользователь с таким email уже зарегистрирован
```

## Под капотом

Сервер БД возвращает поле `Code: "23505"`, `ConstraintName: "users_email_key"`, `Detail: "Key (email)=(...) already exists"`. Драйвер заполняет структуру `PgError`.

## Подводные камни

Проверка по тексту ошибки `strings.Contains(err.Error(), "unique constraint")` ломается при смене локали сервера СУБД.

## На собеседовании

**Вопрос с собеседования:** «Какие еще важные SQLSTATE коды ошибок вы проверяете в Go коде?»
**Ответ:** 
- `23503`: `foreign_key_violation` (связанная запись не найдена).
- `23514`: `check_violation` (нарушено ограничение CHECK).
- `40001`: `serialization_failure` (конфликт транзакции, требует retry).
- `40P01`: `deadlock_detected` (дедлок, требует retry).
- `57014`: `query_canceled` (превышен statement_timeout).
