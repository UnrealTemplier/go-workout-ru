# Сброс тела в io.Discard и гарантированное сохранение Keep-Alive соединения

## Условие

Покажи **утечку соединений**, если забыть `resp.Body.Close()`. Запусти 10000 запросов без закрытия — получи `"too many open files"`. Исправь: всегда закрывай Body, даже если не читаешь (или используй `io.Copy(io.Discard, resp.Body)`).

## Теория

Завершение жизненного цикла HTTP-ответа: для возврата сокета в пул требуется комбинация `io.Copy(io.Discard, resp.Body)` и `resp.Body.Close()`.

## Решение по шагам

1. Создадим функцию отправки запроса.
2. Продемонстрируем гарантированное освобождение ресурсов.
3. Выполним серию запросов в цикле.
4. Проверим результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func safeDiscardRequest(client *http.Client, url string) error {
	resp, err := client.Get(url)
	if err != nil {
		return err
	}
	defer resp.Body.Close()

	// Сбрасываем тело ответа без аллокаций в памяти
	_, err = io.Copy(io.Discard, resp.Body)
	return err
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte("DATA_PAYLOAD"))
	}))
	defer ts.Close()

	client := &http.Client{}

	for i := 1; i <= 100; i++ {
		if err := safeDiscardRequest(client, ts.URL); err != nil {
			panic(err)
		}
	}

	fmt.Println("[Main] 100 запросов успешно завершены, сокеты переиспользованы без утечек.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Main] 100 запросов успешно завершены, сокеты переиспользованы без утечек.
```

## Под капотом

`io.Discard` сбрасывает данные со скоростью сети без аллокаций.

## Подводные камни

Если не вычитать тело до конца, транспорт вынужден разорвать TCP-сессию (TCP RST/FIN).

## На собеседовании

**Вопрос с собеседования:** «Почему io.Copy(io.Discard, resp.Body) критичен для микросервисов с высоким RPS?»
**Ответ:** Без полной вычитки тела ответа `http.Transport` не может гарантировать, что в сокете не осталось данных предыдущего ответа, и закрывает сокет. Вычитка в `io.Discard` сохраняет TCP-сессию активной в пуле Keep-Alive.
