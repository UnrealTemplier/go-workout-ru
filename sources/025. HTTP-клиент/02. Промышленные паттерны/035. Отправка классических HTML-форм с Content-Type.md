# Отправка классических HTML-форм с Content-Type application/x-www-form-urlencoded

## Условие

Напиши `POST` с `application/x-www-form-urlencoded`: используй `url.Values` и `strings.NewReader(values.Encode())`. Отправь на тестовый сервер.

## Теория

Формат `application/x-www-form-urlencoded`: стандартный формат отправки веб-форм. Данные кодируются как ключ-значение в виде `key1=val1&key2=val2` и передаются в теле запроса через функцию `http.PostForm(url, data)` или `http.Post`.

## Решение по шагам

1. Создадим `formData := url.Values{}`.
2. Добавим поля `formData.Set("grant_type", "password")`, `formData.Set("username", "admin")`.
3. Отправим запрос через `http.Post(ts.URL, "application/x-www-form-urlencoded", strings.NewReader(formData.Encode()))`.
4. Сервер парсит форму через `r.ParseForm()` и валидирует данные.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"net/url"
	"strings"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if err := r.ParseForm(); err != nil {
			http.Error(w, err.Error(), http.StatusBadRequest)
			return
		}

		user := r.Form.Get("username")
		grant := r.Form.Get("grant_type")
		fmt.Printf("[Server Form Auth] User: %s | GrantType: %s\n", user, grant)

		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte("OAUTH_TOKEN_GRANTED"))
	}))
	defer ts.Close()

	// Формируем поля формы
	formData := url.Values{}
	formData.Set("grant_type", "password")
	formData.Set("username", "developer@google.com")
	formData.Set("scope", "read:profile write:orders")

	// Отправка запроса
	resp, err := http.Post(
		ts.URL,
		"application/x-www-form-urlencoded",
		strings.NewReader(formData.Encode()),
	)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	body, _ := io.ReadAll(resp.Body)
	fmt.Printf("[Client] Ответ: %s\n", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Server Form Auth] User: developer@google.com | GrantType: password
# [Client] Ответ: OAUTH_TOKEN_GRANTED
```

## Под капотом

Метод `http.PostForm(url, formData)` является удобной оберткой над `http.Post` с `strings.NewReader(formData.Encode())`.

## Подводные камни

В больших формах с бинарными файлами `x-www-form-urlencoded` неэффективен из-за 300% раздувания объема данных (экранирование байтов); используйте `multipart/form-data`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие r.Form от r.PostForm на стороне сервера?»
**Ответ:** `r.Form` объединяет в себе параметры и из URL Query String, и из тела POST-формы. `r.PostForm` содержит строго параметры, переданные в теле POST/PUT запроса, игнорируя query-параметры из строки URL.
