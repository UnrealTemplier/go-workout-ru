# Декодирование JSON-ответа публичного REST API в типизированную структуру

## Условие

Напиши простой HTTP-клиент: `resp, err := http.Get("https://api.github.com/users/golang")`. Прочитай `resp.Body`, декодируй JSON в структуру. Не забудь `defer resp.Body.Close()`.

## Теория

Интеграция с внешними REST API: сопоставление JSON-полей со структурой Go через json-теги `json:"field_name"`.

## Решение по шагам

1. Опишем структуру `GithubUser { Login, Name, PublicRepos, Followers }`.
2. Запустим тестовый эндпоинт.
3. Выполним запрос и распарсим через `json.NewDecoder(resp.Body).Decode(&user)`.
4. Выведем результат.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/http/httptest"
)

type GithubUser struct {
	Login       string `json:"login"`
	Name        string `json:"name"`
	PublicRepos int    `json:"public_repos"`
	Followers   int    `json:"followers"`
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		_, _ = w.Write([]byte(`{
			"login": "golang",
			"name": "The Go Programming Language",
			"public_repos": 140,
			"followers": 12500
		}`))
	}))
	defer ts.Close()

	resp, err := http.Get(ts.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var user GithubUser
	if err := json.NewDecoder(resp.Body).Decode(&user); err != nil {
		panic(err)
	}

	fmt.Println("=== ДАННЫЕ ПОЛЬЗОВАТЕЛЯ GITHUB ===")
	fmt.Printf("Логин:       %s\n", user.Login)
	fmt.Printf("Имя:         %s\n", user.Name)
	fmt.Printf("Репозиториев: %d\n", user.PublicRepos)
	fmt.Printf("Подписчиков: %d\n", user.Followers)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# === ДАННЫЕ ПОЛЬЗОВАТЕЛЯ GITHUB ===
# Логин:       golang
# Имя:         The Go Programming Language
# Репозиториев: 140
# Подписчиков: 12500
```

## Под капотом

`json.Decoder` выполняет потоковую десериализацию прямо из сетевого сокета.

## Подводные камни

Всегда проверяйте `resp.StatusCode == http.StatusOK` перед декодированием JSON, иначе парсер упадет на HTML-странице ошибки 502/404.

## На собеседовании

**Вопрос с собеседования:** «Что произойдет, если в JSON ответе придут дополнительные неизвестные поля?»
**Ответ:** По умолчанию `json.Decoder` просто проигнорирует неизвестные поля. Если требуется строгая валидация структуры, включают режим `decoder.DisallowUnknownFields()`.
