# Структурированный POST-запрос с JSON телом и проверкой ответа

## Условие

**POST-запрос с отправкой JSON**: Создайте структуру `Post` с полями `Title`, `Body`, `UserID`. Сериализуйте её в JSON. Отправьте POST-запрос на тестовый URL с помощью `http.Post` или создав кастомный запрос через `http.NewRequest`. Убедитесь, что вы правильно установили заголовок `Content-Type: application/json`.

## Теория

Формирование REST POST запроса: сериализация структуры в JSON байты и передача через `bytes.NewBuffer` в `http.NewRequest`.

## Решение по шагам

1. Создадим структуру `Post { Title, Body, UserID }`.
2. Сериализуем через `json.Marshal`.
3. Создадим `http.NewRequest("POST", url, bytes.NewBuffer(payload))`.
4. Установим `req.Header.Set("Content-Type", "application/json")`.
5. Отправим запрос и распарсим ответ.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

type Post struct {
	Title  string `json:"title"`
	Body   string `json:"body"`
	UserID int    `json:"userId"`
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if r.Header.Get("Content-Type") != "application/json" {
			http.Error(w, "Invalid Content-Type", http.StatusUnsupportedMediaType)
			return
		}

		var p Post
		_ = json.NewDecoder(r.Body).Decode(&p)
		w.WriteHeader(http.StatusCreated)
		_, _ = w.Write([]byte(fmt.Sprintf(`{"id": 204, "created_title": %q}`, p.Title)))
	}))
	defer ts.Close()

	newPost := Post{
		Title:  "Основы HTTP-клиента в Go",
		Body:   "Разбор методов Do, Get, Post и пулинга соединений.",
		UserID: 7,
	}

	payload, _ := json.Marshal(newPost)
	req, err := http.NewRequest(http.MethodPost, ts.URL+"/posts", bytes.NewBuffer(payload))
	if err != nil {
		panic(err)
	}
	req.Header.Set("Content-Type", "application/json")

	client := &http.Client{}
	resp, err := client.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	respBytes, _ := io.ReadAll(resp.Body)
	fmt.Printf("[Post Response] Status=%d, Body=%s\n", resp.StatusCode, string(respBytes))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Post Response] Status=201, Body={"id": 204, "created_title": "Основы HTTP-клиента в Go"}
```

## Под капотом

`bytes.NewBuffer(payload)` передает срез байтов без дублирования памяти.

## Подводные камни

Не забывайте `defer resp.Body.Close()`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие bytes.NewReader от bytes.NewBuffer при передаче в http.NewRequest?»
**Ответ:** `bytes.NewReader` реализует `io.Reader`, `io.Seeker` и `io.ReaderAt` (read-only), что позволяет транспорту автоматически определить `Content-Length`. `bytes.NewBuffer` — это мутабельный буфер чтения/записи.
