# Принудительный таймаут HTTP-запроса через context.WithTimeout

## Условие

Напиши **HTTP-клиент с `context.WithTimeout`**: `ctx, cancel := context.WithTimeout(context.Background(), 3*time.Second)`. Передай в `req.WithContext(ctx)`. Покажи, что запрос прерывается при таймауте.

## Теория

Контекстный таймаут запроса: `context.WithTimeout` передает сигнал отмены на уровень сетевого сокета при превышении лимита времени, мгновенно разблокируя клиентскую горутину.

## Решение по шагам

1. Сервер имитирует долгую обработку (150 мс).
2. Клиент настраивает `context.WithTimeout` на 30 мс.
3. Выполняет `client.Do(req)`.
4. Перехватывает ошибку таймаута.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		time.Sleep(150 * time.Millisecond) // Долгий запрос
		w.WriteHeader(http.StatusOK)
	}))
	defer ts.Close()

	ctx, cancel := context.WithTimeout(context.Background(), 30*time.Millisecond)
	defer cancel()

	req, err := http.NewRequestWithContext(ctx, http.MethodGet, ts.URL, nil)
	if err != nil {
		panic(err)
	}

	client := &http.Client{}
	fmt.Println("[Client] Отправка запроса с context таймаутом 30 мс...")
	_, err = client.Do(req)

	if err != nil {
		fmt.Printf("[Client Safety] Запрос прерван по контексту: %v\n", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Client] Отправка запроса с context таймаутом 30 мс...
# [Client Safety] Запрос прерван по контексту: Get "http://127.0.0.1:...": context deadline exceeded
```

## Под капотом

`req.WithContext` или `http.NewRequestWithContext` связывает сетевой дескриптор с таймером в рантайме Go.

## Подводные камни

Функция `req.WithContext(ctx)` возвращает поверхностную копию `*http.Request` с новым контекстом, не мутируя исходный запрос.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие http.NewRequestWithContext от req.WithContext?»
**Ответ:** `http.NewRequestWithContext` создает новый объект запроса сразу с заданным контекстом. `req.WithContext` делает поверхностную копию существующего `*http.Request`, заменяя только поле `ctx` (полезно при пробрасывании контекста в middleware).
