# Интерактивный прогресс-бар скачивания файла через кастомный io.Writer

## Условие

**Скачивание файла с прогресс-баром**: Напишите утилиту, которая скачивает крупный файл (например, архив или картинку) по HTTP. Программа не должна загружать файл в память целиком — используйте `io.Copy`, чтобы записывать данные напрямую в файл на диске по мере скачивания. Реализуйте простой вывод прогресса (сколько процентов скачано) в консоль в реальном времени.

## Теория

Паттерн Progress Tracking Writer: структура `PassThroughWriter`, реализующая `io.Writer`, подсчитывает количество записанных байт и обновляет процент выполнения относительно заголовка `resp.ContentLength`.

## Решение по шагам

1. Создадим структуру `ProgressWriter { Total, Current }`.
2. В методе `Write(p)` накапливаем `Current += len(p)` и выводим процент.
3. Обернем `io.Copy(progressWriter, resp.Body)`.
4. Проверим расчет прогресса.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

type ProgressWriter struct {
	Total      int64
	Downloaded int64
}

func (pw *ProgressWriter) Write(p []byte) (int, error) {
	n := len(p)
	pw.Downloaded += int64(n)

	percent := float64(pw.Downloaded) / float64(pw.Total) * 100
	fmt.Printf("\r [Скачивание] Прогресс: %.1f%% (%d / %d байт)", 
		percent, pw.Downloaded, pw.Total)

	return n, nil
}

func main() {
	const totalSize = 2 * 1024 * 1024 // 2 МБ
	data := bytes.Repeat([]byte("X"), totalSize)

	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Length", fmt.Sprintf("%d", totalSize))
		w.Header().Set("Content-Type", "application/octet-stream")
		_, _ = w.Write(data)
	}))
	defer ts.Close()

	resp, err := http.Get(ts.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	pw := &ProgressWriter{Total: resp.ContentLength}

	// Потоковое копирование через обертку прогресса
	_, err = io.Copy(pw, resp.Body)
	if err != nil {
		panic(err)
	}

	fmt.Println("\n[Main] Скачивание успешно завершено на 100%!")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
#  [Скачивание] Прогресс: 100.0% (2097152 / 2097152 байт)
# [Main] Скачивание успешно завершено на 100%!
```

## Под капотом

`resp.ContentLength` считывается из заголовка `Content-Length`. Если сервер использует `Transfer-Encoding: chunked`, `ContentLength` равен `-1`.

## Подводные камни

Если `resp.ContentLength == -1`, процент прогресса вычислить невозможно, выводят только общий объем скачанных байтов.

## На собеседовании

**Вопрос с собеседования:** «Почему resp.ContentLength может быть равен -1?»
**Ответ:** Если сервер генерирует ответ динамически и отправляет данные по частям с заголовком `Transfer-Encoding: chunked`, точный размер тела ответа заранее неизвестен, и заголовок `Content-Length` отсутствует. В Go поле `resp.ContentLength` в этом случае устанавливается в `-1`.
