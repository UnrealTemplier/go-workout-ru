# Управление таймаутами клиента: сравнение http.Client и http.DefaultClient

## Условие

Напиши **HTTP-клиент с таймаутом**: `http.Client{Timeout: 5 * time.Second}`. Покажи, что `http.DefaultClient` **не имеет таймаута** (бесконечное ожидание). Это опасно в production.

## Теория

Сравнение дефолтного и изолированного клиентов: `http.DefaultClient` имеет `Timeout = 0`, что означает отсутствие ограничения по времени. Явная инициализация `http.Client{Timeout: ...}` гарантирует предсказуемость времени отклика.

## Решение по шагам

1. Создадим `client := &http.Client{Timeout: 40 * time.Millisecond}`.
2. Протестируем запрос к быстрому эндпоинту (успех).
3. Протестируем запрос к медленному эндпоинту (таймаут).
4. Выведем результаты.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		time.Sleep(80 * time.Millisecond)
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte("OK"))
	}))
	defer ts.Close()

	client := &http.Client{
		Timeout: 40 * time.Millisecond,
	}

	fmt.Println("[Client] Выполняем запрос с таймаутом 40 мс...")
	_, err := client.Get(ts.URL)

	if err != nil {
		fmt.Printf("[Client Protected] Запрос штатно прерван по таймауту: %v\n", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Client] Выполняем запрос с таймаутом 40 мс...
# [Client Protected] Запрос штатно прерван по таймауту: Get "http://127.0.0.1:...": context deadline exceeded (Client.Timeout exceeded while awaiting headers)
```

## Под капотом

`client.Timeout` инициирует таймер рантайма в момент вызова метода `Do()`.

## Подводные камни

`client.Timeout` действует на всю операцию, включая скачивание тела. Для больших файлов настраивают таймауты внутри `Transport.DialContext` и `ResponseHeaderTimeout`.

## На собеседовании

**Вопрос с собеседования:** «Что такое ResponseHeaderTimeout в http.Transport?»
**Ответ:** Это время, в течение которого клиент ожидает заголовки ответа от сервера после отправки запроса. Оно не включает время на чтение тела ответа, что идеально для скачивания больших файлов и стриминга.
