# Комбинирование Query-параметров и заголовков авторизации в одном запросе

## Условие

**Параметры запроса и заголовки**: Напишите программу, которая выполняет запрос, добавляя кастомные HTTP-заголовки (например, `Authorization: Bearer my_token`) и Query-параметры (например, `?page=2&limit=10`). Для сборки URL с параметрами используйте структуру `net/url` и её методы.

## Теория

Полноценная сборка REST-запроса: динамическое добавление query-параметров через `net/url` и установка метаданных авторизации в `req.Header`.

## Решение по шагам

1. Сформируем URL с параметрами `?page=2&limit=10`.
2. Добавим заголовок `Authorization: Bearer my_secret_token`.
3. Отправим запрос на тестовый сервер.
4. Сервер проверяет параметры и заголовок.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"net/url"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		page := r.URL.Query().Get("page")
		limit := r.URL.Query().Get("limit")
		auth := r.Header.Get("Authorization")

		fmt.Printf("[Server] Получен запрос: page=%s, limit=%s, auth=%s\n", page, limit, auth)
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte(`{"items": ["item1", "item2"], "page": 2}`))
	}))
	defer ts.Close()

	// 1. Сборка URL
	parsedURL, _ := url.Parse(ts.URL + "/api/v1/items")
	q := parsedURL.Query()
	q.Set("page", "2")
	q.Set("limit", "10")
	parsedURL.RawQuery = q.Encode()

	// 2. Создание запроса и заголовков
	req, _ := http.NewRequest(http.MethodGet, parsedURL.String(), nil)
	req.Header.Set("Authorization", "Bearer my_secret_token")
	req.Header.Set("Accept", "application/json")

	client := &http.Client{}
	resp, err := client.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	body, _ := io.ReadAll(resp.Body)
	fmt.Printf("[Client] Ответ: %s\n", string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Server] Получен запрос: page=2, limit=10, auth=Bearer my_secret_token
# [Client] Ответ: {"items": ["item1", "item2"], "page": 2}
```

## Под капотом

`r.URL.Query()` на стороне сервера парсит query-параметры из строки `RawQuery` в `url.Values`.

## Подводные камни

Не используйте `url.QueryEscape` для всего URL целиком, иначе двоеточия и слэши протокола превратятся в `%3A%2F%2F`.

## На собеседовании

**Вопрос с собеседования:** «Как безопасно передать сложные параметры (например, массивы и фильтры) в GET-запросе?»
**Ответ:** Использовать `url.Values.Add("ids", "1")`, `url.Values.Add("ids", "2")` (результирует в `?ids=1&ids=2`), либо передавать Base64-encoded JSON в одном параметре `?filter=eyJzdGF0dXMiOiJhY3RpdmUifQ==`.
