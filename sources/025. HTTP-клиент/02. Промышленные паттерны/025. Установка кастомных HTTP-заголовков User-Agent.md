# Установка кастомных HTTP-заголовков User-Agent и Authorization

## Условие

Напиши **HTTP-клиент с кастомными заголовками**: `req.Header.Set("User-Agent", "MyBot/1.0")`, `req.Header.Set("Authorization", "Bearer ...")`. Покажи, что `http.DefaultClient` использует дефолтный User-Agent.

## Теория

Заголовки сетевой идентификации: `http.DefaultClient` отправляет заголовок `User-Agent: Go-http-client/1.1` (или 2.0). Большинство внешних Cloudflare/WAF и REST API серверов (GitHub API, Cloudflare) блокируют запросы со стандартным User-Agent Go, требуя явного указания названия сервиса.

## Решение по шагам

1. Поднимем сервер, инспектирующий `User-Agent` и `Authorization`.
2. Отправим запрос со стандартным клиентом (дефолтный UA).
3. Отправим запрос с кастомными заголовками.
4. Проверим разницу.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Printf(" [Server Inspection] Path: %-12s | User-Agent: %s\n", 
			r.URL.Path, r.Header.Get("User-Agent"))
		w.WriteHeader(http.StatusOK)
	}))
	defer ts.Close()

	// 1. Дефолтный запрос через http.Get
	resp1, _ := http.Get(ts.URL + "/default")
	resp1.Body.Close()

	// 2. Кастомный запрос с кастомными заголовками
	req, _ := http.NewRequest(http.MethodGet, ts.URL+"/custom", nil)
	req.Header.Set("User-Agent", "EnterpriseBot/2.4 (Linux; x86_64)")
	req.Header.Set("Authorization", "Bearer JWT_SECRET_TOKEN_123")
	req.Header.Set("X-Request-ID", "REQ-998811")

	client := &http.Client{}
	resp2, _ := client.Do(req)
	resp2.Body.Close()

	fmt.Println("[Client] Запросы с заголовками успешно отправлены.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
#  [Server Inspection] Path: /default     | User-Agent: Go-http-client/1.1
#  [Server Inspection] Path: /custom      | User-Agent: EnterpriseBot/2.4 (Linux; x86_64)
# [Client] Запросы с заголовками успешно отправлены.
```

## Под капотом

Если заголовок `User-Agent` не задан явно, рантайм `net/http` автоматически подставляет константу `Go-http-client/1.1`.

## Подводные камни

Сервисы вроде GitHub API возвращают `403 Forbidden`, если `User-Agent` отсутствует или равен дефолтному значению Go.

## На собеседовании

**Вопрос с собеседования:** «Зачем микросервисы передают заголовок X-Request-ID (или Traceparent W3C)?»
**Ответ:** Для распределенной трассировки (Distributed Tracing / OpenTelemetry): сквозной `X-Request-ID` передается через всю цепочку микросервисов (API Gateway -> Auth -> Billing -> DB), позволяя найти все логи одного пользовательского запроса в Jaeger/Grafana Tempo.
