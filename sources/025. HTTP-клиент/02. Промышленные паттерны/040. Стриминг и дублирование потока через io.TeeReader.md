# Стриминг и дублирование потока через io.TeeReader для логирования

## Условие

Напиши **HTTP-загрузчик файла**: `http.Get` по URL, `io.Copy` в локальный файл. Покажи прогресс: в отдельной горутине читай `resp.ContentLength` и сколько байт скопировано (через `io.TeeReader` или `io.Reader` обёртку).

## Теория

Паттерн Stream Splitting (Разветвитель потока): функция `io.TeeReader(r, w)` возвращает `io.Reader`, который при каждом чтении из `r` синхронно дублирует прочитанные байты в `w` (по аналогии с Unix-утилитой `tee`).

## Решение по шагам

1. Создадим тестовый сервер.
2. Обернем `resp.Body` через `tee := io.TeeReader(resp.Body, logger)`.
3. Считаем данные в целевой файл через `io.Copy(dest, tee)`.
4. Проверим, что данные попали и в файл, и в логгер.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte("STREAMING_TELEMETRY_PAYLOAD"))
	}))
	defer ts.Close()

	resp, err := http.Get(ts.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var fileStorage bytes.Buffer
	var debugLogger bytes.Buffer

	// TeeReader дублирует каждый байт из resp.Body в debugLogger во время чтения
	tee := io.TeeReader(resp.Body, &debugLogger)

	// Читаем из tee в целевое хранилище
	written, err := io.Copy(&fileStorage, tee)
	if err != nil {
		panic(err)
	}

	fmt.Printf("[TeeReader Pipeline] Записано в файл:   %d байт (%s)\n", written, fileStorage.String())
	fmt.Printf("[TeeReader Pipeline] Записано в логгер: %d байт (%s)\n", debugLogger.Len(), debugLogger.String())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [TeeReader Pipeline] Записано в файл:   27 байт (STREAMING_TELEMETRY_PAYLOAD)
# [TeeReader Pipeline] Записано в логгер: 27 байт (STREAMING_TELEMETRY_PAYLOAD)
```

## Под капотом

`io.TeeReader` не создает промежуточных буферов в памяти: вызов `Read` напрямую вызывает `Write` второго получателя.

## Подводные камни

Если запись в дублирующий `io.Writer` вернет ошибку, чтение из `TeeReader` тоже прервется с ошибкой.

## На собеседовании

**Вопрос с собеседования:** «Как с помощью io.TeeReader посчитать SHA-256 хеш скачиваемого файла на лету?»
**Ответ:** Создать хешер `hasher := sha256.New()`, обернуть поток `tee := io.TeeReader(resp.Body, hasher)` и передать в `io.Copy(file, tee)`. По завершении скачивания `hasher.Sum(nil)` вернет точный SHA-256 хеш без повторного чтения файла с диска.
