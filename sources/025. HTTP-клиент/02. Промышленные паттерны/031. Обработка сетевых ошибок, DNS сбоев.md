# Обработка сетевых ошибок, DNS сбоев и HTTP статус-кодов (404/500)

## Условие

**Обработка ошибок и статус-кодов**: Выполните запрос к несуществующему домену и обработайте возникающую сетевую ошибку. Выполните запрос к существующему домену, но по некорректному адресу (чтобы получить статус `404 Not Found`). Напишите корректную обработку статус-кодов ответов (проверку `resp.StatusCode`).

## Теория

Разделение ошибок сетевого и прикладного уровня:
1. **Сетевые ошибки (`err != nil`):** DNS lookup failed, connection refused, connection timeout. В этом случае `resp == nil`.
2. **Прикладные HTTP-ошибки (`err == nil`):** сервер успешно ответил, но статус-код равен 404, 401, 500. В этом случае `resp != nil` и `resp.Body` ОБЯЗАН быть закрыт.

## Решение по шагам

1. Выполним запрос к несуществующему хосту `http://non-existent-domain-xyz.invalid`.
2. Обработаем сетевую ошибку.
3. Выполним запрос к существующему серверу по несуществующему пути `/missing`.
4. Обработаем статус `http.StatusNotFound`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func main() {
	client := &http.Client{}

	// 1. Сетевая ошибка (DNS / Connect failure)
	_, err := client.Get("http://invalid-domain-123456789.invalid")
	if err != nil {
		fmt.Printf("[Network Error Handled] Сетевой сбой: %v\n", err)
	}

	// 2. HTTP ошибка 404 Not Found
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		http.NotFound(w, r)
	}))
	defer ts.Close()

	resp, err := client.Get(ts.URL + "/unknown-page")
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	if resp.StatusCode == http.StatusNotFound {
		fmt.Printf("[HTTP Status Handled] Получен ожидаемый статус 404: %s\n", resp.Status)
	} else {
		body, _ := io.ReadAll(resp.Body)
		fmt.Printf("[Response] %s\n", string(body))
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Network Error Handled] Сетевой сбой: Get "http://invalid-domain-123456789.invalid": dial tcp: lookup invalid-domain-123456789.invalid: no such host
# [HTTP Status Handled] Получен ожидаемый статус 404: 404 Not Found
```

## Под капотом

Сетевые ошибки возвращают типы `*net.OpError` и `*url.Error`.

## Подводные камни

Статус 500 Internal Server Error возвращает `err == nil`! Проверяйте `resp.StatusCode >= 400`.

## На собеседовании

**Вопрос с собеседования:** «Возвращает ли http.Get ошибку при получении HTTP 500 Internal Server Error?»
**Ответ:** Нет! Функция `http.Get` возвращает `err == nil`, потому что сетевой протокол HTTP отработал успешно и сервер вернул валидный ответ. Проверка ошибочных статус-кодов (4xx, 5xx) является ответственностью прикладного кода через `resp.StatusCode`.
