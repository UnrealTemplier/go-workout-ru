# Базовый GET-запрос к публичному API и форматирование строки ответа

## Условие

**Базовый GET-запрос**: Напишите программу, которая выполняет GET-запрос к публичному тестовому API (например, `https://jsonplaceholder.typicode.com/posts/1`) с помощью `http.Get`. Считайте тело ответа, преобразуйте его в строку и выведите в консоль.

## Теория

Чтение текстовых данных ответа: поток байтов `io.ReadAll(resp.Body)` преобразуется в строку `string(bytes)` для отображения.

## Решение по шагам

1. Запустим тестовый JSON эндпоинт.
2. Выполним запрос `http.Get(url)`.
3. Считаем тело через `io.ReadAll`.
4. Выведем результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte(`{"userId": 1, "id": 1, "title": "delectus aut autem", "completed": false}`))
	}))
	defer ts.Close()

	resp, err := http.Get(ts.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	bodyBytes, err := io.ReadAll(resp.Body)
	if err != nil {
		panic(err)
	}

	fmt.Println("Ответ от REST API:")
	fmt.Println(string(bodyBytes))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Ответ от REST API:
# {"userId": 1, "id": 1, "title": "delectus aut autem", "completed": false}
```

## Под капотом

`resp.Body` реализует `io.Reader`, поток закрывается вызовом `Close()`.

## Подводные камни

Всегда проверяйте `resp.StatusCode == http.StatusOK` перед обработкой тела.

## На собеседовании

**Вопрос с собеседования:** «Каков порядок обработки HTTP ответа в Go?»
**Ответ:** 1. Проверить сетевую ошибку `if err != nil`; 2. Добавить `defer resp.Body.Close()`; 3. Проверить статус код `if resp.StatusCode != http.StatusOK`; 4. Вычитать тело ответа.
