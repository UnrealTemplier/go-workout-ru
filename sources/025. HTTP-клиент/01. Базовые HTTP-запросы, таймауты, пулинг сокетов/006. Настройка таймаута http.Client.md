# Настройка таймаута http.Client и перехват ошибки context.DeadlineExceeded

## Условие

Настрой кастомный `http.Client` с `Timeout: 5 * time.Second`. Сделай запрос к серверу, который отвечает дольше 5 секунд (можно использовать `httpbin.org/delay/10`). Поймай ошибку таймаута.

## Теория

Политика таймаутов `http.Client.Timeout`: задает максимальное суммарное время на выполнение всего запроса целиком, включая DNS, TCP Handshake, TLS Handshake, отправку и чтение ответа.

## Решение по шагам

1. Создадим сервер с задержкой ответа 100 мс.
2. Настроим клиент с `Timeout: 25 * time.Millisecond`.
3. Выполним запрос `client.Get(ts.URL)`.
4. Поймаем ошибку `Client.Timeout exceeded`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		time.Sleep(100 * time.Millisecond)
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte("Delayed Response"))
	}))
	defer ts.Close()

	client := &http.Client{
		Timeout: 25 * time.Millisecond,
	}

	fmt.Println("[Client] Отправка запроса с таймаутом 25 мс...")
	_, err := client.Get(ts.URL)

	if err != nil {
		fmt.Printf("[Client Safety] ПЕРЕХВАЧЕН ТАЙМАУТ: %v\n", err)
	} else {
		fmt.Println("[Client] Ошибка: запрос должен был прерваться по таймауту!")
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Client] Отправка запроса с таймаутом 25 мс...
# [Client Safety] ПЕРЕХВАЧЕН ТАЙМАУТ: Get "http://127.0.0.1:...": context deadline exceeded (Client.Timeout exceeded while awaiting headers)
```

## Под капотом

Под капотом `client.Timeout` создает таймер контекста `context.WithTimeout`, который автоматически прерывает системные сетевые вызовы рантайма.

## Подводные камни

`client.Timeout` включает время на чтение всего Response Body. Если вы скачиваете файл 1 ГБ, таймаут клиента должен быть достаточно большим или управляться контекстом.

## На собеседовании

**Вопрос с собеседования:** «Почему в http.DefaultClient таймаут по умолчанию равен нулю?»
**Ответ:** По историческим причинам в Go нулевой таймаут означает бесконечное ожидание (`no timeout`). В продакшене это считается критической уязвимостью, так как зависший сторонний API может заблокировать все горутины сервиса.
