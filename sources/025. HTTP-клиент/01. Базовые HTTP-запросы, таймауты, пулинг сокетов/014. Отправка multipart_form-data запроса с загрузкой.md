# Отправка multipart/form-data запроса с загрузкой файлов через mime/multipart

## Условие

Загрузите файл на сервер, используя `multipart/form-data` (пакет `mime/multipart` и `http.NewRequest`).

## Теория

Формат Multipart Form-Data (RFC 7578): используется для отправки файлов и текстовых полей формы. Структура `multipart.Writer` генерирует уникальный разделитель границ (Boundary) и форматирует тело запроса с заголовками `Content-Disposition: form-data; name="file"; filename="..."`.

## Решение по шагам

1. Создадим `body := &bytes.Buffer{}` и `writer := multipart.NewWriter(body)`.
2. Создадим файловое поле `part, _ := writer.CreateFormFile("avatar", "profile.png")`.
3. Запишем байты файла в `part`.
4. Закроем `writer.Close()` и передадим `writer.FormDataContentType()` в `http.NewRequest`.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"mime/multipart"
	"net/http"
	"net/http/httptest"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		err := r.ParseMultipartForm(10 << 20)
		if err != nil {
			http.Error(w, err.Error(), http.StatusBadRequest)
			return
		}

		user := r.FormValue("username")
		file, header, err := r.FormFile("document")
		if err != nil {
			http.Error(w, err.Error(), http.StatusBadRequest)
			return
		}
		defer file.Close()

		content, _ := io.ReadAll(file)
		fmt.Printf("[Server Upload] Пользователь: %s\n", user)
		fmt.Printf("[Server Upload] Имя файла: %s (Размер: %d байт)\n", header.Filename, len(content))
		fmt.Printf("[Server Upload] Содержимое: %s\n", string(content))

		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte("UPLOAD_SUCCESS"))
	}))
	defer ts.Close()

	body := &bytes.Buffer{}
	writer := multipart.NewWriter(body)

	_ = writer.WriteField("username", "alex_dev")

	part, err := writer.CreateFormFile("document", "contract.txt")
	if err != nil {
		panic(err)
	}
	_, _ = part.Write([]byte("Текст официального договора оказания услуг."))

	_ = writer.Close()

	req, err := http.NewRequest(http.MethodPost, ts.URL, body)
	if err != nil {
		panic(err)
	}

	req.Header.Set("Content-Type", writer.FormDataContentType())

	client := &http.Client{}
	resp, err := client.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	respMsg, _ := io.ReadAll(resp.Body)
	fmt.Printf("[Client Response] %s\n", string(respMsg))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Server Upload] Пользователь: alex_dev
# [Server Upload] Имя файла: contract.txt (Размер: 78 байт)
# [Server Upload] Содержимое: Текст официального договора оказания услуг.
# [Client Response] UPLOAD_SUCCESS
```

## Под капотом

`writer.FormDataContentType()` возвращает строку вида `multipart/form-data; boundary=...`.

## Подводные камни

Всегда вызывайте `writer.Close()` ДО передачи тела в запрос, иначе закрывающий boundary не запишется.

## На собеседовании

**Вопрос с собеседования:** «Как загрузить 5 ГБ файл через multipart/form-data без загрузки всего файла в RAM?»
**Ответ:** Использовать `io.Pipe()`: в отдельной горутине `multipart.Writer` пишет в `PipeWriter`, а `http.NewRequest` читает из `PipeReader`.
