# Парсинг URL и безопасное кодирование параметров через net/url и url.Values

## Условие

Используй `net/url` для парсинга URL. Добавь query-параметры (например, `?q=golang&page=2`) с помощью `url.Values`.

## Теория

Безопасная сборка Query-строки: ручная конкатенация строк (`"?q=" + str`) уязвима к инъекциям и ломается на пробелах и спецсимволах (`&`, `=`, `?`). Пакет `net/url` и тип `url.Values` автоматически экранируют символы согласно RFC 3986 (Percent-Encoding).

## Решение по шагам

1. Распарсим базовый URL через `url.Parse("https://api.example.com/search")`.
2. Создадим `params := url.Values{}`.
3. Добавим параметры через `params.Add("q", "golang & concurrency")`.
4. Присвоим `parsedURL.RawQuery = params.Encode()`.
5. Выведем собранный URL.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/url"
)

func main() {
	baseURL := "https://api.github.com/search/repositories"
	parsedURL, err := url.Parse(baseURL)
	if err != nil {
		panic(err)
	}

	query := url.Values{}
	query.Add("q", "language:go stars:>1000")
	query.Add("sort", "stars")
	query.Add("order", "desc")
	query.Add("page", "2")

	parsedURL.RawQuery = query.Encode()

	fmt.Println("Итоговый скомпонованный URL:")
	fmt.Println(parsedURL.String())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Итоговый скомпонованный URL:
# https://api.github.com/search/repositories?order=desc&page=2&q=language%3Ago+stars%3A%3E1000&sort=stars
```

## Под капотом

Метод `query.Encode()` сортирует ключи по алфавиту и заменяет спецсимволы на `%XX` или `+`.

## Подводные камни

`query.Set()` заменяет значение ключа, а `query.Add()` добавляет второе значение к тому же ключу (`?tag=go&tag=web`).

## На собеседовании

**Вопрос с собеседования:** «В чем разница между url.Path и url.RawPath в структуре url.URL?»
**Ответ:** `url.Path` содержит декодированный путь (например, `/user/иван`), а `url.RawPath` — оригинальный закодированный путь (`/user/%D0%B8%D0%B2%D0%B0%D0%BD`). Если путь содержит символы `%2F` (экранированный слэш), Go использует `RawPath` для сохранения точной структуры URL.
