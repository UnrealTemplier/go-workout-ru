# Инициализация безопасного http.Client с таймаутом взамен глобального get

## Условие

**Таймаут клиента**: Глобальный `http.Get` не имеет таймаута (он может висеть вечно). Создай свой клиент: `client := &http.Client{Timeout: 3 * time.Second}`. Сделай запрос через `client.Get(...)`.

## Теория

Защита микросервисов: создание экземпляра `http.Client{Timeout: d}` является базовым правилом сетевой надежности (Resilience).

## Решение по шагам

1. Создадим клиента `client := &http.Client{Timeout: 50 * time.Millisecond}`.
2. Выполним запрос к серверу.
3. Проверим статус ответа.
4. Выведем результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		time.Sleep(10 * time.Millisecond)
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte("Fast Response"))
	}))
	defer ts.Close()

	client := &http.Client{
		Timeout: 50 * time.Millisecond,
	}

	resp, err := client.Get(ts.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	fmt.Printf("[Client] Успешный запрос со статусом: %s\n", resp.Status)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Client] Успешный запрос со статусом: 200 OK
```

## Под капотом

`client.Timeout` оборачивает сетевые системные вызовы в контекстный таймер.

## Подводные камни

Не забывайте, что `http.Get` использует дефолтный клиент без таймаута.

## На собеседовании

**Вопрос с собеседования:** «Какой линтер находит использование http.DefaultClient в кодовой базе?»
**Ответ:** Линтер `noctx` и правила `gosec` (G107) в составе `golangci-lint` отслеживают вызовы `http.Get`, `http.Post` и создание запросов без контекста.
