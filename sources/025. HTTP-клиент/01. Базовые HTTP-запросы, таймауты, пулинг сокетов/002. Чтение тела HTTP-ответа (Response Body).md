# Чтение тела HTTP-ответа (Response Body) через io.ReadAll

## Условие

Прочитай тело ответа (Response Body) с помощью `io.ReadAll` и выведи первые 100 байт в консоль.

## Теория

Интерфейс `io.ReadCloser`: поле `resp.Body` представляет собой поток входящих байтов. Функция `io.ReadAll(resp.Body)` считывает все доступные байты до получения маркера конца потока `io.EOF`.

## Решение по шагам

1. Выполним GET-запрос к тестовому HTTP-серверу.
2. Прочитаем тело через `bodyBytes, err := io.ReadAll(resp.Body)`.
3. Ограничим вывод первыми 100 байтами `bodyBytes[:limit]`.
4. Выведем результат в консоль.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "text/plain")
		_, _ = w.Write([]byte("Go is an open source programming language that makes it easy to build simple, fast, and reliable software."))
	}))
	defer ts.Close()

	resp, err := http.Get(ts.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	bodyBytes, err := io.ReadAll(resp.Body)
	if err != nil {
		panic(err)
	}

	limit := 60
	if len(bodyBytes) < limit {
		limit = len(bodyBytes)
	}

	fmt.Printf("[HTTP Body] Всего считано: %d байт\n", len(bodyBytes))
	fmt.Printf("[HTTP Body] Первые %d байт: %q\n", limit, string(bodyBytes[:limit]))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [HTTP Body] Всего считано: 107 байт
# [HTTP Body] Первые 60 байт: "Go is an open source programming language that makes it easy" 
```

## Под капотом

`io.ReadAll` динамически расширяет внутренний буфер `bytes.Buffer` по мере поступления чанков данных от сетевой карты.

## Подводные камни

`io.ReadAll` считывает весь ответ в оперативную память. Для больших файлов (100 МБ+) используйте `io.Copy(file, resp.Body)` или `io.LimitReader` во избежание OOM.

## На собеседовании

**Вопрос с собеседования:** «Как защитить HTTP-клиент от атаки Zip-бомбой или бесконечным потоком байтов в Response Body?»
**Ответ:** Обернуть `resp.Body` в `io.LimitReader(resp.Body, maxBytes)` (например, 10 МБ). Если сервер передает больше данных, `Read` завершится ошибкой или вернет усеченные данные, не допустив переполнения RAM.
