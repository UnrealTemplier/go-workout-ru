# POST-запрос с отправкой сериализованного JSON на REST API эндпоинт

## Условие

**POST-запрос с JSON**: Закодируй структуру в JSON. Отправь POST-запрос на `https://jsonplaceholder.typicode.com/posts` с помощью `http.Post`. Укажи Content-Type `application/json`.

## Теория

Интеграция с REST API сервисами: формирование JSON-объектов через `json.Marshal` и отправка в теле POST-запроса.

## Решение по шагам

1. Опишем структуру `BlogPost { Title, Body, UserID }`.
2. Закодируем в JSON.
3. Отправим запрос через `http.Post`.
4. Проверим парсинг полученного ответа.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

type BlogPost struct {
	Title  string `json:"title"`
	Body   string `json:"body"`
	UserID int    `json:"userId"`
}

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		var post BlogPost
		_ = json.NewDecoder(r.Body).Decode(&post)
		defer r.Body.Close()

		w.Header().Set("Content-Type", "application/json")
		w.WriteHeader(http.StatusCreated)
		_, _ = w.Write([]byte(fmt.Sprintf(`{"id": 101, "title": %q, "userId": %d}`, post.Title, post.UserID)))
	}))
	defer ts.Close()

	newPost := BlogPost{
		Title:  "Архитектура микросервисов на Go",
		Body:   "Подробный разбор HTTP-клиента, контекстов и пулинга соединений.",
		UserID: 42,
	}

	jsonData, _ := json.Marshal(newPost)

	resp, err := http.Post(ts.URL+"/posts", "application/json", bytes.NewReader(jsonData))
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	body, _ := io.ReadAll(resp.Body)
	fmt.Printf("[REST API Response] Status=%d, Body=%s\n", resp.StatusCode, string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [REST API Response] Status=201, Body={"id": 101, "title": "Архитектура микросервисов на Go", "userId": 42}
```

## Под капотом

`json.NewDecoder(r.Body).Decode(&post)` парсит JSON напрямую из потока сокета без аллокации промежуточного слайса байт.

## Подводные камни

Поля структуры обязаны быть экспортируемыми (с заглавной буквы), иначе `json.Marshal` их проигнорирует.

## На собеседовании

**Вопрос с собеседования:** «Когда использовать bytes.Buffer, а когда io.Pipe для отправки больших JSON POST-запросов?»
**Ответ:** `bytes.Buffer` загружает весь JSON в память (подходит для объектов \(< 5\text{ МБ}\)). `io.Pipe()` позволяет сериализатору `json.NewEncoder(pw).Encode(data)` писать данные напрямую в поток сокета в параллельной горутине с \(O(1)\) RAM.
