# Потоковое скачивание больших файлов на диск через io.Copy без расхода RAM

## Условие

Реализуйте скачивание большого файла (например, видео или ISO-образа) с сохранением на диск через `io.Copy`, не загружая всё тело ответа в оперативную память.

## Теория

Потоковая передача данных (Stream Piping): метод `io.Copy(destinationFile, resp.Body)` копирует байты из сетевого сокета в файловый дескриптор порциями по 32 КБ. Это позволяет скачивать файлы любого размера (10 ГБ+) с постоянным потреблением памяти в несколько килобайт.

## Решение по шагам

1. Запустим тестовый сервер, отдающий поток байтов.
2. В клиенте создадим целевой буфер.
3. Вызовем `written, err := io.Copy(dest, resp.Body)`.
4. Проверим объем записанных данных.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/octet-stream")
		chunk := bytes.Repeat([]byte("A"), 1024*1024)
		for i := 0; i < 5; i++ {
			_, _ = w.Write(chunk)
		}
	}))
	defer ts.Close()

	resp, err := http.Get(ts.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	var diskSimulator bytes.Buffer

	writtenBytes, err := io.Copy(&diskSimulator, resp.Body)
	if err != nil {
		panic(err)
	}

	fmt.Printf("[File Downloader] Успешно скачано: %.2f МБ (%d байт) с константной памятью O(1) RAM!\n", 
		float64(writtenBytes)/(1024*1024), writtenBytes)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [File Downloader] Успешно скачано: 5.00 МБ (5242880 байт) с константной памятью O(1) RAM!
```

## Под капотом

`io.Copy` циклически вызывает `resp.Body.Read(buf[32KB])` и `file.Write(buf)`, не удерживая прочитанные порции в куче.

## Подводные камни

Не забывайте закрывать и файл `defer file.Close()`, и сетевой ответ `defer resp.Body.Close()`.

## На собеседовании

**Вопрос с собеседования:** «Как возобновить скачивание оборванного файла (Resume Download)?»
**Ответ:** Получить размер уже скачанной части файла на диске и передать заголовок HTTP Range: `req.Header.Set("Range", fmt.Sprintf("bytes=%d-", currentSize))`. Сервер с поддержкой Range вернет статус `206 Partial Content`.
