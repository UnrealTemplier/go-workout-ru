# Базовый HTTP GET-запрос через http.Get и анализ Response StatusCode

## Условие

Используй `http.Get`, чтобы сделать запрос к `https://golang.org`. Выведи статус-код ответа (например, 200 OK).

## Теория

Клиентский HTTP в Go: функция `http.Get(url)` использует стандартный транспорт `http.DefaultClient` для выполнения HTTP/1.1 или HTTP/2 GET-запроса. Возвращаемая структура `*http.Response` содержит статус-код `resp.StatusCode` (целое число) и текстовую строку статуса `resp.Status` (например, "200 OK").

## Решение по шагам

1. Запустим тестовый HTTP-сервер на базе `net/http/httptest`.
2. Выполним запрос с помощью `http.Get(ts.URL)`.
3. Обязательно закроем тело ответа `defer resp.Body.Close()`.
4. Выведем `resp.StatusCode` и `resp.Status`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte("Golang Official Site"))
	}))
	defer ts.Close()

	resp, err := http.Get(ts.URL)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close() // КРИТИЧНО: освобождение сокета в пул

	fmt.Printf("[HTTP Client] Статус-код: %d\n", resp.StatusCode)
	fmt.Printf("[HTTP Client] Строка статуса: %s\n", resp.Status)
	fmt.Printf("[HTTP Client] Протокол: %s\n", resp.Proto)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [HTTP Client] Статус-код: 200
# [HTTP Client] Строка статуса: 200 OK
# [HTTP Client] Протокол: HTTP/1.1
```

## Под капотом

`http.Get` выполняет полный цикл: DNS-резолвинг, TCP 3-Way Handshake, TLS Negotiation (для HTTPS), отправку HTTP-заголовков и чтение заголовков ответа.

## Подводные камни

Всегда вызывайте `resp.Body.Close()`, иначе базовое TCP-соединение не вернется в `Idle Connection Pool` и сокет останется висеть в памяти.

## На собеседовании

**Вопрос с собеседования:** «Почему проверка if err != nil должна идти ДО вызова defer resp.Body.Close()?»
**Ответ:** Если при установке соединения произошла ошибка сети или DNS (например, dial tcp: lookup failed), указатель `resp` будет равен `nil`. Вызов `resp.Body.Close()` приведет к фатальной панике `nil pointer dereference`.
