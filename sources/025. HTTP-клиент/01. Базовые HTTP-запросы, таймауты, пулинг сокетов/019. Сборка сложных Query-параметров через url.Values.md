# Сборка сложных Query-параметров через url.Values и rawQuery

## Условие

**Query-параметры**: Не клей URL руками (как `?name=Ivan&age=20`). Используй `url.Values{}`. Добавь параметры, затем приклей их к запросу: `req.URL.RawQuery = q.Encode()`.

## Теория

Формирование Query-строки в объекте `http.Request`: изменение поля `req.URL.RawQuery = values.Encode()` позволяет безопасно внедрить параметры в уже созданный запрос.

## Решение по шагам

1. Создадим `req, _ := http.NewRequest("GET", "https://api.com/users", nil)`.
2. Создадим `q := req.URL.Query()`.
3. Добавим параметры `q.Add("filter", "active")`, `q.Add("limit", "50")`.
4. Запишем `req.URL.RawQuery = q.Encode()`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"net/http"
)

func main() {
	req, err := http.NewRequest(http.MethodGet, "https://api.bank.com/v1/transactions", nil)
	if err != nil {
		panic(err)
	}

	q := req.URL.Query()
	q.Add("account_id", "ACC-99881122")
	q.Add("currency", "RUB")
	q.Add("status", "COMPLETED")
	q.Add("from_date", "2026-01-01")

	req.URL.RawQuery = q.Encode()

	fmt.Println("Сформированный URL запроса с Query-параметрами:")
	fmt.Println(req.URL.String())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Сформированный URL запроса с Query-параметрами:
# https://api.bank.com/v1/transactions?account_id=ACC-99881122&currency=RUB&from_date=2026-01-01&status=COMPLETED
```

## Под капотом

`req.URL.Query()` парсит `RawQuery` в новую мапу `url.Values`, поэтому для применения изменений обязательно присваивание `req.URL.RawQuery = q.Encode()`.

## Подводные камни

Изменение мапы, возвращенной `req.URL.Query()`, не меняет URL автоматически без вызова `Encode()`.

## На собеседовании

**Вопрос с собеседования:** «Почему q := req.URL.Query(); q.Set("a", "b") само по себе не меняет URL запроса?»
**Ответ:** Потому что метод `Query()` парсит строку и возвращает **копию** структуры `url.Values`. Чтобы изменения вступили в силу, необходимо явно перезаписать поле `req.URL.RawQuery = q.Encode()`.
