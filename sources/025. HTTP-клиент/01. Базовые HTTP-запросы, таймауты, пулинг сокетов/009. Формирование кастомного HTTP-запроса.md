# Формирование кастомного HTTP-запроса через http.NewRequest и Header.Set

## Условие

**Кастомный запрос (Custom Headers)**: Тебе нужно передать токен авторизации. Используй `req, err := http.NewRequest("GET", url, nil)`. Добавь заголовок: `req.Header.Set("Authorization", "Bearer my-token")`. Выполни запрос через `client.Do(req)`.

## Теория

Конструктор `http.NewRequest`: позволяет сформировать произвольный HTTP-запрос, настроить HTTP-заголовки (`req.Header`), куки и тело запроса. Метод `client.Do(req)` отправляет сконфигурированный объект запроса.

## Решение по шагам

1. Создадим запрос `http.NewRequest("GET", url, nil)`.
2. Добавим заголовок авторизации `req.Header.Set("Authorization", "Bearer secret-token-999")`.
3. Добавим `req.Header.Set("User-Agent", "GoService/2.0")`.
4. Выполним через `client.Do(req)` и проверим на сервере.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func main() {
	ts := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		auth := r.Header.Get("Authorization")
		ua := r.Header.Get("User-Agent")

		fmt.Printf("[Server] Получен Auth Header: %s\n", auth)
		fmt.Printf("[Server] Получен User-Agent:  %s\n", ua)

		if auth == "Bearer secret-jwt-token-xyz" {
			w.WriteHeader(http.StatusOK)
			_, _ = w.Write([]byte(`{"access": "granted"}`))
		} else {
			w.WriteHeader(http.StatusUnauthorized)
			_, _ = w.Write([]byte(`{"error": "unauthorized"}`))
		}
	}))
	defer ts.Close()

	req, err := http.NewRequest(http.MethodGet, ts.URL+"/api/secure", nil)
	if err != nil {
		panic(err)
	}

	req.Header.Set("Authorization", "Bearer secret-jwt-token-xyz")
	req.Header.Set("User-Agent", "BackendWorkoutClient/1.0")
	req.Header.Set("Accept", "application/json")

	client := &http.Client{}
	resp, err := client.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	body, _ := io.ReadAll(resp.Body)
	fmt.Printf("[Client] Ответ сервера (Status %d): %s\n", resp.StatusCode, string(body))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Server] Получен Auth Header: Bearer secret-jwt-token-xyz
# [Server] Получен User-Agent:  BackendWorkoutClient/1.0
# [Client] Ответ сервера (Status 200): {"access": "granted"}
```

## Под капотом

`req.Header` представляет собой мапу `map[string][]string`. Метод `Set()` канонизирует регистр ключа с помощью `textproto.CanonicalMIMEHeaderKey`.

## Подводные камни

Для нестандартных заголовков, требующих точного регистра, прямая запись в мапу `req.Header["x-my-header"] = []string{val}` обходит канонизацию.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между req.Header.Set() и req.Header.Add()?»
**Ответ:** `Set(k, v)` перезаписывает все существующие значения для данного ключа. `Add(k, v)` добавляет новое значение в срез `[]string`, позволяя передавать множественные заголовки с одинаковым именем.
