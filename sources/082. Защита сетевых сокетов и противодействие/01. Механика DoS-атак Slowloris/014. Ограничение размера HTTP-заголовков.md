# Ограничение размера HTTP-заголовков и защита от атак Header Bombing

## Условие

Сконфигурируйте MaxHeaderBytes: 1 << 20 (1 МБ) в http.Server и протестируйте отсечение гигантских заголовков со статусом 431 Request Header Fields Too Large.

### Исходная формулировка

**Ограничение размера заголовков.**: Установите `http.MaxBytesReader` для ограничения размера тела запроса. Для заголовков используйте `http.Server.MaxHeaderBytes`. Протестируйте запрос с гигантскими заголовками.

## Теория

Злоумышленник может отправить запрос с HTTP-заголовками размером в сотни мегабайт (Header Bombing). Если сервер не ограничивает размер буфера парсинга, он выделит огромные срезы байт в оперативной памяти для хранения карты заголовков `http.Header`. Поле `MaxHeaderBytes` задает максимальный допустимый объем всех входящих заголовков запроса. При превышении сервер мгновенно отклоняет запрос со статусом `HTTP 431 Request Header Fields Too Large`.

## Решение по шагам

Установите параметр `MaxHeaderBytes: 1 << 20` (1 МБ) в `http.Server`.
Сформируйте тестовый запрос с заголовком размером 2 МБ.
Отправьте запрос серверу и зафиксируйте код ответа HTTP 431.
Убедитесь, что сервер не аллоцирует память под избыточные заголовки.

## Код решения

**`header_limit_server.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"time"
)

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("/api/test", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprintln(w, "Headers OK")
	})

	srv := &http.Server{
		Addr:              ":8080",
		Handler:           mux,
		MaxHeaderBytes:    1 << 20,          // Жесткий лимит 1 МБ на все HTTP заголовки
		ReadHeaderTimeout: 5 * time.Second,
	}

	fmt.Println("[SERVER] Защита от Header Bombing активна (лимит 1 МБ)")
	_ = srv
}
```

ℹ️ Ограничение максимального размера входящих заголовков HTTP

## Под капотом

Go использует `bufio.Reader` со специальным счетчиком прочитанных байт при парсинге заголовков. Если счетчик превышает `MaxHeaderBytes`, парсер прерывает цикл и возвращает ошибку `http: request header too large`.

## Подводные камни

Если установить `MaxHeaderBytes` слишком маленьким (например, 2 КБ), сервер начнет отклонять легитимные запросы с большими JWT-токенами авторизации или куками (Cookie overflow).

## На собеседовании

Какой код ответа возвращает сервер Go при превышении MaxHeaderBytes? Возвращается стандартный код HTTP 431 Request Header Fields Too Large (или разрыв соединения при грубом превышении буфера).
