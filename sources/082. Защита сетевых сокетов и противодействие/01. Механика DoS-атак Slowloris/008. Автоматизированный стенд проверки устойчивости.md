# Автоматизированный стенд проверки устойчивости к Slowloris

## Условие

Разработайте Go-скрипт стресс-тестирования, который параллельно отправляет Slowloris-трафик и регулярные проверочные HTTP-запросы (Healthcheck) с измерением p99 задержки ответа сервера.

### Исходная формулировка

**Slowloris: демонстрация атаки.**: Напишите (в образовательных целях) Go-«атакующий»: открывает 1000 TCP-соединений, шлёт HTTP-заголовки байт за байтом с `time.Sleep(10s)` между байтами. Запустите против дефолтного `http.ListenAndServe`. Покажите, что сервер исчерпывает лимит соединений и перестаёт отвечать legit клиентам.

## Теория

Для подтверждения защищенности сервиса перед релизом в production организуют стресс-тест. Тестовый стенд запускает пул фоновых медленных горутин, одновременно отправляя контрольные запросы с замером времени отклика. Если сервер уязвим, latency контрольных запросов резко возрастает до таймаута, либо запросы отклоняются с ошибкой `connection refused`.

## Решение по шагам

Запустите фоновую генерацию 500 медленных соединений.
В основном потоке отправляйте запрос `GET /health` каждую секунду.
Замеряйте время Round-Trip Time (RTT).
Сформируйте отчет о проценте успешных запросов и деградации задержки.

## Код решения

**`slowloris_benchmark.go`**

```go
package main

import (
	"context"
	"fmt"
	"net/http"
	"time"
)

func probeServer(url string) (time.Duration, error) {
	ctx, cancel := context.WithTimeout(context.Background(), 2*time.Second)
	defer cancel()

	start := time.Now()
	req, _ := http.NewRequestWithContext(ctx, "GET", url, nil)
	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		return 0, err
	}
	defer resp.Body.Close()
	return time.Since(start), nil
}

func main() {
	targetURL := "http://127.0.0.1:8080/health"
	fmt.Printf("[BENCH] Зондирование доступности сервиса %s под нагрузкой...\n", targetURL)

	// Тестовый замер доступности
	dur, err := probeServer(targetURL)
	if err != nil {
		fmt.Printf("[ALERT] Сервер недоступен: %v\n", err)
	} else {
		fmt.Printf("[OK] Сервер ответил за %v\n", dur)
	}
}
```

ℹ️ Зондирование доступности сервиса во время стресс-теста

## Под капотом

Если все доступные воркеры рантайма заняты ожиданием данных на медленных сокетах, входящие соединения скапливаются в очереди SYN Backlog ядра ОС, вызывая резкий рост времени установления соединения (connect latency).

## Подводные камни

Запуск бенчмарка против публичных серверов без письменного согласия владельцев классифицируется как противоправная DoS-атака.

## На собеседовании

В Wildberries регулярный DoS-фаззинг и стресс-тестирование Slowloris являются обязательной частью Chaos Engineering перед крупными распродажами.
