# Автоматизированный аудит устойчивости утилитой slowhttptest

## Условие

Используйте утилиту slowhttptest для проведения контролируемой стресс-атаки Slowloris на тестовый сервис Go и сформируйте HTML-отчет с графиком доступности сервиса.

### Исходная формулировка

**Slowloris testing tool**: Используйте `slowhttptest` для тестирования вашего server:
```bash
slowhttptest -c 1000 -i 10 -r 200 -t GET -u http://localhost:8080
```

## Теория

Утилита `slowhttptest` — отраслевой стандарт тестирования серверов на уязвимость к медленным DoS-атакам (Slowloris, Slow POST, Slow Read). Она умеет открывать тысячи соединений с заданным темпом передачи заголовков (`-i 10`) и зондировать сервис контрольными запросами для вычисления времени наступления отказа (Service Available percentage).

## Решение по шагам

Установите утилиту: `apt-get install slowhttptest`.
Запустите тест: `slowhttptest -c 1000 -H -i 10 -r 200 -t GET -u http://localhost:8080 -g -o slowloris_report`.
Проанализируйте сгенерированные графики доступности сервиса.
Убедитесь, что сервер с настроенным `ReadHeaderTimeout` удерживает 100% доступность.

## Код решения

**`run_slowhttptest.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail

TARGET_URL="http://127.0.0.1:8080"

echo "[STRESS-TEST] Запуск аудита устойчивости к Slowloris (slowhttptest)..."

# -c 1000: 1000 параллельных соединений
# -H: Slowloris режим (медленные заголовки)
# -i 10: интервал 10 секунд между досылкой байтов
# -r 200: скорость подключения 200 conn/sec
# -t GET: метод запроса
# -l 60: длительность теста 60 секунд
slowhttptest -c 1000 -H -i 10 -r 200 -t GET -u "${TARGET_URL}" -l 60 -g -o /tmp/report || true

echo "[OK] Стресс-тестирование завершено. Отчет сформирован."
```

ℹ️ Скрипт стресс-тестирования сервера утилитой slowhttptest

## Под капотом

slowhttptest отправляет неполные HTTP-заголовки и отслеживает код ответа зондирующего сокета. Если зондирующий сокет не может установить TCP-соединение за 5 секунд, статус сервиса помечается как NO (Unavailable).

## Подводные камни

Запуск теста с слишком высоким `-r` (rate) на слабой машине может исчерпать ресурсы локального сетевого стека клиента до того, как сервер почувствует нагрузку.

## На собеседовании

В отчетах penetration testing оценка устойчивости веб-приложений к Slowloris с помощью slowhttptest является обязательным разделом аудита соответствия OWASP.
