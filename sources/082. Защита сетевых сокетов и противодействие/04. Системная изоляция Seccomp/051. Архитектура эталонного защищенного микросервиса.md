# Архитектура эталонного защищенного микросервиса (Ultimate Secure Microservice)

## Условие

Спроектируйте и реализуйте архитектурный каркас production-grade Go микросервиса, объединяющий защиту цепочки поставок (Supply Chain), сетевой харднинг (Network Hardening), изоляцию ядра (Seccomp/Capabilities) и наблюдаемость (Slog/Prometheus).

### Исходная формулировка

**Финальный босс (Secure Go Microservice):**
    Создайте production-grade secure microservice:

    **Supply Chain Security:**
    * **govulncheck** в CI pipeline (fail на high/critical)
    * **go.sum verification** через `go mod verify`
    * **Cosign signing** для Docker images и binaries
    * **SBOM generation** через Syft в SPDX format
    * **SLSA Level 3 provenance** через slsa-github-generator
    * **Private module registry** через Athens с S3 backend
    * **Vendoring** для reproducible builds

    **Network Security:**
    * **HTTP Server hardening:**
      - ReadHeaderTimeout: 10s
      - ReadTimeout: 30s
      - WriteTimeout: 30s
      - IdleTimeout: 120s
      - MaxHeaderBytes: 1MB
    * **Request body limiting** через http.MaxBytesReader
    * **TCP keepalive** с 30s period
    * **Connection rate limiting** через custom listener
    * **Context timeouts** для всех outbound requests

    **Kernel-level Security:**
    * **seccomp profile** для ограничения syscall'ов:
      - Разрешены: read, write, open, close, mmap, etc.
      - Запрещены: ptrace, reboot, mount, etc.
    * **Linux capabilities:**
      - Drop ALL capabilities
      - Add только необходимые (NET_BIND_SERVICE для port 80)
    * **Read-only root filesystem** в Docker
    * **Non-root user** (UID 65534)

    **Container Security:**
    * **Distroless base image** (gcr.io/distroless/static)
    * **Multi-stage build** для minimal attack surface
    * **Resource limits** (CPU, memory) в Kubernetes
    * **Network policies** для isolation
    * **Pod security standards** (restricted profile)

    **Observability:**
    * **Structured logging** через slog с request_id, trace_id
    * **Metrics** через Prometheus (connections, latency, errors)
    * **Distributed tracing** через OpenTelemetry
    * **Security events logging** (failed auth, rate limit hits)

    **Testing:**
    * **govulncheck** в pre-commit hooks
    * **Slowloris testing** через slowhttptest
    * **Penetration testing** через OWASP ZAP
    * **Chaos testing** (network delays, packet loss)

    **Deployment:**
    * **GitOps** через ArgoCD
    * **Signed images** только в production
    * **SBOM attestation** verification перед deploy
    * **Canary deployment** с security monitoring
    * **Automatic rollback** при security anomalies

---

## Теория

Финальный рубеж разработки безопасных систем — сквозная интеграция всех уровней защиты (Defense-in-Depth):
1. Supply Chain: проверка go.sum, сканирование govulncheck в CI, генерация SBOM через Syft, подпись Cosign и SLSA L3 provenance.
2. Сетевая безопасность: ReadHeaderTimeout, WriteTimeout, IdleTimeout, MaxHeaderBytes, MaxBytesReader, TCP Keepalive, Rate Limiting.
3. Изоляция ОС: Seccomp-профиль, сброс всех Linux Capabilities (Drop ALL), non-root пользователь (UID 65534), read-only rootfs.
4. Наблюдаемость: структурированные логи slog с request_id/trace_id, Prometheus метрики соединений и задержек.

## Решение по шагам

Инициализируйте защищенный `http.Server` со всеми таймаутами.
Внедрите middleware ограничения размера тела и семафор параллелизма.
Настройте экспорт метрик и эндпоинт `/healthz`.
Сконфигурируйте Dockerfile на базе `FROM scratch` с непривилегированным пользователем.
Подготовьте манифест Seccomp и Kubernetes SecurityContext.

## Код решения

**`secure_service_capstone.go`**

```go
package main

import (
	"context"
	"fmt"
	"log/slog"
	"net/http"
	"os"
	"os/signal"
	"syscall"
	"time"
)

func main() {
	logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
	slog.SetDefault(logger)

	mux := http.NewServeMux()
	mux.HandleFunc("/healthz", func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte(`{"status":"OK","hardened":true}`))
	})

	srv := &http.Server{
		Addr:              ":8080",
		Handler:           mux,
		ReadHeaderTimeout: 5 * time.Second,
		ReadTimeout:       15 * time.Second,
		WriteTimeout:      15 * time.Second,
		IdleTimeout:       60 * time.Second,
		MaxHeaderBytes:    1 << 20,
	}

	go func() {
		slog.Info("[STARTUP] Защищенный микросервис запущен", "addr", srv.Addr)
		if err := srv.ListenAndServe(); err != nil && err != http.ErrServerClosed {
			slog.Error("Фатальная ошибка сервера", "error", err)
		}
	}()

	quit := make(chan os.Signal, 1)
	signal.Notify(quit, syscall.SIGINT, syscall.SIGTERM)
	<-quit
	slog.Info("[SHUTDOWN] Плавная остановка сервиса...")

	ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
	defer cancel()
	_ = srv.Shutdown(ctx)
	slog.Info("[SHUTDOWN] Сервер успешно остановлен.")
}
```

ℹ️ Эталонный архитектурный каркас защищенного микросервиса на Go

## Под капотом

Такая архитектура нейтрализует векторы атак на всех стадиях: компилятор отсекает уязвимости зависимостей, рантайм защищает память от DoS, ядро блокирует эксплойты прав, а мониторинг обеспечивает прозрачность.

## Подводные камни

Формальное внедрение одного уровня защиты (например, Seccomp) бесполезно, если в коде оставлен http.ListenAndServe без таймаутов.
