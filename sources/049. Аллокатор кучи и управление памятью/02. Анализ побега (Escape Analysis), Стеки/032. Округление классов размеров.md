# Округление классов размеров и трассировка GODEBUG=allocfreetrace

## Условие

**Классы размеров (Size Classes)**: Go не выделяет память байт в байт. Аллокатор разбивает кучу на `mspan` (страницы памяти) для объектов определенных классов (8 байт, 16 байт, 32 байта...). Выдели объект на 25 байт. Включи `GODEBUG=allocfreetrace=1`. Найди в логах, что для твоего объекта на самом деле был выделен слот из Size Class = 32 байта (потеря 7 байт памяти ради скорости аллокации).

## Теория

В традиционном представлении программистов память выделяется «байт в байт». Однако в Go куча дискретна:
- При запросе 25 байт рантайм сопоставляет размер с таблицей `size_to_class8`:
  Ближайший поддерживаемый класс размера, больший или равный 25 — это **Size Class 4 (32 байта)**.
- Рантайм выделяет 32-байтный слот.
- Реальный объект занимает первые 25 байт, а оставшиеся 7 байт остаются неиспользованным технологическим запасом.

Флаг `GODEBUG=allocfreetrace=1` логирует каждую операцию аллокации и освобождения в реальном времени с выводом размера слота и стектрейса вызова.

## Решение по шагам

1. Создайте структуру размером ровно 25 байт.
2. Выделите экземпляр этой структуры в куче.
3. Запустите программу с переменной окружения `GODEBUG=allocfreetrace=1`.
4. Найдите в выводе stderr строку аллокации слота 32 байта.

## Код решения

**`size_round.go`**

```go
package main

import (
	"fmt"
	"unsafe"
)

// Структура ровно 25 байт
type Struct25 struct {
	Data [25]byte
}

//go:noinline
func allocate25() *Struct25 {
	return &Struct25{Data: [25]byte{1, 2, 3}}
}

func main() {
	fmt.Printf("Размер структуры Struct25: %d байт\n", unsafe.Sizeof(Struct25{}))

	obj := allocate25()
	fmt.Printf("Объект создан по адресу: %p\n", obj)
	fmt.Println("Для проверки запустите с GODEBUG=allocfreetrace=1 и найдите аллокацию 32B.")
}
```

ℹ️ Выделение объекта 25 байт, округляемого аллокатором до класса 32 байта

**`Терминал`**

```bash
GODEBUG=allocfreetrace=1 go run size_round.go 2>&1 | grep -A 5 "allocate25"
```

## Под капотом

В `src/runtime/malloc.go`:
```go
var sizeclass uint8
if size <= smallSizeMax-8 {
    sizeclass = size_to_class8[divRoundUp(size, smallSizeDiv)]
}
```
Для размера 25: `divRoundUp(25, 8) = 4`.
В массиве `size_to_class8[4]` хранится индекс класса 4.
Класс 4 в таблице `class_to_size` соответствует размеру 32 байта.
Вычисление класса размера выполняется за **1 чтение из массива** без циклов и делений!

## Подводные камни

1. Флаг `allocfreetrace=1` собирает полный стектрейс на каждую операцию выделения памяти, замедляя выполнение в 100 раз. Не запускайте его на нагруженных программах.
2. Проектируя сетевые протоколы и DTO, старайтесь укладывать размеры структур в степени двойки или точные значения size classes Go (8, 16, 24, 32, 48, 64, 80, 96, 112, 128...).

## На собеседовании

**Вопрос с собеседования:** Как рантайм Go за \(O(1)\) находит класс размера по произвольному целому числу байт \(N \le 32768\)?
**Ответ:** Рантайм использует две быстрые таблицы прямого поиска:
1. Для объектов до 1024 байт: массив `size_to_class8[divRoundUp(N, 8)]` (шаг 8 байт).
2. Для объектов от 1024 до 32768 байт: массив `size_to_class128[divRoundUp(N-1024, 128)]` (шаг 128 байт).
Поиск класса сводится к битовому сдвигу и одному чтению из массива в памяти, занимая менее 1 наносекунды.
