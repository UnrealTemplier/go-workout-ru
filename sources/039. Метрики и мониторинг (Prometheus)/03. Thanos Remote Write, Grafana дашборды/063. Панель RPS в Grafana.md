# Панель RPS в Grafana: визуализация скорости запросов rate(http_requests_total[5m])

## Условие

Создайте Grafana-дашборд с панелью: `rate(http_requests_total[5m])` — количество запросов в секунду.

## Теория

Визуализация скорости входящих запросов (RPS):
- Запрос PromQL: `rate(http_requests_total[5m])`.
- В панели Timeseries в Grafana настраивают:
  - Единицы измерения (Unit): `Requests / sec (reqps)`.
  - Легенда: `{{method}} {{path}}` или `{{code}}`.
  - Заливка области под графиком (Fill Opacity: 15%) для наглядности тренда.
- Позволяет моментально отслеживать дневные пики активности пользователей и ночные спады.

## Решение по шагам

1. Создайте спецификацию панели RPS.
2. Задайте параметры единиц измерения `reqps`.
3. Сформируйте запрос с агрегацией по методам.
4. Проверьте валидность параметров панели.

## Код решения

**`rps_panel_config_test.go`**

```go
package main

import (
	"fmt"
	"testing"
)

type RPSPanelConfig struct {
	Title string
	Unit  string
	Expr  string
}

func TestRPSPanelConfig(t *testing.T) {
	cfg := RPSPanelConfig{
		Title: "Throughput (RPS)",
		Unit:  "reqps",
		Expr:  "sum(rate(http_requests_total[5m]))",
	}

	if cfg.Unit != "reqps" || cfg.Expr != "sum(rate(http_requests_total[5m]))" {
		t.Fatalf("Некорректная конфигурация RPS: %+v", cfg)
	}

	fmt.Println("Конфигурация панели RPS успешно верифицирована:")
	fmt.Printf("  • Заголовок панели: %s\n", cfg.Title)
	fmt.Printf("  • Единица (Unit):  %s (req/s)\n", cfg.Unit)
	fmt.Printf("  • PromQL:          %s\n", cfg.Expr)
}
```

## Под капотом

Функция `rate()` рассчитывает прирост счетчика в секунду: если за 5 минут пришло 300 запросов, `rate()` вернет \(300 / 300 = 1.0\) req/s.

## Подводные камни

Использовать функцию `increase()` вместо `rate()` на графике RPS: `increase()` вернет суммарное число запросов за 5 минут (300 запросов), а не скорость в секунду.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие функций rate() и irate() в PromQL?»
**Ответ:** `rate()` усредняет скорость по всему временному окну (например 5 минут), сглаживая шум. `irate()` (Instant Rate) вычисляет скорость строго по двум последним точкам внутри окна, показывая мгновенные микро-всплески. Для алертов и графиков трендов всегда используют `rate()`, а `irate()` применяют только для поиска кратковременных скачков высокой частоты.
