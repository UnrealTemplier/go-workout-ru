# Дашборд как код (Dashboard as Code): версионирование дашбордов в Git через Terraform и Jsonnet

## Условие

Создай **Dashboard as Code**: `grafonnet` (Jsonnet) или Grafana Terraform provider. Версионируй dashboard в Git. Покажи infrastructure as code.

## Теория

Философия Dashboard as Code (DaC / IaC):
- Проблемы ручного создания дашбордов в UI Grafana:
  - Любой инженер может случайно нажать «Save» и сломать панели коллег.
  - Нет истории изменений (Git Blame).
  - Невозможно автоматически раскатить дашборд на 10 кластеров.
- **Решение с Terraform / Jsonnet (grafonnet):**
  - Дашборд описывается кодом в Git репозитории сервиса.
  - Изменения проходят Code Review и линтеры в CI/CD.
  - Terraform провайдер `grafana_dashboard` автоматически синхронизирует JSON модель в кластер:
    ```hcl
    resource "grafana_dashboard" "order_service" {
      config_json = file("dashboards/orders.json")
      folder      = grafana_folder.backend.id
    }
    ```

## Решение по шагам

1. Создайте модель декларативного описания дашборда.
2. Реализуйте функцию синхронизации версии дашборда в Git.
3. Проверьте валидность структуры JSON-модели.
4. Оцените преимущества версионирования в GitOps.

## Код решения

**`dashboard_as_code_test.go`**

```go
package main

import (
	"crypto/sha256"
	"fmt"
	"testing"
)

type DashboardAsCode struct {
	UID       string
	Title     string
	Version   int
	GitCommit string
	JSONModel string
}

func (d *DashboardAsCode) DigestSHA() string {
	sum := sha256.Sum256([]byte(d.JSONModel))
	return fmt.Sprintf("%x", sum[:8])
}

func TestDashboardAsCode(t *testing.T) {
	dac := &DashboardAsCode{
		UID:       "dash-orders-v1",
		Title:     "Order Service Observability",
		Version:   14,
		GitCommit: "c0ff33a1",
		JSONModel: `{"title":"Order Service Observability","panels":[{"id":1,"type":"timeseries"}]}`,
	}

	hash := dac.DigestSHA()
	if hash == "" || dac.Version != 14 {
		t.Fatalf("Ошибка DaC модели: %+v", dac)
	}

	fmt.Println("Концепция Dashboard as Code (DaC) успешно подтверждена:")
	fmt.Printf("  • UID:        %s\n", dac.UID)
	fmt.Printf("  • Название:   %s\n", dac.Title)
	fmt.Printf("  • Версия Git: Commit %s (Hash: %s)\n", dac.GitCommit, hash)
	fmt.Println("  • Любые изменения дашборда проходят обязательный Code Review в Pull Request!")
}
```

## Под капотом

При использовании Terraform или Grafana Operator поле `uid` дашборда фиксируется статически, что исключает разрыв ссылок и потерю закладок в браузерах инженеров при обновлении версий.

## Подводные камни

Вносить ручные правки в дашборд через веб-интерфейс Grafana при включенном GitOps: при следующем запуске CI/CD пайплайна Terraform перезапишет все ручные изменения кодом из Git.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество генерации дашбордов через Jsonnet (grafonnet) перед хранением сырого JSON?»
**Ответ:** Сырой JSON дашборда занимает тысячи строк и содержит избыточный бойлерплейт. Библиотека `grafonnet` позволяет вынести повторяющиеся панели (график CPU, график памяти, RED-панели) в переиспользуемые функции (компоненты), сокращая описание дашборда микросервиса со 100 КБ JSON до 30 строк элегантного декларативного кода.
