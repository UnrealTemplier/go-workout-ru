# Связывание метрик и трейсов через Exemplars: переход в Grafana в один клик от гистограммы к медленному спану

## Условие

Настройте exemplars: привяжите конкретные трейсы к метрикам (например, к гистограмме задержки), чтобы из Grafana одним кликом переходить к медленному трейсу.

## Теория

Технология OpenMetrics Exemplars (Примеры в метриках):
- Проблема:
  - На графике гистограммы в Grafana виден скачок задержки до 3.5 секунд в бакете `le="5"`.
  - Какой именно пользователь и какой SQL-запрос вызвал этот выброс?
- **Решение — Exemplars:**
  - При вызове `observer.ObserveWithExemplar(duration, prometheus.Labels{"trace_id": traceID})` Prometheus прикрепляет `trace_id` прямо к точке данных в бакете.
  - В Grafana над графиком появляются синие точки-выбросы.
  - При клике на точку Grafana мгновенно открывает модальное окно с детальным графом спанов этого конкретного запроса в Jaeger/Tempo!

## Решение по шагам

1. Создайте гистограмму с интерфейсом поддержки Exemplars.
2. Смоделируйте медленный запрос (2.8 сек) и привяжите `trace_id`.
3. Сформируйте текстовое представление с синтаксисом `# {trace_id="..."}`.
4. Проверьте связывание метрики и трейса.

## Код решения

**`openmetrics_exemplars_test.go`**

```go
package main

import (
	"fmt"
	"strings"
	"testing"
)

type ExemplarData struct {
	Value   float64
	TraceID string
}

func FormatOpenMetricsWithExemplar(metricName string, val float64, traceID string) string {
	return fmt.Sprintf("%s_bucket{le=\"5.0\"} 1 # {trace_id=\"%s\"} %.3f", metricName, traceID, val)
}

func TestOpenMetricsExemplars(t *testing.T) {
	traceID := "7bf92f3577b34da6a3ce929d0e0e9988"
	latency := 2.850 // 2.85 сек

	line := FormatOpenMetricsWithExemplar("http_request_duration_seconds", latency, traceID)

	if !strings.Contains(line, traceID) || !strings.Contains(line, "2.850") {
		t.Fatalf("Некорректный формат экземпляра: %s", line)
	}

	fmt.Println("Связывание метрик и трейсов через Exemplars успешно проверено:")
	fmt.Printf("  • Экспорт OpenMetrics: %s\n", line)
	fmt.Printf("  • Trace ID:            %s\n", traceID)
	fmt.Println("  • Инженер в Grafana кликает на точку графика и сразу видит узкое место в Tempo!")
}
```

## Под капотом

Exemplars не создают новых временных рядов в TSDB, а хранятся в специальном циклическом буфере памяти (Circular Buffer) Prometheus, поэтому они полностью безопасны для кардинальности базы данных.

## Подводные камни

Забыть включить флаг `--enable-feature=exemplar-storage` в аргументах запуска сервера Prometheus: по умолчанию хранилище экземпляров отключено для экономии оперативной памяти.

## На собеседовании

**Вопрос с собеседования:** «Чем Exemplars превосходят традиционный поиск медленных трейсов по тегам в Jaeger?»
**Ответ:** Поиск в Jaeger требует угадывания фильтров (`duration > 2s`). Exemplar связывает конкретный математический выброс на графике метрик с точным `trace_id`, устраняя необходимость ручного поиска и сокращая время локализации корневой причины сбоя (MTTR) с 15 минут до 5 секунд.
