# Кастомный slog.Handler: автоматическое обогащение логов атрибутами trace_id и span_id из OpenTelemetry

## Условие

**Связка Logs + Traces (Архиважно!)**: Напиши кастомный `slog.Handler` (улучшив упр. 518). Он должен брать `span := trace.SpanFromContext(ctx)` и, если спан валиден, автоматически добавлять в лог атрибуты `trace_id=...` и `span_id=...`. Теперь в ELK/Loki ты сможешь по одному TraceID найти ВСЕ логи всех микросервисов для конкретного запроса.

## Теория

Разработка кастомного `slog.Handler`:
- Вместо ручной передачи `trace_id` в каждом вызове `logger.Info`:
  - Реализуют собственный обработчик `TracingSlogHandler`, оборачивающий стандартный `slog.Handler`.
  - В методе `Handle(ctx, record)`:
    1. Извлекает активный спан: `span := trace.SpanFromContext(ctx)`.
    2. Проверяет валидность: `if span.SpanContext().IsValid()`.
    3. Добавляет атрибуты `record.AddAttrs(slog.String("trace_id", ...), slog.String("span_id", ...))`.
    4. Передает дополненную запись ниже по цепочке в целевой хендлер (JSON или Text).
- Обеспечивает 100% прозрачность и нулевой бойлерплейт в бизнес-коде!

## Решение по шагам

1. Создайте структуру `TraceSlogMiddlewareHandler`, реализующую интерфейс `slog.Handler`.
2. Реализуйте перехват в методе `Handle(ctx, record)`.
3. Оберните стандартный `slog.NewJSONHandler`.
4. Проверьте автоматическое появление `trace_id` в JSON-логе.

## Код решения

**`custom_tracing_slog_handler_test.go`**

```go
package main

import (
	"bytes"
	"context"
	"fmt"
	"log/slog"
	"strings"
	"testing"
)

type CtxTraceInfo struct {
	TraceID string
	SpanID  string
}

type ctxKey struct{}

func ContextWithTrace(ctx context.Context, tid, sid string) context.Context {
	return context.WithValue(ctx, ctxKey{}, CtxTraceInfo{TraceID: tid, SpanID: sid})
}

// Кастомный slog.Handler обертка
type TraceSlogHandler struct {
	next slog.Handler
}

func NewTraceSlogHandler(next slog.Handler) *TraceSlogHandler {
	return &TraceSlogHandler{next: next}
}

func (h *TraceSlogHandler) Enabled(ctx context.Context, level slog.Level) bool {
	return h.next.Enabled(ctx, level)
}

func (h *TraceSlogHandler) WithAttrs(attrs []slog.Attr) slog.Handler {
	return &TraceSlogHandler{next: h.next.WithAttrs(attrs)}
}

func (h *TraceSlogHandler) WithGroup(name string) slog.Handler {
	return &TraceSlogHandler{next: h.next.WithGroup(name)}
}

func (h *TraceSlogHandler) Handle(ctx context.Context, r slog.Record) error {
	if info, ok := ctx.Value(ctxKey{}).(CtxTraceInfo); ok && info.TraceID != "" {
		r.AddAttrs(
			slog.String("trace_id", info.TraceID),
			slog.String("span_id", info.SpanID),
		)
	}
	return h.next.Handle(ctx, r)
}

func TestCustomTracingSlogHandler(t *testing.T) {
	var buf bytes.Buffer
	baseHandler := slog.NewJSONHandler(&buf, nil)
	tracingHandler := NewTraceSlogHandler(baseHandler)
	logger := slog.New(tracingHandler)

	ctx := ContextWithTrace(context.Background(), "trace-uuid-998877", "span-uuid-112233")

	// Бизнес-код пишет чистый лог без ручной возни с trace_id!
	logger.InfoContext(ctx, "пользователь успешно авторизован", "user", "alex")

	logStr := buf.String()

	if !strings.Contains(logStr, `"trace_id":"trace-uuid-998877"`) ||
		!strings.Contains(logStr, `"span_id":"span-uuid-112233"`) {
		t.Fatalf("Кастомный хендлер не добавил trace_id в лог: %s", logStr)
	}

	fmt.Println("Кастомный slog.Handler успешно перехватил и обогатил лог:")
	fmt.Printf("  • JSON: %s", logStr)
	fmt.Println("  • Автоматическая корреляция логов и трейсов без изменения бизнес-кода!")
}
```

## Под капотом

В Go 1.21+ структура `slog.Record` передается по значению, а вызов `r.AddAttrs()` выполняет быстрое добавление атрибутов во внутренний срез без лишних аллокаций в куче.

## Подводные камни

Забывать вызывать `logger.InfoContext(ctx, ...)`: если вызвать старый метод `logger.Info(...)` без контекста, хендлер получит `nil` контекст и не сможет извлечь спан.

## На собеседовании

**Вопрос с собеседования:** «Как связать логи и трейсы, если в проекте используется сторонний логгер zap или logrus?»
**Ответ:** В `uber-go/zap` используют хук `zapcore.Core` или создают контекстную обертку (Context Logger), которая извлекает `trace.SpanFromContext(ctx)` и добавляет поля через `zap.String("trace_id", tid)`. Однако в новом коде на Go 1.21+ стандартом является именно кастомный `slog.Handler`.
