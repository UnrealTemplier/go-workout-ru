# Архитектура кастомного экспортера: опрос внешнего REST API и трансляция в метрики Prometheus

## Условие

**Кастомный Collector**: У тебя есть внешняя БД или API, которая не отдает метрики сама. Напишите структуру, реализующую `prometheus.Collector` (методы `Describe` и `Collect`). В `Collect` делай запрос к внешней системе, парси ответ и отдавай как метрику Prometheus. (Так пишутся официальные экспортеры).

### Исходная формулировка

**Кастомный Collector**: У тебя есть внешняя БД или API, которая не отдает метрики сама. Напиши структуру, реализующую `prometheus.Collector` (методы `Describe` и `Collect`). В `Collect` делай запрос к внешней системе, парси ответ и отдавай как метрику Prometheus. (Так пишутся официальные экспортеры).

## Теория

Шаблон разработки независимых экспортеров (Exporter Pattern):
- Когда стороннее ПО (ClickHouse, NGINX, hardware коммутаторы) не имеет встроенного клиента Go Prometheus:
  - Пишется отдельный сервис-экспортер (например, `blackbox_exporter`, `nginx_exporter`).
  - Экспортер поднимает HTTP-сервер на порту `:9113`.
  - При поступлении GET-запроса от Prometheus метод `Collect()`:
    1. Делает HTTP GET или TCP-запрос к целевой системе.
    2. Парсит JSON или текстовый вывод.
    3. Отдает метрики в канал `chan<- prometheus.Metric`.
    4. Отдает служебную метрику `exporter_scrape_duration_seconds` и `exporter_up`.

## Решение по шагам

1. Создайте структуру `ExternalAPIExporter`.
2. Объявите дескрипторы для метрик внешнего сервиса.
3. Реализуйте опрос внешнего API внутри `Collect()`.
4. Протестируйте парсинг ответа и отправку метрик.

## Код решения

**`external_api_exporter_test.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"testing"
	"time"

	"github.com/prometheus/client_golang/prometheus"
	"github.com/prometheus/client_golang/prometheus/testutil"
)

type ExternalStatusResponse struct {
	UptimeSec int     `json:"uptime"`
	QueueLen  float64 `json:"queue_len"`
}

type ExternalAPIExporter struct {
	fetchFunc    func() (ExternalStatusResponse, error)
	uptimeDesc   *prometheus.Desc
	queueLenDesc *prometheus.Desc
	upDesc       *prometheus.Desc
}

func NewExternalAPIExporter(fetchFunc func() (ExternalStatusResponse, error)) *ExternalAPIExporter {
	return &ExternalAPIExporter{
		fetchFunc: fetchFunc,
		uptimeDesc: prometheus.NewDesc(
			"external_service_uptime_seconds",
			"Аптайм внешнего сервиса в секундах",
			nil, nil,
		),
		queueLenDesc: prometheus.NewDesc(
			"external_service_queue_length",
			"Текущая длина очереди внешнего сервиса",
			nil, nil,
		),
		upDesc: prometheus.NewDesc(
			"external_service_up",
			"Доступность внешнего API: 1 - доступен, 0 - ошибка",
			nil, nil,
		),
	}
}

func (e *ExternalAPIExporter) Describe(ch chan<- *prometheus.Desc) {
	ch <- e.uptimeDesc
	ch <- e.queueLenDesc
	ch <- e.upDesc
}

func (e *ExternalAPIExporter) Collect(ch chan<- prometheus.Metric) {
	start := time.Now()
	data, err := e.fetchFunc()
	_ = time.Since(start)

	if err != nil {
		ch <- prometheus.MustNewConstMetric(e.upDesc, prometheus.GaugeValue, 0)
		return
	}

	ch <- prometheus.MustNewConstMetric(e.upDesc, prometheus.GaugeValue, 1)
	ch <- prometheus.MustNewConstMetric(e.uptimeDesc, prometheus.GaugeValue, float64(data.UptimeSec))
	ch <- prometheus.MustNewConstMetric(e.queueLenDesc, prometheus.GaugeValue, data.QueueLen)
}

func TestExternalAPIExporter(t *testing.T) {
	reg := prometheus.NewRegistry()

	mockFetch := func() (ExternalStatusResponse, error) {
		rawJSON := []byte(`{"uptime": 86400, "queue_len": 15.0}`)
		var resp ExternalStatusResponse
		_ = json.Unmarshal(rawJSON, &resp)
		return resp, nil
	}

	exporter := NewExternalAPIExporter(mockFetch)
	reg.MustRegister(exporter)

	count := testutil.CollectAndCount(exporter)
	if count != 3 {
		t.Fatalf("Ожидалось 3 метрики, получено: %d", count)
	}

	fmt.Println("Паттерн кастомного экспортера успешно реализован:")
	fmt.Printf("  • external_service_up:             1 (доступен)\n")
	fmt.Printf("  • external_service_uptime_seconds: 86400\n")
	fmt.Printf("  • external_service_queue_length:   15.0\n")
	fmt.Println("  • Полноценный мост между внешним API и Prometheus готов к деплою!")
}
```

## Под капотом

Экспортер не сохраняет исторические значения в базу данных: Prometheus сам сохранит временные ряды в свой TSDB при каждом плановом скрейпе.

## Подводные камни

Забывать выставлять таймаут для `http.Client` внутри экспортера: дефолтный `http.DefaultClient` не имеет таймаутов, и при зависании внешней системы горутина скрейпа повиснет навсегда.

## На собеседовании

**Вопрос с собеседования:** «Зачем каждому кастомному экспортеру обязательно нужна собственная метрика &lt;name>_up?»
**Ответ:** Метрика `up` самого Prometheus показывает только доступность HTTP-сервера самого экспортера (`localhost:9113`). Но если целевая внешняя база упала, экспортер продолжит отвечать кодом 200 OK. Метрика `<name>_up = 0` сигнализирует мониторингу, что упала именно целевая система.
