# Базовый счетчик requests_total: декларация CounterOpts и инкремент при каждом входящем HTTP-запросе

## Условие

Подключите `github.com/prometheus/client_golang/prometheus` и создайте простейший **Counter**: `requests_total`. Инкрементируйте его при каждом HTTP-запросе.

## Теория

Простейший глобальный счетчик без меток:
- Когда метки не требуются (например, глобальный счетчик всех событий в системе), используют скалярный `prometheus.Counter` вместо вектора `CounterVec`.
- **Преимущество скалярного Counter:**
  - Нулевой оверхед на поиск по хеш-мапе меток.
  - Прямой вызов `counter.Inc()`.
  - Максимальная скорость выполнения (наносекунды).

## Решение по шагам

1. Создайте `prometheus.Counter` через `prometheus.NewCounter`.
2. Зарегистрируйте его в тестовом реестре.
3. Выполните серию из 10 HTTP-запросов.
4. Проверьте итоговое значение счетчика.

## Код решения

**`simple_requests_counter_test.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"testing"

	"github.com/prometheus/client_golang/prometheus"
	"github.com/prometheus/client_golang/prometheus/testutil"
)

func TestSimpleRequestsCounter(t *testing.T) {
	reg := prometheus.NewRegistry()

	requestsTotal := prometheus.NewCounter(prometheus.CounterOpts{
		Name: "requests_total",
		Help: "Общее число всех входящих запросов к сервису",
	})
	reg.MustRegister(requestsTotal)

	handler := http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		requestsTotal.Inc()
		w.WriteHeader(http.StatusOK)
		fmt.Fprint(w, "PONG")
	})

	for i := 0; i < 10; i++ {
		req := httptest.NewRequest("GET", "/ping", nil)
		rec := httptest.NewRecorder()
		handler.ServeHTTP(rec, req)
	}

	val := testutil.ToFloat64(requestsTotal)
	if val != 10.0 {
		t.Fatalf("Ожидалось 10.0, получено: %f", val)
	}

	fmt.Println("Простой Counter requests_total успешно верифицирован:")
	fmt.Printf("  • Имя метрики: requests_total\n")
	fmt.Printf("  • Значение:    %.0f (10 запросов обработано)\n", val)
}
```

## Под капотом

Скалярный `Counter` реализует интерфейс `prometheus.Metric` и экспортируется как одна строка в текстовом формате: `requests_total 10`.

## Подводные камни

Использовать имя метрики без суффикса `_total`: соглашение об именовании в Prometheus требует, чтобы все счетчики оканчивались суффиксом `_total` (например, `orders_processed_total`).

## На собеседовании

**Вопрос с собеседования:** «Каковы основные соглашения об именовании метрик в Prometheus (Naming Conventions)?»
**Ответ:** Имя метрики должно содержать пространство имен приложения, подсистему и суффикс единицы измерения (`<namespace>_<subsystem>_<name>_<units>_total`). Пример: `http_server_request_duration_seconds`, `database_pool_connections_active`.
