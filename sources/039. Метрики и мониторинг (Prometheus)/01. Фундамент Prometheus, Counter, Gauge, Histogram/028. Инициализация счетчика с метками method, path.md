# Инициализация счетчика с метками method, path, status через MustRegister и WithLabelValues

## Условие

Установи Prometheus клиент: `github.com/prometheus/client_golang/prometheus`. Создай **Counter**: `requestsTotal := prometheus.NewCounterVec(prometheus.CounterOpts{Name: "http_requests_total", Help: "Total HTTP requests"}, []string{"method", "path", "status"})`. Зарегистрируй `prometheus.MustRegister(requestsTotal)`. Инкрементируй: `requestsTotal.WithLabelValues("GET", "/users", "200").Inc()`.

## Теория

Канонический синтаксис инициализации CounterVec:
- Стандартный трехкомпонентный кортеж меток:
  - `method`: HTTP глагол (GET, POST, PUT, DELETE).
  - `path`: нормализованный путь API (`/users`, `/catalog/{id}`).
  - `status`: код ответа (`200`, `201`, `404`, `500`).
- Вызов `WithLabelValues(...)` выполняет поиск или создание экземпляра Counter для данной комбинации меток и инкрементирует его.

## Решение по шагам

1. Создайте `CounterVec` с тремя метками.
2. Зарегистрируйте его в тестовом реестре.
3. Вызовите `WithLabelValues("GET", "/users", "200").Inc()`.
4. Проверьте правильность итогового значения.

## Код решения

**`canonical_counter_vec_test.go`**

```go
package main

import (
	"fmt"
	"testing"

	"github.com/prometheus/client_golang/prometheus"
	"github.com/prometheus/client_golang/prometheus/testutil"
)

func TestCanonicalCounterVec(t *testing.T) {
	reg := prometheus.NewRegistry()

	requestsTotal := prometheus.NewCounterVec(
		prometheus.CounterOpts{
			Name: "http_requests_total",
			Help: "Total HTTP requests",
		},
		[]string{"method", "path", "status"},
	)
	reg.MustRegister(requestsTotal)

	// Инкремент канонического запроса
	requestsTotal.WithLabelValues("GET", "/users", "200").Inc()

	val := testutil.ToFloat64(requestsTotal.WithLabelValues("GET", "/users", "200"))
	if val != 1.0 {
		t.Fatalf("Ожидалось 1.0, получено: %f", val)
	}

	fmt.Println("Канонический CounterVec успешно верифицирован:")
	fmt.Printf("  • requestsTotal.WithLabelValues(\"GET\", \"/users\", \"200\").Inc() -> %.0f\n", val)
}
```

## Под капотом

Внутри `CounterVec` преобразует срез значений меток в единый 64-битный хэш FNV-1a для быстрого поиска в мапе без блокировки глобального мьютекса при повторных вызовах.

## Подводные камни

Передавать аргументы в `WithLabelValues` в неправильном порядке (например, перепутать `path` и `status`): компилятор Go не сможет поймать ошибку, так как все аргументы имеют тип `string`, и метки запишутся с перепутанными значениями.

## На собеседовании

**Вопрос с собеседования:** «Что безопаснее: WithLabelValues() или With(prometheus.Labels{})?»
**Ответ:** Метод `With(prometheus.Labels{"method": "GET", "status": "200"})` безопаснее, так как имена меток явно указаны в ключе мапы, что исключает ошибки перестановки аргументов местами. Однако `WithLabelValues()` работает на 15–20% быстрее, так как не требует аллокации мапы в куче.
