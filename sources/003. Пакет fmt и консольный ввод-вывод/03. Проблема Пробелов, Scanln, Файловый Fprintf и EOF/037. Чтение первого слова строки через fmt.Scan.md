# Чтение первого слова строки через fmt.Scan

## Условие

Считай строку, введенную пользователем, до первого пробела с помощью `fmt.Scan`.

## Теория

Закрепляем поведение `fmt.Scan` со строковыми аргументами:
- Идеально подходит для чтения команд из одного слова (например `start`, `stop`, `restart`);
- Весь хвост строки остается в потоке.

## Решение по шагам

1. Запрашиваем команду у пользователя.
2. Считываем первое слово в переменную `cmd`.
3. Выводим команду.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var command string
	fmt.Print("Введите команду: ")

	_, err := fmt.Scan(&command)
	if err != nil {
		fmt.Printf("Ошибка чтения: %v\n", err)
		return
	}

	fmt.Printf("Первое слово команды: [%s]\n", command)
}
```

ℹ️ Чтение первого слова

**`Терминал`**

```bash
go run main.go
# Введите команду: deploy --env=production --replicas=3
# Первое слово команды: [deploy]
```

ℹ️ Вывод

## Под капотом

Сканер считывает руны до встречи первого пробельного символа Unicode — не только ASCII 32 (`' '`), но и `\t`, `\r`, `\n`, неразрывного пробела U+00A0 и других: в `fmt/scan.go` для этого есть своя таблица `isSpace`, совпадающая с `unicode.IsSpace`. Для `Scan` перевод строки — такой же разделитель, как пробел.

## Подводные камни

- Если остаток строки не нужен, буфер `Stdin` необходимо очистить, иначе последующие операции ввода прочитают старые аргументы.

## На собеседовании

**Вопрос с собеседования:** «Как быстро очистить оставшиеся непрочитанные данные в буфере `os.Stdin`?»
**Ответ:** Прочитать остаток строки до символа `\n` из того же `bufio.Reader`, через который идёт весь ввод: `reader.ReadString('\n')`. Одноразовый `bufio.NewReader(os.Stdin).ReadString('\n')` для этого не годится: он забирает в свой буфер до 4 КБ, то есть может прихватить и следующие строки (при вставке нескольких строк или вводе из pipe), и они пропадут вместе с ридером.
