# Чтение строки ввода с переводом строки через fmt.Scanln

## Условие

**Ввод нескольких значений**: Запросите у пользователя имя и возраст в одну строку, разделенные пробелом, используя `fmt.Scanln`. Сохраните их в соответствующие переменные.

## Теория

Функция **`fmt.Scanln`**:
1. Считывает данные аналогично `fmt.Scan`;
2. Но **строго останавливается при встрече символа перевода строки `\n`**;
3. Требует, чтобы все запрошенные аргументы были переданы на одной текущей строке.

## Решение по шагам

1. Объявляем `var name string` и `var age int`.
2. Вызываем `fmt.Scanln(&name, &age)`.
3. Если пользователь нажал Enter раньше, чем ввел возраст, `Scanln` вернет ошибку `unexpected newline`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var (
		name string
		age  int
	)

	fmt.Print("Введите имя и возраст в одну строку (через пробел): ")
	n, err := fmt.Scanln(&name, &age)
	if err != nil {
		fmt.Printf("❌ Ошибка ввода: %v (успешно считано аргументов: %d)\n", err, n)
		return
	}

	fmt.Printf("✔ Пользователь %s, возраст %d успешно сохранен.\n", name, age)
}
```

ℹ️ Однострочный ввод через Scanln

**`Терминал`**

```bash
go run main.go
# Введите имя и возраст в одну строку (через пробел): Михаил 32
# ✔ Пользователь Михаил, возраст 32 успешно сохранен.
```

ℹ️ Ввод данных

## Под капотом

`fmt.Scanln` в цикле сканирования проверяет флаг `nlIsEnd = true`. При встрече байта `\n` функция немедленно прерывает считывание оставшихся переменных.

## Подводные камни

- В отличие от `fmt.Scan` (который готов ждать ввода на следующих строках), `fmt.Scanln` сразу завершается ошибкой, если на текущей строке не хватило аргументов.

## На собеседовании

**Вопрос с собеседования:** «В чем ключевое отличие `fmt.Scan` от `fmt.Scanln`?»
**Ответ:** `fmt.Scan` считает `\n` обычным пробелом и переходит на следующую строку в поисках аргументов, тогда как `fmt.Scanln` трактует `\n` как обязательный конец списка аргументов текущего вызова.
