# Чтение ФИО с пробелами через bufio.NewReader и strings.TrimSpace

## Условие

**Чтение строки с пробелами**: Попробуйте ввести ФИО с пробелами через `fmt.Scan`. Обратите внимание, почему считывается только первое слово. Исправьте это, применив `bufio.NewReader(os.Stdin)` и метод `ReadString('\n')`.

## Теория

Полное решение проблемы ввода строк с пробелами:
1. Оборачиваем `os.Stdin` в `bufio.NewReader(os.Stdin)`;
2. Считываем до нажатия клавиши Enter: `reader.ReadString('\n')`;
3. Удаляем хвостовой перенос строки: `strings.TrimSpace(line)`.

## Решение по шагам

1. Инициализируем буферизованный ридер.
2. Считываем полное имя (3 слова с пробелами).
3. Проверяем корректность считывания всех слов.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"strings"
)

func main() {
	reader := bufio.NewReader(os.Stdin)
	fmt.Print("Введите полное ФИО (например, Иванов Иван Иванович): ")

	rawFIO, err := reader.ReadString('\n')
	if err != nil {
		fmt.Printf("Ошибка чтения: %v\n", err)
		return
	}

	cleanFIO := strings.TrimSpace(rawFIO)
	words := strings.Fields(cleanFIO)

	fmt.Printf("✔ Успешно считано ФИО: [%s]\n", cleanFIO)
	fmt.Printf("  Количество слов: %d\n", len(words))
}
```

ℹ️ Правильное чтение ФИО

**`Терминал`**

```bash
go run main.go
# Введите полное ФИО (например, Иванов Иван Иванович): Смирнов Алексей Петрович
# ✔ Успешно считано ФИО: [Смирнов Алексей Петрович]
#   Количество слов: 3
```

ℹ️ Результат

## Под капотом

`strings.Fields` разбивает строку по любым пробельным Unicode-символам, игнорируя повторяющиеся пробелы.

## Подводные камни

- Создание нового `bufio.NewReader(os.Stdin)` на каждый ввод внутри цикла: ридер буферизует 4 КБ данных. Если создать новый ридер, данные из буфера старого ридера будут потеряны. Ридер создается **один раз до цикла**.

## На собеседовании

**Вопрос с собеседования:** «Почему нельзя пересоздавать `bufio.NewReader(os.Stdin)` внутри цикла чтения?»
**Ответ:** При первом чтении `bufio.Reader` забирает из `Stdin` до 4096 байт в свой внутренний буфер. Если на следующей итерации создать новый объект `bufio.NewReader`, уже считанные в старый буфер байты окажутся недоступны новому ридеру и будут утеряны.
