# Форматирование структуры Person: сравнительный анализ

## Условие

Создай структуру `Person` с полями `Name`, `Age`, `City`. Выведи её разными способами: `%v`, `%+v`, `%#v`. Объясни разницу.

## Теория

Разница модификаторов на реальной доменной модели:
- `%v` — компактные сырые данные;
- `%+v` — имена полей для логов сервиса;
- `%#v` — полная спецификация Go для воспроизведения в тестах.

## Решение по шагам

1. Объявляем структуру `Person`.
2. Инициализируем объект `p := Person{Name: "Елена", Age: 26, City: "Казань"}`.
3. Выводим с детальным пояснением каждого формата.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Person struct {
	Name string
	Age  int
	City string
}

func main() {
	p := Person{Name: "Елена", Age: 26, City: "Казань"}

	fmt.Printf("1. Компактный вывод (%%v):\n")
	fmt.Printf("   %v\n\n", p)

	fmt.Printf("2. Структурированный лог-вывод (%%+v):\n")
	fmt.Printf("   %+v\n\n", p)

	fmt.Printf("3. Точный Go-литерал для юнит-тестов (%%#v):\n")
	fmt.Printf("   %#v\n", p)
}
```

ℹ️ Форматирование структуры Person

**`Терминал`**

```bash
go run main.go
# 1. Компактный вывод (%v):
#    {Елена 26 Казань}
# 
# 2. Структурированный лог-вывод (%+v):
#    {Name:Елена Age:26 City:Казань}
# 
# 3. Точный Go-литерал для юнит-тестов (%#v):
#    main.Person{Name:"Елена", Age:26, City:"Казань"}
```

ℹ️ Результаты

## Под капотом

При `%#v` название пакета `main` перед именем структуры `Person` подставляет не компилятор, а рантайм: `fmt` получает его через рефлексию (`reflect.Type.String()` возвращает `main.Person`).

## Подводные камни

- Если передать указатель `&p`, `%#v` выведет `&main.Person{...}` со знаком амперсанда.

## На собеседовании

**Вопрос с собеседования:** «Как распечатать структуру в формате красивого отформатированного JSON (Indented JSON)?»
**Ответ:** Через `json.MarshalIndent(p, "", "  ")`.
