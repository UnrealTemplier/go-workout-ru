# Построчный буферизованный сканер bufio.Scanner

## Условие

**Буферизованный сканер**: Напиши бесконечный цикл, использующий `bufio.Scanner` для чтения строк из консоли. Цикл должен завершаться при вводе слова "exit".

## Теория

Пакет `bufio.Scanner` — стандарт индустрии для потокового чтения строк в Go:
1. Вызов `scanner.Scan()` возвращает `true`, пока в потоке есть данные;
2. `scanner.Text()` возвращает строку без завершающего `\n`;
3. `scanner.Bytes()` возвращает срез байт с нулевым выделением памяти;
4. Ошибки потока проверяются через `scanner.Err()`.

## Решение по шагам

1. Создаем `scanner := bufio.NewScanner(os.Stdin)`.
2. В цикле `for scanner.Scan()` считываем текст.
3. При вводе `"exit"` завершаем цикл.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"strings"
	"unicode/utf8"
)

func main() {
	scanner := bufio.NewScanner(os.Stdin)
	fmt.Println("Введите строки (для выхода введите 'exit'):")

	lineNum := 1
	for {
		fmt.Printf("[%02d] > ", lineNum)
		if !scanner.Scan() {
			break // Достигнут EOF или ошибка потока
		}

		line := scanner.Text()
		if strings.TrimSpace(line) == "exit" {
			fmt.Println("Работа сканера завершена.")
			break
		}

		fmt.Printf("     Длина строки: %d байт, %d рун\n", len(line), utf8.RuneCountInString(line))
		lineNum++
	}

	if err := scanner.Err(); err != nil {
		fmt.Printf("Критическая ошибка чтения: %v\n", err)
	}
}
```

**`Терминал`**


ℹ️ Работа сканера

## Под капотом

`bufio.Scanner` держит один обычный буфер-срез (не кольцевой; начальный размер 4 КБ), читает в него из `io.Reader` и вызывает `split`-функцию, которая сканирует байты в поиске символов перевода строк. Когда место кончается, сканер сдвигает непрочитанный остаток в начало буфера (`copy`) или удваивает буфер — но не больше `bufio.MaxScanTokenSize` (64 КБ, лимит меняется через `scanner.Buffer`).

## Подводные камни

- Вызов `scanner.Bytes()` возвращает срез, указывающий на внутренний перезаписываемый буфер сканера. Если сохранить этот срез в долгоживущую структуру без копирования (`copy()`), на следующей итерации данные будут затерты!
- Строка длиннее 64 КБ: токен вместе с разделителем должен поместиться в буфер размером `bufio.MaxScanTokenSize`, иначе `Scan()` вернёт `false`, а `scanner.Err()` — `bufio.ErrTooLong` (`bufio.Scanner: token too long`). Лимит поднимают до начала чтения: `scanner.Buffer(make([]byte, 0, 64*1024), 1<<20)`.

## На собеседовании

**Вопрос с собеседования:** «Почему для чтения больших текстовых файлов (логов на десятки гигабайт) используют `bufio.Scanner`, а не `os.ReadFile`?»
**Ответ:** `os.ReadFile` загружает весь файл целиком в оперативную память (что вызовет Out-Of-Memory панику на больших файлах), тогда как `bufio.Scanner` читает файл потоково небольшими порциями в один переиспользуемый буфер (начально 4 КБ, растёт до максимального размера токена — 64 КБ по умолчанию) с постоянным и минимальным потреблением RAM.
