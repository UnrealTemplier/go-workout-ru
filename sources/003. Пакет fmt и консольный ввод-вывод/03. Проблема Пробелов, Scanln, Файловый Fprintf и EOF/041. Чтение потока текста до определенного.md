# Чтение потока текста до определенного символа-терминатора

## Условие

**Чтение до определенного символа**: Напишите программу, которая считывает текст из консоли до тех пор, пока пользователь не введет точку `.`. Используйте `bufio`.

## Теория

Метод `bufio.Reader.ReadString(delim byte)`:
1. Принимает в качестве разделителя любой байт (например, точку `'.'`);
2. Считывает весь текст (включая пробелы и переносы строк), пока не встретит этот байт.

## Решение по шагам

1. Создаем `reader := bufio.NewReader(os.Stdin)`.
2. Вызываем `reader.ReadString('.')`.
3. Выводим весь прочитанный фрагмент текста.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"errors"
	"fmt"
	"io"
	"os"
)

func main() {
	reader := bufio.NewReader(os.Stdin)
	fmt.Println("Введите любой текст (чтение завершится, как только вы поставите точку '.'):")

	text, err := reader.ReadString('.')
	if err != nil {
		// io.EOF без точки: ReadString всё равно вернул прочитанный текст — не теряем его.
		if !errors.Is(err, io.EOF) || text == "" {
			fmt.Printf("Ошибка чтения: %v\n", err)
			return
		}
		fmt.Printf("\n⚠️ Ввод закончился раньше, чем встретилась точка. Прочитано:\n%s\n", text)
		return
	}

	fmt.Printf("\n✔ Успешно прочитано до точки:\n%s\n", text)
}
```

## Под капотом

`ReadString` ищет `delim` во внутреннем буфере `bufio.Reader` — обычном срезе (не кольцевом) на 4 КБ — через `bytes.IndexByte`. Как только байт найден, данные от начала до позиции разделителя включительно копируются в возвращаемую строку; если разделителя в буфере нет, ридер дочитывает поток и накапливает куски.

## Подводные камни

- Сама точка `.` входит в возвращаемую строку. Если она не нужна, используйте `strings.TrimSuffix(text, ".")`.
- Если поток закончился до точки, `ReadString` возвращает всё прочитанное **вместе** с `io.EOF`. Проверка `if err != nil { return }` молча выбросит этот текст — сначала посмотрите, не пуста ли строка.

## На собеседовании

**Вопрос с собеседования:** «Как устроен сетевой протокол HTTP 1.1 при чтении заголовков запроса?»
**Ответ:** Заголовки HTTP 1.1 отделяются от тела запроса двойным переводом строки `\r\n\r\n`. Сервер читает сокет через `bufio.Reader`, пока не встретит эту терминальную последовательность байт.
