# Парсинг календарной даты через fmt.Scanf (ДД/ММ/ГГГГ)

## Условие

**Шаблонный ввод**: Напишите программу, которая считывает дату в формате `ДД/ММ/ГГГГ` с помощью функции `fmt.Scanf` и раскладывает её на три целочисленные переменные (день, месяц, год).

## Теория

Парсинг строгого формата через шаблон со слэшами:
- Шаблон `"%d/%d/%d\n"` требует строгого совпадения разделителей `/`.
- После считывания необходимо провести валидацию диапазонов: день (1–31), месяц (1–12), год (> 1970).

## Решение по шагам

1. Задаем переменные `day, month, year int`.
2. Вызываем `fmt.Scanf("%d/%d/%d\n", &day, &month, &year)`.
3. Валидируем диапазоны календаря.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func main() {
	var day, month, year int

	fmt.Print("Введите дату в формате ДД/ММ/ГГГГ (например, 15/09/2026): ")
	n, err := fmt.Scanf("%d/%d/%d\n", &day, &month, &year)

	if err != nil || n != 3 {
		fmt.Printf("❌ Неверный формат даты. Ошибка: %v\n", err)
		return
	}

	if month < 1 || month > 12 || day < 1 || day > 31 || year < 1970 {
		fmt.Printf("❌ Некорректные календарные значения: %02d/%02d/%04d\n", day, month, year)
		return
	}

	fmt.Printf("✔ Успешно разобрана дата: День=%02d, Месяц=%02d, Год=%04d\n", day, month, year)
}
```

ℹ️ Результат разбора

## Под капотом

`Scanf` сопоставляет байт `/` с входным потоком. Если в потоке стоит точка или дефис (`02.09.2026`), сканер немедленно прерывается.

## Подводные камни

- `fmt.Scanf` не проверяет реальное количество дней в конкретном месяце (например, 31 февраля). Для полной валидации дат используют `time.Date(...)`.
