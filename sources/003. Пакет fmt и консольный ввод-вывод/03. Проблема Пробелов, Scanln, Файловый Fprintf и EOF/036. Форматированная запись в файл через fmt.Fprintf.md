# Форматированная запись в файл через fmt.Fprintf и io.Writer

## Условие

Используй `fmt.Fprintf` для записи форматированного текста в файл (используй `os.File` как `io.Writer`).

## Теория

Интерфейс `io.Writer`:
- Любой объект, имеющий метод `Write(p []byte) (n int, err error)`, является `io.Writer`.
- Файл `*os.File`, сетевой сокет `net.Conn`, буфер `bytes.Buffer`, поток `os.Stdout` — все они реализуют `io.Writer`.
- Функция `fmt.Fprintf(writer, format, args...)` записывает форматированный текст в **любой** `io.Writer` единым универсальным API!

## Решение по шагам

1. Создаем файл через `os.Create("report.txt")`.
2. Обязательно добавляем `defer file.Close()`.
3. Записываем структурированные данные через `fmt.Fprintf(file, ...)`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"os"
	"time"
)

func main() {
	fileName := "system_report.log"
	file, err := os.Create(fileName)
	if err != nil {
		fmt.Printf("Ошибка создания файла: %v\n", err)
		return
	}
	defer file.Close()

	// Запись заголовка отчета
	fmt.Fprintf(file, "=== СИСТЕМНЫЙ ОТЧЕТ СЕРВЕРА ===\n")
	fmt.Fprintf(file, "Дата генерации: %s\n", time.Now().Format("2006-01-02 15:04:05"))
	fmt.Fprintf(file, "Статус:         %s\n", "OK")
	fmt.Fprintf(file, "Нагрузка CPU:   %.2f%%\n", 14.85)
	fmt.Fprintf(file, "Память (RAM):   %d МБ из %d МБ\n", 1024, 8192)

	fmt.Printf("✔ Отчет успешно записан в файл %s\n", fileName)
}
```

ℹ️ Запись в файл через fmt.Fprintf

**`Терминал`**

```bash
go run main.go
# ✔ Отчет успешно записан в файл system_report.log

cat system_report.log
# === СИСТЕМНЫЙ ОТЧЕТ СЕРВЕРА ===
# Дата генерации: 2026-09-02 14:20:00
# Статус:         OK
# Нагрузка CPU:   14.85%
# Память (RAM):   1024 МБ из 8192 МБ
```

ℹ️ Проверка созданного файла

## Под капотом

`fmt.Fprintf` вызывает метод `file.Write()` структуры `*os.File`, который под капотом транслируется в системный вызов ядра `sys_write(fd, ...)`.

## Подводные камни

- Забыть закрыть файл через `defer file.Close()`: дескриптор файла утечет (File Descriptor Leak), что в долгоживущем сервисе приведет к ошибке `too many open files`.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go интерфейс `io.Writer` содержит всего один метод `Write([]byte)`?»
**Ответ:** Это фундаментальный принцип философии Go (Single Method Interface). Минималистичный контракт позволяет бесшовно соединять любые компоненты: логгеры, gzip-компрессоры, сетевые соединения и файлы без адаптеров.
