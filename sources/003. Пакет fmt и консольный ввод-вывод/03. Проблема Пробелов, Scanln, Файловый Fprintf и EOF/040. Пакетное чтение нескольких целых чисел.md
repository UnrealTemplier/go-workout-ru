# Пакетное чтение нескольких целых чисел через fmt.Scan

## Условие

Считай три целых числа через пробел в три переменные с помощью `fmt.Scan`.

## Теория

Функция `fmt.Scan(&a, &b, &c)` считывает сразу несколько значений подряд:
- Пробелы между числами игнорируются;
- Переносы строк между числами также трактуются как разделители.

## Решение по шагам

1. Объявляем `var x, y, z int`.
2. Вызываем `fmt.Scan(&x, &y, &z)`.
3. Вычисляем их сумму и среднее арифметическое.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var x, y, z int
	fmt.Print("Введите 3 целых числа (через пробел или Enter): ")

	n, err := fmt.Scan(&x, &y, &z)
	if err != nil {
		fmt.Printf("❌ Ошибка ввода: %v (прочитано: %d)\n", err, n)
		return
	}

	sum := x + y + z
	avg := float64(sum) / 3.0

	fmt.Printf("Сумма: %d, Среднее: %.2f\n", sum, avg)
}
```

ℹ️ Считывание трех чисел

**`Терминал`**

```bash
go run main.go
# Введите 3 целых числа (через пробел или Enter): 10 20 30
# Сумма: 60, Среднее: 20.00
```

ℹ️ Результат вычислений

## Под капотом

Парсер выполняет итерацию по переданному срезу указателей, пока счетчик прочитанных аргументов не достигнет `len(a)`.

## Подводные камни

- Целочисленное деление `sum / 3` отбросит дробную часть (`65 / 3 = 21`, а не `21.66`). Всегда приводите к `float64(sum) / 3.0`.

## На собеседовании

**Вопрос с собеседования:** «Что вернет выражение `5 / 2` в Go и как получить `2.5`?»
**Ответ:** Так как оба операнда целые числа `int`, результат будет `2` (целочисленное деление с отсечением остатка). Чтобы получить `2.5`, хотя бы один операнд должен быть вещественным: `5.0 / 2` или `float64(5) / 2`.
