# Строгий позиционный ввод по шаблону через fmt.Scanf

## Условие

**Строгое чтение**: Используй `fmt.Scanf`, чтобы считать данные строго в формате "Имя: [имя] Возраст: [возраст]" (без запятой после имени — почему, см. «Подводные камни»).

## Теория

Функция `fmt.Scanf`:
1. Считывает данные из `os.Stdin` строго в соответствии со строкой формата;
2. Все литеральные символы в шаблоне (двоеточия, запятые, пробелы) обязаны точно совпасть с введенным текстом.

## Решение по шагам

1. Задаем формат `"Имя: %s Возраст: %d\n"`.
2. Считываем данные в переменные.
3. Проверяем ошибку.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var name string
	var age int

	fmt.Println("Введите данные строго в формате: Имя: <имя> Возраст: <число>")
	fmt.Print("> ")

	n, err := fmt.Scanf("Имя: %s Возраст: %d\n", &name, &age)
	if err != nil {
		fmt.Printf("❌ Ошибка соответствия шаблону: %v (прочитано полей: %d)\n", err, n)
		return
	}

	fmt.Printf("✔ Успешно считано: Имя = %s, Возраст = %d\n", name, age)
}
```

ℹ️ Строгое шаблонное сканирование

**`Терминал`**

```bash
go run main.go
# Введите данные строго в формате: Имя: <имя> Возраст: <число>
# > Имя: Артем Возраст: 24
# ✔ Успешно считано: Имя = Артем, Возраст = 24
```

ℹ️ Успешный ввод

## Под капотом

`Scanf` сопоставляет каждый байт строки формата со входящим потоком символов. Если буква не совпадает, сканер прекращает работу с ошибкой `input does not match format`.

## Подводные камни

- Забыть указать символ переноса строки `\n` в конце шаблона `Scanf`. `Scan` от этого не ломается (он считает `\n` пробелом), и на Linux/macOS с переводом строки `\n` следующий `Scanf` тоже отработает. Ломается ввод с `\r\n` (Windows): следующий `Scanf`/`Scanln` получит `unexpected newline`. Заканчивайте формат `\n` или читайте строки через `bufio` и разбирайте их `fmt.Sscanf`.
- Запятая после `%s` в шаблоне: `%s` читает до пробела и забирает запятую вместе с именем. Формат `"Имя: %s, Возраст: %d"` на вводе `Имя: Артем, Возраст: 24` падает с `input does not match format`, а формат без запятой на том же вводе молча запишет `name = "Артем,"`. Для полей с запятыми читайте строку целиком и разбирайте её через `strings.Split`.

## На собеседовании

**Вопрос с собеседования:** «Почему в высоконагруженных сетевых протоколах не используют `fmt.Scanf` для парсинга пакетов?»
**Ответ:** `fmt.Scanf` использует рефлексию, выделяет память в куче под аргументы и работает в десятки раз медленнее, чем ручной парсинг байтового среза через индексы или бинарные кодеки (`binary.BigEndian`, Protobuf).
