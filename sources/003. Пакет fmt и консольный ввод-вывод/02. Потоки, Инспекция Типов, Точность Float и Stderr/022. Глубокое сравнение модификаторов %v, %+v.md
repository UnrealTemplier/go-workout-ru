# Глубокое сравнение модификаторов %v, %+v и %#v для сложных структур

## Условие

**Вывод структуры/массива**: Используй модификаторы `%v`, `%+v` и `%#v` для вывода сложных данных. Пойми разницу между ними.

## Теория

Для вложенных структур и коллекций:
- `%v`: выводит только сырые значения;
- `%+v`: рекурсивно выводит имена всех полей структур;
- `%#v`: выводит полный Go-код, который можно скопировать и вставить обратно в редактор для воссоздания объекта.

## Решение по шагам

1. Создаем структуру `Config` с вложенными полями и срезом.
2. Сравниваем вывод трех спецификаторов.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Database struct {
	Host string
	Port int
}

type AppConfig struct {
	AppID   string
	DB      Database
	Tags    []string
	Enabled bool
}

func main() {
	cfg := AppConfig{
		AppID:   "payment-gate",
		DB:      Database{Host: "pg-master.internal", Port: 5432},
		Tags:    []string{"fintech", "pci-dss"},
		Enabled: true,
	}

	fmt.Printf("--- 1. %%v ---\n%v\n\n", cfg)
	fmt.Printf("--- 2. %%+v ---\n%+v\n\n", cfg)
	fmt.Printf("--- 3. %%#v ---\n%#v\n", cfg)
}
```

ℹ️ Сравнение модификаторов на сложной структуре

**`Терминал`**

```bash
go run main.go
# --- 1. %v ---
# {payment-gate {pg-master.internal 5432} [fintech pci-dss] true}
# 
# --- 2. %+v ---
# {AppID:payment-gate DB:{Host:pg-master.internal Port:5432} Tags:[fintech pci-dss] Enabled:true}
# 
# --- 3. %#v ---
# main.AppConfig{AppID:"payment-gate", DB:main.Database{Host:"pg-master.internal", Port:5432}, Tags:[]string{"fintech", "pci-dss"}, Enabled:true}
```

ℹ️ Вывод программы

## Под капотом

`%#v` печатает значение в синтаксисе составного литерала Go (Go-syntax representation), добавляя кавычки вокруг строк, тип среза и имена типов каждого вложенного поля. Это не AST и не всегда компилируемый код: вложенные указатели выводятся адресами вида `(*main.Node)(0xc000010030)`.

## Подводные камни

- Вывод циклических структур (где структура А ссылается на Б, а Б на А через указатели): `fmt` циклы **не** обнаруживает и многоточий не печатает. Бесконечной рекурсии здесь нет по другой причине: разыменовывается только указатель верхнего уровня (`&{…}`), а вложенные указатели печатаются как адреса (`&{a 0xc000010030}`). Зато самоссылающийся срез или map (`s := []any{nil}; s[0] = s; fmt.Println(s)`) уходит в рекурсию и роняет программу с `fatal error: stack overflow`, которую нельзя перехватить `recover`.

## На собеседовании

**Вопрос с собеседования:** «Как скрыть приватные/чувствительные поля структуры при сериализации в логи?»
**Ответ:** Реализовать интерфейс `fmt.Stringer` (`func (c AppConfig) String() string`), где поля `Password` или `Token` заменяются на `"***"`.
