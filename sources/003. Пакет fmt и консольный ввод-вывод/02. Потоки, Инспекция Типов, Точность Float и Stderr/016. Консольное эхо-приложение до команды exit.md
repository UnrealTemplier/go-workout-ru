# Консольное эхо-приложение до команды exit

## Условие

Сделайте эхо-программу, которая читает строки до "exit" и выводит каждую с префиксом > .

### Исходная формулировка

Сделайте эхо-программу, которая читает строки до `"exit"` и выводит каждую с префиксом `> `.

---

## Теория

Паттерн Echo-сервера / консольного эхо:
1. Инициализация буферизованного сканера `bufio.NewScanner(os.Stdin)`;
2. Цикл `scanner.Scan()`, ожидающий ввода очередной строки;
3. Проверка условия завершения (`strings.EqualFold(line, "exit")`);
4. Форматированный вывод строки с префиксом `> `.

## Решение по шагам

1. Создаем `scanner := bufio.NewScanner(os.Stdin)`.
2. В цикле `for scanner.Scan()` считываем строку через `scanner.Text()`.
3. Если строка `"exit"` — завершаем работу.
4. Выводим `fmt.Printf("> %s\n", text)`.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"strings"
)

func main() {
	scanner := bufio.NewScanner(os.Stdin)
	fmt.Println("Эхо-программа запущена (введите 'exit' для выхода):")

	for scanner.Scan() {
		line := scanner.Text()
		if strings.TrimSpace(line) == "exit" {
			fmt.Println("Завершение работы эхо-программы.")
			break
		}
		fmt.Printf("> %s\n", line)
	}

	if err := scanner.Err(); err != nil {
		fmt.Printf("Ошибка сканера: %v\n", err)
	}
}
```

## Под капотом

`bufio.Scanner` по умолчанию использует функцию разделения `bufio.ScanLines`, которая ищет байты `\n` или `\r\n` и возвращает строку без этих разделителей.

## Подводные камни

- Забыть проверить `scanner.Err()` после выхода из цикла: если поток ввода аварийно оборвется (например, ошибка чтения сокета/файла), цикл завершится, но ошибка не будет обработана.

## На собеседовании

**Вопрос с собеседования:** «Что произойдет, если в `bufio.Scanner` передать строку длиннее 64 КБ?»
**Ответ:** `scanner.Scan()` вернет `false`, а `scanner.Err()` вернет ошибку `bufio.Scanner: token too long`. Чтобы читать длинные строки (например, гигантские JSON логи), нужно переопределить буфер через `scanner.Buffer(buf, maxCapacity)`.
