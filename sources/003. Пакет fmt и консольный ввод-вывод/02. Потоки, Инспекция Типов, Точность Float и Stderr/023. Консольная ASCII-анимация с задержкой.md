# Консольная ASCII-анимация с задержкой через time.Sleep

## Условие

Реализуйте простой ASCII-art (например, песочные часы), выводя символы посимвольно с задержкой через `time.Sleep`.

## Теория

Консольная анимация строится на:
1. Выводе кадров (frames) с помощью `fmt.Print`;
2. Задержках между кадрами `time.Sleep(100 * time.Millisecond)`;
3. Сбросе буфера `os.Stdout.Sync()`.

## Решение по шагам

1. Создаем кадры песочных часов.
2. В цикле выводим кадры с задержкой и очисткой экрана.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	frames := []string{
		"⏳ [====      ] Загрузка ядра...",
		"⏳ [=======   ] Инициализация БД...",
		"⏳ [==========] Сервис готов к работе!",
	}

	for _, frame := range frames {
		fmt.Printf("\r%s", frame)
		time.Sleep(500 * time.Millisecond)
	}
	fmt.Println("\n🚀 Сервер успешно стартовал!")
}
```

ℹ️ ASCII прогресс анимация

**`Терминал`**

```bash
go run main.go
# ⏳ [==========] Сервис готов к работе!
# 🚀 Сервер успешно стартовал!
```

ℹ️ Динамический вывод

## Под капотом

Символ `\r` (Carriage Return, код 13) возвращает курсор в начало текущей строки терминала без перевода строки, позволяя перезаписывать текст на месте.

## Подводные камни

- Если новая строка короче предыдущей, старые символы в конце строки не сотрутся. Их нужно перезаписывать пробелами.

## На собеседовании

**Вопрос с собеседования:** «Зачем в CLI-утилитах при выводе спиннера проверяют `isatty` (является ли stdout интерактивным терминалом)?»
**Ответ:** Если вывод перенаправлен в файл (`app > log.txt`) или работает в CI пайплайне, символы `\r` загрязняют лог. Поэтому утилиты проверяют интерактивность терминала (`term.IsTerminal`) и отключают анимацию в неинтерактивном режиме.
