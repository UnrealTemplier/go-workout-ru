# Формирование строк в памяти без вывода на экран через fmt.Sprintf

## Условие

**Форматирование без вывода**: Используйте функцию `fmt.Sprintf` для сборки строки из различных переменных. Сохраните результат в переменную и выведите её позже через `println`.

## Теория

Функция `fmt.Sprintf`:
1. Принимает строку формата и аргументы аналогично `fmt.Printf`;
2. НЕ выводит текст в консоль;
3. Возвращает готовую отформатированную строку `string`, которую можно сохранить в переменную, передать в БД или отправить по сети.

## Решение по шагам

1. Формируем строку сообщения через `fmt.Sprintf`.
2. Сохраняем результат в переменную `msg`.
3. Выводим строку встроенной функцией `println`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	service := "Billing"
	code := 404
	duration := 15.42

	// Сборка строки в памяти
	msg := fmt.Sprintf("Сервис [%s] вернул код %d за %.2f мс", service, code, duration)

	// Вывод сохраненной строки встроенным println
	println(msg)
}
```

ℹ️ Форматирование через fmt.Sprintf

**`Терминал`**

```bash
go run main.go
# Сервис [Billing] вернул код 404 за 15.42 мс
```

ℹ️ Вывод сохраненной строки

## Под капотом

`fmt.Sprintf` использует пул буферов `ppFree` (sync.Pool), собирает байты в буфер и возвращает новую строку `string(buf)`.

## Подводные камни

- Склеивание сотен тысяч строк в цикле через `fmt.Sprintf` в горячем коде: на каждой итерации аллоцируется новая строка. Для конкатенации в циклах используют `strings.Builder`.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество `strings.Builder` перед `fmt.Sprintf` при генерации больших текстовых отчетов?»
**Ответ:** `strings.Builder` динамически наращивает внутренний срез байт без промежуточных аллокаций памяти и при вызове `.String()` преобразует срез в строку через `unsafe.Pointer` с нулевым копированием (zero-copy).
