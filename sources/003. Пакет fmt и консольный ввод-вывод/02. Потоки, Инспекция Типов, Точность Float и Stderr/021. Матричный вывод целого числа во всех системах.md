# Матричный вывод целого числа во всех системах счисления

## Условие

**Форматирование чисел**: Выведите одно и то же целое число в десятичном (`%d`), двоичном (`%b`), восьмеричном (`%o`) и шестнадцатеричном (`%x` и `%X`) форматах.

## Теория

Таблица спецификаторов:
- `%d` — 10-ричная (2024);
- `%b` — 2-ичная (`11111101000`);
- `%o` — 8-ричная (`3750`);
- `%x` — 16-ричная строчная (`7e8`);
- `%X` — 16-ричная заглавная (`7E8`).

## Решение по шагам

1. Задаем число `2024`.
2. Выводим его во всех форматах с заголовками.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	year := 2024

	fmt.Printf("DEC (10): %d\n", year)
	fmt.Printf("BIN (2):  %b\n", year)
	fmt.Printf("OCT (8):  %o\n", year)
	fmt.Printf("HEX (16): %x\n", year)
	fmt.Printf("HEX (16): %X\n", year)
}
```

ℹ️ Матричный вывод числа

**`Терминал`**

```bash
go run main.go
# DEC (10): 2024
# BIN (2):  11111101000
# OCT (8):  3750
# HEX (16): 7e8
# HEX (16): 7E8
```

ℹ️ Результат

## Под капотом

При использовании `%x` и `%X` рантайм использует разные таблицы символов `hextable` (`0123456789abcdef` vs `0123456789ABCDEF`).

## Подводные камни

- Использование спецификатора `%d` для чисел типа `float`: вызовет предупреждение компилятора и ошибку форматирования.

## На собеседовании

**Вопрос с собеседования:** «Как распечатать IPv4 адрес из числа `uint32` (например `0x7F000001` -> `127.0.0.1` )?»
**Ответ:** Побайтовым сдвигом: `fmt.Printf("%d.%d.%d.%d", byte(ip>>24), byte(ip>>16), byte(ip>>8), byte(ip))`.
