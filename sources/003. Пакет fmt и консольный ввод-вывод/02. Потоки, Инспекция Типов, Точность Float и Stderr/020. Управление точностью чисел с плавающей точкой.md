# Управление точностью чисел с плавающей точкой (%.2f)

## Условие

**Точность float**: Задай число с плавающей точкой (например, 3.14159) и выведи его с точностью строго до 2-х знаков после запятой.

## Теория

Спецификаторы точности для `float32` и `float64`:
- `%.2f` — строго 2 знака после запятой с округлением до ближайшего значения (а не отбрасыванием хвоста);
- `%.4f` — строго 4 знака;
- `%8.2f` — общая ширина поля 8 символов, из них 2 знака после запятой;
- `%e` / `%.2e` — экспоненциальная запись (`3.14e+00`).

## Решение по шагам

1. Задаем число `pi := 3.1415926535`.
2. Выводим с разной точностью через `%.0f`, `%.2f`, `%.5f`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	pi := 3.1415926535

	fmt.Printf("Исходное:     %f\n", pi)
	fmt.Printf("Без дроби:    %.0f\n", pi)
	fmt.Printf("2 знака (%%.2f): %.2f\n", pi)
	fmt.Printf("5 знаков (%%.5f): %.5f\n", pi)
}
```

ℹ️ Управление точностью вещественных чисел

**`Терминал`**

```bash
go run main.go
# Исходное:     3.141593
# Без дроби:    3
# 2 знака (%.2f): 3.14
# 5 знаков (%.5f): 3.14159
```

ℹ️ Округление

## Под капотом

Алгоритм форматирования `strconv.FormatFloat` использует алгоритм Ryu или Grisu3 для быстрого и точного перевода IEEE 754 float в десятичную строку.

## Подводные камни

- Округление в `Printf` — не простое отбрасывание хвоста (truncation), но и не «школьное» округление десятичной записи: округляется **точное двоичное значение** числа. Ровные половинки, точно представимые в `float64` (0.5, 2.5, 0.25), округляются к чётному: `%.0f` для 0.5 → `0`, для 2.5 → `2`, `%.1f` для 0.25 → `0.2`. А `2.675` печатается через `%.2f` как `2.67`, потому что в `float64` оно хранится как чуть меньшее 2.675 число (так же `1.005` → `1.00`, `0.35` → `0.3` при `%.1f`).

## На собеседовании

**Вопрос с собеседования:** «Как отформатировать float так, чтобы отсечь незначащие нули на конце (например, 3.50 -> 3.5, но 3.14159 -> 3.14159)?»
**Ответ:** С помощью спецификатора `%g` (compact representation): `3.50` → `3.5`, `3.14159` → `3.14159`. Оговорка: для больших и малых чисел `%g` переходит на экспоненциальную запись (`100000000.0` → `1e+08`, `0.00001` → `1e-05`). Если нужна обычная запись без лишних нулей, используйте `strconv.FormatFloat(x, 'f', -1, 64)` (`100000000.0` → `100000000`).
