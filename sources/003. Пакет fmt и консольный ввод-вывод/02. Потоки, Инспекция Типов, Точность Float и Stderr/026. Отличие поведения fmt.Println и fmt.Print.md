# Отличие поведения fmt.Println и fmt.Print

## Условие

**Базовый вывод**: Напишите программу, которая выводит три строки с помощью `fmt.Println` и три строки с помощью `fmt.Print`. Обратите внимание на автоматическую расстановку пробелов и переносов строк.

## Теория

Разница между `Print` и `Println`:
- **`fmt.Print`**: НЕ добавляет перенос строки в конце. Пробелы между аргументами добавляются **только если ни один из соседних операндов не является строкой**.
- **`fmt.Println`**: ВСЕГДА добавляет пробелы между всеми аргументами и перенос строки `\n` в конце.

## Решение по шагам

1. Вызываем `fmt.Println` с несколькими аргументами.
2. Вызываем `fmt.Print` с теми же аргументами.
3. Сравниваем форматирование.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	fmt.Println("=== Вызовы fmt.Println ===")
	fmt.Println("Строка 1", "Строка 2", 100)
	fmt.Println("Строка 3")

	fmt.Println("\n=== Вызовы fmt.Print ===")
	fmt.Print("Строка 1", "Строка 2", 100)
	fmt.Print("Строка 3\n")
}
```

ℹ️ Сравнение Print и Println

**`Терминал`**

```bash
go run main.go
# === Вызовы fmt.Println ===
# Строка 1 Строка 2 100
# Строка 3
# 
# === Вызовы fmt.Print ===
# Строка 1Строка 2 100Строка 3
```

ℹ️ Обратите внимание на склеивание строк в Print

## Под капотом

В реализации `fmt.Print` стоит условие: `if i > 0 && isString == false && prevString == false { addSpace() }`.

## Подводные камни

- Ожидание пробела в `fmt.Print("Hello", "World")`: результатом будет `HelloWorld`.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go функция `fmt.Print("A", "B")` не ставит пробел, а `fmt.Print(1, 2)` ставит?»
**Ответ:** Таков дизайн спецификации Go: если оба соседних операнда не являются строками (например числа `1` и `2`), без пробела они бы слились в неразличимое число `12`. А для строк предполагается, что разработчик сам контролирует разделители.
