# Комплексный мастер-класс по всем спецификаторам fmt.Printf

## Условие

Используя fmt.Printf, выведи: целое число во всех базах, float с разной точностью, строку в кавычках и без, bool, формат Go (%#v), тип (%T).

### Исходная формулировка

Используя `fmt.Printf`, выведи:
- Целое число в десятичном, двоичном, восьмеричном и шестнадцатеричном виде
- Число с плавающей точкой с точностью 2, 5, 10 знаков после запятой
- Строку в кавычках и без
- Булево значение
- Значение в "формате Go" (`%#v`)
- Тип переменной (`%T`)

## Теория

Обобщающий практикум по всем ключевым спецификаторам форматирования в одном месте.

## Решение по шагам

1. Создаем набор тестовых переменных.
2. Выводим каждую переменную с пояснением спецификатора.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	n := 255
	f := 3.1415926535
	s := "Go Workout"
	b := true

	fmt.Printf("1. Числа (Dec/Bin/Oct/Hex): %d | %b | %o | %x\n", n, n, n, n)
	fmt.Printf("2. Float (2/5 знаков):      %.2f | %.5f\n", f, f)
	fmt.Printf("3. Строка (обычная/кавычки): %s | %q\n", s, s)
	fmt.Printf("4. Булево:                   %t\n", b)
	fmt.Printf("5. Go-синтаксис (%%#v):       %#v\n", s)
	fmt.Printf("6. Тип переменной (%%T):      %T\n", f)
}
```

ℹ️ Комплексное форматирование

**`Терминал`**

```bash
go run main.go
# 1. Числа (Dec/Bin/Oct/Hex): 255 | 11111111 | 377 | ff
# 2. Float (2/5 знаков):      3.14 | 3.14159
# 3. Строка (обычная/кавычки): Go Workout | "Go Workout"
# 4. Булево:                   true
# 5. Go-синтаксис (%#v):       "Go Workout"
# 6. Тип переменной (%T):      float64
```

ℹ️ Результат вывода

## Под капотом

`fmt.Printf` компилирует строку формата в промежуточные токены и последовательно вызывает внутренние методы `fmt.pp`.

## Подводные камни

- Лишние или недостающие аргументы вызовут ошибку форматирования `%!(EXTRA string=...)`.

## На собеседовании

**Вопрос с собеседования:** «Какая разница в производительности между `fmt.Printf("%s", str)` и `fmt.Print(str)`?»
**Ответ:** `fmt.Print(str)` работает быстрее, так как не парсит строку формата на наличие символов `%`.
