# Инспекция типов переменных через спецификатор %T

## Условие

**Вывод типов**: Напишите программу, которая принимает переменные разных типов и выводит их тип в консоль с помощью спецификатора `%T`.

## Теория

Спецификатор **`%T`** в `fmt.Printf`:
1. Выводит точное имя типа переменной на языке Go;
2. Для пользовательских типов выводит путь пакета и имя (`main.User`);
3. Для указателей выводит звездочку `*int`;
4. Для функций выводит их полную сигнатуру `func(string) int`.

## Решение по шагам

1. Создаем переменные разных типов (примитивы, указатели, структуры, срезы, каналы).
2. Выводим их через `fmt.Printf("%T\n", var)`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type OrderID uint64

func main() {
	var id OrderID = 100500
	num := 42
	ptr := &num
	ch := make(chan string)
	fn := func(x int) bool { return x > 0 }

	fmt.Printf("id:  значение = %v, тип = %T\n", id, id)
	fmt.Printf("num: значение = %v, тип = %T\n", num, num)
	fmt.Printf("ptr: значение = %v, тип = %T\n", ptr, ptr)
	fmt.Printf("ch:  значение = %v, тип = %T\n", ch, ch)
	fmt.Printf("fn:  значение = %v, тип = %T\n", fn, fn)
}
```

ℹ️ Вывод типов через %T

**`Терминал`**

```bash
go run main.go
# id:  значение = 100500, тип = main.OrderID
# num: значение = 42, тип = int
# ptr: значение = 0xc0000180a8, тип = *int
# ch:  значение = 0xc000062060, тип = chan string
# fn:  значение = 0x48a240, тип = func(int) bool
```

ℹ️ Вывод типов

## Под капотом

При обработке `%T` рантайм Go обращается к структуре `_type` из метаданных интерфейса (eface/iface), где хранится строковое имя типа в бинарнике.

## Подводные камни

- Если переменная интерфейсного типа содержит `nil`, `%T` выведет `<nil>`. Если интерфейс содержит конкретное значение, `%T` выведет динамический тип лежащего внутри значения, а не тип самого интерфейса.

## На собеседовании

**Вопрос с собеседования:** «Как получить имя типа без `fmt.Printf("%T")` для высокопроизводительного кода?»
**Ответ:** Через `reflect.TypeOf(v).String()` или `reflect.TypeOf(v).Name()`.
