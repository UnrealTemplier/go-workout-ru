# Исследование 5 различных типов данных через %T

## Условие

**Исследование типов**: Создай 5 переменных разных типов. Используй `fmt.Printf` и `%T`, чтобы программа сама вывела их типы.

## Теория

Язык Go является статически типизированным. Спецификатор `%T` позволяет исследовать как встроенные, так и сложные композитные типы.

## Решение по шагам

1. Создаем 5 различных типов: `byte`, `rune`, `complex128`, `[3]int`, `map[string]int`.
2. Выводим значение и тип для каждого.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var b byte = 'A'               // псевдоним uint8
	var r rune = 'Ж'               // псевдоним int32
	var c complex128 = 3 + 4i      // комплексное число
	var arr [3]int = [3]int{1, 2, 3} // массив фиксированной длины
	dict := map[string]int{"one": 1} // хэш-таблица

	fmt.Printf("1. Байт:      значение = %c, тип = %T\n", b, b)
	fmt.Printf("2. Руна:      значение = %c, тип = %T\n", r, r)
	fmt.Printf("3. Комплекс:  значение = %v, тип = %T\n", c, c)
	fmt.Printf("4. Массив:    значение = %v, тип = %T\n", arr, arr)
	fmt.Printf("5. Словарь:   значение = %v, тип = %T\n", dict, dict)
}
```

ℹ️ Исследование типов Go

**`Терминал`**

```bash
go run main.go
# 1. Байт:      значение = A, тип = uint8
# 2. Руна:      значение = Ж, тип = int32
# 3. Комплекс:  значение = (3+4i), тип = complex128
# 4. Массив:    значение = [1 2 3], тип = [3]int
# 5. Словарь:   значение = map[one:1], тип = map[string]int
```

ℹ️ Анализ типов

## Под капотом

В выводе видно, что `byte` раскрывается как `uint8`, а `rune` — как `int32`, так как они являются строгими type alias в языке Go.

## Подводные камни

- Массив `[3]int` и срез `[]int` — это принципиально разные типы! Размер массива входит в его сигнатуру типа.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между Type Definition `type MyInt int` и Type Alias `type MyInt = int` при выводе через `%T`?»
**Ответ:** Для Type Definition `%T` выведет новое пользовательское имя `main.MyInt`. Для Type Alias `%T` выведет исходный базовый тип `int`, так как алиас — это просто синоним существующего типа.
