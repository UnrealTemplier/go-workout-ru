# Универсальный спецификатор форматирования %v

## Условие

**Универсальный спецификатор**: Создайте переменные разных типов (число, строка, булево). Выведите их в консоль, используя `fmt.Printf` со спецификатором `%v`.

## Теория

Спецификатор `%v` (value) — универсальный глагол форматирования в Go.
Он автоматически выбирает наиболее естественное строковое представление для любого типа данных:
- Для чисел — стандартная десятичная запись;
- Для булевых — `true` / `false`;
- Для срезов — элементы в квадратных скобках `[1 2 3]`;
- Для словарей — `map[key:val]`;
- Для указателей — шестнадцатеричный адрес памяти.

## Решение по шагам

1. Создаем переменные примитивных и композитных типов.
2. Выводим каждую через `fmt.Printf("%v\n", val)`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	count := 42
	greeting := "Привет, Go!"
	isActive := true
	pi := 3.14159
	scores := []int{100, 95, 88}
	config := map[string]string{"env": "production", "region": "ru-central1"}

	fmt.Printf("Int:    %v\n", count)
	fmt.Printf("String: %v\n", greeting)
	fmt.Printf("Bool:   %v\n", isActive)
	fmt.Printf("Float:  %v\n", pi)
	fmt.Printf("Slice:  %v\n", scores)
	fmt.Printf("Map:    %v\n", config)
}
```

ℹ️ Универсальный вывод через %v

**`Терминал`**

```bash
go run main.go
# Int:    42
# String: Привет, Go!
# Bool:   true
# Float:  3.14159
# Slice:  [100 95 88]
# Map:    map[env:production region:ru-central1]
```

ℹ️ Вывод

## Под капотом

При обработке `%v` форматировщик проверяет, реализует ли тип интерфейс `fmt.Stringer` (метод `String() string`) или `error` (метод `Error() string`). Если да — вызывается этот метод; иначе значение форматируется встроенным рефлексивным обходчиком `printValue`.

## Подводные камни

- Попытка использовать `%v` для форматирования байтового среза `[]byte`: он выведет список чисел `[72 101 108 108 111]`, а не строку `"Hello"`. Для вывода байтов как строки используют `%s` или явное приведение `string(bytes)`.

## На собеседовании

**Вопрос с собеседования:** «Как сделать так, чтобы структура при выводе через `%v` возвращала кастомный JSON или маскировала пароль?»
**Ответ:** Реализовать для структуры метод `String() string` (интерфейс `fmt.Stringer`). При любом вызове `%v`, `fmt.Println` или `fmt.Sprintf` рантайт автоматически вызовет метод `String()`.
