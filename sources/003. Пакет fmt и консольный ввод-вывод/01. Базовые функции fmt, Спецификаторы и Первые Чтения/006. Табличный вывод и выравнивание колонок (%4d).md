# Табличный вывод и выравнивание колонок (%4d)

## Условие

Выведите таблицу квадратов чисел от 1 до 10 с выравниванием колонок (задайте ширину в `%4d` и т.п.).

## Теория

Флаги ширины поля в `fmt.Printf`:
- `%4d` — число выравнивается **по правому краю**, дополняясь пробелами до 4 символов;
- `%-4d` — число выравнивается **по левому краю**;
- `%04d` — число дополняется ведущими нулями (`0007`).

## Решение по шагам

1. Печатаем заголовок таблицы с разделителями.
2. В цикле от 1 до 10 выводим число, его квадрат и куб с фиксированной шириной колонок.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	fmt.Println("+------+--------+---------+")
	fmt.Println("| Число| Квадрат|   Куб   |")
	fmt.Println("+------+--------+---------+")

	for n := 1; n <= 10; n++ {
		fmt.Printf("| %4d |  %5d |  %6d |\n", n, n*n, n*n*n)
	}

	fmt.Println("+------+--------+---------+")
}
```

ℹ️ Выравнивание числовых колонок

**`Терминал`**

```bash
go run main.go
# +------+--------+---------+
# | Число| Квадрат|   Куб   |

# |    1 |      1 |       1 |
# |    2 |      4 |       8 |
# |    3 |      9 |      27 |
# |    4 |     16 |      64 |

# |    8 |     64 |     512 |
```

ℹ️ Идеально выровненная таблица

## Под капотом

Форматтер вычисляет количество символов в числе и приписывает `width - len` пробелов в буфер перед записью цифр.

## Подводные камни

- Если число шире указанной ширины (например, число 100000 при `%4d`), Go **не будет обрезать число**, а напечатает его полностью, что может сдвинуть верстку таблицы.

## На собеседовании

**Вопрос с собеседования:** «Как динамически задать ширину колонки во время выполнения программы, если ширина заранее неизвестна?»
**Ответ:** С помощью звездочки `*`: `fmt.Printf("%*d", width, value)`. Значение ширины передается как отдельный аргумент перед самим числом.
