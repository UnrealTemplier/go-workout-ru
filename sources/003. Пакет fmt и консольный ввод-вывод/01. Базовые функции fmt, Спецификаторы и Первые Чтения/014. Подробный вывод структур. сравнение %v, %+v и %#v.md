# Подробный вывод структур: сравнение %v, %+v и %#v

## Условие

**Подробный вывод структур**: Создайте простую структуру `User` с полями `Name` и `Age`. Инициализируйте её. Выведите её в консоль тремя способами: через `%v`, `%+v` и `%#v`. Сравните результаты.

## Теория

Разница модификаторов вывода структур:
1. `%v` (Value): выводит только значения полей `{Алексей 29}`;
2. `%+v` (Plus Value): выводит имена полей и их значения `{Name:Алексей Age:29}`;
3. `%#v` (Syntax Value): выводит полное объявление типа на языке Go `main.User{Name:"Алексей", Age:29}`.

## Решение по шагам

1. Объявляем структуру `type User struct { Name string; Age int }`.
2. Создаем экземпляр `u := User{Name: "Алексей", Age: 29}`.
3. Выводим через `%v`, `%+v`, `%#v`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type User struct {
	Name string
	Age  int
}

func main() {
	user := User{Name: "Алексей", Age: 29}

	fmt.Printf("1. Базовый %%v:    %v\n", user)
	fmt.Printf("2. С полями %%+v:   %+v\n", user)
	fmt.Printf("3. Go-синтакс %%#v: %#v\n", user)
}
```

ℹ️ Сравнение модификаторов вывода структур

**`Терминал`**

```bash
go run main.go
# 1. Базовый %v:    {Алексей 29}
# 2. С полями %+v:   {Name:Алексей Age:29}
# 3. Go-синтакс %#v: main.User{Name:"Алексей", Age:29}
```

## Под капотом

При `%+v` и `%#v` форматировщик обходит поля структуры через `reflect.Type.Field(i).Name` и считывает смещения полей в оперативной памяти.

## Подводные камни

- Приватные (неэкспортированные со строчной буквы) поля структуры также будут выведены в `%+v`, поэтому не передавайте в логгер структуры с секретными полями вроде `passwordHash` или токенами доступа.

## На собеседовании

**Вопрос с собеседования:** «Какой модификатор `%v`, `%+v` или `%#v` рекомендуется использовать в сообщениях об ошибках юнит-тестов `t.Errorf`?»
**Ответ:** Рекомендуется `%#v` (или `diff` библиотек вроде `go-cmp`), так как `%#v` явно показывает кавычки у пустых строк `""`, `nil` vs пустые срезы `[]int{}` и точные типы полей, предотвращая ложное ощущение совпадения значений.
