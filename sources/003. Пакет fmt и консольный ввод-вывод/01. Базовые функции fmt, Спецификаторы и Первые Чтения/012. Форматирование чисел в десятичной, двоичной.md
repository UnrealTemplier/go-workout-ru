# Форматирование чисел в десятичной, двоичной и шестнадцатеричной системах

## Условие

**Форматирование чисел**: Через `fmt.Printf` выведи одно и то же число в десятичной (`%d`), двоичной (`%b`) и шестнадцатеричной (`%x`) системах.

## Теория

Спецификаторы систем счисления для целочисленных типов:
- `%d` (Decimal) — основание 10;
- `%b` (Binary) — основание 2 (битовое представление);
- `%x` / `%X` (Hexadecimal) — основание 16 (строчные/прописные буквы);
- `%o` / `%O` (Octal) — основание 8 (с префиксом `0o`).
- Флаг `#` (`%#x`, `%#b`, `%#o`) добавляет канонический префикс `0x`, `0b`, `0o`.

## Решение по шагам

1. Задаем число (например, `255` или `1024`).
2. Выводим число с использованием спецификаторов `%d`, `%b`, `%x`, `%#x`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	num := 255

	fmt.Printf("Десятичная:       %d\n", num)
	fmt.Printf("Двоичная:         %b\n", num)
	fmt.Printf("Двоичная с 0b:    %#b\n", num)
	fmt.Printf("Шестнадцатеричная: %x\n", num)
	fmt.Printf("HEX с префиксом:  %#X\n", num)
}
```

ℹ️ Числовые системы счисления

**`Терминал`**

```bash
go run main.go
# Десятичная:       255
# Двоичная:         11111111
# Двоичная с 0b:    0b11111111
# Шестнадцатеричная: ff
# HEX с префиксом:  0XFF
```

ℹ️ Вывод числа 255

## Под капотом

Для форматирования чисел пакет `fmt` использует внутренний модуль `strconv.FormatInt`, который без аллокаций выполняет побитовый сдвиг и маскирование битов числа в локальный байтовый буфер на стеке.

## Подводные камни

- Вывод отрицательных чисел в двоичной системе (`%b`): Go выводит `-101`, а не дополнительный код (two's complement). Чтобы увидеть битовое представление отрицательного числа, приведите его к беззнаковому типу `uint64(int64_val)`.

## На собеседовании

**Вопрос с собеседования:** «Как распечатать битовую маску сетевых прав Linux (например, `0755`) в каноническом восьмеричном виде?»
**Ответ:** Через спецификатор `%#o`: `fmt.Printf("%#o", 0755)` выведет `0755`.
