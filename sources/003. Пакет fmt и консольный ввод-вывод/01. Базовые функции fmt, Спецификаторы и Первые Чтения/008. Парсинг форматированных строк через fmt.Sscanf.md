# Парсинг форматированных строк через fmt.Sscanf

## Условие

Используйте `fmt.Sscanf` для парсинга строки формата "Имя, возраст, рост" в соответствующие переменные.

## Теория

Функция `fmt.Sscanf` разбирает входную строку по заданному шаблону:
- `fmt.Sscanf(sourceStr, "%s %d %f", &name, &age, &height)`
- Она извлекает данные в переменные соответствующих типов без ручного вызова `strings.Split`.

## Решение по шагам

1. Создаем исходную форматированную строку.
2. Объявляем переменные `name`, `age`, `height`.
3. Вызываем `fmt.Sscanf`.
4. Проверяем возвращенное количество прочитанных полей `n` и ошибку.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	cleanLog := "Дмитрий 28 185.5"

	var (
		name   string
		age    int
		height float64
	)

	pattern := "%s %d %f"

	n, err := fmt.Sscanf(cleanLog, pattern, &name, &age, &height)
	if err != nil {
		fmt.Printf("Ошибка парсинга: %v (успешно полей: %d)\n", err, n)
		return
	}

	fmt.Printf("Разобрано %d полей:\n", n)
	fmt.Printf("• Имя:     %s\n", name)
	fmt.Printf("• Возраст: %d\n", age)
	fmt.Printf("• Рост:    %.1f см\n", height)
}
```

**`Терминал`**

## Под капотом

`fmt.Sscanf` создает виртуальный `strings.Reader` над строкой и запускает лексер, сопоставляющий литеральные символы шаблона с входным потоком байт.

## Подводные камни

- Спецификатор `%s` в `Sscanf` читает до первого пробела. Если имя состоит из двух слов ("Иван Петр"), `%s` прочитает только "Иван", а остаток строки сломает шаблон.

## На собеседовании

**Вопрос с собеседования:** «Когда вместо `fmt.Sscanf` следует использовать регулярные выражения `regexp`?»
**Ответ:** `fmt.Sscanf` подходит только для строго фиксированных шаблонов без опциональных полей. Если формат строки вариативен, содержит необязательные группы или сложные разделители, используют скомпилированные регулярные выражения `regexp.MustCompile(...)`.
