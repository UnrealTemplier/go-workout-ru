# Интерактивное консольное меню с циклом и switch

## Условие

Напишите простейшее меню: бесконечный цикл, чтение команды, `switch`, выход по `"exit"`.

## Теория

Интерактивный REPL (Read-Eval-Print Loop) в консоли:
1. Бесконечный цикл `for {}`;
2. Вывод приглашения ввода (`> `);
3. Считывание команды через `bufio.Reader`;
4. Диспетчеризация через оператор `switch command`;
5. Завершение работы программы при команде `"exit"` или `"quit"` через `return` или `os.Exit(0)`.

## Решение по шагам

1. Инициализируем `reader := bufio.NewReader(os.Stdin)`.
2. Запускаем бесконечный цикл `for`.
3. Читаем строку, очищаем через `strings.TrimSpace`.
4. В `switch` обрабатываем команды: `status`, `help`, `version`, `exit`.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"errors"
	"fmt"
	"io"
	"os"
	"strings"
	"time"
)

func main() {
	reader := bufio.NewReader(os.Stdin)
	fmt.Println("=== Утилита управления сервером (введите 'help' для списка команд) ===")

	for {
		fmt.Print("app> ")
		input, err := reader.ReadString('\n')
		// Последняя команда без \n приходит вместе с io.EOF: сначала выполняем её,
		// а выходим, когда EOF пришёл с пустой строкой (или при другой ошибке).
		if err != nil && (!errors.Is(err, io.EOF) || input == "") {
			fmt.Println("Завершение по сигналу ввода.")
			break
		}

		cmd := strings.ToLower(strings.TrimSpace(input))

		switch cmd {
		case "exit", "quit":
			fmt.Println("Выключение утилиты. До свидания!")
			return
		case "help":
			fmt.Println("Доступные команды: status, time, ping, exit")
		case "status":
			fmt.Println("Статус: Сервер активен, нагрузка CPU: 12%")
		case "time":
			fmt.Printf("Текущее время: %s\n", time.Now().Format("15:04:05"))
		case "ping":
			fmt.Println("PONG!")
		case "":
			// Пользователь просто нажал Enter
			continue
		default:
			fmt.Printf("Неизвестная команда '%s'. Введите 'help'.\n", cmd)
		}
	}
}
```

# app> status

## Под капотом

Консольный ввод переводится ядром ОС в режим канонического ввода (Canonical Mode), при котором данные передаются в программу только после нажатия пользователем клавиши Enter.

## Подводные камни

- Забыть привести ввод к нижнему регистру (`strings.ToLower`): команды `Exit`, `EXIT` и `exit` будут распознаваться как разные строки.
- Проверять `err` до обработки данных: если последняя строка пришла без `\n` (pipe или файл: `printf 'ping' | ./app`), `ReadString` возвращает её вместе с `io.EOF`, и команда теряется. Сначала обработайте непустой `input`, а выходите, когда `io.EOF` пришёл с пустой строкой.

## На собеседовании

**Вопрос с собеседования:** «Как корректно завершить REPL-цикл, если пользователь нажал Ctrl+C или Ctrl+D?»
**Ответ:** Нажатие Ctrl+D генерирует ошибку `io.EOF` в `ReadString`, при которой цикл корректно прерывается через `break`. Нажатие Ctrl+C посылает сигнал `SIGINT`, для перехвата которого запускают горутину с `os/signal`.
