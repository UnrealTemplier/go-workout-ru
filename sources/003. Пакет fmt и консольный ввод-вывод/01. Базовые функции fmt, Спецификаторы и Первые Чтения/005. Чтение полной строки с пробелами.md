# Чтение полной строки с пробелами через bufio.Reader.ReadString

## Условие

Считайте строку, содержащую пробелы, с помощью `bufio.NewReader` и `os.Stdin.ReadString`.

## Теория

Функция `fmt.Scan` останавливается на первом же пробеле.
Чтобы считать **всю введенную строку целиком** (включая пробелы) до нажатия клавиши Enter:
1. Используется метод `reader.ReadString('\n')`;
2. Он считывает байты до символа разделителя (delimiter);
3. Символ `\n` (а на Windows `\r\n`) остается в конце строки, поэтому его удаляют через `strings.TrimSpace`.

## Решение по шагам

1. Создаем `reader := bufio.NewReader(os.Stdin)`.
2. Читаем строку до `\n`: `text, err := reader.ReadString('\n')`.
3. Очищаем от переносов строк: `strings.TrimSpace(text)`.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"strings"
)

func main() {
	reader := bufio.NewReader(os.Stdin)
	fmt.Print("Введите ваше полное имя и должность: ")

	input, err := reader.ReadString('\n')
	if err != nil {
		fmt.Printf("Ошибка чтения: %v\n", err)
		return
	}

	cleanInput := strings.TrimSpace(input)
	fmt.Printf("Получено: [%s] (длина: %d символов)\n", cleanInput, len(cleanInput))
}
```

ℹ️ Чтение строки с пробелами

**`Терминал`**

```bash
go run main.go
# Введите ваше полное имя и должность: Иван Иванов Lead Go Engineer
# Получено: [Иван Иванов Lead Go Engineer] (длина: 45 символов)
```

ℹ️ Ввод строки с несколькими пробелами

## Под капотом

`ReadString` динамически увеличивает внутренний буфер, если разделитель `\n` не встретился в первом чанке 4 КБ.

## Подводные камни

- На Windows при нажатии Enter терминал отправляет два байта `\r\n`. Если использовать `strings.TrimSuffix(input, "\n")`, невидимый символ `\r` останется в строке и может затереть вывод в консоли. Используйте `strings.TrimSpace` или `strings.TrimRight(input, "\r\n")`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие `bufio.Reader.ReadString('\n')` от `bufio.Scanner.Scan()`?»
**Ответ:** `ReadString` возвращает строку вместе с разделителем `\n` и аллоцирует строку на каждый вызов. `bufio.Scanner` автоматически отсекает `\n`, переиспользует внутренний буфер байт `scanner.Bytes()` без лишних аллокаций памяти и безопаснее ограничивает максимальную длину строки (`maxScanTokenSize = 64 * 1024`).
