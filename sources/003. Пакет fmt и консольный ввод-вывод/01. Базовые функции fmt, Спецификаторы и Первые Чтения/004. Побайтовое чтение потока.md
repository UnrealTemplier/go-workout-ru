# Побайтовое чтение потока через bufio.Reader.ReadByte

## Условие

Прочитайте один байт (`bufio.Reader.ReadByte`) и определите, является ли он цифрой.

## Теория

Пакет `bufio` предоставляет буферизованный ввод-вывод.
Метод `bufio.Reader.ReadByte()`:
1. Считывает ровно один байт (`byte` = `uint8`);
2. Если в буфере пусто, запрашивает блок данных из `os.Stdin` (обычно 4096 байт) за один системный вызов;
3. В таблице ASCII цифры от `'0'` до `'9'` имеют непрерывный диапазон кодов от 48 (`0x30`) до 57 (`0x39`).

## Решение по шагам

1. Оборачиваем `os.Stdin` в `bufio.NewReader(os.Stdin)`.
2. Вызываем `reader.ReadByte()`.
3. Проверяем условие `b >= '0' && b <= '9'`.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"os"
)

func main() {
	reader := bufio.NewReader(os.Stdin)
	fmt.Print("Введите один символ: ")

	b, err := reader.ReadByte()
	if err != nil {
		fmt.Printf("Ошибка чтения байта: %v\n", err)
		return
	}

	if b >= '0' && b <= '9' {
		fmt.Printf("Символ '%c' (код %d) — это ЦИФРА.\n", b, b)
	} else {
		fmt.Printf("Символ '%c' (код %d) — НЕ цифра.\n", b, b)
	}
}
```

ℹ️ Побайтовое чтение через bufio.Reader

**`Терминал`**

```bash
go run main.go
# Введите один символ: 7
# Символ '7' (код 55) — это ЦИФРА.
```

ℹ️ Проверка символа

## Под капотом

Буферизация минимизирует количество контекст-свитчей в ядро Linux. Чтение 1000 байт по одному через небуферизованный `os.Stdin.Read` вызовет 1000 системных вызовов `sys_read`, тогда как `bufio.Reader` выполнит всего один вызов ядра.

## Подводные камни

- В UTF-8 кириллические символы (например, 'Я') занимают 2 байта. Попытка прочитать русский символ через `ReadByte()` прочитает только первый байт UTF-8 префикса (`0xD0`/`0xD1`). Для Unicode используют `ReadRune()`.

## На собеседовании

**Вопрос с собеседования:** «Как устроен буфер в `bufio.NewReader` и каков его размер по умолчанию?»
**Ответ:** По умолчанию размер внутреннего среза `buf` составляет 4096 байт (`defaultBufSize = 4096`). Если требуется другой размер (например, для чтения 64 КБ сетевых пакетов), используется `bufio.NewReaderSize(rd, 65536)`.
