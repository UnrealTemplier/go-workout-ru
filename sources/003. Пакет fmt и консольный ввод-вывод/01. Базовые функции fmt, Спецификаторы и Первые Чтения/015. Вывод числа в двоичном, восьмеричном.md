# Вывод числа в двоичном, восьмеричном и шестнадцатеричном форматах

## Условие

Используйте `fmt.Printf` для вывода целого числа в двоичном, восьмеричном и шестнадцатеричном форматах.

## Теория

Закрепляем вывод систем счисления:
- `%b` — двоичный вид (binary);
- `%o` — восьмеричный вид (octal);
- `%x` — шестнадцатеричный вид в нижнем регистре (hex lowercase);
- `%X` — шестнадцатеричный вид в верхнем регистре (hex uppercase).

## Решение по шагам

1. Задаем число, например `12345`.
2. Выводим его во всех четырех форматах в красивой таблице.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	value := 12345

	fmt.Printf("Десятичное (Dec): %12d\n", value)
	fmt.Printf("Двоичное (Bin):   %12b\n", value)
	fmt.Printf("Восьмеричное (Oct): %10o\n", value)
	fmt.Printf("HEX (строчные):   %12x\n", value)
	fmt.Printf("HEX (прописные):  %12X\n", value)
}
```

ℹ️ Форматирование систем счисления

**`Терминал`**

```bash
go run main.go
# Десятичное (Dec):        12345
# Двоичное (Bin):   11000000111001
# Восьмеричное (Oct):      30071
# HEX (строчные):           3039
# HEX (прописные):          3039
```

ℹ️ Результат форматирования

## Под капотом

Все алгоритмы перевода систем счисления в `strconv` используют битовые маски: для двоичной — сдвиг на 1 бит (`>> 1`), для восьмеричной — маска `0b111` и сдвиг на 3 бита, для шестнадцатеричной — маска `0b1111` и сдвиг на 4 бита.

## Подводные камни

- Путаница между восьмеричным числовым литералом (`0755` в коде) и строковым представлением. Начиная с Go 1.13 рекомендуется писать литералы с префиксом `0o755` и `0b1011`.

## На собеседовании

**Вопрос с собеседования:** «Как вывести шестнадцатеричный дамп байтового среза (Hex Dump) аналогично утилите `hexdump -C`?»
**Ответ:** С помощью пакета `encoding/hex`: `fmt.Println(hex.Dump(data))` или глагола `fmt.Printf("% x", data)` (с пробелами между байтами).
