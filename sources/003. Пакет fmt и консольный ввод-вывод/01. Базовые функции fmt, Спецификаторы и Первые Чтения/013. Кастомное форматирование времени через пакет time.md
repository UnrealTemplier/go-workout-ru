# Кастомное форматирование времени через пакет time и fmt.Printf

## Условие

Выведите текущее время в кастомном формате с помощью `fmt.Printf` и пакета `time`.

## Теория

**Уникальная особенность Go:**
В отличие от языков C, Python или Java (где используются абстрактные коды `%Y-%m-%d %H:%M:%S`), в Go шаблон форматирования времени задается через **эталонную константную дату Mon Jan 2 15:04:05 MST 2006**:
- Месяц: `01`
- День: `02`
- Час: `15` (или `03` для 12-часового формата)
- Минута: `04`
- Секунда: `05`
- Год: `2006`
- Временная зона: `-0700` или `MST`

## Решение по шагам

1. Получаем текущее время: `now := time.Now()`.
2. Вызываем метод `now.Format("2006-01-02 15:04:05")`.
3. Печатаем через `fmt.Printf`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	now := time.Now()

	// 1. Стандартный ISO 8601 / RFC3339
	fmt.Printf("RFC3339:   %s\n", now.Format(time.RFC3339))

	// 2. Пользовательский формат даты и времени
	custom := now.Format("02.01.2006 15:04:05")
	fmt.Printf("Кастомный: %s\n", custom)

	// 3. Формат для логов с миллисекундами
	logFormat := now.Format("2006/01/02 15:04:05.000")
	fmt.Printf("Лог-тайм:  %s\n", logFormat)
}
```

ℹ️ Форматирование времени в Go

**`Терминал`**

```bash
go run main.go
# RFC3339:   2026-09-02T14:15:30+03:00
# Кастомный: 02.09.2026 14:15:30
# Лог-тайм:  2026/09/02 14:15:30.452
```

ℹ️ Вывод времени

## Под капотом

Рантайм Go парсит шаблон по ключевым числовым маркерам: 1 (месяц), 2 (день), 3 (час), 4 (минута), 5 (секунда), 6 (год). Это позволяет компилятору быстро сопоставлять шаблон без разбора регулярок.

## Подводные камни

- Попытка написать `now.Format("YYYY-MM-DD")`: Go буквально напечатает буквы `YYYY-MM-DD` вместо года и месяца! Всегда используйте числа `2006-01-02`.

## На собеседовании

**Вопрос с собеседования:** «Почему для парсинга и форматирования времени в Go была выбрана дата 1 2 3 4 5 6 7?»
**Ответ:** Это мнемонический ряд: 1 (Jan), 2 (день), 3 (PM час), 4 (минута), 5 (секунда), 6 (2006 год), 7 (зона -0700). Запомнив ряд 1-2-3-4-5-6-7, инженер может составить любой шаблон без обращения к документации.
