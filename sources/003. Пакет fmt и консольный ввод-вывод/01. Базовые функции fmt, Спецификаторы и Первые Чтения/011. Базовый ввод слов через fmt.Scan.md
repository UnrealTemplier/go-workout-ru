# Базовый ввод слов через fmt.Scan

## Условие

**Базовый ввод слов**: Напишите программу, которая запрашивает у пользователя имя (одно слово) через `fmt.Scan` и здоровается с ним.

## Теория

При считывании в строковую переменную `var name string` функция `fmt.Scan(&name)`:
1. Пропускает любые ведущие пробелы и символы перевода строк;
2. Читает непрерывную последовательность непробельных символов;
3. Останавливается при первом же пробеле, табуляции или Enter.

## Решение по шагам

1. Объявляем `var name string`.
2. Запрашиваем ввод: `fmt.Scan(&name)`.
3. Выводим приветствие.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var name string
	fmt.Print("Введите ваше имя: ")

	_, err := fmt.Scan(&name)
	if err != nil {
		fmt.Printf("Ошибка чтения: %v\n", err)
		return
	}

	fmt.Printf("Привет, %s! Добро пожаловать в мир Go.\n", name)
}
```

ℹ️ Считывание одного слова

**`Терминал`**

```bash
go run main.go
# Введите ваше имя: Александр
# Привет, Александр! Добро пожаловать в мир Go.
```

ℹ️ Запуск программы

## Под капотом

Сканер Go парсит поток `io.RuneReader` и сохраняет символы в буфер, после чего создает строку `string` из накопленного среза байт UTF-8.

## Подводные камни

- Если пользователь введет имя и фамилию ("Илон Маск"), переменная `name` получит только "Илон", а слово "Маск" останется в буфере потока ввода.

## На собеседовании

**Вопрос с собеседования:** «Является ли `fmt.Scan` потокобезопасным при параллельном вызове из нескольких горутин?»
**Ответ:** Нет! Все функции `fmt.Scan*` работают с общим глобальным ресурсом `os.Stdin` без мьютексов. Параллельное чтение из нескольких горутин приведет к состоянию гонки за дескриптор ввода и перемешиванию прочитанных байт.
