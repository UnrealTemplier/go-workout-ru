# Рекурсивный расчет суммарного размера директории через filepath.WalkDir

## Условие

Напишите утилиту, которая принимает путь к папке и выводит суммарный размер всех файлов внутри неё, рекурсивно обходя подпапки.

## Теория

`filepath.WalkDir` обходит все вложенные элементы. Метод `d.Info()` запрашивает метаданные файла, из которых извлекается точный размер `info.Size()`.

## Решение по шагам

1. Создадим дерево каталогов с файлами разного размера.
2. Реализуем функцию `CalculateDirSize(path string) (int64, int, error)`.
3. Просуммируем `info.Size()` для всех файлов `!d.IsDir()`.
4. В `main` выведем суммарный размер и количество файлов.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io/fs"
	"log"
	"os"
	"path/filepath"
)

func CalculateDirSize(root string) (totalSize int64, fileCount int, err error) {
	err = filepath.WalkDir(root, func(path string, d fs.DirEntry, err error) error {
		if err != nil {
			return err
		}
		if !d.IsDir() {
			info, err := d.Info()
			if err != nil {
				return err
			}
			totalSize += info.Size()
			fileCount++
		}
		return nil
	})
	return totalSize, fileCount, err
}

func main() {
	root := "metrics_storage"
	_ = os.MkdirAll(root+"/node1/logs", 0755)
	_ = os.WriteFile(root+"/node1/logs/app.log", make([]byte, 1024), 0644) // 1024 B
	_ = os.WriteFile(root+"/summary.json", make([]byte, 512), 0644)        // 512 B

	size, count, err := CalculateDirSize(root)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Директория:       %s\n", root)
	fmt.Printf("Всего файлов:     %d\n", count)
	fmt.Printf("Суммарный размер: %d байт (%.2f KB)\n", size, float64(size)/1024)

	_ = os.RemoveAll(root)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Директория:       metrics_storage
# Всего файлов:     2
# Суммарный размер: 1536 байт (1.50 KB)
```

## Под капотом

`d.Info()` вызывает `stat` только для файлов, экономя системные вызовы для каталогов.

## Подводные камни

Учитывайте, что размер файлов на диске (Disk Usage) кратен размеру кластера файловой системы (обычно 4096 байт), поэтому 1-байтный файл занимает на диске 4KB.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие Apparent Size от Disk Usage (du)?»
**Ответ:** Apparent Size (`info.Size()`) — логический размер данных в байтах. Disk Usage — физический объем секторов на диске с учетом размера блоков и разреженных файлов (Sparse Files).
