# Бинарная сериализация структуры PlayerData в кодировке Little Endian

## Условие

**Бинарная запись**: Создайте структуру `PlayerData` с полями `ID uint32`, `Level uint16`, `Score float32`. Используя пакет `encoding/binary`, запишите эту структуру в файл `player.dat` в бинарном формате (в кодировке Little Endian).

## Теория

Бинарная сериализация структур с типами `uint32` (4B), `uint16` (2B) и `float32` (4B) упаковывает объект в компактный 10-байтный бинарный файл без форматирования строк.

## Решение по шагам

1. Объявим структуру `PlayerData struct { ID uint32; Level uint16; Score float32 }`.
2. Создадим файл `player.dat`.
3. Вызовем `binary.Write(file, binary.LittleEndian, player)`.
4. Проверим размер полученного файла на диске (ровно 10 байт).

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/binary"
	"fmt"
	"log"
	"os"
)

type PlayerData struct {
	ID    uint32  // 4 байта
	Level uint16  // 2 байта
	Score float32 // 4 байта
}

func main() {
	path := "player.dat"
	player := PlayerData{
		ID:    1048576,
		Level: 42,
		Score: 99.75,
	}

	file, err := os.Create(path)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	if err := binary.Write(file, binary.LittleEndian, player); err != nil {
		log.Fatalf("Ошибка бинарной записи: %v", err)
	}

	info, _ := file.Stat()
	fmt.Printf("Структура PlayerData успешно сохранена в %s\n", path)
	fmt.Printf("Размер бинарного файла на диске: %d байт (ровно 4+2+4)\n", info.Size())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Структура PlayerData успешно сохранена в player.dat
# Размер бинарного файла на диске: 10 байт (ровно 4+2+4)
```

## Под капотом

`binary.Write` упаковывает `float32` по стандарту IEEE 754 в виде 4 байт `math.Float32bits`.

## Подводные камни

В `binary.Write` запрещено передавать типы с динамической длиной (`string`, `[]byte`).

## На собеседовании

**Вопрос с собеседования:** «Почему размер структуры в файле (10 байт) может отличаться от размера в оперативной памяти unsafe.Sizeof?»
**Ответ:** Из-за выравнивания памяти процессора (Struct Memory Padding). В памяти 64-битной системы структура `PlayerData` может занимать 12 байт (2 байта паддинга после `Level`), но `binary.Write` упаковывает поля плотно без паддинга.
