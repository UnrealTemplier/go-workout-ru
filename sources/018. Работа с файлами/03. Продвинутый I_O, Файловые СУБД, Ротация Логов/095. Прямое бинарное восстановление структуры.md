# Прямое бинарное восстановление структуры PlayerData через binary.Read

## Условие

**Бинарное чтение**: Откройте файл `player.dat`. Считайте из него бинарные данные напрямую в новую структуру `PlayerData` с помощью `binary.Read`. Выведите поля структуры, чтобы убедиться в правильности восстановления.

## Теория

`binary.Read(r, binary.LittleEndian, &player)` вычитывает ровно необходимое количество байт из файла и декодирует их напрямую в поля структуры.

## Решение по шагам

1. Объявим структуру `PlayerData struct { ID uint32; Level uint16; Score float32 }`.
2. Запишем тестовый бинарный файл `player.dat`.
3. Откроем файл через `os.Open`.
4. Вызовем `binary.Read(f, binary.LittleEndian, &restored)`.
5. В `main` распечатаем восстановленные поля.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/binary"
	"fmt"
	"log"
	"os"
)

type PlayerData struct {
	ID    uint32
	Level uint16
	Score float32
}

func main() {
	path := "player.dat"

	// Подготовка данных
	_ = os.Remove(path)
	fOut, _ := os.Create(path)
	_ = binary.Write(fOut, binary.LittleEndian, PlayerData{ID: 777, Level: 99, Score: 1450.5})
	fOut.Close()

	// Бинарное чтение напрямую в структуру
	fIn, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer fIn.Close()

	var p PlayerData
	if err := binary.Read(fIn, binary.LittleEndian, &p); err != nil {
		log.Fatalf("Ошибка binary.Read: %v", err)
	}

	fmt.Println("Структура успешно восстановлена из бинарного файла:")
	fmt.Printf(" -> Player ID: %d\n", p.ID)
	fmt.Printf(" -> Level:     %d\n", p.Level)
	fmt.Printf(" -> Score:     %.1f\n", p.Score)

	_ = os.Remove(path)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Структура успешно восстановлена из бинарного файла:
#  -> Player ID: 777
#  -> Level:     99
#  -> Score:     1450.5
```

## Под капотом

`binary.Read` использует рефлексию для чтения байт в каждый адрес памяти структуры.

## Подводные камни

В `binary.Read` обязательно передавать указатель `&p`, иначе возникнет ошибка `binary.Read: non-pointer PlayerData`.

## На собеседовании

**Вопрос с собеседования:** «Как прочитать массив из 1000 структур PlayerData за один системный вызов?»
**Ответ:** Передать указатель на срез `players := make([]PlayerData, 1000); binary.Read(f, binary.LittleEndian, &players)`.
