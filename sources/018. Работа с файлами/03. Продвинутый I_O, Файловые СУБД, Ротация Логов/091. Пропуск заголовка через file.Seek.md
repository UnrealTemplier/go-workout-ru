# Пропуск заголовка через file.Seek и вычитка оставшегося тела файла

## Условие

**Управление курсором (Seek)**: Открой файл. Используй `file.Seek`, чтобы пропустить первые 10 байт, а затем считай остальные.

## Теория

Пропуск фиксированного заголовка (`file.Seek(10, io.SeekStart)`) используется при парсинге контейнерных форматов (RIFF WAV, MP4, custom binary frames).

## Решение по шагам

1. Создадим файл с 10-байтным заголовком и полезной нагрузкой.
2. Откроем файл через `os.Open`.
3. Сместим курсор на 10 байт вперед через `file.Seek`.
4. Вычитаем оставшиеся данные через `io.ReadAll`.
5. В `main` убедимся, что прочитана только полезная нагрузка.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"log"
	"os"
)

func main() {
	path := "frame.dat"
	// 10 байт заголовка "HEADER1234" + полезная нагрузка
	payload := "HEADER1234Body payload data string"
	_ = os.WriteFile(path, []byte(payload), 0644)

	file, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	// Пропускаем первые 10 байт заголовка
	offset, err := file.Seek(10, io.SeekStart)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("Курсор чтения установлен на смещение: %d байт\n", offset)

	body, err := io.ReadAll(file)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Прочитанное тело пакета: %q\n", string(body))
	_ = os.Remove(path)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Курсор чтения установлен на смещение: 10 байт
# Прочитанное тело пакета: "Body payload data string" 
```

## Под капотом

`file.Seek(10, io.SeekStart)` вызывает `lseek(fd, 10, SEEK_SET)`.

## Подводные камни

Если файл меньше 10 байт, `Seek` переместит курсор, но `io.ReadAll` вернет пустой срез и `EOF`.

## На собеседовании

**Вопрос с собеседования:** «Как пропустить N байт в объекте io.Reader без метода Seek (например, в сетевом сокете)?»
**Ответ:** Использовать `io.CopyN(io.Discard, reader, N)`. Байты будут вычитаны из потока и безопасно отброшены.
