# Валидация заголовка и сигнатуры PNG файла

## Условие

Напиши программу, которая читает заголовок PNG-файла (первые 8 байт — сигнатура `\x89PNG\r\n\x1a\n`). Проверь, что файл действительно PNG.

## Теория

Спецификация W3C PNG определяет строгую 8-байтную сигнатуру: `\x89 P N G \r \n \x1a \n` (`0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A`). Чтение ровно 8 байт через `io.ReadFull` позволяет валидировать формат файла.

## Решение по шагам

1. Зададим константу сигнатуры PNG.
2. Создадим валидный PNG заголовок.
3. Откроем файл и прочитаем первые 8 байт.
4. Сравним через `bytes.Equal(header, pngSignature)`.
5. В `main` выведем результат проверки.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"log"
	"os"
)

var pngHeader = []byte{0x89, 'P', 'N', 'G', 0x0D, 0x0A, 0x1A, 0x0A}

func isPNG(path string) (bool, error) {
	file, err := os.Open(path)
	if err != nil {
		return false, err
	}
	defer file.Close()

	buf := make([]byte, 8)
	if _, err := io.ReadFull(file, buf); err != nil {
		return false, err
	}

	return bytes.Equal(buf, pngHeader), nil
}

func main() {
	path := "image_test.png"
	_ = os.WriteFile(path, append(pngHeader, []byte("IHDR_CHUNK_DATA")...), 0644)

	valid, err := isPNG(path)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Файл %s является валидным PNG: %v\n", path, valid)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Файл image_test.png является валидным PNG: true
```

## Под капотом

Символы `\r\n\x1a\n` в сигнатуре PNG специально предназначены для обнаружения повреждений при ошибочной передаче файла в текстовом режиме FTP/DOS.

## Подводные камни

Используйте `io.ReadFull`, а не `file.Read`, чтобы гарантированно прочитать все 8 байт.

## На собеседовании

**Вопрос с собеседования:** «Зачем нужна io.ReadFull вместо file.Read?»
**Ответ:** `file.Read` может вернуть меньше запрошенного числа байт. `io.ReadFull` гарантирует точное чтение всего переданного среза или возвращает ошибку `io.ErrUnexpectedEOF`.
