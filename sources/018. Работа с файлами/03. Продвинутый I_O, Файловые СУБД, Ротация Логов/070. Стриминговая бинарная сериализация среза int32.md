# Стриминговая бинарная сериализация среза int32 в LittleEndian

## Условие

Напиши программу, которая записывает слайс `[]int32` в бинарный файл. Используй `encoding/binary.Write` с порядком байт `binary.LittleEndian`. Прочитай обратно и проверь.

## Теория

`binary.Write(w, binary.LittleEndian, slice)` записывает весь срез целиком за один системный вызов, сохраняя по 4 байта на каждый элемент.

## Решение по шагам

1. Создадим срез `values := []int32{42, 1024, -999, 1337}`.
2. Откроем файл `int32_data.bin` на запись.
3. Вызовем `binary.Write`.
4. Откроем на чтение и вычитаем срез через `binary.Read`.
5. В `main` убедимся в совпадении данных.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/binary"
	"fmt"
	"log"
	"os"
)

func main() {
	filename := "int32_data.bin"
	original := []int32{42, 1024, -999, 1337, 987654}

	// 1. Запись в бинарный файл
	fOut, err := os.Create(filename)
	if err != nil {
		log.Fatal(err)
	}
	if err := binary.Write(fOut, binary.LittleEndian, original); err != nil {
		fOut.Close()
		log.Fatal(err)
	}
	fOut.Close()

	// 2. Чтение из бинарного файла
	fIn, err := os.Open(filename)
	if err != nil {
		log.Fatal(err)
	}
	defer fIn.Close()

	restored := make([]int32, len(original))
	if err := binary.Read(fIn, binary.LittleEndian, &restored); err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Исходный массив:      %v\n", original)
	fmt.Printf("Прочитанный массив:   %v\n", restored)

	_ = os.Remove(filename)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Исходный массив:      [42 1024 -999 1337 987654]
# Прочитанный массив:   [42 1024 -999 1337 987654]
```

## Под капотом

`binary.Write` вычисляет размер среза через `reflect` и копирует память напрямую в дескриптор.

## Подводные камни

Длина среза `restored` должна быть заранее инициализирована нужным количеством элементов `make([]int32, N)`.

## На собеседовании

**Вопрос с собеседования:** «Как прочитать бинарный файл, если количество int32 чисел заранее неизвестно?»
**Ответ:** Узнать размер файла через `stat.Size()`, вычислить количество элементов `count := stat.Size() / 4` и аллоцировать срез `make([]int32, count)`.
