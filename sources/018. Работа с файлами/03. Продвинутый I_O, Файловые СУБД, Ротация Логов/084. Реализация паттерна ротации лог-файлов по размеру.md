# Реализация паттерна ротации лог-файлов по размеру

## Условие

Напиши программу, которая реализует лог-файл с ротацией: при достижении размера 1MB — переименовывает текущий файл в `log.1`, `log.2` и т.д., и создаёт новый.

## Теория

Ротация логов предотвращает переполнение диска. При превышении лимита размера текущий файл атомарно переименовывается (`os.Rename`), а для записи открывается новый чистый дескриптор.

## Решение по шагам

1. Реализуем структуру `RotatingLogger`.
2. В методе `Write(msg string)` проверяем текущий размер через `file.Stat()`.
3. Если `size >= maxSize` — вызываем `rotate()`.
4. В `main` запишем данные и проверим ротацию.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

type RotatingLogger struct {
	basePath string
	maxBytes int64
	file     *os.File
	count    int
}

func NewRotatingLogger(basePath string, maxBytes int64) (*RotatingLogger, error) {
	f, err := os.OpenFile(basePath, os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0644)
	if err != nil {
		return nil, err
	}
	return &RotatingLogger{basePath: basePath, maxBytes: maxBytes, file: f}, nil
}

func (l *RotatingLogger) rotate() error {
	l.file.Close()
	l.count++
	backupPath := fmt.Sprintf("%s.%d", l.basePath, l.count)

	if err := os.Rename(l.basePath, backupPath); err != nil {
		return err
	}

	fmt.Printf("[ROTATION] Файл ротирован в %s\n", backupPath)

	f, err := os.OpenFile(l.basePath, os.O_CREATE|os.O_WRONLY|os.O_TRUNC, 0644)
	if err != nil {
		return err
	}
	l.file = f
	return nil
}

func (l *RotatingLogger) Log(msg string) error {
	info, err := l.file.Stat()
	if err != nil {
		return err
	}
	if info.Size() >= l.maxBytes {
		if err := l.rotate(); err != nil {
			return err
		}
	}
	_, err = l.file.WriteString(msg + "\n")
	return err
}

func (l *RotatingLogger) Close() error {
	return l.file.Close()
}

func main() {
	base := "app_rot.log"
	// Лимит 40 байт для демонстрации
	logger, err := NewRotatingLogger(base, 40)
	if err != nil {
		log.Fatal(err)
	}
	defer logger.Close()

	_ = logger.Log("Line 1: Server initialized")
	_ = logger.Log("Line 2: Heavy database query completed")
	_ = logger.Log("Line 3: Cache cleared")

	// Очистка
	_ = os.Remove(base)
	_ = os.Remove(base + ".1")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [ROTATION] Файл ротирован в app_rot.log.1
```

## Под капотом

`os.Rename` в пределах одной файловой системы атомарен и выполняется за \(O(1)\) без копирования байтов.

## Подводные камни

В production-коде для ротации логов используют проверенный пакет `gopkg.in/natefinch/lumberjack.v2`.

## На собеседовании

**Вопрос с собеседования:** «Почему os.Rename атомарен в Linux?»
**Ответ:** Системный вызов `renameat2` просто обновляет запись указателя на `inode` в каталоге родительской директории без перемещения самих блоков данных на физическом носителе.
