# Создание глубокой структуры директорий data/logs/2026/07/ через os.MkdirAll

## Условие

**Создание вложенных директорий**: Используй `os.MkdirAll`, чтобы создать сложную структуру папок: `data/logs/2026/07/`.

## Теория

`os.MkdirAll` создает путь любой глубины в один вызов, устанавливая права доступа `0755` ко всем созданным подкаталогам.

## Решение по шагам

1. Зададим глубокий путь `data/logs/2026/07`.
2. Вызовем `os.MkdirAll(path, 0755)`.
3. Создадим тестовый файл внутри самой глубокой папки.
4. Проверим существование пути через `os.Stat`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
	"path/filepath"
)

func main() {
	targetDir := filepath.Join("data", "logs", "2026", "07")

	if err := os.MkdirAll(targetDir, 0755); err != nil {
		log.Fatalf("Ошибка MkdirAll: %v", err)
	}

	testFile := filepath.Join(targetDir, "access.log")
	_ = os.WriteFile(testFile, []byte("Log payload 2026"), 0644)

	info, err := os.Stat(testFile)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Успешно создана структура папок: %s\n", targetDir)
	fmt.Printf("Файл внутри доступен: %s (%d байт)\n", testFile, info.Size())

	_ = os.RemoveAll("data")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Успешно создана структура папок: data/logs/2026/07
# Файл внутри доступен: data/logs/2026/07/access.log (16 байт)
```

## Под капотом

`os.MkdirAll` использует системный вызов `mkdir` для каждого отсутствующего сегмента пути.

## Подводные камни

Убедитесь, что у процесса есть права на запись во все родительские директории.

## На собеседовании

**Вопрос с собеседования:** «Что произойдет, если в пути MkdirAll один из промежуточных элементов уже существует как обычный файл, а не папка?»
**Ответ:** `os.MkdirAll` вернет ошибку `syscall.ENOTDIR` (not a directory), так как нельзя создать директорию внутри существующего файла.
