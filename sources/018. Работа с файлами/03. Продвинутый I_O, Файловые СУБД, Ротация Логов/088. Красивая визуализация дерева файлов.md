# Красивая визуализация дерева файлов и каталогов с отступами

## Условие

Напиши программу, которая рекурсивно обходит директорию (`filepath.Walk` или `filepath.WalkDir`). Выведи дерево файлов и папок с отступами.

## Теория

Иерархический вывод вычисляет уровень вложенности на основе количества разделителей `filepath.Separator` в относительном пути от корня.

## Решение по шагам

1. Создадим тестовую структуру директорий.
2. Реализуем обход через `filepath.WalkDir`.
3. Вычислим относительный путь через `filepath.Rel(root, path)`.
4. Сформируем визуальный отступ `strings.Repeat("  ", depth)`.
5. В `main` выведем дерево.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io/fs"
	"log"
	"os"
	"path/filepath"
	"strings"
)

func PrintTree(root string) error {
	return filepath.WalkDir(root, func(path string, d fs.DirEntry, err error) error {
		if err != nil {
			return err
		}
		if path == root {
			fmt.Printf("📦 %s/\n", root)
			return nil
		}

		rel, _ := filepath.Rel(root, path)
		depth := strings.Count(rel, string(filepath.Separator))
		indent := strings.Repeat("  ", depth)

		if d.IsDir() {
			fmt.Printf("%s📁 %s/\n", indent, d.Name())
		} else {
			fmt.Printf("%s📄 %s\n", indent, d.Name())
		}
		return nil
	})
}

func main() {
	root := "sample_app"
	_ = os.MkdirAll(root+"/api/v1", 0755)
	_ = os.MkdirAll(root+"/configs", 0755)
	_ = os.WriteFile(root+"/main.go", []byte("package main"), 0644)
	_ = os.WriteFile(root+"/api/v1/router.go", []byte("package v1"), 0644)
	_ = os.WriteFile(root+"/configs/app.yaml", []byte("env: prod"), 0644)

	defer os.RemoveAll(root)

	if err := PrintTree(root); err != nil {
		log.Fatal(err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# 📦 sample_app/
# 📁 api/
#   📁 v1/
#     📄 router.go
# 📁 configs/
#   📄 app.yaml
# 📄 main.go
```

## Под капотом

`filepath.WalkDir` гарантирует обход каталогов в лексикографическом порядке.

## Подводные камни

Для исключения скрытых файлов добавьте проверку `if strings.HasPrefix(d.Name(), ".") { return nil }`.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать утилиту tree на чистом Go?»
**Ответ:** Использовать `filepath.WalkDir` с форматированием префиксов `├── ` и `└── ` на основе проверки последнего элемента в каталоге через `os.ReadDir`.
