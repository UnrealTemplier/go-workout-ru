# Поиск файлов по расширению и подсчет их суммарного размера

## Условие

Напиши программу, которая находит все файлы с определённым расширением в директории и поддиректориях. Подсчитай их общий размер.

## Теория

Фильтрация по расширению `filepath.Ext(path) == targetExt` в сочетании с `d.Info()` позволяет агрегировать статистику файлов заданного типа (например, размер всех `.log` файлов).

## Решение по шагам

1. Создадим дерево файлов с расширениями `.log`, `.txt`, `.csv`.
2. Реализуем функцию `FindAndSumBySize(root, ext string) (int64, []string, error)`.
3. В `main` выведем список найденных файлов и их суммарный размер.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io/fs"
	"log"
	"os"
	"path/filepath"
)

func FindAndSumBySize(root, ext string) (int64, []string, error) {
	var totalSize int64
	var matches []string

	err := filepath.WalkDir(root, func(path string, d fs.DirEntry, err error) error {
		if err != nil {
			return err
		}
		if !d.IsDir() && filepath.Ext(path) == ext {
			info, err := d.Info()
			if err != nil {
				return err
			}
			totalSize += info.Size()
			matches = append(matches, path)
		}
		return nil
	})

	return totalSize, matches, err
}

func main() {
	root := "log_archive"
	_ = os.MkdirAll(root+"/server1", 0755)
	_ = os.WriteFile(root+"/system.log", make([]byte, 2048), 0644)
	_ = os.WriteFile(root+"/server1/app.log", make([]byte, 4096), 0644)
	_ = os.WriteFile(root+"/server1/readme.md", []byte("docs"), 0644)

	defer os.RemoveAll(root)

	size, files, err := FindAndSumBySize(root, ".log")
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Найдено .log файлов: %d\n", len(files))
	for _, f := range files {
		fmt.Printf(" -> %s\n", f)
	}
	fmt.Printf("Суммарный объем: %d байт (%.2f KB)\n", size, float64(size)/1024)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Найдено .log файлов: 2
#  -> log_archive/server1/app.log
#  -> log_archive/system.log
# Суммарный объем: 6144 байт (6.00 KB)
```

## Под капотом

`filepath.Ext` возвращает расширение с ведущей точкой (например, `".log"`).

## Подводные камни

Сравнение расширений чувствительно к регистру в Linux (`.LOG` != `.log`). Для надежности используйте `strings.ToLower(filepath.Ext(path))`.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать поиск по сложным glob паттернам (например *.2026-*.log)?»
**Ответ:** Использовать функцию `filepath.Match(pattern, d.Name())` внутри `filepath.WalkDir`.
