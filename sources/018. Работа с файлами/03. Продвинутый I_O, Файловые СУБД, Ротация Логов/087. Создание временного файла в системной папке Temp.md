# Создание временного файла в системной папке Temp через os.CreateTemp

## Условие

Временно создай файл в системной папке для временных файлов с помощью `os.CreateTemp`.

## Теория

Передача пустой строки `""` в первый аргумент `os.CreateTemp("", "pattern-*.ext")` автоматически выбирает системный каталог временных файлов (`os.TempDir()`, обычно `/tmp` в Linux и `%TEMP%` в Windows).

## Решение по шагам

1. Вызовем `tmpFile, err := os.CreateTemp("", "session-*.tmp")`.
2. Установим `defer os.Remove(tmpFile.Name())` и `defer tmpFile.Close()`.
3. Запишем временные данные.
4. Выведем путь к файлу.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	// Пустая строка dir означает системную директорию os.TempDir()
	tmpFile, err := os.CreateTemp("", "session-payload-*.tmp")
	if err != nil {
		log.Fatal(err)
	}
	defer os.Remove(tmpFile.Name())
	defer tmpFile.Close()

	fmt.Printf("Временный файл создан в системной папке: %s\n", tmpFile.Name())

	if _, err := tmpFile.WriteString("Encrypted auth token"); err != nil {
		log.Fatal(err)
	}

	data, _ := os.ReadFile(tmpFile.Name())
	fmt.Printf("Прочитано из временного файла: %s\n", string(data))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Временный файл создан в системной папке: /tmp/session-payload-2983719284.tmp
# Прочитано из временного файла: Encrypted auth token
```

## Под капотом

`os.TempDir()` проверяет переменные окружения `$TMPDIR`, `$TMP`, `$TEMP`, `$USERPROFILE`, а в Unix возвращает `/tmp`.

## Подводные камни

В Linux `/tmp` часто монтируется как `tmpfs` в оперативной памяти (RAM). Запись гигантских файлов в `/tmp` может переполнить RAM.

## На собеседовании

**Вопрос с собеседования:** «Почему создание временного файла в /tmp безопасно от коллизий имен (Race Condition)?»
**Ответ:** `os.CreateTemp` открывает файл с флагами `O_RDWR|O_CREATE|O_EXCL` и правами `0600`. Флаг `O_EXCL` на уровне ядра гарантирует атомарный отказ, если файл с таким именем уже существует, повторяя генерацию случайного имени.
