# Модификация середины файла в режиме os.O_RDWR без перезаписи

## Условие

**[Каверзный кейс]**: Открой файл для чтения и записи одновременно `os.O_RDWR`. Запиши что-то в середину файла, не затирая его полностью (используй `Seek`).

## Теория

Режим `os.O_RDWR` позволяет одновременно читать и записывать в произвольные участки файла через перемещение курсора `file.Seek`.

## Решение по шагам

1. Создадим файл `[1234567890]`.
2. Откроем в режиме `os.O_RDWR`.
3. Сместим курсор на позицию 4: `file.Seek(4, io.SeekStart)`.
4. Запишем строку `"XXXX"`.
5. В `main` убедимся, что остальная часть файла не пострадала.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"log"
	"os"
)

func main() {
	path := "in_place_edit.txt"
	_ = os.WriteFile(path, []byte("0123456789ABCDEF"), 0644)

	// Открываем на чтение и запись одновременно
	file, err := os.OpenFile(path, os.O_RDWR, 0644)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	// Смещаем курсор на позицию 5 (символ '5')
	if _, err := file.Seek(5, io.SeekStart); err != nil {
		log.Fatal(err)
	}

	// Записываем 4 символа поверх существующих
	if _, err := file.WriteString("XXXX"); err != nil {
		log.Fatal(err)
	}

	// Читаем файл с начала
	data, _ := os.ReadFile(path)
	fmt.Printf("Исходный файл: 0123456789ABCDEF\n")
	fmt.Printf("Результат:     %s\n", string(data))

	_ = os.Remove(path)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Исходный файл: 0123456789ABCDEF
# Результат:     01234XXXX9ABCDEF
```

## Под капотом

Запись в режиме `O_RDWR` перезаписывает только байты по текущему смещению курсора, сохраняя все последующие байты файла.

## Подводные камни

Не используйте флаг `os.O_TRUNC`, иначе файл будет очищен при открытии.

## На собеседовании

**Вопрос с собеседования:** «Как работают embedded key-value базы вроде BoltDB / bbolt?»
**Ответ:** Они открывают файл БД в режиме `O_RDWR` и отображают его в память через `mmap` (Memory-Mapped File). Запись страниц B+ дерева выполняется напрямую по вычисленным смещениям на диске.
