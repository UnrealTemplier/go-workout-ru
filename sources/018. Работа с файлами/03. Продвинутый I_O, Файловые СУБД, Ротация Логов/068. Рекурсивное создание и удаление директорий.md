# Рекурсивное создание и удаление директорий: os.MkdirAll и os.RemoveAll

## Условие

Создайте вложенную структуру папок с помощью `os.MkdirAll` и удалите её рекурсивно с помощью `os.RemoveAll`.

## Теория

`os.MkdirAll` создает дерево каталогов. `os.RemoveAll(path)` рекурсивно удаляет весь каталог со всеми подпапками и файлами внутри (аналог команды `rm -rf`).

## Решение по шагам

1. Создадим дерево `sandbox/a/b/c`.
2. Запишем файл внутри `sandbox/a/b/c/data.txt`.
3. Проверим существование.
4. Вызовем `os.RemoveAll("sandbox")`.
5. Убедимся в полной очистке.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	deepPath := "sandbox/a/b/c"

	// 1. Создание дерева
	if err := os.MkdirAll(deepPath, 0755); err != nil {
		log.Fatal(err)
	}
	_ = os.WriteFile(deepPath+"/data.txt", []byte("Temporary build artifact"), 0644)
	fmt.Printf("Создано дерево каталогов: %s/\n", deepPath)

	// 2. Рекурсивное удаление (rm -rf)
	if err := os.RemoveAll("sandbox"); err != nil {
		log.Fatalf("Ошибка RemoveAll: %v", err)
	}
	fmt.Println("Вся структура 'sandbox/' успешно и безопасно удалена")

	// 3. Проверка
	_, err := os.Stat("sandbox")
	fmt.Printf("Директория существует: %v\n", err == nil)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Создано дерево каталогов: sandbox/a/b/c/
# Вся структура 'sandbox/' успешно и безопасно удалена
# Директория существует: false
```

## Под капотом

`os.RemoveAll` обходит директорию снизу вверх (post-order traversal), удаляя файлы системным вызовом `unlink` и папки вызовом `rmdir`.

## Подводные камни

Будьте предельно осторожны с `os.RemoveAll`: если путь окажется пустым `""` или `"/"`, можно случайно удалить корневую файловую систему!

## На собеседовании

**Вопрос с собеседования:** «Что вернет os.RemoveAll, если переданного пути не существует?»
**Ответ:** `os.RemoveAll` вернет `nil` (без ошибки), так как его контракт гарантирует, что после вызова путь гарантированно отсутствует на диске.
