# Запись сырых бинарных данных int32 в формате LittleEndian

## Условие

**Запись бинарных данных**: Используй пакет `encoding/binary`. Создай слайс чисел типа `int32` и запиши их в файл как сырые байты в формате `LittleEndian` (`binary.Write`). Обрати внимание, что файл после этого нельзя нормально прочитать в обычном блокноте.

## Теория

Бинарный файл содержит машинные байты чисел. При открытии такого файла в текстовом редакторе байты отображаются как нечитаемые спецсимволы, так как они не являются печатными символами ASCII/UTF-8.

## Решение по шагам

1. Создадим срез `nums := []int32{0x00000041, 0x00000042, 0x00000043, 0x0000000A}`.
2. Запишем в `binary.bin` через `binary.Write(f, binary.LittleEndian, nums)`.
3. Прочитаем файл как строку и выведем шестнадцатеричный дамп.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/binary"
	"fmt"
	"log"
	"os"
)

func main() {
	path := "raw_numbers.bin"
	numbers := []int32{1, 256, 65536, 16777216}

	f, err := os.Create(path)
	if err != nil {
		log.Fatal(err)
	}
	defer f.Close()

	if err := binary.Write(f, binary.LittleEndian, numbers); err != nil {
		log.Fatal(err)
	}

	rawBytes, _ := os.ReadFile(path)
	fmt.Printf("Файл записан (%d байт). Шестнадцатеричный дамп:\n", len(rawBytes))
	for i, b := range rawBytes {
		fmt.Printf("%02X ", b)
		if (i+1)%4 == 0 {
			fmt.Print("| ")
		}
	}
	fmt.Println()

	_ = os.Remove(path)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Файл записан (16 байт). Шестнадцатеричный дамп:
# 01 00 00 00 | 00 01 00 00 | 00 00 01 00 | 00 00 00 01 |
```

## Под капотом

Число `256` (`0x00000100`) в Little Endian записывается как байты `00 01 00 00`.

## Подводные камни

Никогда не пытайтесь парсить бинарные файлы текстовым сканером `bufio.Scanner` — байт `0x0A` будет ошибочно воспринят как перевод строки `\n`.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество Protobuf/FlatBuffers перед сырым binary.Write?»
**Ответ:** Protobuf поддерживает эволюцию схемы данных (добавление новых полей без поломки старых версий) и сжатие чисел (Varint/ZigZag), уменьшая размер сообщений в разы.
