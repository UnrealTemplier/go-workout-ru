# Создание исполняемого Bash скрипта и установка прав 0755 через os.Chmod

## Условие

**Права доступа (Chmod)**: Создай скрипт (например, файл `script.sh` с текстом `echo "hello"`). Используй `os.Chmod`, чтобы выдать ему права на исполнение (`0755`).

## Теория

Для запуска скрипта в Unix файлу необходим бит `x` (Execution). Права `0755` (`rwxr-xr-x`) разрешают запуск скрипта всем пользователям системы.

## Решение по шагам

1. Создадим файл `script.sh` со строкой `#!/bin/bash\necho "Hello from Go generated script!"\n`.
2. Изменим права на `0755` через `os.Chmod`.
3. Запросим метаданные через `os.Stat` и выведем `info.Mode().Perm()`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	scriptPath := "runner.sh"
	scriptBody := "#!/bin/sh\necho 'Worker initialized successfully'\n"

	// 1. Создаем файл скрипта
	if err := os.WriteFile(scriptPath, []byte(scriptBody), 0644); err != nil {
		log.Fatal(err)
	}

	// 2. Делаем файл исполняемым (chmod 0755)
	if err := os.Chmod(scriptPath, 0755); err != nil {
		log.Fatal(err)
	}

	info, err := os.Stat(scriptPath)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Файл:  %s\n", scriptPath)
	fmt.Printf("Права: %v (%04o)\n", info.Mode().Perm(), info.Mode().Perm())
	fmt.Printf("Исполняемый (x-бит установлен): %v\n", info.Mode().Perm()&0111 != 0)

	_ = os.Remove(scriptPath)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Файл:  runner.sh
# Права: -rwxr-xr-x (0755)
# Исполняемый (x-бит установлен): true
```

## Под капотом

`os.Chmod` устанавливает биты `0100` (User X), `0010` (Group X), `0001` (Other X).

## Подводные камни

В Windows бит исполнения определяется расширением файла (`.exe`, `.bat`), а не правами chmod.

## На собеседовании

**Вопрос с собеседования:** «Как запустить сгенерированный скрипт напрямую из Go процесса?»
**Ответ:** Использовать пакет `os/exec`: `cmd := exec.Command("./runner.sh"); out, err := cmd.CombinedOutput()`.
