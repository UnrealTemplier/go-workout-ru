# Построчный подсчет ошибок ERROR в лог-файле

## Условие

Напиши функцию, которая читает лог-файл (текстовый) и возвращает количество строк, содержащих слово "ERROR".

## Теория

Построчный подсчет через `bufio.Scanner` и `strings.Contains` позволяет анализировать многогигабайтные лог-файлы с константной памятью \(O(1)\).

## Решение по шагам

1. Создадим лог-файл `system.log`.
2. Реализуем функцию `CountErrorLines(path string) (int, error)`.
3. В цикле сканирования проверим `strings.Contains(scanner.Text(), "ERROR")`.
4. В `main` выведем общее число сбоев.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"log"
	"os"
	"strings"
)

func CountErrorLines(path string) (int, error) {
	file, err := os.Open(path)
	if err != nil {
		return 0, err
	}
	defer file.Close()

	scanner := bufio.NewScanner(file)
	count := 0

	for scanner.Scan() {
		if strings.Contains(scanner.Text(), "ERROR") {
			count++
		}
	}

	return count, scanner.Err()
}

func main() {
	path := "app_events.log"
	payload := "INFO: app started\nERROR: db timeout\nWARN: high cpu\nERROR: disk full\nINFO: healthy"
	_ = os.WriteFile(path, []byte(payload), 0644)

	errCount, err := CountErrorLines(path)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Обнаружено строк с ошибками [ERROR]: %d\n", errCount)
	_ = os.Remove(path)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Обнаружено строк с ошибками [ERROR]: 2
```

## Под капотом

`strings.Contains` выполняет быстрый поиск байтовой последовательности `ERROR`.

## Подводные камни

Используйте `scanner.Bytes()` и `bytes.Contains(scanner.Bytes(), []byte("ERROR"))` для нулевых аллокаций памяти.

## На собеседовании

**Вопрос с собеседования:** «Как оптимизировать CountErrorLines для максимального throughput на NVMe SSD?»
**Ответ:** Использовать `bytes.Count(chunk, []byte("\nERROR"))` на блоках по 1MB или пакет `golang.org/x/sys/unix` с системным вызовом `mmap`.
