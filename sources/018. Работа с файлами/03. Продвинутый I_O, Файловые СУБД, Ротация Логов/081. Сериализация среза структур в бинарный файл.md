# Сериализация среза структур в бинарный файл через encoding/gob

## Условие

Создайте структуру `Record` и запишите слайс таких структур в бинарный файл с помощью пакета `encoding/gob`.

## Теория

`encoding/gob` поддерживает прямую сериализацию срезов структур `[]Record` без необходимости кодировать каждый элемент вручную.

## Решение по шагам

1. Объявим структуру `Record struct { ID int; Task string; Done bool }`.
2. Создадим срез записей `records`.
3. Сериализуем через `gob.NewEncoder(f).Encode(records)`.
4. Откроем файл и восстановим весь срез через `gob.NewDecoder(f).Decode(&restored)`.
5. В `main` распечатаем результат.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/gob"
	"fmt"
	"log"
	"os"
)

type TaskRecord struct {
	ID        int
	TaskTitle string
	IsDone    bool
}

func main() {
	path := "tasks.gob"
	original := []TaskRecord{
		{ID: 1, TaskTitle: "Design Database Schema", IsDone: true},
		{ID: 2, TaskTitle: "Implement JWT Middleware", IsDone: true},
		{ID: 3, TaskTitle: "Setup Kubernetes Cluster", IsDone: false},
	}

	// 1. Запись среза структур в gob
	outFile, err := os.Create(path)
	if err != nil {
		log.Fatal(err)
	}
	if err := gob.NewEncoder(outFile).Encode(original); err != nil {
		outFile.Close()
		log.Fatal(err)
	}
	outFile.Close()

	// 2. Чтение среза структур
	inFile, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer inFile.Close()

	var restored []TaskRecord
	if err := gob.NewDecoder(inFile).Decode(&restored); err != nil {
		log.Fatal(err)
	}

	fmt.Println("Восстановленный список задач из gob:")
	for _, t := range restored {
		fmt.Printf(" -> [%02d] (Done: %-5v) %s\n", t.ID, t.IsDone, t.TaskTitle)
	}

	_ = os.Remove(path)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Восстановленный список задач из gob:
#  -> [01] (Done: true ) Design Database Schema
#  -> [02] (Done: true ) Implement JWT Middleware
#  -> [03] (Done: false) Setup Kubernetes Cluster
```

## Под капотом

`gob.Encode` записывает длину среза в заголовок и сериализует элементы последовательно.

## Подводные камни

Если типы полей изменились между версиями программы, `gob.Decode` может вернуть ошибку несовместимости типов.

## На собеседовании

**Вопрос с собеседования:** «Нужно ли регистрировать типы через gob.Register?»
**Ответ:** Только при сериализации интерфейсов (например, когда поле структуры имеет тип `interface{}` или `any`), чтобы декодер знал конкретный тип за интерфейсом.
