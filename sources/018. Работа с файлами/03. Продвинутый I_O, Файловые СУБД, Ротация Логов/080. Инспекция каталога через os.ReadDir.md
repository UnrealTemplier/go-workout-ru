# Инспекция каталога через os.ReadDir: фильтрация файлов и подпапок

## Условие

**Работа с папками**: Используй `os.ReadDir`, чтобы получить список всех файлов и папок в текущей директории. Выведи их имена и укажи, кто из них является директорией (метод `IsDir()`).

## Теория

`os.ReadDir(path)` возвращает срез `[]fs.DirEntry`. Метод `entry.IsDir()` возвращает булевый флаг, позволяя разделить папки и обычные файлы без вызова `stat`.

## Решение по шагам

1. Создадим папку `explorer_demo`.
2. Добавим файлы и подпапки.
3. Прочитаем записи через `os.ReadDir`.
4. Выведем форматированный список с типами `[DIR]` и `[FILE]`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	path := "explorer_demo"
	_ = os.MkdirAll(path+"/subfolder", 0755)
	_ = os.WriteFile(path+"/data.csv", []byte("1,2,3"), 0644)
	_ = os.WriteFile(path+"/server.go", []byte("package main"), 0644)

	entries, err := os.ReadDir(path)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Каталог: %s/\n", path)
	for _, e := range entries {
		typeStr := "[FILE]"
		if e.IsDir() {
			typeStr = "[DIR ]"
		}
		fmt.Printf("%s %s\n", typeStr, e.Name())
	}

	_ = os.RemoveAll(path)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Каталог: explorer_demo/
# [FILE] data.csv
# [FILE] server.go
# [DIR ] subfolder
```

## Под капотом

Свойство `entry.IsDir()` вычисляется из `d_type` системного вызова `getdents64`.

## Подводные камни

`os.ReadDir` сортирует результаты лексикографически по имени файла.

## На собеседовании

**Вопрос с собеседования:** «Как определить, что DirEntry является симлинком?»
**Ответ:** Проверить битовую маску: `if e.Type()&fs.ModeSymlink != 0 { /* элемент является символической ссылкой */ }`.
