# Назначение временных файлов и гарантированная очистка через defer os.Remove

## Условие

Напиши программу, которая создаёт временный файл (`os.CreateTemp`), пишет в него, а затем автоматически удаляет (`defer os.Remove`). Объясни, зачем нужны временные файлы.

## Теория

Назначение временных файлов:
1. **Атомарная запись (Atomic Save):** запись во временный файл и последующий `os.Rename` исключают появление недописанных файлов при сбое.
2. **Изоляция параллельных тестов:** каждый тест работает со своим уникальным файлом.
3. **Разгрузка оперативной памяти (Offloading):** хранение многогигабайтных промежуточных результатов на диске.

## Решение по шагам

1. Создадим временный файл через `os.CreateTemp("", "analytics-*.tmp")`.
2. Установим `defer os.Remove(f.Name())`.
3. Запишем данные и закроем файл.
4. В `main` убедимся в удалении файла.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
	"log"
	"os"
)

func runOffloadedTask() {
	// Создаем временный файл в системной папке /tmp
	tmpFile, err := os.CreateTemp("", "bigdata-chunk-*.tmp")
	if err != nil {
		log.Fatal(err)
	}
	tmpName := tmpFile.Name()
	defer os.Remove(tmpName) // Удаление при выходе
	defer tmpFile.Close()    // Закрытие перед удалением

	fmt.Printf("[1] Создан временный буфер: %s\n", tmpName)

	// Запись промежуточного результата
	_, _ = tmpFile.WriteString("Large interim aggregated dataset")

	fmt.Println("[2] Промежуточные вычисления успешно выполнены")
}

func main() {
	runOffloadedTask()

	// Проверка, что файл удален
	fmt.Println("[3] Выход из функции: временный файл гарантированно удален с диска")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [1] Создан временный буфер: /tmp/bigdata-chunk-819284719.tmp
# [2] Промежуточные вычисления успешно выполнены
# [3] Выход из функции: временный файл гарантированно удален с диска
```

## Под капотом

`os.Remove` удаляет запись файла из директории ядра операционной системы.

## Подводные камни

Если программа завершится по сигналу `SIGKILL` (`kill -9`), `defer` не выполнится, и файл останется в `/tmp`. ОС периодически очищает `/tmp` через `systemd-tmpfiles`.

## На собеседовании

**Вопрос с собеседования:** «Выполняются ли defer-функции при os.Exit(1) или log.Fatal()?
**Ответ:** Нет! `os.Exit` немедленно завершает процесс через системный вызов `exit_group(2)`, минуя раскрутку стека и все зарегистрированные `defer` функции.
