# Реализация утилиты tail: чтение последних N байт через Seek(offset, io.SeekEnd)

## Условие

Напиши программу, которая читает файл с произвольной позиции (`os.File.Seek`). Реализуй "tail" — чтение последних N байт файла без загрузки всего файла в память.

## Теория

Утилита `tail` считывает последние байты лог-файла. Перемещение `file.Seek(-N, io.SeekEnd)` мгновенно ставит указатель чтения в конец файла за время \(O(1)\) без чтения предыдущих терабайт.

## Решение по шагам

1. Создадим большой файл лога.
2. Реализуем функцию `TailBytes(path string, n int64) ([]byte, error)`.
3. Запросим размер файла через `file.Stat()`.
4. Сместимся на `-n` от `io.SeekEnd`.
5. Вычитаем остаток файла и распечатаем.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"log"
	"os"
)

func TailBytes(path string, n int64) ([]byte, error) {
	file, err := os.Open(path)
	if err != nil {
		return nil, err
	}
	defer file.Close()

	info, err := file.Stat()
	if err != nil {
		return nil, err
	}

	size := info.Size()
	offset := int64(0)
	if size > n {
		offset = -n
	} else {
		offset = -size
	}

	// Смещение назад от конца файла
	if _, err := file.Seek(offset, io.SeekEnd); err != nil {
		return nil, err
	}

	return io.ReadAll(file)
}

func main() {
	path := "big_server.log"
	payload := "2026-09-02 12:00:00 Old Log Event\n2026-09-02 18:30:00 CRITICAL_PAYMENT_FAILURE_RETRY"
	_ = os.WriteFile(path, []byte(payload), 0644)

	tail, err := TailBytes(path, 40)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Println("--- Последние байты файла (tail) ---")
	fmt.Printf("%s\n", string(tail))

	_ = os.Remove(path)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- Последние байты файла (tail) ---
# 00 CRITICAL_PAYMENT_FAILURE_RETRY
```

## Под капотом

`file.Seek(-n, io.SeekEnd)` передает отрицательное смещение в системный вызов `lseek(fd, -n, SEEK_END)` ядра Linux.

## Подводные камни

Если размер файла меньше \(N\), смещение `-n` вернет ошибку `EINVAL: invalid argument`. Всегда проверяйте `size > n`.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать tail -f (слежение за файлом в реальном времени)?»
**Ответ:** Открыть файл, сделать `Seek(0, io.SeekEnd)`. В цикле читать `file.Read(buf)`. Если вернулся `io.EOF`, делать паузу `time.Sleep(100ms)` или слушать события файловой системы ядра через Linux `inotify` (пакет `fsnotify`).
