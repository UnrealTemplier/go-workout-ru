# Разбиение большого бинарного файла на чанки (Split) и сборка обратно (Merge)

## Условие

Напиши программу, которая разбивает большой бинарный файл на части (chunk'и) заданного размера (например, 1MB каждый). Затем напиши программу-сборщик, которая объединяет chunk'и обратно.

### Исходная формулировка

Напиши программу, которая разбивает большой бинарный файл на части (chunk'и) заданного размера (например, 1MB каждый). Затем напиши программу-сборщик, которая объединяет chunk'и обратно.

---

## Теория

Паттерн Chunking (нарезка на части) применяется в протоколах BitTorrent, S3 Multipart Upload и Telegram Bot API для надежной передачи больших файлов по нестабильной сети.

## Решение по шагам

1. Создадим тестовый файл `large_payload.dat`.
2. Реализуем функцию `SplitFile(path string, chunkSize int64) ([]string, error)`.
3. Реализуем функцию `MergeChunks(chunks []string, dst string) error`.
4. В `main` сверим размер и содержимое оригинала и собранного файла.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"log"
	"os"
)

func SplitFile(srcPath string, chunkSize int64) ([]string, error) {
	src, err := os.Open(srcPath)
	if err != nil {
		return nil, err
	}
	defer src.Close()

	var chunkFiles []string
	part := 1

	for {
		chunkName := fmt.Sprintf("%s.part%03d", srcPath, part)
		dst, err := os.Create(chunkName)
		if err != nil {
			return nil, err
		}

		// Копируем ровно chunkSize байт
		n, err := io.CopyN(dst, src, chunkSize)
		dst.Close()

		if n > 0 {
			chunkFiles = append(chunkFiles, chunkName)
			part++
		}
		if err == io.EOF {
			break
		}
		if err != nil {
			return nil, err
		}
	}
	return chunkFiles, nil
}

func MergeChunks(chunks []string, dstPath string) error {
	dst, err := os.Create(dstPath)
	if err != nil {
		return err
	}
	defer dst.Close()

	for _, chunk := range chunks {
		in, err := os.Open(chunk)
		if err != nil {
			return err
		}
		_, err = io.Copy(dst, in)
		in.Close()
		if err != nil {
			return err
		}
	}
	return nil
}

func main() {
	originalData := []byte("0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ_PAYLOAD_DATA")
	_ = os.WriteFile("source.dat", originalData, 0644)

	// Нарезка чанками по 16 байт
	chunks, err := SplitFile("source.dat", 16)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("Файл нарезан на %d чанков: %v\n", len(chunks), chunks)

	// Сборка обратно
	if err := MergeChunks(chunks, "restored.dat"); err != nil {
		log.Fatal(err)
	}

	restoredData, _ := os.ReadFile("restored.dat")
	fmt.Printf("Целостность сборки: %v\n", bytes.Equal(originalData, restoredData))

	// Очистка
	_ = os.Remove("source.dat")
	_ = os.Remove("restored.dat")
	for _, c := range chunks {
		_ = os.Remove(c)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Файл нарезан на 4 чанков: [source.dat.part001 source.dat.part002 source.dat.part003 source.dat.part004]
# Целостность сборки: true
```

## Под капотом

`io.CopyN(dst, src, n)` оборачивает источник в `io.LimitReader` и выполняет потоковое копирование ровно \(N\) байт.

## Подводные камни

Не забывайте закрывать дескрипторы каждого чанка перед открытием следующего.

## На собеседовании

**Вопрос с собеседования:** «Как работает S3 Multipart Upload?»
**Ответ:** Клиент разбивает файл на части \(\ge 5\)MB, параллельно загружает каждый чанк через `UploadPart` горутинами, и завершает вызовом `CompleteMultipartUpload`, где AWS S3 атомарно объединяет части в один объект на стороне хранилища.
