# Файловая база данных с фиксированным размером записей (CRUD)

## Условие

Напиши программу, которая реализует простую базу данных в файле: запись структур `Record { ID int; Name string; Score float64 }` с фиксированным размером записи. Реализуй CRUD: Create, Read, Update, Delete (soft delete).

## Теория

Файловые СУБД с фиксированным размером слота (Slot Size) позволяют вычислять точное смещение любой записи по формуле: \(\text{offset} = \text{slotID} \times \text{recordSize}\). Чтение и перезапись выполняются за \(O(1)\) через `file.Seek`.

## Решение по шагам

1. Объявим структуру `Record struct { ID int32; Name [24]byte; Score float64; IsDeleted bool }`.
2. Реализуем `WriteRecord(slot int, r Record)` через `file.Seek`.
3. Реализуем `ReadRecord(slot int)` через `file.Seek`.
4. Реализуем `SoftDelete(slot int)` через обновление флага `IsDeleted`.
5. В `main` покажем работу CRUD-операций.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"encoding/binary"
	"fmt"
	"log"
	"os"
)

type Record struct {
	ID        int32
	Name      [24]byte
	Score     float64
	IsDeleted bool
}

const recordSize = 37 // 4 + 24 + 8 + 1 байт

type DatabaseEngine struct {
	file *os.File
}

func NewDB(path string) (*DatabaseEngine, error) {
	f, err := os.OpenFile(path, os.O_RDWR|os.O_CREATE, 0644)
	if err != nil {
		return nil, err
	}
	return &DatabaseEngine{file: f}, nil
}

func (db *DatabaseEngine) Close() error {
	return db.file.Close()
}

func (db *DatabaseEngine) Write(slot int64, rec Record) error {
	offset := slot * recordSize
	if _, err := db.file.Seek(offset, ioSeekStart()); err != nil {
		return err
	}
	return binary.Write(db.file, binary.LittleEndian, rec)
}

func (db *DatabaseEngine) Read(slot int64) (Record, error) {
	offset := slot * recordSize
	var rec Record
	if _, err := db.file.Seek(offset, ioSeekStart()); err != nil {
		return rec, err
	}
	err := binary.Read(db.file, binary.LittleEndian, &rec)
	return rec, err
}

func ioSeekStart() int { return 0 }

func main() {
	dbPath := "mini_engine.db"
	db, err := NewDB(dbPath)
	if err != nil {
		log.Fatal(err)
	}
	defer func() {
		db.Close()
		_ = os.Remove(dbPath)
	}()

	// 1. Create: пишем в слот 0 и 1
	var name1 [24]byte
	copy(name1[:], "Alice")
	_ = db.Write(0, Record{ID: 101, Name: name1, Score: 98.5, IsDeleted: false})

	var name2 [24]byte
	copy(name2[:], "Bob")
	_ = db.Write(1, Record{ID: 102, Name: name2, Score: 85.0, IsDeleted: false})

	// 2. Read: прямое чтение слота 1 за O(1)
	rec, _ := db.Read(1)
	cleanName := string(bytes.TrimRight(rec.Name[:], "\x00"))
	fmt.Printf("[Read Slot 1] ID=%d, Name=%s, Score=%.1f\n", rec.ID, cleanName, rec.Score)

	// 3. Delete (Soft delete) слота 0:
	rec0, _ := db.Read(0)
	rec0.IsDeleted = true
	_ = db.Write(0, rec0)

	rec0Updated, _ := db.Read(0)
	fmt.Printf("[Read Slot 0] Deleted: %v\n", rec0Updated.IsDeleted)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Read Slot 1] ID=102, Name=Bob, Score=85.0
# [Read Slot 0] Deleted: true
```

## Под капотом

`file.Seek(slot * recordSize, io.SeekStart)` мгновенно смещает курсор в точную ячейку на диске без сканирования предыдущих записей.

## Подводные камни

Используйте строгие массивы `[24]byte` вместо срезов `[]byte`, иначе размер структуры будет варьироваться и сломает расчет смещения.

## На собеседовании

**Вопрос с собеседования:** «Как устроены файлы страниц в PostgreSQL / InnoDB?»
**Ответ:** Таблицы хранятся в виде страниц фиксированного размера (обычно 8KB или 16KB). В начале страницы находится заголовок (Page Header), а строки адресуются через массив смещений (Slot Array) в конце страницы.
