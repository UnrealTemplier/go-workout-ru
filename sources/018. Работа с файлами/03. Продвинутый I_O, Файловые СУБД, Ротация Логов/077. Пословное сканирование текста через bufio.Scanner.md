# Пословное сканирование текста через bufio.Scanner и bufio.ScanWords

## Условие

**Посимвольное или пословное чтение**: Используя `bufio.Scanner` и метод `scanner.Split(bufio.ScanWords)`, настройте сканер так, чтобы он читал файл не построчно, а слово за словом. Выведите каждое слово на новой строке.

## Теория

`scanner.Split(bufio.ScanWords)` переключает сканер в режим извлечения отдельных слов, автоматически пропуская любые пробельные символы (пробелы, табуляции, переводы строк).

## Решение по шагам

1. Создадим файл `words.txt`.
2. Откроем файл через `os.Open`.
3. Настроим `scanner.Split(bufio.ScanWords)`.
4. В цикле `for scanner.Scan()` выведем каждое слово.
5. Проверим `scanner.Err()`.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"log"
	"os"
)

func main() {
	path := "words.txt"
	_ = os.WriteFile(path, []byte("HighLoad   Golang \n Architecture \t Distributed\nSystems"), 0644)

	file, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	scanner := bufio.NewScanner(file)
	scanner.Split(bufio.ScanWords) // Настройка пословного режима

	wordIdx := 1
	for scanner.Scan() {
		fmt.Printf("Слово #%d: %s\n", wordIdx, scanner.Text())
		wordIdx++
	}

	if err := scanner.Err(); err != nil {
		log.Fatal(err)
	}

	_ = os.Remove(path)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Слово #1: HighLoad
# Слово #2: Golang
# Слово #3: Architecture
# Слово #4: Distributed
# Слово #5: Systems
```

## Под капотом

`bufio.ScanWords` использует функцию `unicode.IsSpace(r)` для пропуска последовательностей пробелов.

## Подводные камни

Знаки препинания (запятые, точки) не удаляются автоматически и остаются частью слова (например, `"word,"`).

## На собеседовании

**Вопрос с собеседования:** «Как построить частотный словарь слов (Word Count Map) из 10GB текста на Go?»
**Ответ:** Читать файл потоково через `bufio.Scanner` с `bufio.ScanWords` и инкрементировать счетчик в `map[string]int` (или использовать `scanner.Bytes()` с кастомным хеш-мапом без аллокаций).
