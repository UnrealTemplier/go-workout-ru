# Блочное чтение через bufio.NewReader порциями по 1024 байта

## Условие

Используй `bufio.NewReader` для чтения файла блоками по 1024 байта (через метод `Read`).

## Теория

`bufio.NewReader(f)` буферизует чтение из диска, объединяя системные вызовы ядра и предоставляя удобный метод `r.Read(buf)`.

## Решение по шагам

1. Создадим тестовый файл `dataset.bin`.
2. Обернем `os.Open` в `bufio.NewReader`.
3. В цикле прочитаем блоками по 1024 байта.
4. Проверим `io.EOF`.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"errors"
	"fmt"
	"io"
	"log"
	"os"
)

func main() {
	path := "dataset.bin"
	_ = os.WriteFile(path, make([]byte, 2500), 0644) // 2500 байт

	file, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	reader := bufio.NewReader(file)
	buf := make([]byte, 1024)
	totalRead := 0
	chunkNum := 1

	for {
		n, err := reader.Read(buf)
		if n > 0 {
			fmt.Printf("Чанк #%d: прочитано %d байт\n", chunkNum, n)
			totalRead += n
			chunkNum++
		}
		if err != nil {
			if errors.Is(err, io.EOF) {
				break
			}
			log.Fatal(err)
		}
	}

	fmt.Printf("Всего прочитано: %d байт\n", totalRead)
	_ = os.Remove(path)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Чанк #1: прочитано 1024 байт
# Чанк #2: прочитано 1024 байт
# Чанк #3: прочитано 452 байт
# Всего прочитано: 2500 байт
```

## Под капотом

`bufio.Reader` держит свой внутренний буфер 4096 байт и считывает данные из ОС крупными блоками.

## Подводные камни

Метод `reader.Read(buf)` может вернуть $n < len(buf)$ даже если файл еще не закончился.

## На собеседовании

**Вопрос с собеседования:** «Когда bufio.Reader читает напрямую в пользовательский буфер минуя внутренний кэш?»
**Ответ:** Если размер запрашиваемого буфера `len(buf)` больше или равен размеру внутреннего буфера `bufio.Reader` (по умолчанию 4KB), ридер оптимизирует системный вызов и читает напрямую в целевой слайс.
