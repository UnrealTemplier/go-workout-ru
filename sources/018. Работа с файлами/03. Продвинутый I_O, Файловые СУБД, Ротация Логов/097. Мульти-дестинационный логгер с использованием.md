# Мульти-дестинационный логгер с использованием io.MultiWriter

## Условие

Напиши программу, которая использует `io.MultiWriter` для одновременной записи в файл и в консоль. Напиши логгер, который пишет в несколько destination'ов.

## Теория

`io.MultiWriter(w1, w2, ...)` дублирует каждую операцию записи во все переданные приемники `io.Writer`. Это стандартный способ в Go для одновременной записи логов в консоль (`os.Stdout`) и в файл на диске.

## Решение по шагам

1. Создадим файл `app_multi.log`.
2. Создадим мульти-писатель `mw := io.MultiWriter(os.Stdout, logFile)`.
3. Настроим стандартный логгер `log.SetOutput(mw)`.
4. Запишем несколько логов и убедимся, что они появились в консоли и в файле.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"log"
	"os"
)

func main() {
	logFilePath := "app_multi.log"
	file, err := os.OpenFile(logFilePath, os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0644)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	// Объединяем stdout и файл в единый MultiWriter
	multiWriter := io.MultiWriter(os.Stdout, file)

	// Настраиваем стандартный логгер Go
	customLogger := log.New(multiWriter, "[AUDIT] ", log.Ldate|log.Ltime)

	customLogger.Println("Сервис успешно инициализирован")
	customLogger.Println("Подключение к брокеру Kafka установлено")

	fileData, _ := os.ReadFile(logFilePath)
	fmt.Printf("\n--- Проверка содержимого файла %s ---\n", logFilePath)
	fmt.Print(string(fileData))

	_ = os.Remove(logFilePath)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [AUDIT] 2026/09/02 18:30:00 Сервис успешно инициализирован
# [AUDIT] 2026/09/02 18:30:00 Подключение к брокеру Kafka установлено
# 
# --- Проверка содержимого файла app_multi.log ---
# [AUDIT] 2026/09/02 18:30:00 Сервис успешно инициализирован
# [AUDIT] 2026/09/02 18:30:00 Подключение к брокеру Kafka установлено
```

## Под капотом

`io.MultiWriter` последовательно вызывает метод `Write` у каждого писателя. Если один из них возвращает ошибку, запись прерывается.

## Подводные камни

Если один из приемников медленный (например, сетевой сокет), `io.MultiWriter` заблокирует запись и во все остальные приемники.

## На собеседовании

**Вопрос с собеседования:** «Как работает io.TeeReader?»
**Ответ:** `io.TeeReader(r, w)` при чтении из `r` автоматически дублирует прочитанные байты в `w` (аналог Unix-утилиты `tee`).
