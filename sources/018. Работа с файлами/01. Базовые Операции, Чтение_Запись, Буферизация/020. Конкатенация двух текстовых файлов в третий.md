# Конкатенация двух текстовых файлов в третий через io.Copy

## Условие

Слейте два текстовых файла в третий: откройте оба на чтение, третий на запись, копируйте последовательно.

## Теория

Слияние файлов (Concatenation) выполняется последовательным вызовом `io.Copy(merged, file1)` и `io.Copy(merged, file2)` без загрузки обоих файлов целиком в RAM.

## Решение по шагам

1. Создадим два файла: `part1.txt` и `part2.txt`.
2. Создадим файл-приемник `merged.txt`.
3. Скопируем первый файл через `io.Copy`.
4. Скопируем второй файл через `io.Copy`.
5. В `main` проверим объединенный результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"log"
	"os"
)

func mergeFiles(dst string, sources ...string) error {
	out, err := os.Create(dst)
	if err != nil {
		return err
	}
	defer out.Close()

	for _, srcPath := range sources {
		in, err := os.Open(srcPath)
		if err != nil {
			return err
		}
		_, copyErr := io.Copy(out, in)
		in.Close()
		if copyErr != nil {
			return copyErr
		}
	}
	return nil
}

func main() {
	_ = os.WriteFile("part1.txt", []byte("Section 1: Overview\n"), 0644)
	_ = os.WriteFile("part2.txt", []byte("Section 2: Architecture\n"), 0644)

	if err := mergeFiles("merged.txt", "part1.txt", "part2.txt"); err != nil {
		log.Fatal(err)
	}

	result, _ := os.ReadFile("merged.txt")
	fmt.Println("--- Merged Result ---")
	fmt.Print(string(result))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- Merged Result ---
# Section 1: Overview
# Section 2: Architecture
```

## Под капотом

Курсор файла `out` непрерывно сдвигается вперед, соединяя байты из двух потоков в один файл на диске.

## Подводные камни

Обязательно закрывайте входные файлы `in.Close()` внутри цикла, чтобы не накапливать открытые дескрипторы при слиянии сотен файлов.

## На собеседовании

**Вопрос с собеседования:** «Как объединить 1000 файлов по 100MB без использования гигабайт памяти?»
**Ответ:** Использовать стриминг через `io.Copy` в цикле. Память останется константной (\(O(1)\), около 32KB для буфера `io.Copy`) независимо от суммарного размера файлов.
