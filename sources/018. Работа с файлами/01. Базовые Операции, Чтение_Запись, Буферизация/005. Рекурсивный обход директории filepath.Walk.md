# Рекурсивный обход директории filepath.Walk и фильтрация .go файлов

## Условие

Рекурсивно обойдите директорию (`filepath.Walk`), выведите только файлы с расширением `.go`.

## Теория

Функция `filepath.Walk(root, walkFn)` рекурсивно обходит файловое дерево, вызывая коллбэк `WalkFunc` для каждого найденного файла и каталога.

## Решение по шагам

1. Зададим корневую директорию для поиска.
2. Вызовем `filepath.Walk`.
3. Внутри функции обратного вызова отфильтруем каталоги `if info.IsDir()`.
4. Проверим расширение через `filepath.Ext(path) == ".go"`.
5. Выведем путь к каждому найденному `.go` файлу.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
)

func main() {
	// Создаем структуру для демонстрации
	_ = os.MkdirAll("demo/pkg/sub", 0755)
	_ = os.WriteFile("demo/main.go", []byte("package main"), 0644)
	_ = os.WriteFile("demo/pkg/util.go", []byte("package pkg"), 0644)
	_ = os.WriteFile("demo/pkg/sub/sub.go", []byte("package sub"), 0644)
	_ = os.WriteFile("demo/readme.md", []byte("# Docs"), 0644)

	defer os.RemoveAll("demo")

	fmt.Println("Найденные .go файлы:")
	err := filepath.Walk("demo", func(path string, info fs.FileInfo, err error) error {
		if err != nil {
			return err
		}
		// Пропускаем директории
		if info.IsDir() {
			return nil
		}
		// Проверяем расширение
		if filepath.Ext(path) == ".go" {
			fmt.Printf(" -> %s (%d байт)\n", path, info.Size())
		}
		return nil
	})

	if err != nil {
		fmt.Printf("Ошибка обхода: %v\n", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Найденные .go файлы:
#  -> demo/main.go (12 байт)
#  -> demo/pkg/sub/sub.go (11 байт)
#  -> demo/pkg/util.go (11 байт)
```

## Под капотом

`filepath.Walk` вызывает `os.Lstat` для каждого файла в дереве каталогов. Начиная с Go 1.16 доступна более быстрая функция `filepath.WalkDir`, которая использует `fs.DirEntry` и избегает лишних вызовов `stat`.

## Подводные камни

Если внутри коллбэка вернуть `filepath.SkipDir` для директории, обходчик пропустит все файлы внутри этой папки.

## На собеседовании

**Вопрос с собеседования:** «Почему filepath.WalkDir быстрее filepath.Walk в Go 1.16+?»
**Ответ:** `filepath.Walk` на каждом шаге выполняет системный вызов `os.Lstat`, что на дисках с миллионами файлов создает миллионы IOPS. `filepath.WalkDir` берет тип файла напрямую из системного вызова `getdents64` (структура `DirEntry`), вызывая `Info()` только при явном запросе.
