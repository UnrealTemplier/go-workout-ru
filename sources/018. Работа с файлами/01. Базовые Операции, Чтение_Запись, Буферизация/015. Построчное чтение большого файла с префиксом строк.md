# Построчное чтение большого файла с префиксом строк

## Условие

**Построчное чтение (Scanner)**: Создайте большой текстовый файл с несколькими строками текста. Напишите программу, которая с помощью `bufio.NewScanner` считывает этот файл построчно и выводит каждую строку с префиксом `[Line X]: `.

## Теория

`bufio.NewScanner` оптимизирован для парсинга текстовых файлов построчно, выделяя минимальный объем памяти.

## Решение по шагам

1. Создадим файл `server.log` с несколькими записями.
2. Откроем файл через `os.Open`.
3. Создадим сканер и проитерируемся по строкам.
4. Выведем с префиксом `[Line %d]: %s`.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"log"
	"os"
)

func main() {
	path := "server.log"
	_ = os.WriteFile(path, []byte("INFO: Server init\nWARN: High memory\nERROR: Connection dropped"), 0644)

	f, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer f.Close()

	scanner := bufio.NewScanner(f)
	lineIdx := 1
	for scanner.Scan() {
		fmt.Printf("[Line %d]: %s\n", lineIdx, scanner.Text())
		lineIdx++
	}

	if err := scanner.Err(); err != nil {
		log.Fatal(err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Line 1]: INFO: Server init
# [Line 2]: WARN: High memory
# [Line 3]: ERROR: Connection dropped
```

## Под капотом

Каждый вызов `scanner.Scan()` ищет байт `\n` (ASCII 10) во внутреннем буфере с помощью функции `bytes.IndexByte`.

## Подводные камни

Не модифицируйте срез `scanner.Bytes()`, так как следующий вызов `scanner.Scan()` перезапишет те же самые ячейки памяти.

## На собеседовании

**Вопрос с собеседования:** «Почему scanner.Bytes() опасен при сохранении в срез []byte?»
**Ответ:** Срез `scanner.Bytes()` ссылается на мутируемый буфер сканера. Если сохранить его в срез `rows = append(rows, scanner.Bytes())`, все элементы в `rows` будут указывать на один и тот же массив и перезапишутся последней строкой файла. Для сохранения нужно клонировать байты `bytes.Clone()` или делать `make([]byte)` + `copy()`.
