# Построчное чтение файла через bufio.Scanner и defer file.Close

## Условие

Откройте файл с помощью `os.Open`, прочитайте его построчно, используя `bufio.Scanner`, и обязательно закройте файл через `defer`.

## Теория

`bufio.Scanner` читает поток данных небольшими порциями в кольцевой буфер фиксированного размера (по умолчанию 64KB), разделяя данные по символу перевода строки `\n`. Это позволяет обрабатывать терабайтные файлы с константным потреблением оперативной памяти \(O(1)\).

## Решение по шагам

1. Откроем файл `os.Open("data.txt")`.
2. Проверим ошибку открытия `if err != nil`.
3. Установим `defer file.Close()`.
4. Инициализируем `scanner := bufio.NewScanner(file)`.
5. В цикле `for scanner.Scan()` прочитаем строки и выведем их с номерами.
6. Проверим ошибку сканера `if err := scanner.Err(); err != nil`.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"log"
	"os"
)

func main() {
	// Подготовка данных
	filename := "metrics.txt"
	_ = os.WriteFile(filename, []byte("cpu_usage_pct 45.2\nmemory_alloc_mb 1024\ngoroutines_count 128"), 0644)

	file, err := os.Open(filename)
	if err != nil {
		log.Fatalf("Не удалось открыть файл: %v", err)
	}
	defer file.Close()

	scanner := bufio.NewScanner(file)
	lineNum := 1
	for scanner.Scan() {
		line := scanner.Text()
		fmt.Printf("Строка #%d: %s\n", lineNum, line)
		lineNum++
	}

	if err := scanner.Err(); err != nil {
		log.Fatalf("Ошибка в процессе сканирования: %v", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Строка #1: cpu_usage_pct 45.2
# Строка #2: memory_alloc_mb 1024
# Строка #3: goroutines_count 128
```

## Под капотом

`bufio.Scanner` использует внутренний буфер `bufio.MaxScanTokenSize` (64KB). При чтении строки он сдвигает указатели и возвращает срез байт `Bytes()` или строку `Text()` без символа `\n`.

## Подводные камни

Если длина одной строки в файле превышает 64KB (например, гигантский JSON на одной строке), `scanner.Scan()` вернет `false`, а `scanner.Err()` выдаст ошибку `bufio.Scanner: token too long`. Для таких файлов нужно увеличивать буфер через `scanner.Buffer(buf, max)` или использовать `bufio.Reader.ReadString('\n')`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие scanner.Text() от scanner.Bytes()? Какая функция эффективнее для HighLoad?»
**Ответ:** `scanner.Bytes()` возвращает срез, указывающий напрямую на внутренний буфер сканера с **0 аллокаций памяти**. `scanner.Text()` выделяет новую строку в куче при каждом вызове. В HighLoad-коде для минимизации работы GC всегда используют `scanner.Bytes()`.
