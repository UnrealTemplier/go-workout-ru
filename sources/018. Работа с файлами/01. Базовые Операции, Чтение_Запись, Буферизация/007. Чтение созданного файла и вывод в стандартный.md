# Чтение созданного файла и вывод в стандартный вывод

## Условие

Прочитайте всё содержимое созданного файла в память с помощью `os.ReadFile` и выведите на экран.

## Теория

`os.ReadFile` возвращает `([]byte, error)`. Преобразование в `string` создает копию данных, готовую для текстового вывода через `fmt.Println`.

## Решение по шагам

1. Создадим файл `notes.txt`.
2. Запишем в него многострочный текст через `os.WriteFile`.
3. Прочитаем с помощью `os.ReadFile`.
4. Выведем результат в консоль.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	path := "notes.txt"
	initialData := "1. Init Go Modules\n2. Configure CI/CD\n3. Deploy to Kubernetes"

	if err := os.WriteFile(path, []byte(initialData), 0644); err != nil {
		log.Fatalf("Ошибка записи: %v", err)
	}

	content, err := os.ReadFile(path)
	if err != nil {
		log.Fatalf("Ошибка чтения: %v", err)
	}

	fmt.Println("--- Заметки проекта ---")
	fmt.Println(string(content))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- Заметки проекта ---
# 1. Init Go Modules
# 2. Configure CI/CD
# 3. Deploy to Kubernetes
```

## Под капотом

`os.ReadFile` открывает дескриптор в режиме `O_RDONLY` и использует системный вызов `read` до достижения `EOF`.

## Подводные камни

Всегда проверяйте `err != nil`, прежде чем преобразовывать `content` в строку, так как при ошибке `content` равен `nil`.

## На собеседовании

**Вопрос с собеседования:** «Что происходит с памятью при string(content) в Go?»
**Ответ:** Выражение `string(content)` выполняет аллокацию памяти в куче и побайтовое копирование среза `[]byte` в новую неизменяемую строку `string`. В Go 1.22 компилятор может оптимизировать это копирование только внутри `map[string(b)]` поиска.
