# Универсальная функция ReadLines с корректной обработкой переносов строк

## Условие

Напиши функцию `ReadLines(filename string) ([]string, error)`, которая читает файл построчно (`bufio.Scanner` с `ScanLines`). Обработай пустые строки и файл без последнего `\n`.

## Теория

`bufio.ScanLines` — стандартная функция разбиения для `bufio.Scanner`. Она автоматически корректно обрабатывает файлы, в конце которых нет завершающего символа переноса строки `\n`.

## Решение по шагам

1. Реализуем функцию `ReadLines(filename string) ([]string, error)`.
2. Откроем файл, установим `defer f.Close()`.
3. Создадим сканер `scanner := bufio.NewScanner(f)`.
4. В цикле соберем строки в срез `var lines []string`.
5. В `main` протестируем файл без `\n` в конце.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"log"
	"os"
)

func ReadLines(filename string) ([]string, error) {
	file, err := os.Open(filename)
	if err != nil {
		return nil, fmt.Errorf("ReadLines open: %w", err)
	}
	defer file.Close()

	var lines []string
	scanner := bufio.NewScanner(file)
	scanner.Split(bufio.ScanLines)

	for scanner.Scan() {
		lines = append(lines, scanner.Text())
	}

	if err := scanner.Err(); err != nil {
		return nil, fmt.Errorf("ReadLines scan: %w", err)
	}

	return lines, nil
}

func main() {
	// Файл без \n на последней строке:
	_ = os.WriteFile("test_lines.txt", []byte("Alpha\n\nBeta\nGamma"), 0644)

	lines, err := ReadLines("test_lines.txt")
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Всего строк вычитано: %d\n", len(lines))
	for i, l := range lines {
		fmt.Printf("line[%d] = %q\n", i, l)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Всего строк вычитано: 4
# line[0] = "Alpha"
# line[1] = ""
# line[2] = "Beta"
# line[3] = "Gamma" 
```

## Под капотом

`ScanLines` распознает как Unix `\n`, так и Windows `\r\n` окончания строк.

## Подводные камни

Если файл содержит пустые строки, они возвращаются как `""` и увеличивают длину среза `lines`.

## На собеседовании

**Вопрос с собеседования:** «Как обработать файл размером 50GB через ReadLines?»
**Ответ:** Никак: возвращать `[]string` для 50GB файла нельзя, так как это вызовет OOM. Для больших файлов используют потоковый генератор с функцией обратного вызова `ForEachLine(path, func(line string) error)` или канал строк.
