# Перенаправление содержимого файла в os.Stdout через io.Copy

## Условие

Откройте файл для чтения и запишите его содержимое в `os.Stdout` с помощью `io.Copy`.

## Теория

`os.Stdout` реализует интерфейс `io.Writer`. Функция `io.Copy(os.Stdout, file)` стримит данные из файла напрямую в терминал без промежуточных строковых преобразований.

## Решение по шагам

1. Создадим файл `banner.txt`.
2. Откроем `banner.txt` на чтение через `os.Open`.
3. Добавим `defer f.Close()`.
4. Вызовем `io.Copy(os.Stdout, f)`.
5. В `main` убедимся в выводе данных в консоль.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"log"
	"os"
)

func main() {
	path := "banner.txt"
	_ = os.WriteFile(path, []byte("====================================\n=== GO HIGHLOAD WORKOUT ENGINE   ===\n====================================\n"), 0644)

	f, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer f.Close()

	fmt.Println("Прямой вывод файла в os.Stdout через io.Copy:")
	if _, err := io.Copy(os.Stdout, f); err != nil {
		log.Fatal(err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Прямой вывод файла в os.Stdout через io.Copy:
# ====================================
# === GO HIGHLOAD WORKOUT ENGINE   ===
# ==================================== 
```

## Под капотом

`io.Copy` читает из дескриптора файла (fd 3) и пишет в дескриптор стандартного вывода stdout (fd 1).

## Подводные камни

Не забывайте проверять ошибку `io.Copy`, так как stdout может быть закрыт вызывающим процессом (Broken Pipe).

## На собеседовании

**Вопрос с собеседования:** «Как реализовать аналог утилиты cat на чистом Go?»
**Ответ:** Простая функция `io.Copy(os.Stdout, file)` для каждого аргумента из `os.Args[1:]`. Это дает максимальную производительность ввода-вывода с нулевыми накладными расходами.
