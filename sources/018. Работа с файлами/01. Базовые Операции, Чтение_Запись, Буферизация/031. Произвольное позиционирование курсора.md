# Произвольное позиционирование курсора через file.Seek

## Условие

**Произвольное позиционирование (Seek)**: Откройте файл. Используйте метод `file.Seek`, чтобы переместить указатель чтения/записи на 5 байт вперед от начала файла. Прочитайте следующие 3 байта и выведите их.

## Теория

Метод `file.Seek(offset, whence)` перемещает указатель курсора внутри файла:
- `io.SeekStart` (`0`): отсчет от начала файла.
- `io.SeekCurrent` (`1`): отсчет от текущей позиции курсора.
- `io.SeekEnd` (`2`): отсчет от конца файла.

## Решение по шагам

1. Создадим файл `alphabet.txt` со строкой `"0123456789ABCDEF"`.
2. Откроем файл через `os.Open`.
3. Переместим курсор: `file.Seek(5, io.SeekStart)`.
4. Прочитаем 3 байта в буфер `buf := make([]byte, 3)`.
5. В `main` убедимся, что вычитаны символы `"567"`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"log"
	"os"
)

func main() {
	path := "alphabet.txt"
	_ = os.WriteFile(path, []byte("0123456789ABCDEF"), 0644)

	file, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	// Сдвиг на 5 байт от начала
	newOffset, err := file.Seek(5, io.SeekStart)
	if err != nil {
		log.Fatalf("Ошибка Seek: %v", err)
	}
	fmt.Printf("Курсор перемещен на позицию: %d\n", newOffset)

	// Читаем 3 байта
	buf := make([]byte, 3)
	n, err := io.ReadFull(file, buf)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Прочитано %d байт: %q\n", n, string(buf))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Курсор перемещен на позицию: 5
# Прочитано 3 байт: "567" 
```

## Под капотом

`file.Seek` транслируется в системный вызов `lseek(2)`, который изменяет файловый указатель в ядре без дискового ввода-вывода.

## Подводные камни

`Seek` не работает на сетевых сокетах, Unix пайпах и `os.Stdin` (вернет ошибку `ESPIPE: illegal seek`).

## На собеседовании

**Вопрос с собеседования:** «Как узнать текущий размер файла с помощью Seek без os.Stat?»
**Ответ:** Вызвать `size, err := file.Seek(0, io.SeekEnd)`. Метод вернет смещение от начала файла, которое в точности равно его размеру в байтах.
