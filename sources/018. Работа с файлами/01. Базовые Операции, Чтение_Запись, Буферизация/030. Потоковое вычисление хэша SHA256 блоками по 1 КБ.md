# Потоковое вычисление хэша SHA256 блоками по 1 КБ

## Условие

Читайте большой файл блоками по 1 КБ, вычисляя SHA256-хэш всего файла.

## Теория

Криптографический хэш `crypto/sha256` реализует интерфейс `io.Writer`. Функция `io.Copy(hash, file)` или блочное чтение позволяет вычислить контрольную сумму файла любого объема без загрузки в память.

## Решение по шагам

1. Создадим файл `data.bin`.
2. Инициализируем `h := sha256.New()`.
3. В цикле вычитаем файл порциями по 1024 байта и запишем в `h.Write(buf[:n])`.
4. Получим финальный хэш `h.Sum(nil)` и выведем в виде hex-строки.

## Код решения

**`main.go`**

```go
package main

import (
	"crypto/sha256"
	"encoding/hex"
	"errors"
	"fmt"
	"io"
	"log"
	"os"
)

func computeSHA256Chunks(path string) (string, error) {
	file, err := os.Open(path)
	if err != nil {
		return "", err
	}
	defer file.Close()

	hasher := sha256.New()
	buf := make([]byte, 1024) // Блок 1 КБ

	for {
		n, err := file.Read(buf)
		if n > 0 {
			hasher.Write(buf[:n])
		}
		if err != nil {
			if errors.Is(err, io.EOF) {
				break
			}
			return "", err
		}
	}

	hashBytes := hasher.Sum(nil)
	return hex.EncodeToString(hashBytes), nil
}

func main() {
	path := "checksum_test.txt"
	_ = os.WriteFile(path, []byte("Cryptographic hash verification pipeline in Go 1.22"), 0644)

	hash, err := computeSHA256Chunks(path)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("SHA256 (%s) = %s\n", path, hash)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# SHA256 (checksum_test.txt) = 66e85559be39e160e9a4f6cf7015db636e0bb7d63da671802a8cf2921319c59d
```

## Под капотом

`sha256.New()` поддерживает внутреннее состояние (8 32-битных регистров), обновляемое алгоритмом Merkle–Damgård при поступлении каждого блока.

## Подводные камни

Вместо ручного цикла в production-коде используют `io.Copy(hasher, file)`, что дает идентичный результат в одну строку.

## На собеседовании

**Вопрос с собеседования:** «Как проверить целостность скачиваемого по HTTP файла на лету?»
**Ответ:** Обернуть `http.Response.Body` в `io.TeeReader(resp.Body, hasher)` и передать в `io.Copy(file, teeReader)`. Файл одновременно сохраняется на диск и вычисляется его SHA256 за один проход.
