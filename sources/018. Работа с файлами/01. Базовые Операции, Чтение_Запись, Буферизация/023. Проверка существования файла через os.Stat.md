# Проверка существования файла через os.Stat и errors.Is(err, os.ErrNotExist)

## Условие

Проверь существование файла с помощью `os.Stat`. Обработай ошибку `os.IsNotExist(err)`.

## Теория

`os.Stat(name)` возвращает метаданные `fs.FileInfo`. Если файл не существует, возвращается ошибка, которую проверяют через `errors.Is(err, os.ErrNotExist)` или `os.IsNotExist(err)`.

## Решение по шагам

1. Напишем функцию `fileExists(filename string) (bool, error)`.
2. Вызовем `os.Stat(filename)`.
3. Обработаем ошибку `errors.Is(err, os.ErrNotExist)`.
4. В `main` проверим существующий и несуществующий файлы.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
	"os"
)

func fileExists(path string) (bool, error) {
	_, err := os.Stat(path)
	if err == nil {
		return true, nil // Файл существует
	}
	if errors.Is(err, os.ErrNotExist) || os.IsNotExist(err) {
		return false, nil // Файл гарантированно не существует
	}
	return false, err // Другая ошибка (например, нет прав доступа на родительскую папку)
}

func main() {
	_ = os.WriteFile("config.yaml", []byte("version: 1"), 0644)

	for _, name := range []string{"config.yaml", "missing.json"} {
		exists, err := fileExists(name)
		if err != nil {
			fmt.Printf("Ошибка проверки %s: %v\n", name, err)
		} else {
			fmt.Printf("Файл %-12s существует: %v\n", name, exists)
		}
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Файл config.yaml  существует: true
# Файл missing.json существует: false
```

## Под капотом

`os.Stat` выполняет системный вызов `statx`/`stat`. Если возвращен код ошибки `ENOENT`, Go транслирует его в `os.ErrNotExist`.

## Подводные камни

Проверка существования перед открытием подвержена уязвимости TOCTOU (Time-of-Check to Time-of-Use). Если файл создается монопольно, надежнее сразу открывать `os.OpenFile(..., os.O_CREATE|os.O_EXCL, ...)`.

## На собеседовании

**Вопрос с собеседования:** «Что такое race condition TOCTOU при работе с файлами?»
**Ответ:** Если сначала проверить существование файла через `os.Stat`, а затем создать его через `os.Create`, другой процесс может успеть создать файл в промежутке между вызовами. Решение: атомарное открытие с флагом `os.O_EXCL` (fail if exists).
