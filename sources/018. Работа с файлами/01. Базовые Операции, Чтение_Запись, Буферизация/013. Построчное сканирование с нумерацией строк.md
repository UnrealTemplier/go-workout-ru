# Построчное сканирование с нумерацией строк: bufio.Scanner

## Условие

Прочитай файл построчно с помощью `bufio.Scanner`. Выведи каждую строку в консоль с её номером.

## Теория

Построчное сканирование разбивает текст по символам `\n` или `\r\n`. Метод `scanner.Text()` возвращает текущую строку без завершающих символов перевода строки.

## Решение по шагам

1. Создадим тестовый файл `todo.txt`.
2. Откроем файл через `os.Open`.
3. Инициализируем `bufio.NewScanner(file)`.
4. В цикле увеличим счетчик и выведем `[Line N]: <text>`.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"log"
	"os"
)

func main() {
	path := "todo.txt"
	_ = os.WriteFile(path, []byte("Buy coffee\nRefactor microservice\nWrite unit tests"), 0644)

	f, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer f.Close()

	scanner := bufio.NewScanner(f)
	line := 1
	for scanner.Scan() {
		fmt.Printf("[%02d] %s\n", line, scanner.Text())
		line++
	}

	if err := scanner.Err(); err != nil {
		log.Fatalf("Ошибка сканера: %v", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [01] Buy coffee
# [02] Refactor microservice
# [03] Write unit tests
```

## Под капотом

`bufio.Scanner` не аллоцирует новые буферы на каждой итерации, а циклически перезаписывает один внутренний буфер.

## Подводные камни

Всегда проверяйте `scanner.Err()` после завершения цикла `for scanner.Scan()`, так как сканер может прерваться по ошибке I/O до достижения конца файла.

## На собеседовании

**Вопрос с собеседования:** «Что вернет scanner.Scan() при достижении EOF?»
**Ответ:** Вернет `false`. При этом `scanner.Err()` вернет `nil` (так как EOF считается штатным завершением, а не ошибкой).
