# Быстрая атомарная запись среза байт через os.WriteFile

## Условие

**Быстрая запись всего файла**: Используя функцию `os.WriteFile`, запишите массив байт в новый файл `fast.txt`, указав права доступа `0644`.

## Теория

`os.WriteFile(filename, data, perm)` (Go 1.16+) открывает файл в режиме `O_WRONLY|O_CREATE|O_TRUNC`, записывает срез `data` и гарантированно закрывает дескриптор.

## Решение по шагам

1. Создадим срез байт `data := []byte("Fast atomic byte write")`.
2. Вызовем `os.WriteFile("fast.txt", data, 0644)`.
3. Проверим ошибку `err != nil`.
4. В `main` прочитаем файл обратно и убедимся в успешной записи.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	path := "fast.txt"
	payload := []byte("Fast atomic byte write\nCreated via os.WriteFile")

	if err := os.WriteFile(path, payload, 0644); err != nil {
		log.Fatalf("Ошибка os.WriteFile: %v", err)
	}

	res, err := os.ReadFile(path)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Println("--- fast.txt ---")
	fmt.Println(string(res))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- fast.txt ---
# Fast atomic byte write
# Created via os.WriteFile
```

## Под капотом

`os.WriteFile` создает файл, если его не было, или усекает его, если он существовал.

## Подводные камни

`os.WriteFile` перезаписывает файл полностью. Для дозаписи используйте `os.OpenFile` с флагом `O_APPEND`.

## На собеседовании

**Вопрос с собеседования:** «Является ли os.WriteFile атомарным при сбое питания сервера?»
**Ответ:** Нет. `os.WriteFile` усекает файл и пишет данные. Если питание отключится в процессе записи, на диске останется полупустой поврежденный файл. Для гарантированной атомарности пишут во временный файл `os.CreateTemp` в том же разделе, вызывают `Sync()` и делают `os.Rename()`.
