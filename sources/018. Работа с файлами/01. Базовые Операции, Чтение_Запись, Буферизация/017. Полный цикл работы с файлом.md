# Полный цикл работы с файлом: Create, Write, Close, ReadFile

## Условие

Создай файл `hello.txt` программно (`os.Create`). Запиши в него строку "Hello, File!". Закрой файл (`defer f.Close()`). Прочитай файл обратно (`os.ReadFile` или `ioutil.ReadFile`) и выведи содержимое.

## Теория

`os.Create(name)` создает новый файл с правами `0666` (с учетом `umask`) или усекает существующий файл до нулевого размера (`O_TRUNC`).

## Решение по шагам

1. Создадим `hello.txt` через `os.Create`.
2. Добавим `defer f.Close()`.
3. Запишем `"Hello, File!"` через `f.WriteString`.
4. Прочитаем через `os.ReadFile` и выведем.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	filename := "hello.txt"

	// 1. Создание и запись
	f, err := os.Create(filename)
	if err != nil {
		log.Fatalf("Ошибка создания: %v", err)
	}
	if _, err := f.WriteString("Hello, File!"); err != nil {
		f.Close()
		log.Fatalf("Ошибка записи: %v", err)
	}
	f.Close() // Закрываем перед чтением

	// 2. Чтение обратно
	data, err := os.ReadFile(filename)
	if err != nil {
		log.Fatalf("Ошибка чтения: %v", err)
	}

	fmt.Println("Прочитано из файла:", string(data))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Прочитано из файла: Hello, File!
```

## Под капотом

`os.Create` эквивалентен `os.OpenFile(name, os.O_RDWR|os.O_CREATE|os.O_TRUNC, 0666)`.

## Подводные камни

Если не закрыть файл перед чтением другим процессом в Windows, возникнет ошибка блокировки файла.

## На собеседовании

**Вопрос с собеседования:** «Каковы права файла при создании os.Create("test.txt") с правами 0666?»
**Ответ:** Реальные права файла вычисляются как `0666 & ~umask`. Если системный `umask` равен `0022`, итоговые права файла на диске будут `0644` (`-rw-r--r--`).
