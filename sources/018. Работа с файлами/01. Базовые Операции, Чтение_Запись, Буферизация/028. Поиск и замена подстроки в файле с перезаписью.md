# Поиск и замена подстроки в файле с перезаписью

## Условие

Найдите и замените определенное слово в текстовом файле, перезаписав его (прочитайте -> измените -> перезапишите).

## Теория

Паттерн Find-and-Replace для небольших файлов: чтение всего содержимого через `os.ReadFile`, замена через `bytes.ReplaceAll` или `strings.ReplaceAll` и перезапись через `os.WriteFile`.

## Решение по шагам

1. Создадим файл `template.txt` со словом `HOST_NAME`.
2. Прочитаем файл через `os.ReadFile`.
3. Заменим подстроку через `strings.ReplaceAll`.
4. Перезапишем файл через `os.WriteFile`.
5. В `main` убедимся в замене.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
	"strings"
)

func replaceInFile(path, oldWord, newWord string) error {
	data, err := os.ReadFile(path)
	if err != nil {
		return fmt.Errorf("чтение: %w", err)
	}

	modified := strings.ReplaceAll(string(data), oldWord, newWord)

	if err := os.WriteFile(path, []byte(modified), 0644); err != nil {
		return fmt.Errorf("перезапись: %w", err)
	}
	return nil
}

func main() {
	path := "template.txt"
	_ = os.WriteFile(path, []byte("Server address: http://HOST_NAME:8080/api/v1"), 0644)

	if err := replaceInFile(path, "HOST_NAME", "api.cloud.corp"); err != nil {
		log.Fatal(err)
	}

	result, _ := os.ReadFile(path)
	fmt.Println("Результат замены:")
	fmt.Println(string(result))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Результат замены:
# Server address: http://api.cloud.corp:8080/api/v1
```

## Под капотом

`strings.ReplaceAll` заменяет все непересекающиеся вхождения подстроки, выделяя новую строку нужной длины.

## Подводные камни

Для файлов на десятки гигабайт замена в памяти невозможна — нужно читать файл потоково и писать результат во временный файл.

## На собеседовании

**Вопрос с собеседования:** «Как оптимизировать replaceInFile для работы без преобразования []byte -> string -> []byte?»
**Ответ:** Использовать `bytes.ReplaceAll(data, []byte(old), []byte(new))` напрямую на срезах байт. Это исключит лишние аллокации строк в куче.
