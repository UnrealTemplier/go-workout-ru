# Запись и чтение структурированных CSV файлов через encoding/csv

## Условие

Создайте CSV-файл (через запятую), запишите туда 5 строк данных, а затем прочитайте его с помощью пакета `encoding/csv`.

## Теория

Пакет `encoding/csv` стандартной библиотеки Go реализует RFC 4180 спецификацию CSV: автоматическое экранирование кавычек, обработку запятых внутри полей и переносов строк.

## Решение по шагам

1. Создадим файл `users.csv`.
2. Инициализируем `writer := csv.NewWriter(file)`.
3. Запишем заголовок и 5 строк через `writer.WriteAll`.
4. Откроем файл и вычитаем все строки через `csv.NewReader(file).ReadAll()`.
5. В `main` выведем данные в виде таблицы.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/csv"
	"fmt"
	"log"
	"os"
)

func main() {
	path := "users.csv"

	// 1. Запись CSV
	records := [][]string{
		{"ID", "Name", "Role", "City"},
		{"1", "Алексей", "Backend Lead", "Москва"},
		{"2", "Мария", "DevOps Engineer", "СПб"},
		{"3", "Дмитрий", "SRE Specialist", "Казань"},
		{"4", "Елена", "Product Owner", "Екатеринбург"},
		{"5", "Иван", "QA Automation", "Новосибирск"},
	}

	outFile, err := os.Create(path)
	if err != nil {
		log.Fatal(err)
	}
	w := csv.NewWriter(outFile)
	if err := w.WriteAll(records); err != nil {
		outFile.Close()
		log.Fatal(err)
	}
	outFile.Close()

	// 2. Чтение CSV
	inFile, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer inFile.Close()

	r := csv.NewReader(inFile)
	rows, err := r.ReadAll()
	if err != nil {
		log.Fatal(err)
	}

	fmt.Println("--- Таблица пользователей из CSV ---")
	for _, row := range rows {
		fmt.Printf("%-3s | %-10s | %-16s | %s\n", row[0], row[1], row[2], row[3])
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- Таблица пользователей из CSV ---
# ID  | Name       | Role             | City
# 1   | Алексей    | Backend Lead     | Москва
# 2   | Мария      | DevOps Engineer  | СПб
# 3   | Дмитрий    | SRE Specialist   | Казань
# 4   | Елена      | Product Owner    | Екатеринбург
# 5   | Иван       | QA Automation    | Новосибирск
```

## Под капотом

`csv.Writer.WriteAll` автоматически вызывает `w.Flush()` и проверяет `w.Error()`.

## Подводные камни

Если использовать `writer.Write` в цикле по одной строке, обязателен вызов `writer.Flush()` в конце, иначе последние строки останутся в буфере.

## На собеседовании

**Вопрос с собеседования:** «Как настроить csv.Reader для файлов с разделителем точка с запятой (;) или табуляцией (\t)?»
**Ответ:** Установить поле `reader.Comma = ';'` или `reader.Comma = '\t'`. Для чтения строк с разным количеством колонок устанавливают `reader.FieldsPerRecord = -1`.
