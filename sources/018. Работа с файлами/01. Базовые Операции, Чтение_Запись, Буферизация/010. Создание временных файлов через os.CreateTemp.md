# Создание временных файлов через os.CreateTemp и очистка defer os.Remove

## Условие

Создайте временный файл (`os.CreateTemp`), запишите данные, выведите путь, а затем удалите (или используйте `defer os.Remove`).

## Теория

Функция `os.CreateTemp(dir, pattern)` создает уникальный файл в системном каталоге временных файлов (обычно `/tmp` в Linux), гарантируя отсутствие коллизий имен. Идиоматичный паттерн очистки — немедленный `defer os.Remove(f.Name())`.

## Решение по шагам

1. Создадим временный файл `tmpFile, err := os.CreateTemp("", "workout-*.tmp")`.
2. Добавим отложенное удаление `defer os.Remove(tmpFile.Name())` и закрытие `defer tmpFile.Close()`.
3. Запишем временные данные и выведем путь к файлу.
4. В `main` убедимся, что файл удален после выхода из функции.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func runWithTempFile() {
	// Создание временного файла в системной папке /tmp
	tmpFile, err := os.CreateTemp("", "worker-cache-*.tmp")
	if err != nil {
		log.Fatalf("Ошибка CreateTemp: %v", err)
	}
	// Двойной defer: сначала закрываем, потом удаляем
	defer os.Remove(tmpFile.Name())
	defer tmpFile.Close()

	fmt.Printf("Временный файл создан: %s\n", tmpFile.Name())

	// Запись временных вычислений
	if _, err := tmpFile.WriteString("Intermediate hash payload"); err != nil {
		log.Fatal(err)
	}

	fmt.Println("Временные данные успешно обработаны")
}

func main() {
	runWithTempFile()
	fmt.Println("Функция завершена, временный файл автоматически удален с диска")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Временный файл создан: /tmp/worker-cache-371829104.tmp
# Временные данные успешно обработаны
# Функция завершена, временный файл автоматически удален с диска
```

## Под капотом

Символ `*` в паттерне имени заменяется рантаймом на случайную последовательность цифр, генерируемую с помощью безопасного генератора псевдослучайных чисел.

## Подводные камни

В Windows удаление открытого файла может блокироваться ОС. Поэтому `defer tmpFile.Close()` должен выполняться раньше `defer os.Remove()` (LIFO порядок defer).

## На собеседовании

**Вопрос с собеседования:** «Зачем нужен os.CreateTemp в интеграционных тестах?»
**Ответ:** Чтобы каждый тест работал в полностью изолированном временном файле/папке, исключая взаимное влияние тестов при параллельном запуске (`t.Parallel()`) и гарантируя очистку диска через `t.Cleanup()`.
