# Создание одиночной директории через os.Mkdir

## Условие

Создай новую директорию с помощью `os.Mkdir`.

## Теория

Функция `os.Mkdir(name, perm)` создает один каталог с указанными правами доступа. Если родительский каталог не существует или создаваемая папка уже есть, возвращается ошибка.

## Решение по шагам

1. Зададим имя каталога `new_folder`.
2. Создадим его с правами `0755` через `os.Mkdir`.
3. Проверим метаданные через `os.Stat` и метод `info.IsDir()`.
4. В `main` убедимся в создании.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	dirName := "reports_2026"

	// Удалим если осталась от прошлых запусков
	_ = os.Remove(dirName)

	// Создание директории с правами rwxr-xr-x (0755)
	if err := os.Mkdir(dirName, 0755); err != nil {
		log.Fatalf("Ошибка создания папки: %v", err)
	}
	fmt.Printf("Директория %s успешно создана\n", dirName)

	// Проверка свойств
	info, err := os.Stat(dirName)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("Является директорией: %v, Права: %v\n", info.IsDir(), info.Mode().Perm())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Директория reports_2026 успешно создана
# Является директорией: true, Права: -rwxr-xr-x
```

## Под капотом

`os.Mkdir` вызывает системный вызов `mkdirat(2)` / `mkdir(2)`.

## Подводные камни

В отличие от `os.MkdirAll`, вызов `os.Mkdir` упадет с ошибкой, если промежуточные папки в пути не существуют.

## На собеседовании

**Вопрос с собеседования:** «Зачем директориям в Linux нужен бит исполнения x (например, 0755)?»
**Ответ:** В Unix бит исполнения `x` для директории означает право на **вход** в нее (traversal) и доступ к метаданным файлов внутри. Без бита `x` пользователь не сможет прочитать файл в папке, даже зная его точное имя.
