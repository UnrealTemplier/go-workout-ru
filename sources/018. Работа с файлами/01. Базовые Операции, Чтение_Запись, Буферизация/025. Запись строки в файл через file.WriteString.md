# Запись строки в файл через file.WriteString

## Условие

**Запись строки**: Откройте файл на запись и запишите в него строку `"Привет, Go!"` с помощью метода `file.WriteString`.

## Теория

Метод `file.WriteString(s string) (n int, err error)` оптимизирован для записи строк: он преобразует строку в байты без дополнительных аллокаций памяти в куче.

## Решение по шагам

1. Создадим файл `greeting.txt` через `os.Create`.
2. Добавим `defer f.Close()`.
3. Запишем строку через `f.WriteString("Привет, Go!\n")`.
4. В `main` прочитаем файл и выведем содержимое.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	filename := "greeting.txt"

	f, err := os.Create(filename)
	if err != nil {
		log.Fatalf("Ошибка создания: %v", err)
	}
	defer f.Close()

	n, err := f.WriteString("Привет, Go!\n")
	if err != nil {
		log.Fatalf("Ошибка записи: %v", err)
	}

	fmt.Printf("Записано %d байт в файл %s\n", n, filename)

	data, _ := os.ReadFile(filename)
	fmt.Print(string(data))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Записано 21 байт в файл greeting.txt
# Привет, Go!
```

## Под капотом

Символы кириллицы в UTF-8 занимают по 2 байта каждый, поэтому строка «Привет, Go!\n» (13 символов) занимает 21 байт.

## Подводные камни

Не забывайте, что `WriteString` возвращает количество *байт*, а не количество символов/рун.

## На собеседовании

**Вопрос с собеседования:** «Почему file.WriteString(s) эффективнее file.Write([]byte(s))?»
**Ответ:** Выражение `[]byte(s)` всегда выделяет новый срез байт в куче и копирует в него данные. Внутренняя реализация `file.WriteString(s)` использует `unsafe.StringData` и передает указатель напрямую в системный вызов ядра с **0 аллокаций памяти**.
