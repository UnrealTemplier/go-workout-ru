# Удаление файлов с диска через os.Remove

## Условие

Удали файл с помощью `os.Remove`.

## Теория

Функция `os.Remove(name)` удаляет файл или пустую директорию. Если файл не существует, возвращается ошибка `os.ErrNotExist`.

## Решение по шагам

1. Создадим файл `junk.tmp`.
2. Проверим его наличие через `os.Stat`.
3. Удалим файл через `os.Remove("junk.tmp")`.
4. Повторно вызовем `os.Stat` и убедимся в удалении.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
	"log"
	"os"
)

func main() {
	path := "junk.tmp"
	_ = os.WriteFile(path, []byte("garbage data"), 0644)
	fmt.Printf("Файл %s успешно создан\n", path)

	// Удаление файла
	if err := os.Remove(path); err != nil {
		log.Fatalf("Ошибка удаления: %v", err)
	}
	fmt.Printf("Файл %s успешно удален с диска\n", path)

	// Проверка отсутствия
	_, err := os.Stat(path)
	if errors.Is(err, os.ErrNotExist) {
		fmt.Println("Проверка подтвердила: файл больше не существует")
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Файл junk.tmp успешно создан
# Файл junk.tmp успешно удален с диска
# Проверка подтвердила: файл больше не существует
```

## Под капотом

`os.Remove` вызывает системный вызов `unlinkat(2)` / `unlink(2)`, уменьшая счетчик жестких ссылок на inode до 0.

## Подводные камни

`os.Remove` не может удалить непустую директорию (вернет `directory not empty`). Для рекурсивного удаления используют `os.RemoveAll`.

## На собеседовании

**Вопрос с собеседования:** «Что происходит в Linux, если удалить файл (os.Remove), пока другой процесс держит его открытым?»
**Ответ:** Имя файла удаляется из каталога (директории), но сам `inode` и блоки данных остаются на диске до тех пор, пока последний открывший процесс не закроет файловый дескриптор. Место на диске освободится только после закрытия дескриптора.
