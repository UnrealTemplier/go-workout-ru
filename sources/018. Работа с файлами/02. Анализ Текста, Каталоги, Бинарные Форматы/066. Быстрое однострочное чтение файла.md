# Быстрое однострочное чтение файла через os.ReadFile

## Условие

**Быстрое чтение всего файла**: Используя функцию `os.ReadFile`, прочитайте весь файл `test.txt` за один вызов. Преобразуйте результат в строку и выведите его в консоль.

## Теория

`os.ReadFile` — самая лаконичная и безопасная функция для чтения конфигураций, шаблонов и небольших файлов за один вызов.

## Решение по шагам

1. Создадим файл `test.txt`.
2. Вызовем `data, err := os.ReadFile("test.txt")`.
3. Преобразуем `string(data)`.
4. Выведем результат в консоль.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	path := "quick_read_test.txt"
	_ = os.WriteFile(path, []byte("Go 1.22: Instant Single-Line File Reading"), 0644)

	// Чтение за один вызов
	data, err := os.ReadFile(path)
	if err != nil {
		log.Fatalf("Ошибка чтения: %v", err)
	}

	contentStr := string(data)
	fmt.Printf("Прочитано (%d байт):\n%s\n", len(data), contentStr)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Прочитано (41 байт):
# Go 1.22: Instant Single-Line File Reading
```

## Под капотом

`os.ReadFile` делает `os.Open`, `stat`, `io.ReadAll` и `defer f.Close()` под капотом.

## Подводные камни

Не забывайте обрабатывать `err`, так как при ошибке `data` равна `nil`.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go 1.16+ отказались от ioutil.ReadFile?»
**Ответ:** Пакет `io/ioutil` дублировал функционал и размывал структуру стандартной библиотеки. Перенос `ReadFile` в пакет `os` сделал API логичным: файловые операции находятся строго в пакете `os`.
