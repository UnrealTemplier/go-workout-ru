# Десериализация бинарных данных через encoding/gob

## Условие

Прочитайте созданный `gob`-файл обратно в память и выведите данные на экран.

## Теория

Формат `encoding/gob` — нативный высокоскоростной бинарный формат сериализации Go. Он сохраняет информацию о типах и структурах данных, позволяя надежно восстанавливать сложные графы объектов.

## Решение по шагам

1. Объявим структуру `UserSession struct { UserID int; Username string; Scopes []string }`.
2. Запишем экземпляр в файл через `gob.NewEncoder(f).Encode(...)`.
3. Откроем файл и прочитаем через `gob.NewDecoder(f).Decode(...)`.
4. В `main` проверим точное восстановление срезов и полей.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/gob"
	"fmt"
	"log"
	"os"
)

type UserSession struct {
	UserID   int
	Username string
	Scopes   []string
}

func main() {
	path := "session.gob"

	original := UserSession{
		UserID:   1001,
		Username: "cloud_admin",
		Scopes:   []string{"read:users", "write:billing", "admin:all"},
	}

	// 1. Запись gob
	outFile, err := os.Create(path)
	if err != nil {
		log.Fatal(err)
	}
	if err := gob.NewEncoder(outFile).Encode(original); err != nil {
		outFile.Close()
		log.Fatal(err)
	}
	outFile.Close()

	// 2. Чтение gob
	inFile, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer inFile.Close()

	var restored UserSession
	if err := gob.NewDecoder(inFile).Decode(&restored); err != nil {
		log.Fatal(err)
	}

	fmt.Println("Восстановленная сессия из gob-файла:")
	fmt.Printf(" -> ID:     %d\n", restored.UserID)
	fmt.Printf(" -> User:   %s\n", restored.Username)
	fmt.Printf(" -> Scopes: %v\n", restored.Scopes)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Восстановленная сессия из gob-файла:
#  -> ID:     1001
#  -> User:   cloud_admin
#  -> Scopes: [read:users write:billing admin:all]
```

## Под капотом

`gob` передает в заголовке потока метаданные типов (type descriptions), поэтому поля декодируются даже при изменении порядка их объявления в структуре.

## Подводные камни

Сериализуются только публичные (экспортируемые с заглавной буквы) поля структуры.

## На собеседовании

**Вопрос с собеседования:** «Когда применять gob вместо JSON или Protobuf?»
**Ответ:** `gob` идеален для внутреннего взаимодействия между Go-сервисами (RPC) и локального кэширования структур Go на диск, так как не требует сторонних компиляторов (`protoc`) и работает быстрее JSON.
