# Полный цикл сериализации/десериализации JSON с тегами структур

## Условие

Напиши программу, которая сериализует структуру в JSON (`encoding/json`) и записывает в файл. Затем читает из файла и десериализует. Используй теги структур `json:"field_name"`.

## Теория

Теги структур `json:"field_name,omitempty"` задают маппинг между полями Go-структуры (PascalCase) и полями JSON документа (snake_case/camelCase).

## Решение по шагам

1. Объявим структуру `ClusterNode struct { NodeID string json:"node_id"; IP string json:"ip_address" }`.
2. Сериализуем через `json.MarshalIndent`.
3. Сохраним в файл через `os.WriteFile`.
4. Прочитаем файл и десериализуем через `json.Unmarshal`.
5. В `main` убедимся в корректности данных.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"log"
	"os"
)

type ClusterNode struct {
	NodeID    string `json:"node_id"`
	IPAddress string `json:"ip_address"`
	IsLeader  bool   `json:"is_leader"`
}

func main() {
	path := "node.json"

	original := ClusterNode{
		NodeID:    "node-alpha-01",
		IPAddress: "192.168.1.50",
		IsLeader:  true,
	}

	// 1. Маршалинг в JSON
	bytesJSON, err := json.MarshalIndent(original, "", "  ")
	if err != nil {
		log.Fatal(err)
	}

	if err := os.WriteFile(path, bytesJSON, 0644); err != nil {
		log.Fatal(err)
	}

	// 2. Чтение и анмаршалинг
	readBytes, err := os.ReadFile(path)
	if err != nil {
		log.Fatal(err)
	}

	var restored ClusterNode
	if err := json.Unmarshal(readBytes, &restored); err != nil {
		log.Fatal(err)
	}

	fmt.Println("Восстановленная структура из JSON:")
	fmt.Printf(" -> NodeID:   %s\n", restored.NodeID)
	fmt.Printf(" -> IP:       %s\n", restored.IPAddress)
	fmt.Printf(" -> Leader:   %v\n", restored.IsLeader)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Восстановленная структура из JSON:
#  -> NodeID:   node-alpha-01
#  -> IP:       192.168.1.50
#  -> Leader:   true
```

## Под капотом

`json.Unmarshal` использует рефлексию `reflect` для сопоставления JSON-ключей с тегами `json:"..."` структуры.

## Подводные камни

Тег `json:"-"` исключает поле из сериализации, а `omitempty` пропускает поле, если оно равно zero value.

## На собеседовании

**Вопрос с собеседования:** «Как работают быстрые JSON парсеры вроде easyjson или sonic?»
**Ответ:** Они используют кодогенерацию на этапе сборки (без рефлексии) или JIT-компиляцию инструкций AVX2/AVX-512, ускоряя сериализацию в 3–5 раз по сравнению со стандартным `encoding/json`.
