# Создание многоуровневых директорий через os.MkdirAll

## Условие

Создай вложенные директории `a/b/c` с помощью `os.MkdirAll`.

## Теория

`os.MkdirAll(path, perm)` создает все недостающие промежуточные директории в пути (аналог команды `mkdir -p`). Если путь уже существует, `os.MkdirAll` ничего не делает и безопасно возвращает `nil`.

## Решение по шагам

1. Зададим глубокий путь `storage/cache/daily/2026/09/`.
2. Вызовем `os.MkdirAll(path, 0755)`.
3. Убедимся в отсутствии ошибок.
4. Проверим существование самой глубокой папки через `os.Stat`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	deepPath := "storage/cache/daily/2026/09"

	// Создание всех промежуточных папок (mkdir -p)
	if err := os.MkdirAll(deepPath, 0755); err != nil {
		log.Fatalf("Ошибка MkdirAll: %v", err)
	}
	fmt.Printf("Дерево каталогов %s успешно создано\n", deepPath)

	// Проверка
	info, err := os.Stat(deepPath)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("Директория валидна: %v, Права: %v\n", info.IsDir(), info.Mode().Perm())

	// Очистка
	_ = os.RemoveAll("storage")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Дерево каталогов storage/cache/daily/2026/09 успешно создано
# Директория валидна: true, Права: -rwxr-xr-x
```

## Под капотом

`os.MkdirAll` рекурсивно проверяет существование каждого родительского каталога через `stat` и создает отсутствующие звенья цепи.

## Подводные камни

Права `perm` применяются ко всем создаваемым папкам в пути.

## На собеседовании

**Вопрос с собеседования:** «Почему вызов os.MkdirAll идемпотентен?»
**Ответ:** Потому что повторный вызов с тем же путем не возвращает ошибку `file exists`, а проверяет, что существующий путь является директорией, и возвращает `nil`.
