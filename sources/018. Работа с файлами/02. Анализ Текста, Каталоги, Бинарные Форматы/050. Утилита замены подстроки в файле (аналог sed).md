# Утилита замены подстроки в файле (аналог sed) с созданием бэкапа

## Условие

Напиши программу, которая заменяет все вхождения подстроки в файле на другую подстроку (аналог `sed`). Создай резервную копию оригинала.

## Теория

Безопасная замена в файле (in-place replacement) требует создания резервной копии (`filename.bak`) перед модификацией. Это защищает от потери данных при сбое питания в процессе записи.

## Решение по шагам

1. Создадим файл `settings.env`.
2. Создадим бэкап `settings.env.bak` через `os.WriteFile`.
3. Заменим подстроку через `bytes.ReplaceAll`.
4. Перезапишем оригинальный файл.
5. В `main` убедимся в наличии бэкапа и обновленного файла.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"log"
	"os"
)

func SedReplace(path, oldText, newText string) error {
	// 1. Читаем оригинал
	data, err := os.ReadFile(path)
	if err != nil {
		return fmt.Errorf("read: %w", err)
	}

	// 2. Создаем резервную копию .bak
	bakPath := path + ".bak"
	if err := os.WriteFile(bakPath, data, 0644); err != nil {
		return fmt.Errorf("backup failed: %w", err)
	}

	// 3. Заменяем вхождения
	updated := bytes.ReplaceAll(data, []byte(oldText), []byte(newText))

	// 4. Перезаписываем исходный файл
	if err := os.WriteFile(path, updated, 0644); err != nil {
		return fmt.Errorf("write updated: %w", err)
	}

	fmt.Printf("Файл %s успешно обновлен. Бэкап сохранен в %s\n", path, bakPath)
	return nil
}

func main() {
	path := "settings.env"
	_ = os.WriteFile(path, []byte("ENV=staging\nDB_HOST=staging.db.corp\nPORT=8080"), 0644)

	if err := SedReplace(path, "staging", "production"); err != nil {
		log.Fatal(err)
	}

	res, _ := os.ReadFile(path)
	fmt.Println("--- Обновленный файл ---")
	fmt.Println(string(res))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Файл settings.env успешно обновлен. Бэкап сохранен в settings.env.bak
# --- Обновленный файл ---
# ENV=production
# DB_HOST=production.db.corp
# PORT=8080
```

## Под капотом

`bytes.ReplaceAll` выполняет замену среза байт без конвертации в `string`, снижая нагрузку на сборщик мусора.

## Подводные камни

Убедитесь, что права доступа бэкапа совпадают с правами исходного файла.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать атомарную замену файла без риска повреждения при краше ОС?»
**Ответ:** Записать обновленные данные во временный файл `os.CreateTemp` в том же каталоге, вызвать `file.Sync()` для сброса на физический диск, а затем выполнить атомарный системный вызов `os.Rename(tempName, targetName)`.
