# Кроссплатформенная манипуляция путями через path/filepath

## Условие

Используйте функции `path/filepath.Join`, `filepath.Dir`, `filepath.Base`, `filepath.Ext` для разбора и построения путей.

### Исходная формулировка

Используйте функции `path/filepath.Join`, `filepath.Dir`, `filepath.Base`, `filepath.Ext` для разбора и построения путей.

## Теория

Пакет `path/filepath` автоматически учитывает специфику операционной системы (разделитель `/` в Linux/macOS и `\` в Windows):
- `filepath.Join`: соединение фрагментов пути с очисткой `..` и `//`.
- `filepath.Dir`: извлечение родительского каталога.
- `filepath.Base`: получение финального имени файла.
- `filepath.Ext`: извлечение расширения файла.

## Решение по шагам

1. Сформируем путь через `filepath.Join("var", "log", "app", "service.log.gz")`.
2. Извлечем директорию через `filepath.Dir`.
3. Извлечем имя файла через `filepath.Base`.
4. Извлечем расширение через `filepath.Ext`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"path/filepath"
)

func main() {
	// Кроссплатформенное объединение путей
	fullPath := filepath.Join("var", "log", "subsystem", "audit_report.json")
	fmt.Printf("Полный путь: %s\n", fullPath)

	// Разбор компонентов пути
	dir := filepath.Dir(fullPath)
	base := filepath.Base(fullPath)
	ext := filepath.Ext(fullPath)

	fmt.Printf(" -> Директория (Dir):  %s\n", dir)
	fmt.Printf(" -> Имя файла (Base):  %s\n", base)
	fmt.Printf(" -> Расширение (Ext):  %s\n", ext)

	// Очистка относительных переходов
	dirtyPath := filepath.Join("var", "log", "..", "opt", "app", ".", "bin")
	cleanPath := filepath.Clean(dirtyPath)
	fmt.Printf(" -> Очищенный путь:    %s\n", cleanPath)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Полный путь: var/log/subsystem/audit_report.json
#  -> Директория (Dir):  var/log/subsystem
#  -> Имя файла (Base):  audit_report.json
#  -> Расширение (Ext):  .json
#  -> Очищенный путь:    var/opt/app/bin
```

## Под капотом

`filepath.Clean` нормализует путь лексически без выполнения системных вызовов к диску.

## Подводные камни

Для URL-адресов в вебе нужно использовать пакет `path`, а не `path/filepath`, так как URL всегда использует прямой слэш `/`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие пакета path от path/filepath?»
**Ответ:** Пакет `path` оперирует исключительно путями со слэшем `/` (стандарт URL, zip-архивы, protobuf). Пакет `path/filepath` адаптируется под ОС хоста (использует `\` на Windows и `/` на Unix).
