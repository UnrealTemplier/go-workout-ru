# Чтение содержимого каталога через os.ReadDir

## Условие

Прочитай содержимое директории с помощью `os.ReadDir`. Выведи имена всех файлов.

## Теория

Функция `os.ReadDir(dirname)` (Go 1.16+) возвращает срез `[]fs.DirEntry`, отсортированный по имени файлов. Это современная и быстрая замена устаревшему методу `os.ReadDirnames`/`ioutil.ReadDir`.

## Решение по шагам

1. Создадим тестовую папку `workspace/` с несколькими файлами.
2. Вызовем `entries, err := os.ReadDir("workspace")`.
3. В цикле выведем имя каждого элемента и признак директории `entry.IsDir()`.
4. В `main` убедимся в сортировке.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	dir := "workspace"
	_ = os.MkdirAll(dir+"/nested_dir", 0755)
	_ = os.WriteFile(dir+"/config.json", []byte("{}"), 0644)
	_ = os.WriteFile(dir+"/main.go", []byte("package main"), 0644)
	_ = os.WriteFile(dir+"/readme.md", []byte("# Docs"), 0644)

	entries, err := os.ReadDir(dir)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Содержимое директории %s:\n", dir)
	for _, entry := range entries {
		itemType := "FILE"
		if entry.IsDir() {
			itemType = "DIR "
		}
		fmt.Printf("[%s] %s\n", itemType, entry.Name())
	}

	_ = os.RemoveAll(dir)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Содержимое директории workspace:
# [FILE] config.json
# [FILE] main.go
# [DIR ] nested_dir
# [FILE] readme.md
```

## Под капотом

`os.ReadDir` читает записи пакетами через системный вызов `getdents64` и сортирует их с помощью `sort.Slice`.

## Подводные камни

`os.ReadDir` считывает весь каталог целиком в память. Для каталогов с миллионами файлов используют метод `file.ReadDir(n)` для пагинации.

## На собеседовании

**Вопрос с собеседования:** «Почему os.ReadDir быстрее ioutil.ReadDir?»
**Ответ:** `ioutil.ReadDir` вызывал `stat` для каждого файла в папке для заполнения `FileInfo`. `os.ReadDir` возвращает легкие структуры `DirEntry`, беря тип файла напрямую из каталога ядра без единого лишнего вызова `stat`.
