# Безопасная проверка существования файла перед чтением

## Условие

**Проверка существования**: Напиши функцию, которая с помощью `os.Stat` и `os.IsNotExist(err)` проверяет, существует ли файл перед тем, как попытаться его прочесть.

## Теория

Функция проверки `os.Stat` возвращает метаданные файла. Проверка `os.IsNotExist(err)` позволяет выдать пользователю дружелюбное сообщение об ошибке конфигурации.

## Решение по шагам

1. Создадим функцию `SafeRead(path string) ([]byte, error)`.
2. Проверим существование через `os.Stat`.
3. Если файл существует — прочитаем через `os.ReadFile`.
4. В `main` протестируем успешный и неуспешный сценарии.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"os"
)

func SafeRead(path string) ([]byte, error) {
	_, err := os.Stat(path)
	if err != nil {
		if os.IsNotExist(err) {
			return nil, fmt.Errorf("SafeRead: файл %q не найден", path)
		}
		return nil, fmt.Errorf("SafeRead: ошибка доступа: %w", err)
	}

	return os.ReadFile(path)
}

func main() {
	_ = os.WriteFile("existing.txt", []byte("Content data"), 0644)

	if data, err := SafeRead("existing.txt"); err == nil {
		fmt.Printf("Прочитано: %s\n", string(data))
	}

	if _, err := SafeRead("not_found.txt"); err != nil {
		fmt.Printf("Отказ: %v\n", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Прочитано: Content data
# Отказ: SafeRead: файл "not_found.txt" не найден
```

## Под капотом

`os.Stat` возвращает ошибку `*fs.PathError`, из которой функция `os.IsNotExist` извлекает код `syscall.ENOENT`.

## Подводные камни

В конкурентной среде файл может быть удален между `os.Stat` и `os.ReadFile`. В критическом коде лучше сразу вызывать `os.Open` и обрабатывать ошибку.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go 1.13+ рекомендуют errors.Is(err, os.ErrNotExist) вместо os.IsNotExist(err)?»
**Ответ:** Потому что `errors.Is` умеет разворачивать цепочки обернутых ошибок (`fmt.Errorf("step: %w", err)`), тогда как `os.IsNotExist` проверяет только верхний тип ошибки и ломается на обертках.
