# Парсинг TSV/CSV с разделителем табуляции и вывод форматированной таблицы

## Условие

Напиши программу, которая читает CSV-файл (или файл с разделителем табуляции) и выводит данные в виде отформатированной таблицы. Используй `strings.Split` или `encoding/csv`.

### Исходная формулировка

Напиши программу, которая читает CSV-файл (или файл с разделителем табуляции) и выводит данные в виде отформатированной таблицы. Используй `strings.Split` или `encoding/csv`.

## Теория

Пакет `encoding/csv` поддерживает произвольные разделители колонок через установку `reader.Comma = '\t'` для файлов TSV (Tab-Separated Values).

## Решение по шагам

1. Создадим TSV файл `servers.tsv` с табуляцией в качестве разделителя.
2. Инициализируем `csv.NewReader(f)` и зададим `r.Comma = '\t'`.
3. Прочитаем все строки через `r.ReadAll()`.
4. Выведем отформатированную таблицу с выравниванием колонок.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/csv"
	"fmt"
	"log"
	"os"
)

func main() {
	path := "servers.tsv"
	tsvData := "Host\tIP\tRegion\tStatus\napp-01\t10.0.1.10\teu-central-1\tUP\ndb-master\t10.0.2.15\teu-central-1\tUP\ncache-01\t10.0.3.20\tus-east-1\tDOWN\n"
	_ = os.WriteFile(path, []byte(tsvData), 0644)

	file, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	reader := csv.NewReader(file)
	reader.Comma = '\t' // Настройка разделителя (Tab)

	records, err := reader.ReadAll()
	if err != nil {
		log.Fatal(err)
	}

	fmt.Println("=== СЕРВЕРНАЯ ИНФРАСТРУКТУРА (TSV) ===")
	for i, row := range records {
		if i == 0 {
			fmt.Printf("%-12s | %-14s | %-14s | %s\n", row[0], row[1], row[2], row[3])
			fmt.Println("-------------+----------------+----------------+--------")
		} else {
			fmt.Printf("%-12s | %-14s | %-14s | %s\n", row[0], row[1], row[2], row[3])
		}
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# === СЕРВЕРНАЯ ИНФРАСТРУКТУРА (TSV) ===
# Host         | IP             | Region         | Status
# -------------+----------------+----------------+--------
# app-01       | 10.0.1.10      | eu-central-1   | UP
# db-master    | 10.0.2.15      | eu-central-1   | UP
# cache-01     | 10.0.3.20      | us-east-1      | DOWN
```

## Под капотом

`csv.Reader` парсит символы построчно, удаляя разделитель `\t` и возвращая срез строк `[]string`.

## Подводные камни

По умолчанию `csv.Reader` требует одинакового количества колонок во всех строках. Если строки имеют разную длину, установите `reader.FieldsPerRecord = -1`.

## На собеседовании

**Вопрос с собеседования:** «Почему в BigData TSV предпочтительнее CSV?»
**Ответ:** Табуляция (`\t`) практически никогда не встречается внутри текстовых полей, что исключает необходимость сложного экранирования кавычек и ускоряет парсинг в несколько раз (Hadoop/ClickHouse/Spark).
