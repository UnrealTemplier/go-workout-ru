# Установка и валидация прав доступа к файлу через FileMode.Perm()

## Условие

Создай файл с правами доступа `0644` (`os.Create` + `os.Chmod` или `os.OpenFile` с правами). Проверь права через `os.Stat` и `FileMode.Perm()`.

## Теория

`FileMode.Perm()` возвращает биты разрешений Unix (`0777` маску). Это позволяет проверить, имеет ли файл правильные права чтения и записи для владельца, группы и остальных пользователей.

## Решение по шагам

1. Создадим файл `secure.cfg` с правами `0600` (чтение/запись только владельцем).
2. Вызовем `os.Chmod("secure.cfg", 0600)`.
3. Запросим `info.Mode().Perm()`.
4. Сравним биты с константой `0600`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	filename := "secure.cfg"
	_ = os.WriteFile(filename, []byte("API_SECRET_KEY=12345"), 0644)

	// Устанавливаем строгие права: -rw------- (0600)
	if err := os.Chmod(filename, 0600); err != nil {
		log.Fatal(err)
	}

	info, err := os.Stat(filename)
	if err != nil {
		log.Fatal(err)
	}

	perm := info.Mode().Perm()
	fmt.Printf("Файл: %s\n", filename)
	fmt.Printf("Права в строковом виде: %v\n", perm)
	fmt.Printf("Права в восьмеричном:   %04o\n", perm)

	if perm == 0600 {
		fmt.Println("Проверка безопасности пройдена: файл защищен от чтения другими пользователями")
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Файл: secure.cfg
# Права в строковом виде: -rw-------
# Права в восьмеричном:   0600
# Проверка безопасности пройдена: файл защищен от чтения другими пользователями
```

## Под капотом

`FileMode` — это 32-битное целое число (`uint32`), где младшие 9 бит хранят стандартные Unix rwxrwxrwx разрешения.

## Подводные камни

В Windows большинство битов Unix-прав игнорируются, поддерживается только атрибут Read-Only.

## На собеседовании

**Вопрос с собеседования:** «Как проверить, что файл является исполняемым скриптом в Linux на Go?»
**Ответ:** Проверить наличие бита исполнения: `if info.Mode().Perm()&0111 != 0 { /* файл исполняемый */ }`.
