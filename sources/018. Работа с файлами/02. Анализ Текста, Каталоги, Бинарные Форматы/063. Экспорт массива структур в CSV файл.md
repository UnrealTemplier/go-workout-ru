# Экспорт массива структур в CSV файл через encoding/csv

## Условие

Запиши массив структур в текстовый файл формата CSV (используй `encoding/csv`).

## Теория

Для записи массива структур в CSV их поля сериализуются в строковые срезы `[]string` и передаются в `csv.Writer`.

## Решение по шагам

1. Объявим структуру `Product struct { ID int; Title string; Price float64 }`.
2. Создадим файл `products.csv`.
3. Запишем заголовок таблицы.
4. В цикле преобразуем каждую структуру в `[]string` и вызовем `w.Write`.
5. Вызовем `w.Flush()`.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/csv"
	"fmt"
	"log"
	"os"
	"strconv"
)

type Product struct {
	ID    int
	Title string
	Price float64
}

func main() {
	path := "catalog.csv"
	items := []Product{
		{ID: 101, Title: "SSD NVMe 1TB", Price: 89.99},
		{ID: 102, Title: "RAM DDR5 32GB", Price: 129.50},
		{ID: 103, Title: "CPU Core i9", Price: 499.00},
	}

	file, err := os.Create(path)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	w := csv.NewWriter(file)
	defer w.Flush()

	// Заголовок
	_ = w.Write([]string{"ID", "Title", "Price"})

	// Строки данных
	for _, p := range items {
		record := []string{
			strconv.Itoa(p.ID),
			p.Title,
			strconv.FormatFloat(p.Price, 'f', 2, 64),
		}
		if err := w.Write(record); err != nil {
			log.Fatal(err)
		}
	}

	w.Flush()
	if err := w.Error(); err != nil {
		log.Fatal(err)
	}

	data, _ := os.ReadFile(path)
	fmt.Println("--- catalog.csv ---")
	fmt.Print(string(data))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- catalog.csv ---
# ID,Title,Price
# 101,SSD NVMe 1TB,89.99
# 102,RAM DDR5 32GB,129.50
# 103,CPU Core i9,499.00
```

## Под капотом

`strconv.FormatFloat` форматирует числа с плавающей точкой без потери точности и аллокаций памяти.

## Подводные камни

Если поле содержит запятую (например `"Mouse, Optical"`), `csv.Writer` автоматически обернет поле в кавычки `\"Mouse, Optical\"` по RFC 4180.

## На собеседовании

**Вопрос с собеседования:** «Как безопасно экранировать поля с кавычками внутри CSV?»
**Ответ:** Пакет `encoding/csv` делает это автоматически: кавычка внутри поля удваивается (`"John ""The Boss"" Doe"`).
