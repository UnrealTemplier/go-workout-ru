# Поиск и фильтрация всех .txt файлов через filepath.WalkDir

## Условие

Используйте пакет `path/filepath` для обхода директории и вывода путей всех `.txt` файлов (walk).

## Теория

`filepath.WalkDir` (Go 1.16+) — наиболее производительный способ обхода файловой системы в Go, фильтрующий файлы по расширению `filepath.Ext(path) == ".txt"`.

## Решение по шагам

1. Создадим дерево тестовых файлов (`.txt`, `.log`, `.json`).
2. Вызовем `filepath.WalkDir`.
3. Отфильтруем папки `if d.IsDir()`.
4. Сверим `filepath.Ext(path) == ".txt"`.
5. Распечатаем найденные пути.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io/fs"
	"log"
	"os"
	"path/filepath"
)

func findTxtFiles(root string) ([]string, error) {
	var txtPaths []string

	err := filepath.WalkDir(root, func(path string, d fs.DirEntry, err error) error {
		if err != nil {
			return err
		}
		if !d.IsDir() && filepath.Ext(path) == ".txt" {
			txtPaths = append(txtPaths, path)
		}
		return nil
	})

	return txtPaths, err
}

func main() {
	root := "docs_vault"
	_ = os.MkdirAll(root+"/sub1/sub2", 0755)
	_ = os.WriteFile(root+"/guide.txt", []byte("guide"), 0644)
	_ = os.WriteFile(root+"/sub1/faq.txt", []byte("faq"), 0644)
	_ = os.WriteFile(root+"/sub1/sub2/license.txt", []byte("license"), 0644)
	_ = os.WriteFile(root+"/sub1/image.png", []byte("png"), 0644)

	defer os.RemoveAll(root)

	found, err := findTxtFiles(root)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Найдено %d текстовых файлов (.txt):\n", len(found))
	for _, p := range found {
		fmt.Printf(" -> %s\n", p)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Найдено 3 текстовых файлов (.txt):
#  -> docs_vault/guide.txt
#  -> docs_vault/sub1/faq.txt
#  -> docs_vault/sub1/sub2/license.txt
```

## Под капотом

`filepath.WalkDir` получает тип файла `d.Type()` напрямую из `DirEntry` без `stat`.

## Подводные камни

В Windows пути содержат обратные слэши `\`. Для унификации путей используют `filepath.ToSlash(path)`.

## На собеседовании

**Вопрос с собеседования:** «Как пропустить всю ветку каталога (например, .git или node_modules) при обходе?»
**Ответ:** Внутри коллбэка проверить `if d.IsDir() && d.Name() == "node_modules" { return filepath.SkipDir }`. Обходчик немедленно пропустит всю эту папку.
