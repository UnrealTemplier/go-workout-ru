# Инспекция метаданных файла через os.Stat: размер, права, ModTime

## Условие

Получите информацию о файле (размер, права доступа, время модификации) через `os.Stat` и выведите её в человекочитаемом формате.

## Теория

Интерфейс `fs.FileInfo`, возвращаемый функцией `os.Stat(name)`, предоставляет исчерпывающие метаданные о файловом объекте: `Name()`, `Size()`, `Mode()`, `ModTime()`, `IsDir()`, `Sys()`.

## Решение по шагам

1. Создадим файл `archive.tar.gz`.
2. Вызовем `info, err := os.Stat("archive.tar.gz")`.
3. Распечатаем все свойства в форматированном виде.
4. В `main` проверим вывод метаданных.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
	"time"
)

func main() {
	path := "archive.tar.gz"
	_ = os.WriteFile(path, []byte("COMPRESSED_BINARY_PAYLOAD_CHUNK_DATA"), 0644)

	info, err := os.Stat(path)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Println("--- Метаданные файла ---")
	fmt.Printf("Имя файла:             %s\n", info.Name())
	fmt.Printf("Размер на диске:       %d байт\n", info.Size())
	fmt.Printf("Права доступа (Mode):  %v\n", info.Mode())
	fmt.Printf("Является каталогом:    %v\n", info.IsDir())
	fmt.Printf("Время модификации:     %s\n", info.ModTime().Format(time.RFC1123))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- Метаданные файла ---
# Имя файла:             archive.tar.gz
# Размер на диске:       36 байт
# Права доступа (Mode):  -rw-r--r--
# Является каталогом:    false
# Время модификации:     Wed, 02 Sep 2026 18:30:00 +04
```

## Под капотом

`os.Stat` разыменовывает симлинки. Если нужно получить свойства самого симлинка, используют `os.Lstat`.

## Подводные камни

`info.Size()` для каталогов в Linux возвращает размер индексного дескриптора (обычно 4096 байт), а не суммарный размер файлов внутри!

## На собеседовании

**Вопрос с собеседования:** «В чем разница между os.Stat и os.Lstat?»
**Ответ:** `os.Stat` переходит по символическим ссылкам (follow symlink) и возвращает метаданные целевого файла. `os.Lstat` возвращает информацию о самом файле-симлинке (`ModeSymlink`).
