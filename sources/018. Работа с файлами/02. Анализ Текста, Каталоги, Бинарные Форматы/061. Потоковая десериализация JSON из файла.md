# Потоковая десериализация JSON из файла через json.NewDecoder

## Условие

Прочитай структуру из JSON файла с помощью `json.NewDecoder`.

## Теория

`json.NewDecoder(r io.Reader)` парсит JSON-поток непосредственно из файла без полной загрузки всего содержимого в строковую память.

## Решение по шагам

1. Создадим файл `app_settings.json`.
2. Объявим структуру `AppSettings struct { AppName string; Debug bool; Port int }`.
3. Откроем файл через `os.Open`.
4. Вызовем `json.NewDecoder(file).Decode(&settings)`.
5. В `main` распечатаем поля структуры.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"log"
	"os"
)

type AppSettings struct {
	AppName string `json:"app_name"`
	Debug   bool   `json:"debug"`
	Port    int    `json:"port"`
}

func main() {
	path := "app_settings.json"
	_ = os.WriteFile(path, []byte(`{"app_name": "BillingGateway", "debug": false, "port": 9090}`), 0644)

	file, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	var settings AppSettings
	if err := json.NewDecoder(file).Decode(&settings); err != nil {
		log.Fatalf("Ошибка парсинга JSON: %v", err)
	}

	fmt.Println("Успешно распарсен JSON конфиг:")
	fmt.Printf(" -> Название: %s\n", settings.AppName)
	fmt.Printf(" -> Отладка:  %v\n", settings.Debug)
	fmt.Printf(" -> Порт:     %d\n", settings.Port)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Успешно распарсен JSON конфиг:
#  -> Название: BillingGateway
#  -> Отладка:  false
#  -> Порт:     9090
```

## Под капотом

`json.NewDecoder` использует лексер и стейт-машину, парся токен за токеном прямо из буфера `io.Reader`.

## Подводные камни

Передавайте в `Decode` указатель на структуру `&settings`, иначе поля структуры не заполнятся.

## На собеседовании

**Вопрос с собеседования:** «Как запретить json.NewDecoder парсить неизвестные поля (Unknown Fields)?»
**Ответ:** Вызвать метод `decoder.DisallowUnknownFields()` перед вызовом `Decode()`. Если JSON содержит лишние поля, декодер вернет ошибку.
