# Реализация утилиты фильтрации строк Grep на Go

## Условие

Сканируйте файл построчно, выведите строки, содержащие заданное слово (простой grep).

## Теория

Построчная фильтрация через `bufio.Scanner` и `strings.Contains` позволяет находить нужные фрагменты в терабайтных логах с нулевой нагрузкой на RAM.

## Решение по шагам

1. Создадим тестовый лог `access.log`.
2. Реализуем функцию `Grep(path, pattern string) error`.
3. В цикле сканирования проверим `strings.Contains(line, pattern)`.
4. Выведем совпавшие строки с их порядковыми номерами.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"log"
	"os"
	"strings"
)

func Grep(path, pattern string) error {
	file, err := os.Open(path)
	if err != nil {
		return err
	}
	defer file.Close()

	scanner := bufio.NewScanner(file)
	lineNum := 1

	for scanner.Scan() {
		line := scanner.Text()
		if strings.Contains(line, pattern) {
			fmt.Printf("%s:%d: %s\n", path, lineNum, line)
		}
		lineNum++
	}

	return scanner.Err()
}

func main() {
	path := "access.log"
	_ = os.WriteFile(path, []byte("GET /index.html 200\nPOST /login 401\nGET /api/v1/users 200\nPOST /checkout 500"), 0644)

	fmt.Println("Поиск ошибок (HTTP 500 и 401):")
	_ = Grep(path, "500")
	_ = Grep(path, "401")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Поиск ошибок (HTTP 500 и 401):
# access.log:4: POST /checkout 500
# access.log:2: POST /login 401
```

## Под капотом

`strings.Contains` использует оптимизированный алгоритм поиска подстроки Rabin-Karp / Boyer-Moore в зависимости от длины паттерна.

## Подводные камни

Для регистронезависимого поиска используйте `strings.Contains(strings.ToLower(line), strings.ToLower(pattern))`.

## На собеседовании

**Вопрос с собеседования:** «Как оптимизировать Grep на многоядерном сервере для 100 файлов логов?»
**Ответ:** Запустить пул горутин (воркеров), где каждая горутина независимо читает свой файл и отправляет результаты в общий канал `chan MatchResult`.
