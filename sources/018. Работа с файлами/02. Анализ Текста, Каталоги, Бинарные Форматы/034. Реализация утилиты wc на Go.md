# Реализация утилиты wc на Go: подсчет строк, слов и символов через SplitFunc

## Условие

Напиши программу, которая подсчитывает количество строк, слов и символов в текстовом файле (аналог `wc`). Используй `bufio.Scanner` с разными `SplitFunc`.

## Теория

`bufio.Scanner` настраивается с помощью функции разделения `scanner.Split(fn)`:
- `bufio.ScanLines` — построчное чтение.
- `bufio.ScanWords` — разделение по пробельным символам (слова).
- `bufio.ScanRunes` / `bufio.ScanBytes` — подсчет символов/байт.

## Решение по шагам

1. Создадим тестовый файл `document.txt`.
2. Реализуем функцию подсчета строк `countTokens(path, bufio.ScanLines)`.
3. Реализуем подсчет слов `countTokens(path, bufio.ScanWords)` и рун `countTokens(path, bufio.ScanRunes)`.
4. В `main` выведем статистику в формате утилиты Unix `wc`.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"log"
	"os"
)

func countTokens(path string, splitFn bufio.SplitFunc) (int, error) {
	file, err := os.Open(path)
	if err != nil {
		return 0, err
	}
	defer file.Close()

	scanner := bufio.NewScanner(file)
	scanner.Split(splitFn)

	count := 0
	for scanner.Scan() {
		count++
	}
	return count, scanner.Err()
}

func main() {
	path := "document.txt"
	_ = os.WriteFile(path, []byte("Go is an open source programming language\nthat makes it easy to build simple, reliable, and efficient software."), 0644)

	lines, err := countTokens(path, bufio.ScanLines)
	if err != nil {
		log.Fatal(err)
	}

	words, _ := countTokens(path, bufio.ScanWords)
	runes, _ := countTokens(path, bufio.ScanRunes)

	fmt.Printf("Файл: %s\n", path)
	fmt.Printf(" -> Строк:    %d\n", lines)
	fmt.Printf(" -> Слов:     %d\n", words)
	fmt.Printf(" -> Символов: %d\n", runes)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Файл: document.txt
#  -> Строк:    2
#  -> Слов:     17
#  -> Символов: 111
```

## Под капотом

`bufio.ScanWords` использует `unicode.IsSpace` для пропуска пробелов, табуляций и переносов строк.

## Подводные камни

Для подсчета строк, слов и символов за один проход эффективнее написать свой кастомный `io.Reader` или парсить байты в одном цикле.

## На собеседовании

**Вопрос с собеседования:** «Как написать собственную функцию SplitFunc для разделения по кастомному разделителю (например, символ null-терминатора \x00)?»
**Ответ:** Сигнатура: `func(data []byte, atEOF bool) (advance int, token []byte, err error)`. Находим `bytes.IndexByte(data, 0)`. Если найден — возвращаем `idx + 1, data[:idx], nil`. Если нет и `atEOF`, возвращаем `len(data), data, nil`.
