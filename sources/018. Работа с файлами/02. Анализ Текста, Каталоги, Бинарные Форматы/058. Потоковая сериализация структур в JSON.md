# Потоковая сериализация структур в JSON через json.NewEncoder

## Условие

Запиши структуру в файл в формате JSON с помощью `encoding/json` и `json.NewEncoder`.

## Теория

`json.NewEncoder(w io.Writer)` стримит сериализованные байты напрямую в целевой файл, исключая создание промежуточного большого среза `[]byte` в оперативной памяти (в отличие от `json.Marshal`). Метод `SetIndent` форматирует JSON с отступами.

## Решение по шагам

1. Объявим структуру `DatabaseConfig`.
2. Создадим файл `db_config.json`.
3. Инициализируем `encoder := json.NewEncoder(file)`.
4. Настроим отступы `encoder.SetIndent("", "  ")`.
5. Вызовем `encoder.Encode(cfg)`.
6. В `main` проверим форматированный JSON файл.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"log"
	"os"
)

type DatabaseConfig struct {
	Host         string   `json:"host"`
	Port         int      `json:"port"`
	DatabaseName string   `json:"db_name"`
	MaxConns     int      `json:"max_conns"`
	Replicas     []string `json:"replicas"`
}

func main() {
	path := "db_config.json"

	cfg := DatabaseConfig{
		Host:         "pg-cluster.internal",
		Port:         5432,
		DatabaseName: "orders_db",
		MaxConns:     100,
		Replicas:     []string{"pg-replica-01", "pg-replica-02"},
	}

	file, err := os.Create(path)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	// Потоковый энкодер с отступами для красивого форматирования
	encoder := json.NewEncoder(file)
	encoder.SetIndent("", "  ")

	if err := encoder.Encode(cfg); err != nil {
		log.Fatalf("Ошибка сериализации: %v", err)
	}

	data, _ := os.ReadFile(path)
	fmt.Println("--- db_config.json ---")
	fmt.Print(string(data))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# --- db_config.json ---
# {
#   "host": "pg-cluster.internal",
#   "port": 5432,
#   "db_name": "orders_db",
#   "max_conns": 100,
#   "replicas": [
#     "pg-replica-01",
#     "pg-replica-02"
#   ]
# }
```

## Под капотом

`json.NewEncoder.Encode` автоматически добавляет символ перевода строки `\n` в конец вывода.

## Подводные камни

Поля структуры обязательно должны быть экспортируемыми (начинаться с заглавной буквы), иначе `json.Encode` их проигнорирует.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между json.Marshal и json.NewEncoder(w).Encode()?»
**Ответ:** `json.Marshal` сериализует весь объект в срез `[]byte` в куче. `json.NewEncoder` пишет результат порциями напрямую в `io.Writer`, что снижает пиковое потребление RAM при отправке в сеть или файл.
