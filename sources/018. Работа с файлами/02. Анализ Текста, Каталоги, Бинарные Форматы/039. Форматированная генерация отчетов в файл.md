# Форматированная генерация отчетов в файл через fmt.Fprintf

## Условие

Используйте `fmt.Fprintf` для форматированной записи в файл (создайте простой отчёт).

## Теория

Функция `fmt.Fprintf(w io.Writer, format, args...)` принимает любой интерфейс `io.Writer` (включая `*os.File`), позволяя записывать форматированные таблицы, отчеты и метрики.

## Решение по шагам

1. Создадим файл `report.txt`.
2. Добавим `defer f.Close()`.
3. Запишем форматированный заголовок и строки таблицы через `fmt.Fprintf`.
4. В `main` прочитаем сгенерированный отчет.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
	"time"
)

type ServiceStat struct {
	Name    string
	RPS     int
	Latency float64
	Errors  int
}

func main() {
	path := "service_report.txt"
	f, err := os.Create(path)
	if err != nil {
		log.Fatal(err)
	}
	defer f.Close()

	stats := []ServiceStat{
		{"auth-service", 4500, 1.25, 0},
		{"billing-service", 1200, 8.40, 2},
		{"order-service", 8900, 3.15, 1},
	}

	fmt.Fprintf(f, "=== СИСТЕМНЫЙ ОТЧЕТ МИКРОСЕРВИСОВ ===\n")
	fmt.Fprintf(f, "Дата формирования: %s\n\n", time.Now().Format("2006-01-02 15:04:05"))
	fmt.Fprintf(f, "%-18s | %-8s | %-12s | %s\n", "Service Name", "RPS", "Latency (ms)", "Errors")
	fmt.Fprintf(f, "-------------------+----------+--------------+--------\n")

	for _, s := range stats {
		fmt.Fprintf(f, "%-18s | %-8d | %-12.2f | %d\n", s.Name, s.RPS, s.Latency, s.Errors)
	}

	data, _ := os.ReadFile(path)
	fmt.Print(string(data))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# === СИСТЕМНЫЙ ОТЧЕТ МИКРОСЕРВИСОВ ===
# Дата формирования: 2026-09-02 18:30:00
# 
# Service Name       | RPS      | Latency (ms) | Errors
# -------------------+----------+--------------+--------
# auth-service       | 4500     | 1.25         | 0
# billing-service    | 1200     | 8.40         | 2
# order-service      | 8900     | 3.15         | 1
```

## Под капотом

`fmt.Fprintf` форматирует строку во внутренний буфер и вызывает метод `w.Write(buf)`.

## Подводные камни

Для высоконагруженной генерации терабайтных отчетов оборачивайте `*os.File` в `bufio.NewWriter(f)` перед передачей в `fmt.Fprintf`.

## На собеседовании

**Вопрос с собеседования:** «Почему fmt.Fprintf(f, ...) может быть неэффективен без bufio.Writer?»
**Ответ:** Потому что каждый вызов `fmt.Fprintf` совершает отдельный системный вызов `write(2)`. Оборачивание в `bufio.Writer` агрегирует мелкие форматированные строки в память и отправляет их на диск крупными пачками по 4KB.
