# Запись ASCII байтов в файл через file.Write

## Условие

**Запись среза байт**: Запишите в файл массив байт (например, `[]byte{65, 66, 67, 10}`) с помощью метода `file.Write`. Проверьте, какие символы появились в файле.

## Теория

Байты `65, 66, 67, 10` в таблице кодировки ASCII соответствуют символам `'A', 'B', 'C', '\n'`. Метод `file.Write(b)` записывает сырые байты без преобразований.

## Решение по шагам

1. Создадим срез байт `[]byte{65, 66, 67, 10}`.
2. Создадим файл `raw_ascii.txt`.
3. Запишем срез через `file.Write(bytes)`.
4. Прочитаем файл как строку и убедимся в появлении `"ABC\n"`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	path := "raw_ascii.txt"
	file, err := os.Create(path)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	// ASCII коды: 65='A', 66='B', 67='C', 10='\n'
	rawBytes := []byte{65, 66, 67, 10}

	n, err := file.Write(rawBytes)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("Записано %d сырых байт\n", n)

	content, _ := os.ReadFile(path)
	fmt.Printf("Текстовое представление файла: %q\n", string(content))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Записано 4 сырых байт
# Текстовое представление файла: "ABC\n" 
```

## Под капотом

`file.Write` передает указатель на срез напрямую в системный вызов `write(2)` ядра OS.

## Подводные камни

Символ `\n` имеет ASCII код 10 (Line Feed). В Windows для DOS-формата требуется `\r\n` (коды 13 и 10).

## На собеседовании

**Вопрос с собеседования:** «Какова разница между file.Write([]byte) и file.WriteString(string)?»
**Ответ:** На функциональном уровне они идентичны. Но `file.WriteString` оптимизирован компилятором для работы со строками без аллокации временного среза `[]byte`.
