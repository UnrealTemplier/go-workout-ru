# Низкоуровневое чтение бинарных данных через file.Read и обработка io.EOF

## Условие

Прочитай бинарные данные из файла с помощью `file.Read`. Обработай ошибку `io.EOF`.

## Теория

Метод `file.Read(b []byte)` заполняет слайс `b` байтами из файла. При достижении конца файла возвращается ошибка `io.EOF`. Если прочитана часть байт (\(n > 0\)), их необходимо обработать до выхода.

## Решение по шагам

1. Создадим бинарный файл с произвольными байтами.
2. Откроем файл через `os.Open`.
3. В цикле вызовем `file.Read(chunk)`.
4. Проверим `errors.Is(err, io.EOF)` для корректного выхода.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
	"io"
	"log"
	"os"
)

func main() {
	path := "raw_bytes.bin"
	_ = os.WriteFile(path, []byte{0x01, 0x02, 0x03, 0x04, 0x05, 0x06, 0x07}, 0644)

	file, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	chunk := make([]byte, 3) // Читаем порциями по 3 байта
	iteration := 1

	for {
		n, err := file.Read(chunk)
		if n > 0 {
			fmt.Printf("Итерация %d: прочитано %d байт -> % X\n", iteration, n, chunk[:n])
			iteration++
		}
		if err != nil {
			if errors.Is(err, io.EOF) {
				fmt.Println("Достигнут конец файла (io.EOF)")
				break
			}
			log.Fatalf("Ошибка I/O: %v", err)
		}
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Итерация 1: прочитано 3 байт -> 01 02 03
# Итерация 2: прочитано 3 байт -> 04 05 06
# Итерация 3: прочитано 1 байт -> 07
# Достигнут конец файла (io.EOF)
```

## Под капотом

`file.Read` напрямую вызывает системный вызов `read(2)` ядра операционной системы.

## Подводные камни

Никогда не используйте полный срез `chunk` при выводе — используйте только вычитанную часть `chunk[:n]`.

## На собеседовании

**Вопрос с собеседования:** «Почему метод io.Reader.Read не гарантирует заполнение всего переданного среза buf?»
**Ответ:** По контракту `io.Reader`, метод возвращает столько байт, сколько доступно в данный момент (например, при чтении из сетевого сокета или пайпа). Для гарантированного заполнения всего буфера используют `io.ReadFull(r, buf)`.
