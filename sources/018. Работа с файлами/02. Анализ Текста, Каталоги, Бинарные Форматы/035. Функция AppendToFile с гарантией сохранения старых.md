# Функция AppendToFile с гарантией сохранения старых данных

## Условие

Напиши функцию `AppendToFile(filename string, text string) error`, которая дописывает текст в конец файла. Используй флаг `os.O_APPEND`. Проверь, что старое содержимое сохраняется.

## Теория

Идиоматичная функция дозаписи открывает файл с флагами `os.O_APPEND|os.O_CREATE|os.O_WRONLY` и правами `0644`, гарантируя корректную работу как для существующих, так и для новых файлов.

## Решение по шагам

1. Реализуем `AppendToFile(filename, text string) error`.
2. Запишем первую строку.
3. Допишем вторую строку.
4. Прочитаем файл и убедимся, что обе строки присутствуют.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"log"
	"os"
)

func AppendToFile(filename string, text string) error {
	f, err := os.OpenFile(filename, os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0644)
	if err != nil {
		return fmt.Errorf("AppendToFile open: %w", err)
	}
	defer f.Close()

	if _, err := f.WriteString(text); err != nil {
		return fmt.Errorf("AppendToFile write: %w", err)
	}
	return nil
}

func main() {
	path := "application.log"
	_ = os.Remove(path) // Очистка

	if err := AppendToFile(path, "Line 1: Server started\n"); err != nil {
		log.Fatal(err)
	}
	if err := AppendToFile(path, "Line 2: Client connected\n"); err != nil {
		log.Fatal(err)
	}

	data, _ := os.ReadFile(path)
	fmt.Print(string(data))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Line 1: Server started
# Line 2: Client connected
```

## Под капотом

Флаг `O_APPEND` обеспечивает конкатенацию в конец файла на уровне ядра ОС.

## Подводные камни

Не забывайте добавлять символ `\n` в конец дописываемого текста, если требуется разделение по строкам.

## На собеседовании

**Вопрос с собеседования:** «Что будет, если открыть файл с флагом O_APPEND, но без O_WRONLY/O_RDWR?»
**Ответ:** По умолчанию флаг режима доступа равен `0` (`os.O_RDONLY`). Попытка записи в файл, открытый только на чтение, вернет ошибку `bad file descriptor`.
