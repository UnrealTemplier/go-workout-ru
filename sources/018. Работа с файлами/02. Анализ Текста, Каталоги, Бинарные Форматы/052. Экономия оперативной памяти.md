# Экономия оперативной памяти: потоковое чтение через bufio.Scanner

## Условие

**Чтение по строкам**: Создай большой текстовый файл (несколько абзацев). Используй `bufio.Scanner`, чтобы считывать и выводить файл строго по одной строке (чтобы экономить оперативную память).

## Теория

Потоковое чтение гарантирует, что в оперативной памяти единовременно находится только одна текущая строка, что предотвращает утечки и скачки потребления RAM при обработке терабайтных логов.

## Решение по шагам

1. Создадим файл с несколькими абзацами текста.
2. Откроем файл через `os.Open`.
3. Создадим `scanner := bufio.NewScanner(file)`.
4. В цикле обработаем каждую строку и освободим память.
5. Проверим `scanner.Err()`.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"log"
	"os"
)

func streamProcessLines(path string) error {
	file, err := os.Open(path)
	if err != nil {
		return err
	}
	defer file.Close()

	scanner := bufio.NewScanner(file)
	lineCount := 0

	for scanner.Scan() {
		line := scanner.Text()
		lineCount++
		// Потоковая обработка каждой строки без сохранения в массив:
		fmt.Printf("[Stream #%d] %s\n", lineCount, line)
	}

	return scanner.Err()
}

func main() {
	path := "article.txt"
	_ = os.WriteFile(path, []byte("Paragraph 1: Go concurrency model\nParagraph 2: Memory allocator design\nParagraph 3: Garbage collector phases"), 0644)

	if err := streamProcessLines(path); err != nil {
		log.Fatal(err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Stream #1] Paragraph 1: Go concurrency model
# [Stream #2] Paragraph 2: Memory allocator design
# [Stream #3] Paragraph 3: Garbage collector phases
```

## Под капотом

`bufio.Scanner` повторно использует один внутренний срез байт размером 64KB, исключая давление на GC.

## Подводные камни

Не сохраняйте `scanner.Text()` в глобальный слайс внутри цикла, иначе экономия памяти будет сведена к нулю.

## На собеседовании

**Вопрос с собеседования:** «Какова сложность по памяти при потоковом чтении файла через bufio.Scanner?»
**Ответ:** Потребление памяти константно: \(O(1)\) относительно размера файла (максимум \(O(L)\), где \(L\) — максимальная длина одной строки, по умолчанию 64KB).
