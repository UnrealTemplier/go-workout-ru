# Определение MIME-типа и формата по магическому числу (Magic Bytes)

## Условие

Откройте бинарный файл с помощью `os.Open` и прочитайте первые 16 байт, чтобы определить "магическое число" (сигнатуру) файла.

## Теория

Магические числа (Magic Numbers / File Signatures) — первые фиксированные байты файла, идентифицирующие его формат (например, `GIF89a`, `\x89PNG`, `\xFF\xD8\xFF` для JPEG, `PK\x03\x04` для ZIP). Пакет `http.DetectContentType` использует первые 512 байт файла для определения MIME-типа.

## Решение по шагам

1. Создадим файлы с сигнатурами PNG и ZIP.
2. Напишем функцию `DetectMagic(path string)`.
3. Вычитаем первые 16 байт через `io.ReadFull`.
4. Сравним сигнатуру и выведем определенный формат.

## Код решения

**`main.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"log"
	"os"
)

var (
	pngMagic = []byte{0x89, 'P', 'N', 'G', 0x0D, 0x0A, 0x1A, 0x0A}
	zipMagic = []byte{'P', 'K', 0x03, 0x04}
	pdfMagic = []byte{'%', 'P', 'D', 'F'}
)

func detectFormat(path string) (string, error) {
	f, err := os.Open(path)
	if err != nil {
		return "", err
	}
	defer f.Close()

	header := make([]byte, 16)
	n, err := io.ReadFull(f, header)
	if err != nil && err != io.ErrUnexpectedEOF && err != io.EOF {
		return "", err
	}

	header = header[:n]
	switch {
	case bytes.HasPrefix(header, pngMagic):
		return "Image (PNG)", nil
	case bytes.HasPrefix(header, zipMagic):
		return "Archive (ZIP / JAR / DOCX)", nil
	case bytes.HasPrefix(header, pdfMagic):
		return "Document (PDF)", nil
	default:
		return "Unknown Binary Format", nil
	}
}

func main() {
	// Создаем тестовый заголовок PNG
	_ = os.WriteFile("sample.png", append(pngMagic, []byte("DATA_PAYLOAD")...), 0644)

	format, err := detectFormat("sample.png")
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Формат файла sample.png определен как: %s\n", format)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Формат файла sample.png определен как: Image (PNG)
```

## Под капотом

`bytes.HasPrefix` сравнивает слайсы байт за \(O(M)\) без аллокаций памяти.

## Подводные камни

Никогда не доверяйте расширению файла (например, `.jpg`), так как злоумышленник может загрузить исполняемый файл `.exe`, переименовав его в `.png`.

## На собеседовании

**Вопрос с собеседования:** «Как в веб-серверах Go проверяют безопасность загружаемых пользователями файлов (File Upload)?»
**Ответ:** Читают первые 512 байт из `multipart.File` и передают в `http.DetectContentType(buf)`. Сверяют полученный MIME-тип с белым списком разрешенных типов независимо от имени файла, переданного клиентом.
