# Чтение файла порциями строго по 16 байт через file.Read до io.EOF

## Условие

**Чтение по кускам (Chunks)**: Открой файл и читай его порциями ровно по 16 байт в цикле, используя метод `file.Read(buf)` до достижения `io.EOF`.

## Теория

Чтение строго фиксированными порциями (`file.Read(buf)`) — фундаментальный паттерн для парсеров бинарных пакетов, видеопотоков и баз данных (чтение страниц размером 4KB/8KB).

## Решение по шагам

1. Создадим файл `stream.dat` длиной 45 байт.
2. Откроем файл через `os.Open`.
3. В цикле вычитаем по 16 байт в буфер `buf := make([]byte, 16)`.
4. Для каждого куска выведем размер и шестнадцатеричный дамп.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
	"io"
	"log"
	"os"
)

func main() {
	path := "stream.dat"
	_ = os.WriteFile(path, []byte("0123456789ABCDEFabcdefghij0123456789FinalChunk"), 0644)

	file, err := os.Open(path)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	buf := make([]byte, 16)
	chunkIndex := 1

	for {
		n, err := file.Read(buf)
		if n > 0 {
			fmt.Printf("Chunk #%d (размер %2d байт): %q\n", chunkIndex, n, string(buf[:n]))
			chunkIndex++
		}
		if err != nil {
			if errors.Is(err, io.EOF) {
				fmt.Println("Поток успешно вычитан до конца (io.EOF)")
				break
			}
			log.Fatalf("Ошибка чтения: %v", err)
		}
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Chunk #1 (размер 16 байт): "0123456789ABCDEF"
# Chunk #2 (размер 16 байт): "abcdefghij012345"
# Chunk #3 (размер 14 байт): "6789FinalChunk"
# Поток успешно вычитан до конца (io.EOF)
```

## Под капотом

`file.Read` читает из page cache ядра до границы буфера `buf`.

## Подводные камни

Последний чанк часто меньше 16 байт. Использование `buf` вместо `buf[:n]` приведет к чтению старых байтов из предыдущей итерации!

## На собеседовании

**Вопрос с собеседования:** «Почему чтение chunk-ами по 16 байт неэффективно для дисков NVMe SSD?»
**Ответ:** Размер блока на современных SSD составляет 4096 байт (4KB). Системные вызовы по 16 байт тратят процессорное время на переключение контекста. Оптимальный размер чанка в Go — 32KB–64KB.
