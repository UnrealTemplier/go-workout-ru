# Оптимизация Leader Lease: Локальное чтение без сетевого обмена

## Условие

Raft leader lease: Leader lease для read optimization: если leader уверен, что нет другого лидера (lease time < election timeout), он отвечает на read локально без round-trip к followers. Покажите временные границы безопасности.

### Исходная формулировка

**Raft leader lease**: Leader lease для read optimization: если leader уверен, что нет других leaders, можно читать локально.

## Теория

Ограничение алгоритма ReadIndex: даже пустой сетевой раунд кворума heartbeats добавляет задержку \(1 - 2\) мс.
Оптимизация Leader Lease (Lease Read):
- Когда лидер избирается или получает подтверждение сердечных сокращений от большинства фоловеров в момент \(T_0\), он гарантированно знает:
  - Ни один фоловер не начнет новые выборы раньше, чем через минимальный интервал `ElectionTimeout`.
  - Следовательно, в интервале времени \([T_0, \; T_0 + \text{ElectionTimeout} - \Delta]\) никакой другой лидер в кластере **физически не может быть избран**!
- В течение этого временного окна (Leader Lease Window) действующий лидер имеет право отдавать результат чтения прямо из оперативной памяти FSM с нулевым сетевым оверхедом (0 сетевых хопов, задержка менее 50 микросекунд).
\(\Delta\) (Safety Margin) компенсирует возможный дрейф часов и задержку выполнения кода.

## Решение по шагам

1. Создаем структуру LeaderLeaseTracker с временной меткой продления и интервалом действия.
2. Реализуем метод RenewLease(quorumAckTime).
3. Реализуем метод CanServeLeaseRead(now).
4. Проверяем быстрое чтение в пределах валидного окна аренды.
5. Симулируем истечение окна аренды: подтверждаем fallback-переход к сетевому подтверждению (ReadIndex).

## Код решения

**`raft_leader_lease.go`**

```go
package main

import (
	"fmt"
	"time"
)

type LeaderLease struct {
	leaseDuration time.Duration
	safetyMargin  time.Duration
	grantedAt     time.Time
	validUntil    time.Time
}

func NewLeaderLease(electionTimeout time.Duration) *LeaderLease {
	// Безопасный срок аренды = 60% от минимального election timeout
	duration := (electionTimeout * 6) / 10
	margin := electionTimeout / 10
	return &LeaderLease{
		leaseDuration: duration,
		safetyMargin:  margin,
	}
}

func (l *LeaderLease) Renew() {
	now := time.Now()
	l.grantedAt = now
	l.validUntil = now.Add(l.leaseDuration)
	fmt.Printf("[Leader Lease] Renewed via majority ACK. Valid for %v (Until %s)\n",
		l.leaseDuration, l.validUntil.Format("15:04:05.000"))
}

func (l *LeaderLease) CanServeLocalRead() (bool, time.Duration) {
	now := time.Now()
	if now.Before(l.validUntil) {
		remaining := l.validUntil.Sub(now)
		return true, remaining
	}
	return false, 0
}

func main() {
	// Election timeout = 500 мс -> Lease = 300 мс
	lease := NewLeaderLease(500 * time.Millisecond)
	lease.Renew()

	// 1. Немедленное чтение (аренда свежая)
	ok, rem := lease.CanServeLocalRead()
	fmt.Printf("Read #1: Can serve locally from RAM? %v (Remaining lease: %v -> 0 RTT!)\n", ok, rem)

	// 2. Имитация прошествия 350 мс (аренда истекла)
	fmt.Println("\n... Sleeping 350ms (lease window expires) ...")
	time.Sleep(350 * time.Millisecond)

	okExpired, _ := lease.CanServeLocalRead()
	fmt.Printf("Read #2: Can serve locally from RAM? %v (Fallback to network ReadIndex required!)\n", okExpired)
}
```

## Под капотом

В TiKV (движок базы TiDB на Go/Rust) концепция Leader Lease доведена до совершенства: фоловеры при ответе на heartbeat явно соглашаются не начинать выборы в течение срока аренды лидера (`LeaseAck`). Это гарантирует безопасность даже при наличии асимметричных сетевых партиций.

## Подводные камни

NTP Time Jumps (Скачки физических часов): если использовать `time.Now()` в системах, где NTP демон резко корректирует время назад или вперед (Clock Stepping), срок аренды лидера может оказаться невалидным. В Go для расчета интервалов ВСЕГДА используется встроенный Monotonic Clock (`time.Since`, `time.Until`), не подверженный внешним скачкам NTP.

## На собеседовании

В: Почему в Google Spanner для реализации TrueTime используются атомные часы и GPS-приемники?
О: Spanner использует аппаратные атомные часы для ограничения неопределенности времени \(\epsilon \le 7\) мс. Это позволяет выполнять глобально распределенные транзакции чтения вообще без сетевых раундов и без координации между континентами, опираясь исключительно на физическое время.
