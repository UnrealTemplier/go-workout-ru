# Idempotency Key Generation: принцип 'One Key = One Intent' и правила клиентских SDK

## Условие

29. **Idempotency key generation**: Клиент генерирует UUID v4 для каждого уникального действия. Один key = одно действие.

### Исходная формулировка

**Idempotency key generation**: Клиент генерирует UUID v4 для каждого уникального действия. Один key = одно действие.

## Теория

Золотое правило генерации ключей: **One Key = One Intent (Один ключ равен одному намерению пользователя)**.

Архитектурные требования к клиентским SDK (Frontend, iOS, Android, Backend SDK):
1. Ключ привязывается к моменту инициации действия пользователем (нажатие кнопки 'Оформить заказ').
2. При сетевых повторах HTTP-клиента (Automatic Retry) ключ **никогда не перегенерируется**.
3. Если пользователь изменил сумму, адрес доставки или состав корзины — это **новое намерение**, для которого генерируется **новый UUIDv4**.
4. Хранение ключа: на мобильных устройствах ключ сохраняется в локальной БД (Room / SQLite) до подтверждения получения ответа сервером.

## Решение по шагам

1. Реализуйте структуру `OrderIntent` с неизменным ключом `IdempotencyKey`.
2. Создайте метод `MutateIntent`, который сбрасывает и перегенерирует ключ при изменении данных.
3. Продемонстрируйте постоянство ключа при ретраях.
4. Продемонстрируйте смену ключа при изменении суммы.

## Код решения

**`one_key_one_intent.go`**

```go
package main

import (
	"crypto/rand"
	"fmt"
)

func NewUUIDv4() string {
	var b [16]byte
	_, _ = rand.Read(b[:])
	b[6] = (b[6] & 0x0f) | 0x40
	b[8] = (b[8] & 0x3f) | 0x80
	return fmt.Sprintf("%08x-%04x-%04x-%04x-%12x", b[0:4], b[4:6], b[6:8], b[8:10], b[10:16])
}

type UserActionIntent struct {
	IdempotencyKey string
	ActionName     string
	Amount         int
}

func NewOrderIntent(amount int) *UserActionIntent {
	return &UserActionIntent{
		IdempotencyKey: NewUUIDv4(), // Генерируется один раз при создании действия
		ActionName:     "create_order",
		Amount:         amount,
	}
}

// Изменение намерения требует нового ключа!
func (intent *UserActionIntent) UpdateAmount(newAmount int) {
	intent.Amount = newAmount
	intent.IdempotencyKey = NewUUIDv4() // Новое намерение -> Новый ключ!
	fmt.Printf("[Client SDK] Order modified! Generated NEW Idempotency Key: %s\n", intent.IdempotencyKey)
}

func main() {
	// Пользователь нажал кнопку "Оплатить 1000 руб"
	intent := NewOrderIntent(1000)
	fmt.Printf("1. User initiates payment intent (Amount: %d):\n -> Idempotency Key: %s\n\n",
		intent.Amount, intent.IdempotencyKey)

	// Сетевые ретраи: ключ ОБЯЗАН оставаться тем же!
	fmt.Println("2. Network Retry Loop (Simulating 3 retries due to timeouts):")
	for attempt := 1; attempt <= 3; attempt++ {
		fmt.Printf(" -> Retry attempt #%d: Reusing SAME Key: %s\n", attempt, intent.IdempotencyKey)
	}

	// Пользователь передумал и изменил сумму на 1500 руб
	fmt.Println("\n3. User changes cart content (New Intent):")
	intent.UpdateAmount(1500)
	fmt.Printf(" -> Send new request with NEW Key: %s (Amount: %d)\n", intent.IdempotencyKey, intent.Amount)
}
```

ℹ️ Ключ неизменен при ретраях одного действия и обновляется только при смене намерения

## Под капотом

Клиентские SDK Stripe и AWS связывают ключ идемпотентности с локальной памятью потока или объектом запроса. Внутренний транспорт HTTP-клиента при повторе `Transport.RoundTrip()` копирует исходный объект запроса без генерации новых метаданных.

## Подводные камни

1. Генерация ключа внутри HTTP Transport RoundTripper: если интерцептор генерирует ключ на каждый вызов `RoundTrip()`, повторные попытки библиотеки пойдут с разными ключами.
2. Сохранение одного ключа на всю сессию пользователя: все покупки за день заблокируются как дубликаты.

## На собеседовании

Вопрос: Что делать, если пользователь нажал кнопку 'Оплатить' два раза подряд с интервалом в 100 мс (Double Click)?
Ответ: Фронтенд должен: 1) немедленно блокировать (disable) кнопку в UI, 2) использовать один и тот же `Idempotency-Key` для любого сетевого запроса, порожденного этим экраном. Бэкенд встретит второй запрос статусом 409 Conflict или вернет кэшированный ответ первого.
