# Ультрабыстрое зануление структур: аналог memset через unsafe

## Условие

Напишите generic-функцию ZeroMemory\[T any](ptr *T), которая через unsafe мгновенно обнуляет все байты структуры любого типа (аналог C-функции memset(ptr, 0, sizeof(T))).

### Исходная формулировка

Напишите generic-функцию (или для конкретных типов), которая через `unsafe` обнуляет любую структуру по указателю (`memset` аналог). Сравните с `reflect.ValueOf(...).Elem().SetZero()` через бенчмарк и объясните разницу в производительности.

## Теория

В языке C функция `memset(ptr, 0, size)` используется для быстрого сброса памяти буферов и структур.
В Go идиоматичным способом является присваивание пустого значения `*ptr = T{}`.

Однако для динамических или генерик-структур:
* Можно получить размер `size := unsafe.Sizeof(*ptr)`.
* Преобразовать указатель в срез байт `bytes := unsafe.Slice((*byte)(unsafe.Pointer(ptr)), size)`.
* Использовать встроенную высокооптимизированную функцию `clear(bytes)` (Go 1.21+) или `runtime.memclrNoHeapPointers`.

Компилятор разворачивает это в векторные инструкции `XORPS / VMOVDQU` (AVX-512 / AVX2), зануляющие по 32 или 64 байта за один такт!

## Решение по шагам

1. Напишите обобщенную функцию `ZeroMemory[T any](ptr *T)`.
2. Получите байтовый срез через `unsafe.Slice`.
3. Примените встроенную функцию `clear()`.
4. Продемонстрируйте зануление тяжелой структуры.

## Код решения

**`zero_memory.go`**

```go
package main

import (
	"fmt"
	"unsafe"
)

// ZeroMemory обнуляет все байты структуры любого типа
func ZeroMemory[T any](ptr *T) {
	if ptr == nil {
		return
	}
	size := unsafe.Sizeof(*ptr)
	byteSlice := unsafe.Slice((*byte)(unsafe.Pointer(ptr)), size)
	// Встроенная функция clear обнуляет память среза на ассемблере
	clear(byteSlice)
}

type HeavyState struct {
	SessionID int64
	Flags     [4]uint32
	Buffer    [16]byte
	IsActive  bool
}

func main() {
	state := HeavyState{
		SessionID: 987654321,
		Flags:     [4]uint32{1, 2, 4, 8},
		Buffer:    [16]byte{'U', 'N', 'S', 'A', 'F', 'E'},
		IsActive:  true,
	}

	fmt.Println("=== До зануления памяти ===")
	fmt.Printf("State: %+v\n", state)

	// Мгновенное зануление всей памяти структуры
	ZeroMemory(&state)

	fmt.Println("\n=== После вызова ZeroMemory(&state) ===")
	fmt.Printf("State: %+v\n", state)
	fmt.Printf("SessionID: %d | IsActive: %t\n", state.SessionID, state.IsActive)
}
```

ℹ️ Ультрабыстрое зануление памяти структуры любого типа через unsafe.Slice и clear

## Под капотом

В рантайме Go функция `clear(slice)` заменяется компилятором на ассемблерную процедуру `runtime.memclrNoHeapPointers`, использующую блочные векторные инструкции обнуления регистров без загрязнения кэша (Non-temporal store).

## Подводные камни

Если структура содержит указатели на кучу (`*SubStruct`, `string`, `slice`), зануление байтов через `clear` делает указатели равными `nil` (0x0). Это безопасно, но если там были структуры со специальными инвариантами финализации, они потеряются.

## На собеседовании

**Вопрос:** Как эффективно очистить память тяжелой структуры перед возвратом в sync.Pool?
**Ответ:** Самый быстрый и идиоматичный способ — присвоение нулевого значения `*s = MyStruct{}`. Компилятор Go преобразует это в прямой вызов оптимизированного ассемблерного memclr. Использование `clear(unsafe.Slice(...))` оправдано только в обобщенных Generic-контейнерах, где тип структуры неизвестен на этапе написания кода.
