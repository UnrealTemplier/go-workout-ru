# Исследование выравнивания памяти: unsafe.Alignof

## Условие

Создайте структуру с полями разных типов. Используйте unsafe.Sizeof для получения размера в байтах и unsafe.Alignof для получения коэффициента выравнивания каждого поля.

### Исходная формулировка

**Исследование памяти (`unsafe.Sizeof`, `Alignof`)**: Создай структуру с разными типами полей. Используй `unsafe.Sizeof` для получения её размера в байтах и `unsafe.Alignof` для получения выравнивания.

## Теория

Функция `unsafe.Alignof(x)` возвращает **фактор выравнивания (Alignment Factor)** типа:
* Память переменной типа `T` обязана начинаться по адресу, кратному `Alignof(T)`.
* `unsafe.Alignof(bool)` = 1
* `unsafe.Alignof(int16)` = 2
* `unsafe.Alignof(int32)` = 4
* `unsafe.Alignof(int64)` = 8
* `unsafe.Alignof(struct)` = максимальное выравнивание среди всех полей этой структуры.

Компилятор размещает поля по смещениям, кратным их индивидуальному выравниванию. Если текущее смещение не кратно `Alignof`, компилятор вставляет пустые байты (**Padding**).

## Решение по шагам

1. Создайте структуру `ComplexData` с полями `byte`, `int64`, `int32`, `bool`.
2. Выведите выравнивание каждого поля через `unsafe.Alignof`.
3. Выведите размер структуры и фактор ее общего выравнивания.

## Код решения

**`alignof_demo.go`**

```go
package main

import (
	"fmt"
	"unsafe"
)

type ComplexData struct {
	A byte    // Align: 1
	B int64   // Align: 8
	C int32   // Align: 4
	D bool    // Align: 1
}

func main() {
	var cd ComplexData

	fmt.Println("=== Факторы выравнивания полей (unsafe.Alignof) ===")
	fmt.Printf("Поле A (byte):   Align = %d, Offset = %2d\n", unsafe.Alignof(cd.A), unsafe.Offsetof(cd.A))
	fmt.Printf("Поле B (int64):  Align = %d, Offset = %2d\n", unsafe.Alignof(cd.B), unsafe.Offsetof(cd.B))
	fmt.Printf("Поле C (int32):  Align = %d, Offset = %2d\n", unsafe.Alignof(cd.C), unsafe.Offsetof(cd.C))
	fmt.Printf("Поле D (bool):   Align = %d, Offset = %2d\n", unsafe.Alignof(cd.D), unsafe.Offsetof(cd.D))

	fmt.Println("\n=== Свойства всей структуры ===")
	fmt.Printf("Размер структуры (Sizeof):   %d байт\n", unsafe.Sizeof(cd))
	fmt.Printf("Выравнивание структуры:      %d байт\n", unsafe.Alignof(cd))
}
```

ℹ️ Определение факторов выравнивания и смещений полей структуры

## Под капотом

Размер структуры всегда кратен ее максимальному фактору выравнивания. Если после последнего поля `D (bool)` занят 21 байт, компилятор добавляет еще 3 байта padding в конец (Tail Padding), чтобы итоговый размер стал 24 (кратен 8).

## Подводные камни

В 32-битных архитектурах (ARM32, x86-32) выравнивание `int64` равно 4 байтам, что требует особого внимания при атомарных операциях `sync/atomic`.

## На собеседовании

**Вопрос:** Почему размер структуры ComplexData { A byte; B int64; C int32; D bool } равен 24 байтам, хотя сумма размеров полей всего 14 байт?
**Ответ:** Поле A (1 байт) дополняется 7 байтами padding, чтобы поле B (int64) началось по адресу, кратному 8. Поле C занимает 4 байта, поле D — 1 байт (итого 21 байт). В конец структуры компилятор добавляет 3 байта tail padding, чтобы общий размер стал кратен 8 байтам (максимальному выравниванию структуры). Итого 24 байта.
