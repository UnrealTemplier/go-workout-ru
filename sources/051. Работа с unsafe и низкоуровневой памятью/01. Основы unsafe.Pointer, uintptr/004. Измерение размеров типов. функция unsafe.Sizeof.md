# Измерение размеров типов: функция unsafe.Sizeof

## Условие

Используйте unsafe.Sizeof для вывода размера базовых типов: int, string, slice, bool. Объясните размер пустой структуры struct{} и интерфейса any.

### Исходная формулировка

Используй `unsafe.Sizeof` для вывода размера структур `int`, `string`, `slice`, `bool`. Посчитай размер пустой структуры `struct{}` (должен быть 0) и размер структуры с полем `bool` и `int64` (выравнивание/padding).

## Теория

Функция `unsafe.Sizeof(x)` вычисляет размер переменной в байтах **на этапе компиляции**:

1. **Базовые типы (на 64-битных системах):**
   * `bool`, `byte`, `uint8`, `int8`: **1 байт**.
   * `int16`, `uint16`: **2 байта**.
   * `int32`, `uint32`, `float32`: **4 байта**.
   * `int`, `uint`, `int64`, `uint64`, `float64`, указатели `*T`: **8 байт**.

2. **Составные заголовки (Headers):**
   * **`string`:** **16 байт** (2 слова: указатель на байты `Data uintptr` + длина `Len int`).
   * **`slice`:** **24 байта** (3 слова: указатель `Data uintptr` + `Len int` + `Cap int`).
   * **`any` / `interface{}`:** **16 байт** (2 слова: указатель на тип `_type` + указатель на данные `data`).

3. **Пустая структура `struct{}`:**
   * **0 байт**! Не занимает места в памяти, используется для очередей сигналов (`chan struct{}`) и множеств (`map[T]struct{}`).

## Решение по шагам

1. Объявите переменные каждого базового типа.
2. Выведите размер каждой переменной через `unsafe.Sizeof()`.
3. Создайте массив из 10 000 000 пустых структур `struct{}` и покажите, что его размер равен 0.

## Код решения

**`sizeof_demo.go`**

```go
package main

import (
	"fmt"
	"unsafe"
)

func main() {
	var (
		b     bool
		i     int
		s     string
		sl    []byte
		empty struct{}
		iface any
	)

	fmt.Println("=== Размеры типов в памяти (x86-64 / ARM64) ===")
	fmt.Printf("bool:               %2d байт\n", unsafe.Sizeof(b))
	fmt.Printf("int:                %2d байт\n", unsafe.Sizeof(i))
	fmt.Printf("string:             %2d байт (Data + Len)\n", unsafe.Sizeof(s))
	fmt.Printf("[]byte (slice):     %2d байт (Data + Len + Cap)\n", unsafe.Sizeof(sl))
	fmt.Printf("any (interface):    %2d байт (_type + data)\n", unsafe.Sizeof(iface))
	fmt.Printf("struct{} (пустая):  %2d байт\n", unsafe.Sizeof(empty))

	// Массив из 100 млн пустых структур
	var massive [100000000]struct{}
	fmt.Printf("Размер массива из 100 млн struct{}: %d байт!\n", unsafe.Sizeof(massive))
}
```

ℹ️ Вычисление размеров структур и заголовков Go через unsafe.Sizeof

## Под капотом

`unsafe.Sizeof` не является обычной функцией рантайма. Она вычисляется компилятором на этапе парсинга AST и заменяется на числовую числовую константу в машинном коде, не создавая накладных расходов в рантайме.

## Подводные камни

`unsafe.Sizeof(mySlice)` возвращает размер **заголовка среза (24 байта)**, а не размер данных в базовом массиве! Аналогично для строки — возвращается 16 байт, а не длина строки.

## На собеседовании

**Вопрос:** Сколько памяти занимает переменная типа interface{} на 64-битной архитектуре и почему?
**Ответ:** Переменная типа `any` (interface{}) занимает ровно 16 байт. В рантайме интерфейс представляется структурой `eface`, состоящей из двух указателей по 8 байт: `_type` (указатель на метаданные о типе значения) и `data` (указатель на само значение в куче или стеке).
