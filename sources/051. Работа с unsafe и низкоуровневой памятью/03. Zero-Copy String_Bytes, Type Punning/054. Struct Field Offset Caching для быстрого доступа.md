# Struct Field Offset Caching для быстрого доступа

## Условие

Напишите утилиту, которая кэширует offsets полей структур при инициализации через `reflect.Type`, а затем в runtime осуществляет чтение и запись значений через `unsafe.Pointer + cachedOffset` без вызовов reflection. Сравните скорость с чистым `reflect.Value`.

### Исходная формулировка

**Struct field offset caching**: Напишите утилиту, которая кэширует offsets полей структур для быстрого доступа без reflection в runtime.

## Теория

Пакет `reflect` предоставляет гибкие средства интроспекции, но методы вроде `reflect.ValueOf(v).FieldByName("X").SetInt(val)` требуют многократных аллокаций, поиска строкового имени в срезе полей и проверки типов.
В HighLoad ORM и сериализаторах (например, `sonic`, `json-iterator`) применяется паттерн:
1. Во время старта приложения структура сканируется через рефлексию один раз, а байтовые смещения (`offset`) сохраняются в кэш.
2. В горячем цикле запросов доступ к полям выполняется мгновенно через `unsafe.Pointer(base + offset)`.

## Решение по шагам

1. Создайте структуру `FastFieldAccessor` с закэшированным `uintptr offset`.
2. Инициализируйте аксессор через `reflect.TypeOf(T{}).FieldByName()`.
3. Реализуйте метод `GetInt64(ptr unsafe.Pointer) int64`.
4. Реализуйте метод `SetInt64(ptr unsafe.Pointer, val int64)`.
5. Продемонстрируйте многократное ускорение по сравнению с `reflect.Value.SetInt`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"reflect"
	"time"
	"unsafe"
)

type UserProfile struct {
	Username string
	Score    int64
	Active   bool
}

type FastAccessor struct {
	offset uintptr
}

func NewFastAccessor(t reflect.Type, fieldName string) *FastAccessor {
	field, ok := t.FieldByName(fieldName)
	if !ok {
		panic("поле не найдено")
	}
	return &FastAccessor{offset: field.Offset}
}

func (a *FastAccessor) SetInt64(structPtr unsafe.Pointer, val int64) {
	target := (*int64)(unsafe.Add(structPtr, a.offset))
	*target = val
}

func (a *FastAccessor) GetInt64(structPtr unsafe.Pointer) int64 {
	target := (*int64)(unsafe.Add(structPtr, a.offset))
	return *target
}

func main() {
	u := UserProfile{Username: "Alice", Score: 100, Active: true}

	t := reflect.TypeOf(u)
	scoreAccessor := NewFastAccessor(t, "Score")

	fmt.Printf("Закэшированное смещение поля Score: %d байт\n", scoreAccessor.offset)

	// Чтение и запись через закэшированный оффсет
	scoreAccessor.SetInt64(unsafe.Pointer(&u), 999)
	fmt.Printf("Обновленный Score через FastAccessor: %d\n", u.Score)

	// Замер производительности: FastAccessor vs Reflect
	const iters = 1_000_000

	startFast := time.Now()
	ptr := unsafe.Pointer(&u)
	for i := 0; i < iters; i++ {
		scoreAccessor.SetInt64(ptr, int64(i))
	}
	fastDur := time.Since(startFast)

	val := reflect.ValueOf(&u).Elem()
	fieldVal := val.FieldByName("Score")
	startReflect := time.Now()
	for i := 0; i < iters; i++ {
		fieldVal.SetInt(int64(i))
	}
	reflectDur := time.Since(startReflect)

	fmt.Printf("FastAccessor (unsafe+cache): %v\n", fastDur)
	fmt.Printf("Reflect FieldByName:         %v\n", reflectDur)
	fmt.Printf("Ускорение: %.1fx раз!\n", float64(reflectDur)/float64(fastDur))
}
```

ℹ️ Кэширование смещений полностью устраняет накладные расходы динамической рефлексии.

**`Терминал`**

```bash
go run main.go
# Вывод:
# Закэшированное смещение поля Score: 16 байт
# Обновленный Score через FastAccessor: 999
# FastAccessor (unsafe+cache): 2.1ms
# Reflect FieldByName:         35.8ms
# Ускорение: 17.0x раз!
```

## Под капотом

`reflect.Value.SetInt` выполняет проверку флага мутабельности `flagRO`, валидацию типа, проверку адресации и indirect-разрешение указателей при каждой итерации. `FastAccessor.SetInt64` инлайнится компилятором в одну прямую инструкцию `MOVQ rbx, [rax + offset]`.

## Подводные камни

Кэшированные смещения привязаны к конкретному типу структуры. Если передать указатель на структуру другого типа или другого размера, программа повредит память.

## На собеседовании

**Вопрос с собеседования:** Как работают быстрые JSON-парсеры в Go (например, sonic от ByteDance)?
**Ответ:** Они используют JIT-компиляцию или генерацию ассемблерного кода на лету, кэшируя байтовые смещения полей и выполняя прямое копирование данных через `unsafe.Pointer` в обход пакета `reflect` и write barrier.
