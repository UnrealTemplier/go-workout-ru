# Извлечение указателя из interface (eface/iface) без рефлексии

## Условие

Создайте функцию, которая принимает `any`, извлекает указатель на данные через `unsafe.Pointer` и внутреннюю структуру `emptyInterface`, минуя медленный пакет `reflect`. Модифицируйте поле переданного объекта напрямую.

### Исходная формулировка

**Reflection-free interface**: Создайте функцию, которая принимает `any`, извлекает указатель на данные через `unsafe.Pointer` и `reflect.Value`, модифицирует значение напрямую.

## Теория

Интерфейс `any` (или `interface{}`) в рантайме Go представлен 16-байтной структурой `eface`:
```go
type eface struct {
    _type *_type
    data  unsafe.Pointer
}
```
Пакет `reflect` при каждом вызове `reflect.ValueOf(x)` упаковывает значение в структуру с аллокацией памяти.
Используя прямую проекцию на `eface`, можно мгновенно извлечь нетипизированный указатель `data` на объект за 0 аллокаций и нулевой overhead.

## Решение по шагам

1. Определите структуру `emptyInterface struct { typ unsafe.Pointer; data unsafe.Pointer }`.
2. Напишите функцию `ExtractDataPtr(v any) unsafe.Pointer`.
3. Преобразуйте `unsafe.Pointer(&v)` в `*emptyInterface` и верните поле `data`.
4. Создайте структуру `User { Age int }` и передайте `&u` в функцию.
5. Измените поле `Age` через полученный указатель.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"unsafe"
)

// emptyInterface дублирует структуру eface из runtime/runtime2.go
type emptyInterface struct {
	typ  unsafe.Pointer
	data unsafe.Pointer
}

// ExtractDataPtr возвращает сырой указатель на данные внутри interface{}
func ExtractDataPtr(v any) unsafe.Pointer {
	return (*emptyInterface)(unsafe.Pointer(&v)).data
}

type User struct {
	Name string
	Age  int
}

func main() {
	u := User{Name: "Gopher", Age: 20}
	fmt.Printf("До модификации: %+v\n", u)

	// Передаем указатель на структуру в any
	ptr := ExtractDataPtr(&u)

	// ptr указывает на объект User
	userPtr := (*User)(ptr)
	userPtr.Age = 35

	fmt.Printf("После модификации через eface: %+v\n", u)
	fmt.Printf("Адреса совпадают: %t\n", userPtr == &u)
}
```

ℹ️ eface.data содержит прямой указатель на значение, если значение является указателем.

**`Терминал`**

```bash
go run main.go
# Вывод:
# До модификации: {Name:Gopher Age:20}
# После модификации через eface: {Name:Gopher Age:35}
# Адреса совпадают: true
```

## Под капотом

Интерфейс в Go бывает двух видов: `eface` (пустой интерфейс `any`) и `iface` (непустой интерфейс с методами, содержащий `itab`). В обоих случаях второе машинное слово структуры — это указатель `data unsafe.Pointer`. Если в интерфейс передан указатель `*T`, `data` хранит ровно этот адрес.

## Подводные камни

Если передать в `any` значение по значению (`User`, а не `*User`), компилятор Go аллоцирует копию в куче и сохранит указатель на копию. Изменение по `ptr` изменит копию, а не оригинальную локальную переменную.

## На собеседовании

**Вопрос с собеседования:** В чем разница между `eface` и `iface` в рантайме Go?
**Ответ:** `eface` представляет пустой интерфейс `any`/`interface{}` и состоит из 2 слов: указатель на метаданные типа (`*_type`) и указатель на данные (`data`). `iface` представляет интерфейс с методами и состоит из указателя на таблицу интерфейса (`*itab`, содержащую тип структуры, список указателей на функции методов и хэш) и указателя на данные (`data`).
