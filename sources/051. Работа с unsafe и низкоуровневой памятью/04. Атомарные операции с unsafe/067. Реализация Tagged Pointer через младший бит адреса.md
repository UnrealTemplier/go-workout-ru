# Реализация Tagged Pointer через младший бит адреса

## Условие

Реализуйте **tagged pointer**: упакуйте 1-битный флаг (например, `isDeleted` или `isDirty`) в младший бит указателя через `uintptr`. Напишите функции `Pack(ptr *Node, tag bool) uintptr` и `Unpack(tagged uintptr) (*Node, bool)`. Проверьте, почему это работает на 64-битных системах.

### Исходная формулировка

Реализуйте **tagged pointer**: упакуйте 1-битный флаг в младший бит указателя через `uintptr`. Напишите функции `pack(ptr unsafe.Pointer, flag bool)` / `unpack(packed uintptr)`. Объясните, почему это работает только при alignment ≥ 2 и почему это невозможно сделать без `unsafe`.

## Теория

На 64-битных архитектурах структуры, содержащие 64-битные типы (`int64`, указатели), выравниваются по границе 8 байт.
Это означает, что младшие 3 бита адреса любого указателя на такую структуру **всегда равны нулю**:
- Адрес: `...000` (кратен 8)
- Адрес: `...100` (кратен 4).

Техника **Tagged Pointer** использует неиспользуемый нулевой младший бит для упаковки булевого флага прямо в указатель без увеличения размера структуры. Это экономит память в красно-черных деревьях, lock-free списках и Concurrent SkipList.

## Решение по шагам

1. Создайте структуру `Node struct { Value int64; Next *Node }`.
2. Напишите `Pack(ptr *Node, tag bool) uintptr`: если `tag == true`, примените `| 1`.
3. Напишите `Unpack(val uintptr) (*Node, bool)`: извлеките `tag = (val & 1) == 1`, очистите бит `ptr = val &^ 1`.
4. Создайте узел и проверьте сохранение и восстановление адреса и флага.
5. Объясните правила работы с GC.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"runtime"
	"unsafe"
)

type Node struct {
	Value int64
	Next  *Node
}

const tagMask = uintptr(1)

// Pack упаковывает булев флаг в младший бит адреса
func Pack(ptr *Node, tag bool) uintptr {
	u := uintptr(unsafe.Pointer(ptr))
	if tag {
		return u | tagMask
	}
	return u
}

// Unpack извлекает оригинальный указатель и флаг
func Unpack(tagged uintptr) (*Node, bool) {
	tag := (tagged & tagMask) != 0
	cleanPtr := tagged &^ tagMask // сброс младшего бита
	return (*Node)(unsafe.Pointer(cleanPtr)), tag
}

func main() {
	node := &Node{Value: 42}
	addr := uintptr(unsafe.Pointer(node))

	fmt.Printf("Исходный адрес node: 0x%X (младший бит: %d)\n", addr, addr&1)

	// Упаковываем узел с флагом isDeleted = true
	tagged := Pack(node, true)
	fmt.Printf("Tagged Pointer:      0x%X (младший бит: %d)\n", tagged, tagged&1)

	// Распаковываем
	restoredNode, isDeleted := Unpack(tagged)
	fmt.Printf("Распакованный узел:  %p, Значение: %d, Флаг isDeleted: %t\n",
		restoredNode, restoredNode.Value, isDeleted)
	fmt.Printf("Адреса совпадают:    %t\n", restoredNode == node)

	// Удерживаем node от преждевременного сбора GC
	runtime.KeepAlive(node)
}
```

ℹ️ Маска &^ 1 (AND NOT 1) гарантированно очищает младший бит адреса перед разыменованием.

**`Терминал`**

```bash
go run main.go
# Вывод:
# Исходный адрес node: 0x...0 (младший бит: 0)
# Tagged Pointer:      0x...1 (младший бит: 1)
# Распакованный узел:  0x..., Значение: 42, Флаг isDeleted: true
# Адреса совпадают:    true
```

## Под капотом

Выравнивание структур по границе 8 байт гарантирует, что \(addr \equiv 0 \pmod 8\). Биты 0, 1 и 2 гарантированно свободны. Установка бита 0 превращает число в нечетный адрес. Если попытаться разыменовать такой указатель без очистки бита, процессор выполнит unaligned чтение или вызовет аппаратное исключение.

## Подводные камни

Переменная `tagged` имеет тип `uintptr`. GC не знает, что в ней спрятан указатель на `node`. Если не удерживать объект через другую ссылку или `runtime.KeepAlive`, объект `node` будет уничтожен сборщиком мусора!

## На собеседовании

**Вопрос с собеседования:** Почему tagged pointers опасны в Go по сравнению с C++?
**Ответ:** В C++ сборщика мусора нет, и программист сам управляет памятью. В Go сборщик мусора сканирует память: если указатель модифицирован тегом в младшем бите и сохранен как `unsafe.Pointer`, GC посчитает его невалидным указателем на середину объекта или чужой блок и упадет в панику. Хранить tagged pointer в Go можно только как `uintptr` с обязательным удержанием корня через `runtime.KeepAlive`.
