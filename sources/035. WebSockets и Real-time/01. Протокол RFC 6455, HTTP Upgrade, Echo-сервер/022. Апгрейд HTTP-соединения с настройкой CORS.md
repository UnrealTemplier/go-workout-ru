# Апгрейд HTTP-соединения с настройкой CORS: безопасность CheckOrigin и валидация хостов

## Условие

**Апгрейд HTTP-соединения**: Напишите стандартный HTTP-сервер. В обработчике `/ws` выполните процедуру обновления (upgrade) протокола HTTP до WebSocket с помощью библиотеки `github.com/gorilla/websocket` (используя структуру `websocket.Upgrader`). Настройте CORS, разрешив подключения со всех доменов во время рукопожатия (handshake).

## Теория

Политика однородного происхождения (SOP) и WebSockets:
- В браузерах WebSocket **НЕ подчиняется стандартному CORS**:
  - Браузер отправляет заголовок `Origin`, но НЕ делает предварительный preflight-запрос `OPTIONS`.
  - Без проверки `CheckOrigin` любой вредоносный сайт (`evil.com`) может выполнить WebSocket-запрос к вашему API в фоновом режиме от лица залогиненного пользователя!
- Правильная настройка:
  - Для разработки / публичных API: `CheckOrigin: func(r *http.Request) bool { return true }`.
  - Для продакшена: проверка `origin` по строгому белому списку доверенных доменов.

## Решение по шагам

1. Создайте обработчик эндпоинта `/ws`.
2. Настройте `websocket.Upgrader` с разрешающей функцией `CheckOrigin`.
3. Запустите HTTP-сервер с данным обработчиком.
4. Протестируйте успешный апгрейд с произвольным заголовком `Origin`.

## Код решения

**`ws_cors_upgrade_test.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"strings"
	"testing"

	"github.com/gorilla/websocket"
)

func newCORSUpgrader() websocket.Upgrader {
	return websocket.Upgrader{
		ReadBufferSize:  1024,
		WriteBufferSize: 1024,
		CheckOrigin: func(r *http.Request) bool {
			// Разрешаем любые Origin (аналог Access-Control-Allow-Origin: *)
			return true
		},
	}
}

func handleWebSocketCORS(w http.ResponseWriter, r *http.Request) {
	upgrader := newCORSUpgrader()
	conn, err := upgrader.Upgrade(w, r, nil)
	if err != nil {
		return
	}
	defer conn.Close()

	_ = conn.WriteMessage(websocket.TextMessage, []byte("CORS Handshake OK"))
}

func TestCORSWebSocketUpgrade(t *testing.T) {
	server := httptest.NewServer(http.HandlerFunc(handleWebSocketCORS))
	defer server.Close()

	wsURL := "ws" + strings.TrimPrefix(server.URL, "http")

	dialer := websocket.Dialer{}
	header := make(http.Header)
	header.Set("Origin", "https://external-partner-site.ru")

	conn, resp, err := dialer.Dial(wsURL, header)
	if err != nil {
		t.Fatalf("Ошибка подключения с внешним Origin: %v", err)
	}
	defer conn.Close()

	if resp.StatusCode != http.StatusSwitchingProtocols {
		t.Fatalf("Ожидался статус 101, получено: %d", resp.StatusCode)
	}

	_, msg, _ := conn.ReadMessage()
	if string(msg) != "CORS Handshake OK" {
		t.Fatalf("Неверный ответ: %s", string(msg))
	}

	fmt.Printf("Рукопожатие с внешним Origin успешно выполнено: %s (Статус %d)\n",
		string(msg), resp.StatusCode)
}
```

ℹ️ Настройка Upgrader.CheckOrigin для поддержки кросс-доменных подключений

**`Терминал`**

```bash

# Вывод:

```

## Под капотом

Если `CheckOrigin` возвращает `false`, `Upgrader.Upgrade` автоматически отправляет клиенту статус `HTTP 403 Forbidden` с телом `"websocket: request origin not allowed by Upgrader.CheckOrigin"` и прерывает рукопожатие.

## Подводные камни

Считать, что директива CORS в middleware `w.Header().Set("Access-Control-Allow-Origin", "*")` защищает WebSocket: браузер игнорирует CORS заголовки при WebSocket-рукопожатии, валидация происходит исключительно через `CheckOrigin`.

## На собеседовании

**Вопрос с собеседования:** «Что такое атака CSWSH (Cross-Site WebSocket Hijacking)?»
**Ответ:** Это аналог CSRF, но для WebSockets. Пользователь заходит на вредоносный сайт `attacker.com`. Скрипт в браузере выполняет `new WebSocket('wss://bank.com/ws')`. Браузер автоматически прикрепляет сессионные куки пользователя. Если сервер `bank.com` не проверяет заголовок `Origin`, злоумышленник получает полноценный двусторонний доступ к банковскому сокету жертвы.
