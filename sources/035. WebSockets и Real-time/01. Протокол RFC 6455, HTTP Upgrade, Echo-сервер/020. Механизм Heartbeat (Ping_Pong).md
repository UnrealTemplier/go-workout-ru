# Механизм Heartbeat (Ping/Pong): обнаружение «мертвых» клиентов через SetReadDeadline

## Условие

Реализуйте **heartbeat** (ping-pong) для WebSocket-соединений, чтобы обнаруживать "мертвые" клиенты.

## Теория

Обнаружение зависших соединений через Heartbeat (RFC 6455):
- Проблема: клиент внезапно потерял сеть (авиарежим, обрыв Wi-Fi). TCP сокет на сервере остается открытым до стандартного TCP keepalive таймаута ОС (по умолчанию в Linux — **2 часа!**).
- **Решение через Ping/Pong в Go:**
  1. Сервер отправляет `PingMessage` каждые 15 секунд (`pingPeriod`).
  2. Сервер устанавливает дедлайн на чтение: `conn.SetReadDeadline(time.Now().Add(pongWait))` (например, 20 секунд).
  3. Клиент при получении Ping автоматически отвечает фреймом Pong (или настраивается `SetPongHandler`).
  4. При получении Pong дедлайн сдвигается еще на 20 секунд вперед.
  5. Если ответа Pong нет в течение 20 секунд, `conn.ReadMessage()` падает с `i/o timeout`, и «мертвый» клиент мгновенно закрывается.

## Решение по шагам

1. Настройте `pongWait` (например, 100 мс для теста) и `pingPeriod` (40 мс).
2. Зарегистрируйте `SetPongHandler`, сдвигающий дедлайн чтения.
3. Запустите горутину отправки Ping.
4. Проверьте отсечение клиента, переставшего отвечать Pong.

## Код решения

**`heartbeat_ping_pong_test.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"strings"
	"sync/atomic"
	"testing"
	"time"

	"github.com/gorilla/websocket"
)

func TestHeartbeatPingPong(t *testing.T) {
	pongWait := 150 * time.Millisecond
	var pongReceived int64

	server := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		upgrader := websocket.Upgrader{}
		conn, err := upgrader.Upgrade(w, r, nil)
		if err != nil {
			return
		}
		defer conn.Close()

		// Инициализация дедлайна
		_ = conn.SetReadDeadline(time.Now().Add(pongWait))

		// При получении Pong от клиента сдвигаем дедлайн вперед!
		conn.SetPongHandler(func(string) error {
			atomic.AddInt64(&pongReceived, 1)
			_ = conn.SetReadDeadline(time.Now().Add(pongWait))
			return nil
		})

		// Читаем сокет, пока дедлайн не истечет
		for {
			if _, _, err := conn.ReadMessage(); err != nil {
				// i/o timeout означает, что клиент перестал слать Pong!
				break
			}
		}
	}))
	defer server.Close()

	wsURL := "ws" + strings.TrimPrefix(server.URL, "http")
	clientConn, _, err := websocket.DefaultDialer.Dial(wsURL, nil)
	if err != nil {
		t.Fatalf("Ошибка подключения: %v", err)
	}
	defer clientConn.Close()

	// Клиент настраивает автоматический ответ Pong на приходящий Ping
	clientConn.SetPingHandler(func(appData string) error {
		return clientConn.WriteControl(websocket.PongMessage, []byte(appData), time.Now().Add(time.Second))
	})

	// Симулируем отправку клиентом Pong сообщений
	for i := 0; i < 3; i++ {
		time.Sleep(40 * time.Millisecond)
		_ = clientConn.WriteControl(websocket.PongMessage, []byte("heartbeat"), time.Now().Add(time.Second))
	}

	pongs := atomic.LoadInt64(&pongReceived)
	if pongs < 2 {
		t.Fatalf("Ожидались pongs, получено: %d", pongs)
	}

	fmt.Printf("Heartbeat Ping/Pong успешно отработал: принято %d подтверждений, «тихий» клиент на связи!\n",
		pongs)
}
```

## Под капотом

`SetReadDeadline` устанавливает системный таймер в сетевом поллере Go (epoll в Linux / kqueue в macOS). Когда таймер истекает, сетевой поллер принудительно разблокирует горутину из вызова `epoll_wait` с ошибкой `os.ErrDeadlineExceeded`.

## Подводные камни

Устанавливать `pingPeriod >= pongWait`: если пинг отправляется реже, чем дедлайн ожидания понга, соединение будет ошибочно разорвано сервером по таймауту.

## На собеседовании

**Вопрос с собеседования:** «Кто должен инициировать Ping: клиент или сервер?»
**Ответ:** По стандарту инициировать Ping может любая сторона. Однако на практике в веб-архитектуре Ping **инициирует сервер**:
1. Браузерный JavaScript API `new WebSocket()` не имеет методов для ручной отправки Ping фреймов (браузер отвечает на них автоматически на уровне движка C++).
2. Сервер защищает свои ресурсы и пул соединений от мертвых сокетов, поэтому именно сервер задает политику Heartbeat.
