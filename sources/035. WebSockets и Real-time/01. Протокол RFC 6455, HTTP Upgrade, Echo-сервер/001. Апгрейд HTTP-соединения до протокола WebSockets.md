# Апгрейд HTTP-соединения до протокола WebSockets: Upgrader, CheckOrigin и рукопожатие

## Условие

Установи `github.com/gorilla/websocket`. Напиши HTTP-обработчик, который использует `websocket.Upgrader` для апгрейда HTTP-запроса в WebSocket-соединение.

## Теория

Механика протокола WebSocket (RFC 6455):
- WebSockets начинается как стандартный HTTP GET-запрос с особыми заголовками:
  - `Upgrade: websocket`
  - `Connection: Upgrade`
  - `Sec-WebSocket-Key: dGhlIHNhbXBsZSBub25jZQ==`
  - `Sec-WebSocket-Version: 13`
- Библиотека `github.com/gorilla/websocket`:
  - `websocket.Upgrader`: структура, отвечающая за валидацию заголовков рукопожатия и перевод TCP-сокета в дуплексный режим.
  - Поле `CheckOrigin`: функция проверки источника (Origin) запроса для защиты от Cross-Site WebSocket Hijacking (CSWSH).
  - Метод `Upgrader.Upgrade(w, r, nil)` перехватывает базовое сетевое соединение `net.Conn` через интерфейс `http.Hijacker`, возвращает статус `101 Switching Protocols` и отдает структуру `*websocket.Conn`.

## Решение по шагам

1. Настройте структуру `websocket.Upgrader` с буферами чтения и записи.
2. Реализуйте функцию `CheckOrigin` для фильтрации разрешенных доменов.
3. Вызовите `upgrader.Upgrade(w, r, responseHeader)`.
4. Протестируйте HTTP-рукопожатие и получение статуса 101 Switching Protocols.

## Код решения

**`ws_upgrade_test.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"strings"
	"testing"

	"github.com/gorilla/websocket"
)

var upgrader = websocket.Upgrader{
	ReadBufferSize:  1024,
	WriteBufferSize: 1024,
	CheckOrigin: func(r *http.Request) bool {
		// В проде проверяют r.Header.Get("Origin") против белого списка доменов!
		origin := r.Header.Get("Origin")
		return origin == "" || strings.HasSuffix(origin, ".example.com") || origin == "http://localhost:3000"
	},
}

func wsHandler(w http.ResponseWriter, r *http.Request) {
	conn, err := upgrader.Upgrade(w, r, nil)
	if err != nil {
		// Upgrader сам отправляет соответствующий HTTP-статус при ошибке
		return
	}
	defer conn.Close()

	// Соединение успешно переведено на протокол WebSocket!
	_ = conn.WriteMessage(websocket.TextMessage, []byte("Добро пожаловать в WebSocket!"))
}

func TestWebSocketUpgrade(t *testing.T) {
	server := httptest.NewServer(http.HandlerFunc(wsHandler))
	defer server.Close()

	// Конвертируем http:// в ws://
	wsURL := "ws" + strings.TrimPrefix(server.URL, "http")

	dialer := websocket.Dialer{}
	header := make(http.Header)
	header.Set("Origin", "http://localhost:3000")

	conn, resp, err := dialer.Dial(wsURL, header)
	if err != nil {
		t.Fatalf("Ошибка Dial: %v", err)
	}
	defer conn.Close()

	if resp.StatusCode != http.StatusSwitchingProtocols {
		t.Fatalf("Ожидался статус 101, получено: %d", resp.StatusCode)
	}

	msgType, msg, err := conn.ReadMessage()
	if err != nil {
		t.Fatalf("Ошибка чтения приветствия: %v", err)
	}

	if msgType != websocket.TextMessage || string(msg) != "Добро пожаловать в WebSocket!" {
		t.Fatalf("Неожиданное сообщение: %s", string(msg))
	}

	fmt.Println("Рукопожатие WebSocket успешно завершено (HTTP 101 Switching Protocols)!")
	fmt.Printf("Сервер ответил: %s\n", string(msg))
}
```

ℹ️ Корректная инициализация Upgrader и проверка рукопожатия 101 Switching Protocols

## Под капотом

Метод `Upgrade` вызывает `w.(http.Hijacker).Hijack()`, забирая дескриптор сокета `net.Conn` и буферизированный ридер/райтер `bufio.ReadWriter` у стандартного HTTP-сервера. После этого рантайм `net/http` перестает управлять данным сокетом, и вся ответственность за его закрытие ложится на разработчика.

## Подводные камни

Возвращать `CheckOrigin: func(r *http.Request) bool { return true }` в продакшене без осознания рисков: любой сторонний вредоносный сайт в браузере пользователя сможет открыть WebSocket к вашему API, используя куки сессии жертвы (уязвимость CSWSH).

## На собеседовании

**Вопрос с собеседования:** «Как устроен алгоритм вычисления Sec-WebSocket-Accept при рукопожатии?»
**Ответ:** Сервер берет заголовок `Sec-WebSocket-Key`, конкатенирует его с жестко фиксированной магической строкой GUID (`"258EAFA5-E914-47DA-95CA-C5AB0DC85B11"`), вычисляет SHA-1 хэш от полученной строки и кодирует результат в Base64. Клиент проверяет заголовок `Sec-WebSocket-Accept`, чтобы убедиться, что сервер действительно поддерживает протокол WebSocket, а не просто проксирует трафик.
