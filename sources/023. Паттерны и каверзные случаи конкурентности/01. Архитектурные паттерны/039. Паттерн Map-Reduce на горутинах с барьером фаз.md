# Паттерн Map-Reduce на горутинах с барьером фаз sync.WaitGroup

## Условие

Реализуй **Map-Reduce**: фаза Map — N горутин обрабатывают входные данные, фаза Reduce — одна горутина агрегирует результаты из канала. Используй `sync.WaitGroup` для барьера между фазами.

## Теория

Паттерн Map-Reduce в памяти:
1. Фаза Map: \(N\) параллельных горутин трансформируют исходные данные и пишут промежуточные результаты в канал.
2. Барьер: `sync.WaitGroup` ожидает завершения всех Map-воркеров и закрывает канал.
3. Фаза Reduce: терминальная горутина агрегирует (схлопывает) поток в итоговый результат.

## Решение по шагам

1. Подготовим срез слов.
2. В фазе Map параллельно подсчитаем длины слов.
3. Закроем промежуточный канал через барьер `wg.Wait()`.
4. В фазе Reduce сложим суммарную длину всех слов.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	words := []string{"golang", "concurrency", "goroutine", "channel", "mutex", "pipeline"}

	mapChan := make(chan int, len(words))
	var mapWg sync.WaitGroup

	// --- 1. ФАЗА MAP (Параллельная обработка) ---
	for _, word := range words {
		mapWg.Add(1)
		go func(w string) {
			defer mapWg.Done()
			mapChan <- len(w) // Отображаем слово в его длину
		}(word)
	}

	// --- 2. БАРЬЕР МЕЖДУ ФАЗАМИ ---
	go func() {
		mapWg.Wait()
		close(mapChan)
	}()

	// --- 3. ФАЗА REDUCE (Агрегация результатов) ---
	totalLength := 0
	wordCount := 0
	for length := range mapChan {
		totalLength += length
		wordCount++
	}

	avgLength := float64(totalLength) / float64(wordCount)
	fmt.Printf("Обработано слов: %d, Суммарная длина символов: %d\n", wordCount, totalLength)
	fmt.Printf("Средняя длина слова: %.2f символов\n", avgLength)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Обработано слов: 6, Суммарная длина символов: 47
# Средняя длина слова: 7.83 символов
```

## Под капотом

Барьерная горутина `go func() { mapWg.Wait(); close(mapChan) }()` развязывает фазы Map и Reduce без блокировки основного потока.

## Подводные камни

Запуск фазы Reduce до закрытия `mapChan` без барьера приведет к зависанию `for range`.

## На собеседовании

**Вопрос с собеседования:** «Как распределенный MapReduce (Hadoop, Spark) соотносится с Go-конкурентностью?»
**Ответ:** Модель каналов и горутин в Go реализует те же принципы Map-Shuffle-Reduce в рамках одного сервера с использованием общей памяти и кольцевых очередей `hchan` вместо сетевых сокетов.
