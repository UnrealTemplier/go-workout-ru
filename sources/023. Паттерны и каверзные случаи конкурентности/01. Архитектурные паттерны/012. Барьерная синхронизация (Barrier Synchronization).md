# Барьерная синхронизация (Barrier Synchronization) фаз вычислений

## Условие

Барьерная синхронизация: используйте канал, чтобы заставить несколько горутин дождаться друг друга перед стартом следующей фазы.

## Теория

Паттерн Barrier (Барьер) разделяет параллельный алгоритм на фазы: ни одна горутина не может перейти к Фазе 2, пока **все** \(N\) горутин не завершат Фазу 1.

## Решение по шагам

1. Создадим структуру `Barrier` с `sync.WaitGroup`.
2. Запустим 3 воркера.
3. Заставим их синхронизироваться на барьере после Фазы 1.
4. Проверим одновременный переход к Фазе 2.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

type Barrier struct {
	count int
	wg    sync.WaitGroup
	gate  chan struct{}
}

func NewBarrier(n int) *Barrier {
	b := &Barrier{
		count: n,
		gate:  make(chan struct{}),
	}
	b.wg.Add(n)
	return b
}

func (b *Barrier) Await() {
	b.wg.Done()
	<-b.gate // Блокировка до открытия ворот
}

func (b *Barrier) Release() {
	b.wg.Wait()
	close(b.gate) // Мгновенное открытие ворот для всех горутин
}

func main() {
	const numNodes = 3
	barrier := NewBarrier(numNodes)
	var finalWg sync.WaitGroup

	for i := 1; i <= numNodes; i++ {
		finalWg.Add(1)
		go func(id int) {
			defer finalWg.Done()
			fmt.Printf("[Node #%d] Выполнение Фазы 1 (Инициализация)...\n", id)
			time.Sleep(time.Duration(id*10) * time.Millisecond)

			fmt.Printf("[Node #%d] Достиг барьера -> Ожидание остальных...\n", id)
			barrier.Await()

			fmt.Printf(" -> [Node #%d] Старт Фазы 2 (Распределенные вычисления)!\n", id)
		}(i)
	}

	barrier.Release()
	finalWg.Wait()
	fmt.Println("[Main] Все фазы барьерной синхронизации успешно пройдены.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Node #1] Выполнение Фазы 1 (Инициализация)...
# [Node #2] Выполнение Фазы 1 (Инициализация)...

# [Node #1] Достиг барьера -> Ожидание остальных...
# [Node #2] Достиг барьера -> Ожидание остальных...
# [Node #3] Достиг барьера -> Ожидание остальных...

#  -> [Node #2] Старт Фазы 2 (Распределенные вычисления)!
# [Main] Все фазы барьерной синхронизации успешно пройдены.
```

## Под капотом

`close(gate)` пробуждает все горутины из состояния ожидания за один системный такт.

## Подводные камни

Одноразовый барьер нельзя переиспользовать повторно без создания нового канала ворот.
