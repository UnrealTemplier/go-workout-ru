# Отмена долгой операции скачивания через select и сигнальный канал

## Условие

Реализуйте отмену долгой операции (например, скачивания файла) по сигналу из канала, используя `select` внутри цикла чтения.

## Теория

Шаг потокового ввода-вывода обязан проверять сигнал отмены перед каждым пакетом данных.

## Решение по шагам

1. Создадим функцию `downloadFile(cancelChan <-chan struct{})`.
2. В цикле скачивания чанков проверяем `select` с `cancelChan`.
3. Отправим сигнал отмены на середине загрузки.
4. Проверим корректную остановку.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func downloadFile(cancelChan <-chan struct{}) {
	fmt.Println("[Downloader] Старт загрузки файла (100 MB)...")

	for chunk := 1; chunk <= 10; chunk++ {
		select {
		case <-cancelChan:
			fmt.Printf("[Downloader] Загрузка отменена пользователем на чанке %d/10! Удаляю временный файл.\n", chunk)
			return
		default:
			time.Sleep(10 * time.Millisecond) // Имитация загрузки чанка
			fmt.Printf(" -> [Downloader] Скачан чанк %d/10 (%.0f%%)\n", chunk, float64(chunk)*10)
		}
	}

	fmt.Println("[Downloader] Файл успешно скачан!")
}

func main() {
	cancelChan := make(chan struct{})

	go func() {
		time.Sleep(35 * time.Millisecond)
		fmt.Println("\n[User] Нажата кнопка 'Отмена скачивания'!")
		close(cancelChan) // Сигнал отмены
	}()

	downloadFile(cancelChan)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Downloader] Старт загрузки файла (100 MB)...
#  -> [Downloader] Скачан чанк 1/10 (10%)
#  -> [Downloader] Скачан чанк 2/10 (20%)
#  -> [Downloader] Скачан чанк 3/10 (30%)
# 
# [User] Нажата кнопка 'Отмена скачивания'!
# [Downloader] Загрузка отменена пользователем на чанке 4/10! Удаляю временный файл.
```

## Под капотом

`close(cancelChan)` делает канал немедленно готовым к чтению Zero Value во всех `select`.

## Подводные камни

Если опустить `default`, `select` заблокируется на первой же итерации.

## На собеседовании

**Вопрос с собеседования:** «Как отменить операцию io.Copy в Go?»
**Ответ:** `io.Copy` блокирует поток на системном вызове `read()`. Для отмены сокет или файл закрывают из другой горутины (`conn.Close()`), что немедленно приводит к возврату ошибки `net.ErrClosed` из `io.Copy`.
