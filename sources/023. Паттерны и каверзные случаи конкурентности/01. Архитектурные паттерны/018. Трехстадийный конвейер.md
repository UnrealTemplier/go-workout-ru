# Трехстадийный конвейер: Генерация (1..100) -> Нечетные -> Квадраты

## Условие

**Паттерн "Конвейер" (Pipeline)**: Напишите конвейер обработки чисел из трех стадий (каждая стадия — это функция, принимающая канал и возвращающая новый канал):
* Стадия 1: Генерация чисел от 1 до 100.
* Стадия 2: Фильтрация (пропускает только нечетные числа).
* Стадия 3: Возведение в квадрат.
В функции `main` прочитайте финальные результаты из выходного канала.

## Теория

Практика функциональной декомпозиции конвейера: каждая стадия оформлена отдельной чистой функцией, принимающей и возвращающей канал.

## Решение по шагам

1. Реализуем `stageGenerate(max int) <-chan int`.
2. Реализуем `stageFilterOdd(in <-chan int) <-chan int`.
3. Реализуем `stageSquare(in <-chan int) <-chan int`.
4. Выведем первые 5 результатов в `main`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

// Стадия 1: Генерация чисел 1..100
func stageGenerate(max int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out)
		for i := 1; i <= max; i++ {
			out <- i
		}
	}()
	return out
}

// Стадия 2: Фильтрация нечетных чисел
func stageFilterOdd(in <-chan int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out)
		for n := range in {
			if n%2 != 0 {
				out <- n
			}
		}
	}()
	return out
}

// Стадия 3: Возведение в квадрат
func stageSquare(in <-chan int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out)
		for n := range in {
			out <- n * n
		}
	}()
	return out
}

func main() {
	// Композиция конвейера
	pipeline := stageSquare(stageFilterOdd(stageGenerate(10)))

	fmt.Println("Квадраты нечетных чисел от 1 до 10:")
	for res := range pipeline {
		fmt.Printf(" -> %d\n", res)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Квадраты нечетных чисел от 1 до 10:
#  -> 1
#  -> 9
#  -> 25
#  -> 49
#  -> 81
```

## Под капотом

Каждая стадия закрывает свой выходной канал, запуская каскадное завершение цикла `for range` следующей стадии.

## Подводные камни

Пропуск `defer close(out)` на любой стадии заморозит конвейер навсегда.

## На собеседовании

**Вопрос с собеседования:** «Как обработать ошибки, возникающие внутри промежуточных стадий Pipeline?»
**Ответ:** Передавать через канал структуры-результаты `Result[T]{ Value T, Err error }` либо передавать выделенный канал ошибок `errc <-chan error`.
