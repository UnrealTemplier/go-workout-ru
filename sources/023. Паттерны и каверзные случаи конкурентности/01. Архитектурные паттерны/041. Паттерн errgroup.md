# Паттерн errgroup: конкурентный запуск N задач с отменой по первой ошибке

## Условие

Реализуй **"errgroup"** вручную (или используй `golang.org/x/sync/errgroup`): запускаешь N горутин, если **любая** возвращает ошибку — отменяешь остальные через `context.WithCancel`. Собери первую ошибку.

## Теория

Паттерн `errgroup.Group`:
1. Управление пулом горутин с `sync.WaitGroup`.
2. Захват первой встреченной ошибки через `sync.Once`.
3. Автоматическая отмена контекста `cancel()` для всех остальных параллельных задач.

## Решение по шагам

1. Реализуем структуру `CustomErrGroup` с `context.WithCancel` и `sync.Once`.
2. Метод `Go(fn func() error)`.
3. Метод `Wait() error`.
4. Запустим 3 задачи, одна из которых сымитирует сбой.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"errors"
	"fmt"
	"sync"
	"time"
)

type CustomErrGroup struct {
	ctx      context.Context
	cancel   context.CancelFunc
	wg       sync.WaitGroup
	errOnce  sync.Once
	firstErr error
}

func WithContext(parent context.Context) (*CustomErrGroup, context.Context) {
	ctx, cancel := context.WithCancel(parent)
	return &CustomErrGroup{ctx: ctx, cancel: cancel}, ctx
}

func (g *CustomErrGroup) Go(fn func() error) {
	g.wg.Add(1)
	go func() {
		defer g.wg.Done()
		if err := fn(); err != nil {
			g.errOnce.Do(func() {
				g.firstErr = err
				g.cancel() // Отменяем все остальные горутины при первой ошибке!
			})
		}
	}()
}

func (g *CustomErrGroup) Wait() error {
	g.wg.Wait()
	g.cancel()
	return g.firstErr
}

func main() {
	g, ctx := WithContext(context.Background())

	// Задача 1: Успешная
	g.Go(func() error {
		time.Sleep(10 * time.Millisecond)
		return nil
	})

	// Задача 2: Завершается с ошибкой
	g.Go(func() error {
		time.Sleep(15 * time.Millisecond)
		return errors.New("ошибка базы данных: connection refused")
	})

	// Задача 3: Долгая (должна быть отменена)
	g.Go(func() error {
		select {
		case <-time.After(100 * time.Millisecond):
			return nil
		case <-ctx.Done():
			fmt.Println(" -> [Task #3] Успешно прервана по сигналу отмены!")
			return ctx.Err()
		}
	})

	err := g.Wait()
	fmt.Printf("[Main] Итоговая ошибка errgroup: %v\n", err)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
#  -> [Task #3] Успешно прервана по сигналу отмены!
# [Main] Итоговая ошибка errgroup: ошибка базы данных: connection refused
```

## Под капотом

`sync.Once` гарантирует, что переменная `firstErr` сохранит строго первую произошедшую ошибку.

## Подводные камни

Все задачи внутри `errgroup` обязаны слушать `ctx.Done()`, чтобы отмена действительно останавливала выполнение.

## На собеседовании

**Вопрос с собеседования:** «Каковы ключевые методы пакета golang.org/x/sync/errgroup?»
**Ответ:** `g, ctx := errgroup.WithContext(ctx)` создает группу, метод `g.Go(fn)` запускает задачу, `g.SetLimit(N)` ограничивает параллелизм (в Go 1.20+), а `g.Wait()` блокируется до завершения всех задач и возвращает первую ошибку.
