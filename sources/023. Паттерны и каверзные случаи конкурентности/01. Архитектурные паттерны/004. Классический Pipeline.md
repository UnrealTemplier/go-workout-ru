# Классический Pipeline: генерация, трансформация и терминальный вывод

## Условие

Pipeline: стадии `generate` → `square` → `print`. Используйте каналы для связи.

## Теория

Терминальная стадия конвейера потребляет данные и выполняет сайд-эффекты (вывод в консоль, запись на диск). Закрытие входного канала каскадно распространяется по всей цепочке до финального потребителя.

## Решение по шагам

1. Функция `generate(nums ...int) <-chan int`.
2. Функция `square(in <-chan int) <-chan int`.
3. Функция `printResults(in <-chan int)`.
4. Свяжем стадии и выполним расчет.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func generate(nums ...int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out)
		for _, n := range nums {
			out <- n
		}
	}()
	return out
}

func square(in <-chan int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out)
		for n := range in {
			out <- n * n
		}
	}()
	return out
}

func printResults(in <-chan int) {
	for val := range in {
		fmt.Printf("[Pipeline Out] Квадрат числа: %d\n", val)
	}
}

func main() {
	numbers := generate(1, 3, 5, 7)
	squared := square(numbers)
	printResults(squared)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Pipeline Out] Квадрат числа: 1
# [Pipeline Out] Квадрат числа: 9
# [Pipeline Out] Квадрат числа: 25
# [Pipeline Out] Квадрат числа: 49
```

## Под капотом

Каналы обеспечивают синхронизацию скорости стадий: быстрая генерация притормаживается, если стадия обработки не успевает вычитывать буфер (Backpressure).

## Подводные камни

Не забывайте `close(out)` в `defer` на каждой промежуточной стадии конвейера.

## На собеседовании

**Вопрос с собеседования:** «Что такое Backpressure в Go Pipeline?»
**Ответ:** Это естественный механизм противодавления, когда заблокированная запись в небуферизованный (или заполненный буферизованный) канал заставляет предыдущую стадию приостановить генерацию, предотвращая исчерпание RAM.
