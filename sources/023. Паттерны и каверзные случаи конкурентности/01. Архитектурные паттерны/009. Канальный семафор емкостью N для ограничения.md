# Канальный семафор емкостью N для ограничения доступа к внешнему ресурсу

## Условие

Семафор на основе канала (буферизированный канал ёмкостью N): ограничьте количество одновременно выполняющихся горутин, которые обращаются к внешнему ресурсу.

## Теория

Паттерн Bounded Concurrency: защита пулов соединений СУБД от исчерпания `max_connections`.

## Решение по шагам

1. Создадим семафор на 2 слота.
2. Запустим 4 горутины, имитирующие доступ к СУБД.
3. Продемонстрируем строгий лимит одновременных подключений.
4. Проверим результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

type DBGateway struct {
	sem chan struct{}
}

func NewDBGateway(maxConns int) *DBGateway {
	return &DBGateway{
		sem: make(chan struct{}, maxConns),
	}
}

func (g *DBGateway) Query(id int, wg *sync.WaitGroup) {
	defer wg.Done()

	g.sem <- struct{}{}        // Acquire
	defer func() { <-g.sem }() // Release

	fmt.Printf("[DB] Подключение открыто для горутины #%d\n", id)
	time.Sleep(15 * time.Millisecond)
	fmt.Printf(" -> [DB] Подключение закрыто для горутины #%d\n", id)
}

func main() {
	gateway := NewDBGateway(2) // Максимум 2 соединения
	var wg sync.WaitGroup

	for i := 1; i <= 4; i++ {
		wg.Add(1)
		go gateway.Query(i, &wg)
	}

	wg.Wait()
	fmt.Println("[Main] Все запросы к БД выполнены в рамках лимита подключений.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [DB] Подключение открыто для горутины #1
# [DB] Подключение открыто для горутины #2
#  -> [DB] Подключение закрыто для горутины #1
#  -> [DB] Подключение закрыто для горутины #2
# [DB] Подключение открыто для горутины #3
# [DB] Подключение открыто для горутины #4
#  -> [DB] Подключение закрыто для горутины #3
#  -> [DB] Подключение закрыто для горутины #4
# [Main] Все запросы к БД выполнены в рамках лимита подключений.
```

## Под капотом

Буфер канала размера \(N\) удерживает \(N\) маркеров.

## Подводные камни

Вызов `<-sem` без предварительного `sem <- struct{}{}` нарушит баланс семафора.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать Acquire с поддержкой таймаута контекста?»
**Ответ:** Через `select`: `select { case sem <- struct{}{}: return nil; case <-ctx.Done(): return ctx.Err() }`.
