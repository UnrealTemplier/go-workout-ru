# Слияние двух независимых каналов: функция Merge(ch1, ch2)

## Условие

**Fan-in (Слияние)**: Напиши функцию `Merge(ch1, ch2 <-chan int) <-chan int`. Внутри запусти горутину, которая читает из обоих каналов (через `select` или горутины с WaitGroup) и пишет данные в один общий выходной канал.

## Теория

Бинарный Fan-In для слияния двух каналов с гарантией закрытия выхода после исчерпания обоих источников.

## Решение по шагам

1. Объявим `Merge(ch1, ch2 <-chan int) <-chan int`.
2. Запустим 2 горутины с `sync.WaitGroup`.
3. В фоновой горутине вызовем `close(out)`.
4. Проверим результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func Merge(ch1, ch2 <-chan int) <-chan int {
	out := make(chan int)
	var wg sync.WaitGroup

	forward := func(c <-chan int) {
		defer wg.Done()
		for val := range c {
			out <- val
		}
	}

	wg.Add(2)
	go forward(ch1)
	go forward(ch2)

	go func() {
		wg.Wait()
		close(out)
	}()

	return out
}

func main() {
	c1 := make(chan int, 2)
	c2 := make(chan int, 2)

	c1 <- 10; c1 <- 20; close(c1)
	c2 <- 30; c2 <- 40; close(c2)

	merged := Merge(c1, c2)

	for res := range merged {
		fmt.Printf("Получено значение: %d\n", res)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Получено значение: 10
# Получено значение: 20
# Получено значение: 30
# Получено значение: 40
```

## Под капотом

Две горутины `forward` безопасно пишут в общий `out`.

## Подводные камни

Не закрывайте `out` до завершения обеих горутин.

## На собеседовании

**Вопрос с собеседования:** «Можно ли сделать Merge(ch1, ch2) без создания двух горутин?»
**Ответ:** Можно через одну горутину с циклом `for ch1 != nil || ch2 != nil` и `select`, выставляя закрытый канал в `nil` (`ch = nil`).
