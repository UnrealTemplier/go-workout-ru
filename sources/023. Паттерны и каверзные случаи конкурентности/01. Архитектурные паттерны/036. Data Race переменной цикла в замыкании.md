# Data Race переменной цикла в замыкании (Loop Variable Shadowing)

## Условие

**Data Race с замыканием**: Запустите цикл `for`, в котором создаются горутины, использующие переменную цикла `i`. (Для Go < 1.22 все выведут последнее значение).

## Теория

До Go 1.22 переменная цикла `for i := 0; i < N; i++` переиспользовала один и тот же адрес памяти на всех итерациях. Анонимные горутины захватывали указатель на `i`, что приводило к Data Race и выводу одинаковых последних значений. В Go 1.22+ семантика цикла изменена на создание новой переменной на каждой итерации.

## Решение по шагам

1. Напишем цикл запуска горутин.
2. Продемонстрируем передачу параметра `go func(val int)` как канонический кросс-версионный стандарт.
3. Проверим вывод с флагом `-race`.
4. Убедимся в корректности.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup
	const total = 5

	wg.Add(total)
	for i := 1; i <= total; i++ {
		// КАНОНИЧЕСКИЙ СПОСОБ: передача i параметром горутины гарантирует
		// независимую копию на стеке для ЛЮБОЙ версии Go (включая старые)!
		go func(val int) {
			defer wg.Done()
			fmt.Printf("Горутина получила значение: %d\n", val)
		}(i)
	}

	wg.Wait()
	fmt.Println("[Main] Все горутины вывели уникальные значения.")
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# Горутина получила значение: 1
# Горутина получила значение: 2
# Горутина получила значение: 3
# Горутина получила значение: 4
# Горутина получила значение: 5
# [Main] Все горутины вывели уникальные значения.
```

## Под капотом

Передача `val int` в аргументы создает локальную копию значения на фрейме стека созданной горутины.

## Подводные камни

Не полагайтесь на неявное поведение компилятора — явная передача параметров всегда предпочтительнее.

## На собеседовании

**Вопрос с собеседования:** «Какое изменение в поведении цикла for произошло в релизе Go 1.22?»
**Ответ:** Начиная с Go 1.22 переменные цикла `for i := range ...` имеют per-iteration область видимости (каждая итерация создает новую переменную в памяти), устраняя классический баг замыканий без флага GOEXPERIMENT=loopvar.
