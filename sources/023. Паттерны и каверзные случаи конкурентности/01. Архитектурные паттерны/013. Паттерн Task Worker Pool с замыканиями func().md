# Паттерн Task Worker Pool с замыканиями func() error и каналом результатов

## Условие

Реализуй **Worker Pool**: фиксированное число воркеров (например, 3), канал задач (`chan func() error`), канал результатов. Воркеры читают задачи, выполняют, отправляют результат. `main` закрывает канал задач и ждёт `sync.WaitGroup`.

## Теория

Паттерн Function Task Pool: задачи передаются в виде функций высшего порядка `func() error`. Это позволяет воркерам выполнять любые разнородные операции (HTTP-запросы, парсинг, запись в БД) через единый универсальный интерфейс.

## Решение по шагам

1. Создадим канал задач `tasks := make(chan func() error, 10)`.
2. Создадим канал ошибок `results := make(chan error, 10)`.
3. Запустим 3 воркера.
4. Отправим задачи, соберем ошибки и закроем пул.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

type Task = func() error

func taskWorker(id int, tasks <-chan Task, results chan<- error, wg *sync.WaitGroup) {
	defer wg.Done()
	for task := range tasks {
		err := task()
		results <- err
	}
}

func main() {
	tasks := make(chan Task, 5)
	results := make(chan error, 5)
	var wg sync.WaitGroup

	const numWorkers = 3
	for i := 1; i <= numWorkers; i++ {
		wg.Add(1)
		go taskWorker(i, tasks, results, &wg)
	}

	// Отправка разнородных задач
	tasks <- func() error {
		time.Sleep(5 * time.Millisecond)
		return nil
	}
	tasks <- func() error {
		time.Sleep(10 * time.Millisecond)
		return fmt.Errorf("ошибка парсинга JSON")
	}
	tasks <- func() error {
		time.Sleep(5 * time.Millisecond)
		return nil
	}
	close(tasks)

	go func() {
		wg.Wait()
		close(results)
	}()

	errCount := 0
	for err := range results {
		if err != nil {
			errCount++
			fmt.Printf("[Result] Задача завершилась с ошибкой: %v\n", err)
		} else {
			fmt.Println("[Result] Задача выполнена успешно")
		}
	}

	fmt.Printf("[Main] Обработка завершена. Всего ошибок: %d\n", errCount)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Result] Задача выполнена успешно
# [Result] Задача выполнена успешно
# [Result] Задача завершилась с ошибкой: ошибка парсинга JSON
# [Main] Обработка завершена. Всего ошибок: 1
```

## Под капотом

Замыкания `func() error` упаковывают окружение задачи в структуру с указателем на функцию.

## Подводные камни

Внутри замыкания не забывайте захватывать переменные цикла по значению.

## На собеседовании

**Вопрос с собеседования:** «Каковы преимущества передачи func() error вместо жестких структур данных в Task Pool?»
**Ответ:** Это обеспечивает максимальную гибкость и полиморфизм: вызывающий код может передать любую функцию с любыми аргументами без изменения кода самого Worker Pool.
