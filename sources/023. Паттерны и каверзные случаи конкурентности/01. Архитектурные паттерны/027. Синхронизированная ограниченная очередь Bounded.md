# Синхронизированная ограниченная очередь Bounded Queue на каналах

## Условие

Реализуй **Bounded Queue** через канал: `type Queue struct { ch chan int }`. Методы `Enqueue(v int) bool` (false если полон), `Dequeue() (int, bool)`. Используй канал как синхронизированную очередь.

## Теория

Буферизованный канал Go — это готовая lock-free кольцевая очередь FIFO. Методы `Enqueue` и `Dequeue` с использованием `select default` позволяют реализовать неблокирующую очередь.

## Решение по шагам

1. Создадим структуру `Queue struct { ch chan int }`.
2. Реализуем `Enqueue(v int) bool` с `select default`.
3. Реализуем `Dequeue() (int, bool)` с `select default`.
4. Протестируем поведение при переполнении и опустошении.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

type Queue struct {
	ch chan int
}

func NewQueue(capacity int) *Queue {
	return &Queue{
		ch: make(chan int, capacity),
	}
}

func (q *Queue) Enqueue(v int) bool {
	select {
	case q.ch <- v:
		return true
	default:
		return false // Очередь переполнена
	}
}

func (q *Queue) Dequeue() (int, bool) {
	select {
	case val := <-q.ch:
		return val, true
	default:
		return 0, false // Очередь пуста
	}
}

func main() {
	q := NewQueue(2)

	fmt.Println("Enqueue 10:", q.Enqueue(10)) // true
	fmt.Println("Enqueue 20:", q.Enqueue(20)) // true
	fmt.Println("Enqueue 30:", q.Enqueue(30)) // false (полна!)

	val, ok := q.Dequeue()
	fmt.Printf("Dequeue: val=%d, ok=%v\n", val, ok)

	fmt.Println("Enqueue 30 (повторно):", q.Enqueue(30)) // true
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Enqueue 10: true
# Enqueue 20: true
# Enqueue 30: false
# Dequeue: val=10, ok=true
# Enqueue 30 (повторно): true
```

## Под капотом

`select default` возвращает управление за пару процессорных инструкций без блокировки горутины в планировщике.

## Подводные камни

Для блокирующих версий методов достаточно убрать секцию `default`.

## На собеседовании

**Вопрос с собеседования:** «Какова сложность операций Enqueue и Dequeue в канале Go?»
**Ответ:** \(O(1)\) по времени и \(O(1)\) по дополнительной памяти благодаря кольцевому буферу массива внутри структуры `hchan`.
