# Паттерн Fan-Out / Fan-In: параллельная обработка и слияние результатов

## Условие

Fan-out/Fan-in: генератор чисел, несколько горутин умножают числа на 2, затем объединяют результаты в один канал.

## Теория

Паттерн Fan-Out/Fan-In — фундаментальный архитектурный паттерн конкурентности в Go. Fan-Out (Разветвление) распределяет задачи из одного канала между \(N\) параллельными горутинами для параллельного выполнения на всех ядрах CPU. Fan-In (Слияние) мультиплексирует выходные каналы всех воркеров в единый результирующий поток с помощью `sync.WaitGroup`.

## Решение по шагам

1. Создадим генератор `generator(nums ...int) <-chan int`.
2. Запустим несколько параллельных воркеров (Fan-Out): `worker(in <-chan int) <-chan int`.
3. Реализуем функцию слияния (Fan-In): `merge(cs ...<-chan int) <-chan int`.
4. В `main` прочитаем результаты из общего канала.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

// Генератор входных данных
func generator(nums ...int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out)
		for _, n := range nums {
			out <- n
		}
	}()
	return out
}

// Воркер (Fan-Out этап)
func multiplier(in <-chan int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out)
		for n := range in {
			out <- n * 2
		}
	}()
	return out
}

// Слияние N каналов в один (Fan-In этап)
func merge(cs ...<-chan int) <-chan int {
	out := make(chan int)
	var wg sync.WaitGroup

	output := func(c <-chan int) {
		defer wg.Done()
		for n := range c {
			out <- n
		}
	}

	wg.Add(len(cs))
	for _, c := range cs {
		go output(c)
	}

	go func() {
		wg.Wait()
		close(out)
	}()

	return out
}

func main() {
	in := generator(1, 2, 3, 4, 5, 6)

	// Fan-Out: 2 параллельных воркера
	w1 := multiplier(in)
	w2 := multiplier(in)

	// Fan-In: слияние результатов в один канал
	for res := range merge(w1, w2) {
		fmt.Printf("Получен результат умножения: %d\n", res)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Получен результат умножения: 2
# Получен результат умножения: 4
# Получен результат умножения: 6
# Получен результат умножения: 8
# Получен результат умножения: 10
# Получен результат умножения: 12
```

## Под капотом

Несколько горутин `multiplier` конкурируют за получение элементов из одного входного канала `in`. Рантайм Go гарантирует, что каждый элемент канала достанется ровно одной горутине без дублирования.

## Подводные камни

Закрытие результирующего канала `out` до завершения всех горутин `output` приведет к фатальной панике `panic: send on closed channel`.

## На собеседовании

**Вопрос с собеседования:** «Почему в паттерне Fan-In закрытие результирующего канала выносят в отдельную горутину go func() { wg.Wait(); close(out) }?»
**Ответ:** Потому что функция `merge` обязана сразу вернуть канал `<-chan int` вызывающему коду без блокировки, а закрытие канала должно произойти строго асинхронно после вычитки всех входных каналов.
