# Паттерн Generator: генератор чисел Фибоначчи в инкапсулированной горутине

## Условие

**Генератор (Generator)**: Напишите функцию, которая возвращает канал и в скрытой горутине генерирует туда последовательность чисел (например, Фибоначчи).

## Теория

Паттерн Generator инкапсулирует создание канала и запуск фоновой горутины внутри функции. Вызывающий код получает только однонаправленный канал `<-chan int` для чтения.

## Решение по шагам

1. Объявим `FibonacciGenerator(limit int) <-chan int`.
2. Внутри выделим `ch := make(chan int)`.
3. В горутине вычислим \(N\) чисел Фибоначчи и закроем канал.
4. В `main` прочитаем последовательность через `for range`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

// FibonacciGenerator генерирует первые n чисел Фибоначчи
func FibonacciGenerator(n int) <-chan int {
	ch := make(chan int)

	go func() {
		defer close(ch)
		a, b := 0, 1
		for i := 0; i < n; i++ {
			ch <- a
			a, b = b, a+b
		}
	}()

	return ch
}

func main() {
	fmt.Println("Первые 8 чисел Фибоначчи:")
	for num := range FibonacciGenerator(8) {
		fmt.Printf(" -> %d\n", num)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Первые 8 чисел Фибоначчи:
#  -> 0
#  -> 1
#  -> 1
#  -> 2
#  -> 3
#  -> 5
#  -> 8
#  -> 13
```

## Под капотом

`FibonacciGenerator` скрывает состояние `(a, b)` внутри лексического замыкания горутины.

## Подводные камни

Если вызывающий код прекратит чтение до исчерпания \(n\), горутина зависнет. Для защиты добавляют канал отмены `ctx context.Context`.

## На собеседовании

**Вопрос с собеседования:** «Как сделать генератор безопасным от утечек при досрочном прерывании?»
**Ответ:** Передавать `ctx context.Context` первым аргументом и оборачивать отправку в канал в `select { case ch <- val: case <-ctx.Done(): return }`.
