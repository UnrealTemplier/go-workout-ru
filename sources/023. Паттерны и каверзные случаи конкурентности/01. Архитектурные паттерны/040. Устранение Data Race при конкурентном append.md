# Устранение Data Race при конкурентном append в общий срез

## Условие

**Data Race со слайсом**: Несколько горутин одновременно делают `append` в один общий слайс. Программа упадет с `concurrent map read and map write` или повредит память. Защитите слайс мьютексом.

## Теория

Срез (Slice) в Go состоит из трех полей `(array unsafe.Pointer, len int, cap int)`. Конкурентный вызов `append` из нескольких горутин без мьютекса приводит к повреждению памяти (Memory Corruption), перезаписи указателей на массив и потере элементов.

## Решение по шагам

1. Создадим структуру `SafeSlice` с `sync.Mutex`.
2. Реализуем метод `Append(val int)`.
3. Запустим 1000 горутин, выполняющих конкурентный `Append`.
4. Проверим результат с флагом `-race`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

type SafeSlice struct {
	mu   sync.Mutex
	data []int
}

func (s *SafeSlice) Append(val int) {
	s.mu.Lock()
	defer s.mu.Unlock()
	s.data = append(s.data, val)
}

func (s *SafeSlice) Len() int {
	s.mu.Lock()
	defer s.mu.Unlock()
	return len(s.data)
}

func main() {
	safe := &SafeSlice{}
	var wg sync.WaitGroup
	const total = 1000

	wg.Add(total)
	for i := 0; i < total; i++ {
		go func(val int) {
			defer wg.Done()
			safe.Append(val)
		}(i)
	}

	wg.Wait()
	fmt.Printf("Финальный размер среза: %d (Ожидалось: %d, Race отсутствует!)\n", 
		safe.Len(), total)
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# Финальный размер среза: 1000 (Ожидалось: 1000, Race отсутствует!)
```

## Под капотом

Мьютекс гарантирует, что реаллокация подлежащего массива при росте `cap` среза происходит строго атомарно для одной горутины.

## Подводные камни

Без мьютекса параллельный `append` потеряет до 50% данных и выдаст ошибку `DATA RACE` в Race Detector.

## На собеседовании

**Вопрос с собеседования:** «Почему append в слайс не является потокобезопасным в Go?»
**Ответ:** Потому что структура `reflect.SliceHeader` занимает 24 байта (3 машинных слова). Модификация `len`, `cap` и копирование указателя на массив `Data` не могут быть выполнены одной неделимой инструкцией CPU.
