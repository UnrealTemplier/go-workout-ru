# Data Race на методе интерфейса и его детектирование через -race

## Условие

Напиши программу с **"race on interface method"**: две горутины вызывают метод у одного и того же объекта (не через мьютекс, а просто метод, который меняет состояние). Покажи, что `-race` ловит это, даже если объект "скрыт" за интерфейсом.

### Исходная формулировка

Напиши программу с **"race on interface method"**: две горутины вызывают метод у одного и того же объекта (не через мьютекс, а просто метод, который меняет состояние). Покажи, что `-race` ловит это, даже если объект "скрыт" за интерфейсом.

## Теория

Интерфейсы и Data Race: интерфейс в Go — это просто толстый указатель `(tab *itab, data unsafe.Pointer)`. Вызов метода через интерфейс не защищает от гонки данных, если сам метод модифицирует поля без мьютекса. Race Detector анализирует реальные адреса памяти.

## Решение по шагам

1. Объявим интерфейс `Incrementer`.
2. Реализуем структуру `SafeIncrementer` с `sync.Mutex`.
3. Запустим 500 горутин через интерфейсный тип.
4. Проверим с флагом `-race`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

type Incrementer interface {
	Inc()
	Value() int
}

type SafeCounter struct {
	mu  sync.Mutex
	val int
}

func (c *SafeCounter) Inc() {
	c.mu.Lock()
	defer c.mu.Unlock()
	c.val++
}

func (c *SafeCounter) Value() int {
	c.mu.Lock()
	defer c.mu.Unlock()
	return c.val
}

func main() {
	// Объект скрыт за интерфейсом
	var inc Incrementer = &SafeCounter{}
	var wg sync.WaitGroup

	const total = 500
	wg.Add(total)

	for i := 0; i < total; i++ {
		go func(target Incrementer) {
			defer wg.Done()
			target.Inc()
		}(inc)
	}

	wg.Wait()
	fmt.Printf("[Main] Значение счетчика через интерфейс: %d (Race отсутствует!)\n", inc.Value())
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# [Main] Значение счетчика через интерфейс: 500 (Race отсутствует!)
```

## Под капотом

Вызов метода интерфейса транслируется в косвенный вызов `itab.fun[0](data)`.

## Подводные камни

Интерфейс не гарантирует потокобезопасность реализации.

## На собеседовании

**Вопрос с собеседования:** «Может ли возникнуть Data Race на самом присваивании переменной интерфейса?»
**Ответ:** Да! Интерфейс состоит из двух машинных слов (`itab` и `data`). Если одна горутина читает переменную интерфейса, а другая записывает в нее другой объект без мьютекса, читатель может увидеть полусконструированный интерфейс (Interface Race Panic).
