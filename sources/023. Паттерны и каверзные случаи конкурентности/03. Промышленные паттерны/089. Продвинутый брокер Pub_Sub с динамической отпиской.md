# Продвинутый брокер Pub/Sub с динамической отпиской Unsubscribe

## Условие

**[Высокая сложность] Publish/Subscribe (Шина событий)**: Создай структуру `Broker`. Метод `Subscribe()` возвращает новый канал. Метод `Publish(msg)` рассылает сообщение всем подписчикам (горутина бродкастит во все каналы). Реализуй отписку.

## Теория

Паттерн Event Broker с динамической отпиской: брокер управляет множеством каналов-подписчиков под защитой `sync.RWMutex`. Метод `Unsubscribe(ch)` безопасно удаляет канал из среза и закрывает его.

## Решение по шагам

1. Создадим структуру `AdvancedBroker` с мьютексом и срезом каналов.
2. Реализуем `Subscribe() <-chan string`.
3. Реализуем `Unsubscribe(ch)`.
4. Реализуем `Publish(msg)`.
5. Продемонстрируем отписку одного из клиентов.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

type AdvancedBroker struct {
	mu   sync.RWMutex
	subs map[chan string]struct{}
}

func NewAdvancedBroker() *AdvancedBroker {
	return &AdvancedBroker{
		subs: make(map[chan string]struct{}),
	}
}

func (b *AdvancedBroker) Subscribe() chan string {
	b.mu.Lock()
	defer b.mu.Unlock()

	ch := make(chan string, 10)
	b.subs[ch] = struct{}{}
	return ch
}

func (b *AdvancedBroker) Unsubscribe(ch chan string) {
	b.mu.Lock()
	defer b.mu.Unlock()

	if _, ok := b.subs[ch]; ok {
		delete(b.subs, ch)
		close(ch)
		fmt.Println("[Broker] Подписчик успешно отписан и канал закрыт.")
	}
}

func (b *AdvancedBroker) Publish(msg string) {
	b.mu.RLock()
	defer b.mu.RUnlock()

	for ch := range b.subs {
		select {
		case ch <- msg:
		default:
		}
	}
}

func main() {
	broker := NewAdvancedBroker()

	sub1 := broker.Subscribe()
	sub2 := broker.Subscribe()

	var wg sync.WaitGroup
	wg.Add(2)

	go func() {
		defer wg.Done()
		for msg := range sub1 {
			fmt.Printf(" [Sub 1] %s\n", msg)
		}
	}()

	go func() {
		defer wg.Done()
		for msg := range sub2 {
			fmt.Printf(" [Sub 2] %s\n", msg)
		}
	}()

	broker.Publish("Новость 1")
	time.Sleep(5 * time.Millisecond)

	// Отписываем первого подписчика
	broker.Unsubscribe(sub1)

	// Вторую новость получит только Sub 2
	broker.Publish("Новость 2 (только для активных)")
	time.Sleep(5 * time.Millisecond)

	broker.Unsubscribe(sub2)
	wg.Wait()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
#  [Sub 1] Новость 1
#  [Sub 2] Новость 1
# [Broker] Подписчик успешно отписан и канал закрыт.
#  [Sub 2] Новость 2 (только для активных)
# [Broker] Подписчик успешно отписан и канал закрыт.
```

## Под капотом

Мапа `subs map[chan string]struct{}` обеспечивает удаление подписчика за \(O(1)\).

## Подводные камни

Закрытие канала при отписке оповещает горутину подписчика о выходе из цикла `for msg := range sub`.

## На собеседовании

**Вопрос с собеседования:** «Почему в качестве реестра подписчиков мапа map[chan T]struct{} лучше слайса []chan T?»
**Ответ:** Мапа позволяет находить и удалять отписывающийся канал за \(O(1)\) по значению самого указателя на канал без необходимости линейного сканирования среза за \(O(N)\).
