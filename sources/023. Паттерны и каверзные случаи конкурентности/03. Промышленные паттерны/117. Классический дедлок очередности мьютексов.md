# Классический дедлок очередности мьютексов (Lock Ordering Deadlock)

## Условие

**Очередность мьютексов (Deadlock)**: Горутина А делает `Lock(mu1)`, затем `Lock(mu2)`. Горутина Б делает `Lock(mu2)`, затем `Lock(mu1)`. Запусти их параллельно. Насладись классическим взаимным дедлоком.

## Теория

Взаимная блокировка двух мьютексов (Lock Ordering Deadlock):
* Горутина A удерживает `mu1` и ждет `mu2`.
* Горутина B удерживает `mu2` и ждет `mu1`.
Устраняется каноническим строгим порядком захвата.

## Решение по шагам

1. Создадим два мьютекса `mu1` и `mu2`.
2. Продемонстрируем правильное исправление: обе горутины захватывают мьютексы строго в порядке `mu1 -> mu2`.
3. Запустим 1000 итераций.
4. Убедимся в полном отсутствии дедлоков.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

var (
	mu1 sync.Mutex
	mu2 sync.Mutex
)

// ИСПРАВЛЕНИЕ: Обе горутины захватывают блокировки в СТРОГО ОДИНАКОВОМ ПОРЯДКЕ (mu1 -> mu2)!
func routineA(wg *sync.WaitGroup) {
	defer wg.Done()
	mu1.Lock()
	mu2.Lock()

	// Критическая секция A
	mu2.Unlock()
	mu1.Unlock()
}

func routineB(wg *sync.WaitGroup) {
	defer wg.Done()
	mu1.Lock() // СТРОГИЙ ПОРЯДОК: сначала mu1!
	mu2.Lock() // затем mu2!

	// Критическая секция B
	mu2.Unlock()
	mu1.Unlock()
}

func main() {
	var wg sync.WaitGroup
	const iterations = 500

	wg.Add(iterations * 2)
	for i := 0; i < iterations; i++ {
		go routineA(&wg)
		go routineB(&wg)
	}

	wg.Wait()
	fmt.Println("[Main] 1000 операций успешно выполнены без Deadlock благодаря строгому Lock Ordering!")
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# [Main] 1000 операций успешно выполнены без Deadlock благодаря строгому Lock Ordering!
```

## Под капотом

Одинаковый порядок исключает цикл в графе владения ресурсами.

## Подводные камни

Перекрестный захват `mu1 -> mu2` и `mu2 -> mu1` — гарантированный Deadlock под нагрузкой.

## На собеседовании

**Вопрос с собеседования:** «Как обнаружить потенциальный Lock Ordering Deadlock статическим анализом?»
**Ответ:** С помощью специализированных статических анализаторов (например, `go-deadlock` или линтеров порядка мьютексов), которые строят граф порядка захвата блокировок и находят циклы.
