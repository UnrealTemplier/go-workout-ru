# Параллельный парсер логов: построчное чтение и Worker Pool из 10 горутин

## Условие

**Параллельный парсер**: Напишите программу, которая читает большой лог-файл построчно, передает строки в Worker Pool из 10 горутин, которые парсят JSON и агрегируют статистику в потокобезопасную структуру.

## Теория

Высокопроизводительный конвейер парсинга: построчный ридер отправляет строки в канал `lines`, пул из 10 воркеров выполняет тяжелый JSON unmarshal, а результаты атомарно агрегируются в структуру статистики.

## Решение по шагам

1. Создадим структуру `LogStats` со счетчиками `atomic.Int64`.
2. Создадим канал `lines := make(chan string, 100)`.
3. Запустим пул из 10 воркеров.
4. Отправим 20 лог-записей и выведем агрегированный отчет.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"sync"
	"sync/atomic"
)

type LogEntry struct {
	Level   string `json:"level"`
	Message string `json:"message"`
}

type Stats struct {
	total atomic.Int64
	info  atomic.Int64
	warn  atomic.Int64
	error atomic.Int64
}

func parseWorker(lines <-chan string, stats *Stats, wg *sync.WaitGroup) {
	defer wg.Done()
	for line := range lines {
		var entry LogEntry
		if err := json.Unmarshal([]byte(line), &entry); err == nil {
			stats.total.Add(1)
			switch entry.Level {
			case "INFO":
				stats.info.Add(1)
			case "WARN":
				stats.warn.Add(1)
			case "ERROR":
				stats.error.Add(1)
			}
		}
	}
}

func main() {
	lines := make(chan string, 50)
	var stats Stats
	var wg sync.WaitGroup

	const numWorkers = 10
	for i := 0; i < numWorkers; i++ {
		wg.Add(1)
		go parseWorker(lines, &stats, &wg)
	}

	// Генерация логов
	sampleLogs := []string{
		`{"level":"INFO","message":"User logged in"}`,
		`{"level":"WARN","message":"High memory usage"}`,
		`{"level":"ERROR","message":"DB connection timeout"}`,
		`{"level":"INFO","message":"Payment processed"}`,
		`{"level":"ERROR","message":"Disk full"}`,
	}

	for _, l := range sampleLogs {
		lines <- l
	}
	close(lines)

	wg.Wait()

	fmt.Printf("[Stats] Всего обработано: %d логов\n", stats.total.Load())
	fmt.Printf(" -> INFO:  %d\n", stats.info.Load())
	fmt.Printf(" -> WARN:  %d\n", stats.warn.Load())
	fmt.Printf(" -> ERROR: %d\n", stats.error.Load())
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Stats] Всего обработано: 5 логов
#  -> INFO:  2
#  -> WARN:  1
#  -> ERROR: 2
```

## Под капотом

`atomic.Int64` (Go 1.19+) предоставляет типобезопасные методы `Add` и `Load` без накладных расходов на мьютексы.

## Подводные камни

Не используйте `sync.Mutex` для простых счетчиков в воркерах — атомики работают значительно быстрее.

## На собеседовании

**Вопрос с собеседования:** «Как распараллелить разбор терабайтного файла на Go?»
**Ответ:** Разбить файл на чанки по байтовым смещениям (Chunk Offsets), выровнять границы по переводам строк `\n` и запустить независимые горутины-воркеры с `io.NewSectionReader`.
