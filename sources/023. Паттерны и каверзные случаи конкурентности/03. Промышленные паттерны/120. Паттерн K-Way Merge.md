# Паттерн K-Way Merge: упорядоченное слияние K отсортированных каналов

## Условие

**Конкурентное слияние отсортированных данных (K-Way Merge)**: У вас есть 3 канала, в которые фоновые горутины отправляют отсортированные числа (например, в первом канале: `1, 4, 7...`, во втором: `2, 5, 8...`, в третьем: `3, 6, 9...`). Напишите функцию, которая считывает данные из этих каналов и сливает их в один выходной канал так, чтобы на выходе числа шли строго по возрастанию (`1, 2, 3, 4, 5, 6...`).

## Теория

Паттерн K-Way Merge (Слияние K упорядоченных потоков): классический алгоритм внешней сортировки. Мержер поддерживает буфер текущих головных элементов из всех \(K\) каналов и на каждом шаге отдает минимальный элемент в результирующий поток.

## Решение по шагам

1. Создадим функцию `KWayMerge(channels ...<-chan int) <-chan int`.
2. Считаем по первому элементу из каждого активного канала.
3. В цикле находим наименьший элемент, отправляем в `out` и дочитываем следующий из соответствующего канала.
4. Проверим слияние 3 отсортированных последовательностей.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"math"
)

func KWayMerge(channels ...chan int) <-chan int {
	out := make(chan int)

	go func() {
		defer close(out)
		k := len(channels)
		heads := make([]int, k)
		valid := make([]bool, k)

		// Инициализация первых элементов
		for i, ch := range channels {
			if val, ok := <-ch; ok {
				heads[i] = val
				valid[i] = true
			}
		}

		for {
			minVal := math.MaxInt
			minIdx := -1

			// Поиск минимального среди головных элементов
			for i := 0; i < k; i++ {
				if valid[i] && heads[i] < minVal {
					minVal = heads[i]
					minIdx = i
				}
			}

			if minIdx == -1 {
				return // Все каналы полностью вычитаны
			}

			out <- minVal

			// Дочитываем следующий элемент из канала победителя
			if next, ok := <-channels[minIdx]; ok {
				heads[minIdx] = next
			} else {
				valid[minIdx] = false
			}
		}
	}()

	return out
}

func main() {
	c1 := make(chan int, 3)
	c2 := make(chan int, 3)
	c3 := make(chan int, 3)

	c1 <- 1; c1 <- 4; c1 <- 7; close(c1)
	c2 <- 2; c2 <- 5; c2 <- 8; close(c2)
	c3 <- 3; c3 <- 6; c3 <- 9; close(c3)

	merged := KWayMerge(c1, c2, c3)

	fmt.Print("Результат K-Way Merge: ")
	for val := range merged {
		fmt.Printf("%d ", val)
	}
	fmt.Println()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Результат K-Way Merge: 1 2 3 4 5 6 7 8 9
```

## Под капотом

Для большого числа каналов \(K\) линейный поиск заменяют на Min-Heap с асимптотикой \(O(N \log K)\).

## Подводные камни

Каналы обязаны подавать строго отсортированные возрастающие данные.

## На собеседовании

**Вопрос с собеседования:** «Где в СУБД (PostgreSQL, ClickHouse) применяется алгоритм K-Way Merge?»
**Ответ:** В фазе Merge древовидных структур LSM-tree (LevelDB, RocksDB, ClickHouse) и при выполнении внешних сортировок (External Merge Sort), когда объем данных превышает размер ОЗУ.
