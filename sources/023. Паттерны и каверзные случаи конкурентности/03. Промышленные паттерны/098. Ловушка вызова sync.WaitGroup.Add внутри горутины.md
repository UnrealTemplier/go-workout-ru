# Ловушка вызова sync.WaitGroup.Add внутри горутины

## Условие

Напиши программу с **"defer wg.Done" в цикле**: `for i := 0; i < 3; i++ { go func() { defer wg.Done(); ... }() }`. Покажи, что `wg.Add(3)` должен быть **до** цикла, иначе `wg.Wait()` может сработать раньше запуска горутин.

## Теория

Критическое правило `sync.WaitGroup`: вызов `wg.Add(1)` обязан выполняться **строго ДО** создания горутины в родительском потоке. Если `wg.Add()` вызывается внутри тела самой горутины, `wg.Wait()` в `main` может выполниться до того, как горутина успеет вызваться, и программа преждевременно завершится.

## Решение по шагам

1. Продемонстрируем канонический вызов `wg.Add(total)` ДО цикла.
2. Внутри горутин вызовем `defer wg.Done()`.
3. Убедимся в детерминированном ожидании всех задач.
4. Проверим результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

func main() {
	var wg sync.WaitGroup
	const total = 3

	// КАНОНИЧЕСКОЕ ПРАВИЛО: wg.Add вызывается ДО старта горутин!
	wg.Add(total)

	for i := 1; i <= total; i++ {
		go func(id int) {
			defer wg.Done()
			time.Sleep(10 * time.Millisecond)
			fmt.Printf(" [Goroutine #%d] Выполнена\n", id)
		}(i)
	}

	wg.Wait() // Гарантированно дождется всех 3 горутин!
	fmt.Println("[Main] Все горутины успешно завершились.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
#  [Goroutine #1] Выполнена
#  [Goroutine #2] Выполнена
#  [Goroutine #3] Выполнена
# [Main] Все горутины успешно завершились.
```

## Под капотом

`wg.Add(total)` выставляет счетчик до запуска горутин, исключая гонку с `wg.Wait()`.

## Подводные камни

Вызов `wg.Add(1)` внутри `go func()` — одна из самых распространенных ошибок начинающих разработчиков.

## На собеседовании

**Вопрос с собеседования:** «Почему wg.Add(1) нельзя делать первой строкой внутри go func()?»
**Ответ:** Потому что планировщик Go не гарантирует немедленный старт горутины. Главный поток может дойти до `wg.Wait()` раньше, чем запустится хотя бы одна горутина, увидеть счетчик 0 и мгновенно выйти из программы.
