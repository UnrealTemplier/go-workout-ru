# Плавное завершение работы (Graceful Shutdown) микросервиса по сигналам ОС

## Условие

**Плавное завершение работы (Graceful Shutdown)**: Напишите каркас серверного приложения.
* Программа должна запускать фоновый воркер, обрабатывающий задачи в цикле.
* Напишите прослушиватель системных сигналов ОС (например, `SIGINT`, `SIGTERM` через пакет `os/signal`).
* При получении сигнала о закрытии (например, нажатие Ctrl+C в консоли), программа не должна обрываться мгновенно. Она должна остановить прием новых задач, дождаться завершения текущих активных задач, закрыть все каналы и файлы, и только после этого корректно завершить работу процесса.

## Теория

Шаблон продакшн-сервера: фоновый воркер с очередью, перехватчик `os/signal`, завершение текущих задач и безопасное освобождение ресурсов.

## Решение по шагам

1. Создадим очередь задач.
2. Запустим фоновый воркер.
3. Перехватим сигнал остановки через `signal.Notify`.
4. Дождемся завершения активных транзакций через `sync.WaitGroup`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"os"
	"os/signal"
	"sync"
	"syscall"
	"time"
)

func backgroundWorker(ctx context.Context, queue <-chan int, wg *sync.WaitGroup) {
	defer wg.Done()
	fmt.Println("[Worker] Воркер запущен и обрабатывает очередь...")

	for {
		select {
		case <-ctx.Done():
			fmt.Printf("[Worker] Получен сигнал отмены (%v)! Дообрабатываю задачи из очереди...\n", ctx.Err())
			for task := range queue {
				fmt.Printf(" -> [Draining] Завершена задача #%d\n", task)
			}
			fmt.Println("[Worker] Очередь пуста. Чистый выход воркера.")
			return
		case task, ok := <-queue:
			if !ok {
				return
			}
			fmt.Printf(" -> [Processing] Выполнена задача #%d\n", task)
			time.Sleep(10 * time.Millisecond)
		}
	}
}

func main() {
	ctx, cancel := context.WithCancel(context.Background())
	queue := make(chan int, 5)
	var wg sync.WaitGroup

	wg.Add(1)
	go backgroundWorker(ctx, queue, &wg)

	// Наполняем очередь
	queue <- 1
	queue <- 2
	queue <- 3

	// Симуляция получения SIGINT
	sigChan := make(chan os.Signal, 1)
	signal.Notify(sigChan, os.Interrupt, syscall.SIGTERM)

	go func() {
		time.Sleep(15 * time.Millisecond)
		sigChan <- os.Interrupt
	}()

	<-sigChan
	fmt.Println("\n[Main] Сигнал Ctrl+C перехвачен! Запуск Graceful Shutdown...")

	cancel()    // Сигнал воркеру
	close(queue) // Закрываем прием

	wg.Wait()
	fmt.Println("[Main] Сервер штатно остановлен без потери данных.")
}
```
