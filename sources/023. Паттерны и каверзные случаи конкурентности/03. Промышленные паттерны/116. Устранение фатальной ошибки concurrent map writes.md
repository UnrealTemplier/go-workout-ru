# Устранение фатальной ошибки concurrent map writes через SafeMap

## Условие

**[Разделяемая мапа (Concurrent Map Write)]**: Запусти 10 горутин, пишущих в одну `map[int]int`. Поймай фатальную ошибку `concurrent map writes`. Исправь с помощью `sync.Mutex` (создай `SafeMap` структуру).

## Теория

Защита от concurrent map writes: встраивание `sync.RWMutex` в структуру `SafeMap` оборачивает операции чтения и записи в блокировки, обеспечивая потокобезопасность.

## Решение по шагам

1. Создадим структуру `SafeMap[K comparable, V any]` со встроенным `sync.RWMutex`.
2. Реализуем `Set(k, v)` и `Get(k)`.
3. Запустим 50 параллельных писателей и читателей.
4. Проверим с флагом `-race`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

type SafeMap struct {
	mu sync.RWMutex
	m  map[int]int
}

func NewSafeMap() *SafeMap {
	return &SafeMap{m: make(map[int]int)}
}

func (sm *SafeMap) Set(k, v int) {
	sm.mu.Lock()
	defer sm.mu.Unlock()
	sm.m[k] = v
}

func (sm *SafeMap) Get(k int) (int, bool) {
	sm.mu.RLock()
	defer sm.mu.RUnlock()
	val, ok := sm.m[k]
	return val, ok
}

func main() {
	sm := NewSafeMap()
	var wg sync.WaitGroup

	const total = 100
	wg.Add(total)

	for i := 0; i < total; i++ {
		go func(id int) {
			defer wg.Done()
			sm.Set(id, id*10)
			_, _ = sm.Get(id)
		}(i)
	}

	wg.Wait()
	val, _ := sm.Get(5)
	fmt.Printf("[SafeMap] Все 100 конкурентных операций завершены! sm.Get(5) = %d\n", val)
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# [SafeMap] Все 100 конкурентных операций завершены! sm.Get(5) = 50
```

## Под капотом

`sm.mu.Lock()` защищает внутренние бакеты `hmap` от параллельной реаллокации при росте мапы.

## Подводные камни

Прямой доступ к несинхронизированной мапе `m[k] = v` уронит весь процесс.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go не сделали стандартную мапу потокобезопасной по умолчанию?»
**Ответ:** Подавляющее большинство мап в программах используются внутри одной горутины. Встроенная синхронизация замедлила бы все однопоточные операции в 2-3 раза. Разработчикам предоставили возможность добавлять мьютексы только там, где это необходимо.
