# Антипаттерн Context.Value Misuse: разделение метаданных и бизнес-данных

## Условие

Напиши программу с **"context.Value misuse"**: передаёшь большой объект через `ctx.Value`. Покажи, что это антипаттерн (контекст — для **метаданных** запроса, а не для бизнес-данных). Перепиши: передавай данные через каналы/аргументы.

## Теория

Антипаттерн Context Misuse: передача бизнес-структур (User, Cart, Order) через `context.WithValue` разрушает строгую типизацию, снижает производительность (поиск по связному списку за \(O(N)\) с аллокациями `interface{}`) и скрывает сигнатуру функции. Контекст предназначен **исключительно для транзитных метаданных** (TraceID, Auth Token).

## Решение по шагам

1. Покажем правильный подход: бизнес-данные передаются явными аргументами `OrderRequest`.
2. В `context.Context` передается строго `trace_id`.
3. Убедимся в строгой типизации без type assertions.
4. Проверим работу.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
)

type contextKey string

const traceIDKey contextKey = "trace_id"

// Бизнес-данные оформлены явной типизированной структурой
type Order struct {
	ID     int
	Amount float64
	UserID int
}

// ПРАВИЛЬНО: ctx для метаданных, order — явный аргумент бизнес-логики!
func ProcessOrder(ctx context.Context, order Order) error {
	traceID, _ := ctx.Value(traceIDKey).(string)

	fmt.Printf("[TraceID: %s] Обработка заказа #%d на сумму %.2f руб. (User #%d)\n", 
		traceID, order.ID, order.Amount, order.UserID)
	return nil
}

func main() {
	// Контекст содержит только Request Metadata
	ctx := context.WithValue(context.Background(), traceIDKey, "req-uuid-98721")

	// Бизнес-сущность создается явно
	order := Order{ID: 101, Amount: 4990.50, UserID: 42}

	_ = ProcessOrder(ctx, order)
	fmt.Println("[Main] Заказ успешно обработан с соблюдением принципов чистой архитектуры.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [TraceID: req-uuid-98721] Обработка заказа #101 на сумму 4990.50 руб. (User #42)
# [Main] Заказ успешно обработан с соблюдением принципов чистой архитектуры.
```

## Под капотом

Явная передача параметров в функцию позволяет компилятору передавать их в регистрах CPU (ABIInternal) без аллокаций в куче.

## Подводные камни

Попытка положить в context.WithValue мутабельную бизнес-мапу или указатель приведет к неконтролируемым гонкам данных.

## На собеседовании

**Вопрос с собеседования:** «Каковы 3 официальных правила использования context.WithValue в Go?»
**Ответ:** 1) Только для Request-Scoped метаданных (TraceID, UserID из JWT); 2) Ключи должны быть неэкспортируемыми типами (`type ctxKey struct{}`); 3) Данные внутри контекста должны быть иммутабельными (read-only).
