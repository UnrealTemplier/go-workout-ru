# Микросервис-заглушка: HTTP-сервер с задержкой и конкурентные клиенты с таймаутом

## Условие

Микросервис-заглушка: запустите HTTP-сервер с хендлером, который имитирует задержку. Сделайте несколько конкурентных GET-запросов с таймаутом через `http.Client` + `context`, отменяйте долгие запросы.

### Исходная формулировка

Микросервис-заглушка: запустите HTTP-сервер с хендлером, который имитирует задержку. Сделайте несколько конкурентных GET-запросов с таймаутом через `http.Client` + `context`, отменяйте долгие запросы.

## Теория

Тестирование устойчивости сетевого клиента: `http.NewRequestWithContext(ctx, ...)` позволяет клиенту прервать долгий запрос, если сервер превысил установленный дедлайн.

## Решение по шагам

1. Запустим тестовый HTTP-сервер с задержкой 50 мс.
2. Отправим быстрый запрос (таймаут 100 мс) — успех.
3. Отправим медленный запрос (таймаут 20 мс) — отмена по таймауту.
4. Проверим результаты.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"net/http"
	"net/http/httptest"
	"time"
)

func main() {
	// Мок сервера с искусственной задержкой 40 мс
	server := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		time.Sleep(40 * time.Millisecond)
		w.WriteHeader(http.StatusOK)
		_, _ = w.Write([]byte("HTTP 200 SUCCESS"))
	}))
	defer server.Close()

	client := server.Client()

	// 1. Запрос с достаточным таймаутом (80 мс) -> Успех
	ctxOk, cancelOk := context.WithTimeout(context.Background(), 80*time.Millisecond)
	defer cancelOk()

	reqOk, _ := http.NewRequestWithContext(ctxOk, "GET", server.URL, nil)
	respOk, err := client.Do(reqOk)
	if err == nil {
		fmt.Printf("[Запрос 1 (Таймаут 80мс)] Статус: %s\n", respOk.Status)
		respOk.Body.Close()
	}

	// 2. Запрос со слишком коротким таймаутом (15 мс) -> Отмена
	ctxTimeout, cancelTimeout := context.WithTimeout(context.Background(), 15*time.Millisecond)
	defer cancelTimeout()

	reqTimeout, _ := http.NewRequestWithContext(ctxTimeout, "GET", server.URL, nil)
	_, err = client.Do(reqTimeout)
	if err != nil {
		fmt.Printf("[Запрос 2 (Таймаут 15мс)] ПРЕРВАН: %v\n", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Запрос 1 (Таймаут 80мс)] Статус: 200 OK
# [Запрос 2 (Таймаут 15мс)] ПРЕРВАН: Get "http://127.0.0.1:...": context deadline exceeded
```

## Под капотом

`client.Do` разрывает сокет и отменяет системный вызов `read()` при срабатывании контекста.

## Подводные камни

Всегда вызывайте `resp.Body.Close()` при успешном ответе.

## На собеседовании

**Вопрос с собеседования:** «Почему в http.Client нужно настраивать Timeout, а не использовать http.DefaultClient?»
**Ответ:** В `http.DefaultClient` таймаут равен 0 (бесконечность). При зависании удаленного сервера горутины клиента заблокируются навсегда, что приведет к исчерпанию пула потоков и памяти всего сервиса.
