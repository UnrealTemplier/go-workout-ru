# Устранение грязного перемешивания вывода в консоль через sync.Mutex

## Условие

**"Грязный" вывод в консоль**: Запусти 10 горутин, которые пишут длинные строки через `fmt.Print`. Посмотри, как символы перемешиваются. Создай мьютекс специально для логирования (или используй пакет `log`, который под капотом использует мьютексы), чтобы решить эту проблему.

## Теория

Синхронизация потока stdout: стандартные функции `fmt.Print` и `os.Stdout.Write` не атомарны для многосимвольных строк. Параллельный вызов из 10 горутин перемешивает байты на экране. Использование мьютекса или стандартного пакета `log` обеспечивает атомарную построчную запись.

## Решение по шагам

1. Создадим потокобезопасный логер `SafeConsoleLogger` с `sync.Mutex`.
2. Запустим 5 параллельных горутин, выводящих длинные форматированные строки.
3. Убедимся, что строки выводятся чисто без перемешивания символов.
4. Проверим с флагом `-race`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

type SafeLogger struct {
	mu sync.Mutex
}

func (l *SafeLogger) Logf(format string, args ...any) {
	l.mu.Lock()
	defer l.mu.Unlock()
	fmt.Printf(format, args...)
}

func main() {
	logger := &SafeLogger{}
	var wg sync.WaitGroup

	const numWorkers = 5
	wg.Add(numWorkers)

	for i := 1; i <= numWorkers; i++ {
		go func(id int) {
			defer wg.Done()
			// Атомарный вывод без разрыва строк
			logger.Logf("[Worker #%d] ──> Пакет транзакции #%d успешно валидирован и записан в журнал.\n", id, id*100)
		}(i)
	}

	wg.Wait()
	fmt.Println("[Main] Все строки выведены без единого перемешивания символов.")
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# [Worker #1] ──> Пакет транзакции #100 успешно валидирован и записан в журнал.
# [Worker #2] ──> Пакет транзакции #200 успешно валидирован и записан в журнал.
# [Worker #3] ──> Пакет транзакции #300 успешно валидирован и записан в журнал.
# [Worker #4] ──> Пакет транзакции #400 успешно валидирован и записан в журнал.
# [Worker #5] ──> Пакет транзакции #500 успешно валидирован и записан в журнал.

```

## Под капотом

Мьютекс сериализует системные вызовы `write(1, ...)` к файловому дескриптору stdout.

## Подводные камни

В `fmt.Printf` без мьютекса вывод разных горутин перемешивается на уровне символов.

## На собеседовании

**Вопрос с собеседования:** «Является ли стандартный пакет log потокобезопасным в Go?»
**Ответ:** Да, стандартный тип `log.Logger` защищает метод `Output()` внутренним `sync.Mutex`, гарантируя атомарность записи каждой строки лога в `io.Writer`.
