# Мемоизация тяжелых вычислений с дедупликацией (Concurrent Memoize)

## Условие

**Мемоизация с блокировками**: Реализуйте функцию мемоизации для тяжелого вычисления, которая гарантирует, что если две горутины одновременно запросили одно и то же значение, вычисление произойдет только один раз (используйте `sync.Map` или `singleflight.Group` из `golang.org/x/sync`).

## Теория

Паттерн Concurrent Memoizer: кэширует не только готовые результаты, но и незавершенные вычисления (Promises). Если ключ уже рассчитывается другой горутиной, повторные вызовы ждут завершения первого расчета без повторного исполнения.

## Решение по шагам

1. Создадим структуру `Memoizer` с `sync.Mutex` и мапой каналов.
2. Метод `Get(key, computeFn)`.
3. Запустим 4 параллельные горутины по ключу `"fib:40"`.
4. Убедимся, что вычисление выполнилось ровно 1 раз.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"sync/atomic"
	"time"
)

type memoEntry struct {
	res string
	err error
	wg  sync.WaitGroup
}

type Memoizer struct {
	mu    sync.Mutex
	cache map[string]*memoEntry
}

func NewMemoizer() *Memoizer {
	return &Memoizer{cache: make(map[string]*memoEntry)}
}

func (m *Memoizer) Compute(key string, fn func() (string, error)) (string, error) {
	m.mu.Lock()
	entry, exists := m.cache[key]
	if exists {
		m.mu.Unlock()
		entry.wg.Wait() // Ждем завершения расчета первой горутиной
		return entry.res, entry.err
	}

	entry = &memoEntry{}
	entry.wg.Add(1)
	m.cache[key] = entry
	m.mu.Unlock()

	// Первая горутина выполняет реальный расчет
	entry.res, entry.err = fn()
	entry.wg.Done()

	return entry.res, entry.err
}

func main() {
	memo := NewMemoizer()
	var computeCount int32
	var wg sync.WaitGroup

	for i := 1; i <= 4; i++ {
		wg.Add(1)
		go func(callerID int) {
			defer wg.Done()
			val, _ := memo.Compute("crypto_hash", func() (string, error) {
				atomic.AddInt32(&computeCount, 1)
				fmt.Println(" -> [Heavy Compute] Выполняется тяжелый расчет хеша (Ровно 1 раз!)...")
				time.Sleep(20 * time.Millisecond)
				return "0xDEADBEEF9872", nil
			})
			fmt.Printf(" [Caller #%d] Получен хеш: %s\n", callerID, val)
		}(i)
	}

	wg.Wait()
	fmt.Printf("[Main] Итог: 4 вызова получили результат, вычисление запускалось %d раз!\n", computeCount)
}
```

**`Терминал`**


## Под капотом

`entry.wg.Wait()` блокирует повторные горутины до вызова `entry.wg.Done()`.

## Подводные камни

В случае паники внутри `fn()` не забудьте вызвать `entry.wg.Done()` в `defer`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие Memoizer от обычного Cache с мьютексом?»
**Ответ:** Обычный кэш при промахе (Cache Miss) отпустит мьютекс, и 10 параллельных горутин параллельно запустят тяжелый расчет. Мемоизер блокирует повторные расчеты по тому же ключу на уровне Promises/WaitGroups.
