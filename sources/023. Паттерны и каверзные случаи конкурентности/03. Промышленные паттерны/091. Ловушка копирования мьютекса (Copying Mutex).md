# Ловушка копирования мьютекса (Copying Mutex) и проверка через go vet

## Условие

Напиши программу с **"copying mutex"**: передаёшь структуру с `sync.Mutex` по значению в горутину. Покажи, что это **копия** мьютекса, и синхронизация не работает. Исправь: передавай указатель.

## Теория

Копирование структуры, содержащей `sync.Mutex`, создает независимую копию внутреннего состояния блокировки. Каждая горутина блокирует свой собственный локальный мьютекс, что приводит к полной потере взаимного исключения и гонкам данных.

## Решение по шагам

1. Создадим структуру `Counter` с `sync.Mutex`.
2. Продемонстрируем передачу строго по указателю `*Counter`.
3. Запустим 500 параллельных инкрементов.
4. Проверим с `go vet` и `go run -race`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

type Counter struct {
	mu  sync.Mutex
	val int
}

// ПРАВИЛЬНО: метод принимает POINTER RECEIVER (*Counter), исключая копирование мьютекса!
func (c *Counter) Inc() {
	c.mu.Lock()
	defer c.mu.Unlock()
	c.val++
}

func (c *Counter) Value() int {
	c.mu.Lock()
	defer c.mu.Unlock()
	return c.val
}

func main() {
	c := &Counter{}
	var wg sync.WaitGroup

	const total = 500
	wg.Add(total)

	for i := 0; i < total; i++ {
		go func(cnt *Counter) {
			defer wg.Done()
			cnt.Inc() // Передаем указатель cnt!
		}(c)
	}

	wg.Wait()
	fmt.Printf("[Main] Счетчик: %d (Race отсутствует, мьютекс не копировался!)\n", c.Value())
}
```

**`Терминал`**

```bash
go vet main.go && go run -race main.go
# Вывод:
# [Main] Счетчик: 500 (Race отсутствует, мьютекс не копировался!)
```

## Под капотом

Передача указателя `*Counter` гарантирует, что все горутины работают с единым экземпляром мьютекса в памяти.

## Подводные камни

Использование value receiver `func (c Counter) Inc()` немедленно сломает синхронизацию.

## На собеседовании

**Вопрос с собеседования:** «Как линтер go vet находит копирование мьютексов?»
**Ответ:** Через анализатор `copylocks`, который проверяет AST программы на наличие копирования типов, реализующих интерфейс `sync.Locker`.
