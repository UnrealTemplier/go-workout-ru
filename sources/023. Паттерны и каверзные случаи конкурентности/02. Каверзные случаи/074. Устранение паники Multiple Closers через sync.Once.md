# Устранение паники Multiple Closers через sync.Once (Множественные закрыватели)

## Условие

Напиши программу с **"multiple closers"**: две горутины могут закрыть канал. Получи панику. Решение: только **писатель** закрывает канал, или используй `sync.Once`.

## Теория

Проблема Multiple Closers: когда несколько горутин имеют право закрыть канал (например, при наступлении ошибки в любой из них), одновременный вызов `close(ch)` приведет к панике. Паттерн `sync.Once` гарантирует атомарное закрытие строго один раз.

## Решение по шагам

1. Создадим структуру `SafeCloser` с `sync.Once`.
2. Запустим 3 параллельных воркера, вызывающих закрытие.
3. Проверим отсутствие паники `close of closed channel`.
4. Запустим с флагом `-race`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

type MultiCloserChannel struct {
	Ch   chan int
	once sync.Once
}

func (m *MultiCloserChannel) Close() {
	m.once.Do(func() {
		close(m.Ch)
		fmt.Println("[MultiCloser] Канал успешно и безопасно закрыт ровно 1 раз.")
	})
}

func main() {
	mc := &MultiCloserChannel{Ch: make(chan int)}
	var wg sync.WaitGroup

	// 4 параллельных воркера одновременно пытаются закрыть канал
	for i := 1; i <= 4; i++ {
		wg.Add(1)
		go func(id int) {
			defer wg.Done()
			mc.Close()
		}(i)
	}

	wg.Wait()
	fmt.Println("[Main] Все 4 горутины завершились без единой паники.")
}
```

**`Терминал`**

```bash
go run -race main.go
# Вывод:
# [MultiCloser] Канал успешно и безопасно закрыт ровно 1 раз.
# [Main] Все 4 горутины завершились без единой паники.
```

## Под капотом

`sync.Once` атомарно проверяет флаг `done` и выполняет функцию закрытия ровно один раз.

## Подводные камни

Не пытайтесь использовать обычный булев флаг без мьютекса — это приведет к Data Race.

## На собеседовании

**Вопрос с собеседования:** «Как устроен sync.Once под капотом?»
**Ответ:** `sync.Once` состоит из поля `done uint32` и `sync.Mutex`. Сначала выполняется быстрый атомарный `atomic.LoadUint32(&o.done)` (Fast Path). Если 0 — захватывается мьютекс (Slow Path), повторно проверяется `done` (Double-Checked Locking), вызывается функция и выставляется `atomic.StoreUint32(&o.done, 1)`.
