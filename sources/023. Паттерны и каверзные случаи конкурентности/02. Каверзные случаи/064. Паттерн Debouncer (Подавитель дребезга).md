# Паттерн Debouncer (Подавитель дребезга) на таймерах time.Timer

## Условие

**Debouncer (Подавитель дребезга)**: Напиши функцию, которая принимает канал событий (кликов). Она должна передавать событие дальше, только если с момента прошлого события прошло более 500 мс. (Используй `time.Timer`).

## Теория

Паттерн Debounce: откладывает обработку события до момента, когда наступит «период тишины» заданной длительности (\(T=30\) мс). Любое новое входящее событие сбрасывает таймер `timer.Reset(delay)`.

## Решение по шагам

1. Создадим функцию `Debounce(in <-chan string, delay time.Duration) <-chan string`.
2. В цикле считывания при каждом событии сбрасываем `timer.Reset()`.
3. По срабатыванию `<-timer.C` отправляем последнее накопленное значение.
4. Проверим сжатие пачки из 3 кликов в 1 финальное событие.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func Debounce(in <-chan string, delay time.Duration) <-chan string {
	out := make(chan string)

	go func() {
		defer close(out)
		var timer *time.Timer
		var lastMsg string
		var hasValue bool

		for {
			var timerChan <-chan time.Time
			if timer != nil {
				timerChan = timer.C
			}

			select {
			case msg, ok := <-in:
				if !ok {
					if hasValue {
						out <- lastMsg
					}
					return
				}
				lastMsg = msg
				hasValue = true
				if timer != nil {
					timer.Stop()
				}
				timer = time.NewTimer(delay)

			case <-timerChan:
				if hasValue {
					out <- lastMsg
					hasValue = false
					timer = nil
				}
			}
		}
	}()

	return out
}

func main() {
	in := make(chan string, 5)

	// Подавитель дребезга с окном тишины 25 мс
	debounced := Debounce(in, 25*time.Millisecond)

	// Быстрая серия из 3 кликов (интервал 5 мс)
	in <- "Клик 1"
	time.Sleep(5 * time.Millisecond)
	in <- "Клик 2"
	time.Sleep(5 * time.Millisecond)
	in <- "Клик 3 (Финальный)"
	close(in)

	for res := range debounced {
		fmt.Printf("[Debounced Event] Сработало действие: %s\n", res)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Debounced Event] Сработало действие: Клик 3 (Финальный)
```

## Под капотом

Сброс таймера отменяет предыдущие промежуточные события, пропуская только последнее устойчивое значение.

## Подводные камни

Не забывайте вызывать `timer.Stop()` перед созданием нового таймера.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие Debounce от Throttle?»
**Ответ:** Throttle выполняет первое событие немедленно и игнорирует последующие в течение временного окна. Debounce ждет, пока поток событий полностью успокоится на заданное время, и выполняет только самое последнее.
