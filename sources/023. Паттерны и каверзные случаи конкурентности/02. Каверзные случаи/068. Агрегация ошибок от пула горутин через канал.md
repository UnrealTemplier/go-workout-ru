# Агрегация ошибок от пула горутин через канал ошибок

## Условие

Обработка ошибок в горутинах: канал для ошибок, main собирает ошибки от воркеров и агрегирует их.

## Теория

Паттерн Error Channel Aggregation: параллельные горутины отправляют возникшие ошибки в буферизованный канал `errChan chan error`. Главный поток собирает все ошибки и формирует итоговый отчет.

## Решение по шагам

1. Создадим канал `errChan := make(chan error, numWorkers)`.
2. Запустим горутины, часть из которых вернет ошибку.
3. Закроем канал после `wg.Wait()`.
4. Агрегируем ошибки в единый список.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

func asyncTask(id int, errChan chan<- error, wg *sync.WaitGroup) {
	defer wg.Done()
	time.Sleep(5 * time.Millisecond)

	if id == 2 {
		errChan <- fmt.Errorf("воркер #%d: сбой сети", id)
	} else if id == 4 {
		errChan <- fmt.Errorf("воркер #%d: неверный формат данных", id)
	}
}

func main() {
	const total = 5
	errChan := make(chan error, total)
	var wg sync.WaitGroup

	for i := 1; i <= total; i++ {
		wg.Add(1)
		go asyncTask(i, errChan, &wg)
	}

	wg.Wait()
	close(errChan)

	var collectedErrors []error
	for err := range errChan {
		collectedErrors = append(collectedErrors, err)
	}

	fmt.Printf("[Main] Завершено. Обнаружено ошибок: %d/%d\n", len(collectedErrors), total)
	for _, err := range collectedErrors {
		fmt.Printf(" -> Ошибка: %v\n", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Main] Завершено. Обнаружено ошибок: 2/5
#  -> Ошибка: воркер #2: сбой сети
#  -> Ошибка: воркер #4: неверный формат данных
```

## Под капотом

Буфер емкостью `total` исключает блокировку горутин при записи ошибок.

## Подводные камни

В небуферизованном канале без параллельного читателя горутина зависнет на `errChan <- err`.

## На собеседовании

**Вопрос с собеседования:** «Как объединить несколько ошибок в одну в Go 1.20+?»
**Ответ:** С помощью функции `errors.Join(errs...)`, которая склеивает срез ошибок в единый объект `error` с поддержкой методов `errors.Is` и `errors.As`.
