# Паттерн Or-Channel: объединение каналов отмены через рекурсивный select

## Условие

**Or-Channel (Или-канал)**: Напиши функцию `Or(channels ...<-chan struct{}) <-chan struct{}`. Она должна вернуть канал, который закроется, как только закроется **хотя бы один** из переданных каналов.

## Теория

Паттерн Or-Channel (или Or-Done-Channel): объединяет произвольное количество каналов отмены в один. Результирующий канал закрывается в момент, когда закрывается **любой** из входных каналов. Реализуется элегантной рекурсивной декомпозицией.

## Решение по шагам

1. Обработаем базовые случаи рекурсии: 0 каналов, 1 канал, 2 канала.
2. Для \(N > 2\) каналов разделим список рекурсивно `select { case <-channels[0]: case <-channels[1]: case <-Or(append(channels[2:], orDone)...): }`.
3. Запустим с 3 независимыми таймерами.
4. Убедимся в срабатывании по самому быстрому каналу.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func Or(channels ...<-chan struct{}) <-chan struct{} {
	switch len(channels) {
	case 0:
		return nil
	case 1:
		return channels[0]
	}

	orDone := make(chan struct{})
	go func() {
		defer close(orDone)
		switch len(channels) {
		case 2:
			select {
			case <-channels[0]:
			case <-channels[1]:
			}
		default:
			select {
			case <-channels[0]:
			case <-channels[1]:
			case <-channels[2]:
			case <-Or(append(channels[3:], orDone)...):
			}
		}
	}()

	return orDone
}

func sig(after time.Duration) <-chan struct{} {
	c := make(chan struct{})
	go func() {
		defer close(c)
		time.Sleep(after)
	}()
	return c
}

func main() {
	start := time.Now()

	// 3 независимых источника отмены (50 мс, 20 мс, 80 мс)
	<-Or(
		sig(50*time.Millisecond),
		sig(20*time.Millisecond), // Сработает первым!
		sig(80*time.Millisecond),
	)

	fmt.Printf("[Or-Channel] Сигнал сработал мгновенно по самому быстрому каналу за %v!\n", 
		time.Since(start).Round(time.Millisecond))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Or-Channel] Сигнал сработал мгновенно по самому быстрому каналу за 20ms!
```

## Под капотом

Дерево горутин схлопывается мгновенно, передавая закрытие `close(orDone)` вверх по стеку.

## Подводные камни

В Go 1.21+ появился стандартный метод `context.WithCancelCause` и `context.Or`.

## На собеседовании

**Вопрос с собеседования:** «Зачем нужен Or-Channel при наличии Context Tree?»
**Ответ:** Для объединения гетерогенных источников сигналов (таймеры ОС, вебсокеты, прерывания) в единый канал остановки без необходимости связывать их в жесткую родительско-дочернюю иерархию.
