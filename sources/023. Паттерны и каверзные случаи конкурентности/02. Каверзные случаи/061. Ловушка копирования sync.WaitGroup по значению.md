# Ловушка копирования sync.WaitGroup по значению (copylocks)

## Условие

**WGC (WaitGroup Copy)**: Передайте `sync.WaitGroup` в анонимную функцию (горутину) по значению (без взятия адреса). Убедитесь, что `Wait()` в `main` никогда не дождется завершения.

## Теория

Структура `sync.WaitGroup` содержит внутреннее 64-битное атомарное состояние счетчика. Передача `sync.WaitGroup` по значению (by value) создает изолированную копию структуры: горутина вызывает `Done()` на копии, а исходный `wg.Wait()` в `main` зависает в вечном дедлоке. Утилита `go vet` детектирует это как ошибку `copylocks`.

## Решение по шагам

1. Продемонстрируем передачу `*sync.WaitGroup` по указателю как единственно верный способ.
2. Запустим горутину с передачей `&wg`.
3. Убедимся в мгновенном завершении `wg.Wait()`.
4. Проверим с `go vet`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

// ПРАВИЛЬНО: sync.WaitGroup передается СТРОГО ПО УКАЗАТЕЛЮ (*sync.WaitGroup)
func workerSafe(id int, wg *sync.WaitGroup) {
	defer wg.Done()
	time.Sleep(10 * time.Millisecond)
	fmt.Printf("[Worker #%d] Задача завершена\n", id)
}

func main() {
	var wg sync.WaitGroup

	wg.Add(1)
	go workerSafe(1, &wg) // Передаем адрес &wg!

	wg.Wait()
	fmt.Println("[Main] Успешная синхронизация без ошибки copylocks.")
}
```

**`Терминал`**

```bash
go vet main.go && go run main.go
# Вывод:
# [Worker #1] Задача завершена
# [Main] Успешная синхронизация без ошибки copylocks.
```

## Под капотом

`sync.WaitGroup` реализует интерфейс `sync.Locker` с запретом копирования через линтер `copylocks`.

## Подводные камни

Передача `wg sync.WaitGroup` по значению в сигнатуре функции — частая ошибка новичков.

## На собеседовании

**Вопрос с собеседования:** «Почему типы из пакета sync (Mutex, RWMutex, WaitGroup, Cond) категорически нельзя копировать?»
**Ответ:** Потому что они содержат внутренние указатели на списки ожидания семафоров ОС (`uint32` флаги). Копирование структуры разрывает связь с оригинальным примитивом синхронизации и вызывает дедлоки.
