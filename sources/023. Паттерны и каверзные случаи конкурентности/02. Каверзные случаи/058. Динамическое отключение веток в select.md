# Динамическое отключение веток в select через nil-каналы

## Условие

`nil`-канал в `select`: покажите, что `select` игнорирует case с `nil`-каналом, что можно использовать для динамического отключения веток.

## Теория

Чтение или запись в `nil`-канал блокируется навсегда. В конструкции `select` ветка с `nil`-каналом считается вечно неактивной и полностью игнорируется рантаймом. Присваивание `ch = nil` позволяет динамически выключать отработавшие каналы без пересоздания структуры `select`.

## Решение по шагам

1. Создадим два канала `c1` и `c2`.
2. В цикле `select` при закрытии канала выставляем `c1 = nil` или `c2 = nil`.
3. Цикл продолжается, пока оба канала не станут `nil`.
4. Проверим чистое слияние.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func main() {
	c1 := make(chan string, 2)
	c2 := make(chan string, 2)

	c1 <- "А"; c1 <- "Б"; close(c1)
	c2 <- "1"; c2 <- "2"; close(c2)

	fmt.Println("Чтение из двух каналов с динамическим отключением через nil:")

	for c1 != nil || c2 != nil {
		select {
		case msg, ok := <-c1:
			if !ok {
				fmt.Println(" -> [Канал 1 закрыт] Выставляем c1 = nil (ветка отключена)"); c1 = nil
				continue
			}
			fmt.Printf("Из c1: %s\n", msg)

		case msg, ok := <-c2:
			if !ok {
				fmt.Println(" -> [Канал 2 закрыт] Выставляем c2 = nil (ветка отключена)"); c2 = nil
				continue
			}
			fmt.Printf("Из c2: %s\n", msg)
		}
	}

	fmt.Println("[Main] Оба канала закрыты и полностью вычитаны.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Чтение из двух каналов с динамическим отключением через nil:
# Из c1: А
# Из c1: Б
#  -> [Канал 1 закрыт] Выставляем c1 = nil (ветка отключена)
# Из c2: 1
# Из c2: 2
#  -> [Канал 2 закрыт] Выставляем c2 = nil (ветка отключена)
# [Main] Оба канала закрыты и полностью вычитаны.
```

## Под капотом

Рантайм исключает ветку с `nil`-каналом из списка опрашиваемых дескрипторов в функции `runtime.selectgo`.

## Подводные камни

Если забыть выставить `ch = nil`, `select` будет бесконечно крутиться, считывая Zero Value из закрытого канала.

## На собеседовании

**Вопрос с собеседования:** «Что произойдет при вызове select {} на пустом select без веток?»
**Ответ:** Горутина заблокируется навсегда. Если это произошло в `main`, рантайм аварийно завершится с `fatal error: all goroutines are asleep - deadlock!`.
