# Паттерн Future / Promise: асинхронный FetchData с немедленным возвратом канала

## Условие

**Паттерн "Future/Promise"**: Напишите функцию `FetchData() <-chan string`, которая мгновенно возвращает канал (обещание результата), а внутри запускает фоновую горутину для тяжелого вычисления. Когда вычисление завершено, горутина пишет результат в канал и закрывает его. В основной горутине выполните другие полезные действия, а затем заберите результат из канала, когда он понадобится.

## Теория

Асинхронная фабрика Future: функция возвращает `<-chan string` мгновенно, позволяя вызывающему коду продолжить работу параллельно.

## Решение по шагам

1. Создадим `FetchData(serviceName string) <-chan string`.
2. Внутри запустим горутину с `defer close(ch)`.
3. В `main` инициируем запрос и займемся полезной работой.
4. Прочитаем результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func FetchData(source string) <-chan string {
	promise := make(chan string, 1)

	go func() {
		defer close(promise)
		time.Sleep(20 * time.Millisecond) // Имитация тяжелого запроса
		promise <- fmt.Sprintf("Данные от сервиса [%s]: OK", source)
	}()

	return promise
}

func main() {
	start := time.Now()

	// Асинхронный старт запроса
	futureBilling := FetchData("Billing-Gateway")

	fmt.Println("[Main] Рендеринг интерфейса в основном потоке...")
	time.Sleep(10 * time.Millisecond)

	// Получение результата из Future
	result := <-futureBilling
	fmt.Printf("[Main] Получен результат за %v: %s\n", 
		time.Since(start).Round(time.Millisecond), result)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Main] Рендеринг интерфейса в основном потоке...
# [Main] Получен результат за 20ms: Данные от сервиса [Billing-Gateway]: OK
```

## Под капотом

Буфер 1 в `make(chan string, 1)` защищает фоновую горутину от блокировки.

## Подводные камни

Не забывайте `close(promise)`.

## На собеседовании

**Вопрос с собеседования:** «Как во Future добавить поддержку таймаута при чтении?»
**Ответ:** Через `select`: `select { case res := <-future: return res, nil; case <-time.After(timeout): return nil, ErrTimeout }`.
