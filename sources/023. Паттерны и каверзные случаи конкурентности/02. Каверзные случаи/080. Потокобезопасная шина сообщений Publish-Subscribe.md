# Потокобезопасная шина сообщений Publish-Subscribe с мьютексами

## Условие

**Паттерн "Publish-Subscribe" (Pub-Sub)**: Напишите простую шину сообщений на чистом Go. Должна быть структура `PubSub` с методами `Subscribe(topic string) <-chan string` и `Publish(topic string, msg string)`. Обеспечьте потокобезопасность шины (используйте мьютексы).

## Теория

Потокобезопасная шина событий (Event Bus) на чистом Go с поддержкой топиков и неблокирующей рассылки.

## Решение по шагам

1. Создадим структуру `EventBus` с `sync.RWMutex`.
2. Реализуем `Subscribe(topic)`.
3. Реализуем `Publish(topic, msg)`.
4. Проверим работу двух независимых подписчиков.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

type EventBus struct {
	mu     sync.RWMutex
	topics map[string][]chan string
}

func NewEventBus() *EventBus {
	return &EventBus{
		topics: make(map[string][]chan string),
	}
}

func (eb *EventBus) Subscribe(topic string) <-chan string {
	eb.mu.Lock()
	defer eb.mu.Unlock()

	ch := make(chan string, 10)
	eb.topics[topic] = append(eb.topics[topic], ch)
	return ch
}

func (eb *EventBus) Publish(topic, msg string) {
	eb.mu.RLock()
	defer eb.mu.RUnlock()

	for _, ch := range eb.topics[topic] {
		select {
		case ch <- msg:
		default:
			fmt.Println("[EventBus] Предупреждение: буфер подписчика полон, пропуск")
		}
	}
}

func main() {
	bus := NewEventBus()

	userEvents := bus.Subscribe("user.events")
	var wg sync.WaitGroup
	wg.Add(1)

	go func() {
		defer wg.Done()
		fmt.Printf("[Email-Notifier] Получено событие: %s\n", <-userEvents)
		fmt.Printf("[Email-Notifier] Получено событие: %s\n", <-userEvents)
	}()

	time.Sleep(5 * time.Millisecond)

	bus.Publish("user.events", "UserRegistered: ID=42")
	bus.Publish("user.events", "PasswordChanged: ID=42")

	wg.Wait()
	fmt.Println("[Main] Шина сообщений PubSub отработала корректно.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Email-Notifier] Получено событие: UserRegistered: ID=42
# [Email-Notifier] Получено событие: PasswordChanged: ID=42
# [Main] Шина сообщений PubSub отработала корректно.
```

## Под капотом

`select default` защищает шину от блокировки медленными подписчиками.

## Подводные камни

Не забывайте `RWMutex` при итерации по слайсу подписчиков.

## На собеседовании

**Вопрос с собеседования:** «Как реализовать метод Unsubscribe(topic, ch)?»
**Ответ:** Захватить `Lock()`, найти канал в `topics[topic]`, удалить его быстрым сдвигом среза и закрыть канал `close(ch)`.
