# Неблокирующая отправка в канал с default (Non-Blocking Send)

## Условие

Напиши программу с **"select on send without default"**: `select { case ch <- v: }`. Если канал небуферизованный и нет читателя — это **блокировка**. Добавь `default` для non-blocking send.

## Теория

Неблокирующая отправка (Non-Blocking Send): конструкция `select { case ch <- v: return true; default: return false }` мгновенно возвращает `false`, если буфер полон или читатель не готов, предотвращая блокировку горутины.

## Решение по шагам

1. Создадим небуферизованный канал без читателя.
2. Продемонстрируем неблокирующую отправку с `default`.
3. Убедимся, что вызов завершается за микросекунды.
4. Проверим результат.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func trySend(ch chan int, val int) bool {
	select {
	case ch <- val:
		fmt.Printf(" -> Успешно отправлено значение: %d\n", val)
		return true
	default:
		fmt.Printf(" [!] Читатель не готов! Отправка значения %d пропущена без блокировки\n", val)
		return false
	}
}

func main() {
	unbufferedChan := make(chan int) // Небуферизованный канал без читателя

	fmt.Println("Попытка отправки в канал без читателя:")
	res := trySend(unbufferedChan, 999)

	fmt.Printf("[Main] Результат неблокирующей отправки: %v (Блокировка исключена!)\n", res)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Попытка отправки в канал без читателя:
#  [!] Читатель не готов! Отправка значения 999 пропущена без блокировки
# [Main] Результат неблокирующей отправки: false (Блокировка исключена!)
```

## Под капотом

`select default` проверяет готовность очереди `recvq` канала за \(O(1)\) без переключения контекста горутины.

## Подводные камни

В `select { case ch <- v: }` без `default` горутина заблокируется навсегда.

## На собеседовании

**Вопрос с собеседования:** «В каких сценариях применяется Non-Blocking Send?»
**Ответ:** При сборе метрик/логов (если буфер логов переполнен, лучше отбросить метрику, чем затормозить бизнес-логику), в брокерах сообщений и при оповещении фоновых воркеров.
