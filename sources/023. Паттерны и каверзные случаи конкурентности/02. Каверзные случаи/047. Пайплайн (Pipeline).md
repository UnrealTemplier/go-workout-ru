# Пайплайн (Pipeline): чистые функции стадий генерации, возведения и печати

## Условие

**Пайплайн (Pipeline)**: Создай конвейер: Генератор -> Сквер (возводит в квадрат) -> Принтер (выводит). Каждая стадия — это функция, принимающая входной канал и возвращающая выходной.

## Теория

Композиция каналов в конвейер: потоковая обработка данных без промежуточных срезов в ОЗУ.

## Решение по шагам

1. Создадим `genNums(nums ...int) <-chan int`.
2. Создадим `squareNums(in <-chan int) <-chan int`.
3. Создадим `printNums(in <-chan int)`.
4. Соединим вызовы.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
)

func genNums(nums ...int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out)
		for _, n := range nums {
			out <- n
		}
	}()
	return out
}

func squareNums(in <-chan int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out)
		for n := range in {
			out <- n * n
		}
	}()
	return out
}

func printNums(in <-chan int) {
	for val := range in {
		fmt.Printf(" -> Результат конвейера: %d\n", val)
	}
}

func main() {
	printNums(squareNums(genNums(2, 4, 6, 8)))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
#  -> Результат конвейера: 4
#  -> Результат конвейера: 16
#  -> Результат конвейера: 36
#  -> Результат конвейера: 64
```

## Под капотом

Каналы передают данные напрямую между ядрами процессора через кэш L3.

## Подводные камни

Не забывайте `defer close(out)`.

## На собеседовании

**Вопрос с собеседования:** «Каковы ограничения паттерна Pipeline?»
**Ответ:** Накладные расходы на синхронизацию каналов для микровычислений (сложение двух int) могут быть выше, чем простой цикл. Pipeline идеален для I/O, трансформации сетевых пакетов и парсинга.
