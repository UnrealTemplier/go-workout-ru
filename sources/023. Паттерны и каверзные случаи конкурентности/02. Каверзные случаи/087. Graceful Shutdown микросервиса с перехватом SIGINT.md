# Graceful Shutdown микросервиса с перехватом SIGINT через os/signal.Notify

## Условие

**Graceful Shutdown (Мягкое завершение)**: Используй `os/signal.Notify` для перехвата `SIGINT` (Ctrl+C). При получении сигнала инициируй отмену через Context, дождись завершения воркеров через `WaitGroup` и только потом выходи из `main`.

### Исходная формулировка

**Graceful Shutdown (Мягкое завершение)**: Используй `os/signal.Notify` для перехвата `SIGINT` (Ctrl+C). При получении сигнала инициируй отмену через Context, дождись завершения воркеров через `WaitGroup` и только потом выходи из `main`.

---

## Теория

Канонический паттерн Graceful Shutdown: перехват сигналов ОС (`os.Interrupt`, `syscall.SIGTERM`), широковещательная отмена дочерних контекстов и корректное ожидание завершения активных транзакций через `sync.WaitGroup`.

## Решение по шагам

1. Создадим канал сигналов `sigChan := make(chan os.Signal, 1)`.
2. Настроим `signal.Notify(sigChan, os.Interrupt)`.
3. Запустим фоновый воркер с `ctx.Done()`.
4. Сымитируем сигнал остановки и дождемся чистого выхода.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"os"
	"os/signal"
	"sync"
	"time"
)

func serverWorker(ctx context.Context, id int, wg *sync.WaitGroup) {
	defer wg.Done()
	fmt.Printf("[Worker #%d] Серверный обработчик запущен...\n", id)

	for {
		select {
		case <-ctx.Done():
			fmt.Printf(" -> [Worker #%d] Сигнал Shutdown получен! Завершаю транзакцию и выхожу.\n", id)
			time.Sleep(10 * time.Millisecond) // Сброс буферов на диск
			return
		default:
			time.Sleep(5 * time.Millisecond)
		}
	}
}

func main() {
	ctx, cancel := context.WithCancel(context.Background())
	sigChan := make(chan os.Signal, 1)
	signal.Notify(sigChan, os.Interrupt) // Перехват Ctrl+C (SIGINT)

	var wg sync.WaitGroup
	wg.Add(2)
	go serverWorker(ctx, 1, &wg)
	go serverWorker(ctx, 2, &wg)

	// Симуляция отправки сигнала через 25 мс
	go func() {
		time.Sleep(25 * time.Millisecond)
		sigChan <- os.Interrupt
	}()

	sig := <-sigChan
	fmt.Printf("\n[Main] Получен сигнал ОС: %v! Старт Graceful Shutdown...\n", sig)
	cancel() // Отменяем контекст всех воркеров

	wg.Wait()
	fmt.Println("[Main] Все воркеры успешно завершены. Чистый выход процесса (Exit 0).")
}
```

**`Терминал`**

```bash

# [Worker #2] Серверный обработчик запущен...
```

## Под капотом

Канал сигналов создается с буфером 1 (`make(chan os.Signal, 1)`), чтобы рантайм не заблокировался при доставке сигнала из ядра ОС.

## Подводные камни

В Go 1.16+ для упрощения используют функцию `signal.NotifyContext`.

## На собеседовании

**Вопрос с собеседования:** «Почему канал для signal.Notify обязательно должен быть буферизованным?»
**Ответ:** Пакет `os/signal` отправляет сигналы без блокировки. Если канал небуферизован и горутина не стоит на чтении в данный момент, сигнал ОС может быть безвозвратно потерян.
