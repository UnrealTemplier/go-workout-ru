# Паттерн Tee-канал (Тройник): расщепление потока на два исходящих канала

## Условие

**Tee-канал (Тройник)**: Напиши функцию, которая читает из одного канала и дублирует каждое значение в **два** исходящих канала.

## Теория

Паттерн Tee Channel (аналог Unix-утилиты `tee`): принимает входной поток `in` и возвращает пару каналов `(out1, out2)`, куда одновременно и синхронно дублирует каждый элемент.

## Решение по шагам

1. Создадим функцию `Tee(in <-chan int) (<-chan int, <-chan int)`.
2. В цикле считываем `val` из `in`.
3. Записываем `val` в `out1` и `out2` через переменные `nil`-каналов в `select`.
4. Проверим считывание из обоих каналов.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

func Tee(in <-chan int) (<-chan int, <-chan int) {
	out1 := make(chan int)
	out2 := make(chan int)

	go func() {
		defer close(out1)
		defer close(out2)

		for val := range in {
			// Синхронная отправка в оба канала без блокировки одним из них
			var ch1, ch2 chan int = out1, out2
			for i := 0; i < 2; i++ {
				select {
				case ch1 <- val:
					ch1 = nil // Отправлено в первый канал -> отключаем
				case ch2 <- val:
					ch2 = nil // Отправлено во второй канал -> отключаем
				}
			}
		}
	}()

	return out1, out2
}

func main() {
	in := make(chan int, 3)
	in <- 10; in <- 20; in <- 30; close(in)

	t1, t2 := Tee(in)
	var wg sync.WaitGroup

	wg.Add(2)
	go func() {
		defer wg.Done()
		for v := range t1 {
			fmt.Printf(" [Branch 1] %d\n", v)
		}
	}()

	go func() {
		defer wg.Done()
		for v := range t2 {
			fmt.Printf(" [Branch 2] %d\n", v)
		}
	}()

	wg.Wait()
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
#  [Branch 1] 10
#  [Branch 2] 10
#  [Branch 1] 20
#  [Branch 2] 20
#  [Branch 1] 30
#  [Branch 2] 30
```

## Под капотом

Использование локального внутреннего цикла с отключением веток через `ch1 = nil` гарантирует, что медленный читатель не вызовет потерю данных для быстрого читателя.

## Подводные камни

Последовательная запись `out1 <- val; out2 <- val` без `select` заблокирует обе ветки, если первый читатель задержится.

## На собеседовании

**Вопрос с собеседования:** «Где в стандартной библиотеке Go используется паттерн Tee?»
**Ответ:** В функции `io.TeeReader(r Reader, w Writer) Reader`, которая прозрачно дублирует все байты, считываемые из `r`, в поток записи `w`.
