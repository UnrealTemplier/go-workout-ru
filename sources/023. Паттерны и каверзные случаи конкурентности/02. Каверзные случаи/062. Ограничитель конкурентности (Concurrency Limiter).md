# Ограничитель конкурентности (Concurrency Limiter) на 10 соединений

## Условие

**Семафор на каналах (Concurrency Limiter)**: Напишите функцию, которая должна параллельно скачать 100 файлов. Однако жесткий лимит операционной системы разрешает одновременно открывать не более 10 сетевых соединений. Реализуйте этот ограничитель конкурентности, используя буферизованный канал емкостью 10 в качестве семафора (запись в канал перед стартом задачи, чтение из канала при завершении задачи).

## Теория

Concurrency Limiter: буферизованный канал емкостью 10 ограничивает параллелизм ровно 10 одновременными задачами.

## Решение по шагам

1. Создадим семафор `sem := make(chan struct{}, 10)`.
2. Запустим 20 задач.
3. Каждая горутина входит через `sem <- struct{}{}` и выходит через `defer func() { <-sem }()`.
4. Проверим соблюдение лимита.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
	"time"
)

func downloadWorker(id int, sem chan struct{}, wg *sync.WaitGroup) {
	defer wg.Done()

	sem <- struct{}{}        // Захват сетевого слота
	defer func() { <-sem }() // Освобождение слота

	time.Sleep(10 * time.Millisecond) // Имитация скачивания
	if id%5 == 0 {
		fmt.Printf(" -> Скачан файл #%d\n", id)
	}
}

func main() {
	const maxConnections = 10
	const totalFiles = 20

	sem := make(chan struct{}, maxConnections)
	var wg sync.WaitGroup

	for i := 1; i <= totalFiles; i++ {
		wg.Add(1)
		go downloadWorker(i, sem, &wg)
	}

	wg.Wait()
	fmt.Println("[Main] Все 20 файлов успешно скачаны в пределах лимита 10 соединений.")
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
#  -> Скачан файл #5
#  -> Скачан файл #10
#  -> Скачан файл #15
#  -> Скачан файл #20
# [Main] Все 20 файлов успешно скачаны в пределах лимита 10 соединений.
```

## Под капотом

Канал `sem` удерживает до 10 пустых структур `struct{}` в буфере.

## Подводные камни

Освобождение семафора должно быть в `defer`, чтобы паника не заблокировала слот.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между записью в семафор ДО go func() и ВНУТРИ go func()?»
**Ответ:** Запись *до* `go func()` предотвращает создание лишних горутин в памяти. Запись *внутри* `go func()` создает все 100 горутин сразу, но ограничивает их активную фазу вычислений.
