# Потоковая (Streaming) построчная обработка логов через конвейер каналов

## Условие

Реализуй **"streaming"** обработку: читаешь большой файл построчно, отправляешь строки в pipeline (стадия 1), фильтруешь (стадия 2), агрегируешь статистику (стадия 3). Всё — через каналы, без загрузки файла целиком в память.

## Теория

Потоковая обработка больших объемов данных (Streaming BigData): построчное чтение через `bufio.Scanner` и передача строк в конвейер позволяет обрабатывать 100-гигабайтные лог-файлы с потреблением всего 10 МБ оперативной памяти (\(O(1)\) RAM).

## Решение по шагам

1. Стадия 1 `streamReader`: построчно читает текст.
2. Стадия 2 `streamFilter`: фильтрует только строки с `"ERROR"`.
3. Стадия 3 `streamAggregator`: подсчитывает статистику ошибок.
4. Выведем итоговый отчет.

## Код решения

**`main.go`**

```go
package main

import (
	"bufio"
	"fmt"
	"strings"
)

func streamReader(logData string) <-chan string {
	out := make(chan string, 10)
	go func() {
		defer close(out)
		scanner := bufio.NewScanner(strings.NewReader(logData))
		for scanner.Scan() {
			out <- scanner.Text()
		}
	}()
	return out
}

func streamFilter(in <-chan string, keyword string) <-chan string {
	out := make(chan string, 10)
	go func() {
		defer close(out)
		for line := range in {
			if strings.Contains(line, keyword) {
				out <- line
			}
		}
	}()
	return out
}

func streamAggregator(in <-chan string) (int, map[string]int) {
	total := 0
	counts := make(map[string]int)

	for line := range in {
		total++
		if strings.Contains(line, "500") {
			counts["500 Internal Error"]++
		} else if strings.Contains(line, "504") {
			counts["504 Gateway Timeout"]++
		}
	}
	return total, counts
}

func main() {
	sampleLogs := `2026-09-03 12:00:01 INFO [auth] User logged in
2026-09-03 12:00:02 ERROR [billing] 500 DB connection lost
2026-09-03 12:00:03 INFO [orders] Order created
2026-09-03 12:00:04 ERROR [gateway] 504 Gateway Timeout
2026-09-03 12:00:05 ERROR [billing] 500 Deadlock detected`

	lines := streamReader(sampleLogs)
	errors := streamFilter(lines, "ERROR")
	totalErrors, stats := streamAggregator(errors)

	fmt.Printf("Потоковый анализ завершен! Всего ошибок: %d\n", totalErrors)
	for errType, count := range stats {
		fmt.Printf(" -> %s: %d раз\n", errType, count)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Потоковый анализ завершен! Всего ошибок: 3
#  -> 500 Internal Error: 2 раз
#  -> 504 Gateway Timeout: 1 раз
```

## Под капотом

`bufio.Scanner` читает файл блоками по 64 КБ, передавая по одной строке в канал `out` без аллокации всего файла в память.

## Подводные камни

При чтении очень длинных строк (более 64 КБ) необходимо увеличить буфер через `scanner.Buffer()`.

## На собеседовании

**Вопрос с собеседования:** «Почему в продакшене потоковая обработка логов на каналах предпочтительнее ioutil.ReadFile / os.ReadFile?»
**Ответ:** `os.ReadFile` загружает весь файл целиком в кучу (heap), что при обработке файлов размером 5-10 ГБ вызовет мгновенный OOM Killer в контейнере Kubernetes. Потоковый конвейер потребляет фиксированные единицы килобайт.
