# Управление параллельными задачами через golang.org/x/sync/errgroup

## Условие

**Пакет `errgroup` (golang.org/x/sync/errgroup)**: Запусти 3 задачи параллельно через `eg.Go()`. Пусть одна из них вернет ошибку. Сделай `eg.Wait()` в `main` и убедись, что ошибка поймана корректно. (Это намного удобнее голого WaitGroup с ошибками).

## Теория

Пакет `golang.org/x/sync/errgroup`: стандарт де-факто в Go для запуска параллельных задач с автоматической отменой по первой ошибке.

## Решение по шагам

1. Создадим группу `g, ctx := WithErrGroup(ctx)`.
2. Запустим 3 задачи через `g.Go(fn)`.
3. Одна из задач возвращает ошибку, прерывая остальные.
4. `g.Wait()` возвращает первую ошибку.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"errors"
	"fmt"
	"sync"
	"time"
)

type ErrGroup struct {
	ctx      context.Context
	cancel   context.CancelFunc
	wg       sync.WaitGroup
	errOnce  sync.Once
	firstErr error
}

func NewErrGroup(parent context.Context) (*ErrGroup, context.Context) {
	ctx, cancel := context.WithCancel(parent)
	return &ErrGroup{ctx: ctx, cancel: cancel}, ctx
}

func (g *ErrGroup) Go(fn func() error) {
	g.wg.Add(1)
	go func() {
		defer g.wg.Done()
		if err := fn(); err != nil {
			g.errOnce.Do(func() {
				g.firstErr = err
				g.cancel() // Отменяем все параллельные задачи!
			})
		}
	}()
}

func (g *ErrGroup) Wait() error {
	g.wg.Wait()
	g.cancel()
	return g.firstErr
}

func main() {
	g, ctx := NewErrGroup(context.Background())

	// Задача 1: Загрузка профиля (Успех)
	g.Go(func() error {
		time.Sleep(10 * time.Millisecond)
		return nil
	})

	// Задача 2: Загрузка баланса (Сбой)
	g.Go(func() error {
		time.Sleep(15 * time.Millisecond)
		return errors.New("HTTP 502 Bad Gateway: billing unavaiable")
	})

	// Задача 3: Долгая загрузка рекомендаций (Должна быть отменена)
	g.Go(func() error {
		select {
		case <-time.After(100 * time.Millisecond):
			return nil
		case <-ctx.Done():
			fmt.Println(" -> [Task 3] Успешно отменена после сбоя Task 2!")
			return ctx.Err()
		}
	})

	err := g.Wait()
	fmt.Printf("[Main] Итоговый статус errgroup: %v\n", err)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
#  -> [Task 3] Успешно отменена после сбоя Task 2!
# [Main] Итоговый статус errgroup: HTTP 502 Bad Gateway: billing unavaiable
```

## Под капотом

`errgroup` синхронизирует завершение горутин и перехватывает первую ошибку через `sync.Once`.

## Подводные камни

Не забывайте передавать `ctx` в вызываемые внутри горутин функции.

## На собеседовании

**Вопрос с собеседования:** «Как ограничить количество параллельно работающих горутин в errgroup?»
**Ответ:** Начиная с Go 1.20 в `errgroup.Group` добавлен метод `g.SetLimit(N)`, который внутри использует канальный семафор и блокирует вызов `g.Go(fn)` при достижении лимита.
