# Установка TTL на 3 секунды и проверка экспирации с time.Sleep

## Условие

**TTL (Время жизни)**: Сохрани ключ с таймаутом (expiration) в 3 секунды. Прочитай его (убедись, что он есть), сделай `time.Sleep(4 * time.Second)`, попробуй прочитать снова и убедись, что он удален.

## Теория

Таймаут экспирации может быть задан при создании (`SET key val EX 3`) либо назначен существующему ключу командой `EXPIRE key seconds` / `PEXPIRE key milliseconds`.

## Решение по шагам

1. Запишите `"expiring_key"` с TTL 3 секунды.
2. Прочитайте значение немедленно — убедитесь в наличии.
3. Вызовите `time.Sleep(4 * time.Second)`.
4. Повторите чтение и зафиксируйте `redis.Nil`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"errors"
	"fmt"
	"log"
	"time"

	"github.com/redis/go-redis/v9"
)

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	key := "short_lived_token"
	ttl := 3 * time.Second

	// 1. Установка с TTL 3 сек
	err := rdb.Set(ctx, key, "temporary_secret", ttl).Err()
	if err != nil {
		log.Fatalf("Set failed: %v", err)
	}
	fmt.Printf("Ключ '%s' сохранен с TTL %v\n", key, ttl)

	// 2. Чтение сразу
	val, err := rdb.Get(ctx, key).Result()
	if err != nil {
		log.Fatalf("Get failed: %v", err)
	}
	fmt.Printf("Успешно прочитан до истечения: %s\n", val)

	// 3. Пауза 4 секунды
	fmt.Println("Спим 4 секунды...")
	time.Sleep(4 * time.Second)

	// 4. Чтение после истечения
	_, err = rdb.Get(ctx, key).Result()
	if errors.Is(err, redis.Nil) {
		fmt.Println("Ключ гарантированно удален после 4 секунд!")
	} else {
		log.Fatalf("Ошибка: ожидалось удаление ключа, получено err=%v", err)
	}
}
```

ℹ️ Проверка удаления ключа по таймеру

**`Терминал`**

```bash
go run main.go
# Вывод:
# Ключ 'short_lived_token' сохранен с TTL 3s
# Успешно прочитан до истечения: temporary_secret
# Спим 4 секунды...
# Ключ гарантированно удален после 4 секунд!
```

## Под капотом

Когда Go-клиент после паузы отправляет команду `GET short_lived_token`, Redis сначала проверяет словарь `expires`. Обнаружив, что текущее системное время превышает таймстемп экспирации, Redis вызывает функцию `expireIfNeeded()`, которая удаляет объект из памяти и генерирует событие Keyspace Notification `__keyevent@0__:expired` (если включено в конфигурации).

## Подводные камни

Использовать `time.Sleep` в юнит-тестах: тесты становятся медленными и флакующими (flaky). В юнит-тестах используют `miniredis` с методом `s.FastForward(4 * time.Second)` для мгновенного перемещения виртуального времени вперед без реального ожидания.

## На собеседовании

**Вопрос с собеседования:** «Можно ли убрать TTL у ключа, сделав его снова бессрочным?»
**Ответ:** Да, для этого существует команда `PERSIST key`. Она удаляет таймстемп экспирации из словаря `expires`, сохраняя сам ключ и его значение в `dict` неизменными.
