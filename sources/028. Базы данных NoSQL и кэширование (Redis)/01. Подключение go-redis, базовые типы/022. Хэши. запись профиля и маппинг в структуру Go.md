# Хэши: запись профиля и маппинг в структуру Go через Scan

## Условие

**Hashes**: Сохраните профиль пользователя (`HSET user:1 name "John" age 30`). Прочитайте одно поле (`HGET`) и весь объект (`HGETALL` с маппингом в структуру через `ScanAsTuple` или `MapStringString`).

## Теория

Команда `HSET` позволяет атомарно записать несколько полей хэша.
Библиотека `go-redis` обладает мощным механизмом `Scan`: если передать указатель на структуру с тегами `redis:"field_name"`, метод `rdb.HGetAll(ctx, key).Scan(&targetStruct)` автоматически десериализует строковые поля хэша в типизированные поля структуры Go (строки, целые числа, булевы флаги).

## Решение по шагам

1. Опишите структуру `User` с тегами `redis:"name"` и `redis:"age"`.
2. Запишите поля через `rdb.HSet`.
3. Прочитайте одно поле `name` через `rdb.HGet`.
4. Считайте весь хэш и распарсите в структуру через `.Scan(&user)`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/redis/go-redis/v9"
)

type User struct {
	Name   string `redis:"name"`
	Age    int    `redis:"age"`
	Active bool   `redis:"active"`
}

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	key := "user:1"
	_ = rdb.Del(ctx, key).Err()

	// 1. HSET: запись полей
	err := rdb.HSet(ctx, key, "name", "John", "age", 30, "active", true).Err()
	if err != nil {
		log.Fatalf("Ошибка HSet: %v", err)
	}

	// 2. HGET: чтение одного поля
	name, err := rdb.HGet(ctx, key, "name").Result()
	if err != nil {
		log.Fatalf("Ошибка HGet: %v", err)
	}
	fmt.Printf("1. Чтение одного поля HGet 'name': %s\n", name)

	// 3. HGETALL + Scan в структуру
	var u User
	if err := rdb.HGetAll(ctx, key).Scan(&u); err != nil {
		log.Fatalf("Ошибка Scan структуры: %v", err)
	}

	fmt.Printf("2. Полный объект десериализован: Name=%s, Age=%d, Active=%v\n",
		u.Name, u.Age, u.Active)
}
```

ℹ️ Использование Scan для автоматического маппинга хэша в структуру

**`Терминал`**

```bash
go run main.go
# Вывод:
# 1. Чтение одного поля HGet 'name': John
# 2. Полный объект десериализован: Name=John, Age=30, Active=true
```

## Под капотом

Метод `.Scan()` в `go-redis` парсит поля через рефлексию `reflect`, ищет теги `redis:"..."` и преобразует строковые представления в нативные типы Go с помощью функции `strconv.ParseInt`, `strconv.ParseBool` и т.д. Это работает «из коробки» без сторонних библиотек.

## Подводные камни

Забывать указывать теги `redis:"..."`. Если тег не указан, маппер попытается сопоставить точное имя поля структуры Go с учетом регистра (`Name` != `name`).

## На собеседовании

**Вопрос с собеседования:** «Почему Redis Hashes эффективнее хранения множества независимых ключей вида `user:1:name`, `user:1:age`?»
**Ответ:** Каждый отдельный ключ в Redis требует собственной записи `dictEntry` (24 байта) + заголовок `robj` (16 байт) + указатели jemalloc. 10 миллионов мелких ключей потратят гигабайты на оверхед метаданных. Объединение полей в один Hash использует оптимизированный `listpack`, снижая потребление памяти в 5–10 раз.
