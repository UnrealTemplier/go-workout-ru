# Сортированные множества ZSET: лидерборд с очками (ZADD/ZINCRBY/ZREVRANGE)

## Условие

**Sorted Sets (ZSET)**: Реализуйте лидерборд игроков. Используйте `ZADD` с оценкой (score), `ZINCRBY` для изменения счета и `ZREVRANGE` для получения топ-10 игроков.

## Теория

Sorted Set (ZSET) — одна из мощнейших структур данных в Redis. Каждый элемент множества уникален и ассоциирован с числом с плавающей точкой — **score** (очки, рейтинг, таймстемп).
Элементы автоматически поддерживаются в отсортированном порядке по возрастанию score.

Основные команды:
- `ZADD key score member` — вставка за \(O(\log N)\).
- `ZINCRBY key increment member` — изменение счета за \(O(\log N)\).
- `ZREVRANGE key start stop [WITHSCORES]` — выборка топа от большего к меньшему за \(O(\log N + M)\).

## Решение по шагам

1. Добавьте трех игроков с очками через `rdb.ZAdd`.
2. Увеличьте счет игрока через `rdb.ZIncrBy`.
3. Получите топ игроков через `rdb.ZRevRangeWithScores`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/redis/go-redis/v9"
)

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	leaderboardKey := "game:leaderboard:weekly"
	_ = rdb.Del(ctx, leaderboardKey).Err()

	// 1. ZADD: начальные очки
	err := rdb.ZAdd(ctx, leaderboardKey,
		redis.Z{Score: 1500, Member: "player_alice"},
		redis.Z{Score: 2100, Member: "player_bob"},
		redis.Z{Score: 1800, Member: "player_charlie"},
	).Err()
	if err != nil {
		log.Fatalf("ZAdd error: %v", err)
	}

	// 2. ZINCRBY: игрок Alice побеждает в матче и получает +800 очков
	newScore, err := rdb.ZIncrBy(ctx, leaderboardKey, 800, "player_alice").Result()
	if err != nil {
		log.Fatalf("ZIncrBy error: %v", err)
	}
	fmt.Printf("Alice набрала очки! Новый счет: %.0f\n", newScore)

	// 3. ZREVRANGE: Получаем топ-3 лидеров с очками
	topPlayers, err := rdb.ZRevRangeWithScores(ctx, leaderboardKey, 0, 2).Result()
	if err != nil {
		log.Fatalf("ZRevRange error: %v", err)
	}

	fmt.Println("\n🏆 ТАБЛИЦА ЛИДЕРОВ (ТОП-3):")
	for rank, p := range topPlayers {
		fmt.Printf("  Место #%d: %s (очков: %.0f)\n", rank+1, p.Member, p.Score)
	}
}
```

## Под капотом

Внутри Redis структура ZSET реализована с помощью комбинации **Skip List** (список с пропусками) и хэш-таблицы `dict`. Хэш-таблица обеспечивает мгновенный доступ к score любого игрока за \(O(1)\), а Skip List позволяет поддерживать упорядоченность элементов и выполнять диапазонные выборки и поиск ранга за \(O(\log N)\) без дорогой пересортировки.

## Подводные камни

Команда `ZREVRANGE` с Redis 6.2 считается устаревшей в пользу обобщенной `ZRANGE ... REV WITHSCORES`. В `go-redis` метод `ZRevRangeWithScores` поддерживается для обратной совместимости, но современный код может использовать `ZRangeArgs`.

## На собеседовании

**Вопрос с собеседования:** «Как в ZSET узнать точное место игрока в таблице среди 10 миллионов участников?»
**Ответ:** Командой `ZREVRANK key member`. Она возвращает индекс игрока (начиная с 0 для топ-1) за время \(O(\log N)\) благодаря Skip List с поддержкой счетчиков длины переходов (`span`).
