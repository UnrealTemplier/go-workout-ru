# Таблица лидеров на Sorted Set: ZAdd и извлечение топ-3 игроков

## Условие

**Sorted Set**: Используй `client.ZAdd` для создания таблицы лидеров (игроки и их очки). Выведи топ-3 игрока с наибольшим количеством очков (`client.ZRevRangeWithScores`).

## Теория

Сортированные множества позволяют моментально получать лидерборды любого масштаба. Сложность вызова `ZRevRangeWithScores(ctx, key, 0, 2)` составляет всего \(O(\log N + 3)\), что позволяет обновлять и отдавать рейтинги миллионам пользователей в реальном времени.

## Решение по шагам

1. Запишите в ZSET 5 участников с баллами.
2. Извлеките топ-3 лидеров.
3. Распечатайте турнирную таблицу.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/redis/go-redis/v9"
)

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	key := "tournament:top_gamers"
	_ = rdb.Del(ctx, key).Err()

	// Заполняем таблицу очками игроков
	err := rdb.ZAdd(ctx, key,
		redis.Z{Score: 1250, Member: "Player_Neo"},
		redis.Z{Score: 3400, Member: "Player_Trinity"},
		redis.Z{Score: 2890, Member: "Player_Morpheus"},
		redis.Z{Score: 4100, Member: "Player_AgentSmith"},
		redis.Z{Score: 1980, Member: "Player_Cypher"},
	).Err()
	if err != nil {
		log.Fatalf("ZAdd error: %v", err)
	}

	// Топ-3 игрока с наивысшими очками
	top3, err := rdb.ZRevRangeWithScores(ctx, key, 0, 2).Result()
	if err != nil {
		log.Fatalf("ZRevRange error: %v", err)
	}

	fmt.Println("🏆 Топ-3 игрока турнира:")
	for place, z := range top3 {
		fmt.Printf("  %d место: %-18s (очки: %.0f)\n", place+1, z.Member, z.Score)
	}
}
```

ℹ️ Топ-3 игрока турнира через ZRevRangeWithScores

**`Терминал`**

```bash
go run main.go
# Вывод:
# 🏆 Топ-3 игрока турнира:
#   1 место: Player_AgentSmith  (очки: 4100)
#   2 место: Player_Trinity     (очки: 3400)
#   3 место: Player_Morpheus    (очки: 2890)
```

## Под капотом

Sorted Set внутри хранит хэш-таблицу для проверки наличия элемента за \(O(1)\) и Skip List для диапазонной выборки. При вставке `ZAdd` элемент одновременно регистрируется в обоих компонентах структуры.

## Подводные камни

Передавать в `Score` нечисловые значения: Redis ZSET поддерживает только 64-битные числа с плавающей точкой IEEE 754 float64.

## На собеседовании

**Вопрос с собеседования:** «Как с помощью ZSET удалить игроков с нулевым или отрицательным рейтингом?»
**Ответ:** Командой `ZREMRANGEBYSCORE key "-inf" 0`. Она удаляет все элементы со счетом от минус бесконечности до нуля за время \(O(\log N + M)\).
