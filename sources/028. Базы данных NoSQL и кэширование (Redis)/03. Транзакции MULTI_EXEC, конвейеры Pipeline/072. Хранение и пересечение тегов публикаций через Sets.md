# Хранение и пересечение тегов публикаций через Sets и SInter

## Условие

**Set**: Используй `client.SAdd` для хранения тегов. Добавь теги к двум разным постам. Используй `client.SInter` для нахождения общих тегов у этих постов (пересечение множеств).

## Теория

Операция пересечения `SINTER` вычисляет элементы, общие для всех переданных множеств. Сложность операции составляет \(O(N \times M)\), где \(N\) — мощность наименьшего множества.

## Решение по шагам

1. Добавьте теги поста 1 (`post:10:tags`).
2. Добавьте теги поста 2 (`post:20:tags`).
3. Найдите пересечение через `rdb.SInter`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/redis/go-redis/v9"
)

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	p1 := "post:10:tags"
	p2 := "post:20:tags"

	_ = rdb.Del(ctx, p1, p2).Err()

	// SAdd
	_ = rdb.SAdd(ctx, p1, "database", "redis", "nosql", "caching").Err()
	_ = rdb.SAdd(ctx, p2, "database", "postgres", "sql", "caching").Err()

	// SInter
	common, err := rdb.SInter(ctx, p1, p2).Result()
	if err != nil {
		log.Fatalf("SInter failed: %v", err)
	}

	fmt.Println("Общие теги между постом 10 и постом 20:")
	for _, t := range common {
		fmt.Printf("  • %s\n", t)
	}
}
```

ℹ️ Поиск общих тегов через SInter

**`Терминал`**

```bash
go run main.go
# Вывод:
# Общие теги между постом 10 и постом 20:
#   • database
#   • caching
```

## Под капотом

Алгоритм `SINTER` в Redis сначала сортирует множества по размеру (кардинальности). Затем он берет элементы самого маленького множества и проверяет их наличие в остальных множествах через хэш-таблицу \(O(1)\). Это минимизирует количество проверок.

## Подводные камни

Вызов `SInter` над множествами на разных узлах в Redis Cluster без Hash Tags.

## На собеседовании

**Вопрос с собеседования:** «Как сохранить результат пересечения тегов в новый ключ без передачи на бэкенд?»
**Ответ:** Командой `SINTERSTORE destination_key key1 key2`. Redis сохранит результат прямо на сервере за \(O(N \times M)\).
