# Мокание Redis в юнит-тестах с помощью библиотеки miniredis

## Условие

**Мокание (miniredis)**: Используйте `github.com/alicebob/miniredis` для in-memory эмуляции Redis в unit-тестах.

## Теория

Библиотека `miniredis` — чистая реализация сервера Redis на языке Go:
- Не требует установки Redis и запуска Docker.
- Стартует в памяти процесса за доли миллисекунды.
- Поддерживает метод `s.FastForward(duration)` для мгновенного перемещения времени вперед и тестирования экспирации TTL без реального `time.Sleep()`!

## Решение по шагам

1. Создайте `mr, err := miniredis.Run()`.
2. Подключите клиент `redis.NewClient` к `mr.Addr()`.
3. Протестируйте запись, чтение и `FastForward`.

## Код решения

**`cache_test.go`**

```go
package main

import (
	"context"
	"errors"
	"fmt"
	"testing"
	"time"

	"github.com/alicebob/miniredis/v2"
	"github.com/redis/go-redis/v9"
)

func TestCacheExpirationWithMiniredis(t *testing.T) {
	ctx := context.Background()

	// 1. Запуск in-memory сервера Redis
	mr, err := miniredis.Run()
	if err != nil {
		t.Fatalf("Failed to start miniredis: %v", err)
	}
	defer mr.Close()

	// 2. Создаем клиент, смотрящий на in-memory адрес
	rdb := redis.NewClient(&redis.Options{Addr: mr.Addr()})
	defer rdb.Close()

	key := "token:test"
	ttl := 10 * time.Minute

	// Сохраняем с TTL 10 минут
	if err := rdb.Set(ctx, key, "secret_data", ttl).Err(); err != nil {
		t.Fatalf("Set failed: %v", err)
	}

	// 3. Мгновенно перематываем виртуальное время на 11 минут вперед!
	mr.FastForward(11 * time.Minute)

	// 4. Проверяем, что ключ протух без реального ожидания 11 минут
	_, err = rdb.Get(ctx, key).Result()
	if !errors.Is(err, redis.Nil) {
		t.Fatalf("Expected redis.Nil after expiration, got %v", err)
	}

	fmt.Println("✅ Тест успешно прошел за 2 миллисекунды благодаря mr.FastForward()!")
}
```

ℹ️ Мгновенное тестирование TTL с miniredis

**`Терминал`**

```bash
go test -v cache_test.go
# Вывод:
# === RUN   TestCacheExpirationWithMiniredis
# ✅ Тест успешно прошел за 2 миллисекунды благодаря mr.FastForward()!
# --- PASS: TestCacheExpirationWithMiniredis (0.00s)
# PASS
```

## Под капотом

`miniredis` парсит протокол RESP и хранит ключи в обычных мапах Go. Метод `FastForward` сдвигает внутренние часы `mockTime` и принудительно вызывает проверку протухания, позволяя тестам с таймаутами в дни или недели выполняться за микросекунды.

## Подводные камни

Полагаться на `miniredis` для проверки сложных Lua-скриптов или специфичных команд Redis 7+. Некоторые редкие фичи или баги ядра Redis в `miniredis` не воспроизводятся.

## На собеседовании

**Вопрос с собеседования:** «Почему в CI/CD юнит-тесты с `miniredis` лучше прямого подключения к dev-базе?»
**Ответ:** 1. Изоляция (каждый тест стартует со своим чистым инстансом, нет взаимного влияния). 2. Скорость (нет сетевых задержек, сотни тестов проходят за 1 секунду). 3. Отсутствие внешних зависимостей (тесты собираются и проходят даже без сетевого доступа в контейнере сборщика).
