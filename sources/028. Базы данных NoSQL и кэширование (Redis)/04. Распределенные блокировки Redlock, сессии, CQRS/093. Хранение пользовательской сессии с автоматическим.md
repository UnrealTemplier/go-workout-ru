# Хранение пользовательской сессии с автоматическим продлением TTL (Touch)

## Условие

Реализуйте сохранение сессии пользователя в Redis с TTL, обновляемым при каждом запросе.

## Теория

Метод `rdb.Expire(ctx, key, ttl)` сбрасывает обратный отсчет таймера экспирации. В протоколе Redis это эквивалентно обновлению поля `expires` в словаре ключей. Это позволяет поддерживать сессию активной до тех пор, пока пользователь взаимодействует с сервисом.

## Решение по шагам

1. Сохраните сессию с TTL 15 минут.
2. Проверьте оставшийся TTL.
3. Вызовите функцию обновления активности `TouchSession`.
4. Убедитесь, что TTL восстановился до полных 15 минут.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"
	"time"

	"github.com/redis/go-redis/v9"
)

type SessionService struct {
	rdb *redis.Client
	ttl time.Duration
}

func (s *SessionService) Touch(ctx context.Context, sessionID string) error {
	key := fmt.Sprintf("session:%s", sessionID)
	refreshed, err := s.rdb.Expire(ctx, key, s.ttl).Result()
	if err != nil {
		return err
	}
	if !refreshed {
		return fmt.Errorf("сессия не существует")
	}
	return nil
}

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	svc := &SessionService{rdb: rdb, ttl: 15 * time.Minute}
	sessKey := "session:token_9012"

	// Создаем сессию
	_ = rdb.Set(ctx, sessKey, "user_id_44", 15*time.Minute).Err()

	// Имитируем запрос через 2 секунды
	time.Sleep(100 * time.Millisecond)

	// Продлеваем сессию
	if err := svc.Touch(ctx, "token_9012"); err != nil {
		log.Fatalf("Touch error: %v", err)
	}

	remaining, _ := rdb.TTL(ctx, sessKey).Result()
	fmt.Printf("Сессия успешно продлена! Новый TTL: %v\n", remaining)
}
```

ℹ️ Автоматическое продление срока жизни сессии

**`Терминал`**

```bash
go run main.go
# Вывод: Сессия успешно продлена! Новый TTL: 15m0s
```

## Под капотом

Сложность команды `EXPIRE` составляет строго \(O(1)\). Redis просто перезаписывает 64-битное целое число в хэш-таблице `db.expires` без изменения самого значения ключа.

## Подводные камни

Вызывать `Touch` при каждом статическом запросе (загрузка css, js, картинок). Обновляйте сессию только при реальных API-запросах.

## На собеседовании

**Вопрос с собеседования:** «Что возвращает команда `EXPIRE key seconds`?»
**Ответ:** Целое число `1`, если таймаут был успешно установлен/обновлен, и `0`, если указанный ключ не существует.
