# Полноценный Session Store: HSet, HGetAll, Expire и HDel при Logout

## Условие

Реализуй **Session Store** в Redis: `HSET session:abc123 user_id 123 expires 1234567890`. При каждом запросе — `HGETALL` + проверка TTL. `HDEL` при logout. Используй `EXPIRE` на весь ключ.

## Теория

Промышленный интерфейс Session Store объединяет:
- `SaveSession(sessionID, data, ttl)`
- `GetSession(sessionID)`
- `DestroySession(sessionID)` — удаление при логауте.

## Решение по шагам

1. Создайте структуру `RedisSessionStore`.
2. Реализуйте полный жизненный цикл: логин, проверка, логаут.
3. Продемонстрируйте завершение сессии.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"
	"time"

	"github.com/redis/go-redis/v9"
)

type SessionStore struct {
	rdb *redis.Client
}

func (s *SessionStore) Login(ctx context.Context, token string, userID int64, ttl time.Duration) error {
	key := "session:" + token
	pipe := s.rdb.TxPipeline()
	pipe.HSet(ctx, key, "user_id", userID, "logged_at", time.Now().Unix())
	pipe.Expire(ctx, key, ttl)
	_, err := pipe.Exec(ctx)
	return err
}

func (s *SessionStore) Check(ctx context.Context, token string) (map[string]string, error) {
	key := "session:" + token
	data, err := s.rdb.HGetAll(ctx, key).Result()
	if err != nil {
		return nil, err
	}
	if len(data) == 0 {
		return nil, fmt.Errorf("сессия недействительна")
	}
	return data, nil
}

func (s *SessionStore) Logout(ctx context.Context, token string) error {
	key := "session:" + token
	return s.rdb.Del(ctx, key).Err()
}

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	store := &SessionStore{rdb: rdb}
	token := "abc123_session_cookie"

	// 1. Вход в систему
	_ = store.Login(ctx, token, 8841, 1*time.Hour)
	fmt.Println("1. Пользователь 8841 успешно авторизован")

	// 2. Проверка сессии
	sess, err := store.Check(ctx, token)
	if err != nil {
		log.Fatalf("Check error: %v", err)
	}
	fmt.Printf("2. Данные сессии: UserID=%s\n", sess["user_id"])

	// 3. Выход из системы (Logout)
	_ = store.Logout(ctx, token)
	fmt.Println("3. Выполнен Logout")

	// 4. Повторная проверка
	_, err = store.Check(ctx, token)
	fmt.Printf("4. Проверка после Logout: %v (доступ закрыт)\n", err)
}
```

ℹ️ Реализация хранилища сессий с логаутом

# 2. Данные сессии: UserID=8841

# 4. Проверка после Logout: сессия недействительна (доступ закрыт)

## Под капотом

Для моментального логаута вызов `DEL` освобождает ключ за микросекунды, гарантируя мгновенный отзыв доступа на всех серверах кластера.

## Подводные камни

Хранить сессии только в оперативной памяти инстанса Go: при перезапуске пода (Rolling Update в K8s) все пользователи разлогинятся. Redis обеспечивает централизованное состояние.

## На собеседовании

**Вопрос с собеседования:** «Почему сессии в Redis предпочтительнее JWT без состояния (Stateless JWT)?»
**Ответ:** Stateless JWT невозможно мгновенно отозвать при компрометации (утечке токена) или блокировке пользователя администратором до истечения его `exp`. Хранение сессий в Redis дает мгновенный отзыв доступа (Revocation) в реальном времени.
