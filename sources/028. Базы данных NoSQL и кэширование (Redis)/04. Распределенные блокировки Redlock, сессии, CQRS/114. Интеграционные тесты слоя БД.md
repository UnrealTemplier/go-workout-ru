## Теория

Интеграционное тестирование связки PostgreSQL + Redis в `testcontainers-go` гарантирует проверку полной цепочки работы Cache-Aside и транзакций в условиях, идентичных продакшену.

## Решение по шагам

1. Опишите запуск PostgreSQL и Redis через Testcontainers.
2. Проверьте запись в БД и инвалидацию в Redis.
3. Проверьте чистоту состояния.

## Код решения

**`integration_test.go`**

```go
package main

import (
	"context"
	"fmt"
	"testing"
	"time"

	"github.com/redis/go-redis/v9"
	"github.com/testcontainers/testcontainers-go"
	"github.com/testcontainers/testcontainers-go/wait"
)

func TestFullIntegrationSuite(t *testing.T) {
	ctx := context.Background()

	// Поднимаем изолированный Redis
	req := testcontainers.ContainerRequest{
		Image:        "redis:7-alpine",
		ExposedPorts: []string{"6379/tcp"},
		WaitingFor:   wait.ForLog("Ready to accept connections").WithStartupTimeout(20 * time.Second),
	}

	container, err := testcontainers.GenericContainer(ctx, testcontainers.GenericContainerRequest{
		ContainerRequest: req,
		Started:          true,
	})
	if err != nil {
		t.Skipf("Docker недоступен в текущей среде: %v", err)
		return
	}
	defer func() { _ = container.Terminate(ctx) }()

	endpoint, _ := container.Endpoint(ctx, "")
	rdb := redis.NewClient(&redis.Options{Addr: endpoint})
	defer rdb.Close()

	// Проверяем запись и чтение
	err = rdb.Set(ctx, "integration:key", "value_ok", 0).Err()
	if err != nil {
		t.Fatalf("Set failed: %v", err)
	}

	val, err := rdb.Get(ctx, "integration:key").Result()
	if err != nil || val != "value_ok" {
		t.Fatalf("Get mismatch: %v", err)
	}

	fmt.Printf("✅ Интеграционный тест успешно выполнен в контейнере %s!\n", endpoint)
}
```

## Под капотом

Тесты с Testcontainers воспроизводимы на любой машине разработчика и в пайплайнах GitLab CI / GitHub Actions без необходимости предварительной настройки локальных сервисов.

## Подводные камни

Забывать вызывать `container.Terminate()` в `defer`. Без этого остановленные контейнеры могут засорять диск хоста.

## На собеседовании

**Вопрос с собеседования:** «Как ускорить интеграционные тесты с Testcontainers в CI/CD?»
**Ответ:** 1. Использовать `reuse` контейнеров (`testcontainers.WithReuse()`). 2. Предварительно кэшировать образы Docker на CI-раннерах (`docker pull` на этапе warmup). 3. Использовать tmpfs для директории данных PostgreSQL/Redis.
