# Очередь задач на списках: Producer LPush и Consumer RPop

## Условие

**List**: Используй `client.LPush` и `client.RPop`. Реализуй простую очередь задач (клади строки в список слева, забирай справа).

## Теория

Связка `LPUSH` и `RPOP` формирует классическую структуру данных FIFO (первым пришел — первым обслужен). Запись слева добавляет в начало списка, а чтение справа забирает самые старые элементы.

## Решение по шагам

1. Запишите в список задачи A, B, C через `LPush`.
2. Считайте задачи через `RPop`.
3. Убедитесь, что порядок извлечения строго соответствует A, B, C.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/redis/go-redis/v9"
)

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	key := "queue:simple_fifo"
	_ = rdb.Del(ctx, key).Err()

	// Producer отправляет задачи A, затем B, затем C
	_ = rdb.LPush(ctx, key, "Task_A").Err()
	_ = rdb.LPush(ctx, key, "Task_B").Err()
	_ = rdb.LPush(ctx, key, "Task_C").Err()

	fmt.Println("Задачи отправлены: Task_A, Task_B, Task_C")

	// Consumer извлекает через RPop
	fmt.Println("Порядок извлечения:")
	for i := 1; i <= 3; i++ {
		task, err := rdb.RPop(ctx, key).Result()
		if err != nil {
			log.Fatalf("RPop failed: %v", err)
		}
		fmt.Printf("  Шаг %d: извлечена %s\n", i, task)
	}
}
```

ℹ️ Классический FIFO порядок через LPush и RPop

**`Терминал`**

```bash
go run main.go
# Вывод:
# Задачи отправлены: Task_A, Task_B, Task_C
# Порядок извлечения:
#   Шаг 1: извлечена Task_A
#   Шаг 2: извлечена Task_B
#   Шаг 3: извлечена Task_C
```

## Под капотом

Обе операции `LPUSH` и `RPOP` выполняются за \(O(1)\) благодаря двусвязному списку `quicklist` с указателями на начало (`head`) и конец (`tail`).

## Подводные камни

Использовать `LPOP` вместо `RPOP` при вставке через `LPUSH`. Это превратит очередь FIFO в стек LIFO (Last In, First Out).

## На собеседовании

**Вопрос с собеседования:** «Как реализовать LIFO стек в Redis?»
**Ответ:** Либо `LPUSH` + `LPOP`, либо `RPUSH` + `RPOP`.
