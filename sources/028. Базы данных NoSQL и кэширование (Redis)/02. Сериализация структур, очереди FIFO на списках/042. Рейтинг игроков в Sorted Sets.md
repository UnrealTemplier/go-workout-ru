# Рейтинг игроков в Sorted Sets: сохранение и извлечение топа

## Условие

Сортированные множества: сохраните рейтинг игроков (`ZADD`), получите топ-10 (`ZREVRANGE WITHSCORES`).

## Теория

Структура ZSET хранит пары (score, member). Метод `ZRevRangeWithScores(ctx, key, start, stop)` позволяет получать диапазон элементов в порядке убывания очков (от лидера к отстающим) вместе с их баллами.

## Решение по шагам

1. Запишите в ZSET рейтинги игроков.
2. Запросите топ игроков через `rdb.ZRevRangeWithScores`.
3. Распечатайте результаты с указанием занятого места.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/redis/go-redis/v9"
)

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	key := "game:leaderboard:season2"
	_ = rdb.Del(ctx, key).Err()

	// ZADD
	_ = rdb.ZAdd(ctx, key,
		redis.Z{Score: 9500, Member: "ProGamer_X"},
		redis.Z{Score: 8200, Member: "CyberNinja"},
		redis.Z{Score: 11000, Member: "ShadowMaster"},
	).Err()

	// ZREVRANGE WITHSCORES (топ-3)
	top, err := rdb.ZRevRangeWithScores(ctx, key, 0, 2).Result()
	if err != nil {
		log.Fatalf("ZRevRange failed: %v", err)
	}

	fmt.Println("🏆 Топ игроков:")
	for idx, player := range top {
		fmt.Printf("  #%d. %s — %.0f очков\n", idx+1, player.Member, player.Score)
	}
}
```

ℹ️ Выборка рейтинга с очками

**`Терминал`**

```bash
go run main.go
# Вывод:
# 🏆 Топ игроков:
#   #1. ShadowMaster — 11000 очков
#   #2. ProGamer_X — 9500 очков
#   #3. CyberNinja — 8200 очков
```

## Под капотом

Элементы в Skip List упорядочены по score. Поиск начала диапазона происходит за \(O(\log N)\), дальнейший проход \(M\) элементов — за \(O(M)\). Если ZSET содержит мало элементов, Redis использует компактный `listpack`, переходя на `skiplist` при превышении лимитов `zset-max-listpack-entries`.

## Подводные камни

Использовать отрицательные индексы без понимания логики: индекс `0` — это первое место, `-1` — последнее место.

## На собеседовании

**Вопрос с собеседования:** «Какова сложность удаления игрока из лидерборда `ZREM key member`?»
**Ответ:** Сложность \(O(\log N)\). Redis находит узел в хэш-таблице `dict` за \(O(1)\), а затем за \(O(\log N)\) перестраивает указатели в Skip List.
