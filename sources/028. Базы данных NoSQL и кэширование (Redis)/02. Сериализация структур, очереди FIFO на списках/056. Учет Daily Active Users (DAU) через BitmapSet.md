# Учет Daily Active Users (DAU) через BitmapSet и BitCount

## Условие

Напиши функцию `BitmapSet(key string, offset int64, value int) error` через `rdb.SetBit(ctx, key, offset, value)`. Используй для **daily active users**: каждый пользователь = бит по своему ID. Посчитай `BitCount` для анализа.

## Теория

Битовые карты идеально подходят для расчета аудиторных метрик. Каждый бит — это бинарный индикатор действия пользователя.

## Решение по шагам

1. Напишите метод `BitmapSet(ctx, key, offset, val)`.
2. Зафиксируйте визиты пользователей.
3. Рассчитайте DAU через `rdb.BitCount`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/redis/go-redis/v9"
)

type AnalyticsTracker struct {
	rdb *redis.Client
}

func (t *AnalyticsTracker) BitmapSet(ctx context.Context, key string, offset int64, value int) error {
	return t.rdb.SetBit(ctx, key, offset, value).Err()
}

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	tracker := &AnalyticsTracker{rdb: rdb}
	key := "dau:2026-09-03"
	_ = rdb.Del(ctx, key).Err()

	// Фиксируем пользователей с UserID: 10, 25, 10, 99
	users := []int64{10, 25, 10, 99}
	for _, u := range users {
		_ = tracker.BitmapSet(ctx, key, u, 1)
	}

	count, err := rdb.BitCount(ctx, key, nil).Result()
	if err != nil {
		log.Fatalf("BitCount error: %v", err)
	}

	fmt.Printf("Уникальных пользователей за день (DAU): %d\n", count)
}
```

ℹ️ Фиксация активности через BitmapSet

**`Терминал`**

```bash
go run main.go
# Вывод: Уникальных пользователей за день (DAU): 3
```

## Под капотом

Redis автоматически расширяет байтовую строку при необходимости. Максимальный размер строки в Redis составляет 512 МБ (\(2^{32}\) бит), что позволяет адресовать более 4 миллиардов пользователей в одной битовой карте.

## Подводные камни

Использование строковых UUID вместо целых чисел `int64`. Для UUID битовые карты не подходят (слишком большие разреженные смещения).

## На собеседовании

**Вопрос с собеседования:** «Каковы ограничения Bitmaps при разреженных данных (sparse data)?»
**Ответ:** Если у вас всего 2 пользователя с ID 1 и ID 3 000 000 000, строка займет ~375 МБ оперативной памяти ради хранения всего двух битов. Для разреженных данных используют Roaring Bitmaps или HyperLogLog.
