# Хранение уникальных IP-адресов через Sets и SCard

## Условие

**Множества (Sets - Уникальность)**: Тебе нужно хранить уникальные IP посетителей. Сделай 10 вызовов `SAdd` с одним и тем же IP и 5 с другим. Сделай `SCard` (количество). Убедись, что размер сета = 2.

## Теория

Команда `SCARD key` возвращает мощность множества (количество уникальных элементов) за константное время \(O(1)\).

## Решение по шагам

1. Создайте ключ `unique_ips`.
2. Добавьте 10 раз `"192.168.1.1"` и 5 раз `"10.0.0.1"`.
3. Проверьте кардинальность через `SCard`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/redis/go-redis/v9"
)

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	key := "security:unique_ips_set"
	_ = rdb.Del(ctx, key).Err()

	// 10 раз один и тот же IP
	for i := 0; i < 10; i++ {
		_ = rdb.SAdd(ctx, key, "192.168.1.1").Err()
	}

	// 5 раз другой IP
	for i := 0; i < 5; i++ {
		_ = rdb.SAdd(ctx, key, "10.0.0.1").Err()
	}

	// Получаем количество через SCARD
	count, err := rdb.SCard(ctx, key).Result()
	if err != nil {
		log.Fatalf("SCard error: %v", err)
	}

	fmt.Printf("Итоговое число уникальных IP в сете: %d\n", count)
	if count == 2 {
		fmt.Println("✅ Множество гарантировало дедупликацию!")
	}
}
```

ℹ️ Дедупликация через Set и O(1) подсчет через SCard

**`Терминал`**

```bash
go run main.go
# Вывод:
# Итоговое число уникальных IP в сете: 2
# ✅ Множество гарантировало дедупликацию!
```

## Под капотом

`SCARD` не пересчитывает элементы обходом, а возвращает поле `dictSize(set)` или `intsetLen(set)`, поэтому вызов выполняется мгновенно.

## Подводные камни

Полагаться на сортировку в Set: элементы расположены в случайном порядке корзин хэш-таблицы.

## На собеседовании

**Вопрос с собеседования:** «Как случайно выбрать одного победителя розыгрыша из Redis Set?»
**Ответ:** Командой `SRANDMEMBER key` (без удаления) или `SPOP key` (с атомарным удалением победителя из списка). Обе операции выполняются за \(O(1)\).
