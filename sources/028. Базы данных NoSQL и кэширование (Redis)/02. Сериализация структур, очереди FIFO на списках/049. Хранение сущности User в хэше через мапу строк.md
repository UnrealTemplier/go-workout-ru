# Хранение сущности User в хэше через мапу строк HashSet

## Условие

Напиши функцию `HashSet(key string, fields map[string]string) error` через `rdb.HSet(ctx, key, fields)`. Реализуй хранение объекта `User` в Redis hash: `HSET user:123 name Alice email alice@example.com`.

## Теория

Метод `rdb.HSet` принимает в качестве значений не только перечисление аргументов через запятую, но и мапу `map[string]interface{}` или `map[string]string`. Это позволяет преобразовывать словари Go напрямую в хэши Redis за один сетевой вызов.

## Решение по шагам

1. Напишите функцию `HashSet(ctx, key, fields)`.
2. Сохраните профиль `user:123`.
3. Убедитесь в сохранении вызовом `rdb.HGetAll`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/redis/go-redis/v9"
)

type UserHashStore struct {
	rdb *redis.Client
}

func (s *UserHashStore) HashSet(ctx context.Context, key string, fields map[string]string) error {
	return s.rdb.HSet(ctx, key, fields).Err()
}

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	store := &UserHashStore{rdb: rdb}
	key := "user:123"
	_ = rdb.Del(ctx, key).Err()

	userFields := map[string]string{
		"name":       "Alice",
		"email":      "alice@example.com",
		"department": "Engineering",
		"status":     "active",
	}

	if err := store.HashSet(ctx, key, userFields); err != nil {
		log.Fatalf("HashSet error: %v", err)
	}

	fmt.Printf("Пользователь успешно сохранен в хэш '%s'\n", key)

	allFields, _ := rdb.HGetAll(ctx, key).Result()
	fmt.Printf("Прочитано из Redis: %v\n", allFields)
}
```

ℹ️ Сохранение мапы в Redis Hash

**`Терминал`**

```bash
go run main.go
# Вывод:
# Пользователь успешно сохранен в хэш 'user:123'
# Прочитано из Redis: map[department:Engineering email:alice@example.com name:Alice status:active]
```

## Под капотом

В протоколе RESP клиент сериализует мапу как чередующуюся последовательность ключей и значений: `HSET user:123 name Alice email alice@example.com`. Сервер Redis выполняет операцию за \(O(K)\), где \(K\) — число переданных полей.

## Подводные камни

Передавать в мапу `nil`-значения. Клиент `go-redis` вернет ошибку сериализации или запишет пустую строку.

## На собеседовании

**Вопрос с собеседования:** «Устарела ли команда `HMSET` в Redis?»
**Ответ:** Да. Начиная с Redis 4.0 команда `HSET` стала вариативной (принимает произвольное количество пар поле-значение). Поэтому команда `HMSET` объявлена устаревшей (deprecated) и не рекомендуется к использованию в новом коде.
