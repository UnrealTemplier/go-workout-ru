# Хранение структур в Hashes: HSet, HGet и HGetAll

## Условие

**Работа со структурами через Hashes**: Redis поддерживает тип данных Hash, позволяющий работать с отдельными полями объекта без полной его перезаписи. Используйте команды `HSet`, `HGet` и `HGetAll` для хранения и чтения профиля пользователя.

## Теория

Использование Redis Hashes дает колоссальное преимущество перед JSON при частичных обновлениях: чтобы изменить статус пользователя `is_banned = true`, не нужно вычитывать весь JSON, десериализовать в Go, менять флаг и сериализовать обратно. Достаточно вызвать `HSET user:1 is_banned true`.

## Решение по шагам

1. Запишите профиль пользователя через `HSet`.
2. Измените только одно поле `email` через `HSet`.
3. Считайте все поля через `HGetAll`.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/redis/go-redis/v9"
)

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	key := "profile:user:501"
	_ = rdb.Del(ctx, key).Err()

	// 1. Первичная запись профиля
	_ = rdb.HSet(ctx, key, "username", "mikhail", "role", "analyst", "visits", 1).Err()

	// 2. Точечное обновление роли без перезаписи других полей
	_ = rdb.HSet(ctx, key, "role", "senior_analyst").Err()

	// 3. Точечный инкремент счетчика внутри хэша
	_ = rdb.HIncrBy(ctx, key, "visits", 1).Err()

	// 4. Чтение всех актуальных полей
	fields, err := rdb.HGetAll(ctx, key).Result()
	if err != nil {
		log.Fatalf("HGetAll failed: %v", err)
	}

	fmt.Println("Актуальный профиль из Hash:")
	for k, v := range fields {
		fmt.Printf("  • %s = %s\n", k, v)
	}
}
```

ℹ️ Частичное обновление полей через Hash

**`Терминал`**

```bash
go run main.go
# Вывод:
# Актуальный профиль из Hash:
#   • username = mikhail
#   • role = senior_analyst
#   • visits = 2
```

## Под капотом

Команда `HINCRBY key field increment` атомарно изменяет числовое поле прямо внутри хэша без сетевых блокировок и без необходимости вычитки объекта в память Go.

## Подводные камни

Попытка задать индивидуальный TTL для отдельного поля хэша. До Redis 7.4 TTL можно было ставить только на весь хэш целиком! Начиная с Redis 7.4 появилась экспериментальная поддержка `HEXPIRE`, но в большинстве продакшенов TTL ставится на ключ хэша целиком.

## На собеседовании

**Вопрос с собеседования:** «Как удалить одно конкретное поле из Redis Hash?»
**Ответ:** Командой `HDEL key field1 [field2 ...]`. Если удалены все поля хэша, Redis автоматически удаляет и сам ключ из памяти.
