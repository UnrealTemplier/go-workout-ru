# Лидерборд на Sorted Set: добавление игроков и извлечение топ-10 с очками

## Условие

Напиши функцию `SortedSetAdd(key string, members ...redis.Z) error`, использующую `rdb.ZAdd(ctx, key, members...)`. Реализуй **leaderboard**: добавь игроков с очками, получи топ-10 через `ZRevRangeWithScores(ctx, key, 0, 9)`.

## Теория

Команда `ZREVRANGEBYSCORE` или современная `ZRANGE ... REV WITHSCORES` возвращает срез объектов `redis.Z`, содержащих строковый идентификатор `Member` и числовой `Score`. Это ядро любых игровых рейтингов, систем репутации и топ-чартов музыки/видео.

## Решение по шагам

1. Напишите метод `SortedSetAdd(ctx, key, members...)`.
2. Заполните лидерборд 10 игроками с очками.
3. Запросите топ-10 через `rdb.ZRevRangeWithScores(ctx, key, 0, 9)`.
4. Распечатайте таблицу мест с форматированием.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/redis/go-redis/v9"
)

type LeaderboardService struct {
	rdb *redis.Client
}

func (s *LeaderboardService) SortedSetAdd(ctx context.Context, key string, members ...redis.Z) error {
	return s.rdb.ZAdd(ctx, key, members...).Err()
}

func (s *LeaderboardService) GetTop(ctx context.Context, key string, count int64) ([]redis.Z, error) {
	return s.rdb.ZRevRangeWithScores(ctx, key, 0, count-1).Result()
}

func main() {
	ctx := context.Background()
	rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
	defer rdb.Close()

	svc := &LeaderboardService{rdb: rdb}
	key := "arena:season_1:ratings"
	_ = rdb.Del(ctx, key).Err()

	// Загружаем список участников
	err := svc.SortedSetAdd(ctx, key,
		redis.Z{Member: "player_kirill", Score: 2450},
		redis.Z{Member: "player_maxim", Score: 3120},
		redis.Z{Member: "player_olga", Score: 2890},
		redis.Z{Member: "player_sergey", Score: 1950},
		redis.Z{Member: "player_dmitry", Score: 3500},
	)
	if err != nil {
		log.Fatalf("SortedSetAdd failed: %v", err)
	}

	// Извлекаем топ-3
	top, err := svc.GetTop(ctx, key, 3)
	if err != nil {
		log.Fatalf("GetTop failed: %v", err)
	}

	fmt.Println("🏆 ТОП ИГРОКОВ СЕЗОНА:")
	for i, p := range top {
		fmt.Printf("  #%d | Ник: %-15s | Рейтинг: %.0f\n", i+1, p.Member, p.Score)
	}
}
```

## Под капотом

Временная сложность выборки диапазона из Sorted Set составляет \(O(\log N + M)\), где \(N\) — общее число игроков, а \(M\) — количество возвращаемых записей. Благодаря Skip List поиск первого элемента занимает логарифмическое время, а дальнейший обход \(M\) элементов происходит простым шагом по связному списку нулевого уровня.

## Подводные камни

Использовать в качестве Member сложные структуры. Member должен быть компактным ID (например UUID или числовой ID). Хранить профиль игрока следует отдельно в Hash или реляционной базе.

## На собеседовании

**Вопрос с собеседования:** «Что происходит в ZSET, если у двух игроков одинаковый score?»
**Ответ:** Если score совпадает, Redis упорядочивает элементы лексикографически (в алфавитном порядке значений Member). Это гарантирует строгий детерминированный порядок вывода.
