# Экспорт и импорт криптографических ключей в формате PKCS#8 PEM

## Условие

**Экспорт и импорт PEM-ключей**: Напишите код сохранения ваших сгенерированных ключей на диск. Преобразуйте приватный ключ в формат PKCS#8, закодируйте его в PEM-блок с типом `PRIVATE KEY` с помощью пакета `encoding/pem` [541] и запишите в файл. Напишите код обратного считывания и парсинга PEM-файла с диска в объект ключа Go.

## Теория

В экосистеме UNIX и облачных сервисах криптографические ключи хранятся в файлах `.pem` или `.key`:
1. **Бинарный стандарт**: ASN.1 DER (Distinguished Encoding Rules).
2. **Текстовый транспорт**: PEM (Privacy-Enhanced Mail) — Base64 кодирование бинарного DER с заголовками `-----BEGIN ...-----` и `-----END ...-----`.
3. **PKCS#8 (RFC 5208)**: современный универсальный стандарт кодирования приватных ключей. В отличие от устаревшего PKCS#1 (`BEGIN RSA PRIVATE KEY`), PKCS#8 содержит явный идентификатор OID криптографического алгоритма и поддерживает RSA, ECDSA и Ed25519 в рамках единого интерфейса `x509.MarshalPKCS8PrivateKey` / `x509.ParsePKCS8PrivateKey`.

## Решение по шагам

1. Сгенерируйте ключевую пару RSA-2048 через `rsa.GenerateKey`.
2. Преобразуйте приватный ключ в DER через `x509.MarshalPKCS8PrivateKey(privKey)`.
3. Создайте структуру `pem.Block{Type: "PRIVATE KEY", Bytes: derBytes}`.
4. Запишите PEM-файл на диск с правами `0600`.
5. Прочитайте файл с диска через `os.ReadFile` и `pem.Decode`.
6. Распарсите DER через `x509.ParsePKCS8PrivateKey` и приведите тип к `*rsa.PrivateKey`.

## Код решения

**`pem_roundtrip.go`**

```go
package main

import (
	"crypto/rand"
	"crypto/rsa"
	"crypto/x509"
	"encoding/pem"
	"errors"
	"fmt"
	"os"
)

// SavePrivateKeyPKCS8PEM сохраняет ключ в файл
func SavePrivateKeyPKCS8PEM(privKey *rsa.PrivateKey, filename string) error {
	// 1. Преобразуем ключ в бинарный стандарт ASN.1 PKCS#8
	derBytes, err := x509.MarshalPKCS8PrivateKey(privKey)
	if err != nil {
		return fmt.Errorf("failed to marshal PKCS#8: %w", err)
	}

	// 2. Создаем PEM-блок
	pemBlock := &pem.Block{
		Type:  "PRIVATE KEY",
		Bytes: derBytes,
	}

	// 3. Записываем на диск с жесткими правами 0600 (только для владельца)
	file, err := os.OpenFile(filename, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0600)
	if err != nil {
		return err
	}
	defer file.Close()

	return pem.Encode(file, pemBlock)
}

// LoadPrivateKeyPKCS8PEM загружает ключ с диска
func LoadPrivateKeyPKCS8PEM(filename string) (*rsa.PrivateKey, error) {
	data, err := os.ReadFile(filename)
	if err != nil {
		return nil, err
	}

	block, _ := pem.Decode(data)
	if block == nil || block.Type != "PRIVATE KEY" {
		return nil, errors.New("failed to find valid 'PRIVATE KEY' PEM block")
	}

	keyAny, err := x509.ParsePKCS8PrivateKey(block.Bytes)
	if err != nil {
		return nil, fmt.Errorf("failed to parse PKCS#8 key: %w", err)
	}

	rsaKey, ok := keyAny.(*rsa.PrivateKey)
	if !ok {
		return nil, errors.New("parsed key is not an RSA private key")
	}

	return rsaKey, nil
}

func main() {
	privKey, _ := rsa.GenerateKey(rand.Reader, 2048)
	keyPath := "service_identity.key"
	defer os.Remove(keyPath)

	if err := SavePrivateKeyPKCS8PEM(privKey, keyPath); err != nil {
		panic(err)
	}
	fmt.Println("Приватный ключ успешно сериализован в PKCS#8 PEM!")

	// Читаем обратно
	loadedKey, err := LoadPrivateKeyPKCS8PEM(keyPath)
	if err != nil {
		panic(err)
	}

	fmt.Printf("Ключ успешно прочитан и восстановлен!\n")
	fmt.Printf("Модуль N совпадает? %v\n", loadedKey.N.Cmp(privKey.N) == 0)
	fmt.Printf("Секретная экспонента D совпадает? %v\n", loadedKey.D.Cmp(privKey.D) == 0)
}
```

## Под капотом

Функция `pem.Encode` разбивает Base64 строку на строки ровно по 64 символа, добавляя завершающий символ новой строки `\n`. Это гарантирует совместимость с утилитами OpenSSL, curl и инструментами командной строки Linux.

## Подводные камни

Использование прав доступа по умолчанию `0644` при создании файлов приватных ключей (ключ становится доступен для чтения всем локальным пользователям сервера).

## На собеседовании

**Вопрос с собеседования:** «Почему функция `x509.ParsePKCS8PrivateKey` возвращает `any` (интерфейс), а не конкретную структуру `*rsa.PrivateKey`?»
**Ответ:** Стандарт PKCS#8 является полиморфным контейнером. Внутри блока может находиться ключ RSA, ECDSA (P-256, P-384), Ed25519 или постквантовый ML-KEM. Парсер декодирует поле `AlgorithmIdentifier.Algorithm` (OID), инстанциирует соответствующую структуру в рантайме Go и возвращает её как `any`, требуя от вызывающего кода явного приведения типа (type assertion).
