# Чтение публичного ключа RSA из PEM и шифрование коротких секретов

## Условие

**Шифрование RSA (OAEP)**: Напиши код, который читает публичный ключ из файла и шифрует короткое сообщение (например, симметричный ключ) с помощью `rsa.EncryptOAEP`. Расшифруй его приватным ключом.

## Теория

В сервисной архитектуре микросервис-клиент часто не имеет доступа к приватному ключу сервера, владея лишь открытым ключом `server.pub.pem`.

**Процедура работы:**
1. Файл `server.pub.pem` считывается с диска.
2. Блок декодируется через `pem.Decode`.
3. Парсится структура SubjectPublicKeyInfo через `x509.ParsePKIXPublicKey`.
4. Выполняется приведение типов к `*rsa.PublicKey`.
5. Короткий секрет (например, 256-битный сессионный ключ AES) шифруется через `rsa.EncryptOAEP` с хешем SHA-256.

## Решение по шагам

1. Создайте пару RSA-2048 и запишите публичный ключ в файл PEM.
2. Реализуйте функцию `LoadRSAPublicKey(path string) (*rsa.PublicKey, error)`.
3. Сгенерируйте 32 байта симметричного ключа.
4. Зашифруйте ключ с помощью загруженного публичного ключа.
5. Расшифруйте приватным ключом и проверьте байтовое совпадение.

## Код решения

**`rsa_encrypt_flow.go`**

```go
package main

import (
	"bytes"
	"crypto/rand"
	"crypto/rsa"
	"crypto/sha256"
	"crypto/x509"
	"encoding/pem"
	"errors"
	"fmt"
	"io"
	"os"
)

// LoadRSAPublicKey парсит открытый ключ из PEM-файла
func LoadRSAPublicKey(path string) (*rsa.PublicKey, error) {
	data, err := os.ReadFile(path)
	if err != nil {
		return nil, err
	}

	block, _ := pem.Decode(data)
	if block == nil || block.Type != "PUBLIC KEY" {
		return nil, errors.New("invalid public key PEM block")
	}

	pubInterface, err := x509.ParsePKIXPublicKey(block.Bytes)
	if err != nil {
		return nil, fmt.Errorf("failed to parse PKIX public key: %w", err)
	}

	rsaPub, ok := pubInterface.(*rsa.PublicKey)
	if !ok {
		return nil, errors.New("parsed key is not an RSA public key")
	}

	return rsaPub, nil
}

func main() {
	privKey, _ := rsa.GenerateKey(rand.Reader, 2048)
	pubDER, _ := x509.MarshalPKIXPublicKey(&privKey.PublicKey)

	pubFile := "external_service.pub.pem"
	defer os.Remove(pubFile)
	_ = os.WriteFile(pubFile, pem.EncodeToMemory(&pem.Block{Type: "PUBLIC KEY", Bytes: pubDER}), 0644)

	// 1. Клиент читает публичный ключ из файла
	pubKey, err := LoadRSAPublicKey(pubFile)
	if err != nil {
		panic(err)
	}
	fmt.Printf("Публичный ключ успешно загружен из файла! Размер модуля: %d бит\n", pubKey.N.BitLen())

	// 2. Генерируем 32-байтный сессионный ключ
	sessionKey := make([]byte, 32)
	_, _ = io.ReadFull(rand.Reader, sessionKey)

	// 3. Шифруем сессионный ключ публичным ключом
	ciphertext, err := rsa.EncryptOAEP(sha256.New(), rand.Reader, pubKey, sessionKey, nil)
	if err != nil {
		panic(err)
	}
	fmt.Printf("Сессионный ключ зашифрован RSA-OAEP: %d байт\n", len(ciphertext))

	// 4. Сервер расшифровывает сессионный ключ
	decryptedKey, err := rsa.DecryptOAEP(sha256.New(), rand.Reader, privKey, ciphertext, nil)
	if err != nil {
		panic(err)
	}

	if bytes.Equal(sessionKey, decryptedKey) {
		fmt.Println("УСПЕХ: Сессионный ключ расшифрован сервером и побайтово совпал!")
	}
}
```

## Под капотом

При считывании открытого ключа парсер `x509.ParsePKIXPublicKey` выполняет проверку корректности ASN.1 формата, валидирует длину открытой экспоненты \(e\) и убеждается, что модуль \(N\) положителен и не содержит лидирующих битов знака.

## Подводные камни

Попытка распарсить публичный ключ функцией `x509.ParsePKCS1PublicKey`, если PEM содержит заголовок `PUBLIC KEY` вместо `RSA PUBLIC KEY`.

## На собеседовании

**Вопрос с собеседования:** «Чем отличается формат PEM `PUBLIC KEY` от формата `RSA PUBLIC KEY`?»
**Ответ:** `RSA PUBLIC KEY` — это спецификация PKCS#1, хранящая только два поля: \(N\) и \(e\). Она привязана исключительно к RSA. `PUBLIC KEY` — это стандарт X.509 SubjectPublicKeyInfo (PKIX), содержащий OID алгоритма (`rsaEncryption`, `id-ecPublicKey`, `id-Ed25519`) и тело ключа. Стандарт `PUBLIC KEY` является универсальным и используется всеми современными веб-сервисами.
