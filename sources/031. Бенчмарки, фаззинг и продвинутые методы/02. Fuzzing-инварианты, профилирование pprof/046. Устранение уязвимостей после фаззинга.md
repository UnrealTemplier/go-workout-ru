# Устранение уязвимостей после фаззинга: рефакторинг Reverse на руны и стабилизация

## Условие

**Исправление кода после Фаззинга**: Перепиши `Reverse`, работая с рунами (тип `[]rune`), чтобы она корректно поддерживала любые Unicode-символы. Запусти фаззинг снова (оставь на пару минут) — он должен работать без ошибок.

## Теория

Цикл разработки Fuzz-Driven Bug Fixing:
1. Фаззер генерирует сбой на не-ASCII символе.
2. Инженер анализирует краш-кейс `testdata/fuzz/FuzzName/...`.
3. Код рефакторится: переход от среза байт `[]byte` к срезу рун `[]rune`.
4. Повторный запуск фаззера с флагом `-fuzztime=30s` подтверждает полное устранение дефекта на миллионах мутаций.

## Решение по шагам

1. Реализуйте функцию `UnicodeReverse(s string) string` на срезе рун.
2. Добавьте проверку `utf8.ValidString`.
3. Запустите фаззер и убедитесь в отсутствии сбоев.

## Код решения

**`unicode_reverse.go`**

```go
package main

func UnicodeReverse(s string) string {
	runes := []rune(s)
	n := len(runes)
	for i := 0; i < n/2; i++ {
		runes[i], runes[n-1-i] = runes[n-1-i], runes[i]
	}
	return string(runes)
}
```

ℹ️ Устойчивая функция реверса Unicode строк

**`unicode_reverse_fuzz_test.go`**

```go
package main

import (
	"testing"
	"unicode/utf8"
)

func FuzzUnicodeReverse(f *testing.F) {
	// Базовый корпус семян
	f.Add("Hello, World!")
	f.Add("Привет, мир!")
	f.Add("日本語と中文")
	f.Add("Go 🚀 2026")

	f.Fuzz(func(t *testing.T, original string) {
		if !utf8.ValidString(original) {
			return
		}

		rev := UnicodeReverse(original)
		doubleRev := UnicodeReverse(rev)

		if !utf8.ValidString(rev) {
			t.Fatalf("Испорчен UTF-8: %q -> %q", original, rev)
		}

		if doubleRev != original {
			t.Fatalf("Двойной реверс не совпал: %q != %q", original, doubleRev)
		}
	})
}
```

## На собеседовании

**Вопрос с собеседования:** «Какова разница между фаззингом и юнит-тестированием с точки зрения поиска регрессий?»
**Ответ:** Юнит-тесты проверяют детерминированные гипотезы разработчика («что я ожидал»). Фаззинг исследует пространство непредвиденных состояний («что я забыл предусмотреть»), превращая найденные краевые аномалии в постоянные юнит-тесты.
