# Фаззинг симметричности: верификация инварианта двойного реверса Reverse(Reverse(s)) == s

## Условие

Напиши функцию `Reverse(s string) string`, переворачивающую строку (руны!). Напиши фазз-тест: `func FuzzReverse(f *testing.F) { f.Add("hello"); f.Fuzz(func(t *testing.T, orig string) { rev := Reverse(orig); rev2 := Reverse(rev); if orig != rev2 { t.Fatalf("Reverse(Reverse(%q)) = %q", orig, rev2) } }) }`. Запусти `go test -fuzz=FuzzReverse`.

## Теория

Математическое свойство инволюции (Involution Property):
- Операция \(f\) называется инволюцией, если её двукратное применение возвращает исходное состояние:
  $$f(f(x)) = x$$
- Реверс строки — классическая инволюция: дважды перевернутая строка обязана быть идентична начальной.
- Фаззинг этого свойства на рунах (`[]rune`) доказывает математическую корректность алгоритма на любых символах алфавитов мира.

## Решение по шагам

1. Напишите `ReverseRunes(s string) string`.
2. Создайте фазз-тест `FuzzReverseRune`.
3. Добавьте seed `"hello"`.
4. Проверьте равенство `orig == rev2`.

## Код решения

**`rune_reverse.go`**

```go
package main

// ReverseRunes переворачивает строку с сохранением Unicode символов
func ReverseRunes(s string) string {
	r := []rune(s)
	for i, j := 0, len(r)-1; i < j; i, j = i+1, j-1 {
		r[i], r[j] = r[j], r[i]
	}
	return string(r)
}
```

ℹ️ Корректная функция реверса на рунах

**`rune_reverse_fuzz_test.go`**

```go
package main

import (
	"testing"
	"unicode/utf8"
)

func FuzzReverseRune(f *testing.F) {
	f.Add("hello")
	f.Add("Привет, Яндекс!")
	f.Add("Go 2026")

	f.Fuzz(func(t *testing.T, orig string) {
		// Фильтруем битый вход (фаззер может подать невалидный UTF-8)
		if !utf8.ValidString(orig) {
			return
		}

		rev := ReverseRunes(orig)
		rev2 := ReverseRunes(rev)

		if orig != rev2 {
			t.Fatalf("Нарушение инволюции! Reverse(Reverse(%q)) = %q", orig, rev2)
		}
	})
}
```

ℹ️ Фаззинг инварианта двойного реверса

## Под капотом

Проверка `if !utf8.ValidString(orig) { return }` отсекает мусорные байтовые последовательности, которые фаззер генерирует случайным образом и которые изначально не являлись валидным текстом.

## Подводные камни

Забывать проверку `utf8.ValidString`: если на вход подать невалидный UTF-8, функция `string([]rune)` заменит невалидные байты на `\uFFFD`, и двойной реверс не совпадет.

## На собеседовании

**Вопрос с собеседования:** «Какова алгоритмическая сложность и потребление памяти функции ReverseRunes?»
**Ответ:** Сложность по времени \(O(N)\), где \(N\) — длина строки. По памяти \(O(N)\): создание среза `[]rune` требует выделения нового массива в куче размером \(4 \times N\) байт. Для оптимизации в Hot Path можно переиспользовать предварительно выделенный буфер рун.
