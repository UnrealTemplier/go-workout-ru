# Конкурентная отмена контекста: широковещательное завершение пула горутин через ctx.Done()

## Условие

Проверьте корректность `context.Context` в конкурентной среде: отмените контекст и убедитесь, что все горутины завершились за разумное время.

## Теория

Широковещательная отмена (Context Fan-Out Cancellation):
- Один контекст `ctx` может передаваться десяткам параллельных горутин.
- Закрытие канала `<-ctx.Done()` при вызове `cancel()` — это **широковещательный сигнал** (Broadcast Signal): все заблокированные горутины одновременно просыпаются и выходят.
- Тест проверяет:
  1. Запускается 50 горутин, ожидающих `ctx.Done()`.
  2. Вызывается `cancel()`.
  3. Все 50 горутин завершаются за разумное время (<50 мс), подтверждая отсутствие зависших горутин.

## Решение по шагам

1. Создайте отменяемый контекст.
2. Запустите 50 горутин с `sync.WaitGroup`.
3. Вызовите `cancel()`.
4. Замерьте время завершения всех горутин через `wg.Wait()`.

## Код решения

**`fanout_cancel_test.go`**

```go
package main

import (
	"context"
	"sync"
	"testing"
	"time"
)

func TestContextBroadcastCancellation(t *testing.T) {
	ctx, cancel := context.WithCancel(context.Background())
	const numGoroutines = 50

	var wg sync.WaitGroup
	wg.Add(numGoroutines)

	for i := 0; i < numGoroutines; i++ {
		go func() {
			defer wg.Done()
			select {
			case <-ctx.Done():
				return // Корректный выход по сигналу отмены
			case <-time.After(5 * time.Second):
				t.Error("Таймаут: горутина не получила сигнал отмены!")
			}
		}()
	}

	// Даем всем горутинам гарантированно встать на чтение
	time.Sleep(20 * time.Millisecond)

	start := time.Now()
	// ШИРОВЕЩАТЕЛЬНАЯ ОТМЕНА: будим все 50 горутин разом!
	cancel()

	wg.Wait()
	elapsed := time.Since(start)

	t.Logf("Все %d горутин успешно завершились за %v", numGoroutines, elapsed)

	if elapsed > 100*time.Millisecond {
		t.Fatalf("Слишком долгое завершение горутин: %v (ожидалось < 100 мс)", elapsed)
	}
}
```

ℹ️ Тест широковещательной отмены 50 горутин через context.Context

## Под капотом

Закрытие канала в Go переводит его в состояние, когда любая операция чтения `<-ch` немедленно возвращает нулевое значение типа без блокировки, позволяя пробудить миллион горутин за доли миллисекунды.

## Подводные камни

Использовать отправку в канал `ch <- struct{}{}` вместо `close(ch)` для остановки пула воркеров: отправка разбудит только одну горутину, а остальные останутся висеть в дедлоке.

## На собеседовании

**Вопрос с собеседования:** «В чем преимущество передачи context.Context первым аргументом функции по гайдлайнам Go?»
**Ответ:** Это стандарт языка (Convention Over Configuration). Любой разработчик и библиотека знают, что первый аргумент `ctx` управляет дедлайном, трассировкой (OpenTelemetry) и отменой операции, гарантируя прозрачное пробрасывание по всему стеку микросервиса.
