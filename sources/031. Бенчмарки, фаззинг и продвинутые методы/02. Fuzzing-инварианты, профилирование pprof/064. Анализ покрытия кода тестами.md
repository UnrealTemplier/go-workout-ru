# Анализ покрытия кода тестами: флаг go test -cover и метрика statements

## Условие

Запусти тесты с флагом покрытия: `go test -cover`. Посмотри процент покрытия (например, `coverage: 85.2% of statements`).

## Теория

Метрика Statement Coverage в Go:
- Флаг `go test -cover` включает анализ покрытия на уровне операторов (Statements).
- Компилятор Go делит функции на базовые блоки операторов и внедряет невидимые счетчики выполнения.
- Вывод команды:
  `coverage: 85.2% of statements`
- Отражает процент строк исполняемого кода, который был физически затронут во время прогона тестов.

## Решение по шагам

1. Напишите функцию с условием `if/else`.
2. Напишите тест, покрывающий только одну ветку.
3. Запустите `go test -cover`.
4. Добавьте тест для второй ветки и доведите покрытие до 100%.

## Код решения

**`status_check.go`**

```go
package main

func CheckHTTPStatus(code int) string {
	if code >= 200 && code < 300 {
		return "SUCCESS"
	} else if code >= 400 && code < 500 {
		return "CLIENT_ERROR"
	}
	return "SERVER_ERROR"
}
```

ℹ️ Функция с 3 ветвями операторов

**`status_check_test.go`**

```go
package main

import "testing"

func TestCheckHTTPStatus(t *testing.T) {
	// Покрываем 200 OK
	if res := CheckHTTPStatus(200); res != "SUCCESS" {
		t.Errorf("got %q; want SUCCESS", res)
	}

	// Покрываем 404 Not Found
	if res := CheckHTTPStatus(404); res != "CLIENT_ERROR" {
		t.Errorf("got %q; want CLIENT_ERROR", res)
	}

	// Покрываем 500 Internal Error
	if res := CheckHTTPStatus(500); res != "SERVER_ERROR" {
		t.Errorf("got %q; want SERVER_ERROR", res)
	}
}
```

ℹ️ Тест с полным покрытием всех 3 ветвей

**`Терминал`**

```bash
go test -cover status_check_test.go status_check.go
# Вывод:
# ok      command-line-arguments    0.002s    coverage: 100.0% of statements
```

## Под капотом

Инструмент `go test -cover` модифицирует исходный код перед компиляцией, оборачивая операторы в инкременты статического массива: `GoCover.Count[0]++`.

## Подводные камни

Гнаться за 100% покрытием ради отчета: тест может выполнить 100% строк кода, не сделав ни единого ассерта на корректность результата вычислений.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие Statement Coverage от Branch Coverage?»
**Ответ:** Statement Coverage фиксирует факт исполнения строки кода. Branch Coverage проверяет, были ли пройдены все возможные комбинации логических условий (например, для `if a && b` проверяются кейсы `true/true`, `true/false`, `false/true`, `false/false`). В Go флаг `-cover` измеряет операторы (Statements), а для условий используют мутационное тестирование.
