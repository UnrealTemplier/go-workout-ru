# Фаззинг криптографических функций: проверка лавинного эффекта и фиксированной длины дайджеста

## Условие

Напиши фазз-тест для **криптографической функции**: `Hash(data []byte) []byte`. Проверь свойства: длина хеша фиксирована, малое изменение входа → большое изменение выхода (hamming distance).

## Теория

Криптографические свойства хеш-функций (SHA-256):
1. **Фиксированная длина (Fixed Digest Length):** независимо от того, подан 0 байт или 1 гигабайт, дайджест SHA-256 строго равен 32 байтам (256 бит).
2. **Лавинный эффект (Avalanche Effect):** изменение даже одного бита на входе обязано приводить к статистическому изменению около 50% всех бит на выходе (расстояние Хэмминга \(\approx 128\) бит).
3. **Детерминизм:** `Hash(x) == Hash(x)`.

## Решение по шагам

1. Напишите обертку над SHA-256.
2. Объявите фазз-тест с проверкой длины дайджеста 32 байта.
3. Добавьте проверку лавинного эффекта при инверсии 1 бита.
4. Запустите фаззинг.

## Код решения

**`crypto_hash_test.go`**

```go
package main

import (
	"crypto/sha256"
	"math/bits"
	"testing"
)

func CryptoHash(data []byte) [32]byte {
	return sha256.Sum256(data)
}

// BitHammingDistance вычисляет число различающихся бит между двумя хешами
func BitHammingDistance(h1, h2 [32]byte) int {
	diffBits := 0
	for i := 0; i < 32; i++ {
		diffBits += bits.OnesCount8(h1[i] ^ h2[i])
	}
	return diffBits
}

func FuzzCryptoHashProperties(f *testing.F) {
	f.Add([]byte("secure-token"))
	f.Add([]byte(""))
	f.Add([]byte("\xff\xff\xff\xff"))

	f.Fuzz(func(t *testing.T, payload []byte) {
		h1 := CryptoHash(payload)

		// Инвариант 1: строгий размер 32 байта
		if len(h1) != 32 {
			t.Fatalf("Длина хеша не равна 32: %d", len(h1))
		}

		if len(payload) > 0 {
			// Мутируем ровно 1 младший бит первого байта
			mutated := make([]byte, len(payload))
			copy(mutated, payload)
			mutated[0] ^= 0x01

			h2 := CryptoHash(mutated)

			// Инвариант 2: Лавинный эффект (из 256 бит должно измениться от 60 до 200 бит)
			dist := BitHammingDistance(h1, h2)
			if dist < 40 {
				t.Fatalf("Слабый лавинный эффект! Изменилось всего %d бит из 256 для входа %q",
					dist, payload)
			}
		}
	})
}
```

## Под капотом

Функция `bits.OnesCount8(x ^ y)` компилируется в одну аппаратную инструкцию процессора `POPCNT` (Population Count), вычисляя расстояние Хэмминга за 1 такт CPU.

## Подводные камни

Пытаться инвертировать бит при `len(payload) == 0`: обращение `payload[0]` на пустом слайсе вызовет панику `index out of range`.

## На собеседовании

**Вопрос с собеседования:** «Почему для хеширования паролей категорически запрещено использовать SHA-256?»
**Ответ:** SHA-256 спроектирован быть максимально быстрым (миллионы хешей в секунду на GPU), что делает его уязвимым для атак перебором по радужным таблицам (Brute-Force). Для паролей используют медленные ресурсоемкие функции формирования ключа: `bcrypt`, `Argon2id` или `scrypt`, требующие фиксированного объема RAM и времени CPU.
