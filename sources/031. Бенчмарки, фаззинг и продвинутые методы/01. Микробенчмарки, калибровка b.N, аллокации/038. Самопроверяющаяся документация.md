# Самопроверяющаяся документация: тестируемые примеры ExampleFormatMoney и комментарий // Output

## Условие

**Тестирование на примерах (Examples)**: Напишите функцию `FormatMoney(amount int) string`. В файле тестов напишите функцию-документацию `ExampleFormatMoney()` [345]. Внутри тела функции вызовите `fmt.Println(FormatMoney(1000))` и добавьте в самом конце специальный комментарий `// Output: 1 000 руб.` [345]. Убедитесь, что `go test` автоматически валидирует соответствие вывода программы вашему комментарию.

## Теория

Паттерн Testable Examples в Go:
- Функции вида `ExampleXxx()` в `_test.go` файлах выполняют тройную роль:
  1. Они отображаются в документации `godoc` и `pkg.go.dev` как интерактивные примеры с кнопкой «Run».
  2. При наличии комментария `// Output:` раннер `go test` компилирует и исполняет функцию, перехватывает `os.Stdout` и сравнивает его с текстом после `// Output:`.
  3. Если вывод не совпадает хотя бы на один пробел — тест падает! Документация никогда не устаревает.

## Решение по шагам

1. Напишите функцию форматирования денег с пробелами между тысячами.
2. Объявите функцию `ExampleFormatMoney()`.
3. Добавьте вызов `fmt.Println` и строку `// Output: 1 000 руб.`.
4. Запустите `go test -v` и убедитесь в валидации.

## Код решения

**`money_formatter.go`**

```go
package main

import "fmt"

// FormatMoney форматирует сумму с разделителями тысяч
func FormatMoney(amount int) string {
	if amount >= 1000 && amount < 1000000 {
		thousands := amount / 1000
		remainder := amount % 1000
		return fmt.Sprintf("%d %03d руб.", thousands, remainder)
	}
	return fmt.Sprintf("%d руб.", amount)
}
```

ℹ️ Функция форматирования денежной суммы

**`money_formatter_test.go`**

```go
package main

import "fmt"

// ExampleFormatMoney демонстрирует использование FormatMoney
func ExampleFormatMoney() {
	result := FormatMoney(1000)
	fmt.Println(result)

	// Output:
	// 1 000 руб.
}
```

ℹ️ Самопроверяющийся тест-пример с секцией Output

**`Терминал`**

```bash
go test -v money_formatter_test.go money_formatter.go
# Вывод:
# === RUN   ExampleFormatMoney
# --- PASS: ExampleFormatMoney (0.00s)
# PASS
```

## Под капотом

Раннер `go test` подменяет дескриптор стандартного вывода `os.Stdout` на именованный пайп (`os.Pipe()`), перехватывает все байты вывода и сверяет их с парсером AST-комментариев.

## Подводные камни

Использовать неупорядоченный вывод (например, печать мапы): порядок итерации мапы случаен, поэтому тест упадет. Для мап используют комментарий `// Unordered output:`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие // Output: от // Unordered output: в Go Examples?»
**Ответ:** `// Output:` требует строгого построчного совпадения вывода. `// Unordered output:` сортирует строки фактического вывода и строки комментария перед сравнением, что позволяет тестировать вывод элементов хеш-таблиц или параллельных горутин.
