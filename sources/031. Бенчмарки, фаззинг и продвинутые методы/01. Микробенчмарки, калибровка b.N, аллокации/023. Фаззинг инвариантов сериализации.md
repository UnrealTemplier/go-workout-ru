# Фаззинг инвариантов сериализации: Round-Trip свойство Decode(Encode(x)) == x

## Условие

Создайте fuzz-тест, который проверяет инвариант: `Decode(Encode(x)) == x` (round-trip property).

## Теория

Тестирование свойств (Property-Based Testing) через Round-Trip Fuzzing:
- Для большинства кодеков (JSON, Protobuf, Base64, Hex, Gob) трудно вручную составить список всех возможных входных строк со спецсимволами.
- **Фундаментальный математический инвариант:**
  Любой валидный объект \(X\), закодированный в байты и декодированный обратно, обязан быть идентичен оригиналу:
  $$\text{Decode}(\text{Encode}(x)) = x$$
- Если фаззер генерирует случайную строку, и после `Encode -> Decode` получается другое значение — кодек содержит скрытый баг порчи данных!

## Решение по шагам

1. Напишите кодировщик и декодировщик Base64.
2. Объявите фазз-тест `FuzzRoundTripBase64`.
3. Выполните цикл `Encode -> Decode`.
4. Сравните результат с исходным значением через `bytes.Equal`.

## Код решения

**`codec_fuzz_test.go`**

```go
package main

import (
	"bytes"
	"encoding/base64"
	"testing"
)

func FuzzRoundTripBase64(f *testing.F) {
	// Добавляем семена: пустая строка, бинарные байты, UTF-8
	f.Add([]byte(""))
	f.Add([]byte("Hello, HighLoad World!"))
	f.Add([]byte("\x00\x01\x02\xff\xfe\xfd"))
	f.Add([]byte("Привет, Яндекс и Ozon!"))

	f.Fuzz(func(t *testing.T, original []byte) {
		// 1. Кодирование (Encode)
		encoded := base64.StdEncoding.EncodeToString(original)

		// 2. Декодирование (Decode)
		decoded, err := base64.StdEncoding.DecodeString(encoded)
		if err != nil {
			t.Fatalf("Декодирование упало с ошибкой на данных %q: %v", original, err)
		}

		// 3. ПРОВЕРКА ИНВАРИАНТА: Decode(Encode(x)) == x
		if !bytes.Equal(original, decoded) {
			t.Fatalf("Нарушение Round-Trip инварианта!\nOriginal: %v\nDecoded:  %v", original, decoded)
		}
	})
}
```

ℹ️ Фаззинг инварианта взаимной обратимости кодирования

## Под капотом

Round-Trip фаззинг автоматически тестирует граничные байты (нулевой байт `\x00`, невалидный UTF-8, байты с установленным старшим битом), гарантируя симметричность кодека.

## Подводные камни

Применять `Decode(Encode(x)) == x` к вещественным числам `float64`: из-за особенностей стандарта IEEE-754 `NaN != NaN`, поэтому `math.IsNaN` требует отдельной проверки.

## На собеседовании

**Вопрос с собеседования:** «Какие еще математические инварианты можно тестировать фаззингом кроме Round-Trip?»
**Ответ:** 1. **Идемпотентность:** `f(f(x)) == f(x)` (например, форматирование `gofmt` или нормализация URL). 2. **Коммутативность:** `Add(a, b) == Add(b, a)`. 3. **Инвариант оракула:** сравнение быстрого оптимизированного ассемблерного алгоритма с эталонной наивной реализацией `FastSort(x) == SlowSort(x)`.
