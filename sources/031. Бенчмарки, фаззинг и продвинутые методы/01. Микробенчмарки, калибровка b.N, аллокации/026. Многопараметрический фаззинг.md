# Многопараметрический фаззинг: генерация кортежей аргументов (int, string, bool) в f.Fuzz

## Условие

Используйте `f.Add` с разными типами данных (int, string, bool) в одном fuzz-тесте для тестирования функций, принимающих множество типов.

## Теория

Фаззинг сигнатур с несколькими аргументами:
- Функции бизнес-логики часто принимают несколько разнотипных параметров: `ProcessUser(id int, name string, isAdmin bool)`.
- Фаззинг в Go поддерживает кортежи примитивных типов любой длины!
- Метод `f.Add(10, "Иван", true)` задает начальный кортеж.
- Фаззер одновременно мутирует и строку (добавляя спецсимволы и длинные строки), и число (проверяя отрицательные значения и переполнения `math.MaxInt`), и булевый флаг.

## Решение по шагам

1. Напишите функцию обработки заказа с несколькими параметрами.
2. Создайте фазз-тест с сигнатурой `(t *testing.T, count int, coupon string, isVIP bool)`.
3. Задайте начальные семена кортежей.
4. Проверьте обработку граничных значений.

## Код решения

**`order_pricing.go`**

```go
package main

import "strings"

func CalculateDiscount(itemsCount int, promoCode string, isVIP bool) float64 {
	// Граничные проверки
	if itemsCount <= 0 {
		return 0.0
	}

	discount := 0.0
	if isVIP {
		discount += 15.0
	}

	// Проверка промокода
	cleanPromo := strings.ToUpper(strings.TrimSpace(promoCode))
	if cleanPromo == "SALE2026" {
		discount += 20.0
	}

	if itemsCount >= 10 {
		discount += 5.0
	}

	if discount > 50.0 {
		discount = 50.0 // Максимальная скидка 50%
	}
	return discount
}
```

ℹ️ Функция расчета скидки с 3 разнотипными параметрами

**`order_pricing_fuzz_test.go`**

```go
package main

import "testing"

func FuzzCalculateDiscount(f *testing.F) {
	// Добавляем кортежи начальных параметров: (int, string, bool)
	f.Add(1, "SALE2026", false)
	f.Add(15, "", true)
	f.Add(-5, "INVALID", false)
	f.Add(100, " sale2026 ", true)

	f.Fuzz(func(t *testing.T, count int, promo string, isVIP bool) {
		d := CalculateDiscount(count, promo, isVIP)

		// Инвариант: скидка всегда в диапазоне [0.0, 50.0]
		if d < 0.0 || d > 50.0 {
			t.Fatalf("Инвариант нарушен! Скидка %.2f вне диапазона [0, 50] для: count=%d promo=%q isVIP=%v",
				d, count, promo, isVIP)
		}
	})
}
```

ℹ️ Фаззинг кортежей разнотипных аргументов

**`Терминал`**

## Под капотом

Движок фаззинга Go генерирует псевдослучайные мутации независимо для каждого типа аргумента, используя битовые сдвиги для чисел и словарные подстановки для строк.

## Подводные камни

Передавать в `f.Add` типы, отличные от параметров в `f.Fuzz`: компилятор выдаст панику во время сборки теста.

## На собеседовании

**Вопрос с собеседования:** «Как с помощью фаззинга находить целочисленные переполнения (Integer Overflow)?»
**Ответ:** Фаззер автоматически подставляет граничные значения `math.MaxInt32`, `math.MinInt64`, `0` и `-1`. В теле фазз-теста проверяют математический инвариант: например, для сложения положительных чисел `a > 0 && b > 0` результат обязан удовлетворять `a + b > a`. Если произошло переполнение в отрицательную область, тест падает.
