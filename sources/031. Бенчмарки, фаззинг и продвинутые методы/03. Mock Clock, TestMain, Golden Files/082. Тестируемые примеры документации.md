# Тестируемые примеры документации: функция ExampleAdd и валидация комментария // Output:

## Условие

Напиши **"example test"**: `func ExampleAdd() { fmt.Println(Add(2, 3)) // Output: 5 }`. Запусти `go test`. Покажи, что Example-тесты выполняются и проверяют `// Output:` комментарий.

## Теория

Исполняемая документация (Executable Documentation):
- Example-тесты — уникальная возможность языка Go, объединяющая модульное тестирование и живую документацию.
- Функция `ExampleFunctionName()` размещается в файле `_test.go`.
- В конце функции ставится комментарий:
  ```go
  // Output:
  // ожидаемый текст stdout
  ```
- При запуске `go test` раннер перехватывает `os.Stdout` и сверяет его со значением комментария. При несовпадении тест завершается с ошибкой `FAIL: got "..." want "..."`.

## Решение по шагам

1. Объявите функцию `Add(a, b int) int`.
2. Создайте функцию `ExampleAdd()`.
3. Добавьте вывод `fmt.Println(Add(2, 3))` и секцию `// Output: 5`.
4. Запустите `go test -v` и подтвердите выполнение.

## Код решения

**`calc.go`**

```go
package main

// Add складывает два числа
func Add(a, b int) int {
	return a + b
}
```

ℹ️ Целевая функция Add

**`calc_example_test.go`**

```go
package main

import "fmt"

func ExampleAdd() {
	sum := Add(2, 3)
	fmt.Println(sum)

	// Output:
	// 5
}
```

ℹ️ Example-тест с валидацией комментария Output

**`Терминал`**

```bash
go test -v calc_example_test.go calc.go
# Вывод:
# === RUN   ExampleAdd
# --- PASS: ExampleAdd (0.00s)
# PASS
# ok      command-line-arguments    0.002s
```

## Под капотом

Если убрать комментарий `// Output:`, Example-функция будет просто скомпилирована (для проверки синтаксиса), но не будет исполняться во время прогона тестов.

## Подводные камни

Лишние пробелы в конце строки комментария: парсер Go требует точного посимвольного совпадения строк.

## На собеседовании

**Вопрос с собеседования:** «Как назвать Example-тест для метода структуры или для отдельного метода с несколькими примерами?»
**Ответ:** По соглашению Go:
- Для типа: `ExampleTypeName()`
- Для метода структуры: `ExampleTypeName_MethodName()`
- Для нескольких примеров одной функции: `ExampleAdd_basic()`, `ExampleAdd_advanced()`.
