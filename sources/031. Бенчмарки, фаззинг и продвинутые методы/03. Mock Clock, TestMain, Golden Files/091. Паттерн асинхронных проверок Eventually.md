# Паттерн асинхронных проверок Eventually: цикл опроса с таймаутом без хрупких time.Sleep

## Условие

Используйте `eventually`-паттерн (цикл с retry и таймаутом) для тестирования асинхронных операций без `time.Sleep`.

## Теория

Почему жесткий `time.Sleep` в тестах — антипаттерн:
- Если поставить `time.Sleep(1 * time.Second)`:
  - Тест всегда тратит 1 секунду, даже если операция выполнилась за 2 миллисекунды (замедление прогона CI).
  - На медленном CI-раннере 1 секунды может не хватить, и тест случайно упадет (Flaky Test).
- **Паттерн Eventually (Polling with Timeout):**
  - Опрос условия каждые 5–10 мс.
  - Мгновенное завершение, как только условие выполнено (Fast Path).
  - Жесткий предельный таймаут (Fail Fast).

## Решение по шагам

1. Напишите хелпер `assertEventually`.
2. Запустите асинхронное обновление состояния.
3. Проверьте наступление условия через цикл опроса.
4. Убедитесь в быстром прохождении теста.

## Код решения

**`eventually_test.go`**

```go
package main

import (
	"sync"
	"testing"
	"time"
)

// assertEventually опрашивает условие с интервалом tick до истечения timeout
func assertEventually(t *testing.T, condition func() bool, timeout, tick time.Duration) {
	t.Helper()
	deadline := time.Now().Add(timeout)
	for time.Now().Before(deadline) {
		if condition() {
			return // Условие успешно выполнено!
		}
		time.Sleep(tick)
	}
	t.Fatalf("Условие не было удовлетворено за отведенный таймаут %v", timeout)
}

func TestAsyncOperationWithEventually(t *testing.T) {
	var mu sync.Mutex
	ready := false

	// Асинхронная операция завершится через 15 мс
	go func() {
		time.Sleep(15 * time.Millisecond)
		mu.Lock()
		ready = true
		mu.Unlock()
	}()

	start := time.Now()

	// Опрашиваем готовность каждые 5 мс с лимитом 500 мс
	assertEventually(t, func() bool {
		mu.Lock()
		defer mu.Unlock()
		return ready
	}, 500*time.Millisecond, 5*time.Millisecond)

	elapsed := time.Since(start)
	t.Logf("Тест завершился мгновенно по факту готовности за %v", elapsed)
}
```

ℹ️ Паттерн assertEventually для асинхронных проверок

**`Терминал`**

```bash
go test -v eventually_test.go
# Вывод:
# === RUN   TestAsyncOperationWithEventually
#     eventually_test.go:44: Тест завершился мгновенно по факту готовности за 16.2ms
# --- PASS: TestAsyncOperationWithEventually (0.02s)
# PASS
```

## Под капотом

Тест выполнился ровно за 16 мс вместо ожидания секунды, сэкономив 984 мс процессорного времени CI-раннера.

## Подводные камни

Забывать защищать проверяемую переменную мьютексом: опрос состояния из тестовой горутины при параллельной записи приведет к Data Race под флагом `-race`.

## На собеседовании

**Вопрос с собеседования:** «Какая популярная библиотека в Go реализует паттерн Eventually?»
**Ответ:** Пакет `github.com/stretchr/testify/assert` метод `assert.Eventually(t, condition, timeout, tick)`, а также BDD-фреймворк `onsi/gomega` метод `Eventually(actual).Should(Equal(expected))`.
