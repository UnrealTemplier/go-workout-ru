# Фаззинг парсера длительности: функция ParseDuration и фазз-тест FuzzParseDuration

## Условие

Напиши функцию `ParseDuration(s string) (int, error)`, которая парсит строки вида "10s", "5m". Создай Fuzz-тест: `func FuzzParseDuration(f *testing.F)`.

## Теория

Тестирование парсинга временных интервалов:
- Строка длительности состоит из числа и единицы измерения: `"10s"`, `"5m"`, `"2h"`, `"500ms"`.
- Типичные ошибки парсеров:
  1. Паника при обращении к последнему символу на пустой строке `s[len-1]`.
  2. Ошибки при переполнении `int` на огромных числах `"9999999999999999999s"`.
  3. Отрицательные значения `"-10s"`.
- Фаззинг верифицирует: функция возвращает ошибку или корректные секунды, никогда не падая в `panic`.

## Решение по шагам

1. Напишите функцию `ParseSimpleDuration(s string) (int, error)`.
2. Создайте фазз-тест `FuzzParseDuration`.
3. Добавьте валидные и невалидные семена.
4. Запустите фаззинг.

## Код решения

**`duration_parser.go`**

```go
package main

import (
	"errors"
	"strconv"
	"strings"
)

func ParseSimpleDuration(s string) (int, error) {
	s = strings.TrimSpace(s)
	if len(s) < 2 {
		return 0, errors.New("слишком короткая строка")
	}

	unit := s[len(s)-1:]
	numStr := s[:len(s)-1]

	val, err := strconv.Atoi(numStr)
	if err != nil {
		return 0, err
	}
	if val < 0 {
		return 0, errors.New("отрицательная длительность недопустима")
	}

	switch unit {
	case "s":
		return val, nil
	case "m":
		return val * 60, nil
	case "h":
		return val * 3600, nil
	default:
		return 0, errors.New("неизвестная единица измерения")
	}
}
```

ℹ️ Безопасный парсер секунд, минут и часов

**`duration_parser_fuzz_test.go`**

```go
package main

import "testing"

func FuzzParseDuration(f *testing.F) {
	f.Add("10s")
	f.Add("5m")
	f.Add("2h")
	f.Add("invalid")
	f.Add("")
	f.Add("-1s")

	f.Fuzz(func(t *testing.T, input string) {
		sec, err := ParseSimpleDuration(input)
		if err == nil {
			if sec < 0 {
				t.Fatalf("Инвариант: отрицательные секунды при err == nil: %d", sec)
			}
		}
	})
}
```

ℹ️ Фазз-тест парсера длительности

## Под капотом

Проверка `if len(s) < 2` защищает от сбоя при индексации `s[:len(s)-1]`, гарантируя устойчивость парсера к пустым и односимвольным строкам.

## Подводные камни

Использовать срез байт `s[len(s)-1:]` без проверки валидности UTF-8: если последний символ мультибайтовый, срез возьмет только последний байт, что приведет к битому символу.

## На собеседовании

**Вопрос с собеседования:** «Какую максимальную длительность может представить стандартный time.Duration в Go?»
**Ответ:** Тип `time.Duration` представляет собой `int64` наносекунд. Максимальное значение — около 290 лет (`math.MaxInt64` наносекунд, или \(\approx 292\) года).
