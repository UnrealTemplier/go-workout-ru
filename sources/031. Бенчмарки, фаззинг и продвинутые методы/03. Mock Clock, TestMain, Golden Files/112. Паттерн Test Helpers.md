# Паттерн Test Helpers: вызов t.Helper() и корректная локализация номеров строк сбоя

## Условие

Используйте паттерн "Test Helpers" — вынесите общую setup-логику в функцию с `t.Helper()`, чтобы ошибки указывали на вызывающий тест, а не на сам хелпер.

## Теория

Зачем нужна директива `t.Helper()`:
- При выносе проверок в вспомогательную функцию (например `assertStringEquals(t, actual, expected)`):
  - Без `t.Helper()`: отчет об ошибке `t.Fatalf` укажет на строчку внутри самой вспомогательной функции. Если хелпер вызывается из 30 мест, невозможно понять, какой именно вызов упал!
  - С вызовом `t.Helper()`: рантайм Go исключает текущий фрейм стека и указывает на **точный номер строки в теле теста**, откуда был вызван хелпер.

## Решение по шагам

1. Напишите функцию-хелпер с вызовом `t.Helper()`.
2. Вызовите хелпер из нескольких тестов.
3. Убедитесь в чистоте отчета об ошибках.

## Код решения

**`test_helpers.go`**

```go
package main

import (
	"strings"
	"testing"
)

// AssertContainsSubstring проверяет наличие подстроки с корректным позиционированием стека
func AssertContainsSubstring(t *testing.T, fullText, sub string) {
	// ОБЯЗАТЕЛЬНЫЙ МАРКЕР ХЕЛПЕРА:
	t.Helper()

	if !strings.Contains(fullText, sub) {
		t.Fatalf("Текст не содержит ожидаемую подстроку!\nFull: %q\nSub:  %q",
			fullText, sub)
	}
}

func AssertNoError(t *testing.T, err error) {
	t.Helper()
	if err != nil {
		t.Fatalf("Неожиданная ошибка: %v", err)
	}
}
```

ℹ️ Тестовые хелперы с вызовом t.Helper()

**`helpers_usage_test.go`**

```go
package main

import "testing"

func TestDemonstrateHelperStack(t *testing.T) {
	logMessage := "2026-09-03 [INFO] Service started successfully on port 8080"

	// При ошибке стектрейс укажет ровно на строку 9 или 10 этого файла!
	AssertContainsSubstring(t, logMessage, "[INFO]")
	AssertContainsSubstring(t, logMessage, "port 8080")
	AssertNoError(t, nil)
}
```

ℹ️ Использование хелперов в тестовом сценарии

**`Терминал`**

```bash
go test -v helpers_usage_test.go test_helpers.go
# Вывод:
# === RUN   TestDemonstrateHelperStack
# --- PASS: TestDemonstrateHelperStack (0.00s)
# PASS
```

## Под капотом

Метод `t.Helper()` добавляет адрес Program Counter функции во внутренний список `testing.common.helperPCs`. При формировании лога раннер обходит стек вверх до первой функции, не входящей в этот список.

## Подводные камни

Забывать `t.Helper()` во вложенных хелперах: если хелпер `A` вызывает хелпер `B`, директива `t.Helper()` обязана быть вызвана в обоих!

## На собеседовании

**Вопрос с собеседования:** «Можно ли вызывать t.Helper() внутри анонимных функций или замыканий?»
**Ответ:** ДА, абсолютно допустимо. Если замыкание используется как повторяющийся ассерт внутри теста, вызов `t.Helper()` в первой строке замыкания скроет его собственный фрейм и укажет на строку создания замыкания.
