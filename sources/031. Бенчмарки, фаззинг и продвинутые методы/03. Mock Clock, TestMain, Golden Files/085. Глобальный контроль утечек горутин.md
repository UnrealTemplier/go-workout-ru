# Глобальный контроль утечек горутин: библиотека go.uber.org/goleak и VerifyNone

## Условие

Используйте `goleak` (`go.uber.org/goleak`) для обнаружения утечек горутин в тестах.

## Теория

Библиотека `go.uber.org/goleak`:
- Разработана инженерами Uber для защиты микросервисов от накопления зависших горутин.
- `defer goleak.VerifyNone(t)` сканирует стек горутин в конце теста.
- Игнорирует системные горутины рантайма (GC worker, signal handler, netpoller).
- Если найдена пользовательская зависшая горутина — тест падает с распечаткой полного стек-трейса строки создания горутины!

## Решение по шагам

1. Напишите тест функции с отменяемым контекстом.
2. Добавьте `defer goleak.VerifyNone(t)`.
3. Убедитесь в прохождении теста при корректном завершении воркера.

## Код решения

**`goleak_demo_test.go`**

```go
package main

import (
	"context"
	"testing"
	"time"

	"go.uber.org/goleak"
)

func SafeWorkerWithCancel(ctx context.Context) {
	ch := make(chan int)
	go func() {
		select {
		case <-ch:
		case <-ctx.Done():
			return // Корректно выходим из горутины!
		}
	}()
}

func TestWorkerNoLeaksUberGoleak(t *testing.T) {
	// Детектор утечек от Uber
	defer goleak.VerifyNone(t)

	ctx, cancel := context.WithCancel(context.Background())
	SafeWorkerWithCancel(ctx)

	// Отменяем контекст
	cancel()
	time.Sleep(10 * time.Millisecond) // Время на завершение
}
```

ℹ️ Проверка отсутствия утечек горутин с goleak

**`Терминал`**

```bash
# Установка библиотеки Uber:
go get go.uber.org/goleak

go test -v goleak_demo_test.go
# Вывод:

# --- PASS: TestWorkerNoLeaksUberGoleak (0.01s)
# PASS
```

## Под капотом

`goleak` делает снимок всех горутин через `runtime.Stack`, парсит заголовки пакетов и сопоставляет дельту горутин до и после выполнения теста.

## Подводные камни

Забывать отменять контекст `cancel()`: если контекст не отменен, горутина останется в рантайме и `goleak` по праву завалит тест.

## На собеседовании

**Вопрос с собеседования:** «Как с помощью goleak защитить сразу ВСЕ тесты пакета без добавления defer в каждую функцию?»
**Ответ:** Объявить функцию `TestMain(m *testing.M)` и вызвать `goleak.VerifyTestMain(m)`. Библиотека проверит отсутствие утечек горутин глобально после завершения всех тестов пакета.
