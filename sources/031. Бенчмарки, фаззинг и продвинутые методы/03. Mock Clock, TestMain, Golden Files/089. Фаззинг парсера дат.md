# Фаззинг парсера дат: валидация формата YYYY-MM-DD и защита от некорректных календарей

## Условие

Напишите fuzz-тест для функции `ParseDate(s string) (time.Time, error)`, которая принимает строку в формате `YYYY-MM-DD`. Запустите `go test -fuzz=FuzzParseDate`.

## Теория

Календарные ловушки при парсинге дат:
- Формат `YYYY-MM-DD` содержит скрытые краевые случаи:
  1. Високосные годы (29 февраля валидно в 2024 и 2028 годах, но невалидно в 2026 и 2100 годах).
  2. Несуществующие даты (31 апреля, 00 месяц, отрицательные года).
  3. Экстремальные года `99999-01-01`.
- Фаззер проверяет устойчивость функции `time.Parse("2006-01-02", s)` к любым аномальным строкам.

## Решение по шагам

1. Напишите `ParseISODate(s string) (time.Time, error)`.
2. Создайте фазз-тест `FuzzParseDate`.
3. Добавьте валидные даты и краевые случаи (29 февраля).
4. Запустите фаззинг.

## Код решения

**`date_parser.go`**

```go
package main

import (
	"time"
)

// ParseISODate парсит дату строго в формате YYYY-MM-DD
func ParseISODate(s string) (time.Time, error) {
	return time.Parse("2006-01-02", s)
}
```

ℹ️ Функция парсинга даты по стандарту ISO

**`date_parser_fuzz_test.go`**

```go
package main

import (
	"testing"
)

func FuzzParseDate(f *testing.F) {
	// Добавляем начальные семена
	f.Add("2026-09-03")
	f.Add("2024-02-29") // Високосный год
	f.Add("2026-02-29") // Невисокосный год (ошибка)
	f.Add("invalid-date")
	f.Add("0000-00-00")

	f.Fuzz(func(t *testing.T, dateStr string) {
		tm, err := ParseISODate(dateStr)
		if err == nil {
			// Инвариант: дата обязана форматироваться обратно в ту же самую строку!
			reformatted := tm.Format("2006-01-02")
			if reformatted != dateStr {
				t.Fatalf("Рассинхронизация даты! Вход: %q, Форматировано: %q", dateStr, reformatted)
			}
		}
	})
}
```

## Под капотом

Магическая дата-шаблон в Go `2006-01-02 15:04:05` соответствует мнемоническому ряду: 1 (месяц), 2 (день), 3 (час), 4 (минута), 5 (секунда), 6 (год). Функция `time.Parse` отклоняет невалидные календарные дни.

## Подводные камни

Использовать шаблон `YYYY-MM-DD` буквально: в Go буквы YYYY не являются модификаторами формата, для года используется строго `2006`!

## На собеседовании

**Вопрос с собеседования:** «Почему в Go для форматирования времени используется дата 2 января 2006 года вместо %Y-%m-%d как в C/Python?»
**Ответ:** Это уникальное дизайнерское решение создателей Go: числовой ряд `1 2 3 4 5 6 7` (Jan 2 15:04:05 2006 MST) позволяет писать наглядные читаемые шаблоны форматирования без необходимости учить десятки спецсимволов процентов (`%Y`, `%m`, `%d`).
