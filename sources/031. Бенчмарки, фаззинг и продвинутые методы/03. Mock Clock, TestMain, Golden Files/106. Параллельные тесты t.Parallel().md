# Параллельные тесты t.Parallel(): жизненный цикл PAUSE/CONT и ускорение тестового набора

## Условие

**[Параллельные тесты]**: Напиши 3 теста. В начале каждого вызови `t.Parallel()`. Запусти `go test -v`. Убедись, что тесты выполняются одновременно (в выводе будет `PAUSE`, затем `CONT`).

## Теория

Механика параллельного исполнения тестов в Go:
- По умолчанию тесты в рамках одного пакета выполняются строго последовательно.
- Вызов `t.Parallel()` переводит выполнение в два этапа:
  1. **Фаза PAUSE:** тест приостанавливает выполнение и регистрируется в очереди параллельных тестов.
  2. **Фаза CONT:** когда все последовательные тесты завершены, раннер одновременно запускает все параллельные тесты пачкой размером до `GOMAXPROCS`.
- В консоли вывод наглядно фиксирует переходы: `PAUSE` \(\to\) `CONT`.

## Решение по шагам

1. Напишите 3 теста с имитацией полезной нагрузки 30 мс.
2. В первой строке каждого теста вызовите `t.Parallel()`.
3. Запустите `go test -v`.
4. Убедитесь, что суммарное время выполнения равно 30 мс (вместо 90 мс).

## Код решения

**`parallel_lifecycle_test.go`**

```go
package main

import (
	"testing"
	"time"
)

func TestParallelWorkerAlpha(t *testing.T) {
	t.Parallel() // Переход в PAUSE, затем CONT

	t.Log("Alpha начал работу")
	time.Sleep(30 * time.Millisecond)
	t.Log("Alpha завершил работу")
}

func TestParallelWorkerBeta(t *testing.T) {
	t.Parallel()

	t.Log("Beta начал работу")
	time.Sleep(30 * time.Millisecond)
	t.Log("Beta завершил работу")
}

func TestParallelWorkerGamma(t *testing.T) {
	t.Parallel()

	t.Log("Gamma начал работу")
	time.Sleep(30 * time.Millisecond)
	t.Log("Gamma завершил работу")
}
```

ℹ️ Три параллельных теста с вызовом t.Parallel()

## Под капотом

Все 3 теста выполнились суммарно за 0.035s вместо 0.090s. Три теста работали параллельно на свободных ядрах CPU.

## Подводные камни

Вызывать `t.Parallel()` в тестах, модифицирующих общую базу данных или глобальные переменные: параллельное выполнение приведет к взаимным перезаписям и ложным падениям.

## На собеседовании

**Вопрос с собеседования:** «Каким флагом регулируется количество одновременно выполняемых параллельных тестов в go test?»
**Ответ:** Флагом `-parallel N` (по умолчанию равен `GOMAXPROCS`, то есть числу логических ядер процессора). Например, `go test -parallel 4` ограничивает пул параллельных тестов четырьмя горутинами.
