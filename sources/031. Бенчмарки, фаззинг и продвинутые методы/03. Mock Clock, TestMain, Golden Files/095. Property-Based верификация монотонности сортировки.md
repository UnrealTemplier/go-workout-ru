# Property-Based верификация монотонности сортировки: проверка a[i] <= a[i+1] на 1000 срезах

## Условие

Сформулируйте инвариант для функции сортировки: "после сортировки каждый элемент <= следующего". Проверьте это на 1000 случайных слайсов.

## Теория

Формальное определение отсортированности массива:
- Массив \(A\) длины \(N\) отсортирован по неубыванию тогда и только тогда, когда:
  $$\forall i \in [0, N-2]: \quad A[i] \le A[i+1]$$
- Проверка этого инварианта на 1000 случайно сгенерированных срезах случайного размера с произвольным разбросом чисел гарантирует математическую корректность алгоритма сортировки.

## Решение по шагам

1. Напишите предикат `VerifySortedAscending(nums []int) bool`.
2. Запустите цикл из 1000 случайных срезов.
3. Выполните сортировку `slices.Sort`.
4. Подтвердите соблюдение инварианта монотонности.

## Код решения

**`monotonic_sort_test.go`**

```go
package main

import (
	"math/rand"
	"slices"
	"testing"
)

func VerifyMonotonicOrder(s []int) bool {
	for i := 0; i < len(s)-1; i++ {
		if s[i] > s[i+1] {
			return false // Нарушение: элемент больше следующего!
		}
	}
	return true
}

func TestMonotonicSortInvariant1000Runs(t *testing.T) {
	rand.Seed(2026)

	for run := 0; run < 1000; run++ {
		size := rand.Intn(150)
		slice := make([]int, size)
		for i := range slice {
			slice[i] = rand.Intn(10000) - 5000
		}

		slices.Sort(slice)

		if !VerifyMonotonicOrder(slice) {
			t.Fatalf("Инвариант монотонности нарушен на прогоне %d! Срез: %v", run, slice)
		}
	}
}
```

## Под капотом

Тест проверяет граничные размеры срезов: 0 элементов (пустой срез), 1 элемент (тривиально отсортирован), срез с дубликатами и отрицательными числами.

## Подводные камни

Использовать строгое неравенство `s[i] < s[i+1]`: сортировка допускает одинаковые элементы (\(a[i] == a[i+1]\)), строгое неравенство упадет на дубликатах.

## На собеседовании

**Вопрос с собеседования:** «Какова временная сложность проверки отсортированности массива?»
**Ответ:** Ровно \(O(N)\) (один линейный проход по массиву с \(N-1\) операцией сравнения).
