# Инициализация проекта gqlgen: структура каталогов, генерация кода и базовый резолвер

## Условие

Установите `gqlgen` (или `graphql-go`), инициализируйте проект. Определите схему с типом `User` (id, name, email) и запросом `users: [User!]!`. Реализуйте резолвер, возвращающий тестовые данные.

## Теория

Структура проекта на базе `gqlgen`:
- `server.go` — точка входа HTTP-сервера, монтирующая GraphQL handler и Playground.
- `graph/schema.graphqls` — исходная схема SDL.
- `graph/schema.resolvers.go` — файл бизнес-логики, куда разработчик пишет реализацию резолверов.
- `graph/generated.go` — автоматически генерируемый движок парсинга, валидации и выполнения запросов (никогда не редактируется вручную!).
- `graph/model/models_gen.go` — сгенерированные структуры Go (`type User struct`).

## Решение по шагам

1. Опишите интерфейс корневого резолвера.
2. Создайте реализацию метода `Users` с mock-данными.
3. Смоделируйте выполнение запроса.
4. Проверьте корректность сериализации JSON.

## Код решения

**`mock_users_resolver_test.go`**

```go
package main

import (
	"context"
	"fmt"
	"testing"
)

type User struct {
	ID    string `json:"id"`
	Name  string `json:"name"`
	Email string `json:"email"`
}

type QueryResolver interface {
	Users(ctx context.Context) ([]*User, error)
}

type Resolver struct {
	users []*User
}

func (r *Resolver) Users(ctx context.Context) ([]*User, error) {
	return r.users, nil
}

func TestUsersResolver(t *testing.T) {
	mockData := []*User{
		{ID: "usr_1", Name: "Алексей Иванов", Email: "alex@yandex.ru"},
		{ID: "usr_2", Name: "Дарья Петрова", Email: "daria@ozon.ru"},
	}

	r := &Resolver{users: mockData}

	users, err := r.Users(context.Background())
	if err != nil {
		t.Fatalf("Ошибка получения пользователей: %v", err)
	}

	if len(users) != 2 || users[0].Name != "Алексей Иванов" {
		t.Fatalf("Некорректный результат выборки: %+v", users)
	}

	fmt.Printf("UsersResolver успешно вернул %d пользователей из mock-хранилища!\n", len(users))
}
```

ℹ️ Базовая реализация резолвера выборки списка сущностей

**`Терминал`**

```bash
go test -v mock_users_resolver_test.go
# Вывод:
# === RUN   TestUsersResolver
# UsersResolver успешно вернул 2 пользователей из mock-хранилища!
# --- PASS: TestUsersResolver (0.00s)
# PASS
```

## Под капотом

`gqlgen` связывает резолверы со сгенерированным кодом через интерфейс `ResolverRoot`. При запуске генератор проверяет, какие методы уже реализованы в `schema.resolvers.go`, и генерирует заглушки только для новых полей.

## Подводные камни

Вручную редактировать `generated.go` или `models_gen.go`: при следующем запуске `gqlgen generate` любые ручные правки в этих файлах будут безвозвратно перезаписаны.

## На собеседовании

**Вопрос с собеседования:** «Почему в резолверах Go всегда первым аргументом передается context.Context?»
**Ответ:** Контекст несет критически важную информацию: таймауты запроса (`ctx.Done()`), данные аутентификации пользователя (JWT Claims), логгеры с correlation-id, спаны трейсинга OpenTelemetry, а также экземпляры **DataLoaders** для решения проблемы N+1.
