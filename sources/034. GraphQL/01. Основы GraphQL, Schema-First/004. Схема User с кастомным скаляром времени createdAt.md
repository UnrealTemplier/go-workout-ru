# Схема User с кастомным скаляром времени createdAt: Time! и генерация моделей в gqlgen

## Условие

Определи **GraphQL schema** для `User`: `type User { id: ID! name: String! email: String! createdAt: Time! }`. Сгенерируй код через `gqlgen generate`. Покажи, как gqlgen создаёт Go-структуры из schema.

## Теория

Маппинг типов SDL в структуры Go:
- По умолчанию стандартные скаляры маппятся:
  - `ID` \(\to\) `string`
  - `String` \(\to\) `string`
  - `Int` \(\to\) `int`
  - `Float` \(\to\) `float64`
  - `Boolean` \(\to\) `bool`
- Скаляр `Time!` мапится в стандартный пакет `time.Time`.
- Сгенерированная Go-структура в `models_gen.go` содержит json-теги и строгую типизацию:
```go
type User struct {
    ID        string    `json:"id"`
    Name      string    `json:"name"`
    Email     string    `json:"email"`
    CreatedAt time.Time `json:"createdAt"`
}
```

## Решение по шагам

1. Опишите структуру с полями схемы.
2. Используйте `time.Time` для поля `CreatedAt`.
3. Смоделируйте сериализацию структуры в JSON.
4. Проверьте соответствие формату RFC3339.

## Код решения

**`generated_model_test.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"testing"
	"time"
)

// Модель, генерируемая gqlgen из schema.graphqls
type User struct {
	ID        string    `json:"id"`
	Name      string    `json:"name"`
	Email     string    `json:"email"`
	CreatedAt time.Time `json:"createdAt"`
}

func TestGeneratedModelSerialization(t *testing.T) {
	now := time.Date(2026, 9, 3, 12, 0, 0, 0, time.UTC)
	u := User{
		ID:        "usr_42",
		Name:      "Анна Сергеева",
		Email:     "anna@ozon.ru",
		CreatedAt: now,
	}

	bytes, err := json.Marshal(u)
	if err != nil {
		t.Fatalf("Ошибка сериализации: %v", err)
	}

	expected := `{"id":"usr_42","name":"Анна Сергеева","email":"anna@ozon.ru","createdAt":"2026-09-03T12:00:00Z"}`
	if string(bytes) != expected {
		t.Fatalf("Несовпадение JSON: got %s, want %s", string(bytes), expected)
	}

	fmt.Println("Сгенерированная модель User успешно сериализована в канонический RFC3339 JSON!")
}
```

ℹ️ Сериализация времени в модели gqlgen в формате ISO-8601 / RFC3339

**`Терминал`**

```bash
go test -v generated_model_test.go
# Вывод:
# === RUN   TestGeneratedModelSerialization
# Сгенерированная модель User успешно сериализована в канонический RFC3339 JSON!
# --- PASS: TestGeneratedModelSerialization (0.00s)
# PASS
```

## Под капотом

Встроенный маршалер `graphql.MarshalTime` сериализует даты в строковом представлении `time.RFC3339Nano`, обеспечивая совместимость с любыми JavaScript клиентами (React, iOS, Android).

## Подводные камни

Использовать строковый тип `String` вместо `Time` для дат: клиенты теряют возможность валидировать форматы дат на этапе запроса, а сервер вынужден вручную парсить строки во всех резолверах.

## На собеседовании

**Вопрос с собеседования:** «Как в gqlgen использовать собственную доменную модель User вместо сгенерированной в models_gen.go?»
**Ответ:** В файле `gqlgen.yml` в секции `models` настраивается биндинг:
```yaml
models:
  User:
    model: github.com/my/project/internal/domain.User
```
Тогда генератор использует существующую модель и не будет дублировать структуру в `models_gen.go`.
