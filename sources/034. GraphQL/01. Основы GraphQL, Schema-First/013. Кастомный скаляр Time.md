# Кастомный скаляр Time: реализация интерфейсов MarshalGQL и UnmarshalGQL для time.Time

## Условие

Реализуйте **кастомный скаляр** `Time` (для `time.Time`), реализовав методы `MarshalGQL` и `UnmarshalGQL`. Это нужно для корректной работы с датами.

## Теория

Контракт кастомного скаляра в `gqlgen`:
- Для любого кастомного типа в Go требуются 2 метода:
  1. `MarshalGQL(w io.Writer)`: преобразует Go-значение в валидный JSON-литерал и записывает в `w`.
  2. `UnmarshalGQL(v any) error`: принимает распарсенное значение из запроса (строку, число, bool) и десериализует его в Go-тип.
- Реализация для `time.Time` гарантирует, что даты всегда передаются в строгом формате ISO 8601 / RFC 3339.

## Решение по шагам

1. Создайте пользовательский тип `CustomTime`.
2. Реализуйте метод `MarshalGQL` с экранированием кавычек.
3. Реализуйте метод `UnmarshalGQL` с парсингом `time.RFC3339`.
4. Протестируйте оба направления сериализации.

## Код решения

**`custom_time_scalar_test.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"strconv"
	"testing"
	"time"
)

type CustomTime time.Time

func (ct CustomTime) MarshalGQL(w io.Writer) {
	t := time.Time(ct)
	// Обязательно выводим кавычки для строки JSON
	_, _ = io.WriteString(w, strconv.Quote(t.Format(time.RFC3339)))
}

func (ct *CustomTime) UnmarshalGQL(v any) error {
	str, ok := v.(string)
	if !ok {
		return fmt.Errorf("ожидалась строка для скаляра Time, получено: %T", v)
	}

	parsed, err := time.Parse(time.RFC3339, str)
	if err != nil {
		return fmt.Errorf("невалидный формат даты RFC3339: %w", err)
	}

	*ct = CustomTime(parsed)
	return nil
}

func TestCustomTimeScalar(t *testing.T) {
	// 1. Тест MarshalGQL
	sample := time.Date(2026, 9, 3, 15, 30, 0, 0, time.UTC)
	ct := CustomTime(sample)

	var buf bytes.Buffer
	ct.MarshalGQL(&buf)
	expectedJSON := `"2026-09-03T15:30:00Z"`

	if buf.String() != expectedJSON {
		t.Fatalf("Ошибка маршалинга: got %s, want %s", buf.String(), expectedJSON)
	}

	// 2. Тест UnmarshalGQL
	var unmarshaled CustomTime
	err := unmarshaled.UnmarshalGQL("2026-09-03T15:30:00Z")
	if err != nil {
		t.Fatalf("Ошибка демаршалинга: %v", err)
	}

	if time.Time(unmarshaled).Year() != 2026 {
		t.Fatal("Год распарсен неверно")
	}

	fmt.Printf("Кастомный скаляр Time успешно сериализован (%s) и десериализован!\n", buf.String())
}
```

## Под капотом

Метод `MarshalGQL` пишет сырые байты напрямую в поток. Если забыть добавить кавычки `strconv.Quote`, JSON станет невалидным, так как дата будет выведена без кавычек.

## Подводные камни

Использовать парсинг без указания временной зоны: даты без указания смещения UTC будут интерпретироваться в локальной зоне сервера, вызывая смещение времени на несколько часов.

## На собеседовании

**Вопрос с собеседования:** «Зачем создавать кастомный скаляр Upload в GraphQL?»
**Ответ:** Спецификация GraphQL Multipart Request позволяет передавать бинарные файлы (картинки, документы) через `multipart/form-data`. Кастомный скаляр `Upload` мапится в `graphql.Upload` (`io.Reader` + метаданные `filename`, `contentType`), позволяя загружать файлы без base64-кодирования.
