# Field Masks через graphql.CollectFields: динамический SQL SELECT только запрошенных полей

## Условие

Используйте **field masks** (через `graphql.CollectFields`) для оптимизации запросов к БД — загружайте только те поля, которые реально запрошены клиентом.

## Теория

Оптимизация обращений к базе через Field Masks:
- Допустим, таблица `products` содержит тяжелые колонки `description_html` (10 КБ) и `specs_json` (20 КБ).
- Запрос клиента для каталога:
  `query { products { id title price } }`
- Если бэкенд выполняет `SELECT * FROM products`, база перегоняет мегабайты неиспользуемых данных по сети.
- С помощью `graphql.CollectFieldsCtx(ctx, nil)`:
  1. Сервер извлекает точный список запрошенных клиентом колонок: `["id", "title", "price"]`.
  2. Формирует SQL: `SELECT id, title, price FROM products`.
  3. Трафик сети и нагрузка на память уменьшаются в десятки раз!

## Решение по шагам

1. Создайте функцию извлечения запрошенных полей.
2. Реализуйте построитель динамического SQL SELECT.
3. Проверьте исключение тяжелых полей.
4. Протестируйте итоговый SQL-запрос.

## Код решения

**`field_mask_sql_test.go`**

```go
package main

import (
	"fmt"
	"strings"
	"testing"
)

// Белый список колонок для защиты от SQL-инъекций
var allowedColumns = map[string]string{
	"id":          "id",
	"title":       "title",
	"price":       "price",
	"description": "description_html",
	"specs":       "specs_json",
}

func BuildOptimizedSQL(tableName string, requestedGQLFields []string) string {
	selectedCols := make([]string, 0, len(requestedGQLFields))
	for _, f := range requestedGQLFields {
		if col, ok := allowedColumns[f]; ok {
			selectedCols = append(selectedCols, col)
		}
	}

	if len(selectedCols) == 0 {
		selectedCols = []string{"id"} // fallback
	}

	return fmt.Sprintf("SELECT %s FROM %s", strings.Join(selectedCols, ", "), tableName)
}

func TestFieldMaskSQL(t *testing.T) {
	// Клиент запросил только id, title и price
	requestedFields := []string{"id", "title", "price"}

	query := BuildOptimizedSQL("products", requestedFields)
	expected := "SELECT id, title, price FROM products"

	if query != expected {
		t.Fatalf("Некорректный SQL: got '%s', want '%s'", query, expected)
	}

	fmt.Printf("Динамический Field Mask успешно сгенерировал SQL:\n  %s\n", query)
	fmt.Println("Тяжелые колонки description_html и specs_json исключены из выборки!")
}
```

## Под капотом

Обязательно используйте белый список соответствия полей GraphQL колонкам БД (`allowedColumns`), чтобы исключить возможность передачи зловредных выражений в тело SQL-запроса.

## Подводные камни

Вставлять имена полей из GraphQL напрямую в SQL без белого списка: уязвимость SQL Injection через передачу алиасов в запросе.

## На собеседовании

**Вопрос с собеседования:** «Как в ORM (например GORM или Ent) передавать field masks из GraphQL?»
**Ответ:** В GORM используют метод `.Select(columns...)`:
```go
fields := graphql.CollectAllFields(ctx)
db.Select(fields).Find(&users)
```
Это предотвращает чтение неиспользуемых колонок на уровне базы данных.
