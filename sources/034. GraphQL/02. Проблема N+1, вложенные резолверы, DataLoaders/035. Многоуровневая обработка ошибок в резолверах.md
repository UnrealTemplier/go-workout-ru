# Многоуровневая обработка ошибок в резолверах: форматирование gqlerror.Error с метаданными

## Условие

Добавьте обработку ошибок в резолверах: возвращайте `gqlerror.Error` с кастомными кодами ошибок.

## Теория

Формат ошибок GraphQL по спецификации RFC:
```json
{
  "errors": [
    {
      "message": "недостаточно средств на счете",
      "locations": [{ "line": 2, "column": 3 }],
      "path": ["transferMoney"],
      "extensions": {
        "code": "INSUFFICIENT_FUNDS",
        "current_balance": 150.0,
        "required_amount": 500.0,
        "timestamp": "2026-09-03T21:00:00Z"
      }
    }
  ],
  "data": null
}
```
- Поле `extensions` — единственный легитимный способ передавать типизированные метаданные ошибок клиентам.

## Решение по шагам

1. Создайте кастомный конструктор GraphQL ошибок.
2. Добавьте метаданные в словарь `Extensions`.
3. Смоделируйте ошибку недостатка баланса в резолвере.
4. Проверьте корректность сериализации структуры ошибки.

## Код решения

**`custom_gql_error_test.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
	"testing"
	"time"

	"github.com/vektah/gqlparser/v2/gqlerror"
)

func NewBusinessError(msg, code string, extra map[string]any) *gqlerror.Error {
	ext := map[string]any{
		"code":      code,
		"timestamp": time.Now().UTC().Format(time.RFC3339),
	}
	for k, v := range extra {
		ext[k] = v
	}

	return &gqlerror.Error{
		Message:    msg,
		Extensions: ext,
	}
}

func TestCustomGqlError(t *testing.T) {
	err := NewBusinessError(
		"недостаточно средств на счете",
		"INSUFFICIENT_FUNDS",
		map[string]any{
			"current_balance": 150.0,
			"required_amount": 500.0,
		},
	)

	b, _ := json.MarshalIndent(err, "", "  ")

	if err.Extensions["code"] != "INSUFFICIENT_FUNDS" {
		t.Fatalf("Некорректный код: %v", err.Extensions)
	}

	fmt.Printf("Кастомная GraphQL ошибка успешно сериализована:\n%s\n", string(b))
}
```

## Под капотом

Пакет `github.com/vektah/gqlparser/v2/gqlerror` предоставляет тип `List`, позволяющий возвращать сразу несколько ошибок из одного метода резолвера.

## Подводные камни

Помещать стек-трейсы паник в `message` ошибки в проде: пользователи увидят внутренние пути к файлам и логику сервера, что является уязвимостью Information Disclosure.

## На собеседовании

**Вопрос с собеседования:** «Как в GraphQL реализовать локализацию (i18n) сообщений об ошибках?»
**Ответ:** Сервер возвращает стабильный машиночитаемый код `extensions.code: "INSUFFICIENT_FUNDS"` и параметры подстановки (`extensions.params: { min: 500 }`). Клиентское приложение (React/Flutter) сопоставляет код с файлом локализации пользователя (`ru.json`, `en.json`) и отображает текст на языке устройства клиента.
