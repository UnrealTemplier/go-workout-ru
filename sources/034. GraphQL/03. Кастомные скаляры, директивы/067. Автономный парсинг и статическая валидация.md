# Автономный парсинг и статическая валидация запросов через gqlparser без запуска сервера

## Условие

Используйте `gqlparser` для парсинга и валидации GraphQL-запросов вручную (без запуска сервера).

## Теория

Автономная статическая валидация через `gqlparser`:
- Библиотека `github.com/vektah/gqlparser/v2`:
  - Содержит эталонный лексер, парсер и валидатор GraphQL на Go.
  - Позволяет:
    1. Загрузить схему из строки/файла (`gqlparser.LoadSchema`).
    2. Распарсить документ запроса в AST (`parser.ParseQuery`).
    3. Проверить запрос на соответствие схеме (`validator.Validate`).
- Применяется в CI/CD скриптах, линтерах и юнит-тестах без поднятия HTTP портов.

## Решение по шагам

1. Загрузите базовую схему через `gqlparser.LoadSchema`.
2. Распарсите тестовый документ запроса.
3. Вызовите валидатор `validator.Validate`.
4. Протестируйте выявление несуществующих полей в запросе.

## Код решения

**`standalone_validator_test.go`**

```go
package main

import (
	"fmt"
	"testing"

	"github.com/vektah/gqlparser/v2"
	"github.com/vektah/gqlparser/v2/ast"
	"github.com/vektah/gqlparser/v2/parser"
	"github.com/vektah/gqlparser/v2/validator"
)

func TestStandaloneGraphQLValidation(t *testing.T) {
	sdl := `
		type User {
			id: ID!
			name: String!
		}
		type Query {
			user(id: ID!): User
		}
	`

	schema, err := gqlparser.LoadSchema(&ast.Source{Name: "schema.graphqls", Input: sdl})
	if err != nil {
		t.Fatalf("Ошибка схемы: %v", err)
	}

	// 1. Валидный запрос
	validQuery := "query { user(id: \"10\") { id name } }"
	docValid, errParse := parser.ParseQuery(&ast.Source{Input: validQuery})
	if errParse != nil {
		t.Fatalf("Ошибка парсинга: %v", errParse)
	}

	errsValid := validator.Validate(schema, docValid)
	if len(errsValid) != 0 {
		t.Fatalf("Валидный запрос забракован: %v", errsValid)
	}
	fmt.Println("1. Валидный запрос успешно прошел проверку схемы!")

	// 2. Невалидный запрос (несуществующее поле 'unknownField')
	invalidQuery := "query { user(id: \"10\") { id unknownField } }"
	docInvalid, _ := parser.ParseQuery(&ast.Source{Input: invalidQuery})
	errsInvalid := validator.Validate(schema, docInvalid)

	if len(errsInvalid) == 0 {
		t.Fatal("Ожидалась ошибка валидации несуществующего поля")
	}

	fmt.Printf("2. Статический валидатор корректно отловил ошибку:\n   %s\n", errsInvalid[0].Message)
}
```

ℹ️ Статическая валидация GraphQL документов через gqlparser

## Под капотом

`gqlparser` выполняет более 30 правил валидации по спецификации GraphQL (проверка типов аргументов, отсутствие циклов во фрагментах, непустые наборы полей объектов).

## Подводные камни

Использовать медленные регулярные выражения для валидации запросов вместо `gqlparser`: парсер строит строгое синтаксическое дерево AST, находя ошибки, невидимые регуляркам.

## На собеседовании

**Вопрос с собеседования:** «Зачем выполнять AST валидацию до вызова резолверов?»
**Ответ:** Фаза валидации отсекает 100% синтаксических ошибок, опечаток в полях и несовпадений типов за доли микросекунды в оперативной памяти. Это гарантирует, что резолверы и база данных никогда не будут нагружаться заведомо некорректными запросами.
