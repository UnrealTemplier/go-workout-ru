# Интеграция с GraphQL Code Generator (TypeScript): сквозная типобезопасность от БД до фронтенда

## Условие

Используйте **GraphQL Code Generator** на фронтенде (TypeScript) для генерации типобезопасных клиентов из вашей схемы.

## Теория

Сквозная типобезопасность между Go и TypeScript:
- Инструмент `@graphql-codegen/cli`:
  1. Читает `schema.graphqls`, опубликованную Go-бэкендом.
  2. Сканирует `.graphql` файлы на фронтенде.
  3. Генерирует 100% строгие TypeScript интерфейсы и кастомные React-хуки (`useGetUsersQuery`).
- Преимущества:
  - Любое изменение поля в схеме Go немедленно подсвечивается ошибкой компилятора TypeScript на фронтенде.
  - Нулевая рассинхронизация типов между командами бэкенда и фронтенда.

## Решение по шагам

1. Опишите файл конфигурации `codegen.yml`.
2. Опишите фронтенд-запрос `GetUsers.graphql`.
3. Смоделируйте сгенерированные TypeScript интерфейсы.
4. Проверьте строгую типизацию полей.

## Код решения

**`codegen.yml`**

```yaml
schema: "http://localhost:8080/query"
documents: "src/**/*.graphql"
generates:
  src/generated/graphql.ts:
    plugins:
      - "typescript"
      - "typescript-operations"
      - "typescript-react-apollo"
    config:
      skipTypename: false
      withHooks: true
```

ℹ️ Конфигурация GraphQL Code Generator для TypeScript React

**`generated_frontend_types.ts`**

```typescript
// Автоматически сгенерировано GraphQL Code Generator из Go схемы
export type Maybe<T> = T | null;

export interface User {
  __typename?: 'User';
  id: string;
  name: string;
  email: string;
}

export interface GetUsersQuery {
  __typename?: 'Query';
  users: Array<User>;
}

// Типобезопасный результат хука
export function renderUserProfile(user: User): string {
  return `Пользователь: ${user.name} (${user.email})`;
}
```

## Под капотом

`graphql-codegen` строит соответствие AST схемы GraphQL и AST TypeScript компилятора, генерируя строгие типы для каждого отдельного поля.

## Подводные камни

Использовать тип `any` в TypeScript коде: это уничтожает все преимущества статической типизации GraphQL схемы.

## На собеседовании

**Вопрос с собеседования:** «Как предотвратить поставку неиспользуемых полей схемы в итоговый бандл фронтенда?»
**Ответ:** Использовать фрагменты GraphQL (`Fragment Colocation` в Relay/Apollo): каждый React-компонент объявляет фрагмент ровно с теми полями, которые ему нужны (`fragment UserCard on User { name avatarUrl }`). Генератор типов компилирует точный тип для каждого компонента, а бандлер выполняет dead-code elimination.
