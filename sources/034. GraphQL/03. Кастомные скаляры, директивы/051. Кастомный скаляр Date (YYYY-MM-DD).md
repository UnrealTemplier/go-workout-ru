# Кастомный скаляр Date (YYYY-MM-DD): валидация формата даты без времени и привязка в gqlgen.yml

## Условие

**Кастомные скаляры (Scalars)**: По умолчанию GraphQL поддерживает только базовые типы (String, Int, Float, Boolean, ID). Добавьте в схему кастомный скаляр `scalar Date`. Настройте `gqlgen` так, чтобы он связывал этот скаляр со стандартным Go-типом `time.Time`. Напишите методы маршалинга и демаршалинга для преобразования строки формата `YYYY-MM-DD` в `time.Time` и обратно.

## Теория

Скаляр Date (календарная дата без времени):
- В отличие от `DateTime`, скаляр `Date` не содержит часов, минут и таймзон:
  - Пример: день рождения пользователя (`"1995-04-12"`), дата поставки товара.
- Методы сериализации:
  - Шаблон форматирования: `"2006-01-02"`.
  - `MarshalGQL`: сериализует дату как `"YYYY-MM-DD"`.
  - `UnmarshalGQL`: проверяет точное соответствие формату из 10 символов.

## Решение по шагам

1. Создайте тип `CustomDate time.Time`.
2. Реализуйте метод `MarshalGQL` с форматом `2006-01-02`.
3. Реализуйте метод `UnmarshalGQL` с валидацией строки.
4. Протестируйте отсечение недопустимых форматов.

## Код решения

**`date_only_scalar_test.go`**

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"strconv"
	"testing"
	"time"
)

const DateFormat = "2006-01-02"

type Date time.Time

func (d Date) MarshalGQL(w io.Writer) {
	t := time.Time(d)
	_, _ = io.WriteString(w, strconv.Quote(t.Format(DateFormat)))
}

func (d *Date) UnmarshalGQL(v any) error {
	str, ok := v.(string)
	if !ok {
		return fmt.Errorf("ожидалась строка для скаляра Date, получено: %T", v)
	}

	parsed, err := time.Parse(DateFormat, str)
	if err != nil {
		return fmt.Errorf("невалидный формат даты (ожидается YYYY-MM-DD): %w", err)
	}

	*d = Date(parsed)
	return nil
}

func TestDateOnlyScalar(t *testing.T) {
	// 1. Маршалинг
	birthDate := Date(time.Date(1995, 4, 12, 0, 0, 0, 0, time.UTC))
	var buf bytes.Buffer
	birthDate.MarshalGQL(&buf)

	if buf.String() != `"1995-04-12"` {
		t.Fatalf("Ошибка маршалинга: %s", buf.String())
	}

	// 2. Анмаршалинг валидной даты
	var d Date
	if err := d.UnmarshalGQL("1995-04-12"); err != nil {
		t.Fatalf("Ошибка анмаршалинга: %v", err)
	}

	// 3. Отклонение даты с часами/минутами
	if err := d.UnmarshalGQL("1995-04-12T10:00:00Z"); err == nil {
		t.Fatal("Ожидался отказ для формата со временем")
	}

	fmt.Printf("Кастомный скаляр Date (YYYY-MM-DD) успешно валидирован: %s\n", buf.String())
}
```

## Под капотом

В `gqlgen.yml` биндинг скаляра настраивается в секции `models`:
```yaml
models:
  Date:
    model: my-project/graph/model.Date
```
Генератор напрямую свяжет сгенерированные резолверы с методами типа `Date`.

## Подводные камни

Использовать формат `time.DateOnly` в версиях Go старше 1.20: константа `time.DateOnly = "2006-01-02"` была добавлена только в Go 1.20.

## На собеседовании

**Вопрос с собеседования:** «Почему для дней рождения нельзя использовать timestamp со временем?»
**Ответ:** Из-за часовых поясов! Если человек родился в 00:00 в Москве (+03:00), то при переводе в UTC это будет 21:00 предыдущего дня. Клиент в Лондоне отобразит день рождения на день раньше! Календарные даты (день рождения, дата заезда в отель) не имеют таймзоны и должны передаваться строго как `YYYY-MM-DD`.
