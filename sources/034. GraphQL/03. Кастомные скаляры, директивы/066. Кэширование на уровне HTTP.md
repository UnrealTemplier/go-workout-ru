# Кэширование на уровне HTTP: заголовки Cache-Control max-age для Query и no-store для Mutations

## Условие

Настройте **кэширование на уровне HTTP** через `Cache-Control` заголовки для query (но не для mutations!).

## Теория

Стратегия HTTP-кэширования в GraphQL:
- По умолчанию GraphQL использует POST запросы, которые промежуточные CDN (Cloudflare, Fastly, Nginx) **не кэшируют**.
- Для включения кэширования:
  1. Запросы Query выполняются через `GET /query?query=...` (или APQ GET запросы по хэшу).
  2. Сервер рассчитывает минимальный TTL кэша для запрошенных полей.
  3. Для Query выставляется заголовок: `Cache-Control: public, max-age=60`.
  4. Для Mutation ВСЕГДА выставляется: `Cache-Control: no-store, no-cache, must-revalidate`.

## Решение по шагам

1. Создайте функцию установки заголовков кэширования.
2. Проверьте установку `max-age` для операций чтения.
3. Проверьте установку `no-store` для мутаций.
4. Протестируйте работу HTTP middleware.

## Код решения

**`cache_control_test.go`**

```go
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
	"testing"
)

type OperationType string

const (
	OpQuery    OperationType = "query"
	OpMutation OperationType = "mutation"
)

func ApplyCacheControl(w http.ResponseWriter, opType OperationType, ttlSeconds int) {
	if opType == OpMutation {
		// Мутации никогда не кэшируются!
		w.Header().Set("Cache-Control", "no-store, no-cache, must-revalidate")
		return
	}

	// Запросы чтения могут кэшироваться на CDN
	w.Header().Set("Cache-Control", fmt.Sprintf("public, max-age=%d", ttlSeconds))
}

func TestCacheControlHeaders(t *testing.T) {
	// 1. Тест Query
	recQuery := httptest.NewRecorder()
	ApplyCacheControl(recQuery, OpQuery, 300)
	if recQuery.Header().Get("Cache-Control") != "public, max-age=300" {
		t.Fatalf("Некорректный кэш для Query: %s", recQuery.Header().Get("Cache-Control"))
	}

	// 2. Тест Mutation
	recMutation := httptest.NewRecorder()
	ApplyCacheControl(recMutation, OpMutation, 300)
	if recMutation.Header().Get("Cache-Control") != "no-store, no-cache, must-revalidate" {
		t.Fatalf("Мутация не должна кэшироваться: %s", recMutation.Header().Get("Cache-Control"))
	}

	fmt.Println("HTTP Cache-Control заголовки успешно настроены:")
	fmt.Printf("  • Query:    %s\n", recQuery.Header().Get("Cache-Control"))
	fmt.Printf("  • Mutation: %s\n", recMutation.Header().Get("Cache-Control"))
}
```

## Под капотом

Директива `@cacheControl(maxAge: 60)` в схеме позволяет динамически вычислять наименьший общий знаменатель времени жизни (Lowest Common Max-Age) среди всех запрошенных клиентом полей.

## Подводные камни

Кэшировать приватные данные пользователя (`Cache-Control: public`): публичный CDN закэширует личный кабинет пользователя A и отдаст его пользователю B! Приватные запросы требуют `Cache-Control: private`.

## На собеседовании

**Вопрос с собеседования:** «Как кэшировать GraphQL запросы на CDN Cloudflare, если они отправляются методом POST?»
**Ответ:** Напрямую POST запросы не кэшируются. Используют **Automatic Persisted Queries (APQ) поверх HTTP GET**: клиент отправляет `GET /query?extensions={"persistedQuery":{"sha256Hash":"..."}}`. Поскольку это идемпотентный GET запрос со стабильным URL, Cloudflare кэширует его на Edge-серверах как обычный статический ресурс.
