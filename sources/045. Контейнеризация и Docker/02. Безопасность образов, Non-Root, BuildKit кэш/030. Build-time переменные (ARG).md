# Build-time переменные (ARG) и инъекция версии через ldflags

## Условие

**Build-time variables**: Передавайте Git commit hash и версию через `--build-arg` и `ldflags`: `RUN go build -ldflags="-X main.version=${VERSION} -X main.commit=${COMMIT}"`.

## Теория

В продакшн-эксплуатации критически важно точно знать, какая версия кода, коммит и дата сборки исполняются в запущенном контейнере.

Механизм внедрения метаданных сборки:
1. В `Dockerfile` объявляются аргументы сборки:
   `ARG VERSION=dev`
   `ARG COMMIT=none`
   `ARG BUILD_TIME=unknown`
2. Линковщик Go (`go tool link`) поддерживает флаг `-X <package>.<variable>=<value>`, который динамически перезаписывает строковые переменные пакета прямо в бинарном коде во время сборки без изменения исходных файлов.
3. Команда компиляции:
   `RUN go build -ldflags="-X main.Version=${VERSION} -X main.Commit=${COMMIT} -X main.BuildTime=${BUILD_TIME}"`

При запуске `docker build --build-arg VERSION=v1.2.3 --build-arg COMMIT=$(git rev-parse --short HEAD) ...` значения из Git автоматически внедряются в скомпилированный бинарник.

## Решение по шагам

1. Объявите строковые переменные `Version`, `Commit`, `BuildTime` в пакете `main`.
2. Создайте эндпоинт `/version`, возвращающий эти данные в формате JSON.
3. В `Dockerfile` настройте директивы `ARG` и проброс через `-ldflags`.
4. Соберите образ с передачей параметров `--build-arg`.
5. Убедитесь, что приложение корректно сообщает свою версию.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"log"
	"net/http"
)

// Переменные, перезаписываемые компилятором через -ldflags -X
var (
	Version   = "dev"
	Commit    = "none"
	BuildTime = "unknown"
)

type BuildInfo struct {
	Version   string `json:"version"`
	Commit    string `json:"commit"`
	BuildTime string `json:"build_time"`
}

func main() {
	http.HandleFunc("/version", func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		_ = json.NewEncoder(w).Encode(BuildInfo{
			Version:   Version,
			Commit:    Commit,
			BuildTime: BuildTime,
		})
	})

	log.Printf("Starting application version: %s (commit: %s)\n", Version, Commit)
	_ = http.ListenAndServe(":8080", nil)
}
```

ℹ️ Сервис с динамически внедряемыми метаданными сборки

**`Dockerfile`**

```dockerfile
FROM golang:1.24-alpine AS builder

# Аргументы времени сборки
ARG VERSION=dev
ARG COMMIT=none
ARG BUILD_TIME=unknown

WORKDIR /src
COPY main.go .

# Инъекция значений аргументов в переменные пакета main
RUN CGO_ENABLED=0 GOOS=linux go build \
    -ldflags="-w -s \
      -X 'main.Version=${VERSION}' \
      -X 'main.Commit=${COMMIT}' \
      -X 'main.BuildTime=${BUILD_TIME}'" \
    -o /bin/app main.go

FROM scratch
COPY --from=builder /bin/app /bin/app
EXPOSE 8080
ENTRYPOINT ["/bin/app"]
```

ℹ️ Dockerfile с поддержкой ARG и инъекции ldflags

**`Терминал`**

```bash
# Сборка образа с передачей версии и коммита
docker build \
  --build-arg VERSION=v2.4.1 \
  --build-arg COMMIT=a7f83b1 \
  --build-arg BUILD_TIME=$(date -u +'%Y-%m-%dT%H:%M:%SZ') \
  -t app-versioned:v2.4.1 .

# Запуск
docker run -d -p 8080:8080 --name test-ver app-versioned:v2.4.1

# Проверка ответа (вернет JSON с внедренными параметрами)
curl -s http://localhost:8080/version

# Очистка
docker rm -f test-ver
```

## Под капотом

Линковщик Go на этапе создания таблицы данных инициализации ELF-файла заменяет адреса памяти строковых литералов указанных глобальных переменных на переданные константы. Переменная обязана иметь строковый тип (`string`), иначе линковщик проигнорирует флаг `-X`.

## Подводные камни

1. Попытка переопределить нестроковую переменную (например, `int`): линковщик выдаст ошибку `cannot set with -X: not a string variable`.
2. Опечатка в имени пакета: если переменная находится в пакете `internal/version`, флаг должен быть `-X 'myproject/internal/version.Version=...'`.

## На собеседовании

**Вопрос с собеседования:** «Каковы ограничения флага `-X` линковщика Go при внедрении метаданных в бинарник?»
**Ответ:** 1) Флаг `-X` может перезаписывать значения только глобальных переменных строкового типа (`string`). Переменные других типов (`int`, `bool`, структуры) перезаписать нельзя. 2) Переменные должны быть объявлены через `var`, а не как константы `const`. 3) Требуется указывать полный путь к пакету относительно модуля (например, `-X 'example.com/mod/pkg/buildinfo.Version=1.0.0'`).
