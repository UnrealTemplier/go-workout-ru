# Security by Default: эталонный защищенный контейнер в HighLoad продакшне

## Условие

**Security by Default**: non-root containers, read-only root FS, minimal base images (distroless/scratch), no secrets in images, mTLS, network policies, RBAC, Pod Security Standards, Falco runtime detection.

## Теория

Финальный синтез всех практик контейнеризации в концепции **Security by Default** объединяет:
1. **Минимальный базовый образ (`gcr.io/distroless/static-debian12:nonroot`).**
2. **Непривилегированный пользователь (UID 65532).**
3. **Файловая система только для чтения (`read_only: true`).**
4. **Сброс всех привилегий ядра Linux (`cap_drop: [ALL]`).**
5. **Запрет повышения прав (`no-new-privileges: true`).**
6. **Монтирование оперативной памяти для временных файлов (`tmpfs: /tmp`).**
7. **Встроенный Healthcheck без внешних утилит.**

Такой контейнер неуязвим для подавляющего большинства векторов атак и готов к развертыванию в финансовых, банковских и высоконагруженных enterprise-системах с наивысшими требованиями регуляторов (PCI DSS, HIPAA, GDPR).

## Решение по шагам

1. Напишите полноценный Go микросервис со встроенным healthcheck.
2. Создайте эталонный защищенный `Dockerfile`.
3. Опишите защищенный `docker-compose.yml`.
4. Соберите и запустите контейнер, проверив все уровни безопасности.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"fmt"
	"log"
	"net/http"
	"os"
	"os/signal"
	"syscall"
	"time"
)

func main() {
	// Режим проверки здоровья для Docker HEALTHCHECK
	if len(os.Args) > 1 && os.Args[1] == "healthcheck" {
		client := http.Client{Timeout: 2 * time.Second}
		resp, err := client.Get("http://127.0.0.1:8080/healthz")
		if err != nil || resp.StatusCode != http.StatusOK {
			os.Exit(1)
		}
		os.Exit(0)
	}

	mux := http.NewServeMux()
	mux.HandleFunc("/healthz", func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusOK)
		w.Write([]byte("OK"))
	})

	mux.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprintf(w, "Enterprise HighLoad Service running under Security by Default standards!\nUID: %d\n", os.Getuid())
	})

	server := &http.Server{
		Addr:         ":8080",
		Handler:      mux,
		ReadTimeout:  5 * time.Second,
		WriteTimeout: 10 * time.Second,
	}

	// Graceful Shutdown перехват сигналов SIGTERM и SIGINT
	sigChan := make(chan os.Signal, 1)
	signal.Notify(sigChan, os.Interrupt, syscall.SIGTERM)

	go func() {
		log.Println("Server listening on :8080...")
		if err := server.ListenAndServe(); err != nil && err != http.ErrServerClosed {
			log.Fatalf("Server error: %v", err)
		}
	}()

	<-sigChan
	log.Println("Shutting down gracefully...")

	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	if err := server.Shutdown(ctx); err != nil {
		log.Fatalf("Forced shutdown: %v", err)
	}
	log.Println("Server exited successfully.")
}
```

ℹ️ Production микросервис с самопроверкой и Graceful Shutdown

**`Dockerfile`**

```dockerfile
# syntax=docker/dockerfile:1

# Stage 1: Build
FROM golang:1.24-alpine AS builder

WORKDIR /src

COPY go.mod go.sum* ./
RUN --mount=type=cache,target=/go/pkg/mod \
    go mod download

COPY . .

RUN --mount=type=cache,target=/go/pkg/mod \
    --mount=type=cache,target=/root/.cache/go-build \
    CGO_ENABLED=0 GOOS=linux go build \
    -ldflags="-w -s" \
    -o /bin/server .

# Stage 2: Final Minimal & Hardened Distroless
FROM gcr.io/distroless/static-debian12:nonroot

WORKDIR /app
COPY --from=builder /bin/server /app/server

USER nonroot:nonroot

EXPOSE 8080

HEALTHCHECK --interval=10s --timeout=2s --start-period=2s --retries=3 \
  CMD ["/app/server", "healthcheck"]

ENTRYPOINT ["/app/server"]
```

ℹ️ Эталонный защищенный Dockerfile

**`docker-compose.yml`**

```yaml
services:
  production_service:
    build: .
    ports:
      - "8080:8080"
    restart: always
    read_only: true
    security_opt:
      - no-new-privileges:true
    cap_drop:
      - ALL
    tmpfs:
      - /tmp:rw,noexec,nosuid,size=32m
    deploy:
      resources:
        limits:
          cpus: '1.5'
          memory: 256M
        reservations:
          cpus: '0.2'
          memory: 64M
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3" 
```

**`Терминал`**

```bash
curl http://localhost:8080/

# Проверка здоровья
docker inspect --format='{{json .State.Health.Status}}' $(docker compose ps -q production_service)

# Очистка

```

## Под капотом

Данный сервис реализует все требования безопасности OCI Runtime Specification. Рантайм изолирует процесс в пространствах имен `mnt`, `pid`, `net`, `ipc`, `uts`, монтирует rootfs в режиме `ro`, отключает все флаги `capabilities` в дескрипторе процесса и обеспечивает корректную маршрутизацию сигналов остановки `SIGTERM` благодаря тому, что Go-сервер является процессом PID 1.

## Подводные камни

1. Попытка записи временных данных мимо смонтированного tmpfs каталога `/tmp`.
2. Забытый буферизированный канал сигналов `make(chan os.Signal, 1)`.

## На собеседовании

**Вопрос с собеседования:** «Опишите чеклист из 7 ключевых пунктов для подготовки Go-микросервиса к безопасному промышленному развертыванию в Docker / Kubernetes.»
**Ответ:** 1) Multi-stage сборка с финальным этапом на базе `FROM scratch` или `distroless` (минимальный вес и 0 CVE). 2) Статическая компиляция `CGO_ENABLED=0 -ldflags="-w -s"`. 3) Запуск строго от непривилегированного пользователя (`USER nonroot` или `USER 10001`). 4) Монтирование корневой файловой системы в режиме только для чтения (`read_only: true`) с памятью `tmpfs` для `/tmp`. 5) Полный сброс привилегий ядра Linux (`cap_drop: [ALL]`) и запрет эскалации (`no-new-privileges: true`). 6) Жесткие ограничения cgroups на память и процессор (Memory limits, CPU quotas) с интеграцией `automaxprocs`. 7) Реализация корректного перехвата `SIGTERM` для Graceful Shutdown и самопроверки здоровья (Healthcheck).
