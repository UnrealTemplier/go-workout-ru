# Type Switch: switch val := v.(type) с обработкой базовых типов

## Условие

Type Switch: Перепиши с использованием конструкции switch val := v.(type) { case string: ... case int: ... default: ... }.

### Исходная формулировка

**Type Switch**: Перепиши упр. 189 с использованием конструкции `switch val := v.(type) { case string: ... case int: ... default: ... }`.

## Теория

Закрепление синтаксиса Type Switch.

## Решение по шагам

1. Пишем `DescribeType(v any)`.
2. Обрабатываем `int`, `string`, `default`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func DescribeType(v any) {
	switch val := v.(type) {
	case string:
		fmt.Printf("Строковый тип: %q\n", val)
	case int:
		fmt.Printf("Целое число: %d\n", val)
	default:
		fmt.Printf("Прочий тип: %v\n", val)
	}
}

func main() {
	DescribeType("Привет")
	DescribeType(100)
	DescribeType(3.14)
}
```

**`Терминал`**

```bash
go run main.go
# Строковый тип: "Привет"
# Целое число: 100
# Прочий тип: 3.14
```

## Под капотом

Компилятор строит таблицу типов `type_descriptor`.

## Подводные камни

- Использование fallthrough в Type Switch (запрещено спецификацией Go).

## На собеседовании

**Вопрос с собеседования:** «Разрешен ли `fallthrough` в `type switch`?»
**Ответ:** НЕТ! В `type switch` оператор `fallthrough` запрещен, так как тип переменной не может быть одновременно двумя разными типами.
