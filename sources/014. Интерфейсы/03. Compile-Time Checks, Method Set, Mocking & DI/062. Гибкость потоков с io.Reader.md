# Гибкость потоков с io.Reader: подсчет пробелов CountSpaces(r io.Reader) (int, error)

## Условие

**Гибкость с `io.Reader`**: Напишите функцию `CountSpaces(r io.Reader) (int, error)`, которая подсчитывает количество пробелов в потоке данных. Продемонстрируйте её работу, передав туда сначала строку (обернутую в `strings.NewReader`), а затем открытый файл `os.File`.

## Теория

Потоковая обработка любых объемов данных без загрузки всего файла в память.

## Решение по шагам

1. Пишем `CountSpaces(r io.Reader) (int, error)`.
2. Читаем буфером 64 байта в цикле.
3. Тестируем со `strings.NewReader` и `bytes.NewReader`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"io"
	"strings"
)

func CountSpaces(r io.Reader) (int, error) {
	buf := make([]byte, 64)
	spaces := 0

	for {
		n, err := r.Read(buf)
		if n > 0 {
			for _, b := range buf[:n] {
				if b == ' ' {
					spaces++
				}
			}
		}
		if err == io.EOF {
			break
		}
		if err != nil {
			return spaces, err
		}
	}
	return spaces, nil
}

func main() {
	text := "Go — это выразительный, лаконичный, чистый и эффективный язык."
	count, _ := CountSpaces(strings.NewReader(text))

	fmt.Printf("Строка: %q\nКоличество пробелов: %d\n", text, count)
}
```

**`Терминал`**

```bash
go run main.go
# Строка: "Go — это выразительный, лаконичный, чистый и эффективный язык."
# Количество пробелов: 8
```

## Под капотом

Потоковое чтение с фиксированным буфером памяти \(O(1)\).

## Подводные камни

- Выделение буфера размером со весь файл.
