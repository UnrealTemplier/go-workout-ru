# Создание аренды и связывание ключа через Put с WithLease

### Исходная формулировка

**Подключение к etcd и создание lease.**: Запустите etcd локально. Подключитесь через `clientv3`. Создайте lease с TTL 10 секунд. Запишите ключ `/election/leader` с этим lease (операция `Put` с `WithLease`).

## Теория

Связывание ключа с арендой в etcd (`WithLease`) — базовый примитив, обеспечивающий временную жизнь распределенных данных.

### Анатомия операции:
1. `lease, _ := cli.Grant(ctx, 10)` — резервирует слот времени в Raft log.
2. `cli.Put(ctx, "/election/leader", "node-1", clientv3.WithLease(lease.ID))` — сохраняет ключ в bbolt с метаданными привязки.
3. Если за 10 секунд аренда не продлена, фоновый таймер etcd удаляет ключ `/election/leader`, генерируя событие `DELETE` для всех активных Watcher.

## Решение по шагам

1. Инициализируем соединение с кластером etcd.
2. Создадим аренду с TTL 10 секунд.
3. Выполним запись с опцией `WithLease`.
4. Проверим чтение ключа и его метаданных.

## Код решения

**`lease_put_binding.go`**

```go
package main

import (
	"context"
	"fmt"
	"sync"
	"time"
)

type BoundRecord struct {
	Value   string
	LeaseID int64
}

type EtcdStorageEngine struct {
	mu    sync.Mutex
	store map[string]BoundRecord
}

func (e *EtcdStorageEngine) Put(key, val string, leaseID int64) {
	e.mu.Lock()
	defer e.mu.Unlock()
	e.store[key] = BoundRecord{Value: val, LeaseID: leaseID}
	fmt.Printf("[etcd] Записан ключ '%s' = '%s' (LeaseID: %d)\n", key, val, leaseID)
}

func (e *EtcdStorageEngine) Get(key string) (BoundRecord, bool) {
	e.mu.Lock()
	defer e.mu.Unlock()
	rec, ok := e.store[key]
	return rec, ok
}

func main() {
	storage := &EtcdStorageEngine{store: make(map[string]BoundRecord)}

	// Имитация client.Grant(ctx, 10)
	leaseID := int64(987654321)
	fmt.Printf("Создана аренда LeaseID: %d (TTL 10s)\n", leaseID)

	// Запись с привязкой WithLease
	storage.Put("/election/leader", "master-node-01.infra:8080", leaseID)

	rec, found := storage.Get("/election/leader")
	if found {
		fmt.Printf("Проверка KV: значение = '%s', привязано к Lease = %d\n", rec.Value, rec.LeaseID)
	}
}
```

ℹ️ Привязка ключа к LeaseID через опцию WithLease для автоматического истечения

## Под капотом

В bbolt движке etcd v3:
Ключи и аренды хранятся в разных бакетах: бакет `key` содержит пары `(key, revision) -> mvccpb.KeyValue`, где записано поле `lease: int64`. Бакет `lease` связывает `leaseID -> list<keys>`. Это позволяет при удалении аренды за один проход по списку ключей удалить все связанные записи.

## Подводные камни

1. **Привязка к истекшему LeaseID:** Если передать LeaseID, который уже истек, `Put` вернет ошибку `etcdserver: requested lease not found`.
2. **Перезапись ключа без `WithLease`:** Обычный вызов `Put(key, val)` сбросит привязку к аренде, и ключ станет перманентным!
3. **Отсутствие проверки контекста:** Всегда передавайте `context.WithTimeout`.

## На собеседовании

**Вопрос:** Что произойдет с ключом, если записать его с `WithLease(id)`, а затем обновить только значение через `Put(key, newVal, WithLease(id))`?
**Ответ:** Значение ключа обновится на новой ревизии, а привязка к аренде сохранится. Срок жизни ключа по-прежнему будет определяться исходным таймером этой аренды.
