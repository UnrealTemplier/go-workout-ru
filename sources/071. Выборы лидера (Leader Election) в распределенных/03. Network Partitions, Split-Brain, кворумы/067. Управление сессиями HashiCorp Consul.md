# Управление сессиями HashiCorp Consul: Жизненный цикл и Session TTL

## Условие

Установи клиент `github.com/hashicorp/consul/api`. В Consul механизм выборов завязан на сессии (Session). Реализуй создание сессии с TTL (10 сек), привязку к ноде и автоматическое продление (renew).

### Исходная формулировка

**Consul Session**: Установи клиент `github.com/hashicorp/consul/api`. В Consul механизм выборов работает через сессии и блокировки ключей. Создай сессию (Session) с TTL 10 секунд.

## Теория

Сессия в HashiCorp Consul (`api.Session`) представляет собой распределенный контракт аренды, связывающий проверки здоровья узла (Health Checks) с распределенными блокировками в Consul KV.
Ключевые параметры сессии Consul:
1. `TTL`: минимальное время жизни сессии (от 10s до 86400s). Если сессия не продлевается в течение этого окна, она признается истекшей (expired).
2. `Behavior`: определяет судьбу заблокированных ключей при истечении сессии:
   - `BehaviorRelease` (по умолчанию): снимает блокировку с ключа (`Session = ""`), сохраняя его значение.
   - `BehaviorDelete`: безвозвратно удаляет сам ключ из Consul KV.
3. `LockDelay`: защитный интервал времени (от 0 до 60s), в течение которого ни один другой узел не может занять этот ключ после разрыва сессии.
4. `NodeChecks`: список проверок (Serf Health Check, HTTP Health Check), при падении которых сессия инвалидируется мгновенно.

## Решение по шагам

1. Описываем структуру SessionEntry с параметрами TTL, NodeID и Behavior.
2. Создаем менеджер ConsulSessionManager с фоновым циклом продления (Periodic Renew).
3. Проверяем своевременную отправку запросов продления с интервалом \(TTL / 2\).
4. Имитируем остановку продления и проверку наступления таймаута сессии.
5. Демонстрируем корректное удаление сессии при штатном выходе.

## Код решения

**`consul_session_manager.go`**

```go
package main

import (
	"context"
	"fmt"
	"sync"
	"sync/atomic"
	"time"
)

type SessionEntry struct {
	ID        string
	Node      string
	TTL       time.Duration
	Behavior  string
	LockDelay time.Duration
	ExpiresAt time.Time
}

type MockConsulSessionStore struct {
	mu       sync.Mutex
	sessions map[string]*SessionEntry
	counter  atomic.Int64
}

func NewMockConsulSessionStore() *MockConsulSessionStore {
	return &MockConsulSessionStore{
		sessions: make(map[string]*SessionEntry),
	}
}

func (s *MockConsulSessionStore) Create(node string, ttl time.Duration) string {
	s.mu.Lock()
	defer s.mu.Unlock()

	id := fmt.Sprintf("session-%04d", s.counter.Add(1))
	s.sessions[id] = &SessionEntry{
		ID:        id,
		Node:      node,
		TTL:       ttl,
		Behavior:  "release",
		LockDelay: 0,
		ExpiresAt: time.Now().Add(ttl),
	}
	return id
}

func (s *MockConsulSessionStore) Renew(id string) bool {
	s.mu.Lock()
	defer s.mu.Unlock()

	sess, ok := s.sessions[id]
	if !ok || time.Now().After(sess.ExpiresAt) {
		return false
	}
	sess.ExpiresAt = time.Now().Add(sess.TTL)
	return true
}

func (s *MockConsulSessionStore) Destroy(id string) {
	s.mu.Lock()
	defer s.mu.Unlock()
	delete(s.sessions, id)
}

type SessionLifecycleController struct {
	store     *MockConsulSessionStore
	nodeID    string
	sessionID string
	ttl       time.Duration
	cancel    context.CancelFunc
}

func NewSessionLifecycleController(nodeID string, ttl time.Duration, store *MockConsulSessionStore) *SessionLifecycleController {
	return &SessionLifecycleController{
		store:  store,
		nodeID: nodeID,
		ttl:    ttl,
	}
}

func (c *SessionLifecycleController) Start(ctx context.Context) string {
	c.sessionID = c.store.Create(c.nodeID, c.ttl)
	fmt.Printf("[%s] Created Consul session: %s (TTL=%v)\n", c.nodeID, c.sessionID, c.ttl)

	renewCtx, cancel := context.WithCancel(ctx)
	c.cancel = cancel

	// Фоновый цикл продления с интервалом TTL/2
	go func() {
		ticker := time.NewTicker(c.ttl / 2)
		defer ticker.Stop()

		for {
			select {
			case <-renewCtx.Done():
				return
			case <-ticker.C:
				ok := c.store.Renew(c.sessionID)
				if ok {
					fmt.Printf("[%s] Consul session %s renewed successfully.\n", c.nodeID, c.sessionID)
				} else {
					fmt.Printf("[%s] ERROR: Failed to renew Consul session %s (expired or destroyed)\n",
						c.nodeID, c.sessionID)
					return
				}
			}
		}
	}()

	return c.sessionID
}

func (c *SessionLifecycleController) Stop() {
	if c.cancel != nil {
		c.cancel()
	}
	c.store.Destroy(c.sessionID)
	fmt.Printf("[%s] Destroyed Consul session: %s\n", c.nodeID, c.sessionID)
}

func main() {
	store := NewMockConsulSessionStore()
	controller := NewSessionLifecycleController("consul-client-node-1", 400*time.Millisecond, store)

	ctx := context.Background()
	_ = controller.Start(ctx)

	// Даем сессии продлиться дважды
	time.Sleep(500 * time.Millisecond)

	// Завершаем работу
	controller.Stop()
	time.Sleep(100 * time.Millisecond)
	fmt.Println("Consul session lifecycle test finished.")
}
```

## Под капотом

В официальном Go SDK `github.com/hashicorp/consul/api` метод `session.RenewPeriodic` устроен следующим образом:
```go
go client.Session().RenewPeriodic(sessionTTL, doneCh, nil, func(entry *api.SessionEntry) {
    // Callback при каждом успешном обновлении
})
```
Под капотом он запускает таймер на \(TTL / 2\) и делает HTTP PUT запрос к `/v1/session/renew/<session_id>`. Если сервер возвращает HTTP 404 (сессия исчезла), клиент закрывает канал `doneCh`, сигнализируя приложению о потере сессии.

## Подводные камни

Установка `TTL` меньше 10 секунд: Consul намеренно запрещает создание сессий с TTL менее 10 секунд (сервер вернет ошибку `TTL must be between 10s and 86400s`), чтобы предотвратить лавинную нагрузку на Raft-кластер Consul от частых обновлений. Если вам требуется реакция на сбой менее 10 секунд, используйте etcd с Lease TTL от 1 секунды.

## На собеседовании

В: Что произойдет с сессией Consul, если узел кратковременно потеряет сетевую связность с серверами Consul?
О: Если разрыв сети продлится дольше TTL сессии, серверы Consul признают сессию просроченной и снимут блокировку с ключа лидера. При восстановлении сети локальный клиент при первой же попытке `Renew` получит 404 NotFound. Обработчик клиента обязан мгновенно прекратить исполнение функций лидера и перезапустить процедуру создания новой сессии.
