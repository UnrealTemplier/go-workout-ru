# Отмена кампании кандидатов: Управление контекстом ожидания

## Условие

Фоловерам может надоесть ждать выборов. Оберни `election.Campaign` в контекст с таймаутом. Если за 10 секунд нода не стала лидером — отмени кампанию и перейди в режим ожидания (fallback).

### Исходная формулировка

**Отмена кампании**: Фоловерам может надоесть ждать выборов. Оберни `election.Campaign` в `context.WithCancel`. Отмени контекст через 5 секунд. Убедись, что узел прекращает попытки стать лидером и завершает работу без ошибок.

## Теория

В архитектуре распределенных систем длительное блокирование горутины кандидата на неопределенный срок без таймаута — антипаттерн (Goroutine Leak / Resource Starvation).
Сценарии, когда кандидату требуется отмена кампании:
1. Таймаут готовности (Readiness Deadline): сервис не может простаивать вечно. Если за 10 секунд узел не стал лидером, он должен переключиться в режим `Worker/Observer` и начать выполнять второстепенные задачи.
2. Динамическое перераспределение ресурсов: освобождение соединений к координатору при снижении нагрузки.
Механизм отмены в `concurrency.Election`:
Вызов `election.Campaign(ctx, val)` уважает отмену контекста: если `ctx` отменяется (`context.DeadlineExceeded` или `context.Canceled`), etcd клиент корректно удаляет свою временную заявку из очереди ревизий, не оставляя мусорных ключей в базе данных.

## Решение по шагам

1. Создаем структуру CampaignWithTimeoutRunner.
2. Оборачиваем попытку выборов в `context.WithTimeout(ctx, 10*time.Second)`.
3. Обрабатываем ошибку `context.DeadlineExceeded`.
4. Переводим узел в режим пассивного наблюдателя (Fallback Observer Mode).
5. Проверяем корректность освобождения ресурсов при таймауте.

## Код решения

**`campaign_timeout_fallback.go`**

```go
package main

import (
	"context"
	"errors"
	"fmt"
	"time"
)

type CampaignManager struct {
	nodeID string
}

func NewCampaignManager(nodeID string) *CampaignManager {
	return &CampaignManager{nodeID: nodeID}
}

// Имитация election.Campaign(ctx)
func (m *CampaignManager) MockEtcdCampaign(ctx context.Context) error {
	fmt.Printf("[%s] Entering election campaign queue...\n", m.nodeID)

	// Допустим, текущий лидер держит ключ долго
	select {
	case <-ctx.Done():
		return ctx.Err()
	case <-time.After(5 * time.Second): // Лидер освободил бы ключ через 5 сек
		return nil
	}
}

func (m *CampaignManager) RunCampaignWithTimeout(parent context.Context, timeout time.Duration) {
	campaignCtx, cancel := context.WithTimeout(parent, timeout)
	defer cancel()

	err := m.MockEtcdCampaign(campaignCtx)
	if err != nil {
		if errors.Is(err, context.DeadlineExceeded) {
			fmt.Printf("[%s] CAMPAIGN TIMED OUT after %v! Switching to Fallback Observer Mode.\n",
				m.nodeID, timeout)
			m.startFallbackWorker()
			return
		}
		fmt.Printf("[%s] Campaign cancelled with error: %v\n", m.nodeID, err)
		return
	}

	fmt.Printf("[%s] WON ELECTION! Running as active leader.\n", m.nodeID)
}

func (m *CampaignManager) startFallbackWorker() {
	fmt.Printf("[%s] Fallback Worker active: Serving read-only queries and background indexing.\n", m.nodeID)
}

func main() {
	mgr := NewCampaignManager("worker-node-aux-1")

	// Устанавливаем короткий таймаут 300 мс (меньше времени ожидания ключа 5s)
	mgr.RunCampaignWithTimeout(context.Background(), 300*time.Millisecond)

	fmt.Println("Campaign timeout and fallback transition verified successfully.")
}
```

## Под капотом

Внутри `concurrency.Election.Campaign`:
Если переданный контекст отменяется до того, как кандидат стал лидером, метод выполняет откат:
```go
select {
case <-ctx.Done():
    e.Resign(e.client.Ctx()) // Удаляет свой созданный ключ претендента
    return ctx.Err()
}
```
Благодаря этому в etcd не накапливаются мертвые ревизии от кандидатов, которые отказались от участия.

## Подводные камни

Использование того же отмененного контекста для удаления ключа в `Resign()`: etcd клиент внутри `election.go` использует независимый системный контекст `e.client.Ctx()`, чтобы удалить ключ кандидата при отмене пользовательского контекста. Если бы он использовал `ctx`, ключ завис бы в etcd до истечения Lease TTL.
