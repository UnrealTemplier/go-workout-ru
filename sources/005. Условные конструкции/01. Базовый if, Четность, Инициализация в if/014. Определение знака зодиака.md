# Определение знака зодиака: каскадный if против tagless switch

## Условие

Напиши программу, которая по дню и месяцу рождения определяет **знак зодиака**. Используй длинную цепочку `if / else if`. Затем перепиши ту же логику через `switch` без тега (tagless switch) и сравни читаемость.

## Теория

**Tagless Switch (`switch { case ... }`):**
- `switch` без аргумента эквивалентен `switch true`;
- Каждая ветка `case` содержит произвольное логическое выражение `bool`;
- Является идиоматичной, более чистой и структурированной заменой длинных каскадов `if - else if - else if`.

## Решение по шагам

1. Пишем функцию через `if / else if`.
2. Пишем функцию через `tagless switch`.
3. Сравниваем читаемость.

## Код решения

**`main.go`**

```go
package main

import "fmt"

// Вариант 1: Tagless switch (Switch True) - чистый и структурированный код
func GetZodiacSignSwitch(day, month int) string {
	switch {
	case (month == 3 && day >= 21) || (month == 4 && day <= 19):
		return "Овен"
	case (month == 4 && day >= 20) || (month == 5 && day <= 20):
		return "Телец"
	case (month == 5 && day >= 21) || (month == 6 && day <= 20):
		return "Близнецы"
	case (month == 6 && day >= 21) || (month == 7 && day <= 22):
		return "Рак"
	case (month == 7 && day >= 23) || (month == 8 && day <= 22):
		return "Лев"
	case (month == 8 && day >= 23) || (month == 9 && day <= 22):
		return "Дева"
	case (month == 9 && day >= 23) || (month == 10 && day <= 22):
		return "Весы"
	case (month == 10 && day >= 23) || (month == 11 && day <= 21):
		return "Скорпион"
	case (month == 11 && day >= 22) || (month == 12 && day <= 21):
		return "Стрелец"
	case (month == 12 && day >= 22) || (month == 1 && day <= 19):
		return "Козерог"
	case (month == 1 && day >= 20) || (month == 2 && day <= 18):
		return "Водолей"
	case (month == 2 && day >= 19) || (month == 3 && day <= 20):
		return "Рыбы"
	default:
		return "Некорректная дата"
	}
}

func main() {
	fmt.Println("12 апреля: ", GetZodiacSignSwitch(12, 4))
	fmt.Println("25 августа:", GetZodiacSignSwitch(25, 8))
	fmt.Println("31 декабря:", GetZodiacSignSwitch(31, 12))
}
```

ℹ️ Зодиак через tagless switch

**`Терминал`**

```bash
go run main.go
# 12 апреля:  Овен
# 25 августа: Дева
# 31 декабря: Козерог
```

ℹ️ Результаты

## Под капотом

В `switch true` компилятор последовательно проверяет выражения `case` до первого истинного `true`, после чего сразу выходит из конструкции.

## Подводные камни

- В длинных `if-else if` легко допустить ошибку выравнивания или пропустить фигурную скобку, тогда как `case` имеет плоский и строгий синтаксис.

## На собеседовании

**Вопрос с собеседования:** «В чем семантическая разница между `switch { ... }` и `switch true { ... }` в Go?»
**Ответ:** Они абсолютно идентичны. Если после ключевого слова `switch` выражение отсутствует, компилятор по умолчанию подставляет константу `true`.
