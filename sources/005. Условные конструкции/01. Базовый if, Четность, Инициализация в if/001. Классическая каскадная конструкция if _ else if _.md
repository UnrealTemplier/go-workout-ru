# Классическая каскадная конструкция if / else if / else для анализа знака числа

## Условие

Напиши программу, которая читает целое число из консоли и сообщает: положительное оно, отрицательное или ноль. Используй конструкцию `if / else if / else`.

## Теория

**Условный оператор `if` в Go:**
1. Круглые скобки вокруг условия `(x > 0)` **запрещены** (линтер и компилятор требуют `if x > 0`);
2. Фигурные скобки `{ ... }` **строго обязательны**, даже если в блоке всего одна строка (в отличие от C/C++/Java);
3. Ключевое слово `else` или `else if` обязано находиться **на той же строке**, что и закрывающая фигурная скобка `}` предыдущего блока: `} else if {` (из-за правила автоматической вставки точек с запятой компилятором).

## Решение по шагам

1. Считываем число из консоли через `fmt.Scan`.
2. Проверяем условие `n > 0`, `n < 0` и ветку `else` для нуля.
3. Выводим соответствующий вердикт.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func CheckNumberSign(n int) string {
	if n > 0 {
		return "Число положительное"
	} else if n < 0 {
		return "Число отрицательное"
	} else {
		return "Число равно нулю"
	}
}

func main() {
	var num int
	fmt.Print("Введите целое число: ")
	if _, err := fmt.Scan(&num); err != nil {
		fmt.Println("Ошибка ввода:", err)
		return
	}

	result := CheckNumberSign(num)
	fmt.Printf("Результат для %d: %s\n", num, result)
}
```

ℹ️ Каскадный if / else if / else

**`Терминал`**

```bash
go run main.go
# Введите целое число: -42
# Результат для -42: Число отрицательное
```

## Под капотом

Компилятор Go преобразует цепочку `if-else` в узлы SSA-графа с инструкциями условного перехода `JGT` (Jump if Greater) и `JLT` (Jump if Less) с оптимизацией предсказания ветвлений (Branch Prediction).

## Подводные камни

- Перенос `else` на новую строку:
  ```go

  }

  }
  ```

## На собеседовании

**Вопрос с собеседования:** «Почему в Go фигурные скобки `{}` обязательны даже для однострочных `if`?»
**Ответ:** Это защищает от знаменитого критического бага Apple SSL goto fail (CVE-2014-1266), когда пропущенные скобки привели к ложному безусловному переходу и взлому проверки SSL-сертификатов.
