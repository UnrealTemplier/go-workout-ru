# Изоляция переменной age в заголовке каскадного if / else if

## Условие

**`if` с коротким объявлением**: внутри условия объявите переменную `age := ...` и используйте её только в блоках `if/else if/else`.

## Теория

Переменная, объявленная в первой секции `if`, остается доступной во всех промежуточных ветках `else if` и финальной `else`.

## Решение по шагам

1. Получаем возраст через вызов вспомогательной функции.
2. Проверяем категории.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func fetchUserAge() int {
	return 21
}

func main() {
	// Переменная age живет только внутри этого каскада
	if age := fetchUserAge(); age < 18 {
		fmt.Printf("Доступ запрещен: возраст %d < 18\n", age)
	} else if age >= 18 && age < 65 {
		fmt.Printf("Доступ открыт: возраст %d (рабочая группа)\n", age)
	} else {
		fmt.Printf("Специальный доступ: возраст %d\n", age)
	}
}
```

ℹ️ Изоляция age в каскаде

**`Терминал`**

```bash
go run main.go
# Доступ открыт: возраст 21 (рабочая группа)
```

ℹ️ Вывод

## Под капотом

Стековый слот переменной `age` выделяется в начале базового блока и освобождается после перехода к следующей инструкции функции `main`.

## Подводные камни

- Попытка объявить еще один `age := ...` во вложенном `else if`.
