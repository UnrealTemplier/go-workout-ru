# Булевы упрощения и идиоматичный синтаксис условий в Go

## Условие

**Булевы упрощения**: Создайте переменную `isValid bool = true`. Напишите условие `if`, проверяющее её значение. Избегайте явного сравнения вида `if isValid == true` — напишите идиоматичный для Go вариант.

## Теория

**Идиоматика булевых выражений в Go:**
- ❌ Неидиоматично: `if isValid == true` / `if isValid == false`
- ✅ Идиоматично: `if isValid` / `if !isValid`
- Сравнение с `true`/`false` избыточно и считается антипаттерном в Go Code Review.

## Решение по шагам

1. Создаем булевы переменные `isValid` и `isAdmin`.
2. Пишем чистые условия `if isValid`, `if !isValid`, `if isValid && !isAdmin`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	isValid := true
	isAdmin := false

	// Идиоматичная проверка истинности
	if isValid {
		fmt.Println("✔ Состояние валидно (if isValid)")
	}

	// Идиоматичная проверка ложности (через оператор отрицания !)
	if !isAdmin {
		fmt.Println("✔ Обычный пользователь (if !isAdmin)")
	}

	// Комбинированная проверка
	if isValid && !isAdmin {
		fmt.Println("✔ Активный стандартный аккаунт")
	}
}
```

ℹ️ Идиоматичные булевы условия

**`Терминал`**

```bash
go run main.go
# ✔ Состояние валидно (if isValid)
# ✔ Обычный пользователь (if !isAdmin)
# ✔ Активный стандартный аккаунт
```
