# Каскадная классификация возрастных групп пользователей

## Условие

**Каскадный `if`**: Считай возраст пользователя. Напиши цепочку `if - else if - else`, которая выводит: 0-12 (ребенок), 13-17 (подросток), 18-59 (взрослый), 60+ (пенсионер).

## Теория

Каскадные проверки диапазонов упорядочиваются от меньшего к большему или наоборот.

## Решение по шагам

1. Получаем возраст.
2. Проверяем диапазоны: `< 0` (ошибка), `<= 12` (ребенок), `<= 17` (подросток), `<= 59` (взрослый), `>= 60` (пенсионер).

## Код решения

**`main.go`**

```go
package main

import "fmt"

func GetAgeCategory(age int) string {
	if age < 0 || age > 150 {
		return "Некорректный возраст"
	} else if age <= 12 {
		return "ребенок"
	} else if age <= 17 {
		return "подросток"
	} else if age <= 59 {
		return "взрослый"
	} else {
		return "пенсионер"
	}
}

func main() {
	ages := []int{5, 14, 25, 68, -2}
	for _, a := range ages {
		fmt.Printf("Возраст %3d -> Категория: %s\n", a, GetAgeCategory(a))
	}
}
```

ℹ️ Классификация возраста

**`Терминал`**

```bash
go run main.go
# Возраст   5 -> Категория: ребенок
# Возраст  14 -> Категория: подросток
# Возраст  25 -> Категория: взрослый
# Возраст  68 -> Категория: пенсионер
# Возраст  -2 -> Категория: Некорректный возраст
```

ℹ️ Вывод

## Под капотом

Компилятор оптимизирует цепочки сравнений в последовательные инструкции `CMP` и условные джампы `JLE` / `JGE`.

## Подводные камни

- Нарушение порядка условий (например, проверка `age <= 59` раньше `age <= 12` перехватит всех детей как взрослых).

## На собеседовании

**Вопрос с собеседования:** «Когда вместо каскадного `if-else` лучше использовать `switch`?»
**Ответ:** Когда количество веток превышает 3–4, либо когда проверяются точные дискретные значения. `switch` без тега читается чище и легче масштабируется.
