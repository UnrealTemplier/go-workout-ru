# Алгоритм проверки високосного года через логические операторы && и ||

## Условие

Напиши программу, которая определяет **високосный год**. Условие: делится на 4, но не делится на 100, либо делится на 400. Используй логические операторы `&&` и `||`.

## Теория

**Григорианский календарь:**
Год является високосным (Leap Year), если:
$$\text{isLeap} = (year \% 4 == 0 \ \&\&\ year \% 100 \ne 0)\ ||\ (year \% 400 == 0)$$
Приоритет оператора `&&` выше, чем `||`, однако круглые скобки явно фиксируют порядок и улучшают читаемость.

## Решение по шагам

1. Реализуем функцию `IsLeapYear(year int) bool`.
2. Проверяем годы: 2000 (високосный), 1900 (не високосный), 2024 (високосный), 2023 (обычный).

## Код решения

**`main.go`**

```go
package main

import "fmt"

func IsLeapYear(year int) bool {
	return (year%4 == 0 && year%100 != 0) || (year%400 == 0)
}

func main() {
	testYears := []int{1900, 2000, 2020, 2023, 2024}

	for _, y := range testYears {
		if IsLeapYear(y) {
			fmt.Printf("%d год — Високосный (366 дней)\n", y)
		} else {
			fmt.Printf("%d год — Обычный (365 дней)\n", y)
		}
	}
}
```

ℹ️ Проверка високосного года

**`Терминал`**

```bash
go run main.go
# 1900 год — Обычный (365 дней)
# 2000 год — Високосный (366 дней)
# 2020 год — Високосный (366 дней)
# 2023 год — Обычный (365 дней)
# 2024 год — Високосный (366 дней)
```

ℹ️ Вывод

## Под капотом

Компилятор Go использует короткое замыкание (Short-circuit Evaluation): если `year % 4 == 0 && year % 100 != 0` истинно, правая часть `year % 400 == 0` даже не вычисляется.

## Подводные камни

- Упрощение формулы до `year % 4 == 0`: 1900, 2100 и 2200 годы не являются високосными, хотя и делятся на 4.
