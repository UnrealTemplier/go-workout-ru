# Цепочка if-else if-else для перевода числовых оценок в буквенные

## Условие

**Цепочка `if-else if-else`**: переведите числовую оценку (0–100) в буквенную (A, B, C, D, F) с несколькими ветками.

## Теория

Практическое закрепление цепочки условий с граничными значениями.

## Решение по шагам

1. Пишем функцию `FormatGrade(points int) string`.
2. Тестируем все ветки.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func FormatGrade(points int) string {
	if points >= 90 {
		return "A (Отлично)"
	} else if points >= 80 {
		return "B (Хорошо)"
	} else if points >= 70 {
		return "C (Удовлетворительно)"
	} else if points >= 60 {
		return "D (Слабо)"
	} else {
		return "F (Неудовлетворительно)"
	}
}

func main() {
	testPoints := []int{92, 85, 74, 63, 40}
	for _, p := range testPoints {
		fmt.Printf("%2d баллов -> %s\n", p, FormatGrade(p))
	}
}
```

ℹ️ Перевод баллов в оценку

**`Терминал`**

```bash
go run main.go
# 92 баллов -> A (Отлично)
# 85 баллов -> B (Хорошо)
# 74 баллов -> C (Удовлетворительно)
# 63 баллов -> D (Слабо)
# 40 баллов -> F (Неудовлетворительно)
```

ℹ️ Результат

## Под капотом

Все ветки компилируются в прямое ветвление с отсечением условий.

## Подводные камни

- Отсутствие проверки на отрицательные баллы в реальных веб-формах.

## На собеседовании

**Вопрос с собеседования:** «Как повысить производительность каскадного `if-else`, если частоты срабатывания веток известны заранее?»
**Ответ:** Размещать наиболее часто выполняющиеся условия первыми в цепочке (Branch Frequency Optimization), чтобы минимизировать число проверок `CMP` в среднем.
