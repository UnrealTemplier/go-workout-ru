# Категоризация рабочих и выходных дней через группированный switch

## Условие

**Множественные значения в `case`**: Перепишите предыдущую программу с днями недели так, чтобы `switch` группировал дни: в одном `case` перечислялись будни (1, 2, 3, 4, 5) и выводилось "Будний день", а в другом — выходные (6, 7) с выводом "Выходной".

## Теория

Закрепление синтаксиса группировки дней.

## Решение по шагам

1. Создаем функцию классификации.
2. Проверяем граничные условия.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func DayType(day int) string {
	switch day {
	case 1, 2, 3, 4, 5:
		return "Будний день"
	case 6, 7:
		return "Выходной"
	default:
		return "Неизвестный день"
	}
}

func main() {
	for d := 1; d <= 7; d++ {
		fmt.Printf("День %d: %s\n", d, DayType(d))
	}
}
```

ℹ️ Группировка будней и выходных

**`Терминал`**

```bash
go run main.go
# День 1: Будний день
# День 2: Будний день
# День 3: Будний день
# День 4: Будний день
# День 5: Будний день
# День 6: Выходной
# День 7: Выходной
```

ℹ️ Вывод

## Под капотом

Компилятор оптимизирует проверку через битовую маску или диапазон.

## Подводные камни

- Забыть ветку `default`.

## На собеседовании

**Вопрос с собеседования:** «Как проверить день недели с помощью пакета `time`?»
**Ответ:** `now := time.Now(); switch now.Weekday() { case time.Saturday, time.Sunday: ... }`.
