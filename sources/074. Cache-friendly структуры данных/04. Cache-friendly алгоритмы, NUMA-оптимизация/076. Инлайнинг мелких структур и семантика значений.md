# Инлайнинг мелких структур и семантика значений (Value vs Pointer Semantics)

## Условие

Исследуйте преимущества семантики значений (Value Semantics) над указателями для мелких структур (размером до 16-24 байт, например Point, UUID, Complex, Time). Продемонстрируйте, как передача по значению исключает разыменование указателей и аллокации в куче.

### Исходная формулировка

**Inline small structs**: Для маленьких структур (< 16 байт) используйте value semantics вместо pointer. Это избегает pointer indirection.

## Теория

В языке Go существует распространенное заблуждение: «Передавать структуры по указателю всегда быстрее, потому что копируется всего 8 байт адреса». Для больших структур (> 64-128 байт) это справедливо. Однако для **мелких структур** (\(\le 16\dots24\) байт, таких как `struct { X, Y float64 }` или `time.Time`) передача по указателю — антипаттерн:

1. **Косвенная адресация (Pointer Indirection)**: при обращении `p.X` процессор вынужден сначала прочитать адрес указателя, а затем загрузить значение из памяти (два чтения вместо одного).
2. **Побег в кучу (Escape Analysis)**: передача указателя часто заставляет компилятор аллоцировать объект в куче (`escapes to heap`), нагружая GC и фрагментируя память.
3. **Регистровая передача (Go Register ABI)**: начиная с Go 1.17, структуры размером до 9 регистров передаются напрямую через регистры ЦПУ (`RAX`, `RBX`, `RCX`, `XMM0-XMM15`), то есть копирование в памяти вообще не происходит! Значение мгновенно оказывается в регистрах вызываемой функции.

## Решение по шагам

1. Создайте структуру `Point2D` с двумя полями `float64` (16 байт).
2. Реализуйте функцию сложения с семантикой указателей `AddPtr(a, b *Point2D) *Point2D`.
3. Реализуйте функцию сложения по значению `AddVal(a, b Point2D) Point2D`.
4. Запустите сравнительный бенчмарк для 10 000 000 вызовов.
5. Продемонстрируйте отсутствие аллокаций в куче для семантики значений с помощью флага `go build -gcflags="-m"`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
	"unsafe"
)

type Point2D struct {
	X float64
	Y float64
}

// Семантика указателей: косвенная адресация и потенциальный escape в кучу
func AddPtr(a, b *Point2D) Point2D {
	return Point2D{X: a.X + b.X, Y: a.Y + b.Y}
}

// Семантика значений: передача в регистрах ЦПУ без обращения к RAM
func AddVal(a, b Point2D) Point2D {
	return Point2D{X: a.X + b.X, Y: a.Y + b.Y}
}

func main() {
	var p Point2D
	fmt.Printf("Размер Point2D: %d байт (точно 2 регистра ЦПУ)\n\n", unsafe.Sizeof(p))

	const iters = 20_000_000
	p1 := Point2D{X: 1.5, Y: 2.5}
	p2 := Point2D{X: 3.5, Y: 4.5}

	// 1. Бенчмарк семантики указателей
	startPtr := time.Now()
	resPtr := Point2D{}
	for i := 0; i < iters; i++ {
		resPtr = AddPtr(&p1, &p2)
	}
	dPtr := time.Since(startPtr)
	fmt.Printf("Pointer Semantics: %v (res=%v)\n", dPtr, resPtr)

	// 2. Бенчмарк семантики значений
	startVal := time.Now()
	resVal := Point2D{}
	for i := 0; i < iters; i++ {
		resVal = AddVal(p1, p2)
	}
	dVal := time.Since(startVal)
	fmt.Printf("Value Semantics:   %v (res=%v)\n", dVal, resVal)

	if dVal < dPtr {
		fmt.Printf("Value semantics быстрее в %.2fx раз благодаря прямому использованию регистров!\n",
			float64(dPtr)/float64(dVal))
	}
}
```

ℹ️ Мелкие структуры размером до 16-24 байт передаются процессором через регистры без обращений к памяти.

## Под капотом

В Go 1.17+ вызов `AddVal(p1, p2)` компилируется в размещение `p1.X` в регистре `%xmm0`, `p1.Y` в `%xmm1`, `p2.X` в `%xmm2`, `p2.Y` в `%xmm3`. Инструкция `addsd` выполняет сложение напрямую между регистрами за 1 такт ЦПУ. Для `AddPtr` компилятор вынужден сначала загрузить указатели в целочисленные регистры (`%rax`, `%rbx`), а затем выполнить косвенную загрузку из памяти `movsd (%rax), %xmm0`, добавляя задержку обращения к кэшу.

## Подводные камни

1. Превышение порога размера: для структур размером от 64 байт копирование по значению начинает уступать передаче указателя.
2. Необходимость мутации: если функция должна изменить состояние исходного объекта, передача по указателю обязательна.

## На собеседовании

Классический вопрос Google/Uber Go Guidelines: «Почему в стандартном пакете time тип time.Time передается по значению, а не по указателю?». Ответ: размер `time.Time` равен 24 байтам, он спроектирован как immutable value object, легко помещается в регистры, не аллоцируется в куче и исключает Data Race при конкурентном чтении.
