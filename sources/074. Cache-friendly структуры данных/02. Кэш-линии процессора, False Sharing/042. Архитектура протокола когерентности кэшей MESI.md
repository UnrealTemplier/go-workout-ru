### Исходная формулировка

**Cache coherency protocol (MESI)**: Изучите MESI protocol:
* Modified (эксклюзивно изменён)
* Exclusive (эксклюзивно чист)
* Shared (разделён между кэшами)
* Invalid (недействителен)

## Теория

Протокол когерентности **MESI** (также известный как Illinois Protocol) обеспечивает строгую аппаратную иллюзию общей памяти в многоядерных системах.

Четыре состояния кэш-линии:
1. **Invalid (I):** Данных нет или они устарели. При обращении ядро обязано отправить запрос на шину (Bus Read).
2. **Shared (S):** Данные валидны, присутствуют в памяти и, возможно, в кэшах других ядер. Запись запрещена без инвалидации остальных.
3. **Exclusive (E):** Данные валидны, присутствуют ТОЛЬКО в этом кэше и совпадают с оперативной памятью. Ядро может мгновенно перейти в Modified при записи без обращения к шине.
4. **Modified (M):** Данные изменены только в этом кэше (грязные). Только это ядро имеет право читать и писать без задержек.

**Транзакции на общей шине (Bus Snooping):**
- **BusRd:** Ядро запрашивает чтение линии без намерения модификации.
- **BusRdX (Read Invalidate / RFO):** Ядро запрашивает чтение с намерением записи, требуя от всех остальных ядер аннулировать свои копии (`I`).
- **BusUpgr:** Ядро уже имеет линию в `S` и запрашивает право на эксклюзивную запись, переводя остальных в `I`.
- **BusWB (Write Back):** Вытеснение измененной строки `M` обратно в память DRAM.

## Решение по шагам

1. Создайте перечисление состояний `MESIState: M, E, S, I`.
2. Создайте структуру `CoreCache` с картой линий кэша.
3. Смоделируйте шину интерконнекта `MESIBus`, связывающую 2 ядра CPU.
4. Выполните операцию: Core 0 читает адрес X \(\to\) переход в Exclusive.
5. Core 1 читает адрес X \(\to\) переход обоих ядер в Shared.
6. Core 1 пишет в адрес X \(\to\) Core 1 переходит в Modified, Core 0 инвалидируется в Invalid.
7. Продемонстрируйте протокол пошагово в консоли.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"sync"
)

type MESIState string

const (
	StateM MESIState = "MODIFIED"
	StateE MESIState = "EXCLUSIVE"
	StateS MESIState = "SHARED"
	StateI MESIState = "INVALID"
)

type CacheLine struct {
	Tag   uint64
	State MESIState
	Data  int64
}

type SimulatedCPU struct {
	mu     sync.Mutex
	cores  map[int]*CoreCache
	memory map[uint64]int64
}

type CoreCache struct {
	id    int
	lines map[uint64]*CacheLine
	bus   *SimulatedCPU
}

func NewSimulatedCPU(numCores int) *SimulatedCPU {
	cpu := &SimulatedCPU{
		cores:  make(map[int]*CoreCache),
		memory: make(map[uint64]int64),
	}
	for i := 0; i < numCores; i++ {
		cpu.cores[i] = &CoreCache{
			id:    i,
			lines: make(map[uint64]*CacheLine),
			bus:   cpu,
		}
	}
	return cpu
}

func (c *CoreCache) Read(tag uint64) int64 {
	c.bus.mu.Lock()
	defer c.bus.mu.Unlock()

	line, exists := c.lines[tag]
	if exists && line.State != StateI {
		fmt.Printf("[Core %d] Read Hit on 0x%x (State: %s) -> %d\n", c.id, tag, line.State, line.Data)
		return line.Data
	}

	fmt.Printf("[Core %d] Read Miss on 0x%x! Broadcasting BusRd...\n", c.id, tag)
	// Проверяем, есть ли линия в других ядрах
	otherHasIt := false
	for otherID, otherCore := range c.bus.cores {
		if otherID == c.id {
			continue
		}
		if otherLine, ok := otherCore.lines[tag]; ok && otherLine.State != StateI {
			otherHasIt = true
			otherLine.State = StateS // переводим соседа в Shared
			fmt.Printf("  -> Snooped by Core %d: transitioned to SHARED\n", otherID)
		}
	}

	val := c.bus.memory[tag]
	newState := StateE
	if otherHasIt {
		newState = StateS
	}

	c.lines[tag] = &CacheLine{Tag: tag, State: newState, Data: val}
	fmt.Printf("[Core %d] Line 0x%x loaded in state %s\n", c.id, tag, newState)
	return val
}

func (c *CoreCache) Write(tag uint64, val int64) {
	c.bus.mu.Lock()
	defer c.bus.mu.Unlock()

	fmt.Printf("\n[Core %d] Initiating Write to 0x%x = %d...\n", c.id, tag, val)
	// Инвалидируем копии во всех остальных ядрах
	for otherID, otherCore := range c.bus.cores {
		if otherID == c.id {
			continue
		}
		if otherLine, ok := otherCore.lines[tag]; ok && otherLine.State != StateI {
			otherLine.State = StateI
			fmt.Printf("  -> Core %d line 0x%x INVALIDATED by bus snooping!\n", otherID, tag)
		}
	}

	c.lines[tag] = &CacheLine{Tag: tag, State: StateM, Data: val}
	fmt.Printf("[Core %d] Line 0x%x transitioned to MODIFIED (Exclusive Ownership)\n", c.id, tag)
}

func main() {
	cpu := NewSimulatedCPU(2)
	c0 := cpu.cores[0]
	c1 := cpu.cores[1]

	const targetAddr uint64 = 0x1000

	// 1. Core 0 читает адрес
	fmt.Println("--- STEP 1: Core 0 reads address 0x1000 ---")
	c0.Read(targetAddr)

	// 2. Core 1 читает тот же адрес
	fmt.Println("\n--- STEP 2: Core 1 reads address 0x1000 ---")
	c1.Read(targetAddr)

	// 3. Core 1 записывает в адрес
	fmt.Println("\n--- STEP 3: Core 1 writes new value to 0x1000 ---")
	c1.Write(targetAddr, 999)

	// 4. Core 0 пытается прочесть свой кэш
	fmt.Println("\n--- STEP 4: Core 0 attempts read after invalidation ---")
	c0.Read(targetAddr)
}
```

ℹ️ Программная симуляция смены состояний протокола когерентности кэшей MESI и Snooping-шины

## Под капотом

В физическом процессоре Snooping Bus реализована через распределенный фильтр каталогов (Directory-Based Coherence) или кольцевую шину (Ring Interconnect). Каждое ядро слушает транзакции шины через аппаратный блок Snoop Logic. При обнаружении запроса `RFO` на свою строку ядро обязано подтвердить инвалидацию через специальный сигнал `HITM#` (Hit Modified).

## Подводные камни

1. Забывание, что переход в `M` требует сброса буферов записи: частые переходы `S -> M` парализуют производительность всех ядер процессора.
2. Предположение, что компилятор знает о протоколе MESI: компилятор оптимизирует инструкции, но физический протокол когерентности исполняется на 100% аппаратурой кремния.

## На собеседовании

«Что такое RFO (Request For Ownership) в протоколе когерентности кэшей?»
Ответ: RFO — это комбинированная операция шины (Read + Invalidate). Она запрашивает актуальное значение кэш-линии из памяти (или другого ядра) и одновременно приказывает всем остальным ядрам перевести свои копии этой линии в состояние `Invalid`. RFO выполняется при первой операции записи потока в разделяемую память.
