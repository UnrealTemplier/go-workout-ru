# Матрица явных преобразований типов (Type Casting)

## Условие

Преобразуйте `int` в `float64` и обратно, `string` в `[]byte` и `[]rune`, `int` в `string` (через `strconv.Itoa` и через `string(rune)`).

## Теория

Базовые трансформации типов в Go:
1. `float64(intVal)` / `int(floatVal)` (с отбрасыванием дробной части);
2. `[]byte(str)` — срез сырых байт UTF-8;
3. `[]rune(str)` — срез кодовых точек Unicode (символов);
4. `strconv.Itoa(42)` \(\rightarrow\) строка `"42"`;
5. `string(rune(65))` \(\rightarrow\) символ `"A"` (по коду ASCII/Unicode).

## Решение по шагам

1. Проводим конвертацию чисел.
2. Проводим конвертацию строк в байты и руны.
3. Сравниваем `strconv.Itoa` и `string(rune)`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	// 1. Числовые преобразования
	var i int = 42
	var f float64 = float64(i)
	var truncatedInt int = int(99.99) // Дробная часть отсекается -> 99

	fmt.Printf("1. Числа:  i=%d -> f=%.2f, float=99.99 -> int=%d\n", i, f, truncatedInt)

	// 2. Строка в байты и руны
	text := "Go 🚀"
	bytes := []byte(text)
	runes := []rune(text)
	fmt.Printf("2. Строка: %q\n", text)
	fmt.Printf("   []byte: %v (байт: %d)\n", bytes, len(bytes))
	fmt.Printf("   []rune: %v (руны: %d)\n", runes, len(runes))

	// 3. int -> string (Разница между strconv.Itoa и string(rune))
	numStr := strconv.Itoa(65)     // Строка "65"
	runeStr := string(rune(65))    // Символ с кодом 65 -> "A"

	fmt.Printf("3. strconv.Itoa(65)  -> %q\n", numStr)
	fmt.Printf("   string(rune(65))   -> %q\n", runeStr)
}
```

ℹ️ Матрица преобразования типов

**`Терминал`**

```bash
go run main.go
# 1. Числа:  i=42 -> f=42.00, float=99.99 -> int=99
# 2. Строка: "Go 🚀"
#    []byte: [71 111 32 240 159 154 128] (байт: 7)
#    []rune: [71 111 32 128640] (руны: 4)
# 3. strconv.Itoa(65)  -> "65"
#    string(rune(65))   -> "A" 
```

## Под капотом

Преобразование `string([]byte)` и `[]byte(string)` выделяет новый блок памяти и копирует байты (за исключением некоторых оптимизаций компилятора при поиске по ключу мапы `m[string(b)]`).

## Подводные камни

- Попытка преобразовать число `int` в строку через `string(42)`: в старых версиях Go это возвращало символ `*` (ASCII 42), а в современных версиях `go vet` выдает предупреждение о некорректной конвертации. Всегда используйте `strconv.Itoa`.

## На собеседовании

**Вопрос с собеседования:** «Как преобразовать `[]byte` в `string` без аллокации памяти в куче (Zero-Copy)?»
**Ответ:** Начиная с Go 1.20, используют функцию `unsafe.String(unsafe.SliceData(b), len(b))` или `strings.Builder`.
