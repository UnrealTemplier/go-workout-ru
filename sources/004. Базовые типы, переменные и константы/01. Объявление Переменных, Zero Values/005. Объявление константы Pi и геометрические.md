# Объявление константы Pi и геометрические вычисления

## Условие

Создайте константу `Pi` и используйте её для вычисления площади круга заданного радиуса.

## Теория

Константы в Go объявляются через `const`:
1. Значение константы обязано быть известно на этапе компиляции;
2. Константы не занимают места в оперативной памяти (они встраиваются как литералы в инструкции ассемблера);
3. Формула площади круга: \(S = \pi \cdot r^2\).

## Решение по шагам

1. Объявляем `const Pi = 3.141592653589793`.
2. Задаем радиус `radius := 5.0`.
3. Рассчитываем площадь и выводим с точностью до 4 знаков.

## Код решения

**`main.go`**

```go
package main

import "fmt"

const Pi = 3.14159265358979323846

func CircleArea(radius float64) float64 {
	return Pi * radius * radius
}

func main() {
	r := 5.5
	area := CircleArea(r)

	fmt.Printf("Радиус:          %.2f см\n", r)
	fmt.Printf("Константа Pi:    %.10f\n", Pi)
	fmt.Printf("Площадь круга S: %.4f кв.см\n", area)
}
```

ℹ️ Вычисление площади круга с константой

**`Терминал`**

```bash
go run main.go
# Радиус:          5.50 см
# Константа Pi:    3.1415926536
# Площадь круга S: 95.0332 кв.см
```

ℹ️ Результат вычисления

## Под капотом

Нетипизированные числовые константы в Go вычисляются с высокой математической точностью (минимум 256 бит точности мантиссы в компиляторе) и округляются только в момент присвоения типизированной переменной `float64`.

## Подводные камни

- Попытка взять адрес константы `&Pi`: компилятор выдаст ошибку `cannot take the address of Pi`, так как у констант нет адреса в RAM.

## На собеседовании

**Вопрос с собеседования:** «Где хранятся константы в скомпилированном ELF-бинарнике Go?»
**Ответ:** Числовые константы внедряются непосредственно в машинные инструкции операндами (Immediate Operands), а строковые константы размещаются в секции только для чтения `.rodata` (Read-Only Data).
