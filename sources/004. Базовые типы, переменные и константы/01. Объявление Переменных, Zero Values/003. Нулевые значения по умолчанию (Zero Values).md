# Нулевые значения по умолчанию (Zero Values) в языке Go

## Условие

Продемонстрируйте zero-значения для `int`, `float64`, `string`, `bool`, `complex128`.

## Теория

В Go концептуально **отсутствует неинициализированная память** и мусорные значения (в отличие от C/C++).
Если переменная объявлена без явного начального значения, рантайм гарантированно заполняет её память нулями:
- `int`, `int8`-`int64`, `uint`, `rune`, `byte` \(\rightarrow\) `0`
- `float32`, `float64` \(\rightarrow\) `0.0`
- `string` \(\rightarrow\) `""` (пустая строка длиной 0)
- `bool` \(\rightarrow\) `false`
- `complex64`, `complex128` \(\rightarrow\) `(0+0i)`
- Указатели, слайсы, мапы, каналы, интерфейсы, функции \(\rightarrow\) `nil`

## Решение по шагам

1. Объявляем переменные разных типов через `var` без присваивания.
2. Выводим их через `%#v` и `%q` для наглядности.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var i int
	var f float64
	var s string
	var b bool
	var c complex128

	fmt.Printf("int:        %#v\n", i)
	fmt.Printf("float64:    %#v\n", f)
	fmt.Printf("string:     %q (длина: %d)\n", s, len(s))
	fmt.Printf("bool:       %#v\n", b)
	fmt.Printf("complex128: %#v\n", c)
}
```

ℹ️ Демонстрация Zero Values

**`Терминал`**

```bash
go run main.go
# int:        0
# float64:    0
# string:     "" (длина: 0)
# bool:       false
# complex128: (0+0i)
```

ℹ️ Гарантированная инициализация нулями

## Под капотом

При аллокации стекового фрейма горутины или блока в куче рантайм выполняет инструкцию процессора `DUFFZERO` / `MEMCLR` (быстрое обнуление диапазона памяти регистрами SSE/AVX).

## Подводные камни

- Пустая строка `""` имеет длину 0, но это валидный объект `string` (указатель `Data = nil`, `Len = 0`). Она не равна `nil`! В Go строки никогда не могут быть `nil`.

## На собеседовании

**Вопрос с собеседования:** «Что такое принцип "Make the zero value useful" в стандартной библиотеке Go?»
**Ответ:** Это паттерн проектирования, согласно которому структуры должны быть готовы к работе сразу после объявления нулевого значения без вызова конструктора. Примеры: `sync.Mutex` готов к `Lock()` без инициализации; `bytes.Buffer` готов к `Write()`; `sync.WaitGroup` готов к `Add()`.
