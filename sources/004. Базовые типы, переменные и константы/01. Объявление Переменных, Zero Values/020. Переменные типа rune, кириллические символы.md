# Переменные типа rune, кириллические символы и кодовые точки

## Условие

Создайте переменную типа `rune` (алиас для `int32`), присвойте ей кириллический символ и выведите его как символ и как число.

## Теория

**Тип `rune` в Go:**
- Является встроенным синонимом (Type Alias) для `int32`;
- Представляет собой одну кодовую точку Unicode (Code Point);
- Литералы рун задаются в **одинарных кавычках** `'Я'`.

## Решение по шагам

1. Объявляем `var r rune = 'Я'`.
2. Выводим как символ (`%c`), число (`%d`) и Unicode (`U+%04X`).

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var r rune = 'Я'

	fmt.Printf("Символ:       %c\n", r)
	fmt.Printf("Десятичный:   %d\n", r)
	fmt.Printf("Unicode код:  U+%04X\n", r)
	fmt.Printf("Тип в рантайме: %T\n", r)
}
```

ℹ️ Руна и её кодовая точка

**`Терминал`**

```bash
go run main.go
# Символ:       Я
# Десятичный:   1071
# Unicode код:  U+042F
# Тип в рантайме: int32
```

ℹ️ Результат инспекции руны

## Под капотом

При компиляции символ `'Я'` преобразуется компилятором в целочисленную константу `1071` (`0x042F`).

## Подводные камни

- Использование двойных кавычек `"Я"` вместо одинарных `'Я'`: двойные кавычки создают тип `string` (срез из 2 байт `[]byte{0xD0, 0xAF}`), а одинарные — число `rune`.

## На собеседовании

**Вопрос с собеседования:** «Чем `byte` отличается от `rune` в Go?»
**Ответ:** `byte` — это алиас `uint8` (1 байт, от 0 до 255, кодировка ASCII). `rune` — это алиас `int32` (4 байта, все символы Unicode от латиницы и кириллицы до иероглифов и эмодзи).
