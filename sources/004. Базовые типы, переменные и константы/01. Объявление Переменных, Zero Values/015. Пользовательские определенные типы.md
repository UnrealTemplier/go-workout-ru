# Пользовательские определенные типы (type Celsius float64) и строгая типизация

## Условие

Создайте псевдоним типа `type Celsius float64` и используйте его для переменных, демонстрируя строгую типизацию.

## Теория

**Определенные типы (Type Definitions):**
Конструкция `type Celsius float64`:
1. Создает **новый независимый тип** `Celsius` с базовым представлением `float64`;
2. Переменную типа `Celsius` **нельзя напрямую сложить или присвоить** переменной типа `float64` или `Fahrenheit`;
3. Позволяет прикреплять к типу собственные методы (`func (c Celsius) ToFahrenheit() Fahrenheit`).

## Решение по шагам

1. Объявляем `type Celsius float64`.
2. Создаем метод форматирования `String()`.
3. Показываем ошибку при попытке сложить с обычным `float64` без явного каста.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Celsius float64
type Fahrenheit float64

func (c Celsius) ToFahrenheit() Fahrenheit {
	return Fahrenheit(c*9/5 + 32)
}

func main() {
	var roomTemp Celsius = 24.5
	var rawFloat float64 = 10.0

	// Ошибка компиляции при прямом сложении:
	// sum := roomTemp + rawFloat // mismatched types Celsius and float64

	// Явное преобразование типов:
	sum := roomTemp + Celsius(rawFloat)
	fahrenheit := roomTemp.ToFahrenheit()

	fmt.Printf("Температура в Цельсиях: %.1f °C\n", roomTemp)
	fmt.Printf("Сумма температур:       %.1f °C\n", sum)
	fmt.Printf("В Фаренгейтах:          %.1f °F\n", fahrenheit)
}
```

ℹ️ Строгая типизация с Type Definition

**`Терминал`**

```bash
go run main.go
# Температура в Цельсиях: 24.5 °C
# Сумма температур:       34.5 °C
# В Фаренгейтах:          76.1 °F
```

## Под капотом

В компиляторе Go оба типа имеют одинаковый `Underlying Type` (`float64`), что гарантирует нулевые накладные расходы при касте `Celsius(floatVal)`.

## Подводные камни

- Путаница между Type Definition `type Celsius float64` (новый тип) и Type Alias `type Celsius = float64` (просто синоним). Для алиасов сложение с `float64` разрешено, а для новых типов — строго запрещено.
