# Области видимости и ограничения оператора короткого объявления :=

## Условие

Объявите переменные с использованием короткого объявления (`:=`) и изучите, в каких областях видимости оно работает.

## Теория

Правила работы `:=`:
- ✅ Разрешено внутри функций, циклов `for`, блоков `if`, `switch`;
- ❌ Запрещено на уровне пакета (Package Level Scope).

## Решение по шагам

1. Показываем корректное использование `:=` во вложенных блоках.
2. Показываем ошибку при попытке использовать `:=` вне функций.

## Код решения

**`main.go`**

```go
package main

import "fmt"

// На уровне пакета РАЗРЕШЕНО только var или const:
var PackageVar = 100
// PackageShort := 200 // ОШИБКА: non-declaration statement outside function body

func main() {
	// Внутри функции:
	funcVar := 200

	if true {
		blockVar := 300
		fmt.Printf("В блоке if: funcVar = %d, blockVar = %d\n", funcVar, blockVar)
	}

	// blockVar здесь недоступен (Block Scope)
	fmt.Printf("В main(): PackageVar = %d, funcVar = %d\n", PackageVar, funcVar)
}
```

ℹ️ Области видимости оператора :=

**`Терминал`**

```bash
go run main.go
# В блоке if: funcVar = 200, blockVar = 300
# В main(): PackageVar = 100, funcVar = 200
```

ℹ️ Результат

## Под капотом

На уровне пакета разрешены только конструкции верхнего уровня (Top-Level Declarations: `type`, `const`, `var`, `func`), так как порядок их инициализации компилятор вычисляет по графу зависимостей.

## Подводные камни

- Попытка использовать `:=` для инициализации глобальных переменных.

## На собеседовании

**Вопрос с собеседования:** «Как в Go инициализировать глобальную переменную сложной логикой с обработкой ошибок?»
**Ответ:** С помощью функции `init()` или пакета `sync.Once`.
