# Генератор перечислений iota и константы базовых типов

## Условие

Создайте константы чисел, строк, а также перечисление дней недели с помощью `iota`.

## Теория

Специальный идентификатор **`iota`**:
1. Автоматический генератор последовательных целых чисел (0, 1, 2, ...);
2. Сбрасывается в `0` при каждом новом блоке `const (...)`;
3. Инкрементируется на 1 в каждой новой строке константного блока.

## Решение по шагам

1. Создаем числовые и строковые константы.
2. Создаем перечисление дней недели с помощью `iota`.
3. Печатаем значения.

## Код решения

**`main.go`**

```go
package main

import "fmt"

const (
	AppName = "PaymentGateway"
	Version = "v2.4.0"
	MaxConn = 1000
)

type Weekday int

const (
	Sunday Weekday = iota // 0
	Monday                // 1
	Tuesday               // 2
	Wednesday             // 3
	Thursday              // 4
	Friday                // 5
	Saturday              // 6
)

func main() {
	fmt.Printf("Сервис: %s (%s), Макс соединений: %d\n\n", AppName, Version, MaxConn)

	fmt.Println("Перечисление Weekday (через iota):")
	fmt.Printf("Sunday:    %d\n", Sunday)
	fmt.Printf("Monday:    %d\n", Monday)
	fmt.Printf("Friday:    %d\n", Friday)
	fmt.Printf("Saturday:  %d\n", Saturday)
}
```

ℹ️ Использование iota для перечислений

**`Терминал`**

```bash
go run main.go
# Сервис: PaymentGateway (v2.4.0), Макс соединений: 1000
# 
# Перечисление Weekday (через iota):
# Sunday:    0
# Monday:    1
# Friday:    5
# Saturday:  6
```

## Под капотом

При компиляции блока `const` компилятор подставляет вместо `iota` целочисленный индекс текущей спецификации константы в AST-дереве.

## Подводные камни

- Если в середину enum на `iota` случайно вставить новый элемент, значения всех последующих констант сдвинутся на 1, что может сломать совместимость со старыми записями в базе данных!

## На собеседовании

**Вопрос с собеседования:** «Как сделать так, чтобы `iota` начиналась с 1 вместо 0?»
**Ответ:** Либо написать `const ( First = iota + 1; Second; ... )`, либо пропустить ноль с помощью blank identifier: `const ( _ = iota; First; Second )`.
