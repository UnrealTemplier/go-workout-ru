# Усечение дробной части при преобразовании float64 к int (Truncation)

## Условие

Используй преобразование типов: приведи `float64` к `int` и посмотри, что произойдет с дробной частью.

## Теория

При приведении `int(floatVal)`:
1. Дробная часть **отбрасывается (Truncation / Round towards zero)**;
2. `3.99` \(\rightarrow\) `3` (а не `4`!);
3. `-3.99` \(\rightarrow\) `-3`.

## Решение по шагам

1. Создаем положительный и отрицательный float.
2. Кастуем к `int`.
3. Сравниваем с математическим округлением `math.Round`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"math"
)

func main() {
	pos := 3.99
	neg := -3.99

	fmt.Printf("Исходный pos:         %f -> int(pos):        %d (отсечение)\n", pos, int(pos))
	fmt.Printf("Исходный neg:        %f -> int(neg):        %d (отсечение)\n", neg, int(neg))
	fmt.Printf("Округление math.Round: %f -> int(Round(pos)): %d\n", pos, int(math.Round(pos)))
}
```

ℹ️ Усечение vs округление

**`Терминал`**

```bash
go run main.go
# Исходный pos:         3.990000 -> int(pos):        3 (отсечение)
# Исходный neg:        -3.990000 -> int(neg):        -3 (отсечение)
# Округление math.Round: 3.990000 -> int(Round(pos)): 4
```

ℹ️ Результат

## Под капотом

Инструкция `CVTTSD2SI` (Convert with Truncation Scalar Double to Integer) выполняет отсечение мантиссы.

## Подводные камни

- Ожидание, что `int(9.99)` округлится до `10`.

## На собеседовании

**Вопрос с собеседования:** «Как округлить число вверх (Ceil) и вниз (Floor) в Go?»
**Ответ:** С помощью функций `math.Ceil(f)` (вверх к плюс бесконечности) и `math.Floor(f)` (вниз к минус бесконечности).
