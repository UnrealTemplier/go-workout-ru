# Объявление нескольких переменных одного типа в одной строке

## Условие

Объяви несколько переменных одного типа в одной строке.

## Теория

Синтаксис Go позволяет объявлять несколько переменных одного типа через запятую:
`var x, y, z int = 1, 2, 3` или `var x, y, z int` (все получат 0).

## Решение по шагам

1. Объявляем переменные `width, height, depth int = 1920, 1080, 32`.
2. Выводим их.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var width, height, depth int = 1920, 1080, 32

	fmt.Printf("Разрешение: %d x %d (глубина: %d бит)\n", width, height, depth)
}
```

ℹ️ Однострочное объявление однотипных переменных

**`Терминал`**

```bash
go run main.go
# Разрешение: 1920 x 1080 (глубина: 32 бит)
```

ℹ️ Результат

## Под капотом

Компилятор парсит список идентификаторов и применяет общий тип `int` ко всем элементам списка.

## Подводные камни

- Попытка указать разные типы в одной инструкции `var a int, b string = 1, "hi"`: это недопустимо в одном выражении `var`. Для разных типов используют `var ( a int; b string )` или короткое `a, b := 1, "hi"`.

## На собеседовании

**Вопрос с собеседования:** «Какой вариант однострочного объявления считается более идиоматичным: `var a, b = 1, 2` или `a, b := 1, 2`?»
**Ответ:** Внутри функций стандартом является `a, b := 1, 2`. Форма `var` используется только при необходимости явного задания интерфейсного типа или нулевых значений.
