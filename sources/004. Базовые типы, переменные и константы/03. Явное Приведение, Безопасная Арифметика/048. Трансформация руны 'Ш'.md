# Трансформация руны 'Ш': числовой код и преобразование в строку

## Условие

**Работа с рунами**: Объявите переменную типа `rune` со значением `'Ш'`. Выведите её числовое представление (код Unicode), а затем преобразуйте в строку и выведите как символ.

## Теория

Руна `'Ш'`:
- Код Unicode: `1064` (`0x0428`);
- Преобразование `string(r)` кодирует 4-байтное число руны в 2-байтовую UTF-8 строку (`0xD0 0xA8`).

## Решение по шагам

1. Создаем `var r rune = 'Ш'`.
2. Печатаем код и символ.
3. Преобразуем в строку `str := string(r)`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var r rune = 'Ш'

	fmt.Printf("Символ:       %c\n", r)
	fmt.Printf("Код Unicode:  %d (U+%04X)\n", r, r)

	// Преобразование руны в строку UTF-8
	s := string(r)
	fmt.Printf("Строка:       %s (байт: %d)\n", s, len(s))
}
```

ℹ️ Преобразование руны в строку

**`Терминал`**

```bash
go run main.go
# Символ:       Ш
# Код Unicode:  1064 (U+0428)
# Строка:       Ш (байт: 2)
```

ℹ️ Результат

## Под капотом

Функция `string(rune)` вызывает рантайм-метод `runtime.intstring`, который кодирует руну в буфер UTF-8.

## Подводные камни

- Преобразование отрицательного числа `rune(-1)` в строку: вернет символ замены `\uFFFD` (символ ошибки Unicode).

## На собеседовании

**Вопрос с собеседования:** «Что вернет выражение `string(65)` в Go?»
**Ответ:** Символ `"A"`, так как 65 — это ASCII код буквы A.
