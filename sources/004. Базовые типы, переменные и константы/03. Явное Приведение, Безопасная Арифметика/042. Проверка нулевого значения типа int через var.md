# Проверка нулевого значения типа int через var

## Условие

Объяви переменную типа `int` с помощью `var`, выведи её значение (должен быть 0).

## Теория

Объявление `var x int` резервирует память под переменную и инициализирует её нулем.

## Решение по шагам

1. Объявляем `var score int`.
2. Выводим значение.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var score int

	fmt.Printf("Значение score: %d\n", score)
	fmt.Printf("Является нулем?  %t\n", score == 0)
}
```

ℹ️ Zero value для int

**`Терминал`**

```bash
go run main.go
# Значение score: 0
# Является нулем?  true
```

ℹ️ Вывод

## Под капотом

Память стека очищается инструкцией `XOR RAX, RAX`.

## Подводные камни

- Написание `var score int = 0` считается антипаттерном (Redundant Initialization): линтеры рекомендуют просто `var score int`.

## На собеседовании

**Вопрос с собеседования:** «Когда по стандарту Go Code Style следует использовать `var x int`, а когда `x := 0`?»
**Ответ:** Если нужно нулевое значение — используют `var x int` (сигнализирует читателю о дефолтном состоянии). Если нужно ненулевое начальное значение — используют `x := 42`.
