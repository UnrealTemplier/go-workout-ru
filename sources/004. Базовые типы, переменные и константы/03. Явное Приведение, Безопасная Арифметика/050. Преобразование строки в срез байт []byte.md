# Преобразование строки в срез байт []byte и анализ длины UTF-8

## Условие

**Преобразование строк в байты**: Создайте строку `"Go язык"`. Преобразуйте её в срез байт `[]byte`. Выведите длину полученного среза. Почему длина среза байт больше, чем количество символов в строке?

## Теория

**UTF-8 кодирование строки `"Go язык"`:**
- `"G"` (1 байт: `0x47`)
- `"o"` (1 байт: `0x6F`)
- `" "` (1 байт: `0x20`)
- `"я"` (2 байта: `0xD1 0x8F`)
- `"з"` (2 байта: `0xD0 0xB7`)
- `"ы"` (2 байта: `0xD1 0x8B`)
- `"к"` (2 байта: `0xD0 0xBA`)
Итого: \(1 + 1 + 1 + 2 + 2 + 2 + 2 = 11\) байт при 7 видимых символах!

## Решение по шагам

1. Создаем строку `"Go язык"`.
2. Конвертируем в `[]byte`.
3. Выводим побайтовую раскладку и объясняем разницу.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	s := "Go язык"
	b := []byte(s)

	fmt.Printf("Строка:             %s\n", s)
	fmt.Printf("Количество символов:%d\n", utf8.RuneCountInString(s))
	fmt.Printf("Длина среза байт:   %d байт\n", len(b))
	fmt.Printf("Байты в HEX:        % X\n", b)
}
```

ℹ️ Анализ длины строки и среза байт

**`Терминал`**

```bash
go run main.go
# Строка:             Go язык
# Количество символов:7
# Длина среза байт:   11 байт
# Байты в HEX:        47 6F 20 D1 8F D0 B7 D1 8B D0 BA
```

ℹ️ Результат

## Под капотом

В UTF-8 символы с кодами \(> 127\) кодируются последовательностью от 2 до 4 байт с установленными старшими битами `110xxxxx 10xxxxxx`.

## Подводные камни

- Выделение буфера `make([]byte, len(runes))` приведет к переполнению буфера при записи UTF-8 текста.

## На собеседовании

**Вопрос с собеседования:** «Почему создатели Go Роб Пайк и Кен Томпсон выбрали UTF-8 в качестве стандарта для языка?»
**Ответ:** Потому что Кен Томпсон и Роб Пайк сами изобрели кодировку UTF-8 в 1992 году для операционной системы Plan 9. Она обратно совместима с ASCII и не содержит нулевых байт внутри строк.
