# Конвертация числа в строку через strconv.Itoa и конкатенация

## Условие

**Конвертация числа в строку**: Преобразуй число `42` в строку (`Itoa`) и конкатенируй с другой строкой.

## Теория

Функция `strconv.Itoa(n)`:
- Быстро конвертирует целое число в десятичную строку `"42"`;
- Конкатенация со строкой через оператор `+`.

## Решение по шагам

1. Преобразуем `42` в строку.
2. Склеиваем со строкой `"Ответ на главный вопрос: "`.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	answer := 42
	msg := "Ответ на главный вопрос Вселенной: " + strconv.Itoa(answer)

	fmt.Println(msg)
}
```

ℹ️ Конвертация и конкатенация

**`Терминал`**

```bash
go run main.go
# Ответ на главный вопрос Вселенной: 42
```

ℹ️ Вывод

## Под капотом

Для чисел от 0 до 99 `strconv.Itoa` использует статическую таблицу констант в памяти без аллокаций.

## Подводные камни

- Использование `string(42)` вместо `strconv.Itoa(42)`.

## На собеседовании

**Вопрос с собеседования:** «Как `strconv.Itoa` оптимизирован для небольших чисел в стандартной библиотеке Go?»
**Ответ:** В пакете `strconv` есть предварительно сгенерированная таблица строковых констант `digits = "00010203...99"`. Для чисел \(< 100\) возврат происходит мгновенно по прямому индексу из статической памяти.
