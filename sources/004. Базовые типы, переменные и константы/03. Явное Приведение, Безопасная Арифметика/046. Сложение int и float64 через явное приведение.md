# Сложение int и float64 через явное приведение типов

## Условие

**Явное приведение типов**: Создай `int` и `float64`. Попытайся сложить их напрямую (увидишь ошибку). Затем приведи к одному типу и сложи.

## Теория

Закрепление типизации вещественных и целых чисел.

## Решение по шагам

1. Создаем `var x int = 15` и `var y float64 = 4.8`.
2. Приводим `x` к `float64(x)` и складываем с `y`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var x int = 15
	var y float64 = 4.8

	result := float64(x) + y

	fmt.Printf("Сумма: %.2f (тип результата: %T)\n", result, result)
}
```

ℹ️ Сложение разнотипных чисел

**`Терминал`**

```bash
go run main.go
# Сумма: 19.80 (тип результата: float64)
```

ℹ️ Вывод

## Под капотом

Компилятор выполняет приведение типа операнда на регистре процессора перед вызовом инструкции `ADDSD`.

## Подводные камни

- Приведение `int(y)` отбросит `0.8`, дав результат `19`, а не `19.8`.

## На собеседовании

**Вопрос с собеседования:** «Как математически корректно округлить `float64` до ближайшего целого `int`?»
**Ответ:** Через функцию `math.Round(f)`: `int(math.Round(4.8))` вернет `5`.
