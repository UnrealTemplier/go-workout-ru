# Математические константы в блоке const (...)

## Условие

**Групповые константы**: Объявите блок констант, описывающих математические величины (Пи, Экспонента) через `const (...)`.

## Теория

Блок математических констант высокой точности:
- \(\pi \approx 3.1415926535\)
- \(e \approx 2.7182818284\)
- \(\phi \approx 1.6180339887\) (золотое сечение)

## Решение по шагам

1. Создаем блок `const (...)`.
2. Выводим значения констант.

## Код решения

**`main.go`**

```go
package main

import "fmt"

const (
	Pi    = 3.14159265358979323846
	E     = 2.71828182845904523536
	Phi   = 1.61803398874989484820
	Sqrt2 = 1.41421356237309504880
)

func main() {
	fmt.Printf("Pi:    %.8f\n", Pi)
	fmt.Printf("E:     %.8f\n", E)
	fmt.Printf("Phi:   %.8f\n", Phi)
	fmt.Printf("Sqrt2: %.8f\n", Sqrt2)
}
```

ℹ️ Математические константы

**`Терминал`**

```bash
go run main.go
# Pi:    3.14159265
# E:     2.71828183
# Phi:   1.61803399
# Sqrt2: 1.41421356
```

ℹ️ Вывод

## Под капотом

Все эти константы уже предрассчитаны в стандартном пакете `math` (`math.Pi`, `math.E`, `math.Phi`).

## Подводные камни

- Переопределение константы с меньшей точностью (например `const Pi = 3.14`), что ухудшит точность расчетов физических моделей.

## На собеседовании

**Вопрос с собеседования:** «Какова точность хранения констант внутри компилятора Go?»
**Ответ:** Компилятор использует пакет `math/big`, сохраняя целочисленные константы с неограниченной разрядностью, а вещественные — с точностью 512 бит.
