# Комплексные числа (complex128) и пакет math/cmplx

## Условие

Объявите переменную типа `complex128`, выполните базовые арифметические операции и выведите мнимую и действительную части.

## Теория

**Комплексные числа в Go:**
- `complex64` (два `float32`) и `complex128` (два `float64`);
- Литералы создаются с суффиксом `i`: `z := 3 + 4i` или через функцию `complex(real, imag)`;
- Встроенные функции: `real(z)` (действительная часть), `imag(z)` (мнимая часть);
- Модуль числа вычисляется через `cmplx.Abs(z)`.

## Решение по шагам

1. Создаем комплексные числа \(z_1 = 3 + 4i\) и \(z_2 = 1 - 2i\).
2. Выполняем сложение и умножение.
3. Извлекаем действительную и мнимую части.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"math/cmplx"
)

func main() {
	z1 := 3 + 4i
	z2 := complex(1, 2)

	sum := z1 + z2
	prod := z1 * z2
	modulus := cmplx.Abs(z1) // sqrt(3^2 + 4^2) = 5

	fmt.Printf("z1:          %v (Re: %.1f, Im: %.1f)\n", z1, real(z1), imag(z1))
	fmt.Printf("z2:          %v\n", z2)
	fmt.Printf("Сумма z1+z2: %v\n", sum)
	fmt.Printf("Произведение:%v\n", prod)
	fmt.Printf("Модуль |z1|: %.2f\n", modulus)
}
```

ℹ️ Операции над комплексными числами

**`Терминал`**

```bash
go run main.go
# z1:          (3+4i) (Re: 3.0, Im: 4.0)
# z2:          (1+2i)
# Сумма z1+z2: (4+6i)
# Произведение:(-5+10i)
# Модуль |z1|: 5.00
```

## Под капотом

В памяти `complex128` представлен как непрерывный 16-байтный блок из двух последовательных чисел IEEE 754 `float64` (8 байт real + 8 байт imag).

## Подводные камни

- Сравнение комплексных чисел через `==`: два числа равны только если и `real(a) == real(b)`, и `imag(a) == imag(b)`.
