# Групповое блочное объявление переменных var (...)

## Условие

**Блочное объявление**: Объявите группу переменных разных типов, используя ключевое слово `var` и круглые скобки `var (...)`.

## Теория

Блочное объявление `var (...)`:
1. Повышает читаемость кода при группировке связанных переменных (например, настроек модуля);
2. Разрешено как на уровне пакета, так и внутри функций;
3. Позволяет сочетать явные типы и вывод типов.

## Решение по шагам

1. Объявляем блок настроек базы данных.
2. Выводим конфигурацию.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var (
		dbHost     = "127.0.0.1"
		dbPort int = 5432
		dbUser     = "postgres"
		dbSSL      = false
		dbPoolSize = 20
	)

	fmt.Println("=== КОНФИГУРАЦИЯ БАЗЫ ДАННЫХ ===")
	fmt.Printf("Хост:   %s:%d\n", dbHost, dbPort)
	fmt.Printf("Юзер:   %s\n", dbUser)
	fmt.Printf("SSL:    %t\n", dbSSL)
	fmt.Printf("Пул:    %d соединений\n", dbPoolSize)
}
```

ℹ️ Блочное объявление переменных

**`Терминал`**

```bash
go run main.go
# === КОНФИГУРАЦИЯ БАЗЫ ДАННЫХ ===
# Хост:   127.0.0.1:5432
# Юзер:   postgres
# SSL:    false
# Пул:    20 соединений
```

ℹ️ Вывод

## Под капотом

Синтаксический сахар компилятора: разворачивается во внутренний список объявлений `DeclList`.

## Подводные камни

- Загромождение функций гигантскими блоками `var (...)`: локальные переменные лучше объявлять как можно ближе к месту их непосредственного использования.

## На собеседовании

**Вопрос с собеседования:** «В чем стандарт Go Code Review по группировке `var` и `const`?»
**Ответ:** В один блок `var (...)` или `const (...)` группируют только логически связанные сущности (например, группу настроек одного сервиса или группу ошибок пакета). Несвязанные переменные разделяют на разные блоки.
