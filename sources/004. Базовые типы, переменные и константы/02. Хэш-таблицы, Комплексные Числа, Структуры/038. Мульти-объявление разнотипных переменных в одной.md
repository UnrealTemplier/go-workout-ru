# Мульти-объявление разнотипных переменных в одной строке

## Условие

**Мульти-объявление**: Объявите три переменные разных типов в одной строке (например, `a, b, c := 1, 2.5, "hello"`). Выведите их значения.

## Теория

Множественное объявление:
- `a, b, c := 1, 2.5, "hello"`
- Компилятор сопоставляет каждый операнд слева с соответствующим выражением справа по порядку.

## Решение по шагам

1. Объявляем три разнотипные переменные в одну строку.
2. Выводим значения и типы.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	a, b, c := 1, 2.5, "hello"

	fmt.Printf("a: %v (%T)\n", a, a)
	fmt.Printf("b: %v (%T)\n", b, b)
	fmt.Printf("c: %v (%T)\n", c, c)
}
```

ℹ️ Мульти-объявление в одну строку

**`Терминал`**

```bash
go run main.go
# a: 1 (int)
# b: 2.5 (float64)
# c: hello (string)
```

ℹ️ Результат

## Под капотом

Все правые выражения вычисляются до выполнения присваивания.

## Подводные камни

- Несоответствие количества переменных слева и значений справа: вызовет ошибку `assignment mismatch: 3 variables but 2 values`.

## На собеседовании

**Вопрос с собеседования:** «В каком порядке вычисляются выражения в множественном присваивании `a, b = b, a`?»
**Ответ:** Все выражения в правой части вычисляются строго слева направо, их результаты временно фиксируются, после чего происходит одновременное присваивание в левые переменные.
