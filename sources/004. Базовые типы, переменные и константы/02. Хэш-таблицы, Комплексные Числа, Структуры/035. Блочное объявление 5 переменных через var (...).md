# Блочное объявление 5 переменных через var (...)

## Условие

**Блочное объявление**: Объяви 5 переменных через конструкцию `var ( ... )`.

## Теория

Закрепляем синтаксис `var (...)`:
- Позволяет компактно инициализировать состояние пакета или функции.

## Решение по шагам

1. Объявляем 5 переменных системных метрик.
2. Выводим их значения.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var (
		cpuCores   = 16
		memoryGB   = 64.0
		hostname   = "k8s-worker-prod-04"
		isReady    = true
		activePods = 48
	)

	fmt.Printf("Хост: %s | CPU: %d ядер | RAM: %.1f ГБ | Ready: %t | Pods: %d\n",
		hostname, cpuCores, memoryGB, isReady, activePods)
}
```

ℹ️ 5 переменных в блоке var

**`Терминал`**

```bash
go run main.go
# Хост: k8s-worker-prod-04 | CPU: 16 ядер | RAM: 64.0 ГБ | Ready: true | Pods: 48
```

ℹ️ Вывод

## Под капотом

Все 5 переменных размещаются в непрерывном стековом фрейме функции `main`.

## Подводные камни

- Случайная опечатка с точкой с запятой: в Go переносы строк служат автоматическими разделителями инструкций.

## На собеседовании

**Вопрос с собеседования:** «В каком случае компилятор Go принимает решение аллоцировать переменную на стеке, а не в куче?»
**Ответ:** Если анализ побега (Escape Analysis) доказывает, что указатель на переменную не покидает текущую функцию (не возвращается наружу, не сохраняется в глобальную структуру и не передается в интерфейс `any`), переменная аллоцируется на сверхбыстром стеке с нулевыми затратами на сборку мусора.
