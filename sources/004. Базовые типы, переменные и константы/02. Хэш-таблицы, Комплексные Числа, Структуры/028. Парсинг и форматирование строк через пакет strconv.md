# Парсинг и форматирование строк через пакет strconv

## Условие

Используйте `strconv.Atoi`, `strconv.ParseFloat`, `strconv.FormatBool` для преобразования строк и обратно.

## Теория

Пакет `strconv` — стандарт индустрии для высокопроизводительной конвертации:
- `strconv.Atoi(s)` — строка \(\rightarrow\) `int`;
- `strconv.Itoa(i)` — `int` \(\rightarrow\) строка;
- `strconv.ParseFloat(s, 64)` — строка \(\rightarrow\) `float64`;
- `strconv.ParseBool(s)` — строка \(\rightarrow\) `bool` ("true", "1", "false", "0");
- `strconv.FormatBool(b)` — `bool` \(\rightarrow\) `"true"` / `"false"`.

## Решение по шагам

1. Парсим строку в `int`, `float64`, `bool`.
2. Конвертируем значения обратно в строки.
3. Обрабатываем ошибки.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	// 1. Строка -> Число / Float / Bool
	i, err1 := strconv.Atoi("100500")
	f, err2 := strconv.ParseFloat("36.6", 64)
	b, err3 := strconv.ParseBool("true")

	if err1 != nil || err2 != nil || err3 != nil {
		fmt.Println("Ошибка парсинга!")
		return
	}

	fmt.Printf("Распарсено: i = %d (%T), f = %.1f (%T), b = %t (%T)\n", i, i, f, f, b, b)

	// 2. Обратно в строку
	strI := strconv.Itoa(i)
	strF := strconv.FormatFloat(f, 'f', 2, 64)
	strB := strconv.FormatBool(b)

	fmt.Printf("В строки:   strI = %q, strF = %q, strB = %q\n", strI, strF, strB)
}
```

ℹ️ Двусторонняя конвертация через strconv

**`Терминал`**

```bash
go run main.go
# Распарсено: i = 100500 (int), f = 36.6 (float64), b = true (bool)
# В строки:   strI = "100500", strF = "36.60", strB = "true" 
```

## Под капотом

`strconv` оптимизирован на уровне ассемблера и не использует рефлексию `reflect`, работая в десятки раз быстрее `fmt.Sprintf` и `fmt.Sscanf`.

## Подводные камни

- Игнорирование ошибки `strconv.Atoi`: если строка содержит пробел `" 42 "`, функция вернет ошибку `ErrSyntax`. Предварительно используйте `strings.TrimSpace`.

## На собеседовании

**Вопрос с собеседования:** «Как `strconv.AppendInt(dst, 42, 10)` помогает сократить аллокации памяти?»
**Ответ:** Вместо создания новой строки `string` в куче, `AppendInt` дописывает отформатированные байты числа в уже существующий срез `dst []byte` с нулевыми аллокациями.
