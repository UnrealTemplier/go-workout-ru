# Форматирование времени в популярных форматах через пакет time

## Условие

Получите текущее время, отформатируйте его в нескольких популярных форматах (пакет `time`).

## Теория

Ключевые стандарты форматирования времени:
- `time.RFC3339` (`2006-01-02T15:04:05Z07:00`) — стандарт для JSON/REST API;
- `time.RFC1123` — стандарт для HTTP-заголовков (`Date`, `Last-Modified`);
- `2006-01-02` — стандарт SQL для дат (`DATE`);
- `15:04:05` — время без даты.

## Решение по шагам

1. Получаем `now := time.Now()`.
2. Выводим время в разных форматах.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	now := time.Now()

	fmt.Println("1. RFC3339 (API):    ", now.Format(time.RFC3339))
	fmt.Println("2. RFC1123 (HTTP):   ", now.Format(time.RFC1123))
	fmt.Println("3. Только дата (SQL):", now.Format("2006-01-02"))
	fmt.Println("4. Время (24-час):   ", now.Format("15:04:05"))
	fmt.Println("5. Человекочитаемый: ", now.Format("02 Jan 2006, 15:04 (MST)"))
}
```

ℹ️ Популярные форматы времени

**`Терминал`**

```bash
go run main.go
# 1. RFC3339 (API):     2026-09-02T15:10:00+03:00
# 2. RFC1123 (HTTP):    Wed, 02 Sep 2026 15:10:00 MSK
# 3. Только дата (SQL): 2026-09-02
# 4. Время (24-час):    15:10:00
# 5. Человекочитаемый:  02 Sep 2026, 15:10 (MSK)
```

## Под капотом

Структура `time.Time` содержит монотонный счетчик (Monotonic Clock) для точного замера длительности и настенные часы (Wall Clock) для отображения даты.

## Подводные камни

- Сравнение времени через `t1 == t2` вместо `t1.Equal(t2)`: если у одной из переменных есть монотонное время, а у другой нет (например после JSON десериализации), оператор `==` вернет `false`, тогда как `Equal` сравнит моменты времени корректно.

## На собеседовании

**Вопрос с собеседования:** «Зачем в Go 1.9 в структуру `time.Time` добавили Monotonic Clock?»
**Ответ:** Чтобы вычисление длительности `time.Since(start)` не давало сбоев и отрицательных значений при коррекции системного времени операционной системы серверами NTP или переходе на зимнее/летнее время.
