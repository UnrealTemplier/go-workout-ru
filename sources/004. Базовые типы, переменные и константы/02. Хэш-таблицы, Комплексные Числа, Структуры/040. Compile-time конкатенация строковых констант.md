# Compile-time конкатенация строковых констант без накладных расходов

## Условие

Объявите несколько строковых констант и проведите их конкатенацию во время компиляции (без рантайм-затрат).

### Исходная формулировка

Объявите несколько строковых констант и проведите их конкатенацию во время компиляции (без рантайм-затрат).

---

## Теория

**Compile-Time Constant Folding:**
Если операция сложения строк выполняется над `const`:
1. Компилятор склеивает строки **во время компиляции**;
2. В скомпилированном бинарнике сохраняется одна готовая итоговая строка;
3. В рантайме не тратится ни одного такта CPU и ни одного байта оперативной памяти на конкатенацию.

## Решение по шагам

1. Объявляем константы `Host`, `Port`, `Endpoint`.
2. Склеиваем их в константу `FullURL`.
3. Выводим итоговую константу.

## Код решения

**`main.go`**

```go
package main

import "fmt"

const (
	Protocol = "https://"
	Domain   = "api.cloud.yandex.net"
	Version  = "/v2"
	Resource = "/compute/instances"

	// Конкатенация происходит на этапе компиляции (Zero Cost):
	FullURL = Protocol + Domain + Version + Resource
)

func main() {
	fmt.Println("Сконкатенированный URL (Compile-Time):")
	fmt.Println(FullURL)
}
```

ℹ️ Конкатенация констант на этапе компиляции

**`Терминал`**

```bash
go run main.go
# Сконкатенированный URL (Compile-Time):
# https://api.cloud.yandex.net/v2/compute/instances
```

ℹ️ Результат

## Под капотом

Оптимизатор компилятора выполняет Constant Folding и помещает строку `"https://api.cloud.yandex.net/v2/compute/instances"` напрямую в таблицу строк секции `.rodata`.

## Подводные камни

- Попытка использовать вызов функции внутри объявления `const` (`const url = FullURL + strings.ToLower("PATH")`): константы не могут зависеть от функций рантайма.

## На собеседовании

**Вопрос с собеседования:** «Какие операции разрешено выполнять над строковыми константами на этапе компиляции?»
**Ответ:** Конкатенацию `+`, взятие длины `len(c)` (если аргумент — константная строка) и сравнения `==`, `!=`, `<`, `>`.
