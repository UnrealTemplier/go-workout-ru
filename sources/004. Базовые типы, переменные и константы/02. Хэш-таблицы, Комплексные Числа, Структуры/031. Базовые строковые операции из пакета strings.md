# Базовые строковые операции из пакета strings

## Условие

Строковые операции из пакета `strings`: `Contains`, `HasPrefix`, `Split`, `Join`, `Replace`, `ToLower`.

## Теория

Пакет `strings` — ядро работы с текстом:
- `strings.Contains(s, sub)` — проверка наличия подстроки;
- `strings.HasPrefix(s, prefix)` — проверка префикса;
- `strings.Split(s, sep)` — разделение на срез строк;
- `strings.Join(slice, sep)` — склеивание среза в одну строку;
- `strings.ReplaceAll(s, old, new)` — замена подстрок;
- `strings.ToLower(s)` / `strings.ToUpper(s)` — смена регистра.

## Решение по шагам

1. Тестируем все функции пакета `strings`.
2. Выводим результат каждого метода.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	rawURL := "https://api.example.com/v1/users/list"

	fmt.Println("Contains 'api':", strings.Contains(rawURL, "api"))
	fmt.Println("HasPrefix 'https':", strings.HasPrefix(rawURL, "https"))

	// Split и Join
	parts := strings.Split(rawURL, "/")
	fmt.Printf("Split: %#v\n", parts)

	joined := strings.Join(parts, " -> ")
	fmt.Println("Join:", joined)

	// Replace и ToLower
	replaced := strings.ReplaceAll(rawURL, "https://", "http://")
	fmt.Println("ReplaceAll:", replaced)

	fmt.Println("ToLower:", strings.ToLower("GOLANG PRO"))
}
```

## Под капотом

Функция `strings.Join` предварительно подсчитывает суммарную длину всех элементов среза и разделителей, аллоцируя один срез байт ровно нужного размера, что исключает повторные реаллокации.

## Подводные камни

- Склеивание строк через оператор `+` в цикле: порождает \(O(N^2)\) аллокаций. Всегда используйте `strings.Join` или `strings.Builder`.

## На собеседовании

**Вопрос с собеседования:** «Почему `strings.ToLower` корректно работает с турецкими буквами `i`/`İ` только при использовании пакета `golang.org/x/text/cases`?»
**Ответ:** Стандартный `strings.ToLower` использует правила Unicode по умолчанию. Для языково-специфичных трансформаций (турецкий, азербайджанский) требуется модуль локализации с учетом контекста языка.
