# Побитовые операции над uint8 (&, |, ^, <<, >>)

## Условие

Используйте побитовые операторы (`&`, `|`, `^`, `<<`, `>>`) над переменными типа `uint8`.

## Теория

**Побитовые операторы в Go:**
- `&` (AND) — побитовое И (маскирование);
- `|` (OR) — побитовое ИЛИ (установка битов);
- `^` (XOR / NOT) — исключающее ИЛИ (бинарная операция) или побитовая инверсия (унарная операция `^x`);
- `&^` (AND NOT) — сброс битов (битовая очистка, Bit Clear);
- `<<` / `>>` — побитовый сдвиг влево/вправо.

## Решение по шагам

1. Задаем маски `var a uint8 = 0b1100` (12) и `var b uint8 = 0b1010` (10).
2. Вычисляем результаты операций и выводим в двоичном виде `%08b`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var a uint8 = 0b00001100 // 12
	var b uint8 = 0b00001010 // 10

	fmt.Printf("a:       %08b (%d)\n", a, a)
	fmt.Printf("b:       %08b (%d)\n\n", b, b)

	fmt.Printf("a & b:   %08b (AND)\n", a&b)
	fmt.Printf("a | b:   %08b (OR)\n", a|b)
	fmt.Printf("a ^ b:   %08b (XOR)\n", a^b)
	fmt.Printf("a &^ b:  %08b (AND NOT - сброс битов b из a)\n", a&^b)
	fmt.Printf("a << 2:  %08b (Сдвиг влево на 2 -> * 4)\n", a<<2)
	fmt.Printf("a >> 2:  %08b (Сдвиг вправо на 2 -> / 4)\n", a>>2)
}
```

ℹ️ Побитовые операторы

**`Терминал`**

```bash
go run main.go
# a:       00001100 (12)
# b:       00001010 (10)
# 
# a & b:   00001000 (AND)
# a | b:   00001110 (OR)
# a ^ b:   00000110 (XOR)
# a &^ b:  00000100 (AND NOT - сброс битов b из a)
# a << 2:  00000000 (Сдвиг влево на 2 -> * 4) [переполнение старших бит: 48]
# a >> 2:  00000011 (Сдвиг вправо на 2 -> / 4)
```

ℹ️ Результаты битовых операций

## Под капотом

Все побитовые операторы транслируются напрямую в соответствующие инструкции процессора (`AND`, `OR`, `XOR`, `SHL`, `SHR`) и выполняются за 1 такт CPU.

## Подводные камни

- Сдвиг на число бит, большее или равное размеру типа (например `var x uint8 = 1; x << 8`): вызовет ошибку компилятора `shift count 8 >= width of uint8`.

## На собеседовании

**Вопрос с собеседования:** «Зачем в Go есть уникальный оператор `&^` (Bit Clear)?»
**Ответ:** Конструкция `a &^ b` сбрасывает в `a` все биты, которые установлены в `1` в маске `b`. В языках C/C++ для этого приходится писать `a & (~b)`. Наличие `&^` делает битовые манипуляции более читаемыми и лаконичными.
