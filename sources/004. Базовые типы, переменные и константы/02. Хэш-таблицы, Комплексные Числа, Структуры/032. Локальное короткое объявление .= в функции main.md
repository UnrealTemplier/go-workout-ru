# Локальное короткое объявление := в функции main

## Условие

**Короткое объявление**: Используй оператор `:=` внутри функции `main` для создания новых переменных.

## Теория

Оператор `:=` — самый идиоматичный и часто используемый способ объявления локальных переменных в Go.

## Решение по шагам

1. Создаем переменные различных типов в `main` через `:=`.
2. Выводим их.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	serverName := "auth-node-01"
	connections := 350
	loadAverage := 0.75
	isMaster := true

	fmt.Printf("Узел: %s, Подключений: %d, Нагрузка: %.2f, Мастер: %t\n",
		serverName, connections, loadAverage, isMaster)
}
```

ℹ️ Идиоматичное короткое объявление

**`Терминал`**

```bash
go run main.go
# Узел: auth-node-01, Подключений: 350, Нагрузка: 0.75, Мастер: true
```

ℹ️ Вывод

## Под капотом

Компилятор автоматически сопоставляет литералы типам `string`, `int`, `float64`, `bool`.

## Подводные камни

- Объявление переменной через `:=`, которая затем нигде не используется: компилятор завершится с ошибкой `v declared and not used`.

## На собеседовании

**Вопрос с собеседования:** «Почему компилятор Go запрещает неиспользуемые локальные переменные?»
**Ответ:** Для чистоты кода, предотвращения накопления мертвого кода (Dead Code) и исключения багов, когда разработчик объявил переменную для результата, но забыл передать её дальше.
