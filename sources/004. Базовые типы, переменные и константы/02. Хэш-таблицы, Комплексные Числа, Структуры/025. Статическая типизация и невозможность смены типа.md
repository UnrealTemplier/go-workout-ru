# Статическая типизация и невозможность смены типа переменной

## Условие

**Краткое объявление**: Создайте несколько переменных с помощью оператора `:=`. Попробуйте изменить их тип после объявления (например, присвоить строке число). Зафиксируйте поведение компилятора.

## Теория

Go — язык со **строгой статической типизацией**:
1. Тип переменной привязывается к ней один раз на этапе компиляции;
2. Переменной типа `string` невозможно присвоить `int` или `bool` (в отличие от динамических Python, JS, PHP);
3. Любая попытка изменить тип пресекается компилятором (Type Mismatch).

## Решение по шагам

1. Создаем переменную `data := "текстовые данные"`.
2. Демонстрируем ошибку при попытке `data = 100`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	msg := "Hello, Go!"
	fmt.Printf("msg = %s (тип: %T)\n", msg, msg)

	// Попытка присвоить другой тип вызовет ошибку компиляции:
	// msg = 42 // ОШИБКА: cannot use 42 (untyped int constant) as string value in assignment
}
```

ℹ️ Статическая типизация переменной

**`Терминал`**

```bash
# Попытка компиляции:
# go run main.go
# ./main.go:10:8: cannot use 42 (untyped int constant) as string value in assignment
```

ℹ️ Ошибка компиляции

## Под капотом

Каждый идентификатор регистрируется в таблице типов компилятора `types.Object`. При проверке типов `check.assign()` типы левой и правой части сравниваются на идентичность `Identical(T1, T2)`.

## Подводные камни

- Иллюзия динамической типизации через `var x any = "hello"; x = 42`. Хотя интерфейс `any` позволяет сохранять любые значения, в высоконагруженном коде это приводит к оверхеду на боксинг и потерю проверок компилятора.

## На собеседовании

**Вопрос с собеседования:** «Каковы преимущества статической типизации перед динамической в крупных кодовых базах (Monorepo)?»
**Ответ:** 1) Обнаружение 100% опечаток и несоответствий типов во время компиляции до деплоя в прод; 2) Безопасный автоматический рефакторинг в IDE; 3) Высокая производительность за счет прямых машинных инструкций без рантайм-инспекций типов.
