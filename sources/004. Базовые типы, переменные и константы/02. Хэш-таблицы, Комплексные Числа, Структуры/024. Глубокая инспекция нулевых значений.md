# Глубокая инспекция нулевых значений через Go-синтаксис (%#v)

## Условие

**Нулевые значения (Zero values)**: Объявите переменные типов `int`, `float64`, `string`, `bool`, `*int`, `[]int`, `map[string]int` без явной инициализации. Выведите их значения с помощью `%#v`, чтобы увидеть их дефолтные значения.

## Теория

Спецификатор `%#v` отображает точный Go-литерал значения.
Для ссылочных типов (`*int`, `[]int`, `map`) он наглядно показывает `nil`, а для строк — кавычки `""`.

## Решение по шагам

1. Объявляем переменные через `var`.
2. Выводим каждую переменную через `%#v`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var (
		i   int
		f   float64
		s   string
		b   bool
		ptr *int
		sl  []int
		mp  map[string]int
		ch  chan bool
		fn  func()
	)

	fmt.Printf("int:            %#v\n", i)
	fmt.Printf("float64:        %#v\n", f)
	fmt.Printf("string:         %#v\n", s)
	fmt.Printf("bool:           %#v\n", b)
	fmt.Printf("*int:           %#v\n", ptr)
	fmt.Printf("[]int:          %#v\n", sl)
	fmt.Printf("map[string]int: %#v\n", mp)
	fmt.Printf("chan bool:      %#v\n", ch)
	fmt.Printf("func():         %#v\n", fn)
}
```

ℹ️ Инспекция всех дефолтных значений

**`Терминал`**

```bash
go run main.go
# int:            0
# float64:        0
# string:         ""
# bool:           false
# *int:           (*int)(nil)
# []int:          []int(nil)
# map[string]int: map[string]int(nil)
# chan bool:      (chan bool)(nil)
# func():         (func())(nil)
```

ℹ️ Точные Go-литералы

## Под капотом

Все ссылочные типы в Go под капотом представляют собой указатели на управляющие структуры рантайма. Нулевое значение для них — это нулевой машинный адрес `0x0` (`nil`).

## Подводные камни

- `nil`-срез `var s []int` имеет `len = 0` и `cap = 0`, при этом `s == nil` истинно. Но в функцию `append(s, 1)` передавать `nil`-срез абсолютно безопасно!

## На собеседовании

**Вопрос с собеседования:** «В чем разница между `nil`-слайсом `var a []int` и пустым слайсом `b := []int{}` при сериализации в JSON?»
**Ответ:** `json.Marshal(a)` вернет JSON `null`, а `json.Marshal(b)` вернет пустой массив `[]`. В REST API это критично для контрактов мобильных клиентов и фронтенда.
