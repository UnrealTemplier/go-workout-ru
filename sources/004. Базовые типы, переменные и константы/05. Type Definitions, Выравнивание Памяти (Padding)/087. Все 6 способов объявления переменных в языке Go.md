# Все 6 способов объявления переменных в языке Go

## Условие

Объяви переменные всеми возможными способами: var x int; var x = 10; var x int = 10; x := 10; var x, y, z = 1, 2, 3; var ( x = 1; y = 2 ). Выведи все переменные.

### Исходная формулировка

Объяви переменные всеми возможными способами:
- `var x int`
- `var x = 10`
- `var x int = 10`
- `x := 10` (краткое объявление)
- `var x, y, z = 1, 2, 3`
- `var ( x = 1; y = 2 )` (групповое объявление)
Выведи все переменные.

## Теория

Полная матрица синтаксических конструкций объявления переменных.

## Решение по шагам

1. Демонстрируем все 6 способов объявления.
2. Выводим значения.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	// Способ 1: var с типом (Zero value)
	var v1 int

	// Способ 2: var с выводом типа
	var v2 = 10

	// Способ 3: var с явным типом и значением
	var v3 int = 20

	// Способ 4: Краткое объявление :=
	v4 := 30

	// Способ 5: Мульти-объявление в одну строку
	var v5a, v5b, v5c = 1, 2, 3

	// Способ 6: Блочное объявление var (...)
	var (
		v6a = 100
		v6b = 200
	)

	fmt.Printf("1. %d, 2. %d, 3. %d, 4. %d\n", v1, v2, v3, v4)
	fmt.Printf("5. %d, %d, %d\n", v5a, v5b, v5c)
	fmt.Printf("6. %d, %d\n", v6a, v6b)
}
```

ℹ️ Все 6 способов объявления переменных

**`Терминал`**

```bash
go run main.go
# 1. 0, 2. 10, 3. 20, 4. 30
# 5. 1, 2, 3
# 6. 100, 200
```

ℹ️ Вывод

## Под капотом

Все формы сводятся компилятором к одинаковым промежуточным представлениям AST `ast.ValueSpec`.

## Подводные камни

- Использование длинных форм `var x int = 10` там, где достаточно `x := 10`.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие семантики `var x = 10` и `x := 10`?»
**Ответ:** Они семантически эквивалентны внутри функции, но `var x = 10` можно использовать на уровне пакета, а `x := 10` — строго внутри функций.
