# Смещение нумерации в iota (January = 1 .. December = 12)

## Условие

**Смещение в iota**: Создайте перечисление месяцев года, используя `iota`, но так, чтобы `January` имел значение 1, а не 0.

## Теория

Для смещения нумерации к первому элементу прибавляют числовую константу:
`January Month = iota + 1`
Все последующие строки автоматически наследуют формулу `iota + 1`.

## Решение по шагам

1. Создаем `type Month int`.
2. Объявляем `January = iota + 1` до `December`.
3. Проверяем значения.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Month int

const (
	January Month = iota + 1 // 1
	February                 // 2
	March                    // 3
	April                    // 4
	May                      // 5
	June                     // 6
	July                     // 7
	August                   // 8
	September                // 9
	October                  // 10
	November                 // 11
	December                 // 12
)

func main() {
	fmt.Printf("January:  %02d\n", January)
	fmt.Printf("July:     %02d\n", July)
	fmt.Printf("December: %02d\n", December)
}
```

ℹ️ Смещение в iota

**`Терминал`**

```bash
go run main.go
# January:  01
# July:     07
# December: 12
```

ℹ️ Вывод

## Под капотом

Компилятор подставляет выражение `iota + 1` в каждую неинициализированную строку константного блока.

## Подводные камни

- Написание формулы на каждой строке: достаточно написать `iota + 1` только в первой строке.

## На собеседовании

**Вопрос с собеседования:** «Как устроен `time.Month` в стандартной библиотеке Go?»
**Ответ:** В точности так же: `type Month int; const ( January Month = 1 + iota; February; ... )`.
