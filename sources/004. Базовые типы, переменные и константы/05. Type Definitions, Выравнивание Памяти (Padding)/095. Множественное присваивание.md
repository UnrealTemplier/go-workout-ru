# Множественное присваивание и циклический сдвиг трех переменных (a, b, c = b, c, a)

## Условие

Напиши программу с множественным присваиванием: `a, b = b, a` (обмен значениями без временной переменной). Реализуй циклический сдвиг трёх переменных: `a, b, c = b, c, a`.

## Теория

**Циклический сдвиг (Circular Shift):**
Выражение `a, b, c = b, c, a`:
1. Временно фиксирует старые значения `(b, c, a)`;
2. Одновременно записывает: в `a` попадает старый `b`, в `b` — старый `c`, в `c` — старый `a`;
3. Выполняется атомарно без промежуточных переменных.

## Решение по шагам

1. Создаем `a, b, c := 1, 2, 3`.
2. Выполняем циклический сдвиг `a, b, c = b, c, a`.
3. Проверяем новые позиции.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	a, b, c := 1, 2, 3
	fmt.Printf("До сдвига:    a = %d, b = %d, c = %d\n", a, b, c)

	// Циклический сдвиг влево
	a, b, c = b, c, a
	fmt.Printf("Сдвиг 1:      a = %d, b = %d, c = %d\n", a, b, c)

	// Повторный сдвиг
	a, b, c = b, c, a
	fmt.Printf("Сдвиг 2:      a = %d, b = %d, c = %d\n", a, b, c)
}
```

ℹ️ Циклический сдвиг трех переменных

**`Терминал`**

```bash
go run main.go
# До сдвига:    a = 1, b = 2, c = 3
# Сдвиг 1:      a = 2, b = 3, c = 1
# Сдвиг 2:      a = 3, b = 1, c = 2
```

ℹ️ Результат сдвига

## Под капотом

Компилятор загружает значения в три регистра процессора и сохраняет их в новые слоты памяти.

## Подводные камни

## На собеседовании

**Вопрос с собеседования:** «Как реализовать генератор чисел Фибоначчи в цикле через множественное присваивание?»
**Ответ:** `a, b = 0, 1; for i := 0; i < n; i++ { a, b = b, a+b }`.
