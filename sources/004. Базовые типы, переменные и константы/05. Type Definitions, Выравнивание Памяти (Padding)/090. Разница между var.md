# Разница между var и := при создании новой переменной и затенении

## Условие

Напиши программу, которая демонстрирует разницу между `var` и `:=` внутри функции. Покажи случай, когда `:=` создаёт новую переменную, а когда переиспользует существующую (shadowing).

## Теория

Сравнение `var` и `:=`:
- `var` объявляет переменную с фиксированным типом;
- `:=` в том же блоке перезаписывает существующую (при наличии новой), но во вложенном блоке **затеняет** её.

## Решение по шагам

1. Демонстрируем частичное переприсваивание на верхнем уровне функции.
2. Демонстрируем затенение во вложенном блоке.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	// 1. Частичное переприсваивание (переиспользование):
	a := 10
	a, b := 20, "hello" // a переиспользована, b создана
	fmt.Printf("1. Внешний a = %d, b = %s\n", a, b)

	// 2. Вложенный блок (создание новой изолированной переменной):
	if true {
		a := 999 // Новая переменная в Block Scope!
		fmt.Printf("2. Внутренний затененный a = %d\n", a)
	}

	fmt.Printf("3. Внешний a после блока = %d\n", a)
}
```

ℹ️ Переиспользование vs Затенение

**`Терминал`**

```bash
go run main.go
# 1. Внешний a = 20, b = hello
# 2. Внутренний затененный a = 999
# 3. Внешний a после блока = 20
```

ℹ️ Вывод

## Под капотом

В первом случае генерируется `OpCopy`, во втором — `OpVarDef` нового стекового слота.

## Подводные камни

- Ошибочное ожидание, что `a := 999` внутри `if` обновит внешний `a`.

## На собеседовании

**Вопрос с собеседования:** «Как обновить внешнюю переменную внутри блока `if` без затенения?»
**Ответ:** Использовать обычный оператор присваивания `=`, а не короткое объявление `:=`.
