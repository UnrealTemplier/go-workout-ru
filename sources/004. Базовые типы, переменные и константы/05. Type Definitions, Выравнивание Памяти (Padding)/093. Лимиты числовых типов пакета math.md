# Лимиты числовых типов пакета math (MaxInt8, MinFloat32)

## Условие

Поиск лимитов: Используя пакет math (например, math.MaxInt8, math.MinFloat32), выведите максимальные и минимальные значения для типов int8, uint16, float32.

### Исходная формулировка

**Поиск лимитов**: Используя пакет `math` (например, `math.MaxInt8`, `math.MinFloat32`), выведите максимальные и минимальные значения для типов `int8`, `uint16`, `float32`.

## Теория

Константы пакета `math`:
- `int8`: `math.MinInt8` (-128) .. `math.MaxInt8` (127);
- `uint16`: 0 .. `math.MaxUint16` (65535);
- `float32`: `math.SmallestNonzeroFloat32` (\(1.4 \times 10^{-45}\)) .. `math.MaxFloat32` (\(3.4 \times 10^{38}\)).

## Решение по шагам

1. Импортируем `math`.
2. Выводим границы типов.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"math"
)

func main() {
	fmt.Println("=== ЧИСЛОВЫЕ ЛИМИТЫ (math) ===")
	fmt.Printf("int8:    мин = %d, макс = %d\n", math.MinInt8, math.MaxInt8)
	fmt.Printf("uint16:  мин = %d, макс = %d\n", 0, math.MaxUint16)
	fmt.Printf("float32: мин положит = %e, макс = %e\n",
		math.SmallestNonzeroFloat32, math.MaxFloat32)
}
```

ℹ️ Лимиты типов в math

**`Терминал`**

```bash
go run main.go

# uint16:  мин = 0, макс = 65535

```

## Под капотом

Все константы разрешаются компилятором без системных вызовов.

## Подводные камни

- Путаница между `SmallestNonzeroFloat32` (наименьшее положительное ненулевое число) и `-MaxFloat32` (наименьшее отрицательное число).

## На собеседовании

**Вопрос с собеседования:** «Чему равно минимальное отрицательное число типа `float64`?»
**Ответ:** `-math.MaxFloat64` (\(\approx -1.79 \times 10^{38}\)).
