# Инициализация переменной типа byte символом 'A' и вывод кода

## Условие

Создай переменную типа `byte` и присвой ей символ `'A'`. Выведи его числовое значение.

## Теория

Символьный литерал `'A'`:
- Тип `byte` (`uint8`);
- ASCII код буквы 'A' равен `65` (`0x41`).

## Решение по шагам

1. Объявляем `var b byte = 'A'`.
2. Выводим как символ и как число.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var b byte = 'A'

	fmt.Printf("Символ:       %c\n", b)
	fmt.Printf("ASCII код:    %d\n", b)
	fmt.Printf("HEX код:      0x%X\n", b)
	fmt.Printf("Тип переменной:%T\n", b)
}
```

ℹ️ Переменная типа byte

**`Терминал`**

```bash
go run main.go
# Символ:       A
# ASCII код:    65
# HEX код:      0x41
# Тип переменной:uint8
```

ℹ️ Результат

## Под капотом

Компилятор подставляет константу 65 в 1-байтовый регистр `AL`.

## Подводные камни

- Попытка присвоить кириллический символ `var b byte = 'Я'`: компилятор выдаст ошибку `constant 1071 overflows byte`.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go `byte` является алиасом `uint8`, а не отдельным типом?»
**Ответ:** Чтобы не плодить лишних приведений типов между сырыми байтами и числами при работе с сетевыми сокетами и файлами.
