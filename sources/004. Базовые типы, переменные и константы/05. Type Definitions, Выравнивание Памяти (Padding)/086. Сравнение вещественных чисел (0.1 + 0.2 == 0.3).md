# Сравнение вещественных чисел (0.1 + 0.2 == 0.3) и функция AlmostEqual с эпсилон

## Условие

**Сравнение вещественных чисел**: Создайте две переменные `float64` со значениями `0.1 + 0.2` и `0.3`. Сравните их через `==`. Напишите правильную функцию сравнения вещественных чисел с использованием небольшой дельты (эпсилон).

## Теория

**Функция AlmostEqual:**
$$|a - b| < \varepsilon$$
Где \(\varepsilon = 10^{-9}\) — допустимая погрешность округления чисел IEEE 754.

## Решение по шагам

1. Демонстрируем ложность `0.1 + 0.2 == 0.3`.
2. Реализуем `AlmostEqual(a, b, epsilon float64) bool`.
3. Проверяем правильность работы.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"math"
)

func AlmostEqual(a, b, epsilon float64) bool {
	return math.Abs(a-b) < epsilon
}

func main() {
	a := 0.1 + 0.2
	b := 0.3

	fmt.Printf("a = %.20f\n", a)
	fmt.Printf("b = %.20f\n\n", b)

	fmt.Printf("1. Прямое сравнение (a == b): %t (ОШИБОЧНО!)\n", a == b)
	fmt.Printf("2. Безопасное AlmostEqual:   %t (КОРРЕКТНО!)\n", AlmostEqual(a, b, 1e-9))
}
```

ℹ️ Корректное сравнение вещественных чисел

**`Терминал`**

```bash
go run main.go
# a = 0.30000000000000004441
# b = 0.29999999999999998890
# 
# 1. Прямое сравнение (a == b): false (ОШИБОЧНО!)
# 2. Безопасное AlmostEqual:   true (КОРРЕКТНО!)
```

## Под капотом

Функция `math.Abs` сбрасывает старший знаковый бит числа через битовую маску за 1 такт.

## Подводные камни

- Использование `==` при проверке баланса в финтех-сервисах.

## На собеседовании

**Вопрос с собеседования:** «Почему для очень больших или очень маленьких вещественных чисел абсолютный эпсилон \(|a - b| < \varepsilon\) работает плохо и как его заменить?»
**Ответ:** Для чисел произвольного масштаба используют относительный эпсилон (Relative Epsilon): \(|a - b| \le \varepsilon \cdot \max(|a|, |b|)\).
