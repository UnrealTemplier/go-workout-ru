# Программное извлечение вещественной и мнимой части комплексного числа

## Условие

**Комплексные числа**: Создайте комплексное число `3 + 4i`. Извлеките его действительную и мнимую части программным путем.

## Теория

Встроенные функции Go:
- `real(c)` — возвращает вещественную часть;
- `imag(c)` — возвращает мнимую часть.

## Решение по шагам

1. Создаем `c := 3 + 4i`.
2. Извлекаем `re := real(c)` и `im := imag(c)`.
3. Выводим результаты.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	c := 3 + 4i

	re := real(c)
	im := imag(c)

	fmt.Printf("Комплексное число: %v\n", c)
	fmt.Printf("Действительная Re: %.2f (тип: %T)\n", re, re)
	fmt.Printf("Мнимая Im:         %.2f (тип: %T)\n", im, im)
}
```

ℹ️ Функции real() и imag()

**`Терминал`**

```bash
go run main.go
# Комплексное число: (3+4i)
# Действительная Re: 3.00 (тип: float64)
# Мнимая Im:         4.00 (тип: float64)
```

ℹ️ Вывод

## Под капотом

Функции `real` и `imag` являются встроенными интринсиками (Compiler Intrinsics) и компилируются в прямое чтение первого или второго 64-битного слова из памяти.

## Подводные камни

- Попытка передать некомплексное число в `real()`.

## На собеседовании

**Вопрос с собеседования:** «Каковы типы возвращаемых значений `real(c)` для `complex64` и `complex128`?»
**Ответ:** Для `complex64` возвращается `float32`, для `complex128` — `float64`.
