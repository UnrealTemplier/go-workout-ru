# Базовые перечисления дней недели на iota

## Условие

**Перечисления через iota (база)**: Создай блок констант, представляющих дни недели (Понедельник=0, Вторник=1, ...), используя `iota`.

## Теория

Базовый шаблон констант от 0 до 6.

## Решение по шагам

1. Создаем блок констант дней недели.
2. Выводим значения.

## Код решения

**`main.go`**

```go
package main

import "fmt"

const (
	Monday = iota
	Tuesday
	Wednesday
	Thursday
	Friday
	Saturday
	Sunday
)

func main() {
	fmt.Printf("Понедельник: %d\n", Monday)
	fmt.Printf("Вторник:     %d\n", Tuesday)
	fmt.Printf("Пятница:     %d\n", Friday)
	fmt.Printf("Воскресенье: %d\n", Sunday)
}
```

ℹ️ Базовое перечисление

**`Терминал`**

```bash
go run main.go
# Понедельник: 0
# Вторник:     1
# Пятница:     4
# Воскресенье: 6
```

ℹ️ Вывод

## Под капотом

Все константы разрешаются в целые числа 0..6 на этапе компиляции.

## Подводные камни

- Забыть, что `Monday` будет равен 0.

## На собеседовании

**Вопрос с собеседования:** «Можно ли объявить константу `iota` вне блока `const`?»
**Ответ:** Нет, `iota` имеет смысл и компилируется исключительно внутри спецификаций констант `const`.
