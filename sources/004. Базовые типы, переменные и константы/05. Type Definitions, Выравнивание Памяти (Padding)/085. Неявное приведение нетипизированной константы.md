# Неявное приведение нетипизированной константы при умножении на float64

## Условие

Изучи неявное преобразование нетипизированных констант: умножь целочисленную константу на `float64` переменную без ошибок.

## Теория

Нетипизированная константа `const Multiplier = 10` не имеет фиксированного типа и принимает тип соседнего операнда `float64`.

## Решение по шагам

1. Объявляем `const Multiplier = 10`.
2. Умножаем на `var price float64 = 19.99`.
3. Проверяем компиляцию без явного каста.

## Код решения

**`main.go`**

```go
package main

import "fmt"

const Multiplier = 10 // Нетипизированная константа

func main() {
	var price float64 = 19.99

	// Нетипизированный Multiplier плавно адаптируется под float64:
	total := price * Multiplier

	fmt.Printf("Итого: %.2f (тип: %T)\n", total, total)
}
```

ℹ️ Умножение нетипизированной константы на float64

**`Терминал`**

```bash
go run main.go
# Итого: 199.90 (тип: float64)
```

ℹ️ Вывод

## Под капотом

Компилятор вычисляет `price * float64(10.0)`.

## Подводные камни

- Попытка сделать то же самое с переменной `var m int = 10; price * m` вызовет ошибку компиляции.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между `const a = 10` и `var a = 10` в плане типизации?»
**Ответ:** `const a = 10` — нетипизированная константа без жесткого типа. `var a = 10` — типизированная переменная, которой компилятор жестко присвоил тип `int`.
