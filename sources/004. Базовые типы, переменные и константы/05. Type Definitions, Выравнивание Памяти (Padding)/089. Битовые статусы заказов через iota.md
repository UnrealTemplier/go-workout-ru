# Битовые статусы заказов через iota и сдвиг влево 1 << iota

## Условие

**Магия iota**: Задай статусы заказов (Pending=1, Processing=2, Completed=4, Failed=8), используя `iota` и оператор побитового сдвига `<<`.

## Теория

Битовые флаги статусов заказов:
- `Pending = 1 << 0` (1)
- `Processing = 1 << 1` (2)
- `Completed = 1 << 2` (4)
- `Failed = 1 << 3` (8)

## Решение по шагам

1. Создаем `OrderStatus = 1 << iota`.
2. Выводим значения констант.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type OrderStatus int

const (
	Pending OrderStatus = 1 << iota // 1
	Processing                      // 2
	Completed                       // 4
	Failed                          // 8
)

func main() {
	fmt.Printf("Pending:    %04b (%d)\n", Pending, Pending)
	fmt.Printf("Processing: %04b (%d)\n", Processing, Processing)
	fmt.Printf("Completed:  %04b (%d)\n", Completed, Completed)
	fmt.Printf("Failed:     %04b (%d)\n", Failed, Failed)
}
```

ℹ️ Статусы заказов через битовый сдвиг

**`Терминал`**

```bash
go run main.go
# Pending:    0001 (1)
# Processing: 0010 (2)
# Completed:  0100 (4)
# Failed:     1000 (8)
```

ℹ️ Результат

## Под капотом

Битовые флаги позволяют хранить до 64 различных состояний объекта в одном 8-байтном поле `uint64`.

## Подводные камни

- Сложение битовых флагов через `+` вместо `|`: если флаг добавлен дважды, `+` приведет к перескоку бита в соседний разряд. Всегда используйте побитовое ИЛИ `|`.

## На собеседовании

**Вопрос с собеседования:** «Как проверить, находится ли заказ в одном из финальных статусов (`Completed` или `Failed`) одной операцией?»
**Ответ:** `isFinal := (status & (Completed | Failed)) != 0`.
