# Пропуск значений 0 и 1 в iota через множественный blank identifier

## Условие

**Пропуск значений в iota**: Создайте перечисление, в котором значения 0 и 1 пропускаются с помощью пустого идентификатора `_`, а константы начинаются со значения 2.

## Теория

Для пропуска нескольких значений `iota`:
- `_ = iota` (0)
- `_` (1)
- `ItemA` (2)
- `ItemB` (3)

## Решение по шагам

1. Создаем блок констант с пропуском 0 и 1.
2. Проверяем, что константы начинаются с 2.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Priority int

const (
	_            Priority = iota // 0 (пропущен)
	_                            // 1 (пропущен)
	PriorityLow                  // 2
	PriorityMedium               // 3
	PriorityHigh                 // 4
)

func main() {
	fmt.Printf("PriorityLow:    %d\n", PriorityLow)
	fmt.Printf("PriorityMedium: %d\n", PriorityMedium)
	fmt.Printf("PriorityHigh:   %d\n", PriorityHigh)
}
```

ℹ️ Пропуск нескольких значений в iota

**`Терминал`**

```bash
go run main.go
# PriorityLow:    2
# PriorityMedium: 3
# PriorityHigh:   4
```

ℹ️ Результат

## Под капотом

Каждая строка блока увеличивает внутренний счетчик `iota` на 1.

## Подводные камни

- Забыть, что пропуск `_` всё равно расходует индекс `iota`.

## На собеседовании

**Вопрос с собеседования:** «Как начать нумерацию `iota` сразу с 100?»
