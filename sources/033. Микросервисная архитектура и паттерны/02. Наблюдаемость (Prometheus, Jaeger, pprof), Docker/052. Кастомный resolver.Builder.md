# Кастомный resolver.Builder: динамическая интеграция gRPC с Consul или etcd

## Условие

Реализуйте кастомный `resolver.Builder` для интеграции с Consul или etcd для service discovery.

## Теория

Архитектура собственного резолвера gRPC:
- Интерфейс `resolver.Builder`:
  - `Build(target resolver.Target, cc resolver.ClientConn, opts resolver.BuildOptions) (resolver.Resolver, error)`
  - `Scheme() string` — префикс схемы, например `"consul"`.
- Интерфейс `resolver.Resolver`:
  - `ResolveNow(resolver.ResolveNowOptions)` — принудительное обновление адресов.
  - `Close()` — освобождение ресурсов.
- При изменении подов резолвер вызывает:
  `cc.UpdateState(resolver.State{Addresses: []resolver.Address{...}})`

## Решение по шагам

1. Реализуйте структуру кастомного билдера с методом `Scheme()`.
2. Реализуйте метод `Build` с уведомлением `cc.UpdateState`.
3. Зарегистрируйте билдер в глобальном реестре `resolver.Register`.
4. Протестируйте резолвинг схемы `consul:///`.

## Код решения

**`custom_consul_resolver_test.go`**

```go
package main

import (
	"fmt"
	"testing"

	"google.golang.org/grpc/resolver"
)

type CustomConsulBuilder struct{}

func (b *CustomConsulBuilder) Scheme() string {
	return "myconsul"
}

func (b *CustomConsulBuilder) Build(
	target resolver.Target,
	cc resolver.ClientConn,
	opts resolver.BuildOptions,
) (resolver.Resolver, error) {
	// Имитируем запрос к Consul API
	endpoints := []resolver.Address{
		{Addr: "10.0.2.50:50051"},
		{Addr: "10.0.2.51:50051"},
	}

	// Передаем адреса в ядро gRPC
	err := cc.UpdateState(resolver.State{Addresses: endpoints})
	if err != nil {
		return nil, err
	}

	return &noopResolver{}, nil
}

type noopResolver struct{}
func (r *noopResolver) ResolveNow(resolver.ResolveNowOptions) {}
func (r *noopResolver) Close()                                {}

func TestCustomResolverRegistration(t *testing.T) {
	builder := &CustomConsulBuilder{}
	resolver.Register(builder)

	// Проверяем, что схема зарегистрирована
	found := resolver.Get("myconsul")
	if found == nil {
		t.Fatal("Резолвер myconsul не зарегистрирован!")
	}

	fmt.Printf("Кастомный резолвер gRPC успешно зарегистрирован для схемы: %s:///\n", found.Scheme())
}
```

## Под капотом

Функция `resolver.Register` сохраняет билдер в глобальной потокобезопасной карте. При вызове `grpc.NewClient("myconsul:///service")` gRPC автоматически выбирает нужный билдер по схеме URI.

## Подводные камни

Блокировать вызов `Build()` долгим сетевым запросом к Consul: метод `Build` должен быстро запустить фоновую горутину отслеживания, иначе создание gRPC клиента зависнет.

## На собеседовании

**Вопрос с собеседования:** «Когда вызывается метод ResolveNow у кастомного резолвера?»
**Ответ:** gRPC вызывает `ResolveNow()`, когда все существующие соединения SubConn перешли в статус сбоя (`TRANSIENT_FAILURE`). Это сигнал резолверу немедленно опросить Consul/DNS повторно, так как текущие IP-адреса, вероятно, устарели.
