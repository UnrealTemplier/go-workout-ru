# Авторегистрация в Service Discovery: регистрация адреса в Consul при старте и динамический lookup

## Условие

**Регистрация и обнаружение сервисов (Service Discovery)**: Поднимите локальный инстанс HashiCorp Consul или etcd (можно в Docker). Напишите код на Go, который при старте вашего gRPC-сервера автоматически регистрирует его адрес и порт в системе Service Discovery. Напишите код gRPC-клиента, который не знает жесткого адреса сервера, а перед вызовом запрашивает актуальный список доступных IP-адресов серверов у Consul.

## Теория

Процесс Service Registration & Client Lookup в Consul:
1. **Регистрация сервиса при запуске:**
   ```go
   registration := &api.AgentServiceRegistration{
       ID:      "order-service-pod-42",
       Name:    "order-service",
       Port:    50051,
       Address: "10.0.1.15",
       Check:   &api.AgentServiceCheck{GRPC: "10.0.1.15:50051", Interval: "10s"},
   }
   consul.Agent().ServiceRegister(registration)
   ```
2. **Graceful Deregistration при завершении:**
   `defer consul.Agent().ServiceDeregister("order-service-pod-42")`
3. **Клиентский Lookup:**
   `entries, _, _ := consul.Health().Service("order-service", "", true, nil)` — возвращает только здоровые поды.

## Решение по шагам

1. Создайте структуру сервисного агента Consul.
2. Реализуйте регистрацию с проверкой здоровья.
3. Напишите клиентский метод `LookupHealthyEndpoints`.
4. Протестируйте обнаружение сервиса.

## Код решения

**`consul_lifecycle_test.go`**

```go
package main

import (
	"fmt"
	"sync"
	"testing"
)

type RegisteredInstance struct {
	ID      string
	Service string
	Address string
	Port    int
	Healthy bool
}

type MockConsulAgent struct {
	mu       sync.RWMutex
	services map[string]*RegisteredInstance
}

func NewMockConsul() *MockConsulAgent {
	return &MockConsulAgent{services: make(map[string]*RegisteredInstance)}
}

func (c *MockConsulAgent) ServiceRegister(id, service, addr string, port int) error {
	c.mu.Lock()
	defer c.mu.Unlock()
	c.services[id] = &RegisteredInstance{
		ID:      id,
		Service: service,
		Address: addr,
		Port:    port,
		Healthy: true,
	}
	return nil
}

func (c *MockConsulAgent) ServiceDeregister(id string) error {
	c.mu.Lock()
	defer c.mu.Unlock()
	delete(c.services, id)
	return nil
}

func (c *MockConsulAgent) LookupHealthy(service string) []string {
	c.mu.RLock()
	defer c.mu.RUnlock()
	var addrs []string
	for _, inst := range c.services {
		if inst.Service == service && inst.Healthy {
			addrs = append(addrs, fmt.Sprintf("%s:%d", inst.Address, inst.Port))
		}
	}
	return addrs
}

func TestConsulDiscoveryWorkflow(t *testing.T) {
	consul := NewMockConsul()

	// 1. Старт пода и регистрация
	_ = consul.ServiceRegister("order-pod-1", "order-service", "10.0.1.15", 50051)
	_ = consul.ServiceRegister("order-pod-2", "order-service", "10.0.1.16", 50051)

	// 2. Клиент резолвит адреса
	endpoints := consul.LookupHealthy("order-service")
	if len(endpoints) != 2 {
		t.Fatalf("Ожидалось 2 адреса, получено: %d", len(endpoints))
	}
	fmt.Printf("Клиент динамически обнаружил endpoints: %v\n", endpoints)

	// 3. Graceful Shutdown первого пода
	_ = consul.ServiceDeregister("order-pod-1")

	endpointsAfter := consul.LookupHealthy("order-service")
	if len(endpointsAfter) != 1 || endpointsAfter[0] != "10.0.1.16:50051" {
		t.Fatalf("Некорректный список после дерегистрации: %v", endpointsAfter)
	}
	fmt.Printf("После дерегистрации остался активный endpoint: %v\n", endpointsAfter)
}
```

## Под капотом

Consul использует протокол Gossip (библиотека Memberlist на базе SWIM) для мгновенного обнаружения падений нод в кластере без перегрузки центрального сервера.

## Подводные камни

Забывать вызывать `ServiceDeregister` при получении `SIGTERM`: под уже завершил работу, а Consul будет направлять на него трафик еще 10–30 секунд до срабатывания Health Check таймаута.

## На собеседовании

**Вопрос с собеседования:** «Что делать клиенту, если кластер Consul временно стал недоступен?»
**Ответ:** Клиент обязан реализовать локальное кэширование списка адресов (Last Known Good Endpoints). При отказе Consul клиент продолжает обращаться к последним известным подам, обеспечивая автономность системы.
