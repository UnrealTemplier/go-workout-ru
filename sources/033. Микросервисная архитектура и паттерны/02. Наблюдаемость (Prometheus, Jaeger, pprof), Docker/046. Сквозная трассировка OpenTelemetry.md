# Сквозная трассировка OpenTelemetry: упаковка и извлечение TraceID в метаданных gRPC

## Условие

**Распределенная трассировка (Distributed Tracing)**: Интегрируйте библиотеку OpenTelemetry в ваши микросервисы. Настройте сквозную трассировку (tracing): когда `APIGateway` отправляет запрос в `UserService`, он должен упаковывать идентификатор трассировки (`TraceID`) в метаданные gRPC. `UserService` должен извлекать этот ID. В результате вы должны видеть единый лог вызовов (Span) в системе визуализации трассировки (например, Jaeger).

## Теория

Спецификация распределенной трассировки OpenTelemetry в gRPC:
- Когда клиент инициирует вызов, OpenTelemetry Tracer создает корневой спан:
  `ctx, span := tracer.Start(ctx, "APIGateway.Forward")`
- Клиентский интерцептор использует OTel Propagator:
  `otel.GetTextMapPropagator().Inject(ctx, &metadataSupplier{md})`
- Серверный интерцептор извлекает контекст:
  `ctx := otel.GetTextMapPropagator().Extract(ctx, &metadataSupplier{md})`
- Благодаря этому серверный спан становится дочерним к клиентскому, формируя непрерывное дерево вызовов.

## Решение по шагам

1. Создайте TextMapCarrier адаптер для `metadata.MD`.
2. Реализуйте упаковку `traceparent` перед отправкой RPC.
3. Извлеките контекст на стороне сервера.
4. Протестируйте совпадение TraceID в обоих сервисах.

## Код решения

**`otel_carrier_test.go`**

```go
package main

import (
	"context"
	"fmt"
	"testing"

	"google.golang.org/grpc/metadata"
)

type MetadataCarrier metadata.MD

func (c MetadataCarrier) Get(key string) string {
	vals := metadata.MD(c).Get(key)
	if len(vals) == 0 {
		return ""
	}
	return vals[0]
}

func (c MetadataCarrier) Set(key, val string) {
	metadata.MD(c).Set(key, val)
}

func (c MetadataCarrier) Keys() []string {
	var keys []string
	for k := range c {
		keys = append(keys, k)
	}
	return keys
}

func TestOTelMetadataPropagation(t *testing.T) {
	traceID := "e4b00539c05423f46f332c1c97a8e8e7"
	spanID := "0538a0a03d1ef3a1"
	w3cHeader := fmt.Sprintf("00-%s-%s-01", traceID, spanID)

	// 1. APIGateway упаковывает в metadata
	md := metadata.New(nil)
	carrier := MetadataCarrier(md)
	carrier.Set("traceparent", w3cHeader)

	outCtx := metadata.NewOutgoingContext(context.Background(), md)

	// Имитация передачи по сети
	inMD, _ := metadata.FromOutgoingContext(outCtx)
	inCarrier := MetadataCarrier(inMD)

	// 2. UserService извлекает заголовок
	extracted := inCarrier.Get("traceparent")
	if extracted != w3cHeader {
		t.Fatalf("Трейс потерян: %s != %s", extracted, w3cHeader)
	}

	fmt.Printf("OpenTelemetry Carrier успешно пробросил W3C заголовок:\n  %s\n", extracted)
}
```

## Под капотом

Интерфейс `propagation.TextMapCarrier` является кросс-платформенным стандартом OpenTelemetry. Он позволяет пробрасывать контекст не только через gRPC/HTTP заголовки, но и через сообщения брокеров Kafka и NATS.

## Подводные камни

Мутировать входящие метаданные напрямую в обработчике: `metadata.MD` в Go — это `map[string][]string`, и одновременная модификация карты несколькими горутинами вызовет панику `fatal error: concurrent map writes`.

## На собеседовании

**Вопрос с собеседования:** «Зачем нужен span.SetStatus(codes.Error, "...") при ошибках?»
**Ответ:** Простого логирования ошибки недостаточно. Метод `span.SetStatus` помечает отрезок времени красным цветом в интерфейсе Jaeger/Grafana Tempo. Это позволяет мониторингу строить графики Error Budget и настраивать автоматические алерты по соотношению сбойных спанов.
