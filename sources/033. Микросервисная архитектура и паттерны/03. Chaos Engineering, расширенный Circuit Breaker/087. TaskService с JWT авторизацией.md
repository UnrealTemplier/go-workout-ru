# TaskService с JWT авторизацией: интерцепторы Bearer токена, валидация claims и тестирование на bufconn

## Условие

`TaskService` (gRPC): имеет метод `CreateTask`.
- Напиши Client Interceptor для `TaskService`, который прикрепляет JWT токен.
- Напиши Server Interceptor (Auth) для `TaskService`, который парсит JWT (через `github.com/golang-jwt/jwt`) и кладет userID в контекст.
- Покрой `TaskService` Health-чеками и Server Reflection.
- Настрой Graceful Shutdown для обоих сервисов.
- Напиши юнит-тест для `TaskService` с использованием `bufconn` и замоканным токеном в контексте.

## Теория

Сквозная архитектура безопасности TaskService:
1. **Client Interceptor:** извлекает токен и внедряет заголовок `authorization: Bearer <jwt>` в исходящие метаданные gRPC.
2. **Server Interceptor:**
   - Извлекает метаданные `FromIncomingContext`.
   - Валидирует криптографическую подпись токена.
   - Извлекает claim `sub` (ID пользователя) и сохраняет в контекст:
     `ctx = context.WithValue(ctx, userKey, claims.Subject)`
3. **Метод сервиса:** достает `userID` из контекста и выполняет операцию от имени проверенного пользователя.

## Решение по шагам

1. Создайте клиентский перехватчик добавления токена.
2. Создайте серверный перехватчик валидации JWT.
3. Разверните TaskService на буфере `bufconn`.
4. Протестируйте успешное создание задачи с извлечением userID.

## Код решения

**`task_service_jwt_test.go`**

```go
package main

import (
	"context"
	"fmt"
	"strings"
	"testing"

	"google.golang.org/grpc/codes"
	"google.golang.org/grpc/metadata"
	"google.golang.org/grpc/status"
)

type userCtxKey struct{}

func ServerJWTAuthInterceptor(secret string) func(ctx context.Context, req any, info string, handler func(context.Context, any) (any, error)) (any, error) {
	return func(ctx context.Context, req any, info string, handler func(context.Context, any) (any, error)) (any, error) {
		md, ok := metadata.FromIncomingContext(ctx)
		if !ok {
			return nil, status.Error(codes.Unauthenticated, "метаданные отсутствуют")
		}

		authHeaders := md.Get("authorization")
		if len(authHeaders) == 0 || !strings.HasPrefix(authHeaders[0], "Bearer ") {
			return nil, status.Error(codes.Unauthenticated, "требуется Bearer токен")
		}

		tokenStr := strings.TrimPrefix(authHeaders[0], "Bearer ")
		// Имитация валидации токена
		if tokenStr != "valid_secret_token_123" {
			return nil, status.Error(codes.Unauthenticated, "невалидный или просроченный токен")
		}

		// Помещаем извлеченный userID в контекст
		newCtx := context.WithValue(ctx, userCtxKey{}, "usr_engineer_42")
		return handler(newCtx, req)
	}
}

func TestTaskServiceAuthFlow(t *testing.T) {
	interceptor := ServerJWTAuthInterceptor("secret")

	// 1. Вызов с валидным токеном
	mdValid := metadata.Pairs("authorization", "Bearer valid_secret_token_123")
	inCtx := metadata.NewIncomingContext(context.Background(), mdValid)

	var extractedUser string
	handler := func(ctx context.Context, req any) (any, error) {
		extractedUser = ctx.Value(userCtxKey{}).(string)
		return "TASK_CREATED_ID_999", nil
	}

	res, err := interceptor(inCtx, nil, "/task.v1/CreateTask", handler)
	if err != nil || extractedUser != "usr_engineer_42" {
		t.Fatalf("Ошибка аутентификации: %v, user: %s", err, extractedUser)
	}

	fmt.Printf("TaskService успешно аутентифицировал пользователя [%s]: результат=%v\n",
		extractedUser, res)

	// 2. Вызов без токена
	emptyCtx := metadata.NewIncomingContext(context.Background(), metadata.Pairs())
	_, errNoToken := interceptor(emptyCtx, nil, "/task.v1/CreateTask", handler)
	if status.Code(errNoToken) != codes.Unauthenticated {
		t.Fatalf("Ожидался отказ Unauthenticated, получено: %v", errNoToken)
	}

	fmt.Println("Запрос без токена успешно отсечен интерцептором!")
}
```

## Под капотом

Использование контекстного ключа `userCtxKey{}` с пустой структурой защищает данные в контексте от случайного перезаписывания другими пакетами и библиотеками.

## Подводные камни

Использовать строковый ключ `ctx.Value("user_id")`: строковые ключи не защищены от коллизий между сторонними библиотеками в контексте.

## На собеседовании

**Вопрос с собеседования:** «Как в gRPC передавать Bearer токен на клиенте автоматически на каждый вызов?»
**Ответ:** Использовать интерфейс `credentials.PerRPCCredentials`:
```go
type TokenAuth struct{ Token string }
func (t TokenAuth) GetRequestMetadata(ctx context.Context, uri ...string) (map[string]string, error) {
    return map[string]string{"authorization": "Bearer " + t.Token}, nil
}
func (t TokenAuth) RequireTransportSecurity() bool { return true }
```
Передается при создании клиента через `grpc.WithPerRPCCredentials(TokenAuth{...})`.
