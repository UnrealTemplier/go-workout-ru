# Срез из массива [6]int{10,20,30,40,50,60} и мутация s[0] = 99

## Условие

**Создание среза из массива**: Создайте массив `arr := [6]int{10, 20, 30, 40, 50, 60}`. Создайте срез `s := arr[1:4]`. Выведите элементы среза, его длину `len(s)` и емкость `cap(s)`. Измените `s[0] = 99`. Выведите исходный массив `arr`. Поменялся ли он?

## Теория

Расчет параметров:
- `len(s) = 4 - 1 = 3`;
- `cap(s) = 6 - 1 = 5`;
- `s[0] = 99` изменяет `arr[1]`.

## Решение по шагам

1. Объявляем `arr := [6]int{10, 20, 30, 40, 50, 60}`.
2. Создаем `s := arr[1:4]`.
3. Мутируем `s[0] = 99`.
4. Выводим массив `arr`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	arr := [6]int{10, 20, 30, 40, 50, 60}
	s := arr[1:4]

	fmt.Printf("Срез s:      %v | len = %d, cap = %d\n", s, len(s), cap(s))
	s[0] = 99

	fmt.Printf("Срез после:  %v\n", s)
	fmt.Printf("Массив arr:  %v (arr[1] изменился на 99!)\n", arr)
}
```

ℹ️ Срез из массива 6 элементов

**`Терминал`**

```bash
go run main.go
# Срез s:      [20 30 40] | len = 3, cap = 5
# Срез после:  [99 30 40]
# Массив arr:  [10 99 30 40 50 60] (arr[1] изменился на 99!)
```

ℹ️ Вывод

## Под капотом

Разделение памяти между `arr` и `s`.

## Подводные камни

- Неверный расчет емкости: `cap` равен 5, а не 3.

## На собеседовании

**Вопрос с собеседования:** «До какого индекса массива `arr` может безопасно дорасти срез `s` без реаллокации?»
**Ответ:** До конца массива `arr` (включая `arr[5]`), так как `cap(s) == 5`.
