# Создание среза через make([]int, 3) и гарантия Zero Values

## Условие

Создай пустой слайс с помощью `make([]int, 3)`. Выведи значения (они должны быть нулями).

## Теория

Вызов `make([]int, 3)` инициализирует срез длины 3 и емкости 3, где все 3 элемента равны `0`.

## Решение по шагам

1. Создаем `s := make([]int, 3)`.
2. Выводим срез и проверяем равенство нулю всех ячеек.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	s := make([]int, 3)

	fmt.Printf("Срез s: %v | len = %d, cap = %d\n", s, len(s), cap(s))
	for i, v := range s {
		fmt.Printf("  s[%d] = %d\n", i, v)
	}
}
```

ℹ️ Срез из 3 нулей

**`Терминал`**

```bash
go run main.go
# Срез s: [0 0 0] | len = 3, cap = 3
#   s[0] = 0
#   s[1] = 0
#   s[2] = 0
```

ℹ️ Вывод

## Под капотом

`runtime.makeslice` выделяет 24 байта памяти под 3 целых числа и обнуляет их.

## Подводные камни

- Добавление элементов через `append`: `s = append(s, 10)` добавит 10 на индекс 3, сделав срез `[0 0 0 10]`.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между `make([]int, 3)` и `make([]int, 0, 3)`?»
**Ответ:** Первый имеет `len=3` (3 готовых нуля, запись по индексу `s[i]`), второй имеет `len=0, cap=3` (пустой срез, готов к заполнению через `append`).
