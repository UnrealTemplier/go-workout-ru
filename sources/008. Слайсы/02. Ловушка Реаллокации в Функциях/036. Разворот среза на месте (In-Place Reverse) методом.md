# Разворот среза на месте (In-Place Reverse) методом Two Pointers

## Условие

Сделайте «reverse in-place»: разверните слайс без выделения дополнительной памяти.

## Теория

Алгоритм разворота сходящимися указателями `i` и `j` со сложностью \(O(N)\) по времени и \(O(1)\) по памяти.

## Решение по шагам

1. Пишем `ReverseInPlace(s []int)`.
2. Запускаем `for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1`.
3. Меняем `s[i], s[j] = s[j], s[i]`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func ReverseInPlace(s []int) {
	for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1 {
		s[i], s[j] = s[j], s[i]
	}
}

func main() {
	numbers := []int{10, 20, 30, 40, 50, 60}

	fmt.Printf("До разворота:    %v\n", numbers)
	ReverseInPlace(numbers)
	fmt.Printf("После разворота: %v\n", numbers)
}
```

ℹ️ Разворот среза In-Place

**`Терминал`**

```bash
go run main.go
# До разворота:    [10 20 30 40 50 60]
# После разворота: [60 50 40 30 20 10]
```

ℹ️ Вывод

## Под капотом

Атомарный swap `s[i], s[j] = s[j], s[i]` выполняется через регистры `RAX` и `RBX` без промежуточных переменных.

## Подводные камни

- Неправильное условие `i <= j` (лишняя итерация для нечетных длин).
