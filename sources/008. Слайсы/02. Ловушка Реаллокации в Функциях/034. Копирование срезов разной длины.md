# Копирование срезов разной длины и возврат числа скопированных элементов в copy

## Условие

Создайте два слайса и скопируйте элементы из одного в другой с помощью встроенной функции `copy`. Что вернет `copy`, если целевой слайс короче исходного?

## Теория

**Правило минимальной длины в `copy(dst, src)`:**
- Число скопированных элементов всегда строго равно \(\min(\text{len}(dst), \text{len}(src))\);
- Если `dst` короче `src`, копируются только первые `len(dst)` элементов;
- Остальные элементы `src` игнорируются без генерации паники.

## Решение по шагам

1. Создаем `src := []int{10, 20, 30, 40, 50}` (`len=5`).
2. Создаем `dst := make([]int, 2)` (`len=2`).
3. Копируем и анализируем результат.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	src := []int{10, 20, 30, 40, 50}
	dst := make([]int, 2) // Целевой срез короче исходного!

	copied := copy(dst, src)

	fmt.Printf("src:         %v (len=%d)\n", src, len(src))
	fmt.Printf("dst:         %v (len=%d)\n", dst, len(dst))
	fmt.Printf("Скопировано: %d элементов (min(len(dst), len(src)))\n", copied)
}
```

ℹ️ Копирование в короткий срез

**`Терминал`**

```bash
go run main.go
# src:         [10 20 30 40 50] (len=5)
# dst:         [10 20] (len=2)
# Скопировано: 2 элементов (min(len(dst), len(src)))
```

ℹ️ Скопированы только первые 2 элемента

## Под капотом

`runtime.memmove` получает размер \(\min(\text{len}(dst), \text{len}(src)) \times \text{elemSize}\).

## Подводные камни

- Ожидание, что `copy` автоматически расширит `dst`: `copy` никогда не изменяет длину среза.

## На собеседовании

**Вопрос с собеседования:** «Как скопировать все элементы `src` в `dst`, если размер `dst` заранее неизвестен?»
**Ответ:** `dst = make([]T, len(src)); copy(dst, src)` или `dst = append([]T(nil), src...)`.
