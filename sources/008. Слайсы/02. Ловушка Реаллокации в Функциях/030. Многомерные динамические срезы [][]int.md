# Многомерные динамические срезы [][]int (матрица 3x3) и табличный вывод

## Условие

**Многомерные срезы**: Создай срез срезов `[][]int` (матрицу 3x3). Заполни её числами и выведи в виде таблички.

## Теория

**Устройство среза срезов `[][]T`:**
- Это одномерный срез, элементами которого являются структуры `SliceHeader` внутренних срезов;
- В отличие от массива `[3][3]int`, строки `[][]int` могут иметь разную длину и не обязаны располагаться в непрерывной памяти.

## Решение по шагам

1. Создаем внешнюю структуру `matrix := make([][]int, 3)`.
2. В цикле инициализируем каждую строку `matrix[i] = make([]int, 3)`.
3. Заполняем числами от 1 до 9.
4. Выводим таблицу.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	rows, cols := 3, 3
	matrix := make([][]int, rows)

	val := 1
	for i := range matrix {
		matrix[i] = make([]int, cols)
		for j := range matrix[i] {
			matrix[i][j] = val
			val++
		}
	}

	fmt.Println("Динамическая матрица 3x3:")
	for i, row := range matrix {
		fmt.Printf("Строка [%d]: %v\n", i, row)
	}
}
```

ℹ️ Срез срезов 3x3

**`Терминал`**

```bash
go run main.go
# Динамическая матрица 3x3:
# Строка [0]: [1 2 3]
# Строка [1]: [4 5 6]
# Строка [2]: [7 8 9]
```

ℹ️ Вывод

## Под капотом

Выполняется 4 аллокации: 1 для внешнего среза и 3 для внутренних срезов.

## Подводные камни

- Забыть проинициализировать строки `matrix[i] = make(...)`: обращение к `matrix[i][j]` вызовет панику `nil pointer dereference / index out of range`.

## На собеседовании

**Вопрос с собеседования:** «Как выделить плоскую непрерывную матрицу `[][]T` за 2 аллокации вместо \(N+1\)?»
**Ответ:** Выделить один большой базовый срез `data := make([]T, N*M)` и распределить его строки через слайсинг `matrix[i] = data[i*M : (i+1)*M]`.
