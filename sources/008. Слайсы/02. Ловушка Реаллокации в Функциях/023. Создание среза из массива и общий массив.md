# Создание среза arr[1:4] из массива и модификация общего базового массива

## Условие

Создайте слайс из массива (`arr[1:4]`). Измените элемент в слайсе и посмотрите, как изменился исходный массив (общий базовый массив).

## Теория

Практическое подтверждение разделяемой памяти.

## Решение по шагам

1. Создаем `arr := [5]int{10, 20, 30, 40, 50}`.
2. Создаем `s := arr[1:4]`.
3. Модифицируем `s[1] = 999`.
4. Проверяем `arr[2]`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	arr := [5]int{10, 20, 30, 40, 50}
	s := arr[1:4] // s видит [20, 30, 40]

	s[1] = 999 // Меняет элемент arr[2]

	fmt.Printf("Срез s:  %v\n", s)
	fmt.Printf("Массив:  %v (arr[2] = 999)\n", arr)
}
```

ℹ️ Мутация через срез

**`Терминал`**

```bash
go run main.go
# Срез s:  [20 999 40]
# Массив:  [10 20 999 40 50] (arr[2] = 999)
```
