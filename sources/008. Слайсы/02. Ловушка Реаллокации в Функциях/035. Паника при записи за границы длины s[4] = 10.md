# Паника при записи за границы длины s[4] = 10 при наличии емкости make([]int, 3, 5)

## Условие

**Функция `make`**: Создайте срез целых чисел длиной 3 и емкостью 5 с помощью `make([]int, 3, 5)`. Выведите его структуру через форматирование `%#v`. Попробуйте присвоить значение элементу с индексом 4 (`s[4] = 10`). Зафиксируйте панику и объясните, почему нельзя писать в элементы, выходящие за рамки текущей длины, даже если емкости достаточно.

## Теория

**Строгое разграничение `len` и `cap` при индексации:**
- Индексация `s[i]` проверяет условие \(0 \le i < \text{len}(s)\);
- Даже если `cap(s) == 5`, ячейка `s[4]` не входит в диапазон длины `len(s) == 3`;
- Прямая запись `s[4] = 10` вызывает панику `index out of range [4] with length 3`.

## Решение по шагам

1. Создаем `s := make([]int, 3, 5)`.
2. Печатаем через `%#v`.
3. Перехватываем панику при `s[4] = 10`.
4. Показываем правильное добавление через `append`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	s := make([]int, 3, 5)
	fmt.Printf("Структура среза: %#v | len = %d, cap = %d\n\n", s, len(s), cap(s))

	defer func() {
		if r := recover(); r != nil {
			fmt.Printf("⚠️ Перехвачена паника: %v\n", r)
			fmt.Println("Причина: запись s[4] запрещена, так как 4 >= len(s)!")
		}
	}()

	fmt.Println("Попытка прямой записи s[4] = 10...")
	s[4] = 10 // Паника!
}
```

ℹ️ Паника при записи вне len

**`Терминал`**

```bash
go run main.go
# Структура среза: []int{0, 0, 0} | len = 3, cap = 5
# 
# Попытка прямой записи s[4] = 10...
# ⚠️ Перехвачена паника: runtime error: index out of range [4] with length 3
# Причина: запись s[4] запрещена, так как 4 >= len(s)!
```

ℹ️ Паника перехвачена

## Под капотом

Проверка `CMPQ idx, s.Len` выполняется аппаратно перед обращением к памяти.

## Подводные камни

- Попытка инициализировать срез `make([]int, 0, 10)` и затем писать `s[0] = 1`: вызовет панику на индексе 0.

## На собеседовании

**Вопрос с собеседования:** «Как безопасно записать значение в резервную ячейку `cap` без `append`?»
**Ответ:** Расширить срез перед записью: `s = s[:5]; s[4] = 10`.
