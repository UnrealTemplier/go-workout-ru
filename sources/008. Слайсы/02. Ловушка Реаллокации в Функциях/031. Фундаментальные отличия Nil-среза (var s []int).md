# Фундаментальные отличия Nil-среза (var s []int) от Пустого среза (s := []int{})

## Условие

Создай **nil-слайс**: `var s []int`. Проверь `s == nil`, `len(s)`, `cap(s)`. Создай **empty slice**: `s := []int{}`. Проверь `s == nil` (false!). Объясни разницу между nil и empty slice и когда это важно.

## Теория

**Nil Slice vs Empty Slice:**
1. **Nil-срез (`var s []int`):**
   - `s.Data == 0x0` (указатель `nil`);
   - `len == 0`, `cap == 0`;
   - `s == nil` возвращает `true`;
   - В JSON сериализуется как `null`.
2. **Пустой срез (`s := []int{}` или `make([]int, 0)`):**
   - `s.Data != 0x0` (указывает на специальный глобальный маркер `zerobase`);
   - `len == 0`, `cap == 0`;
   - `s == nil` возвращает `false`;
   - В JSON сериализуется как `[]`.

## Решение по шагам

1. Объявляем `var sNil []int`.
2. Объявляем `sEmpty := []int{}`.
3. Сравниваем их свойства и поведение в JSON.

## Код решения

**`main.go`**

```go
package main

import (
	"encoding/json"
	"fmt"
)

type Response struct {
	Items []int `json:"items"`
}

func main() {
	var sNil []int
	sEmpty := []int{}

	fmt.Printf("sNil:   isNil = %-5t | len = %d | cap = %d\n", sNil == nil, len(sNil), cap(sNil))
	fmt.Printf("sEmpty: isNil = %-5t | len = %d | cap = %d\n\n", sEmpty == nil, len(sEmpty), cap(sEmpty))

	// Разница в JSON-сериализации:
	jsonNil, _ := json.Marshal(Response{Items: sNil})
	jsonEmpty, _ := json.Marshal(Response{Items: sEmpty})

	fmt.Printf("JSON с nil-срезом:    %s\n", jsonNil)
	fmt.Printf("JSON с пустым срезом: %s\n", jsonEmpty)
}
```

**`Терминал`**

```bash
go run main.go
# sNil:   isNil = true  | len = 0 | cap = 0
# sEmpty: isNil = false | len = 0 | cap = 0
# 
# JSON с nil-срезом:    {"items":null}
# JSON с пустым срезом: {"items":[]}
```

## Под капотом

Все пустые срезы в Go указывают на адрес `runtime.zerobase`.

## Подводные камни

- Отправка `{"items": null}` вместо `{"items": []}` в REST API мобильным клиентам, что часто вызывает падения фронтенда.

## На собеседовании

**Вопрос с собеседования:** «Как проверять срез на пустоту в Go: `if s == nil` или `if len(s) == 0`?»
**Ответ:** Всегда через `if len(s) == 0`! Это корректно обрабатывает как `nil`-срезы, так и пустые аллоцированные срезы.
