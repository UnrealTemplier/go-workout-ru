# Корректная обработка перекрывающихся диапазонов (Overlapping Slices) в copy

## Условие

Используй `copy(dst, src)` для копирования слайса. Покажи, что `copy` корректно обрабатывает **перекрывающиеся** диапазоны (overlapping slices). Например, скопируй `s[2:]` в `s[1:]` для сдвига элементов влево.

## Теория

**Гарантия `runtime.memmove` для перекрывающихся срезов:**
- В отличие от функции `memcpy` в C, которая приводит к `Undefined Behavior` при пересечении адресов источника и приемника, встроенная функция `copy` в Go использует `memmove`;
- `memmove` определяет направление перекрытия и копирует байты в безопасном порядке (справа-налево или слева-направо), предотвращая затирание исходных данных.

## Решение по шагам

1. Создаем `s := []int{10, 20, 30, 40, 50}`.
2. Сдвигаем элементы влево через `copy(s[1:], s[2:])`.
3. Усекаем срез `s = s[:len(s)-1]`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	s := []int{10, 20, 30, 40, 50}
	fmt.Printf("1. Исходный срез:           %v\n", s)

	// Сдвиг элементов [30, 40, 50] на позицию 1 (удаление числа 20):
	copied := copy(s[1:], s[2:])
	fmt.Printf("2. Скопировано элементов:    %d\n", copied)
	fmt.Printf("3. Срез после copy:          %v\n", s)

	// Отрезаем дубликат последнего элемента:
	s = s[:len(s)-1]
	fmt.Printf("4. Итоговый срез (len=%d):    %v\n", len(s), s)
}
```

ℹ️ Сдвиг перекрывающихся срезов через copy

**`Терминал`**

```bash
go run main.go
# 1. Исходный срез:           [10 20 30 40 50]
# 2. Скопировано элементов:    3
# 3. Срез после copy:          [10 30 40 50 50]
# 4. Итоговый срез (len=4):    [10 30 40 50]
```

ℹ️ Безопасный сдвиг выполнен

## Под капотом

`runtime.memmove` выполняет векторные инструкции `REP MOVSQ` с проверкой `dst < src`.

## Подводные камни

- Забыть усечь длину среза `s = s[:len(s)-1]`, оставив дубликат `[10 30 40 50 50]`.

## На собеседовании

**Вопрос с собеседования:** «Чем `copy` в Go отличается от функции `memcpy` в языке C?»
**Ответ:** `copy` в Go всегда семантически эквивалентен `memmove` и на 100% безопасен для любых перекрывающихся срезов.
