# Пошаговое добавление 10 элементов в срез с трассировкой len и cap

## Условие

Создайте срез целых чисел, добавьте к нему 10 элементов в цикле, выводя `len` и `cap` на каждом шаге.

## Теория

Трассировка динамического роста емкости среза.

## Решение по шагам

1. Инициализируем `var s []int`.
2. В цикле 1..10 добавляем числа.
3. Печатаем таблицу состояния на каждом шаге.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	var s []int

	fmt.Println("Шаг | Добавлено | len | cap | Содержимое")
	fmt.Println("----------------------------------------")
	for i := 1; i <= 10; i++ {
		s = append(s, i*10)
		fmt.Printf("%3d | %9d | %3d | %3d | %v\n", i, i*10, len(s), cap(s), s)
	}
}
```

ℹ️ Трассировка роста среза

**`Терминал`**


ℹ️ Вывод

## Под капотом

Аллокации происходят на шагах 1, 2, 3, 5, 9.

## Подводные камни

- Использование `append` в нагруженных циклах без предварительного `make(..., 0, N)` приводит к множественным лишним копированиям памяти.

## На собеседовании

**Вопрос с собеседования:** «Сколько раз аллоцируется память при добавлении 1000 элементов в `var s []int`?»
**Ответ:** Примерно 11–12 раз (1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 848, 1280). Предварительный `make([]T, 0, 1000)` сокращает число аллокаций до 1.
