# Базовый срез s2 := s[1:3] из среза целых чисел

## Условие

Создай слайс `s := []int{1, 2, 3, 4, 5}`. Сделай срез `s2 := s[1:3]`. Выведи `s2`.

## Теория

Извлечение поддиапазона из среза.

## Решение по шагам

1. Создаем `s := []int{1, 2, 3, 4, 5}`.
2. Создаем `s2 := s[1:3]`.
3. Печатаем `s2`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	s := []int{1, 2, 3, 4, 5}
	s2 := s[1:3]

	fmt.Printf("Исходный срез s:  %v\n", s)
	fmt.Printf("Подсрез s2[1:3]: %v\n", s2)
}
```

ℹ️ Срез из среза

**`Терминал`**

```bash
go run main.go
# Исходный срез s:  [1 2 3 4 5]
# Подсрез s2[1:3]: [2 3]
```

ℹ️ Вывод

## Под капотом

`s2` указывает на `&s[1]`.

## Подводные камни

- Выход за пределы `cap(s)`.

## На собеседовании

**Вопрос с собеседования:** «Чему равен `cap(s2)`?»
**Ответ:** \(5 - 1 = 4\).
