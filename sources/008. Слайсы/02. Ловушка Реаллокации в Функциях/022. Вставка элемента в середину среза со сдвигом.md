# Вставка элемента в середину среза со сдвигом через append и copy

## Условие

**Вставка в середину**: Используя `append` и `copy`, вставь число `99` на 2-й индекс среза, раздвинув остальные элементы, а не перезаписывая их.

## Теория

**Паттерн вставки элемента In-Place (Insert with Shift):**
1. Увеличиваем срез на 1 фиктивный элемент: `s = append(s, 0)`;
2. Сдвигаем элементы правее индекса вставки на 1 позицию вправо: `copy(s[index+1:], s[index:])`;
3. Записываем вставляемое значение: `s[index] = value`;
4. Это самый быстрый и эффективный способ вставки в Go без создания промежуточных срезов.

## Решение по шагам

1. Инициализируем `s := []int{1, 2, 3, 4, 5}`.
2. Вставляем 99 на позицию `index = 2`.
3. Анализируем результат.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func InsertShift(s []int, index int, value int) []int {
	// 1. Расширяем срез на 1 слот:
	s = append(s, 0)

	// 2. Сдвигаем элементы [index..len-2] вправо на 1 позицию:
	copy(s[index+1:], s[index:])

	// 3. Вставляем новое значение в освободившийся слот:
	s[index] = value

	return s
}

func main() {
	s := []int{10, 20, 30, 40, 50}
	fmt.Printf("До вставки:    %v\n", s)

	s = InsertShift(s, 2, 99)
	fmt.Printf("После вставки: %v (99 вставлен на индекс 2)\n", s)
}
```

ℹ️ Вставка через append + copy

**`Терминал`**

```bash
go run main.go
# До вставки:    [10 20 30 40 50]
# После вставки: [10 20 99 30 40 50] (99 вставлен на индекс 2)
```

ℹ️ Порядок остальных элементов сохранен

## Под капотом

`copy` вызывает `memmove`, который безопасно копирует перекрывающиеся области памяти справа налево.

## Подводные камни

- Попытка ручного цикла копирования слева направо: это затерло бы все элементы значением `s[index]`.

## На собеседовании
