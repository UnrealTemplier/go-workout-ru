# Очистка среза ClearSlice(s) через s[:0] с переиспользованием выделенной памяти

## Условие

Напиши функцию `ClearSlice(s []int) []int`, которая возвращает слайс нулевой длины (`s[:0]`), сохраняя ёмкость. Покажи, что `append` после `ClearSlice` переиспользует память.

## Теория

**Паттерн переиспользования буфера (Zero-Allocation Buffer Reuse):**
- Срез `s[:0]` сбрасывает длину `Len = 0`, но сохраняет исходную емкость `Cap` и указатель на память `Data`;
- Последующие вызовы `append` пишут в уже выделенный массив без единой аллокации в куче;
- Является ключевым паттерном для `sync.Pool` и высоконагруженных сетевых сервисов.

## Решение по шагам

1. Пишем функцию `ClearSlice(s []int) []int { return s[:0] }`.
2. Создаем срез емкостью 5.
3. Сбрасываем в `s[:0]` и повторно заполняем через `append`.
4. Убеждаемся, что адрес базового массива не изменился.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func ClearSlice(s []int) []int {
	return s[:0]
}

func main() {
	buf := make([]int, 0, 5)
	buf = append(buf, 10, 20, 30)

	addrBefore := fmt.Sprintf("%p", &buf[0])
	fmt.Printf("1. До очистки:   %v | len = %d, cap = %d (адрес: %s)\n",
		buf, len(buf), cap(buf), addrBefore)

	// Очищаем срез с сохранением capacity:
	buf = ClearSlice(buf)
	fmt.Printf("2. После очистки: %v | len = %d, cap = %d\n",
		buf, len(buf), cap(buf))

	// Заполняем заново:
	buf = append(buf, 100, 200)
	addrAfter := fmt.Sprintf("%p", &buf[0])
	fmt.Printf("3. Новые данные: %v | len = %d, cap = %d (адрес: %s - ТОТ ЖЕ!)\n",
		buf, len(buf), cap(buf), addrAfter)
}
```

ℹ️ Переиспользование буфера через s[:0]

**`Терминал`**

```bash
go run main.go
# 1. До очистки:   [10 20 30] | len = 3, cap = 5 (адрес: 0xc000014070)
# 2. После очистки: [] | len = 0, cap = 5
# 3. Новые данные: [100 200] | len = 2, cap = 5 (адрес: 0xc000014070 - ТОТ ЖЕ!)
```

ℹ️ Память переиспользована без аллокаций

## Под капотом

Инструкция сброса `Len = 0` занимает 1 такт CPU без вызова рантайма.

## Подводные камни

- Если срез хранит указатели `[]*Object`, `s[:0]` не зануляет старые элементы \(\rightarrow\) они будут удерживаться в памяти до перезаписи. В Go 1.21+ для зануления вызывают `clear(s)`.

## На собеседовании

**Вопрос с собеседования:** «В чем разница между `s = s[:0]` и встроенной функцией `clear(s)` в Go 1.21+?»
**Ответ:** `s = s[:0]` устанавливает `len = 0`. Встроенная функция `clear(s)` сохраняет `len`, но зануляет все элементы среза до их zero-значений.
