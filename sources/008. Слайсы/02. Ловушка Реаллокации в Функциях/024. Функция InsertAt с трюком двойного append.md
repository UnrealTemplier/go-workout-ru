# Функция InsertAt с трюком двойного append и анализ опасности общего массива

## Условие

Напиши функцию `InsertAt(s []int, index int, value int) []int`, которая вставляет элемент в середину. Сделай через `append(s[:index], append([]int{value}, s[index:]...)...)`. Объясни, почему нужна временная переменная (иначе может быть неожиданное поведение из-за shared array).

## Теория

**Вставка через вложенный `append`:**
`append(s[:index], append([]int{value}, s[index:]...)...)`:
- Внутренний `append([]int{value}, s[index:]...)` создает новый срез с `value` в начале и остатком среза;
- Внешний `append(s[:index], ...)` склеивает левую часть с вновь созданной правой частью;
- Создание `[]int{value}` гарантирует выделение нового буфера, исключая перезапись хвоста `s[index:]`.

## Решение по шагам

1. Пишем функцию `InsertAt(s []int, index int, value int) []int`.
2. Тестируем вставку в начало, середину и конец.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func InsertAt(s []int, index int, value int) []int {
	if index < 0 || index > len(s) {
		panic("index out of range")
	}
	// Безопасная склейка через временный срез
	return append(s[:index], append([]int{value}, s[index:]...)...)
}

func main() {
	items := []int{1, 2, 4, 5}
	fmt.Printf("Исходный: %v\n", items)

	items = InsertAt(items, 2, 3)
	fmt.Printf("Вставка 3 на индекс 2: %v\n", items)
}
```

ℹ️ Функция InsertAt

**`Терминал`**

```bash
go run main.go
# Исходный: [1 2 4 5]
# Вставка 3 на индекс 2: [1 2 3 4 5]
```

ℹ️ Элемент успешно вставлен

## Под капотом

Внутренний `[]int{value}` аллоцирует буфер под правую часть в куче.

## Подводные камни

- Выделение лишней памяти на `[]int{value}`. Паттерн `append + copy` из упр. 22 быстрее и экономнее.

## На собеседовании

**Вопрос с собеседования:** «Какой способ вставки быстрее: `append(s[:i], append([]int{v}, s[i:]...)...)` или `s = append(s, 0); copy(s[i+1:], s[i:]); s[i] = v`?»
**Ответ:** Способ с `copy` в несколько раз быстрее, так как делает максимум 1 аллокацию (при необходимости) и не создает промежуточный срез.
