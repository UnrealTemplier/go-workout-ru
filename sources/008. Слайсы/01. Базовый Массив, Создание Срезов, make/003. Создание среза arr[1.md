# Создание среза arr[1:4] из массива, расчет len/cap и мутация общего базового массива

## Условие

Создание среза из массива: Используя массив [5]int{10, 20, 30, 40, 50}, создай срез s := arr[1:4]. Выведи срез, его len и cap. Измени s[0] и проверь, изменился ли оригинальный массив.

### Исходная формулировка

**Создание среза из массива**: Используя массив из упр. 143, создай срез `s := arr[1:4]`. Выведи срез, его `len` и `cap`. Измени `s[0]` и проверь, изменился ли оригинальный массив.

## Теория

**Анатомия операции среза `arr[low:high]`:**
- `len(s) = high - low` (в данном случае \(4 - 1 = 3\));
- `cap(s) = len(arr) - low` (в данном случае \(5 - 1 = 4\), так как capacity отсчитывается от начала среза `low` до конца базового массива);
- Срез `s` не копирует данные, а ссылается на ячейки `arr[1]`, `arr[2]`, `arr[3]`.

## Решение по шагам

1. Инициализируем массив `arr := [5]int{10, 20, 30, 40, 50}`.
2. Создаем срез `s := arr[1:4]`.
3. Печатаем срез, `len(s)` и `cap(s)`.
4. Мутируем `s[0] = 999` и проверяем `arr`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	arr := [5]int{10, 20, 30, 40, 50}
	s := arr[1:4] // Элементы arr[1], arr[2], arr[3]

	fmt.Printf("Исходный массив arr: %v\n", arr)
	fmt.Printf("Срез s:              %v | len = %d, cap = %d\n\n", s, len(s), cap(s))

	// Изменяем первый элемент среза:
	s[0] = 999

	fmt.Println("После s[0] = 999:")
	fmt.Printf("Срез s:              %v\n", s)
	fmt.Printf("Массив arr:          %v (arr[1] мутировал!)\n", arr)
}
```

ℹ️ Срез как окно в базовый массив

**`Терминал`**

```bash
go run main.go
# Исходный массив arr: [10 20 30 40 50]
# Срез s:              [20 30 40] | len = 3, cap = 4
# 
# После s[0] = 999:
# Срез s:              [999 30 40]
# Массив arr:          [10 999 30 40 50] (arr[1] мутировал!)
```

ℹ️ Элемент arr[1] изменился на 999

## Под капотом

Указатель `s.Data` равен `&arr[1]`. Запись `s[0] = 999` пишет напрямую по адресу `&arr[1]`.

## Подводные камни

- Непонимание того, что изменение среза меняет исходный массив, пока не произошла реаллокация `append`.

## На собеседовании

**Вопрос с собеседования:** «Чему равна емкость `cap` для `arr[2:5]` у массива `[10]int`?»
**Ответ:** \(\text{len}(arr) - 2 = 10 - 2 = 8\). Длина `len` равна \(5 - 2 = 3\).
