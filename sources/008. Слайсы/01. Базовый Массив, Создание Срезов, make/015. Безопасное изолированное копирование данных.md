# Безопасное изолированное копирование данных через встроенную функцию copy(dst, src)

## Условие

**Безопасное копирование**: Создай срез на 5 элементов. Создай второй срез через `make` такой же длины. Используй встроенную функцию `copy(dst, src)`, чтобы скопировать данные. Измени копию и проверь оригинал.

## Теория

**Встроенная функция `copy(dst, src []T) int`:**
- Копирует элементы из `src` в `dst`;
- Количество скопированных элементов равно \(\min(\text{len}(dst), \text{len}(src))\);
- Создает абсолютно независимую копию в памяти;
- Возвращает число успешно скопированных элементов.

## Решение по шагам

1. Создаем исходный срез `src := []int{10, 20, 30, 40, 50}`.
2. Создаем `dst := make([]int, len(src))`.
3. Вызываем `copied := copy(dst, src)`.
4. Мутируем `dst[0] = 999` и проверяем `src`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	src := []int{10, 20, 30, 40, 50}
	dst := make([]int, len(src)) // Важно: длина dst должна быть >= len(src)!

	copied := copy(dst, src)
	fmt.Printf("Скопировано элементов: %d\n", copied)

	// Изменяем копию:
	dst[0] = 999

	fmt.Printf("Оригинал src: %v (адрес: %p)\n", src, &src[0])
	fmt.Printf("Копия dst:    %v (адрес: %p)\n", dst, &dst[0])
}
```

ℹ️ Изолированное копирование через copy

**`Терминал`**

```bash
go run main.go
# Скопировано элементов: 5
# Оригинал src: [10 20 30 40 50] (адрес: 0xc000014070)
# Копия dst:    [999 20 30 40 50] (адрес: 0xc0000140a0)
```

ℹ️ Разные адреса памяти и независимые данные

## Под капотом

`copy` вызывает ассемблерную процедуру `runtime.memmove`, копирующую \(N \times 8\) байт за минимальное число тактов CPU.

## Подводные камни

- Вызов `copy` в неаллоцированный срез `var dst []int; copy(dst, src)`: `dst` имеет `len=0`, поэтому будет скопировано ровно 0 элементов!

## На собеседовании

**Вопрос с собеседования:** «Как склонировать срез одной строкой в Go 1.21+?»
**Ответ:** `dst := slices.Clone(src)` из стандартного пакета `slices`.
