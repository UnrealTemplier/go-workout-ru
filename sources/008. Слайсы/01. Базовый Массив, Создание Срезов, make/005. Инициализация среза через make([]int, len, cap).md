# Инициализация среза через make([]int, len, cap) и разделение понятий длины и емкости

## Условие

**Инициализация `make`**: Создай срез через `s := make([]int, 3, 5)`. Выведи его значения, длину и вместимость.

## Теория

**Встроенная функция `make([]T, len, cap)`:**
- Выделяет непрерывный блок памяти в куче под `cap` элементов;
- Инициализирует первые `len` элементов нулевыми значениями (`Zero Values`);
- Позволяет заранее резервировать память (Pre-allocation) во избежание дорогостоящих реаллокаций при `append`.

## Решение по шагам

1. Создаем срез `s := make([]int, 3, 5)`.
2. Выводим элементы `%v`, длину `len(s)` и емкость `cap(s)`.
3. Рассматриваем представление через `%#v`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	s := make([]int, 3, 5)

	fmt.Printf("Значение среза (%%v):  %v\n", s)
	fmt.Printf("Детально (%%#v):       %#v\n", s)
	fmt.Printf("Длина len(s):          %d (доступные для чтения/записи индексы 0..2)\n", len(s))
	fmt.Printf("Емкость cap(s):        %d (зарезервировано памяти под 5 элементов)\n", cap(s))
}
```

ℹ️ Инициализация среза через make

**`Терминал`**

```bash
go run main.go
# Значение среза (%v):  [0 0 0]
# Детально (%#v):       []int{0, 0, 0}
# Длина len(s):          3 (доступные для чтения/записи индексы 0..2)
# Емкость cap(s):        5 (зарезервировано памяти под 5 элементов)
```

ℹ️ Вывод

## Под капотом

`make([]int, 3, 5)` компилируется в вызов `runtime.makeslice(intType, 3, 5)`.

## Подводные камни

- Обращение к `s[3] = 10` при `len == 3` и `cap == 5`: вызовет `panic: runtime error: index out of range [3] with length 3`, так как индексы ограничены `len`, а не `cap`.

## На собеседовании

**Вопрос с собеседования:** «Что происходит, если параметр `cap` опущен в `make([]T, len)`?»
**Ответ:** Емкость `cap` приравнивается к длине `len` (`cap == len`).
