# Сравнение массивов через == и ограничения типов (несравнимость массивов со срезами и мапами)

## Условие

Сравните два массива одинакового размера с помощью оператора `==`. Выясните, какие типы массивов нельзя сравнивать (например, содержащие слайсы или мапы).

## Теория

**Правила сравнимости составных типов в Go:**
- Массив `[N]T` сравним через `==` тогда и только тогда, когда **тип элемента `T` является сравнимым (comparable)**;
- Базовые типы (`int`, `string`, `bool`, указатели, структуры со сравнимыми полями) сравнимы;
- Срезы `[]int`, мапы `map[K]V` и функции `func()` НЕ сравнимы \(\rightarrow\) массивы `[2][]int` или `[2]map[string]int` компилятор **запрещает сравнивать через `==`**.

## Решение по шагам

1. Сравниваем два массива `[3]int`.
2. Объявляем массив срезов `[2][]int`.
3. Показываем ошибку компиляции при попытке сравнения массивов срезов.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	// 1. Сравнимые массивы (элементы int сравнимы):
	a := [3]int{1, 2, 3}
	b := [3]int{1, 2, 3}
	fmt.Printf("a == b: %t\n", a == b)

	// 2. Несравнимые массивы (элементы []int несравнимы):
	s1 := [2][]int{{1, 2}, {3, 4}}
	s2 := [2][]int{{1, 2}, {3, 4}}
	_ = s1
	_ = s2

	// fmt.Println(s1 == s2) // ОШИБКА КОМПИЛЯЦИИ: invalid operation: s1 == s2 ([2][]int cannot be compared)
	fmt.Println("Массивы срезов [2][]int нельзя сравнивать через ==!")
}
```

ℹ️ Сравнимость массивов

**`Терминал`**

```bash
go run main.go
# a == b: true
# Массивы срезов [2][]int нельзя сравнивать через ==!
```

ℹ️ Результат

## Под капотом

Компилятор проверяет флаг `Comparable` в дескрипторе типа `Type` во время проверки типов (Type Checking).

## Подводные камни

- Попытка использовать массив структур `[2]User` как ключ в `map`, если у `User` есть поле `Tags []string`.

## На собеседовании

**Вопрос с собеседования:** «Как сравнить два массива срезов `[2][]int` на равенство элементов?»
**Ответ:** Использовать цикл со `slices.Equal(s1[i], s2[i])` или `reflect.DeepEqual(s1, s2)`.
