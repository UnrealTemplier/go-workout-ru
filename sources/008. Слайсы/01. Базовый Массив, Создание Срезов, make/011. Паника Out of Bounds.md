# Паника Out of Bounds: почему индекс len(s) недопустим для чтения и записи

## Условие

**Паника Out of bounds**: Попробуй обратиться к элементу среза по индексу, равному его длине (например, `s[len(s)]`). Изучи сообщение о панике.

## Теория

**Защита границ индексов (Zero-based Indexing):**
- Допустимые индексы среза лежат строго в диапазоне \([0, \text{len}(s) - 1]\);
- Индекс `len(s)` указывает на первый элемент *за пределами длины*;
- Попытка доступа `s[len(s)]` вызывает фатальную контролируемую панику `runtime error: index out of range`.

## Решение по шагам

1. Создаем `s := []int{10, 20, 30}` (`len = 3`).
2. Перехватываем панику через `recover()` при попытке чтения `s[3]`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func SafeSliceAccess(s []int, idx int) {
	defer func() {
		if r := recover(); r != nil {
			fmt.Printf("⚠️ Перехвачена паника: %v\n", r)
		}
	}()

	fmt.Printf("Попытка доступа к s[%d] при len(s)=%d...\n", idx, len(s))
	val := s[idx]
	fmt.Printf("Значение: %d\n", val)
}

func main() {
	s := []int{10, 20, 30}

	SafeSliceAccess(s, 2)         // Допустимый последний индекс (len-1)
	SafeSliceAccess(s, len(s))    // Индекс 3 -> Паника!
}
```

ℹ️ Перехват паники out of bounds

**`Терминал`**

```bash
go run main.go
# Попытка доступа к s[2] при len(s)=3...
# Значение: 30
# Попытка доступа к s[3] при len(s)=3...
# ⚠️ Перехвачена паника: runtime error: index out of range [3] with length 3
```

ℹ️ Паника успешно перехвачена

## Под капотом

Компилятор генерирует машинную инструкцию `CMPQ idx, len; JAE runtime.panicIndex`.

## Подводные камни

- Путаница между максимальным индексом `len-1` и длиной `len` в циклах с `<=`.

## На собеседовании

**Вопрос с собеседования:** «Можно ли отключить проверку границ срезов (Bounds Checking) в Go для максимальной скорости?»
**Ответ:** Стандартный компилятор `gc` не позволяет отключить проверки глобально ради безопасности. Однако оптимизатор компилятора (BCE — Bounds Check Elimination) автоматически удаляет избыточные проверки в доказанно безопасных циклах.
