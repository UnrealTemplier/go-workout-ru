# Утилита InspectSlice: глубокая печать SliceHeader (Data pointer, Len, Cap)

## Условие

Напиши функцию InspectSlice(name string, s []int), которая выводит имя, длину, ёмкость и адрес underlying array (через &s[0], но осторожно с пустым слайсом). Используй для отладки последующих упражнений.

### Исходная формулировка

Напиши функцию `InspectSlice(name string, s []int)`, которая выводит имя, длину, ёмкость и **адрес underlying array** (через `&s[0]`, но осторожно с пустым слайсом). Используй для отладки последующих упражнений.

---

## Теория

**Безопасная инспекция структуры среза:**
- Для непустого среза (`len > 0`) адрес базового массива можно получить как `&s[0]` или через `unsafe.SliceData(s)` (Go 1.20+);
- Для пустого среза обращение к `&s[0]` вызовет панику, поэтому требуется проверка длины;
- Внутреннее представление среза состоит из указателя `Data`, длины `Len` и емкости `Cap`.

## Решение по шагам

1. Пишем функцию `InspectSlice(name string, s []int)`.
2. Проверяем `len(s) > 0` перед взятием адреса.
3. Тестируем на заполненном, пустом и nil-срезе.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"unsafe"
)

func InspectSlice(name string, s []int) {
	var ptr uintptr
	if len(s) > 0 {
		ptr = uintptr(unsafe.Pointer(&s[0]))
	} else if cap(s) > 0 {
		ptr = uintptr(unsafe.Pointer(unsafe.SliceData(s)))
	}

	fmt.Printf("[%s] Data: 0x%x | Len: %d | Cap: %d | isNil: %t | Val: %v\n",
		name, ptr, len(s), cap(s), s == nil, s)
}

func main() {
	var sNil []int
	sEmpty := []int{}
	sAlloc := make([]int, 3, 5)

	InspectSlice("sNil", sNil)
	InspectSlice("sEmpty", sEmpty)
	InspectSlice("sAlloc", sAlloc)
}
```

ℹ️ Утилита инспекции дескриптора среза

**`Терминал`**

```bash
go run main.go
# [sNil] Data: 0x0 | Len: 0 | Cap: 0 | isNil: true | Val: []
# [sEmpty] Data: 0x0 | Len: 0 | Cap: 0 | isNil: false | Val: []
# [sAlloc] Data: 0xc000014070 | Len: 3 | Cap: 5 | isNil: false | Val: [0 0 0]
```

ℹ️ Разница между nil, empty и make

## Под капотом

В Go 1.20+ функция `unsafe.SliceData(s)` возвращает указатель на базовый массив даже при `len == 0`, если `cap > 0`.

## Подводные камни

- Взятие `&s[0]` без проверки `len(s) > 0`: вызовет `panic: index out of range`.

## На собеседовании

**Вопрос с собеседования:** «Чем `unsafe.SliceData` лучше прямого каста через `(*reflect.SliceHeader)`?»
**Ответ:** `reflect.SliceHeader` объявлен устаревшим (deprecated) в Go 1.21, так как сборщик мусора не видит `uintptr` как живой указатель. `unsafe.SliceData` типобезопасен и поддерживается рантаймом.
