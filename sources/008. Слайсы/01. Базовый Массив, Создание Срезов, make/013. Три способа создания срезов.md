# Три способа создания срезов: Литерал []T{}, make([]T, len) и make([]T, len, cap)

## Условие

Создай слайс тремя способами: `[]int{1,2,3}`, `make([]int, 5)`, `make([]int, 5, 10)`. Для каждого выведи `len` и `cap`. Объясни разницу.

## Теория

**Сравнительная таблица способов инициализации:**
1. `[]int{1, 2, 3}` \(\rightarrow\) литерал со значениями (`len=3, cap=3`);
2. `make([]int, 5)` \(\rightarrow\) 5 нулевых элементов (`len=5, cap=5`);
3. `make([]int, 5, 10)` \(\rightarrow\) 5 нулевых элементов и 5 слотов в резерве (`len=5, cap=10`).

## Решение по шагам

1. Создаем срезы всеми тремя способами.
2. Выводим `len`, `cap` и значения.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	s1 := []int{1, 2, 3}
	s2 := make([]int, 5)
	s3 := make([]int, 5, 10)

	fmt.Printf("1. []int{1,2,3}:       %v | len = %d, cap = %d\n", s1, len(s1), cap(s1))
	fmt.Printf("2. make([]int, 5):     %v | len = %d, cap = %d\n", s2, len(s2), cap(s2))
	fmt.Printf("3. make([]int, 5, 10): %v | len = %d, cap = %d\n", s3, len(s3), cap(s3))
}
```

ℹ️ Сравнение трех способов создания среза

**`Терминал`**

```bash
go run main.go
# 1. []int{1,2,3}:       [1 2 3] | len = 3, cap = 3
# 2. make([]int, 5):     [0 0 0 0 0] | len = 5, cap = 5
# 3. make([]int, 5, 10): [0 0 0 0 0] | len = 5, cap = 10
```

ℹ️ Результаты

## Под капотом

Для `make([]int, 5, 10)` выделяется 80 байт памяти, но индексировать разрешено только первые 40 байт (5 элементов `int`).

## Подводные камни

- Использование `s := make([]int, 5)` с последующим `s = append(s, 1)`: срез станет длины 6 с нулями в начале `[0 0 0 0 0 1]`. Для `append` создают `make([]int, 0, 5)`.

## На собеседовании

**Вопрос с собеседования:** «Как правильно аллоцировать срез, в который планируется добавлять \(N\) элементов через `append`?»
**Ответ:** `make([]T, 0, N)` с нулевой длиной и емкостью \(N\).
