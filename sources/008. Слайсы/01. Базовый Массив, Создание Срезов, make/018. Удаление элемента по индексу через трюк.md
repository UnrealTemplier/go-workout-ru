# Удаление элемента по индексу через трюк со слиянием append(s[:i], s[i+1:]...)

## Условие

**Удаление элемента (Трюк с append)**: Имея срез `[1, 2, 3, 4, 5]`, удали элемент `3` (по индексу 2), используя слияние двух частей среза через `append`: `append(s[:2], s[3:]...)`.

## Теория

**Идиоматичное удаление со сдвигом (Order-Preserving Delete):**
- Срез `s[:i]` берет элементы до индекса `i` (не включая его);
- Срез `s[i+1:]` берет элементы после индекса `i`;
- `append(s[:i], s[i+1:]...)` сдвигает хвостовые элементы влево, затирая элемент с индексом `i`;
- Сложность \(O(N - i)\) по времени, \(O(1)\) по дополнительной памяти (In-Place).

## Решение по шагам

1. Инициализируем `s := []int{1, 2, 3, 4, 5}`.
2. Удаляем индекс 2 через `s = append(s[:2], s[3:]...)`.
3. Анализируем результат и остаточную емкость.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	s := []int{1, 2, 3, 4, 5}
	fmt.Printf("До удаления:    %v | len = %d, cap = %d\n", s, len(s), cap(s))

	indexToRemove := 2 // Удаляем число 3

	// Трюк с append:
	s = append(s, 0)[:len(s)] // демонстрация
	s = append(s[:indexToRemove], s[indexToRemove+1:]...)

	fmt.Printf("После удаления: %v | len = %d, cap = %d\n", s, len(s), cap(s))
}
```

ℹ️ Удаление элемента по индексу

**`Терминал`**

```bash
go run main.go
# До удаления:    [1 2 3 4 5] | len = 5, cap = 5
# После удаления: [1 2 4 5] | len = 4, cap = 5
```

ℹ️ Элемент 3 удален, порядок сохранен

## Под капотом

Элементы `4, 5` сдвигаются на 1 позицию влево в том же базовом массиве. Память не перевыделяется.

## Подводные камни

- Утечка памяти при удалении указателей `[]*Object`: если в срезе хранятся указатели, сдвиг оставляет ссылку на последний элемент в ячейке `cap`! Для сборщика мусора необходимо явно занулить хвост: `s[len(s)-1] = nil` или использовать `slices.Delete`.

## На собеседовании

**Вопрос с собеседования:** «Какая стандартная функция появилась в Go 1.21 для удаления элементов среза?»
**Ответ:** `slices.Delete(s, i, j)` (удаляет диапазон от `i` до `j`, обнуляя освободившиеся слоты).
