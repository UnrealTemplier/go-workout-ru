# Мутация s2[0] = 99 в подсрезе и влияние на исходный срез s

## Условие

**[Каверзный кейс]**: В слайсе `s` из предыдущего задания измени `s2[0]` на `99`. Выведи `s`. Объясни, почему изменился оригинал (слайсы делят один базовый массив).

## Теория

Разбор коллизий при разделении памяти между дочерним и родительским срезами.

## Решение по шагам

1. Создаем `s := []int{1, 2, 3, 4, 5}`.
2. Создаем `s2 := s[2:4]`.
3. Мутируем `s2[0] = 99`.
4. Проверяем `s[2]`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	s := []int{1, 2, 3, 4, 5}
	s2 := s[2:4] // s2 указывает на [3, 4]

	fmt.Printf("Исходный s:  %v\n", s)
	fmt.Printf("Подсрез s2:  %v\n\n", s2)

	// Меняем первый элемент подсреза:
	s2[0] = 99

	fmt.Println("После s2[0] = 99:")
	fmt.Printf("Подсрез s2:  %v\n", s2)
	fmt.Printf("Исходный s:  %v (элемент s[2] изменился на 99!)\n", s)
}
```

ℹ️ Коллизия разделяемой памяти

**`Терминал`**

```bash
go run main.go
# Исходный s:  [1 2 3 4 5]
# Подсрез s2:  [3 4]
# 
# После s2[0] = 99:
# Подсрез s2:  [99 4]
# Исходный s:  [1 2 99 4 5] (элемент s[2] изменился на 99!)
```

ℹ️ Вывод

## Под капотом

`s2.Data` физически указывает на `&s[2]`.

## Подводные камни

- Неожиданные сайд-эффекты в параллельных функциях.

## На собеседовании

**Вопрос с собеседования:** «Как передать поддиапазон среза в функцию, гарантируя, что функция не сможет изменить оригинал?»
**Ответ:** Склонировать поддиапазон: `sub := slices.Clone(s[2:4])` или `sub := append([]T(nil), s[2:4]...)`.
