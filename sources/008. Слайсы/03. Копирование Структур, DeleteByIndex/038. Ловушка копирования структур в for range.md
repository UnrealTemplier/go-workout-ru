# Ловушка копирования структур в for range и правильная мутация по индексу

## Условие

Создай слайс структур `[]Person`. Пройди `for _, p := range persons` и попробуй изменить `p.Age` внутри цикла. Покажи, что оригинал не меняется (range копирует значение). Исправь через `for i := range persons { persons[i].Age++ }`.

## Теория

**Копирование элементов в `for range`:**
- `for _, p := range persons` на каждой итерации копирует всю структуру `Person` в локальную переменную `p`;
- Мутация `p.Age++` изменяет только эту локальную копию;
- Для изменения данных в срезе обращаются по индексу: `persons[i].Age++`.

## Решение по шагам

1. Создаем структуру `Person{Name string, Age int}`.
2. Создаем срез `[]Person`.
3. Показываем ошибку при попытке мутации `p.Age++`.
4. Исправляем через `persons[i].Age++`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Person struct {
	Name string
	Age  int
}

func main() {
	team := []Person{
		{Name: "Иван", Age: 25},
		{Name: "Елена", Age: 30},
	}
	fmt.Printf("1. Исходный срез:   %+v\n", team)

	// ОШИБКА: p - это локальная копия
	for _, p := range team {
		p.Age = 99
	}
	fmt.Printf("2. После _, p :=:   %+v (НЕ изменился!)\n", team)

	// ПРАВИЛЬНО: через прямой индекс
	for i := range team {
		team[i].Age = 99
	}
	fmt.Printf("3. После team[i]:   %+v (УСПЕШНО!)\n", team)
}
```

ℹ️ Копирование структур в for range

**`Терминал`**

```bash
go run main.go
# 1. Исходный срез:   [{Name:Иван Age:25} {Name:Елена Age:30}]
# 2. После _, p :=:   [{Name:Иван Age:25} {Name:Елена Age:30}] (НЕ изменился!)
# 3. После team[i]:   [{Name:Иван Age:99} {Name:Елена Age:99}] (УСПЕШНО!)
```

ℹ️ Результаты мутации

## Под капотом

`runtime.memmove` копирует байты структуры в стек цикла.

## Подводные камни

- Надежда на то, что `p` является ссылкой на элемент среза.

## На собеседовании

**Вопрос с собеседования:** «Как писать `for _, p := range` и мутировать объекты?»
**Ответ:** Использовать срез указателей `[]*Person`.
