# Изменение длины среза в функции: почему void-функция с append не меняет len оригинала

## Условие

**Изменение длины среза в функции**: Напиши функцию, которая принимает срез, делает `append` и возвращает **ничего**. Вызови в `main` и посмотри, изменилась ли длина оригинала. Перепиши функцию так, чтобы она возвращала новый срез (идиоматичный способ в Go).

## Теория

**Анатомия передачи дескриптора среза:**
- При вызове `func f(s []int)` в функцию передается **локальная копия структуры `SliceHeader`**;
- `append` внутри функции обновляет поле `Len` в этой локальной копии;
- Поле `Len` исходного среза в вызывающей функции остается неизменным;
- **Идиома Go:** Функции, модифицирующие длину среза, обязаны возвращать новый срез: `func f(s []int) []int`.

## Решение по шагам

1. Пишем `BadAppend(s []int)`.
2. Пишем `GoodAppend(s []int) []int`.
3. Сравниваем результаты в `main`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

// Неправильно: срез передается по значению, len в main не изменится
func BadAppend(s []int) {
	s = append(s, 999)
}

// Правильно: идиоматичный возврат обновленного среза
func GoodAppend(s []int) []int {
	return append(s, 999)
}

func main() {
	s := []int{1, 2, 3}

	fmt.Printf("1. До вызовов:     %v (len=%d)\n", s, len(s))
	BadAppend(s)
	fmt.Printf("2. После BadAppend: %v (len=%d - ДЛИНА НЕ ИЗМЕНИЛАСЬ!)\n", s, len(s))

	s = GoodAppend(s)
	fmt.Printf("3. После GoodAppend:%v (len=%d - УСПЕШНО!)\n", s, len(s))
}
```

ℹ️ Идиоматичный возврат среза

**`Терминал`**

```bash
go run main.go
# 1. До вызовов:     [1 2 3] (len=3)
# 2. После BadAppend: [1 2 3] (len=3 - ДЛИНА НЕ ИЗМЕНИЛАСЬ!)
# 3. После GoodAppend:[1 2 3 999] (len=4 - УСПЕШНО!)
```

ℹ️ Вывод

## Под капотом

`SliceHeader` копируется в 3 регистра `(RAX, RBX, RCX)` при вызове функции.

## Подводные камни

- Ожидание, что срез ведет себя как указатель на объект (как в Java `ArrayList`).

## На собеседовании

**Вопрос с собеседования:** «Можно ли передать указатель на срез `*[]int` в функцию?»
**Ответ:** Можно (`func f(s *[]int) { *s = append(*s, 1) }`), но это считается неидиоматичным в Go, за исключением специфических библиотек десериализации. Стандартом является возврат `[]T`.
