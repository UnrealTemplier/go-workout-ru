# Функция ChunkSlice: разбиение среза на пачки и ловушка разделяемой памяти

## Условие

Напиши функцию `ChunkSlice(s []int, size int) [][]int`, которая разбивает слайс на подслайсы заданного размера. Обрати внимание: подслайсы **делят** underlying array с оригиналом! Изменение в chunk изменит оригинал.

## Теория

**Паттерн Chunking / Batching:**
- Разбиение на пачки через `s[start:end]`;
- Все чанки ссылаются на **тот же базовый массив**;
- Мутация `chunks[0][0] = 999` немедленно меняет `s[0]`.

## Решение по шагам

1. Пишем `ChunkSlice(s []int, size int) [][]int`.
2. Разбиваем срез из 8 элементов по 3 штуки.
3. Демонстрируем разделяемую память.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func ChunkSlice(s []int, size int) [][]int {
	if size <= 0 {
		return nil
	}
	var chunks [][]int
	for start := 0; start < len(s); start += size {
		end := start + size
		if end > len(s) {
			end = len(s)
		}
		chunks = append(chunks, s[start:end])
	}
	return chunks
}

func main() {
	data := []int{1, 2, 3, 4, 5, 6, 7, 8}
	chunks := ChunkSlice(data, 3)

	fmt.Printf("Исходный срез: %v\n", data)
	fmt.Printf("Чанки (по 3):  %v\n\n", chunks)

	// Изменение чанка меняет оригинал:
	chunks[0][0] = 999
	fmt.Println("После chunks[0][0] = 999:")
	fmt.Printf("Чанки:         %v\n", chunks)
	fmt.Printf("Исходный:      %v (data[0] изменился!)\n", data)
}
```

ℹ️ Разбиение на чанки

**`Терминал`**

```bash
go run main.go
# Исходный срез: [1 2 3 4 5 6 7 8]
# Чанки (по 3):  [[1 2 3] [4 5 6] [7 8]]
# 
# После chunks[0][0] = 999:
# Чанки:         [[999 2 3] [4 5 6] [7 8]]
# Исходный:      [999 2 3 4 5 6 7 8] (data[0] изменился!)
```

ℹ️ Чанки делят базовый массив с оригиналом

## Под капотом

Создаются только легковесные структуры `SliceHeader` без дублирования данных.

## Подводные камни

- Забыть проверку `end > len(s)`: вызовет панику `slice bounds out of range`.

## На собеседовании
