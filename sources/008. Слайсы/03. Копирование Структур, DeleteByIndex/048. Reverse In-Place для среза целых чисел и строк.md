# Reverse In-Place для среза целых чисел и строк

## Условие

Reverse In-Place: Напиши функцию, которая разворачивает переданный срез задом наперед, не выделяя память под новый срез (меняя элементы местами).

### Исходная формулировка

**Reverse In-Place**: Напиши функцию, которая разворачивает переданный срез задом наперед, не выделяя память под новый срез (меняя элементы местами).

---

## Теория

Закрепление разворота срезов на месте.

## Решение по шагам

1. Пишем `Reverse(s []string)`.
2. Меняем `s[i], s[j] = s[j], s[i]`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Reverse(s []string) {
	for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1 {
		s[i], s[j] = s[j], s[i]
	}
}

func main() {
	words := []string{"Go", "is", "awesome", "and", "fast"}
	fmt.Printf("До:    %v\n", words)

	Reverse(words)
	fmt.Printf("После: %v\n", words)
}
```

ℹ️ Reverse строк на месте

**`Терминал`**

```bash
go run main.go
# До:    [Go is awesome and fast]
# После: [fast and awesome is Go]
```

## На собеседовании

**Вопрос с собеседования:** «Какая функция разворота строк на месте используется для UTF-8?»
**Ответ:** Для строк UTF-8 сначала преобразуют строку в срез рун `r := []rune(str)`, разворачивают его и конвертируют обратно `string(r)`.
