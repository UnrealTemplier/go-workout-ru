# Быстрое удаление за O(1) без сохранения порядка (Fast / Unordered Delete)

## Условие

Реализуйте функцию *быстрого* удаления элемента из слайса (без сохранения порядка: просто переместите последний элемент на место удаляемого).

## Теория

**Fast Delete \(O(1)\) (Удаление заменой последним элементом):**
1. Перемещаем последний элемент на место удаляемого: `s[i] = s[len(s)-1]`;
2. Усекаем срез на 1: `s = s[:len(s)-1]`;
3. Время работы **строго \(O(1)\)** независимо от размера среза!

## Решение по шагам

1. Пишем `FastDelete(s []int, i int) []int`.
2. Удаляем элемент из середины.
3. Проверяем скорость и порядок.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func FastDelete(s []int, i int) []int {
	if i < 0 || i >= len(s) {
		return s
	}
	s[i] = s[len(s)-1] // Переносим хвост на место i
	return s[:len(s)-1] // Отрезаем последний элемент
}

func main() {
	s := []int{10, 20, 30, 40, 50}
	fmt.Printf("До удаления:    %v\n", s)

	s = FastDelete(s, 1) // Удаляем число 20
	fmt.Printf("После FastDelete(index 1): %v (число 50 встало на место 20)\n", s)
}
```

ℹ️ Быстрое удаление за O(1)

**`Терминал`**

```bash
go run main.go
# До удаления:    [10 20 30 40 50]
# После FastDelete(index 1): [10 50 30 40] (число 50 встало на место 20)
```

ℹ️ Удаление за O(1) выполнено

## Под капотом

Всего 1 операция записи в память и 1 декремент длины.

## Подводные камни

- Использование там, где критичен порядок следования элементов (например, очереди).

## На собеседовании

**Вопрос с собеседования:** «В каких структурах данных применяется Fast Delete за \(O(1)\)?»
**Ответ:** В пулах соединений, графах, множествах (Set) на основе срезов и игровых движках для списка активных сущностей.
