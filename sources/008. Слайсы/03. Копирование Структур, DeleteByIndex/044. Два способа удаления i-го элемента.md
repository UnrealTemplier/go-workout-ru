# Два способа удаления i-го элемента: с сохранением порядка (append) и через copy

## Условие

Удалите i-й элемент из слайса с сохранением порядка (два способа).

## Теория

Сравнение двух подходов:
1. `append(s[:i], s[i+1:]...)`
2. `copy(s[i:], s[i+1:])` с последующим `s = s[:len(s)-1]`

## Решение по шагам

1. Реализуем оба способа.
2. Проверяем результаты.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func DeleteMethod1(s []int, i int) []int {
	return append(s[:i], s[i+1:]...)
}

func DeleteMethod2(s []int, i int) []int {
	copy(s[i:], s[i+1:])
	return s[:len(s)-1]
}

func main() {
	s1 := []int{10, 20, 30, 40, 50}
	s2 := []int{10, 20, 30, 40, 50}

	res1 := DeleteMethod1(s1, 2)
	res2 := DeleteMethod2(s2, 2)

	fmt.Printf("Способ 1 (append): %v\n", res1)
	fmt.Printf("Способ 2 (copy):   %v\n", res2)
}
```

ℹ️ Два способа удаления элемента

**`Терминал`**

```bash
go run main.go
# Способ 1 (append): [10 20 40 50]
# Способ 2 (copy):   [10 20 40 50]
```

ℹ️ Оба способа дают идентичный результат

## Под капотом

Оба способа транслируются в вызов `runtime.memmove`.

## Подводные камни

- Забыть усечь срез `s[:len(s)-1]` во втором способе.

## На собеседовании

**Вопрос с собеседования:** «Какой способ предпочтительнее в современном Go?»
**Ответ:** `slices.Delete(s, i, i+1)` в Go 1.21+.
