# Удаление элемента по индексу с сохранением порядка (Order-Preserving Delete)

## Условие

Реализуйте функцию, которая удаляет элемент из слайса по индексу с сохранением порядка остальных элементов (используя `append`).

## Теория

Удаление с сохранением порядка элементов со сложностью \(O(N)\).

## Решение по шагам

1. Пишем `RemoveOrdered(s []string, i int) []string`.
2. Проверяем валидность индекса.
3. Склеиваем `append(s[:i], s[i+1:]...)`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func RemoveOrdered(s []string, i int) []string {
	if i < 0 || i >= len(s) {
		return s
	}
	return append(s[:i], s[i+1:]...)
}

func main() {
	tasks := []string{"Auth", "Database", "BugFix", "Deploy", "Logs"}
	fmt.Printf("До:    %v\n", tasks)

	tasks = RemoveOrdered(tasks, 2) // Удаляем "BugFix"
	fmt.Printf("После: %v\n", tasks)
}
```

ℹ️ Удаление с сохранением порядка

**`Терминал`**

```bash
go run main.go
# До:    [Auth Database BugFix Deploy Logs]
# После: [Auth Database Deploy Logs]
```

ℹ️ Порядок задач сохранен

## Под капотом

Элементы сдвигаются влево в непрерывной памяти.

## Подводные камни

- Необработанный выход за границы индекса.

## На собеседовании

**Вопрос с собеседования:** «Какова сложность удаления первого элемента `s = s[1:]` против удаления из середины?»
**Ответ:** Удаление первого элемента через `s = s[1:]` занимает \(O(1)\) времени (просто сдвиг указателя `Data`). Удаление из середины занимает \(O(N)\) из-за сдвига элементов.
