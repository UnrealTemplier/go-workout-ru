# Вставка элемента в середину среза по индексу через append и copy

## Условие

Вставьте элемент в середину слайса (по индексу) с помощью `append` и копирования.

## Теория

Закрепление паттерна вставки.

## Решение по шагам

1. Создаем функцию `Insert(s []string, i int, val string) []string`.
2. Расширяем через `append(s, "")`.
3. Сдвигаем через `copy(s[i+1:], s[i:])`.
4. Записываем `s[i] = val`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func InsertString(s []string, i int, val string) []string {
	s = append(s, "")
	copy(s[i+1:], s[i:])
	s[i] = val
	return s
}

func main() {
	stack := []string{"Go", "Docker", "PostgreSQL"}
	fmt.Printf("До вставки:    %v\n", stack)

	stack = InsertString(stack, 1, "Kubernetes")
	fmt.Printf("После вставки: %v\n", stack)
}
```

ℹ️ Вставка строки в середину

**`Терминал`**

```bash
go run main.go
# До вставки:    [Go Docker PostgreSQL]
# После вставки: [Go Kubernetes Docker PostgreSQL]
```

ℹ️ Вывод

## Под капотом

Векторный сдвиг заголовков строк через `memmove`.

## Подводные камни

- Вставка с невалидным индексом.

## На собеседовании

**Вопрос с собеседования:** «Какова сложность вставки элемента в начало среза `s = append([]T{v}, s...)`?»
**Ответ:** \(O(N)\) по времени и \(O(N)\) по памяти из-за выделения нового буфера под `[]T{v}` и копирования всех элементов.
