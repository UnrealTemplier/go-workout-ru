# Создание независимой копии среза через make + copy и проверка изоляции

## Условие

Используй `copy()` для создания независимой копии слайса. Измени копию и убедись, что оригинал не изменился.

## Теория

Гарантия глубокого клонирования среза.

## Решение по шагам

1. Создаем оригинал `orig := []string{"Alpha", "Beta", "Gamma"}`.
2. Создаем независимую копию `clone := make([]string, len(orig))`.
3. Копируем и мутируем копию.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	orig := []string{"Alpha", "Beta", "Gamma"}
	clone := make([]string, len(orig))
	copy(clone, orig)

	clone[0] = "MODIFIED"

	fmt.Printf("Оригинал: %v\n", orig)
	fmt.Printf("Копия:    %v\n", clone)
}
```

ℹ️ Изолированная копия среза строк

**`Терминал`**

```bash
go run main.go
# Оригинал: [Alpha Beta Gamma]
# Копия:    [MODIFIED Beta Gamma]
```

ℹ️ Оригинал не затронут

## Под капотом

Выделен новый блок памяти под заголовки строк `clone`.

## Подводные камни

- Вызов `copy` в неинициализированный срез `var clone []string`.

## На собеседовании

**Вопрос с собеседования:** «Является ли `copy` глубоким клонированием для среза указателей `[]*Object`?»
**Ответ:** НЕТ! `copy` скопирует только сами адреса указателей (Shallow Copy). Объекты по указателям останутся общими.
