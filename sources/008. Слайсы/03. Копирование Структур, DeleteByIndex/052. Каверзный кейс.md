# Каверзный кейс: append(s3, 10) в подсрез и перезапись следующего элемента родительского среза

## Условие

**[Каверзный кейс]**: Сделай срез `s3 := s[1:3]` и сделай `append(s3, 10)`. Посмотри, изменится ли оригинальный массив `s` (зависит от capacity).

## Теория

**Опасность перезаписи памяти при `append` в подсрез:**
- Пусть `s := []int{1, 2, 3, 4, 5}`;
- `s3 := s[1:3]` имеет `len=2` (элементы 2, 3) и `cap=4` (элементы 2, 3, 4, 5);
- Вызов `s3 = append(s3, 10)` видит, что `len(2) < cap(4)` \(\rightarrow\) реаллокации нет;
- Число 10 записывается в слот `s[3]`, **затирая число 4 в исходном срезе**!

## Решение по шагам

1. Создаем `s := []int{1, 2, 3, 4, 5}`.
2. Создаем `s3 := s[1:3]`.
3. Делаем `s3 = append(s3, 10)`.
4. Смотрим на повреждение исходного среза `s`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func main() {
	s := []int{1, 2, 3, 4, 5}
	s3 := s[1:3] // [2, 3], cap = 4

	fmt.Printf("Исходный s: %v\n", s)
	fmt.Printf("Срез s3:    %v | len = %d, cap = %d\n\n", s3, len(s3), cap(s3))

	// append пишет в существующий базовый массив:
	s3 = append(s3, 10)

	fmt.Println("После s3 = append(s3, 10):")
	fmt.Printf("Срез s3:    %v\n", s3)
	fmt.Printf("Исходный s: %v (ВНИМАНИЕ: элемент s[3] был перезаписан на 10!)\n", s)
}
```

ℹ️ Перезапись родительского среза

**`Терминал`**

```bash
go run main.go
# Исходный s: [1 2 3 4 5]
# Срез s3:    [2 3] | len = 2, cap = 4
# 
# После s3 = append(s3, 10):
# Срез s3:    [2 3 10]
# Исходный s: [1 2 3 10 5] (ВНИМАНИЕ: элемент s[3] был перезаписан на 10!)
```

ℹ️ Элемент 4 затерт числом 10

## Под капотом

`append` записал значение по адресу `s3.Data + 2*sizeof(int)`, что совпадает с адресом `&s[3]`.

## Подводные камни

- Создание подсреза без трехзначного слайсинга и последующий `append` в него.

## На собеседовании

**Вопрос с собеседования:** «Как предотвратить затирание `s[3]` при вызове `append(s3, 10)`?»
**Ответ:** Использовать Full Slice Expression: `s3 := s[1:3:3]`. В этом случае `cap(s3) == 2`, и `append` гарантированно выделит новый массив, оставив `s` неизменным.
