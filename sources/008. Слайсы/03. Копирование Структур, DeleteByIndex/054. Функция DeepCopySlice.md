# Функция DeepCopySlice: гарантированное создание независимого среза

## Условие

Напиши функцию `DeepCopySlice(s []int) []int`, которая создаёт полностью независимую копию (новый underlying array). Используй `make` + `copy`.

## Теория

Реализация надежного клонирования срезов целых чисел.

## Решение по шагам

1. Пишем `DeepCopySlice(s []int) []int`.
2. Обрабатываем случай `s == nil`.
3. Выделяем `make([]int, len(s))` и копируем.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func DeepCopySlice(s []int) []int {
	if s == nil {
		return nil
	}
	clone := make([]int, len(s))
	copy(clone, s)
	return clone
}

func main() {
	original := []int{100, 200, 300}
	copied := DeepCopySlice(original)

	copied[0] = 999

	fmt.Printf("Оригинал: %v (адрес: %p)\n", original, &original[0])
	fmt.Printf("Копия:    %v (адрес: %p)\n", copied, &copied[0])
}
```

ℹ️ Глубокая копия среза

**`Терминал`**

```bash
go run main.go
# Оригинал: [100 200 300] (адрес: 0xc000014070)
# Копия:    [999 200 300] (адрес: 0xc0000140a0)
```

ℹ️ Разные адреса

## Под капотом

Выделяется новый блок в куче.

## Подводные камни

- Возврат `[]int{}` вместо `nil`, если входной срез был `nil`.

## На собеседовании

**Вопрос с собеседования:** «Какая функция в пакете `slices` заменяет `DeepCopySlice` в Go 1.21+?»
**Ответ:** `slices.Clone(s)` (возвращает `nil` для `nil`-среза и новую копию для непустого).
