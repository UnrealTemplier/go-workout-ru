# Безопасное извлечение ошибки через errors.As

## Условие

Используйте `errors.As(err, &validationErr)` для безопасного извлечения вашей кастомной ошибки из глубины обернутых ошибок.

## Теория

`errors.As` заменяет устаревший Type Assertion `err.(MyError)`. В отличие от кастинга, `errors.As` успешно находит ошибку даже внутри многократно обернутой цепочки.

## Решение по шагам

1. Создадим структуру `ValidationError struct { Field string; Code string }`.
2. Напишем функцию с двукратным оборачиванием ошибки.
3. В `main` извлечем `ValidationError` через `errors.As`.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type ValidationError struct {
	Field string
	Code  string
}

func (e *ValidationError) Error() string {
	return fmt.Sprintf("validation failed on field %s (code: %s)", e.Field, e.Code)
}

func parsePayload() error {
	return &ValidationError{Field: "username", Code: "ERR_TOO_SHORT"}
}

func handleRequest() error {
	if err := parsePayload(); err != nil {
		return fmt.Errorf("http handler failed: %w", err)
	}
	return nil
}

func main() {
	err := handleRequest()

	var valErr *ValidationError
	if errors.As(err, &valErr) {
		fmt.Println("Успешно извлечена структура ValidationError:")
		fmt.Printf(" -> Поле: %s\n", valErr.Field)
		fmt.Printf(" -> Код:  %s\n", valErr.Code)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Успешно извлечена структура ValidationError:
#  -> Поле: username
#  -> Код:  ERR_TOO_SHORT
```

## Под капотом

`errors.As` находит первую ошибку в цепочке, чей тип совместим с типом переменной, переданной по указателю.

## Подводные камни

Всегда проверяйте булев результат `if errors.As(err, &target)`. Использование `valErr` без проверки при `false` приведет к nil pointer dereference.

## На собеседовании

**Вопрос с собеседования:** «Почему type assertion err.(*MyError) опасен в современном Go?»
**Ответ:** Если функция внутри обернет ошибку через `fmt.Errorf("%w")`, `err` перестанет быть `*MyError` (станет `*fmt.wrapError`), и type assertion завершится неудачей или паникой.
