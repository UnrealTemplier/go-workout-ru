# Sentinel-ошибки в нескольких функциях пакета

## Условие

Создай **sentinel error**: `var ErrNotFound = errors.New("not found")`. Используй её в нескольких функциях. Проверь через `errors.Is` в разных уровнях обёртки.

## Теория

Sentinel-ошибки объявляются как пакетные переменные `var Err... = errors.New(...)` и экспортируются для использования другими пакетами.

## Решение по шагам

1. Объявим `var ErrNotFound = errors.New("item not found")`.
2. Создадим функции `GetProduct(id int)` и `GetCategory(id int)`.
3. В `main` обработаем результат обеих функций единым блоком `errors.Is`.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

var ErrNotFound = errors.New("item not found")

func GetProduct(id int) error {
	if id <= 0 {
		return fmt.Errorf("product repo: %w", ErrNotFound)
	}
	return nil
}

func GetCategory(id int) error {
	if id <= 0 {
		return fmt.Errorf("category repo: %w", ErrNotFound)
	}
	return nil
}

func checkItem(name string, fetch func(int) error, id int) {
	err := fetch(id)
	if errors.Is(err, ErrNotFound) {
		fmt.Printf("[%s #%d] Объект не найден в системе (HTTP 404)\n", name, id)
	} else if err != nil {
		fmt.Printf("[%s #%d] Системная ошибка: %v\n", name, id, err)
	} else {
		fmt.Printf("[%s #%d] Успешно загружен\n", name, id)
	}
}

func main() {
	checkItem("Товар", GetProduct, -1)
	checkItem("Категория", GetCategory, -5)
	checkItem("Товар", GetProduct, 10)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [Товар #-1] Объект не найден в системе (HTTP 404)
# [Категория #-5] Объект не найден в системе (HTTP 404)
# [Товар #10] Успешно загружен
```

## Под капотом

Один экземпляр переменной `ErrNotFound` переиспользуется всеми функциями пакета без новых аллокаций.

## Подводные камни

Пакетные переменные `var Err...` мутабельны. Ни в коем случае не перезаписывайте их значения в рантайме.

## На собеседовании

**Вопрос с собеседования:** «Как защитить sentinel error от случайной перезаписи из другого пакета?»
**Ответ:** Использовать кастомный тип константы: `type Error string; func (e Error) Error() string { return string(e) }; const ErrNotFound = Error("not found")`.
