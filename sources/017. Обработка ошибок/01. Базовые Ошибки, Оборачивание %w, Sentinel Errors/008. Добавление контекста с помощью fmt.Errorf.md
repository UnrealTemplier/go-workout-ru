# Добавление контекста с помощью fmt.Errorf и глагола %v

## Условие

Используй `fmt.Errorf("reading %s: %v", filename, err)` для добавления контекста. Покажи, что `%v` просто вставляет текст ошибки.

## Теория

Спецификатор `%v` преобразует ошибку `err` в строку через вызов `err.Error()`. При этом результирующая ошибка не реализует метод `Unwrap()`, а значит исходная ошибка скрыта.

## Решение по шагам

1. Создадим ошибку `var ErrDiskFailure = errors.New("hardware read error")`.
2. Обернем её с помощью `%v`: `fmt.Errorf("reading %s: %v", filename, err)`.
3. В `main` покажем, что `errors.Is` вернет `false`.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

var ErrDiskFailure = errors.New("hardware read error")

func readFile(filename string) error {
	// Добавляем строковый контекст без оборачивания:
	return fmt.Errorf("reading %s: %v", filename, ErrDiskFailure)
}

func main() {
	err := readFile("app.json")
	fmt.Println("Текст ошибки:", err)

	// errors.Is не может развернуть %v:
	if errors.Is(err, ErrDiskFailure) {
		fmt.Println("Disk failure detected")
	} else {
		fmt.Println("errors.Is вернул false (цепочка разорвана глаголом %v)")
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Текст ошибки: reading app.json: hardware read error
# errors.Is вернул false (цепочка разорвана глаголом %v)
```

## Под капотом

Спецификатор `%v` создает обычную структуру `errors.errorString`, в которую записывается отформатированная строка.

## Подводные камни

Если вам нужно сохранить возможность проверки исходной ошибки выше по стеку, используйте `%w` вместо `%v`.

## На собеседовании

**Вопрос с собеседования:** «Когда разрыв цепочки через %v является преимуществом?»
**Ответ:** Когда нужно скрыть детали реализации внутреннего слоя (Information Hiding). Например, чтобы слой HTTP-контроллеров не зависел от драйвера базы данных PostgreSQL.
