# Базовые ошибки: errors.New против fmt.Errorf

## Условие

**Базовые ошибки**: Используй `errors.New("bad input")` и `fmt.Errorf("user %s not found", name)` для создания простых ошибок.

## Теория

- `errors.New` используется для статических текстовых сообщений, не требующих форматирования.
- `fmt.Errorf` используется для динамических сообщений с интерполяцией переменных (ID, имена файлов, статусы).

## Решение по шагам

1. Создадим функцию `checkInput(input string) error` со статической ошибкой `errors.New`.
2. Создадим функцию `findUser(name string) error` с динамической ошибкой `fmt.Errorf`.
3. В `main` вызовем обе функции и распечатаем результат.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

func checkInput(input string) error {
	if input == "" {
		return errors.New("bad input: empty payload")
	}
	return nil
}

func findUser(name string) error {
	// Симулируем отсутствие пользователя
	return fmt.Errorf("user %q not found in local cache", name)
}

func main() {
	if err := checkInput(""); err != nil {
		fmt.Println("checkInput err:", err)
	}

	if err := findUser("Алексей"); err != nil {
		fmt.Println("findUser err:  ", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# checkInput err: bad input: empty payload
# findUser err:   user "Алексей" not found in local cache
```

## Под капотом

`errors.New` возвращает указатель `&errorString{s}`. Два вызова `errors.New("err") == errors.New("err")` вернут `false`, так как сравниваются адреса в куче.

## Подводные камни

По соглашению Go, текст ошибок должен начинаться со строчной буквы и не заканчиваться точкой (кроме имен собственных и аббревиатур), чтобы при оборачивании текст сливался в читаемую фразу.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go сообщения об ошибках пишут со строчной буквы?»
**Ответ:** Потому что ошибки в Go часто оборачиваются в цепочки через `fmt.Errorf("failed to %s: %w", op, err)`. Если бы каждая ошибка начиналась с заглавной буквы, цепочка выглядела бы неаккуратно: `Failed to open: File not found: Permission denied`.
