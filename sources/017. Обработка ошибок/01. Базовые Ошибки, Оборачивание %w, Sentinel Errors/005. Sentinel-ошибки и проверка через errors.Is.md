# Sentinel-ошибки и проверка через errors.Is

## Условие

Создайте Sentinel-ошибку `var ErrNotFound = errors.New("not found")`. Используйте `errors.Is(err, ErrNotFound)` для проверки, даже если ошибка была обернута несколько раз.

## Теория

Sentinel Error (маркерная ошибка) — это предопределенная переменная на уровне пакета. `errors.Is` рекурсивно разворачивает цепочку ошибок через `Unwrap()`, проверяя, есть ли среди них искомый маркер.

## Решение по шагам

1. Объявим `var ErrNotFound = errors.New("not found")`.
2. Создадим цепочку из трех функций: `repoFind -> serviceGet -> handlerGet`.
3. Каждая промежуточная функция оборачивает ошибку через `%w`.
4. В `main` убедимся, что `errors.Is(err, ErrNotFound)` находит маркер на самом верху.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

var ErrNotFound = errors.New("not found")

func repoFind(id int) error {
	return ErrNotFound
}

func serviceGet(id int) error {
	if err := repoFind(id); err != nil {
		return fmt.Errorf("service error for id %d: %w", id, err)
	}
	return nil
}

func handlerGet(id int) error {
	if err := serviceGet(id); err != nil {
		return fmt.Errorf("handler GET failed: %w", err)
	}
	return nil
}

func main() {
	err := handlerGet(100)
	if err != nil {
		fmt.Println("Цепочка ошибок:", err)
		if errors.Is(err, ErrNotFound) {
			fmt.Println("-> Результат: запись успешно опознана как ErrNotFound (HTTP 404)")
		}
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Цепочка ошибок: handler GET failed: service error for id 100: not found
# -> Результат: запись успешно опознана как ErrNotFound (HTTP 404)
```

## Под капотом

`errors.Is` проверяет `err == target`, а если не совпало — вызывает метод `Is(error) bool` у структуры ошибки (если он есть) или метод `Unwrap() error`, повторяя поиск по цепочке.

## Подводные камни

Не сравнивайте обернутые ошибки через оператор `==`, так как `err == ErrNotFound` вернет `false` для обернутой ошибки.

## На собеседовании

**Вопрос с собеседования:** «Как работает errors.Is под капотом?»
**Ответ:** 1) Проверяет прямое равенство `err == target`. 2) Проверяет, реализует ли `err` метод `Is(target error) bool`. 3) Если нет, вызывает `Unwrap()` и рекурсивно повторяет алгоритм для внутренней ошибки.
