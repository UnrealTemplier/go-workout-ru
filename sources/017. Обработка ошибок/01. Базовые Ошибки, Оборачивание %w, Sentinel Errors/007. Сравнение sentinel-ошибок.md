# Сравнение sentinel-ошибок: оператор == против errors.Is

## Условие

**Sentinel Errors (Маркерные ошибки)**: Объяви на уровне пакета `var ErrNotFound = errors.New("not found")`. Верни её из функции. В `main` сравни результат строго: `if err == ErrNotFound`.

## Теория

Прямое сравнение `err == ErrNotFound` работает только для прямых необернутых ошибок. Как только ошибка будет обернута через `%w`, прямое сравнение вернет `false`.

## Решение по шагам

1. Объявим пакетную переменную `var ErrUserNotFound = errors.New("user not found")`.
2. Создадим функцию `findDirect(id int) error`, возвращающую `ErrUserNotFound` напрямую.
3. Продемонстрируем успешное сравнение через `==`.
4. Покажем, что для обернутой ошибки `==` ломается, а `errors.Is` работает надежно.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

var ErrUserNotFound = errors.New("user not found")

func findDirect(id int) error {
	return ErrUserNotFound
}

func findWrapped(id int) error {
	return fmt.Errorf("user service: %w", ErrUserNotFound)
}

func main() {
	err1 := findDirect(1)
	fmt.Println("findDirect == ErrUserNotFound:", err1 == ErrUserNotFound)

	err2 := findWrapped(2)
	fmt.Println("findWrapped == ErrUserNotFound:", err2 == ErrUserNotFound) // false!
	fmt.Println("errors.Is(findWrapped, ErrUserNotFound):", errors.Is(err2, ErrUserNotFound)) // true!
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# findDirect == ErrUserNotFound: true
# findWrapped == ErrUserNotFound: false
# errors.Is(findWrapped, ErrUserNotFound): true
```

## Под капотом

`errors.New` выделяет уникальный адрес в памяти. Оператор `==` сравнивает равенство указателей интерфейса `iface.data`.

## Подводные камни

В современном коде Go 1.13+ всегда предпочитайте `errors.Is` прямому оператору `==`.

## На собеседовании

**Вопрос с собеседования:** «Почему в Go 1.13+ не рекомендуется использовать if err == ErrNotFound?»
**Ответ:** Потому что любая внутренняя функция в цепочке вызовов может обернуть ошибку контекстом через `fmt.Errorf("%w")`, после чего прямое сравнение `==` перестанет работать, что приведет к трудноуловимым багам.
