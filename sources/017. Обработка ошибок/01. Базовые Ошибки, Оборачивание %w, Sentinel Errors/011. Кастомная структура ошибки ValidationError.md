# Кастомная структура ошибки ValidationError с метаданными полей

## Условие

**Кастомная структура ошибки**: Создайте структуру `ValidationError` с полями `FieldName string` и `Value any`. Реализуйте метод `Error() string` для этой структуры, чтобы она удовлетворяла интерфейсу `error`.

## Теория

Кастомные ошибки-структуры позволяют передавать вызывающему коду структурированную контекстную информацию (имя некорректного поля, переданное значение, допустимые границы).

## Решение по шагам

1. Объявим структуру `ValidationError` с полями `FieldName string` и `Value any`.
2. Реализуем метод `(e ValidationError) Error() string`.
3. Создадим функцию `validateEmail(email string) error`.
4. В `main` проверим валидацию.

## Код решения

**`main.go`**

```go
package main

import (
	"fmt"
	"strings"
)

type ValidationError struct {
	FieldName string
	Value     any
}

func (e ValidationError) Error() string {
	return fmt.Sprintf("поле %q содержит невалидное значение: %v", e.FieldName, e.Value)
}

func validateEmail(email string) error {
	if !strings.Contains(email, "@") {
		return ValidationError{
			FieldName: "email",
			Value:     email,
		}
	}
	return nil
}

func main() {
	err := validateEmail("invalid-email-address")
	if err != nil {
		fmt.Println("Ошибка валидации:", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Ошибка валидации: поле "email" содержит невалидное значение: invalid-email-address
```

## Под капотом

Поскольку ресивер `(e ValidationError)` объявлен по значению, любая переменная `ValidationError` реализует `error` напрямую.

## Подводные камни

Если объявить метод на указателе `(e *ValidationError)`, то передача структуры по значению `ValidationError{}` не будет удовлетворять интерфейсу `error`.

## На собеседовании

**Вопрос с собеседования:** «Когда объявлять метод Error() на указателе (*MyError), а когда на значении (MyError)?»
**Ответ:** По соглашению в Go метод `Error()` объявляют на указателе `*MyError`, если структура содержит мутируемые поля или для исключения копирования тяжелых структур. Если структура маленькая и иммутабельная (как `time.ParseError`), допустим value receiver.
