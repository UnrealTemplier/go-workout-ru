# Паттерн Must: LoadConfig против MustLoadConfig

## Условие

**Паника vs Ошибка**: Напиши пакет `config`. Сделай функцию `LoadConfig() error` (которая читает файл и возвращает ошибку, если файла нет) и функцию `MustLoadConfig()`, которая вызывает `LoadConfig` и если есть ошибка — делает `panic()`. Это классический паттерн "Must".

## Теория

Префикс `Must...` — общепринятое соглашение в Go для функций инициализации, которые паникуют при сбое. Они применяются только во время старта приложения (`main` или `init`), когда продолжение работы невозможно.

## Решение по шагам

1. Создадим структуру `Config`.
2. Реализуем `LoadConfig(path string) (*Config, error)`.
3. Реализуем `MustLoadConfig(path string) *Config`.
4. В `main` покажем работу паттерна.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type Config struct {
	Port int
}

func LoadConfig(path string) (*Config, error) {
	if path == "" {
		return nil, errors.New("config path is empty")
	}
	return &Config{Port: 8080}, nil
}

// MustLoadConfig паникует при ошибке инициализации
func MustLoadConfig(path string) *Config {
	cfg, err := LoadConfig(path)
	if err != nil {
		panic(fmt.Sprintf("критический сбой загрузки конфига: %v", err))
	}
	return cfg
}

func main() {
	// Безопасная инициализация при старте:
	cfg := MustLoadConfig("app.yaml")
	fmt.Printf("Конфигурация успешно загружена: Port=%d\n", cfg.Port)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Конфигурация успешно загружена: Port=8080
```

## Под капотом

Паттерн `Must` избавляет от необходимости писать `if err != nil` при инициализации глобальных переменных `var re = regexp.MustCompile(...)`.

## Подводные камни

Никогда не вызывайте `Must...` функции внутри HTTP-хендлеров или фоновых воркеров — это приведет к падению сервера.

## На собеседовании

**Вопрос с собеседования:** «В каких стандартных пакетах Go используется паттерн Must?»
**Ответ:** `regexp.MustCompile`, `template.Must`, `net/url.MustParse`. Они предназначены для компиляции статических константных выражений на этапе старта.
