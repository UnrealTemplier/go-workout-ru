# Sentinel-ошибка ErrPermissionDenied и проверка вложенности

## Условие

**Проверка ошибок через `errors.Is`**: Объявите глобальную ошибку-маркер (sentinel error) `var ErrPermissionDenied = errors.New("доступ запрещен")`. Напишите функцию, которая глубоко в цепочке вызовов возвращает эту ошибку (обернутую другими ошибками). В функции `main` проверьте наличие этой конкретной ошибки в цепочке с помощью `errors.Is`.

## Теория

Sentinel-ошибки безопасности должны надежно определяться на уровне контроллера для возврата клиенту кода `403 Forbidden` вместо `500 Internal Server Error`.

## Решение по шагам

1. Объявим `var ErrPermissionDenied = errors.New("доступ запрещен")`.
2. Создадим три уровня вложенности вызовов.
3. В `main` проверим `errors.Is(err, ErrPermissionDenied)`.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

var ErrPermissionDenied = errors.New("доступ запрещен")

func checkACL(userID int) error {
	return ErrPermissionDenied
}

func secureService(userID int) error {
	if err := checkACL(userID); err != nil {
		return fmt.Errorf("security check: %w", err)
	}
	return nil
}

func apiHandler(userID int) error {
	if err := secureService(userID); err != nil {
		return fmt.Errorf("api endpoint /admin: %w", err)
	}
	return nil
}

func main() {
	err := apiHandler(42)
	if errors.Is(err, ErrPermissionDenied) {
		fmt.Println("Безопасность: доступ отклонен (HTTP 403)")
		fmt.Printf("Полная трассировка: %v\n", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Безопасность: доступ отклонен (HTTP 403)
# Полная трассировка: api endpoint /admin: security check: доступ запрещен
```

## Под капотом

`errors.Is` раскручивает стек вызовов без выделения дополнительной памяти.

## Подводные камни

Не маскируйте ошибки прав доступа под общую ошибку базы данных.

## На собеседовании

**Вопрос с собеседования:** «Почему в микросервисах важно мапить ErrPermissionDenied в HTTP 403 / gRPC PermissionDenied?»
**Ответ:** Чтобы клиентское приложение понимало причину отказа (ошибка авторизации) и не запускало бессмысленные автоматические повторы (Retry Storm).
