# Сбор слайса ошибок и объединение через errors.Join (Go 1.20+)

## Условие

Реализуйте функцию, которая может вернуть несколько ошибок (слайс ошибок). Используйте `errors.Join` (Go 1.20+) для объединения.

## Теория

`errors.Join(errs...)` принимает срез `[]error` и объединяет их в единую структуру, реализующую интерфейс `error`.

## Решение по шагам

1. Создадим функцию `checkServerHealth() error`.
2. Проверим базу данных, кэш и брокер сообщений.
3. Соберем ошибки и объединим через `errors.Join`.
4. В `main` распечатаем статус здоровья.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

var (
	ErrDBDown    = errors.New("db: connection timeout")
	ErrCacheDown = errors.New("redis: out of memory")
)

func checkServerHealth() error {
	var errs []error

	// Проверка 1: БД
	errs = append(errs, ErrDBDown)
	// Проверка 2: Кэш
	errs = append(errs, ErrCacheDown)

	return errors.Join(errs...)
}

func main() {
	err := checkServerHealth()
	if err != nil {
		fmt.Println("Отчет о сбоях сервера:")
		fmt.Println(err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Отчет о сбоях сервера:
# db: connection timeout
# redis: out of memory
```

## Под капотом

`joinError` формирует единую строку через `\n`, сохраняя исходный срез ошибок внутри структуры.

## Подводные камни

Если слайс `errs` содержит только `nil`, `errors.Join` вернет `nil`.
