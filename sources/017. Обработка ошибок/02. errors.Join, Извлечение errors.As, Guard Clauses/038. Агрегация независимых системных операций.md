# Агрегация независимых системных операций

## Условие

Напиши функцию, выполняющую несколько независимых операций. Собери все ошибки в `[]error`. Верни aggregated error через `fmt.Errorf("multiple errors: %w", errors.Join(errs...))` (Go 1.20+) или просто склей строк.

## Теория

При параллельном или последовательном выполнении независимых задач (очистка временных файлов, сброс кэшей) важно выполнить *все* задачи и вернуть совокупную ошибку.

## Решение по шагам

1. Создадим функцию `cleanupOldLogs(dirs []string) error`.
2. Для каждой директории выполним удаление.
3. Объединим ошибки через `errors.Join` с контекстом `fmt.Errorf`.
4. В `main` вызовем очистку.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

func cleanDir(dir string) error {
	if dir == "/var/log/protected" {
		return errors.New("permission denied")
	}
	return nil
}

func cleanupOldLogs(dirs []string) error {
	var errs []error
	for _, d := range dirs {
		if err := cleanDir(d); err != nil {
			errs = append(errs, fmt.Errorf("cleanup %s: %w", d, err))
		}
	}

	if len(errs) > 0 {
		return fmt.Errorf("cleanup failed with %d errors:\n%w", len(errs), errors.Join(errs...))
	}
	return nil
}

func main() {
	dirs := []string{"/tmp/logs", "/var/log/protected", "/opt/logs"}
	if err := cleanupOldLogs(dirs); err != nil {
		fmt.Println(err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# cleanup failed with 1 errors:
# cleanup /var/log/protected: permission denied
```

## Под капотом

Двойное оборачивание через `%w` и `errors.Join` сохраняет полную древовидную структуру ошибок.

## Подводные камни

Не прерывайте цикл очистки при первой ошибке, если остальные директории могут быть успешно очищены.

## На собеседовании

**Вопрос с собеседования:** «В чем отличие Best Effort от Fail Fast?»
**Ответ:** Fail Fast немедленно завершает операцию при первой ошибке. Best Effort выполняет максимально возможный объем работы, собирает все возникшие ошибки и возвращает их агрегированный результат.
