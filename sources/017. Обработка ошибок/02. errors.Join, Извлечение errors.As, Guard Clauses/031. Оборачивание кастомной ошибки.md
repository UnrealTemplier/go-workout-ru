# Оборачивание кастомной ошибки и распаковка через errors.As

## Условие

Верни кастомную ошибку из функции, обернув её через `%w`. Извлеки оригинальный тип ошибки с помощью `errors.As`.

## Теория

Кастомные структуры ошибок, обернутые через `%w`, сохраняют все свои поля и методы при извлечении через `errors.As`.

## Решение по шагам

1. Создадим структуру `QuotaExceededError struct { Limit, Used int }`.
2. Обернем её: `fmt.Errorf("storage service: %w", &QuotaExceededError{Limit: 100, Used: 120})`.
3. В `main` извлечем структуру через `errors.As` и подсчитаем перерасход.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type QuotaExceededError struct {
	Limit int
	Used  int
}

func (e *QuotaExceededError) Error() string {
	return fmt.Sprintf("превышена квота: использовано %d из %d MB", e.Used, e.Limit)
}

func uploadFile(sizeMB int) error {
	limit := 100
	if sizeMB > limit {
		return fmt.Errorf("upload handler: %w", &QuotaExceededError{Limit: limit, Used: sizeMB})
	}
	return nil
}

func main() {
	err := uploadFile(150)
	if err != nil {
		var quotaErr *QuotaExceededError
		if errors.As(err, &quotaErr) {
			fmt.Printf("Перерасход квоты на %d MB!\n", quotaErr.Used-quotaErr.Limit)
		}
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Перерасход квоты на 50 MB!
```

## Под капотом

`errors.As` выполняет рекурсивный поиск по цепочке `Unwrap` и находит указатель на `*QuotaExceededError`.

## Подводные камни

Переменная `var quotaErr *QuotaExceededError` изначально равна `nil`. `errors.As` сама инициализирует её адресом найденной структуры.

## На собеседовании

**Вопрос с собеседования:** «Может ли errors.As извлечь интерфейс, а не конкретную структуру?»
**Ответ:** Да! `errors.As` может искать ошибку, реализующую определенный интерфейс (например `interface{ Timeout() bool }`), что позволяет писать абстрактные обработчики.
