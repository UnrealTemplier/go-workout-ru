# Агрегация ошибок валидации формы через errors.Join (Go 1.20+)

## Условие

Изучите функцию `errors.Join` (Go 1.20+), чтобы собрать несколько ошибок, возникших при валидации разных полей формы, в одну агрегированную ошибку.

## Теория

Функция `errors.Join(errs ...error) error` объединяет срез ошибок в единое дерево ошибок. Результирующая ошибка форматирует все сообщения через перенос строки `\n` и реализует метод `Unwrap() []error`.

## Решение по шагам

1. Создадим форму `RegistrationForm` с полями `Email`, `Password`, `Age`.
2. Напишем валидатор `ValidateForm(f RegistrationForm) error`.
3. Соберем ошибки в срез и вернем `errors.Join(errs...)`.
4. В `main` убедимся, что `errors.Is` находит любую из ошибок в объединенном результате.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
	"strings"
)

var (
	ErrInvalidEmail    = errors.New("некорректный email")
	ErrPasswordTooWeak = errors.New("пароль должен быть не менее 8 символов")
	ErrUnderage        = errors.New("возраст должен быть не менее 18 лет")
)

type RegistrationForm struct {
	Email    string
	Password string
	Age      int
}

func ValidateForm(f RegistrationForm) error {
	var errs []error
	if !strings.Contains(f.Email, "@") {
		errs = append(errs, ErrInvalidEmail)
	}
	if len(f.Password) < 8 {
		errs = append(errs, ErrPasswordTooWeak)
	}
	if f.Age < 18 {
		errs = append(errs, ErrUnderage)
	}
	return errors.Join(errs...)
}

func main() {
	form := RegistrationForm{
		Email:    "bad-email",
		Password: "123",
		Age:      15,
	}

	err := ValidateForm(form)
	if err != nil {
		fmt.Println("Сводная ошибка валидации:")
		fmt.Println(err)

		// errors.Is находит каждую отдельную ошибку в Join:
		fmt.Println("-> Email с ошибкой:", errors.Is(err, ErrInvalidEmail))
		fmt.Println("-> Пароль слабый: ", errors.Is(err, ErrPasswordTooWeak))
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Сводная ошибка валидации:
# некорректный email
# пароль должен быть не менее 8 символов
# возраст должен быть не менее 18 лет
# -> Email с ошибкой: true
# -> Пароль слабый:  true
```

## Под капотом

`errors.Join` фильтрует `nil` элементы и возвращает `nil`, если все аргументы равны `nil`.

## Подводные камни

`errors.Join` доступен только в Go 1.20+. В старых версиях использовались внешние библиотеки вроде `uber-go/multierr`.

## На собеседовании

**Вопрос с собеседования:** «Как errors.Is проверяет ошибку внутри errors.Join?»
**Ответ:** `errors.Join` возвращает структуру `joinError`, реализующую метод `Unwrap() []error`. Функция `errors.Is` рекурсивно обходит каждый элемент возвращенного среза.
