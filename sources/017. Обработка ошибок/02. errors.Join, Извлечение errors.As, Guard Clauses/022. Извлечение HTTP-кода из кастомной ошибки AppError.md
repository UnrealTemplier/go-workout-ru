# Извлечение HTTP-кода из кастомной ошибки AppError через errors.As

## Условие

**Извлечение типа `errors.As`**: Оберни свою структуру `AppError` (из упр. 202) через `%w`. В `main` используй `errors.As(err, &myAppErr)`, чтобы достать её из обертки и прочитать конкретный HTTP `Code`.

## Теория

`errors.As` позволяет слою HTTP-хендлеров централизованно мапить кастомные ошибки доменного слоя в соответствующие HTTP-статус коды (400, 403, 404, 500).

## Решение по шагам

1. Объявим `type AppError struct { HTTPCode int; Message string }`.
2. Реализуем `(e *AppError) Error() string`.
3. Создадим цепочку вызовов `DomainService -> HTTPHandler`.
4. В `main` извлечем `HTTPCode`.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

type AppError struct {
	HTTPCode int
	Message  string
}

func (e *AppError) Error() string {
	return fmt.Sprintf("HTTP %d: %s", e.HTTPCode, e.Message)
}

func domainLogic() error {
	return &AppError{HTTPCode: 403, Message: "доступ запрещен настройками приватности"}
}

func service() error {
	if err := domainLogic(); err != nil {
		return fmt.Errorf("service layer: %w", err)
	}
	return nil
}

func main() {
	err := service()
	if err != nil {
		var appErr *AppError
		if errors.As(err, &appErr) {
			fmt.Printf("Отправка клиенту статуса: %d\n", appErr.HTTPCode)
			fmt.Printf("Тело ответа:             %s\n", appErr.Message)
		}
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Отправка клиенту статуса: 403
# Тело ответа:             доступ запрещен настройками приватности
```

## Под капотом

`errors.As` проверяет типы на соответствие указателю `*AppError` и копирует адрес структуры.

## Подводные камни

Передавайте в `errors.As` указатель на указатель `&appErr`, где `var appErr *AppError`.

## На собеседовании

**Вопрос с собеседования:** «Как в production HTTP-серверах реализуют централизованный Error Handler?»
**Ответ:** Кастомные HTTP-хэндлеры возвращают `error`. Централизованный middleware перехватывает ошибку, через `errors.As` извлекает `*AppError`, выставляет соответствующий HTTP-код, пишет аудит-лог и отправляет JSON клиенту.
