# Диспетчеризация sentinel errors через switch и errors.Is

## Условие

Напиши функцию, возвращающую разные sentinel errors: `ErrInvalidInput`, `ErrNotFound`, `ErrPermissionDenied`. В вызывающем коде используй `switch` с `errors.Is` для разной логики обработки.

### Исходная формулировка

Напиши функцию, возвращающую разные sentinel errors: `ErrInvalidInput`, `ErrNotFound`, `ErrPermissionDenied`. В вызывающем коде используй `switch` с `errors.Is` для разной логики обработки.

---

## Теория

Конструкция `switch` с предикатами `errors.Is` позволяет элегантно маршрутизировать обработку различных бизнес-ошибок.

## Решение по шагам

1. Объявим три sentinel-ошибки: `ErrInvalidInput`, `ErrNotFound`, `ErrPermissionDenied`.
2. Создадим функцию `executeAction(code int) error`.
3. В `main` напишем блок `switch` с ветками `case errors.Is(err, ...)`.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

var (
	ErrInvalidInput      = errors.New("invalid input")
	ErrNotFound          = errors.New("not found")
	ErrPermissionDenied  = errors.New("permission denied")
)

func executeAction(scenario int) error {
	switch scenario {
	case 1:
		return fmt.Errorf("action: %w", ErrInvalidInput)
	case 2:
		return fmt.Errorf("action: %w", ErrNotFound)
	case 3:
		return fmt.Errorf("action: %w", ErrPermissionDenied)
	default:
		return nil
	}
}

func handle(scenario int) {
	err := executeAction(scenario)
	switch {
	case errors.Is(err, ErrInvalidInput):
		fmt.Println("[400 Bad Request] Некорректные параметры запроса")
	case errors.Is(err, ErrNotFound):
		fmt.Println("[404 Not Found] Запрошенный объект не существует")
	case errors.Is(err, ErrPermissionDenied):
		fmt.Println("[403 Forbidden] Недостаточно прав для операции")
	case err != nil:
		fmt.Printf("[500 Internal Error] Непредвиденный сбой: %v\n", err)
	default:
		fmt.Println("[200 OK] Успешное выполнение")
	}
}

func main() {
	handle(1)
	handle(2)
	handle(3)
	handle(0)
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# [400 Bad Request] Некорректные параметры запроса
# [404 Not Found] Запрошенный объект не существует
# [403 Forbidden] Недостаточно прав для операции
# [200 OK] Успешное выполнение
```

## Под капотом

`switch` без условия (tagless switch) вычисляет булевы выражения в порядке их объявления сверху вниз.

## Подводные камни

Ветка `case err != nil` должна быть предпоследней перед `default`, чтобы перехватывать все остальные непредвиденные ошибки.

## На собеседовании

**Вопрос с собеседования:** «В каком порядке следует проверять ошибки в switch?»
**Ответ:** От самых специфичных и частых ошибок к более общим, завершая проверкой `case err != nil` для непредвиденных системных сбоев (Catch-all).
