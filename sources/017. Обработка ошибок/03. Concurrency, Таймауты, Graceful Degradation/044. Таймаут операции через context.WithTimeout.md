# Таймаут операции через context.WithTimeout и context.DeadlineExceeded

## Условие

Напиши функцию `Timeout(operation func() error, timeout time.Duration) error`, используя `context.WithTimeout`. Отменяй операцию по таймауту и возвращай `context.DeadlineExceeded`.

## Теория

`context.WithTimeout` — стандартный способ ограничения времени выполнения блокирующих операций. При превышении лимита контекст закрывает канал `ctx.Done()` и возвращает ошибку `context.DeadlineExceeded`.

## Решение по шагам

1. Создадим функцию `RunWithTimeout(timeout time.Duration, op func() error) error`.
2. Запустим операцию в горутине, передавая результат в канал `done := make(chan error, 1)`.
3. Через `select` выберем `case err := <-done` или `case <-ctx.Done(): return ctx.Err()`.
4. В `main` проверим быстрый и зависающий вызовы.

## Код решения

**`main.go`**

```go
package main

import (
	"context"
	"errors"
	"fmt"
	"time"
)

func RunWithTimeout(timeout time.Duration, op func() error) error {
	ctx, cancel := context.WithTimeout(context.Background(), timeout)
	defer cancel()

	done := make(chan error, 1)
	go func() {
		done <- op()
	}()

	select {
	case err := <-done:
		return err
	case <-ctx.Done():
		return ctx.Err() // context.DeadlineExceeded
	}
}

func main() {
	slowOperation := func() error {
		time.Sleep(100 * time.Millisecond)
		return nil
	}

	err := RunWithTimeout(20*time.Millisecond, slowOperation)
	if errors.Is(err, context.DeadlineExceeded) {
		fmt.Println("Операция отменена по таймауту:", err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Операция отменена по таймауту: context deadline exceeded
```

## Под капотом

Буферизованный канал `make(chan error, 1)` предотвращает утечку горутины, если та завершится после истечения таймаута.

## Подводные камни

Всегда создавайте канал завершения с буфером размера 1, иначе горутина зависнет на отправке `done <- op()`, вызвав утечку памяти (Goroutine Leak).

## На собеседовании

**Вопрос с собеседования:** «Почему канал done в паттерне Timeout обязан быть буферизованным?»
**Ответ:** Если канал небуферизован, а операция завершилась после того, как `select` вышел по `ctx.Done()`, горутина навечно заблокируется на `done <- err`, так как читателя больше нет. Буфер емкостью 1 позволяет горутине завершиться и быть собранной сборщиком мусора.
