# Множественные ошибки и их проверка через errors.Is

## Условие

**[Каверзный кейс]**: Напиши функцию, которая возвращает несколько ошибок одновременно. (Можно использовать `errors.Join` из Go 1.20+). Проверь наличие конкретной ошибки в объединенной ошибке через `errors.Is`.

## Теория

`errors.Is` умеет находить маркерную ошибку внутри `errors.Join`, даже если она является лишь одной из пяти объединенных ошибок.

## Решение по шагам

1. Объявим две маркерные ошибки `ErrQuotaExceeded` и `ErrRateLimited`.
2. Создадим функцию `checkLimits() error`, возвращающую обе ошибки через `errors.Join`.
3. В `main` проверим наличие каждой ошибки через `errors.Is`.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
)

var (
	ErrQuotaExceeded = errors.New("monthly quota exceeded")
	ErrRateLimited   = errors.New("too many requests per second")
)

func checkLimits() error {
	return errors.Join(ErrQuotaExceeded, ErrRateLimited)
}

func main() {
	err := checkLimits()

	fmt.Println("Полный текст объединенных ошибок:")
	fmt.Println(err)

	fmt.Println("\nПроверка через errors.Is:")
	fmt.Println("-> Содержит ErrQuotaExceeded:", errors.Is(err, ErrQuotaExceeded))
	fmt.Println("-> Содержит ErrRateLimited:  ", errors.Is(err, ErrRateLimited))
	fmt.Println("-> Содержит ErrNotFound:     ", errors.Is(err, errors.New("not found")))
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Полный текст объединенных ошибок:
# monthly quota exceeded
# too many requests per second
# 
# Проверка через errors.Is:
# -> Содержит ErrQuotaExceeded: true
# -> Содержит ErrRateLimited:   true
# -> Содержит ErrNotFound:      false
```

## Под капотом

`joinError.Unwrap()` возвращает срез `[]error`, по которому `errors.Is` выполняет рекурсивный поиск.

## Подводные камни

Не проверяйте объединенные ошибки простым сравнением `err == ErrQuotaExceeded`, так как `joinError` — это отдельная структура.

## На собеседовании

**Вопрос с собеседования:** «Как errors.As работает с errors.Join?»
**Ответ:** `errors.As` обходит срез ошибок слева направо и возвращает *первую* ошибку, совпавшую с запрашиваемым типом.
