# Комплексная валидация формы регистрации через errors.Join

## Условие

**Объединение ошибок (`errors.Join`)**: Напишите валидатор формы регистрации. Напишите несколько независимых проверок (валидация email, пароля, возраста). Соберите все возникшие ошибки в один пакет с помощью функции `errors.Join` (доступна в современных версиях Go) и верните результат вызывающему коду.

## Теория

Комплексная валидация позволяет пользователю исправить все ошибки в форме за один раз, а не отправлять запрос по кругу после исправления каждого отдельного поля.

## Решение по шагам

1. Создадим форму `UserSignupRequest`.
2. Реализуем проверки: email содержит `@`, пароль \(\ge 8\) символов, возраст \(\ge 18\).
3. Объединим ошибки через `errors.Join`.
4. В `main` выведем отчет.

## Код решения

**`main.go`**

```go
package main

import (
	"errors"
	"fmt"
	"strings"
)

type UserSignupRequest struct {
	Email    string
	Password string
	Age      int
}

func ValidateSignup(req UserSignupRequest) error {
	var errs []error

	if !strings.Contains(req.Email, "@") || !strings.Contains(req.Email, ".") {
		errs = append(errs, errors.New("email: некорректный формат адреса"))
	}
	if len(req.Password) < 8 {
		errs = append(errs, errors.New("password: длина должна быть не менее 8 символов"))
	}
	if req.Age < 18 {
		errs = append(errs, errors.New("age: регистрация доступна только с 18 лет"))
	}

	return errors.Join(errs...)
}

func main() {
	req := UserSignupRequest{
		Email:    "invalid_email",
		Password: "short",
		Age:      16,
	}

	if err := ValidateSignup(req); err != nil {
		fmt.Println("Ошибки заполнения формы:")
		fmt.Println(err)
	}
}
```

**`Терминал`**

```bash
go run main.go
# Вывод:
# Ошибки заполнения формы:
# email: некорректный формат адреса
# password: длина должна быть не менее 8 символов
# age: регистрация доступна только с 18 лет
```

## Под капотом

`errors.Join` создает структуру `joinError`, форматируя сообщения через `\n`.

## Подводные камни

Не используйте `errors.Join`, если ошибки должны приводить к мгновенной остановке вычислений (Fail Fast).

## На собеседовании

**Вопрос с собеседования:** «Как обработать каждую ошибку из errors.Join по отдельности?»
**Ответ:** Если ошибка реализует `interface{ Unwrap() []error }`, можно вызвать этот метод и проитерироваться по срезу вложенных ошибок `for _, err := range err.(interface{ Unwrap() []error }).Unwrap()`.
