# Анализ энтропии: расчет энтропии Шеннона (Shannon Entropy) для проверки CSPRNG

## Условие

**Entropy analysis**: Напишите утилиту, которая оценивает энтропию сгенерированных данных через подсчёт Shannon entropy. Убедитесь, что ваш генератор даёт ~8 бит/байт.

## Теория

**Информационная энтропия Шеннона** (Shannon Entropy, 1948) — фундаментальная мера неопределенности или плотности информации в источнике данных.

Формула энтропии Шеннона:
$$H(X) = - \sum_{i=0}^{255} P(x_i) \log_2 P(x_i)$$
где:
- \(P(x_i) = \frac{\text{count}(x_i)}{N}\) — эмпирическая вероятность появления байта со значением \(x_i \in [0, 255]\) в потоке длиной \(N\) байт.
- \(\log_2 P(x_i)\) — объем информации в битах.

Интерпретация результатов:
1. **Для абсолютно случайного криптографического источника (CSPRNG):** Все 256 значений байт встречаются с одинаковой вероятностью \(P(x_i) = \frac{1}{256}\).
   $$H_{\max} = - \sum_{i=0}^{255} \frac{1}{256} \log_2\left(\frac{1}{256}\right) = - 256 \cdot \frac{1}{256} \cdot (-8) = 8.0 \text{ бит/байт}$$
   Значение \(H \approx 7.999 \dots 8.000\) свидетельствует об отсутствии паттернов и высокой энтропии.
2. **Для несжатого английского текста:** \(H \approx 3.5 - 4.5\) бит/байт.
3. **Для вырожденного источника (все нули):** \(H = 0.0\) бит/байт.

## Решение по шагам

1. Создайте функцию `CalculateShannonEntropy(data []byte) float64`.
2. Подсчитайте частоту появления каждого из 256 возможных байтов с помощью массива `[256]int`.
3. Для каждого встретившегося байта вычислите вероятность \(p = \text{count} / N\).
4. Суммируйте значение \(-p \cdot \log_2(p)\) с использованием `math.Log2`.
5. Сгенерируйте 100 000 байт через `crypto/rand` и убедитесь, что энтропия \(\approx 7.999\) бит/байт.
6. Для сравнения вычислите энтропию структурированного JSON/текста.

## Код решения

**`main.go`**

```go
package main

import (
	"crypto/rand"
	"fmt"
	"io"
	"log"
	"math"
)

// CalculateShannonEntropy вычисляет информационную энтропию в битах на байт (максимум 8.0)
func CalculateShannonEntropy(data []byte) float64 {
	if len(data) == 0 {
		return 0.0
	}

	// 1. Подсчет частоты каждого байта (0..255)
	var freq [256]int
	for _, b := range data {
		freq[b]++
	}

	total := float64(len(data))
	var entropy float64

	// 2. Расчет суммы по формуле Шеннона: -SUM(p * log2(p))
	for _, count := range freq {
		if count == 0 {
			continue
		}
		p := float64(count) / total
		entropy -= p * math.Log2(p)
	}

	return entropy
}

func main() {
	sampleSize := 100_000

	// 1. Тест криптографического генератора crypto/rand
	csprngData := make([]byte, sampleSize)
	if _, err := io.ReadFull(rand.Reader, csprngData); err != nil {
		log.Fatalf("Ошибка CSPRNG: %v", err)
	}
	csprngEntropy := CalculateShannonEntropy(csprngData)

	// 2. Тест обычного структурированного текста
	plainText := []byte("The quick brown fox jumps over the lazy dog. HighLoad Go Enterprise Security!")
	textData := make([]byte, sampleSize)
	for i := 0; i < sampleSize; i++ {
		textData[i] = plainText[i%len(plainText)]
	}
	textEntropy := CalculateShannonEntropy(textData)

	// 3. Тест вырожденных данных (все нули)
	zeroData := make([]byte, sampleSize)
	zeroEntropy := CalculateShannonEntropy(zeroData)

	fmt.Println("=== Анализ информационной энтропии Шеннона (Shannon Entropy) ===")
	fmt.Printf("1. crypto/rand (CSPRNG): %.5f бит/байт (Идеал: ~8.00000)\n", csprngEntropy)
	fmt.Printf("2. Повторяющийся текст:  %.5f бит/байт (Присутствует избыточность)\n", textEntropy)
	fmt.Printf("3. Нулевые байты (0x00): %.5f бит/байт (Полная предсказуемость)\n\n", zeroEntropy)

	if csprngEntropy > 7.99 {
		fmt.Println("ВЕРДИКТ: Генератор crypto/rand обладает безупречной энтропией ядра ОС.")
	}
}
```

## Под капотом

Связь энтропии Шеннона со сжатием и шифрованием:
1. **Теорема Шеннона о кодировании источника:** Никакой алгоритм сжатия без потерь (Gzip, ZSTD, Snappy) не может сжать данные до размера, меньшего, чем их энтропия Шеннона.
2. Данные с энтропией \(H \approx 8.0\) бит/байт математически неотличимы от белого шума и не сжимаются (коэффициент сжатия Gzip будет \(\ge 100\%\)).
3. Если зашифрованный AES-GCM шифротекст или вывод ГСЧ сжимается архиватором, это однозначный признак криптографической уязвимости (утечка структуры открытого текста или плохой ГСЧ).

## Подводные камни

1. **Ложное чувство безопасности (Entropy vs Cryptographic Security):** Высокая энтропия Шеннона (\(\approx 8.0\)) является *необходимым*, но *не достаточным* условием криптостойкости! Простой счетчик \(0, 1, 2, \dots\) или генератор `math/rand` при достаточно большом объеме также дадут энтропию ~7.99 бит/байт, однако они на 100% предсказуемы.
2. **Деление на ноль:** При пустом входном срезе `len(data) == 0` вычисление вероятностей упадет с делением на 0 или `NaN` в логарифме. Необходима предварительная проверка длины.

## На собеседовании

**Вопрос с собеседования:** Почему высокая энтропия Шеннона (близкая к 8.0 бит/байт) не гарантирует, что генератор случайных чисел является криптографически стойким?
**Ответ:** Энтропия Шеннона измеряет только **равномерность частотного распределения байт** в массиве данных (отсутствие перекоса в сторону отдельных байтов). Например, последовательность чисел \(0, 1, 2, 3 \dots 255\), повторенная 1000 раз, покажет идеальную энтропию 8.0 бит/байт, но следующее число тривиально предсказывается. Криптографическая стойкость (CSPRNG) требует соблюдения гораздо более строгого критерия — **непредсказуемости следующего бита (Next-Bit Unpredictability)** при известности всей предыдущей истории, что проверяется тестами NIST SP 800-22 и Dieharder, а не одной лишь формулой Шеннона.
