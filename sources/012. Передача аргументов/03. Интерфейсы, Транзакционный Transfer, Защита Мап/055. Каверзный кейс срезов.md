# Каверзный кейс срезов: передача по значению и мутация s[0] = 99

## Условие

**Каверзный случай: Срезы (Slices)**: Создай срез `s := []int{1, 2, 3}`. Передай его в функцию по значению (без `*`). Внутри функции измени первый элемент (`s[0] = 99`). Убедись, что в `main` элемент *тоже изменился*, хотя срез передавался по значению. (Объяснение: срез сам по себе содержит неявно указатель на базовый массив).

## Теория

Глубокое закрепление дуализма срезов: заголовок по значению, данные по ссылке.

## Решение по шагам

1. Создаем срез `s := []int{1, 2, 3}`.
2. Пишем `MutateFirst(s []int)`.
3. Проверяем в `main()`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func MutateFirst(s []int) {
	if len(s) > 0 {
		s[0] = 99
	}
}

func main() {
	s := []int{1, 2, 3}
	fmt.Printf("До:    %v\n", s)

	MutateFirst(s)

	fmt.Printf("После: %v (s[0] ИЗМЕНИЛСЯ НА 99!)\n", s)
}
```

**`Терминал`**

```bash
go run main.go
# До:    [1 2 3]
# После: [99 2 3] (s[0] ИЗМЕНИЛСЯ НА 99!)
```

## Под капотом

Прямая запись по указателю `s.Data`.

## Подводные камни

- Неожиданная мутация срезов при передаче в сторонние функции.

## На собеседовании

**Вопрос с собеседования:** «Как защитить срез от мутаций при передаче в функцию?»
**Ответ:** Передавать клонированную копию через `slices.Clone(s)` или копировать в локальный срез `copy()`.
