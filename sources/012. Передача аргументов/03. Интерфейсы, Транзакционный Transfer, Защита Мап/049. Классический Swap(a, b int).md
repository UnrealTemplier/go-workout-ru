# Классический Swap(a, b *int) и атомарный обмен в регистрах CPU

## Условие

Напиши функцию `Swap(a, b *int)`, которая меняет значения двух переменных местами.

## Теория

Обмен значений по указателям.

## Решение по шагам

1. Пишем `Swap(a, b *int)`.
2. Выполняем `*a, *b = *b, *a`.
3. Проверяем переменные.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func Swap(a, b *int) {
	if a != nil && b != nil {
		*a, *b = *b, *a
	}
}

func main() {
	x, y := 10, 99
	fmt.Printf("До Swap:    x=%d, y=%d\n", x, y)

	Swap(&x, &y)

	fmt.Printf("После Swap: x=%d, y=%d\n", x, y)
}
```

**`Терминал`**

```bash
go run main.go
# До Swap:    x=10, y=99
# После Swap: x=99, y=10
```

## Под капотом

Инструкции `MOVQ` через регистры CPU.

## Подводные камни

- Передача `nil`-указателя.

## На собеседовании

**Вопрос с собеседования:** «Как поменять два значения без третьей переменной и кортежа?»
**Ответ:** Через побитовое XOR: `*a ^= *b; *b ^= *a; *a ^= *b`.
