# Передача головы связного списка Node в функцию и последовательный обход

## Условие

Создай структуру `Node` с полем `Next *Node`. Построй связный список из 3 элементов. Передай голову списка в функцию и пройдись по нему.

## Теория

Передача корневого указателя динамической цепочки узлов.

## Решение по шагам

1. Создаем структуру `Node{Value int, Next *Node}`.
2. Пишем функцию `Traverse(head *Node)`.
3. Обходим список.

## Код решения

**`main.go`**

```go
package main

import "fmt"

type Node struct {
	Value int
	Next  *Node
}

func Traverse(head *Node) {
	curr := head
	for curr != nil {
		fmt.Printf("[%d] -> ", curr.Value)
		curr = curr.Next
	}
	fmt.Println("nil")
}

func main() {
	head := &Node{Value: 10, Next: &Node{Value: 20, Next: &Node{Value: 30}}}
	fmt.Print("Связный список: ")
	Traverse(head)
}
```

**`Терминал`**

```bash
go run main.go
# Связный список: [10] -> [20] -> [30] -> nil
```

## Под капотом

Обход указателей по адресам в куче.

## Подводные камни

- Передача зацикленного списка без проверки шагов.

## На собеседовании

**Вопрос с собеседования:** «Как удалить узел из середины списка за \(O(1)\)?»
**Ответ:** Перенаправить указатель: `prev.Next = curr.Next`.
