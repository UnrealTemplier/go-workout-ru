# Каналы (Channels) как ссылочный тип: передача дескриптора по значению и чтение данных

## Условие

**Каналы (Channels) как ссылочный тип**: Создайте канал. Передайте его в функцию по значению. Запишите данные в канал внутри функции, а прочитайте снаружи. Работает ли передача каналов по значению как передача ссылки?

## Теория

Закрепление ссылочной природы каналов в Go.

## Решение по шагам

1. Создаем канал `ch := make(chan string, 1)`.
2. Пишем функцию `WriteMessage(ch chan string)`.
3. Читаем сообщение в `main()`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func WriteMessage(ch chan string) {
	ch <- "Сообщение успешно доставлено через канал!"
}

func main() {
	ch := make(chan string, 1)

	WriteMessage(ch)

	msg := <-ch
	fmt.Printf("Получено: %s\n", msg)
}
```

**`Терминал`**

```bash
go run main.go
# Получено: Сообщение успешно доставлено через канал!
```

## Под капотом
