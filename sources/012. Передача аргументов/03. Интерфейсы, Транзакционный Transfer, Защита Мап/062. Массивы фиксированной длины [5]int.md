# Массивы фиксированной длины [5]int и иммутабельность оригинала при передаче

## Условие

**Массивы (Arrays) фиксированной длины**: Создайте массив `[5]int{1, 2, 3, 4, 5}`. Передайте его в функцию по значению. Измените элемент внутри функции. Изменился ли массив снаружи? (Обратите внимание на ключевое отличие поведения массивов от срезов в Go).

## Теория

Демонстрация полного копирования 40-байтного массива.

## Решение по шагам

1. Создаем `[5]int{1, 2, 3, 4, 5}`.
2. Пишем функцию `ZeroOutArray(a [5]int)`.
3. Проверяем результат.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func ZeroOutArray(a [5]int) {
	for i := range a {
		a[i] = 0
	}
}

func main() {
	numbers := [5]int{1, 2, 3, 4, 5}
	fmt.Printf("До вызова:    %v\n", numbers)

	ZeroOutArray(numbers)

	fmt.Printf("После вызова: %v (МАССИВ СОХРАНИЛ ВСЕ ЗНАЧЕНИЯ!)\n", numbers)
}
```

**`Терминал`**

```bash
go run main.go
# До вызова:    [1 2 3 4 5]
# После вызова: [1 2 3 4 5] (МАССИВ СОХРАНИЛ ВСЕ ЗНАЧЕНИЯ!)
```

## Под капотом

40 байт данных копируются на стековый кадр функции.

## Подводные камни

- Предположение, что массив изменится как срез.
