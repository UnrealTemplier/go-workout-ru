# Правильный append через указатель *s = append(*s, 4) в оригинале

## Условие

**Правильный Append через функцию**: Чтобы `append` сработал на оригинале, перепиши функцию из упр. 88, передавая указатель на срез `*[]int`, и выполни `*s = append(*s, 4)`.

## Теория

Закрепление паттерна `*s = append(*s, ...)`.

## Решение по шагам

1. Пишем `AppendFour(s *[]int)`.
2. Вызываем с адресом `&slice`.
3. Проверяем в `main()`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func AppendFour(s *[]int) {
	if s != nil {
		*s = append(*s, 4)
	}
}

func main() {
	s := []int{1, 2, 3}
	AppendFour(&s)
	fmt.Printf("Результат: %v (len=%d)\n", s, len(s))
}
```

**`Терминал`**

```bash
go run main.go
# Результат: [1 2 3 4] (len=4)
```

## На собеседовании

**Вопрос с собеседования:** «Какой тип имеет `&s`?»
**Ответ:** `*[]int`.
