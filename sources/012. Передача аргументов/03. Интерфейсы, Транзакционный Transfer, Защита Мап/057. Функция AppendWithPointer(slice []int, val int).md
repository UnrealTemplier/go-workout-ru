# Функция AppendWithPointer(slice *[]int, val int) и обновление емкости снаружи

## Условие

**Передача среза по указателю**: Напишите функцию `AppendWithPointer(slice *[]int, val int)`. Передайте туда срез по указателю и примените `append`. Убедитесь, что теперь изменения (размер и емкость) отразились снаружи.

## Теория

Мутация среза через разыменование указателя на заголовок.

## Решение по шагам

1. Пишем `AppendWithPointer(slice *[]int, val int)`.
2. Вызываем `*slice = append(*slice, val)`.
3. Тестируем.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func AppendWithPointer(slice *[]int, val int) {
	if slice != nil {
		*slice = append(*slice, val)
	}
}

func main() {
	var nums []int
	AppendWithPointer(&nums, 100)
	AppendWithPointer(&nums, 200)

	fmt.Printf("nums: %v (len=%d, cap=%d)\n", nums, len(nums), cap(nums))
}
```

**`Терминал`**

```bash
go run main.go
# nums: [100 200] (len=2, cap=2)
```
