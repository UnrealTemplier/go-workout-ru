# Удвоение числа по указателю DoublePtr(n *int)

## Условие

**Передача по указателю**: Перепиши функцию как `DoublePtr(n *int)` и умножь `*n` на 2. Передай адрес переменной. Проверь, что оригинал изменился.

## Теория

Базовая мутация примитива через разыменование.

## Решение по шагам

1. Пишем `DoublePtr(n *int)`.
2. Выполняем `*n *= 2`.
3. Тестируем в `main()`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func DoublePtr(n *int) {
	if n != nil {
		*n *= 2
	}
}

func main() {
	val := 21
	fmt.Printf("До DoublePtr:    %d\n", val)

	DoublePtr(&val)

	fmt.Printf("После DoublePtr: %d\n", val)
}
```

**`Терминал`**

```bash
go run main.go
# До DoublePtr:    21
# После DoublePtr: 42
```

## Под капотом

Инструкция `SHLQ $1, (AX)` (битовый сдвиг влево на 1 для быстрого умножения на 2).

## Подводные камни

- Забыть проверку `n != nil`.

## На собеседовании

**Вопрос с собеседования:** «Как оптимизатор Go компилирует умножение на степени двойки?»
**Ответ:** Заменяет `MULQ` на быструю инструкцию битового сдвига `SHLQ`.
