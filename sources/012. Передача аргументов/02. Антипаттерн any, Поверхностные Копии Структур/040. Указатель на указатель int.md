# Указатель на указатель **int: цепочка адресов x -> p -> pp и изменение **pp

## Условие

Напиши функцию `PointerToPointer()`. Создай `x := 10`, `p := &x`, `pp := &p`. Измени `x` через `**pp`. Объясни, зачем нужны указатели на указатели.

## Теория

Косвенная модификация через два уровня указателей.

## Решение по шагам

1. Создаем `x := 10`.
2. Создаем `p := &x` и `pp := &p`.
3. Изменяем `**pp = 777`.
4. Печатаем значение `x`.

## Код решения

**`main.go`**

```go
package main

import "fmt"

func PointerToPointer() {
	x := 10
	p := &x
	pp := &p

	fmt.Printf("1. Исходный x:    %d\n", x)

	**pp = 777

	fmt.Printf("2. x после **pp:  %d (адрес p: %p, адрес pp: %p)\n", x, p, pp)
}

func main() {
	PointerToPointer()
}
```

**`Терминал`**

```bash
go run main.go
# 1. Исходный x:    10
# 2. x после **pp:  777 (адрес p: 0xc000018030, адрес pp: 0xc000010048)
```

## Под капотом

Двойное разыменование через процессорные регистры.

## Подводные камни

- Разыменование `*pp` при `pp == nil`.
